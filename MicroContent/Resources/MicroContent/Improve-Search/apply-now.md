# Apply Now Applications

Source: https://rmxhelp.rentmanager.com/MicroContent/Resources/MicroContent/Improve-Search/apply-now.htm

Apply Now allows prospective tenants to submit an online application and automates the process of receiving rental applications, collecting application fees, and screening prospects. This feature greatly reduces the time it takes to convert viable prospects into rent-paying tenants.

 More Information

 This feature is licensed as part of Web Portal Suite and must be purchased separately. If you have Web Portal Suite , you can also link to Apply Now from a custom website or a Web Template Suite website. For more information, contact your sales representative at sales@rentmanager.com .

 You can design your applications in Rent Manager to suit the needs of each of your properties, and assign those applications to their associated properties. Applications can be used and customized for many types of applicants, such as tenants applying to lease an apartment or home, short-term rental guests applying to rent a campsite, or students applying to live in student housing.

 Related Preferences

 Before you can start using Apply Now applications, you must first check the Enable Apply Now option in system web preferences. For more information, refer to Tenant Web Access Apply Now General (System Web Preferences) .

 Types of Applications

 There are two kinds of application templates: Primary and Sub-Application . Primary application templates are used to collect information for the main contact for a lease, while subapplication templates are used for additional associated coapplicants such as roommates and guarantors. Applicants send subapplications to any necessary contacts to ensure that all of the information is consolidated in one place.

 You can create application templates for primary applicants and subapplicants, as well as design and customize each template. The application designer allows you to choose what fields to include or require, where to put them on the application, how to separate them into sections, and the methods by which values can be entered or selected in each field.

 Application Type
 Description

 Primary Application

 Primary applications are used to determine the main party responsible for the lease or rental agreement. This person holds primary liability for the lease and is usually the first point of contact for the landlord. The primary applicant is the person who initiates the application process and is considered the primary tenant, meaning they are responsible for fulfilling the terms of the lease, such as paying rent on time.

 In the primary application designer, you can add a section for the primary applicant to add sub-applicants, such as additional occupants or guarantors.

 Sub-Application

 Subapplications are sent to the additional applicants specified by the primary applicant who submitted the primary application. These subapplications gather the personal information from the subapplicants and can also have its own section for further subapplicants, such as guarantors for roommates.

 More Information

 If you screen your applicants, it's important to know the federal laws and regulations surrounding this process. Did you know that you must obtain authorization from each applicant to collect their consumer information? You can easily do this using Apply Now applications and setting up your application template to include an additional applicant section. Creating a sub-application allows you to collect the required signatures from each applicant, ensuring your compliance when accessing their consumer information. Creating the sub-application also offers the ability to select additional options for screening preferences and application fees for the co-applicant(s).

 Designing an Application

 The application designer, for both primary applications and sub-applications, allows you to customize your application templates so you can organize the information to best suit the needs of your business and your prospective tenants. When you design an application template, you can select which properties it is used for and what information it requests from a prospect. For more information, refer to Add a Primary Application Template and Add a Sub-Application Template .

 Warning

 If you edit an existing application template, it only affects new applications going forward and does not retroactively change applications that have already been submitted or started.

 Application templates are organized and designed using the following components:

 Components
 Description

 Major Section

 This is a main segment of the application used to divide different areas of information. They can be composed of one or more fields and/or one or more minor sections. You can have multiple major sections. At least one major section is required.

 Minor Section

 These are subsections within a major section and further divide major sections into smaller segments to further organize requested information. You can have multiple minor sections in a major section, but they are not required. Each minor section can have one or more fields.

 Field

 A specific piece of information the application is requesting from the occupant(s), such as name, date of birth, and so on. Fields can be added to major sections and minor sections.

 Additional Applicant

 This is a main segment (similar to a major section), but rather than adding fields or sub-sections, you can add lines for each type of individual applicant (such as roommate, guarantor, or spouse) that is also applying on the lease. Additionally, you can select the sub-application template that should be sent to each type of applicant.

 Establishing Application Settings

 Application templates have customizable settings that can be set to affect all templates, templates at a specific property, or one individual template. These settings allow you to control application fees, screenings, disclaimers, and whether or not a unit is automatically reserved when an application is completed. For more information, refer to Set Up Apply Now Application Settings .

 More Information

 To set up application fees, you must have a Zego ePay account. To use automatic screenings, you must have an AmRent account. Both Zego ePay and AmRent Screenings are licensed features and must be purchased separately. For more information, contact your sales representative at sales@rentmanager.com .

 Level
 Description

 System

 These settings apply to all application template at all properties by default, unless those settings are overridden on the property or template level.

 Property

 These settings override the system preferences but apply only to application templates for the selected property.

 Application Template

 These settings override the system preferences and/or property settings, but apply only to the selected application template.

 Using Apply Now Applications

 After you have set up your application templates, you can also perform the following tasks:

 Action
 Description

 Manage submitted applications

 Applications submitted by prospective tenants via Apply Now are automatically imported to Rent Manager . You may then decide to use that application to create a new (or update an existing) prospect or tenant record.

 For more information, refer to Applications (Page) .

 Set up Automated Notifications

 With automated notifications, you can send alerts to a customized list of recipients when a certain set of conditions are met. For applications, you can customize notifications to alert you when applications are fully submitted via Apply Now , or when an application has been started, but is not yet finished and submitted.

 For more information, refer to Application Submitted (Automated Notification) and Application Started, Not Completed (Automated Notification) .

 Monitor applications from your dashboard

 You can use the Recent Online Applications dashboard tile to help keep track of rental applications submitted by prospects through Apply Now and their screening status right from your Express dashboard.

 For more information, refer to Recent Online Applications (Dashboard Tile) .

 Directly send application to prospects

 Once you have created an application template and assigned it to at least one property, you can either email the prospect an application link directly from Rent Manager , or copy an application link tied to a specific property or unit that can be shared outside of Rent Manager .

 For more information, refer to Send an Online Application .

 Customize an Apply Now link

 If you wish to customize the Apply Now link that you send to prospects so that it already has certain information filled out (such as the Rent Manager location, property, or unit) so the prospect does not have to select it manually.

 For more information, refer to Create and Customize Apply Now Links .
