# Owner Prospect Details (Page)

Source: https://rmxhelp.rentmanager.com/MicroContent/Resources/MicroContent/Improve-Search/owner-prospect.htm

The Owner Prospects details page lets you view and manage general account and contact information for the currently selected owner prospect. You can also update the owner prospect's lead information, interest level, and status.

 To view an owner prospect's details page, go to   arrow_forward Owners arrow_forward General arrow_forward Owner Prospects and select an owner prospect from the list.

 The following tiles display by default. If a custom layout is applied to your details page, you might not see all of the following tiles. For more information about creating and assigning layouts, refer to My Layouts (Page) and System Layouts (Page) .

 Account

 This tile displays the Name of the owner prospect, which is used when referencing the owner prospect and for correspondence generated to the owner prospect in Rent Manager , and Display Name of the owner prospect, which displays on the Owner Prospects page.

 Comment

 This tile displays an optional comment for the owner prospect. The comment can be used in scripts for letter templates and Report Writer .

 Addresses

 This tile displays the associated addresses of the owner prospect. To view additional addresses, select one from the tabs at the top of the tile, using the arrows to view additional tabs.

 Miscellaneous

 This tile displays information about the owner prospect's email, leasing agent and application.

 Field
 Description

 Application Date

 The date when the owner prospect applied. This date can be used in letter templates scripts for your owner prospects.

 Display Color

 The color used to identify owner prospects of certain types, groups, or any other specifications you prefer. For example, different colors may indicate owner prospects with a specific lead source or interest level. The color displays as a bar to the left of the owner prospect in some areas of Rent Manager , such as the Owner Prospects page.

 Email Address

 The primary email address used to contact the owner prospect. The email subscription status displays as (active), (partially unsubscribed), or (unsubscribed).

 To view and configure the subscription status for emails associated with the owner prospect's account, click Manage Subscriptions . For more information, refer to Unsubscribe From Emails .

 Interest Level

 The owner prospect's interest level ( 0 through 10 , with 10 being the highest) in your property.

 Owner Prospect Lead Source

 The main source of information that describes how this owner prospect learned about your company. This information is reflected in the Owner Prospect Box Score report and can give you insight on what types of marketing strategies are most effective for your company.

 Sales Representative

 The user who acts as the prospect's leasing agent. Users with the option Owner Sales Rep selected on the user's details page display in this list.

 Status

 The status of the owner prospect ( Owner , Lost , or Lost-Rejected ). This status displays in the Owner Prospect Box Score report and can help track the performance of your sales representatives.

 To update the status of an owner prospect, click Change .

 Phone Numbers

 This tile tracks the contact numbers for the owner prospect organized by phone number types. The number used as the primary contact for this account is marked as Default . Additionally, if a phone number can be used for text messaging, it is marked in the T column.

 Properties

 This tile displays a list of properties owned by the owner prospect.

 Column
 Description

 Properties

 The name of the property owned by the owner prospect.

 Property Type

 The type of property ( Apartment , Single Family , Commercial , Manufactured Housing , and so on) owned by the owner prospect.

 Unit Count

 The number of units in the associated property owned by the owner prospect.

 UDFs

 User-defined fields display on this tile based on when a value was added to the UDF. The order in which the user-defined fields display may not match the order that displays in the User Defined Fields pop-up or on the User Defined Fields page. This tile displays up to six owner prospect-type UDFs with values and used to track information that Rent Manager does not track by default.

 History/Notes

 This tile displays history/note items associated with the owner prospect. History/notes let you record information that supplements or clarifies what’s entered in other fields, such as notes about phone conversations, items on a to-do list, or explanations about transactions.

 Column
 Description

 Date

 The date the history/note item was created.

 Type

 The system-generated history/note type. For example, if the history/note item is linked to a signable document sent to the owner prospect, the Signable Document type displays.

 Note

 The information to describe the history/note item (e.g., Scheduled contract negotiations ). If no text is entered, the column displays blank.
