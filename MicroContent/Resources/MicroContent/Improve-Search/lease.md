# Tenant Leases (Pop-Up)

Source: https://rmxhelp.rentmanager.com/MicroContent/Resources/MicroContent/Improve-Search/lease.htm

From a tenant's View Leases pop-up, you can add, edit, renew, and delete leases associated with a tenant. A lease can be created with or without an assigned unit.

 More Information

 This information applies to noncommercial leases. To learn more about commercial leases, refer to Add a Commercial Lease .

 When adding a lease to an existing tenant on the View Leases page, Unit is a required field, and a unit must be selected in order to add the lease.

 More Information

 Only information related to the properties to which you have access displays. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 To view a tenant's lease(s), go to arrow_forward Rental Info arrow_forward General arrow_forward Tenants and select a tenant from the list. Then on the Leases tile, click .

 To reorder the list when a tenant has multiple leases, click and drag . Changing the order of leases affects the order in which they display in the Leases tile and also affects how leases are indexed when scripting. For more information, refer to Lease Class (Script) .

 Column Descriptions

 The tenant View Leases pop up display the columns below. If the tenant multiple leases, each lease displays as a separate row.

 Column
 Description

 Property

 The property associated with the lease.

 Unit

 The unit associated the lease.

 Start Date

 The date on which the lease starts.

 End Date

 The date on which the lease ends.

 Original Date

 For leases that were renewed at least once, the Original Date displays the date on which the original lease started. If a tenant is still on their first lease, the column displays the same date as the Start Date .
