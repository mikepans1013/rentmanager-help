# Recurring Charges

Source: https://rmxhelp.rentmanager.com/MicroContent/Resources/MicroContent/Improve-Search/recurring-charges.htm

Any charge that occurs regularly can be entered as a recurring charge to save time. For example, a monthly rent charge can be set as a recurring rent charge type posted each month to a tenant.

 Recurring charges can be set at the property, unit type, unit, and tenant levels. Tenants automatically inherit charges set for the property, unit type, or unit linked to their tenant account. For example, all tenants of a specific unit type would inherit a utility fee at the unit type level. However, recurring charges set at the tenant level only apply to that tenant account.

 Recurring Charge
 Description

 Property

 Property-level recurring charges are posted to all tenants at a particular property, allowing you to set up a single recurring charge at the property level rather than setting up a recurring charge on each individual tenant account.

 Unit Type

 Unit type-level recurring charges are entered as a charge that always applies to units of that specific unit type, and are posted to tenants occupying units associated with that unit type.

 Unit

 Unit-level recurring charges are entered as a charge that always applies to that specific unit, no matter who occupies the unit.

 Tenant

 Tenant level recurring charges apply only to the specific tenant account they are assigned to.
