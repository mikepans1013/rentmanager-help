# Tag

Source: https://rmxhelp.rentmanager.com/MicroContent/Resources/MicroContent/Improve-Search/tag.htm

In Express users can @mention other users with the @ tag on a history note item. Once @mentioned, the program sends a notification email with the note's contents to the tagged user, along with a link to the history note in Express .

 Additionally, you can add a contact image and title on the User page, which displays in the users list when an individual is @mentioned in a history note.
