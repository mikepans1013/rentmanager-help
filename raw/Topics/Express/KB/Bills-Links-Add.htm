Add Links to a Bill

To ensure accurate expense tracking, you can easily add links to work orders or purchase orders (POs) directly to your existing bills in Rent Manager. Additionally, you can link work orders to Smart Bills during the review process, and you can also follow the steps below to add these links retroactively to Smart Bills which have already been created.

More Information

Smart Bills is a licensed feature and must be purchased separately. For more information, contact your sales representative at sales@rentmanager.com.

Link a Work Order

You can link a work order from an existing issue to a bill or Smart Bill. The steps and privileges required to complete this action vary depending on whether you are adding to a standard bill or a Smart Bill.

Bills

Related Privileges

Group Privilege Column
Accounting View bill register Enabled
Payables Bills View, Edit
Service Manager Issues View, Edit

For more information, refer to Control User Access.

To link a work order to an existing bill, do the following:

  1. Go to arrow_forward Payables arrow_forward Bills arrow_forward Bills and select a bill.
    The bill's details page displays.

  2. In the Work Order Items tile, click Link Work Order Items.
    The Link Work Order Items pop-up displays.

  3. In the Select Issue section, use the available filters to locate the work order you wish to link to the bill. The list populates with issues that match your filter criteria.

    Filter Description

    Assigned To

    Include issues currently assigned to the selected Rent Manager user. To show all tickets regardless of assigned user, select Any.

    Category

    Include issues associated with the selected issue category, such as Maintenance. To show all tickets regardless of category, select Any.

    Search

    Enter a keyword or number, such as an issue title or ID number, to display only issues that meet this criteria.

    Show Closed Issues

    If checked, any issues that have been resolved and marked as closed are included in the list.

    Status

    Include issues that are currently in the selected issue status, such as <New>. To show all tickets regardless of status, select Any.

    Vendor

    Include issues associated with the selected vendor. To show all tickets regardless of vendor, select Any.

    By default, this field populates with the vendor associated with the bill. This is because the bill and issue cannot be assigned to different vendors.

  4. In the list below, click to the left of the issue that you wish to link to the bill.

  5. Click Next.
    The next page displays bill attachments and information about the selected issue, including work order items associated with the issue.

  6. Review and edit or add work order items on the selected issue. Each option is described below.

    Section Description

    Link Existing Work Order Items

    Select each work order item you wish to link to the bill.

    This section displays only if the selected issue has work order items already added.

    Link New Work Order Items

    If you wish to add additional work order items to the issue and link them to the bill, enter that information in the available fields. To add additional work order items, click Add Item. For more information, refer to Add a Work Order.

  7. Click Save.
    The issue work order is linked to the bill, and any edits or additions made to the work order items are updated on the issue.

Link a Purchase Order

Related Privileges

Group Privilege Column
Accounting View bill register Enabled
Payables Bills View, Edit

For more information, refer to Control User Access.

You can link an existing purchase order (PO) to a bill to track authorized purchases that are related to the bill.

To link a PO to an existing bill, do the following:

  1. Go to arrow_forward Payables arrow_forward Bills arrow_forward Bills and select a bill.
    The bill's details page displays.

  2. In the Purchase Order tile, click Link Existing Purchase Order.
    The Link Existing PO pop-up displays.

  3. Use the available filters to locate the PO you wish to link to the bill. The list populates with POs that match your filter criteria.

    Filter Description

    Create Date

    Enter a date range to display only POs that were added to Rent Manager on or between the set start and end dates.

    Search

    Enter a keyword or number, such as a PO title or ID number, to display only POs that meet this criteria.

    Vendor

    Include POs associated with the selected vendor.

    By default, this field populates with the vendor associated with the bill.

  4. In the list below, click to the left of the PO that you wish to link to the bill.

  5. Click Link.
    The PO is linked to the bill.

    Related Privileges

    If you are prompted to adjust the amount to match the PO's total to the bills, enter the correct quantity for each line item in the Billing Qty column, then click Link again. To perform this action, the privilege listed below is required.

    Group Privilege Column
    POs/Estimates Purchase orders View, Edit

    For more information, refer to Control User Access.
