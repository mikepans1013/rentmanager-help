Add an Owner Report Batch

A report batch is a collection of reports that can be generated simultaneously to save time and increase efficiency. The report options of each report within the batch can be configured to generate the report automatically with little to no input from the user. Report batches can also be scheduled to generate at a certain time and date, then emailed to the specified addresses.

Setting up report batches for owners allows you generate reports that are tailored to those owners and their properties.

Related Privileges

Group Privilege Column
Letter/Email Templates/Reports/Packets Run reports Enabled

Additionally, on the Reports tab, you must have access to the corresponding reports you wish to add to the batch.

For more information, refer to Control User Access.

Step 1: Add a Report Batch

To create a new owner report batch, do the following:

  1. Go to arrow_forward Manage Batches and click Add Batch.

  2. In the Included Reports section, click Add.

  3. Search or navigate to each report you wish to include, then click for the report to add it to the Reports to Add section. You can add the same report multiple times if you need to send different versions of a single report in the same batch.

  4. When all the desired reports are added to the Reports to Add section, click Add.
    The reports are added in the order selected to the Report Batch page.

Step 2: Customize Order and Report Options

To change the order of reports and establish the options used when generating the batch, do the following:

  1. In the Included Reports section, you can change the order in which the reports generate by clicking and dragging next to each report.

  2. Select each report in the list to configure the report options.

    More Information

    Selecting singular dates (MM/DD/YYYY) causes the report to run with the exact same date(s) each time it is run. To ensure the report date updates based on the day the batch is run, use any of the options listed under Use relative date.

  3. To prompt users for a value when generating this batch, toggle on the Ask option. If enabled, the report batch cannot be automated.

  4. Once the report options for all reports are configured, in the Batch Options section, enter a unique Name for this report batch.

  5. To enable this report to display on arrow_forward Report Batches, select Show in Reports Menu.

  6. Click Save.
    The new report batch is added to the Report Batches page.

Step 3: Assign the Owner's Default Report Batch

Related Privileges

Group Privilege Column
Owners Owners View, Edit

For more information, refer to Control User Access.

To assign a default report batch for an owner, do the following:

  1. Go to arrow_forward Owners arrow_forward General arrow_forward Owners and select an owner.
    The owner's details page displays.

  2. On the action bar to the right, select arrow_forward Owner Reports.
    The Owner Reports pop-up displays.

  3. In the Owner Specific Report Settings section's Default Batch field, select the report batch you created from the drop-down list.

    Related Preferences

    If there is an owner report batch that you would like to be the system-wide default, you can set it as the Default owner report batch in system preferences, then select <System Default> for the owner(s). For more information, refer to Owner Report Settings (System Preferences).

  4. If the owner report batch includes at least one owner statement, in the Owner Statement Comment field, enter additional information to display on the statement(s).

  5. Click Save.
    The owner's default report batch is saved.

Step 4: Run the Owner Report Batch

Once the default batch is saved, you can generate it directly from the Owner Reports pop-up, or from the owner account's action bar by selecting arrow_forward Owner Report Batch. For more information, refer to Run an Owner Report Batch.
