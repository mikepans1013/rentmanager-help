Customize Service Issue Options

When you create or edit an issue in Rent Manager, you can enter values into issue-type user-defined fields (UDFs), set the category, status, and priority of the issue, and associate the issue with a workflow project and/or job. Although you can complete the issue add wizard without this information, setting up these tools before adding your issue helps streamline the issue creation process.

Issue User-Defined Fields

Related Privileges

Group Privilege Column
User Defined Fields User defined fields Add, View

For more information, refer to Control User Access.

User-defined fields (UDFs) are custom fields you create to track data that Rent Manager does not track by default. Issue-type UDFs are used specifically to track additional information on service issues. For more information on creating issue-type UDFs, refer to Add a User Defined Field.

Issue Categories

Related Privileges

Group Privilege Column
Service Manager List manager View, Edit

For more information, refer to Control User Access.

Issue categories are classifications that help sort and track certain types of issues, such as the specialization required to complete the issue or whether the work is to be done indoors or outdoors. They also aid in filters and saved issue lists. For more information, refer to Add an Issue Category.

Issue Statuses

Related Privileges

Group Privilege Column
Service Manager List manager View, Edit

For more information, refer to Control User Access.

Issue statuses are conditions that describe the current progress of an issue, such as Work in Progress or Resolved. Issues can also be sorted by status in filters and saved issue lists, which helps identify the progress of open issues at a glance. For more information, refer to Add an Issue Status.

Issue Priorities

Related Privileges

Group Privilege Column
Service Manager List manager View, Edit

For more information, refer to Control User Access.

Issue priorities are levels that you create to describe the urgency with which a service issue needs to be completed, such as Critical or Low. Issues can be sorted by priority in filters and saved issue lists, which can help you focus on the most urgent open issues over those that are less pressing. For more information, refer to Add an Issue Priority.

Jobs

Related Privileges

Group Privilege Column
Accounting Jobs Add, View

For more information, refer to Control User Access.

The job costing feature makes it possible to track transactions associated with specific jobs completed by your business, such as the construction of a parking garage. By linking an issue to a job, you can include any work order payments as part of the job transaction history. For more information on creating jobs, refer to Jobs (Page).

Related Preferences

In order to use the job costing tool in Rent Manager, Enable job costing must be checked in system preferences. For more information, refer to General Options (System Preferences).

Inventory Items

Related Privileges

Group Privilege Column
Sales/Invoicing Items Add, View

For more information, refer to Control User Access.

Inventory items are products or services from your company that require payment, such as light bulbs or employee labor. These items must be added if you wish to create a work order for an issue, which allows you to charge the appropriate amount for the item and track the quantity of physical products. Those charges can then be invoiced to a tenant or billed to the property. For more information, refer to Add an Inventory Item.
