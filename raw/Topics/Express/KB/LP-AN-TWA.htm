Automated Notifications for Tenant Web Access (TWA)

Automated notifications allow you to send alerts to a customizable list of recipients when a certain set of conditions are met to help streamline your workflows and processes. These notifications can be customized using plain text and scripting for personalized text and/or email messages.

There are many options for automated notifications regarding Tenant Web Access (TWA) to inform you of payments, estimates, surveys/polls, issues, and signable documents. These notifications are described in the table below.

Attention

Ensure the table is the full and current list of automated notifications related to Tenant Web Access.

Notification Description

Changed Contact Info via TWA

Informs users or external recipients after a tenant changes their contact information through TWA.

Documents Published to TWA

Informs tenants after a signable document is published to their TWA portal.

Issue Created via TWA

Informs users or external recipients when a new issue is submitted by tenants in TWA so they can follow up.

Late Payment via TWA

Informs users—such as the property manager —when tenants submit a late payment via TWA.

Payment Made via TWA

Informs users, tenants, or owners when tenants submit a payment through TWA, either manually or via AutoPay.

Prospect Signable Document Aging

Informs prospects when a signable document has been waiting on their signature for a set amount of time.

Survey (Poll) Closing

Informs users or tenants when a survey/poll posted to TWA is a certain number of days away from the End Date.

Tenant Estimate Aging

Informs users (e.g., sales representatives) or tenants when a tenant estimate is a certain number of days old and has not expired or been set to a status of Approved or Rejected.

Tenant Estimate Expiring

Informs users (e.g., sales representatives) or tenants when a tenant estimate is a certain number of days away from its expiration date.

Tenant Signable Document Aging

Informs users or external recipients when a signable document has been waiting on a tenant or prospect's signature for a set amount of time.

Tenant Turned Auto Pay via TWA OFF

Informs users (e.g., property manager) when tenants disable their AutoPay schedule in TWA.

Tenant Turned Auto Pay via TWA ON

Informs users (e.g., property manager) when tenants create or enable an AutoPay schedule in TWA.

TWA Message Board Approval Needed

Informs users (e.g., property manager) when a tenant makes a new post on the TWA message board.

TWA Webuser Locked Out

Informs users (e.g., property manager) when a tenant's TWA web user account is locked out due to exceeding the number of incorrect password attempts established in system web preferences.

Web Chat Offline Message

Informs users (e.g., property manager) when a web chat message is received while no users are logged into the queue to answer the message.
