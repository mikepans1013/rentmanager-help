Send an Online Application

If you use Apply Now, you can track and send electronic applications for prospects. After you create an application template and assign it to at least one property, you can email an application link directly from Rent Manager via the prospect account or via the details page for the property or unit the prospect is interested in. You can also copy an application link and share it outside of Rent Manager. If the prospect does not already have an account, one is automatically created for them when they submit a completed application.

More Information

This feature is licensed and must be purchased separately. For more information, contact your sales representative at sales@rentmanager.com.

Related Preferences

Before you can send applications, you need to enable Apply Now in system web preferences and establish the properties/units you plan to send applications for. For more information, refer to Tenant Web Access Apply Now General (System Web Preferences) and Tenant Web Access Apply Now Included Units (System Web Preferences).

Option 1: Send from Prospect Details

Related Privileges

Group Privilege Column
Tenants/Prospects Prospects View
Application View

For more information, refer to Control User Access.

To send an application directly from a prospect's account, do the following:

  1. Go to arrow_forward Rental Info arrow_forward General arrow_forward Prospects and select a prospect.
    The Prospect details page displays.

  2. On the action bar to the right, select arrow_forward Send Online Application.

  3. In the Application Information section, select the following options:

    Field Description

    Property

    The property that the prospect wants to apply for. The selected property must have an application template assigned to it. For more information, refer to Set Up Apply Now Application Settings.

    More Information

    This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property.

    Unit/Unit Type

    The unit or kind of unit the prospect wishes to apply for. If a unit has already been reserved for the prospect in the Reservation/Expected Lease Information section, the reserved Unit and the Property are automatically populated in the first two fields.

    Application template

    The custom electronic application that the prospect needs to complete. Only application templates assigned to the property display.

  4. In the Applicant Section section, check the box next to the primary applicant's name, then enter information in the following columns:

    Column Description

    Name

    The name of the applicant. This field is populated automatically for the primary applicant and cannot be edited.

    Email Address

    The email address the prospect's application should be sent to. For prospects who already have an account, this field automatically populates with the prospect's contact information.

    Applicant Type

    The type of application the prospect needs to complete (e.g., Primary Applicant, Co-Applicant, Guarantor).

    If the selected Application template does not have an Additional Applicant section, only Primary Applicant displays. If the template does have an Additional Applicant section, only the application type(s) set up for the sub-application(s) in that section display.

    More Information

    The Fee Amount, Other Charges, Screening Report and Income Verification fields are populated automatically and cannot be edited. Depending on your Rent Manager setup, the information is retrieved from system web preferences, the Property Application Settings pop-up, or the Application Template Settings pop-up. For more information, refer to Tenant Web Access Apply Now ePay (System Web Preferences) and Property Application Settings (Pop-Up).

  5. If needed, click Add Item and enter information for additional applicants in the columns.

  6. Click Send.
    The Apply Now link is sent to the selected applicant(s).

Option 2: Email Apply Now Link for a Specific Property/Unit

Related Privileges

Group Privilege Column
System Compose Email Enabled
Properties/Units Properties View
Units View

For more information, refer to Control User Access.

To email an Apply Now link for a specific property or unit to a prospect, do the following:

  1. Go to arrow_forward Rental Info arrow_forward General arrow_forward Properties or arrow_forward Rental Info arrow_forward General arrow_forward Units and select the desired property or unit.
    The entity's details page displays.

  2. On the action bar on the right, click arrow_forward Email Apply Now Link.
    The Compose Email pop-up displays.

  3. In the To... field, enter the email address(es) to send the link to.

  4. Optionally, enter additional details in the email. For more information, refer to Send an Email.

  5. Click Send.
    The Apply Now link for the selected property or unit is sent to the recipient(s).

Option 3: Copy Apply Now Link for a Specific Property/Unit

Related Privileges

Group Privilege Column
Properties/Units Properties View
Units View

For more information, refer to Control User Access.

To copy an Apply Now link and send it outside of Rent Manager, do the following:

  1. Go to arrow_forward Rental Info arrow_forward General arrow_forward Properties or arrow_forward Rental Info arrow_forward General arrow_forward Units and select the desired property or unit.
    The entity's details page displays.

  2. On the action bar on the right, click arrow_forward Copy Apply Now Link.
    The property- or unit-specific Apply Now link is copied to your clipboard.

  3. Paste the link in the desired location, such an email client or word processor.
    Once the prospect receives the link, they can proceed with the Apply Now application process.
