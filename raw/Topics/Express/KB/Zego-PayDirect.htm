Zego PayDirect

In addition to collecting payments, you can utilize Zego ePay to pay bills and distribute funds to owners and vendors by using PayDirect. PayDirect is a service provided by Zego that allows you to make outgoing payments for various property management expenses.

Warning

PayDirect cannot be used to process all owner or vendor payments. The service is strictly intended for real estate-related transactions (e.g., landscaping, carpet cleaning, painting, water damage) and all outgoing payments must be related to the properties you manage. For more information on usage restrictions, refer to What is PayDirect? on Zego's website.

More Information

ePay is a licensed feature by Zego. To use Zego ePay, you must set up an account with Zego and enter that information into Rent Manager. Once you have ePay enabled in Rent Manager, you also need the PayDirect feature enabled in your Zego account to process vendor and owner transactions. For more information, contact sales@rentmanager.com.

Once you have signed up for PayDirect with Zego, you can begin using it for owner and vendor payments in Rent Manager by establishing related system preferences and account-specific settings.

Owner ePay

To use PayDirect for outbound owner ePay payments, you must first select Enable ePay for Owners in system preferences and establish ePay bank IDs. For more information, refer to Owner ePay (System Preferences).

Once enabled, you need to establish owner-specific ePay settings for distributions. You can also make ePay the default method for owner payments or select it when processing manual owner payments.

Option Description

Owner ePay settings

You need to acquire an owner's bank account information before you can make payments with ePay. Then, on their account's ePay Settings pop-up, select Turn on pay owner account on file and enter that information in the corresponding fields. For more information, refer to Owner ePay Settings (Pop-Up).

Owner payment method

If owners should always receive distributions using ePay, you can go to their details page and, in the Miscellaneous tile's Payment Method field, select ePay from the drop-down list. For more information, refer to Owner Details (Page).

Owner distributions and payments

When processing owner payments, you can choose to use ePay, even if that is not the owner's default payment method as long, as that owner has ePay settings established. For more information, refer to Pay Owners and Manual Owner Pay.

Owner bills

When creating bills and processing bill payments, you can choose to use ePay even if that is not the owner's default payment method as long as that owner has ePay settings established. For more information, refer to Add a One-Time Vendor/Owner Bill and Pay Bills.

Vendor ePay

To use PayDirect for outbound vendor ePay payments, you must first select Enable ePay for Vendors in system preferences and establish ePay bank IDs. For more information, refer to Vendor ePay (System Preferences).

Once enabled, you need to establish vendor-specific ePay settings for payments. You can also make ePay the default method for vendor payments or select it when paying bills.

Option Description

Vendor ePay settings

You need to acquire a vendor's bank account information before you can make payments with ePay. Then, on their account's ePay Settings pop-up, select Turn on account on file and enter that information in the corresponding fields. For more information, refer to Vendor ePay Settings (Pop-Up).

Vendor payment method

If vendors should always receive payments using ePay, you can go to their details page and, in the Bill Settings tile's Payment Method field, select ePay from the drop-down list. For more information, refer to Vendor Details (Page).

Vendor bills

When creating bills and processing bill payments, you can choose to use ePay, even if that is not the vendor's default payment method, as long as that vendor has ePay settings established. For more information, refer to Add a One-Time Vendor/Owner Bill and Pay Bills.
