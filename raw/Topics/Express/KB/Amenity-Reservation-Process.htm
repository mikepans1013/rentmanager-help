Process an Amenity Reservation

If your property has amenities that your tenants can reserve, such as a clubhouse or car charging stations, the reservable amenities tool in Rent Manager allows you to establish an internal calendar to keep track of those reservations. You can also allow your tenants to book a reservation in Tenant Web Access (TWA), then have a user approve, deny, or cancel the request from within Rent Manager.

Warning

It is recommended that you cancel or deny requests to preserve historical data and properly communicate with tenants; typically, amenity reservation requests should be deleted only if they were created in error. Deleting an amenity reservation request is permanent and cannot be undone. Additionally, the record of the request is removed and tenants cannot be automatically notified that their request was deleted.

Related Privileges

Group Privilege Column
Setup Manage Amenity Reservations Enabled

For more information, refer to Control User Access.

To process amenity reservation requests, go to arrow_forward Services arrow_forward Community arrow_forward Amenity Reservations.

Approve an Amenity Reservation

To approve a tenant's amenity reservation request, do the following:

  1. On the request you want to approve, select arrow_forward Approve.
    The Approve reservable amenity reservation request pop-up displays.

  2. Click Yes.
    The amenity reservation request's status is updated to Approved and an email is sent to notify the tenant that their request was approved.

Cancel an Amenity Reservation

If an amenity reservation needs to be canceled, do the following:

  1. Go to arrow_forward Services arrow_forward Community arrow_forward Amenity Reservations.
    The Amenity Reservation Requests page displays.

  2. On the request you want to cancel, select arrow_forward Cancel.
    The Cancel Reservation Request pop-up displays.

  3. In the Reason field, enter an explanation for the cancellation (e.g., Emergency maintenance).

  4. Click OK.
    The amenity reservation request's status is updated to Canceled.

    More Information

    If you want to automatically notify the tenant that their reservation was canceled, create a tenant notification setup for the Amenity Reservation Canceled automated notification. For more information, refer to Amenity Reservation Canceled (Automated Notification).

Deny an Amenity Reservation

To deny a tenant's amenity reservation request, do the following:

  1. Go to arrow_forward Services arrow_forward Community arrow_forward Amenity Reservations.
    The Amenity Reservation Requests page displays.

  2. On the request you want to deny, select arrow_forward Deny.
    The Deny Reservation Request pop-up displays.

  3. In the Reason field, enter an explanation for the denial (e.g., Overdue charges on account).

  4. Click OK.
    The amenity reservation request's status is updated to Denied.

    More Information

    If you want to automatically notify the tenant that their reservation was denied, create a tenant notification setup for the Amenity Reservation Denied automated notification. For more information, refer to Amenity Reservation Denied (Automated Notification).
