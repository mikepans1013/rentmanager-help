Add a One-Time Charge

Handling tenant and prospect transactions is an important part of your business, so Rent Manager offers you a number of ways to add charges to their accounts. To address transactions that occur only once, Rent Manager allows you to add one-time charges to your tenant and prospect accounts any time the need arises. One-time charges can be added to one account, multiple accounts at the same time, or accounts with multiple leases.

Related Privileges

Group Privilege Column
Tenants/Prospects Tenants View
Receivables Tenant transactions Add

For more information, refer to Control User Access.

Option 1: Add a One-Time Charge to a Single Account

You may need to charge a tenant once to cover damage they caused in their unit or a prospect account to cover a processing fee that wasn't charged initially. Since that is not a charge that is recurring on a scheduled basis, adding a one-time charge is the best way to address this.

To add a new one-time charge to an account:

  1. Go to the corresponding page below and select the tenant or prospect account:

    Entity Type Description

    Tenant

     arrow_forward Rental Info arrow_forward General arrow_forward Tenants and select a tenant account.

    Prospect

     arrow_forward Rental Info arrow_forward General arrow_forward Prospects and select a prospect account.

    The details page for the tenant or prospect displays.

  2. On the Transactions tile, click Add Charge.
    The Transaction Detail pop-up displays.

  3. Enter the desired information about the charge.

    Field Description

    Charge Type

    The charge type to use when this charge is posted. The posted charge impacts the general ledger (GL) account linked to the charge type.

    Unit

    The unit associated with the one-time charge.

    Date

    The date on which this charge is due.

    Amount

    The total desired one-time charge amount.

    To automatically prorate the charge based on the charge date, enter the full amount of the charge and then click Prorate. For more information, refer to Add a Prorated Charge.

    Comment

    A descriptive phrase or note regarding the charge. If entered, the comment displays on the account's View Transactions page.

    Reference #

    A unique number or phrase to help further identify the charge. If entered, the reference displays on the account's View Transitions page.

  4. Click Save.
    The charge is added to the View Transactions page.

Option 2: Add a One-Time Charge to Multiple Accounts

In other cases, you may need to add the same one-time charge to multiple accounts. For example, if multiple accounts cause damage to a common area at your property, you can easily add a one-time charge to each account involved.

To add a new one-time charge to multiple accounts, do the following:

  1. Go to the corresponding page below and select the tenant or prospect account:

    Entity Type Description

    Tenant

     arrow_forward Rental Info arrow_forward General arrow_forward Tenants and select a tenant account.

    Prospect

     arrow_forward Rental Info arrow_forward General arrow_forward Prospects and select a prospect account.

    The Tenants or Prospects page displays.

  2. At the top left of the page, click Bulk Actions arrow_forward Add Charge.
    The option to select accounts displays.

  3. Select each account receiving the one-time charge. When finished, click Add Charge.
    The Transaction Details pop-up displays.

  4. Enter the desired information about the charge.

    Field Description

    Charge Type

    The charge type to use when this charge is posted. The posted charge impacts the general ledger (GL) account linked to the charge type.

    Date

    The date on which this charge is due.

    Amount

    The total desired one-time charge amount.

    To automatically prorate the charge based on the charge date, enter the full amount of the charge and then click Prorate.

    Comment

    A descriptive phrase or note regarding the charge. If entered, the comment displays on the account's View Transactions page.

    Reference #

    A unique number or phrase to help further identify the charge. If entered, the reference displays on the account's View Transactions page.

  5. Click Save.
    The charge is added to the View Transactions page for each account receiving the charge.

Option 3: Add a One-Time Charge to a Tenant with Multiple Leases

You may have tenants that hold more than one lease with your company. For example, if you have tenant that has a lease for both their unit and their parking space and you want to charge the tenant once for damage done to their unit, you can add the charge to just the lease connected to the unit. This is an important distinction because adding the charge to the wrong lease may result in confusion for your tenant about the charge for which they are responsible.

To add a charge to one tenant with multiple leases, do the following:

  1. Go to  arrow_forward Rental Info arrow_forward Tenants.
    The Tenants page displays.

  2. Select the tenant who is receiving the charge.
    The Tenant details page displays.

  3. Click Add Charge.
    The Transaction Detail pop-up displays.

  4. From the Unit drop-down menu, select the unit to be linked to the one-time charge.

  5. Enter the desired information about the charge.

    Field Description

    Charge Type

    The charge type to use when this charge is posted. The posted charge expenses the general ledger (GL) account linked to the charge type.

    Unit

    The unit associated with the one-time charge.

    Date

    The date on which this charge is due.

    Amount

    The total desired one-time charge amount.

    To automatically prorate the charge based on the charge date, enter the full amount of the charge and then click Prorate.

    Comment

    A descriptive phrase or note regarding the charge. If entered, the comment displays on the tenant's View Transactions page.

    Reference #

    A unique number or phrase to help further identify the charge. If entered, the reference displays on the tenant's View Transactions page.

  6. Click Save.
    The charge is added to the View Transactions page.
