Short Term Rentals (STR)

Short-term rental (STR) portfolios can contain a wide variety of housing, such as campgrounds, RV parks, hotels, vacation rentals, and hostels. With Rent Manager's short-term rental (STR) tools, you can set up properties to accommodate different types of amenities and guest experiences. Easily view the property's availability, make a reservation, and check in guests.

These differ from traditional properties in Rent Manager, as guests do not sign leases to rent spaces at these properties but instead use reservations that require a check-in, and depart after a few days or weeks. These guests are added through a specific STR workflow but after creation are tracked as prospects and tenants in your database. Units at these properties can have one guest check out and another check in on the same day. Rates are based on the length of the stay, or long-term rentals with recurring charges can be set up as well.

System Preferences

Before taking short-term rental reservations, you must establish the STR settings in system preferences. You can set Rent Manager to create guest accounts as tenants or prospects, when to date charges for reservations, and which unit types to include for STR types. For more information, refer to Short Term Rental (STR) Reservations (System Preferences).

STR Properties

To set an existing property up for short-term rentals, on the property's details page, you must set its Property Type to either Short Term Rental or RV/Campground. To create a new short term rental property, refer to Add a Short Term Rental Property.

After creating your properties, you just need to add units for the properties for each reservable space, such as each campsite, room, or bunk. For more information, refer to Add a Unit.

The property type to select for the property depends on your business needs for that location. The table below describes the primary capabilities of the two STR property types.

Type Description

RV/Campground

This property type is best used for campgrounds or RV parks. Units added to the property allow you to establish the size of the space, amp service(s) that can be accommodated, and if the space allows for pull-through parking for each unit. Additionally, you can set up rate schedules for the property and allow guests to submit reservations via the STR Online Booking portal. For more information, refer to STR Online Booking (Pop-Up) or STR Rate Schedules (Pop-Up).

Short Term Rental

This property type is best used for other short-term rentals such as vacation homes, hotels, or hostels. This property type works similarly to most other property types (such as Apartment, Single Family, and so on) and uses internet listing service (ILS) sites for marketing, but still counts as an STR property for reservations, reporting, and other Rent Manager functions.

STR Reservations

After you set up your STR properties and units, you can start accepting guest reservations. When guests arrive for their reservations, you can check them in using the Check-ins page and monitor them using the STR reservations calendar. Additionally, you can use various reports, automated notifications, and dashboard titles to track your guest reservations.

Manage STR Reservations

The table below provides a list of tools in Rent Manager you can use for managing your STR guest reservations.

Page Description

Check-ins

The Check-ins page allows you to manage all of the STR guest reservations at a property for a specified date, and allows you to see all the guests arriving at your property on the current day. This tool is particularly useful for receptionists at the property so they can easily check in each guest as they arrive. For more information, refer to STR Check-Ins (Page).

STR Reservations

The STR Reservations page displays a calendar of all your guest reservations. Additionally, it allows you to find units that match your guests' desired travel dates and amenities, then make and edit reservations for those units. For more information, refer to STR Reservations (Page).

Find Reservation

The Find Reservation page allows you to quickly find specific reservations by searching the tenant name or email, property short name, unit name, or the reservation confirmation number.

Track STR Reservations

The following STR reports allow you to generate information about your guest reservations:

Report Description

Arrivals/Departures (Report)

View contact information and reserved units for guests arriving and departing during a specified date range.

Guest Listing (Report)

View contact information and reserved units for current guests.

Vehicle Listing (Report)

View vehicle details and contact information for current guests.

Short Term Rental (STR) Unit Occupancy Trend (Report)

Show the percentage of time a unit has been occupied during the specified date range.

Short Term Rental (STR) Property Occupancy Trend (Report)

View the occupancy percentage of the property over a specified period of time.

Short Term Rental Vacancy (Report)

Show what units are vacant at a property on a specified date.

The following STR dashboard tiles allow you to monitor at-a-glance information about your guest reservations from the Dashboard page:

Dashboard Tile Description

Guest Arrival List (Dashboard Tile)

This dashboard tile helps track scheduled or expected arrivals and departures for reservations at STR properties occurring within a set number of days. Arrival dates that include an asterisk indicate that the guest was already checked in.

STR Reservations Payment Due (Dashboard Tile)

This dashboard tile displays unpaid charges for STR reservations for tenants and prospects. This tile can be filtered to include STR reservation payments based on how many days in the future the payment is due, while overdue payments are always displayed.

STR Rate Schedules

For properties with a Property Type of RV/Campground, you must create the rate schedules for the properties. STR rate schedules allow you to maintain rates used to charge for reservations, providing you with an easy way to calculate STR rates for a complex variety of reservation fees, seasonal fees, pet fees, and so on. STR rate schedules define each rate within the schedule on a property and automatically apply to reservations that fit the requirements set up on the schedule. It also allows for multiple schedules per property, as you may have one schedule for in-season rentals, another for off-season rentals, and anything in between. For more information, refer to Add an STR Rate Schedule.

STR Online Booking

After successfully establishing your short-term rentals and rate schedules in Rent Manager, you can choose to allow guests to make their own reservations online at properties with a Property Type of RV/Campground. The STR Online Booking feature enables your RV/campground sites to be reservable online via the STR Online Booking portal. Guests are taken to your site via a URL that is generated when you enable online booking in system web preferences. STR properties with the property type Short Term Rental are not available for online booking licensing.

To start using the STR Online Booking portal, you must configure the following settings in system web preferences:

Preference Description

RV/Campground Online Booking General (System Web Preferences)

These preferences allow you to select which properties are enabled for STR Online Booking as well as define your payment booking policy. When a property is selected, the online booking URL becomes active.

RV/Campground Online Booking Guest Info (System Web Preferences)

These preferences allow you to require guests to provide additional information when they are completing the guest information portion of their STR booking, such as vehicle information.

STR Online Booking RV/Campground Settings (System Web Preferences)

These preferences allow you to establish what ePay payment types and convenience types are used for guest payments made via the STR Online Booking portal.

RV/Campground Online Booking ePay (System Web Preferences)

These preferences allow you to establish reservation limits and messages for the STR Online Booking portal.

More Information

These system web preferences can be overridden on the property level for properties that follow a different configuration. For more information, refer to Property STR Settings (Pop-Up).

After setting up Online Booking, you can configure the information that displays on the portal for each STR property on the property's Marketing Setup page. For more information, refer to STR Property Marketing Setup (Pop-Up).
