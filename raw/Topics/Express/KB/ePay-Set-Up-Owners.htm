Set Up ePay for Owners

Zego ePay automatically transfers money—either from ePay payments you make to others or that you receive from others in the real world—and deposits it into the actual bank(s).

Zego ePay can be used for owners who want to electronically do the following:

  • Receive owner contributions by debiting the owner's ACH, credit card, or debit card account and depositing those funds into your bank account.

  • Pay out owner distributions by crediting your bank account and depositing those funds into an owner's bank account.

More Information

ePay is a licensed feature by Zego. To use Zego ePay, you must set up an account with Zego and enter that information into Rent Manager. In addition, to use ePay for vendor and owner transactions, you also need the PayDirect feature enabled in your Zego account. For more information, contact sales@rentmanager.com.

Step 1: Enable System Preferences

In order to begin using ePay processing for owners, the following system preferences must be enabled.

Related Privileges

Group Privilege Column
System System Preferences View, Edit
ePay Access ePay Settings Enabled
Setup and perform ePay operations Enabled

For more information, refer to Control User Access.

System Preference Description

General ePay

Enable Zego ePay and enter your Zego account credentials. For more information, refer to General ePay (System Preferences).

More Information

Before you can set the other ePay system preferences, the Enable ePay option in these general ePay preferences must be checked and the Merchant Information section must have your ePay account information entered..

Advanced ePay

Select preferences to control the types of ACH, credit card, and debit card accounts that you can accept and how the deposits of ePay payments are tracked in Rent Manager. For more information, refer to Advanced ePay (System Preferences).

Batch ePay

Select preferences to control how multiple ePay payments are processed. For more information, refer to Batch ePay (System Preferences).

Owner ePay

The system ePay defaults for bank account(s), warning limits, and platform fee charges that should be applied to owner accounts. This system preference is required and must be enabled before owner ePay can be used. For more information, refer to Owner ePay (System Preferences).

Security ePay

Rent Manager allows you to purge inactive data from the system, establish password parameters, and set your ePay password. For more information, refer to Security ePay (System Preferences).

Step 2: Add ePay Information to Owner Account

Related Privileges

Group Privilege Column
Owners Owners View, Edit
ePay Setup and perform ePay operations Enabled

For more information, refer to Control User Access.

Payment information must be entered on the owner's ePay Settings pop-up in order to use ePay processing. The information entered remains on the owner’s account to be used in the future for ePay transactions.

More Information

ePay information must be entered for the associated property to process transactions. For more information, refer to Property ePay Settings (Pop-Up).

To add ePay information to an owner account, do the following:

  1. Go to arrow_forward Owners arrow_forward General arrow_forward Owners and select an owner from the list.
    The owner's details page displays.

  2. Click arrow_forward ePay Settings.

  3. If prompted, enter the ePay password to authenticate your ePay account and press Authenticate.

  4. Select Turn on owner contribution account on file or Turn on pay owner account on file. Both options are described below.

Enable ePay for Owner Contributions

If you check Turn on owner contribution account on file, you can enter information needed to process owner contributions as ePay transactions for this owner. After you enter the below information, click Save.

Account Information

Select an Account Type to be debited for contributions from this owner. Based on the type of account, the following fields display:

Field Description

ACH

The ACH account to be debited from the owner.

Account Number

The account number (usually 10–12 digits) specific to the owner's bank account.

First Name

The first name of the owner associated with the account.

Last Name

The last name of the owner associated with the account.

Routing Number

The routing number associated with the owner's ACH account.

Credit Card

The credit card account to be debited from the owner.

Card Number

The credit card's account number.

CVV2

The three-digit CVV2 security code, typically found on the back of most credit cards or the four-digit code on the front of an American Express card.

Exp Month

The credit card's expiration month.

Exp Year

The credit card's expiration year.

First Name

The first name of the owner associated with the account.

Last Name

The last name of the owner associated with the account.

Type

Rent Manager examines the first four digits of the card number to determine the card type (e.g., Visa, MasterCard, Discover, American Express).

Debit Card

The debit card account to be debited from the owner.

Card Number

The debit card's account number.

CVV2

The three-digit CVV2 security code, typically found on the back of most debit cards or the four-digit code on the front of an American Express card.

Exp Month

The debit card's expiration month.

Exp Year

The debit card's expiration year.

First Name

The first name of the owner associated with the account.

Last Name

The last name of the owner associated with the account.

Type

Rent Manager examines the first four digits of the card number to determine the card type (e.g., Visa, MasterCard, Discover, American Express).

Billing Information

Enter the billing address for this owner or click Fill From Owner to pull the owner’s primary address from the Addresses tile.

Enable ePay for Owner Distributions

If you check Turn on pay owner account on file, you can enter information needed to pay owners using ePay. Click Save to record your changes.

Account Information

Select an Account Type to be credited for distributions to this owner. Enter information for the following fields:

Field Description

Account Number

The account number (usually 10–12 digits) specific to the owner's bank account.

First Name

The first name of the owner associated with the account.

Last Name

The last name of the owner associated with the account.

Routing Number

The nine digit number used to identify the bank.

Billing Information

Enter the billing address for this owner or click Fill From Owner to pull the owner’s primary address from the Addresses tile.
