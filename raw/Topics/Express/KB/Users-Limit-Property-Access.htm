Limit Access to a Property

It's best practice to grant users access to only the properties they require. This ensures that users are only viewing and making changes to information associated with those properties, safeguarding your business from user errors and improper access to business information. For example, if a user creates a service issue, they must have access to any properties that they want to link to it.

There are two options for limiting property access. You can either limit access at the property level, determining all users with access to a specific property, or on the user level, determining all properties that a specific user can access. Though either method works for limiting property access, one might be easier than the other depending on the situation. For example, if you've recently added a new property and need to assign existing users to access the property, grant users access at the property level so that you don't have to switch between multiple user accounts. Alternatively, if you've recently hired someone to work at multiple properties, updating property access at the user level can save time.

Option 1: Limit User Access by Property

Related Privileges

Group Privilege Column
Properties/Units Properties View, Edit

For more information, refer to Control User Access.

Restricting property access on the Property details page is helpful when you need to remove or add access for multiple users at the same property. For example, if multiple people switch from working at one of your properties to another, it is easier to update this information on the specific properties instead of individually going through each user account to adjust access.

To grant access for a single property to multiple users on a Property details page, do the following:

  1. Go to arrow_forward Rental Info arrow_forward Properties and select the property.
    The Property details page displays.

  2. On the Other Information tile, click the drop-down arrow in the User Privileges field.


  3. Check the names of any users that should maintain access to the property.

  4. Click Save to confirm your changes.
    Only users selected on this tile have access to this property when they next log in.

Option 2: Limit User Access by User

Related Privileges

Group Privilege Column
System Manage all users and privileges View, Edit

For more information, refer to Control User Access.

Restricting property access on the User details page is helpful when you need to remove or add access for a single user across multiple properties. For example, if a user is promoted to a position where they require access to a large group of properties, it is simpler and faster to adjust access in one place on the User details page than on multiple Property details pages.

To grant a single user access to multiple properties through a Userdetails page, do the following:

  1. Go to arrow_forward Administration arrow_forward Users and select a user.

  2. On the user General tab, locate the Properties tile and check the properties to which the user requires access.

  3. Click Save to confirm your changes.
    The next time this user logs in, they have access to only the properties selected.
