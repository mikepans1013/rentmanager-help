Smart Bills

Rent Manager's Smart Bills feature allows you to streamline your invoice management process. With this feature, you can easily upload invoices via a PDF or image format, allowing Orion AI to extract the relevant data and create draft transactions automatically. Smart Bills also includes an intuitive review process, allowing you to ensure the accuracy of transactions before posting them as actual bills. Additionally, vendors can send invoices in PDF Format directly to a dedicated email inbox for seamless integration into the Smart Bills workflow.

More Information

This feature is licensed and must be purchased separately. For more information, contact your sales representative at sales@rentmanager.com.

How It Works

When your vendors send you invoices, Orion AI extracts the relevant information to create transactions in Rent Manager. The vendor listed on the bill is then automatically matched to the existing vendor in your Rent Manager database. To get started with Smart Bills, you can upload an existing vendor bill from your computer to the Smart Bills page. You can also create inboxes that vendors can use specifically for emailing their invoices. Once the bill is uploaded or has been emailed to a Smart Bills inbox, you can review or make changes to the bill's details before posting it as a transaction to be paid.

Property and Vendor Aliases

Aliases in Rent Manager are used to improve Smart Bills matching by identifying additional property addresses and vendor names that display on the invoices and matching them to existing Rent Manager records. For example, if you have a vendor in Rent Manager that sends an invoice using their full company name, or if you have a property that uses an address instead of the name listed in Rent Manager, the alias can be used to identify and correctly link them to the existing vendor in your database. Creating individual aliases can help you more quickly identify invoices sent from each vendor. Aliases can be automatically created through the Smart Bills Review page, or added manually to ensure accurate matching. For more information, refer to Add an Alias.

Smart Bills Inboxes

To help you keep track of the vendors you work with and the bills that you pay, Smart Bills inboxes can be created to sort bills by property or other criteria. Vendors can send invoices directly to a dedicated email inbox for seamless integration into the Smart Bills workflow. Inboxes can be added and modified using the Manage Smart Bill Inboxes pop-up.

To add a Smart Bills inbox, do the following:

  1. Go to arrow_forward Payables arrow_forward Bills arrow_forward Smart Bills. The Smart Bills page displays.

  2. Click Manage Inboxes.

  3. Click Add Inbox to setup a new inbox to which vendors can email invoices.

  4. Enter the requested information and settings. For more information, refer to Manage Smart Bills Inboxes (Pop-Up).

  5. Click Save when finished.
    The vendor can use the system-generated email to send invoices directly to the Smart Bills page.

Next Steps

After uploading your first bills using the Smart Bills feature, there are few additional things you can do. The following pages allow you to use, manage, and pay Smart Bills.

Page Description

Smart Bills

The Smart Bills page lists any bills manually uploaded or emailed in by a vendor that are waiting to be reviewed and posted to Rent Manager. For more information, refer to Smart Bills (Page).

Smart Bill Review

Once bills are uploaded or send in by vendors, review the information Orion AI pulls from the invoice and create a new Rent Manager bill with that information. For more information, refer to Review Smart Bills.

Pay Bills

After your new bills are created, you can mark them as paid through the Pay Bills page. For more information, refer to Pay Bills.
