Customize Asset Options

When you create or edit an asset in Rent Manager, you can enter values into asset-type user-defined fields (UDFs), categorize the asset by type, identify the manufacturer, track the status of the title, define the procedures that must be completed for maintenance, and select a status that describes the current state of the asset. Although you can complete the asset wizard without this information, setting up these tools before adding your asset helps streamline the asset creation process.

Asset User-Defined Fields

Related Privileges

Group Privilege Column
User Defined Fields User defined fields Add, View

For more information, refer to Control User Access.

User-defined fields (UDFs) are custom fields you create to track data that Rent Manager does not track by default. Asset-type UDFs are used specifically to track additional information on asset accounts. For more information on creating asset-type UDFs, refer to Add a User Defined Field.

Asset Types

Related Privileges

Group Privilege Column
Asset Management Asset Types Add, View

For more information, refer to Control User Access.

Asset types are classifications that help sort and track certain types of assets. For example, if your property has on-site laundry, you could create a Washing Machine asset type, then create assets for each washing machine you own with that type selected. For more information, refer to Add an Asset Type.

Manufacturers

Related Privileges

Group Privilege Column
Asset Management Asset Manufacturers Add, View

For more information, refer to Control User Access.

Asset manufacturers are the companies that produce and supply your assets. You can enter the company's address, contact, and website information, which allows you to easily communicate with the manufacturer if you need additional information or support regarding the asset. For more information, refer to Add an Asset Manufacturer.

Title Statuses

Related Privileges

Group Privilege Column
Asset Management Manage Asset Title Statuses Enabled

For more information, refer to Control User Access.

Asset title statuses are conditions that describe the state of ownership for the asset. For example, you may add a Clear Title status to indicate that the asset's title is in your company's name, or add a Lien Found status if the asset has an unpaid debt. For more information, refer to Add an Asset Title Status.

Asset Workflows

Related Privileges

Group Privilege Column
Asset Management Manage Asset Workflows Enabled

For more information, refer to Control User Access.

Asset workflows are used in conjunction with asset statuses to track the progress of certain routine processes, such as the purchase or sale of an asset or moving an asset to another physical location. For more information, refer to Add an Asset Workflow.

Asset Statuses

Related Privileges

Group Privilege Column
Asset Management Asset Statuses Add, View

For more information, refer to Control User Access.

Asset statuses are used to track the current condition or state of the asset. For example, you may create an Inventory status for available assets that are not in use, or an Out for Repair status to indicate when an asset is temporarily unavailable while receiving maintenance. For more information, refer to Add an Asset Status.
