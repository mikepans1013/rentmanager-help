Set Up Web Chat

Rent Manager's Web Chat feature allows you to place a chat button on your Tenant Web Access (TWA), Owner Web Access (OWA), and Web Template Suite sites, as well as custom websites. When a visitor clicks this button, they are connected with a Rent Manager user to begin a web chat. Within this chat, you can quickly add a visitor as a prospect, or create an issue for a tenant. Logs from these chats are retained in Rent Manager for your reference.

More Information

This feature is licensed and must be purchased separately. For more information, contact your sales representative at sales@rentmanager.com.

Step 1: Create Queues

Related Privileges

Group Privilege Column
Web Chat Queues Add, View

For more information, refer to Control User Access.

To utilize the Web Chat feature, you need to create at least one Web Chat queue, in which you specify the questions a visitor should be asked, the Rent Manager users who answer messages in that queue, and the queue settings. For a more details on adding a queue, refer to Add a Web Chat Queue.

To create a Web Chat queue, do the following:

  1. Go to arrow_forward Communication arrow_forward Web Chat arrow_forward Manage Queues.
    The Manage Queues page displays.

  2. At the top, click Add Queue.
    The queue is created.

  3. In the header of the General Information section, check Enable.

  4. Edit the options in the General Information section as desired.

  5. In the Chat Agents section, click Add Agent.
    The Add Chat Agent pop-up displays.

  6. In the Name field, select a user that participates in this queue from the drop-down list.

  7. Check Admin or Agent. Users who are designated as Admin can reorder conversations in queues, assign conversations to other users, view all pending conversations in the queue, and take conversations in any order. Checking Admin also selects Agent. Users designated as Agent can only take the next conversation in the queue, and they can only view the next conversation waiting.

  8. Click OK.
    The designated user display in the Chat Agents section. Add additional users as needed.

  9. Use the following sections to build the functionality of the queue:

    Section Description

    Questions

    Add introductory questions that the visitor is asked when they initiate a web chat.

    Saved Replies

    Add common responses that can be quickly selected during a chat to save you time.

    Actions

    Determine what actions, such as adding an issue or a new prospect, users may take from the chat.

  10. Click OK.
    The new queue is saved and added to the list of queues in the left panel of the page.

Step 2: Utilize Web Chat on Your Portals

Related Privileges

Group Privilege Column
System System Preferences View, Edit

For more information, refer to Control User Access.

In order to place a Web Chat button on your Rent Manager portals (TWA, OWA, and Web Template Suite), you must enable them and determine which queue they are directed to when beginning a chat.

More Information

This topic assumes you are using a Rent Manager portal. If you are not using any of the listed portals, the Web Chat plug-in can be added to your custom website.

Portal Description

Tenant Web Access (TWA)

In system web preferences, check Enable Web Chat and specify which queue is used for TWA users. For more information, refer to Tenant Web Access Web Chat (System Web Preferences).

Owner Web Access (OWA)

In system web preferences, check Enable Web Chat and specify which queue is used for OWA users. For more information, refer to Owner Web Access Web Chat (System Web Preferences).

Web Template Suite

In system web preferences, check Enable Web Chat and select which queue is used on your website.

Next Steps

Once a Web Chat queue is created, there are various actions available to utilize the feature. For more information, refer to Conduct a Web Chat Conversation.
