12.960 Release Notes

The release begins rolling out on May 17, 2023.

New Features

The Task Automation tool now offers a way to automate the delivery of statements to tenants. With this automation, you can easily send tenant statements via email or Virtual Post Office (VPO). In addition, you can make statements available via Tenant Web Access (TWA) by adding the statement to History/Notes and selecting a history category that is available to tenants in TWA (set in System Web Preferences).

As part of these improvements, the following updates were made:

  • To enable this tool, the Task Automation (System Preferences) include a new Tenant Statements field.
    Path: arrow_forward Admin arrow_forward Preferences arrow_forward System Preferences arrow_forward Task Automation

  • To set the default statement method, the General Report Options (System Preferences) includes a Tenant Statement section.
    Path: arrow_forward Admin arrow_forward Preferences arrow_forward System Preferences arrow_forward Report Options arrow_forward General

  • You can override the default statement method for a property on the Property Details page Other Information tile Statement Method field.
    Path: arrow_forward Rental Info arrow_forward select a property arrow_forward Other Information tile

  • You can set the tenant’s preferred delivery method on the Tenant Details page Miscellaneous tile Statement Method field.
    Path: arrow_forward Rental Info arrow_forward select a tenant arrow_forward Miscellaneous tile

  • The Statement Method report option was added to the Tenant Statement 8.5x11 (Report) and all custom form tenant statements now include a Statement Method report option so you can easily generate the tenant statement and filter by the delivery method.

  • The Tenant Statement Automation page was added, where you can add automation schedules.
    Path: arrow_forward Admin arrow_forward Task Automation arrow_forward Tenant Statements

If you use the Metered Utilities tool, you can now import and export meter readings into or from Rent Manager Express, as well as manage the file formats used for those import/export files using the following new pages:

  • The File Format page, which allows you to set the formatting for import or export meter reading files.
    Path: arrow_forward Services arrow_forward Metered Utilities arrow_forward File Formats

  • The MU Import From File page, which allows you to import multiple meter readings.
    Path: arrow_forward Services arrow_forward Metered Utilities arrow_forward Import From File

  • The MU Export To File page, which allows you to export your selected meter reading data.
    Path: arrow_forward Services arrow_forward Metered Utilities arrow_forward Export To File

To make it easier to manage Associations in Rent Manager Express, you can now configure and share specific financial reports with your board members, committee members, or all homeowners within the association through Tenant Web Access (TWA). These reports can be generated on a recurring or one-time basis. Once a report is published, it displays live data based on the parameters you’ve specified in Rent Manager.

As part of these improvements, the following updates were made:

  • The Tenant Web Access Page Setup (System Web Preferences) Reports section was updated with a Show Reports field.
    Path: arrow_forward Admin arrow_forward Preferences arrow_forward System Web Preferences arrow_forward Page Setup arrow_forward Reports

  • An Association - Published TWA Reports page was added, which allows you to add, delete, or view a list of pre-selected system reports from Rent Manager and publish them for specific audiences to view in TWA.
    Path: arrow_forward Rental Info arrow_forward Properties arrow_forward select an association property arrow_forward click View More on the action bar arrow_forward Published TWA Reports

  • An Association - Scheduled TWA Reports page was added, which allows you to add, edit, preview, or delete TWA report schedules for your users in TWA.
    Path: arrow_forward Rental Info arrow_forward Properties arrow_forward select an association property arrow_forward click View More on the action bar arrow_forward TWA Report Schedules

  • An Add Report Schedule page was added, which allows you to set up recurring TWA report schedules.
    Path: arrow_forward Rental Info arrow_forward Properties arrow_forward select an association property arrow_forward click View More on the action bar arrow_forward Published TWA Reports arrow_forward Add Report

The Import Owner Contracts tool was added, which allows you to import new owner contracts into your Rent Manager database.

Path: arrow_forward Admin arrow_forward Import arrow_forward Import Owner Contracts

The Import Depreciation Setup tool was added, which allows you to import asset depreciation schedules to asset records in your Rent Manager database.

Path: arrow_forward Admin arrow_forward Import arrow_forward Import Depreciation Setup

Enhancements

To make Rent Manager Express more intuitive and user-friendly, changes were made to several registers. These changes include making information easier to read on the screen and vastly improving navigation. Buttons were added or repositioned to simplify performing popular actions, and icons were added next to phone numbers and emails so you can perform these actions directly from the register. Additionally, changes were made to how data displays in these registers, improving organization, spacing, and legibility.

In addition, the following detail pages were updated with a simplified scoreboard which includes buttons for popular actions:

  • Tenants

  • Prospects

  • Units

  • Properties

  • Owners

  • Assets

  • Loans

  • Vendors

With the changes to scoreboards, summary cards were removed which reduces scrolling on these pages.

The LeaseTrack Insurance integration was updated, allowing you to enable a master policy and corresponding charge amount on a property-by-property basis, as well as the ability to exclude specific unit types from tracking renter’s insurance.

Additionally, to support commercial properties that also have residential units, commercial properties are now allowed to be included in the renter's insurance tracking and enforcement. Previously they were excluded by default. Be sure to use the Unit Type exclusion option so only residential units are included.

As part of these improvements, the following updates were made:

  • The Renters Insurance (System Preferences) were updated to improve consistency and usability.

  • The Renters Insurance Breakdown dashboard tile and the Insurance Breakdown (Report) were updated to improve organization, spacing, and legibility.

To help you manage the contacts on your tenant and prospect accounts, you can now make contacts inactive. By default, all contacts are active.

To support this functionality, the following changes were made:

  • The tenant and prospect View Contacts pages were updated with Active and Show Inactive checkboxes in Form view and Grid view.

  • Tenants can now be filtered by their inactive contacts using the basic filter.

  • An Active function was added to the Contact Class (Script), which allows you to determine whether the contact has Active checked on the View Contact page. The function displays True if the contact is active. Otherwise, False displays.

  • An IncludeInactive parameter was added to the tenant Contact Count Function (Script) and Contact List Function (Script), which allows you to specify whether to include a tenant’s inactive contacts. By default, the function displays only the active contacts.

  • The Current Occupancy Count Function (Script) and Current Occupancy List Function (Script) were updated and now default to include only active contacts in the list.

  • The Tenant Profile, Prospect Profile, Birthday / Age Listing, Occupancy Listing, Tenant Contact Labels, and Prospect Contact Labels reports were updated and now default to include only active contacts in the results.

The CashPay (System Preferences) were updated with an Amount Due section, which allows you to select Total Balance due or Current Balance due for your tenant's CashPay payments. Additionally, several of the options on this page were renamed to improve clarity.

Path: arrow_forward Admin arrow_forward Preferences arrow_forward System Preferences arrow_forward ePay arrow_forward CashPay

To have greater control over which of your properties have access to Tenant Web Access (TWA), a Disable TWA for Selected Properties field was added to Tenant Web Access General (System Web Preferences).

Path: arrow_forward Admin arrow_forward Preferences arrow_forward System Web Preferences arrow_forward Tenant Web Access arrow_forward General

To add a violation when in rmAppSuite map view, the following updates were made:

  • Violation (System Preferences) were added, which allows you to Show all units in map view and Customize pin colors by violation stage.
    Path: arrow_forward Admin arrow_forward Preferences arrow_forward System Preferences arrow_forward rmAppSuite arrow_forward Violations

  • When Show all units in map view is enabled in system preferences, a new option is available in the Address section of a unit’s details page and displays the GPS coordinates of the unit, provided a geocode has been captured and stored for the unit in Rent Manager.

The add violation from map view tool will be available in rmAppSuite next month (App Version 1.35).

To restrict a user in rmAppSuite from viewing a contact’s history/notes even if they can View the contact, a View History/Notes in Contacts privilege was added to the rmAppSuite privilege group.
