12.1000 Release Notes

The release begins rolling out on September 20, 2023.

New Features

We are excited to announce several updates to Express, designed to make customizing, organizing, and navigating the application a breeze! The My Workspace page is now your new default home screen. From the workspace, you can quickly jump to your favorite pages and reports, as well as access training resources in a snap!

Changes were also made to revamp the menu, making information easier to read and vastly improving navigation. The menu immediately opens to a list of your favorite pages, which makes it easy to jump to the parts of the program you use the most. The updated menu is organized into groups of features and includes options to easily access reports and setup items related to the selected group. For example, the Accounting group includes links at the bottom that jump to admin setups for accounting-based features and financial-based reports.

The Internet Listing Service (ILS) marketing integration is now available in Express. With ILS, you can effortlessly push your unit and property information from your database onto various ILS platforms. All data changes in Rent Manager automatically update on each ILS site, so you’ll never have to worry about posting an unavailable unit or listing inaccurate rates.

The Address Types page was added, which allows you to add and manage your own categories of addresses such as billing or forwarding.

Enhancements

To better create, update, and track applications submitted by prospects in Express, the following changes were made:

  • The Applications page was updated with Status field, which allows you to sort the applications by status (In Progress, Completed, and Canceled).

  • The Application details page was updated with Summary, Applicants, and Applicant Details sections. The Summary section displays details about the application's progress, the Applicants section displays information about each applicant and the status of their application, and the Applicant Details section displays questions asked of the applicant(s) and their answers.

  • Additionally, from the details page, you can print the application in the style of a Rent Manager report (Application Detail), as it appeared on Apply Now (Web Application), and as a report which contains the information entered on TWA Apply Now Disclaimers system web preferences, as well as the applicant's signature (Application Disclaimers).

The Property details page was updated to include the View More menu options to Email Apply Now Link and Copy Apply Now Link regardless of Property Type.

System web preferences were updated to allow you to specify the font size for disclaimers that display on your Apply Now applications. These updates were made to follow the recent Colorado House Bill 23-1099, which requires application disclaimers to be at least 12 pt bolded font.

Inventory items were updated so the Inventory Transactions tab Value column takes the item's cost into consideration when calculating values. Additionally, the Type column was updated to display Automatic Increase and Automatic Decrease when an invoice is created with a quantity exceeding the quantity available for the associated property and there are remaining items with <No Property Assignment>.
