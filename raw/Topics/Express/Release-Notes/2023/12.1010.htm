12.1010 Release Notes

The release begins rolling out on October 17, 2023.

New Features

To improve usability and streamline the process of customizing the display for certain pages in Express, the Layout tool was updated in several exciting ways. These updates make creating layouts that optimize your workflows and meet your individual business needs, a breeze!

To support this update, the following changes were made:

  • The Layouts page was renamed System Layouts and allows you to add layouts, copy another user’s layout, and assign roles and property types for each layout.
    Path: arrow_forward Administration arrow_forward Customization arrow_forward System Layouts

  • The My Layouts page was added, which allows you to view and manage layouts that have been created by you, or system layouts that have been assigned to you or modified by you.
    Path: arrow_forward Administration arrow_forward Customization arrow_forward My Layouts

  • Edit Own Layouts, Design Layouts, Assign System Layouts, and Manage System Layouts were added to the Setup Privilege Group.
    Path: arrow_forward Administration arrow_forward Users arrow_forward Users arrow_forward select a user from the list arrow_forward click the Privileges tab

  • The Layout Editor was updated to make customization more intuitive and user-friendly, simplifying adding, deleting, or repositioning fields and limiting what users see and how they interact with your data based on their user role or privileges. Additionally, you now have more flexibility determining the size and placement of tiles, and scripting fields have been improved by incorporating Script Builder.
    Path: arrow_forward Administration arrow_forward Customization arrow_forward System Layouts | My Layouts arrow_forward click Add Layout

For commercial reconciliations, Express now supports the ability to set up amortized payment schedules for tenants with large commercial recoverable expense (CRE) charges and even provide exemptions and discounts that are part of a tenant's contract. To support this, a new CAM (Common Area Maintenance) expense adjustment tool was added, which allows you to manually create additional expense adjustments to add or deduct amounts from a selected general ledger (GL) account while performing a CAM reconciliation.

As a part of this update, a new CAM Expense Adjustments page was added, which allows you to track amortized and one-time adjustments made for CAM reconciliations. To view this page, you need the new CAM Expense Adjustments privilege that was added to the Commercial Recoverable Expenses (CRE) Privilege Group.

Path: arrow_forward Receivables arrow_forward Commercial arrow_forward CAM Expense Adjustments

The Move Out wizard was added, which allows you to easily move a tenant out of an associated unit. The wizard allows you to enter a move-out date, adjust user defined fields (UDFs), edit contact information, enable a unit status for the vacated unit or an asset status for a vacated or returned asset, and initiate the make-ready process.

Path: arrow_forward Rental Info arrow_forward General arrow_forward Tenants arrow_forward select a tenant from the list arrow_forward click Move out on the Leases tile

The Assign Amenities page was added, which allows you to assign amenities to specific units and/or properties.

Path: arrow_forward Administration arrow_forward Rental Info arrow_forward Properties/Units arrow_forward Assign Amenities

Enhancements

The Tenant ePay – Lockbox system preferences were updated with Payment Options section, which allows you to accept partial payments (less than the current balance in their transaction ledger) and/or accept payments that are greater than the transaction ledger balance through Zego Pay Lockbox. A Statement Return Address section was also added, which allows you to determine the address that displays at the top of the Tenant Statement (Option 2) – Lockbox report.

Path: arrow_forward Administration arrow_forward Preferences arrow_forward System Preferences arrow_forward Tenant ePay arrow_forward Lockbox

Additionally, the General Report Options system preferences were updated with Tenant Statements section, which allows you to choose what displays on tenant statements and how those statements are generated.

Path: arrow_forward Administration arrow_forward Preferences arrow_forward System Preferences arrow_forward Report Optionsarrow_forward General
