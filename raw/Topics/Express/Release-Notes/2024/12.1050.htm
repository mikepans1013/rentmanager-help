12.1050 Release Notes

The release begins rolling out on February 20, 2024.

New Features

Per the IRS regulations for the 2023 Tax Year, corrected returns must be filed electronically if the original returns were filed electronically. We’ve made it easy for you to do this with our new Export Corrected 1099 and Export Corrected 1098 tools. These tools allow you to create 1099 and 1098 correction files, which can be filed electronically via the IRS FIRE system (provided the original returns were submitted via FIRE). As part of this update, the following changes were made:

  • Both export options feature step-by-step wizards to easily guide you through the exporting process.

  • The Export Corrected 1099 wizard utilizes two distinct workflows for owners and vendors.

  • A Getting Started section was added to both wizards, which details the setup required before you can begin the export process.

  • The Export Corrected 1099 Summary and Export Corrected 1098 Summary reports were added, which provide a breakdown of the options you used to generate the corrected export file.

To improve the process of resetting your Rent Manager password, a new Forgot Password? option was added to the Express login page.

Enhancements

To give tenants and association members the ability to schedule weekly, quarterly, semi-annual, and annual payments in Tenant Web Access (TWA) and rmResident, you can now enable new payment frequencies for AutoPay. Additionally, this update provides your tenants with even greater visibility and control over their scheduled payments by allowing them to specify dates for AutoPay to start and end. As part of this update, the following changes were made in Rent Manager:

  • The Tenant Web Access AutoPay system web preferences were updated with Weekly, Quarterly, Semiannually, and Annually frequency fields, allowing you to select different frequencies for tenants and associations. The Weekly option is available only to tenants with weekly rent periods.

  • The tenant’s Autopay pop-up was updated with additional Frequency, Start Date, and End Date fields.

  • The setup options for TWA and rmResident were updated to accommodate the new payment frequencies and start and end dates.
To easily match which bill payment should be allocated to the corresponding owner invoice, the Owner Payment Allocation pop-up was updated with Reference # and Comment columns. This update occurs when you are creating management company receivables and have the option checked in system preferences to Allow manual allocation of payment at the time bills are paid.
In our continuing efforts to improve the Purchase Order (PO) Workflow tool, a new Edit approved purchase orders POs/Estimates privilege was added. With this privilege enabled, users can edit approved and partially approved POs. Additionally, users with the privilege to Edit purchase orders can now edit rejected POs and reopen closed POs.
The Check details page was updated with performance improvements, including making popular actions more intuitive and significantly reducing load times.
