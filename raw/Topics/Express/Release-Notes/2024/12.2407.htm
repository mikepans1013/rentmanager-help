12.240700 Release Notes

The release begins rolling out on July 23, 2024.

New Features

STR import tools were added to Rent Manager Express!

Express

To help you manage your short-term rentals (STR), you can now import STR Reservations, STR Guests, and STR Guest Prospects into Rent Manager, greatly reducing the amount of time spent on data entry.

Platform Path

Express

arrow_forward Administration arrow_forward Import arrow_forward Import Records arrow_forward Import STR Guests | Import STR Guest Prospects | Import STR Reservations

Enhancements

Add a new vendor or general ledger (GL) account to a check or bill on-the-fly!

Express

On-the-fly functionality was added to Express, enabling you to quickly create new vendor or GL account records while adding or updating a check or bill without losing your progress!

Platform Path

Express

arrow_forward Payables arrow_forward Checks arrow_forward Checks

arrow_forward Payables arrow_forward Bills arrow_forward Bills

The Express Dashboard was updated with improved styling and usability!

Express

In our continuing efforts to make Rent Manager Express more intuitive and user-friendly, exciting changes were made to the Dashboard. This includes redesigned dashboard tiles that make information easier to read and the addition or shifting of action icons to make it easier to adjust a tile’s filters and settings. Additionally, you can now save images of graph tiles, allowing you to add the images in your slide decks and documents.

Quickly locate an issue by its ID number from Command Launch.

Express

To simplify the process of locating and managing service issues, you can now search for issues by their Issue ID number directly from Command Launch.

The grid print tool has come to several pages in Express!

Express

The tool was added to several register pages in Rent Manager Express (including the tenant View Transactions and User Defined Fields pop-ups), allowing you to speedily generate a report which can be printed or exported to PDF, HTML, Text, or Excel.

A Property Short Names column was added to Vendor Transactions.

Express Rent Manager 12

A Property Short Names column was added to the Vendor Transactions pop-up, enabling you to identify which transactions correspond to which property without opening the details of each transaction.

Express

The Vendors page was updated with the Bulk Actions option to Compose Email. This addition lets you quickly email multiple vendors at once.

Updated and expanded filtering options have come to the Prospects, Estimates, and Recurring Bills pages.

Express

The Filter options on the Prospects, Estimates, and Recurring Bills were enhanced and expanded, giving you the ability to create advanced filters and save them as system filters.

rmAppSuite Pro was updated to make uploading inspections faster and easier!

rmAppSuite Pro

To improve uploading inspections, the following updates were made to the Inspections feature:

  • The speed of uploading an inspection was substantially increased.

  • The reliability of inspection uploads, including images, were significantly enhanced.

  • An automated recovery tool and the ability to retry image uploads in case of issues were added, eliminating the need for manual intervention.

  • The ability to stop in-progress inspection uploads from the Upload register was added, allowing for changes before resubmitting.
