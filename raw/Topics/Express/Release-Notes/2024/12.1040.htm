12.1040 Release Notes

The release begins rolling out on January 23, 2024.

Enhancements

The Purchase Order (PO) Workflow tool has been updated, giving you even more control, clarity, and organization of your PO process. Workflows can now be automatically assigned to a purchase order based on the selected inventory item, preventing user error and increasing efficiency.

Multiple approval tiers within PO workflows have also been introduced with this enhancement, enabling you to establish users and user roles, as well as a maximum dollar value for each tier.

For more information, refer the Rent Manager Help File’s PO Workflows documentation.

Purchase orders (POs) created in Express can now be linked to bills imported from AvidInvoice. To accommodate this enhancement, the following updates were made:

  • The AvidXchange system preferences were updated with a Link purchase order on imported bills from AvidInvoice option, which, when enabled, automatically links the PO number from an AvidInvoice to the bill created using the Import button on the AvidInvoice page.
    Path: arrow_forward Administration arrow_forward System Preferences arrow_forward AvidXchange

  • The Purchase Order details page was updated with a Link Existing Bill option, which allows you to search and filter for existing bills to link to the PO.
    Path: arrow_forward Payables arrow_forward General arrow_forward Purchase Orders arrow_forward select a PO from the list

  • The Bill Details page was updated with a Link Existing PO option, which allows you to search and filter for existing POs to link to the bill.
    Path: arrow_forward Payables arrow_forward Bills arrow_forward Bills arrow_forward select a bill from the list

  • The Bills page was updated with a Show unmatched Avid PO#s only filter option and an Avid PO # column. The filter option and column display only if the Link purchase order on imported bills from AvidInvoice system preference has been enabled.
    Path: arrow_forward Payables arrow_forward Bills arrow_forward Bills

The tenant Payment Details pop-up was updated, allowing you to view the check/money order image for payments submitted via the Zego Pay Lockbox integration.

Path: arrow_forward Rental Info arrow_forward General arrow_forward Tenants arrow_forward click on the Transactions tile arrow_forward select a payment from the list

To improve usability and streamline the process of adding tenant and prospect payments in Express, the Receive Payment process was updated in several exciting ways. These updates make adding single and batch payments, as well as applying credits, a breeze!

To support this update, the following improvements were made:

  • The Receive Payment pop-up can now be easily accessed from the and Command Launch and features improved search and filter abilities.

  • The Receive Payment and Add Payment pop-ups utilize color-coding, allowing you to easily identify late charges and partial and full payments.

  • Additionally, if the tenant has unapplied credits on their account, a notification box displays at the top of the pop-up and allows you to Apply Credits Now.

  • The batch payment process has been updated to improve usability, allowing you to easily add individual payments to a batch.
