12.910 Release Notes

The release begins rolling out on December 13, 2022.

New Features

To make it easier to add scripts to Letter Templates, the following tools were added:

  • The Insertable Fields list, which contains functions that can be added to your letter template as placeholders that populate with specific information related to the recipient of the letter.

  • The Script Builder page, which is a test environment for scripting functions where you can modify a script from within the editor, test the script, and insert the script back into the source letter, report, field, and so on.

Meter Readings, which can be used to set up, view, and enter meter readings of a selected utility for the units of a selected property, were added to Rent Manager Express.

To support this feature, the following pages were added:

  • The Meter Readings Setup page, which allows you to specify for each utility at each property the type of meter that is billed, assign meters to units, and optionally enter previous consumption history.
    Path: arrow_forward Services arrow_forward Metered Utilities arrow_forward Meter Readings arrow_forward Meter Readings Setup

  • The Meter Readings page, which allows you to view, edit, and post meter readings.
    Path: arrow_forward Services arrow_forward Metered Utilities arrow_forward Meter Readings arrow_forward Add Meter Readings

  • The Unit Consumption History page, which allows you to view the rate of consumption for a unit (or alternatively, tenant consumption) over time.
    Path: arrow_forward Services arrow_forward Metered Utilities arrow_forward Meter Readings arrow_forward Add Meter Readings arrow_forward in the Edit Readings section click Consumption History.

The Digital Signatures page was added, which allows you to view and/or add an image of a handwritten signature that can be saved and placed on printed checks to save time.

Path: arrow_forward Admin arrow_forward Setup arrow_forward Payables arrow_forward Digital Signatures

The Modify Market Rent page was added, which allows you to adjust market rent amounts for a batch of units within a selected property to reflect current values.

Path: arrow_forward Receivables arrow_forward Modify arrow_forward Modify Market Rent

A Reservable Amenities tile was added to the Property Details page, which allows you to keep track of amenity (clubhouse, car charging station, and so on) reservations. Additionally, the Community Calendar page was added, which displays scheduled reservable amenities and community-wide events in a single location, giving you an overview of what facilities at the property are in use and a schedule of upcoming events.

Path: arrow_forward Rental Info arrow_forward Properties arrow_forward select a property arrow_forward Reservable Amenities tile

Path: arrow_forward Services arrow_forward Community arrow_forward Community Calendars

The Manage Webhooks page was added, which allows you to send information from your database to a secure web address when specific events occur in Rent Manager.

Path: arrow_forward Admin arrow_forward Setup arrow_forward Manage Webhooks

The Lease Term Adjustment Tool page was added, which allows you to apply a lease term to multiple leases at once.

Path: arrow_forward Admin arrow_forward Setup arrow_forward Rental Information arrow_forward Lease Term Adjustment Tool

The Web Chat feature was added, which allows you to communicate with your tenants and owners through a website (Tenant Web Access (TWA), Owner Web Access (OWA), and Web Template Suite sites, as well as custom websites).

To support this feature, the following pages were added:

  • The Manage Queues page, which allows you to add new queues and edit existing ones and select which Rent Manager users may participate in queues.
    Path: arrow_forward Correspondence arrow_forward Web Chat arrow_forward Manage Queues

  • The My Conversations page, which allows you to log in and out of queues and chat with visitors.
    Path: arrow_forward Correspondence arrow_forward Web Chat arrow_forward My Conversations

  • The Closed Conversations page, which allows you to view previous web chat conversations.
    Path: arrow_forward Correspondence arrow_forward Web Chat arrow_forward Closed Conversations

  • The Unlinked Conversations page, which allows you to view previous web chat conversations which are not linked to an account in Rent Manager.

  • The Offline Conversations page, which allows you to view web chat conversations received when the queue was offline.
    Path: arrow_forward Correspondence arrow_forward Web Chat arrow_forward Offline Conversations

The Utilities Automated Postings page was added, which allows you to add and edit automated utilities postings.

Path: arrow_forward Admin arrow_forward Task Automation arrow_forward Utilities

Enhancements

The Lease Details page was updated for tenants with a Commercial Lease to include Charge Escalations, Charge Type Setup, and CRE Setup tabs.

Path: arrow_forward Rental Info arrow_forward Tenants arrow_forward select a commercial tenant arrow_forward View More arrow_forward Leases arrow_forward select and click Renew

The Filter options on the Tenants and Properties pages were updated and expanded so you can now create advanced filters and save your filters as system filters (which can be viewed and managed in Rent Manager 12).

Path: arrow_forward Rental Info arrow_forward Tenants arrow_forward

Path: arrow_forward Rental Info arrow_forward Properties arrow_forward

During an electronic bank reconciliation or electronic credit card reconciliation you now have the option to Delete any imported transactions that do not match the transactions on your bank or credit card statements.
