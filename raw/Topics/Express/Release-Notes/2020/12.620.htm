12.620 Release Notes

The release begins rolling out on July 21, 2020.

New Features

Links to Express release notes were added in the following places:

  • Upon login, the What's New tile now includes links to the most recent release notes and past release notes.

  • The menu ribbon now includes a icon that notifies a user when new release notes are available.

  • The About Rent Manager pop-up now includes a link to the current version of release notes and past release notes. you can access this pop-up by going to arrow_forward Software and Licensing Info.

  • The Release Information dashboard tile was added which will show release information and links to the corresponding release notes.

Enhancements

The Dashboard was updated with an action bar with the ability to favorite the page and quick access to the help file.

Path: arrow_forward Dashboard

The Tenants register was updated to remember your Status filter selections so your preferred filters are set each time you open the window.

Path: arrow_forward Tenants

The Details page for properties was updated in the following ways:

  • The Ownerships summary tile was renamed to owners.

  • A slide-up page for Owners was added which displays the property's owner(s). This panel can be accessed from the action bar ( arrow_forward Owners) or from the Manage link on the Owners summary tile.

The Owners register filter for Show Inactive was replaced with Status filters for Past, Current, and Future.

Path: arrow_forward Rental Info arrow_forward Owners arrow_forward Owners

The Details page for owners was updated with a slide-up panel for Ownership which displays the owner's portfolio. This panel can be accessed from the action bar ( arrow_forward Ownership)

Owner Estimates can now be memorized from the action bar.

Path: arrow_forward Receivables arrow_forward Estimates arrow_forward select an owner estimate arrow_forward arrow_forward Memorize

The filter options on the Memorized Estimates page was updated in the following ways:

  • A filter was added for estimate Type.

  • The Is Taxable filter was renamed Taxable.

  • The Interest filter was removed.

Path: arrow_forward Receivables arrow_forward Memorized Estimates

Completed Apply Now applications that include attached files now list each file as a link which, when clicked, downloads the file for viewing.

Path: arrow_forward Rental Info arrow_forward Applications
