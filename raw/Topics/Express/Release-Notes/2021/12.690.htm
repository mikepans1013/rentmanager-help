12.690 Release Notes

The release begins rolling out on February 16, 2021.

New Features

A Vendor Credits register was added, which allows you to manage credits associated with your vendors.

Path: arrow_forward Payables arrow_forward Vendor Credits

A Post Management Fees page was added, which allows you to calculate and post fees for the properties you manage.

Path: arrow_forward Rental Info arrow_forward Owners arrow_forward Post Management Fees

Enhancements

The Owner Prospect Details page was updated so you can now convert your owner prospects to owners. You can do this using the Change button in the Lead Information section or the View More menu option to Change Status.

The Asset Maintenance Details pop-up now includes an option to Create Service Issue for this Maintenance. Additionally, you can select whether you want the service issue to be opened immediately or opened a specified number of days before the issue is due.

Path: arrow_forward Rental Info arrow_forward Assets arrow_forward select an asset arrow_forward History/Notes arrow_forward open the asset’s maintenance details

The Make Ready Board was updated in the following ways:

  • Quick filters were added for Properties and Days to Show. Additionally, a Filters menu was added to filter your make ready board data further.

  • A legend and counter were added to the footer of the page to clarify what the colors in the board represent and to show the total number of make ready processes in the list.

Path: arrow_forward Services arrow_forward Make Ready arrow_forward Make Ready Board

The Add Contact slide-up page was added to make creating a contact from the View Contacts page in Grid View easier.

Path: arrow_forward Rental Info arrow_forward Tenants arrow_forward select a tenant arrow_forward Contacts arrow_forward arrow_forward Add

The Property Details page now includes an Owner Check Setup summary tile which allows you to view and Manage the way in which you pay your property’s owners.

The Layout Editor was updated in the following ways:

  • User defined fields created in Rent Manager 12 can now be added to tenant, property, and asset layouts in Rent Manager Express.

  • Tenant layouts now include Primary Contact fields. Additionally, a Script field is now available which allows you to pull dynamic information into your custom tenant layouts.

  • Property layouts now include fields for Late Fees, Ownerships, Primary Owner, and Screenings.
