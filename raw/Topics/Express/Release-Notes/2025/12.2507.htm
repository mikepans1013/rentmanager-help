12.250700 Changelog

The release begins rolling out on July 22, 2025.

New Features

Simplify company credit card transactions and employee reimbursements with Smart Receipts, powered by Orion AI.

Express rmAppSuite Pro

The Smart Receipts feature was added to Rent Manager Express, allowing you to streamline your expense management process. Simply upload your receipts to Rent Manager via a PDF or image format, and Orion AI extracts the relevant data and creates draft transactions automatically. Even better, Rent Manager users can be linked to a vendor account, making it easy to reimburse them for any personal charges. Smart Receipts also includes an intuitive review process, enabling you to ensure the accuracy of company credit card charges or reimbursements before posting them as actual bills or credit card transactions.

Coming soon to rmAppSuite Pro, the ability to capture pictures of receipts while in the field. This upcoming resource allows your technicians to take pictures of receipts, categorize the expense, and send them directly to the Smart Receipts page.

More Information

Smart Receipts is a licensed feature—for more information, please contact your sales representative at sales@rentmanager.com.

For more information, refer to the Smart Receipts topic in Express help.

Effortlessly transform your property images into interactive, data-rich maps with bird's eye view (BEV).

Express Rent Manager 12

The bird's eye view (BEV) tool was added to Rent Manager Express, which allows you to create a visual representation of your properties, providing a high-level overview of a property as well as detailed information for each unit within a property. In Express, the map creation process was streamlined, including the ability to use pins to represent units. Additionally, existing maps in Rent Manager 12 can now be viewed in Express. A Quick Add Mode was also added, which automatically guides you through a list of units so you can designate units on the map with one click. Creating and viewing maps for mixed-use and multiple floor properties is now easier than ever, with the addition of a floor and property selector.

As a part of these updates, the following changes were made in Rent Manager Express:

  • The Manage BEV Maps page was added, which lists the available maps to view and can be assigned to users, edited, and exported directly from the page. For more information, refer to the Manage Bird's Eye View (BEV) Maps (Page) topic in Express help.

  • The Default Map Settings pop-up was added, which allows you to configure the default settings for the BEV tool. For more information, refer to the Bird's Eye View (BEV) Default Map Settings (Pop-Up) topic in Express help.

  • The Add a Bird's Eye View Map pop-up was added, which allows you to create a BEV map by importing an overhead image of your property in Rent Manager. You can then link pins to the units in your database. For more information, refer to the Add a Bird's Eye View (BEV) Map topic in Express help.

  • The View BEV Maps page was added, which allows you to use BEV views to filter the units that display based on a specific criterion, such as the occupant's unpaid balance or whether a tenant recently moved out of the unit. For more information, refer to the View Bird's Eye View (BEV) Maps (Page) topic in Express help.

  • The Manage BEV Map Views page was added, which allows you to create and manage map views that display specific information regarding the units. Each map view has its own legend to identify the information displayed. For more information, refer to the Manage BEV Map Views topic in Express help.

  • The Edit BEV Map page was added, which allows you to add units and customize settings for a map. For more information, refer to the Edit BEV Map (Page) topic in Express help.

  • The Map Settings pop-up was added, which allows you to edit information for your maps after they've been created. The settings here can be used to update or change the name of the map, select or deselect properties to which it applies, as well as how the map displays. For more information, refer to the Bird's Eye View (BEV) Map Settings (Pop-Up) topic in Express help.

  • The Edit Default Unit Information pop-up was added, which allows you to customize the map's unit information card that displays while viewing the map, provided you haven't set the Edit Unit Information for an individual map. For more information, refer to the Edit Bird's Eye View (BEV) Default Unit Information (Pop-Up) topic in Express help.

  • The Edit Unit Information pop-up was added, which allows you to override the default unit information for user-created map views, ensuring that the views you create display the most important details about your properties and units. For more information, refer to the Edit Bird's Eye View (BEV) Unit Information (Pop-Up) topic in Express help.

The BEV tool also received several updates in Rent Manager 12. These updates have improved navigation and added or repositioned sections, filters, and fields to simplify the map creation process.

Catch unusual meter readings immediately with utility consumption groups.

Express rmAppSuite Pro

The utility consumption group tool was added in Rent Manager Express, which allows you to create ranges to instantly flag unusual meter readings, whether too high or low. Additionally, you can customize your technician's process in rmAppSuite Pro by requiring an image of the meter or a detailed note depending on the reading, and quickly review the exceptions with the Utility Consumption with Ranges report.

As a part of these updates, the following changes were made in Rent Manager Express:

  • The Utilities privilege group was updated with a Utility consumption groups privilege, which grants the user the ability to Add, View, Edit, and/or Delete utility consumption groups. For more information, refer to the Utilities Privilege Group topic in Express help.

  • The Manage Consumption Groups pop-up was added, which allows you to set and manage custom thresholds for normal, high, and low consumption to receive alerts in rmAppSuite Pro and gain visibility in reports when usage spikes or drops unexpectedly. For more information, refer to the Manage Metered Utilities High/Low Settings topic in Express help.

  • The Add Meter Readings page was renamed Meter Readings and was updated with additional filters, fields, and columns to simplify managing meter readings.

  • The Unit Consumption History pop-up was renamed View Consumption History and an Images column was added, which indicates an image is available for the associated meter reading.

  • The Utility Consumption with Ranges report was added, which allows you to review the consumption ranges on the meter readings at your properties as of a specified date range.

Get high-level tracking and reporting for your manufactured housing properties with the new site classification tool.

Express Rent Manager 12

The site classification tool was added for manufactured housing-type properties, which allows you to monitor units (or sites) by considering the site's legal owner, the type of asset(s) present at that site, its occupancy status, and whether the site is generating revenue.

As part of this update, the following changes were made:

  • The Asset Management privilege group was updated with a Homeowner Statuses privilege, which grants the user the ability to add, edit, and/or delete the current legal ownership status for assets associated with an Asset Type that is marked as Is Home.

  • The Homeowner Status pop-up was added, which displays the legal ownership status that corresponds with the site classification Rent Manager automatically applies to the associated unit, the date that the homeowner status was added, and the user who originally added the homeowner status. Statuses can also be added and edit from this pop-up. For more information, refer to the Homeowner Statuses (Pop-Up) topic in Express help.

  • The Site Classification dashboard tile was added, which provides a snapshot of the current classification status of your units as of the current date. For more information, refer to the Site Classification (Dashboard Tile) topic in Express help.

  • The Site Classification Listing report was added, which displays a list of manufactured housing units and the system-defined site classifications of those units. For more information, refer to the Site Classification Listing (Report) topic in Express help.

  • The Summary Rent Roll and Rent Roll & Recurring Charges reports were updated with an Include Site Classification report option, which, when enabled, displays the short name of each unit's site classification as of the specified date.

For more information, refer to the Site Classification topic in Express help.

Enhancements

The short-term rental (STR) workflow tool was significantly enhanced to give you more control.

Express Rent Manager 12

In our continuing efforts to take STR management to the next level, the STR workflow tool was updated with flexible payment options in the STR Online Booking portal, minimum stay requirements, direct bookings from site maps, the ability to generate and distribute promotional codes, and dynamic rate management. These updates will help you optimize occupancy and increase profitability, make the booking process more intuitive and user friendly, and enhance your marketing efforts and revenue management.

As part of this update, the following changes were made Rent Manager:

  • The STR Online Booking - RV/Campground - General system web preferences were updated with Payment Link Message section, which allows you to establish the default email or text message when sending a payment link. For more information, refer to the RV/Campground Online Booking General (System Web Preferences) topic in Express help.

  • The Setup privilege group was updated with a Manage STR Promotions privilege, which, when Enabled, grants the user the ability to access the STR Promotions page.

  • The STR Promotions page was added, which allows you to add and manage discounts for STR reservations based on specific criteria. Promotions are set up with a unique promo code that guests can enter in the Online Booking Portal, and promotional periods can be limited based on the date the guest books their reservation and the dates the reservation is for. Additionally, you can control whether promotions are applied to an entire stay or on a nightly basis, and can require a minimum number of nights for the discount to be used. For more information, refer to the Add a Short Term Rental (STR) Promotion topic in Express help.

  • The STR Promotions and Member Discounts report was added, which displays the usage of your promotions and member discounts over a specified time frame. For more information, refer to the STR Promotions & Member Discounts (Report) topic in Express help.

  • The Add Dynamic Rate pop-up was added, which allows you to dynamically update pricing for nightly rates based on the occupancy levels and booking times at your properties. The rules established here determine when a rate increase or decrease is applied to reservations based on an occupancy criteria.

Scanning and reviewing your checks just got easier with the new check scanner enhancements.

Express Rent Manager 12

The check scanner feature was updated, allowing you to capture more details from your checks with a faster and smoother flow. With this enhancement, the check scanner now automatically reads the amount on checks, reducing errors and saving you time.

For more information, refer to the Set Up Epson Check Scanner topic in Express help.

Additionally, if you have purchased a license for Optical Character Recognition (OCR) for check scanning, an Auto fill tenant balance when check scanner does not read amount system preference was added. When enabled, this preference automatically sets a scanned check’s Amount, when the scanner fails to read the amount from the check, to the tenant’s full balance. If the check scanner successfully reads an amount from a check, the amount read by the scanner is automatically entered in the Amount field. For more information, refer to the Check Scanning (System Preferences) topic in Express help.

More Information

This OCR feature is licensed and must be purchased separately. For more information, contact your sales representative at sales@rentmanager.com.
