Month to Month Adjustment Tool

The Month to Month Adjustment Tool allows you to set multiple tenants to a month-to-month (MTM) lease all at once. You can use this tool to add a MTM lease term after their current Lease End date if the lease has no established Move Out or Expected Move Out date. This tool is useful for situations where residents are not ready to move out of their unit when their lease ends. For example, if a tenant does not know exactly when they intend to move out or may need to move out on short notice, you can allow them to continue to rent monthly after their lease is over.

Additionally, you can use this tool to convert the existing lease for any tenant accounts that do not have a Lease End or Move Out date established for their lease, allowing you to set occupants who are renting on a monthly basis to have an MTM lease term if it was not done when their account(s) were created.

The headings below provide the steps for how to use this tool depending on the action you wish to perform: adding an MTM lease after their current lease ends or setting a tenant's indefinite lease to month-to-month.

Option 1: Add MTM Lease After Current Lease Ends

To renew leases with a month-to-month (MTM) lease term, do the following:

  1. In the Properties field, select each property in the drop-down list to examine the tenants at those properties. Alternatively, select a property Group to display only properties included in that group.
    The list displays only tenants with leases at the selected properties.

  2. Select the option to Add a MTM lease following leases that have ended, but have no move out or expected move out date set.
    The list displays only leases with a Lease Start and Lease End date, but no Move Out or Expected Move Out dates. The following columns display:

    Column Description

    Tenant

    The first and last name of the tenant account to which the lease is attached.

    Property

    The property of the lease's assigned unit.

    Unit

    The unit with which the lease is associated.

    Lease Start

    The date on which the lease officially begins according to the lease agreement, as entered in the Lease Start date of the lease's details.

    Lease End

    The date on which the lease officially ends, as entered in the Lease End date of the lease's details. The month-to-month lease is set to begin on to the day after this date.

  3. If you wish to include only leases with a Lease End date that falls under a specified amount of time, check Exclude leases that ended more than the lease age limit. Then, in the Lease age limit field, enter the number of months. For example, if you enter 12, only leases that ended within the last twelve months display in the list.

  4. Select each lease in the list that should have a MTM lease term added after it ends.

  5. Click Add Month-To-Month Lease.
    The selected leases have a MTM lease added for the day after their Lease End date.

Option 2: Set Indefinite Leases to Month-to-Month

To set existing leases with no end date as month-to-month (MTM), do the following:

  1. In the Properties field, select each property in the drop-down list to examine the tenants at those properties. Alternatively, select a property Group to display only properties included in that group.
    The list displays only tenants with leases at the selected properties.

  2. Select the option to Set the lease term to MTM for leases that have a lease start date, but no lease end or move out date.
    The list displays only leases with a Lease Start date, but no and Lease End or Move Out dates. The following columns display:

    Column Description

    Tenant

    The first and last name of the tenant account to which the lease is attached.

    Property

    The property of the lease's assigned unit.

    Unit

    The unit with which the lease is associated.

    Lease Start

    The date on which the lease officially begins according to the lease agreement, as entered in the Lease Start date of the lease's details.

    Lease End

    This column always displays blank when this option is selected.

  3. If you wish to include only leases that do not already have a Lease Term set, check Exclude leases with term specified.

  4. Select each lease in the list that should have the current Lease Term set to MTM.

  5. Click Set Lease Terms.
    The selected leases are set to have month-to-month lease terms.
