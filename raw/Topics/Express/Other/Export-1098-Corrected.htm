Export Corrected 1098

If you are required by the IRS to produce 1098 tax forms for tenants who paid you interest on an owner-financed loan, you can export the forms as a text (TXT) file to submit directly to the IRS. These files are for use with the IRS File Information Returns Electronically (FIRE) system, which is different from the Information Returns Intake System (IRIS) filing portal and uses a separate Transmitter Control Code (TCC). If you submitted incorrect information on a 1098 generated from Rent Manager, you can quickly generate a corrected form using Export Corrected 1098. The corrected 1098 file should then be sent to the IRS by the IRS-mandated deadline(s).

Step 1: Select Export Options

To export your corrected 1098 forms, do the following:

  1. Go to arrow_forward Receivables arrow_forward Loans arrow_forward Export Corrected 1098.

  2. Confirm you have the information and details listed on the page and click Next.

  3. In the Which tax year will be used for the export? drop-down, select the tax year of your original 1098 form.

Step 2: Enter Transmitter Information

After you confirm the export options, select the Transmitter Information tab on the left or click Next.

Enter information in the fields below related to the sender of the 1098 form. Click Copy From Management Company to auto-fill the Transmitter Information tab with information from the property management company's details page.

Field Description

Tax ID

The tax identification number (TIN) issued to your business by the IRS.

If you use Copy From Management Company, this displays the information from the property's details page under Other Information arrow_forward Property Tax ID.

TCC

The Transmitter Control Code (TCC) issued to your business by the IRS to submit the 1098 electronically. This code must be obtained from the IRS before you attempt to submit the 1098.

Transmitter Name

The name of your property management company.

If you use Copy From Management Company, this displays the information from the property's details page under General arrow_forward Full Name.

Contact Name

The name of the person the IRS should contact.

If you use Copy From Management Company, this displays the information from the property's details page under General arrow_forward Manager.

Contact Phone

The phone number of your property management company.

If you use Copy From Management Company, this displays the information from the property's details page under Phone Numbers arrow_forward Number that is marked as Default.

Contact Email

The email address of your property management company.

If you use Copy From Management Company, this displays the information from the property's details page under General arrow_forward Email.

Company Name

The name of your property management company used for billing purposes.

If you use Copy From Management Company, this displays the information from the property's details page under Other Information arrow_forward Billing Name 1 and Billing Name 2.

Street Address

The number and street of your property management company's billing address.

If you use Copy From Management Company, this displays the information from the property's details page under Primary Address for the address marked as Billing.

City

The city of your property management company's billing address.

If you use Copy From Management Company, this displays the information from the property's details page under Primary Address for the address marked as Billing.

State

The state of your property management company's billing address.

If you use Copy From Management Company, this displays the information from the property's details page under Primary Address for the address marked as Billing.

Postal Code

The postal code of your property management company's billing address.

If you use Copy From Management Company, this displays the information from the property's details page under Primary Address for the address marked as Billing.

Step 3: Select a Loan

After you enter the transmitter information, select the Loan Selection tab on the left or click Next. In the Which loan requires corrections? field, select the tenant whose 1098 transaction data is included in the corrected 1098 file from the drop-down list.

Step 4: Enter Lender Information

After you select a loan to correct, select the Lender Information tab on the left or click Next.

To auto-fill the remaining fields with information from the selected entity's details page, in the Which lender was used on the original export file? field, select Management Company, Property, or Owner. To manually enter the required tax information, select Manual Entry and fill out all remaining fields.

Step 5: Select Mortgage Insurance Charge Types

On the Mortgage Insurance tab, in the Charge Types field, select the charge type(s) to use when calculating mortgage insurance premiums and interest data.

Step 6: Select Correction Type

After you choose which charge types apply to mortgage insurance, select the Correction Type tab on the left or click Next. Check any of the options for information that needs to be corrected.

Step 7: Enter Original File Information

On this tab, enter information as it was on your original file to ensure that Rent Manager correctly matches fields. The fields that display on this tab depend on the options you select on the Correction Type tab. Some options do not require you to enter original file information.

Step 8: Enter Corrected Information

In this tab, enter corrected information as it should display on the new 1098 form. The top of this tab displays fields for providing corrected information. If any information was not completed as part of the Original File tab, the bottom of this tab displays fields required for filing. Enter information in these fields to match your original 1098. The fields that display on this tab depend on the options you select on the Correction Type tab.

Step 9: Review Summary

After all information is entered, select the Summary tab on the left or click Next. On the tab, verify that the information in each field is correct. Then, in the File Name field, enter the desired name for the export file.

More Information

To save a test file than can be sent to the IRS during their specified testing date range, check Generate Test File . Then, in the File Name field, enter the desired file name for the export. For more information, refer to the IRS website.

When finished, click Download File to download the completed 1098 file and select if you want to print a summary of the export options you selected.

Warning

If any loans in the export, on the Loan Contacts pop-up for the loan, doesn't have a tax ID entered in the Soc Sec # field, a warning pop-up displays to let you know those loans are excluded from the export. A tax ID must be added to the loan before you can download the file and print the export summary.

If you select Yes, the Export Corrected 1098 Summary pop-up displays along with a generated Export Corrected 1098 Summary report. You can use options on the top right to download or print the summary.
