Inspection Worksheet (Report)

The Inspection Worksheet report is printed and given to the inspector to use while evaluating each area and item during an inspection. This worksheet provides information on the property and unit being inspected, as well as your property management company's contact details. Each item listed in the report displays a Status to be assigned by the inspector upon evaluation.

The bottom of the report provides lines for both the inspector and the associated tenant (if applicable) to sign off and date the inspection once it's completed.

Related Privileges

For more information, refer to Control User Access.

To view the Inspection Report report, do the following:

  1. Go to arrow_forward Services arrow_forward Inspections arrow_forward Inspections and select an inspection.
    The inspection's details page displays.

  2. On the top right of the page, click the Reports drop-down and select Print Inspection Worksheet.
    The Inspection Worksheet report is generated in a PDF file format.

Related Preferences

Reports may look different depending on whether or not the Use modernized report style system preference is enabled. For more information, refer to General Report Options (System Preferences).

Report Results

The report results are described below including, if applicable, section, column, and subreport descriptions.

Inspection Details

The Inspection Details section displays information on the property and unit inspected, the inspector, and more. Each field is described below:

Field Description

Address

The default address of the property where the inspection occurs.

Date

The date of the inspection. This field is not prefilled by Rent Manager and is to be completed by the inspector during the inspection.

Inspector

The name of the user who is responsible for carrying out the inspection.

Move In Date

The tenant's Move In Date as it displays on the tenant's details page in the Leases tile.

Property

The name of the property at which the inspection occurs.

Status

The current state of the inspection process (e.g., New, In Progress, etc.), as it displays on the inspection's details page in the Information tile's Status field.

Tenant

The name of the tenant associated with the inspection, as it displays on the inspection's details page in the Tenant field

Type

The type of inspection being performed (e.g., Move-In, Move-Out).

Unit

The unit at the property at which this inspection occurs.

Management Contact Details

The Management Contact Details section displays information on the property account created for your management company, as entered in system preferences in the Management Company page. Each field is described below:

Field Description

Address

The default address of your management company, as entered on your management company's property details page in the Primary Addresses tile.

Name

The name of your management company, as entered on your management company's property details page in the General tile.

Phone Number

The phone number of your management company, as entered on your management company's property details page in the Phone Numbers tile.

Areas and Items

The defined areas (the rooms inspected, e.g., Living Room, Master Bedroom), items (the objects within the rooms, e.g., Windows, Outlets & Switches) and statuses (e.g., Poor, Acceptable) that display in the inspection worksheet are determined by the inspection template selected when the inspection is created. Each item listed in the worksheet should have a Status selected by the inspector upon evaluation.

The areas and items listed on the worksheet display and are customizable from the inspection's details page. Additionally, areas and items can be added and edited from the Inspection Template page. For more information, refer to Add Inspection Areas and Add Inspection Items.

The following fields display for each item listed in the worksheet:

Field Description

Status

The reported state (e.g., Poor, Acceptable, Needs Repair) that best describes the condition of the item.

More Information

The statuses listed are customizable from the Inspection Template page in the Edit Item pop-up. for more information, refer to Add an Inspection Status.

Notes

Optional comments by the inspector regarding the evaluated item.
