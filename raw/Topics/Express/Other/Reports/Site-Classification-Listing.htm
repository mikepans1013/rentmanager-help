Site Classification Listing (Report)

The Site Classification Listing report displays a list of manufactured housing units and the system-defined site classifications of those units. Site classifications are determined by several factors, including the Homeowner Status of any assets associated with units, whether a resident-owned RV is occupying a lot, or if the asset is rentable.

Related Privileges

Group Privilege Column
Letter/Email Templates/Reports/Packets Run reports Enabled

Additionally, on the Reports tab, you must have access to Site Classification Listing.

For more information, refer to Control User Access.

To view the Site Classification Listing report, do the following:

  1. Go to arrow_forward Rental Info arrow_forward Occupancy arrow_forward Site Classification Listing.
    The Reports: Site Classification Listing page displays.

  2. Adjust the report options as desired. Each option is described below.

  3. Generate the report in your desired file format(s).

Related Preferences

Reports may look different depending on whether or not the Use modernized report style system preference is enabled. For more information, refer to General Report Options (System Preferences).

Report Options

The report options described below determine what data displays in the report.

Properties to Include

Select each property to be included in the report. Only properties with a Property Type of Manufactured Housing display in the list.

More Information

This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property.

Optionally, check Show Inactive Properties to include properties that are no longer active.

As of Date

Rent Manager examines relevant report information as of (up through) the date entered to determine the data that displays in the report.

Unit Types to Include

Select the unit type(s) to be examined in the report. Only the units associated with the properties selected in the Properties to Include section and assigned to the selected unit type(s) display.

Site Classifications to Include

Check each site classification to be included in the report. The report displays assets with the selected site classifications applied based on the site's legal owner, whether the site can be rented, the occupancy status, and the type of asset(s) and/or resident-owned RV present at that site. For more information, refer to Site Classification.

Run Properties Separately

Check to generate a separate report for each selected property. Otherwise, all selected properties are combined into a single report.

Show Unit Type Breakdown

Separates the report results by site classification and unit type. For example, if you use 1B/1B and 2B/1.5B unit types for units with a Resident Owned site classification, the report includes sections for 1B/1B: Resident Owned and 2B/1.5B: Resident Owned units, rather than a single Resident Owned section.

Exclude Site Classifications with No Assigned Units

Check to display only site classifications that are applicable to at least one unit.

Sort Options

Select one of the following options to determine how the report results are sorted in each site classification section:

Option Description

Home/RV

Units are sorted alphanumerically based on whether there is a home-type asset or resident-owned RV associated with the lease on the selected As of Date. Units with an associated home-type asset display the name of that asset, while units with a resident-owned RV on their lease display Resident Owned RV.

Property

Units are sorted alphanumerically by Property.

Unit

Units are sorted alphanumerically by Unit name.

Unit Type

Units are sorted alphanumerically by Unit Type name. If the Show Unit Type Breakdown report option is enabled, this sort option cannot be selected.

Report Results

The report results are described below including, if applicable, section, column, and subreport descriptions.

Report Header

The report header displays the report name and key information selected in the report options, such as date information and which properties were examined in the report.

Column Descriptions

The columns that display in the report are described below.

Column Description

Home/RV

If a home-type asset is associated with the unit on the selected As of Date, the asset's name displayed. If a resident-owned RV is currently on the unit's lot on the selected As of Date, Resident Owned RV displays.

Property

The name of the unit's manufactured housing-type property.

Unit

The name of the unit with the assigned site classification.

Unit Type

The name of the unit's type. This column displays only if Show Unit Type Breakdown is not selected in the report options.

Summary Subreport

The Summary subreport displays the total number of units with each site classification, along with information about their occupation statuses. Only the classifications selected in the report options display in this subreport.

Column Description

# of Units

The total number of units with the associated site classification on the selected As of Date.

% Occupied

The percentage of units that are occupied on the selected As of Date.

% Vacant

The percentage of units that are not occupied on the selected As of Date.

Occupied Units

The total number of occupied units with the associated site classification on the selected As of Date.

Site Classification

The name of the system-defined site classification(s) included in the report.

Vacant Units

The total number of unoccupied units on the selected As of Date.
