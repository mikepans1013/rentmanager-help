Owner Profile (Report)

The Owner Profile report creates a detailed breakdown of a selected owner account, including basic information, information about ownership status, management fee structure, user defined fields, and owner history/note items.

Related Privileges

Group Privilege Column
Letter/Email Templates/Reports/Packets Run reports Enabled

Additionally, on the Reports tab, you must have access to Owner Profile.

For more information, refer to Control User Access.

To view the Owner Profile report, do the following:

  1. Go to arrow_forward Owners arrow_forward General arrow_forward Owners and select an owner.
    The Owner details page displays.

  2. On the action bar to the right, click arrow_forward Owner Profile.
    The Reports: Owner Profile page displays.

  3. Adjust the report options as desired. Each option is described below.

  4. Generate the report in your desired file format(s).

Report Options

The report options described below determine what data displays in the report.

Date Range

Enter or select the date range to determine the data that displays in the report.

In the Date Range section, set the From and To dates for which the report should examine data.

These fields automatically populate with today’s date. Enter a different date or select a date from the calendar. Alternatively, adjust the dates using the available preset buttons or click to open more options for setting a date range.

Report Results

The report results are described below including, if applicable, section, column, and subreport descriptions.

Report Header

The report header displays the report name and key information selected in the report options, such as date information and which properties were examined in the report.

Owner Info

The Owner Info section displays basic information about the owner in the following fields. Unless otherwise noted, all fields display as they are entered on the Owner details page.

Field Description

Name

The name of the owner, which is used when referencing the owner and for correspondence generated to the owner in Rent Manager.

Address

The street of the address that is checked as Default.

City

The city of the address that is checked as Default.

State

The state of the address that is checked as Default.

Zip

The postal code of the address that is checked as Default.

Work Phone

The number entered in the Work phone number type.

Home Phone

The number entered in the Home phone number type.

Mobile Phone

The number entered in the Cell phone number type.

Email

The email address used to contact the owner.

Tax ID

The tax identification code for the owner.

Draw Account

The general ledger account that tracks distributions to the owner.

Contribution Account

The general ledger account that tracks contributions from the owner.

Partners

The names of other owners who hold partial ownership in at least one of the selected owner's properties. Partners are configured on property's Owners pop-up.

Comment

Any additional notes or memos pertaining to the owner.

Ownerships

The Ownerships section lists each of the properties in which the owner has a stake. Information about the ownerships is displayed in the columns below. Unless otherwise noted, all information displays as it appears on the Owners pop-up.

Column Description

Property

The name of each property in the owner's portfolio.

Contract Start

The date on which the contract for each property went into effect.

Contract End

The date on which the contract for each property expires.

Percent

The percentage of property ownership for each property.

Reserve

The minimum amount of money that must remain in the bank to cover expenses for each property.

Bank Account

The Default Bank account for each property as displayed on the property's details page.

Management Fees

The Management Fees section of the report displays each property's fees schedule as it appears on the property's Fees Setup pop-up. All management fee setups configured for the owner's property during the Date Range display.

Sub-headers display the names of each property and, if applicable, the selected management fee template. Fee information for the property is listed below each sub-header. The following fields display in the section:

Field Description

Minimum Fee

The minimum amount of management fees that should be collected from each property per posting.

Maximum Fee

The maximum amount of management fees that should be collected from each property per posting.

Flat Fee

The flat-rate fee that is collected from each property per posting.

Per Unit Fee

The flat-rate fee that is collected for each unit at the property per posting.

% of Total Income

The percentage of total (gross) income collected from each property per posting.

% of Net Income

The percentage of net income collected from each property per posting.

The following columns display in the section:

Column Description

Account

The general ledger account from which fees are collected on a percentage basis per posting.

Method

The basis, Cash or Accrual, in which management fees for each general ledger account are collected.

Percent

The percentage of each general ledger account's total that is collected per posting.

PT

If the fees are collected from each general ledger account on a pass-through basis, X displays.

Fee Account

The general ledger account that tracks the management fees expense applied to the property.

Income Account

The general ledger account that tracks the management fees income collected by the property management company.

User Defined

The User Defined section displays information about any owner user defined fields with values entered for the owner in the following columns:

Column Description

Name

The name of each owner-type user defined field.

Value

The value entered or selected for each owner-type user defined field.

History/Notes

The History/Notes section displays information about any owner history note items entered for the owner during the selected Date Range in the following columns:

Column Description

Date

The date on which the history item was entered for the owner.

Time

The time at which the history item was entered for the owner.

Regarding

The body of the history item as entered in the Note or Description fields.

Type

The system-generated type of the history item entered for the owner such as Note or Text Message.
