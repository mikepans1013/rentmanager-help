ePay Returns (Report)

The ePay Returns report displays failed ePay payments processed via Task Automation or the ePay Returns page.

ePay payments can fail because the tenant had non-sufficient funds (NSF) or because a user voided the payment in Rent Manager. At the end of the report, if more than one property or bank is included in the report's results, the returns are divided into subreports that include Returns by Property, Returns by Type, and Returns by Bank.

More Information

ePay returns processed manually via tenant transactions do not display in this report.

Related Privileges

Group Privilege Column
Letter/Email Templates/Reports/Packets Run reports Enabled

Additionally, on the Reports tab, you must have access to ePay Returns.

For more information, refer to Control User Access.

To view the ePay Returns report, do the following:

  1. Go to arrow_forward Banking arrow_forward ePay arrow_forward ePay Returns.
    The Reports: ePay Returns page displays.

  2. Adjust the report options as desired. Each option is described below.

  3. Generate the report in your desired file format(s).

Related Preferences

Reports may look different depending on whether or not the Use modernized report style system preference is enabled. For more information, refer to General Report Options (System Preferences).

Report Options

The report options described below determine what data displays in the report.

Properties to Include

Select each property or a property Group to be included in the report.

More Information

This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property.

Optionally, check Show Inactive Properties to include properties that are no longer active.

Date Range

Enter or select the date range to determine the data that displays in the report.

In the Date Range section, set the From and To dates for which the report should examine data.

These fields automatically populate with today’s date. Enter a different date or select a date from the calendar. Alternatively, adjust the dates using the available preset buttons or click to open more options for setting a date range.

Status

Select a failed ePay payment status (NSF and Returned) from the drop-down list so only failed ePay payments with the selected Status display. The NSF status displays the ePay payments that could not be processed due to non-sufficient funds. The Returned status displays the ePay payments that could not be processed for other reasons, such as an incorrect bank account or card number.

Sort Options

Select one of the following options to determine how the report results are sorted.

Option Description

Bank

ePay failed payments are sorted alphanumerically by the associated bank's account name. The transactions are further sorted chronologically by date in ascending order (oldest to newest).

Property

ePay failed payments are sorted alphanumerically by Property name.

Return Date

ePay failed payments are sorted chronologically by the date on which the ePay transaction was returned to Zego in ascending order (oldest to newest).

Status

ePay failed payments are sorted by Status (NSF, then Returned).

Report Results

The report results are described below including, if applicable, section, column, and subreport descriptions.

Report Header

The report header displays the report name and key information selected in the report options, such as date information and which properties were examined in the report.

Column Descriptions

The columns that display in the report are described below.

Column Description

Account

The first and last name of the tenant or prospect associated with the returned payment.

Amount

The total dollar amount of the returned payment.

Bank

The account name of the bank associated with the returned payment.

NSF Fee

The Default Amount assigned to the charge type set as the default Non-Sufficient Funds Fees in system preferences. This amount can be overridden per property on the property details page's Other Information tile.

Pay Method

The type of payment associated with the returned transaction (e.g., Visa, Savings).

Property

The property associated with the returned payment.

Response ID

The unique number generated by Zego when the ePay payment was made. This number is used by Zego for tracking purposes.

Return

The date that the payment was returned to Zego.

Return Code

The Zego return code relating to the reason for the payment's return (e.g, RO1). For a complete list of return codes, refer to ACH/E-Check Return Codes on Zego's website.

Reversal

The date set for the payment reversal as selected in the ePay Returns page's Summary section.

Status

The cause of the ePay return (NSF or Returned). The NSF status represents the ePay payments that could not be processed due to non-sufficient funds. The Returned status represents the ePay payments that could not be processed for other reasons, such as an incorrect bank account or card number.

Transaction

The date the payment was originally posted.

Unit

The unit associated with the returned payment.
