Add an Asset

By creating assets in Rent Manager, you can track important information for various items that your company owns, such as washing machines, storage units, and manufactured homes. The Add Asset wizard allows you to efficiently create a new asset. You can enter the physical location and condition of items, lease them to tenants, and track financial activity for rent payments and repairs.

More Information

To streamline the creation process, consider setting up asset user-defined fields (UDFs), title statuses, manufacturers, and other information related to your assets before adding asset accounts. For more information, refer to Customize Asset Options.

Step 1: Enter Asset Information

To create an asset, do the following:

  1. Go to arrow_forward Rental Info arrow_forward General arrow_forward Assets.
    The Assets page displays.

  2. Click Add Asset.

    On the left, the Asset Information tab is selected by default when you open the wizard.

  3. In the General tile, enter the asset's information into the available fields described below.

    Field Description

    Asset Type

    The category that best classifies the type of asset being created.

    Homeowner Status

    The legal ownership status (i.e., Community Owned, Employee Owned, etc.) of the home-type asset. For more information, refer to Homeowner Statuses (Pop-Up).

    This field is available only if the selected Asset Type for this asset is set up as a home.

    Name

    A unique label to identify the asset.

    This asset is rentable

    Indicates that tenants can lease the asset as they would a unit. Then, in the Market Rent field, enter the amount to charge renters of this asset.

    This option is available only if Track Financials is enabledand the Homeowner Status is set to Community Owned or Change of Ownership.

    Track financials for this asset

    Check to enable financial reporting for the asset, then select the Property with which the asset's financial activity is associated.

  4. In the Asset Details, enter or select additional asset information into the available fields described below. If the selected Asset Type for this asset is set up as a home, this tile displays as Home Details.

    Field Description

    Bathrooms

    The number of bathrooms the asset contains.

    This field is available only if the selected Asset Type for this asset is set up as a home.

    Bedrooms

    The number of bedrooms the asset contains.

    This field is available only if the selected Asset Type for this asset is set up as a home.

    Dimensions

    The measurable size of the asset, such as length and width.

    Manufactured Date

    The date the asset was produced by the company.

    Manufacturer

    The company that produced and supplied this asset.

    Model

    The model name of the asset.

    Serial Number

    The asset's unique serial identification number.

    Square Footage

    The size of the asset in square feet.

    This field is available only if the selected Asset Type for this asset is set up as a home.

  5. In the Purchase & Loan Information, enter or select financial information into the available fields described below.

    Field Description

    Lienholder

    The name of the financial institution that retains legal claim to the asset until the loan associated with the Loan Number is paid off.The person or business who owns and loaned the asset.

    Loan Number

    The number assigned to the loan by the lender.

    Purchase Date

    The date that your company purchased the asset.

    Purchase Price

    The price for which your company purchased the asset.

    More Information

    This amount is not automatically entered in your financial data. In order for the cost to display on financial reports, you must manually write a check, create a journal entry, or include the amount as part of a beginning balance.

    Sale Price

    The price for which you would sell or did sell this asset.

    Sale Price

    The price for which you would sell or did sell this asset.

    Title Status

    The current condition of the asset's title (e.g., Clear Title or In Process).

  6. In the Comment tile, enter additional information or notes about the asset.

Step 2: Select Location and Set Status

After entering the asset information, select the Location and Status tab on the left. To add the location and status of the asset, do the following:

  1. In the Location tile, enter the asset's service dates and the associated property and/or unit into the available fields described below.

    Field Description

    From

    The date that the asset was moved to the specified location.

    Property

    The property at which the asset is physically located.

    Service Life End

    The date that the asset was or is to be taken out of service.

    Service Life Start

    The date that the asset was put into service.

    To

    The date that the asset was or is to be removed from the specified location. If this is not known, leave this field blank.

    Unit

    The unit at which the asset is physically located.

  2. In the Status tile, enter or select the asset's workflow and status information into the available fields described below.

    Field Description

    Asset Status

    The condition that best describes the state of the asset.

    Asset Workflow

    The order of procedures that is to begin when the asset is created.

    Comment

    Additional information or notes about the asset.

    From Date

    The date on which the selected Asset Status is first applicable.

Step 3: Add Warranty and Maintenance Details

If you track maintenance items such as service agreements on washer/dryers, you can record the warranty and maintenance information on your asset. Similarly, if you manage manufactured housing properties, you might need to track assets as they move to different physical locations.

After entering the asset location and status, select the Warranty/Maintenance tab on the left. In the Warranty/Maintenance tile, enter information into the available fields described below.

Field Description

Maintenance Vendor

The primary vendor who is responsible for servicing and/or maintaining this asset.

Service Agreement

Indicates that this asset has a maintenance service agreement with the manufacturer or vendor. Once checked, additional fields are made available. Each field is described below.

Service Agreement Expiration

The date that the manufacturer or vendor service agreement for this asset ends.

Service Period (Months)

The number of months that elapses between each maintenance service for this asset for the duration of the service agreement.

Warranty Expiration Date

The date that the warranty for this asset expires.

Warranty Information

Any additional details regarding the warranty for this asset, such as terms or special stipulations.

Step 4: Enter Asset UDF Values

After entering the asset's general information, select the User Defined Fields tab on the left. In the User Defined Fields tile, only required UDFs display in the Name column. Required UDFs are marked with an asterisk (*) and must have a Value entered to create the asset.

To view all the asset-type UDFs in the database, click View All UDFs. For each UDF applicable to the asset you are adding, enter or select the information in the Value column for the associated UDF.

Step 5: Save the New Asset

Once you have established the asset-type UDFs, click Save and Finish to complete the asset creation process and close the pop-up. Alternatively, click Save and New to finish adding the asset and refresh the pop-up to add another asset.
