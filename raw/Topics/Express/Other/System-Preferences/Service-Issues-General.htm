Service Issue General Options (System Preferences)

Adjust these preferences to choose default options for information that displays in Service Manager issues, work orders, and forms.

Related Privileges

Group Privilege Column
System System Preferences View, Edit

For more information, refer to Control User Access.

To set these system preferences, do the following:

  1. Go to arrow_forward Administration, then go to Preferences arrow_forward System Preferences arrow_forward Service Issues arrow_forward General.

  2. Edit the settings as desired. Each setting is described below.

  3. Click Save to accept your changes.

Preference Descriptions

Each setting is described below:

Show Extra Information on Service Issues

Select any of the following options to be included in both the Links section of each service issue and the System Work Order report. Enabled options can be selected, if applicable, on service issues, which then display on printed work orders.

Option Description

Allowed To Enter

Check to include an option on issues to determine whether service technicians can enter the unit without the tenant present.

Signature on File

Check to include an option on issues to determine whether the property management company has the tenant's signature on file.

Has Pets

Check to include an option on issues to determine whether the tenant has pets.

General

The General section manages the notification and display details of your service issues. The following options are available in this section:

Option Description

Stop issue popup previews (Setting this can increase performance)

Check to prevent new service issues from automatically being displayed in a preview window. Displaying pop-ups can make the system run slower.

Notify me when new issues appear in my default list(s)

Check to receive a notification message when a new service issue is added to the default issue list.

If Rent Manager is running as an application on your computer but is not the program you are currently displaying or working with, the Rent Manager notification window will flash on the screen until you switch to Rent Manager.

More Information

This option is applicable only for Rent Manager Standalone users.

Show close form when closing from the register

Check to make a confirmation pop-up appear when you click the Cl checkbox to close an issue directly from the issue list in Rent Manager 12.

Recalculate sale price on work order when cost changes

Check to have Rent Manager automatically update the Sale Price (calculated as Sale Price = Default Cost x Markup) when the Cost of a line item on an issue is changed.

Automatically advance issues when checklist items are completed

Check to have Rent Manager automatically assign the service issue to the first user in the checklist with an open checklist item after an item is completed.

Use WO# as Invoice # when creating a bill

Check to populate the Invoice # field with the work order number when linking vendor or owner bills to a service issue. You may also specify a custom Prefix (up to ten characters) that will be affixed to the beginning of this number.

Assign new service tickets to

Select a user to whom new issues (created through Rent Manager, Tenant Web Access, or rmInspection) will be assigned by default. This chosen default can also be overridden on the property level.

In-House Maintenance Company

If you use Rent Manager to track the financials and services provided by your in-house maintenance company, this section allows you to create a vendor bill from a work order for your in-house maintenance technicians using the item's Sale Price.

Check Set an in-house maintenance company and select a Vendor from the drop-down list so, when new vendor bills are added to work order line items associated with the selected vendor, the in-house maintenance company is billed using the Sale Price instead of the base Cost.

Billing Name and Address

This section allows you to determine which name and address displays in the Billing Details section at the top left of the Service Order List report.

Option Description

Use Name From

Select the default location from which to retrieve the name to display in the billing details.

Property Name

The Full Name of the issue's property as entered on the Property details page.

Property Billing Name

Billing Name 1 and/or Billing Name 2 of the issue's property as entered on the Property details page in the Other Information section.

Management Company Property Name

The Full Name of the property designated as the management company in system preferences as entered on the Property details page.

Management Company Property Billing Name

Billing Name 1 and/or Billing Name 2 of the property designated as the management company in system preferences as entered on the Property details page in the Other Information section.

Use Address From

Select the default location from which the property and management company Billing Address is retrieved.

Property: Address Type

The address entered in the selected address type of the issue's property.

Management Company: Address Type

The address entered in the selected address type of the property designated as the management company in system preferences.

Print Details

This section allows you to enter a message to display in the Signature section at the bottom of a printed service order.

Maintenance Schedule

In this section, select the issue category or categories (e.g., Property Wide, Maintenance, Electrical, Plumbing, Emergency, Office) that display on the Maintenance Schedule page. ***All Issue Categories is selected by default.
