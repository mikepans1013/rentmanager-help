Move In/Move Out List (Dashboard Tile)

The Move In/Move Out List dashboard tile helps you track scheduled or expected move ins and move outs occurring within a set number of days. The property and the unit at which the activity is occurring is displayed, as well as the relevant dates.

The information on this dashboard tile may be represented in a graph or a list.

For more information, refer to Control User Access.

Filter Information

Related Privileges

Group Privilege Column
Setup Edit dashboard data filters Enabled

For more information, refer to Control User Access.

To filter the information that displays in the dashboard tile, click arrow_forward Settings to open the Move In/Move Out List Data Filters pop-up. The available filter options are listed below.

Option Description

Days to Include

The number of days in the future that a move in, move out, or expected move out occurs in order to be included in the tile results. For example, if you enter 30 in this field, move in and move out information displays for the next month.

Property Filter

Each property whose move in and move out information is included in the tile. To include all current and future properties, select <All Properties>. Alternatively, select a property Group from the drop-down list.

If <All Properties> is selected, you can also check Include inactive if 'All Properties' selected to calculate averages for all current and future properties whether they are active or inactive.

More Information

This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property.

Show Values

If checked, the total number of move ins, move outs, and expected move outs display over each point of the Line graph or on each bar of the Bar graph.

Graph Type

Optionally, select the desired display option from the Graph Type drop-down list.

Line

The number of move ins, move outs, and expected move outs display in a line graph, with move ins in blue, move outs in orange, and expected move outs in green. The number for each date can be viewed by hovering your cursor over each point on the graph.

If Show Values is checked, the number of move ins, move outs, and expected move outs display above each point.

Bar

The number of move ins, move outs, and expected move outs display in a bar graph, with move ins in blue, move outs in orange, and expected move outs in green. The number for each date can be viewed by hovering your cursor over each bar on the graph.

If Show Values is checked, the number of move ins, move outs, and expected move outs display on each bar.

None

The Property, Unit, Move In date, Move Out date, and Exp. Move Out date for each tenant display in a list. Options in the footer allow you to navigate to different pages of the tile.

Ignore dashboard property filter

If checked, override the property filter configured on the Dashboard.

Column Descriptions

The information that displays on the tile is organized into the following columns.

Column Description

Property

The property and the unit at which the activity is occurring.

Unit

The unit at which the activity is occurring.

Move In

The date the tenant moved into the unit.

Move Out

The date the tenant is moving out of the unit, if applicable.

Exp Move Out

The date the tenant expects to move out.

Axis Descriptions

The information that displays on each axis in the graph is described below.

Axis Description

X
(Horizontal)

The date being examined in a MM/DD/YY format.

Y
(Vertical)

The number of move ins, move outs, and expected move outs.
