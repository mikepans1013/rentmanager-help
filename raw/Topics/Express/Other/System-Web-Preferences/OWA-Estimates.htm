Owner Web Access Estimates (System Web Preferences)

Adjust these preferences to determine if owners can view, approve, or reject owner estimates in Owner Web Access. Additionally, settings for approvals and rejections can be established.

Related Privileges

Group Privilege Column
System System Web Preferences Enabled

For more information, refer to Control User Access.

Related Preferences

To access Owner Web Access settings, at least one location must be enabled for OWA in system web preferences. For more information, refer to Licensing (System Web Preferences).

To set these system preferences, do the following:

  1. Go to arrow_forward Administration, then go to Preferences arrow_forward System Web Preferences arrow_forward Owner Web Access arrow_forward Estimates.

  2. Check the Show Estimates option to allow owners to view estimates in the Owner Web Access portal. By default, only estimates that are assigned to the specified owner, have the Active option checked, and have a Status other than Draft display.

  3. Optionally, check Include inactive estimates to also display estimates where the Active option is unchecked.

  4. Edit the settings as desired. Each setting is described below.

  5. Click Save to accept your changes.

Preference Descriptions

Each setting is described below.

Preference Description

Include estimate History/Notes with the selected history categories

Check to allow owners to view the history note items on estimates which have a specified history category assigned. After checking this option, click the History Categories drop-down menu, and check each estimate-type category that owners should be allowed to view.

To allow owners to view all history note items with an estimate-type category assigned, check the box directly to the left of the Search field. To allow owners to view items with no category assigned, check Unassigned.

Enable owner estimate approval and rejection

Check to allow owners to approve and/or reject estimates via Owner Web Access. When enabled, owners are shown a message on their OWA dashboard, indicating that there is an estimate to review. On the estimate, Approve and Reject buttons display.

After checking this option, additional options become available:

Send notification to owner when estimate set to 'Awaiting Approval'

Check to automatically send an email notification to an owner when the Status of an estimate is set to Awaiting Approval.

Regardless of whether or not this option is enabled, owners see a notification on their OWA dashboard upon logging in that a new estimate is available to review.

More Information

This requires the owner's email address be entered on the Miscellaneous tile of their account.

Approval Message

Enter the message that displays to an owner after they click Approve on an estimate prior to signing.

Approval Confirmation Message

Enter a message that displays on the Approved confirmation pop-up, such as "Thank you. We will be in touch to discuss a start date."

Rejection Message

When an owner rejects an estimate in OWA, a Comments box displays so that they may include information about why they chose to reject the estimate.

Enter the message that you wish to display above the Comments box. For example, "Please comment below to tell us why the estimate was rejected."
