Service Manager Privilege Group

Service Manager privileges provide access to service-related features such as issues and lists, workflow projects and templates, and list filters and options.

Related Privileges

Group Privilege Column
System Manage assigned users and privileges View, Edit
Manage all users and privileges View, Edit

For more information, refer to Control User Access.

To manage these privileges, do the following:

  1. Go to arrow_forward Administration, then go to Users arrow_forward Users. Select a user and click the Privileges tab.

  2. Click next to the privilege group to expand the privilege list.

  3. To enable a privilege, check the box. Each privilege is described below.

  4. Click Save.

Privilege Descriptions

Each privilege is described below.

Privilege Description

Issues

Allows a user to add, view, edit, or delete service issues within the Service Manager menu. This privilege allows a user to perform actions such as:

  • Linking issues to tenants, units, and/or properties.

  • Assigning categories, priorities, statuses, and individual users to issues.

  • Attaching issues to Purchase Orders, Invoices, and vendor and owner Bills.

Issue Checklist

Allows a user to add, edit, or delete Checklists within an issue.

Recurring Issues

Allows a user to add, view, edit, or delete Recurring Issues.

Workflow Projects

Allows a user to add, view, edit, or delete workflow projects in Service Manager. For more information, refer to Workflow Projects (Page).

Workflow Templates

Allows a user to add, view, edit, or delete workflow templates in the Workflow Templates (Page).

Filters

Allows a user to add, view, edit, or delete filters on the issues list.

Edit projects using a restricted workflow template

If a workflow project created from a template has the option Restrict editing on workflow projects with this workflow template selected, this privilege is required in order for users to perform the following actions:

  • Adding and removing steps.

  • Reorganizing steps and stages.

  • Editing task step and issue step details.

  • Editing certain workflow project settings.

List manager

Allows a user to view or edit issue Priorities, Categories, and Statuses.

Additionally, allows a user to view or edit Saved Issue Lists, as well as save new lists from the Issues page.

Checklist templates

Allows a user to add, view, edit, or delete Checklist Templates.

Close issue

Allows a user to close an issue when the work is completed.

Close issue without a resolution

Allows a user to close an issue without entering an explanation in the Resolution field of the issue's details.

Lock issue

Allows a user to check Lock Issue in Issue Details so that only that user may edit, delete, or close the service issue.

Check in/out times

Allows a user to add, edit, or delete service tech check-in and check-out times in service issues via Add Tech Time on the issue's History/Notes tile.

Other techs' check in/out times

Allows a user to add, edit, or delete the check-in and check-out times of other service techs.

Edit all service issue layouts

Related Privileges

Group Privilege Column
Setup Manage form tabs Enabled

For more information, refer to Control User Access.

Allows a user to edit the issue layouts assigned to that user, other users, or user roles.

Edit own service issue layouts

Related Privileges

Group Privilege Column
Setup Design custom tabs Enabled

For more information, refer to Control User Access.

Allows a user to customize their own issue layouts.

Maintenance Techs

Allows a user to add, view, edit, or delete Maintenance Techs. For more information, refer to Add Maintenance Techs.

Maintenance Groups

Allows a user to add, view, edit, or delete Maintenance Groups. For more information, refer to Add a Maintenance Group.

View Maintenance Schedule

Allows a user to view the Maintenance Schedule page. For more information, refer to Maintenance Schedule (Page).

Schedule issues outside a tech's working hours

Allows a user to override the schedule for a maintenance group and assign issues to technicians when they are not scheduled to work.
