Post RUBS

For properties without submeters, the ratio utility billing system (RUBS) is an efficient, fast method for allocating utility costs from property-wide master meter readings among the property's tenants and units. Once RUBS is enabled and a template is assigned to a utility or master meter for a property, RUBS charges can be posted to the property when master bills are ready for posting. When posted, the RUBS template assigned to each master meter automatically calculates and charges each tenant's account their proportional share of the utility bill.

In addition to posting the charges from the Post RUBS page, RUBS charges can be posted alongside posting other existing recurring charges from the Post Recurring Charges page, or toggled as a Master Meter Bill and selecting Post RUBS from the Bill details page. For more information, refer to Post Recurring Charges and Post a RUBS Master Meter Bill.

Step 1: Configure the RUBS Charges

To select the RUBS bills you want to post, do the following:

  1. Go to arrow_forward Services arrow_forward Metered Utilities arrow_forward Post RUBS.

  2. In the Posting Information tile, enter the information in the following fields:

    Field Description

    Charge Comment

    An optional note providing additional information on the RUBS charge.

    Create Invoices

    If checked, invoices are generated for each tenant being charged on the master meter bill.

    Invoice Comment

    A default note to be added to each created invoice. This field is available only if Create Invoices is checked.

    Post Date

    The calendar date the RUBS charge is posted to each selected property.

    Use rent day for posting

    If checked, each tenant's RUBS charge is posted on the day of the month specified by the Due Day field in the General tab on the tenant's details page. Otherwise, new charges are posted on the month of the chosen Post Date.

Step 2: Select the RUBS Bills to Post

Once you configured the RUBS charges, select the properties in which to post the RUBS bills by doing the following:

  1. Check the applicable properties to post charges to. To find specific RUBS bills to select, use the Search field . Review the information in each column as described below:

    Column Description

    Bill Amount

    The total dollar amount billed on the master meter for the associated property. This value is not a RUBS calculated value. The amount is rounded down to the nearest cent to avoid overcharge laws.

    Bill Date

    The calendar date on which the master meter bill was created.

    Due Date

    The date the master meter bill is considered due, as specified in the Due Date field on the bill's details page.

    Invoice #

    The unique reference number that is assigned to the master meter bill, as specified in the Invoice # field on the bill's details page.

    Memo

    An optional message or reference for the master meter bill.

    Property

    The property expensed by the vendor in the master meter bill.

    Vendor

    The vendor account that receives the payment for the master meter bill.

  2. Click Post Charges.
    The Print Report pop-up displays.

  3. To print a summary report of the RUBS posting, select your preferred print method from the drop-down list. Then click Yes. Otherwise, click No.
    The RUBS bills are calculated using each master meter's RUBS template and are posted to tenant accounts for the selected properties.
