Run a Tenant or Prospect Screening

Rent Manager has partnered with AmRent to provide the ability to perform a screening for a prospect or tenant’s credit, criminal, and eviction history within Rent Manager. Prospects and their associated contacts can be screened as part of their application process. You can also screen a tenant if they are looking to rent an additional unit or move to a new unit at one of your properties. In order to ensure accurate results, you must enter each contact's information, select a screening report type, and define an estimated rental amount in the Run Screening pop-up.

More Information

To run a screening for a person that is not a tenant or prospect in Rent Manager, refer to Run a Screening for a Non-Tenant or Prospect.

To generate a screening, do the following:

  1. Go to arrow_forward Rental Info arrow_forward General arrow_forward Prospects | Tenants and select an account.
    The prospect or tenant's details page displays.

  2. On the action bar to the right, select arrow_forward Run Screening.

  3. Check the box next to the contact(s) you are screening. Selecting a contact displays a scoreboard at the top of the pop-up with the contact's name and Applicant Type.

  4. In the Report Type field, select the available screening report based on your contract with AmRent. For more information on each report type, refer to Screening Settings (System Preferences).

  5. In the Personal Information section, review and verify the details about the contact. The information entered in Rent Manager populates by default and the following fields are available:

    Field Description

    Annual Income

    Group Privilege Column
    Tenants/Prospects View annual income Enabled

    The contact's yearly income. To view the amount, click .

    Birth Date

    The contact's date of birth. This field is required.

    Name (First, Middle, Last)

    The contact's full name. The First Name and Last Name fields are required.

    Phone Number

    The contact's primary phone number.

    Social Security Number

    The contact's social security number (SSN). To view the full SSN, click .

    Related Privileges

    Group Privilege Column
    Tenants/Prospects View complete tenant SSNs Enabled

    For more information, refer to Control User Access.

  6. In the Address section, select one of the available prospect, tenant, or contact address types from the Fill From Address drop-down list or manually enter an address.

  7. In the Rental Information section's Monthly Rent field, the unit's active Market Rent amount populates automatically. Alternatively, enter the estimated rent charge for the unit they are being screened for.

  8. In the Additional Mapped Fields section, AmRent fields that are set up in system preferences but are not included in Rent Manager screenings by default display. For more information on mapped fields, refer to Screening Settings (System Preferences).

  9. Click Submit.
    The screening is submitted to AmRent and can be tracked on the Screenings page.

    More Information

    If all required information is entered but some data is incomplete, such as a missing Middle Name or Annual Income, a pop-up displays warning you that submitting a screening without that information may result in inaccurate data. You can still complete the screening by clicking Yes, or click No to enter additional information.
