Command Launch Results (Personal Preferences)

Command launch examines menu items—such as reports, letters, or entity accounts (tenants, prospects, and so on)—when you enter criteria in the search bar. You can customize which categories to include in your search results.

Related Privileges

The options that display on this page are dependent on your user privileges. For example, if you do not have privileges to view owners, then Owners does not display in the list.

For more information, refer to Control User Access.

To set these personal preferences, do the following:

  1. Go to arrow_forward Administration, then go to Preferences arrow_forward Personal Preferences arrow_forward Command Launch Settings arrow_forward Results.
    The Personal Preferences: Command Launch Settings - Results page displays.

  2. In one of the tiles, select a category and click or to the move the category to the other tile. To select more than one category, hold Ctrl and click on multiple categories. To move all categories at once, click or .

  3. To edit the order in which the categories display in command launch, in the Selected Results tile, select a category and click or . To move the selected categories to the top or bottom of the order, click or respectively. The Menu and Reports categories must be at the top.

  4. Click Save.
    The personal preference configuration is updated.

Command Launch Results

Each setting is described below:

Options Description

Available Results

Categories that do not display when running a search in command launch.

Selected Results

Categories that display when running a search in command launch.
