Escalate a Violation

With Rent Manager violations, you can escalate a tenant violation to the next stage if the issue hasn't been corrected in a timely manner. Only violations with more than one stage can be escalated. Charges, internal actions, stage information, letter template, and violation code information populate by default according to the settings established on the violation code's details page.

Related Privileges

Group Privilege Column
Tenants/Prospects Violations View, Edit

For more information, refer to Control User Access.

To escalate an open violation, do the following:

  1. Go to  arrow_forward Rental Info arrow_forward General arrow_forward Violations and select an open violation.
    The violation's details page displays.

  2. In the Stage Information section, click Escalate.

  3. In the Stage Information section, enter or select the needed stage information into the available fields.

    More Information

    The stages to which you can escalate are the available stages as of the time the violation was created. Any changes made to the stages are available only on violations created after those changes were made.

    Field Description

    New Stage

    The name of the stage to which the violation is escalating. By default, the next stage is selected. To view information on each escalation stage associated with the violation code, click View Stages.

    Escalation Date

    The date on which the violation is being escalated. By default, today's date populates.

    Days to Comply

    The number of days the tenant has to resolve the violation before it is escalated again. This field is automatically populated by the violation code's defined stages and cannot be edited.

    Due Date

    The date by which the tenant is expected to resolve the violation. The date that populates by default is determined by the Escalation Date plus the number of Days to Comply.

  4. In the Internal Actions section, enter the actions that must be taken for this escalation stage of the violation. If this information is defined on the violation code, it automatically populates in this section by default.

  5. If the all necessary internal actions have been completed or will be with this escalation (such as letters sent or charges added), check Actions Confirmed. If the violation code requires that the necessary actions must be taken before escalating, you will be unable to proceed with escalating the violation until this option is checked.

  6. In the Add Charge for Violation section, click Add Charge to add a charge to the violation. Charges established on the violation code populate by default. Charges added to a violation also add a history note to the tenant account and the violation.

    Related Privileges

    Group Privilege Column
    Receivables Tenant transactions Add
    History Tenant History/Notes Add
    Violation History/Notes Add

    For more information, refer to Control User Access.

    When adding a charge, enter information into the following fields on the Add Charge pop-up:

    Field Description

    Charge Type

    The charge type to use when this charge is posted. The posted charge expenses the general ledger (GL) account linked to the charge type.

    Unit

    The unit associated with the violation. This field cannot be edited.

    Date

    The date on which the charge is posted to the tenant account.

    Amount

    The amount of the violation charge.

    Comment

    An additional comment regarding the charge. This field automatically populates with information about the violation code, stage, and today's date.

    Reference #

    A unique number or phrase to help further identify the charge. If entered, the reference displays on the tenant's transactions page.

  7. In the History Notes section, you can add a history/note recording the escalation violation on the tenant's account.

    Related Privileges

    Group Privilege Column
    History Tenant History/Notes Add

    For more information, refer to Control User Access.

    To add a history note, add information into the available fields:

    Field Description

    Note

    Enter a custom message to display in the history note regarding the violation escalation, such as the reason for escalating.

    Category

    The history category to classify the type of history/note, such as Violations. For more information, refer to History Categories (Page).

    File

    To upload and attach a related image or document to the history/note, such as a photo of the violation being unresolved, click .

  8. In the Write Letter section, select whether you wish to send a Tenant-type or Violation-type letter template, then in the Letter field, select the letter template to send to the tenant regarding the escalation.

  9. Click Escalate.
    The selected letter generates for the tenant—allowing you to print it or send it directly to the tenant—and the violation is escalated to the next stage.
