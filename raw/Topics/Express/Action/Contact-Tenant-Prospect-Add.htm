Add a Tenant/Prospect Contact

Rent Manager allows you to add contacts to each tenant and prospect account you have in your database. On the tenant or prospect View Contacts pop-up, you can view and manage information about the people associated with your tenant and prospect accounts. Contacts can be other occupants of the unit, cosigners on the lease, business contacts, or other associated individuals. By default, the tenant displays as the Primary contact and is listed first in the list of contacts. By default, the primary prospect or tenant automatically displays first on this tab as a contact.

Related Privileges

Group Privilege Column
Tenants/Prospects Prospects View, Edit
Tenants View, Edit

For more information, refer to Control User Access.

To add a new contact to a prospect or tenant account, do the following:

  1. Go to arrow_forward Rental Info arrow_forward Tenants | Prospects and select a tenant or prospect from the list.
    The tenant or prospect's details page displays.

  2. On the Contacts tile, click Add Contact.

    More Information

    Click  Copy to duplicate the selected contact locally in this account or copy the contact to another account.

  3. If this is the primary contact for the account, check Primary. A contact can be made Primary to make them the main point of contact. Only one contact can be selected as Primary for each account. Primary is checked by default for the first contact entered for the account.

  4. To display this contact’s name on statements and printed labels, check Show On Statement/Labels. Only two contacts can have Show On Statement/Labels checked on a single account.

  5. Enter any of the following Personal Information for the contact.

    Field Description

    First Name

    The first name of the contact.

    Middle Name

    The middle name of the contact.

    Last Name

    The last name of the contact.

    Soc Sec#/

    Tax ID

    The contact's social security number. For commercial tenants, the field name of Tax ID displays, and the contact's tax identification number (TIN) should be entered.

    Related Privileges

    Group Privilege Column
    Tenants/Prospects View complete tenant SSNs Enabled

    For more information, refer to Control User Access.

    Email

    The contact's primary email address in which they can be sent reports, statements, and so on.

    Birthday

    The contact's date of birth.

    Employer

    The name of the contact's employer.

    Annual Income

    The contact's annual net income.

    Related Privileges

    Group Privilege Column
    Tenants/Prospects View annual income Enabled

    For more information, refer to Control User Access.

    License

    The license plate number of the contact's vehicle.

    Vehicle

    The make and model of the contact's vehicle.

    Type

    The user-created contact type that best describes the contact. For more information, refer to Contact Types (Page).

    Applicant Type

    The system-generated type of applicant that best describes the contact. For example, select Co-Applicant if the contact being added is included on the renters lease.

  6. In the Addresses section, select a user-created address type from the drop-down menu and enter the address into the field.

  7. In the User Defined Fields section, enter a Value for any applicable UDFs.

  8. In the Phone Numbers section, enter phone numbers (including area code) and extensions associated with user-created phone number types such as Home, Work, Cell, etc. Next to the number that you want Rent Manager to use in reports, bills, letters, scripting, or when you use rmVoIP to call the contact, check Default. If a phone number can be used for text messaging, check the box in the T column.

  9. Click Save.
    The contact is added to the tenant or prospect account.

    More Information

    Once the contact is saved, you can add an image of the contact. Back on the on the Contacts tile, click and select the contact from the tabs on the left. Click and drag an image to the center section, or click Upload to browse your computer for a file to attach. When finished, click Save.
