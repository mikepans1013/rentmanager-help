Add a Utility

Metered Utilities (MU) allows you to bill tenants for usage of utilities such as gas, electric, water, and sewer. Every billing period, individual meter readings are entered and utility consumption charges are calculated and billed to the appropriate tenant. For each utility that you measure, you must add that utility to Rent Manager.

Related Privileges

Group Privilege Column
Utilities Metered utilities Enabled
Utility information Add, View

For more information, refer to Control User Access.

Step 1: Enter Utility Information

To add a utility, do the following:

  1. Go to arrow_forward Services arrow_forward Metered Utilities arrow_forward Utilities.
    The Utilities page displays.

  2. Click Add Utility.

  3. In the Utility Information tile, enter the following information:

    Field Description

    Charge Type

    The charge type to use when charging tenants for the selected utility.

    Properties

    The properties at which this utility is available.

    More Information

    This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property.

    Source Utility for Readings

    If a single meter is being used for two or more utilities, select the other utility. Otherwise, leave this field blank.

    For example, water and sewer usage is often read from the same meter even though they have separate calculations. If Water is selected as the Source Utility for Readings for the Sewer utility, tenant readings from the water meter are duplicated in the sewer meter readings.

    Utility Name

    The unique name of the utility as it displays in Rent Manager.

Step 2: Enter Master Meter Information

Master meters record utility usage for an entire property (e.g., the water meter for an apartment building). This allows you to store and manage the meter data for the property and accurately track the total property utility usage and costs. You can also create master meter bills tied to each master meter and billing period to properly record your property-wide consumption and expenses in Rent Manager.

If there are no master meters for this utility, proceed to Step 3: Enter Additional Details.

To add master meter information, do the following:

  1. In the Master Meters tile, click Add Master Meters to add any master meters that record this utility's usage for an entire property.

  2. Enter information into the following fields:

    Field Description

    Default Expense Account

    The default vendor expense account to use on the master meter bills created for properties assigned to this utility.

    The expense account can be overridden for individual property master meters as needed.

    Default Vendor

    The default vendor account to assign to the master meter bills created for properties assigned to this utility.

    The vendor can be overridden for individual property master meters as needed.

    Default RUBS Template

    The default ratio utility billing system (RUBS) template to calculate the utility bill for each tenant at the property based on the master meter bill.

  3. In the grid below, enter information into the available columns.

    Column Description

    Property

    The property for which the master meter tracks consumption.

    Meter Number

    The unique meter number for this master meter. This may be a serial number or other identification number.

    Vendor

    The vendor account to assign to the master meter bills created for this property and the associated source utility and sub-utilities.

    Expense Account

    The expense account to use on the master meter bills created for this property and the associated utility.

    RUBS Enabled

    If selected, a RUBS template is used to calculate the utility bill for each tenant at the property based on the master meter bill.

    RUBS Template

    The RUBS template used to calculate the utility bill for each tenant at the property based on the master meter bill. This field is available only if RUBS Enabled is selected and at lease one RUBS template is created.

  4. To add additional master meters, click Add Master Meter and add that master meter's information.

Step 3: Enter Additional Details

After adding the information for the utility itself and any master meters, you can add contact information such as phone numbers, addresses, and additional comments regarding the utility and its provider. To enter additional utility details, do the following:

  1. In the Contact Information tile, enter the following information.

    Field Description

    Email

    The email address used to communicate with the utility company.

    Name

    The full name of the representative who is the primary contact at the utility company.

  2. In the Addresses tile, enter the primary address of the utility company. If this is the primary address for correspondence with the company, check Default. To verify the address is formatted properly, click Details.

  3. In the Phone Numbers tile, enter any phone numbers used for the utility company. For the primary phone number used for most correspondence, check Default. If the phone number can accept text messages, check T.

  4. In the Comment tile, enter any additional notes or information about the utility. To add a memorized comment, click .

  5. To create the utility and exit the pop-up, click Save & Close. To create the utility and leave the pop-up open to create more utilities, click Save & New.
    The utility is added to Rent Manager.
