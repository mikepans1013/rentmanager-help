Send a Text Message

Using the text messaging feature, you can communicate with tenants, prospects, owner prospects, vendors, property managers, and other Rent Manager users. This allows you to provide individual updates on maintenance requests, inform prospective tenants of available units, contact vendors about their services, and coordinate with other users in your company without leaving the software. In these situations, sending a single, quick text message can be more efficient for the user and recipient than scheduling time to make phone calls.

More Information

Text messaging with Rent Manager is a licensed feature. Contact your sales representative or sales@rentmanager.com for more information.

Related Preferences

In personal preferences, you can establish when or if Rent Manager notifies you that a message was received in the Text Messaging Center. For more information, refer to Text Message Options (Personal Preferences).

In order to send a text message to an entity, a phone number must be designated as text-enabled on the account. To mark a phone number as text-enabled, go to the View Contacts page of the account and, in the Phone Numbers section, check the box in the T column next to the appropriate phone number.

To send a text message, do the following:

  1. Go to arrow_forward Communication arrow_forward Texting/Phone arrow_forward Text Messaging Center.
    The Text Messaging Center page displays.

    More Information

    You can also send texts to individual entities, such as tenants and owners, by navigating to the corresponding page for the type of entity you want to contact. For example, you can go to arrow_forward Rental Info arrow_forward General arrow_forward Tenants and locate the tenant you want to contact. Then, use row actions, which are available from the menu next to each tenant in the list, and select Send Text.

  2. Click New Text.
    The Send Text pop-up displays.

  3. Enter the following information to create a new text message:

    Field Description

    Type

    The entity type to receive the text message. This determines what accounts display in the To field.

    To

    The name of the account to receive the message.

    Phone Number

    The text-enabled number to receive the message. If the account has multiple text-enabled numbers, the primary contact's number marked as Default populates first in the list.

    Message

    The message to be sent to the recipient. Text messages that exceed a character count of 160 are converted into multiple message segments of 160 characters, with a maximum of 1600 characters. Each message segment counts toward your text limit. The number of segments are indicated in the bottom left of the pop-up. You can use Insert Text Template to fill the message box with a saved template.

    Add Image

    Click to attach an image to the text message. This converts the text from an SMS message to a multimedia message (MMS).

  4. Click Send.
    The text message is sent, and displays in the list of conversations.
    You may need to update your filters to display the message you just sent.

More Information

The first text sent to a recipient from the text messaging center and any texts sent via text broadcast or automated notification include an opt-out message. If a recipient opts out, that phone number cannot receive texts from Rent Manager unless they choose to opt back in. Recipients can opt out or opt in at any time. If a recipient wishes to opt back into text messaging, they must text Start from the phone number they opted out with to the number they originally requested to opt out of.

Phone numbers that have opted out of text messaging are identified on the account's View Contacts pop-up, where the checkbox in the T column is replaced with the words Opted out in red text.
