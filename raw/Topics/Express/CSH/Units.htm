Units (Page)

The word unit refers to the physical spaces that are available to rent at each property. A property can have one unit, many units, or no units at all. A single-family home, for example, consists of one unit because there is only one space at the property available for rent. An apartment complex, however, has many units available for rent. Furthermore, the property used to represent your management company has zero units available for rent.

Related Privileges

Group Privilege Column
Properties/Units Units View

For more information, refer to Control User Access.

To view or manage your units, go to arrow_forward Rental Info arrow_forward General arrow_forward Units.

Column Descriptions

The following columns display on this page. By default, some columns display only if added via .

Default Columns Description

Address

The default addresses associated with this unit.

Floor

If applicable, the floor assigned to this unit.

Property

The property with this rental unit.

Square Footage

The size of this unit in square feet.

Unit

The name of this rental unit (e.g., Apt. 042).

Available Columns

Description

Bathrooms

The total number of bathrooms, including half bathrooms, in the unit. For example, for a unit with one full bathroom and one half bathroom, 1.5 displays.

Bedrooms

The total number of bedrooms in the unit.

City

The city as listed in the unit's Default address.

Comment

An optional note about this unit (e.g., Unit is ready to be re-keyed).

Max Occupancy

The maximum number of tenants who can live in this unit at one time.

Postal Code

The postal code as listed in the unit's Default address.

Property Short Name

The short name of the property associated with this rental unit.

Site Classification

The system-derived status indicating the operational state of manufactured housing sites. The classification that displays for each unit is based on the presence of an RV asset or home at the unit location, homeowner status, if the unit is occupied or vacant, if a lease is currently in a rent-free period, and unit status. For more information, refer to Site Classification.

State

The state as listed in the unit's Default address.

Street

 The street as listed in the unit's Default address.

Total Security Deposit

The default security deposit amount tenants are charged when leasing this unit

Unit Type

The category to classify this unit.

UDF: (Unit Type)

Each unit-type user defined field is listed on the Columns pop-up. The value entered on the unit for the selected user defined field displays.

Row Actions

Row actions, which are available from the menu to the right of each unit account, affect only the selected account. To perform actions on multiple accounts, the Bulk Actions menu allows you to select an action and then check all the accounts for which to apply the action.
