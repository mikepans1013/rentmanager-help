STR Reservations (Page)

The STR Reservations page allows you to match your guest's desired travel dates and amenities to a unit at your property and then make and edit reservations for those units. Additionally, this page allows you to see previous, current, and future reservations in a calendar view to visually represent the day to day overview of reservations.

Related Privileges

Group Privilege Column
Properties/Units Properties View

To access the STR reservations calendar, the additional privileges required are dependent on your selection in STR reservations system preferences for the Guest Account section. For more information, refer to Short Term Rental (STR) Reservations (System Preferences).

Depending on the option selected in system preferences, one of the privileges listed below are required. If the option Add Prospect or Tenant is selected, both privileges below are required.

Preference Option Group Privilege Column
Add Tenant Tenants/Prospects Tenants View
Add Prospect Tenants/Prospects Prospect View

For more information, refer to Control User Access.

Warning

To access the STR tool, at least one of your properties in Rent Manager must have the Short Term Rental or RV/Campground property type assigned.

To view the reservations calendar, go to arrow_forward Rental Info arrow_forward Short Term Rentals arrow_forward STR Reservations.

Blocks of time reserved in the calendar are color-coded based on the current status of the reservation. This allows you to easily discern whether or not a unit is available for a guest to rent.

Status Description

Unavailable

The block of time displays a gray bar if the unit has a Unit Status that makes it unavailable to rent.

Reservation

The block of time displays an orange bar if a guest has made a reservation but has not checked into the unit.

Checked In

The block of time displays a green bar if the guest was checked into the unit.

Checked Out

The block of time displays a red bar if a guest has checked out of their unit.

Filter Options

You can filter the calendar based on the guest's criteria. Additionally, select Available Units Only to filter the calendar so that only units available during the selected From and To dates display. Depending on whether the selected Property has a Property Type of Short Term Rental or RV/Campground, different filters display at the top of the page.

Option Description

Property

Select the property to display all of the units at the property on the STR Reservations page.

Unit Type

Select the unit type to filter the calendar so that it shows only units of a specific type.

From

Enter the date on which your guest plans to start renting the unit.

To

Enter the date on which your guest plans to depart.

Returning Guest

To find a guest already in your database, type their name into the search field. After selecting a returning guest, you can click to view their past reservations.

Amenities

Select the desired amenities requested by the guest.

Amps

Select the desired amperage for an electrical hookup requested by the guest. This filter is available only for a property type of RV/Campground.

Length (ft)

Enter the requested length of the unit in feet. This filter is available only for a property type of RV/Campground.

Width (ft)

Enter the requested width of the unit in feet. This filter is available only for a property type of RV/Campground.

Pull-Through Only

Select this option to display only units that allow a vehicle can drive through the spot, park, and exit, without needing to reverse. This filter is available only for a property type of RV/Campground.

# of guests

Enter the number of guests associated with the reservation. This filter is available only for a property type of Short Term Rental.

Bedrooms

Select the number of bedrooms desired by the guest. This filter is available only for a property type of Short Term Rental.

Bathrooms

Select the number of bathrooms desired by the guest. This filter is available only for a property type of Short Term Rental.

Use Exact Match

Enable this setting to display only units that match all of the guests preferences exactly. This filter is available only for a property type of Short Term Rental.
