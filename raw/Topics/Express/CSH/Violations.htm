Violations (Page)

Violations are used to track and document when tenants break the rules and regulations established for your properties. By replicating your rules and regulations in Rent Manager, you can track and manage tenants with violations, including the penalty for the infraction and any escalating penalties for failing to comply. From the Violations page, you can add, escalate, or close violations.

Related Privileges

Group Privilege Column
Tenants/Prospects Violations View

For more information, refer to Control User Access.

To view the Violations page, go to arrow_forward Rental Info arrow_forward General arrow_forward Violations.

On the Violations page, each violation record displays on a row with information organized into columns. Click on an inspection to open the Violation details page, where information specific to that violation is available.

Filter Options

The following filtering options are available on this page.

Option Description

Search

Enter the desired search criteria to display results containing the entered criteria.

Saved Filter

Use the to narrow the list of entities that display in the list by using other criteria.

Closed

Check to include violations marked as Closed on the Violation details page. Open violations display by default.

Show only communication not sent

Check to display only violations that have Comm Sent unchecked on the Violation details page. Open violations display by default.

Column Descriptions

The following columns are available on this page. By default, some columns display only if added via .

Default Columns Description

Comm Sent

If Comm Sent is checked on the Violation details page for the violation's Current Stage, the column displays a Check. Otherwise, the column displays blank.

If all the violations displayed on the page have the Comm Sent field checked, this column does not display.

Violation Date

The date of the infraction occurred or was brought to attention.

Property

The name of the property associated with the offending tenant.

Unit

The unit leased by the offending tenant.

Tenant

The tenant who was issued the violation.

Code

The code (e.g., TRASH, UNAUTH, LOUD) associated with the violation.

Current Stage

The current violation stage associated with the infraction.

Due Date

The date the infraction must be resolved by. Dates that are overdue display in red.

Escalation Date

The date of the last time the violation was escalated. If the violation is not escalated, the Violation Date displays.
Available Columns Description

Actions

If the Actions Confirmed field is checked on the Violation details page, the column displays a .

Action To Resolve

The action the tenant must take before the violation is closed.

Available Stages

The violation stages associated with the code being violated.

Category

The violation category associated with the code being violated.

CC&R Reference

The reference number in the Covenants, Conditions, and Restrictions (CC&R), or similar regulatory document, such as 6.1.2 - Unauthorized Vehicles.

Close Date

The date the violation was marked as closed.

Create Date

The date the violation was recorded in Rent Manager.

Create User

The user that recorded and saved the violation.

Current Stage Letter

The default letter associated with the violation's active stage as defined on the violation code.

Description

Any additional notes regarding the infraction and why it was issued.

Internal Actions

Instructions intended to assist users, such as if there is a grace period before the next escalation.

Internal Notes

Instructions intended to assist users specific to the code associated with the violation, such as if any code specific paperwork must be done before the violation can be closed.

Property Short Name

The short name of the property associated with the offending tenant.

Update Date

The date the violation was last updated.

Update User

The last user to update the violation.
