Reconciliation Changes (Page)

The Reconciliation Changes page displays information about changes to selected bank or credit card accounts since their most recent bank reconciliation or credit card reconciliation, such as changes to reconciled deposits or checks. Use this to quickly identify discrepancies between your accounts in Rent Manager and their real-world counterparts since your last reconciliation. Additionally, this page helps you return your previous cleared balance to the amount of the previous reconciliation.

Related Privileges

Group Privilege Column
Banks/Checks View reconciliation register Enabled
Reconciliation transactions Add

For more information, refer to Control User Access.

To view the changes to bank or credit card accounts since the most recent bank or credit card reconciliation, go to arrow_forward Accounting arrow_forward Banking arrow_forward Reconciliation Changes Register.

The following fields display relevant information about the selected Account.

Related Privileges

This field populates with only banks and credit cards to which you have access. Your access to banks and credit cards can be managed on the user's details page. For more information, refer to Limit Access to a Bank or Credit Card.

Field Description

Reconciliation changes since last reconcile on MM/DD/YYYY

The most recent reconciliation date and the starting date for the changes.

Previous Cleared Balance

The balance that was cleared through bank reconciliation or credit card reconciliation on the account's most recent reconciliation date.

Current Cleared Balance

The new balance following changes to transactions included in the most recent reconciliation.

Difference

The amount gained or lost due to the difference between the Previous Cleared Balance and Current Cleared Balance, calculated using the following formula:

Difference = Current Cleared Balance – Previous Cleared Balance

The Difference is equal to the total value of transactions changed since the most recent reconciliation. Use the difference as a guide to rebalance your transactions. When the difference reaches zero, you can start your next reconciliation.

Column Descriptions

The following columns are available on this page.

Column Description

Change Date

The date and time the change was made to the transaction.

Transaction Type

The category of each transaction. For example, if a deposit was modified after being cleared in a reconciliation, Depositdisplays.

Transaction Date

The date of the transaction as it displays on the Bank Registers.

Description

A brief description of the change to the transaction.

Changed By

The username of the person who made the change.

Amount

The total value of the transaction.

Reconcile Date

The date of the transaction's most recent reconciliation.
