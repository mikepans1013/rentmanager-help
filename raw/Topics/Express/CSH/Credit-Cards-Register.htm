Credit Card Registers (Page)

This page displays the transactions (charges, credits, and payments) associated with the currently selected credit card account. This page makes it easy to manage your credit card transactions and reconcile the transactions against actual credit card statements.

Related Privileges

Group Privilege Column
Payables Credit card transactions View

For more information, refer to Control User Access.

To view and manage credit card transactions, go to arrow_forward Accounting arrow_forward Banking arrow_forward Credit Card Register.

Column Descriptions

The following columns display on this page. By default, some columns display only by using .

Default Column Description

Date

The date the credit card transaction took place.

Reference

If applicable, the note entered by a user describing the type (CC, check number, and so on) of transaction.

Information

Additional information about the transaction including the vendor name and information entered in the Memo or Comment fields of the transaction.

Cleared

A displays if this transaction was reconciled.

Charge

The dollar amount charged to the card.

Credit

The dollar amount credited to the card.

Balance

The running balance of the credit card account as of today's date.

Properties

The short name of the properties selected in the transaction.
Available Column Description

Attachments

A icon displays if there are any files attached to the transaction, such as a digitally scanned copy of a receipt or invoice.

Comment

If applicable, the note entered by a user providing more information about the transaction.

Created By

The full name of the user who created the transaction.

Payee Name

The name of the payee as associated with the transaction.

Vendor

The name of the vendor as associated with the transaction.

Related Privileges

Group Privilege Column
Banks/Checks Reconciled transactions Add, Delete

For more information, refer to Control User Access.

If the transaction has not yet been reconciled but is already accounted for, click Mark as reconciled to manually clear the transaction. The displays in the Cleared column.

If the transaction is already marked as cleared but is not accounted for and still needs to be reconciled later, click Mark as not reconciled to remove the transaction from reconciliation. The is removed from the Cleared column.

Related Preferences

Enable the Show Confirm Reconcile Pop-Up option in personal preferences to receive a pop-up warning whenever a transaction is cleared this way outside of the reconciliation process. For more information, refer to General Settings (Personal Preferences).
