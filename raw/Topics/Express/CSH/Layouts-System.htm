System Layouts (Page)

Custom layouts give you the ability to customize how the details page displays in select areas of Rent Manager Express, similar to custom tabs in Rent Manager 12. Fields can be added, deleted, or repositioned on a page as needed with layouts, and any data entered or updated via a layout is instantly reflected in the database.

You can create system layouts to grant access to select user roles and property types. This allows you to limit what users see and how they interact with your data or add additional fields and user-defined fields (UDFs) to a tile for easier access. It also gives you the ability to create a unique layout for specific property types, such as commercial or short term rental (STR) properties.

Related Privileges

Group Privilege Column
Setup Manage System Layouts Enabled

For more information, refer to Control User Access.

To add and manage system layouts, go to arrow_forward Administration, then go to Customization arrow_forward System Layouts. In the Layout Type section on the left, select the desired entity type.

Column Descriptions

The following columns are available on this page:

Column Description

Name

The unique name used to identify the layout.

System Default

A displays if the layout is set as the default layout for all users.

Type

Indicates whether the layout is a Rent Manager default layout (Standard) or a user-created layout that can be customized (System). Standard layouts cannot be modified or deleted, but they can be copied to a new System layout.

Assigned Roles

The user role(s) with access to this layout.

Assigned Property Types

The property type(s) for which this layout is available. This option is not available for Issue or Asset layouts.

Row Actions

The following row actions are available from the menu:

Option Description

Make Default

Set the system-wide default layout for the selected entity for all users. This layout displays by default only when viewing pages associated with the selected property type(s).

Assign Roles

Select the property type(s) for which this layout is available. For example, a tenant-type system layout with additional commercial information can be limited to only tenants associated with Commercial properties.

Edit

Related Privileges

Group Privilege Column
Setup Design Layouts Enabled

For more information, refer to Control User Access.

Customize the system layout. This option is not available for Standard layouts.

Copy

Related Privileges

Group Privilege Column
Setup Assign System Layouts Enabled
Design Layouts Enabled

For more information, refer to Control User Access.

Copy the layout as a new, editable layout. This is an efficient way to make minor changes to an existing layout's structure without starting from a blank template.

Export

Save the layout as a file that can be stored on your computer outside of Rent Manager. You may wish to export a layout to keep a backup copy stored locally, share with a coworker, or move it to a different Rent Manager location.

Export to Online Template Library

Make your layouts available to other Rent Manager users via the Online Template Library.

Delete
