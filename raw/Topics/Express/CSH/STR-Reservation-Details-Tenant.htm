Tenant Reservations Details (Pop-Up)

The Reservation Details pop-up provides information about a tenant's short-term rental (STR) reservation, including the property, number of guests, vehicle information, and transaction history. From the Reservation Details pop-up, you can also edit and update reservations.

Related Privileges

Group Privilege Column
Tenants/Prospects Tenants View

In addition to these privileges, you must have access to at least one property with either a Short Term Rental or RV/Campground property type assigned.

For more information, refer to Control User Access.

Warning

To access the STR tool, at least one of your properties in Rent Manager must have the Short Term Rental or RV/Campground property type assigned.

To view an STR tenant's reservation info, go to arrow_forward Rental Info arrow_forward General arrow_forward Tenants and select a tenant from the list. Then, on the Reservation tile, the right, click . Next to the reservation you want to review, click arrow_forward Details.

General Info

On this tab, you can view or update basic information about the guest.

More Information

Click Email Payment Link to send an email to your guest with a link to the STR payment portal for their reservation. Alternatively, open the drop-down menu and select Text Payment Link to message the guest's text-ready phone number, or Copy Payment Link to copy the link URL to your clipboard.

The messages sent via email or text can be customized in system web preferences. For more information, refer to RV/Campground Online Booking General (System Web Preferences).

The following fields are available from this section:

Field Description

Confirmation #

A system-generated, eight-digit code used to identify the reservation.

Comment

Any additional notes or comments about the reservation.

Lead Source

How or where the guest learned about your property or business.

Related Preferences

When guests make reservations, the STR Online Booking Portal displays only the lead sources selected in system web preferences. For more information, refer to RV/Campground Online Booking Guest Info (System Web Preferences).

# of Nights

The calculated number of nights between the Arrival date and the Departure date. If no Departure date is entered, this value displays 0.

Arrival

The date the guest plans to arrive.

Departure

The date the guest plans to leave. Rent Manager automatically ends the rental on the specified departure date.

# of Adults

The number of adults associated with the reservation.

# of Children

The number of children associated with the reservation.

# of Pets

The number of pets associated with the reservation.

Property

The property where the guest wishes to stay.

Unit

The unit the guest reserved. If applicable, click to open the Unit Selector and update the unit the guest wishes to reserve.

More Information

If applicable, click to lock the reservation and charge the guest a lock fee. Locking guarantees that the guest receives the spot they reserved and apply to only properties with a Property Type of RV/Campground. This option displays only if the property's applicable rate schedule has the option Charge guest a lock fee to guarantee the selected site checked. For more information, refer to Add an STR Rate Schedule.

Source

Where the guest reservation was created. When manually adding a reservation, Rent Manager displays. If the guest made the reservation online, STR Online Booking displays.

RV/Vehicles Info

On this tab, you can view or update information about the guest's vehicle. If you are adding a reservation at a property with a Property Type of RV/Campground, you can also input information about the guest's RV.

To add an additional RV or vehicle, click .

The columns below are available in this section.

Related Preferences

You can make some fields required for guests make reservations through the STR Online Booking Portal in system web preferences. For more information, refer to RV/Campground Online Booking Guest Info (System Web Preferences).

Column Description

# of Slide Outs

The number of room extenders on the guest's RV or vehicle.

Amps

The amperage(s) of the electrical hookup that the guest's RV requires.

Length

The length of the guest's RV or vehicle. The RV length must be equal to or less than the value entered on the unit's RV/Campground Information tile in the Length field.

License

The license plate number of the guest's RV or vehicle.

Make

The brand of the guest's RV or vehicle.

Model

The model of the guest's RV or vehicle.

Slide Outs

The type(s) of room extenders on the guest's RV or vehicle. Guests can only reserve units that allow their type of slide out as listed on the unit's RV/Campground Information tile in the Slide Outs field.

Type

The guest's RV type (Fifth Wheel, Hybrid Trailer, Pop-Up Camper, and so on). Guests with an RV type that is listed on the unit's RV/Campground Information tile in the Prohibited Eqpt. field cannot reserve the unit.

Width

The width of the guest's RV or vehicle. The RV width must be equal to or less than the value entered on the unit's RV/Campground Information tile in the Width field.

Year

The manufacture year of the guest's RV or vehicle.

Transactions

On this tab, you can view information about charges, payments, taxes, and other transactions associated with this reservation. In addition, you can view the payment policy for the reserved unit.

The following columns are available from the Transactions section:

Column Description

Amount

The total dollar amount of the payment or charge.

Comment

An optional comment entered when the charge or payment was created. The comment also displays on the guest's View Transactions page.

Date

The date that the charge or payment was processed.

Description

The description of the charge type associated with the transaction.

Reference

An optional reference number used to organize transactions in Rent Manager.

In addition, the Payment Policy section displays the payment policy selected on the property's STR Settings page at the time of booking.
