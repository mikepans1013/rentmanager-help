Short Term Rental Property Details (Page)

You can use Rent Manager properties to track data for any financial entity that generates revenue and incurs expenses, including property management companies. Create properties for any real estate you manage, such as single-family homes, duplexes, apartment buildings, strip malls, storage facilities, and manufactured home sites.

Properties are the highest level entity in Rent Manager. You can create and link other entities to properties, such as units and tenants. Units and tenants linked to a property inherit settings and charges set up at the property-level.

The Property Type of Short Term Rental, should be used for properties like vacation homes, hotels, or hostels. This property type works similarly to most other property types (such as Apartment, Single Family, and so on) and uses internet listing service (ILS) sites for marketing, but still counts as an short-term rental (STR) property for reservations, reporting, and other Rent Manager functions. The details page of a short-term rental property displays an overview of all the information related to that property.

From the property details page, you can access an overview of property information, update that information, and configure property-level settings.

More Information

The tiles that display on this page vary depending on the selected Property Type. This topic covers properties with a type of STR selected.

More Information

The following tiles display by default. If a custom layout is applied to your details page, you might not see all of the following tiles. For more information about creating and assigning layouts, refer to My Layouts (Page) and System Layouts (Page).

Images

Displays property-type images in a carousel. To add an image, click or Upload Images. These images can be used for marketing your property on internet listing service (ILS) websites.

General

Information about the property and contact information for the property manager.

Field Description

Active

When unchecked, this property is considered inactive, which means users cannot select or access this property in other areas of Rent Manager. ePay is also disabled for inactive properties.

More Information

If there are occupied units at the property and you uncheck Active, a warning displays after clicking Save.

The Departure Date entered will be applied to all guests with active reservations at the property. Optionally, check Add an inactive status to vacant units if units with no reservation should also be set as inactive. After setting the date, click Save to make the property inactive and end all reservations at the property.

To make the property inactive without setting departure dates, click Save without adding a date.

Display Color

A color to help identify properties of certain types, groups, or any other specifications you prefer. The color displays as a bar to the left of the property in some areas of Rent Manager, such as the Property list page.

Email

The email address for contacting the manager of the property. The email subscription status displays as (active), (partially unsubscribed), or (unsubscribed).

To view and configure the subscription status for emails associated with the property manager's account, click Manage Subscriptions. For more information, refer to Unsubscribe From Emails.

Full Name

The complete legal name for the selected property.

Manager

The name of the person responsible for managing the property.

Property Type

The classification that best suits the property. For short-term rentals such as vacation properties or hotels, Short Term Rental is selected.

Warning

Changing the property type of an established property may result in the loss of some functions.

For example, if you change a property type from Short Term Rental to Apartment, reservations are converted to leases, and Arrival and Departure dates become Move In and Move Out dates.

Short Name

An abbreviated name for the property (ten characters or fewer) that displays on reports.

Primary Address

The addresses associated with this property, including any custom address types.

For the address type that has the property's primary address, check Default. For the address type that has the property's address used for billing, check Billing. Click View on Map to view the address's location in Google Maps.

Property Logo

A visual logo to represent the property or company. Logos can be added to correspondence and marketing materials. Only one image can be used at a time.

Other Information

Additional information associated with the property, such as the property tax ID and square footage.

Field Description

AR Automation Schedule

The accounts receivable (AR) automation schedule to use as the default schedule for the selected property. For more information, refer to Accounts Receivable Automation Schedules (Page).

Related Preferences

If <System Default> is selected, the automation selected in the Default Schedule field in system preferences is used for this property. For more information, refer to Task Automation (System Preferences).

Assign Service Issues

The user who should be assigned to new issues at this property by default. This selection can be overridden on any individual issue.

Related Preferences

If <System Default> is selected, the user selected in the Assign new service issues to field in system preference is assigned to new issues at this property. For more information, refer to Service Issue General Options (System Preferences).

Default Inspector

The user who is assigned to perform or manage inspections at this property.

Enable Lockbox

Enables tenants who are associated with this property to use the Zego Pay Lockbox service.

Related Preferences

This option displays only if the Zego Pay Lockbox service is enabled in system preferences and only for properties that are both marked as Active and enabled for ePay. For more information, refer to Property ePay Settings (Pop-Up) and Tenant Lockbox ePay (System Preferences).

NSF Fee

The default non-sufficient funds (NSF) fee charged to tenants whose payments are rejected.

To set a property-specific NSF fee amount, select Override system default and enter the property's NSF fee amount in the Custom Amount field.

Related Preferences

The value displayed in parenthesis automatically populates with the default amount associated with the NSF charge type selected in Non-Sufficient Funds Fees system preferences.

For more information, refer to General Ledger System Charge Types (System Preferences).

Posting Day

The day of the month that recurring charges are posted to the tenant accounts of this property.

If recurring charges should always be posted on the last day of the month, enter 31. If 31 is entered, months with fewer days will post on whatever the last day of the month is.

Property Amenities

The amenities that are available at the property, such as Wi-Fi, pool access, or included appliances.

Property Tax ID

The tax identification code for the selected property.

Rent Charge Type

Charge type(s) used to record rent charges for this property. This is important for certain reports, such as the Summary Rent Roll, and late fee calculations when the On Rent Only option is selected on the Late Fees pop-up.

Statement Method

The default setting for the preferred delivery method of tenant statements for tenants associated with this property.

<Use System Default>

By default, tenants prefer to receive statements using the default Statement Method set in system preferences. The default method is displayed in parentheses.

For example, if the Statement Method is set to Print in system preferences, the field displays <Use System Default (Print). For more information, refer to General Report Options (System Preferences).

No Statement

By default, tenants prefer not to receive tenant statements by default.

Email Attachment

By default, tenants prefer to receive statements as PDF email attachments by default.

More Information

This option can be used with Task Automation to send tenant statements on a schedule. For more information, refer to Add a Tenant Statement Automation.

Print

By default, tenants prefer to receive printed tenant statements by default.

VPO

By default, tenants prefer to receive printed tenant statements mailed through Virtual Post Office (VPO).

More Information

This option can be used with Task Automation to send tenant statements on a schedule. For more information, refer to Add a Tenant Statement Automation.

Related Preferences

This option displays only if Virtual Post Office is enabled in Rent Manager. For more information, refer to VPO Defaults (System Preferences).

Text Numbers

The phone number(s) that is available to display as the sender number when sending text messages. For more information, refer to Create a Text Broadcast.

Total Sq Ft

The total square footage of this property.

User Privileges

The users who can access this property and its related entities, such as tenants, units, and reports specific to this property.

History/Notes

The most recent history/note items on the property account. History/notes record information about actions taken for this property, such as service issues and system notes.

Field Description

Date

The date the history/note was created.

Note

Information about the history/note describing the event, interaction, or message.

Type

The category the history/note falls into (e.g., Service Issue, Email, Call, Visit, etc.).

Fiscal Year

The fiscal year used for accounting purposes on this property. To set a different fiscal year for this property only, check Override Default and choose the Start Date and End Date for this property's fiscal year.

Related Preferences

The default fiscal year for all properties is set in system preferences. For more information, refer to General Ledger Settings (System Preferences).

Time Zone Offset

Set the time used on the property's web portals (i.e., Tenant Web Access (TWA) or Owner Web Access (OWA)), allowing for an accurate time stamp when recording user actions.

Related Preferences

The default time zone for all properties is set in system web preferences. For more information, refer to Web Access Time Zone (System Web Preferences).

To set a property-specific time zone, check both Override System Web Preferences and Enable Time Zone Offset and then select a time zone from the drop-down list. You can also check Observe Daylight Savings Time, if applicable.

Field Description

Enable Time Zone Offset

Allows you to select the appropriate time zone for the property from the drop-down list.

Observe Daylight Savings Time

If your region observes daylight savings time (DST), check this option to have Rent Manager automatically adjust the time for DST as necessary.

Override System Web Preferences

Enables you to override the time zone selected in system web preferences.

Time Zone

The applicable time zone for this property. By default, the time stamp for web activities is the current LCS server date and time.

Phone Numbers

The phone and other contact numbers associated with the property. To indicate that the phone number can receive text messages, check T.

User Defined Fields (UDFs)

Any custom fields set up by a user. Create user-defined fields to record custom information in addition to the default fields available in Rent Manager. User-defined fields display on this tile based on when a value was added to the UDF. The order in which the user-defined fields display may not match the order that displays in the User Defined Fields pop-up or on the User Defined Fields page. This tile displays up to six UDFs with values.

Recurring Charges

The active recurring charges that post to tenants of this property at specified intervals. Tenants inherit recurring charges set at the property level. You can add new recurring charges, including commercial recoverable expense (CRE) charges, from this tile.

Field Description

Amount

The dollar amount of the recurring charge that posts to the tenant's account.

Charge Type

The charge type to be associated with this recurring charge.

Comment

A phrase or note to show on the View Recurring Charges page.

Frequency

The number of months, weeks, or days that should elapse between each posting of the recurring charge. For example, if a tenant has a Monthly rent period, a frequency of 1 means the recurring charge posts once every month, and a frequency of 3 means the recurring charge posts once every three months.

From Date

The first date on which this recurring charge is applied to the associated tenant accounts when recurring charges are posted.

To Date

The final date on which this recurring charge can be posted to the tenant's account. After this date, this recurring charge is no longer applied to the associated tenant accounts when recurring charges are posted.

Charge Type Banks

Related Privileges

This field populates with only banks to which you have access. Your access to banks can be managed on the user's details page. For more information, refer to Limit Access to a Bank or Credit Card.

Which bank accounts to use for depositing tenant payments, based on the charge types those payments are allocated towards.

Lease Term Rent Offset

Related Privileges

Group Privilege Column
Tenants/Prospects Lease Terms View

For more information, refer to Control User Access.

Related Preferences

This tile displays only if the Allow rent offset to be overridden at the property level system preference is enabled. For more information, refer to Lease Renewals (System Preferences).

This tile displays the difference in the renewal rent amount between the original lease term and the newly selected lease term when offering lease renewals at this property.

Column Description

Duration

The lease term duration in days, months, or years.

Name

The name of the lease term.

Rent Offset

The difference in the renewal rent amount between the original lease term and the newly selected lease term when offering lease renewals.

For example, if the current base rent amount (without rent offset applied) is $1000, and they renew their lease for a lease term that has a -5% rent offset, 5% of the base rent amount ($1000) is subtracted from the base rent amount to get the new rent amount ($950) for the new term.

New Term Rent Amount = Original Term Rent Amount +/– Rent Offset

Reservable Amenities

Amenities that tenants at this property can reserve for use, such as a clubhouse or car charging stations.
