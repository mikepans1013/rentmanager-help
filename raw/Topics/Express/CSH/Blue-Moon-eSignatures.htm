Blue Moon eSignatures (Page)

The Blue Moon eSignatures page allows you to track the progress of Blue Moon lease forms with a requested eSignature. From this page, you can view, resend, or delete existing Blue Moon documents that have pending eSignature requests. This helps you track progress automatically rather than relying on time-consuming manual follow-ups.

More Information

This page tracks only Blue Moon eSignature forms generated via Rent Manager. Blue Moon eSignature forms initiated through the Blue Moon portal do not display in the register.

Related Privileges

Group Privilege Column
Blue Moon Manage eSignature Documents Enabled

For more information, refer to Control User Access.

To access the Blue Moon eSignatures page, go to arrow_forward Communication arrow_forward Signable Documents arrow_forward Blue Moon eSignatures.

Filter Options

The following filters options are available on this page.

Option Description

Date Initiated

Include Blue Moon lease forms that were sent requesting an eSignature during the date range selected.

Status

Filter the list by status to narrow down which Blue Moon lease forms with a requested eSignature display.

Completed

The document was signed by all parties (residents and the owner or representative).

Expired

The eSignature request for the document expired. This applies only to requests with an Expiration Date in the past.

In Progress

At least one resident signed the document where the eSignature was requested.

Pending

The Blue Moon document and corresponding eSignature request was initiated and is still awaiting resident signature(s).

Signed

All residents signed the document and it is ready for completion by the owner or representative.

Column Descriptions

The following columns are available on this page.

Column Description

Date Completed

The date on which the signed document was marked complete.

Date Initiated

The date that the Blue Moon eSignature was requested through Rent Manager.

Document Status

The current status of the document: Pending, In Progress, Signed, Completed, Expired, or Expired (Renewal Offer).

Expiration Date

The date this document is set to expire and become unavailable to sign, if applicable.

Leasing Agent

For a tenant or prospect document, this displays the Leasing Agent selected on the tenant or prospect's details page.

Name

The name of Resident 1 in the Blue Moon document that was sent out with an eSignature request.

Property Short Name

The abbreviated short name of the property associated with the unit.

Signed

The number of signatures received and how many signatures in total are needed for the selected document.

Unit

The name of the unit associated with the Blue Moon lease.
