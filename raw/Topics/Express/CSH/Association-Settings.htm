Association Settings (Pop-Up)

The Association Settings pop-up allows you to customize the messages viewable to homeowners when viewing or submitting requests in Tenant Web Access (TWA). Additionally, you can provide files to download, as well as determine if board members can view and/or vote on requests in TWA.

Related Privileges

Group Privilege Column
Properties/Units Property View
Associations Manage Committees Enabled

For more information, refer to Control User Access.

To view the Association Settings pop-up, go to arrow_forward Rental Info arrow_forward General arrow_forward Properties and select an association-type property. Then, on the action bar to the right, click arrow_forward Board Members and click Association Settings.

More Information

Only properties with a Property Type of Association (as entered on the Property details page) have a Board Members pop-up.

The Association Settings pop-up consists of different tabs, each containing options to be applied to the list of board members associated with the property. When finished, click Save to apply the settings for the property. Each tab is described in more detail below.

Member Settings

The Member Settings tab allows you to customize the makeup of a board member's Tenant Web Access account.

Architectural Requests Page

The Architectural Requests Page section allows you to customize what displays on the Architectural Requests page in Tenant Web Access.

Option Description

Custom TWA Message

Establish a greeting or reminder to display in TWA for the property's homeowners. If no message is entered, the default message set in system web preferences displays.

Files to Display

Manages the files that display on the Architectural Requests page in TWA, for example, you may want to provide a document that lists the guidelines for submitting an architectural request.

To add a new file, click Add and enter the following information:

File

To browse your computer for a file to attach, click .

Name

The name of the file. This name displays to tenants on TWA.

Description

A summary of the file's contents. This summary displays to tenants on TWA.

Submit Request Page

The Submit Request Page section allows you to customize what displays on the Architectural Requests page when the TWA user is submitting a new architectural request.

Option Description

Custom TWA Message

The greeting or reminder to display in TWA for the property's homeowners. If no message is entered, the default message set in system web preferences displays.

Require a File Attachment

If checked, the homeowner is not able to submit a new architectural request without uploading an attachment.

Board Settings

The Board Settings tab allows you to set custom page messages to board members, as well as establish the access level of board members in Tenant Web Access necessary to view or vote on architectural requests.

Requests To Review Page

The Requests To Review Page section allows you to customize what displays on the Architectural Requests page when the TWA user selects the Requests to Review tab.

Option Description

Custom TWA Message

The greeting or reminder to display in TWA for the property's committee and board members. If no message is entered, the default message set in system web preferences displays.

Allow board members to view requests

If checked, board members listed on the Board Members pop-up for the property can view architectural requests in Tenant Web Access.

If this option is selected, you can also enable Allow board members to vote on requests so they can vote to approve or deny architectural requests.
