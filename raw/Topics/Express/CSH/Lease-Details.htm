Lease Details (Page)

The leases tool in Rent Manager allows you to create and manage leases for your tenants directly from their details page. Once a lease has been added, you can view the details of each lease and adjust them as needed.

Related Privileges

Group Privilege Column
Tenants/Prospects Tenants View, Edit
Modify tenant movein/moveout dates Enabled

For more information, refer to Control User Access.

To view lease details for a tenant, go to arrow_forward Rental Info arrow_forward General arrow_forward Tenants and select a tenant from the list. Then, on the Leases tile, click and, on the View Leases pop-up, select the lease whose details you wish to view.

On the left side of the pop-up, you can select any of the past lease renewals. By default, the pop-up opens with the most recent lease.

Lease Information

The Lease Information tab displays basic information associated with the lease, including the property, unit, lease terms, insurance coverage, and user-defined field (UDF) values.

Field Description

Expected Move Out

The date on which the tenant is expected to move out of the unit. This date can be used in place of a move out date for reporting purposes.

Home

The name of the home-type asset associated with the tenant, specified in the asset's Asset Name field. This field displays only for tenants with a leased unit associated with a property that is a Manufactured Housing property type.

Insurance

If LeaseTrack insurance tracking is enabled in Rent Manager, the information that displays depends on the status of the insurance policy for the selected lease, including manufactured housing leases. If the tenant or homeowner is enrolled in a master policy, the master policy's liability limit and type are displayed here.

For more information, refer to LeaseTrack Insurance.

Related Preferences

This field displays only if Enable insurance tracking is checked. For more information, refer to Activate and Set Up LeaseTrack Insurance.

Lease Documents

The documents uploaded to be stored on the lease. This also displays any published signable documents associated with the tenant.

Related Preferences

If you allow tenants to view their leases in Tenant Web Access, they can also access any lease documents uploaded in the portal. For more information, refer to Tenant Web Access Leases Page Setup (System Web Preferences).

Lease End

The date on which the lease expires. Paired with the lease start date, this date can be used to help create a renewal term if no lease term is available when generating renewal offers.

Lease Sign

The date on which the lease was signed by the tenant. This date can be useful in determining which lease came first for tenants with multiple leases.

Lease Start

The date on which the lease begins. This date can be used to help create a renewal term if no lease term is available when generating renewal offers. For more information, refer to Create Renewal Offers.

Lease Term

The expected duration of the lease such as 6 Months or 12 Months.

Market Rent

The average value of the unit in relation to similar rental units in that area.

Move In

The date on which the tenant moves into the unit.

Move Out

The date on which the tenant officially vacates the unit.

Notice

The date on which the tenant gave notice that they are moving out of the unit. This date can be used to generate results on when a unit becomes available for reporting purposes.

Original Start Date

The date on which the lease is initially set to start. This date is selected when the lease is created.

Property

The property at which the tenant is leasing.

Rent Free Period

The Start Date and End Date during which the unit does not generate income due to a rent-free promotion.

This field is available only if the associated unit is located at a manufactured housing-type property and has a home-type asset with the Dealer Owned or Lender Owned homeowner status applied.

Unit

The unit that the tenant is leasing.

User Defined Fields

The Name and Value of any lease-type user-defined fields. Required UDFs are marked with an asterisk (*) and must have a Value entered to save any updates made to the lease.

RV Information

If the leased unit is located at a manufactured housing-type property and does not have a home-type asset, the RV Information tab displays details about the resident-owned RV associated with the lease.

Field Description

# of Slide Outs

The total number of extendable sections of the RV.

Amps

The amperage(s) of the electrical hookup that the RV requires.

Homeowner Status

The ownership status of the RV (Resident Owned, Employee Owned, or Change of Ownership).

Length

The value to describe how long the guest's RV is.

License

The RV's license plate.

Make

The manufacturer of the RV.

Model

The specific model of the RV.

Slide Outs

The location(s) of the RV's slide outs (Driver, Passenger, or Rear).

This RV is currently on the lot

Indicates whether the resident-owned RV is on the leased lot.

Type

The RV type (Fifth Wheel, Hybrid Trailer, Pop-Up Camper, and so on).

Width

The value to describe how wide the guest's RV is.

Year

The year the RV was manufactured.
