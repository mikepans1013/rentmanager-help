Interest Options for Security Deposits (Pop-Up)

Security deposit interest options in Rent Manager allow you to set specific interest conditions for handling the interest earned by tenants on their security deposits.

Related Privileges

Group Privilege Column
Properties/Units Properties View, Edit

For more information, refer to Control User Access.

To view the Interest Options for Security Deposits pop-up, go to arrow_forward Rental Info arrow_forward General arrow_forward Properties and select a property from the list. Then, on the Interest Options for Security Deposits tile, click .

Field Descriptions

The following fields display on the Interest Options for Security Deposits pop-up.

Option Description

Enable Interest

Allows interest to be collected on security deposits at the selected property.

Override System Preference

Replaces the interest options settings in system preferences.

Interest Calculation

How Rent Manager calculates earned security deposit interest.

Simple

Tenants earn interest only on their security deposits.

Annual Compounding

Tenants earn interest on both their security deposits and the interest already earned on those deposits. When calculating interest across more than one year, the interest is compounded on an annual basis using the Rates schedule defined either on this window or on the details page of the specific property.

Disbursement Method

How Rent Manager applies the interest tenants earn on their security deposits.

Credit

The interest earned is allocated as a credit towards the charge type that you select in the Credit Charge Type drop-down list.

Apply to Security Deposit

The earned interest is applied as additional held security deposits for the tenant. If a tenant has more than one type of security deposit charge on their account, the interest is applied proportionally amongst those charges.

Rates

The annualized rates in which interest is earned on security deposits. The following columns display.

Year

The year for which the rate of interest applies.

Rate (%)

The annualized interest rate percentage.

More Information

Use the Rates table to determine the first year to start calculating interest on held tenant security deposits and to track the rate change in subsequent years.

Every year prior to the earliest year entered into the Rates table is calculated at 0%, meaning that interest is not earned on deposits held during those years.

If a year is skipped in the Rates table, Rent Manager automatically uses the rate of the most recent year in which a rate was entered.
