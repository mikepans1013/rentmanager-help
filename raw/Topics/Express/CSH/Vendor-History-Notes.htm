Vendor History/Notes (Pop-Up)

History/note items allow you to record information that supplements or clarifies what’s entered in other fields, such as notes about phone conversations, details for scheduled tasks, and inventory transactions. While Rent Manager automatically creates some history/note items, you can also record information based on your needs. This makes it easier to track events related to each vendor and provide additional details for internal reference.

Related Privileges

Group Privilege Column
Payables Vendors View

For more information, refer to Control User Access.

Filter Options

The available filter and sort options are listed below. Depending on the size of your browser window, these filters may display at the top of the page or you may need to click to view the filter options.

Option Description

Search

You can type in the Search field to narrow the list to match your search criteria.

Filter By Date

Select or enter the From and/or To dates to filter notes created during the selected dates. Click to select a relative date range.

Users

Click the drop-down list and select the desired user(s) to filter for items created by one or more users.

History Category

Click the drop-down list and select the desired categories to include. To include history/note items with no category, select Unassigned.

Type

Click the drop-down list and select the desired types of history/note items.

Only Notes with Attachments

Check to display only history/note items that have an attachment.

Column Descriptions

The following columns are available on this page.

Column Description

Pin

If the history/note item has Pin enabled, displays. If there are no pinned notes, the column does not display.

Type

The system-generated history/note type. For example, if the history/note item is linked to a service issue, the Service Issue type displays.

Date

The date and time the note was created.

Note

The information to describe the history/note (e.g., Called vendor to schedule HVAC maintenance). If no text is entered, the column displays blank.

If an attachment is uploaded to the history/note item, displays. Click to download the attachment or open it in a new tab.

Category

The category of the history/note item selected from the available history categories. If no category is selected, the column displays blank.

User

The user who created the history/note item. If this is a system-generated history/note item, the user displays as Administrator. If the history/note item was generated from Tenant Web Access (TWA), the user displays as <Unassigned>.
