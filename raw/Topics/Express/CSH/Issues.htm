Issues (Page)

The Issues page gives you an overview of each of your issues. Issues can be created or updated directly from the page. You can view expanded information about that issue by clicking on any issue to open the issue's details page.

To customize this page and display only the issues you care about, select Show Quick Filters to access additional filtering options. To quickly reuse the same filter settings in the future, consider creating a saved issue list.

Related Privileges

Group Privilege Column
Service Manager Issues View

For more information, refer to Control User Access.

To view the Issues page, go to arrow_forward Services arrow_forward Service Manager arrow_forward Issues.

Saved issue lists are a set of filters that were saved to be used again on the Issues page. This allows you to create a detailed filter to use without the need to enter the same filters each time you need access to the same list of issues. You can apply any of your saved issues lists by selecting them from the Select an Issue List drop-down at the top of the page.

Filter Options

The following filter options are available on this page.

Options Descriptions

Page Filter

Use the drop-down to select a saved issue list or click to add more advanced filters.

Search

Allows you to display only issues that contain data matching what you enter in this field. For example, you can put in the Issue ID or something from the issue description.

Show Quick Filters

A set of commonly used filters to allow easy access.

You can enter any combination of the following filters:

Property

When the Property tab is selected, only issues associated with the properties or property groups selected display.

Owner

When the Owner tab is selected, only issues associated with the owner or owner groups selected display.

Open Issues

Only issues that do not have a Close Date display.

Closed Issues

Only issues that have a Close Date display.

Category

Only issues with the same Category selected in the issue details display.

Priority

Only issues with the same Priority selected in the issue details display.

Status

Only issues with the same Status selected in the issue details display.

Vendor

Only issues with the same Vendor selected in the issue details display.

Assigned To

Only issues assigned to the same User display.

Created By

Only issues created by the User selected display. If the issue was created from Tenant Web Access (TWA), the column displays TWA Submitted.

Linked To

Only issues linked to the selected entity display. Select the entity type using the drop-down above the field (tenant, prospect, unit, or property) and use the search bar to select a specific entity of that type.

Workflow Project

Only issues with the same Workflow Project selected in the issue details display.

Column Descriptions

The following columns display on this page. By default, some columns display only if added via .

Default Columns Description

Age

The number of days, hours, minutes the issue has been in the system.

Assigned To

The user assigned to complete or monitor this issue. If a user is not assigned to the service issue, <Unassigned> displays.

More Information

Assigned to users can be specified at a system level in the Service Issue General Options system preferences or at a property level, based upon your selection in the Assign Service Issues field on the property's details page. Rent Manager populates the property-level assigned user into this column after you create service issue property links on the Links tile.

Category

The issue category to sort and track types of service issues.

Created By

The user who entered the issue into Rent Manager.

Due

The date by which the issue needs to be completed.

Issue

A brief explanation of the issue (e.g., Change HVAC filters).

Issue ID

The unique identifying number Rent Manager assigns to each issue.

Opened

The date the issue was created in Rent Manager.

Priority

The issue priority that describes the urgency of the issue.

Property

The name of the property associated with this issue.

Status

The current status of the issue (e.g., New, Work in Progress, Unresolved, Resolved).

Unit

The name of the unit (e.g., Apt. 042) associated with the issue.

Row/Bulk Actions

Row actions are available from the menu and affect only the selected issue. To perform the same action on multiple issues, the Bulk Actions menu allows you to select an action and then check all the issues on which to apply the action.

The following actions are available from the Issues page. Actions that may be performed in bulk are designated with a Check.
