Memorized Estimate Details (Page)

Estimates allow you to record the anticipated parts and labor needed to complete a project, itemize the costs, and provide a total amount due including any markups and/or taxes you add. Estimates can also be linked to an invoice, service issue, and/or purchase order.

On a memorized estimate's details page, you can edit estimate information, add inventory items, manage history/note items, or delete the existing estimate.

Related Privileges

Group Privilege Column
POs/Estimates Estimates View, Edit

For more information, refer to Control User Access.

To view the details of a memorized estimate, go to arrow_forward Receivables arrow_forward General arrow_forward Memorized Estimates and select an estimate from the list.

Information

This tile displays general information about the estimate, such as the sales representative and the associated tenant, owner, or prospect account.

Field Description

Address

The default address of the default property associated with the owner, tenant, or prospect account.

Comments

An additional explanation or purpose of the estimate. To select a comment that already exists, select .

Description

Additional information for this memorized estimate, such as when this estimate is used.

Name

A unique name for this memorized estimate.

Property

The property associated with the owner, tenant, or prospect account.

Type

The type of entity the estimate applies to.

Reference

A message about the transaction contained within the memorized estimate.

Sales Rep

The user responsible for creating the charge or selling the associated inventory item to the invoice recipient.

Taxes

This tile displays the tax type and percentage that is applied to any taxable items in the estimate.

Field Description

Tax %

The tax percentage rate to be applied to the total of taxable items displayed in Taxable Amount. If a Tax Type has been selected, this initially displays the tax rate defined for that tax type.

Tax Type

The type of tax to apply to the expenses in this estimate. The Tax % field populates with the percentage rate defined for the selected tax type. For more information, refer to Tax Types (Page).

Taxable

A indicates that expenses related to this estimate are subject to additional tax expenses.

Taxable Amount

The running sum of the line item Total for items with the T column checked. This Taxable Amount is multiplied by the Tax % to calculate the actual Tax applied to the transaction.

Items

This section displays inventory items, and associated costs, that are planned to be purchased as part of this estimate.

Column Description

Amount

The total dollar amount that the purchased quantity of the Item costs you before markup and taxes are added.

Cost

The purchase price you pay per Item.

Item

The inventory item that is purchased as part of this estimate. Once an item is selected, the Cost and Memo fields populate with the item’s information.

Markup

The percentage of the cost of the Item that you charge the estimate recipient beyond the base Cost you paid for the Item.

Memo

Additional information explaining the inventory item. By default, this field populates with the Description from the inventory item, but it can be edited as needed.

Quantity

The quantity of the Item to purchase. The Total updates when the quantity is entered or changed.

Tax

A indicates that the item is taxable. When T is checked, the Amount for this line item is added to the Taxable Amount in the Taxes section. When a Tax Type and Tax % are specified in that section, their tax percentage is multiplied by the Taxable Amount to get the actual Tax applied to the transaction.

Total

The total dollar amount of the Item after any Mark Up is added.
