Evictions (Page)

The eviction process is long and time consuming and requires a variety of different steps and jurisdiction based requirements. With Rent Manager, you can keep track of evictions in progress by recording information like the date of notice, outcome, and associated judgment amounts. On a tenant's details page, the Eviction tile displays information about any in-progress eviction processes. After an eviction process is closed, you can review or edit information from the All Evictions tile, also on the tenant's details page.

For more information, refer to Control User Access.

To view details about an eviction, go to arrow_forward Rental Info arrow_forward Tenants and select a tenant from the list. Then, on the Evictions tile for ongoing evictions or the All Evictions tile for closed evictions, click .

The Eviction pop-up consists of three sections that display information about the tenant, the eviction process, and the status of the process. The information that displays on this page depends on the stage of the eviction case and which eviction workflow is enabled for the property associated with the tenant. For more information, refer to Eviction Workflows (Page).

The top of the page displays basic information about the tenant and the eviction, including what stage the eviction is in. You can click to edit the information that displays in this section.

Field Description

Start Date

The date on which the eviction process began for this tenant.

Eviction Reason

The reason for which the tenant is being evicted.

Close Date

For completed evictions, the date that the case was resolved.

Balance due

The tenant's outstanding balance as of the start of the eviction process.

Details

When the eviction is open, this section displays the most current information about the eviction process based on the stage of the eviction and the eviction workflow assigned. Fields that are associated with the current stage can be updated and fields associated with a future stage are grayed out until the eviction is advanced to the applicable stage.

Once the eviction is closed, all fields from each stage display even if the eviction was closed before it progressed to future stages.

The following fields can display in the Details section:

Field Description

Notice Date

The date on which an eviction notice was sent to the tenant.

Sent to Attorney Date

The date on which the eviction case was sent to an attorney.

Eviction Filed Date

The date on which the eviction case was filed with a court.

Case #

The court-assigned number for the eviction case.

Court Date

The date on which the tenant is due to appear in court to address the case.

Eviction Outcome

The court decision and resulting action against the tenant.

Judgment Amount

The balance the tenant owes after a judgment is rendered in court.

Writ Date

If the eviction case is ruled in favor of the landlord, this is the date on which a decision is rendered.

Don't Accept Partial Payments

Check to indicate that you do not take partial payments from this tenant. A partial payment is considered anything below the tenant's current balance due as of the payment date.

Don't Accept Payments

Check to indicate that you do not accept payments from this tenant, such as in cases where they have a history of NSF payments.

Vacate Date

The date by which the tenant must vacate the unit after a judgment is rendered in the eviction case.

Lockout Date

The date after which the tenant is locked out of the unit by law enforcement.

Eviction Notes

This section displays history/notes items related to the eviction, including system-generated notes about eviction stages and custom notes that you enter. You can search and filter to narrow results. You can also add a new eviction note, or notes about calls, emails, and conversations with the tenant, by clicking Add Note.

The following columns display in the Eviction Notes section:

Column Description

Type

The type of note. These can be system notes that are generated when you advance an eviction workflow, or they can be user notes added via this tile.

Date

The date on which the note was created.

Note

The text of the note.

Category

The grouping under which this note fits.

User

The user who created the note or who advanced the eviction workflow.
