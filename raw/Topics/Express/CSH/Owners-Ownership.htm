Ownership (Pop-Up)

The Ownership pop-up provides at-a-glance information about the properties owned by the currently selected owner. This is a read-only pop-up pulling in information from the property's Owners pop-up. You can click a property in the list to jump to that record.

Related Privileges

Group Privilege Column
Properties/Units Properties View
Owners Owners View

For more information, refer to Control User Access.

To view the Ownership pop-up, go to arrow_forward Owners arrow_forward General arrow_forward Owners and select an owner from the list. Then, on the owner's details page, click arrow_forward Ownership.

Column Descriptions

The following columns are available on this pop-up:

Column Description

Approve Bills

A displays if owner bill approval is enabled for the property.

Property

The name of the property in the owner's portfolio.

Contract Start

The date on which the contract for the property went into effect.

Contract End

If applicable, the date on which the contract for the property expires.

%

The percentage of property ownership for the property.

Reserve

The minimum amount of money that must remain in the bank to cover expenses for the property. This reserve amount can have an impact on owner distributions. For more information, refer to Pay Owners.

Threshold Amount

The minimum amount that a bill allocated to the property must total before the owner is required to approve it.

More Information

This column displays only if Enable owner bill approval is checked in system preferences. For more information, refer to Owner Settings (System Preferences).
