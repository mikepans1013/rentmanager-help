Issue History/Notes (Pop-Up)

Issue history/notes allow you to record information that supplements or clarifies what’s entered in other fields, such as notes about phone conversations, items on a to-do list, and explanations about transactions. While some history/notes are automatically created by Rent Manager, you are also able to record information based on your needs.

Filter Options

The following filter options are available on the page. Depending on the size of your browser window, these filters may display at the top of the page, or you may need to click to view the filter options.

Option Description

Search

Enter search terms in the Search field to find history/notes that contain the searched text.

Filter By Date

Select or enter the From and/or To dates to filter notes created on or between the selected dates. Click to select from preset date ranges.

Users

Click the drop-down list and select users to filter for history/note items created by one or more Rent Manager users.

History Category

Click the drop-down list and select categories to filter for history/note items by category. Select <Unassigned> to include history/notes with no category.

Type

Click the drop-down list and select types to filter history/note items by type.

Only Notes with Attachments

Check to display only history/notes that have an attachment.

Column Descriptions

Columns on the issue History/Notes pop-up display the following information:

Column Description

Pin

Pinned history/notes always display at the top of the list.

Type

The system-generated history/note type. For example, if the history/note is linked to a service issue, the Service Issue type displays.

Date

The date and time the note was created.

Note

The text entered in the Note field of the history/note. If no text is entered, the column displays blank.

If an attachment is uploaded to the history/note item, displays. Click to download the attachment or open it in a new tab.

Category

The category describes the purpose of the note. For example, an email sent to a service tech for the purpose of HVAC maintenance displays the HVAC category.

User

The Rent Manager user who created the history/note. If this is a system-generated history/note, the user displays as Administrator. If the history/note was generated from Tenant Web Access (TWA), the user displays as <Unassigned>.
