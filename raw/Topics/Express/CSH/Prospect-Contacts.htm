Prospect Contacts (Pop-Up)

The View Contacts pop-up lets you view and manage information about the people associated with your prospect's account. Contacts could be other occupants added to the prospect account, co-signers, business contacts, etc. The primary prospect automatically displays first on this pop-up as a contact.

Related Privileges

Group Privilege Column
Tenants/Prospects Prospects View, Edit

For more information, refer to Control User Access.

To view the contacts for a prospect, go to arrow_forward Rental Info arrow_forward General arrow_forward Prospects and select the prospect from the list. Then, on the Contacts tile, click . To view contacts associated with the prospect that are no longer active, click Show Inactive.

The yellow tag is the assigned Type that represents the prospect contact assigned in the Type field. The email that displays beneath the yellow tag can be found in the Email Address field. Additionally, the phone number that displays is the number selected as Default in the Phone Numbers section. If you have an image of your prospect contact, you can add it to the contact.

The following status options are available for the contact:

Field Description

Primary

Indicates that the contact is the primary person your property management company communicates with. One contact must be designated as Primary on each prospect's account. When you add a prospect, the first contact on the account is always the prospect.

Show On Statement/Labels

Includes the contact's name on tenant statements or labels. Only two contacts may have Show On Statement/Labels checked on each prospect account. The first contact on the account is always the prospect, so by default, the prospect has Show On Statement/Labels checked.

Active

The contact is currently associated with the prospect. This allows you to deactivate a contact, such as in the event of a roommate backing out of the lease, without deleting the contact's historical record.

Personal Information

The following fields display in the Personal Information section.

Field Description

First Name

The first name of the contact.

Middle Name

The contact's middle name.

Last Name

The contact's last name.

Soc Sec#

The social security number of the contact.

Related Privileges

To view the full social security number, the following privilege is required:

Group Privilege Column
Tenants/Prospects View complete tenant SSNs Enabled

For more information, refer to Control User Access.

Email Address

The contact's primary email address. To view or update the contact's preferences regarding emails from Rent Manager, click Manage Subscriptions. An icon displays to show if the contact is subscribed to all categories (), unsubscribed from the General category (), or unsubscribed from all categories (). For more information, refer to Unsubscribe From Emails.

Birthday

The contact's date of birth.

Age

The contact's age based on the Birthday and current date.

Employer

The name of the contact's employer.

Annual Income

The contact's annual net income.

Related Privileges

To view the total annual amount, the following privilege is required:

Group Privilege Column
Tenants/Prospects View annual income Enabled

For more information, refer to Control User Access.

License Plate #

The contact's driver's license plate number.

Vehicle

The make and model of the contact's vehicle.

Contact Type

The user-created contact type that best describes the contact (e.g., Co-Signer).

Applicant Type

The type of applicant that best describes the contact (e.g., Primary).

Address

This section displays the contact's associated address.

User Defined Fields

This section displays any contact-type user defined fields and, when applicable, the Value of the user defined field.

Phone Numbers

This section tracks the contact numbers for the contact organized by phone number types. The number used as the primary contact for this account is marked as Default. Additionally, if a phone number can be used for text messaging, it is marked in the T column.
