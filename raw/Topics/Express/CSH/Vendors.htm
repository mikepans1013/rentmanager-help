Vendors (Page)

Vendors are the people and businesses that you pay in exchange for products and services. Tracking vendors helps you manage your accounts payable in Rent Manager.

Related Privileges

Group Privilege Column
Payables Vendors View

For more information, refer to Control User Access.

To view your list of vendors, go to arrow_forward Payables arrow_forward General arrow_forward Vendors.

On the Vendors page, each vendor record displays on a row with information organized into columns. Click on a vendor to open the Vendor details page for that account, where information specific to that vendor is available.

Column Descriptions

The following columns are available on this page. By default, some columns display only if added via .

Default Column Description

Address

The full default address of the vendor's business location.

City

The city of the default address where the vendor is located.

Email

The email address used for contacting the vendor.

Name

The name of the business associated with the vendor account.

Pay Method

The default payment method used to pay this vendor.

Phone Number

The default phone number used for contacting the vendor.

Postal Code

The zip or postal code of the default address where the vendor is located.

State

The state of the default address where the vendor is located.

Street

The street of the default address of the vendor's business.

Terms

When payment is due for this vendor.

Available Column

Description

1099

Indicates that this is a 1099 vendor.

1099 Category

The IRS-based category of the vendor used when generating 1099 forms.

Account Number

The account number for this vendor, which can be used in vendor filters and correspondence scripting.

Active

Indicates that the vendor is active and can be used for bills and purchase orders.

Assigned User

The Rent Manager user linked to the vendor who is reimbursed for any personal charges using Smart Receipts in rmAppSuite Pro. For example, if an employee spends their own money on parts for a maintenance issue, you can create a bill in from rmAppSuite Pro to reimburse the employee for their purchase. For more information, refer to Smart Receipts.

Auto-Fill Info

Indicates that the Auto-Fill Check/Bill Information option is enabled for this vendor.

Category

A user-created category that can be used in vendor filters.

Comment

The custom note entered on the vendor's details page in the Comment tile.

Contact Name

The name of the person who your primary point of contact with the vendor company.

Insurance Expiration

The date on which the vendor's insurance expires.

Payee Name

The name to use on checks and bills associated with the vendor.

Private

Related Privileges

Group Privilege Column
Payables View private vendors Enabled

For more information, refer to Control User Access.

Indicates that the vendor is marked as private.

Property

The properties where the vendor is authorized to provide services.

Workers Comp Expiration

The date on which the vendor's worker's comp expires.

Address: (Type)

Each Address Type is listed on the Columns pop-up. The vendor's associated address of the selected type displays.

Phone Number: (Type)

Each phone number type is listed on the Columns pop-up. The vendor's associated phone number of the selected type displays.

UDF:
(Vendor Type)

Each vendor-type user-defined field is listed on the Columns pop-up. The value entered on the vendor's account for the selected user-defined field displays.

Row/Bulk Actions

Row actions are available from the menu and affect only the selected account. To perform the same action on multiple accounts, the Bulk Actions menu allows you to select an action and then select all the accounts on which to apply the action.

The following actions are available from the Vendors page. Actions that may be performed in bulk are designated with Check.

Send Text

 

Related Privileges

Group Privilege Column
Texting/Broadcast Send/Receive texts Enabled

For more information, refer to Control User Access.

Send a text message to the selected account through the text messaging center. This option displays only if there is a text-enabled phone number listed on the account.

More Information

The first text sent to a recipient from the text messaging center and any texts sent via text broadcast or automated notification include an opt-out message. If a recipient opts out, that phone number cannot receive texts from Rent Manager unless they choose to opt back in. Recipients can opt out or opt in at any time. If a recipient wishes to opt back into text messaging, they must text Start from the phone number they opted out with to the number they originally requested to opt out of.

Phone numbers that have opted out of text messaging are identified on the account's View Contacts pop-up, where the checkbox in the T column is replaced with the words Opted out in red text.

Write Letters

Check

Related Privileges

Group Privilege Column
Letter/Email Templates/Reports/Packets Letter/Email templates/packets View

Additionally, on the Communication tab, you must have access to at least one vendor-type letter.

For more information, refer to Control User Access.

Select a vendor-level letter template from the list to generate a letter for the selected account.

More Information

Letters can be added or removed from this shortcut menu in the letter/email templates register. For more information, refer to Letter/Email Template Settings (Pop-Up).
