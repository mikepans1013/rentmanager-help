Vendor Filters (Pop-Up)

Vendor filters allow you to quickly narrow your search results to get to the vendor information that you really need. Rent Manager gives you the ability to choose from a variety of filtering options to sort your vendors on the Vendors page.

Related Privileges

Group Privilege Column
Payables Vendors View

For more information, refer to Control User Access.

Rent Manager allows you to create filters that can be used temporarily, or saved to use repeatedly. Additionally, they can be saved on a system level for all users, or on a personal level where only your user account can access it. Before saving your filter, enter a Name, and, optionally, a Description to remind you of the filter's purpose.

To create vendor-specific filters from the Vendors page, click .

More Information

If the basic filtering does not meet your needs, you can create an advanced filter which allows you to group your filters for a more granular, precise filtering criteria. For more information, refer to Create an Advanced Filter.

On the Vendors page there are multiple fields available to use for basic filtering of vendors. The fields are divided into multiple sections. Each field is described within the corresponding section below.

General Information

This section contains fields for filtering vendors by information that can be found primarily on their detail pages.

In the Search Options field, select whether the filtered vendor list includes results for vendors based on whether the relevant information Contains your filter criteria or Begins With the your filter criteria.

For example, if you are filtering vendors based on Zip codes that start with 4, you can select Contains to display all tenants whose zip code has the number 4. Alternatively, if you select Begins With, you see results only for vendors whose zip code starts with the number 4.

The available filter fields are described in the table below.

Field Description

Account #

The account number for the vendor, which can be used in vendor filters and correspondence scripting.

Category

A user-created category as listed on the Miscellaneous tile.

City

The city of the default address where the vendor is located.

Comment

The custom note entered on the Vendor details page in the Comment tile.

Contact Name

The name of the person who your primary point of contact with the vendor company.

Display Color

The color that represents specific information about the vendor. For example, if you want to view vendors that are preferred to do work at your properties, select the color assigned to that preference.

Email

The email address used for contacting the vendor.

Is 1099

The 1099 Vendor checkbox is checked on the vendor's details page in the Tax Information tile.

Name

The name of the business associated with the vendor account.

Phone

The phone number selected as Default for the vendor as found on the Contacts tile.

Property Name

The name of the property where the vendor is authorized to provide services.

State

The state of the default address where the vendor is located.

Street

The street of the default address of the vendor's business.

Zip

The Default zip code as listed on the vendor's Addresses tile.

Check Number

This section contains the fields used to filter the vendor list by check numbers. In the Check # field, enter a check number to filter your vendor list to display vendors paid with checks that contain any integer in the in the string of numbers you entered. To view only vendors paid with a specific check, select Exact Match.

User Defined Fields

This section contains additional fields used to filter the vendor list. The user defined fields in this section are specific to vendors.
