Make Ready Details (Page)

The Make Ready Details page displays additional information about a make-ready process, including all actions and items within that process. From this page, individual items can be added or deleted, dates can be adjusted, and notifications for users to take action can be set.

Related Privileges

Group Privilege Column
Properties/Units Make ready board View
Properties/Units Make ready process View

For more information, refer to Control User Access.

To view a project's details page, go to  arrow_forward Services arrow_forward Make Ready arrow_forward Make Ready Board. From the Make Ready page, click on the desired unit.

At the top right of the page, click to view information regarding when and by which user the make-ready was created and updated.

Field Descriptions

The following fields are available in the Details section of this page.

Field Description

Property

The full name of the property whose unit is being made ready.

Unit

The name of the unit in the make-ready process.

Last Move Out

The previous tenant's move out date.

Start Date

The date that the make-ready process begins.

Comments

A detailed description about this process (e.g., This should be a quick turnaround, the tenant was only there for six months).

Manager

The user to oversee the make-ready process.

Related Privileges

Only users with the following privilege display in the list.

Group Privilege Column
Properties/Units Make ready board View

For more information, refer to Control User Access.

Job

If applicable, the name of the job to track transactions associated with the make-ready process. The job is assigned to all issues within the process. For more information, refer to Jobs (Page).

Related Preferences

In order to use the job costing tool in Rent Manager, Enable job costing must be checked in system preferences. For more information, refer to General Options (System Preferences).

Mark as high priority

Check to pin the make-ready process to the top of the Make Ready page.

Enforce Action Sequence

To require that the actions in the make-ready board are completed in the order displayed, check Enforce Action Sequence.

For example, if you have an action titled Move Out Inspection and it is the first (topmost) action on the board, all items in that action must be completed before moving on to the following action if this option is checked.

Column Descriptions

The following columns are available on this page.

Column Description

Action

The name of the make-ready action to be performed.

Type

If the action is linked to a service issue, displays. If the action is linked to an inspection, displays.

Description

The text of the Issue field for service issues and the Description of inspections.

Status

The action's status (Scheduled, In Progress, or Completed).

Assigned To

The user listed as Assigned To on a service issue or, for an inspection, the user listed as Inspector.

Inspector

The full name of the user listed as Inspector on an inspection.

Due

The date the service issue must be completed by. Inspections display as blank.

Scheduled

The date of the inspection or service issue is scheduled to take place.

Completed

The Closed date of the service issue or, for an inspection, the date the Status was changed to Closed.

Notify When Ready

Check for each action that should email the Assigned To user when the item is available.

Related Preferences

The system preference option Notify me when new issues appear in my default list must be enabled, and a valid email specified on the User details page for notification to be sent. For more information, refer to Service Issue General Options (System Preferences) and User Details (Page).
