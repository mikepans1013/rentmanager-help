Manage Location Unit Licensing Limits (Page)

If your company uses the per-unit licensing model, you must purchase a license for each unit actively managed in any of your Rent Manager database locations. The Manage Location Unit Licensing Limits page allows you to set a maximum number of licenses for each location in Rent Manager. This feature is particularly useful for companies that manage franchises and maintain those entities in separate locations. For example, if you have one location for your Denver properties and another location for your Cincinnati properties, you can define the exact number of licenses each location can use. Configuring these limits helps to ensure that one location does not use so many licenses that other locations are unable to operate effectively.

More Information

You may be using the legacy option to pay for Rent Manager, which is based on the number of users who log in to the program concurrently. If you have a per-user subscription, unit licenses are not used in your Rent Manager database.

Related Preferences

To access this feature and enable the related privileges, you must first enable the system preference Manage Unit licenses by location. For more information, refer to General Options (System Preferences).

Related Privileges

Group Privilege Column
System Manage Location unit licensing limits Enabled

For more information, refer to Control User Access.

To view and manage your locations' unit license limits, go to arrow_forward Administration arrow_forward Licensing arrow_forward Manage Location Unit Licensing.

Field Descriptions

The following fields display at the top of the page:

Field Description

Allocated Unit Licenses

The number of purchased licenses that have been allocated to locations.

Available Unit Licenses

The total number of unit licenses that remain unused out of the total the total purchased licenses

Available Unit Licenses = Purchased Unit Licenses - Units Licensed

Purchased Unit Licenses

The total number of unit licenses purchased for your database.

Units Licensed

The total number of licensed units across all locations.

Column Descriptions

The following columns display on the page:

Column Description

Available Unit Licenses

The total number of licenses that can still be used in the location.

Available Unit licenses = Maximum Unit Licenses Allowed - Licensed Units

Last Updated

The date and time that the most recent change was made to the location's Maximum Unit Licenses Allowed.

Licensed Units

The number of currently licensed units in the location.

Maximum Unit Licenses Allowed

The maximum number of units that can be licensed in the location. This field can be edited to increase or decrease the licenses allocated to the location.

Rent Manager Location

The name of the location.

Update User

The username of the user who made the most recent change to the location's Maximum Unit Licenses Allowed.
