Task Automation

There are many actions and procedures you perform in Rent Manager on a regular basis. The Task Automation tool allows you to schedule these routine tasks to run automatically, saving you time and effort. You can automate actions such as posting recurring charges, late fees, loans, recurring bills, and more.

Related Preferences

To enable Task Automation, you must enable each action you wish to automate in system preferences. For more information, refer to Task Automation (System Preferences).

Once you enable Task Automation, you can establish posting schedules for each task you wish to automate. Rent Manager checks each posting schedule daily and performs the task(s) for that day based on their established settings.
