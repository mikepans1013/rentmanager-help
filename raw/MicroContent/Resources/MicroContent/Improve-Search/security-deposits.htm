Security Deposits

Security deposit management is an important part of your daily business processes. Rent Manager makes its possible for you to create all of the security deposit charge types that you could possibly need in order to correctly charge your tenants. Charge types allow you to link the transactions for a specific service or product with a unique general ledger (GL) account. By creating multiple charge types for security deposits, you can categorize different security deposit transactions by their purpose. Having separate charge types also allows you to report on specific types of security deposits, such as seeing how much of your overall held security deposits are made up of pet deposits.

To receive a payment on a security deposit, you add the payment in Rent Manager like you would for any payment and ensure it's allocated to the security deposit charge on the account. Once it's paid, the held Security Deposit balance displays on the tenant's or prospect's details page. However, if you hold security deposits in a different bank, such as a trust or escrow account, and you take a single payment that pays other charges in addition to the security deposit, your process should include moving the security deposit funds to the trust (or escrow) account. Rent Manager makes this easy by allowing you to write a check or use a journal entry to transfer the funds to the trust (or escrow) account. In some localities, security deposits held for tenants can collect interest, which is then added to the total amount held or paid back to the tenant. For these localities, Rent Manager allows you to post security deposit interest to reflect real-world accruals on held deposits.

When your tenants' time at your properties come to an end, one way to ensure a positive move-out experience is by returning their security deposits in a timely and efficient way. Rent Manager makes this process seamless with the security deposit refund tool. This tool allows you to refund their security deposit or apply the deposit (partially or completely) to new or existing charges. You can also use this tool while they are still occupying the property to apply part of a held security deposit toward an open charge.

Keeping an eye on your security deposits can be a lot of work especially when you have to manage the move-in and move-out activity for tenants across multiple properties. To help you maintain this information, Rent Manager has several dashboard tiles and reports that enable you to keep track of the security deposit activity happening at your properties.
