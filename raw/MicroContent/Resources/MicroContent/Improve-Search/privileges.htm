Privilege Groups

There are many actions and procedures you perform in Rent Manager on a regular basis, along with a wide variety of sensitive or role-specific data that may need to be reviewed and modified. By managing user privileges, you can control the information and actions available to users so they are accessing only what they need to perform their role.

Privileges are split into several groups based on their location and functionality in Rent Manager (e.g., Accounting, Service Manager, Tenants/Prospects). Additionally, privileges have differing degrees of customization to expand or limit access to certain data and tools. For example, in the Properties/Units group, the Properties privilege can be set up to allow users to Add, View, Edit, and/or Delete properties, while the Manage STR Rate Schedules privilege can only be Enabled or disabled.

The following privilege groups are available:

Group Description

Accounting

Accounting privileges provide access to accounting features such as GL accounts, charge types, journal options, gross potential rent and check registers.

For more information, refer to Accounting Privilege Group.

Asset Management

Asset management privileges provide access to asset features such as managing and tracking asset manufactures, statuses, types, maintenance records, depreciation schedules, and workflows.

For more information, refer to Asset Management Privilege Group.

Associations

Associations privileges control whether users can view and manage architectural requests received by homeowner associations (HOAs), and the setup of committees that may be part of HOAs.

For more information, refer to Associations Privilege Group.

Banks/Checks

Banks/checks privileges provide access to banking features such as viewing bank registers, creating or editing deposits, printing or modifying checks, using digital signatures, reconciling transactions, and working with positive pay files and templates.

For more information, refer to Banks/Checks Privilege Group.

Bird's Eye View (BEV)

Bird's eye view (BEV) privileges provide access to features that let you create an aerial-pictorial map of a property and its associated units and add database scripting functions to provide pop-up summaries for each unit.

For more information, refer to Bird's Eye View (BEV) Privilege Group.

Blue Moon

Blue Moon is a partner that provides industry-standard leasing documents. The integration between Blue Moon and Rent Manager allows you to seamlessly track your leases and lease documents.

For more information, refer to Blue Moon Privilege Group.

Commercial Recoverable Expenses (CRE)

CRE privileges provide access to commercial recoverable expenses (CRE) features.

For more information, refer to Commercial Recoverable Expenses (CRE) Privilege Group.

Custom Forms

Custom forms provide access to creating and managing custom forms.

For more information, refer to Custom Forms Privilege Group.

eChecks

eChecks privileges control the Safeguard eChecks integration used to pay bills and write checks electronically.

For more information, refer to eChecks Privilege Group.

ePay

ePay privileges provide access to Zego ePay options for Rent Manager's integrated partner Zego that can be used to electronically process prospect or tenant payments, collect application fees with the Apply Now integration, pay vendor bills, process owner contributions, and pay owner distributions.

For more information, refer to ePay Privilege Group.

History

History privileges provide access to history/note features for tenants, prospects, properties, units, vendors, owners, service issues, estimates, purchase orders, assets, jobs, and violations. They also provide access to add or update history categories.

For more information, refer to History Privilege Group.

Importing

Importing privileges allow the user to import external files to add new data to Rent Manager or update existing data.

For more information, refer to Importing Privilege Group.

Inspections

Inspections privileges provide user access to the features of Inspections. Inspections are a licensed feature of rmAppSuite Pro, allowing you to conduct an inspection, make notes, take pictures, and schedule work orders in the field from the site of the inspection.

For more information, refer to Inspections Privilege Group.

Letter/Email Templates/Reports/Packets

Letter and report privileges provide access to the following word processing and reporting features: accessing letter templates, publishing signable documents, editing merged documents, generating system reports, generating Report Writer Financial Report Writer reports from templates, and creating document packets.

For more information, refer to Letter/Email Templates/Reports Packets Privilege Group.

Loans Receivable

Loans receivable privileges provide access to features used to create and manage owner-financed loans, which can be used for home sales as well as for land, equipment, appliances, and more.

For more information, refer to Loans Receivable Privilege Group.

Locations

Locations privileges provide access to features used to manage and change database locations.

For more information, refer to Locations Privilege Group.

Metro 2

Metro 2 privileges provide access to Metro 2 features, which are used to export data from loans in a format that is required by the major consumer reporting bureaus (TransUnion, Equifax, Experian, and Innovis).

For more information, refer to Metro 2 Privilege Group.

Owners

Owner privileges control access to features related to owners, owner prospects, and their life cycle. For fee-based management companies, this includes the ability to post management fees, access or create templates for those fee structures, receive contributions, and pay out distributions.

For more information, refer to Owners Privilege Group.

Payables

Payables privileges provide access to bill paying features, such as adding and updating bills, adding and updating credit card transactions, adding vendors and updating vendor transactions, adjusting Vendor 1099 reports, and using AvidInvoice and AvidPay functions.

For more information, refer to Payables Privilege Group.

Phone System

Phone system privileges provide access to the rmVoIP Phone Service features in Rent Manager.

For more information, refer to Phone System Privilege Group.

POs/Estimates

POs/estimates privileges provide access to features such as creating or editing purchase orders, editing purchase order workflows, and the approval or denial of purchase orders or estimates.

For more information, refer to POs/Estimates Privilege Group.

Properties/Units

Properties/units privileges provide access to property and unit features such as management fee setup, unit types, unit status and unit status types, property groups, bank settings, floors, amenities, image types, unit pickers, and the make ready process.

For more information, refer to Properties/Units Privilege Group.

Receivables

Receivables privileges provide access to features used to charge tenants and prospects for goods and services and then collect payments on behalf of your managed properties.

For more information, refer to Receivables Privilege Group.

Recurring Charges/Market Rent

Recurring charges and market rent privileges provide access to recurring charges that can be assigned to tenants and posted on a scheduled basis as well as adding or updating market rent values for units.

For more information, refer to Recurring Charges/Market Rent Privilege Group.

rmAppSuite

Various privileges for rmAppSuite Pro are available in this group, including if the user may view other users' service issues and text conversations, tenant financial information, and if the user can add or edit an inspection. Additionally, you can give permission to attach photos to selected categories.

For more information, refer to rmAppSuite Privilege Group.

Sales/Invoicing

Sales/invoicing privileges provide access to features related to working with invoices and tracking sales data.

For more information, refer to Sales/Invoicing Privilege Group.

Service Manager

Service Manager privileges provide access to service-related features such as issues and lists, service projects and templates, and list filters and options.

For more information, refer to Service Manager Privilege Group.

Setup

Setup privileges provide access to features used when setting up Rent Manager such as beginning balances, budgets, CPI adjustments, allocation order, dashboards, scoreboards, and menu ribbons.

For more information, refer to Setup Privilege Group.

Subsidies

Subsidies privileges provide access to the subsidy tool, which allows you to define subsidies (for example, for entities such as FEMA or HUD) and then receive a large single subsidy payment and distribute it to the customers associated with that subsidy.

For more information, refer to Subsidies Privilege Group.

Surveys

Survey privileges control property surveys, the ability to publish/send a survey and view its results, and to add responses to surveys and view individual responses.

For more information, refer to Surveys Privilege Group.

System

System privileges provide access to system-level features such as email, user management, administration settings, Rent Manager updates, database maintenance and upgrades, and custom colors.

For more information, refer to System Privilege Group.

Task Automation

Task automation privileges give users access to set up posting schedules in Rent Manager for features such as Task Automation and accounts receivable automation.

For more information, refer to Task Automation Privilege Group.

Tenants/Prospects

Tenants/prospects privileges provide access to features such as adding or updating tenant and/or prospect information, entering lead source information, viewing rental applications, and using the screening features.

For more information, refer to Tenants/Prospects Privilege Group.

Texting/Broadcast

Texting and broadcast privileges provide access to features that allow users to send a single outgoing text or audio message to multiple owners, tenants, prospects, or vendors at once as well as allow users to send and receive text messages in the Text Messaging Center.

For more information, refer to Texting/Broadcast Privilege Group.

User Defined Fields

User-defined fields (UDFs) privileges provide access to user defined fields and encrypted user defined fields. Encrypted UDFs are encoded for the safe storage of sensitive information.

For more information, refer to User Defined Fields Privilege Group.

Utilities

Utilities privileges provide access to Metered Utilities through which you can calculate utility usage and bill tenants.

For more information, refer to Utilities Privilege Group.

VPO

VPO privileges provide access to use and manage Rent Manager's Virtual Post Office (VPO).

For more information, refer to VPO Privilege Group.

Web Chat

These privileges control Web Chat, the administration of queues, the handling of unlinked conversations, and whether an agent may override the set number of conversations at once.

For more information, refer to Web Chat Privilege Group.
