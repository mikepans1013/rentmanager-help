12.650 Release Notes

The release begins rolling out on October 21, 2020.

New Features

A page was added for Owner Contributions, which allows you to view and record owner contributions.

Path: arrow_forward Rental Info arrow_forward Owners arrow_forward Owner Contributions

Enhancements

The Tenant Details page was updated in the following ways:

  • The Back to Tenants link was removed. The action bar now includes the icon, which returns you to the Tenants register.

  • The Leases summary tile was updated to include Lease Term information if the selected tenant has a single active lease.

Path: arrow_forward Rental Info arrow_forward Tenants arrow_forward select a tenant

The Vendor Details page was updated with a View More menu option to View ePay Account on File, which allows you to manage the vendor’s ePay account information.

Path: arrow_forward Payables arrow_forward Vendors arrow_forward select a vendor arrow_forward arrow_forward View ePay Account on File

The Prospect Details page was updated with a View More menu option to Edit Layout, which allows you to navigate to the Layout Editor where you can now create custom prospect layouts.

Path: arrow_forward Rental Info arrow_forward Prospects arrow_forward arrow_forward Edit Layout

Path: Admin arrow_forward Setup arrow_forward Customization arrow_forward Layouts arrow_forward

The Property Details page was updated with a View More menu option for Owner Check Setup.

Path: arrow_forward Rental Info arrow_forward Properties arrow_forward select a property arrow_forward arrow_forward Owner Check Setup

The Owner Details page was updated with the following View More menu options:

  • A Checks option which allows you to view a list of checks distributed to the specified owner. Distributions made via NACHA have an icon with the option to Generate NACHA File.

  • A Management Company option, which allows you to view and edit management fees. In addition, transactions in the list have an icon, which allows you to view transaction Details, Clear Allocations, View Receipt, or reverse a payment by marking the transaction as NSF.


Path: arrow_forward Rental Info arrow_forward Owners arrow_forward select an owner arrow_forward arrow_forward Checks | Management Company

The Add Service Manager Issue page was updated with a Checklist section, which allows you to add checklist items manually or from a template.

Path: arrow_forward Services arrow_forward Service Manager arrow_forward Issues arrow_forward Add Service Issue

The following pages were updated with additional columns to provide more at-a-glance information:

  • The Service Manager Projects register was updated with a Completed column which is part of the default view, as well as the Enforce Sequence column which is available via .
    Path: arrow_forward Services arrow_forward Service Manager arrow_forward Project Manager

  • The Properties register now includes an Active column which allows you to easily tell whether properties listed are active or inactive. This is useful when you use the Show Inactive filter.
    Path: arrow_forward Rental Info arrow_forward Properties arrow_forward

  • The Vendors register now includes Active, Auto-Fill Info, Is 1099, and Private columns.
    Path: arrow_forward Payables arrow_forward Vendors arrow_forward

The following pages were updated to remember your filter selections, so your preferred filters are set each time you open the page:

  • The Prospects register for the Status and Leasing Agent filters
    Path: arrow_forward Rental Info arrow_forward Prospects

  • The Screenings register for the Screening Type filter
    Path: arrow_forward Rental Info arrow_forward Screenings

The following pages were updated to allow you to sort information by column. Your selections are remembered so your preferred sorting method is set each time you open the page.

  • Vendors register
    Path: arrow_forward Payables arrow_forward Vendors

  • Service Manager Projects register
    Path: arrow_forward Services arrow_forward Service Manager arrow_forward Project Manager

  • Service Manager Memorized Issues register
    Path: arrow_forward Services arrow_forward Service Manager arrow_forward Memorized Issues

  • Memorized Estimates register
    Path: arrow_forward Receivables arrow_forward Memorized Estimates

In addition, the Owners, Properties, Prospects, Unit Types, and Units registers now remember your column sort selections.

Path: arrow_forward Rental Info arrow_forward Owners | Properties | Prospects | Unit Types | Units
