# 12.660 Release Notes

Source: https://rmxhelp.rentmanager.com/Topics/Express/Release-Notes/2020/12.660.htm

The release begins rolling out on November 17, 2020.

 New Features

 A Manage Layouts page was added, which allows you to assign or unassign custom property, prospect, or tenant layouts to active users.

 Path: arrow_forward Admin arrow_forward Setup arrow_forward Customization arrow_forward Manage Layouts

 Enhancements

 As part of tax form changes for the 2020 tax year, the following changes were made:

 -
 The Vendor 1096 and Vendor 1099 reports now include a section in the report options to select Associated 1099 Categories with options for Nonemployee Compensation (NEC) or Other Compensation (MISC) . Based on your selection, the generated report is formatted for the corresponding tax form. In addition, if either of these reports are part of a report batch or memorized, Rent Manager asks which 1099 category to use.
Path: arrow_forward Reports arrow_forward Payables arrow_forward Vendor 1096 | Vendor 1099

 -
 The Owner 1099 Copy B report was updated to reflect changes to the 1099-MISC tax form, which includes removing Field 7 Nonemployee compensation and rearranging some of the other fields.
Path: arrow_forward Reports arrow_forward Owners arrow_forward Owner 1099 Copy B

 Applied filters are now represented in a page’s URL, so you can bookmark a page with your filters still applied.

 The pages for Memorized Estimates , Memorized Issues , Owners , Properties , Prospects , Projects , Tenants , Units , Unit Types , and Vendors were updated to improve usability in the following ways:

 -
 If you apply filters to a register page and then navigate to a details page from the filtered results, a search bar and arrows display at the top of the details page, which allow you to navigate through or search the filtered results. In addition, a field listing the applied filters displays.

 -
 You can now use a browser’s back button to return to the register page with applied filters.

 The Layouts Editor was updated to include a Custom Fields section for Tenant type layouts. Now, fields can be customized in the following ways:

 -
 You can drag and drop fields from the list onto new or existing tiles in the canvas. Once inside the canvas, fields can be moved to different places on the same tile or to different tiles.

 -
 You can edit the Field Width and Label.

 -
 If you select a tile from the Default Tiles section, it automatically populates in the canvas with its default fields. From there, you can customize the tile by adding, editing, or deleting fields.

 The Property Details page was updated with a View More menu option to Edit Layout , which allows you to navigate to the Layouts Editor where you can now create custom property layouts.

 The Vendor Transactions page was updated to include a Quick Add option to Write Checks .

 You can now upload files to History/Notes in Rent Manager Express by dragging any file onto a History/Note section or a History/Note slide-up page to open the Note Details pop-up. From there, you can select a History Category , Start Date and Time , and enter a Note , then Save the file.

 The Service Manager Saved Lists register was updated with a Setup Columns icon, which allows you to customize the displayed columns for your user. Any changes you make to the columns will be saved, even if you navigate away from the page.

 Path: arrow_forward Services arrow_forward Service Manager arrow_forward Manage Saved Lists arrow_forward

 The Vendors register was updated to remember your filter selections, so your Show Inactive preference is set each time you open the page.

 Path: arrow_forward Payables arrow_forward Vendors

 On registers with Filters for User Defined Values , selecting a user defined field (UDF) will now automatically add the field to the list, where you can input the UDF value by which you want to filter the register.
