# 12.630 Release Notes

Source: https://rmxhelp.rentmanager.com/Topics/Express/Release-Notes/2020/12.630.htm

The release begins rolling out on August 18, 2020.

 Enhancements

 The Tenants page was updated with an icon to Setup Columns , which allows you to customize the displayed columns for your user.

 Path: arrow_forward Rental Info arrow_forward Tenants

 You can now add a bill from the BILLS page.

 Path: arrow_forward Payables arrow_forward Bills arrow_forward

 The Details page for bills was updated in the following ways:

 The Summary panel on the left now displays the Paid Date , Credit , and Amount associated with any payments made toward the bill.

 The icon was added to the bottom of bills, which allows you to view the Created date and time, the Created By user, the Updated date and time, and the Updated user.

 The action bar now includes options to Print a Bill Worksheet or Delete the current bill.

 Path: arrow_forward Payables arrow_forward Bills arrow_forward select a bill

 When viewing the transactions associated with a vendor, you can now add a bill from the action bar.

 Path: arrow_forward Payables arrow_forward Vendors arrow_forward select a vendor arrow_forward Transactions arrow_forward Add Bill

 The Details page for owners was updated in the following ways:

 -
 A summary tile was added for Reports which allows you to quickly generate the owner’s default report batch.

 -
 A Manage Account tile was added, which allows you to select the Draw Account and Contribution Account for the owner.

 -
 Click the Reports menu in the action bar to generate any of the following reports:

 -
 Owner Profile

 -
 Owner Statement

 -
 Owner Labels

 -
 Owner 1096

 -
 Owner 1099

 -
 Owner 1099 Copy B

 -
 Owner Report Batch

 -
 The View More menu in the action bar was updated in the following ways:

 -
 An option to add NACHA account information.

 -
 An option was added for Owner Reports which opens a pop-up to set the owner’s default report batch.

 -
 The Manage Account option was removed.

 Path: arrow_forward Rental Info arrow_forward Owners arrow_forward Owners arrow_forward select an owner

 A menu option for Owner Report Batches was added which opens a page for you to generate owner report batches.

 Path: arrow_forward Reports arrow_forward Owners arrow_forward Owner Report Batches

 The filter selection on the History/Notes slide-up page on a property or unit record were updated so your preferred filters are set each time you open the page.

 Path: arrow_forward Rental Info arrow_forward Properties | Units arrow_forward select a record arrow_forward History/Notes arrow_forward

 The filter selections on the following slide-up pages for a tenant account were updated so your preferred filters are set each time you open the page:

 -
 The History/Notes slide-up page accessed from the action bar.

 -
 The Transactions slide-up page accessed from the action bar.

 Path: arrow_forward Rental Info arrow_forward Tenants arrow_forward select a tenant arrow_forward arrow_forward History/Notes | Transactions arrow_forward )

 The filter selections on the following slide-up pages for a prospect account were updated so your preferred filters are set each time you open the page:

 -
 The History/Notes slide-up page accessed from the action bar.

 -
 The Interested Properties/Units slide-up page accessed from the action bar.

 -
 The Transactions slide-up page accessed from the action bar.

 Path: arrow_forward Rental Info arrow_forward Prospects arrow_forward select a prospect arrow_forward History/Notes | Interested Properties / Units | Transactions arrow_forward )
