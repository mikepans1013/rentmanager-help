# 12.640 Release Notes

Source: https://rmxhelp.rentmanager.com/Topics/Express/Release-Notes/2020/12.640.htm

The release begins rolling out on September 18, 2020.

 New Features

 You can now create custom layouts for the Tenants page using a new Layouts designer.

 Path: arrow_forward Admin arrow_forward Setup arrow_forward Customization arrow_forward Layouts arrow_forward

 An add wizard has been added for vendors which allows you to quickly input the associated vendor details.

 Path: arrow_forward Payables arrow_forward Vendors arrow_forward

 Enhancements

 There is now an Owner Check Setup page from which you can add, edit, or delete check templates.

 Path: arrow_forward Rental Info arrow_forward Owners arrow_forward Owner Check Setups

 An Open Billable Expenses page was added which can be viewed if the Enable Billable Expenses setting in Rent Manager 12 is enabled. From this page, you can do the following:

 -
 Manage existing or add new billable expenses.

 -
 If the billable expense is tied to a bill, you can jump to the associated bill by clicking the link in the Transaction Type column.

 -
 Click the icon to create an invoice for the selected open billable expense.

 Path: arrow_forward Payables arrow_forward Billable Expenses

 The Bills register was updated with a menu for each bill. From this menu, you can quickly jump to the bill’s details, invoice the bill, or delete the bill.

 Path: arrow_forward Payables arrow_forward Bills

 The registers for Owners , Prospects , Units , Unit Types , and Properties were updated with a Setup Columns icon, which allows you to customize the displayed columns for your user. Any changes you make to the columns will be saved, even if you navigate away from the page.

Path: arrow_forward Rental Info arrow_forward Owners | Properties | Prospects | Units | Unit Types arrow_forward

 The Tenants register was updated to allow you to optionally add image-type or file-type user defined fields as columns in the register. In the column, a download link for the file displays.

 Path: arrow_forward Rental Info arrow_forward Tenants arrow_forward

 If you have saved personal, user, and user role filters in Rent Manager 12 , you can now access them on the following pages in Rent Manager Express :

 -
 Tenants

 -
 Prospects

 -
 Units

 -
 Properties

 -
 Unit Types

 Path: arrow_forward Rental Info arrow_forward Tenants | Prospects | Units | Properties | Unit Types

 The following pages were updated to remember your filter selections, so your preferred filters are set each time you open the page:

 -
 The Applications register for the Application Date and Include associated applications filters.
Path: arrow_forward Rental Info arrow_forward Applications

 -
 The Purchase Orders register for the Status filter.
Path: arrow_forward Payables arrow_forward Purchase Orders

 -
 The Service Manager Issues History for the Users , History Category , Type , and Only Notes with Attachments filters.
Path: arrow_forward Services arrow_forward Service Manager arrow_forward Issues arrow_forward select issue arrow_forward History/Notes arrow_forward arrow_forward

 -
 The Invoices register for the Open / Paid filter.
Path: arrow_forward Receivables arrow_forward Invoices

 Estimates were updated in the following ways:

 -
 The Estimates page action bar icon was replaced with a Quick Add menu option to Add Estimate , Add Tenant Estimate , Add Owner Estimate , or Add from Memorized .
Path: arrow_forward Rental Info arrow_forward Receivables arrow_forward Estimates arrow_forward

 -
 The Estimate Details page was updated with a View More menu option to Copy , which allows you to copy information from an existing estimate to a new estimate.
Path: arrow_forward Rental Info arrow_forward Receivables arrow_forward Estimates arrow_forward select an estimate arrow_forward

 -
 In Owner Web Access (OWA) , when an owner approves or rejects an estimate, the Estimate Details page updates to display the owner’s name and date the status was changed.
Path: arrow_forward Rental Info arrow_forward Receivables arrow_forward Estimates arrow_forward select an estimate

 The Owner Details page was updated with a View More menu option to View ePay Account on File .

 Path: arrow_forward Rental Info arrow_forward Owners arrow_forward Owners arrow_forward select an owner arrow_forward

 The Add Service Manager Issue page was updated with a User Defined Fields section, which allows you to input any user defined field values for the issue.

 Path: arrow_forward Services arrow_forward Service Manager arrow_forward New Issue

 The Units register now has a filter option for Property Group .

 Path: arrow_forward Rental Info arrow_forward Units arrow_forward

 The Service Order List report now includes filters to Show Open Checklist Items and/or Show Completed Checklist Items in the generated report.
