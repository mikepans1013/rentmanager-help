12.610 Release Notes

The release begins rolling out on June 23, 2020.

New Features

A feature exclusive to Express has been added that allows you to search checklist items on a service issue.

Enhancements

Estimates were updated in the following ways:

  • The ability to add and edit estimates for owners was added.

  • The action bar on the Owner Detail page offers a Quick Add option to Add Estimate. In addition, a View More option for Estimates was added, which opens the Estimates register filtered to show estimates associated with the selected owner.

  • A Status field was added, which allows you to track the estimates progress from Draft, Awaiting Approval, Approved, and Rejected.

  • Purchase orders for owners can now be linked to estimates for owners.

The Tenants register was updated in the following ways:

  • You can now select which columns display using Setup Columns.

  • You can now sort by some of the columns in ascending or descending order.

History/Notes were updated to support adding a Follow-up Date. This includes the following changes:

  • Personal Preferences was updated with a section for Calendar Options, which includes the Default history/note follow-up time field. This option allows you to select a default time to prefill a history/note item when adding a Follow-up Date.

  • A Follow-up Completed button was added.

  • In addition to adding a follow-up, you can also delete a Follow-up Date from a history/note item.

The Owner Detail page was updated with a View More option for Ownership, which displays the Property, Contract Start, Contract End, percentage of ownership (%), and Reserve for the owner’s portfolio.

Dashboard tiles that have been added to your Dashboard now include links to the help file for information on the individual tiles.
