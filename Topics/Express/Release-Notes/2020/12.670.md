# 12.670 Release Notes

Source: https://rmxhelp.rentmanager.com/Topics/Express/Release-Notes/2020/12.670.htm

The release begins rolling out on December 15, 2020.

 New Features

 A Pay Owners page was added. If the Create payments for owners privilege is enabled in Rent Manager 12 , you can use this new page to calculate, write, and print checks for your owners.

 Path: arrow_forward Rental Info arrow_forward Owners arrow_forward Pay Owners

 The Journals Register and Journal Details pages were added. These pages allow you to manage, edit, and create journals in Rent Manager Express .

 Path: arrow_forward Accounting arrow_forward Journals

 A Bank Register page was added, which includes a menu option for Details on journal entries. When clicked, the Journal Details page displays.

 Enhancements

 The Rent Manager Express dashboard will now display the Open Make Ready Process dashboard tile if it's on your dashboard in Rent Manager 12 .

 Path: arrow_forward Dashboard

 The Estimate Details page for owners was updated in the following ways:

 -
 If you click Add Purchase Order Link , you are now prompted to select a vendor. On the Purchase Order Details page, the name of the vendor, property, and unit associated with the estimate displays.

 -
 If you click on a linked invoice, the Invoice Details page displays. The Summary section now includes the name of the property management company entered in system preferences.

 -
 If you click on a linked service issue, the Service Issue Details page displays. The Links section now includes links to the property and unit associated with the estimate. Additionally, the Work Order section includes the property and unit information specified on the estimate.

 Path: arrow_forward Rental Info arrow_forward Owners arrow_forward Owners arrow_forward open an owner’s account arrow_forward arrow_forward Estimates

 The Deposit Details page was updated in the following ways:

 -
 If you select a Property Group , the field to select individual Properties is disabled.

 -
 Clicking to add a deposit now prompts an Add Payment-Deposit slide-up page to display.

 -
 The Information pop-up now includes the Created By and Updated By users in addition to the existing Created and Updated dates and times.

 When you choose to memorize an estimate or report, a message now displays stating the report or estimate has been memorized successfully. Additionally, the message includes an option to Click to View , which takes you to the Memorized Reports page or the Memorized Estimate Details page.

 The Owners register was updated with an option to filter by Property Group .

 Path: arrow_forward Rental Info arrow_forward Owners arrow_forward Owners arrow_forward

 The Bills register was updated to remember your filter selections, so your Show unpaid bills only preference is set each time you open the page.

 Path: arrow_forward Payables arrow_forward Bills

 The Service Issue Details page was updated with a Scheduled Date field, which allows you to input the date your service technician is scheduled to address the issue.

 The Property Details page now includes a field for Default Inspector in the Other Information section, so inspections at your property are automatically assigned to the default inspector if no one else is selected.
