12.240703 Release Notes

The release begins rolling out on August 21, 2024.

New Features

Loans Payable tools were added to Rent Manager Express!

Express

We’ve added a Loans Payable tool to Rent Manager Express, which allows you to track your outstanding loan balances, manage loan details, and easily record loan payment transactions. With this update, Rent Manager calculates the principal and interest split on your payments, while also enabling you to add additional costs, such as escrow or insurance, to the payment transaction. Loan payments can also be posted automatically each month through posting automation. Further, amortization schedules are calculated so you quickly see what’s left to pay. With the Loans Payable tool, mortgages, auto loans, and other business loans can now be managed seamlessly in Rent Manager Express.

As part of this update, the existing Loans tool was renamed to Loans Receivable.

For more information, refer to the Loans Payable Add Wizard topic in Express help.
