# 12.1060 Release Notes

Source: https://rmxhelp.rentmanager.com/Topics/Express/Release-Notes/2024/12.1060.htm

The release begins rolling out on March 21, 2024.

 New Features

 We’ve added an @mention user-tagging tool to Rent Manager Express , which allows users to mention other users with the @ tag on a history note item. Once @mentioned, the program sends a notification email with the note's contents to the tagged user, along with a link to the history note in Express . As part of this change, Rent Manager Express now requires all user profiles to include an email address. Additionally, to support this update, you can add a contact image and title on the User page, which displays in the users list when an individual is @mentioned in a history note.

 Enhancements

 An exciting sneak peak! A modern, streamlined design is coming soon to reports in Rent Manager Express . The first 60 reports will be ready in no time, but that's just the beginning—we'll keep at it until all 450+ reports are updated. These exciting changes will be automatic, but if you'd rather wait until all the reports are updated, you can uncheck Use modernized report style in system preferences. For more information on how to access this new setting, refer to General Report Options (System Preferences) .

 Bulk Actions for Add Note was incorporated into the following pages:

 -
 Properties

 -
 Units

 -
 Vendors

 -
 Owners

 This means—using owners as an example—you can select Add Note from the Bulk Actions drop-down list to quickly add a history note item, including attaching a file, to multiple owner records at once. This could be used in conjunction with the Owner Web Access (OWA) History Notes system web preference Displayed Note Categories to push a document/PDF file to the History/Notes of OWA.

 Zego CashPay is now available in Rent Manager Express ! This service allows your tenants and prospects to pay their rent and other charges in cash at more than 30,000 retail locations across the United States. Payments are immediately reflected in your Rent Manager database. CashPay eliminates the need to handle money in your office, reducing liability and enabling tenants and prospects to make payments during convenient retail hours.

 This release also brings Virtual Post Office (VPO) to Express . This Rent Manager -exclusive service allows you to outsource the expensive and time-consuming process of printing and mailing letters, statements, and reports by sending those documents directly to VPO for production and distribution to the appropriate recipients.

 The Vendor layout type was added to System Layouts and My Layouts . This addition makes it a breeze to create a vendor layout that optimizes your workflows and meets your individual business needs!

 We’ve enhanced several pages— Tenants , Issues , Tasks , Owner Prospects , Memorized Journals , and Recurring Journals —making significant speed improvements and making more fields available for searching. For example, previously, you could search the Tenants page on first name, last name, and account number. Now, you can also search on property, unit, address, contacts, license, vehicle, etc.

 Last, but certainly not least, the Blue Moon integration was updated so you can now initiate the Blue Moon eSignature process from Express ! Additionally, the Blue Moon eSignatures page was added. From this page you can monitor the status of your eSignature documents as well as complete (referred to as execute or counter sign in Blue Moon ) eSignature documents. Once the eSignature is completed, a history note item is added to record the completed forms with a copy of the signed forms attached.
