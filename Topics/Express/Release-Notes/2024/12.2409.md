# 12.240900 Release Notes

Source: https://rmxhelp.rentmanager.com/Topics/Express/Release-Notes/2024/12.2409.htm

The release begins rolling out on September 17, 2024.

 New Features

 Efficiently track and manage tenant evictions with the new Eviction Workflows tool!

 Express Rent Manager 12 rmAppSuite Pro

 We’re excited to introduce Eviction Workflows in Rent Manager Express : a streamlined solution for efficiently managing evictions! With this dynamic new tool, you can create and assign custom workflows tailored to each of your properties’ jurisdictions. You can also customize each eviction stage to effortlessly track crucial data in an intuitive layout. Access eviction statuses, notes, and history instantly from a dedicated tile. Additionally, badges are displayed on the Tenant listing and details pages to ensure your team stays informed. Once you’ve set up evictions in Express , you can view evictions on the tenant account from Rent Manager 12 and rmAppSuite Pro .

 For more information, refer to the Set Up Evictions topic.

 Enhancements

 The Loans Payable tool was updated with a handy refinancing wizard and versatile reports.

 Express Rent Manager 12

 The Loans Payable tool was updated, allowing you to effortlessly manage your loan portfolio with new reports and an all-in-one refinance wizard. As part of this update, the following changes were made in Rent Manager Express :

 -
 The Refinance Loan add wizard was added, which enables you to close out a current loan, set up a new loan, capture any financial transactions, and maintain a clear history by linking loans together in history/note items—all in one convenient location. For more information, refer to the Loans Payable Rate-and-Term Refinance topic.

 Additionally, the following changes were made in Rent Manager 12 and Express :

 -
 The Loans Payable Transaction History report was added, which displays a breakdown of recent payments made to loans during a specified date range. Additionally, this report details the total amount paid for all the loans listed, including the principle, interest, and extra payments. For more information, refer to the Loans Payable Transaction History (Report) topic.

 -
 The Loans Payable Listing report was added, which displays a list of the loans you have borrowed from financial institutions for your business. This report allows you to track information about each of your loans, such as how much you pay monthly, the total borrowed amount, and the remaining balance yet to be paid. For more information, refer to the Loans Payable Listing (Report) topic.

 System Filters are now available in Rent Manager Express !

 Express

 The System Filters page was added to Express , allowing you to create filters that can be used for multiple entities and service issues, and for sharing with other Rent Manager users. Existing filters created by individual users can be made available to other users by copying and saving them as system filters.

 Quickly view scanned documents or images associated with a transaction via the new Attachments column.

 Express

 An Attachments column was added to the Journals , Checks , and Bank Register pages, as well as the Vendor Transactions pop-up. If any attachments are associated with a journal, check, bank, or vendor transaction, a displays on the line item. Clicking the icon allows you to quickly view the document or image linked in the transaction.

 Display letters inside the body of an email with the Use merged document as body field option.

 Express

 The Attach to Email pop-up was updated with Use merged document as body field and .html File Format options that allow you to display the contents of a letter inside the body of an email, as opposed to a separate attachment that the recipient must download.
