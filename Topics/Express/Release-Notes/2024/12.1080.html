12.1080 Release Notes

The release begins rolling out on May 14, 2024.

New Features

Quickly take stock of your organization’s user roles with the new User Listing report. This report—which displays users' First Name, Last Name, Email, Phone, Extension, and Roles—lets you track important user contact information and the roles they’ve been assigned.

Path: arrow_forward System arrow_forward Users arrow_forward User Listing

Enhancements

Phone Number Types were added to Express, enabling you to customize the name (label) and types of phone numbers in an entity’s Phone Numbers section.

Path: arrow_forward Administration arrow_forward Customization arrow_forward Phone Number Types

The Prospects page was updated with Bulk Action options for Set to Lost, Change Stage, and Delete. These additions allow you to quickly delete or change the status or stage of one or more prospects at once.

A Memorized Comment icon was added to Memo and Comments fields throughout Express, allowing you to easily insert previously created custom messages in these fields to save time. For example, if you’re creating bills for multiple properties, you can insert a memorized comment in the Memo field to quickly include a property-specific message for each bill.

The Add Payments tool was optimized for the mobile view, making it quicker and easier to enter payments on the go.

To make it easier to update letter templates, generating a single letter now opens the template editor, not a PDF.
