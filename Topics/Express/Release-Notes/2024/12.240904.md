# 12.240904 Release Notes

Source: https://rmxhelp.rentmanager.com/Topics/Express/Release-Notes/2024/12.240904.htm

The release begins rolling out on October 8, 2024.

 New Features

 Use the new Prospect Leasing Board in Express to improve your leasing process and boost conversion rates!

 Express

 The Prospect Leasing Board was added to Rent Manager Express , giving you a central hub to manage and monitor your entire leasing process. Utilizing a Kanban-style board, this new resource provides a panoramic view of your prospect landscape, enabling you to instantly identify where each prospect stands in their leasing journey, organized by your existing prospect stages. The Prospect Leasing Board also makes it easy to spot when a prospect’s Next Contact is due, and flags when an action is overdue, ensuring timely engagements that keep momentum going. What’s more, you can customize prospect card details for improved insight and execute critical actions (write letters, send emails, run and view screenings, etc.) directly from the board.

 For more information, refer to the Prospect Leasing Board (Page) topic in Express help.

 To make automating you leasing workflow easier, the following prospect stage triggers were added:

 -
 Apply Now Application Started , which automatically updates the prospect’s stage when their Apply Now application status is In Progress .

 -
 Expected Move In Date Set , which automatically updates the prospect’s stage when a Move In date is entered on their account.

 -
 Signable Document Pending Acceptance , which automatically updates the prospect’s stage when their published signable document status is Pending Acceptance .

 -
 Appointment Added , which automatically updates the prospect’s stage when a saved appointment is linked to their account.

 Additionally, for stage advancements linked to specific documents, a Signable Document(s) field was added for the Signable Document Published trigger, which allows you to select from a list of available signable documents.

 Lastly, the Prospect Stage Change automated notification was added, which allows you to automatically send an email or text message to prospects, property managers, and/or Rent Manager users when a prospect’s stage changes.

 Enhancements

 Standard Management Fees have been significantly enhanced in Rent Manager .

 Express Rent Manager 12

 To make handling your management fees more intuitive and user-friendly, some exciting enhancements were made to Standard Management Fees! These updates include the integration of partial pass-throughs, seamless fee collection when credits apply to charges, and the ability to deactivate fee templates for both standard and advanced structures. Additionally, the Management Free Breakdown report was updated with an Include Pass Throughs option. Changes were also made to how data displays on the Management Fees Templates page, the Fees Setup pop-up, and the Convert wizard, improving organization, spacing, and legibility.

 The Management Fee Template Listing report was also added to Rent Manager with this update, which allows you to quickly identify the management fee templates used for each property.

 Streamline communication with your tenants when they are charged a late fee with the new Late Fee Posting automated notification!

 Express Rent Manager 12

 The Late Fee Posting automated notification was added, which allows you to automatically send notice letters via email or text message to tenants when late fees are posted using task automation or the Post Late Fees page.
