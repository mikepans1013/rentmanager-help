# 12.1090 Release Notes

Source: https://rmxhelp.rentmanager.com/Topics/Express/Release-Notes/2024/12.1090.htm

The release begins rolling out on June 18, 2024.

 New Features

 The Express Help was redesigned to better serve your learning needs!

 Express

 With this release, Rent Manager Express Help was redesigned to include shorter topics; a curated list of help-resource links, including Rent Manager University videos on the right-hand side of most topics; and optimized search results. Additionally, this Release Notes document was redesigned to make it easier for you to identify what’s been added and updated across all Rent Manager products.

 Income Verification is now available in Rent Manager !

 Express Rent Manager 12

 As previewed in April’s Release Notes, Income Verification, powered by AmRent is now available in Rent Manager ! This new resource is designed to simplify how applicants submit their income details during the resident screening process. Because this licensed feature is a built-in integration, you securely initiate the income verification process from your Prospects and Tenants pages. From there, you can easily send an email or text message to the applicant, where they complete a few steps authorizing their bank account data to be reported directly to Rent Manager for your review. This eliminates paper documentation so you can quickly and confidently verify income.

 If you’re interested in learning more about the Income Verification feature, call (800) 324-3681 option 3, or email rmsales@amrent.com.

 Enhancements

 The Blue Moon integration was improved to make creating and completing your multifamily leases in Rent Manager a breeze!

 Express Rent Manager 12

 Rent Manager 's Blue Moon integration was updated to make it easier to find and fill out fields and ensure field attribute consistency (default values, locks, and required statuses). Required fields always display at the top of lists, unused fields do not display by default, and only fields associated with the selected form display. As a part of this update, the following changes were made in Rent Manager :

 -
 The Blue Moon General system preferences were updated with a Hide fields that are locked in Blue Moon option, which allows you to hide locked fields when generating a Blue Moon lease from a tenant or prospect account in Rent Manager .

 -
 User privileges were updated with an Edit Blue Moon locked fields option, which, if checked, allows locked fields in Blue Moon to be overwritten when generating a Blue Moon lease from a tenant or prospect account.

 Use the new custom layout Issue Links Information option to quickly view linked entity data within your service issues!

 Express Rent Manager 12 rmAppSuite Pro

 Custom issue layouts were updated with an Issue Links Information option, which enables you to quickly view data about linked entities (tenants, units, properties, assets, vendors, and owners) within service issues without having to navigate to the desired entity’s page. For example, this custom section can be utilized by a service tech to determine if a tenant has a pet, how many pets they have, and the associated pet type(s) directly from the issue.

 Additional Express reports were updated with improved styling and usability!

 Express

 An additional 34 reports (including 9 owner reports) received our new streamlined design in this release. Headers that include the report’s name, date information (if applicable), and specified report options were added to all pages of the updated reports. Changes were also made to the way data is displayed in these reports, improving organization, spacing, shading, and legibility.

 In addition to the new styling, we’ve significantly improved the format of Excel exports—removing merged cells and improving the overall alignment—making it much easier to tweak the exported data to fit your needs.

 Updated and expanded filtering options have come to the Units page.

 Express

 The Filter options on the Units page were updated and expanded, giving you the ability to create advanced filters and save your filters as system filters (which can be viewed and managed in Rent Manager 12 ).
