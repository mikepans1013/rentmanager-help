12.720 Release Notes

The release begins rolling out on May 20, 2021.

New Features

The Inventory Items feature was added which includes the following pages:

  • The Inventory Items Register has options to add new inventory items and manage existing inventory items.

  • The Inventory Item Details page allows you to view and edit inventory item information.

Path: arrow_forward Accounting arrow_forward Setup arrow_forward Inventory Items

You can now perform electronic bank reconciliations and electronic credit card reconciliations in Express.

Path: arrow_forward Accounting arrow_forward Reconciliation arrow_forward Electronic Bank Reconciliation | Electronic Credit Card Reconciliation

The Safeguard eChecks feature is now available and includes the following pages:

  • The Post eChecks register
    Path: arrow_forward Payables arrow_forward eChecks arrow_forward Post eChecks

  • The eChecks Returns register
    Path: arrow_forward Payables arrow_forward eChecks arrow_forward eChecks Returns

  • The Reorder eChecks register
    Path: arrow_forward Payables arrow_forward eChecks arrow_forward Reorder eChecks

The Gross Potential Rent (GPR) Posting History feature is now available and includes the following pages:

  • The GPR Posting History register allows you to filter and view previous GPR postings.

  • The GPR Posting History Details page allows you to view cash and accrual journals associated with GPR postings.

Path: arrow_forward Accounting arrow_forward Gross Potential Rent arrow_forward GPR Posting History

You can now export a 1099 to send to the IRS for tax purposes.

Path: arrow_forward Admin arrow_forward Export arrow_forward Export 1099

The VoIP Details page now lets you play a recorded phone call provided you have the Rent Manager 12 privilege to Listen to recorded calls.

You now have the option to merge vendor accounts in Express.

Path: arrow_forward Admin arrow_forward Merge arrow_forward Merge Vendors

Enhancements

The Layout Editor was updated in the following ways:

  • Tenant layouts now include a Primary Contact Address field and allow you to add multiple addresses to a tile.

  • In Unit layouts now include a Default Security Deposits tile and allow you to add User Defined Fields to your custom layout.

  • Property layouts now include a Charge Type Banks tile and Phone Number fields.

  • Prospect layouts now include Primary Contact fields.

Path: arrow_forward Admin Setup arrow_forward Customization arrow_forward Layouts

The Service Manager Priorities, Service Manager Categories, and Service Manager Statuses pages were updated so values in the Name column now display with a border around them. You can click Details to see a preview of the formatting on the Edit pop-ups for each page. Additionally, the Issues, Recurring Issues, and Memorized Issues registers were updated so the values in the Category, Priority, and Status columns also display with borders around them.

On the Unit Details page, a new Default Security Deposits tile displays in the default layout. Additionally, there is now a Quick Add option to Add Default Security Deposit and a View More option for Default Security Deposits.

On the Call Details page, the scoreboard now includes a link to the owner prospect lead source or the prospect lead source.

The Columns pop-up that displays when you click was updated so that all the options display in a singular column.

The User Defined Fields register was moved to Admin arrow_forward Setup arrow_forward User Defined Fields.

You can now generate the Make Ready Details report from the Make Ready Board provided you have the View Make Ready Board privilege enabled.

Path: arrow_forward Services arrow_forward Make Ready arrow_forward Make Ready Board arrow_forward arrow_forward Make Ready Detail Report
