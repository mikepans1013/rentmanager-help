# 12.700 Release Notes

Source: https://rmxhelp.rentmanager.com/Topics/Express/Release-Notes/2021/12.700.htm

The release begins rolling out on March 18, 2021.

 New Features

 You can now Add Owners in Express.

 You can now perform Bank Reconciliations and Credit Card Reconciliations in Express.

 The Chart of Accounts feature is now available in Express. This feature includes the following pages:

 -
 The Chart of Accounts Register which includes action bar options to add and sort chart accounts.

Path: arrow_forward Accounting arrow_forward Chart of Accounts

 -
 The Chart of Accounts Details page which displays account information (e.g., Type , GL Account Number , Name , etc.) and MICR information.

Path: arrow_forward Accounting arrow_forward Chart of Accounts arrow_forward select an account to view details | arrow_forward Details

 You can now view and edit Lead Sources in Express.

 Path: arrow_forward Admin arrow_forward Setup arrow_forward Rental Information arrow_forward Lead Sources

 You can now view and edit Tax Types in Express.

 Path: arrow_forward Admin arrow_forward Setup arrow_forward Accounting arrow_forward Tax Types

 Enhancements

 The Make Ready Board was updated in the following ways:

 -
 You can now click the icon to add or remove priorities. When you do this, a message saying, “The priority has been changed successfully”, now displays at the bottom of the page.

 -
 A Setup Columns icon was added, which allows you to add, remove, and sort information that displays on the header row of each process.

 -
 When you remove an item from a make ready process, a message displays which allows you to choose whether you want to delete the issue or inspection completely or just remove it from the make ready process.

 Path: arrow_forward Rental Info arrow_forward Services arrow_forward Make Ready arrow_forward Make Ready Board

 The Layout Editor was updated in the following ways:

 -
 The Toolbox now includes a search bar which allows you to search for specific fields to add to your layouts.

 -
 Unit layouts are now available.

 -
 Tenant and Property layouts now include Phone Number fields.

 -
 In Tenant layouts , you can now add User Defined Values for primary contacts.

 Path: arrow_forward Admin arrow_forward Setup arrow_forward Customization arrow_forward

 The Unit Details page was updated to include a View More menu option to Edit Layout , which redirects you to the Layout Editor .

 Path: arrow_forward Rental Info arrow_forward Units arrow_forward select a unit arrow_forward

 The Property Details page was updated to include the View More menu options to Email Apply Now Link and Copy Apply Now Link .

 Path: arrow_forward Rental Info arrow_forward Properties arrow_forward select a property arrow_forward

 The Invoices register now includes a Show Open Invoices Only quick filter and a Sort Columns icon.

 Path: arrow_forward Receivables arrow_forward Invoices
