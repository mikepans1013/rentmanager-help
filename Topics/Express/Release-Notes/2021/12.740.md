# 12.740 Release Notes

Source: https://rmxhelp.rentmanager.com/Topics/Express/Release-Notes/2021/12.740.htm

The release begins rolling out on July 21, 2021.

 New Features

 The Vendor 1099 Adjustment Tool was added, which allows you to verify that all of your checks have the appropriate 1099 status and update them if necessary.

 Path: arrow_forward Admin arrow_forward Setup arrow_forward Accounting arrow_forward Vendor 1099 Adjustment Tool

 Asset Depreciation schedules were added to the following pages:

 -
 A Depreciation tile was added to the Asset Details page, which displays the depreciation schedule assigned to the asset. If no schedule was assigned, click Create Depreciation Schedule to track and create journal entries that record the decline in value of a capitalized asset.

 -
 Click View More on the Depreciation tile to view the Depreciation History , which documents each journal entry's date and amount. The Depreciation History page also includes multiple actions to manage the schedule, such as posting depreciation, adding journal entries, generating the Depreciation Schedule report, and more.

 Path: arrow_forward Rental Info arrow_forward Assets arrow_forward select an asset arrow_forward Asset Details

 The AvidInvoice page was added, which allows you to import invoices from vendors using the AvidXchange integration. On this page, you can also click Sync Avid Vendor to compare vendor data between Rent Manager and AvidXchange . If the information has changed, the vendor data is updated to ensure the information is in sync.

 Path: arrow_forward Payables arrow_forward AvidXchange arrow_forward AvidInvoice

 The Prospect Details page now includes a Security Deposit summary card, which displays the amount of any held security deposit. Additionally, you may add, transfer, or refund a security deposit from this card.

 Path: arrow_forward Rental Info arrow_forward Prospects arrow_forward select an prospect arrow_forward Prospect Details

 The Merge Charge Types page was added, which allows you to merge one charge type and its transactions into a second charge type.

 Path: arrow_forward Admin arrow_forward Merge arrow_forward Merge Charge Types

 The Merge GL Accounts page was added, which allows you to merge one general ledger account and its transaction data into a second GL account of the same type and level.

 Path: arrow_forward Admin arrow_forward Merge arrow_forward Merge GL Accounts

 Task Automation for Gross Potential Rent (GPR) was added, where you can set up and print a posting schedule. Additionally, an Automate button was added on the Posting Gross Potential Rent page to set up Task Automation.

 Path: arrow_forward Admin arrow_forward Task Automation arrow_forward GPR

 Enhancements

 The Layout Editor was updated in the following ways:

 -
 Unit layouts now include buttons for Add Note and Market Rent .

 -
 Tenant layouts now include buttons for Default Phone Number , Add Call , Add Email , Add Visit , and Add Note .

 -
 Prospect layouts now include buttons for Default Phone Number , Move In , Prospect Status Change , Add Call , Add Email , Add Visit , and Add Note .

 -
 Property layouts now include buttons for Default Phone Number and Add Note .

 -
 Service Manager Issue layouts now include a Work Order Table tile.

 Path: arrow_forward Admin arrow_forward Setup arrow_forward Customization arrow_forward Layouts

 You can now override a screening decision from the Prospect Details page on the Lead Information tile.

 Path: arrow_forward Rental Info arrow_forward Prospects arrow_forward select an prospect arrow_forward Prospect Details

 The Unit Type Details page now includes a View More icon on the Properties tile.

 Path: arrow_forward Rental Info arrow_forward Unit Types arrow_forward select a unit type arrow_forward Unit Type Details arrow_forward Properties tile arrow_forward View More
