# 12.760 Release Notes

Source: https://rmxhelp.rentmanager.com/Topics/Express/Release-Notes/2021/12.760.htm

The release begins rolling out on September 21, 2021.

 New Features

 The Import Chart of Accounts and Import Payments features were added. Additionally, you can save your import settings as a template for future imports.

 Path: arrow_forward Admin arrow_forward Import arrow_forward Import Chart of Accounts | Import Payments

 Task Automation for Loan Late Fees and Recurring ePay were added. You may add new schedules and edit or delete existing schedules. Additionally, the register of schedules may be printed.

 Path: arrow_forward Admin arrow_forward Task Automation arrow_forward Loan Late Fees | Recurring ePay

 The Violation Categories page was added, where you can organize collections of violation codes that are similar. You can add new categories and edit or delete existing ones.

 Path: arrow_forward Admin arrow_forward Setup arrow_forward Rental Information arrow_forward Violation Categories

 The following reports were added:

 -
 The Basic Owner Statement report which shows financial activity and changes in the property's default bank balance over a specified period.

 -
 The Owner Activity report which displays an owner's income, expenses, management fees paid, and distributions received.

 Path: arrow_forward Reports arrow_forward Owners arrow_forward Basic Owner Statement | Owner Activity

 The following asset pages were added, which allow you to further customize the information about your assets. You can add new items on these pages, as well as edit or delete existing ones:

 -
 The Asset Types page allows you to categorize similar assets.

 -
 The Asset Manufacturers page allows you to specify the company who built your asset, and include that company’s contact and customer service information.

 -
 The Asset Statuses page allows you to create conditions that describe the current state of an asset (e.g., Out For Repair , In Use ).

 Path: arrow_forward Admin arrow_forward Assets arrow_forward Asset Types | Asset Manufacturers | Asset Statuses

 Enhancements

 You may now export loan data in the Metro2 format.

 Path: arrow_forward Admin arrow_forward Export arrow_forward Export to Metro2

 Menu items for Write Check and Add Bill were added to the Payables menu.

 Path: arrow_forward Payables arrow_forward Write Check | Add Bill

 When navigating away from certain pages with unsaved changes, the warning pop-up now includes an option to open the desired page in a new browser tab.

 Setup Columns is now available on all registers so you can determine what columns display on each page.
