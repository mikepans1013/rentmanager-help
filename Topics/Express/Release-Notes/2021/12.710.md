# 12.710 Release Notes

Source: https://rmxhelp.rentmanager.com/Topics/Express/Release-Notes/2021/12.710.htm

The release begins rolling out on April 20, 2021.

 New Features

 There is now a guided workflow to Add Owner Prospects in Rent Manager Express .

 Path: arrow_forward Rental Info arrow_forward Owners arrow_forward Owner Prospects arrow_forward

 The Recurring Journals feature is now available and includes the following pages:

 -
 A Recurring Journals register with options to add or delete recurring journals.
Path: arrow_forward Accounting arrow_forward Recurring Journals

 -
 A Recurring Journal Details page which allows you to edit, print, and/or memorize a recurring journal.
Path: arrow_forward Accounting arrow_forward Recurring Journals arrow_forward select a recurring journal to open the details page

 -
 A Post Recurring Journals page which allows you to select a Post Date , then manually post recurring journals for selected properties or owners.
Path: arrow_forward Accounting arrow_forward Posting arrow_forward Post Recurring Journals

 The Jobs feature is now available and includes the following pages:

 -
 A Jobs register with options to add, delete, sort, and filter jobs.
Path: arrow_forward Accounting arrow_forward Jobs

 -
 A Job Details page which allows you to view the job’s Budget and Recent Transactions .

 -
 A Job Types list which allows you to add, edit, and delete job types.
Path: arrow_forward Admin arrow_forward Setup arrow_forward Accounting arrow_forward Job Types

 You can now add, edit, and delete notes that appear on invoices and estimates.

 Path: arrow_forward Accounting arrow_forward Notes

 A Colors page was added which allows you to create and assign colors to entities.

 Path: arrow_forward Admin arrow_forward Setup arrow_forward Colors

 An Image Types page was added which allows you to create organizational categories for images that are uploaded to your database. These categories appear on the Upload Image pop-up when you select the Image Type field.

 Path: arrow_forward Admin arrow_forward Setup arrow_forward Image Types

 A User Defined Fields (UDFs) register was added which allows you to create and edit UDFs that track information Rent Manager does not track by default.

 Path: arrow_forward Admin arrow_forward Setup arrow_forward Rental Information arrow_forward User Defined Fields

 You can now manage Lease Terms which describe the duration of your tenant’s leases and can be selected on the Add Lease page.

 Path: arrow_forward Admin arrow_forward Setup arrow_forward Rental Information arrow_forward Lease Terms

 A Contact Types page was added which allows you to manage the types of contacts you track such as Emergency Contact or Cosigner which you specify on the View Contacts page.

 Path: arrow_forward Admin arrow_forward Setup arrow_forward Rental Information arrow_forward Contact Types

 A Unit Status Types page was added which allows you to create statuses that determine whether the unit should be considered available and/or vacant. These statuses appear on the Add Unit Status pop-up when you select the Unit Status field.

 Path: arrow_forward Admin arrow_forward Setup arrow_forward Rental Information arrow_forward Unit Status Types

 A Lost Reasons page was added which allows you to create and edit the reasons a prospect’s status was changed to lost or lost/rejected.

 Path: arrow_forward Admin arrow_forward Setup arrow_forward Rental Information arrow_forward Lost Reasons

 You can now create and assign floors to rental units which makes it easier to find specific kinds of units for prospects.

 Path: arrow_forward Admin arrow_forward Setup arrow_forward Rental Information arrow_forward Floors

 A History Categories page was added which allows you to create organizational categories for your notes, calls, visits, and emails.

 Path: arrow_forward Admin arrow_forward Setup arrow_forward Rental Information arrow_forward History Categories

 You can now create and edit Make Ready Actions which classify and determine the order in which service issues and inspections appear on the Make Ready Board .

 Path: arrow_forward Admin arrow_forward Setup arrow_forward Rental Information arrow_forward Make Ready Actions

 You can now manage the following Service Manager setup items in Rent Manager Express :

 -
 Service Manager Priorities which are levels that describe the urgency of an issue.
Path: arrow_forward Admin arrow_forward Setup arrow_forward Service Manager arrow_forward Priorities

 -
 Service Manager Categories which are classifications that help sort and track issues.
Path: arrow_forward Admin arrow_forward Setup arrow_forward Service Manager arrow_forward Categories

 -
 Service Manager Statuses which describe the progress of an issue.
Path: arrow_forward Admin arrow_forward Setup arrow_forward Service Manager arrow_forward Statuses

 You now have the option to export a 1098 which can be sent to the IRS for tax purposes.

 Path: arrow_forward Admin arrow_forward Export arrow_forward Export 1098

 You can now track consumer price index (CPI) adjustments in Rent Manager Express .

 Path: arrow_forward Admin arrow_forward Setup arrow_forward Accounting arrow_forward CPI

 Enhancements

 The Chart of Accounts register was updated in the following ways:

 -
 You now have the option to Print the register.

 -
 You can now drag and drop a row in the list to change the order in which it displays.

 Path: arrow_forward Accounting arrow_forward Chart of Accounts

 The Make Ready Board was updated to include a Sort By option which allows you to sort make ready processes by Unit , Property , Move Out , Next Move In , or Age . Additionally, the page was updated to improve speed and responsiveness.

 Path: arrow_forward Services arrow_forward Make Ready arrow_forward Make Ready Board

 The Layout Editor was updated in the following ways:

 -
 For Tenant layouts, additional late fee fields are now available.

 -
 For Property layouts, a User Privileges field is now available.

 -
 Prospect layouts now include the option to add custom fields, including Prospect User Defined Fields . Additionally, the Lead Information tile now includes an Override Screening Decision checkbox.

 Path: arrow_forward Admin arrow_forward Setup arrow_forward Customization arrow_forward

 ePay options in Rent Manager Express were updated in the following ways:

 -
 Diner’s Club is no longer an available Account Type .

 -
 Debit Card is now an available Account Type .

 -
 The card Type field automatically populates based on the numbers you input in the Card Number field.

 The Vendor Credits register was updated to include a Details option which allows you to view and edit existing vendor credits.

 Path: arrow_forward Payables arrow_forward Vendor Credits arrow_forward arrow_forward Details

 When you click Reconcile on the Bank Reconcile and Credit Card Reconcile pages, a second page where you can sort and view transaction information displays.

 Path: arrow_forward Accounting arrow_forward Reconciliation arrow_forward Bank Reconcile | Credit Card

 On the Asset Details page, information previously located in the Status and Location summary tiles is now available in the Asset Status History and Asset Location tiles. You can use the Layout Editor to customize the information that appears in both tiles.
