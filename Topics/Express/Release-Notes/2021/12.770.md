 The Users register and User Details pages were added, where you can manage information about each Rent Manager user, assign them privileges and/or user roles, and determine the properties, banks, and reports that they can access.

 Path: arrow_forward Admin arrow_forward Setup arrow_forward Users

 The Transaction Search page was added, which allows you to search your database for a transaction that occurred during a specified date range. Additionally, those search results can be further filtered.

 Path: arrow_forward Admin arrow_forward Find arrow_forward Transactions

 The History/Notes Search page was added, which allows you to search your database for history items or notes that match your search term.

 Path: arrow_forward Admin arrow_forward Find arrow_forward History/Notes

 The Import Charges feature was added. Additionally, you can save your import settings as a template for future imports.

 Path: arrow_forward Admin arrow_forward Import arrow_forward Import Charges

 The rmVoIP Unlinked Calls page was added, where records of calls that were not automatically matched to an account in Rent Manager and calls that were not answered are listed. On this page, select a call to view detailed information about the phone number from which the call was placed and the time it was received. Additionally, you may link the phone number to an existing account in your database or add a new tenant or prospect from the call record.

 Path: arrow_forward Correspondence arrow_forward rmVoIP Unlinked Calls

 The Owner Groups page was added, which allows you to create groupings of owners for quicker posting, reporting, and filtering. On this page, you can add new groups and manage or delete existing groups.

 Path: arrow_forward Admin arrow_forward Setup arrow_forward Rental Information arrow_forward Owner Groups

 The Amenities page was added, which allows you to document the features of your units in your database. After creating amenities, they can be assigned to units. On this page, you can add new amenities and update or delete existing ones, as well as order how they display on the Unit Add Wizard and the Amenities section of Unit Detail pages. Additionally, you can set the price of the amenity.

 Path: arrow_forward Admin arrow_forward Setup arrow_forward Rental Information arrow_forward Amenities

 The Posting Rollback register was added, which allows you to reverse charges and account reconciliations.

 Path: arrow_forward Admin arrow_forward Posting Rollback

 Enhancements

 You may now convert management fee templates from standard to advanced fee structures, and vice versa.

 Path: arrow_forward Rental Info arrow_forward Owners arrow_forward Management Fee Templates

 When using Command Launch , you can now hold Ctrl on your keyboard while left-clicking to open the search result in a new browser tab.

 The Unit Add Wizard now allows you to add multiple units at once.

 Path: arrow_forward Rental Info arrow_forward Units arrow_forward Add Unit

 On the Check Details page for eChecks , a link to an image of the check and the processing status of the check now displays. Additionally, if you have enabled the system preference to automatically post eChecks, the eCheck now posts upon being saved.

 Path: arrow_forward Payables arrow_forward Write Checks

 On the Tenant Transactions page, the Move button was added, which allows you to transfer a payment to another tenant at the same property.
