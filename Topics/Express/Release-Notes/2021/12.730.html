12.730 Release Notes

The release begins rolling out on June 15, 2021.

New Features

A Posting Gross Potential Rent page was added, which allows you to post GPR.

Path: arrow_forward Accounting arrow_forward Gross Potential Rent arrow_forward Post GPR

An Account Balance Disbursal page was added, which allows you to create bills or journal entries to transfer funds from one general ledger account to another, allocating specified amounts or charges to multiple properties.

Path: arrow_forward Payables arrow_forward Account Balance Disbursal

A Beginning Balances page was added, which allows you to establish your finances prior to using Rent Manager. Additionally, this page can be printed.

Path: arrow_forward Admin arrow_forward Setup arrow_forward Accounting arrow_forward Beginning Balances

The Post AvidPay page was added, which allows you to write checks and send them to vendors using the AvidXchange integration.

Path: arrow_forward Payables arrow_forward AvidXchange arrow_forward Post AvidPay

Unit Type layouts are now available in the Layout Editor.

Path: arrow_forward Admin arrow_forward Setup arrow_forward Customization arrow_forward Layouts

Enhancements

The Layout Editor was updated in the following ways:

  • Unit layouts now include buttons for Unit Status, Recurring Charge Add, and Recurring Charge Add CAM. In addition, a Script field was added.

  • Property layouts now include the AR Automation Schedule and Property Text Number fields and the Recurring Charge Add and Recurring Charge Add CAM buttons.

  • Tenant layouts now include buttons for Late Fees, TWA Settings, Recurring Charge Add, Recurring Charge Add CAM, and Add Security Deposit.

  • Prospect layouts now include buttons for TWA Settings and Add Security Deposit.

Path: arrow_forward Admin arrow_forward Setup arrow_forward Customization arrow_forward Layouts

The Incoming Calls register now includes a Days to Show filter.

Path: arrow_forward Correspondence arrow_forward rmVoIP Incoming Calls

Available actions on the Call Details pages were added to the action bar. Additionally, the name of the caller’s account now displays in the scoreboard.

Path: arrow_forward Correspondence arrow_forward rmVoIP Incoming Calls arrow_forward select a call arrow_forward Call Details

By clicking View More on User Defined Fields tiles, you can now search user defined fields.

The Prospect Detail page now includes a Lease Term field.

Path: arrow_forward Rental Info arrow_forward Prospects arrow_forward select a prospect arrow_forward Prospect Details

On the Inventory Item page in the Quick Add menu, options were added for Increase Inventory, Decrease Inventory, and Transfer Inventory.

Path: arrow_forward Accounting arrow_forward Setup arrow_forward Inventory Items arrow_forward select an inventory item arrow_forward Inventory Item
