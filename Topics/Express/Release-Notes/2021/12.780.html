12.780 Release Notes

The release begins rolling out on November 16, 2021.

New Features

Quick actions were added to the following registers:

  • Tenants

  • Prospects

  • Owners

  • Units

  • Properties

  • Vendors

  • Owner Prospects

  • Assets

For example, on the Tenants register, you can click on a tenant’s name and quickly compose an email, add a charge, service issue, or history/note item, or publish a signable document, among other actions.

A Letters tab was added to the User Details page, where you can manage the user’s access to letter templates.

Path: arrow_forward Admin arrow_forward Setup arrow_forward Users arrow_forward select a user arrow_forward Letters tab

An Open Detail in a New Tab section was added to the Personal Preferences page, where you can specify what types of Detail pages should open in a new tab.

Path: arrow_forward Preferences arrow_forward Personal arrow_forward Interface arrow_forward Open Detail in a New Tab

Enhancements

As part of tax form changes for the 2021 tax year, the following changes were made:

  • The Vendor 1099 report was updated so that if you select the report option for Nonemployee Compensation (NEC), the FATCA filing requirement field is removed. Additionally, the report now prints three forms per page.

  • The Owner 1099 Copy B report now includes a Miscellaneous Information label in the top-right corner, and the language in several fields was updated.

You may now add recurring and one-time charges when adding a new tenant.

Path: arrow_forward Rental Info arrow_forward Tenants arrow_forward Add Tenant

The Import Budget feature was added to the Admin menu.

Path: arrow_forward Admin arrow_forward Import arrow_forward Import Budget

In the Layout Editor, Service Manager Issue layouts now include the History/Notes, Links, and Issue History tiles.

Path: arrow_forward Admin arrow_forward Setup arrow_forward Customization arrow_forward Layouts

When adding line items to a check, after the Property, Expense Account, and Amount are entered, another row is added to the check with the same Property (and Unit, if specified).

Path: arrow_forward Payables arrow_forward Write Check

When reversing a reconciled journal entry, a warning now displays to alert the user that the journal is already reconciled.

Path: arrow_forward Accounting arrow_forward Journals

After saving system preferences, you are now prompted to log out and back in for the changes to take effect.

Path: arrow_forward Admin arrow_forward Preferences arrow_forward System Preferences

The User Details page was updated so that users who are locked out of Rent Manager due to failed login attempts now have the Locked status displayed at the top of the page.

Path: arrow_forward Admin arrow_forward Setup arrow_forward Users arrow_forward select a user

Property fields now include a Search icon which allows you to search and filter for specific properties in your database.

The Test Connection button was added to System Preferences: rmVoIP, which allows you to confirm your database’s connection to the rmVoIP service. Additionally, this page now displays whether the Connection Status is currently Connected or Closed.

Path: arrow_forward Admin arrow_forward Preferences arrow_forward System Preferences arrow_forward rmVoIP

The Override option was added to the Screenings card on the Prospect Details page. Screenings that have previously been overridden display a green checkmark. Additionally, you may now enter a Description of why the screening decision was overridden. This Description is saved to the prospect (or tenant) History/Notes.

Path: arrow_forward Rental Info arrow_forward Prospects arrow_forward select a prospect arrow_forward Prospect Details arrow_forward Screenings card
