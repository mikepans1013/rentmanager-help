# 12.680 Release Notes

Source: https://rmxhelp.rentmanager.com/Topics/Express/Release-Notes/2021/12.680.htm

The release begins rolling out on January 19, 2021.

 New Features

 The Make Ready feature is now available in Rent Manager Express . This feature includes the following pages:

 -
 The Make Ready Board was added which displays units that are assigned a make ready process with color-coded statuses for the associated issues and inspections.
Path: arrow_forward Services arrow_forward Make Ready arrow_forward Make Ready Board

 -
 A Make Ready Details page was added which includes a full range of action bar options such as the ability to add new or link to issues or inspections.

 -
 The Make Ready Detail and Make Ready Summary reports were added.
Path: arrow_forward Reports arrow_forward Make Ready

 In addition to the new pages listed above, the following changes were also made:

 -
 You can now assign a new Make Ready process from the action bar on tenants and units.

 -
 A history/note for a Make Ready process on a tenant or unit can now open the Make Ready Details .

 -
 A service issue associated with a Make Ready process now includes a link to the Make Ready Details .

 Assets are now available in Rent Manager Express . This feature includes the following pages:

 -
 An Asset register which displays available assets.
Path: arrow_forward Rental Info arrow_forward Assets

 -
 An Asset Details page to view the data about an asset, including slide-up pages for History/Notes and User Defined Fields .

 In addition, asset data is included in applicable Command Launch search results.

 Owner Prospects are now available in Rent Manager Express . This feature includes the following pages:

 -
 An Owner Prospects register which displays the owner prospects in your database.
Path: arrow_forward Rental Info arrow_forward Owners arrow_forward Owner Prospects

 -
 An Owner Prospect Details page to view data about an owner prospect, including slide-up pages for Properties , User Defined Fields , and History/Notes .

 -
 An Owner Prospect Lead Sources page was added to manage the many ways an owner prospect could learn about your business.
Path: arrow_forward Rental Info arrow_forward Owners arrow_forward Owner Prospect Lead Sources

 In addition, Owner Prospect data is included in applicable Command Launch search results.

 A Manual Owner Pay page was added which allows you to make equity distributions to an owner for a specific amount.

 Path: arrow_forward Rental Info arrow_forward Owners arrow_forward Manual Owner Pay

 You can now Pay Bills from Rent Manager Express .

 Path: arrow_forward Payables arrow_forward Posting arrow_forward Pay Bills

 A register was added for Memorized Journals which displays saved journal entries. In addition, you can now memorize an existing journal entry and load the details of a memorized journal when creating a new journal entry.

 Path: arrow_forward Accounting arrow_forward Memorized Journals

 Enhancements

 The Layout Editor was updated in the following ways:

 -
 Asset layouts are now available.

 -
 Property fields were added to the Toolbox .

 -
 The designer now includes an Empty Tile which allows you to add a blank tile to which fields can be added.

 The Vendor Transactions slide-up page was updated to support deleting transactions. On a transaction line, click and select Delete .

 Path: arrow_forward Payables arrow_forward Vendors arrow_forward select a vendor arrow_forward Recent Transactions arrow_forward select a transaction arrow_forward arrow_forward Delete

 Reports that have scripting to prompt a user response prior to generation are now supported in Rent Manager Express .
