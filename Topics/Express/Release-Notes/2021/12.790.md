# 12.790 Release Notes

Source: https://rmxhelp.rentmanager.com/Topics/Express/Release-Notes/2021/12.790.htm

The release begins rolling out on December 14, 2021.

 New Features

 The Ownership Transfer Wizard was added, which allows you to move ownerships between owners with whom you have management contracts if a property is sold, inherited, and so on.

 Positive Pay Formats were added, which allows Rent Manager and your bank to establish a communication system where information about checks you write is shared with the bank before they are cashed. When the checks are cashed, the bank can compare the presented checks against the information you sent them to ensure that the checks were not altered.

 Path: arrow_forward Admin arrow_forward Setup arrow_forward Payables arrow_forward Positive Pay Formats

 Additionally, Export Positive Pay was added, which allows you to save check data in the mapped Positive Pay Formats required by your bank to a file location on your computer or network.

 Path: arrow_forward Admin arrow_forward Task Automation arrow_forward Export Positive Pay

 The Chart of Accounts Mapping feature was added, which allows you to customize the appearance and naming structure of individual general ledger accounts.

 Path: arrow_forward Accounting arrow_forward Chart of Accounts Mapping

 The Import Journals feature was added.

 Path: arrow_forward Admin arrow_forward Import arrow_forward Import Journals

 To help you understand the expenses associated with completed make ready processes, the Make Ready Expense and Make Ready Action Expense reports were added.

 Path: arrow_forward Reports arrow_forward Make Ready arrow_forward Make Ready Expense | Make Ready Action Expense.
