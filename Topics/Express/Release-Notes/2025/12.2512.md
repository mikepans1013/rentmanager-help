# 12.251200 Changelog

Source: https://rmxhelp.rentmanager.com/Topics/Express/Release-Notes/2025/12.2512.htm

The release begins rolling out on December 9, 2025.

 New Features

 Rent Manager 's tax reporting tools have been updated to comply with the IRS.

 Express Rent Manager 12

 The following Rent Manager reports were updated to be in compliance with the IRS's revised tax year requirements which includes aligning each report's options and results with the revised 2025 forms.

 -
 Vendor 1099 (Report)

 -
 Vendor 1099 Copy B (Report)

 -
 Vendor 1096 (Report)

 -
 Owner 1099 (Report)

 -
 Owner 1099 Copy B (Report)

 -
 Loans Receivable 1096 (Report)

 Additionally, the Export 1099 tool was updated, allowing you to generate an export 1099 file in accordance with the IRS's 2025 filing requirements. For more information, refer to the Export Vendor 1099 and Export Corrected Vendor 1099 topics in Express help.

 More Information

 As of tax year 2025, Excess Golden Parachute Payments can no longer be filed using the FIRE system. To report such payments, speak with your accountant about alternative filing methods, such as the IRIS system.

 Control access to Rent Manager 12 with a new privilege.

 Express Rent Manager 12

 To help users transition to Rent Manager Express , the System privilege group was updated with an Access Rent Manager 12 privilege, which allows the user to access Rent Manager 12 . Without this privilege, a user can only access Express . For more information, refer to the System Privilege Group topic in Express help.

 Post with precision with new general ledger system preferences.

 Express Rent Manager 12

 The General Ledger - Settings system preferences were updated with a Parent Accounts section, which allows you to determine if parent accounts can be used for financial transactions. For more information, refer to the General Ledger Settings (System Preferences) topic in Express help.

 You can now import a custom layout or export one you have created in Rent Manager Express .

 Express

 The custom layout tool was updated in Express , allowing you to import and export a custom layout from your workstation or network in order to share with other users. In addition to easily sharing layouts you have created, this update also makes it a breeze to locate helpful layouts from the online template library (OTL), including layouts provided by our API partners to support integration with their services.

 For more information, refer to the Import a Custom Layout topic in Express help.

 Limit rmAppSuite Pro users from viewing previous meter reading information to ensure readings are not estimated!

 Express Rent Manager 12 rmAppSuite Pro

 You can now determine whether rmAppSuite Pro users can view previous Metered Utilities reading information when entering new readings for Metered Utilities with the new rmAppSuite - Utilities system preference. For more information, refer to the rmAppSuite Utilities (System Preferences) topic in Express help.

 More Information

 This feature is licensed and must be purchased separately. For more information, contact your sales representative at sales@rentmanager.com .

 Enhancements

 Transform your rent quote process with the ability to add charges to each quote with seamless efficiency!

 Express Rent Manager 12

 The rent quotes tool was updated so you can easily add recurring and one-time charges to each quote. These new updates streamline the move-in process, allowing you to script the rent quote with any additional charges directly from the prospect's account. Additionally, your default system settings are automatically tied to the prospect, so you can quickly choose which charges are associated with the quote and, if necessary, add new charges.

 As part of this update, the following changes were made:

 -
 The Tenants/Prospects privilege group was updated with a Modify charges in the move in wizard privilege, which, when Enabled , grants the user the ability to add, delete, and inherit/uninherit recurring charges in the Move In wizard. Additionally, this privilege allows the user to add, modify dates, inherit/uninherit, or delete one-time charges in the Move In wizard.

 -
 The General Options - Tenant Charge Setup system preferences were updated to make establishing default recurring, one-time, deposit, and prorated charges more intuitive and user-friendly.

 -
 The Property details page was updated with a Tenant Charge Setup action menu option, allowing you to Override System Preferences and institute property-specific charge setups.

 -
 The Add Rent Quote pop-up was updated with a Charge Type field, which allows you to associate detailed charge information with the rent quote.

 -
 The Prospect details page was updated so it's easier to manage a prospect's quote(s) from the Rent Quotes tile.

 -
 The Move In wizard was updated to display recurring and one-time charges from the rent quote.

 -
 In the RentQuotes scripting class, the Amount function was renamed Rent.

 -
 The following rent quote scripts were added, allowing you to pull specified quote information into custom reports or include in letters and notices.

 -
 [Prospect.RentQuotes.AdditionalRecurring()]

 -
 [Prospect.RentQuotes.OneTimeChargeAmount()]

 -
 [Prospect.RentQuotes.OneTimeChargeCount()]

 -
 [Prospect.RentQuotes.OneTimeChargesList()]

 -
 [Prospect.RentQuotes.RecurringChargeList()]

 -
 [Prospect.RentQuotes.RecurringChargeCount()]

 -
 [Prospect.ReservedQuoteOnetimeCharge()]

 -
 [Prospect.ReservedQuoteAdditionalRecurring()]

 -
 [Prospect.ReservedQuoteRent()]

 The rent quotes tool also received several updates in Rent Manager 12 . These updates have improved navigation and added or repositioned sections, filters, and fields to simplify the rent quotes process.

 The lease renewal tool was updated to make filtering lease and offer expirations by a custom date range a breeze.

 Express

 The Lease Renewal Register 's and Lease Renewal Board 's filters for Lease Expires and Offer Expires were updated with a Custom Date Range option, allowing you to set the From and To dates to examine expiration data within that range. Additionally, the Create Renewal Offers wizard's filter for Leases Expiring Within now accepts a Custom Date Range .

 Get high-level tracking and reporting for your manufactured housing properties with the new site classification updates.

 Express Rent Manager 12

 A new Occupied site classification was added, and is automatically applied to sites that have an active tenant lease, but have neither a homeowner status nor a home-type asset or resident-owned RV associated with them.

 In addition, the Tenants page was updated with an advanced filter and available column for Site Classification , which displays the current Site Classification of the unit associated with the tenant's primary lease.
