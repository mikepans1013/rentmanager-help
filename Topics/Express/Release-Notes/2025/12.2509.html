12.250900 Changelog

The release begins rolling out on September 17, 2025.

New Features

Say goodbye to missing data and disputed unit statuses with the new inspection tool updates.

Express Rent Manager 12 rmAppSuite Pro rmResident

Rent Manager inspections were updated, allowing you to quickly create and send custom move-in inspections to tenants for them to complete via rmResident, ensuring their unit is well-maintained from the start. Self-inspections can be sent to tenants once you kick off the inspection in Rent Manager. Completed self-inspections are automatically recorded in Rent Manager, empowering you to quickly understand and act on your renter’s feedback.

As part of these improvements, the following updates were made:

  • The Inspections privilege group was updated with a Send Tenant Self-Inspections privilege.

  • The Tenant Web Access (TWA) rmResident system web preferences were updated, allowing you to establish Tenant Self-Inspection Settings and Tenant Self-Inspection Invitation Email. For more information, refer to the Tenant Web Access rmResident (System Web Preferences) topic in Express help.

  • The Inspection Template page was updated with Active and rmResident Mode fields. The Active field determines whether the template can be assigned at the unit or unit type and selected when kicking off a new inspection. The rmResident Mode field determines what displays for tenants in rmResident and the areas and/or items they are required to inspect.

  • The Toolbox pop-up was added, which allows you to easily add, edit, and delete your existing inspection components (Areas, Items, and Statuses) from a single location. In addition, a Help Text section was added, which allows you to add instructions to guide employees (in rmAppSuite Pro) and tenants (in rmResident) as they inspect an item. For more information, refer to the Edit an Inspection Template Toolbox topic in Express help.

  • The Tenants page row actions were updated with Send Management Inspection and Send Tenant Self-Inspection options.

  • The Inspections page was updated with an Inspector Type filter and Expiration Date, Submitted By User, and Submitted By Web User were added to available columns.

  • The Inspection Types pop-up was added, which allows you view and manage your inspection types.

  • The Tenant Self-Inspections dashboard tile was added, which displays a list of tenants who have inspections assigned to them. Additionally, the tile displays the Property and Unit associated with the tenant and the inspection's Expiration date and Status (In Progress, Pending Maintenance, Awaiting Review, etc.). For more information, refer to the Tenant Self-Inspections (Dashboard Tile) topic in Express help.

  • The Move In wizard was updated with a Tenant Self-Inspection tile, which allows you to select the inspection's Template, Inspection Type, and Expiration Date.

  • The Tenant Self Inspection Awaiting Review automated notification was added, which automatically alerts users when a tenant submits their unit self-inspection. For more information, refer to the Tenant Self Inspection Awaiting Review (Automated Notification) topic in Express help.

  • The Inspection Scheduled automated notification was renamed Management Inspection Scheduled.

The inspection tool also received several updates in Rent Manager 12. These updates have improved navigation and added or repositioned sections, filters, and fields to simplify the inspection process.

Improve your asset management with new privileges.

Express Rent Manager 12

The Asset Management privilege group was updated with two new privileges, which allow you to streamline your home-type asset management and preserve important details. The Manage Home Asset Locations privilege allows you to safeguard data by limiting the users who can manage home-type asset locations from the Asset details page. The Manage Home Asset Status History privilege allows you to determine the users who can manage home-type asset statuses from the Asset details page.

Managing returned ePay payments in Rent Manager just got easier.

Express Rent Manager 12

The Task Automation tool now offers a way to automate reversals and non-sufficient funds (NSF) fee postings. With the ePay Returns automation, you can easily handle failed ePay payments, notifying Property Managers and/or Other Recipients and addressing returned payments without manual intervention. Additionally, you can set up property-specific NSF fees, ensuring that the correct fee is always applied.

As part of these improvements, the following updates were made:

  • The Task Automation system preferences were updated with a ePay Returns field, which, when enabled, allows you to determine the Property Managers and/or Other Recipients who are notified of failed payments. For more information, refer to the Task Automation (System Preferences) topic in Express help.

  • The Override default NSF fee when processing NSF payments privilege was added, which allows you to override the default NSF fee amount when processing a return on the Check ePay Returns page.

  • The Property details page was updated with NSF Fee fields, which allow you to Override system default and establish the property's Custom Amount.

  • The Properties page was updated NSF Fee available column, which displays the amount to charge as an NSF fee for the payment reversal.

  • The ePay Returns page was updated, making information easier to read, improving navigation, and adding or repositioning columns and fields to simplify performing popular actions.

  • The ePay Returns report was added, which allows you to easily track returns processed on tenant ePay payments.

Access Rent Manager University (RMU) courses and learning paths with the new My Training widget in Rent Manager Express.

Express

The My Training widget was added to the My Workspace page, which allows you to access your assigned RMU courses and learning paths directly from Rent Manager Express. With real-time visibility into your course progress and quick links to continue your learning, this tool makes your Rent Manager training faster, easier, and more intuitive.

Easily edit, organize, and manage your communications with new message template options.

Express Rent Manager 12

To make standardizing your letters, emails, or texts in Rent Manager Express more intuitive and user-friendly, new options were added to message templates. These updates allow you to leverage letter templates for emails, set up templated emails, and create text templates for both individual and bulk messaging (directly or via the Text Messaging Center). For more information, refer to the Letter and Message Templates topic in Express help.

As part of these updates, the following changes were made:

  • The User details page Letters tab was updated and renamed Communication, which allows you to specify which Letter/Email, Texting, and Document Packets privileges to grant to the selected user.

  • The Letters/Reports/Packets privilege group was renamed Letter/Email Templates/Reports/Packets and the Letters/Packets privilege was renamed Letter/Email templates/packets.

  • The Texting/Broadcast privilege group was updated with the new Manage text templates privilege and the Perform text broadcast privilege was renamed Send Bulk Texts/Broadcasts.

  • The Letter Templates page was renamed Letter/Email Templates. Additionally, the page was updated to improve navigation and simplify the message template process.

  • The Text Templates page was added, which allows you to create and manage your text templates.

  • Email templates can now be sent directly from an entity's details page or in bulk actions.

  • Text templates can now be sent directly from an entity's details page, in bulk actions, in a text broadcast, and from the Text Messaging Center.

The message template tool also received several updates in Rent Manager 12. These updates have improved navigation and added or repositioned sections, filters, and fields to simplify the template process.

Enhancements

Rent Manager can now process credit and debit card payments from international billing addresses.

Express Rent Manager 12rmResident Tenant Web Access (TWA)

Rent Manager ePay now supports credit and debit card payments when the billing address is outside the United States. This enhancement extends to Tenant Web Access (TWA), Apply Now, Owner Web Access (OWA), rmResident, and the Short-Term Rental Online Booking Portal, enabling these portals to accept payments with international billing addresses.

Tenants, Prospects, Owners, and Owner Prospects pages were improved to make publishing signable documents a breeze.

Express

To make communicating and sending signable documents in Express more intuitive and user-friendly, the Tenants, Prospects, Owners, and Owner Prospects pages were updated with the option to Publish Signable Documents via the Bulk Actions menu. In addition, this bulk action was added to each stage on the Prospect Leasing Board.
