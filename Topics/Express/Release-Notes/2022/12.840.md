# 12.840 Release Notes

Source: https://rmxhelp.rentmanager.com/Topics/Express/Release-Notes/2022/12.840.htm

The release begins rolling out on May 17, 2022.

 New Features

 You now have the option to customize your Owner Web Access (OWA) portals. Rent Manager Express provides color and theme options that you can select from to make the portal match your business’s branding. Additionally, you now have the option to determine the information that displays on your owners’ OWA dashboards.

 As part of this change, the following system web preferences were added:

 -
 In Owner Web Access Site Header (System Web Preferences) , you can upload your company’s logo and determine where it displays in the site header.

 -
 In Owner Web Access Color Theme (System Web Preferences) , you can change the theme of the toolbar and buttons from the standard Rent Manager blue to a preset or custom color scheme.

 In Owner Web Access Dashboard (System Web Preferences) , you can change the order in which tiles display in OWA or exclude certain tiles from the dashboard.

 Path: arrow_forward Preferences arrow_forward Web | arrow_forward Admin arrow_forward Preferences arrow_forward System Web Preferences

 The Account Groups (Page) feature was added, which allows you to group together two or more tenant accounts for transactional and reporting purposes, while maintaining individual account records for each tenant.

 Additionally, after creating an account group, tenants that are part of the account group have new options available on the Add Payment , View Transactions , and History/Notes pages. These options allow you to add payments for everyone in the account group, and view information for the entire account group rather than just the tenant.

 Path: arrow_forward Admin arrow_forward Setup arrow_forward Rental Information arrow_forward Account Groups

 The Violations feature was added to Rent Manager Express . Violations allow you to document and track when tenants don’t follow the rules and regulations established for your properties. As part of this feature, the following pages were added:

 -
 The Import Violation Codes page, which allows you to import data to new or existing violation codes in Rent Manager Express , greatly reducing the amount of time spent on data entry.
Path: arrow_forward Admin arrow_forward Import arrow_forward Import Violation Codes

 -
 The Violations page, which allows you to add, escalate, or close tenant violations.
Path: arrow_forward Rental Info arrow_forward Violation

 -
 The Violation Details page, which allows you to escalate the violation, add history/note items, write letters, and view attachments.
Path: arrow_forward Rental Info arrow_forward Violations arrow_forward select a violation arrow_forward Violation Details

 -
 The Violations - Communication Needed (Dashboard Tile) , which allows you to track open violations with an escalated stage that still needs to be communicated to the tenant.

 You can now automate the processes of posting Late Fees and Recurring Charges in Rent Manager Express .

 Path: arrow_forward Admin arrow_forward Task Automation arrow_forward Late Fees | Recurring Charges

 The Post Depreciation page was added, which gives you the ability to post depreciation in a batch on a monthly or yearly basis, depending on the asset's schedule.

 Path: arrow_forward Accounting arrow_forward Post Depreciation
