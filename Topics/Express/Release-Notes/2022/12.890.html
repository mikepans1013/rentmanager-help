12.890 Release Notes

The release begins rolling out on October 18, 2022.

New Features

Accounts Receivable (AR) Automation was added to Rent Manager Express, which allows you to automate the process of sending notices via email, text, phone broadcast, and Virtual Post Office (VPO) to a list of tenants at your properties who have open or upcoming charges.

Path: arrow_forward Admin arrow_forward Task Automation arrow_forward Accounts Receivable

The following Homeowners Association (HOA) features are now available in Rent Manager Express:

  • If your property reviews homeowner requests for external changes to their homes (e.g., planting trees), you can now utilize the Architectural Requests page.
    Path: arrow_forward Services arrow_forward Community arrow_forward Architectural Requests

  • Association Committees were added, which allows you to create the various HOA committees to which you can add committee members and board members.
    Path: arrow_forward Admin arrow_forward Setup arrow_forward Association Committees

  • Once you've established your committees, you can manage board and committee members on the property details page in the new Association – Board Members and Committee Members tiles.
    Path: arrow_forward Rental Info arrow_forward Properties arrow_forward select a property with the Property Type set to Association arrow_forward Association – Board Members tile | Committee Members tile

You can now add and view loan information in Rent Manager Express. As a part of these additions, the following pages are now available:

  • The Add Loan Wizard, which allows you to easily add a new owner-financed loan into Rent Manager.
    Path: arrow_forward Receivables arrow_forward Loans arrow_forward Add Loan

  • The Loan Details page, which allows you to view and manage the selected loan.
    Path: arrow_forward Receivables arrow_forward Loans arrow_forward select a loan from the list

The Broadcasting feature was added to Rent Manager Express, which allows you to send an audio or text message to multiple owners, tenants, prospects, or vendors at once.

Path: arrow_forward Correspondence arrow_forward Broadcast arrow_forward Phone Broadcast

Path: arrow_forward Correspondence arrow_forward Broadcast arrow_forward Text Broadcast

The Make Ready Templates page was added, which allows you to define a workflow that can be used to quickly kick off a make ready process for a unit.

Path: arrow_forward Services arrow_forward Make Ready arrow_forward Make Ready Templates

Enhancements

During an Electronic Bank Reconciliation, you now have options for Write Check, Add Journal, or Create Deposit on any Rent Manager transactions that do not match the transactions on your bank statement. When you write a check, create a journal entry, or make a deposit the Rent Manager transaction is automatically matched to the imported transaction.

The first text sent to a recipient from the text messaging center, and any texts sent via text broadcast or automated notification now include an opt-out message. Recipients can opt-out by texting Stop, StopAll, Unsubscribe, Cancel, End, or Quit. Conversely, if the recipient accidentally opted out or changed their mind, they can text Start, Yes, or Unstop to begin receiving texts again. The text commands for both opt-out and opt-in are not case sensitive.
