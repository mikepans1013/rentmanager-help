12.800 Release Notes

The release begins rolling out on January 18, 2022.

New Features

Checklist Templates were added, which are saved lists of to-do items that you can easily add to issues via the Checklist Items tile.

Path: arrow_forward Services arrow_forward Service Manager arrow_forward Checklist Templates

User Roles were added, which are a defined set of user, report, and letter privileges.

Path: arrow_forward Admin arrow_forward Setup arrow_forward User Roles

The Recurring Charge Search page was added, which lets you search for recurring charges that began and/or ended during a specified date range and then filter the results using additional search criteria. The types of recurring charges that you can search for include property, unit type, unit, and tenant.

Path: arrow_forward Admin arrow_forward Find arrow_forward Recurring Charges Search

The Import Jobs feature was added.

Path: arrow_forward Admin arrow_forward Import arrow_forward Import Jobs

The Import Vendors feature was added.

Path: arrow_forward Admin arrow_forward Import arrow_forward Import Vendors

Enhancements

Command Launch was updated to display additional information when you hover over a search result for an entity, such as a tenant, prospect, vendor, and so on.

Additionally, the list on the left of the Personal Preferences page now includes options for Command Launch Results and Command Launch Options, which allow you to manage the types of accounts that display in the search results and the way search results are ordered.
