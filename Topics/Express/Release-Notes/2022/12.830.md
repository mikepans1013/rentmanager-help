# 12.830 Release Notes

Source: https://rmxhelp.rentmanager.com/Topics/Express/Release-Notes/2022/12.830.htm

The release begins rolling out on April 19, 2022.

 Additionally, the Merge Prospects page was added, which provides the ability to copy one prospect and all contacts on that account into another current prospect or current tenant account.

 Path: arrow_forward Admin arrow_forward Merge arrow_forward Merge Prospects

 The Forecast Models feature was added to Rent Manager Express . Forecast models allow you to project future earnings and expenses in scenarios where operating expenses as well as comprehensive rental, vacancy, and renewal options are considered. As part of this feature, the following pages were added:

 -
 The Forecast Models page, which allows you to create, edit, or delete forecast models.

 -
 The Forecast Models Details page, which allows you to view and manage your established forecast models.

 -
 The Add Forecast Models page, which helps you quickly establish parameters to predict future income and expenses.

 Path: arrow_forward Admin arrow_forward Setup arrow_forward Accounting arrow_forward Forecast Models

 You can now view and post loan information in Rent Manager Express . As part of these additions, the following pages are now available:

 -
 A Loans page, which allows you to view and manage owner-financed loans.
Path: arrow_forward Receivables arrow_forward Loans

 -
 A Post Loans page, which allows you to post loans that are nearing their due date.
Path: arrow_forward Receivables arrow_forward Posting arrow_forward Post Loans

 -
 A Post Loan Late Fees page, which allows you to apply loan late fees to tenants who are delinquent on loan-related charges.
Path: arrow_forward Receivables arrow_forward Posting arrow_forward Post Loan Late Fees
