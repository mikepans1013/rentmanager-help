# 12.820 Release Notes

Source: https://rmxhelp.rentmanager.com/Topics/Express/Release-Notes/2022/12.820.htm

The release begins rolling out on March 22, 2022.

 New Features

 Bulk Actions for Write Letters were added to the following pages:

 -
 Tenants

 -
 Prospects

 -
 Owners

 -
 Units

 -
 Properties

 -
 Vendors

 -
 Owner Prospects

 -
 Assets

 For example, on the Tenants page, you can select Write Letters from the Bulk Actions drop-down list and quickly send letters as email attachments to multiple tenants.

 The Utilities page was added, which allows you to manage utility information for tenants and units using Metered Utilities (MU) . It also allows you to edit and create different utilities such as gas, electric, water, and sewer used to bill tenants based on their consumption of that utility.

 Additionally, the Post Utilities page was added, which applies the consumption-based fees for the selected utilities to the associated tenants of the selected properties.

 Path:   arrow_forward Services arrow_forward Metered Utilities

 The Financial Property Migration Wizard was added, which helps you move assets associated with one financial property to another.

 Path: arrow_forward Rental Info arrow_forward Assets arrow_forward click in the action bar arrow_forward Financial Property Migration Wizard

 The Modify Recurring Charges feature was added, which lets you update the amounts of your recurring charges in a batch. This page may be used to make corrections to a batch of recurring charges or to quickly enter rent (or other charge) escalations in Rent Manager Express .

 Path: arrow_forward Receivables arrow_forward Modify arrow_forward Modify Recurring Charges

 The Import Properties feature was added.

 Path: arrow_forward Admin arrow_forward Import arrow_forward Import Properties

 The Asset Workflows feature was added, which allows you to specify a series of stages that an asset may pass through during a process.

 Path: arrow_forward Admin arrow_forward Setup arrow_forward Assets arrow_forward Asset Workflow

 The Prospect Stages page was added, which allows you to create, edit or delete stages that can be manually or automatically assigned to prospects.

 Path: arrow_forward Admin arrow_forward Setup arrow_forward Rental Information arrow_forward Prospect Stages

 System web preferences were added, which allow you to set default values that are appropriate for the web settings of your system.

 As part of this update, the following system web preferences were added:

 -
 In Tenant Web Access General (System Web Preferences) , you can create login messages and set login and/or lockout restrictions for Tenant Web Access (TWA) users, as well as determine how certain aspects of signable documents are handled.
Path: arrow_forward Admin arrow_forward Preferences arrow_forward System Web Preferences arrow_forward Tenant Web Access

 -
 In Tenant Web Access Site Header (System Web Preferences) , you can upload your company’s logo and determine where it displays in the site header.
Path: arrow_forward Admin arrow_forward Preferences arrow_forward System Web Preferences arrow_forward Style arrow_forward Site Header

 -
 In Tenant Web Access Color Theme (System Web Preferences) , you can change the theme of the entire portal from the standard Rent Manager blue to a preset or custom color scheme.
Path: arrow_forward Admin arrow_forward Preferences arrow_forward System Web Preferences arrow_forward Style arrow_forward Color Theme

 -
 In Owner Web Access (System Web Preferences) , you can customize a login message, set login/lockout restrictions, specify the OWA webpage header, and adjust email settings.
Path: arrow_forward Admin arrow_forward Preferences arrow_forward System Web Preferences arrow_forward Owner Web Access arrow_forward General

 Enhancements

 A Scripted Formula field was added to the Property Late Fees and Tenant Late Fees tiles, as well as the Post Late Fees page, which allows you to write a script that calculates the late fee charge amount.
