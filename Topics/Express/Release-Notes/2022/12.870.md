# 12.870 Release Notes

Source: https://rmxhelp.rentmanager.com/Topics/Express/Release-Notes/2022/12.870.htm

The release begins rolling out on August 16, 2022.

 New Features

 A new Zego Pay Lockbox integration is available that allows tenants to submit physical payments to a PO Box managed by Zego . Using a lockbox reduces the amount of time your office spends processing physical payments as well as the risk of incorrect data entry related to those payments.

 When Zego receives a payment, they scan, process, and deposit it into the property's ePay bank account. Zego also uses the information on the envelope, check, and any other information provided to locate the tenant's account and record the payment on the tenant’s transaction ledger in Rent Manager .

 As part of the Zego Pay Lockbox integration, the Other Information tile of the property now includes an option to Enable Lockbox , if the feature is enabled in Rent Manager 12 system preferences. To override system preferences and disable lockbox for the property, uncheck the box.

 Path: arrow_forward Rental Info arrow_forward Properties arrow_forward Other Information tile

 The Tasks page was added, which allows you to view scheduled tasks, view the details of tasks, add new tasks, and delete canceled tasks.

 Additionally, you can now save task templates to make it easier to create similar tasks in the future via the Memorized Tasks page.

 The Appointments page was added to Rent Manager Express , which allows you to view scheduled appointments, view the details of appointments, add new appointments, and delete canceled appointments.

 You can now add violations from the Violations page or from the action bar on a tenant’s details page.

 You can now select contact types from the Compose Email page by clicking and the Batch Email page via the Contact Types field. This allows you to send emails to specific contact categories you have created for the people/contacts associated with your primary tenant (roommate, parent, co-signer, emergency contact, and so on).
