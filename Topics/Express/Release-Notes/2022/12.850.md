# 12.850 Release Notes

Source: https://rmxhelp.rentmanager.com/Topics/Express/Release-Notes/2022/12.850.htm

The release begins rolling out on June 21, 2022.

 New Features

 The Lease Renewals Offers workflow is now available in Rent Manager Express .

 As part of this feature set, the following pages were added:

 -
 The Renewal Offers page, which displays the status of the lease renewal offers that you have made to tenants. On this page, you can manually accept or decline renewal offers on the tenant’s behalf. In addition, you may choose to void or convert the tenant’s lease into a month-to-month agreement.
Path: arrow_forward Rental Info arrow_forward Renewal Offers

 -
 The Renewal Offer Details page, which allows you to view the details of the renewal offer for each tenant.
Path: arrow_forward Rental Info arrow_forward Renewal Offers arrow_forward select a renewal offer arrow_forward Renewal Offer Details

 -
 The Generate Renewal Offers page, which allows you to view a list of tenants with upcoming expiring leases, renew recurring rent charges, create renewal offers, and notify the tenant of the renewal offer.
Path: arrow_forward Rental Info arrow_forward Generate Renewal Offers

 The Online Template Library (OTL) feature was added to Rent Manager Express .

 Path: arrow_forward Admin arrow_forward Online Template Library

 Enhancements

 History categories, which can help you organize history/note items associated with various accounts and records, can now be assigned a Type . Assigning history categories to a specific Type allows you to further control which entities (tenants/prospects, properties, assets, issues, and so on) history categories can be used for.

 To maintain current functionality, <All Types> is selected for all history categories by default. This means that all history categories will continue to be available for every entity (tenant/prospects, properties, and so on) in Rent Manager .

 You can assign history categories to a Type on the History Categories page. Additionally, you can now make categories Inactive when they are no longer in use.

 The Company Code (previously referred to as DBID , Corp ID , Company ID , Enterprise ID , and so on) is now more visible across Rent Manager 12 , Rent Manager Express , rmAppSuite Pro , and rmResident . Additionally, all previous names were removed throughout Rent Manager Express and replaced with Company Code .

 These improvements allow you to quickly find your Company Code , making it easier for users to understand what information they need to include when they’re logging into Rent Manager Express , rmAppSuite Pro , and so on.
