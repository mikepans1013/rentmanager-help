# 12.900 Release Notes

Source: https://rmxhelp.rentmanager.com/Topics/Express/Release-Notes/2022/12.900.htm

The release begins rolling out on November 15, 2022.

 New Features

 Polls, which can be used for voting or gathering feedback from tenants, were added to Rent Manager Express .

 To support this feature, the following pages were added:

 -
 The Polls Register , which allows you to create a new poll or view existing polls.
Path: arrow_forward Services arrow_forward Polls arrow_forward Polls Register

 -
 The Add Poll page, which allows you to add a new poll to collect information from your tenants.
Path: arrow_forward Services arrow_forward Polls arrow_forward Polls Register arrow_forward Add Poll

 -
 The Poll Details page, which allows you to view and manage polls that have been published to Tenant Web Access (TWA) .
Path: arrow_forward Services arrow_forward Polls arrow_forward Polls Register arrow_forward select a poll

 -
 The Poll Results page, which allows you to view real-time results as residents respond to your poll.
Path: arrow_forward Services arrow_forward Polls arrow_forward Polls Register arrow_forward select and click Results

 The Manage Text Numbers page was added, which allows you to control which phone numbers are used for broadcasts, automated notifications, and AR automation schedules that send text alerts, as well as for individual text messages sent to the tenants at each of your properties.

 Path: arrow_forward Admin arrow_forward Setup arrow_forward Manage Text Numbers

 The Property Files page was added, which allows you to upload files related to a property and determine if the file should be available to tenants in the Documents tile on their TWA dashboard.

 Path: arrow_forward Rental Info arrow_forward Properties arrow_forward select a property arrow_forward arrow_forward Property Files

 The Non Recurring CRE page was added, which allows you to distribute one-time expenses related to owning and maintaining a facility, including common areas such as parking lots and lobby renovations.

 Path: arrow_forward Receivables arrow_forward Commercial arrow_forward Non Recurring CRE

 The Address Book page was added, which allows you to record the contact information for people or businesses you email.

 Path: arrow_forward Correspondence arrow_forward Email arrow_forward Compose Email arrow_forward click the To... field

 The VPO Register was added, which allows you to track submissions sent to the Virtual Post Office .

 Path: arrow_forward Correspondence arrow_forward VPO Register arrow_forward VPO Register

 Enhancements

 During an electronic credit card reconciliation, you now have options for Add Charge , Add Credit , or Write Check on any Rent Manager transactions that do not match the transactions on your credit card statement. When you add a charge, add a credit, or write a check, the Rent Manager transaction is automatically matched to the imported transaction.
