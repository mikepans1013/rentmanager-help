# 12.810 Release Notes

Source: https://rmxhelp.rentmanager.com/Topics/Express/Release-Notes/2022/12.810.htm

The release begins rolling out on February 15, 2022.

 New Features

 The Short Term Rentals (STR) feature is now available in Rent Manager Express .

 To access the STR feature set, you must have at least one property with a Property Type of either Short Term Rental or RV/Campground . If you are already tracking temporary rentals at a traditional property, you may assign either of these new property types to convert the existing lease information to reservation information.

 As part of the STR feature set, the following additions were also made:

 -
 A Short Term Rental Reservations page was added.
Path: arrow_forward Rental Info arrow_forward Short Term Rentals arrow_forward Reservations

 -
 A Check-ins page was added. From this page you may open the Check-in Wizard to complete the guest check-in process.
Path: arrow_forward Rental Info arrow_forward Short Term Rentals arrow_forward Check-ins

 -
 To manage how guests are added, Short Term Rental (STR) Reservations (System Preferences) are now available. Depending on your preferences, an Add Reservation icon is added to the action bar on the Tenants and/or Prospects page.
Path: arrow_forward Admin arrow_forward Preferences arrow_forward System Preferences arrow_forward STR Reservations

 -
 For STR guests, the Tenant Details page and Prospect Details page now include a Reservations tile.

 -
 For units at properties with a Property Type of RV/Campground , the Unit Details page has a RV/Campground Information tile.

 -
 A Short Term Rentals report group was added which includes all reports related to short-term rentals.
Path: arrow_forward Reports arrow_forward Short Term Rentals

 We've added more control over bill approvals by adding two additional tiers to Bill Approval Maximums: Tier 2 and Tier 3 . To support these additional tiers, the Approve bills - tier 1 privilege was replaced with the following new privileges:

 -
 Approve bills less than or equal to tier 1

 -
 Approve bills less than or equal to tier 2

 -
 Approve bills less than or equal to tier 3

 Path: arrow_forward Admin arrow_forward Preferences arrow_forward System Preferences arrow_forward Checks/Bills arrow_forward General

 Path: arrow_forward Admin arrow_forward Setup arrow_forward Users arrow_forward Privileges tab arrow_forward Payables Privilege Group

 The Batch Email feature was added, which allows you to send generated reports as email attachments to multiple recipients.

 The Import Assets feature was added.

 Path: arrow_forward Admin arrow_forward Import arrow_forward Import Assets

 The Asset Title Statuses page was added, which allows you to view and manage the asset title statuses.

 Additionally, an Assets tile was added to the Property and Unit Details pages.

 Path: arrow_forward Admin arrow_forward Setup arrow_forward Assets arrow_forward Asset Title Statuses

 Path: arrow_forward Rental Info arrow_forward Properties | Units arrow_forward select a property or unit arrow_forward Assets tile

 The following dashboard tiles were added so that you can easily see information summarized by property:

 -
 Delinquency By Property (Dashboard Tile)

 -
 Expiring Leases by Property (Dashboard Tile)

 -
 Move In/Move Out By Property (Dashboard Tile)

 -
 Vacancy by Property (Dashboard Tile)

 Enhancements

 Task Automation now includes an option for Automate Management Fees , which allows you to add new schedules and edit or delete existing schedules. Additionally, the list of schedules may be printed.

 Path: arrow_forward Admin arrow_forward Task Automation arrow_forward Automate Management Fees

 You may now manage eChecks and Task Automation system preferences in Rent Manager Express .

 Path: arrow_forward Admin arrow_forward Preferences arrow_forward System Preferences
