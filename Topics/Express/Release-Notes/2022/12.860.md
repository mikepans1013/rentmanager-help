# 12.860 Release Notes

Source: https://rmxhelp.rentmanager.com/Topics/Express/Release-Notes/2022/12.860.htm

The release begins rolling out on July 19, 2022.

 New Features

 The Inspections feature is now available in Rent Manager Express .

 As part of this feature set, the following pages were added:

 -
 The Inspections page, which allows you to add and view inspections, print inspection reports, and email tenants and owners inspection reports.
Path: arrow_forward Services arrow_forward Inspections arrow_forward Inspections

 -
 The Inspections Details page, which allows you to edit the details of an inspection.
Path: arrow_forward Services arrow_forward Inspections arrow_forward Inspections arrow_forward select an inspection arrow_forward Inspection Details

 -
 The Inspection Templates page, which allows you to define the areas and items of a unit that need to be examined.
Path: arrow_forward Services arrow_forward Inspections arrow_forward Inspection Templates

 The CAM (Common Area Maintenance) Reconciliation page was added, which allows you to determine if your tenants were charged too much or too little to cover the actual CRE (commercial recoverable expenses) for the respective properties.

 Path: arrow_forward Receivables arrow_forward Commercial arrow_forward CAM Reconciliation

 You can now manage your unit licenses in Rent Manager Express .

 Path: arrow_forward Admin arrow_forward Setup arrow_forward Licensing

 Enhancements

 NEW RECOMMENDATION FOR PREPAYMENTS IN OWNER DISTRIBUTIONS

 There is a new Prepaid receivables option available in Owner Check Setup templates (Path: arrow_forward Rental Info arrow_forward Owners arrow_forward Owner Check Setups) and on the Property Owner Check Setup page (Path: arrow_forward Rental Info arrow_forward Properties arrow_forward Owner Check Setup).

 If you are currently using the Accounts to Exclude from Check Posting section to exclude prepayments from your owner’s check, it is strongly recommended that you check the Prepaid receivables option instead of continuing to exclude the Cash prepay liability account established in the General Ledger System Account section of system preferences.

 Using this new option ensures that only deposited prepayments are withheld from the owner’s check. Furthermore, Rent Manager will know that if a prepayment is undeposited then it has already been excluded from the owner’s check calculation and therefore does not require additional treatment.

 If the new Prepaid receivables option is checked, withheld prepayment amounts are shown in the following reports:

 -
 The Distribution Breakdown report.
Path: arrow_forward Reports arrow_forward Owners arrow_forward Distribution Breakdown

 -
 The Owner Activity report, in the Distribution Breakdown section
Path: arrow_forward Reports arrow_forward Owners arrow_forward Owner Activity

 -
 The Basic Owner Statement , in the Cash Requirements section.
Path: arrow_forward Reports arrow_forward Owners arrow_forward Basic Owner Statement

 Additionally, the System Owner Statement was updated to include a Distribution Breakdown section. To add this section to the report, ensure the Exclusion Option for Distribution Breakdown is unchecked in the report options. If the Prepaid receivables option is checked, withheld prepayments now display in this section of the report.
