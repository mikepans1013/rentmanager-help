# 12.930 Release Notes

Source: https://rmxhelp.rentmanager.com/Topics/Express/Release-Notes/2023/12.930.htm

The release begins rolling out on February 14, 2023.

 New Features

 To make it possible to record multiple payments from multiple tenants at once, the Batch Payments page was added. This new page greatly reduces the time it takes you to record receiving and depositing payments from many tenants.

 Path: arrow_forward Receivables arrow_forward Batch Payments

 Subsidies (HUD, Section 8, FEMA, and so on), which are a form of financial assistance offered to qualifying tenants, were added to Rent Manager Express .

 To support this feature, the following pages were added:

 -
 The Subsidies page, which allows you to create a new subsidy or view existing subsidies.
Path: arrow_forward Admin arrow_forward Setup arrow_forward Rental Information arrow_forward Subsidies

 -
 The Subsidies Details page, which allows you to view and manage which charge type should be paid by the subsidy and which tenants qualify to receive money from the subsidy.
Path: arrow_forward Admin arrow_forward Setup arrow_forward Rental Information arrow_forward Subsidies arrow_forward select a subsidy

 The Unit Migration Wizard was added, which allows you to move one or more units from one property to another. This is helpful if you decide to restructure the way your properties are organized or need to split one property into multiple financial entities.

 Path: arrow_forward Admin arrow_forward Unit Migration Wizard

 To keep track of upcoming appointments and tasks, an integrated Calendar page was added to Rent Manager Express . This page displays important events like upcoming tenant move-ins and move-outs, lease expirations, contract dates, and so on.

 Path: arrow_forward Services arrow_forward Calendar

 To review and manage available integrations for your database that can help with various aspects of property management, the Integrations feature was added to Rent Manager Express .

 To support this feature, the following pages were added:

 -
 The Available Integrations page, which allows you to view information about available API enhancements, contact the sales departments for these integrations, and request activation of an integration directly from within Rent Manager .
Path: arrow_forward Admin arrow_forward Integrations arrow_forward Available Integrations

 -
 The My Integrations page, which allows you to review information about activated integrations, contact sales and/or support for an active integration, modify the integration's settings, cancel an integration request, or deactivate an integration directly from Rent Manager .
Path: arrow_forward Admin arrow_forward Integrations arrow_forward My Integrations

 The Import Owners feature was added, which allows you to import your owner information into your Rent Manager database.

 Path: arrow_forward Admin arrow_forward Import arrow_forward Import Owners

 Enhancements

 To support the new Video Inspections feature, rmAppSuite Inspection (System Preferences) was updated with a Video Inspections field, which allows you to enable the new feature in rmAppSuite Pro . You can then capture and save videos directly in rmAppSuite Pro (when licensed). Once the inspection is submitted the videos will be available in Rent Manager Express . Alternatively, you can choose to manually add URLs to Inspection Areas if your company hosts inspection videos on another site.

 Path: arrow_forward Admin arrow_forward Preferences arrow_forward System Preferences arrow_forward rmInspection

 The Inspection Details page was updated in the following ways:

 -
 If the Video Inspections system preference is set to Manual or rmAppSuite Pro and there is no inspection video present, an Add Video Link option is available in Areas from the menu . Clicking this option allows you to enter the inspection video URL in the Add Video Link pop-up.

 -
 If the Video Inspections system preference is set to Manual or rmAppSuite Pro and there is an inspection video present, a play button displays to the right of the area. Clicking this button plays the video in a pop-up. Alternatively, if you wish to delete the link, click the menu and select Delete Video Link .

 A Manage Email Signature section was added to Personal Preferences: Email Settings , which allows you to create custom messages that are automatically posted to the bottom of emails generated in Rent Manager .

 Path: arrow_forward Preferences arrow_forward Personal arrow_forward Email Settings

 System-type User Defined Fields (UDFs) are now available in the following areas of Rent Manager Express :

 -
 The User Defined Fields page, where you can add, edit, or delete system-type UDFs.

 -
 The Insertable Fields list of Letter Templates and Report Writer .

 Additionally, the System UDF Values page was added, which allows you to view and set or edit the Value of system-type UDFs.

 Path: arrow_forward Admin arrow_forward Setup arrow_forward System UDF Values

 To organize your templates and make them easier to locate, you can now create and manage letter template folders from the Letter Templates page.

 A document packet can now be generated for a Tenant, Prospect, Owner, and Owner Prospect from either the row action Create Document Packet on the corresponding page or from selecting a document packet from the corresponding action bar action on the Detail page.
