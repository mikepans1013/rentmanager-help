12.990 Release Notes

The release begins rolling out on August 15, 2023.

New Features

We are excited to announce the release of Bank Sync, designed to make bank and credit card reconciliations a breeze! This licensed feature uses a built-in integration with Plaid to safely and securely connect Rent Manager to your bank and credit card institutions. Bank sync imports real-world transactions into your electronic reconciliation to simplify the process. Are you missing a real-world transaction in Rent Manager? No problem. You can click on an imported entry to create the missing transaction in your database. Bank Sync means you can stop exporting CSV files from your bank or credit card institutions and you don’t have to configure system preferences to read those files. If you’re reconciling multiple bank or credit card accounts each month, Bank Sync will be a true life-saver! For more information, refer to Set Up Bank Sync.

Two new tenant statement options were added, which feature a more modern, streamlined design and a bottom remittance. The Statement (Option 2) is similar to the existing 8.5 x 11 statement, while the Statement (Option 2) – Lockbox was created specifically for those that utilize our Zego Lockbox feature. This statement includes the tenant’s QR code which can be scanned by Zego to identify which company code, location, and tenant account the payment should be applied.

Path: arrow_forward Reports arrow_forward Tenant Statements arrow_forward Statement (Option 2)

Path: arrow_forward Reports arrow_forward Tenant Statements arrow_forward Statement (Option 2) - Lockbox

To make it easier to add and manage your community calendar, the Community Calendar Event Types page was added. From this page, you can create event types (i.e., categories) for your community-wide events, such as meetings, social events, trash pickup day, and so on. Additionally, you can assign a color to an event type, which displays on the Community Calendar page in Tenant Web Access (TWA) and the Events page in rmResident.

For more information, refer to the Community Calendar and Community Calendar Event Types help file topics.

Path: arrow_forward Admin arrow_forward Setup arrow_forward Community Calendar Event Types

The Service Tech Map feature was added, which allows you to see your rmService users as they check in and out of service issues.

Path: arrow_forward Service arrow_forward Service Tech Map

Pet types are now available in Rent Manager Express, which are categories classifying the different species of animals that are allowed to be kept by tenants as pets.

To support this update, the following changes were made:

  • A Pets tile was added to the Tenant details page, which displays information on the tenant’s pet(s).

  • The View Pets pop-up was added, which allows you to add, modify, and delete a pet record on the tenant’s account.

If you use Apply Now and the Zego ePay integration, the settings entered in the Apply Now - ePay system web preferences can now be overridden as needed by property on the new Property Application Settings pop-up.

Enhancements

User Defined Fields (UDFs) have been updated with a Field Type for Hyperlink, which allows you to create UDFs for embedding linked content in Rent Manager. You can easily click the hyperlink to view it in your browser. These hyperlink UDFs are ideal for effortlessly accessing training or other reference materials.

Path: arrow_forward Admin arrow_forward Setup arrow_forward User Defined Fields

Inventory items were updated so the Inventory Transactions tab Value column takes the item's cost into consideration when calculating values. Additionally, the Type column was updated to display Automatic Increase and Automatic Decrease when an invoice is created with a quantity exceeding the quantity available for the associated property and there are remaining items with <No Property Assignment>.

Path: arrow_forward Accounting arrow_forward Setup arrow_forward Inventory Items arrow_forward select an item from the list arrow_forward click on the Inventory Transactions tile

The Amenity Reservations report was added, which lists amenity reservations scheduled within a specified date range. The report displays the name of the amenity, its status, the date and time of the reservation, and the tenant information associated with the reservation.
