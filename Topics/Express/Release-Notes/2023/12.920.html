12.920 Release Notes

The release begins rolling out on January 17, 2023.

New Features

To make it easier to manage contacts for your vendors, a Vendor Contacts page was added. From this new page, you can create contacts associated with your vendors, edit their information, and delete contacts.

Path: arrow_forward Payables arrow_forward Vendors arrow_forward select a vendor arrow_forward click on the Contacts tile

Google Drive functionality is now configured exclusively in Rent Manager Express system and personal preferences, allowing you to use the service throughout Rent Manager for importing or exporting files to or from Rent Manager. You can also determine whether selected users can access a system-wide, shared Google account for Drive, if they should use a personal Google account, or if they have access to both.

Path: arrow_forward Preferences arrow_forward System arrow_forward Google Drive

Path: arrow_forward Preferences arrow_forward Personal arrow_forward Google Drive Options

The Import Inventory Items feature was added, which allows you to import your inventory details into your Rent Manager database.

Path: arrow_forward Admin arrow_forward Import arrow_forward Import Inventory Items
