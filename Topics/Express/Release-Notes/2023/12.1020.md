# 12.1020 Release Notes

Source: https://rmxhelp.rentmanager.com/Topics/Express/Release-Notes/2023/12.1020.htm

The release begins rolling out on November 14, 2023.

 New Features

 You can now market your multifamily units to Apartments.com! To syndicate to Apartments.com, check the Apartments.com Network option in the Provider Settings section of the Online Listings General system preferences.

 ILS providers may require a paid account before your listings can be posted.

 Path:   arrow_forward   Administration arrow_forward System Preferences arrow_forward Online Listings arrow_forward General

 Express users now can run Financial Report Writer (FRW) reports! FRW enables you to generate customized reports that filter, group, organize, and summarize specific general ledger (GL) financial data.

 Path: arrow_forward Report Writer arrow_forward select a report from the Financial section

 The Write Letter Batch tool was also added in this release, allowing you to generate account-specific letters for any number of recipients. Once your letters are created, you can email them to recipients via Rent Manager or print them to mail or hand deliver.

 Path: arrow_forward Communication arrow_forward Letters arrow_forward Write Letter Batch

 The Redacted Web Application report was added to the Prospect Application detail page, which displays who ordered the applicant's credit to be pulled along with the applicant's acknowledgment of the consent text. The name of the property management company displays in the upper right of the report, while the applicant's social security number and date of birth are redacted. This allows the property management company to be clearly documented while protecting the personally identifiable information (PII) of the applicant.

 Path: arrow_forward Rental Info arrow_forward Leasing arrow_forward Applications arrow_forward select an application from the list arrow_forward click the drop-down arrow on the Print button arrow_forward select Redacted Web Application

 With the addition of the Import Recurring Charges tool to Express , you now can import recurring charges for existing properties, unit types, units, or tenant records into your database, greatly reducing the amount of time spent on data entry.

 Path: arrow_forward Administration arrow_forward Import arrow_forward Import Recurring Charges

 Enhancements

 You can now filter the Tenants list by Subsidy using the basic or advanced filter.

 Path: arrow_forward Rental Info arrow_forward General arrow_forward Tenants arrow_forward

 To hold tenants financially responsible for charges when they break their lease, an update was made to the General Options system preferences that gives you the option to  Prompt to charge unposted recurring charges upon broken lease . When enabled, a pop-up will ask if you want to review and post charges for the duration of the lease any time you save a  Move Out  date that is prior to the  Lease End  date. Additionally, an Automated Notification for  New move-in to a unit with a broken lease was included in this release, which can notify you of this scenario in case charges need to be adjusted on the tenant who broke the lease.

 A unique system-generated vendor account number is now printed on Vendor 1099s and included in the 1099 Export file for vendors. This unique number is required by the IRS if submitting more than one information return of the same type for the same payee (vendor). The account number contains your company code, location ID, and vendor ID. For example, if the company code is cincyprop , with a location ID of 3 , and a vendor ID of 1234 , the 1099 Account Number that displays on the forms is CINCYPROP-3-1234 .

 The IRS updated several annual tax documents for the 2023 tax year, which resulted in changes to several of their forms. To accommodate those adjustments and simplify your tax season, the following updates were made in Express :

 -
 The Vendor 1096 , Vendor 1099 , and Vendor 1099 Copy B reports now include a icon in the Consolidate Properties report option, which, when selected, populates the available fields with your management company information (billing address, default phone number, and tax ID).**
Path: arrow_forward Payables arrow_forward Vendor 1096 | Vendor 1099 | Vendor 1099 Copy B

 -
 The Vendor 1096 , Owner 1096 , and Loan 1096 reports were updated to reflect changes to the 1096 tax form, which includes adding an additional row to Field 6 , where the type of form being filed is indicated.**

 -
 The Vendor 1099 Breakdown report was updated with Vendor Total and Vendor Count fields, as well as a total breakdown section, allowing you to easily track and confirm your 1099 totals before generating 1099s. This is helpful to confirm totals, whether printing or exporting.
Path: arrow_forward Payables arrow_forward Vendor 1099 arrow_forward Vendor 1099 Breakdown

 -
 The Vendor 1099 Adjustment Tool 's Vendor drop-down list was updated with 1099 Vendors and Non-1099 Vendors checkboxes, which allow you to determine the vendors whose checks should populate in the adjustment tool. Additionally, if you select the 1099 checkbox on a line item associated with a non-1099 vendor, an Update Vendor 1099 Status pop-up displays, which allows you to update the status of the vendor account to be a 1099 Vendor .
Path: arrow_forward Administration arrow_forward Accounting arrow_forward Vendor 1099 Adjustment Tool

 **For the 2023 tax year, the IRS requires electronic filing for 10 or more information returns (like 1099s, 1098s, etc.) through the IRS FIRE system.
