12.950 Release Notes

The release begins rolling out on April 18, 2023.

New Features

With Architectural Requests, you can now customize the forms association members fill out. You can create forms for various types of requests, allowing you to specify what fields and attachments are necessary for that type of request (i.e., you can have one form specific to painting a home and another form for building a fence). The forms you create are available in Tenant Web Access (TWA) for homeowners at the associated properties.

To use this new feature, you need the new Associations Privilege Group Manage Architectural Request Forms privilege.

For more information, refer to the RMU Architectural Requests course and the Architectural Request Forms (Page) documentation.

Path: arrow_forward Services arrow_forward Community arrow_forward Architectural Request Forms

The Email Center page was added, which allows you to manage emails sent from Rent Manager as well as subsequent replies. To use this tool, you must set up your email in System Preferences. For more information, refer to the Email Settings (System Preferences) documentation.

Path: arrow_forward Correspondence arrow_forward Email arrow_forward Email Center

The Unit Picker page was added, which can be used to apply a prospect’s preferences to the units at a selected property and see the units with matching results. You can then specify if the prospect is interested in the unit and/or wants to be placed on its Wait List.

Path: arrow_forward Rental Info arrow_forward Prospects arrow_forward select a prospect arrow_forward click View More on the action bar arrow_forward select Unit Picker

The Post Security Deposit Interest page was added, which allows you to post security deposit (SD) interest to reflect real-world accruals on these held deposits.

Path: arrow_forward Receivables arrow_forward Posting arrow_forward Post Security Deposit Interest

Additionally, the Interest Options For Security Deposits tile was added to the Property Details page, which allows you to calculate interest differently for certain properties and override the system-wide settings established at Security Deposit Interest Options (System Preferences).

Path: arrow_forward Rental Info arrow_forward Properties arrow_forward select a property arrow_forward click on Interest Options For Security Deposits tile

Application Templates were added to Rent Manager Express. Apply Now uses application templates to list the information that prospects at your properties need to submit when filling out an application.

To support this feature the following pages were added:

  • The Application Templates page, which allows you to view existing templates and create or import new templates.
    Path: arrow_forward Rental Info arrow_forward Application Templates

  • The Application Templates details page, which allows you to view and/or modify an existing template.
    Path: arrow_forward Rental Info arrow_forward Application Templates arrow_forward select an application template

Enhancements

The Amenity Reservations feature was updated to allow tenants to be automatically charged fees when reserving an amenity. There are also new options to Automatically approve requests submitted via TWA and Require payment when request is submitted via TWA.

For more information, refer to the RMU Reservable Amenities course and the Add a Reservable Amenity documentation.

The Move Payment tool was updated in the following ways:

  • A Move payment between customers privilege was added to the Receivables Privilege Group.

  • The Move Payment pop-up Tenant field has been renamed Tenant/Prospect and allows you to move a payment from one tenant or prospect to another tenant or prospect at the same property.

For more information, refer to the Tenant Transactions (Pop-Up) and Prospect Transactions (Pop-Up) documentation.

The Minnesota CRP (Report) was updated with an Include Other Rentable Items report option, which allows you to include other rentable items such as storage units and garages in your report results.

Path: arrow_forward Reports arrow_forward Custom Reports arrow_forward Minnesota CRP
