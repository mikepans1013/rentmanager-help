# 12.980 Release Notes

Source: https://rmxhelp.rentmanager.com/Topics/Express/Release-Notes/2023/12.980.htm

The release begins rolling out on July 18, 2023.

 New Features

 The Month To Month Adjustment Tool was added, which allows you to apply the month-to-month (MTM) lease term to leases that currently exist in Rent Manager and overwrites any current lease terms. Leases eligible for the use of this tool have a Lease Start date but no Lease End or Move Out dates.

 Additionally, this tool allows you to create a new MTM lease for leases that have Lease Start and Lease End dates that have passed but no Move Out or Expected Move Out dates.

 The Manage Locations pop-up was added, which allows you to add, edit, delete, and switch your database locations.

 Path: arrow_forward Admin arrow_forward Locations arrow_forward Manage Locations

 The Signable Templates page was added, which allows you to view both PDF documents that are imported into Rent Manager and letter templates that include signable fields. From this page, these templates can be imported, edited, deleted, or published to recipients.

 Path: arrow_forward Correspondence arrow_forward Letters arrow_forward Signable Templates

 Enhancements

 In our continuing efforts to make Rent Manager Express more intuitive and user-friendly, several exciting changes were made to add wizards and the Bill , Tenant , and Prospect details pages. These updates have made information easier to read, improved navigation, and added or repositioned buttons and icons to simplify performing popular actions.

 The matching logic for Electronic Bank Reconciliations and Electronic Credit Card Reconciliations was improved so that transactions are evaluated on more data points to increase matches between your bank statement and bank register.

 Path: arrow_forward Accounting arrow_forward Reconciliation arrow_forward Electronic Bank Reconciliation

 Path: arrow_forward Accounting arrow_forward Reconciliation arrow_forward Electronic Credit Card Reconciliation

 The Tenant Web Access (TWA) Welcome dashboard tile was updated with a Contact Us section, which displays your management company’s contact information. The tile was also updated with a button for CashPay Information . Additionally, a CashPay Information page was added to TWA, which allows your tenants to view their CashPay ID along with a Find a CashPay location button and processing instructions for the CashPay agent.
