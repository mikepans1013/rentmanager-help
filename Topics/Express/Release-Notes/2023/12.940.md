# 12.940 Release Notes

Source: https://rmxhelp.rentmanager.com/Topics/Express/Release-Notes/2023/12.940.htm

The release begins rolling out on March 21, 2023.

 New Features

 To provide an additional layer of security when logging in to Rent Manager , Multifactor Authentication is now available. With this new feature enabled, a user must provide a secondary level of authentication, provided by an authenticator app of your choice, after entering their Rent Manager username and password information.

 To support this update, the following changes were made:

 -
 In the System Preferences ( arrow_forward Admin arrow_forward Preferences arrow_forward System Preferences arrow_forward General Options arrow_forward General), the Require Multifactor Authentication (MFA) to log in setting was added. Once enabled, users are required to use an authenticator app to log in to Rent Manager . This change is effective immediately, so it is suggested you speak to your team about this change before enabling the setting.

 -
 A Reset MFA Login action item was added to the User Details page.

 -
 A View RM User MFA Code option was added to the Setup menu.

 For more information, refer to the Multifactor Authentication (MFA) documentation.

 The Import Owner Prospects tool was added, which allows you to import your owner prospect information into your Rent Manager database.

 Path: arrow_forward Admin arrow_forward Import arrow_forward Import Owner Prospects

 The Import Owner Prospects Properties tool was added, which allows you to import the portfolio of properties owned by your owner prospects into your Rent Manager database.

 Path: arrow_forward Admin arrow_forward Import arrow_forward Import Owner Prospects Properties

 The Manage Import Templates tool was added, which allows you to save default values and column mappings of your external .csv file for each import type, saving time on future imports of the same type and making the process smoother overall.

 Path: arrow_forward Admin arrow_forward Import arrow_forward Manage Import Templates

 The Unit to Asset Conversion wizard was added, which allows you to convert units into assets. If you have previously created units to represent assets (such as manufactured homes), this tool allows you to convert those units into assets within Rent Manager .

 Path: arrow_forward Admin arrow_forward Setup arrow_forward Assets arrow_forward Unit to Asset Conversion Wizard

 The Blue Moon integration is now available in Rent Manager Express . Blue Moon provides industry-standard leasing documents that are compliant with your state and/or industry association (e.g., NAA, TAA, GAA, AANC). In Rent Manager , you can export your tenant and prospect information directly into Blue Moon leasing documents, pull in the default lease information from Blue Moon , and send the leases electronically for the tenants or prospects to sign.
