12.970 Release Notes

The release begins rolling out on June 21, 2023.

New Features

An Amenity Reservations page was added, which allows you to track reservation requests for the amenities that your tenants can rent. From this page, you can add, delete, or change the status of any request.

Path: arrow_forward Services arrow_forward Community arrow_forward Amenity Reservations

The Guest Card Templates tool was added, which allows you to add, edit, copy, or delete the prospect and owner prospect contact forms on your website.

Path: arrow_forward Admin arrow_forward Setup arrow_forward Rental Information arrow_forward Guest Card Templates

Additionally, the Prospect Guest Card Submitted (Automated Notifications) and Owner Prospect Guest Card Submitted (Automated Notifications) were added, which allows you to send a notification to a customizable list of people every time a prospect and owner prospect guest card is submitted.

Path: arrow_forward Admin arrow_forward Automated Notifications arrow_forward select Prospect Guest Card Submitted

Path: arrow_forward Admin arrow_forward Automated Notifications arrow_forward select Owner Prospect Guest Card Submitted

The Import Meter Information tool was added, which allows you to import new or update existing meter information not related to metered utilities consumption values (such as Comment, Income Type, Class Code, Route, Rate Zone, Other, and so on) in your Rent Manager database.

Path: arrow_forward Admin arrow_forward Import arrow_forward Import Meter Information

The Check Scanning tool was added, which allows you to scan checks in a batch.

To support this update, the following changes were made:

  • The Check Scanning (Personal Preferences) were added, which allows you to set the Epson single-feed or multi-feed check scanner as your default check scanner in Rent Manager. The options that display vary depending on whether you are using Rent Manager Online or Rent Manager Standalone.
    Path: arrow_forward Admin arrow_forward Preferences arrow_forward Personal Preferences arrow_forward Check Scanning

  • The Scan Checks page was added, which allows you to scan and record multiple checks or money orders in a batch and apply them to tenant or prospect accounts from one page.
    Path: arrow_forward Receivables arrow_forward Posting arrow_forward Scan Checks

Enhancements

In our continuing efforts to make Rent Manager Express more intuitive and user-friendly, exciting changes were made to several register pages. For example, the Issues page was updated, making service issue information easier to read on the screen and vastly improving navigation. Buttons were added or repositioned to simplify performing popular actions, and Quick Filters were added to allow you to limit the issues that display on the page. Additionally, changes were made to how data displays, improving organization, spacing, and legibility.

Text Messaging in Rent Manager was updated, allowing you to exceed the 160 SMS (Short Message Service) character count. Text messages that exceed the character count are converted into multiple segments (i.e., messages) of 160 characters up to a maximum of 1600 characters. To support these improvements, the message fields throughout Rent Manager were updated to reflect the number of messages an individual text message or a text broadcast will use.

Additionally, Property columns were added to the Text Broadcast and Text Broadcast Batches pages, and the interface for selecting entity contacts was updated to improve usability.

Home-type assets linked to units are now available in the Unit drop-down list on the following pages and pop-ups:

  • Job Details

  • Add New Job

  • Prepay Allocations

  • Transaction Details

  • Add Security Deposit
