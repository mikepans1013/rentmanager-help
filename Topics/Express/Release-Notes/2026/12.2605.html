New Features

Take control of your utility billing with the ratio utility billing system (RUBS).

Express Rent Manager 12

The Metered Utilities (MU) tool was enhanced, making dividing charges among tenants (based on factors like occupancy, square footage, number of bedrooms/bathrooms, etc.) a breeze for properties that do not have submeters available. These updates allow you to quickly configure how tenants are charged for utilities, save and reuse those configurations, and automate posting RUBS charges. Additionally, a detailed history of RUBS postings are now easily accessible in Rent Manager's reporting, providing transparency and auditability for all your utility allocations.

As part of this update, the following changes were made:

  • The Utilities privilege group was updated with Post RUBS charges, Rollback RUBS charge postings, and Manage RUBS templates privileges, which allows you to access RUBS functionality in Rent Manager.

  • The System Preferences: Checks/Bills General system preferences were updated with a Require approval before posting RUBS charges field, which, when enabled, prevents RUBS charges from being posted until the master meter bill is approved.

  • The Importing privilege group was updated with an Import Master Meters privilege, which allows you to import external master meter files to add new data to Rent Manager or update existing data.

  • The RUBS Template page was added, allowing you to add and manage your RUBS templates which can then be applied to master meters to calculate tenant charges based on master meter bill amounts.

  • The Post RUBS page was added, which allows you to post RUBS charges for your master meter bills.

  • The Utility Detail page's Master Meters tile was updated with a Default RUBS Template field, which allows you to determine the RUBS template that is applied by default to any master meters for the utility.

  • The Add Utility wizard's Master Meters tab was updated with RUBS Enabled and RUBS Template columns, which allow you to enable and select a RUBS template for each master meter when adding a utility.

  • The Post Recurring Charges page and the Add Recurring Charge Automation Schedule pop-up were updated with a Post RUBS option, which, when checked, allows you to post RUBS charges when posting recurring charges.

  • The Posting Rollback page was updated with the ability to rollback posted RUBS charges.

  • The RUBS Posting Information report was added, which displays a breakdown of posted charges, grouped by bill. This report can be accessed and printed after posting RUBS charges.

  • The Add Bill pop-up and Bill details page have been updated to accommodate posting tenant charges for a utility bill using RUBS calculations.

  • The View Transactions pop-up was updated to display charges posted using RUBS to the corresponding tenant account.

  • The Utility Cost Recover report was updated to display RUBS charge-related information.

For more information, refer to Set Up RUBS.

Quickly process vendor and owner checks with ePay.

Express

The check scanning tool was updated, allowing you to scan vendor and owner checks as other income (also known as a step 3 deposit).

As part of this update, the following changes were made:

  • The Make Deposit, Deposit details, and Make ePay Deposit pages were updated with a Vendor/Owner drop-down field, which allows you to record the source of payments and deposits from vendors and owners.

  • The Vendor Transactions pop-up's Transactions To Include filter was updated with a Deposit option.

  • The Deposit Breakdown report's Tenant column was relabeled Name and displays a tenant's name for tenant transactions, or, if it's an other income transaction, the vendor's or owner's name.

  • The Deposit Detail report's Other Items section was updated to display vendor and owner deposits.

  • The Banks/Checks privilege group's Scan batches of checks privilege was renamed Scan batches of tenant/prospect checks. The privilege group was also updated with a Scan vendor/owner checks privilege, which allows you to scan multiple checks from multiple vendors and owners at a time to post as one payment batch. Additionally, an Edit MICR details and amount of scanned checks privilege was added, which allows you to edit MICR fields (Routing #, Account #, Check #) and Amount when scanning checks for tenants, prospects, vendors, and owners.

  • The ePay privilege group's Process Vendor ePay privilege was renamed Process Vendor/Owner ePay.

  • The Scan Vendor/Owner Checks page was added, which allows you to scan and record multiple checks or money orders in a batch and apply them to vendor and owner accounts efficiently from one page.

  • The ePay Deposit Reconciliation page was updated with a Type column, which displays the entity (Tenant, Vendor, or Owner) linked to the transaction.

  • The Add Payment pop-up was updated with a Scan Check option, which allows you to quickly record a single tenant or prospect check.

The check scanning tool also received several updates in Rent Manager 12. These updates have improved navigation and added or repositioned sections, filters, and fields to simplify the check scanning process.
