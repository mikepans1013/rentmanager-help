12.260550 Changelog

The release begins rolling out on June 11, 2026.

Enhancements

Flag, verify, and post with confidence with Metered Utilities Reviews.

Express rmAppSuite Pro

The Metered Utilities tool was updated, enhancing visibility into your meter reading life cycle, improving the handling of off-cycle move-out readings, and extending exception entry capabilities for technicians using rmAppSuite Pro in the field. These enhancements ensure your approval workflow is more flexible, accessible, and aligned with your real-world property operations.

As part of this update, the following changes were made:

  • The Meter Readings Statuses page is now available to all users, regardless of whether approval workflows are enabled. This update provides a high-level view of meter reading progress to help your team stay informed and confident throughout the billing cycle. For more information, refer to Meter Readings Statuses (Page).

  • The High/Low Settings pop-up's Consumption Groups tab was updated with an Include Off Cycle Readings field, which, when checked, readings with an off-cycle reading type are flagged as an Off-Cycle (Move Out) Exception.

    The Exception Reasons tab was also updated with an Allow rmAppSuite Pro users to select a reason for exceptions, which, when checked, displays an Exception Reason field in rmAppSuite Pro.

    Additionally, the Approval Workflows tab was updated with a Utility Type field, which allows you to assign a utility type to the workflow.

    For more information, refer to Manage Metered Utilities High/Low Settings.

  • The Manage High/Low Settings and Manage Meter Estimate Settings privileges have been moved from the Setup privilege group to the Utilities privilege group.

  • The Utility Consumption with Ranges report was renamed High/Low Consumption. Additionally, in the Ranges/Exceptions field, the Exceptions Only option now includes Estimate exceptions. For more information, refer to High/Low Consumption (Report).

  • The Move Out Readings pop-up was added, which allows you to view and manage all your off-cycle move-out readings from one location. Additionally, if an off-cycle reading triggered an exception, you can quickly access the reading to approve or review it on the fly. For more information, refer to Move Out Readings (Pop-Up).

In addition, to keep your utility tracking precise and transparent, we've enhanced consumption group usability and meter estimate visibility. These updates have improved navigation and added or repositioned sections, filters, and fields to simplify creating consumption ranges. To improve the estimate approval workflow, estimated readings can be flagged, allowing you to quickly identify them as exceptions so you can easily track and review those readings before they are posted.

For the Zego Utility Expense Management integration, Rent Manager now creates checks that pay multiple bills.

Express Rent Manager 12

With this integration enhancement, Zego continues to automatically process your invoices, but Rent Manager now creates checks that more accurately reflect the payments issued to your vendors by creating one check for each matching check number, bank account, and vendor. This allows multiple bills paid by the same check to be correctly associated, simplifying bank reconciliation while letting Zego and Rent Manager handle the intricate details of utility expense management.
