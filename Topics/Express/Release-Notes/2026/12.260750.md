# 12.260750 Changelog

Source: https://rmxhelp.rentmanager.com/Topics/Express/Release-Notes/2026/12.260750.htm

The release begins rolling out on August 21, 2026.

 Enhancements

 Easily retain the financial history of units and assets that are migrated between properties with new enhancements.

 Express

 The Unit to Asset Conversion Wizard and Financial Property Migration Wizard were updated to provide a financial cutoff when migrating units or assets between financial properties. This enhancement guarantees a clean, auditable split, with the old ledger data staying with the source property, while the new financial activity follows the unit or asset—eliminating compromised ledgers, auditing discrepancies, tax complications, and unnecessary manual cleanup.

 The asset tool was updated to provide greater flexibility and guidance for financial tracking and renting.

 Express Rent Manager 12

 Asset settings were updated, allowing you to uncheck Track financials for this asset any time, as long as there are no current or future leases associated with the asset or unpaid tenant or prospect transactions. Additionally, safeguards were added to prevent assets without financial tracking from being linked to new transactions, keeping your financial reports accurate.

 The site classification tool received enhanced customization.

 Express

 The site classification tool was updated, making it easier for every manufactured housing user to take advantage of powerful site tracking and related tools—whether you've transitioned to home assets or not. By providing the flexibility to manage site classifications manually when needed, Rent Manager helps your established communities accurately track lot conditions, unlock integrations like LeaseTrack homeowners insurance, and continue modernizing your operations on your own timeline.

 As part of this update, the following changes were made:

 -
 The Homeowner Statuses & Site Classifications page was updated with Automation Settings , allowing you to automatically update site classifications system-wide based on the tenant occupancy, home asset's homeowner status, and unit status.

 -
 The Property details page was updated with an Automation Settings quick action, allowing you to automatically update site classifications for the specific property based on the tenant occupancy, home asset's homeowner status, and unit status.

 -
 The Properties/Units privilege group was updated with a Manual Entry Site Classifications privilege, which, when Enabled , allows you to add, edit, and delete manual site classification entries.

 -
 Homeowner statuses and site classifications were updated with Resident Owned - Contingent Liability and Promissory Notes options so that unit records accurately reflect their current ownership and financing status.

 -
 The Import Properties tool was updated with Set Site Classification Automatically , Site Classification Automation Start Date , and Default Site Classification fields.

 -
 The Import Units tool was updated with Site Classification and Site Classification Start Date .

 Revolutionize your security deposit management with a faster setup, clear statuses, and seamless deposit workflows.

 Express Rent Manager 12

 Security Deposit Management, powered by Rentable, received several exciting updates to streamline transferring security deposits. The Add Tenant and Move In wizards were updated to include a Rentable Deposit tile, which allows you to send the Rentable invite and complete all the necessary steps of the prospect and tenant add process in a single workflow. Additionally, these updates have made information easier to read, improved navigation, and added or relabeled buttons and fields to simplify collecting and refunding security deposits. For more information, refer to the Move In Wizard and Add a Tenant topics.
