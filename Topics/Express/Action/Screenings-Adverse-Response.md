# Inform an Applicant of Adverse Screening Results

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/Screenings-Adverse-Response.htm

When you reject an application, change a lease agreement, or decide not to renew a lease due to the results of a screening or income verification request, you can use letter templates to inform the prospect or tenant of the decision and the reason for their rejection. For example, you can send letters to tell applicants informing them that they were rejected due to insufficient income or issues with the information they provided.

 Warning

 Your company should review local, state, and federal law to understand your precise obligations related to sending adverse action letters.

 To send an adverse action letter to an applicant, do the following:

 -
 Go to arrow_forward Rental Info arrow_forward Leasing arrow_forward Screenings and select a screening or income verification from the list.
The Screening Detail or Income Verification Detail page displays.

 -
 To select the prospect- or tenant-type letter template for the adverse action letter, do one of the following:

 Option
 Description

 Income Verification

 In the Income Verification Information section's Adverse Action Letters field, select the desired prospect- or tenant-type letter template to send from the drop-down list.

 Screening

 In the Information section, select the prospect- or tenant-type letter template to send from the drop-down list.

 -
 Click Write Letter .
The Compose Letter pop-up displays.

 -
 If applicable, make any necessary edits to the letter.

 -
 Select the method of distribution for the letter:

 Attach the letter to a history/note item on the applicant's Rent Manager account. In the Add to History pop-up's Attach As field, select the file type for the attachment.

 If desired, select the History Category and/or enter additional information in the Note field for the item. To create the history/note item, click Save .

 Download

 Save the letter to your device's default downloads folder to send the letter to the applicant externally. On the Download Document pop-up, enter the File Name and select the File Format , then click Save .

 Send the letter in an email to the applicant. On the Attach to Email pop-up, enter the File Name and select the File Format for the email attachment. Alternatively, to display the contents of the letter in the body of the email instead of attaching it as a file, select Use merged document as body , then click Save .

 Then, enter information in the Compose Email pop-up and click Send . For more information, refer to Send an Email .

 Print

 If you need to send the letter via post office or you need to provide the applicant with a physical copy, go to File arrow_forward Print to send the generated letter to your local printer. This option opens the print controls set in your web browser that you are using to access Rent Manager .
