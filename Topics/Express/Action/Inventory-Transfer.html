Transfer Inventory Between Properties

When linked to certain Rent Manager tools, inventory item quantities are updated in real time. Stock is automatically increased when items are received via a purchase order and automatically decreased when items are issued via an issue or invoice. However, there may be situations that require you to decrease inventory stock at one property and increase the same inventory stock at a different property. For example, you may find it necessary to transfer inventory to a new property if you are no longer managing the property or need to split up inventory so that all of your properties have a specific amount.

Related Preferences

The ability to manually transfer inventory stock displays only if Track inventory by property is enabled in system preferences. For more information refer to P.O./Inventory (System Preferences).

To transfer inventory from one property to another, do the following:

  1. Go to arrow_forward Accounting arrow_forward General arrow_forward Inventory Items.
    The Inventory Items page displays.

  2. Select the inventory item you wish to transfer from the list and click arrow_forward Transfer Inventory.

  3. Enter the following information in the Inventory Information section:

    Field Description

    Item

    The item for which you wish to transfer. By default, the currently selected item is displayed.

    Quantity

    The amount of item stock to be transferred for use at a different property.

    Date

    The date of the transaction. By default, today's date populates.

    Cost

    The cost per item using the following formula:

    Cost = Price - Markup

    Notes

    A note that is added on the Inventory Transactions page, in the Type column.

  4. Enter the following information in the From and To columns:

    Field Description

    Property

    The property from or to the inventory item is transferred. Or, select <No Property Assignment> to unassign the item from a property. Quantities of an item can be assigned to a selected property while other quantities may be assigned to another property or no property.

    Quantity

    When a property is selected, the current amount of inventory stock associated with the property displays.

  5. Click Transfer.
    The Quantity specified to be transferred is transferred from the specified From property to the specified To property.
