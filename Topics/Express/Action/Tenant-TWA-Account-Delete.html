Delete a Tenant's Tenant Web Access (TWA) Account

Deleting the user account may be necessary if a roommate moves out and no longer needs a Tenant Web Access (TWA) account, or if a duplicate account is mistakenly created when moving a prospect in. You can delete the tenant or prospect's Tenant Web Access (TWA) account for them directly from Rent Manager using the Web Access Settings pop-up on their details page.

In any situation where the tenant’s saved Tenant Web Access account should be retained, such as student housing where a tenant may apply to live at the property again, on the Web Access Settings pop-up, consider unchecking Enabled instead. You can also set up the time frame a tenant can log into Tenant Web Access after move out to be able to keep historical data of the Tenant Web Access account but also prevent tenants from accessing the site for an extended period of time. For more information, refer to Tenant Web Access General (System Web Preferences).

Related Preferences

To access Tenant Web Access settings, at least one location must be enabled for TWA. For more information, refer to Licensing (System Web Preferences).

If the system web preference option to Allow Tenant To Create Accounts is checked, the tenant is able to create a new web user account, otherwise a new account needs to be made for them in Rent Manager. For more information, refer to Tenant Web Access Accounts (System Web Preferences)

To delete a TWA account, do the following:

  1. Go to arrow_forward Rental Info arrow_forward General arrow_forward Tenants | Prospects and select a tenant or prospect from the list.
    The Tenant or Prospect details page displays.

  2. On the action bar to the right, click arrow_forward TWA Settings.

  3. In the Web Users section, on the web user that is to be deleted, click arrow_forward Delete.
    The Confirm Delete pop-up displays.

  4. Click Yes.
    The web user account is deleted.
