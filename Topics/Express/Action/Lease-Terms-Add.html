Add a Lease Term

In Rent Manager, lease terms describe the duration of tenant leases and can be selected when entering lease details. You may add lease terms of your own and edit the default lease terms that Rent Manager provides in order to best suit your business needs.

Related Privileges

Group Privilege Column
Tenants/Prospects Lease Terms Add, View

For more information, refer to Control User Access.

To add a new lease term, do the following:

  1. Go to arrow_forward Rental Info arrow_forward Rental Info Setup arrow_forward Tenants/Prospects arrow_forward Lease Terms.
    The Lease Terms page displays.

  2. Click Add Lease Term.
    The Lease Term Details pop-up displays.

  3. Enter a Name to describe the term.

  4. In the Duration field, enter a number and then select the time unit (Days, Months, or Years) from the drop-down list (e.g., 9Months) to describe the length of the lease term.

    More Information

    You cannot create a new lease term with the equivalent duration of an existing lease term. For example, if a lease term for 12 Months already exists, you cannot create a new lease term of 1 Year.

  5. In the Properties section, select each property for which this lease term is available.

  6. To finish, click Save & Close or to save and create additional lease terms, click Save & New.
    The new lease term is added to the list.
