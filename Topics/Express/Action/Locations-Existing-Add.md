# Add an Existing Location

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/Locations-Existing-Add.htm

You can import an existing database location to your system in two circumstances: if your property management company previously deactivated a database location and wants to restore it in your system, or if you acquired another company that uses Rent Manager and want to import their database location(s). This allows you to access the historical data and financial records of the selected database location(s) without the need to manually import or duplicate the information.

 More Information

 If you acquired a company that uses Rent Manager and intend to import their existing database location(s) to your system, you need to work with your sales representative or contact sales@rentmanager.com for assistance performing a data transfer. Once that process is complete, the Add Existing Location pop-up is populated with the acquired company's location(s) that can be imported.

 Locations are a licensed feature and must be purchased separately. For more information, contact your sales representative at sales@rentmanager.com .

 To add an existing location to your database, do the following:

 -
 Go to arrow_forward Administration , then go to Locations arrow_forward Manage Locations .
The Manage Locations pop-up displays.

 -
 Click Add Existing .
The Add Existing Location pop-up displays.

 More Information

 If applicable, all inactive locations display in this pop-up, but you can add an inactive location only if your user account already has access to that location. For more information, refer to the Locations heading on the User Details (Page) page.

 -
 Check the box next to the location(s) you want to add to your database.

 -
 Check Link matching usernames to merge any identical usernames between locations.

 Warning

 Matching usernames should always be linked when adding an existing location. This field is unchecked only if you are explicitly told to do so by an LCS representative that is directly assisting you with this process.

 -
 Click Save .
The selected location(s) is added to your database.
