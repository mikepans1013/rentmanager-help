Add a Memorized Report

Memorized reports are saved for later use and can save you time by eliminating the need to make the same selections each time you run the report. For example, you can save a report for Service Hours to run daily or weekly, or you can memorize a Financial Statement report that you can run monthly.

An example of a time-saving selection is the Other Options field located within the Date Range options of a report. When this option is selected, the next time you run the memorized report, Rent Manager uses the relative date selected (Last Quarter, Next Fiscal Year, Next Quarter, and so on) so you do not need to select a date the next time you run this report.

Related Privileges

Group Privilege Column
Letter/Email Templates/Reports/Packets Run reports Enabled

Additionally, on the Reports tab, you must have access to the corresponding report in the Reports section.

For more information, refer to Control User Access.

To add a new memorized report, do the following:

  1. Go to and select the report you want to memorize.

  2. Make your desired selections in the report options.

  3. On the action bar to the right, click .
    The Memorize Report pop-up displays.

  4. Enter a Name for this memorized report. When creating multiple memorized versions of a report, you want to ensure each report has a unique name. This helps you quickly distinguish the reports that you do want to run from the ones you do not.

  5. Click Save.
    The report is added to both the Memorized Reports menu and the Memorized Reports page.
