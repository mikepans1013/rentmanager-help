# Delete a Unit

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/Units-Delete.htm

The primary reason to delete a unit is that it was added in error and you want to remove the entry so that the unit is unavailable for use. If a unit is linked to a past, current, or future tenant account, it cannot be deleted.

 Warning

 Deleting a unit is permanent and cannot be undone. If you no longer wish to use the unit, instead of deleting it, consider marking it as inactive with a unit status. This allows you to retain the information attached to that unit while removing it from the list of available units. For more information, refer to Add and Assign a Unit Status .
