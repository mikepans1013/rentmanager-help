Refund an ePay Payment

If a tenant or prospect made a payment through ePay and needs to receive a refund, you can process that refund directly through Rent Manager.

More Information

This process is used to fully refund an ePay payment. If you need to make a partial refund for an ePay payment, you must process the refund manually.

Related Privileges

Group Privilege Column
Tenants/Prospects Tenants View
Prospects View
ePay ePay Process ePay refunds

For more information, refer to Control User Access.

To refund an ePay payment, do the following:

  1. Navigate to the desired entity receiving the refund.

    Entity Navigation

    Prospect

    Go to arrow_forward Rental Info arrow_forward General arrow_forward Prospects and select a prospect.

    Tenant

    Go to arrow_forward Rental Info arrow_forward General arrow_forward Tenants and select a tenant.

  2. On the Transactions tile, click .
    The View Transactions pop-up displays.

  3. On the ePay transaction being refunded, select arrow_forward ePay Refund.

  4. If prompted, enter your ePay password.

  5. In the Refund Date field, enter the date that the refund is issued in Rent Manager.

  6. In the Reason field, enter an explanation for the refund.

  7. To create a history/note item on the account to document the ePay refund, select Add History Note.

    Related Privileges

    Depending on whether you are adding history/note items to tenants or prospects, one of the following privileges is required.

    Group Privilege Column
    History Tenant History/Notes Add
    Prospect History/Notes Add

    For more information, refer to Control User Access.

  8. Click Refund.
    The ePay refund is sent to Zego for processing.
