# Add a Site Group

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/STR-Site-Group-Add.htm

Site groups are a way to organize short term rental (STR) units that share similar STR rate schedules together. Each site group is created at the property level, and can contain one or more units. When new STR rate schedules are added to the property, you are given the option to select any previously created site groups. Otherwise, you must select each unit individually. Site groups provide a simple way to create rate schedules for multiple units at the same time.

 Only properties to which you have access display. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 To create a new site group for the property, do the following:

 -
 Go to arrow_forward Rental Info arrow_forward General arrow_forward Properties and select an RV/Campground property from the list.
The property's details page displays.

 -
 On the action bar, click arrow_forward STR Settings .
The Property STR Settings pop-up displays.

 -
 On the General tab, in the Site Groups section, click .
The Add Site Group - Select Units pop-up displays.

 -
 Enter a unique Name for the site group that describes the types of units added to the group.

 -
 If you have STR Online Booking enabled, enter information in the Marketing section to allow available sites to be organized into site groups. This feature makes it easier for guests to view details of the site groups. For more information, refer to STR Online Booking (Pop-Up) .

 The following fields are available in this section:

 Field
 Description

 Marketing Name

 The name of the site group as it should appear on online booking sites.

 Description

 Information about the site group you want to display on the online booking portal.

 Images

 Click Upload Files to add images associated with the site group that display on the online booking portal.

 -
 To filter the units that display in the Matching Units section, click Unit Preferences
The Unit Preferences pop-up displays.

 The following options are available to filter what units are able to be added to the group:

 Option
 Description

 Unit Type

 Units associated with the selected unit types display. Only unit types associated with the property display in the drop-down list. For more information, refer to Unit Types (Page) .

 Amenities

 Units associated with the selected amenities display. For more information, refer to Assign Amenities .

 Width

 A value that describes how wide the space is to generate units with the matching Width entered on the unit's RV/Campground Information tile.

 Length

 A value that describes how long the space is to generate units with the matching Length entered unit's RV/Campground Information tile.

 UDF

 Select a unit-type user defined field (UDF) from the drop-down list. Once selected, in the UDF Value field enter the value for the UDF to find units that match the UDF value. For more information, refer to Unit User Defined Fields (Pop-Up) .

 Amps

 A value that describes the amperage(s) of the electrical hookup requirements to generate units with the matching Amps entered on the unit's RV/Campground Information tile.

 Max Occupancy

 The maximum number of occupants to find units with the matching Max Occupancy entered on the unit's Miscellaneous tile.

 Show Pull-Through only

 Check to find units that have Pull-Through checked on the unit's RV/Campground Information tile.

 -
 To view units in different site groups, click Show units included in a site group . However, those units cannot be selected until they are removed from the existing site group because a unit can be added to only one site group.

 -
 If no information is specified in the Unit Preferences pop-up, all units associated with the property but are added to a different site group display. Select each unit in the Matching Units section you wish to add to the site group, and use the arrows to move them into the Selected Units section. You can also move units back into the Matching Units sections if necessary.

 -
 Click Save
The site group is saved for the property.
