# Change Locations

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/Locations-Change.htm

If you use more than one Rent Manager database location to store data for more than one property management company, you can switch between those locations in Rent Manager Express . Each location maintains its own records, and user access can be restricted to selected users.

 More Information

 Locations are a licensed feature and must be purchased separately. For more information, contact your sales representative at sales@rentmanager.com .

 More Information

 If you use per unit Rent Manager licensing, each unit in each location uses one license.

 For more information, refer to Assign Unit Licenses .

 To switch to a different location, do the following:

 -
 Go to arrow_forward Administration , then go to Locations arrow_forward Change Locations .

 -
 Select the location you wish to access.

 -
 Click Change Locations .
The Rent Manager Express page refreshes and the selected location name displays under your company code.
