# Delete a Charge Type

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/Charge-Type-Delete.htm

You can delete a charge type only when there are no charges of that type currently posted to tenant, prospect, or owner accounts. If you want to delete a charge type with transactions currently assigned to it, you must reassign the transactions to a different type before you are able to delete the selected charge type.

 Since this process requires updating much of your financials, there are very few situations where deleting is necessary. For example, you may delete a charge type because it is a duplicate of an existing charge type or if you entered the information on a new charge type incorrectly.

 Warning

 Deleting a charge type is permanent and cannot be undone. If you no longer wish to use a charge type, instead of deleting it, consider marking it as inactive. This allows you to retain financial data attached to that charge type while removing it from available charge types for future transactions. For information on how to make a charge type inactive, refer to Charge Type Details (Page) .

 To permanently delete a charge type, do the following:

 -
 Go to arrow_forward Accounting arrow_forward General arrow_forward Charge Types .
The Charge Types page displays.

 -
 To the right of the charge type, click arrow_forward Delete .
The Confirm Delete pop-up displays.

 -
 Click Yes .
The charge type is removed from the page and is no longer available to select for transactions.
