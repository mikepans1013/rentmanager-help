# Add a Default Security Deposit to a Unit

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/Units-Security-Deposit-Default-Add.htm

The Default Security Deposit Details pop-up allows you to establish the default amount for security deposits that tenants pay when they move into this unit, as well as the default charge type used to record security deposit payments from tenants. Default security deposit charge types are set in system preferences, but can be overridden for individual units.

 To add a default security deposit, do the following:

 -
 Go to   arrow_forward Rental Info arrow_forward General arrow_forward Units and select a unit from the list.
The unit's details page displays.

 -
 On the Default Security Deposits tile, click .
The View Default Security Deposits pop-up displays.

 -
 Click Add Default Security Deposit .

 -
 Select a Charge Type from the drop-down list to be used for the unit's security deposit.

 Related Preferences

 Deposit types specified in system preferences display in the drop-down list. For more information, refer to Security Deposit General Options (System Preferences) .

 -
 Enter the Amount of the security deposit charge.

 -
 Enter an optional Comment that provides additional information about the security deposit charge.

 -
 Click Save .
The security deposit is added to the Default Security Deposits tile.
