Update a Published Signable Document

Once a signable document is published, few edits can be made without compromising its legally binding elements. If you find that a published document needs to be updated, Rent Manager allows you to amend it in those few areas that are allowed to be edited.

You can edit or amend a document with a status of Published or Expired to modify the Expiration Date and the contacts included as signers (provided there are enough available signature blocks in the document to support the changes). For example, if you did not add a document expiration date and you no longer wish for the document to be signed, you can revise the document after it is published to add this date. Doing this ensures the document cannot be signed after the date entered.

If the document has incorrect content and is not one of the few fields allowed to be edited, the published document must be deleted, updated, and republished before finalizing the document.

To update a published signable document, do the following:

  1. Go to arrow_forward Communication arrow_forward Signable Documents arrow_forward Signable Documents and select the signable document you wish to update.
    The Signable Document Packets page displays.

  2. Click Edit Publish Details.
    The Edit Signable Document Signers pop-up displays.

  3. Make any of the following changes to the document:

    Action Description

    Change the expiration date

    Add, edit, or remove the Expiration Date as needed.

    Update existing signers

    Add, remove, or update the signers assigned to the document. Any changes to a recipient's or contact's email address is reflected on the recipient's account.

    Add new signers

    Click Add Item to add signers to the document. The number of signers you select cannot exceed the number of signature blocks in the document. Use the Number of Signers field to determine how many signers are assigned to the document and how many signers the document can be assigned.

  4. Click Save.
    The document is updated. However, if the recipient has the document open at the time of your edits, you are unable to save your changes.
