# Mass Edit Account Information

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/Entity-Mass-Edit.htm

The mass edit mode tool allows you to update editable columns directly from an entity's register page to efficiently update multiple records and accounts without leaving the entity's register page view. By utilizing the mass edit functionality in Rent Manager , high-volume tasks such as updating multiple records and accounts can be completed in bulk without manual workarounds, saving time and reducing potential for data-entry errors.

 The mass edit mode tool is available for the following entities in Rent Manager :

 -
 Assets

 -
 Bills

 -
 Issues

 -
 Owners

 -
 Properties

 -
 Prospects

 -
 Tenants

 -
 Units

 -
 Unit Types

 -
 Vendors

 Related Privileges

 The View and Edit privileges determine which entities can be mass edited. Depending on your user privileges, you may be able to mass edit some entities in Rent Manager , but not others.

 For more information, refer to Control User Access .

 To use mass edit mode, do the following:

 -
 Navigate to the desired entity. For example, if you want to mass edit tenants, go to arrow_forward Rental Info arrow_forward General arrow_forward Tenants .
The Tenants page displays.

 -
 At the top left of the page, click Bulk Actions arrow_forward Mass Edit Mode .

 -
 Click in the cell of one of the editable columns to edit that account's respective information (such as Name , Email , or Description ). Columns that cannot be edited in mass edit mode are grayed out. The columns that are available to edit vary depending on the selected entity.

 -
 Optionally, to change whether a phone number is text-enabled, click the phone number and then click enable the phone number for texting. Alternatively, to disable texting, click . The Ext. field for extensions is removed when texting is enabled.

 -
 To save your change, click outside the edited field or press Enter .
The field turns green, indicating the edit is successful.

 -
 After finishing the mass edits, on the top of the page, click Exit to exit mass edit mode.
The accounts' information is updated.
