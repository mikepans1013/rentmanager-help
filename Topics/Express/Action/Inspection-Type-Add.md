# Add an Inspection Type

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/Inspection-Type-Add.htm

Rent Manager inspections streamline and standardize the inspections process with customization options to fit your needs. To categorize your inspections and ensure accurate information on the Inspection Activity Report , you can create inspection types to be used for different procedures (e.g., tenant move-ins, property-wide inspections, annual audits).

 To create a new inspection type, do the following:

 -
 Go to arrow_forward Services arrow_forward Inspections arrow_forward Inspections .
The Inspections page displays.

 -
 Click Manage Inspection Types .

 -
 Click Add Type .
A new line item is added.

 -
 In the Type column, enter the name of the new inspection type.

 -
 Click Save .
The inspection type is saved to the list and can be selected when kicking off an inspection.
