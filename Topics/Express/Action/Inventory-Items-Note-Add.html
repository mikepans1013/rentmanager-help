Add an Inventory Item Note

Notes allow you to create categories for inventory items listed on an invoice or estimate. These display as headings on the invoice or estimate to preface a breakdown of the items billed to the tenant, prospect, or owner. Once a note is created, on an invoice or estimate, it can be selected in the Product column to act as a header for any subsequent items.

Related Privileges

Group Privilege Column
Sales/Invoicing Items Add, View

For more information, refer to Control User Access.

To add an inventory item note, do the following:

  1. Go to  arrow_forward Accounting arrow_forward General arrow_forward Notes.
    The Notes page displays.

  2. Click Add Note.

  3. Enter a Name to identify the note. This is the name that displays on the invoice or estimate in the Product column.

  4. Enter a Description to provide more details about what this note represents or when to use it.

  5. To finish, click Save & Close or to save and create additional inventory item notes, click Save & New.
    The new note is added to the list.
