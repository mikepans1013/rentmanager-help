# Add an Issue Category

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/Issues-Category-Add.htm

Issue categories are classifications that you create to help you sort and track types of issues (e.g., Maintenance , Electrical , Plumbing , Emergency , Office ). They also aid in filters and saved issue lists. You can add new issue categories that users can select when filling out issues and format the categories to add visual distinction.

 To add a new issue category, do the following:

 -
 Go to arrow_forward Services arrow_forward Service Setup arrow_forward Service Manager arrow_forward Issue Categories .
The Issue Categories page displays.

 -
 Click Add Category in the upper right.

 -
 Enter the Name of the issue category (e.g., Maintenance , Office , To Do , Emergency ).

 -
 In the Format section, select one or more of the font emphasis options ( Bold , Italic , Underline ) to specify how the Category displays on the Issues page.

 -
 To change the display color of the Name , click the Font Color box. To set a color, click the color swatch.

 Click OK to set the selected color.

 -
 Enter a brief Description of the category (e.g., Property Wide Maintenance , Service Issues , Work to be performed in the office ).

 -
 To finish, click Save & Close , or to create additional issue categories, click Save & New .
The new issue category is created and can be used on issues.
