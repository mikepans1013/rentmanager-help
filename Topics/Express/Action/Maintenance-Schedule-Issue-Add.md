# Add an Issue from the Maintenance Schedule

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/Maintenance-Schedule-Issue-Add.htm

Issues can be created directly from the Maintenance Schedule , allowing you to review the workload of each maintenance technician on a specific day before scheduling a date and time for them to complete the work. This is a simplified method to add an issue that includes only the fields relevant to the maintenance schedule, but additional details can be entered by opening the issue's details page once it is created.

 To add an issue from the Maintenance Schedule , do the following:

 -
 Go to arrow_forward Services arrow_forward Service Manager arrow_forward Maintenance Schedule .
The Maintenance Schedule page displays.

 -
 At the top, click New Issue .

 -
 Enter the issue's information into the available fields described below.

 Field
 Description

 Title

 The name of the issue to display on the Maintenance Schedule page.

 Description

 Additional information about the issue, such as the work that needs to be completed in order for the issue to be considered resolved.

 Assigned To

 The user who is to complete the issue. The drop-down list populates only with users that are set up as maintenance techs. For more information, refer to Add Maintenance Techs .

 Category

 The classification that best describes the type of issue being created (e.g., Maintenance , Emergency ).

 Allowed to Enter

 Check to indicate that service technicians may enter the unit associated with the issue without the tenant present.

 Related Preferences

 This field displays only when Allowed To Enter is checked in system preferences. For more information, refer to Service Issue General Options (System Preferences) .

 -
 Add links to the tenant, unit, and/or property associated with this issue by clicking Add Link on the desired entity and entering the name. If you are adding a tenant link, select the account type you wish to link (i.e., Current Tenant , Past/Future Tenant , or Prospect ).

 -
 In the Open Date field, enter the date and time that the issue is available to service technicians. This field populates with the date and time the issue was created by default.

 -
 In the Scheduled Date field, select the date that the maintenance technician is to begin working on the issue. This is the date on which the issue displays on the Maintenance Schedule page.

 -
 Click Select Time Block and choose an available time block for the issue assignee. Time blocks are defined by maintenance tech and can differ depending on the maintenance tech assigned to the issue. For more information, refer to Maintenance Techs (Page) .

 -
 Click OK .
The pop-up closes and the Scheduled Date field displays the selected date and time block.

 -
 Click Save .
The issue is created. If the issue's Scheduled Date is selected on the Maintenance Schedule page, the issue displays on the schedule under the selected time block and assignee.
