# Manually Renew a Lease

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/Lease-Renew.htm

A tenant's lease can be renewed manually from the tenant's account as needed. A manual lease renewal is necessary in the case of a commercial lease, or if the renewal agreement has already been made outside of Rent Manager rather than via the Create Renewal Offers tool.

 Related Privileges

 Group
 Privilege
 Column

 Tenants/Prospects
 Tenants
 View, Edit

 For more information, refer to Control User Access .

 More Information

 Leases that are renewed manually will not display in the Lease Expiration report, as the report displays only leases created using the Create Renewal Offers tool. For more information on renewal offers, refer to Create Renewal Offers .

 To manually renew a lease, do the following:

 -
 Go to arrow_forward Rental Info arrow_forward General arrow_forward Tenants and select a tenant from the list.
The Tenant details page displays.

 -
 On the Leases tile, click and select a lease from the list.
The Lease Details pop-up displays.

 -
 Click Renew .

 -
 Enter the applicable information for the new lease. The following fields are available:

 Field
 Description

 Lease Start

 Optionally, enter the date on which the lease begins, or click to select the date. This date can be used to help create a renewal term if no lease term is available when generating renewal offers. For more information, refer to Create Renewal Offers .

 Lease Documents

 To add a document associated with the lease, click Upload or Paste .

 Related Preferences

 If you allow tenants to view their leases in Tenant Web Access (TWA) , they can also access any lease documents uploaded in the portal. For more information, refer to Tenant Web Access Leases Page Setup (System Web Preferences) .

 Lease End

 If applicable, enter the date on which the lease expires, or click to select the date. Paired with the lease start date, this date can be used to help create a renewal term if no lease term is available when generating renewal offers.

 Lease Sign

 If applicable, enter the date on which the lease was signed by the tenant, or click to select the date. This date can be useful in determining which lease came first for tenants with multiple leases.

 Lease Term

 If applicable, select the option that represents the expected duration of the renewed lease. For more information, refer to Lease Terms (Page) .

 Move In

 Enter the date on which the tenant moves into the unit, or click to select the date. It is best practice to enter a move-in date as this determines when recurring charges begin for the tenant. Only tenants with the status of Current in Rent Manager receive recurring charges. Tenants with future move-in dates do not receive recurring charges.

 Move Out

 If known, enter the date on which the tenant officially vacates the unit, or click to select the date. If a tenant has a past move-out date, they are considered a past tenant in Rent Manager and do not have recurring charges posted to their account.

 Typically, this field should be left blank until you have a confirmed move out date. For reporting purposes, you can enter an Expected MO (move out) date instead.

 Notice

 If known, enter the date on which the tenant gave notice that they are moving out of the unit, or click to select the date. This date can be used to generate results on when a unit becomes available for reporting purposes.

 Expected Move Out

 If applicable, enter the date on which the tenant is expected to move out of the unit , or click to select the date. This date can be used in place of a move-out date for reporting purposes.

 -
 Optionally, in the User Defined Fields section, enter a Value for any lease-type user-defined fields.

 More Information

 You can create separate user-defined fields for commercial and noncommercial leases. The list of UDFs that display depends on whether the property selected is a commercial property.

 -
 Click Save .
The renewed lease is created for the tenant.
