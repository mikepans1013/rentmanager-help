Delete a Unit

The primary reason to delete a unit is that it was added in error and you want to remove the entry so that the unit is unavailable for use. If a unit is linked to a past, current, or future tenant account, it cannot be deleted.

Warning

Deleting a unit is permanent and cannot be undone. If you no longer wish to use the unit, instead of deleting it, consider marking it as inactive with a unit status. This allows you to retain the information attached to that unit while removing it from the list of available units. For more information, refer toAdd and Assign a Unit Status.

Related Privileges

Group Privilege Column
Properties/Units Units View, Delete

For more information, refer to Control User Access.

To permanently delete a unit, do the following:

  1. Go to  arrow_forward Rental Info arrow_forward General arrow_forward Units and select a unit from the list.
    The unit's details page displays.

  2. On the action bar to the right, click .
    The Confirm Delete pop-up displays.

  3. Click Yes.
    The unit is removed from the Units page.
