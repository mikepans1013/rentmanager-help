Delete an Owner's Owner Web Access (OWA) Account

Deleting an owner's Owner Web Access (OWA) account may be necessary if it has been compromised or if the owner no longer has access to that particular email address and needs to re-register. You can delete the owner's OWA account for them directly from Rent Manager. In any case where the owner's historical Owner Web Access data should be retained—such as the owner is no longer using your property management company—consider unchecking Enabled on the user account instead.

Related Preferences

If the system web preference option to Allow Owner To Create Accounts is checked, the owner will be able to create a new web user account. For more information, refer to Owner Web Access Accounts (System Web Preferences).

To access Owner Web Access settings, at least one location must be enabled for OWA in system web preferences. For more information, refer to Licensing (System Web Preferences).

Related Privileges

Group Privilege Column
Owners Owners View, Edit
Properties/Units Properties View

For more information, refer to Control User Access.

To delete an OWA account, do the following:

  1. Go to arrow_forward Owners arrow_forward General arrow_forward Owners and select the owner from the list.
    The owner's details page displays.

  2. On the action bar to the right, click arrow_forward OWA Settings.
    The Web Access Settings pop-up displays.

  3. In the Web Users section, for the user you need to delete, click arrow_forward Delete.
    The Confirm Delete pop-up displays.

  4. Click Yes.
    The web user account is deleted.
