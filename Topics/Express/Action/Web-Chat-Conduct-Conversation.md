# Conduct a Web Chat Conversation

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/Web-Chat-Conduct-Conversation.htm

Web Chats in which you are participating and queues of which you are part display in the My Conversations page. From this page, you can log in and out of queues to which you are assigned and conduct web chats with visitors to your sites. Additionally, Web Chat is built directly in to Rent Manager , allowing you to quickly access information in your database. For example, if a tenant sends a message to you regarding a maintenance problem, you can quickly create a service issue tied to their account. The tenant's account information is populated within the issue ticket, and the conversation is automatically saved on their History/Notes tile.

 Even while logged into Web Chat queues, you can navigate to other areas of Rent Manager and be available to answer chat requests. If a new request or response is submitted to a queue you are logged into, you receive a red notification dot on the icon at the top right of Rent Manager Express . You can click this icon at any time to be redirected back to the My Conversations page.

 To conduct a conversation through Web Chat, do the following:

 -
 Go to arrow_forward Communication arrow_forward Web Chat arrow_forward My Conversations .
The My Conversations page displays.

 -
 In the Queues tile, click Login for each queue from which you need to accept Web Chat conversations.

 More Information

 In order to start a Web Chat conversation from the My Conversations page, the following privileges on the Manage Queues page are required for the associated queue depending on the action you wish to take:

 -
 To start the next chat, you must have Agent checked on the Chat Agents tile.

 -
 To start any chat in the list, you must have Admin checked on the Chat Agents tile.

 For more information, refer to Manage Queues (Web Chat) (Page) .

 -
 On the Pending Conversations tile, click   arrow_forward   Start Conversation on the chat request you wish to answer.
The chat opens in a new tile on the right side of the page. Multiple conversation tiles can display on the page at the same time.

 -
 Type your reply in the available text field.

 You can click to select one of the Saved Replies from the list to populate the text field with a preset answer established for the queue. For more information, refer to Manage Queues (Web Chat) (Page) .

 Click to browse your computer for an image file to insert into the chat.

 -
 If applicable, perform any necessary Actions for the chat. There are multiple actions which can be taken during a Web Chat. The actions available are determined on the Manage Queues page.

 Transfer

 Transfer the active conversation to another agent in the same queue. This action is always available.

 On the Transfer Conversation pop-up, enter or select the agent to which you wish to assign the chat and, optionally, enter a comment explaining the reason for the transfer, then click OK .
