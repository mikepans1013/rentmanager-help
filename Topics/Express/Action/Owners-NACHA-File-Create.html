Create a NACHA File

If you transfer owner distributions using NACHA, you can create a copy of the NACHA file so it can be processed with your bank. A NACHA file can be generated even if you deleted the original NACHA file that was created when you made the owner distribution. When you pay a check using NACHA, the file can be downloaded later by viewing the check from the owner's details page.

More Information

Before a NACHA file can be generated, you must first set up your Rent Manager database to pay owners with NACHA. For more information, refer to Set Up Rent Manager to Pay Owners with NACHA.

Related Privileges

Group Privilege Column
Owners Owners View
Generate NACHA File Enabled

For more information, refer to Control User Access.

To create and download a NACHA file, do the following:

  1. Go to  arrow_forward Owners arrow_forward General arrow_forward Owners and select an owner from the list.
    The owner's details page displays.

  2. On the action bar on the right, click arrow_forward Checks.
    The Checks pop-up displays.

  3. Click the desired check to expand the row, then click arrow_forwardGenerate NACHA File.
    The file is generated and downloaded to your default downloads folder, and can be sent to the owner's bank.

    More Information

    NACHA files can only be generated for owners that have been paid using the payment format NACHA. For more information, refer to Pay Owners.
