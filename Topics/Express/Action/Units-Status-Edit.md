# Update or End a Unit Status

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/Units-Status-Edit.htm

Unit statuses are exceptions to the standard status of occupied or vacant, such as maintenance or remodeling. These statuses plays a key role in determining whether Rent Manager lets tenants move into the unit or allows prospects to reserve the unit. It also determines whether the unit counts as vacant for certain reports. If the status of a unit needs to be changed at any point, Rent Manager gives you the ability to update a unit status or end it.

 To update or end a unit status, do the following:

 -
 Go to   arrow_forward Rental Info arrow_forward General arrow_forward Units and select a unit from the list.
The unit's details page displays.

 -
 On the Unit Status tile, click .
The View Unit Status pop-up displays.

 -
 To the right of the status you want to change, click arrow_forward Details .
The Unit Status Details pop-up displays.

 -
 To end the current status, enter an End Date .

 -
 When you are finished, click Save .
The unit status is updated for the unit.

 -
 Optionally, to update the unit's status to a new one, click Add Unit Status and assign the unit's new status. For more information, refer to Add and Assign a Unit Status .

 Warning

 Deleting a unit status or changing its existing status removes the historical record of the statuses connected to the unit from Rent Manager . It is recommended you add an End Date on the unit's status if it longer applies. An existing status should only be deleted or changed if it was originally added in error.
