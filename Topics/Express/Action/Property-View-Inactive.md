# View Inactive Properties

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/Property-View-Inactive.htm

By default, only active properties display in the list of properties on the Properties page. To display both active and inactive properties, go to arrow_forward Rental Info arrow_forward General arrow_forward Properties and check Show Inactive at the top.
