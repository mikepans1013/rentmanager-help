Add a Memorized Journal

Journal entries are manual accounting entries that debit the balance of a general ledger (GL) account and credit the balance of another. To save time creating common journal entries for frequent tasks, like transferring security deposits to or from escrow accounts, you can create memorized journals. Memorized journals act as templates that quickly populate general journal information, such as the GL accounts that are debited and credited and the dollar amount of the entry.

Related Privileges

Group Privilege Column
Accounting Memorized journal entries Add, View

For more information, refer to Control User Access.

You can memorize an existing journal by opening the journal's details page and clicking arrow_forward Memorize. You can also create a new memorized journal entry. To add a new memorized journal, do the following:

  1. Go to arrow_forward Accounting arrow_forward Journals arrow_forward Memorized Journals.

  2. Click Add Memorized Journal.

  3. In the top section, enter the following general information.

    Field Description

    Name

    The name that displays in the Memorized Journal List when creating a new journal entry from this memorized journal.

    Reference

    A short note to identify the purpose of the journal entry or to record information like check numbers.

    Basis

    Related Privileges

    Group Privilege Column
    Accounting Set journal basis (cash or accrual) Enabled

    For more information, refer to Control User Access.

    The accounting method for how the journal entry affects financial reports.

    Cash

    The journal entry affects only reports run in a cash accounting basis. All transactions are recorded when cash is paid or received, and unpaid invoices and expenses are not included in financial reports.

    Accrual

    The journal entry affects only reports run in an accrual accounting basis. All transactions are recorded as they are incurred, and unpaid invoices and expenses are included in financial reports.

    Both

    The journal entry affects all reports.

    Period Adjustment

    Notes that this journal entry is an adjusting entry. This allows for the entry to optionally be excluded from financial reports.

    Description

    An explanation of the use case for the memorized journal template.

    Memo

    A longer note to provide further information about the purpose of the journal entry transaction (e.g., Security Deposit Transfer).

  4. In the bottom section, click Add Item to add as many line items as needed and enter the following information for each.

    Column Description

    Account

    The GL account to adjust with this journal entry.

    Property

    The property involved in the account adjustment.

    Unit

    If applicable, the unit associated with the account adjustment.

    Job

    If applicable, the name of the job to track the journal entry. For more information, refer to Jobs (Page).

    Related Preferences

    To create jobs in Rent Manager, you must check Enable job costing in system preferences. For more information, refer to General Options (System Preferences).

    Debit

    The amount that debits the specified account. Debits increase asset and expense accounts.

    Credit

    The amount that credits the specified account. Credits increase income, equity, and liability accounts.

    Memo

    An optional additional message regarding this account adjustment (e.g., Asset Depreciation, Security Deposit Transfer, Company Payroll).

  5. To finish, click Save & Close, or to create additional memorized journals, click Save & New.
    The memorized journal template is created. To auto-populate the memorized details, when creating a new journal entry, click Load Memorized.
