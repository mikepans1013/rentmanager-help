# Reset a Tenant's TWA Password

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/Tenant-TWA-Password-Reset.htm

If a tenant or prospect's web user account password in Tenant Web Access (TWA) has been compromised or lost, you can initiate a password reset for them. The password reset prompts the tenant or prospect to create a new password for their Tenant Web Access account.

 The account recovery email prompting the password reset is sent to the tenant or prospect's email address assigned to their Tenant Web Access username.

 More Information

 A tenant can also reset their password from the Tenant Web Access web portal. To do so, the tenant can click on their name in the top right corner, then go to User Profile and click Change Password .

 You can initiate a password reset for a tenant's or prospect's web user account by doing the following:

 -
 Depending on the account you wish to reset, go to the corresponding page below:

 Entity Type
 Navigation

 Tenant

 arrow_forward Rental Info arrow_forward  General arrow_forward Tenants and select a tenant from the list.

 Prospect

 arrow_forward Rental Info arrow_forward  General arrow_forward Prospects and select a prospect from the list.

 The tenant's or prospect's details page displays.

 -
 On the action bar to the right, click arrow_forward TWA Settings .

 -
 In the Web Users section, go to the web user's email in which the password is to be reset, and click arrow_forward Change Password .

If the email address is linked to another web user account, the password is reset for all linked accounts linked to the email web user.

 -
 Click Change Password to confirm the action.
A confirmation email is sent to the tenant or prospect, prompting them to complete the update.

 More Information

 For security reasons, the email is valid for only fifteen minutes after being sent. If the email needs to be sent again, you can do so by clicking arrow_forward Change Password again.
