# Add a Prospect Email History/Note

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/Prospect-History-Notes-Add-Email.htm

Prospect history/notes record information that supplements or clarifies information entered in other fields in Rent Manager , such as notes about communication with prospects, transactions, and prospect status updates. Rent Manager automatically creates some history/note items at the system level. You can also record email correspondence with prospects as history/notes.

 To add a new prospect email history/note, do the following:

 -
 Go to arrow_forward Rental Info arrow_forward General arrow_forward Prospects and select the prospect to which you want to add an email history/note item.
The prospect's details page displays.

 -
 On the action bar to the right, select arrow_forward Add Email .

 -
 Enter the desired information about the note.

 Field
 Description

 Completed

 Indicate the email's needs are all addressed.

 End Date and Time

 The date and time the subject of the email was resolved. When you check the box, the current date and time populate by default.

 If the history/note item requires further action, check the box and enter a date by which a follow-up on this item should be completed. If needed, this time can be changed in the Follow-up Date field, as it directly affects when scheduled follow-up reminders display.

 Related Preferences

 Set a default follow-up time in personal preferences for the history/note item created when items are added to your calendar. For more information, refer to Calendar Options (Personal Preferences) .

 Once saved, the Created By field displays on the history/note item to distinguish which user initiated the follow-up. A task is also created. For more information, refer to Tasks (Page) .

 More Information

 The user who created the follow-up is also tasked with completing the follow-up and receives reminders via the Dashboard . For more information, refer to My Dashboards (Page) .

 To designate this follow-up as completed, click Follow-up Completed . The history/note item updates with the Completed date and the Followed-up By user, and the task is closed.

 History Category

 The user-created category used to filter history/note items and report results. You can also use these categories to allow Tenant Web Access (TWA) users to view specific email history/note items in their portal. For more information, refer to Tenant Web Access History/Notes (System Web Preferences) .

 Lock Information

 Prevents other users from editing the history/note item.

 Related Preferences

 To remove the ability to lock history/note items, Disable locking of History/Notes must be enabled in system preferences. For more information, refer to General Options (System Preferences) .

 Note

 Any information about the history/note item describing the event, interaction, or message.

 Pin

 If checked, the history/note item displays first in the History/Notes pop-up as pinned .

 Show on payments tab

 Adds the Note to the Add Payment page under the Summary section in the Payment Notes field. For more information, refer to Prospect Payments (Pop-Up) .

 Start Date and Time

 The date and time the email was sent or received. When you open the Email Details pop-up, the current date and time populate by default.

 Click Save .
