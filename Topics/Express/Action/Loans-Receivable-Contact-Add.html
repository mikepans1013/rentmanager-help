Add Borrowers to Loans Receivable

Owner-financed loans are typically used for home sales but can also be used for other loan types such as for land, equipment, appliances, auto, and so on. The loans receivable tool provides the ability to set up the terms and conditions of internal loans. Rent Manager makes it easy for you to add additional borrowers, in the form of contacts, to a loan and account for each individual responsible for paying the loan off.

To add contacts to a loan receivable, do the following:

  1. Go to arrow_forward Receivables arrow_forward Loans Receivable arrow_forward Loans Receivable and select a loan from the list.
    The loan's details page displays.

  2. On the action bar to the right, click arrow_forward Contacts.
    The Loan Contacts pop-up displays.

  3. Click Add Contact.

    More Information

    To save time with manual entry, click  Copy From Tenant to prefill the fields with the information on the tenant's details page.

  4. In the General tile, enter information into the following fields:

    Field Description

    Birthday

    The contact's date of birth.

    First Name

    The contact's given or preferred name.

    Generation

    If needed, additional information to use as a suffix for the contact's name (such as Junior, Senior, II, or III).

    Last Name

    The contact's surname.

    Middle Name

    The contact's middle name or initial.

    Occupation

    The contact's current job.

    Phone

    The contact's phone number. This is the number used to call this contact when making calls from Rent Manager.

    Primary Borrower

    Indicates that the contact information is for the person named on the loan. The Primary Borrower's information is used when generating tax forms in Rent Manager.

    Residence

    Whether the contact Owns or Rents their current residence.

    Soc Sec #

    The contact's social security number. For commercial tenants, the field name of Tax ID displays, and the contact's tax identification number (TIN) should be entered.

    Related Privileges

    Group Privilege Column
    Tenants/Prospects View complete tenant SSNs Enabled

    For more information, refer to Control User Access.

  5. In the Address tile, enter the location details for the contact's place of residence.

    More Information

    For contacts that share the same address as the primary borrower, click Copy From Primary Borrower to prefill the fields with the address information.

  6. In the Options tile, make selections in the following fields:

    Field Description

    ECOA

    The Equal Credit Opportunity Act code to identify the type of borrower account.

    Indicator

    The indicator code to identify the borrower's address type.

  7. In the Employer Information tile, enter information into the following fields:

    Field Description

    City

    The city where the contact's current employer is located.

    Name

    The name of the contact's current employer.

    State

    The state where the contact's current employer is located.

    Street

    The street address of the contact's current employer.

    Zip

    The zip or postal code of the contact's current employer.

  8. Click Save.
    The new contact is added as a borrower to the loan.
