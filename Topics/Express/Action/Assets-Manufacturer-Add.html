Add an Asset Manufacturer

Creating asset manufacturers and then assigning an asset to a manufacturer as part of asset management can help you provide more information about the asset, filter your assets list by manufacturer, and run reports on assets based on selected manufacturers.

Related Privileges

Group Privilege Column
Asset Management Asset Manufacturers Add, View

For more information, refer to Control User Access.

To add a new asset manufacturer, do the following:

  1. Go to arrow_forward Administration, then go to Rental Info arrow_forward Assets arrow_forward Asset Manufacturers.
    The Asset Manufacturers page displays.

  2. Click Add Asset Manufacturer.

  3. Enter the following information:

    Field Description

    Address

    The address of the manufacturing company.

    Comment

    Optionally, enter a comment about the manufacturer.

    Default

    Select this option to make this the Default address for the manufacturing company.

    Email

    The email address used to contact the manufacturing company.

    Name

    The name of the manufacturing company.

    Phone

    The primary phone number used to contact the manufacturing company.

    Website

    The URL of the manufacturing company's website.

  4. Click Save & Close to add the asset manufacturer and close the pop-up. Alternatively, click Save & New to add the asset manufacturer and begin adding another asset manufacturer.
