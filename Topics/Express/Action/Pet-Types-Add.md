# Add a Pet Type

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/Pet-Types-Add.htm

In Rent Manager , you can track the pets owned by your tenants and prospects to make the process of charging pet fees and pet deposits easier. Before you can begin tracking pets, you must first create pet types to classify the different species of animals that are allowed to be kept by tenants as pets.

 For example, if your properties allow tenants to keep dogs and cats, you could create one pet type for dogs and another for cats so that all pets tracked in Rent Manager are grouped under one of those categories. Additionally, if you allow tenants to keep dogs but charge a different fee or deposit based on its size, you can create a pet type for small dogs and another for large dogs.

 Pet types can also be used to track recurring or one-time charge amounts as well as deposit amounts associated with owning each type of pet. The charge types used for each pet-related charge are configured in the Tenant Charge Setup system preferences. For more information, refer to Tenant Charge Setup (System Preferences) .

 To add a pet type, do the following:

 -
 Go to arrow_forward Rental Info arrow_forward Rental Info Setup arrow_forward Tenants/Prospects arrow_forward Pet Types .
The Pet Types page displays.

 -
 At the top of the page, click Add Pet Type .

 -
 Enter the following information in the available fields:

 Field
 Description

 Name

 The name of the pet type (e.g., Cat , Dog , Bird ).

 Description

 An optional message about the pet type (e.g., weight limit 75 lbs ).

 Properties

 The property at which this type of pet is allowed.

 Recurring Amount

 The dollar amount of the recurring pet fee.

 Check Charge per pet if a separate recurring charge should be created for each pet of this type owned by the tenant.

 Optionally, enter a dollar Max Amount to put a cap on the amount that can be charged to a tenant each month for owning multiple pets of this type.

 One Time Fee Amount

 The dollar amount of the one-time fee for the pet type.

 Check Charge per pet if a separate charge should be created for each pet of this type owned by the tenant.

 Optionally, enter a dollar Max Amount to put a cap on the amount that can be charged to a tenant for owning multiple pets of this type.

 Pet Deposit Amount

 The dollar amount of the pet deposit.

 Check Charge per pet if a separate deposit should be created for each pet of this type owned by the tenant.

 Optionally, enter a dollar Max Amount to put a cap on the amount that can be charged to a tenant for owning multiple pets of this type.

 -
 To finish, click Save & Close , or to add additional pet types, click Save & New .
The new pet types(s) is added to Rent Manager .
