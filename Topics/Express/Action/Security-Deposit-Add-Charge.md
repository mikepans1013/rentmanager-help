# Add a Security Deposit Charge

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/Security-Deposit-Add-Charge.htm

Security deposits require their own tracking and must be entered into the appropriate liability account(s). Express makes it easy to enter a new security deposit charge on a tenant or prospect account and ensures it is recorded correctly in your finances and on the individual tenant or prospect account. While entering the security deposit charge, you can record the payment in the same window by selecting the appropriate options for payment type and when the payment was processed.

 More Information

 Funds display as security deposits on reports if the following conditions are met:

 -
 The charge type(s) you use to record security deposits are set up as security deposit charge types in system preferences. For more information, refer to Security Deposit General Options (System Preferences) .

 -
 The security deposit charge is created on the tenant's account and a payment is allocated to the charge.

 -
 The unit selected in the Unit field is linked to same unit where the security deposit is being held.

 To add a security deposit charge to an account, do the following:

 -
 Go to the corresponding page below and select the tenant or prospect account:

 Entity Type
 Description

 Tenant

   arrow_forward Rental Info  arrow_forward General  arrow_forward Tenants and select a tenant account

 Prospect

   arrow_forward Rental Info arrow_forward General arrow_forward Prospects and select a prospect account

 The details page for the tenant or prospect displays.

 -
 On the action bar to the right, click arrow_forward Add Security Deposit .
The Add Security Deposit pop-up displays.

 -
 Enter or select the deposit information into the following fields:

 Field
 Description

 Amount

 The total value of the security deposit being applied to the tenant or prospect account.

 Date

 The date on which the security deposit charge is posted.

 If the tenant or prospect's security deposit payment was received prior to your company using Rent Manager , check Deposit Prior to GL Start Date . This informs Rent Manager that the tenant or prospect's security deposit is accounted for in the property's beginning balances when the database was set up and implemented without duplicating the payments.

 Deposit Type

 The security deposit charge type to apply to the deposit.

 Related Preferences

 This field displays security deposit charge types established in your system preferences. For more information, refer to Security Deposit General Options (System Preferences) .

 Payment Received

 Creates a new payment transaction with the same Date and Amount entered for the security deposit charge. When this field is checked, the following fields are available:

 Memo

 Information put in this field displays in the Comment field of the payment's transaction details.

 Process via ePay

 Processes a payment using the ePay on file for the selected tenant or prospect to pay the security deposit. This option is available only if the tenant is set up for ePay . For more information, refer to Set Up ePay for Tenants and Prospects .

 Reference #

 The check number or the payment method used to pay the security deposit charge.

 View Receipt

 Generates a printable Payment Receipt document after saving the security deposit, at which point you are prompted to select the document's file type (PDF, HTML, Text, or Excel).

 Unit

 The unit associated with the security deposit.

 More Information

 It is recommended that you tie the security deposit to the unit, not just the property. If the security deposit is tied only to the property, it is not included in a number of Rent Manager reports (e.g., Security Deposit Activity , Summary Rent Roll ).

 -
 Click Save to record the security deposit and any selected payment options on the entity's account. Alternatively, click Save & New to finish adding the security deposit and refresh the pop-up to add another security deposit.
