 For more information, refer to Control User Access .

 To add a new one-time charge to the account, do the following:

 -
 Go to   arrow_forward Rental Info arrow_forward General arrow_forward Prospects and select a prospect from the list.
The prospect's details page displays.

 -
 Select   Add   arrow_forward Add Charge .
The Transaction Details pop-up displays.

 -
 Enter the desired information about the charge.

 Field
 Description

 Charge Type

 Select the charge type to be associated with this charge.

 Unit

 Select the property with which the charge is associated.

 Date

 Enter the date for when this charge is due.

 Amount

 Enter the desired recurring charge Amount .

 More Information

 To automatically prorate the charge based on the charge date, enter the full amount of the charge and then click Prorate .

 In the Days Prorated field, the number of days left in the month automatically populates. This number can be adjusted if needed. The Full Charge Amount displays the charge entered, with the prorated calculation appearing in the Prorated Amount field. If the Full Charge Amount is changed, the Prorated Amount updates to show the calculated amount that is to be charged to the tenant.

 When finished, click Save .

 Comment

 Optionally, enter a note about the charge.

 Reference #

 Optionally, enter a unique number or phrase to help identify the charge.

 -
 Click Save .
The charge is added to the View Transactions page.
