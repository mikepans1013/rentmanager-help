Advance an Eviction

The eviction process can be long and include a number of steps before it can be completed. The advance action in the eviction workflow is intended to help you easily move through each stage the process. The amount of times you can advance an eviction is based on how many stages were added to the eviction workflow associated with a property.

For more information, refer to Control User Access.

To advance an eviction, do following:

  1. Go to arrow_forward Rental Info arrow_forward Tenants and select the tenant in the eviction process.
    The tenant's details page displays.

  2. Click Advance on the Eviction tile.

  3. Enter the date on which the stage change takes place. By default, today's date displays.

  4. To add a eviction type system note about this stage change, click Add Eviction Note. The note is saved on the tenant's History/Notes pop-up and on the All Evictions pop-up, in the Eviction Notes section.

  5. Click Advance.
    The eviction is advanced to the next stage in the process and any fields that apply to the stage are available on the Eviction tile
