# Add a Secondary Tenant ePay Account

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/Tenant-ePay-Secondary-Account-Add.htm

Rent Manager allows you to enter a tenant's bank account or card details into Rent Manager to process batch payments or utilize recurring ePay automation. If a tenant also has an alternative payment method they would like to use in case their primary payment method fails or for use in manual one-time ePay payments, you can add a secondary ePay account from the ePay Settings pop-up.

 More Information

 Secondary ePay accounts can be added only for tenants who already have an ePay account or card on file in Rent Manager . For more information, refer to Set Up ePay for Tenants and Prospects .

 To add an additional ePay account for a tenant, do the following:

 -
 Go to arrow_forward Rental Info arrow_forward General arrow_forward Tenants and select a tenant with an existing ePay account.
The tenant's details page displays.

 -
 On the action bar to the right, select arrow_forward ePay Settings and enter your ePay Password if prompted.
The ePay Settings pop-up displays.

 -
 In the Default Account Information section, click Add Secondary Account Information .
The Add Secondary Account Information pop-up displays.

 -
 In the Account Type field, select the desired payment type from the drop-down list. The fields that populate depend on the option selected.

 More Information

 The payment options in this field are dependent on your contract with Zego . For example, your company may have the ability to process payments for credit cards but not debit cards. If you are unsure which account types are available to you, contact your Zego representative.

 -
 Enter the bank account or card information in the fields described below.

 Field
 Description

 First Name

 The first name associated with the bank account or card.

 Last Name

 The last name associated with the bank account or card.

 Account Number

 The full bank account number. This field displays only if, in the Account Type field, ACH - Checking or ACH - Savings is selected.

 Routing Number

 The full routing number for the bank account. This field displays only if, in the Account Type field, ACH - Checking or ACH - Savings is selected.

 Card Number

 The full credit or debit card number. This field displays only if, in the Account Type field, Credit Card or Debit Card is selected.

 Exp Month

 The expiration month of the credit or debit card. This field displays only if, in the Account Type field, Credit Card or Debit Card is selected.

 Exp Year

 The expiration year of the credit or debit card. This field displays only if, in the Account Type field, Credit Card or Debit Card is selected.

 CVV2

 The credit or debit card's three-digit card security code. This field displays only if, in the Account Type field, Credit Card or Debit Card is selected.

 Type

 The associated card company, determined by the prefix of the Card Number . This field is read-only and displays only if, in the Account Type field, Credit Card or Debit Card is selected.

 -
 Click Save .
The secondary ePay account is added to the tenant account and can be used when processing one-time ePay payments.

 More Information

 If the tenant decides to use their secondary ePay account as their default account instead, you can open the ePay Settings pop-up and, on the Secondary Account Information tile, select arrow_forward Set as default .
