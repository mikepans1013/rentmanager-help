Add Maintenance Group Exceptions

With the Maintenance Schedule feature, you can group properties and maintenance technicians together on one maintenance schedule, making it easier to view tech availability and schedule service visits. When you need to add one-time changes to the availability schedule for a maintenance group, such as for office holidays or when the full maintenance team is scheduled for mandatory training, you can create a group exception. Group exceptions prevent the scheduled times from being booked for maintenance visits on the Maintenance Schedule calendar and on Tenant Web Access (TWA).

To add an exception to a maintenance group, do the following:

  1. Go to one of the following pages:

    Page Description

    Maintenance Group

    arrow_forward Services arrow_forward Service Setup arrow_forward Service Manager arrow_forward Maintenance Groups. Select a maintenance group and click Add Group Exception.

    Maintenance Schedule

    arrow_forward Services arrow_forward Service Manager arrow_forward Maintenance Schedule. Click Time Off and then, on the Time off/Exceptions pop-up, select the Group Exception tab. In the Maintenance Group field, select the maintenance group in which to add an exception.

  2. Enter the applicable information on the pop-up.


    Field Description

    From Date

    The day on which the time off is scheduled to begin.

    To Date

    The day on which the time off is scheduled to end.

    All Day

    Check to block the full day for each day between the From Date and To Date.

    Start Time

    The time of day on which the scheduled time off takes effect.

    Hours Per Day

    The total number of labor hours that are scheduled off per day.

    Description

    An optional explanation of the reason for the time off.

  3. If applicable, click Add to add additional hours. For example, if the maintenance group is scheduled for the second half of a Monday and the first half of a Tuesday, you can first set hours for Monday, then click Add to set different hours for Tuesday.

  4. Click Save to complete the maintenance group exception creation process and close the pop-up. Alternatively, click Save & New to finish adding the group exception and refresh the pop-up to add another one.
    The maintenance group's time off is added to the Maintenance Schedule page. The applicable time blocks display in red, and maintenance visits cannot be booked during these times.
