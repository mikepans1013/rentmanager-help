Reopen an Eviction

In the event that an eviction was closed before it reached completion in real life, Rent Manager allows you to easily reopen the eviction. Evictions that are reopened maintain all of the historical information from previous evictions, preventing the need to duplicate the same information in a new eviction process.

Related Privileges

Tenants/Prospects Tenant Eviction Edit

For more information, refer to Control User Access.

To reopen a closed eviction, do the following:

  1. Go to  arrow_forward Rental Info arrow_forward Tenants and select the tenant in the eviction process.
    The tenant's details page displays.

  2. Click on the All Evictions tile.
    The All Evictions pop-up displays.

  3. In the top right of the pop-up, click and select Reopen.

  4. If you wish to continue after reading the message on the pop-up, click Reopen.
    The Reopen Eviction Process pop-up closes and the eviction is successfully reopened. The Eviction tile once again displays on the top of the tenant's details page.
