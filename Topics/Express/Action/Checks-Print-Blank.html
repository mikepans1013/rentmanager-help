Print Blank Checks

Rent Manager allows you to print a check that includes only the check number and bank account information. For example, if a vendor was coming on site to do an evaluation but didn't provide a bill upfront, you can print a blank check and fill in the recipient and dollar amount by hand once you have the total due for the visit.

More Information

To print blank checks, the bank you wish to print the check from must be enabled with MICR. For more information, refer to Set Up MICR for Checks and Deposits.

Related Privileges

Group Privilege Column
Banks/Checks Print Checks Enabled
Print blank checks Enabled

For more information, refer to Control User Access.

To print blank checks, do the following:

  1. Go to arrow_forward Payables arrow_forward Checks arrow_forward Print Checks.
    The Print Checks page displays.

  2. On the Print button, click the drop-down arrow and select Print Blank Checks.
    The Print Blank Checks pop-up displays.

  3. In the Bank field, select the desired bank account from which checks are drawn.

    Related Privileges

    This field populates with only banks to which you have access. Your access to banks can be managed on the user's details page. For more information, refer to Limit Access to a Bank or Credit Card.

  4. If applicable, in the First Check Number field, enter the check number of the first blank check you are printing. If you are printing multiple blank checks, Rent Manager numbers each check starting with this number. By default, the next available check number at the selected bank displays.

    Related Privileges

    Group Privilege Column
    Banks/Checks Override sequential check number enforcement Enabled

    For more information, refer to Control User Access.

  5. In the Number of checks field, enter how many blank checks you wish to print.

  6. Click Print.
    A pop-up displays with the print options from your web browser, where you can select the printer and settings to use for printing the check(s).
