Advance an Asset Workflow

Related Privileges

Group Privilege Column
Asset Management Asset Statuses View
Manage Assets View, Edit

If the asset is a home and is linked to a unit, the following privilege is also required:

Group Privilege Column
Properties/Units Units View, Edit

For more information, refer to Control User Access.

To advance an asset to the next status in a workflow, do the following:

  1. Go to arrow_forward Rental Info arrow_forward General arrow_forward Assets and select an asset from the list.

  2. On the Asset Status History tile, click .
    The View Asset Status pop-up displays.

  3. Click arrow_forward Advance Workflow.

  4. Enter the following information:

    Field Description

    Status

    Select the next status to which you want to advance this workflow.

    Date

    The date on which the change is added.

    Comment

    An optional comment explaining the workflow advancement.

  5. Click Save.
