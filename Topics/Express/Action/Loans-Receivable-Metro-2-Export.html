Export Loans Receivable to Metro 2

The Metro 2 tool enables Rent Manager users to export loan data in Metro 2 format, which is suitable for import by the major credit reporting bureaus. You can export data for a defined posting period for multiple agencies, ensuring that each credit bureau receives accurate reporting on your tenants' accounts.

Warning

In order to export to Metro 2, you must first set up Metro 2 preferences. For more information, refer to Metro 2 Reporting (System Preferences). Additionally, Metro 2 requires contact information for each loan. If contact information is missing, the loan is skipped in the export. The Export Summary's Message column indicates what information must be updated to export successfully. For more information, refer to Add Borrowers to Loans Receivable.

Related Privileges

Group Privilege Column
Metro 2 Create Metro 2 Exports Enabled

For more information, refer to Control User Access.

To export loans receivable data to Metro 2, do the following:

  1. Go to  arrow_forward Receivables arrow_forward Loans Receivable arrow_forward Export to Metro2.
    The Export to Metro2 pop-up displays.

  2. Select each property or property Group to be included in the export.

    More Information

    Only information related to the properties to which you have access displays. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property.

  3. In the Agencies to Include field, select the agencies to provide credit reporting data to.

  4. In the Posting Period fields, select the Month and Year you wish to export data for.

  5. In the Export File Name field, enter a unique name that is included in all exported files (this field displays exportToMetro2.txt by default). For example, if you select the Equifax agency and use the default file name, the file that exports is named EquifaxexportToMetro2.txt.

  6. Click Export.
    The files are exported and the Export Summary pop-up displays. To view the Export Summary report, which provides details on any errors that occurred during the export process, click Yes. Otherwise, click No to close the pop-up.
