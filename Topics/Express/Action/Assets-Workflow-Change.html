Change an Asset Workflow

Asset workflows guide an asset through a series of statuses, which allows you to track the asset's progress through a process, such as purchasing, maintenance, or sales. You can create multiple workflows depending on business needs. For example, you might use one workflow for maintenance tasks that are under warranty by the manufacturer and then another for tasks handled by your in-house team.

From the Change Workflow pop-up, you can edit the workflow name, status, and description.

For more information, refer to Control User Access.

To change the workflow to which the asset is currently assigned, do the following:

  1. Go to arrow_forward Rental Info arrow_forward General arrow_forward Assets and select an asset from the list.
    The asset's details page displays.

  2. On the action bar to the right, click arrow_forward Change Workflow.

    More Information

    If the asset does not currently have a workflow assigned, the action item displays Assign Workflow.

  3. Enter the following information:

    Field Description

    Comment

    An optional comment explaining the workflow advancement.

    Date

    The date on which the change is added.

    Status

    The status that you want to change the workflow to. Only statuses set as a Starting Status in the workflow display in the search.

    Workflow

    The workflow you want to set for this asset.

  4. Click Save.
    The asset workflow is updated for the selected asset.
