# Delete an Issue Category

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/Issues-Category-Delete.htm

The primary reason to delete an issue category is that it was added in error and you want to remove the entry so that the category is unavailable for use. If an issue category is linked to a service issue, it cannot be deleted.

 Warning

 Deleting an issue category is permanent and cannot be undone. If you no longer wish to use the category, instead of deleting it, consider marking it as inactive. This allows you to retain the information attached to that issue category while removing it from available categories for future issues. To make an issue category inactive, on the Edit Issue Category pop-up, uncheck Active .

 To permanently delete an issue category, do the following:

 -
 Go to arrow_forward Services arrow_forward Service Setup arrow_forward Service Manager arrow_forward Issue Categories .
The Issue Categories page displays.

 -
 To the right of the issue category, click arrow_forward Delete .
 The Confirm Delete pop-up displays.

 -
 Click Yes .
The category is removed from the Issue Categories page.
