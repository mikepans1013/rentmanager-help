# Add a Contact Type

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/Contact-Type-Add.htm

Tenants, prospects, and vendors generally have contacts, such as cosigners, additional occupants, family members, business associates, and so on. By creating contact types, you can categorize contacts into groups, determine how they are associated with an account, and provide a breakdown of these individuals as your business requires. For example, when multiple tenants occupy the same unit, such as in student housing, you can create a contact type specifically for roommates. The contact type groups the occupants under one type to make sending violation or renewal notices easier, so you don't have to manually send notices to each individual occupant. Contact types can also be used in online applications so that applicants' contact numbers are automatically sorted by type.

 To add a contact type, do the following:

 -
 Go to arrow_forward Administration , then go to Rental Info arrow_forward Tenants/Prospects arrow_forward Contact Types .
The Contact Types page displays.

 -
 Click Add Contact Type .

 -
 Enter the following information for the new contact type:

 Field
 Description

 Type

 The entity type(s) with which the contact type is associated. For example, if you select Vendor in this field, the contact type can be selected for vendor contacts but cannot be selected for tenant or prospect contacts, and vice versa.

 Name

 A unique identifier to differentiate this contact type from other contact types. This name identifies the contact throughout Rent Manager , such as when choosing email recipients on the Batch Email page.

 Description

 A short summary to provide clarification on when to use this contact type.

 -
 To finish, click Save & Close , or to create additional contact types, click Save & New .
The contact type is saved to the Contact Types page and is available for use.
