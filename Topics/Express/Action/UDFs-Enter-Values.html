Enter User Defined Field Values

User defined fields (UDFs) are custom fields used to track information that Rent Manager does not track by default, such as insurance expiration dates for tenants, key codes for units, parcel IDs for properties, and contract start/end dates for vendors. Each Rent Manager entity (e.g., prospect, asset, service issue, loan, etc.) can have a unique set of UDFs. While each account within an entity shares the same set of UDFs, the values are specific to the selected account.

Additionally, to enter values for encrypted UDFs, you need privileges for each entity type in the User Defined Fields privilege group (e.g., Access Tenant encrypted UDFs).

For more information, refer to Control User Access.

To enter values for an entity's UDFs, do the following:

  1. Go to the details page of the account for which you wish to enter a UDF value.

    More Information

    If you need to enter a value for a system-level UDF, go to arrow_forward Administration, then go to Customization arrow_forward System UDF Values.

  2. On the UDFs tile, click .
    The User Defined Fields pop-up displays.

  3. Enter or select the Value for each desired UDF.

  4. Click Save.
    The UDF value(s) are updated.
