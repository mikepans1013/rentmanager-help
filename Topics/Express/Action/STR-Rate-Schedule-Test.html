Test a Short Term Rental (STR) Rate

Short term rental (STR) rate schedules allow you to maintain rates used to charge for reservations, providing you with an easy way to calculate STR rates. Once a STR rate is added, you are able to test the rate and ensure all the settings enabled are calculating as expected. STR rates can be tested from the property's details page.

Warning

To access the STR tool, at least one of your properties in Rent Manager must have the RV/Campground property type assigned.

Related Privileges

Group Privilege Column
Properties/Units Properties Edit, View
Manage STR Rate Schedules Enabled

For more information, refer to Control User Access.

To test a STR rate, do the following:

  1. Go to arrow_forward Rental Info arrow_forward General arrow_forward Properties and select a property from the list.
    The properties details page displays.

  2. On the STR Rate Schedules tile, click and select a rate schedule from the list.
    The STR Rates pop-up displays.

  3. Click Test Rate.

  4. In the Reservation Info tile, enter any applicable information into the following fields.

    Field Description

    Arrival

    The date the guest plans to arrive.

    Departure

    The date the guest plans to leave.

    # of Nights

    Rent Manager automatically calculates the number of nights between the Arrival date and the Departure date.

    # of Adults

    The number of adults associated with the reservation.

    # of Children

    The number of children associated with the reservation.

    # of Pets

    The number of pets associated with the reservation.

    # of Vehicles

    The number of vehicles associated with the reservation.

    Discount

    The discount that applies to the STR rate. For more information, refer to Add a Short Term Rental Discount.

  5. Click Calculate.
    The Calculated Amount section populates.

  6. In the Calculated Amount section, Rent Manager lists out all the individual, associated fees and provides a Total of all applicable fees and credits. Review the information in the following fields.

    Column Option

    Charge Type

    The name of the charge type associated with the fee or credit.

    Description

    Provides context to what is being applied to the calculated amount.

    Amount

    The total value of the fee. Discounts display the total value of the credit.

  7. When finished ensuring the rate is calculating how you expect it to, click Close.
    The Calculate Rate Amount pop-up closes.
