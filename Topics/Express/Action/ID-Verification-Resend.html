Resend ID Verification

When utilizing ID verifications in prospect or tenant applications, situations may arise where a new link must be resent to the applicant to retry the identity verification process. The ID verification is done through the Apply Now feature in Tenant Web Access (TWA) and must be completed by the applicant or manually overridden before an income verification can be initiated.

This action can be completed only if the applicant cannot successfully complete the ID verification after three attempts or if the applicant selects My information is correct after an unsuccessful attempt.

More Information

Although the Income and ID Verification feature is accessible within Rent Manager, the company that provides the service is AmRent's partner Ibbie. Registered users can retrieve verification reports that can be instantly viewed or printed. Additionally, Income and ID Verification requires different credentials from AmRent Screenings. For information about getting an account or if you have Income Verification and want to utilize ID Verification as well, contact AmRent by calling 800-324-3681 or emailing info@amrent.com.

To resend an ID verification request, do the following:

  1. Go to arrow_forward Rental Info arrow_forward Leasing arrow_forward Applications and select an application.
    The application's details page displays.

  2. In the Applicants tile, for the applicant to whom the ID verification is to be resent, click arrow_forward Resend ID Verification.

  3. Click Resend.
    The ID verification invitation is sent to the selected contact.
