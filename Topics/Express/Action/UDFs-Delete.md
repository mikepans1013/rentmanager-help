# Delete a User-Defined Field

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/UDFs-Delete.htm

The primary reason to delete a user-defined field (UDF) is that it was added in error and you want to remove the entry so that the UDF is unavailable.

 Warning

 Deleting a UDF is permanent and cannot be undone. If you delete a UDF it results in the deletion of that UDF throughout Rent Manager , including any data entered for accounts of the UDF type.

 Related Privileges

 Group
 Privilege
 Column

 User Defined Fields
 User defined fields
 View, Delete

 For more information, refer to Control User Access .

 To permanently delete a UDF, do the following:

 -
 Go to arrow_forward Administration , then go to Customization arrow_forward User Defined Fields .
The User Defined Fields page displays.

 -
 For the UDF you wish to delete, click arrow_forward Delete .
The Confirm Delete pop-up displays.

 -
 Click Yes .
The UDF is removed from the list.
