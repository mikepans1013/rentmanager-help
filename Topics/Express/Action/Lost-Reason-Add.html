Add a Lost Reason

If a prospect decides not to rent from you, or if you reject a prospect's application, you mark a prospect as Lost or Lost/Rejected. While designating the prospect as lost, you can select a Reason from a drop-down menu of options that explains why that prospect is no longer a lead. You can add any number of lost reasons to Rent Manager to account for the variety for situations that a prospect does not become a tenant.

Related Privileges

Group Privilege Column
Tenants/Prospects Manage Lost Reasons Enabled

For more information, refer to Control User Access.

To add a lost reason, do the following:

  1. Go to  arrow_forward Rental Info arrow_forward Rental Info Setup arrow_forward Tenants/Prospects arrow_forward Lost Reasons.
    The Lost Reasons page displays.

  2. Click  Add Lost Reason.
    The Add Lost Reason pop-up displays.

  3. Enter the following information about the lost reason:

    Field Description

    Active

    Allows the lost reason to be available to use. By default, this option is checked.

    Description

    A brief explanation of the reason. For example, for a lost reason named Price, the Description could be Unit(s) were outside the prospect's price range.

    Name

    The unique name for the lost reason (e.g., Price, Unit Unavailable, Rented Elsewhere).

    Status

    One of two system-generated outcomes of the prospect's application. For example, for a lost reason named Evictions, the status can be Lost-rejected because you decided not to rent to the tenant on account of their eviction record.

    Lost

    		 The prospected chooses not to rent from you.
    Lost-rejected You choose not to rent to the prospect.

  4. Click Save & Close to add the lost reason and close the pop-up. Alternatively, click Save & New to add the lost reason and begin adding another lost reason.
