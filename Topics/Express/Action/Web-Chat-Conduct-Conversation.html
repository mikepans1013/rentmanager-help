Conduct a Web Chat Conversation

Web Chats in which you are participating and queues of which you are part display in the My Conversations page. From this page, you can log in and out of queues to which you are assigned and conduct web chats with visitors to your sites. Additionally, Web Chat is built directly in to Rent Manager, allowing you to quickly access information in your database. For example, if a tenant sends a message to you regarding a maintenance problem, you can quickly create a service issue tied to their account. The tenant's account information is populated within the issue ticket, and the conversation is automatically saved on their History/Notes tile.

Even while logged into Web Chat queues, you can navigate to other areas of Rent Manager and be available to answer chat requests. If a new request or response is submitted to a queue you are logged into, you receive a red notification dot on the icon at the top right of Rent Manager Express. You can click this icon at any time to be redirected back to the My Conversations page.

Group Privilege Column
Web Chat Queues View

For more information, refer to Control User Access.

To conduct a conversation through Web Chat, do the following:

  1. Go to arrow_forward Communication arrow_forward Web Chat arrow_forward My Conversations.
    The My Conversations page displays.

  2. In the Queues tile, click Login for each queue from which you need to accept Web Chat conversations.

    More Information

    In order to start a Web Chat conversation from the My Conversations page, the following privileges on the Manage Queues page are required for the associated queue depending on the action you wish to take:

    • To start the next chat, you must have Agent checked on the Chat Agents tile.

    • To start any chat in the list, you must have Admin checked on the Chat Agents tile.

    For more information, refer to Manage Queues (Web Chat) (Page).

  3. On the Pending Conversations tile, click  arrow_forward Start Conversation on the chat request you wish to answer.
    The chat opens in a new tile on the right side of the page. Multiple conversation tiles can display on the page at the same time.

  4. Type your reply in the available text field.

    You can click to select one of the Saved Replies from the list to populate the text field with a preset answer established for the queue. For more information, refer to Manage Queues (Web Chat) (Page).

    Click to browse your computer for an image file to insert into the chat.

  5. If applicable, perform any necessary Actions for the chat. There are multiple actions which can be taken during a Web Chat. The actions available are determined on the Manage Queues page.

    Action Description

    Transfer

    Transfer the active conversation to another agent in the same queue. This action is always available.

    On the Transfer Conversation pop-up, enter or select the agent to which you wish to assign the chat and, optionally, enter a comment explaining the reason for the transfer, then click OK.

    Add Appointment

    Related Privileges

    Group Privilege Column
    Setup Appointments Add, View, Edit

    For more information, refer to Control User Access.

    Create an appointment to be added to the calendar in Rent Manager. For more information, refer to Add an Appointment.

    Add Issue

    Related Privileges

    Group Privilege Column
    Service Manager Issues Add, View

    For more information, refer to Control User Access.

    Create a new service issue for the chat recipient. For more information, refer to Add an Issue.

    Add Owner Prospect

    Related Privileges

    Group Privilege Column
    Owners Owner Prospects Add, View

    For more information, refer to Control User Access.

    Create an owner prospect account for the chat recipient with their name and email address prepopulated. For more information, refer to Add an Owner Prospect.

    The name and email populate only if the corresponding questions are listed on the Manage Queues page and the recipient entered the information.

    Add Prospect

    Related Privileges

    Group Privilege Column
    Tenants/Prospects Prospects Add, View

    For more information, refer to Control User Access.

    Create a prospect account for the chat recipient with their name prepopulated. For more information, refer to Add a Prospect.

    The name populates only if the corresponding question is listed on the Manage Queues page and the recipient entered the information.

    Add Task

    Related Privileges

    Group Privilege Column
    Setup Tasks Add, View

    For more information, refer to Control User Access.

    Create a new task from the conversation. For more information, refer to Add a Task or Memorized Task.

    Add Vendor

    Related Privileges

    Group Privilege Column
    Payables Vendors Add, View

    For more information, refer to Control User Access.

    Create a vendor account for the chat recipient with their name and email address prepopulated. For more information, refer to Add a Vendor.

    The name and email populate only if the corresponding questions are listed on the Manage Queues page and the recipient entered the information.

  6. Click Send .
    The message is sent to the recipient.

  7. When the chat is finished, click Completed.
    The chat ends and is stored on the Closed Conversations page. For more information, refer to Closed Conversations (Web Chat) (Page).
