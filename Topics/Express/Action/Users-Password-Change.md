# Change Password

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/Users-Password-Change.htm

You can change the password associated with your Rent Manager username at any time to protect your account.

 To change your Rent Manager password, do the following:

 -
 Go to arrow_forward Administration , then go to Users arrow_forward Users .
The Users page displays.

 -
 Select your user account from the list.
The User details page displays.

 -
 On the Personal Information tile, click Change Password .
The Change Password pop-up displays.

 -
 Enter your Current Password (what you currently use to log into Rent Manager ).

 -
 Enter a new password in the New Password and Confirm New Password fields. Your new password must meet the following criteria:

 -
 At least 8 characters long.

 -
 Contain at least one number (0-9).

 -
 Contain at least one lowercase alphabetic character (a-z).

 -
 Contain at least one uppercase alphabetic character.

 -
 Click Save .
Your password is updated.
