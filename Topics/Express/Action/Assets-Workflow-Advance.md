 To advance an asset to the next status in a workflow, do the following:

 -
 Go to arrow_forward Rental Info arrow_forward General arrow_forward Assets and select an asset from the list.

 -
 On the Asset Status History tile, click .
The View Asset Status pop-up displays.

 -
 Click arrow_forward Advance Workflow .

 -
 Enter the following information:

 Field
 Description

 Status

 Select the next status to which you want to advance this workflow.

 Date

 The date on which the change is added.

 Comment

 An optional comment explaining the workflow advancement.

 -
 Click Save .
