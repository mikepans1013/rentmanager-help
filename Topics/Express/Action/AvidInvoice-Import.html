Import Avid Bills

Once vendors submit their bills to AvidXchange, you can load these invoices into Rent Manager. For your convenience, AvidInvoice prepares groups of invoices which can be imported into Rent Manager as batches. Each invoice in the imported batch creates a one-time bill. For any invoices with vendor credits, each credit is also imported.

Related Privileges

Group Privilege Column
Payables Bills Add, View
AvidInvoice Enabled

For more information, refer to Control User Access.

To import an AvidInvoice bill, do the following:

  1. Go to arrow_forward Payables arrow_forward AvidXchange arrow_forward AvidInvoice.
    The AvidInvoice Batches page displays.

    More Information

    If this is the first time using AvidInvoice in Rent Manager, you are prompted to enter a From Date. Enter or select the starting date from which AvidXchange collects and downloads batches of invoices.

    Related Preferences

    The From Date for AvidInvoice can be changed only by resetting the date in AvidXchange system preferences. For more information, refer to AvidXchange (System Preferences).

  2. Select each AvidInvoice batch you wish to import into Rent Manager.

  3. Click Import.
    Each invoice in each selected batch is imported as a one-time bill.

    Warning

    AvidInvoice batches can be imported into Rent Manager only once, so be sure that your selections are correct before importing.

  4. If Link purchase order on imported bills from AvidInvoice is enabled in system preferences and any imported bills are matched to POs and the total bill amount is less than the total PO amount, the Adjust Billing Quantity pop-up displays. To make adjustments to the bills prior to import, click Adjust Billing Quantity. Otherwise, click Don't Adjust to close the pop-up.

  5. Click OK to confirm the import.
    The bill(s) are imported in to Rent Manager and can paid from the Pay Bills page.
