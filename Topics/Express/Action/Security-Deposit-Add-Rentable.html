Request a Rentable Security Deposit

Rentable has teamed up with Rent Manager to streamline the security deposit life cycle, from collection to refunds and withholdings, while ensuring compliance with complex local and state regulations. Using Rentable security deposits allows Rentable to handle the operational and compliance aspects of security deposits in a single connected workflow on behalf of property managers, greatly reducing manual accounting work and risk of errors.

To ensure the payment request link from Rentable is sent to the tenant or prospect, it is best practice to use option to add a security deposit rather than a standard charge. A Rentable security deposit should not be added as a standard charge directly unless to correct a currently held security deposit.

More Information

This feature is licensed and must be purchased separately. For more information, contact your sales representative at sales@rentmanager.com.

Before adding a Rentable security deposit charge to a tenant or prospect, Rentable must be fully enabled and set up for the property. For more information, refer to Set Up Security Deposits with Rentable.

To request a Rentable security deposit, do the following:

  1. Go to the corresponding page below and select the prospect or tenant account:

    Entity Type Description

    Prospect

    arrow_forward Rental Info arrow_forward General arrow_forward Prospects and select a prospect account

    Tenant

    arrow_forward Rental Info arrow_forward General arrow_forward Tenants and select a tenant account

    The details page for the prospect or tenant displays.

  2. On the action bar to the right, click arrow_forward Add Security Deposit.

    More Information

    Click More Options arrow_forward Deposit without Rentable to add a standard security deposit charge to the prospect or tenant that does not utilize Rentable. For more information, refer to Add a Security Deposit Charge.

  3. Verify that the information below is correct.

    Field Description

    Email Address

    The email address of the prospect or tenant to which the security deposit payment request is sent.

    First Name

    The first name of the prospect or tenant to which the security deposit payment request is sent.

    Last Name

    The last name of the prospect or tenant to which the security deposit payment request is sent.

    Lease End

    The date on which the tenant's lease expires, as it displays on the tenant's details page in the Leases tile. If this field is blank on the tenant's details page, then this field is editable.

    Lease Start

    The date on which the lease begins, as it displays on the tenant's details page in the Leases tile.

    Move In

    The date on which the tenant moves into the unit, as it displays on the tenant's details page in the Leases tile.

    Unit

    The name of the unit that the tenant is leasing.

  4. In the Charge Type column, select the charge type to use for this Rentable security deposit.

    Related Preferences

    Only charge types designated as security deposit charge types in system preferences display in the drop-down list. For more information, refer to Security Deposit General Options (System Preferences).

  5. In the Deposit Amount column, enter the dollar amount of the Rentable security deposit.

  6. To add another Rentable security deposit charge, click Add Deposit.

  7. Click Send Deposit Invite.
    An invitation is sent to the tenant or prospect's Email Address to set up an account with Rentable. Once the tenant or prospect has set up an account, they can connect their bank account and pay the security deposit seamlessly online.
