# Override an Owner's Owner Web Access (OWA) Account System Defaults

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/Owners-OWA-Account-Override-System-Defaults.htm

An owner's Owner Web Access (OWA) account can be customized by overriding the system defaults on their individual account. By overriding the system defaults, you can determine what an owner can see in Owner Web Access to meet their specific needs without affecting the accounts of other owners.

 For more information, refer to Control User Access .

 Related Preferences

 To access Owner Web Access settings, at least one location must be enabled for OWA in system web preferences. For more information, refer to Licensing (System Web Preferences) .

 To customize an owner's web access settings, do the following:

 -
 Go to arrow_forward Owners arrow_forward General arrow_forward Owners and select an owner from the list.
The owner's details page displays.

 -
 On the action bar on the right, click arrow_forward OWA Settings .

 -
 Check Override System Defaults .
The Owner Web Access settings can now be customized for the selected web owner account.

 -
 Adjust the information in the available sections to match your preferences for this owner. For more information, refer to Owner Web Access Settings (Pop-Up) .

 -
 Click Save .
The owner's web access settings are updated. The owner's Owner Web Access web portal now only displays the tools and reports you've selected.
