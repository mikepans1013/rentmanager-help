Run a Screening for a Non-Tenant or Prospect

If you need to run a screening for someone but do not need that person associated with a tenant or prospect account in Rent Manager, you can generate one-off screenings from the Screenings page. For example, you may need to run a screening for a tenant's guarantor, but not wish to keep the guarantor's information in your system.

More Information

To run screenings for a tenant or prospect account and attach that screening to their account, refer to Run a Tenant or Prospect Screening.

Related Privileges

Group Privilege Column
Tenants/Prospects Access Screenings Add, View

For more information, refer to Control User Access.

To generate a screening for someone that is not associated with a tenant or prospect account, do the following:

  1. Go to arrow_forward Rental Info arrow_forward Leasing arrow_forward Screenings.
    The Screenings page displays.

  2. Click Run Screening.

  3. In the Personal Information section, enter information in the following fields:

    Field Description

    Annual Income

    The person's yearly income.

    Birth Date

    The person's date of birth. This field is required.

    Name (First, Middle, Last)

    The person's full name. The First Name and Last Name fields are required.

    Phone Number

    The person's primary phone number.

    Social Security Number

    The person's social security number (SSN).

  4. In the Address section, enter the full street address of the person being screened.

  5. In the Rental Information section, enter information in the following fields:

    Field Description

    Monthly Rent

    The estimated rent charge for the unit this person is being screened for.

    Property

    The property associated with the unit this person is being screened for.

    More Information

    For screenings linked to tenant or prospect accounts, screenings can be set up to retrieve additional information from Rent Manager fields or user-defined fields (UDFs) that correspond with AmRent fields. The Additional Mapped Fields section displays mapped fields only when running screenings for tenants and prospects. For more information, refer to Screening Settings (System Preferences).

  6. In the Report Type field, select the available screening reports based on your contract with AmRent.

    Related Preferences

    The report types that display in this drop-down list are based on the screening reports associated with the Property selected in the Rental Information section. For more information on each report type, refer to Screening Settings (System Preferences).

  7. Click Submit.
    The screening is submitted to AmRent and can be tracked on the Screenings page.

    More Information

    If all required information is entered but some data is incomplete, such as a missing Middle Name or Annual Income, a pop-up displays warning you that submitting a screening without that information may result in inaccurate data. You can still complete the screening by clicking Yes, or click No to enter more details.
