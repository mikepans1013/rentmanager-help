Update User Time Zone Settings

To accommodate for users that work in different time zones, Rent Manager allows you to set individualized time zones for each user. These time zone settings apply to the time stamps for your incoming system activities, such as incoming texts or emails, and so on. While each property can have its own time zone offset configured on the property's details page, you can establish time zones to accurately reflect the location of your Rent Manager users.

Related Privileges

Group Privilege Column
System Manage all users and privileges View, Edit

For more information, refer to Control User Access.

To update a user's time zone settings, do the following:

  1. Go to arrow_forward Administration, then go to Users arrow_forward Users and select a user from the list.
    The user's details page displays.

  2. On the action bar to the right, click arrow_forward Time Zone.

  3. To enable time zone settings for the specific user, check Override System Web Preferences.

  4. Make selections using the following options.

    Option Description

    Enable Time Zone Offset

    The Time Zone (i.e., Hawaii, Alaska, Pacific, Mountain, Central, Eastern, Atlantic) to apply on the user's time stamps. By default, the time stamp for web activities completed by the user is the current LCS server date and time which is Eastern time.

    Observe Daylight Savings Time

    If the user's region observes daylight saving time (DST), check this option to have Rent Manager automatically adjust the time for DST as necessary.

  5. Click Save.
    The user's time zone settings are updated.
