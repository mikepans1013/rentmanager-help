Reset an Owner's Owner Web Access (OWA) Password

If an owner's web user account password in Owner Web Access (OWA) has been compromised or lost, you can initiate a password reset for them. The password reset prompts the owner to create a new password for their Owner Web Access account.

The account recovery email prompting the password reset is sent to the owner's email address assigned to their Owner Web Access username.

Related Privileges

Group Privilege Column
Owners Owners View, Edit

For more information, refer to Control User Access.

More Information

An owner can also reset their password from the Owner Web Access web portal. To do so, the owner can click on their name in the right corner, then go to User Profile and click Change Password. Additionally, the owner can click Forgot Password on the Owner Web Access login page to initiate a password reset.

To initiate a password reset for an owner's web user account, do the following:

  1. Go to arrow_forward Owners arrow_forward General arrow_forward Owners and select an owner from the list.
    The owner's details page displays.

  2. On the action bar to the right, click arrow_forward OWA Settings.

  3. In the Web Users section, go to the web user's email to reset the password for and click arrow_forward Change Password.


  4. Click Change Password to confirm the action.
    A confirmation email is sent to the owner, prompting them to complete the update.

    More Information

    For security reasons, the email is valid for only fifteen minutes after being sent. If the email needs to be sent again, you can do so by clicking arrow_forward Change Password again.
