# Add a History Category

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/History-Category-Add.htm

History categories help organize and filter the history/note items entered for various accounts and records in Rent Manager . You can create any number of categories, such as Complaints , Evictions , Referrals , Lease Info , or Emails .

 Related Preferences

 If Show Property Notes is enabled in system web preferences, notes of selected categories display in Rent Manager as well as in Tenant Web Access or Owner Web Access . For more information, refer to Tenant Web Access History/Notes (System Web Preferences) or Owner Web Access History/Notes (System Web Preferences) .

 To add a new history category, do the following:

 -
 Go to arrow_forward Administration , then go to Rental Info arrow_forward Tenants/Prospects arrow_forward History Categories .
The History Categories page displays.

 -
 Click Add History Category .
The History Category Add pop-up displays.

 -
 Enter the Name of the history category, which displays as an option in the History Category drop-down when creating a new history/note item. You can use the category name to indicate what kind of note content the category includes (e.g., Misc. , HVAC , or Maintenance ).

 -
 Select the Type to determine the areas of Rent Manager where the history category is applicable, such as for history/note items related to tenants, units, assets, issues, or vendors. The history category displays on only the types selected here.

 -
 To finish, click Save & Close , or to create additional categories, click Save & New .
The history category can be selected when adding or editing history/note items associated with the selected types.
