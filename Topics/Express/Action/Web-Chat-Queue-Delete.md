# Delete a Web Chat Queue

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/Web-Chat-Queue-Delete.htm

The primary reason to delete a web chat queue is that it was added in error and you want to remove the entry so that the web chat queue is unavailable for use. You can delete a web chat queue only if the queue has never received a web chat conversation.

 Warning

 Deleting a web chat queue is permanent and cannot be undone. If you no longer wish to use the web chat queue, instead of deleting it, consider marking it as inactive. This allows you to retain the information attached to that web chat queue while removing it from the available queues. To make a web chat queue inactive, on the queue's General Information tile, uncheck Enabled .

 To permanently delete a web chat queue, do the following:

 -
 Go to arrow_forward Communication arrow_forward Web Chat arrow_forward Manage Queues .
The Mange Queues page displays.

 -
 To the right of the queue, click arrow_forward Delete .
The Delete pop-up displays.

 -
 Click Yes .
The queue is removed from the Manage Queues page.
