Manage Maintenance Tech Hours

With the Maintenance Schedule feature, you can add users as maintenance technicians who can be booked for service appointments. After you set up a tech's schedule, you can edit hours or add additional hours that the tech is available to work. For example, if a tech's availability changes unexpectedly or if they need to work overtime, you can manage their hours from the Edit Hours pop-up.

More Information

The Maintenance Schedule feature is licensed and must be purchased separately. However, a license is not required to use the Maintenance Techs page. Additionally, if you are licensed for rmAppSuite Pro, users added to this page have access to the application's Service feature. For more information, contact your sales representative at sales@rentmanager.com.

To edit or add hours for a maintenance tech, do the following:

  1. Go to arrow_forward Services arrow_forward Service Setup arrow_forward Service Manager arrow_forward Maintenance Techs.
    The Maintenance Techs page displays.

  2. Select a maintenance tech from the list.

  3. Click Edit Hours.

  4. To update the tech's current hours, use the drop-downs next to each day they are scheduled.

  5. Add new hours by clicking Add Hours.

  6. To copy hours from a different maintenance tech, select a user from the Copy hours from existing user drop-down list to duplicate the days and hours to this user's schedule.

  7. In the Days field, check the days for which the hours selected in the From Time and To Time fields apply.

  8. In the From Time field, select the time at which the tech's availability begins on the days checked in the Days field.

  9. In the To Time field, select the time at which the tech's availability ends on the days checked in the Days field.

  10. If applicable, click Add to add additional hours. For example, if the tech is scheduled for different hours on Mondays and Tuesdays, you can first set hours for Mondays, then click Add to set different hours for Tuesdays.

  11. When finished adding hours, click Add.

  12. Click Save to complete adding the new hours and close the pop-up.
    The maintenance tech's hours are added to the Hours tab and also display on the Maintenance Schedule page.
