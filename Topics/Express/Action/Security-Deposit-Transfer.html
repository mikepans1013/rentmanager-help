Transfer a Security Deposit

If a security deposit is on the wrong tenant or prospect account, you need to correct the transactions so it is properly represented on the correct entity's account. If the tenant or prospect receiving the transfer is located at a different property, the options you select while setting up the transfer may change. It is important to confirm both the property and banks associated with both sides of the transfer before attempting to move a security deposit. This ensures that the correct steps are taken to update your financial records.

Additionally, security deposits can be transferred only between entities of the same type (i.e., tenant to tenant or prospect to prospect).

Related Privileges

Group Privilege Column
Tenants/Prospects Customers View, Edit
Prospects View, Edit
Receivables Transfer security deposits Enabled

For more information, refer to Control User Access.

  1. Go to the corresponding page below.

    Entity Type Description

    Tenant

     arrow_forward Rental Info arrow_forward General arrow_forward Tenants and select a tenant account

    Prospect

     arrow_forward Rental Info arrow_forward General arrow_forward Prospects and select a prospect account

    The details page for tenant or prospect displays.

  2. Go to the appropriate location below depending on which entity you need to transfer a security deposit charge from.

    Entity Type Description

    Tenant

    On the tenant's scoreboard, click the drop-down arrow on the Refund Deposit button and select Transfer Deposit.

    Prospect

    On the General tile, to the right of the Security Deposit Held field, click Transfer.

    More Information

    Funds display as security deposits on reports if the following conditions are met:

    • The charge type(s) you use to record security deposits are set up as security deposit charge types in system preferences. For more information, refer to Security Deposit General Options (System Preferences).

    • The security deposit charge is created on the tenant's account and a payment is allocated to the charge.

    • The unit selected in the Unit field is linked to same unit where the security deposit is being held.

  3. In the Transfer From section, enter the Source Bank that currently holds the security deposit(s).

  4. In the Security Deposits section, select each deposit you wish to transfer.

  5. If applicable, change the Amount to Transfer for any of the selected security deposits. The difference between Amount Held and Amount to Transfer remains on the entity currently holding the deposit.

  6. In the Transfer To section, enter the information into the following fields:

    Field Description

    Tenant/Prospect

    The entity that receives the transferred deposit(s).

    Unit

    The unit associated with the transferred security deposit(s).

    Destination Bank

    The bank that receives and holds the transferred security deposit(s).

    Date

    The day the security deposit was originally transferred. By default, today's date populates in this field.

    Method

    Determines how the transfer is processed between the two entities.

    Journal

    A journal entry is used to move the deposit(s) without creating a check and/or deposit. This is most commonly used when both the sending and receiving bank accounts are the same.

    Check

    A check is created to move the deposit(s). Once created, the check must be deposited to the receiving bank account like a normal payment transaction. This is most commonly used when the sending and receiving bank accounts are different and the transfer has not yet been processed at the financial institution.

    Check and Deposit

    A check is created to move the deposit(s), then automatically deposited in Rent Manager. This is most commonly used when the sending and receiving bank accounts are different.

    Comment

    A message to display on the selected method's details.

  7. Click Save.
    The transfer is processed. Charges and credits are added to the associated entities to reflect the security deposit transfer.
