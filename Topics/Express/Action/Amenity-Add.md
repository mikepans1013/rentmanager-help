# Add an Amenity

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/Amenity-Add.htm

Rent Manager allows you to add both unit-level and property-level amenities. A unit-level amenity is specific to a unit(s) but may not apply to every unit or resident at a property. A property-level amenity is available to every unit or resident leasing at the property.

 To add a new amenity, do the following:

 -
 Go to arrow_forward Administration , then go to Rental Info arrow_forward Properties/Units arrow_forward Amenities .
The Amenities page displays.

 -
 Select the Amenity Type you wish to add ( Property or Unit ).

 -
 Click Add Amenity .
The Add Unit Amenity Details or Add Property Amenity Details pop-up displays.

 -
 Enter the applicable information about the amenity.

 Field/Section
 Description

 Name

 The unique name of the amenity.

 Comment

 A note or description of the amenity.

 Price

 The additional cost to use or access the unit-level amenity. This field displays only on the Add Unit Amenity Details pop-up.

 Per Property Override

 If the price of the amenity differs per property, enter a value in the Price column for each desired property. This section displays only on the Add Unit Amenity Details pop-up.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 -
 To finish, click Save & Close or to create additional amenities, click Save & New .
The new amenity is added to the list.
