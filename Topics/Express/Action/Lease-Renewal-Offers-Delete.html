Delete a Lease Renewal Offer

When a lease renewal offer is sent, but is later discovered to be sent in error or a duplicate offer was sent, you can delete the renewal offer. This ensures there are not erroneous documents on tenant accounts or on Tenant Web Access (TWA) that may confuse the tenant or cause further issues.

Warning

Deleting a renewal offer is permanent and cannot be undone. If the renewal offer needs to be updated, instead of deleting it, consider voiding it instead. This allows you to retain historical data of the renewal offer while removing it from any active statuses. For information, refer to Void a Lease Renewal Offer.

Related Privileges

Group Privilege Column
Letter/Email Templates/Reports/Packets Publish document packets Enabled
Void completed signable documents Enabled
Delete completed signable documents Enabled

For more information, refer to Control User Access.

To delete a renewal offer, do the following:

  1. Go to arrow_forward Rental Info arrow_forward Leasing arrow_forward Renewal Offers.

  2. For the offer you wish to delete, click arrow_forward Delete.

  3. Click Yes on the confirmation pop-up.

    Warning

    Deleting a renewal offer that has been Accepted does not remove the new recurring charges. These need to be manually removed from the tenant account.

  4. If there are signable documents with a Published status associated with the renewal offer, a pop-up displays. Select an option from the table below and click Continue to close the pop-up.

    Option Description

    Void published document

    Removes the signable document from Tenant Web Access (TWA) but retains the historical record in Rent Manager.

    Delete published document

    Permanently deletes the signable document from TWA and Rent Manager. This action cannot be undone and is recommended only if the document was created in error.

    The record of the renewal offer is deleted and an entry is added to the Audit Trail report.
