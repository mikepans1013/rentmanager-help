Add a Violation Category

To make the most out of using violations in Rent Manager, you need to create categories as a way to organize collections of violation codes that are similar. Violation categories can be a great way to track the rules and regulations that are important to your community. Assigning a category such as Parking or Lawn Care can help you arrange your codes and make it apparent what situations a code is used for.

Related Privileges

Group Privilege Column
Setup Violation Categories Add, View

For more information, refer to Control User Access.

To add a violation category, do the following:

  1. Go to arrow_forward Rental Info arrow_forward Rental Info Setup arrow_forward Violations arrow_forward Violation Categories.
    The Violation Categories page displays.

  2. At the top of the page, click Add Violation Category.

  3. Enter a Name to described the violation category.

  4. Enter an optional Description of the violation category, such as Homeowner violated trash pick-up code.

  5. To finish, click Save & Close, or to add additional violation categories, click Save & New.
    The new violation category is added to Rent Manager and can be used for violations.
