Search with User Defined Fields (UDFs)

You can search your entire Rent Manager database to quickly find accounts and records. Search by user-defined fields (UDFs) to find accounts and records that include the searched UDFs or even specific values stored in those UDFs.

Related Privileges

Privileges determine what search results are visible and what further actions you can take. Depending on your user privileges, you may be able to open a new page, drill down from the results to specific pages, and perform certain additional actions.

More Information

Only information related to the properties to which you have access displays. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property.

To search your database using UDFs, do the following:

  1. Go to  arrow_forward Search arrow_forward User Defined Fields.
    The User Defined Fields Search page displays. All accounts and records with at least one UDF value display in the list by default.

  2. Further refine your search using the following filters:

    FilterDescription

    Type

    Filters search results by entity type, such as property, vendor, or user. By default, <All Available Types> searches all UDF types that are active in Rent Manager.

    Name

    Filters search results by specific UDFs. Only UDFs of the selected Field Type display. By default, <All Available Fields> searches all UDFs that are active in Rent Manager.

    Containing

    Filters search results that contain specific values.

    Results that meet your criteria display. For example, if you want to search for properties where the trash collection day is Tuesday, you can select Property, Trash Pick-Up Day, and Tuesday in the Type, Name, and Containing search filters.
