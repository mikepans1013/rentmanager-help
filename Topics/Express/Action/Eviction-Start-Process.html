Start an Eviction Process

Rent Manager's evictions tool allows you to start the eviction process by easily beginning an eviction workflow for tenants, tailored to your unique needs and requirements. Once an eviction is started for a tenant, you can track and manage the eviction process from the tenant's details page on the Eviction tile.

For more information, refer to Control User Access.

To start an eviction process on a tenant, do the following:

  1. Go to arrow_forward Rental Info arrow_forward General arrow_forward Tenants.
    The Tenants page displays.

  2. For the tenant you wish to start an eviction process on, click arrow_forward Start Eviction Process.
    The Start Eviction Process pop-up displays.

    More Information

    If you need to start an eviction process for multiple tenants, click Bulk Actions arrow_forward Evictions arrow_forward Start Eviction Process.

  3. On the pop-up, select the following information:

    Field Description

    Eviction Reason

    The category (such as Lease Violation or Non Payment of Rent) to track the reason for why a tenant is in the eviction process. For more information, refer to Eviction Reasons (Page).

    Start Date

    The date the eviction process begins. By default, today's date populates.

    Write Letter

    The name of the letter template selected for the first stage of the eviction workflow. If the start eviction process is done for multiple tenants via Bulk Actions and different workflows are being used with distinct letter templates associated, <Multiple> displays.

    This field displays only if the first stage of the property's assigned eviction workflow has an associated letter template. For more information, refer to Eviction Workflows (Page).

  4. Click Save.
    The eviction is created on the first stage of the assigned eviction workflow (based on the tenant's default property) as indicated by the Evictions tile automatically added to the tenant's details page and the letter associated with the first stage is generated.
