# Add a Tax Type

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/Tax-Types-Add.htm

Tax types are used for invoices when products are sold in areas with different tax rates. In Rent Manager , you can add any number of tax types to account for the various rates in your location, such as state sales taxes. For example, these taxes may apply to the materials purchased when repairing a unit, and can be included on invoices you provide tenants for such repairs.

 To add a tax type, do the following:

 -
 Go to   arrow_forward Administration arrow_forward Accounting arrow_forward General arrow_forward Tax Types .
The Tax Types page displays.

 -
 Click Add Tax Type .
The Add New Tax Type pop-up displays.

 -
 Enter information into the following fields:

 Field
 Description

 Associated Charge Type

 The charge type that is used for transactions associated with the tax type.

 Name

 A descriptive name that identifies the tax type.

 Tax Rate

 The rate that should be charged when this tax type is applied. For example, enter 7.5 if the tax rate is 7.5%.

 -
 Click Save & Close to create the new tax type. Alternatively, click Save & New to continue adding additional tax types.
