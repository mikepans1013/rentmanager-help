# Delete an Issue Priority

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/Issues-Priority-Delete.htm

The primary reason to delete an issue priority is that it was added in error and you want to remove the entry so that the priority is unavailable for use. If an issue priority is linked to service issue, it cannot be deleted.

 Warning

 Deleting an issue priority is permanent and cannot be undone. If you no longer wish to use the priority, instead of deleting it, consider marking it as inactive. This allows you to retain the information attached to that issue priority while removing it from available priorities for future issues. To make an issue priority inactive, on the Edit Priority pop-up, uncheck Active .

 To permanently delete an issue priority, do the following:

 -
 Go to arrow_forward Services arrow_forward Service Setup arrow_forward Service Manager arrow_forward Priorities .
The Issue Priorities page displays.

 -
 To the right of the issue priority, click arrow_forward Delete .
The Confirm Delete pop-up displays.

 -
 Click Yes .
The priority is removed from the Issue Priorities page.
