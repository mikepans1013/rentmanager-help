# Void a Lease Renewal Offer

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/Lease-Renewal-Offers-Void.htm

If you sent a lease renewal offer in error or sent out a lease renewal offer before getting the necessary approval, you can void the lease renewal offer in Rent Manager . If there are published documents associated with the renewal offer, Rent Manager gives you the option of voiding or deleting the published document. Voiding a lease renewal offer is primarily used as an alternative to deleting an offer because it maintains a record of the renewal offer in the tenant's History/Notes , and you can filter for voided offers on the Lease Renewal Board board.

 To void a lease renewal offer, do the following:

 -
 Go to   arrow_forward Rental Info arrow_forward Leasing arrow_forward Lease Renewal Board .
The Lease Renewal Board displays.

 -
 For the lease renewal you would like to void, click arrow_forward Void .
The Void Renewal Offer pop-up displays.

 -
 Click Void to retain historical data of the lease renewal offer and remove it from any active statuses or Void & Create New Offer to void the offer and send the tenant a new offer.

 Warning

 Voiding a renewal offer that has been Accepted does not remove the new recurring charges. These need to be manually removed from the tenant account.

 -
 If there are signable documents with a Published status associated with the lease renewal offer, a pop-up displays. Select an option from the table below and click Continue to close the pop-up.

 Option
 Description

 Void published document

 Removes the signable document from Tenant Web Access (TWA) but retains the historical record in Rent Manager .

 Delete published document

 Permanently deletes the signable document from TWA and Rent Manager . This action cannot be undone and is recommended only if the document was created in error.

 The renewal offer is voided.
