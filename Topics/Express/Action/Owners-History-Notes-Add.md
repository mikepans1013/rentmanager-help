# Add an Owner History/Note

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/Owners-History-Notes-Add.htm

History/notes let you track your interactions with owners. When you enter a history/note item, selecting the type that best relates to your interaction provides you with options and fields to make it easier to record details. The Note type allows you to enter any kind of details, attach files, and schedule a follow-up with the owner. You can also pin the history/note item if it needs more visibility, such as the owner's details page.

 To add a history/note to an owner account, do the following:

 -
 Go to arrow_forward Owners arrow_forward General arrow_forward Owners and select an owner from the list.
The owner's details page displays.

 -
 On the action bar to the right, select arrow_forward Add Note .

 -
 Enter the desired information about the note. The following fields are available:

 If applicable, click Upload or Paste to add a document or image associated with the history/note item.

 If the history/note item requires further action, check the box and enter a date by which a follow-up on this item should be completed. If needed, this time can be changed in the Follow-up Date field, as it directly affects when scheduled follow-up reminders display.

 Related Preferences

 Set a default follow-up time in personal preferences for the history/note item created when items are added to your calendar. For more information, refer to Calendar Options (Personal Preferences) .

 Once saved, the Created By field displays on the history/note item to distinguish which user initiated the follow-up. A task is also created. For more information, refer to Tasks (Page) .

 More Information

 The user who created the follow-up is also tasked with completing the follow-up and receives reminders via the Dashboard . For more information, refer to My Dashboards (Page) .

 To designate this follow-up as completed, click Follow-up Completed . The history/note item updates with the Completed date and the Followed-up By user, and the task is closed.

 History Category

 The user-created category used to filter history/note items and report results. You can also use these categories to allow Owner Web Access (OWA) users to view specific history/note items in their portal, such as contracts or custom reports. For more information, refer to Owner Web Access History/Notes (System Web Preferences) .

 Lock Information

 Prevents other users from editing the history/note item.

 Related Preferences

 To remove the ability to lock history/note items, Disable locking of History/Notes must be enabled in system preferences. For more information, refer to General Options (System Preferences) .

 Note

 Any information about the history/note item describing the event, interaction, or message.

 To notify a Rent Manager user when this history/note item is saved, enter @ followed by their full name (e.g., @Alexander Smith ) and select their account from the drop-down list.

 Pin

 If checked, the history/note item displays first in the History/Notes pop-up as pinned .

 Start Date and Time

 The date and time the history/note item goes into effect. When you open the Note Details pop-up, the current date and time populate by default.

 -
 Click Save .
The new history/note item is added to the owner's History/Notes pop-up.
