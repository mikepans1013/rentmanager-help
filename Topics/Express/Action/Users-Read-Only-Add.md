# Add a Read-Only User

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/Users-Read-Only-Add.htm

Read-only users can view information in Rent Manager , but they cannot change any data. You can further restrict what data a read-only user can view using the Privileges tab.

 Read-Only Access

 Read-only users can do the following:

 -
 View data and pages for which they have View privileges on their user Privileges tab.

 -
 Generate letters and reports to which they have access on their user Letters and Reports tabs.

 -
 Export, print, or download a local copy of reports to their device.

 -
 View system preferences or personal preferences, but not change settings.

 Read-only users cannot do the following:

 -
 Edit any data anywhere in Rent Manager (such as moving, adding, updating, or deleting data).

 -
 Publish reports or letters to Owner Web Access (OWA) or Tenant Web Access (TWA) .

 -
 Send any type of communications (including letters or reports) via email, text, or Virtual Post Office (VPO) .

 -
 View or edit system web preferences.

 To make a user read-only, do the following:

 -
 Go to arrow_forward Administration arrow_forward Users arrow_forward Users and select a user from the list.
The user's details page displays.

 -
 On the General tab in the Options tile, check Read-Only .

 -
 Optionally, further restrict what the user can view on the following tabs. For more information, refer to Control User Access .

 Tab
 Description

 Privileges

 Choose which pages, categories of data, and Rent Manager entity details the user can view. Read-only users must have the required View privilege to access pages and data.

 Reports

 Choose which reports the user can run. In addition to having access to the reports selected in this tab, read-only users must have the following privileges to run reports.
