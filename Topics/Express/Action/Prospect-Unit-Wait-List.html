Add a Prospect to a Unit's Wait List

The Interested Properties/Units pop-up Wait List column allows you to record a prospects preferred unit(s) without impacting the status of the unit. When a unit becomes available, you can run the Prospect Waiting List report to see the prospects waiting to occupying the unit.

Related Privileges

Group Privilege Column
Tenants/Prospects Prospects View, Edit

For more information, refer to Control User Access.

To add units to the prospect's Wait List column, do the following:

  1. Go to  arrow_forward Rental Info arrow_forward General arrow_forward Prospects and select a prospect from the list.
    The prospect's details page displays.

  2. On the Interested Properties/Units tile, click .
    The Interested Properties/Units pop-up displays.

  3. In the Properties field, select the properties to display only units from those properties. By default, this field automatically populates with the prospect's default property.

  4. To add a prospect to the waiting list for a unit (or the Entire Property), check the box in the Wait List column. This also automatically checks the Interested column.

  5. Click Save.
    This displays the unit(s) with a Check on the Interested Properties/Units tile's Wait List column and adds the prospect to the Prospect Waiting List report.
