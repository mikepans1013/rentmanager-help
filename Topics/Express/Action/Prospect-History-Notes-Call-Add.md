# Add a Prospect Call to History/Notes

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/Prospect-History-Notes-Call-Add.htm

Prospect history/notes record information that supplements or clarifies information entered in other fields in Rent Manager , such as notes about communication with prospects, transactions, and prospect status updates. Rent Manager automatically creates some history/note items at the system level. You can also record phone calls with prospects as history/notes.

 To add a call to a prospect's history/notes, do the following:

 -
 Go to   arrow_forward Rental Info arrow_forward General arrow_forward Prospects and select a prospect from the list.
The prospect's details page displays.

 -
 On the action bar to the right, select arrow_forward Add Call .
The Call Details pop-up displays.

 -
 Enter the desired information about the note.

 Field
 Description

 Completed

 Indicates the call's purpose is considered completed or finished.

 End Date and Time

 The date and time the call ended. When you check the box, the current date and time populate by default.

 Follow-up Date

 If the history/note item requires further action, check the box and enter a date by which a follow-up on this item should be completed. If needed, this time can be changed in the Follow-up Date field, as it directly affects when scheduled follow-up reminders display.

 Related Preferences

 Set a default follow-up time in personal preferences for the history/note item created when items are added to your calendar. For more information, refer to Calendar Options (Personal Preferences) .

 Once saved, the Created By field displays on the history/note item to distinguish which user initiated the follow-up. A task is also created. For more information, refer to Tasks (Page) .

 More Information

 The user who created the follow-up is also tasked with completing the follow-up and receives reminders via the Dashboard . For more information, refer to Follow-Up (Dashboard Tile) .

 To designate this follow-up as completed, click Follow-up Completed . The history/note item updates with the Completed date and the Followed-up By user, and the task is closed.

 History Category

 The user-created category used to filter history/note items and report results. You can also use these categories to allow Tenant Web Access (TWA) users to view specific call history/note items in their portal. For more information, refer to Tenant Web Access History/Notes (System Web Preferences) .

 Lock Information

 Prevents other users from editing the history/note item.

 Related Preferences

 To remove the ability to lock history/note items, Disable locking of History/Notes must be enabled in system preferences. For more information, refer to General Options (System Preferences) .

 Note

Information about the call you want to record for future reference.

 Pin

 If checked, the history/note item displays first in the History/Notes pop-up as pinned .

 Result

 The outcome of the conversation. For example, describe any next steps or actions that respond to the call.

 Show on payments tab

 Adds the Note to the Add Payment page under the Summary section in the Payment Notes field. For more information, refer to Prospect Payments (Pop-Up) .

 Spoke with prospect

 Indicate a call took place with the intended recipient rather than leaving a message.

 Start Date and Time

 The date and time the call was taken. When you open the Call Details pop-up, the current date and time populate by default.
