# Delete a Forecast Model

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/Forecast-Model-Delete.htm

The primary reason to delete a forecast model is that it was added in error and you want to remove the entry so that the model is unavailable for use when running the Profit & Loss Forecast report.

 Warning

 Deleting a forecast model is permanent and cannot be undone. If you no longer wish to use the model, instead of deleting it, consider marking it as inactive. This allows you to retain the information attached to that forecast model while removing it from the available models. To make a forecast model inactive, on the Forecast Model Details pop-up, uncheck Active .

 To permanently delete a forecast model, do the following:

 -
 Go to arrow_forward Administration , then go to Accounting arrow_forward General arrow_forward Forecast Models .
The Forecast Models page displays.

 -
 To the right of the forecast model, click arrow_forward Delete .
The Confirm Delete pop-up displays.

 -
 Click Yes .
The model is removed from the Forecast Models page.
