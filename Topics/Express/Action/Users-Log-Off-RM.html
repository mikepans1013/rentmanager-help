Log a User Off of Rent Manager

With per user Rent Manager licensing, there are a limited number of users that can access Rent Manager at the same time. If a user needs to sign in but all available licenses are in use, you can forcibly log another user out of their Rent Manager session to free up a license for another user.

Related Privileges

Group Privilege Column
System Manage Rent Manager Sessions Enabled

For more information, refer to Control User Access.

To log a user out of Rent Manager, do the following:

  1. Go to arrow_forward Administration, then go to Users arrow_forward Manage Rent Manager Sessions.
    The Rent Manager Sessions page displays.

  2. On the user you wish to log out, select arrow_forward Log Off User.

  3. In the Message to user field, enter an optional message to display to the user explaining the reason they are being logged off.

  4. Click Log Off.
    The user is logged out of their Rent Manager session.
