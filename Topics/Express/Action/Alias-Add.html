Add an Alias

As part of Rent Manager's Smart Bills and Smart Receipts features, you can add vendor or property alias to help match the information from the bill or receipt to the information in Rent Manager.Vendor aliases are alternate vendor names found on invoices (for example, Holbrook Heating and Cooling might also be known as Holbrook Sevices, LLC). Property aliases are alternate property names or addresses found on vendor invoices (for example, 1127 Blackwell Drive might also display as 1127 Blackwell DR.). By adding any possible aliases to Rent Manager, you're helping Smart Bills and Smart Receipts match bills or receipts to the correct vendor or property.

More Information

This feature is licensed and must be purchased separately. For more information, contact your sales representative at sales@rentmanager.com.

Related Privileges

To add a new alias, do the following:

  1. Go to arrow_forward Administration, then go to Accounting arrow_forward Manage Aliases.
    The Manage Aliases page displays.

  2. In the Alias Type section, select Vendor or Property.

  3. Click Add Alias.
    The Add Vendor Alias or Add Property Alias pop-up displays.

  4. Enter the following information:

    Field Description

    Vendor

    The name listed on the vendor's details page in the General tile. This field displays only when adding a vendor alias.

    Property

    The full name listed on the property's details page in the General tile.

    More Information

    This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property.

    This field displays only when adding a property alias.

    Alias

    For a vendor, an alternate vendor name that displays on the vendor invoice (e.g., Holbrook Service LLC or Holbrook Heating and Cooling).

    For a property, an alternate property name or address that may display on a vendor invoice (e.g., Flagstone Mobile Home Community or Flagstone MHC).

    More Information

    To add multiple aliases at the same time, enter each alias and add a comma between them.

  5. Click Save & Close to complete the alias creation process and close the pop-up. Alternatively, click Save & New to finish adding the alias and refresh the pop-up to create another alias.
