# Delete an Issue Status

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/Issue-Status-Delete.htm

The primary reason to delete an issue status is that it was added in error and you want to erase the entry so that the issue status is unavailable for use. An issue status that is linked to a service issue cannot be deleted.

 Warning

 Deleting an issue status is permanent and cannot be undone. If you no longer wish to use an issue status, instead of deleting it, consider marking it as inactive. This allows you to retain the information attached to that issue status while removing it from available statuses for future issues. To make an issue status inactive, on the Edit Status pop-up, uncheck Active .

 To permanently delete an issue status, do the following:

 -
 Go to arrow_forward Services arrow_forward Service Setup arrow_forward Statuses .
The Issue Statuses page displays.

 -
 To the right of the issue status, click arrow_forward Delete .
The Confirm Delete pop-up displays.

 -
 Click Yes .
The status is removed from the Issue Statuses page.
