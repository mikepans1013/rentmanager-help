Delete a Task Automation Schedule

The primary reason to delete a task automation schedule is that it was added in error and you want to remove the entry from Rent Manager so that the schedule is unavailable for use.

Warning

Deleting a task automation schedule is permanent and cannot be undone. If you no longer wish to use an automation schedule, uncheck the Active box for that schedule to deactivate it. The task automation schedule remains in the Rent Manager database while removing it from available automation schedules for future postings.

Related Privileges

For more information, refer to Control User Access.

More Information

To delete a task automation schedule, you must have the access to the properties associated with the schedule. Your access to properties can be managed from the user's General tab or from the property's General tab.

To delete a task automation schedule, do the following:

  1. Go to arrow_forward Administration, then go to Automation arrow_forward Task Automation and select a task automation from the list.
    The task automation schedule's details page displays.

  2. On the desired schedule, click arrow_forward Delete.
    The Confirm Delete pop-up displays.

  3. Click Yes to confirm the action.
    The task automation schedule is removed from the list.
