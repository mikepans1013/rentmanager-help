Delete a Make-Ready Template

The primary reason to delete a make-ready template is that it was added in error and you want to remove the entry so that the make-ready template is unavailable for use.

Warning

Deleting a make-ready template is permanent and cannot be undone. If you no longer wish to use a make-ready template, instead of deleting it, consider marking it as inactive. This allows you to retain the workflow attached to that make-ready template while making it unavailable for future make-ready processes. For information on how to make a make-ready template inactive, refer to Make Ready Template Details (Pop-Up).

Related Privileges

Group Privilege Column
Properties/Units Make ready templates View, Delete

For more information, refer to Control User Access.

To permanently delete a make-ready template, do the following:

  1. Go to arrow_forward Services arrow_forward Make Ready arrow_forward Make Ready Templates.
    The Make Ready Templates page displays.

  2. To the right of the make-ready template, click arrow_forward Delete.
    The Confirm Delete pop-up displays.

  3. Click Yes.
    The make-ready template is removed from the page and is no longer available to select for kick off a make-ready for a unit.
