# Add an Asset Status History

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/Assets-Status-History-Add.htm

The asset status history tool allows you to assign statuses to assets to track their use and condition in Rent Manager . This allows you to provide more information about the asset and filter your assets list by status. Asset statuses are also used in conjunction with asset workflows so that assets move through statuses that match your real world procedures.

 To add an asset status, do the following:

 -
 Go to arrow_forward Rental Info arrow_forward General arrow_forward Assets and select an asset from the list.
The asset's details page displays.

 -
 At the top right of the page, click Add Status .
The Add Asset Status History pop-up displays.

 -
 Select the Status that indicates the current state of the asset.

 -
 Select the Date on which the asset is placed in this status.

 -
 Enter an optional Comment explaining the asset status. To add a memorized comment, click .

 -
 Click Save & Close to add the asset status and close the pop-up. Alternatively, click Save & New to add the asset status and begin adding another asset status.
The status is added to the Asset Status History tile.
