# Reset a User's Multifactor Authentication Login

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/Multifactor-Authentication-Reset-Login.htm

Multifactor authentication (MFA) requires users to verify their identity using a third-party authenticator application before they can log in. A one-time code is generated each time a user logs into Rent Manager and cannot be used more than once. In the event that a user loses the MFA token in their authenticator application or gets a new device, you can reset their MFA login directly from Rent Manager .

 Related Preferences

 Multifactor authentication is available only when Require Multifactor Authentication (MFA) to log in is enabled in system preferences. For more information, refer to General Options (System Preferences) .

 More Information

 If you are not using multifactor authentication and need to reset or unlock a user account, refer to Unlock a User Account or Change Password .

 To reset a user's MFA login, do the following:

 -
 Go to arrow_forward Administration , then go to Users arrow_forward Users and select the desired user.
 The User details page displays.

 -
 On the action bar to the right, click arrow_forward Reset MFA Login .
 The MFA Login Reset pop-up displays.

 -
 Click Yes .
The user's MFA login is reset and they must reconfigure their authenticator application the next time they log into Rent Manager .
