# Process a Manual ePay Payment

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/Transactions-ePay-Payment-Add.htm

Handling tenant or prospect payments via ePay is an important part of your daily business processes. In the event that an ePay payment must be completed manually, Rent Manager makes this process easy to do. Before you can process a manual ePay payment ePay payments must first be enabled on the tenant or prospect account. For more information, refer to Set Up ePay for Tenants and Prospects .

 To manually process a payment using ePay from a tenant or prospect account, do the following:

 -
 Go to arrow_forward Rental Info arrow_forward General arrow_forward Tenants | Prospects and select an account.
The tenant or prospect's details page displays.

 -
 On the action to the right, click arrow_forward Add Payment .
The Add Payment pop-up displays.

 -
 In the Payment Info section, enter the information about your payment.

 Option
 Description

 Date

 The date the tenant or prospect is making the payment.

 Reference #

 The following forms of payment to describe the transaction are available to select.

 More Information

 If, in the Payment Summary section, the Process via ePay option is selected, this field displays ePay and cannot be edited.

 Cash

 Record a cash payment.

 MO

 Record a money order payment.

 CC

 Record a credit card payment.

 Check

 Manually type the check number into the Reference # field to record a check payment.

 Amount

 The full dollar amount of the payment received.

 Memo

 A brief comment about this payment, such as how it was applied. Payment memos display in the Comment column of the prospect or tenant's View Transactions pop-up.

 -
 In the Open Charges section, verify that the Current Payment amount entered is correct. If the payment does not cover all open charges, in the list of open charges, check the Pay? box next to the open charge to which to apply this payment.

 -
 In the Payment Summary section, check Process via ePay .

 -
 Click Add Payment . If prompted, enter your ePay password.
The ePay Payment Information pop-up displays.

 -
 Select the payment method from the following options:

 Option
 Description

 Use Account on File

 If the tenant or prospect has one or no payment methods on file, apply the account's saved payment method.

 Make Default

 If the tenant or prospect has one or no payment methods on file, save payment information as the new default ePay account on file for this tenant. This option cannot be selected when Use Account on File is checked.

 Account

 If the tenant or prospect has multiple ePay payment methods on file, the Account field contains a drop-down. Depending on how the tenant wishes to pay, select to Use Default Account or Use Secondary Account . Alternately, to use a different payment method, select Enter New Account Information .

 -
 In the Account Information and Billing Information sections, verify the payment information is correct. If adding a new payment method, ensure the information is entered correctly.

 -
 In the Summary section, enter the following information:

 Field or Section
 Description

 Posting Date

 The date the transaction displays in Rent Manager as received. ePay , however, processes the actual payment today.

 Waive Platform Fee

 The tenant is not charged a platform fee for this payment. Otherwise, the Total Payment amount at the bottom of the section includes the platform fee.

 Payment by Phone

 The user who entered this payment spoke with the tenant or prospect over the phone to approve the payment.

 -
 Once the Total Payment amount is verified as correct, click Make Payment .
The ePay Payment Information pop-up displays.

 -
 Click OK .
If the payment was approved, it and any platform fee charged display in the tenant or prospect's transactions. If the payment is not approved or contains errors, the ePay is not processed.
