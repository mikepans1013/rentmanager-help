# Add a User

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/Users-Add.htm

When setting up user accounts, you can determine an individual's account information, privileges, display defaults, and access to reports, letters, and filters. This ensures the user can be easily identified in the system, access the areas of Rent Manager that are needed to perform their tasks, and unable to access the areas of Rent Manager you determine are outside of what their role needs access to.

 To add a new user, do the following:

 -
 Go to arrow_forward Administration , then go to Users arrow_forward Users .
The Users page displays.

 -
 Click Add User .
The Add User pop-up displays.

 -
 Enter the following information for the new user:

 Option
 Description

 Copy permissions from existing user or role

 Use the permissions from an active user or user role that is set up similar to how you want to set up the new user. The user is created with the exact privileges of the selected user or user role already assigned, but they can be changed for the user at any time.

 Email

 The user's work email address.

 If you use per unit Rent Manager licensing, an email address for each user is required. Setup instructions are sent to this email address.

 First Name

 The user's first name.

 Last Name

 The user's last name.

 Original Password

 A secure password, which the user enters when accessing Rent Manager for the first time. They will be prompted to create a new password the first time they log in.

 Supervisor

 The user's supervisor or manager. The supervisor controls the access of other users for which they are selected as supervisor.

 A supervisor who indirectly supervises another user still has the ability to make changes to that user's account. For example, user A supervises user B, and user B supervises user C. User A can view and edit privileges for both users B and C.

 Depending on the privileges provided, supervisors may also do the following:

 -
 Edit or add new user accounts with privileges only up to the level of their own privileges (i.e., supervisors are not able to grant any privileges that they do not have themselves).

 -
 Assign any user roles they are assigned to supervised users.

 -
 Control the Active status and assignments in the Options tile of the users they supervise.

 UserName

 A unique identifier for the user. This must be different from other users.

 -
 Click Save .
The new user is added to the Users list.
