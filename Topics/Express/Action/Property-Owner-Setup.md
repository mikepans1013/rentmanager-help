 Follow these steps to set up owners of the currently selected property:

 -
 Go to arrow_forward Rental Info arrow_forward General arrow_forward Properties and select an property from the list.
The property's details page displays.

 -
 On the action bar on the right, click arrow_forward   Owners .
The Owners pop-up displays.

 -
 Select the Primary Owner from the drop-down list.

 More Information

 If there is only one owner of this property, simply choose that owner.

 If this property is owned by a partnership, consider choosing the owner with the highest percent of ownership to be the Primary Owner . If there is no owner with a higher percentage of ownership, choose the owner you communicate with more frequently – your primary contact.

 -
 If owner bill approval has been enabled, the following displays across the top of the window:

 -
 Check Require owners to approve bills for all owners if the owner(s) of this property are required to approve bills.

 -
 Enter an amount in Threshold Amount that represents the minimum bill amount that would require owner approval.

 -
 Click + Add Owner .

 -
 Select an Owner from the drop-down list.

 -
 Enter the contract Start date for this owner. If applicable, select the End date.

 -
 Enter this owner’s percentage ( % ) of ownership.

 -
 If applicable, enter a Reserve amount. This is a minimum balance that must be maintained in this property’s bank at all times for this owner.

 -
 If you are dealing with a partnership, click Add Owner and add the Owner , Start , End , % , and Reserve fields for each additional owner.

 -
 Click Save .
