Deposit a Security Deposit Held in Escrow

If you have separate trust (also known as escrow) accounts to hold security deposit payments from tenants and prospects, it is essential that those payments are stored in this bank account. To accurately reflect this financial data in Rent Manager and ensure that payments are not commingled in your records, you need to deposit security deposit payments held in escrow to a dedicated escrow general ledger (GL) account.

More Information

If all security deposits are held in an escrow account, or if you have a dedicated charge type for security deposits held in escrow, you can set up a property-level charge type to ensure that these payments are always deposited to the correct account. For more information, refer to Charge Type Banks (Pop-Up).

Related Privileges

Banks/Checks Bank deposits Add

For more information, refer to Control User Access.

To deposit a security deposit held in escrow, do the following:

  1. Go to arrow_forward Accounting arrow_forward Banking arrow_forward Make Deposit.
    The Make Deposit page displays.

  2. In the list of payments, select only the security deposit payment(s) to be deposited in escrow.

    More Information

    Funds display as security deposits on reports if the following conditions are met:

    • The charge type(s) you use to record security deposits are set up as security deposit charge types in system preferences. For more information, refer to Security Deposit General Options (System Preferences).

    • The security deposit charge is created on the tenant's account and a payment is allocated to the charge.

    • The unit selected in the Unit field is linked to same unit where the security deposit is being held.

  3. Click Deposit.
    The Deposit Information pop-up displays.

  4. In the Bank Account field, select the security deposit escrow account from the drop-down list.

    Related Privileges

    This field populates with only banks to which you have access. Your access to banks can be managed on the user's details page. For more information, refer to Limit Access to a Bank or Credit Card.

  5. In the Deposit Date field, enter the date that the security deposit payment was deposited in your escrow account in real life. The current date populates by default.

  6. Fill out any remaining deposit details. For more information, refer to Make a Bank Deposit.

  7. Click Deposit.
    The selected security deposit payment(s) is deposited to the escrow account.
