# Merge Users

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/Users-Merge.htm

Rent Manager provides the ability to merge one user's past actions with another current user. Merging users copies the source user's past actions to the destination user's record and then removes the source user from the user list.

 You can use this tool, for example, if a person's name changes (through marriage, divorce, etc.) and you want a continuous history of this user's actions. Create a new user with the new name and username as the destination user and then merge the source user into the new user to have all actions performed with the old username show in the current (destination) username.

 More Information

 If you edit the Username on the user's details page, actions performed prior to this change are attributed to the original username and actions performed after this change are attributed to the new username. The same occurs when you merge user accounts. If the user account is no longer in use but you don't want to overwrite the original users actions, you can make the user account inactive instead. To do so, on the user's details page, uncheck Active . An inactive user’s past actions are retained, but no one is able to log in using this username while it is inactive.

 To merge a user, do the following:

 -
 Go to   arrow_forward Administration , then go to Users arrow_forward Merge Users .
The Merge Users pop-up displays.

 -
 Select the Source User whose past actions you want to merge.

 -
 Select the Destination User who inherits the past actions of the source user.

 -
 Click Merge .

 -
 Click Yes to confirm the merging of two users and deletion of the source user.
All the actions previously attributed to the Source User are now attributed to the Destination User .
