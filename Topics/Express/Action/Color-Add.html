Add a Color

Highlight entities and events in Rent Manager with defined colors. Colors can be applied in many areas of Rent Manager, such as appointments, tasks, tenants, and units. For example, you can assign the color green to represent commercial tenants, and all tenants, units, or properties you apply the color to display as green for easy identification.

Related Privileges

Group Privilege Column
System Colors Add, View

For more information, refer to Control User Access.

To add a new color, do the following:

  1. Go to arrow_forward Administration, then go to Customization arrow_forward Colors.
    The Colors page displays.

  2. Click Add Color.

  3. Enter a unique Name for this color.

  4. Click the Color swatch to set a color.

    Either of the following methods can be used to set a color:

    Option Description

    Select from the color palette

    Click in the color bar to pick the color family and then click in the palette to further refine your selection:

    Enter a value

    Use to the right of the field to switch between available color systems, color formats, and color models:

    • Hex
    • RGB
    • HSL

    Enter the value or hex code of the desired color.

    Click OK to set the selected color.

  5. Select the Color Types where this color is to be available for use. If the color should apply to all types, select ***<All Types>.

  6. Click Save & Close to complete the color creation process and close the pop-up. Alternatively, click Save & New to finish adding the color and refresh the pop-up to create another color.
