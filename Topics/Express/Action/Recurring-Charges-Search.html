Search with Recurring Charges

You can search your entire Rent Manager database to quickly find accounts and records. The Recurring Charge Search page lets you search for one or more recurring charges that began and/or ended during specified date ranges and then filter the results using additional search criteria. The types of recurring charges that you can search for include: Property, Unit Type, Unit, and Tenant.

Related Privileges

Privileges determine what search results are visible and what further actions you can take. Depending on your user privileges, you may be able to open a new page, drill down from the results to specific pages, and perform certain additional actions.

More Information

Only information related to the properties to which you have access displays. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property.

To search your database using recurring charges, do the following:

  1. Go to  arrow_forward Search arrow_forward Recurring Charges.
    The Recurring Charge Search page displays.

  2. Further refine your search using the following filters:

    Filter Description

    Type

    Filters search results by entity type (Property, Unit Type, Unit, Tenant).

    Date Range

    A From Date Range and To Date Range during which the charges occurred.

    Search Options

    Whether the filtered list includes recurring charge information that Contains the data you input into one or more fields, or recurring charge information that Begins With the data you input into one or more fields.

    Charge Type

    Filters search results by recurring charges associated with the specified charge type.

    Frequency

    Filters search results by how often the recurring charge posts to the specific account.

    Name

    Filters search results by the name of a property, unit type, unit, or tenant associated with recurring charges.

    Comment

    Filters search results that contain a specific word or phrase.

  3. Click Search.
    Results that meet your criteria display. For example, if you want to search for properties with a garage charge type recurring charge, you can select Property and GARAGE in the Type and Charge Type search filters.
