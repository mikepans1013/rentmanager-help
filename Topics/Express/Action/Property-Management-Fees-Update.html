Update a Property's Management Fee Setup

If you are a fee-based management company, management fees are the payments you collect for managing properties. If the fee setup for one of your properties has changed, you must update the management fees for that property. The best practice is to set an ending date for the prior fee setup to maintain a historical record and to ensure that fee postings do not update to the new structure until they are scheduled to.

To update the management fee setup for a specific property to a new setup, do the following:

  1. Go to arrow_forward Rental Info arrow_forward General arrow_forward Properties and select a property from the list.
    The property's details page displays.

  2. On the action bar to the right, click arrow_forward Fees Setup.
    The Fees Setup pop-up displays.

  3. Click Add Fees Setup.
    The Add Management Fee Setup pop-up displays.

  4. Select the method of the template you wish to use: Standard or Advanced, then click OK.

  5. In the Management Fees field, select the template to apply to this property. Alternatively, select <Custom Setup> to manually enter a fee setup unique to this property in the available fields. For more information, refer to Add an Advanced Management Fee Setup and Add a Standard Management Fee Setup.

    More Information

    If the management fee setup you are adding needs to be added to multiple properties, you can save time by creating a management fee template for the setup. Then select that template for each property's new fee setup instead of manually entering the information for each field on every property. For more information, refer to Add an Advanced Management Fee Template and Add a Standard Management Fee Template.

  6. In the Active Start Date field, enter the date on which this fee setup should take effect for the property. If there is a current fee setup already established for the property, that setup's Active End Date is automatically set to the day before this date.

  7. Click Save.
    The property's management fee setup is updated.
