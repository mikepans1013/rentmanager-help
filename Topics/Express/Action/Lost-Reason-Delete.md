# Delete a Lost Reason

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/Lost-Reason-Delete.htm

The primary reason to delete a lost reason is that it was added in error and you want to remove the entry so that the lost reason is unavailable for use.

 Warning

 Deleting a lost reason is permanent and cannot be undone. If you no longer wish to use the lost reason, instead of deleting it, consider marking it as inactive. This allows you to retain the information attached to that lost reason while removing it from available lost reasons. To make a lost reason inactive, on the Edit Lost Reason pop-up, uncheck Active .

 For more information, refer to Control User Access .

 To permanently delete a lost reason, do the following:

 -
 Go to arrow_forward Rental Info arrow_forward Rental Info Setup arrow_forward Tenants/Prospects arrow_forward Lost Reasons .
 The Lost Reasons page displays.

 -
 To the right of the lost reason, click arrow_forward Delete .
 The Confirm Delete pop-up displays.

 -
 Click Yes .
The lost reason is removed from the Lost Reasons page.
