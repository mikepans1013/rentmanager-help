# Delete a Prospect Stage

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/Prospect-Stage-Delete.htm

The primary reason to delete an existing prospect stage is that it was added in error and you want to remove the entry so that the stage is unavailable for use. If a prospect stage has been used, it cannot be deleted.

 Warning

 Deleting a prospect stage is permanent and cannot be undone. If you no longer wish to use the stage, instead of deleting it, consider marking it as inactive. This allows you to retain the information attached to that prospect stage while removing it from available stages in the leasing process. To make a prospect stage inactive, on the Prospect Stage Details pop-up, uncheck Active .

 To permanently delete a prospect stage, do the following:

 -
 Go to arrow_forward Rental Info arrow_forward Rental Info Setup arrow_forward Tenants/Prospects arrow_forward Prospect Stages .
The Prospect Stages page displays.

 -
 To the right of the prospect stage, click arrow_forward Delete .
The Confirm Delete pop-up displays.

 -
 Click Yes .
The stage is removed from the Prospect Stages page.
