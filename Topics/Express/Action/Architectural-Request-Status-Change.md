# Change the Status of an Architectural Request

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/Architectural-Request-Status-Change.htm

If your property is an association, such as a homeowners association (HOA), the architectural requests tool in Rent Manager allows tenants (i.e., homeowners) at that property to ask the association if they are allowed to make external changes to their home (i.e., unit) such as planting trees, adding gardens, or repainting the building a specific color. Once a request is submitted, use the Architectural Request Detail pop-up to update the request's status based on where it is in the approval process ( More Information Needed , Approved , Denied , Canceled ).

 To change an architectural request's status, do the following:

 -
 Go to arrow_forward Services arrow_forward Community arrow_forward Architectural Requests and select an architectural request from the list.

 -
 On the Details tile, in the Status field, click .
The Change Architectural Request Status pop-up displays.

 -
 In the Status field, select the desired request status.

 Status
 Description

 Pending

 No action has been taken on this request yet.

 Approved

 The request was voted on and accepted.

 Denied

 The request was voted on and declined.

 Canceled

 The request was manually canceled by a user, such as the request being withdrawn.

 More Information Needed

 The person who submitted the request needs to provide additional information in order for the management company to make a decision.

 In Board Review

 The request is ready for discussion and the association is working toward making a decision.

 -
 In the Comments field, enter an optional explanation of the request's status change.

 -
 Click Save .

 -
 On the Architectural Request Detail pop-up, click Save .
The request's status is updated and a history item is added to the History/Notes tile.
