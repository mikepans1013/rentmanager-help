Unlock a User Account

After a user fails ten log in attempts in Rent Manager, their account is locked. The lockout automatically expires in 30 minutes, but another user with the requisite privileges can unlock the user manually. This ensues that users who are locked out can quickly resume their responsibilities, while at the same time maintaining a high level of security for your Rent Manager database.

Unlocking a user account must be done in your default database location. For more information, refer to Manage Locations (Pop-Up).

Related Privileges

To view information for any users, the following privileges are required:

Group Privilege Column
System Manage all users and privileges View
Allow user to unlock other users Enabled

To view information for users that you supervise, the following privileges are required:

Group Privilege Column
System Manage assigned users and privileges View
Allow user to unlock other users Enabled

For more information, refer to Control User Access.

To unlock a user, do the following:

  1. Go to arrow_forward Administration arrow_forward Users arrow_forward Users, then select a locked account from the list.
    The user's details page displays.

  2. On the action bar to the right, click .
    The Unlock User pop-up displays.

  3. Click Yes to unlock the user account.
    A confirmation pop-up displays. The selected user can now log in to Rent Manager.
