Add an Asset Title Status

Asset title statuses are conditions that you create to describe the state of the asset's legal ownership (e.g., Clear Title, No Title, Title with Lien), which helps you track the title regardless of where it is in the ownership process and allows you to filter your assets list by title status.

Related Privileges

Group Privilege Column
Asset Management Manage Asset Title Statuses Enabled

For more information, refer to Control User Access.

To add an asset title status, do the following:

  1. Go to arrow_forward Administration, then go to Rental Info arrow_forward Assets arrow_forward Asset Title Statuses.
    The Asset Title Statuses page displays.

  2. Click Add Status.
    The Add Asset Title Status pop-up displays.

  3. Enter the following information:

    Field Description

    Description

    An optional description of the status.

    Name

    The name of the status to display on the Asset Title Statuses page.

  4. To finish, click Save & Close or to save and create additional asset title statuses, click Save & New.
    The new asset title status is added to the list.
