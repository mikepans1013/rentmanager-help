Change a Prospect Status

Prospects in Rent Manager are potential tenants. You can track which prospects choose to rent with you by changing a prospect's Status. All new prospect accounts start with the Prospect status but can be changed to Tenant, Lost, or Lost/Rejected. For example, if a prospect decides to rent with you, you can update their status to Tenant and convert their prospect account to a tenant account with a lease. You can also track which prospects ultimately choose not to rent with you and use reports like Lost Prospect Breakdown and Box Score to track the effectiveness of your leasing agents and marketing campaigns.

Related Privileges

Group Privilege Column
Tenants/Prospects Prospects View, Edit

For more information, refer to Control User Access.

To change a prospect's status, do the following:

  1. Go to  arrow_forward Rental Info arrow_forward General arrow_forward Prospects and select the prospect account for which you want to change status.
    The prospect's details page displays.

  2. On the action bar on the right, click arrow_forward Prospect Status.
    The Prospect Status Change pop-up displays.

  3. Choose a status in the New Status drop-down and enter the related information. See the table below for more information about each prospect status:

    Status Description

    Tenant

    Related Privileges

    Group Privilege Column
    Tenants/Prospects Change account status to tenant Enabled

    For more information, refer to Control User Access.

    To move a prospect into a unit, do the following:

    1. Select Tenant in the New Status drop-down.

    2. Click Move In.
      The Move In wizard displays.

    3. Complete the Move In wizard by entering information about the new tenant's lease. For more information, refer to Move In Wizard.

    4. Click Move In.
      The prospect account becomes a tenant account, and the lease information is added to the new tenant.

    Lost/Rejected

    Related Privileges

    Group Privilege Column
    Tenants/Prospects Change Account Status to Lost/Lost-Rejected Enabled

    For more information, refer to Control User Access.

    If you choose not to proceed with leasing to this prospect, select Lost/Rejected from the New Status drop-down and enter the following information:

    Lost Date

    The date on which the prospect's tenancy was declined. The Lost Date defaults to today's date. You can edit the date as needed.

    Reason

    The reason you decided that the prospect should not lease with you. Active lost reasons of only the Lost-Rejected type display in the drop-down when you select this status. For more info, refer to Lost Reasons (Page).

    Description

    A description explaining the prospect's status. The description displays in the prospect's history/notes and in reports, such as the Lost Prospect Breakdown report.

    Lost

    Related Privileges

    Group Privilege Column
    Tenants/Prospects Change Account Status to Lost/Lost-Rejected Enabled

    For more information, refer to Control User Access.

    If a prospect chooses not to rent with you, select Lost from the New Status drop-down and enter the following information:

    Lost Date

    The date on which the prospect declined to rent with you. The Lost Date defaults to today's date. You can edit the date as needed.

    Reason

    The reason the prospect decided not to rent with you. Active lost reasons of only the Lost type display in the drop-down when you select this status. For more info, refer to Lost Reasons (Page).

    Description

    A description explaining the prospect's status. The description displays in the prospect's history/notes and in reports, such as the Lost Prospect Breakdown report.

    Prospect

    Related Privileges

    Group Privilege Column

    Tenants/Prospects

    Change account status to prospect

    Enabled

    For more information, refer to Control User Access.

    To return a lost, rejected, or converted prospect to an active prospect status, select Prospect in the New Status drop-down and click Save.

  4. Click Save.
    The prospect's status is updated.
