# Add a Job Type

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/Jobs-Type-Add.htm

Rent Manager allows you to define job types so that each job can be categorized for reporting purposes. For example, you can create a Kitchen Renovation job type for kitchen-specific renovations, a Rekey Locks job type for changing unit locks, or a Landscaping job type for outdoor renovations.

 Related Preferences

 In order to use the job costing tool in Rent Manager , Enable job costing must be checked in system preferences. For more information, refer to General Options (System Preferences) .

 To add a job type, do the following:

 -
 Go to arrow_forward Accounting arrow_forward Accounting Setup arrow_forward Job Types .
The Job Types page displays.

 -
 At the top of the page, click Add Job Type .

 -
 Enter the following information in the available fields:

 Field
 Description

 Name

 The name of the job type (e.g., Rekey Locks , Landscaping , Construction , Renovation ).

 Description

 A brief description about the job type (e.g., Change locks on all units , Outdoor renovations , Generalized construction , Large-scale renovation ).

 -
 To finish, click Save & Close , or to add additional job types, click Save & New .
The new job type(s) is created and can be selected for jobs.
