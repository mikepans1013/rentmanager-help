# Print Blank Checks

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/Checks-Print-Blank.htm

Rent Manager allows you to print a check that includes only the check number and bank account information. For example, if a vendor was coming on site to do an evaluation but didn't provide a bill upfront, you can print a blank check and fill in the recipient and dollar amount by hand once you have the total due for the visit.

 More Information

 To print blank checks, the bank you wish to print the check from must be enabled with MICR. For more information, refer to Set Up MICR for Checks and Deposits .

 To print blank checks, do the following:

 -
 Go to arrow_forward Payables arrow_forward Checks arrow_forward Print Checks .
The Print Checks page displays.

 -
 On the Print button, click the drop-down arrow and select Print Blank Checks .
The Print Blank Checks pop-up displays.

 -
 In the Bank field, select the desired bank account from which checks are drawn.

 Related Privileges

 This field populates with only banks to which you have access. Your access to banks can be managed on the user's details page. For more information, refer to Limit Access to a Bank or Credit Card .

 -
 If applicable, in the First Check Number field, enter the check number of the first blank check you are printing. If you are printing multiple blank checks, Rent Manager numbers each check starting with this number. By default, the next available check number at the selected bank displays.
