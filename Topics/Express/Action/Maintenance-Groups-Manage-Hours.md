# Manage Maintenance Group Hours

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/Maintenance-Groups-Manage-Hours.htm

With the Maintenance Scheduling feature, you can group properties and maintenance technicians together on one maintenance schedule, making it easier to view tech availability and schedule service visits. You can add or edit maintenance group hours from the Maintenance Groups page.

 More Information

 This feature is licensed and must be purchased separately. For more information, contact your sales representative at sales@rentmanager.com .

 To edit or add hours for a maintenance group, do the following:

 -
 Go to arrow_forward Services arrow_forward Service Setup arrow_forward Service Manager arrow_forward Maintenance Groups .
The Maintenance Groups page displays.

 -
 Select a maintenance group from the list.

 -
 Click Edit Time Blocks .

 -
 To update the group's current hours, use the From Time and To Time drop-downs next to each day. If applicable, in the # of Issues column, you can edit the total number of issues that can be booked for each time block.

 -
 To add new time blocks, click Add Time Blocks .

 -
 Enter the following information:

 Field
 Description

 Days

 Check the days for which the hours selected in the From Time and To Time fields apply.

 From Time

 Select the time at which the group's availability begins on the days checked in the Days field.

 To Time

 Select the time at which the group's availability ends on the days checked in the Days field.

 # of Issues

 Enter the total number of issues that can be booked for each time block.

 -
 If applicable, click Add to add additional hours. For example, if you want to add in time for breaks or to separate your time blocks into smaller sections, then click Add to set different hours for each segment of the time block.

 -
 When finished adding hours, click Add .

 -
 Click Save to complete adding the new hours and close the pop-up.
The maintenance group's hours are added and also display on the Maintenance Schedule page.
