Add an Asset Type

Asset types are categories assigned to assets to provide additional information and filter asset lists by type. Creating asset types and then assigning the types to assets as part of asset management also helps you run reports on assets based on the type. For example, having asset types assigned allows you to run an Asset Depreciation Schedule report or an Overdue Asset Maintenance report only for the specific asset types you designate.

Related Privileges

Group Privilege Column
Asset Management Asset Types Add, View

For more information, refer to Control User Access.

To add a new asset type, do the following:

  1. Go to arrow_forward Administration, then go to Rental Info arrow_forward Assets arrow_forward Asset Types.
    The Asset Types page displays.

  2. Click Add Asset Type.
    The Add Asset Type pop-up displays.

  3. Enter the following information:

    Field Description

    Assets of this type are homes

    Assets of this type are designated as home-type assets. When enabled and the type is selected on an asset, the asset's details page includes fields specific to homes and allows an additional lease to be associated with the asset. This is beneficial in manufactured housing situations when you need to lease both the home (the asset) and the lot (the unit).

    Related Preferences

    If the Automatically create a lease for linked 'home' assets or units option is enabled in system preferences, and on a lease, you select a unit that is linked to an asset with an asset type that has the option Assets of this type are homes enabled, an additional lease is automatically generated. For more information, refer to General Options (System Preferences).

    Default Workflow

    The predetermined workflow this asset type follows.

    Description

    Additional information about when to use this type of asset.

    Name

    The name of the asset type (e.g., Dishwasher, Disposal, Furnace, Multi-Section, Single-Section, and so on).

  4. To finish, click Save & Close or to save and create additional asset types, click Save & New.
    The new asset type is added to the list.
