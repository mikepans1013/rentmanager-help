Add an Association Board Member

Board members are the governing body of an association and an integral part of your association. Assigning members to your board in Rent Manager allows you access to additional board-specific features like member polls and surveys, sharing specific property files amongst board members, and viewing and voting on architectural requests. On the Board Members pop-up, you can designate tenants or tenant contacts as board members.

Related Privileges

Group Privilege Column
Properties/Units Properties View, Edit

For more information, refer to Control User Access.

To add an association board member, do the following:

  1. Go to arrow_forward Rental Info arrow_forward General arrow_forward Properties and select an association-type property from the list.
    The property's details page displays.

  2. On the action bar to the right, click arrow_forward Board Members.
    The Board Members pop-up displays.

  3. Click Add.
    The Board Member Details pop-up displays.

  4. Enter the following information:

    Field Description

    Comments

    Additional comments regarding this board member, such as Can fill in for the secretary on occasions the secretary is out.

    Contact Name

    The tenant contact account of the board member.

    Email

    The email address that the board member uses to log into Tenant Web Access (TWA).

    More Information

    If the entered email address does not match an existing TWA account, Rent Manager asks the user to create a TWA account for the email address.

    Tenant

    The primary tenant account of the board member.

    Term End date

    The date on which the contact completes their term as a board member. On this date, the contact loses access to board-specific property files and TWA items.

    Term start date

    The date on which the contact starts as a board member. On this date, the contact gains access to board-specific TWA items.

  5. Click Save.
    The new member is added to the board.
