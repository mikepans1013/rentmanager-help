# Add an Issue Status

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/Issue-Status-Add.htm

Issue statuses are conditions that you create to describe the current progress of an issue (e.g., New , Work in Progress , Resolved , Unresolved ). You can add new statuses that users can select when filling out issues and format the statuses to add visual distinction.

 To add a new issue status, do the following:

 -
 Go to arrow_forward Services arrow_forward Service Setup arrow_forward Service Manager arrow_forward Statuses .
The Issue Statuses page displays.

 -
 On the action bar to the right, click Add Status .

 -
 Enter a label for the new issue status in the Name field (e.g., Work in Progress , Unresolved , Resolved , Escalated ).

 -
 In the Format section, select one or more of the font emphasis options ( Bold , Italic , Underline ) to specify how the Status displays on the Issues page.

 -
 To change the display color of the Name , click the Font Color box. To set a color, click the color swatch.

 Either of the following methods can be used to set a color:

 Enter the value or hex code of the desired color.

 Click OK to set the selected color.

 -
 Enter a brief Description of the status (e.g., Issue has been resolved , Issue has been closed but unresolved , Issue has been escalated to a senior employee ).

 -
 To finish, click Save & Close , or to create additional issue statuses, click Save & New .
The new issue status is created and can be used on issues.
