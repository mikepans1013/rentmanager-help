Delete a Management Fee Setup

The primary reason to delete an existing management fee setup is that it was added in error and you want to remove the entry so that the setup is unavailable for use.

Warning

Deleting a management fee setup is permanent and cannot be undone. If you no longer wish to use the setup or the fee structure is changing, instead of deleting it, set an end date for the setup. This allows you to retain the information attached to that management fee setup while making it inactive so it is no longer used after that date. To end management fee setup, on the Fees Setup pop-up, enter an Active End Date and click Save.

Related Privileges

Group Privilege Column
Properties/Units Management fee setup Delete
Properties View, Edit

For more information, refer to Control User Access.

To permanently delete a management fee setup, do the following:

  1. Go to arrow_forward Rental Info arrow_forward General arrow_forward Properties and select a property from the list.
    The property's details page displays.

  2. On the action bar to the right, click arrow_forward Fees Setup.
    The Fees Setup pop-up displays.

  3. At the top right of the pop-up, click Delete Management Fee Setup.
    The Delete Management Fee Setup pop-up displays.

  4. Click Yes.
    The management fee setup is removed from the Fees Setup pop-up.
