Add a One-Time CAM Expense Adjustment

To ensure that your common area maintenance (CAM) reconciliation values are accurate, you can manually create additional expense adjustments. This allows you to change the expensed general ledger (GL) account for a particular charge or account for one-time exemptions and discounts that are part of a tenant's contract.

For more information, refer to Control User Access.

To add a one-time CAM expense adjustment, do the following:

  1. Go to arrow_forward Receivables arrow_forward Commercial arrow_forward CAM Expense Adjustments.
    The CAM Expense Adjustments page displays.

  2. Click Add One Time Expense.

  3. Enter the expense adjustment's information into the available fields described below.

    Field Description

    Property

    The property to which this adjustment is applied. Only properties with a Property Type of Commercial display.

    Tenant

    The tenant lease(s) to which this adjustment is applied. To view more information about each lease and filter the list, click .

    Adj. Date

    The date of the adjustment as it displays during CAM reconciliations. This adjustment is included in the CAM reconciliation only if it falls in the selected date range for the reconciliation.

    GL Account

    The general ledger (GL) account being expensed for this adjustment.

    Adj. Amount

    The total dollar amount added to the expense account for this one-time adjustment. To deduct an amount from the expense account, enter a negative value. For example, to deduct $5,000 from the selected GL account, enter -5000.

    Internal Note

    A note providing further context for this adjustment that displays only for Rent Manager users.

    Tenant Note

    A note providing further context for this adjustment that displays on the tenant's CAM Reconciliation Statement. For more information, refer to CAM Reconciliation Statement (Report).

  4. Click Save to complete the creation process and close the pop-up. Alternatively, click Save and New to complete the creation process and refresh the pop-up to add another one-time expense adjustment.
    The one-time CAM expense adjustment is added.
