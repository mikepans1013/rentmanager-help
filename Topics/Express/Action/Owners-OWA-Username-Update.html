Update an Owner Web Access (OWA) Username

Owners with Owner Web Access (OWA) accounts use their email addresses as their username to log into the web portal. If the owner wants to change the email address they use to log in, you can make the update for them directly from their account in Rent Manager.

Related Privileges

Group Privilege Column
Owners Owners View, Edit

For more information, refer to Control User Access.

To update an owner's OWA username, do the following:

  1. Go to arrow_forward Owners arrow_forward General arrow_forward Owners and select the owner's account.
    The owner's details page displays.

  2. On the action bar to the right, click arrow_forward OWA Settings.
    The Web Access Settings pop-up displays.

  3. On the email address to change, click arrow_forward Update Username.

  4. In the Email Address field, enter the email address to be used as the new username.

  5. Select Require email and password reset for this web user to force the user to confirm their old password and create a new one before accessing their account.

  6. Click Save.
    The username is updated and an email is sent to the new username, prompting them to log into OWA with the new email address. The next time the owner logs into OWA, they can use their updated username.
