# Add an Architectural Request

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/Architectural-Request-Add.htm

If your property is an association-type, such as a homeowners association (HOA), you can use the architectural requests tool in Rent Manager to document any requests that need to be approved by association members, such as planting trees, adding gardens, or repainting the building a specific color.

 Related Preferences

 If you have the Tenant Web Access (TWA) portal, you can enable settings to allow architectural requests to be submitted and voted on by tenants directly through TWA. For more information, refer to Tenant Web Access Architectural Requests Page Setup (System Web Preferences) .

 To create a new architectural request, do the following:

 -
 Go to arrow_forward Services arrow_forward Community arrow_forward Architectural Requests .
The Architectural Requests page displays.

 -
 Click Add Request .

 -
 In the Details section, enter the following information:

 Field
 Description

 Attachments

 To browse your computer for a file to attach to the request, click Upload Files .

 Description

 The detailed description of the architectural change the tenant is requesting.

 Form

 The architectural request form used to gather or document additional information about the request. This form populates fields in the Architectural Request Detail pop-up's Additional Information tile.

 Property

 The association-type property that the requesting tenant is a member of.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Request

 A brief summary of the requested architectural change.

 Status

 The current state of the request (e.g., Pending , Approved , Denied ).

 Tenant

 The tenant making the architectural request.

 -
 In the Add History section, enter an optional note that is created when the architectural request is saved. In the Category field, select a history category from the drop-down list, then enter a comment in the Note field.

 -
 Click Save & Close to complete the architectural request creation process and close the pop-up. Alternatively, click Save & New to finish adding the request and refresh the pop-up to create another request.
The request is added to Rent Manager and can be voted on by the designated board or committee for the associated property.
