# Roll Back the Last Management Fee Posting for a Property

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/Management-Fee-Posting-Rollback.htm

If you posted management fees for a property in error, or noticed a mistake on a property's most recent posting that needs to be corrected, you can roll back the most recent management fee posting for a specific property. Even if you posted fees for multiple properties at once, you can opt to undo only the posting for an individual property without affecting the other properties in that posting.

 More Information

 If you need to roll back an entire management fee posting for all properties included in the posting, you can do so from the Posting Rollback page. You can also use this page to roll back postings that are older than the most recent posting. For more information, refer to Roll Back a Posting .

 To roll back a management fee posting for a single property, do the following:

 -
 Go to arrow_forward Rental Info arrow_forward General arrow_forward Properties and select a property.
The property's details page displays.

 -
 On the action bar to the right, click arrow_forward Fees .
The Property Fees pop-up displays.

 -
 Verify that the most recent posting at the top of the list is the posting you wish to roll back for this property.

 -
 Click Rollback Last Posting .
The most recent management fee posting for only this property is reversed.

 More Information

 If you need to repost those management fees for the property, ensure that when you post management fees again you do so only for the property you rolled back or the other properties will have duplicate postings. For more information, refer to Post Management Fees .
