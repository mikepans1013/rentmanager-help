Record a Security Deposit Payment

Once a security deposit is charged to a tenant or prospect account, you can receive a payment for that deposit. A security deposit is only considered held once a payment is received for the charge. If you did not record the receipt of payment when adding the security deposit charge, you can do so subsequently by entering a payment on the tenant's or prospect's account.

Related Privileges

Group Privilege Column
Tenants/Prospects Tenants View
Prospects View
Receivables Take tenant payments Enabled

For more information, refer to Control User Access.

To record a payment for a security deposit, do the following:

  1. Depending on what type of account you wish to record the deposit on, follow one of the options in the table:

    Entity Type Description

    Tenant

    arrow_forward Rental Info arrow_forward General arrow_forward Tenants and select a tenant account.

    Prospect

    arrow_forward Rental Info arrow_forward General arrow_forward Prospects and select a prospect account.

    The tenant's or prospect's details page displays.

  2. On the Transactions tile, click Add Payment.
    The Add Payment pop-up displays.

  3. In the Payment Info tile, enter information about this payment into the appropriate fields.

    Option Description

    Amount

    The full dollar amount of the payment received.

    Date

    The date the tenant or prospect is making the payment.

    Memo

    A brief comment about this payment, such as For security deposit. Payment memos display on the prospect or tenant's View Transactions pop-up in the Comment column.

    Reference #

    The following forms of payment to describe the transaction are available to select.

    More Information

    If, in the Payment Summary section, the Process via ePay option is selected, this field displays ePay and cannot be edited.

    Cash

    Record a cash payment.

    CC

    Record a credit card payment.

    Check

    Manually type the check number into the Reference # field to record a check payment.

    MO

    Record a money order payment.

  4. In the Open Charges tile, verify that the Pay? box is checked on the security deposit charge line item and that the appropriate amount is entered in the Current Payment column for that charge.

  5. In the Payment Summary tile, select additional payment options and verify the payment is being applied appropriately.

    Field Description

    Amount Due

    If applicable, the total dollar amount due for all open tenant charges after any partial payments are applied.

    Amount Paid

    If partial payments are allocated to any charges, the total dollar amount of those partial payments displays.

    Current Payment

    The total dollar amount of the payment as entered in the Payment Info tile in the Amount field.

    Original Amount

    The total dollar amount of all open tenant charges before any partial payments are applied.

    Overpayment

    If the amount of the payment exceeds the total Amount Due, the exceeded amount displays. This field displays only when making a payment for a positive amount. The overpaid amount can then be applied as prepay allocations in the Prepay Allocations pop-up or left to be applied as a credit at a later time.

    Overpayment = Amount - Amount Due

    Payment Notes

    Any history/note items with the Show on payments tab option enabled display. If there are no items with this option checked, this field does not display. For more information, refer to Tenant History/Notes (Pop-Up) and Prospect History/Notes (Pop-Up).

    Process via ePay

    Check to process the payment as an ePay payment. This option is available only if the account's associated property is set up for ePay. For more information, refer to Set Up ePay for Tenants and Prospects.

    When this option is checked, the Reference # field is automatically updated to ePay and cannot be edited.

    View Receipt

    Check to print a receipt for the prospect or tenant after accepting the payment.

  6. Click Add Payment
    The payment is recorded in the Transactions tile. On the top of the tenant's account, the Security Deposit field displays the amount held.
