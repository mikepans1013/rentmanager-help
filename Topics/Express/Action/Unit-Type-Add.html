Add a Unit Type

Unit types are categories you create to describe the various units that are available at your managed properties. You can add as many unit types as you need to accurately classify your rental units. For example, you can create a unit type such as PARK to represent parking spaces available at your properties to be rented by tenants.

Related Privileges

Group Privilege Column
Properties/Units Unit types Add, View

For more information, refer to Control User Access.

To add a new unit type, do the following:

  1. Go to arrow_forward Rental Info arrow_forward General arrow_forward Unit Types.
    The Unit Types page displays.

  2. Click Add Unit Type.

  3. Enter information about the unit type in the following fields:

    Field Description

    Unit Type

    The abbreviated name of the unit type that displays on the unit's scoreboard or on reports such as the Unit Type Listing report. For example, you could define a 2 bedroom-2 bath apartment as 2B2B.

    Description

    The details used to describe the unit type. For example, if the unit type is 2B2B, the description can be used to enter the full name as 2 Bedroom/2 Bathroom.

    Other Rentable Item

    Indicates that units of this type are not included in occupancy-based reporting or calculations and do not have marketing information associated with them. For example, storage units and garages may be leased by tenants but are not consider occupied and therefore are excluded from vacancy based reports such as the Unit Turnover report.

    Properties

    The properties at which the unit type applies. For example, PARK, a unit type for parking spaces, should only be available to select at properties where parking spaces can be rented by tenants.

  4. Click Save & Close to complete the unit type creation process and close the pop-up. Alternatively, click Save & New to finish adding the unit type and refresh the pop-up to create another unit type.
