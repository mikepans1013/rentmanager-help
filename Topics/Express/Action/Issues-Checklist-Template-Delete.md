# Delete an Issue Checklist Template

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/Issues-Checklist-Template-Delete.htm

Deleting an issue checklist template removes it from the Checklist Templates page and is no longer available when adding items to a checklist. If items from a checklist template were added to a service issue, those items are not deleted from any applicable service issues.

 Warning

 Deleting an issue checklist template is permanent and cannot be undone. If you no longer wish to use the template, instead of deleting it, consider marking it as inactive. This allows you to retain the information attached to that template while removing it from future use. For information on how to make an issue checklist template inactive, refer to Checklist Template Details (Pop-Up) .

 Related Privileges

 For more information, refer to Control User Access .

 To permanently delete an issue checklist template, do the following:

 -
 Go to arrow_forward Services arrow_forward Service Manager arrow_forward Checklist Templates .
The Checklist Templates page displays.

 -
 To the right of the checklist template, click arrow_forward Delete .
 The Confirm Delete pop-up displays.

 -
 Click Yes .
The template is removed from the Checklist Templates page.
