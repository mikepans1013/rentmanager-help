# Assign a Unit Type to Properties

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/Unit-Type-Assign-to-Property.htm

Unit types represent the various categories of unit that are available at your managed properties. Unit types can take many forms, such as living spaces (e.g., one bedroom, one bathroom), individual offices, storage units, lots of land, parking spaces, etc. Once you've created unit types, you can assign them to your properties to track amenities and match prospects to their desired units. Unit types must be assigned to a property before they can be applied to the units associated with the property.

 To assign a unit type to a property, follow the steps below:

 -
 Go to arrow_forward Rental Info arrow_forward General arrow_forward Unit Types and select a unit type from the list.
The Unit Type details page displays.

 -
 On the action bar on the right, click arrow_forward View Properties .

 -
 Check each Property to be associated with the selected unit type. Alternatively, select from the Property Group drop-down field to automatically select all properties associated with predefined property group. For more information, refer to Property Groups (Page) .

 -
 If all units associated with this type at the property have the same rent amount, you may enter a default Rent Amount .

 -
 Click Save .
The properties associated with the selected unit type are updated, and now these unit types can be applied to the units at the property.
