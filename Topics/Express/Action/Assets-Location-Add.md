# Add an Asset Location

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/Assets-Location-Add.htm

The Add Asset Location pop-up allows you to assign assets to units and properties to track their location in addition to tracking the use and condition of assets in Rent Manager . For example, you may wish to add an asset location when moving a manufactured home to a new lot or when replacing a washing machine rented by a tenant.

 To add an asset location, do the following:

 -
 Go to   arrow_forward Rental Info arrow_forward General arrow_forward Assets and select an asset from the list.
The asset's details page displays.

 -
 On the Asset Location tile, click .
The Asset Locations pop-up displays.

 -
 Click Add Asset Location .

 -
 Enter the following information:

 Field
 Description

 From

 The day the asset arrives at this location.

 Property

 The property at which the asset will be located.

 To

 The day the asset leaves this location. If this is the current location, leave this field blank.

 Unit

 If applicable, the unit at which the asset is located.

 More Information

 Home-type assets in Rent Manager   cannot occupy the same unit as a prospect or tenant owner RV.

 -
 To finish, click Save & Close or to save and create additional locations, click Save & New .
The new asset location is recorded and added to the Asset Location tile. If applicable, the previous entry is given a To date that is one day prior to the start of the new location status.
