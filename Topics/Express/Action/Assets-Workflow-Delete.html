Delete an Asset Workflow

The primary reason to delete an asset workflow is that it was added in error and you want to remove the entry so that the workflow is unavailable for use.

Warning

Deleting an asset workflow is permanent and cannot be undone. If you no longer wish to use the asset workflow, instead of deleting it, consider marking it as inactive. This allows you to retain the information attached to that workflow while removing it from available asset workflows. To make an asset workflow inactive, on the Asset Workflow details page, uncheck Active.

Related Privileges

Group Privilege Column
Asset Management Manage Asset Workflows Enabled

For more information, refer to Control User Access.

To delete an asset workflow, do the following:

  1. Go to arrow_forward Rental Info arrow_forward Rental Info Setup arrow_forward Assets arrow_forward Asset Workflow.
    The Asset Workflows page displays.

  2. To the right of the asset workflow, click  arrow_forward Delete.
    The Confirm Delete pop-up displays.

  3. Click Yes.
    The workflow is removed from the Asset Workflows page.
