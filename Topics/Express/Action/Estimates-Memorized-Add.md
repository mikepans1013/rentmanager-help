# Add a Memorized Estimate

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/Estimates-Memorized-Add.htm

If you frequently create estimates for the same charges, such as fees for damages, you can add a memorized estimate to streamline the process. When estimates are generated from memorized estimates, all general information, tax options, and inventory items populate on the new estimate. By eliminating the need to manually enter data for routine estimates, memorized estimates ensure that you can quickly deliver the appropriate information to the tenants, prospects, and owners who request them.

 More Information

 If you want to use an existing estimate as the basis for a memorized estimate instead of making one from scratch, go to arrow_forward Receivables arrow_forward General arrow_forward Estimates , select the estimate you want to memorize, then click Memorize .

 To add a memorized estimate, do the following:

 -
 Go to   arrow_forward Receivables arrow_forward General arrow_forward Memorized Estimates .
The Memorized Estimates page displays.

 -
 Click   Add Memorized Estimate .
The Add Memorized Estimate pop-up displays.

 -
 Enter general information about the estimate into the following fields:

 Field
 Description

 Address

 The address associated with the estimate. This field automatically populates with the selected Property 's address marked as Default .

 Comments

 A message with additional information or instructions regarding the estimate. Click to add a memorized comment.

 Description

 An additional note to further explain the purpose of this memorized estimate that displays on the Memorized Estimates page.

 Name

 A unique title for this memorized estimate.

 Property

 The property for which the estimate is being created. For Owner estimates, this field defaults to the property established as your property management company in system preferences. For more information, refer to Management Company (System Preferences) .

 Reference

 An optional message about the transaction contained within the memorized estimate.

 Sales Rep

 The Rent Manager user responsible for creating the charge(s) or selling the associated inventory item(s) to the estimate recipient.

 More Information

 Only users with the option Sales Rep/Leasing Agent checked on their account display in the list. For more information, refer to User Details (Page) .

 Type

 The kind of account the memorized estimate is for ( Tenant or Owner ).

 More Information

 Estimates with the type Tenant can also be generated for prospect accounts.

 -
 Enter tax information if any of the inventory items on the estimate are taxable.

 Field
 Description

 Tax %

 The tax percentage rate to be applied to the total of taxable items.

 Tax Type

 The tax type to be applied to the taxable items. The tax types available can be customized for your database. For more information, refer to Tax Types (Page) .

 Taxable

 A indicates that expenses related to this estimate are subject to additional tax expenses.

 Taxable Amount

 The running sum of all inventory items on the estimate that are marked as taxable. You determine which items are taxable in the next step.

 -
 Add inventory items to the estimate by clicking   Add Item and enter information into the following fields as needed:

 Column
 Description

 Item

 The inventory item to purchase as part of this estimate. Once an item is selected, the Cost and Memo fields populate with the item’s information. For more information, refer to Inventory Items (Page) .

 More Information

 For longer estimates, you can select an inventory item note to use as a category header to help organize the items in your estimate. For example, you could add a line with a note called Cleaning with multiple line items related to cleaning costs below it, then add a line item with a note for Damage Control and add line items below it that are related to repairs. For more information, refer to Inventory Item Notes (Page) .

 Inventory item notes are not true items that can be purchased, so they populate data only in the Memo column. All other columns are disabled for inventory item notes.

 Memo

 Additional information explaining the inventory item. By default, this field populates with the Description from the inventory item.

 Quantity

 The quantity of the item to purchase.

 Cost

 The purchase price you pay per item.

 Amount

 The total dollar amount that the purchased quantity of the item costs you before markup and taxes are added.

 Amount = Quantity * Cost

 Markup

 An additional dollar amount to charge beyond the base cost you paid for the item. If a Markup has been established on the item's details page, it displays automatically.

 If the Markup is a flat dollar amount, enter that amount in the column. If the Markup is a percentage, enter the number followed by a % symbol.

 Tax

 If the inventory item is taxable, check this column for that line. When the column is checked, the Total for this line item is added to the Taxable Amount field above.

 Total

 The total dollar amount of the item(s) after the Markup is added.

 -
 After verifying that the total fields are accurate, click Save to create the memorized estimate. Alternatively, click Save & New to start a new estimate, or Save & Close to return to the Memorized Estimates page.

 Field
 Description

 Markup Total

 The total dollar amount of markup added to the cost of all items on the estimate.

 Subtotal

 The subtotal of the estimate before markups and taxes. This is the sum of all lines in the Amount column.

 Tax Total

 The total dollar amount of taxes added to the estimate based on the Taxable Amount .

 Total Amount

 The total dollar amount of the estimate, including all items, taxes, and markup.
