# Add a Property File

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/Property-File-Add.htm

Rent Manager allows you to upload relevant documents and files for a property and, optionally, make any of those files available via Tenant Web Access (TWA) . You can upload images, Rent Manager documents, PDFs, and word processor documents and organize these files into folders. New files can be added from the Add File pop-up on the property's details page.

 To add a new property file, do the following:

 -
 Go to arrow_forward Rental Info arrow_forward General arrow_forward Properties and select a property from the list.
The property's details page displays.

 -
 On the Property Files tile, click .
The Property Files pop-up displays.

 -
 At the top of the pop-up, click Add arrow_forward Add File .
The Add File pop-up displays.

 -
 In the File Attachment field, click   File Upload to select a file from your computer to upload.

 -
 Enter information into the following fields.

 Field

 Description

 Board Only

 Makes this file available only for tenants who are established as association board members at the property.

 This option is available only if the property has a Property Type of Association . For more information, refer to Association Board Members (Pop-Up) .

 Description

 Any further details about the file to display internally to Rent Manager users.

 File Name

 The name you wish to display for the file in Rent Manager and, if applicable, Tenant Web Access (TWA) . By default, the name of the uploaded file automatically populates.

 Folder

 To select a folder in which you wish to save the file, click . This field displays only if one or more folders are added to the property files for the property.

 Show in TWA

 Makes this file available for tenants to view and download in TWA.

 Related Preferences

 Before a file can be viewed in Tenant Web Access (TWA) , the Show Files option must be enabled in system web preferences. For more information, refer to Tenant Web Access Documents Page Setup (System Web Preferences) .

 -
 Click Save .
The file is added to the property's files.
