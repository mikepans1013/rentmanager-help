Add a Location

By creating a new location in Rent Manager, you can organize and update business data independently from the default location. For example, if you work with more than one property management company, you can create multiple locations to keep the data for each company separate. You can also restrict access to select users and set unique user privileges in each location, which can be utilized to limit the permissions a user has in one location without affecting their access in another.

More Information

Locations are a licensed feature and must be purchased separately. For more information, contact your sales representative at sales@rentmanager.com.

More Information

If you use per unit Rent Manager licensing, each unit in each location uses one license.

For more information, refer to Assign Unit Licenses.

Related Privileges

Locations Locations Add, View

For more information, refer to Control User Access.

To create a new location, do the following:

  1. Go to arrow_forward Administration, then go to Locations arrow_forward Manage Locations.
    The Manage Locations pop-up displays.

  2. Click Add.


  3. Enter a unique identifier for this location in the Name field.

  4. In the Copy From field, select an existing location from which to copy data to the new location.

  5. In the User/Role field, select the user(s) that can access this location.

  6. In the Clear Database Info field, select one of the options below for handling the data in the Copy From location.

    Field Option

    Yes

    Removes most of the data from the location selected in the Copy From field. This deletes all properties, rental units, unit types, vendors, tenants, owners, prospects, and transaction history, along with any custom records you entered into the database (e.g., general ledger accounts, bank accounts, credit card accounts, charge types, user defined fields, and so on).

    More Information

    Clearing the database does not remove the information that is included in Rent Manager by default, such as charge types and the chart of accounts.

    No

    Copies all of the data in the Copy From location to the new location.

    Warning

    If you select this option, all Task Automation schedules, automated notification setups, and ePay settings are carried to the new location, which may result in redundant communications and duplicate charges.

  7. Check Inactive Users if, in the User/Role field, you wish to select inactive user accounts.

  8. Click Save.
    The location is added to Rent Manager.
