# Link an Unlinked Call

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/rmVoIP-Call-Link.htm

rmVoIP is the fully independent, business-class phone system offered by LCS . rmVoIP provides enterprise-grade phone features like auto-attendants, hunt groups, conference calls, call forwarding, call recording, and more. If you receive a call from a phone number that is not listed on an account in Rent Manager , you can manually link the calls from the Unlinked Calls page.

 To link an unlinked call, do the following:

 -
 Go to   arrow_forward Communication arrow_forward Texting/Phone arrow_forward   rmVoIP Unlinked Calls and select a call from the list.

 -
 In the Call History tile, enter the following information.Once the call is linked to an account, the note displays on the account's History/Notes .

 Field
 Description

 Category

 The history category that identifies what the call was about.

 Comment

 The explanation of what you discussed with the caller.

 Contact was made

 If checked, signifies that you spoke with the caller, as opposed to a voicemail message or receiving no answer from the caller.

 -
 In the Link Call tile, select the Account Type of Tenant , Prospect , Owner , Owner Prospect , Property or Vendor, to link the call to.

 -
 Enter the Account Name of the entity associated with the call.

 -
 Click Save .
The call is linked to the selected account in Rent Manager .

 More Information

 To unlink a call go to the entity's details page. On the History/Notes tile, click and on the history/note item where the call is logged, click to select the option Unlink rmVoIP Phone Number .
