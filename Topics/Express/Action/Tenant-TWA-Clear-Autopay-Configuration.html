Clear a Tenant's AutoPay Configuration

If a tenant or prospect has enabled an AutoPay schedule through Tenant Web Access (TWA), that AutoPay setup can be managed through their account in Rent Manager.

Once the tenant has created an AutoPay schedule, you have the ability to review the tenant's configuration and clear that schedule if necessary.

Related Privileges

Group Privilege Column
Tenants/Prospects Tenants View, Edit
Prospects View, Edit

For more information, refer to Control User Access.

Related Preferences

If AutoPay has been enabled in system web preferences, tenants have the ability to create and manage automatic payment schedules through TWA. For more information, refer to Tenant Web Access AutoPay (System Web Preferences).

To access Tenant Web Access settings, at least one location must be enabled for TWA. For more information, refer to Licensing (System Web Preferences).

To clear the tenant’s or prospect's current AutoPay configuration, do the following:

  1. Go to the account you wish to edit as described below.

    Entity Navigation

    Tenants

    arrow_forward Rental Info arrow_forward General arrow_forward Tenants and select a tenant from the list.

    Prospects

    arrow_forward Rental Info arrow_forward General arrow_forward Prospects and select a prospect from the list.

    The tenant's or prospect's details page displays.

  2. On the action bar to the right, click arrow_forward TWA Settings.


  3. Click Disable AutoPay.

    Click Disable.

    The AutoPay setup is no longer configured, and the payment schedule that was previously set is cleared so no future payments will be processed automatically. The tenant is sent an email notifying them the AutoPay schedule was deactivated.

    More Information

    Completing this step does not prevent the account from creating a new payment schedule through Tenant Web Access. To fully disable the AutoPay feature in Tenant Web Access for all tenants and prospects, uncheck Enable AutoPay Configuration in system web preferences. For more information, refer to Tenant Web Access AutoPay (System Web Preferences).

    To fully disable the AutoPay feature in Tenant Web Access for a specific tenant or prospect, select Don't Allow TWA Payment on the tenant or prospect's details page. Selecting this option disables all payments from Tenant Web Access. For more information, refer to Limit Payment Options for Tenants.
