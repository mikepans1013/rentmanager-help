Add a Short Term Rental Discount

Discounts are used in a variety of ways for short term rental (STR) reservations. In a property's STR settings, you can create discounts as a flat amount or as a percentage to reduce the reservation fees for stays that occur during seasonal events, promotional campaigns, or based on the duration of the stay or the time of the year the guest reserves the unit. Once the discount(s) is created, all relevant discounts are available to apply on STR reservations during booking.

More Information

Discounts for short term rental reservations can be created only for properties with a Property Type of RV/Campground.

For more information, refer to Control User Access.

To add a new discount to a property, do the following:

  1. Go to arrow_forward Rental Info arrow_forward General arrow_forward Properties and select the desired property.
    The property's details page displays.

  2. On the action bar to the right, select arrow_forward STR Settings.
    The Property STR Settings pop-up displays.

  3. Select the Taxes & Discounts tab and, in the Discounts tile header, click .

  4. Enter information into the following available fields:

    Field Description

    Name

    A unique name for the discount that describes the reason the discount would apply to ensure it is selected correctly when booking reservations.

    Charge Type

    The charge type used when the discount is applied to a reservation. If you need the discount to impact your expenses, select a charge type linked to an expense GL account. If you need the discount to count as income, select a charge type associated with an income GL account. This charge type also displays on the guest's Transactions tile to record the discount.

    Amount

    A flat dollar value to be removed from the reservation total. Alternatively, check Percentage to calculate the entered value as a percentage and remove that percent from the reservation total.

    Select one of the following options to determine how the discount amount is applied:

    Per Stay

    Select if this discount applies only to a specific length of stay(s). In the drop-down, check each length of stay for which the discount is available.

    Per Night

    Select if this discount applies only to nightly reservations.

    If the discount is available only for a certain number of nights, check Set max number of nights to apply discount, and enter the total number of nights on which the discount is active.

    Allow guest to select discount from the STR Online Booking portal

    When checked, guests are allowed to select this discount directly from the Online Booking portal when they make their reservation. For more information, refer to STR Online Booking (Pop-Up).

  5. Click Add & Close to complete the STR discount creation process and close the pop-up. Alternatively, click Add & New to finish adding the STR discount and refresh the pop-up to create another discount.

  6. On the Property STR Setting pop-up, click Save Settings.
    The discount(s) is saved for the property.
