Add a Job

Adding a job in Rent Manager allows you to track transactions associated with specific jobs completed by your business. For example, you can track the costs of job types such as a renovation or construction project or examine the expenses and revenue associated with landscaping work across your entire portfolio.

Related Preferences

In order to use the job costing tool in Rent Manager, Enable job costing must be checked in system preferences. For more information, refer to General Options (System Preferences).

Related Privileges

Group Privilege Column
Accounting Jobs Add, View

For more information, refer to Control User Access.

To add a job, do the following:

  1. Go to arrow_forward Accounting arrow_forward General arrow_forward Jobs.
    The Jobs page displays.

  2. Click Add Job.
    The Add New Job pop-up displays.

  3. Enter a Name for the job to display on the Jobs page.

  4. Enter a Short Name for the job to be used for reporting purposes. For example, if the job name is Parking Garage Construction, the Short Name might be GARAGE.

  5. Enter any of the following optional information:

    Field Description

    Description

    An explanation for the purpose of the job.

    End Date

    The date on which the job ended, if applicable.

    Expected End Date

    The date on which the job is expected to end if it has not yet ended.

    Job Type

    The user-created category that best describes the job (e.g., Bathroom Renovation, Commercial Build-Out, Rekey Locks).

    Start Date

    The date on which the job began or is expected to begin.

  6. Verify that Active is checked in order to assign transactions to this job.

  7. In the Link section, use the Type drop-down list to determine if this job is linked to a Property, Unit, or Asset. Then, in the associated field that populates, select the Property, Unit, or Asset to which this job is linked.

  8. To finish, click Save & Close or to save and create additional jobs, click Save & New.
    The new job is added to the list and available to be selected from the Job field thorough out Rent Manager.
