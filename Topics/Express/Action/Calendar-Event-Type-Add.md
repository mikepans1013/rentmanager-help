# Add Event Types for the Community Calendar

Source: https://rmxhelp.rentmanager.com/Topics/Express/Action/Calendar-Event-Type-Add.htm

The community calendar in Rent Manager allows you to view and schedule community-wide events and amenity reservations. When adding events to your community calendar, you can select the type of event to provide further context and assign each type a different color to identify them at a glance both for internal users in Rent Manager and tenants in Tenant Web Access (TWA) . You can create an event type for all the various events that your community hosts, such as block parties, fundraisers, holiday celebrations, open houses, meetings, and so on.

 To create a new event type, do the following:

 -
 Go to arrow_forward Services arrow_forward Service Setup arrow_forward Community arrow_forward Community Calendar Event Types .
The Community Calendar Event Types page displays.

 -
 At the top of the page, click Add Event Type .

 -
 Enter or select the needed information in the available fields described below.

 Field
 Description

 Name

 A brief, unique name to identify the type of event. This displays for each event on the community calendar both in Rent Manager and in  Tenant Web Access (TWA) .

 Description

 More detailed information about the type of event to provide further context, such as when this type applies to a community calendar event.

 Color

 The color used to help identify community calendar events of this type in both Rent Manager and Tenant Web Access (TWA) . You can click the color bar in the field and choose any desired color.

 Active

 Displays a Check by default to indicate that this event type can be selected for events on the community calendar. Uncheck to disable this event type option for any new events.

 -
 To finish, click Save & Close , or to create additional event types, click Save & New .
