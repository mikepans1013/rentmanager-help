Add a History/Note File to Owner Web Access (OWA)

History/note items let you record information that supplements or clarifies what’s entered in other fields, such as notes about phone conversations, items on a to-do list, or explanations about transactions. To provide your owners with additional information, such as files related to their properties, you can add documents that can be viewed in Owner Web Access (OWA) for owners that have OWA accounts already set up.

Related Privileges

Group Privilege Column
Owners Owners View
History Owner History/Notes Add

For more information, refer to Control User Access.

To add a history/note file to OWA, do the following:

  1. Go to arrow_forward Owners arrow_forward General arrow_forward Owners and select an owner from the list.
    The owner's details page displays.

  2. On the action bar to the right, select arrow_forward Add OWA File.
    The OWA File Details pop-up displays.

  3. Enter information in the following fields.

    Field Description

    File Attachments

    Click Upload or Paste to add the document or image to display in Owner Web Access (OWA).

    Note

    Any information about the history/note item describing the event, interaction, or message to display in OWA.

    Start Date and Time

    The date and time the history/note item goes into effect. When you open the Note Details pop-up, the current date and time populate by default.

  4. Click Save.
    The new history/note item is published to OWA.
