MU File Formats (Page)

The Metered Utilities (MU) File Formats page allows you to add, view, and update the file formats for the files used to import or export meter readings into or from Rent Manager.

Once MU file formats are set up, you have the ability to import multiple meter readings from a text (*.txt) or comma-separated value (*.csv) file or export your selected meter reading data to a text (*.txt) file. Importing a file is useful if you do not have access to a meter reading software that integrates with Rent Manager. You may wish to export a file in order to view meter readings outside of Rent Manager in a spreadsheet, keep a backup stored locally, or share with a co-worker.

Column Descriptions

The following columns are available on this page:

Column Description

Name

The name of the file format (e.g., Electric, Sewer, Water).

Data Format

The file's data format (Fixed or Delimited). Each format is described below.

Fixed

Fields in the import/export file are fixed length without delimiter characters between fields.

Delimited

Fields in the import/export file vary in length and are separated by commas or other delimiter characters.

Line 1 is a Header

A displays if the first line in this file format contains field names or column headers and should be excluded when importing files of this format.

Row Actions

The following row actions are available from the menu:

Action Description

Details

View the full file format, including the data format, fields, and a sample export record.

Export

Saves the file format as an XML file to your computer's designated downloads folder, which can be imported by another Rent Manager user. These XML files are compatible only with Rent Manager.

Delete

Permanently removes the file format from Rent Manager.
