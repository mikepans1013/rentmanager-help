# ePay Returns (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/ePay-Returns.htm

Using ePay allows you to process electronic payments in Rent Manager . When payments made via ePay cannot be processed due to reasons such as insufficient funds or being voided, those payments display in the ePay Returns page. This page allows you to filter the list of payments by property, date, return status, and return code to allow for easier batch payment reversals and consistent application of NSF fees.

 Filter Options

 The following filter options are available.

 Option
 Description

 Properties

 The properties or property group for which you wish to view associated ePay returns. Alternatively, you can select a property Group . To include properties that are no longer active, check Show Inactive Properties .

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Return Date

 The From and/or To dates to only show ePay returns with a transaction date during the specified period.

 Return Status

 The cause of the ePay return. Each status is described below.

 NSF

 The ePay payment could not be processed due to non-sufficient funds.

 Returned

 The ePay payment could not be processed for other reasons, such as an incorrect bank account or card number.

 Return Code

 The specific reason that the ePay payment could not be processed (e.g., RO1: Insufficient Funds , RO2: Account Closed ). Return codes are provided by Zego , and only codes associated with returned payments in the system display in the drop-down list. For a complete list of return codes, refer to ACH/E-Check Return Codes on Zego 's website.

 Returns

 When an ePay payment is returned by Zego , that payment displays in the list of transactions. In this section, all ePay returns that match the selected filter criteria display. Each column is described below.

 Column
 Description

 Account

 The first and last name of the tenant associated with the returned payment.

 Amount

 The total dollar amount of the returned payment.

 Code

 The Zego return code relating to the reason for the payment's return (e.g, RO1 ). For a complete list of return codes, refer to ACH/E-Check Return Codes on Zego 's website.

 Code Description

 A description for the code that indicates why the payment was returned (e.g., Insufficient Funds ).

 ePay Return Date

 The date that the payment was returned to Zego .

 NSF Fee

 The Default Amount for the charge type set as the default Non-Sufficient Funds Fees in system preferences. This amount can be overridden per property on the property details page's Other Information tile.

 More Information

 If Override NSF Fee is selected, this column displays the amount entered in the corresponding field for any selected transactions.

 Response ID

 The unique number generated by Zego when the ePay payment was made. This number is used by Zego for tracking purposes.

 Reversal Date

 The date selected on the Payment Reversal Date field to use for the reversal.

 Status

 The cause of the ePay return. Each status is described below.

 NSF

 The ePay payment could not be processed due to non-sufficient funds.

 Returned

 The ePay payment could not be processed for other reasons, such as an incorrect bank account or card number.

 Transaction Date

 The date the charge to which the returned payment is applied was posted.
