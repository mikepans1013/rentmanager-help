# Tenant History/Notes (Pop-Up)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Tenant-History-Notes.htm

Tenant history/notes record information that supplements or clarifies information entered in other fields in Rent Manager , such as notes about phone conversations, items on a to-do list, and explanations about transactions. Rent Manager automatically creates some history/notes at the system level. You can also record custom information, such as general notes and notes about interactions with tenants.

 Filter Options

 The available filter options are listed below. Depending on the size of your browser window, these filters may display at the top of the page or you may need to click to view the filter options.

 Option
 Description

 Search

 Enter search terms in the Search field to find history/notes that contain the searched text.

 Filter By Date

 Select or enter the From and/or To dates to filter notes created on or between the selected dates. Click to select from preset date ranges.

 Users

 Click the drop-down list and select users to filter for history/note items created by one or more Rent Manager users.

 History Category

 Click the drop-down list and select categories to filter for history/note items by category.

 Select <Unassigned> to include history/notes with no category.

 Type

 Click the drop-down list and select types to filter history/note items by type.

 To select or deselect all options in the list, click the box next to the Search field.

 Only Notes with Attachments

 Check to display only history/notes that have an attachment.

 Unit Notes

 Check to include history/notes for the unit associated with the tenant account.

 Account Group Notes

 Check to display the history/note items from all tenants in this tenant's account group. This option displays only for tenants that are part of an account group. For more information, refer to Manage Account Groups .

 Column Descriptions

 Columns on the tenant History/Notes page display the following information:

 Column
 Description

 Pin

 Pinned history/notes always display at the top of the list.

 Type

 The type of interaction with the tenant that the note represents. For example, if the history/note is linked to a service issue, the Service Issue type displays. If the note records an email sent to a tenant, the Email type displays.

 Date

 The date and time the note was created.

 Note

 For history/notes of a communication type, such as text messages or emails, the Note field displays the message sent to the tenant.

 If an attachment is uploaded to the history/note item, displays. Click to download the attachment or open it in a new tab.

 Category

 The category describes the purpose of the note. For example, an email sent to a tenant for the purpose of advertising displays the Marketing category.

 User

 The Rent Manager user who created the history/note. If this is a system-generated history/note, the user displays as Administrator . If the history/note was generated from Tenant Web Access (TWA) , the user displays as <Unassigned> .
