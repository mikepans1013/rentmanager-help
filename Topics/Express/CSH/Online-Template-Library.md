# Online Template Library (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Online-Template-Library.htm

The online template library (OTL) is a continually updated resource for common property management letter templates, custom tabs, custom forms, and templates for inspections, Report Writer , and Financial Report Writer . Templates can be imported from the OTL for use in your database and edited to meet your needs. You can also export templates you create to the online template library to share with other Rent Manager users. LCS staff then reviews these templates for publication.

 Filter Options

 The following filter and sort options are available on this page.

 Option
 Description

 Search

 Enter the desired search criteria to display results with a Name that matches the search criteria.

 Category

 Select the desired template type from the drop-down list to quickly filter the OTL contents.

 LCS Templates Only

 Check to display only templates published by LCS .

 Sort

 Select a sorting method from the drop-down list to organize the search results by Name , user Rating , Author, Name , or Author, Rating .

 Category Descriptions

 The category folders in the online template library each fall under one of the following template types:

 Category
 Description

 Letter Templates

 Customized letters that combine static text and graphics with dynamic scripting commands that allow you to generate customized content for each letter recipient.

 Report Writer (RW)

 Customized reports created via the Report Writer that utilize both insertable fields specific to the type of report as well as scripting for more customizable options.

 Financial Report Writer

 Customized financial reports that filter, group, organize, and summarize specific general ledger (GL) financial data created via the Financial Report Writer .

 Custom Tabs

 Customized tabs of content used in the Rent Manager 12 interface. Custom tabs are used only in Rent Manager 12 .

 Custom Forms

 Customized statements and invoices created via the custom forms designer in Rent Manager 12 .

 Inspection Templates

 Customized inspection templates that define the areas and items of a unit that need to be examined.
