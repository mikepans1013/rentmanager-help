Amortization CAM Expense Adjustment Details (Pop-Up)

Common area maintenance (CAM) expense adjustments allow an owner, landlord, or property manager to reduce the total expense amount for specific expense accounts being reconciled against the tenant. These adjustments apply only to tenant CAM reconciliations without affecting the tenants' actual financial records in Rent Manager.

Amortization adjustments split an adjustment amount evenly over a specified number of months or years. For example, a new HVAC system is installed in a commercial tenant's building for $50,000. If the tenant is going to cover the full amount, but the owner decides to stretch the large expense out over five year to make it more manageable, you can enter an amortization expense adjustment that splits the full amount evenly into $10,000 payments every year for five years.

To view the details of an amortization CAM expense adjustment, go to arrow_forward Receivables arrow_forward Commercial arrow_forward Cam Expense Adjustments and select an expense adjustment with the type Amortization from the list.

Amortization Details

This section displays information about the expense adjustment, including the property, tenants, dollar amounts, and division schedule.

The following fields are available in this section:

Field Description

Property

The property associated with the expense adjustment.

Tenants

Related Privileges

Group Privilege Column
Tenants/Prospects Tenants View
Commercial Recoverable Expenses (CRE) CAM Expense Adjustments View, Edit

For more information, refer to Control User Access.

The tenant(s) responsible for the payments setup in the expense adjustment.

Start Date

The date on which the expense adjustment begins charging to tenants.

GL Account

The GL account associated with the expense adjustment.

Total Amount

The total dollar amount of the expense. This amount is divided over the number of Periods.

Periods

The intervals of time over which the expense adjustment is divided. Enter the number of Periods in the text box and then select Months or Years. For example, if you enter 12 and select Months, the expense is divided into 12 equal payments that post once a month beginning on the Start Date.

Internal Note

An optional description of the expense adjustment that is viewable only by Rent Manager users.

Tenant Note

An optional description of the expense adjustment that posts to tenant accounts.

More Information

If an amortization adjustment period is reconciled for at least one tenant selected on this adjustment, only the Tenants, GL Account, Internal Note, and Tenant Note fields can be edited. Adjustment periods previously reconciled are not be affected by any changes.

Adjustments

This section displays the date and amount of payments associated with the expense adjustment.

The following columns display in this section:

Column Description

Period

The number of the intervals of time over which the expense adjustment is divided.

Adjustment Date

The date on which the adjusted amount charges tenants.

Adjustment Amount

The total dollar amount of the adjusted expense charged on this date.

Change History

This section displays a log of changes made to the expense adjustment. The section displays only after changes to the expense adjustment are made.

The following columns display in this section:

Column Description

Description

A system-generated explanation of the change that was made.

User

The Rent Manager user who made the change.

Date

The date on which the change was made.
