# Estimate Details (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Estimate-Details.htm

Estimates allow you to record the anticipated parts and labor needed to complete a project, itemize the costs, and provide a total amount due including any markups and/or taxes you add. Estimates can also be linked to an invoice, service issue, and/or purchase order. On an estimate's details page, you can add or edit estimate information, link the estimate to other entities, add inventory items, manage history/note items, or delete existing estimates.

 Recipient and Sender

 This tile displays the following information about the sender and recipient of the estimate:

 Field
 Description

 From Address

 The default address of the default property associated with the owner, tenant, or prospect account.

 From Property

 The property associated with the owner, tenant, or prospect account.

 Owner/Tenant/Prospect

 The owner, tenant, or prospect account to be expensed by bills associated with this estimate.

 To Address

 The default address of the tenant or prospect account, or if the estimate is for an owner, the address of the property's management company.

 General

 This tile displays general information about the estimate, such as the date, sales representative, and status.

 Field
 Description

 Active

 A displays if the estimate is active and can be used to record expected labor and parts expenses.

 Comments

 An additional explanation or purpose of the estimate. To add a memorized comment, click .

 The date that the estimate was created.

 The date on which the estimate expires. This is the date after which your offer to do the specified work at the price you set is no longer valid.

 Reference

 A title or description of the estimate.

 Sales Rep

 The user responsible for creating the charge or selling the associated inventory item to the invoice recipient.

 Status

 The current state of the estimate.

 Draft

 The estimate is a work in progress.

 Awaiting Approval

 The estimate was submitted to a user or owner via Owner Web Access for their approval.

 Approved

 The work defined on the estimate has been approved and is ready to start. The name of the owner or user who approved the estimate, along with the date of approval, displays below this field.

 Rejected

 The owner or user chose not to proceed with the work, and the estimate needs to be adjusted or closed. The name of the owner or user who rejected the estimate, along with the date of rejection, displays below this field.

 Tax Information

 This tile displays the tax type and percentage that is applied to any taxable items in the estimate.

 Field
 Description

 Tax %

 The tax percentage rate to be applied to the total taxable items displayed in Taxable Amount . If a Tax Type is selected, this initially displays the tax rate defined for that tax type.

 Tax Type

 The type of tax to apply to the expenses in this estimate. The Tax % field populates with the percentage rate defined for the selected tax type. For more information, refer to Tax Types (Page) .

 Taxable

 A indicates that expenses related to this estimate are subject to additional tax expenses.

 Taxable Amount

 The running sum of the line item Total for items with the Tax column checked. This Taxable Amount is multiplied by the Tax % to calculate the actual Tax applied to the transaction.

 Links

 This tile displays invoices, service issues, and purchase orders linked to the estimate. Clicking History/Notes displays the History/Notes pop-up, where you add and view history/note items associated with the estimate.

 Items

 This section displays inventory items, and associated costs, that are planned to be purchased as part of this estimate.

 Column
 Description

 Amount

 The total dollar amount that the purchased quantity of the Item costs you before markup and taxes are added.

 Cost

 The purchase price you pay per Item .

 Item

 The inventory item that is purchased as part of this estimate. Once an item is selected, the Cost and Memo fields populate with the item’s information.

 Markup

 The total dollar amount or percentage of the cost of the Item that you charge the recipient of the estimate beyond the base Cost you paid for the item.

 Memo

 Additional information explaining the inventory item. By default, this field populates with the Description from the inventory item.

 Property

 The property where the work is performed. Only properties where the owner has an active ownership display. This column displays only for owner estimates.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Quantity

 The quantity of the Item to purchase. The Total updates if the quantity is changed.

 Tax

 A indicates that the item is taxable. When Tax is checked, the Amount for this line item is added to the Taxable Amount in the Taxes section. When a Tax Type and Tax % are specified in that section, their tax percentage is multiplied by the Taxable Amount to get the actual Tax applied to the transaction.

 Total

 The total dollar amount of the Item after any Markup is added.

 Unit

 The unit where the work is performed. Only units at properties where the owner has an active ownership display. This column displays only for owner estimates.
