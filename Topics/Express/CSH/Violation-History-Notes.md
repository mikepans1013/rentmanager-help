# Violation History/Notes (Pop-Up)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Violation-History-Notes.htm

History/notes allow you to record information that supplements or clarifies what’s entered in other fields, such as notes about phone conversations, items on a to-do list, and explanations about transactions. History/notes on violations are helpful because they allow you to keep track of important details regarding why a violation was made, who was involved, and the related outcomes that may not be included in the description of a violation.

 To view and manage history/notes for a violation, go to arrow_forward Rental Info arrow_forward General arrow_forward Violations and select the desired violation. On the violation's details page click on the History/Notes tile.

 Filter Options

 The available filter and sort options are listed below. Depending on the size of your browser window, these filters may display at the top of the page or you may need to click to view the filter options.

 Option
 Description

 Search

 Enter information into this field to narrow the list to match your search criteria.

 Filter By Date

 Select or enter the From and/or To dates to filter notes created during the selected dates. Click to select a relative date range.

 Users

 Click the drop-down list and select the desired user(s) to filter for items created by one or more Rent Manager users.

 History Categories

 Click the drop-down list and select the desired categories to include. To include history/notes with no category, select Unassigned .

 The list displays categories associated with a related type (tenant/prospect, asset, so on) to the history/notes you are viewing. Violations use categories with the type of Tenant/Prospect .

 Type

 Click the drop-down list and select the desired types of history/note items.

 Only Notes with Attachments

 Check to display only history/notes that have an attachment.

 Column Descriptions

 The following columns display on this pop-up.

 Column
 Description

 Pin

 If the history/note item has Pin enabled, displays. If there are no pinned notes, the column does not display.

 Type

 The system-generated history/note type. For example, if the history/note is linked to an escalation, the Violation Stages type displays.

 Date

 The date and time the note was created.

 Note

 The information to describe the history/note (e.g., Decorations were still up after Easter ). If no text is entered, the column displays blank.

 If an attachment is uploaded to the history/note item, displays. Click to download the attachment or open it in a new tab.

 Category

 The category of the history/note selected from the available history categories. If no category is selected, the column displays blank.

 User

 The user who created the history/note. If this is a system-generated history/note, the user displays as Administrator . If the history/note was generated from Tenant Web Access (TWA) , the user displays as <Unassigned> .
