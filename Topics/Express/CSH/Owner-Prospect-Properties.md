# Owner Prospect Properties (Pop-Up)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Owner-Prospect-Properties.htm

The owner prospect Properties pop-up allows you to catalog the properties in a prospective owner's existing portfolio, including the name, kind of property, and number of associated units.

 For more information, refer to Control User Access .

 To view and manage an owner prospect's existing property portfolio, go to arrow_forward Owners arrow_forward General arrow_forward Owner Prospects and select an owner prospect from the list. Then, on the Properties tile, click .

 Column Descriptions

 The following columns display on the pop-up:

 Column
 Description

 Property

 The full name of the owner prospect's property.

 Property Type

 The Rent Manager Property Type that best matches the owner prospect's property (e.g., Apartment , Commercial , Single Family ).

 Unit Count

 The number of individual units associated with the owner prospect's property.
