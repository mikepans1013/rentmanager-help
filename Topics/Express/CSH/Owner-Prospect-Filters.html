Owner Prospect Filters (Pop-Up)

Owner prospect filters allow you to quickly narrow your search results to get to the owner prospect information that you really need. Rent Manager gives you the ability to choose from a variety of filtering options to sort your owner prospects on the Owner Prospects page.

Owners Owner Prospects View

For more information, refer to Control User Access.

Rent Manager allows you to create filters that can be used temporarily, or saved to use repeatedly. Additionally, they can be saved on a system level for all users, or on a personal level where only your user account can access it. Before saving your filter, enter a Name, and, optionally, a Description to remind you of the filter's purpose.

More Information

If the basic filtering does not meet your needs, you can create an advanced filter which allows you to group your filters for a more granular, precise filtering criteria. For more information, refer to Create an Advanced Filter.

On the Owner Prospects page there are multiple fields available to use for basic filtering of owner prospects. The fields are divided into multiple sections. Each field is described within the corresponding section below.

General Information

This section contains fields for filtering owner prospects by information that can be found primarily on their details pages.

In the Search Options field, select whether the filtered owner prospect list includes results for owner prospects based on whether the relevant information Contains your filter criteria or Begins With the your filter criteria.

For example, if you are filtering owner prospects with a Postal Code that start with 4, you can select Contains to display all owner prospects whose zip or postal code has the number 4. Alternatively, if you select Begins With, you see results only for prospects whose zip or postal code starts with the number 4.

The available filter fields are described in the table below.

Field Description

Account Name

The name of the owner prospect, which is used when referencing the owner prospect and for correspondence generated to the owner prospect in Rent Manager.

City

The Default city as listed on the owner prospect's Addresses tile.

Comment

Additional information relating to the owner prospect, if any, as entered on the Account tile.

Display

The Display Color selected on the owner prospect's Miscellaneous tile. For more information, refer to Colors (Page).

Display Name

The name of the owner prospect, which displays on the Owner Prospects page.

Email

The owner prospect's email address as entered on the Miscellaneous tile.

Interest Level

The owner prospect's interest level (0 through 10, with 10 being highest) in your property as listed on the owner prospect's Miscellaneous tile.

Lead Source

How the owner prospect found out about your property as listed on the owner prospect's Miscellaneous tile. For more information, refer to Owner Prospect Lead Sources (Page).

Phone

The phone number selected as Default for the owner prospect as found on the Phone Numbers tile.

State

The Default state name as listed on the owner prospect's Addresses tile.

Street

The Default street name as listed on the owner prospect's Addresses tile.

Zip

The Default zip code as listed on the owner prospect's Addresses tile.

Contact Information

This section contains fields for filtering owner prospects by their most recent contact information located primarily on the Owner Prospect Box Score report.

The available filter fields are described in the table below.

Field Description

Created Between

Includes owner prospects whose accounts were created during the selected date range.

Last Contact Between

Includes owner prospects whose last contact occurred during the selected date range.

Sales Rep

The sales rep whose owner prospects you want to view in the filter results. Rent Manager users are considered leasing agents when they have been designated with the Sales Rep/Leasing Agent user role.

Other Filters

This section contains additional fields for filtering the owner prospect list, such as filtering by user defined fields (UDFs) or phone numbers.

The available filter fields are described in the table below.

Field Description

Phone Number Type

First, select the phone number type in which to search, then in the Phone Number field to the right, enter a full or partial phone number to filter the results. Only owner prospects that meet the filter criteria for the selected phone number type display.

User Defined Field

Select an owner prospect-type UDF from the list by which to filter owner prospects. Then in the Value field, enter or select the information to narrow your results to owner prospects that meet the entered criteria.
