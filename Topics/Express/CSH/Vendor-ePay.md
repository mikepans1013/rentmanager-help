# Vendor ePay Settings (Pop-Up)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Vendor-ePay.htm

The Vendor ePay feature automatically debits your bank or credit card account, deposits funds into the vendor’s account, and records the transaction in Rent Manager . Each vendor who wants to receive bill payments through ePay processing must have payment information entered on the vendor. The information entered on this pop-up remains on the vendor’s account to be used in future ePay transactions.

 More Information

 ePay information must be entered for the associated property to process transactions. For more information, refer to Property ePay Settings (Pop-Up) .

 To view and manage a vendor's ePay information, go to arrow_forward Payables arrow_forward General arrow_forward Vendors and select a vendor from the list. Then on the action bar to the right, click arrow_forward ePay Settings and enter your ePay Password if prompted.

 Account Information

 This section displays the bank account information used when processing ePay payments for this vendor.

 Field
 Description

 Account Number

 The full bank account number.

 Account Type

 The bank account used to collect ePay payments. Each option is described below.

 ACH - Checking

 Payments are processed using a checking bank account via the automated clearing house (ACH) network.

 ACH - Savings

 Payments are processed using a savings bank account via the automated clearing house (ACH) network.

 First Name

 The first name associated with the bank account.

 Last Name

 The last name associated with the bank account.

 Routing Number

 The full routing number for the bank account.

 Billing Address

 This section displays the street address associated with the vendor's bank account. Click Fill From Vendor to automatically populate the fields with the address marked as Default on the vendor's account.
