# User-Type User Defined Fields (Pop-Up)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/User-UDFs.htm

User-defined fields (UDFs) are custom fields used to track information that Rent Manager does not track by default. You can create UDFs for all entities in Rent Manager , such as properties, units, unit types, and tenants. Each UDF has a control type to determine how this data is recorded (e.g., text, numeric, file, and so on). Creating new or modifying existing user-defined fields must be done on the User Defined Fields page, which updates how UDFs display across all entity types.

 After you create a UDF on the User Defined Fields page, you can enter values for users. For example, you can create UDFs to track user job titles, their emergency contact, and if they prefer a name or pronouns other than the primary contact name on their account.

 From the user User Defined Fields pop-up, you can view and edit the custom information associated with this user. You can also enter search criteria in the Search box to display any UDFs that include the search criteria in their Name or Value .

 Column Descriptions

 The user User Defined Fields pop-up displays the following columns:

 Column
 Description

 Name

 The custom information that is tracked by the UDF. The name can be edited from the User Defined Fields page and changes how the UDF displays everywhere it is available.

 Value

 The information unique to this user. This value can be used in scripting to customize letter templates and Report Writer  reports.
