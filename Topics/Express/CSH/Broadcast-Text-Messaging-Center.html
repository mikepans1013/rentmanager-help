Text Messaging Center (Page)

Rent Manager's text messaging center allows you to view the text messages that were sent to other Rent Manager users, owners, prospects, owner prospects, tenants, or vendors, and read their replies. You can respond to the conversations as well as perform actions, such as creating a new issue, adding a payment, or generating a statement.

Related Preferences

In personal preferences, you can establish when or if Rent Manager notifies you that a message was received in the Text Messaging Center. For more information, refer to Text Message Options (Personal Preferences).

Any texts you send via the text messaging center are recorded on the entity's account. When texting contacts of prospect and tenant accounts, those text messages are recorded in the history/notes of the primary tenant or prospect associated with the account.

Related Privileges

Group Privilege Column
Texting/Broadcast Send/Receive texts Enabled

For more information, refer to Control User Access.

To view and manage messages in the text messaging center, go to arrow_forward Communication arrow_forward Texting/Phone arrow_forward Text Messaging Center.

To show individual messages represented by a single row rather than listing out every individual message in the list, check Group by phone number. Individual messages can still be viewed by selecting the conversation and viewing the conversation details.

Filter Options

You can click Show Filters to display additional filters to select. The following filter options are available.

Option Description

Days to Show

Only text messages that were sent in the past X days display in the list. This is set to 30 days in the past by default.

Hide read conversations

Only conversations that contain unread messages display in the list.

Entity Type

Only text messages with the selected entity type (e.g., Tenant, Owner, Vendor, etc.) display in the list.

Property

Only text messages associated with the properties you select display in the list.

Conversations

This section displays a history of text conversations, with the most recent conversation listed first. Each conversation in the list displays the information from the linked account, such as the entity's name and phone number. Messages show a red dot indicator when there are unread messages in the conversation. For messages you want to revisit, you can use the menu to mark messages as unread. Arrow indicators are used to represent if the most recent message was received () or sent ().

More Information

Only information related to the properties to which you have access displays. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property.

Column Description

Date

The date and time that the last message was either received or sent in the conversation.

Entity Type

The type of entity on the linked account.

Manager

The manager associated with the property of the linked account.

Most Recent Message

The last message that was either received or sent in the conversation.

Recipient Name

The recipient's full name as it displays on the linked account.

Phone

The phone number that is being contacted in the conversation.

Property

The property associated with the linked account.

Unit

The unit associated with the linked account.

Conversation Details

In this section, you can respond to text messages, including uploading images to the message, view the name of the entity linked to the conversation, and view the date and time the text message was received. Any images sent by the recipient also display. Additionally, you can use actions, such as creating a new service issue, viewing the associated account, or adding a payment to a tenant.

Certain actions display only for specific entity types (e.g. Add Payment only shows for tenant accounts). The following options are available.

Action Description

Add Issue

Related Privileges

Group Privilege Column
Service Manager Issues Add, View

For more information, refer to Control User Access.

Create a new service issue linked to the text message recipient. This action can only be taken from conversations linked to tenants and prospects. For more information, refer to Add an Issue.

Add Note

Related Privileges

You need the privilege to add notes for the entity type included in the conversation. Privileges to Add history/notes items can be found in the History privilege category.

For more information, refer to Control User Access.

Add a history/note item to the entity's account.

Add Payment

Related Privileges

Group Privilege Column
Receivables Take tenant payments Enabled

For more information, refer to Control User Access.

Add a new payment to the tenant's account. This action can only be taken from messages linked to tenants. For more information, refer to Add a Payment.

Generate Statement

Related Privileges

Group Privilege Column
Letter/Email Templates/Reports/Packets Run reports Enabled

For more information, refer to Control User Access.

Additionally, you need the privilege to access to the Statement - 8.5X11 report.

Generate the Statement - 8.5x11 for that tenant. This action can only be taken from messages linked to tenants.

Open Service Tech Map

Related Privileges

Group Privilege Column
Service Manager Issues View

For more information, refer to Control User Access.

Sends a ping to the tech to grab their location, then opens the Service Tech Map page to the Locate Individual Tech tab. This option only displays if the user is set up as a maintenance tech. For more information, refer to Service Tech Map.

View Entity

Related Privileges

You need the privilege to view the entity type included in the conversation. For example, if your conversation is with an owner, you need the View privilege for Owners.

For more information, refer to Control User Access.

Opens the entity's account details page in Rent Manager.

Text Broadcasts/Bulk Texts

Related Privileges

Group Privilege Column
Texting/Broadcast Perform phone broadcast Enabled

For more information, refer to Control User Access.

To view existing text broadcasts (i.e., bulk texts) from the Text Messaging Center, in the top-right corner of the page, click . The following sections are available on the Text Broadcasts/Bulk Text pop-up.

Scheduled Broadcast Batches

The left side of the pop-up displays a listing of sent text broadcasts. The default view for this pop-up is to display Current broadcasts, which includes any scheduled broadcast that are not sent as of the time the page generated. You can select Past to show broadcasts that were already sent. Select All to view both current and past text broadcasts.

The following columns display in this section:

Column Description

Create Time

The date and time the broadcast was created.

Run Time

The date and time the current broadcast was sent. For scheduled broadcasts, it displays the date and time the broadcast is scheduled to run.

Submitted

A Check displays when the broadcast is sent successfully.

Text Message

The type (e.g.,sms.text) of message that was sent in the broadcast.

Text Details

This section displays information about the recipients of each text and the status of those texts.

The following columns display in this section:

Column Description

Link

The type of account associated with the phone number.

Name

The name associated with the phone number receiving the text broadcast message.

Number

The ten-digit phone number to which the text broadcast message is sent.

Property

The property associated with the recipient.

Queued

A Check displays when the message is preparing to send.

Received

A Check displays when the message is received by the recipient's phone.

Sent

A Check displays after the message is transmitted.
