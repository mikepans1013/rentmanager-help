Colors (Page)

Highlight entities and events in Rent Manager by using defined colors. Colors can be applied in many areas of Rent Manager such as appointments, tasks, tenants, and units. For example, you can define the color green as Commercial and apply it to commercial tenants, units, and/or properties so commercial tenants and properties display green anywhere colors are available.

Related Privileges

Group Privilege Column
System Colors View

For more information, refer to Control User Access.

To view the Colors page, go to arrow_forward Administration, then go to Customization arrow_forward Colors.

Column Descriptions

The following columns are available on this page.

Column Description

Name

The unique name of this color.

Type

The area in Rent Manager where this color is available as a selection.

Color

A swatch of the color displays.
