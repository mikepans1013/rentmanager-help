# Smart Receipts Page (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Smart-Receipts.htm

Rent Manager 's Smart Receipts feature allows you to streamline your expense management process. With this feature, you can easily take a photo of a receipt via the Capture tool in rmAppSuite Pro or upload an image file of a receipt, allowing Orion AI to extract the relevant data and create draft transactions automatically. Smart Receipts also includes an intuitive review process, allowing you to ensure the accuracy of transactions before posting them to the Credit Card Registers . Additionally, Rent Manager users can be linked to vendor accounts, allowing you to track which user is being reimbursed for personal charges.

 Filter Options

 The following filtering options are available on this page.

 Option
 Description

 Properties

 Filter the receipts on the page based on properties to which you have access. By default, all the properties that you have access to are selected.

 More Information

 Only properties to which you have access display. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Search

 Use the Search field to narrow the list to match your search criteria.

 Users

 Filter the receipts on the page based on the User who submitted the upload. By default, only your user account is selected.

 Column Descriptions

 The following columns are available on this page. By default, some columns display only if added via .

 Column
 Description

 Amount

 The total dollar amount owed taken from the file when the receipt was uploaded.

 Memo

 An optional comment to further explain the receipt (e.g., New doorknob for unit 23 , Dinner with clients , Copy paper for printer ).

 Properties

 The Full Name of the property associated with the Smart Receipt transaction.

 Type

 The receipt's type ( Company Credit Card or Reimbursement ). Company Credit Card indicates that the purchase was made using the company credit card account. Reimbursement indicates that a Rent Manager user made the purchase out of pocket and needs to be reimbursed by the company.

 Units

 The Name of the unit associated with the Smart Receipt transaction.

 Upload Date

 The date and time the receipt was added to Smart Receipts page.

 User

 The Username of the user who submitted the receipt.

 Vendor

 The vendor account associated with the Smart Receipt transaction.

 If a smart receipt was edited from the Smart Receipt Review pop-up and the user clicks Save For Later , an Updated badge displays next to the vendor's name.

 Available Column

 Description

 Attachments

 The name of the image or file that is attached to the Smart Receipt transaction.

 Credit Card

 The GL Account No and Name (e.g., 2104 - Visa ) of the credit card taken from the file when uploading the receipt.

 Receipt Date

 The date, in the mm/dd/yyyy format, taken from the uploaded receipt.
