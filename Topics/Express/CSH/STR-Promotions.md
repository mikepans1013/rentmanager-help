# Short Term Rental (STR) Promotions (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/STR-Promotions.htm

Short-term rental (STR) promotions allow you to offer discounts for STR reservations based on specific criteria. Promotions are set up with a unique promo code that guests can enter in the Online Booking Portal, and promotional periods can be limited based on the date the guest books their reservation and the dates the reservation is for. Additionally, you can control whether promotions are applied to an entire stay or on a nightly basis, and can require a minimum number of nights for the discount to be used.

 Column Descriptions

 The following columns display on the page.

 Column
 Description

 Active

 Indicates that the promotion is available to guests during the Booking Date Range .

 Booking Date Range

 The earliest and latest date that guests can make an STR reservation using the Promo Code .

 Discount Amount

 The dollar amount or percentage of the promotional discount.

 Name

 The unique identifier for the STR promotion.

 Promo Code

 The alphanumeric code that guests need to enter on the STR Online Booking portal to receive the promotional discount.

 Properties

 The STR properties that the promotion is available for.

 Stay Date Range

 The earliest and latest date that guests can stay using the Promo Code .

 Type

 The duration used to calculate the discount ( Per Stay or Per Night ).
