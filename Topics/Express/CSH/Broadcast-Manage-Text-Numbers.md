# Manage Text Numbers (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Broadcast-Manage-Text-Numbers.htm

When Text Broadcasting is enabled in Rent Manager , LCS assigns you a set of up to five text-enabled numbers to display as the sender numbers. The Manage Text Numbers page allows you to control which of these numbers are available for text broadcasting, automated notifications, and accounts receivable automation. You can also set up different numbers to be used for different properties to centralize your text communications.

 More Information

 This feature is licensed and must be purchased separately. For more information, contact your sales representative at sales@rentmanager.com .

 Column Descriptions

 The following columns are available on the page.

 Field
 Description

 Name

 A unique name to identify the number, such as Default Texting .

 Description

 A short summary for the number's use purpose.

 Default

 A displays if the number is the system default.

 More Information

 A default number must be specified. Marking a new number as default removes the Default status from the previous number and applies it to the currently selected number.

 Broadcast

 A displays if the number is designated to perform broadcasts.

 Properties

 The name of each property that can use this number for text broadcasting and messaging. If more than one property is selected, the name of the first property is displayed, followed by the number of additional selected properties.
