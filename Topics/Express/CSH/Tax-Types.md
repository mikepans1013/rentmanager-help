# Tax Types (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Tax-Types.htm

Tax types are used for invoices when products are sold in areas with different tax rates. Tenants can be assigned a tax type so that each tenant is charged the appropriate tax type when they are invoiced for taxable items. This can be helpful when you have tenants with varying tax types based on their location.
