# Account Groups (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Account-Groups.htm

Account groups allow you to group together two or more tenant accounts for transactional and reporting purposes while maintaining individual account records for each tenant. Each account group has a tenant account that serves as the master account, with other tenants in the group are considered subaccounts.

 For example, you may manage student housing and have four students living as roommates in a single unit. Creating an account group allows you to set up each tenant with their own Rent Manager account while also generating a single statement for all of their combined transactions. You can also receive a single payment from one roommate that can be applied against the charges of the other roommates.

 Column Descriptions

 The following columns display on this page.

 Column
 Description

 Master

 If checked, the tenant account is designated as the primary account for the account group. Each account group can have only one master account at a time.

 Account ID

 The system-generated ID number for the associated tenant account.

 Account Name

 The full name of the tenant.

 Property

 The property of the first lease listed for the tenant.

 Unit

 The unit of the first lease listed for the tenant.

 Move In

 The move-in date of the first lease listed for the tenant.

 Move Out

 If applicable, the move-out date of the first lease listed for the tenant.
