Orion Smart Voicemails (Page)

The Smart Voicemails feature—powered by Orion AI—automatically transcribes, summarizes, and categorizes voicemails from phone calls received through rmVoIP in Rent Manager. Orion AI organizes the voicemails by urgency and subject so users can access all voicemails they need to address and streamline the communication review process to save time and reduce missed issues or follow-ups.

The Smart Voicemails page provides information about recent voicemails, such as the message's category, priority level, inbound caller number, the date and time of the call, the voicemail box extension that received the voicemail, and a brief summary of the message generated by Orion AI.

More Information

This feature is licensed and must be purchased separately. For more information, contact your sales representative at sales@rentmanager.com.

Filter Options

The following filter options are available on this page.

Option Description

Date Received

Includes only voicemails that were received within the selected date range. You can select one of the relative options (Last 7 Days, Last 14 Days, Last 30 Days, Last 50 Days), or select Custom Date Range and enter a To and From date to display voicemails received during that time.

High Priority

Includes only voicemails that are marked as high priority.

Search

Allows you to display only voicemails that contain data matching what you enter in this field.

Status

Filter voicemails by their status, as selected on the voicemail's details pop-up. You can select New, Viewed, or Addressed in any combination.

Voicemail Box

Includes the voicemails from the selected Smart Voicemail Box(es).

Column Descriptions

The following columns are available on this page. By default, some columns display only if added via .

Default Column Description

Category

The voicemail category that best identifies the type of call (Billing, Leasing, Maintenance, or Other). The voicemail is automatically categorized by Orion AI, but can be manually overridden by users.

Date

The date and time that the voicemail was received.

High Priority

If displays, the voicemail is marked as high priority, indicating it should be addressed with urgency and/or extra attention.

Name

The name of the entity associated with the voicemail (e.g., tenant, owner, property).

Orion Summary

A concise description of the voicemail recording generated by Orion AI.

Phone Number

The phone number of the inbound caller who left the voicemail.

Property

The property associated with the entity who left the voicemail.

Status

The voicemail status to describe the current progress of this voicemail (Addressed, New, or Viewed).

Unit

The unit associated with the tenant or prospect who left the voicemail, if applicable.

Voicemail Box

The name of the Smart Voicemail Box whose extension received the voicemail.

Available Column

Description

Comment

An optional note providing additional information regarding the call.

Duration

The length of the voicemail message in MM:SS (Minutes:Seconds) format.

Incoming Extension

The extension of the caller's phone number, if applicable.

Link Type

The entity type linked to the call (e.g., Tenant, Vendor, Property, and so on).
