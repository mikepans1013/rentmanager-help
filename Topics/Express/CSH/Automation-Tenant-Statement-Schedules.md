# Tenant Statement Automation Schedules (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Automation-Tenant-Statement-Schedules.htm

You can use this Task Automation to reduce the time needed to manage the generation of tenant statements. After Task Automation is enabled for tenant statements in Rent Manager , you can add, view, and edit tenant statement automations from the Tenant Statement Automation Schedules page.

 More Information

 Only information related to the properties to which you have access displays. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 To view the Tenant Statement Automation Schedules page, go to arrow_forward Administration , then go to Automation arrow_forward Task Automation arrow_forward Tenant Statements .

 Column Descriptions

 The following columns displays on this page. By default, some columns display only if added from the menu.

 Default Column

 Description

 Name

 The unique name of the posting schedule.

 Active

 A displays if the posting schedule is currently enabled.

 Type

 The frequency (either Weekly or Monthly ) of the automated postings.

 Run Day

 The day on which the schedule is executed.

 Statement

 The name of the tenant statement generated by the automation. It can be the system's default tenant statement, or a custom-made tenant statement, such as a tenant statement pre-populated with Lockbox information.

 Statement Method

 The method in which statement is generated and sent to tenants, either as an Email Attachment , VPO , or both.

 From Date

 The relative beginning date to be listed on the statement such as the Start of This Month .

 To Date

 The relative end date to be listed on the statement such as the End of This Month .

 Property Group

 If applicable, the group with multiple properties for which to post the statements. For more information, refer to Property Groups (Page) .

 Properties

 The properties for which to post the statements.

 Start Date

 The date on which the automation becomes active and begins running.

 End Date

 The final day the automation runs. The automation becomes inactive a day after the End Date .

 Available Column

 Description

 Comment

 Additional information entered on the Tenant Statement Automation Details pop-up.

 Create Date

 The date on which this automation was created.

 Created By

 The user who created this automation.

 Tenants To Include

 The group of tenants who receive this automation. This can be Past , Current , Future , or a combination of these options.

 Update Date

 The last date on which the automation was updated.

 Updated By

 The last user to update the automation.
