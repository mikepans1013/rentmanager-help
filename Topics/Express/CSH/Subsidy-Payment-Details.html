Subsidy Payment Details (Pop-Up)

A subsidy is a form of financial assistance offered to qualifying tenants. The most common subsidy examples are HUD, Section 8, and FEMA. If you need to revert a subsidy payment that you have already added to Rent Manager, you can use the subsidy payment rollback tool to remove all transactions and deposits associated with a subsidy payment. A history of previous subsidy payments can be viewed on the Subsidy Payments history page. Select a payment from the list to view its details.

Related Privileges

Group Privilege Column
Subsidies Manage View, Edit

For more information, refer to Control User Access.

To view the details of a subsidy payment, go to arrow_forward Receivables arrow_forward Payments arrow_forward Subsidy History and select a payment batch from the list.

General Information

This section includes the following fields:

Field Description

Subsidy

The name of the subsidy used for the payment (e.g., Housing and Urban Development).

Charge Type

The charge type associated with the subsidy payment.

Amount

The total dollar amount of the subsidy payment.

Reference #

If applicable, the note entered by a user describing the type (CASH, MO, the check number, and so on) of transaction.

Bank

The bank account in which to deposit the subsidy payment.

Payment From

The name of the person, organization, or program providing the subsidy payment.

Payment and Deposit Information

This section includes the following fields:

Field Description

Payment Date

The date on the subsidy check, or the date of the direct deposit.

Deposit Date

The date the subsidy check was deposited into your bank or the date of the direct deposit. If Create Deposit is enabled, a deposit is created in Rent Manager once you post the payment.

Payment Comment

Additional information about the subsidy payment, such as the purpose of the payment.

Deposit Comment

Additional information about the deposited subsidy check.

Tenant Payment List

At the bottom of the page, the list includes all tenants whose payments were included in this batch of subsidy payments. The following columns display in this list:

Column Description

Tenant

The name of the tenant associated with subsidy payment.

Unit

The unit(s) that the associated tenant is leasing. If the tenant is associated with multiple units, <Multi> displays.

Memo

A brief explanation of the payment.

Payment

The amount of the subsidy being applied to the tenant's unpaid balance.
