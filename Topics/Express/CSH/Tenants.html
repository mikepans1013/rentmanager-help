Tenants (Page)

In Rent Manager, you can create tenant accounts to represent anyone who rents from your business. Tenants can include people who lease rental units at your residential properties, space at your commercial properties, or units at your storage facility. Tenants can even be members of your property's homeowners association (HOA).

Tenant accounts store information about your renters, such as their names, contact information, lease information, and notes about your interactions with them.

Related Preferences

Since tenants are broad entities that work differently depending on your business, you also have the ability to change the name of the entity as it displays in Rent Manager. For more information, refer to Entity Types (System Preferences).

The following filter options are available on this page.

Narrow the list of entities that display in the list by selecting filter criteria.

Enter search criteria to display tenants with a matching Name or Account #.

Select a previously-created filter from the drop-list to apply to the list of tenants. System filters display in brackets and must be established in Rent Manager 12 before you are able to use them in Rent Manager Express.

Column Descriptions

The following columns are available on this page. By default, some columns display only if added via .

Default Column Description

Account #

The system-generated unique identifier assigned to each tenant account.

Email

The email address of the Primary contact on the tenant's account.

Lease End

If present, the end date of the tenant's most recent lease.

Lease Start

The start date of the tenant's most recent lease.

Name

The name of the tenant, which is used when referencing the tenant throughout Rent Manager and for correspondence generated from Rent Manager to the tenant.

Phone

The phone number marked as Default for the primary contact.

Property

The default property associated with the tenant. Users must have access to a property to view its tenants.

More Information

Only information related to the properties to which you have access displays. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property.

Status

The tenant's status of past, current, or future as determined by the move in and move out dates on the tenant's most recent lease.

Unit

The unit(s) which the tenant is leasing.
Available Column Description

Address

The address marked as Primary for the tenant.

Arrival Date

For short term rental (STR) tenants, the date that their reservation begins.

Balance

The tenant's current unpaid balance.

Birth Date

The Birthday of the Primary contact on the tenant's account.

City

The city in the address marked as Primary for the tenant.

Comment

Additional notes or information about the tenant, such as Only responds to texts.

Contacts

The name of the Primary contact and the number of additional contacts on the tenant's account displays.

Departure Date

For short term rental (STR) tenants, the date that their reservation ends.

Employer

The employer listed on the Primary contact of the tenant's account.

Eviction Outcome

The result of the eviction (Evicted or Not Evicted), followed by the name assigned to the outcome (e.g., Tenant Pays, Tenant Vacates, Default Judgment, Possession Granted, etc.).

Expected Move Out Date

The expected move out date as shown on the tenant's lease.

Flexible Rent Status

The current state of the tenant's Flexible Rent enrollment. For more information, refer to Flexible Rent.

Last, First Name

The name of the tenant, which is used when referencing the tenant throughout Rent Manager and for correspondence generated from Rent Manager to the tenant. Use this option to display tenant last name first.

Leasing Agent

The user listed as the tenant's leasing agent.

License

The vehicle license plate number of the tenant's Primary contact.

Move In Date

The date on which the tenant moved into their unit.

Move Out Date

The move out date as shown on the tenant's lease.

Postal Code

The postal code in the tenant's Primary address.

Property Short Name

The abbreviated name for the default property associated with the tenant.

Rent Due Day

The date or day of the week on which the tenant's rent is due.

Resident Payout Status

The tenant's Zego Resident Payout security deposit refund status(es) (e.g., Refund Initiated, Refund Canceled, Refund Complete). If the tenant does not have a refund in progress and never has, the column displays blank. For more information, refer to Zego Resident Payout.

Security Deposit

The dollar amount of the security deposit held for this tenant.

Site Classification

For tenants at manufactured housing properties, the current system-derived classification code (e.g., Resident Owned, Employee Owned, Community Owned, etc.) of the unit associated with the tenant's primary lease. For more information, refer to Site Classification.

Source

For tenants who were originally entered in Rent Manager as prospect accounts, this displays the prospect lead source that resulted in original contact with the tenant.

State

The state in the tenant's Primary address.

Statement Method

The default method for statement delivery for the tenant.

Street

The street in the tenant's Primary address.

Unit Type

The type of unit associated with the tenant's default property.

Vehicle

The vehicle name of the Primary contact on the tenant's account.

Address: (Type)

Each Address Type is listed on the Columns pop-up. The tenant's associated address of the selected type displays.

Phone Number: (Type)

Each phone number type is listed on the Columns pop-up. The tenant's associated phone number of the selected type displays.

UDF:
(Tenant Type)

Each tenant-type user defined field is listed on the Columns pop-up. The value entered on the tenant's account for the selected user defined field displays.

Send Text

Related Privileges

Group Privilege Column
Texting/Broadcast Send/Receive texts Enabled

For more information, refer to Control User Access.

Send a text message to the selected account through the text messaging center. This option displays only if there is a text-enabled phone number listed on the account.

More Information

The first text sent to a recipient from the text messaging center and any texts sent via text broadcast or automated notification include an opt-out message. If a recipient opts out, that phone number cannot receive texts from Rent Manager unless they choose to opt back in. Recipients can opt out or opt in at any time. If a recipient wishes to opt back into text messaging, they must text Start from the phone number they opted out with to the number they originally requested to opt out of.

Phone numbers that have opted out of text messaging are identified on the account's View Contacts pop-up, where the checkbox in the T column is replaced with the words Opted out in red text.
