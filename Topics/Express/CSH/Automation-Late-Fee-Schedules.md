# Late Fee Automation Schedules (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Automation-Late-Fee-Schedules.htm

You can use this Task Automation to reduce the time needed to manage late fees and the occurrence of errors from manually entering information like dates and amounts. The ability to schedule when the automation runs ensures that your postings are timely and consistent.

 Related Preferences

 To set up automation schedules, you must have the appropriate automation enabled in system preferences. For more information, refer to Task Automation (System Preferences) .

 To view your automated late fee postings, go to arrow_forward Administration , then go to Automation arrow_forward Task Automation arrow_forward Late Fees .

 Column Descriptions

 The following columns are available on this page.

 Columns
 Description

 Name

 The name of the posting schedule to distinguish differences in multiple automations.

 Active

 A displays if the posting schedule is currently enabled.

 Run Day

 The day of the month on which the automated posting should occur. Rent Manager automatically posts these late fees early in the morning of the chosen Run Day .

 Properties

 The Short Name of each property associated with the schedule, or if more than one property is selected, the short name of the first property is displayed, followed by the number of additional selected properties.

 Charge Types

 Transactions associated with these charge type(s) are examined by Rent Manager when determining if a tenant is delinquent.

 Fee Type

 The charge type used when adding late charges to delinquent tenants.

 Start Date

 The first date that the posting schedule goes into effect.

 More Information

 This is not necessarily the first date that the schedule executes. The options configured in the Schedule Options section on the Late Fee Automated Posting Detail pop-up determines the first run date.

 End Date

 The posting schedule's expiration date. If this field is blank, the schedule continues to post indefinitely or until a date is entered in the End By field on the Late Fee Automated Posting Detail pop-up.

 Last Run Date

 The date on which the most recent posting occurred.

 Next Run Date

 The next date on which the posting occurs, calculated using the Last Run Date and the Run Day selected in the Schedule Options section.
