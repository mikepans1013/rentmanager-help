# Published TWA Reports (Pop-Up)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Association-TWA-Published-Reports.htm

Properties with a Property Type of Association allow you to share reports with the association's board members, committee members and/or all tenants via Tenant Web Access (TWA) . The Published TWA Reports page allows you to view all reports that were published, which members they were published to, and other information about the report. You can also view or edit the details of the shared report or add a new one-time report to publish.

 Column Descriptions

 The following columns are available on this page.

 Field
 Description

 Report Name

 The official name of the report as shown in Rent Manager .

 Display Name

 An alternate name for the report to display to the recipients in TWA.

 Audience

 Indicates if this report was made available to all tenants, board members, and or members of a committee.

 Type

 Indicates whether the report is a One-Time report or a Recurring report.

 Published

 The date on which the report was published to TWA.

 Expires

 The date after which the report is no longer be available to view on TWA.
