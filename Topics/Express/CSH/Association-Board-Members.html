Association Board Members (Pop-Up)

If your property has an association, designate tenants as board members, manage or remove existing board members, or send an email to everyone on the board from the Board Members pop-up.

Related Privileges

Group Privilege Column
Properties/Units Properties View

For more information, refer to Control User Access.

To view the Board Members pop-up, go to arrow_forward Rental Info arrow_forward General arrow_forward Properties and select an association-type property. Then, on the action bar to the right, click arrow_forward Board Members.

Column Descriptions

The following columns display on the pop-up.

Column Description

Contact Name

The full name of the board member.

Role

The title for the board member's position (e.g., Chair, Treasurer, Secretary).

Term Start

The date that the tenant starts their term as a board member, after which they can see board-specific items in Tenant Web Access.

Term End

The date the tenant is no longer a board member, after which they no longer see board-specific property files or items in Tenant Web Access.

Email

The email address of the board member.

Status

The tenant's member status (Current, Past, or Future).

Comments

The comments and/or notes associated with the board member.
