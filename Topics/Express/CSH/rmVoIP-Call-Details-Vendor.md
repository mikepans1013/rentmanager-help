# rmVOIP Vendor Call Details (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/rmVoIP-Call-Details-Vendor.htm

When you receive a phone call from a vendor through rmVoIP , Rent Manager attempts to locate a vendor account in your database with that phone number to immediately provide you with information about the caller. Call records that are linked to vendor accounts allow you to take several actions, such as creating a service issue or adding a history/note item with information provided from the call. It also allows you to greet the vendor by name and with information specific to them when you answer the call because their account details are linked to the call.

 More Information

 This feature is licensed and must be purchased separately. For more information, contact your sales representative at sales@rentmanager.com .

 To view a list of calls you received through rmVoIP , go to arrow_forward Communication arrow_forward Texting/Phone arrow_forward rmVoIP Incoming Call History and select a call from the list. Then, select a call with the Link Type of Vendor from the list.

 Call History

 This tile displays information about the purpose and outcome of the call. This information also displays on the vendor's History/Notes .

 Field
 Description

 Category

 The history category that identifies what the call was about.

 Comment

 The explanation of what you discussed with the caller.

 Spoke with

 If checked, signifies that you spoke with the caller, as opposed to a voicemail message or receiving no answer from the caller. By default, this is checked if an incoming call is answered (establishing a start and end time to the call) or unchecked if an incoming call is not answered or is missed.

 Recent Transactions

 This tile displays information about the most recent transactions associated with the linked vendor account.

 Field
 Description

 Amount

 The total dollar amount of the transaction.

 Comment

 A comment or note about the transaction, such as the nature of the service issue the vendor addressed.

 Date

 The date the transaction posted to the account.

 Information

 Information, such as the affected bank account or the check number that paid the transaction, associated with the transaction.

 Property Short Names

 An abbreviated name for the property (ten characters or fewer) that displays on reports.

 Reference

 If entered, an additional note about the transaction, such as the check number or payment method (ACH, ePay , etc).

 Type

 The category the transaction falls into (e.g., Bills , Credits , Checks , etc.).
