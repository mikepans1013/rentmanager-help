# CAM Expense Adjustments (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/CAM-Expense-Adjustments.htm

To ensure that your common area maintenance (CAM) reconciliation values are accurate, you can manually create additional expense adjustments to add or deduct amounts from a selected general ledger (GL) account. This can be used to set up an amortized payment schedule for tenants with large commercial recoverable expense (CRE) charges, change the expensed GL account for a particular charge, or enter one-time exemptions and discounts that are part of a tenant's contract.

 Column Descriptions

 The columns below are available to review CAM expense adjustments. Columns can be added to or removed from the page by clicking .

 Default Column
 Description

 Canceled

 A displays if the Amortization expense adjustment was canceled. Canceled expense adjustments display only if Show Canceled is checked. This column is always unchecked for One-time expense adjustments.

 Ref#

 The expense adjustment's system-generated reference number.

 Adj. Date

 The date on which the expense adjustment impacts the general ledger (GL) account balance.

 Type

 The option selected when the expense adjustment was created (i.e., Amortization or One-time ).

 GL Account

 The GL account expensed by the adjustment.

 Adj. Amount

 The total dollar amount added or deducted from the GL account based on the tenant's adjustment. If the adjustment amount is a deduction, a minus sign displays before the value.

 For example, if an expense adjustment deducted $500 from the GL account, the column displays -500 .

 Property

 The short name of the property to which this adjustment is applied.

 Tenants

 The tenant lease(s) at the property that received this expense adjustment.

 Internal Note

 A note to provide further context for this adjustment that displays only for Rent Manager users.

 Available Column
 Description

 # Periods

 The number of months or years that an Amortization expense adjustment impacts the GL account during a CAM reconciliation. This column is always blank for One-time expense adjustments.

 Final Date

 The last date on which the expense adjustment impacts the GL account balance. This column is always blank for One-time expense adjustments.

 Start Date

 The first date on which the expense adjustment impacts the GL account balance.

 Tenant Note

 A note to provide further context for this adjustment that displays on the tenant's CAM Reconciliation Statement .

 Total Amount

 The total CAM expense amount for the tenant(s).
