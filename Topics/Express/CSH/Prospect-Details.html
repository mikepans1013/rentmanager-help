Prospect Details (Page)

In Rent Manager, prospects are potential tenants. These individuals express interest in your properties and rental units. The goal is to get prospects to sign leases and become paying tenants of your management company. Prospecting in Rent Manager is designed to help leasing agents and property managers manage prospect information. It also helps track the effectiveness of your leasing agents and marketing campaigns.

Related Privileges

Group Privilege Column
Tenants/Prospects Prospects View, Edit

For more information, refer to Control User Access.

A prospect's details page allows you to view and update information about an individual prospect. To view a prospect's information, go to arrow_forward Rental Info arrow_forward General arrow_forward Prospects and select a prospect from the list.

The following tiles display by default. If a custom layout is applied to your details page, you might not see all of the following tiles. For more information about creating and assigning layouts, refer to My Layouts (Page) and System Layouts (Page).

Additionally, the information that displays on the scoreboard at the top of the page may vary depending on your database's scoreboard setups. For more information, refer to Scoreboards (Page).

More Information

Some Rent Manager integrations may display additional banners of information below the scoreboard regarding the feature.

Addresses

The address(es) associated with this prospect account, such as the address of their current residence.

Contacts

Phone numbers and email addresses for the prospect and other additional potential occupants of their unit. Communication with prospects, such as emails and phone calls, send to the primary contact information listed in this tile by default. You can also add more contacts to the prospect by clicking Add Contact.

Estimates

This tile displays recorded anticipated costs for parts and labor needed to complete projects, itemize the costs, and provide a total amount due including any markups and/or taxes you add. This tile is available only through a custom layout, for more information, refer to Add a Personal Layout.

Column Description

Days Old

The number of days between the current date and the estimate's Create Date as it displays on the Estimates page.

Estimate #

The unique system-generated number assigned to the estimate.

Job

If applicable, the job Name, as it displays on the job's General tile, associated with the estimate. For more information, refer to Jobs (Page).

Related Preferences

In order to use the job costing tool in Rent Manager, Enable job costing must be checked in system preferences. For more information, refer to General Options (System Preferences).

Reference

A user-created identifier for the estimate.

Status

The current stage of the estimate. Only active estimates with the status of Draft or Awaiting Approval display.

Total

The total dollar amount of all inventory items, including any added markup or tax.

General

Information about the prospect and the details of their intended rental, as well as their security deposit information. You can also manage their security deposits from this tile.

Field Description

First Name

The first name of the prospect that shows on reports and scripting.

Last Name

The last name of the prospect that shows on reports and scripting.

Property

The primary property associated with the prospect. Users must have access to this property to view this prospect.

More Information

This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property.

Display Color

A color to help identify prospects of certain types, groups, or any other specifications you prefer. The color displays as a bar to the left of the prospect in some areas of Rent Manager, such as the Prospects list page.

History/Notes

The most recent history/note items on the prospect's account. History/notes record information about interactions and communication with prospects, such as phone conversations or explanations of transactions. You can add a history/note item by clicking Add Note or the drop-down arrow to select a different type.

Column Description

Date

The date the note was created.

Type

The system-generated history/note type. For example, if the history/note item is linked to a service issue, the Service Issue type displays.

Note

The information to describe the history/note item (e.g., Confirmed inspection notice was received). If no text is entered, the column displays blank.

Interested Properties/Units

Information about the units that match the prospect's expressed interest. If the prospect is on the Wait List for a unit, a Check displays.

Lead Information

Information about the prospect's leasing agent, interest level in renting your units, and status in the lead generation process. Additionally, click Move In to begin the process of turning a prospect into a tenant and move them into their unit.

Field Description

Leasing Agent

The user who acts as the prospect's leasing agent, if applicable. Users with the option Sales Rep/Leasing Agent selected on the user's details page display in this list.

Lead Source

The main source of information that describes how this prospect learned about your company. This information is reflected in the Box Score report and can give you insight on what types of marketing strategies are most effective for your company.

Stage

The prospect stage that describes the current progress of a prospect through the leasing process. Clicking opens the Stage History pop-up, which allows you manage the progression of prospects through the leasing process. Tracking these sources can be beneficial for certain prospecting reports (e.g., Box Score and Owner Prospect Box Score) that assess the marketing strategies you have employed. You can also use stages to search for prospect accounts. For more information, refer to Prospect Stage History (Pop-Up).

Interest Level

The prospect's interest level (0 through 10, with 10 being highest) in your property.

Status

The prospect stage that describes the current progress of a prospect through the leasing process. To update the status, click Change. For more information, refer to Change a Prospect Status.

Application Date

The date the prospect's application was received.

Pets

The Pets tile displays the details for each pet entered on the prospect's account, and you can view other pets on the list by clicking the arrows at the bottom. To edit pet details, click to open the View Pets pop-up. This tile displays only if there are pet types established in your database.

Preferences

Information about the type(s) of units the prospect prefers, the number of people who are moving in, and the rent range for the prospect. Additionally, click Unit Picker to search for potential units that meet the prospect's preferences and either reserve them for the prospect, or add the prospect to the waiting list for the unit.

Field Description

Preferred Unit Types

The preferred type(s) of unit the prospect is looking to rent.

Preferred Floors

The preferred floor(s) where the prospect is willing to rent a unit.

Preferred Amenities

The features, services, or other amenities the prospect wants included with their unit.

Number of People

The number of people who will occupy the unit. This can not exceed the unit’s Max Occupancy value.

Rent Min.

The lowest rent amount the prospect anticipates paying for a unit.

Rent Max.

The highest rent amount the prospect anticipates paying for a unit.

Expected Move In Date

The prospect's expected move in date. You should select an expected move- in date that corresponds with the rental plans of the prospect (i.e., in two months, three months, and so on) to view the units that are available at that time.

Expected Move Out Date

If known, the prospect's expected move-out date. This is a soft move out date that does not stop recurring charges from being posted or list the unit as vacant once the date has passed.

Rent Quotes

Information about the lease terms for units and other rentable items (ORI), including rent and other charge amounts, that your company has offered to the prospect during the leasing process. For more information, refer to Rent Quotes (Pop-Up). This tile does not display for prospects with a Status of Tenant, Lost, or Lost/Rejected. It also does not display for prospects associated with RV/Campground- or Short Term Rental-type properties. If the prospect has multiple rent quotes, each quote displays as a separate row with its own row actions available from the menu. To

reserve the unit selected in a rent quote, click Reserve. The rent quote's lease terms, move in date, and unit information are then added to the Reservation Expected Lease Information tile.

Field Description

Additional Recurring

The total of all recurring charges with non-rent charge types in the rent quote’s Recurring Charges section.

Date Quoted

The date on which the rent quote was added to Rent Manager.

Expiration

The date on which the rent quote is set to expire and no longer be valid. If there is not an expiration date, this field is blank.

Lease Term

The duration of the proposed lease, such as twelve months or month-to-month.

Move In

The move in date for the unit and ORI(s) associated with the rent quote.

One Time Charges

The total of all charges selected in the rent quote’s One-time Chargessection.

ORI Unit

The other rentable item (ORI) that is included in the rent quote.

For a unit to be an ORI, its associated unit type must Other Rentable Item enabled.

Property

The property with which the rent quote is associated.

Rent

The total dollar amount of the rent quote.

Status

The status of the rent quote, which can help property managers keep track of quotes that have been offered, accepted, or expired. The following statuses are available:

Reserved

A quote associated with a reserved unit.

Expired

A quote with a past expiration date.

Active

A quote that hasn't expired and is not associated with a reserved unit.

Total Recurring

The total of all recurring charges in the rent quote’s Recurring Charges section.

Unit

The unit with which the rent quote is associated.

Reservation

Information about a prospect's short-term rental (STR) reservation, including the property, unit, arrival and departure dates, and number of nights for their stay. To edit reservation details, click to open the Reservations pop-up. This tile displays only if the prospect is linked to a property with a Property Type of RV/Campground or Short Term Rental.

Field Description

Reserved Property

The property at which the reservation was made.

Unit

The name of the unit the tenant reserved.

Arrival

The start date of the tenant's stay at the unit.

Departure

The end date of tenant's stay at the unit.

# Nights

The calculated number of nights between the Arrival date and the Departure date. If no Departure date is entered, this value displays 0.

This field displays only for tenants with a single reservation.

Request

Any additional information about the reservation.

Source

The origin of the reservation. If the reservation was created by a user, RentManager displays. If the reservation was created by the tenant thorough the Online Booking Portal, OnlineBooking displays.

Confirmation #

The reservation's system-generated confirmation number.

Reservation/Expected Lease Information

Information about a unit that is reserved for the prospect, including the lease term, expected lease dates, and the prospect's expected rent period. Click to open the Unit Selector and view potential units to reserve for the prospect. This tile displays only if the prospect is linked to a property with a Property Type that is not RV/Campground or Short Term Rental.

Field Description

Due Day

The day of the month on which rent is due for this tenant.

If Rent Period is Monthly, there are options to select the day of the month (1–31) on which the tenant's rent is due. The default is 1 (the first of the month).

If Rent Period is Weekly, there are options to select the day of the week (Sunday–Saturday) on which the rent is due (the default is Sunday).

Expected Lease End

The date on which the lease is expected to expire.

Expected Lease Start

The date on which the lease is expected to begin.

Home

The home-type asset's name. This field displays only if a unit is reserved, that unit is associated with a manufactured housing-type property, and has a home located on it, as of the Reserved Move In date.

Lease Term

The duration of the lease.

ORI Unit

The other rentable item (ORI) reserved for the prospect.

For a unit to be an ORI, its associated unit type must have Other Rentable Item enabled.

Rent Period

The expected rental period that determines if the tenant has charges posted to their account on a daily, weekly, or monthly basis.

Reserve associated home

If selected, the Home is linked to the reserved unit.

Reserved Move In

The date the user reserved for the prospect to move in to the unit.

Reserved Move Out

The date on which the prospect is expected to vacate the unit.

Reserved Unit

The unit the user reserved for the prospect.

If the reserved unit is associated with a manufactured housing-type property and does not have a home located on it between the Reserved Move In and Reserved Move Out dates, Add Resident Owned RV displays. Clicking this option opens the Add RV pop-up, where you can enter the details of the resident's RV.

If the reserved unit is associated with a manufactured housing-type property and a resident-owned RV was added to the prospect, View RV Details displays. Clicking this option opens RV Details pop-up, where you can view and edit the details of the resident's RV.

Screening/Verification

Information about a completed prospect screening, including credit, criminal, and eviction history. If you have Income and ID Verification through AmRent, the status of each verification process also displays. Additionally, click Run Screening to begin the screening or verification process for the prospect.

Related Preferences

By default, the Run Screening button displays on this tile, and you can send an income verification request link by clicking the drop-down arrow next to the button and selecting Run Income Verification. The default option that displays can be changed in system preferences using the Default Screening Type option. For more information, refer to Screening Products Credentials (System Preferences).

In the Income & ID Verification section, an icon displays next to the primary contact's name showing the overall ID verification status of all contacts.

Icon Details

All contacts passed ID verification.

At least one contact has passed and at least one contact has failed or has no ID verification status.

All contacts have failed ID verification.

To override the screening workflow solution for a prospect, you can click Screening Not Required for prospects that are not yet screened or Override Screening for prospects that already were screened. Prospects who have the screening workflow solution overridden can be moved in, changing their status to Tenant, regardless of the recommendation provided in the Workflow Solution report.

Transactions

The most recent transactions processed for the prospect's account, including posted charges and payments made. Additionally, you can add a transaction to the prospect account by clicking Add Payment or Add Charge.

Column Description

Date

The date the charge, credit, or payment posted to the account.

Reference #

If applicable, the note entered by a user describing the type (CASH, MO, the check number, and so on) of transaction.

Description

The system-generated details to provide context for the transaction.

Amount

The total value of the transaction. Payments and credits display with a negative value while charges display with a positive value.

Balance

The total amount due on the account after the transaction is applied.

Unit User Defined Information

Any unit-level user defined fields (UDFs) for which the prospect has a specified preference regarding their potential rental unit.

UDFs

User-defined fields display on this tile based on when a value was added to the UDF. The order in which the user-defined fields display may not match the order that displays in the User Defined Fields pop-up or on the User Defined Fields page. This tile displays up to six prospect-type UDFs with values and used to track information that Rent Manager does not track by default.

Workflow Project

Related Privileges

Group Privilege Column
Service Manager Workflow Projects View

For more information, refer to Control User Access.

If the prospect is linked to an active workflow, this tile displays each stage of that workflow process and the number of steps that are completed for each stage. Additionally, you can view each step and its assigned user by clicking to display the Workflow Project Overview.

This tile displays only if the associated workflow project was created from a template with the Show workflow projects on prospect details option enabled. For more information, refer to Workflow Template Details (Pop-Up).
