Unit Filters (Pop-Up)

With unit filters, you can narrow your search results to display only the units that meet your needed search criteria. Rent Manager gives you the ability to choose from a variety of filtering options to sort your units.

Related Privileges

Group Privilege Column
Properties/Units Units View

For more information, refer to Control User Access.

Rent Manager allows you to create filters that can be used temporarily, or saved to use repeatedly. Additionally, they can be saved on a system level for all users, or on a personal level where only your user account can access it. Before saving your filter, enter a Name, and, optionally, a Description to remind you of the filter's purpose.

To create unit-specific filters, go to arrow_forward Rental Info arrow_forward General arrow_forward Units and click .

More Information

If the basic filtering does not meet your needs, you can create an advanced filter which allows you to group your filters for a more granular, precise filtering criteria. For more information, refer to Create an Advanced Filter.

On the Units page, there are multiple fields available for basic filtering of units. The fields are divided into multiple sections. Each field is described below.

General Information

This section contains fields for filtering units by information that can be found on their detail pages, such as the name of the property associated with them, the unit types available, or the square footage.

The following fields display in this section:

Field Description

City

Includes units with an address that contains the city entered here.

Comments

Includes units that have a vale in their Comment field that contains or matches the value entered here.

Display

Includes only the units that have the specified display color set in their General tile.

Owner

Includes units from properties owned by the selected owner.

Postal Code

Includes units with an address that contains the postal or zip code entered here.

Property Group

Includes only the units that are part of the selected property group.

Property Name

Includes units that are located at the specified property.

Show only vacant Units

If checked, includes only vacant units in the filtered list.

Site Classification

Includes only the units that are part of the selected site classification. These classifications are system-derived statuses which indicate the operational state of manufactured housing sites. For more information, refer to Site Classification.

Square Footage

Includes units with a square footage that contains or matches the value entered in this field. For example, if you enter 5 in this field, the resulting list could include units with square footage values such as 500, 1,250, or 1,500.

State

Includes units that have a state abbreviation in their address that contains or matches the value entered in this field. For example, if you enter K in this field, the resulting list could include units in any state with a K in the abbreviation, such KY or KS.

Street

Includes units with an address that contains or matches the value entered in this field.

Unit Name

Includes units with a name that contains or matches the value entered in this field. For example, if you select a property in the Property Name field and then enter 1 in the Unit Name field, the filter displays all units at that property with a 1 anywhere in their unit name.

Unit Type

Includes units that are assigned the selected unit type.

User Defined Fields

In this section, filter units according to values entered for unit-type user-defined fields (UDFs). Select a UDF from the User Defined Field drop-down and then enter a value or select an option in the User Defined Value field.

Amenities

In this section, filter units according to which amenities they offer. All amenities you create are available in this list.
