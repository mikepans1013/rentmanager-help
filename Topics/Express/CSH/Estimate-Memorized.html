Memorized Estimates (Page)

Estimates allow you to record the anticipated parts and labor needed to complete a project, itemize the costs, and provide a total amount due including any markups and/or taxes you add. Estimates can also be linked to an invoice, service issue, and/or purchase order. Memorized estimates are templates from which new estimates can quickly be created. You can either create a memorized estimate from scratch, or you can save an existing estimate as a memorized estimate template.

Related Privileges

Group Privilege Column
POs/Estimates Estimates View

For more information, refer to Control User Access.

To view your memorized estimates, go to arrow_forward Receivables arrow_forward General arrow_forward Memorized Estimates.

Column Descriptions

The following columns display on the page.

Column Description

Name

A title to identify the memorized estimate.

Description

An explanation of the purpose for the estimate.

Reference

A reference number or additional identifier for the estimate.

Total Value

The total dollar amount of the inventory items, including any markup or tax, included in the estimate.

Create Date

The date on which the memorized estimate was created.

Available Column

Description

Comments

Any additional information about the estimate.

From Address

The default address of the property for which the estimate was created.

Property

The full business name of the property for which the estimate was created.

Property Short Name

The abbreviated name of the property for which the estimate was created.

Tax %

The tax rate applied to any taxable inventory items in the estimate.

Tax Type

The tax type applied to any taxable inventory items in the estimate.

Taxable

A displays for estimates that include taxable inventory items.

Type

The type of account that the estimate applies to.

Update Date

The date of the most recent change to the memorized estimates details. If no update was made, this displays the create date.
