Memorized Issues (Page)

Memorized issues allow you to save time by creating templates for common tasks, such as re-keying locks or unclogging drains. Memorized issues are issue templates that are saved to easily create new issues that are already populated with information. You can either create a new memorized issue, or you can memorize an existing issue into a template.

Related Privileges

Group Privilege Column
Service Manager Issues View

For more information, refer to Control User Access.

To view the Memorized Issues page, go to arrow_forward Services arrow_forward Service Manager arrow_forward Memorized Issues.

Column Descriptions

The following columns are available on this page. By default, some columns display only if added via .

Column Description

Category

The type of the issue.

Created By

The user that created the memorized issue.

Description

The text entered in the Memorized Issue Description field of the memorized issue.

Issue

The text entered in the Title field of the memorized issue.

Name

The name of the memorized issue, as entered in the Memorized Issue Name field.

Priority

The urgency you assign to an issue.

Status

The current progress of an issue.

Available Columns

Description

Checklist Item Count

The total number of items (i.e., steps) associated with this memorized issue. For more information, refer to Checklist Items (Pop-Up).

Created

The date the memorized issue was added and saved in Rent Manager.

Issue Description

An optional note about this memorized issue (e.g., Perform standard tune-up on HVAC system. Record any additional costs in Work Order section).

Project

If this memorized issue is part of a project defined in the Service Manager Projects page, the name of the project displays. For more information, refer to Workflow Projects and Templates.

Property

The short name of the property associated with this memorized issue.

Property City

The city as listed in the associated property's Default address.

Property Short Name

The short name of the property associated with this memorized issue.

Property State

The state as listed in the associated property's Default address.

Property Street

The street as listed in the associated property's Default address.

Property Zip

The postal code as listed in the associated property's Default address.

Tenant

The name of the tenant associated with the memorized issue.

Tenant City

The city as listed in the associated tenant's Default address.

Tenant State

The state as listed in the associated tenant's Default address.

Tenant Street

The street as listed in the associated tenant's Default address.

Tenant Zip

The postal code as listed in the associated tenant's Default address.

Unit

The unit associated with the memorized issue.

Unit City

The city as listed in the associated unit's Default address.

Unit State

The state as listed in the associated unit's Default address.

Unit Street

The street as listed in the associated unit's Default address.

Unit Zip

The postal code as listed in the associated unit's Default address.

Update User

The last user who made an update.

Updated

The last date a user updated the memorized issue.

Vendor

The vendor assigned to the memorized issue.
