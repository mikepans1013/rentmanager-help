# Prospect Payments (Pop-Up)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Prospect-Payments.htm

Once a prospect has made a payment in the real world, this payment can be entered in Rent Manager using the Add Payment pop-up. This allows you to record payments and prepayments and apply credits to the selected prospect account.

 Related Privileges

 For more information, refer to Control User Access .

 To access the Add Payment pop-up, go to   arrow_forward Rental Info arrow_forward General arrow_forward Prospects and select a prospect from the list. On the action bar to the right, click   arrow_forward   Add Payment .

 Payment Info

 The Payment Info section includes fields to enter details about the prospect payment. Each field is described below.

 Field
 Description

 Date

 The date the prospect is making the payment.

 Reference #

 The following forms of payment to describe the transaction are available to select.

 More Information

 If, in the Payment Summary section, the Process via ePay option is selected, this field displays ePay and cannot be edited.

 Cash

 Record a cash payment.

 MO

 Record a money order payment.

 CC

 Record a credit card payment.

 Check

 Manually type the check number into the Reference # field to record a check payment.

 Amount

 The full dollar amount of the payment you received.

 Memo

 A brief comment about this payment, such as how it was applied. Payment memos display on prospect's View Transactions pop-up, in the Comment column.

 Open Charges

 The Open Charges section displays the prospect's current open charges. In the section header, the following option is available. To display a single line item for the combined total of items on an invoice, click Collapse Invoices . Otherwise, a separate line for each item on the invoice displays.

 The columns that display in this section are described below.

 Column
 Description

 Date

 The date the charge, credit, or payment posted to the account.

 Reference #

 If applicable, the payment type entered by a user describing the type ( CASH , MO , the check number, and so on) of transaction.

 Description

 The description as entered on the associated charge type for the transaction.

 Original Amount

 The total dollar amount of the charge before any partial payments are applied.

 Amount Paid

 If a partial payment is allocated to the charge, the dollar amount of that partial payment displays.

 Amount Due

 If applicable, the dollar amount due for the charge after any partial payments are applied.

 Current Payment

 The dollar amount you are currently applying to the charge.

 Pay?

 A displays if the charge is currently selected to be paid.

 Payment Summary

 The Payment Summary section includes additional payment options and an overview of the payment's information. Each field is described below.

 Field
 Description

 View Receipt

 Prints a receipt for the prospect after accepting the payment.

 Process via ePay

 Process the payment as an ePay payment. This option is available only if the prospect's property is set up for ePay . When this option is checked, the Reference # field is automatically updated to ePay and cannot be edited.

 Payment Notes

 Any history/note items with the Show on payments tab option enabled display. If there are no items with this option checked, this field does not display.

 Original Amount

 The total dollar amount of all open prospect charges before any partial payments are applied.

 Amount Paid

 If partial payments are allocated to any charges, the total dollar amount of those partial payments displays.

 Amount Due

 If applicable, the total dollar amount due for all open prospect charges after any partial payments are applied.

 Current Payment

 The total dollar amount of the payment as entered in the Payment Info section in the Amount field.

 Overpayment

 If the amount of the payment exceeds the total Amount Due , the exceeded amount displays. This field displays only when making a payment for a positive amount. The overpaid amount can then be applied as prepay allocations in the Prepay Allocations pop-up or left to be applied as a credit at a later time.

 Overpayment = Amount - Amount Due
