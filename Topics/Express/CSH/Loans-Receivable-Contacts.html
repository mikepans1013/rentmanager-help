Loans Receivable Contacts (Pop-Up)

For each loan receivable you have in Rent Manager, you can add contact information for the borrower and any other associated contacts, such as a co-guarantor. The Primary Borrower's contact information is used when generating tax forms from Rent Manager.

Related Privileges

Group Privilege Column
Loans Receivable Loans Receivable View, Edit

For more information, refer to Control User Access.

To view the contacts associated with a loan receivable, go to arrow_forward Receivables arrow_forward Loans Receivable and select a loan from the list. Then, on the action bar to the right, click arrow_forward Contacts.

The Loan Contacts details page is divided into four sections for each contact: General, Address, Options, and Employer Information. Each section and related fields are described below.

General

The following fields display in the General section:

Field Description

Primary Borrower

A indicates that the contact information is for the person named on the loan. The Primary Borrower's information is used when generating tax forms in Rent Manager.

First Name

The contact's given or preferred name.

Middle Name

The contact's middle name or initial.

Last Name

The contact's surname.

Generation

If needed, additional information to use as a suffix for the contact's name (such as Junior, Senior, II, or III).

Soc Sec #

The contact's social security or tax ID number.

Phone

The contact's phone number. This is the number used to call this contact when making calls from Rent Manager.

Birthday

The contact's date of birth.

Occupation

The contact's current job.

Residence

Whether the contact owns or rents their current residence.

Address

The following fields display in the Address section:

Field Description

Street

The street address of the contact's current place of residence.

City

The city where the contact's current place of residence is located.

State

The state where the contact's current place of residence is located.

Zip

The zip or postal code of the contact's current place of residence.

Country

The country where the tenant currently resides.

Options

The following fields display in the Options section:

Field Description

Indicator

The indicator code to identify the borrower's address type.

ECOA

The Equal Credit Opportunity Act code to identify the type of borrower account.

Employer Information

The following fields display in the Employer Information section:

Field Description

Name

The name of the contact's current employer.

Street

The street address of the contact's current employer.

City

The city where the contact's current employer.

State

The state where the contact's current employer is located.

Zip

The zip or postal code of the contact's current employer.
