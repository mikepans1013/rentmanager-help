# Address Types (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Address-Types.htm

Address types let you create and manage your own categories for addresses. This makes it easy to record and reference multiple addresses on the same entity. Additionally, this adds the ability to pull a specific address type into other parts of Rent Manager , such as reports and features that use scripting. Once you define an address type for a specific entity type, you can go to any account for that entity type to enter the associated address.

 To view available address types, go to   arrow_forward   Administration , then go to Customization arrow_forward Address Types and select an entity type.
