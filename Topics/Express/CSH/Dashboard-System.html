System Dashboards (Page)

System dashboards are user-created dashboards that can be set to override the Rent Manager system-default dashboard. You can also manage and share these dashboards with other users to provide them with the most relevant information, removing the need for them to create their own dashboards or having dashboards with information they don't need. From this page, you can create a new system dashboard from scratch, use a provided template, or copy a specific user's dashboard as a system dashboard.

Related Privileges

Group Privilege Column
Setup Manage system dashboards Enabled

For more information, refer to Control User Access.

More Information

Personal dashboards, which are dashboards that are specific to only your user account and cannot be shared with other users, are located on the My Dashboards page. For more information, refer to My Dashboards (Page).

To view the System Dashboards page, go to arrow_forward Administration, then go to Customization arrow_forward System Dashboards.

Column Descriptions

The following columns are available on this page:

Column Description

Name

The name of the dashboard (e.g., Operations, Maintenance, Payables, etc.).

System Default

A displays for the default dashboard.

More Information

Only one dashboard can be considered the default. To change the default dashboard for all assigned users, click on the desired dashboard and select Make Default.

Create User

The Username of the user who created the custom dashboard.

Create Date

The date that the custom dashboard was created.

Update User

The Username of the user who last edited and saved the custom dashboard.

Update Date

The date that the custom dashboard was last updated and saved.

Assigned Users

The usernames of all users who are assigned to access and use the custom dashboard.

Row Actions

The following row actions are available from the menu:

Action Description

Assign Users

Opens the Assign Users pop-up, where the dashboard can be assigned to users and/or user roles. On the Dashboard page, these users can select the dashboard to view.

Make Default

The default dashboard that displays for users who do not have any created or assigned dashboard.

Details

Opens the Edit Dashboard page, where you can manage the dashboard's tiles and settings.

More Information

If the system dashboard was created in Rent Manager 12, it cannot be edited in Rent Manager Express.

Delete

Permanently removes the dashboard from Rent Manager.

Copy

Opens the Copy Dashboard pop-up, which allows you to copy and, if desired, rename the dashboard. By default, the dashboard name begins with Copy of.
