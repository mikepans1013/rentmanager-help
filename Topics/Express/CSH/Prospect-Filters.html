Prospect Filters (Pop-Up)

Prospect filters allow you to quickly narrow your search results to get to the prospect information that you really need. Rent Manager gives you the ability to choose from a variety of filtering options to sort your prospects on the Prospects page.

Related Privileges

Group Privilege Column
Tenants/Prospects Prospects View

For more information, refer to Control User Access.

Rent Manager allows you to create filters that can be used temporarily, or saved to use repeatedly. Additionally, they can be saved on a system level for all users, or on a personal level where only your user account can access it. Before saving your filter, enter a Name, and, optionally, a Description to remind you of the filter's purpose.

To create prospect-specific filters from the Prospects page, click .

More Information

If the basic filtering does not meet your needs, you can create an advanced filter which allows you to group your filters for a more granular, precise filtering criteria. For more information, refer to Create an Advanced Filter.

On the Prospects page there are multiple fields available to use for basic filtering of prospects. The fields are divided into multiple sections. Each field is described within the corresponding section below.

General Information

This section contains fields for filtering prospects by information that can be found primarily on their details pages.

In the Search Options field, select whether the filtered prospect list includes results for prospects based on whether the relevant information Contains your filter criteria or Begins With the your filter criteria.

For example, if you are filtering prospects with a Postal Code that start with 4, you can select Contains to display all prospects whose zip or postal code has the number 4. Alternatively, if you select Begins With, you see results only for prospects whose zip or postal code starts with the number 4.

The available filter fields are described in the table below.

Field Description

Account Name

The name of the prospect's account as entered on the General tile.

Account #

The number generated by Rent Manager for the account as shown on the prospect's scoreboard.

City

The Default city as listed on the prospect's Addresses tile.

Comment

Additional information relating to the prospect, if any, as entered on the General tile.

Default Phone

The phone number selected as Default for the prospect as found on the Contacts tile.

Display

The Display Color selected on the prospect's General tile. For more information, refer to Colors (Page).

Email

The prospect's email address as entered on the Contacts tile.

Employer

The name of the prospect's employer as entered on the View Contacts pop-up.

First Name

The prospect's First Name as entered on the General tile.

Include Inactive Contacts

Includes any contacts in the search results that meet the filter criteria, even if the Active checkbox for that contact is unchecked.

Interest Level

The prospect's interest level (0 through 10, with 10 being highest) in your property as listed on the prospect's Lead Information tile.

Is Company

Includes results for prospects based on whether they are a commercial prospect.

Last Name

The prospect's Last Name as entered on the General tile.

Lead Source

How the prospect found out about your property as listed on the prospect's Lead Information tile. For more information, refer to Prospect Lead Sources (Page).

Postal Code

The Default postal or zip code as listed on the prospect's Addresses tile.

Property

The name of the property associated with the prospect as selected on the General tile.

The Search Options field does not affect this filter option.

More Information

This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property.

Property Group

A group of two or more properties that exist in your Rent Manager database.

The Search Options field does not affect this filter option.

Stage

The current stage of the prospect. For more information, refer to Prospect Stages (Page).

State

The Default state name as listed on the prospect's Addresses tile.

Street

The Default street name as listed on the prospect's Addresses tile.

Lease Information

This section contains fields for filtering prospects by their most recent lease information located primarily on the Reservation/Expected Lease Information tile.

The available filter fields are described in the table below.

Field Description

Created Between

Includes prospects whose accounts were created during the selected date range.

Move In Date Between

The prospect's Reserved Move In date that occurred during the selected date range.

Unit Name

The name of the unit associated with the lease as selected on the Reservation/Expected Lease Information tile.

Unit Type

The type assigned to the unit listed on the lease.

Contact Dates

This section contains fields for filtering prospects by their most recent contact information located primarily on the Prospect Leasing Board.

The available filter fields are described in the table below.

Field Description

Last Contact Between

Includes prospects whose last contact occurred during the selected date range.

Next Contact Between

Includes prospects whose next contact occurs during the selected date range.

Transaction Information

This section contains fields for filtering prospects by transaction information located on the prospect's View Transactions pop-up.

The available filter fields are described in the table below.

Field Description

Balance

Filters prospects based on the current balance on the prospect account.

Click the drop-down arrow at the top right of the field to select a calculation option, then enter the value to compare. For example, if you select > Greater than and enter 100 in the field, the filtered prospect list results display only prospects with a balance over one hundred dollars.

= Equals

Results equal to the entered value display.

<> Does not equal

Results that do not equal the entered value display.

> Greater than

Results that are greater than the entered value display.

< Less than

Results that are less than the entered value display.

>= Greater than or equal to

Results that are greater than or equal to the entered value display.

<= Less than or equal to

Results that are less than or equal to the entered value display.

Check #

Filters prospects based on the Reference # of a prospect payment.

To display only prospects with a payment reference number that matches your entered criteria exactly, check Exact Match. For example, if you enter 123, then the list results are filtered to display only prospects with payment reference numbers of exactly 123. If this option is unchecked, the results include prospects with payment reference numbers that contain 123 anywhere in the field, such as 1234 or 51236.

Open Charges Older Than X Days

Filters prospects based on how long their open charges have not been paid in full.

Unit Information

This section contains fields for filtering prospects by unit information located on the prospect's details page Preferences tile.

The available filter fields are described in the table below.

Field Description

Amenities

The features, services, or other amenities the prospect wants included with their unit.

Floor

The preferred floor where the prospect is willing to rent a unit.

Number of People

Filters prospects based on the number of people to be occupying a unit.

Click the drop-down arrow at the top right of the field to select a calculation option, then enter the value to compare. For example, if you select > Greater than and enter 5 in the field, the filtered prospect list results display only prospects associated with a unit with over five people occupying.

= Equals

Results equal to the entered value display.

<> Does not Equal

Results that do not equal the entered value display.

> Greater than

Results that are greater than the entered value display.

< Less than

Results that are less than the entered value display.

>= Greater than or equal to

Results that are greater than or equal to the entered value display.

<= Less than or equal to

Results that are less than or equal to the entered value display.

Rent Range From

The lowest rent amount the prospect anticipates paying for a unit. In the To field, the highest rent amount the prospect anticipates paying for a unit.

Other Filters

This section contains additional fields for filtering the prospect list, such as filtering by user defined fields (UDFs) or phone numbers.

The available filter fields are described in the table below.

Field Description

Phone Number Type

First, select the phone number type in which to search, then in the Phone Number field to the right, enter a full or partial phone number to filter the results. Only prospects that meet the filter criteria for the selected phone number type display.

User Defined Field

Select a prospect-type UDF from the list by which to filter prospects. Then in the Value field, enter or select the information to narrow your results to prospects that meet the entered criteria.
