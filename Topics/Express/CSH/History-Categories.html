History Categories (Page)

History categories help organize the history/notes entered for various accounts and records. You can create any number of categories—Complaints, Evictions, Referrals, Lease Info, Emails, and so on. History categories help you to efficiently filter and report on the notes you have entered in Rent Manager.

Related Privileges

Group Privilege Column
History History categories View

For more information, refer to Control User Access.

To view the history categories page, go to arrow_forward Rental Info arrow_forward Rental Info Setup arrow_forward Tenants/Prospects arrow_forward History Categories.

Filter Information

Filters Descriptions

Search

Enter the desired search criteria to display results with a Name that matches the search criteria.

Type

Select the history category type (e.g., Tenant/Prospect, Property, Asset, Bill, Estimate) to examine. To display history categories that apply to all entity types, select <All Types>.

Show Inactive

Check Show Inactive to include history categories that are not marked as active in the results.

Column Descriptions

The following columns display on the page.

Column Description

Active

A displays if the history category has Active checked on the History Categories Detail pop-up.

Name

The unique name of the history category (e.g., Eviction, HOA, Maintenance).

Type

The name of the history category type (e.g., Tenant/Prospect, Property, Asset, Bill, Estimate). If the history category is applied to multiple types, a total count of associated types displays at the right (e.g., +1, +2). Click the drop-down arrow to view the associated types for the history category.
