Inspection Details (Page)

The Inspection details page allows you to view and manage information regarding the management inspection or tenant self-inspection. Additionally, you can update the inspection as progress is made.

Related Preferences

This feature is licensed and must be purchased separately. For more information, contact your sales representative at sales@rentmanager.com.

Once the feature is licensed, it must be activated before you can use the Inspection feature in the app. For more information, refer to rmAppSuite Inspection (System Preferences).

Related Privileges

Group Privilege Column
Inspections Inspections View

For more information, refer to Control User Access.

To view an inspection's details page, go to arrow_forward Services arrow_forward Inspections arrow_forward Inspections and select an inspection from the list.

At the top right of the page, click to view information regarding when and by which user the inspection was created and updated. The text Make Ready displays at the bottom left of the page if the inspection is created via a make ready process. For more information, refer to Set Up the Make-Ready Board for Unit Turnover.

The following fields display at the top of the page:

Field Description

Property

The property at which this inspection takes place.

Tenant

The tenant associated with the unit to be inspected.

Unit

The unit at the property for which this inspection should be performed.

More Information

On the inspection details of a tenant self-inspection, the fields at the top of the page cannot be edited.

Information

This tile displays general information entered when the inspection is created. The fields that display vary between management inspections and tenant self-inspections.

Management Inspections

The Information tile for management inspections displays the assigned Inspector, Status, Type, and Inspection Date.

Field Description

Inspection Date

The date on which the inspection is performed.

Inspector

The user who is performing the inspection, or ensuring the inspection is completed.

Status

The current status of the inspection to specify its progress in the inspection process.

Type

The type of inspection being performed (e.g., Annual, Move-In, Move-Out).

Tenant Self-Inspections

The Information tile for tenant self-inspections displays the assigned Status, Type, Inspection Date, and Expiration Date.

Field Description

Expiration Date

The date on which the inspection is no longer accessible in rmResident.

Inspection Date

The date the tenant submits inspection via rmResident.

Status

The current status of the inspection to specify its progress in the inspection process.

Type

The type of inspection being performed (e.g., Annual, Move-In, Move-Out).

Template Settings

This tile displays the settings inherited from the inspection template that determine how the inspection functions in rmResident. It displays only on the inspection details page of tenant self-inspections.

Field Description

Inspector Type

Indicates that this is a tenant self-inspection. The field always displays Tenant.

Require status for all items

Indicates whether the inspection template's rmResident Mode is set to Detailed and the Require status for all items field is checked.

rmResident Mode

The user interface, either Simple or Detailed, that displays in rmResident.

Detailed

 Tenants see the items in each area. They choose which ones to review, or you can require them to inspect all items.
Simple Tenants see the areas and can add items, or they can finish without adding any items.

Description

This tile is used for entering and relaying important information regarding the inspection being performed.

Notes

This tile is used to add additional information that may affect or apply to the inspection being performed. These notes display in the Inspection, Web Inspection, and Inspection Summary reports.

Areas

This tile displays the areas and items that need to be inspected. The areas (the rooms being inspected) and items (the objects within the rooms) that display in the inspection are determined by the inspection template selected when the inspection is created. Click Add Areas to customize the inspection specifically for the unit being inspected. Use the to perform actions on the area selected from the list on the left of the tile, such as adding a new item or deleting the entire area and all items within it. If there is captured video, a Play Video button displays next to the corresponding area.

The following fields are available for each item within an area:

Field Description

Name

The name of the item.

Status

 The status (e.g., Good, Poor, Needs Repair) that best describes the condition of the item. The Status's flags update based on settings in the Toolbox - Edit Statuses tab. For more information, refer to Edit an Inspection Template Toolbox.

Notes

 Any comments or notable observations about the item or its condition.

Images

 If applicable, photos of the item to document its condition.

More Information

On the inspection details of a tenant self-inspection, information in the Areas tile is read-only.
