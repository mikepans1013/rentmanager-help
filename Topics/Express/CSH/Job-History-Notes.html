Job History/Notes (Pop-Up)

History/notes allow you to record information that supplements or clarifies what is entered in other fields, such as notes about phone conversations, items on a to-do list, and explanations about transactions. While some history/note items are automatically created by Rent Manager, you are also able to record information based on your needs. This makes it easier to track events related to each job and provide additional details for internal reference.

Related Preferences

In order to use the job costing tool in Rent Manager, Enable job costing must be checked in system preferences. For more information, refer to General Options (System Preferences).

Related Privileges

Group Privilege Column
Accounting Jobs View

For more information, refer to Control User Access.

To view the job's entire record of history/notes, go to arrow_forward Accounting arrow_forward General arrow_forward Jobs and select a job from the list. Then, on the action bar to the right, click arrow_forward History/Notes.

Filter Options

The available filter options are listed below. Depending on the size of your browser window, these filters may display at the top of the page or you may need to click to view the filter options.

Option Description

Search

You can type in the Search field to narrow the list to match your search criteria.

Filter By Date

Select or enter the From and/or To dates to filter notes created during the selected dates. Click to select a specific date range.

Users

Click the drop-down list and select the desired user(s) or user role(s) to filter for items created by one or more Rent Manager users.

History Category

Click the drop-down list and select the desired categories to include. To include history/note items with no category, select Unassigned.

Type

Click the drop-down list and select the desired types of history/note items.

Only Notes with Attachments

Check to display only history/note items that have a file attached, such as a PDF document or an image.

Column Descriptions

The following columns are available on this page.

Column Description

Pin

If the history/note item has Pin enabled, displays. If there are no pinned items, the column does not display.

Type

The system-generated history/note type. For example, if the history/note item was created by sending an email, the Email type displays.

Date

The date and time the history/note item was created.

Note

The information to describe the history/note item (e.g., Inspection completed. Ready to complete final stage.). If no text is entered, the column displays blank.

If an attachment is uploaded to the history/note item, displays. Click to download the attachment or open it in a new tab.

Category

The category of the history/note item selected from the available history categories. If no category is selected, the column displays blank.

User

The user who created the history/note item. If this is a system-generated history/note item, the user displays as Administrator.
