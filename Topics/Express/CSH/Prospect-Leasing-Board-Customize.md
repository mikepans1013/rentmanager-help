# Customize Prospect Leasing Board (Pop-Up)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Prospect-Leasing-Board-Customize.htm

The Prospect Leasing Board allows you to easily visualize where each of your prospects stand in their leasing journey, organized by your existing prospect stages. Rent Manager allows you to customize each of your prospect leasing boards to meet the needs of your unique leasing process. With the ability to add multiple columns to represent prospect stages, and edit what each prospect card looks like, your leasing board can look exactly the way you need it to.

 To customize a prospect leasing board, go to arrow_forward Rental Info arrow_forward Leasing arrow_forward Prospect Leasing Board and select the leasing board you wish to make changes to by clicking . Then, at the top of the page, click Customize .

 The Customize Board pop-up consists of two sections that contain information about where in the leasing process the prospect is. From this pop-up, Rent Manager allows you to customize each prospect stage and the related prospect cards into individual columns. Each prospect leasing board can be created to track the leasing process at individual properties. The Show Account # on Prospect Card option can be selected to display each prospect's system-generated account number on their card in the leasing board.

 Columns

 Prospect stages can be organized into columns that you see when viewing the Prospect Leasing Board page. Each column you add can contain the prospect stage(s) that apply to the name of the column. For example, if a column should contain prospect cards for prospects that have shown interest, but have yet to begin the application phase, the column can be named Pending and include the prospect stages called Guest Card and Property Tour .

 To add a new column to your leasing board, click Add Column . To change the order of the columns for how they display from leftmost and the bottom rightmost on the board, click and drag .

 Card Settings

 Each leasing board column can be customized with specific prospect cards. Each prospect card can contain up to seven fields that can be arranged to display in order you wish. To change the order of the fields on the prospect card, click and drag .

 The following fields can be used to customize the prospect card.

 Field
 Description

 Application Date

 The date the prospect's application was received.

 Application Status

 The current status of the prospect's application ( In Progress , Completed , or Canceled ).

 Agent

 The name of the prospect's Leasing Agent as displayed on the prospect's details page on the Lead Information tile.

 Balance Due

 The prospect's unpaid balance as of today's date as displayed on the prospect's details page.

 Expected Move in Date

 The date on which the prospect is expected to move into the unit.

 Interest Level

 The prospect's interest level ( 0 through 10 , with 10 being highest) in your property.

 Last Contact

 The date on which the prospect was last reached out to by your company.

 Lead Source

 The main source of information that describes how this prospect learned about your company.

 Lease Start

 The date on which the lease is expected to begin as displayed on the prospect's details page.

 Market Rent

 The market rent of the unit associated with prospect as established on the unit's details page.

 Next Contact

 The next date on which your company is scheduled to reach out to the prospect as established on the Prospect Stage Details pop-up.

 Original Contact

 The date on which the prospect was first contacted by your company and the method used for that communication (such as by email or phone call). If the prospect's original contact comes from a guest card/ Apply Now , the type is Web . If the prospect original contact comes from Apply Now , the type is Application .

 Preferred Move in Date

 The date on which the prospect wishes to move into the unit.

 Rent Quote Amount

 The rent amount for the prospect's reserved rent quote as displayed on the prospect's details page on the Rent Quotes tile.

 Rent Quote Expiration

 The date on which the rent quote is set to expire and no longer be valid. If there is not an expiration date, this field is blank.

 Rent Quote Status

 The status ( Reserved , Expired , or Active ) of the rent quote, which can help property managers keep track of quotes that have been offered, expired, or accepted.

 Screening Status

 The prospect's screening Status as displayed on the prospect's details page on the Screening tile.

 Stage

 The prospect's current stage and the date they were moved to that stage.

 User Defined Fields

 Each prospect-type user-defined field (UDF) created displays to select from. To create a new UDF, click Add User Defined Field .

 Card Actions

 Once a prospect card is added to the leasing board, multiple actions can be taken to progress the prospect through each stage directly from the Prospect Leasing Board page. To help keep your leasing process as efficient as possible, you can edit the actions a user can take with each prospect card.

 Action
 Description

 Add

 Which add actions ( Add Appointment and Add Charge ) can be taken from the prospect leasing board. These actions allow you to add an appointment to link to the prospect's account and add a one-time charge to the prospect's account.

 Add Rent Quote

 Offer the tenant a price for the units they are interested in.

 Add to History

 Add a history/note type of Call , Email , Note , or Visit to the prospect's details page on the History/Notes tile.

 Add to Waitlist

 Add the prospect to a unit's wait list.

 Assign to Agent

 Assign a user to act as the prospect's leasing agent.

 Blue Moon

 Which Blue Moon actions ( Blue Moon : Create Lease , Blue Moon : Create Other Lease Forms , Blue Moon : View eSignatures , and Blue Moon : Complete Document ) can be taken from the prospect leasing board.

 Change Status

 Change the current status of the prospect. For example, if the prospect was rejected during the screening process, their New Status is Lost/Rejected .

 Communication

 Which communication actions ( Send Email , Write Letters , Send Text , Add to Phone Broadcast , and Add to Text Broadcast ) can be taken from the prospect leasing board.

 Documents

 Which document actions ( Create Document Packet , Publish Signable Documents , View Signable Documents , and Complete Document ) can be taken from the prospect leasing board.

 Income Verification

 Which income verification actions ( Run Income Verification , View Income Verification , and Write Income Verification Adverse Action Letters ) can be taken from the prospect leasing board.

 Move In

 Move the prospect in to the property in Rent Manager via the Move In pop-up.

 Move Stage

 Move the prospect to a different stage on the leasing board.

 Reserve Unit

 Reserve a unit, preventing it from displaying as available to be reserved or leased to other prospects or tenants, for the prospect.

 Screening

 Which screening actions ( Run Screening , View Screening , Write Screening Adverse Action Letters , and Override Screening Action ) can be taken from the prospect leasing board.

 Send Application

 Send an application to the prospect.

 View Application

 View an application from the prospect.

 View History

 View a history/note type of Call , Email , Note , or Visit to the prospect's details page on the History/Notes tile.
