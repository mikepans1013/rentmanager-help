# Unit Details (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Units-Details.htm

In Rent Manager , units are the individual spaces you rent to tenants. You can create units for any type of space you rent, such as commercial spaces, single-family homes, apartments, manufactured homes, RV lots, and storage units.

 Units
 View, Edit

 For more information, refer to Control User Access .

 On a unit's details page, you can view and update information about a single unit. To view a unit's detail page, go to arrow_forward Rental Info arrow_forward General arrow_forward Units and select a unit from the list.

 The following tiles display by default. If a custom layout is applied to your details page, you might not see all of the following tiles. For more information about creating and assigning layouts, refer to My Layouts (Page) and System Layouts (Page) .

 Addresses

 The addresses associated with this unit, including any custom address types.

 Amenities

 Amenities that are assigned to this unit display in this tile.

 Assets

 Any active assets linked to the unit, including the date range in which the asset is used at that unit. Assets can be linked to a unit from the General tile of the asset's details page.

 If, on the Asset pop-up, the Show History option is checked, this tile displays all assets that have been linked to this unit in the past. To access the pop-up from this tile, click in the upper right.

 Field
 Description

 Name

 A unique identifier for the asset.

 Type

 The category that best classifies the type of asset.

 From Date

 The date that the asset was moved to the specified unit.

 To Date

 The date that the asset was or is to be removed from the specified unit.

 Last Maintenance

 The last date maintenance was performed on the asset.

 Next Maintenance

 The next date maintenance needs to be performed on the asset.

 Current Market Rent

 The estimated value of the unit in relation to similar rental units in that area.

 Default Security Deposits

 The default amount for security deposits that tenants pay when they move into this unit, as well as the default charge type used to record security deposit payments from tenants. Default security deposit charge types are set in system preferences, but can be overridden for individual units.

 General

 Information about the unit and its basic attributes.

 Field
 Description

 Display Color

 A color to help identify units of certain types, groups, or any other specifications you prefer. The color displays as a bar to the left of the unit in some areas of Rent Manager , such as the Units page.

 Floor

 The floor of the building where the unit is located.

 Name

 The name that identifies the specific unit. Names usually correspond to the unit number or address of the actual rental.

 Site Classification

 The current site classification for a unit. To view a history of site classifications for the unit, click History . This field displays only if the unit is associated with a property that has a Property Type of Manufactured Housing .

 Unit Type

 The custom category that best represents this unit.

 History/Notes

 The most recent history/note items on the unit's account. History/notes record information about actions taken in relation to this unit, such as maintenance and tenant occupancy history. Rent Manager creates notes for system actions, such as the initial unit setup or service requests. You can also add additional notes from the tile.

 Field
 Description

 Date

 The date the history/note was created.

 Type

 The category the history/note falls into (e.g., Service Issue , Email , Call , Visit , etc.)

 Note

 Information about the history/note describing the event, interaction, or message.

 Images

 Add, view, and delete images of the unit.

 Miscellaneous

 Additional information about the unit's attributes. Information in the Miscellaneous tile contributes to marketing and GPR reports, as well as pro rata share calculations for commercial properties. From this tile, you can also link a move-out inspection template to this unit.

 Field
 Description

 Bedrooms

 The number of bedrooms in the unit.

 Bathrooms

 The number of bathrooms in the unit.

 Max Occupancy

 The maximum number of tenants allowed in the unit.

 Square Footage

 The total square footage of the unit.

 Inspection Template

 The inspection template used for move-out inspections on this unit. For more information, refer to Inspection Templates (Page) .

 Occupancy

 Information about the unit's current tenant or the prospect who has reserved the unit. This information is pulled from a tenant's lease or a prospect's record.

 Recurring Charges

 The active recurring charges that post to the tenant occupying the unit at specified intervals. Tenants inherit recurring charges set at the unit level, which allows you to set unit-specific charges such as upcharges for a fireplace or a lake view. You can add new recurring charges, including CRE charges, from this tile.

 Field
 Description

 Charge Type

 The charge type to be associated with this recurring charge.

 Comment

 A phrase or note to show on the View Recurring Charges page.

 Frequency

 The number of months, weeks, or days that should elapse between each posting of the recurring charge. For example, if on the tenant's details page, a tenant has a Monthly rent period, a frequency of 1 means the recurring charge posts once every month, and a frequency of 3 means the recurring charge posts once every three months.

 From Date

 The first date on which this recurring charge is applied to the tenant's account when recurring charges are posted.

 To Date

 The final date on which this recurring charge can be posted to the tenant's account. After this date, this recurring charge is no longer applied to the account when recurring charges are posted.

 Amount

 The amount of the corresponding charge type that posts to the tenant's account.

 RV/Campground Information

 Information about the size and amenities of the campground or RV space. This tile displays only if the unit is linked to a property with the RV/Campground property type. Information from this tile can be used to filter for available units when making reservations.

 Field
 Description

 Length

 The length of the rentable space.

 Width

 The width of the rentable space.

 Amps

 The amperage of the electrical hookup available for this space.

 Prohibited Eqpt.

 Any vehicle or equipment that is not permitted at this unit. Guests with vehicles or equipment of the selected types are unable to reserve this space on the STR Online Booking portal.

 Slide Outs

 The type(s) of room extenders on the guest's RV allowed at the site.

 Pull-Through

 Indicates if a space allows pull-through parking.

 UDFs

 User-defined fields display on this tile based on when a value was added to the UDF. The order in which the user-defined fields display may not match the order that displays in the User Defined Fields pop-up or on the User Defined Fields page. This tile displays up to six unit-type UDFs with values and used to track information that Rent Manager does not track by default.

 Unit Status

 Any current statuses affecting the unit. Unit status determines if a tenant can be moved into the unit or a prospect can reserve the unit in Rent Manager . It also determines whether the unit counts as vacant for certain reports.

 If the unit is linked to an active workflow, this tile displays each stage of that workflow process and the number of steps that are completed for each stage. Additionally, you can view each step and its assigned user by clicking to display the Workflow Project Overview .
