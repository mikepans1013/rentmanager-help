Asset Depreciation Schedules (Pop-Up)

Businesses that expense the cost of assets purchased must track the depreciation of these assets over time. Depreciation is the consistent reduction in the value of an asset and the allocation of the asset's cost over a period of time. With Rent Manager, you can create depreciation schedules that track this decline in value and create journal entries to record the changes. While multiple depreciation schedules can be created for a single asset, only one schedule can be active at a time.

More Information

Before you can create a depreciation schedule, on the asset's details page, the Track Financials option must be enabled, and a financial Property must be selected.

Related Privileges

Group Privilege Column
Asset Management Manage Assets View, Edit

For more information, refer to Control User Access.

To view an asset depreciation schedule, go to  arrow_forward Rental Info arrow_forward General arrow_forward Assets and select an asset from the list. Then, on the action bar to the right, click arrow_forward Depreciation History.

Column Descriptions

The following columns display on the page.

Column Description

Accumulated Depreciation

The total amount of depreciation accumulated as of the end of the period.

Beginning Value

The book value of the asset at the beginning of the period.

Date

The date on which depreciation for the period was posted.

Depreciation Expense

The total amount of depreciation accumulated for the period.

Ending Value

The new book value of the asset after depreciation is posted for the period.

Journal

The reference number of the journal entry posted for the period.
