Virtual Post Office (VPO) (Page)

Virtual Post Office (VPO) allows you to outsource the expensive and time-consuming process of printing, packaging, stamping, and mailing through the US postal system. Any letter-sized statement, invoice, report, or letter under 300 MB can be submitted to the Virtual Post Office for automatic fulfillment and delivery. Rent Manager tracks submissions sent to the Virtual Post Office in the VPO Register, displaying details about the submitted VPO jobs.

Related Privileges

Filter Information

The following filtering options are available on this page.

Filters Descriptions

Search

Enter the desired search criteria to display results that match the search criteria.

Filter by VPO Date

Set the From and To dates for which the filter should examine, or click to select a date from the calendar By default, the beginning date is three months before the current date.

Alternatively, click to open more options for setting a date range.

Show Canceled

Includes VPO jobs that were canceled.

Column Descriptions

The following columns display on the page.

Column Description

Job ID

The system-generated ID associated with the VPO job.

Create Date

The date the VPO job was created.

Fee

The total fee that was charged to your account for the VPO job. A running total of the Total Fee for VPO jobs is displayed at the bottom of the page.

Status

The current state of the VPO job. Each status is described below.

New

The submission was received by LCS.

PreProcessed

The VPO bar codes were added to the pages of your submission and are ready to be printed.

Sent For Fulfillment

The submission was sent to our printing partner.

Canceled

The submission was canceled by a Rent Manager user.

Error

There was a problem with the submission.

User Name

The name of the user who created the VPO job.

Row Actions

The following row actions are available from the menu.

Option Description

Details

View further information about the VPO job.

Cancel Job

Removes the VPO job from the page so it does not progress any further. Only jobs with a status of New or PreProcessed can be canceled.

Download Document

Saves a copy of the VPO job to your local PC.
