# Vendor Contacts (Pop-Up)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Vendor-Contacts.htm

Vendor contacts allow you to view and manage information about the people associated with the vendor, such as a sales representative or a contractor.

 For more information, refer to Control User Access .

 To view a vendor's contacts, go to arrow_forward Payables arrow_forward General arrow_forward Vendors and select a vendor. Then, on the Contacts tile, click .

 The email that displays beneath the contact's name can be found in the Email Address field. The phone number selected as Default displays also displays.

 If the Primary field is checked, the contact is considered the primary person your property management company communicates with. One contact must be designated as Primary on each vendor's account. When you add a vendor, the first contact on the account is always the vendor.

 Personal Information

 This section displays basic information about the contact.

 Field
 Description

 Email

 The contact's primary email address. To view or update the contact's preferences regarding emails from Rent Manager , click Manage Subscriptions . For more information, refer to Unsubscribe From Emails .

 Name

 The contact's full name.

 Type

 The user-created contact type that best describes the contact (e.g., Manager ).

 Phone Numbers

 This section tracks the contact numbers for the contact organized by phone number types. The number used as the primary contact for this account is marked as Default . Additionally, if a phone number can be used for text messaging, it is marked in the T column.
