# Property Files (Pop-Up)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Property-Files.htm

Rent Manager allows you to upload relevant documents and files for a property and, optionally, make any of those files available via Tenant Web Access (TWA) . You can upload images, Rent Manager documents, PDFs, and word processor documents and organize these files into folders.

 To view the Property Files pop-up, go to arrow_forward Rental Info arrow_forward General arrow_forward Properties and select a property from the list. Then on the Property Files tile, click .

 All folders are available in the Home section on the left.

 Columns Descriptions

 The following columns displays on this pop-up.

 Column
 Description

 Name

 For folders, the Name entered when the folder was created or last modified. For files, the File Name entered when the file was uploaded or edited in the property files.

 Description

 Additional information about the file within the folder.

 Show in TWA

 A displays if this property file or folder is available for tenants to view and download in Tenant Web Access (TWA) .

 Board Only

 A displays if this property file or folder is available only for tenants who are established as association board members at the property.

 This option is available only if the property has a Property Type of Association .
