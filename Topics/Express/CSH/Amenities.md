# Amenities (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Amenities.htm

This page lets you track amenities—features or conveniences such as fireplaces, patios, pools, etc. Once you have entered amenities into the database, you can assign them to rental units. This makes it easier to find units with amenities that match the features desired by tenants and prospects.

 Column Descriptions

 The following columns display on the page.

 Column
 Description

 Name

 The name that displays on the units that you can link the amenity to.

 Comment

 An optional comment that provides additional details about the amenity.
