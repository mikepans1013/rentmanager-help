# Checklist Templates (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Issues-Checklist-Templates.htm

Checklist templates are saved lists of to-do items that you can use to easily populate the Checklist section of issues in Rent Manager . Checklist templates are helpful for tasks that always require the same steps to complete, such as changing furnace filters or replacing smoke detectors.

 Column Descriptions

 The following columns are available on this page:

 Column
 Description

 Name

 The unique name used to identify the checklist template.

 Active

 A displays if the template is active. Templates without a display only when the filtering option Show Inactive is checked.

 Item Count

 The number of checklist items or steps in the template.

 Create Date

 The date that the template was created in Rent Manager .

 Created By

 The name of the user who created the template.

 Update Date

 The date that the template was most recently modified.

 Updated By

 The name of the user who most recently modified the template.
