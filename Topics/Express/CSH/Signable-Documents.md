# Signable Documents (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Signable-Documents.htm

Signable documents are personalized forms delivered electronically to tenants, prospects, owners, or owner prospects for their signature. They are generated from signable templates, which are imported PDF documents or letter templates that include signable fields.

 After these documents are sent to selected recipients, they are listed on the Signable Document Packets page where you can view the recipients' progress in signing the document. This page allows you to publish signable documents and view them.

 Column Descriptions

 The following columns are available on this page. By default, some columns display only if added via .

 Column
 Description

 Packet Name

 The name of the template or document packet that makes up the signable document (e.g, Lease Renewal Request ).

 Account

 The system-generated ID associated with the recipient's tenant/prospect account in Rent Manager . For owner- and owner prospect-type documents, this column is blank.

 Name

 The primary recipient's name.

 Status

 The current status of the document.

 Published

 The document was sent to the recipient(s) to be signed.

 Pending Acceptance

 The recipient(s) signed the packet. The packet is waiting to be completed by a Rent Manager user.

 Completed

 Documents that were signed by recipients and, if applicable, the landlord or company representative. Then, once reviewed, the document was marked as a Complete Packet .

 Voided

 The published document was retracted.

 Signed

 The current number of signatures the document has (e.g., 1 of 2 displays when one of the two required signers signed the document).

 Published By

 The full name of the user that published the document to the recipient(s).

 Available Column

 Description

 Date Completed

 The date that the sign document process was done.

 Document Name

 The document or packet's name that displays in the signable document details page Document Name section.

 Expiration Date

 The date this document is set to expire and become unavailable to sign.

 Last Signature Date

 If there is only one signer, the date the document was signed. For multiple signers, the most recent date that one of the recipients signed the document.

 Leasing Agent

 For a tenant or prospect document, this displays the Leasing Agent selected on the prospect or tenant's details page.

 For owner or owner prospect document types, this column is blank.

 Property

 The name of the property associated with the primary recipient.

 For owner or owner prospect document types, this column is blank.

 Property Manager

 For a tenant or prospect document, this displays the Property Manager selected on the prospect or tenant's details page.

 For owner or owner prospect document types, this column is blank.

 Property Short Name

 The abbreviated short name of the property associated with the primary recipient.

 For owner or owner prospect document types, this column is blank.

 Published Date

 The date that the document was published.

 Recipient Message

 An external comment that the recipient can view in Tenant Web Access (TWA) when accessing the document.

 Signature Email Addresses

 The email addresses that were sent notification to sign the published document.

 Tenant Name

 The name of the primary recipient of the document. Owner, owner prospect, and prospect names also display in this column.

 Total Signers

 The number of recipients to which the packet was published.

 Unit

 The name of the unit associated with the primary recipient.

 For owner or owner prospect document types, this column is blank.

 Void Date

 The date that the void document process was done.
