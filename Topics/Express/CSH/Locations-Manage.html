Manage Locations (Pop-Up)

If you work with more than one property management company, you can use separate Rent Manager database locations to keep your data for each company separate. All financial and entity information is unique to each location and maintained independently, including the users that can access the location and their user privileges.

More Information

Locations are a licensed feature and must be purchased separately. For more information, contact your sales representative at sales@rentmanager.com.

More Information

If you use per unit Rent Manager licensing, each unit in each location uses one license.

For more information, refer to Assign Unit Licenses.

Related Privileges

Group Privilege Column
Locations Locations View

For more information, refer to Control User Access.

To manage your database locations, go to arrow_forward Administration, then go to Locations arrow_forward Manage Locations.

Row Actions

The following row actions are available from the menu:

Option Description

Edit

Related Privileges

Group Privilege Column
Locations Locations View, Edit

For more information, refer to Control User Access.

Edit the name of the location and add or remove user(s) that can access it.

Warning

If you remove a user's access to their default location, they are unable to log in to Rent Manager. On the user's details page in the Personal Information section, you can select a different Default Location for the user. For more information, refer to the Locations heading on the User Details (Page) page.
Delete

Related Privileges

Group Privilege Column
Locations Locations View, Delete

For more information, refer to Control User Access.

Deletes the entire location database. The system default location cannot be deleted.

Warning

Deleting a location is a permanent action and cannot be undone.

Switch To

Swap to a different location to view and manage the information in that database.

More Information

This option is available only when there are multiple locations in Rent Manager and your user account has access to more than one location on the User details page. For more information, refer to the Locations heading on the User Details (Page) page.
