Architectural Requests (Page)

If your property is an association, such as a homeowners association (HOA), the architectural requests tool in Rent Manager allows tenants (i.e., homeowners) at that property to ask the association if they are allowed to make external changes to their home (i.e., unit) such as planting trees, adding gardens, or repainting the building a specific color. You can use the Architectural Requests page to manually enter requests or take action on incoming architectural requests from Tenant Web Access (TWA)TWA.

Related Preferences

If you have the TWA portal, the association's committee and/or board members can use TWA to vote on whether or not to approve these requests, and requests can be approved or denied in Rent Manager. For more information, refer to Tenant Web Access Architectural Requests Page Setup (System Web Preferences).

In addition, you can attach custom request forms to manually added architectural requests. These custom forms are created so that each form corresponds with a specific request or is unique per property. This allows you to account for the specific nuances of various requests.

Related Privileges

Associations Manage Architectural Requests Enabled

For more information, refer to Control User Access.

Filter Options

The following filtering options are available on this page.

Option Description

Search

Type in the Search field to narrow the list to match your search criteria.

Status

Filter the requests in the register based on where the request is in the approval process. By default, requests with a Status of Pending display.

The following statuses are available to filter the page.

Pending

No action has been taken on this request.

More Information Needed

The person who submitted the request needs to provide additional information in order for the management company to make a decision.

Approved

The request was accepted.

Denied

The request was declined.

Canceled

The request was manually canceled by a user, such as the request being withdrawn.

In Board Review

The request is ready for discussion and the association is working toward making a decision.

Property

The property whose requests should display.

More Information

Only properties with a Property Type of Association, as entered on the property's details page, display in the list.

(Unread Messages)

Only information related to the properties to which you have access displays. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property.

Request

The subject of the request.

Create Date

The date on which the request was submitted.

Status

The current status of this request (Pending, More Information Needed, Approved, Denied, Canceled, or In Board Review).

Vote Count

The number of votes made on the request versus the total number of board and/or committee members eligible to cast a vote on the request (e.g., 5/6).
