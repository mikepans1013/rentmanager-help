Prospect Interested Properties/Units (Pop-Up)

A prospect's Interested Properties/Units pop-up can be used to view and manage the units that are potential matches for the prospect or units in which the prospect has expressed interest in leasing.

Related Privileges

Group Privilege Column
Tenants/Prospects Prospects View, Edit

For more information, refer to Control User Access.

To access the Interested Properties/Units pop-up, go to arrow_forward Rental Info arrow_forward General arrow_forward Prospects and select a prospect from the list. On the Interested Properties/Units tile, click .

Filter Options

The following filters are available on this pop-up:

Option Description

Properties

Select a property to display only units from that property. This field automatically populates with the prospect's default property.

Show interested only

Check to include only units the prospect is interested in leasing.

Show wait list only

Check to include only units for which the prospect was added to a wait list.

Column Descriptions

The following columns are available on this pop-up:

Column Description

Interested

Indicates the prospect is interested in leasing the unit but has not made a decision yet.

More Information

This information is available only on a prospect's details page by default, but it can be retrieved for Report Writer reports and letter templates using the InterestedUnits function. For more information, refer to Prospect Class (Script).

Next Move Out

The move-out date for the next occupant of the unit.

Next Occupant

The name of the next occupant of the unit.

Property

The name of the property associated with the unit.

Unit

The Name of the unit as displayed on the unit details page's General tile.

Status

The occupancy information for the unit (e.g., 2 Tenants, 1 Future Tenant, Vacant, Available).

Unit Type

The unit's Unit Type as displayed on the unit details page General tile.

Wait List

Indicates that the prospect was added to the unit's waiting list. This includes the prospect on the Prospect Waiting List report, which can be utilized to keep track of waiting lists and ensure that you are contacting the correct prospects when a unit becomes available. For more information, refer to Prospect Waiting List (Report).

If a prospect wants to lease a unit that is not currently available, you can add the prospect to the waiting list until the unit is available to be reserved. For more information, refer to Reserve a Unit for a Prospect.

More Information

Checking the Wait List column also automatically selects the Interested column. If the prospect does not want to be added to the waiting list, select Interested.
