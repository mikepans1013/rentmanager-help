# Asset Statuses (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Asset-Statuses.htm

Asset statuses are conditions that you create to describe the state of the asset (e.g., Inventory , In Use , Out for Repair , Out of Service ). Creating asset statuses and then assigning a status to an asset as part of asset management can help provide more information about the asset and allow you to filter your asset list by status. The statuses you create are able to be selected when you are updating the asset status history.

 The following columns are available on this page.

 The name of the asset status (e.g., In Service , Out For Maintenance , Other , and so on).

 Description

 A brief description of the asset status to help identify when to use a status (e.g., Asset currently out for repair ).
