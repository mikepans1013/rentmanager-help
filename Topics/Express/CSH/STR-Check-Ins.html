STR Check-Ins (Page)

The Check-ins page allows you to manage short term rental guest reservations at a selected property. This page is particularly valuable because it allows you to see all the guests arriving at your property on the current day. Then, you can easily check in each guest as they arrive.

Related Privileges

Group Privilege Column
Properties/Units Properties View

For more information, refer to Control User Access.

Warning

To access the STR tool, at least one of your properties in Rent Manager must have the Short Term Rental or RV/Campground property type assigned.

To view checks ins by arrival day, go to arrow_forward Rental Info arrow_forward Short Term Rentals arrow_forward Check-ins.

Column Descriptions

The following columns are available on this page.

Column Description

Unit

The name of the unit associated with the guest's reservation.

Tenant

The guest's first and last name.

Phone

The guest's phone number.

Email Address

The guest's email address.

Arrival

The first date of the guest's reservation.

Departure

The final date of the guest's reservation. Rent Manager automatically ends the rental on the specified departure date.

Checked In

The date in which the guest was checked in. Guests who are already checked in display only if Show Checked-In is enabled.

# Nights

The calculated number of nights between the Arrival date and the Departure date. If no Departure date is entered, this value displays 0.

Request

Any additional information about the reservation.
