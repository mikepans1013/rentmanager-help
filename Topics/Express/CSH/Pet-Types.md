# Pet Types (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Pet-Types.htm

In Rent Manager , you can track the pets owned by your tenants and prospects to make the process of charging pet fees and pet deposits easier. Before you can begin tracking pets, you must first create pet types to classify the different species of animals that are allowed to be kept by tenants as pets.

 For example, if your properties allow tenants to keep dogs and cats, you could create one pet type for dogs and another for cats so that all pets tracked in Rent Manager are grouped under one of those categories.

 Related Preferences

 Pet types can also be used to track recurring or one-time charge amounts as well as deposit amounts associated with owning each type of pet. The charge types used for each pet-related charge are configured in the Tenant Charge Setup system preferences. For more information, refer to Tenant Charge Setup (System Preferences) .

 Column Descriptions

 Columns on the Pet Types page display the following information:

 Column
 Description

 Name

 The name of the pet type (e.g., Dog , Big Dog , Cat , Reptile , and so on).

 Description

 An optional message for this pet type (e.g., weight limit 75 lbs ).

 Recurring Amount

 The dollar amount of the recurring pet fee.

 Max Recurring Amount

 The dollar amount cap on the amount that can be charged to a tenant each month for owning multiple pets of this type.

 One Time Fee

 The dollar amount of the one time fee for the pet type.

 Max One Time Fee

 The dollar amount cap on the amount that can be charged to a tenant for owning multiple pets of this type.

 Pet Deposit

 The dollar amount of the pet deposit.

 Max Pet Deposit

 The dollar amount cap on the amount that can be charged to a tenant for owning multiple pets of this type.
