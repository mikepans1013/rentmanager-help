Manage Bird's Eye View (BEV) Maps (Page)

Bird's eye view (BEV) maps allows you to create a visual representation of your properties, providing a high-level overview of a property as well as detailed information for each unit within a property. Rent Manager Express utilizes using pins to build out your maps which removes the need to draw out each unit, like you do when creating maps with shapes, streamlining the map creation process. The Manage BEV Maps page lists out the available maps to view and can be assigned to users, edited, and exported directly from the page.

Related Privileges

Group Privilege Column
Bird's Eye View (BEV) BEV Maps View

For more information, refer to Control User Access.

To view bird's eye view maps, go to arrow_forward Rental Info arrow_forward Bird's Eye View (BEV) arrow_forward Manage BEV Maps.

To only view BEV maps that you are selected as a User on, check Show only maps assigned to me.

Column Descriptions

The following columns display on this page.

Column Description

Description

Details to describe what the map is for or any additional comments about the map.

Map Type

The type, Shape or Pin, which is how units are defined on the bird's eye view map.

Map Views

The name of map view(s) associated with the bird's eye view map.

Name

The name of the bird's eye view map.

Property

The property associated with the map.

User

The names of the users with access to the map.
