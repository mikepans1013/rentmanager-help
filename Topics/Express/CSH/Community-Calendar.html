Community Calendar (Page)

The Community Calendar in Rent Manager displays scheduled reservable amenities and community-wide events in a single location, giving you an overview of what facilities at the property are in use and a schedule of upcoming events. Events and reservations for amenities can be added directly from the calendar, and if there are many items on the calendar, you can filter what should display. If you'd like to allow your tenants to reserve amenities via the Community Calendar, reservable amenities must first be established for a property before reservations can be taken.

Related Preferences

In order for the Community Calendar page to display in Tenant Web Access, the Show Community Calendar option must be enabled system web preferences. For more information, refer to Tenant Web Access Community Calendar Page Setup (System Web Preferences).

Related Privileges

Group Privilege Column
Setup Manage Community Events Enabled

For more information, refer to Control User Access.

To view the Community Calendar, go to arrow_forward Services arrow_forward Community arrow_forward Community Calendars.

More Information

Only information related to the properties to which you have access displays. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property.

More Information

The appearance of the community calendar may change depending on your preferences, but this does not affect how tenants see the calendar in Tenant Web Access. For more information, refer to Calendar Options (Personal Preferences).

Filter Descriptions

The following filters are available on this page.

Filters Descriptions

Calendar

Select the month and year, (and optionally, date) you wish to view from the calendar. The selected month and year display at the top.

Use and to navigate through the months and years. Alternatively, click the name of the month to select a specific month from a list, or click the year to jump to a specific year.

Property

The selected property's events and reservation requests display on the calendar.

Reservation Requests

The reservable amenity request(s) you wish to display on the calendar. For more information, refer to Add a Reservable Amenity.

Community Events

The property-wide event type(s) you wish to display on the calendar. For more information, refer to Community Calendar Event Types (Page).
