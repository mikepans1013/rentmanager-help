# Saved Issue Lists (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Issues-Saved-Lists.htm

Saved issue lists are part of Service Manager that allow you to open a filtered Issues page to display only issues that meet certain criteria. These lists are available at the top of the Issues page, allowing you to quickly jump between them. You can enable notifications for a list, which alerts you when the issues in that list are updated or a new issue is added.

 Column Descriptions

 The following columns are available on this page. Columns can be added or removed from this page by clicking .

 Column
 Description

 Name

 The name of the saved issue list.

 Refresh (min)

 How often, in minutes, the saved issue list is updated with new issues in Rent Manager 12 . The minimum refresh time for saved issue lists is 5 minutes.

 More Information

 This refresh time applies to the list that is actively open and selected on the Issues page. Lists that are open but not actively selected on the Issues page refresh every fifteen minutes, or after the list's set Refresh (min) value is greater than 15 .

 Load On Start

 A displays if Load on Start is checked for this list on the Saved Lists window in Rent Manager 12 .

 Notify

 A displays if Notify is checked for this list on the Saved Lists window in Rent Manager 12 .
