# View Unit Status (Pop-Up)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Units-View-Status.htm

Unit statuses are exceptions to the standard status of occupied or vacant. On the View Unit Status pop-up, you can assign a unit status to a unit to define whether it is currently vacant and/or available based on your unit status types. Unit status plays a key role in determining whether Rent Manager allows tenants to move into the unit or prospects to reserve the unit. It also determines whether the unit counts as vacant for reports, such as the Rental Unit Listing report.

 Warning

 If you use per unit Rent Manager licensing, keep in mind that deactivating a unit does not remove its license. You can unassign licenses on the Assign Unit Licenses page.

 For more information, refer to Assign Unit Licenses .

 Column Descriptions

 The following columns are available on this pop-up:

 Column
 Description

 Start Date

 The date that the status takes effect.

 End Date

 The date that the status expires.

 Type

 The associated unit status type (e.g., Make Ready , Inactive ). The selected unit status determines whether the unit displays as available, vacant, or neither during the date range, based on the options selected for that unit status.

 Comment

 An optional note about the status, such as why it was added or when it can be removed.
