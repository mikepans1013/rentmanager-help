# Rent Manager Sessions (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Rent-Manager-Sessions.htm

Accessing Rent Manager with a per-user license requires one license per session (active login). Each user who logs into Rent Manager 12 or Rent Manager Express fills one of the available sessions you have purchased, and once all sessions are in use, no more users are able to log in until a user logs out or is disconnected. This page is used to see what users are currently logged into Rent Manager and to clear up old or unused sessions to allow other users to access Rent Manager .

 More Information

 If you use per-unit Rent Manager licensing, you have an unlimited number of available sessions.

 Filter Options

 The following filter options are available on this page.

 Option
 Descriptions

 Search

 Enter search criteria to display active users with a matching Full Name or User Name .

 Only show users with multiple sessions

 If checked, only users logged into more than one Rent Manager Express and/or Rent Manager 12 session display.

 Column Descriptions

 The following columns are available on this page.

 Column
 Description

 Full Name

 The first and last name of the user as entered on their user's details page.

 User Name

 The Username entered on the user's details page.

 Duration

 The length of time the user has been logged in to the session in HH:MM format.

 Last Activity

 The number of minutes since the user was last active in a Rent Manager Express session. For Rent Manager 12 sessions, this column is blank.

 Product

 Indicates whether the user is logged into Rent Manager Express or Rent Manager 12 .

 Location

 The database location the user is accessing in the session.

 Server User Name

 The Rent Manager 12 server seat the user is logged in with. For Rent Manager Express sessions, this column is blank.
