Job Transactions (Pop-Up)

The job costing feature of Rent Manager makes it possible to track transactions associated with specific jobs completed by your business. The job Transactions pop-up allows you to examine and quickly navigate to transactions that are associated with a job.

Related Privileges

Group Privilege Column
Accounting Jobs View

For more information, refer to Control User Access.

To view a job's transactions, go to arrow_forward Accounting arrow_forward General arrow_forward Jobs and select a job from the list. Then, on the action bar to the right, click arrow_forward Transactions.

Column Descriptions

The following columns display on the page.

Column Description

Type

The type of the transaction, such as Bill or Check.

Date

The date on which the transaction took place.

Reference

If applicable, the system-generated or custom number that identifies the transaction, such as the check number.

Information

A system-generated note that provides further context about the transaction, such as the number of the checks that paid a bill.

Memo

An optional note entered in the corresponding transaction.

Amount

The total dollar amount of the transaction.
