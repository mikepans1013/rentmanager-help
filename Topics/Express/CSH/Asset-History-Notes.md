# Asset History/Notes (Pop-Up)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Asset-History-Notes.htm

History/notes allow you to record information that supplements or clarifies what’s entered in other fields, such as notes about phone conversations, items on a to-do list, and explanations about transactions. While some history/note items are automatically created by Rent Manager , you are also able to record information based on your needs. This makes it easier to track events related to each asset and provide additional details for internal reference.

 Filter Options

 The following filter options are available on the page. Depending on the size of your browser window, these filters may display at the top of the page, or you may need to click to view the filter options.

 Option
 Description

 Search

 Type in the Search field to narrow the list to match your search criteria.

 Filter By Date

 Select or enter the From and/or To dates to filter notes created during the selected dates. Click to select a specific date range.

 Users

 Select user(s) to filter for items created by one or more users.

 History Category

 Select which categories of history/note items to include. To include history/notes with no category, select Unassigned .

 Type

 Select which types of history/note items to display.

 Only Notes with Attachments

 Check to display only history/note items that have an attachment.

 Maintenance

 Select to display history/note items with the following maintenance record statuses:

 All

 History/note items with both open and closed maintenance records display.

 Open

 Only history/note items with open maintenance records display.

 Closed

 Only history/note items with closed maintenance records display.

 Column Descriptions

 The following columns are available on this page.

 Column
 Description

 Pin

 If the history/note item has Pin enabled, displays. If there are no pinned items, the column does not display.

 Type

 The system-generated history/note type. For example, if the history/note item is linked to a maintenance record, the Maintenance type displays.

 Date

 The date and time the history/note item was created.

 Note

 The text entered in the Note field of the history/note item. If no text is entered, the column displays blank.

 If an attachment is uploaded to the history/note item, displays. Click to download the attachment or open it in a new tab.

 Category

 The category of the history/note item selected from the available history categories. If no category is selected, the column displays blank.

 User

 The user who created the history/note item. If this is a system-generated item, the user displays as Administrator .
