Owner Prospect Guest Card Template Details (Pop-Up)

The guest card tool allows you to place a contact form on your website for owner prospects to request more information about your management services. When that form is completed, an account is automatically created for the individual in Rent Manager using the information entered on the guest card. In order to match that information to the correct fields on their account, guest card templates must be created.

Related Privileges

Group Privilege Column
Tenants/Prospects Guest Card Templates View, Edit

For more information, refer to Control User Access.

To view and manage owner prospect guest card templates, go to arrow_forward Administration, then go to Customization arrow_forward Guest Card Templates and select a template from the list.

General Information

This tile displays the unique name and the message displayed to the owner prospect when they submit their guest card.

Field Description

Name

The unique name for the guest card template (e.g., Potential Owner).

Submission Message

The message to display to the owner prospect after they have submitted their information via the guest card (e.g., Thank you! Your information has been submitted!). This field has a limit of 255 characters.

Require human verification (CAPTCHA) before Guest Card submission

Requires owner prospects to complete a CAPTCHA form to submit a guest card, which helps prevent spam.

Guest Card Fields

This tile displays the fields for owner prospects to complete, the corresponding Rent Manager field that their responses update, and whether a value is required before submission. The guest card field matched to Name is required and cannot be deleted.

Column Description

Label

The name that displays on the guest card on your website.

Help Text

The text that displays to provide the guest with more information about the answer they should submit (e.g., Enter all children and adults).

Match To

The Rent Manager field where the owner prospect's information is stored.

Is Required

The guest card field is required for owner prospects to submit a guest card.

Hidden Fields

This tile displays the fields that are automatically assigned to all owner prospect accounts created from guest cards and do not display on the guest card. For example, hidden fields can be used for tracking leasing agent information or the source (website, TV, referral, etc.) from which owner prospects found out about your property management company.

Column Description

System Field

The Rent Manager field automatically assigned to the owner prospect account when they submit a guest card.

Display Color

The color to display to the left of the account name on the Owner Prospects page. For more information, refer to Colors (Page).

Lead Source

The lead source that is applied to accounts created from guest cards.

Leasing Agent

The name of a user who is designated as the owner prospect's leasing agent. For a user to display in this list, their user account page must have Sales Rep/Leasing Agent selected.

User Defined Field

The owner prospect-level user-defined field (UDF) value updated from guest cards.

Value

The selection made for the associated System Field.
