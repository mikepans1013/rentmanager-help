rmVoIP Tenant Call Details (Page)

When you receive a phone call from a tenant through rmVoIP, Rent Manager attempts to locate a tenant account in your database with that phone number to immediately provide you with information about the caller. On the details page for calls, you can take several actions, such as creating a service issue or adding a history/note item with information provided from the call. It also allows you to greet the tenant by name and with information specific to them when you answer the call because their account details are linked to call.

More Information

This feature is licensed and must be purchased separately. For more information, contact your sales representative at sales@rentmanager.com.

To view a list of calls you received through rmVoIP, go to arrow_forward Communication arrow_forward Texting/Phone arrow_forward rmVoIP Incoming Calls and select a call from the list.

Account Information

The top of the page displays information about the linked account.

Field Description

Link Type

The entity type of the caller.

Date/Time

The date and time the call was received.

Phone Number

The phone number of the incoming call.

Tenant Name

The name of the primary contact on the caller's account.

Property

The default property associated with   the tenant.

Address

The address marked as Default on the account.

Balance

The current open balance on the account.

Oldest Charge

The date, charge type, and amount of the oldest outstanding charge on the account. If there are no outstanding charges, None displays.

Call History

This section displays information about the purpose and outcome of the call.

Field Description

Category

The history category that identifies what the call was about.

Comment

The explanation of what you discussed with the caller.

Spoke with

If checked, signifies that you spoke with the caller, as opposed to a voicemail message or receiving no answer from the caller. By default, this is checked if an incoming call is answered (establishing a start and end time to the call) or unchecked if an incoming call is not answered or is missed.

Recent Transactions

This section displays information about the most recent transactions associated with the linked tenant account.

Column Description

Date

The date the transaction was posted to Rent Manager.

Property

The property associated with the transaction. This column displays only if the tenant is leasing at more than one property.

Amount

The dollar amount of the transaction.

Unit

The unit associated with the transaction. This column displays only if the tenant is leasing more than one unit.

Reference #

A note entered by a user describing the type (CASH, MO, the check number, and so on) of transaction.

Description

The system-generated to provide context for the transaction.

Balance

The account's total balance after the transaction was posted.

Recent Issues

Information about the most recent issues displays on this tile.

Column Description

Cl

A displays if the issue was completed and marked as closed on the issue's details page.

Issue

The unique ID number for the issue.

Date

The date the issue was opened.

Title

The name of the issue.
