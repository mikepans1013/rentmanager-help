# Job Details (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Job-Details.htm

The job costing feature of Rent Manager makes it possible to track transactions associated with specific jobs completed by your business. For example, you can track the costs of a renovation or construction project or examine the expenses and revenue associated with landscaping work across your entire portfolio. On the Job details page, you can view and manage general job information, like job types and associated budgets and transactions.

 Related Preferences

 In order to use the job costing tool in Rent Manager , Enable job costing must be checked in system preferences. For more information, refer to General Options (System Preferences) .

 General

 This tile displays basic information about the job, such as the start date and type.

 The following fields display on the tile:

 Field
 Description

 Name

 The full name of the job, which displays on the Jobs page.

 Short Name

 The abbreviated name of the job, which is used to identify the job in reports and other areas of Rent Manager .

 Job Type

 The type of work to be performed for this job. For more information, refer to Job Types (Page) .

 Start Date

 The date on which the job begins.

 End Date

 The date on which the job ends.

 Expected End Date

 The date on which the job is expected to end when it is first created.

 Description

 An explanation of the purpose for the job.

 Active

 A indicates that the job is active, and transactions can be assigned to it.

 Link

 This tile displays the property, unit, or asset linked to the job.

 The following fields display on the tile:

 Field
 Description

 Type

 The entity type to which the job is linked.

 Name

 The full name of the property, unit, or asset that the job is linked to.

 Budget

 This tile displays budgeted dollar amounts for general ledger (GL) accounts for the job.

 The following columns display on the page:

 Column
 Description

 Account

 The GL account used to record the transaction.

 Type

 The type of GL account being used to record the transaction ( Expense , Income , Liability , and so on).

 Comment

 An optional comment explaining the purpose of the budget item.

 Amount

 The total dollar amount allocated to the budget for this portion of the job.

 Recent Transactions

 This tile displays transactions, such as bills and payments, associated with the job.

 The following columns display on the tile:

 Column
 Description

 Type

 The type of the transaction, such as if the transaction is associated with a bill or check.

 Date

 The date on which the transaction took place.

 Reference

 If applicable, the system-generated or custom number that identifies the transaction, such as the check number.

 Information

 A system-generated note that provides further context about the transaction, such as the number of the check that paid a bill.

 Memo

 An optional note entered in the Memo field of the corresponding transaction.

 Amount

 The total dollar amount of the transaction.

 History/Notes

 This tile displays history/note items associated with the job display in this tile.

 The following columns display on the tile:

 Column
 Description

 Date

 The date on which the note was entered into Rent Manager .

 Type

 The system-generated history/note type. For example, if the history/note item is linked to a service issue, the Service Issue type displays.

 Note

 The information to describe the history/note (e.g., Confirmed estimate was received ). If no text is entered, the column displays blank.

 UDFs

 User-defined fields display on this tile based on when a value was added to the UDF. The order in which the user-defined fields display may not match the order that displays in the User Defined Fields pop-up or on the User Defined Fields page. This tile displays up to six UDFs with values and used to track information that Rent Manager does not track by default.
