# Amenity Reservations (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Amenity-Reservations.htm

Rent Manager knows your property has a lot to offer your tenants. With the reservable amenities tool, you can keep your tenants happy and engaged by providing them with the ability to reserve the amenities your property has to offer. The reservable amenities tool in Rent Manager allows you to establish an internal calendar to keep track of those reservations.

 If you have the Tenant Web Access portal, you can choose to allow your tenants to book their own dates and times to use these reservable amenities, and simply approve or decline the request from within Rent Manager . You can also set specific charge types that can be linked to reservations fees that are associated with the reservable amenity.

 After establishing the available reservable amenities on the property, you can manually enter reservations or view and take action on incoming reservation requests from  Tenant Web Access on the Amenity Reservations page.

 Filter Options

 The following filtering options are available on this page.

 Option
 Description

 Search

 You can type in the Search field to narrow the list to match your search criteria.

 Property

 Click the drop-down list and select the property whose requests should display.

 Status

 Filter the requests in the register based on where the request is in the approval process. By default, requests with a Status of Pending display.

 The following status options are available:

 Pending

 No action is taken on this request for reservation.

 Approved

 The reservation is accepted.

 Denied

 The reservation request is declined.

 Canceled

 The reservation request was manually canceled by a user for a reason such as the request was withdrawn.
