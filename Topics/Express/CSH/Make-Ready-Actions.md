# Make-Ready Actions (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Make-Ready-Actions.htm

Make-ready actions, part of the make-ready process, classify and determine the order in which service issues and inspections are available on a make-ready template. Each make-ready action can be assigned to one or more make-ready templates. Make-ready actions can be created before make-ready templates or when adding issues or inspections to a template.

 Column Descriptions

 The following columns are available on this page.

 Column
 Description

 Name

 The name of the action that needs to take place through the make-ready process (e.g., Move Out Inspection , Turnover Activities , Maintenance/Repair , Re-Key Locks ).

 Description

 An explanation of the action (e.g., Inspection of the unit to determine required maintenance ).

 Reorder

 The order in which actions display on the Make Ready Actions page determines the order in which associated issues and inspections process through on the Make Ready board.

 To reorder a make-ready actions, click and hold , then drag it to the desired position in the list.
