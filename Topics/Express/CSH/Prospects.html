Prospects (Page)

In Rent Manager, prospects are potential tenants. These individuals express interest in your properties and rental units. The goal is to get prospects to sign leases and become paying tenants of your management company. Prospecting in Rent Manager is designed to help leasing agents and property managers manage prospect information. It also helps track the effectiveness of your leasing agents and marketing campaigns.

To view your list of prospects, go to arrow_forward Rental Info arrow_forward General arrow_forward Prospects.

On the Prospects page, each prospect displays on a row with information organized into columns. Click on a prospect to open the Prospect details page for that account, where information specific to that prospect is available.

Column Descriptions

The following columns display on the page. By default, some columns display only by using .

Default Column Description

Name

The prospect's full name.

Property

The property that the prospect has expressed interest in

Street

The street of the Default address associated with the prospect.

City

The city of the Default address associated with the prospect.

State

The state of the Default address associated with the prospect.

Postal Code

The postal code of the Default address associated with the prospect.

Additional Column

Description

Account #

The system-generated ID assigned to each prospect account.

Address

The Default address associated with the prospect.

Amenities

The features, services, or other amenities the prospect wants included with their unit.

Arrival Date

For prospects associated with short term rental (STR) properties, the date that their reservation begins.

Comment

An additional note entered on the prospect's details page's General tile.

Contacts

The name of the Primary contact and the number of additional contacts on the prospect's account displays.

Departure Date

For prospects associated with STR properties, the date that their reservation ends.

Email

The email address for contacting the prospect.

Employer

The employer listed on the Primary contact of the prospect's account.

Floors

The preferred floor(s) where the prospect is willing to rent a unit.

Interest Level

The prospect's interest level (0 through 10, with 10 being highest) in your property.

Lead Source

The main source of information that describes how this prospect learned about your company.

Leasing Agent

The user who acts as the prospect's leasing agent.

Number of People

The number of people who will occupy the unit.

Phone

The Default phone number for contacting the prospect.

Property Short Name

The abbreviated name for the property.

Source

For prospects associated with STR properties, where the guest reservation was created. When manually adding a reservation, Rent Manager displays. If the guest made the reservation online, STR Online Booking displays.

Stage

The prospect stage that describes the current progress of a prospect through the leasing process.

Unit

The unit the prospect is looking to lease.

Unit Type

The preferred type(s) of unit the prospect is looking to lease.

Address: (Type)

Each Address Type is listed on the Columns pop-up. The prospect's associated address of the selected type displays.

Phone Number: (Type)

Each phone number type is listed on the Columns pop-up. The prospect's associated phone number of the selected type displays.

UDF: (Prospect-Type)

Each prospect-type user defined field is listed on the Columns pop-up. The value entered on the prospect's account for the selected user defined field displays.

Send Text

  

Related Privileges

Group Privilege Column
Texting/Broadcast Send/Receive texts Enabled

For more information, refer to Control User Access.

Send a text message to the selected account through the text messaging center. This option displays only if there is a text-enabled phone number listed on the account.

More Information

The first text sent to a recipient from the text messaging center and any texts sent via text broadcast or automated notification include an opt-out message. If a recipient opts out, that phone number cannot receive texts from Rent Manager unless they choose to opt back in. Recipients can opt out or opt in at any time. If a recipient wishes to opt back into text messaging, they must text Start from the phone number they opted out with to the number they originally requested to opt out of.

Phone numbers that have opted out of text messaging are identified on the account's View Contacts pop-up, where the checkbox in the T column is replaced with the words Opted out in red text.
