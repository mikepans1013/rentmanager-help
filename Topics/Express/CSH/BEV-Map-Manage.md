# Manage Bird's Eye View (BEV) Maps (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/BEV-Map-Manage.htm

Bird's eye view (BEV) maps allows you to create a visual representation of your properties, providing a high-level overview of a property as well as detailed information for each unit within a property. Rent Manager Express utilizes using pins to build out your maps which removes the need to draw out each unit, like you do when creating maps with shapes, streamlining the map creation process. The Manage BEV Maps page lists out the available maps to view and can be assigned to users, edited, and exported directly from the page.
