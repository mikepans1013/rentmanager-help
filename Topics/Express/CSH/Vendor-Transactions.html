Vendor Transactions (Pop-Up)

This pop-up allows you to view and manage the transactions linked to the currently selected vendor.

Related Privileges

Group Privilege Column
Payables Vendors View

For more information, refer to Control User Access.

To access the Vendor Transactions pop-up, go to arrow_forward Payables arrow_forward General arrow_forward Vendors and select a vendor from the list. Then on the Recent Transactions tile, click to see a list of vendor transactions.

Column Descriptions

The following columns are available on this pop-up:

Column Description

Amount

The total dollar amount of the transaction.

Attachment

A displays if the journal entry has any files, documents, images, etc. attached, such as a copy of the vendor's 1099.

Comment

The Memo written on a bill or check or the Comment field on a credit card or credit transaction.

Date

The date the transaction occurred.

Information

The status information about the transaction:

Bills

If the bill was partially paid, the partial payment displays. If fully paid, the check number of that payment displays.

Checks

The bank account from which the check was drawn displays.

Credit Cards

The specific credit card general ledger (GL) account that was used displays.

Credits

The credited GL account displays.

Deposits

The bank account to which the deposit was made displays.

Property Short Names

The property Short Name associated with the transaction, as displayed on the property's details page.

Reference

Additional information about each transaction:

Bills

The Invoice # of the associated bill.

Checks

The Check Number of the associated check.

Credit Card Transactions/Credits

The associated Reference field.

Deposits

The system-generated deposit number.

Type

The category of transaction linked to this vendor: Bills, Checks, CC (credit cards), or vendor Credits.
