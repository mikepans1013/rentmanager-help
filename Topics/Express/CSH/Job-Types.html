Job Types (Page)

The job costing tool in Rent Manager makes it possible to track transactions associated with specific jobs completed by your business. The Job Types page allows you to define job types so that each job can be categorized for reporting purposes.

Related Preferences

In order to use the job costing tool in Rent Manager, Enable job costing must be checked in system preferences. For more information, refer to General Options (System Preferences).

Related Privileges

Group Privilege Column
Accounting Job types View

For more information, refer to Control User Access.

To view the Job Types page, go to arrow_forward Accounting arrow_forward Accounting Setup arrow_forward General arrow_forward Job Types.

Column Descriptions

The following columns are available on this page.

Column Description

Name

The name of the job type (e.g., Rekey Locks).

Description

A brief description about the job type (e.g., Change locks on all units).
