Reconciles (Page)

The Reconciles page includes both bank reconciliations and credit card reconciliations that were either saved for later or finished. From this page, you can add comments to a reconciliation, manage attachments, and view reports related to each reconciliation.

Related Privileges

Group Privilege Column
Banks/Checks View reconciliation register Enabled

For more information, refer to Control User Access.

To view your reconciliations, go to arrow_forward Accounting arrow_forward Banking arrow_forward Reconciliation Register.

Filter Options

The following filters options are available on this page.

Option Description

Account Type

Select the type of account, either a bank or credit card, that was reconciled or in the process of being reconciled.

Account

Select the name of the bank or credit card that was reconciled or in the process of being reconciled.

Filter By Reconciliation Date

Enter or select the date range for reconciliations you wish to review.

Show Last Completed Reconcile Only

Select this field to display only the latest reconciliations for each account in the register.

Column Descriptions

The following columns are available on this page. By default, some columns display only by using .

Column Description

A

If an attachment is available on a reconciliation, the icon displays. Click the icon to view attachments, such as a bank statement, uploaded to the reconciliation.

Completed

A displays to indicate whether the entry is currently reconciled.

Account

The bank or credit card name associated with the reconciliation.

Rec Date

The date of the bank statement that corresponds with the reconciliation.

Rec Balance

The cleared balance after the reconciliation is completed. If the Reconciled Balance matches your Goal, then your register matches your credit card statement.

Prev Rec Amt

The cleared balance as of the previous bank reconciliation.

Goal

The balance on your actual credit card statement. The goal of the reconciliation is to get the balance of your cleared register (Reconciled Balance) to match your real-world credit card balance.

Difference

The difference between your Goal and the Reconciled Balance. When the Difference is 0, you have reached your goal.

Comment

Any additional information about the associated reconciliation.
Available Columns Description

Completion Date

The date on which the reconciliation was finished.

Create Date

The date the reconciliation was entered and saved in Rent Manager.

Create User

The username of the person who created the reconciliation.

Deposits

The total value of all deposits or credits in the reconciliation.

Payments

The total value of all payments or charges in the reconciliation.

Update Date

The date the reconciliation was last updated and saved in Rent Manager.

Update User

The username of the person who last updated and saved the reconciliation.

Row Actions

The following row actions are available to take from the menu.

Action Description

Edit Comment

Edit the message that displays in the Comment column for the reconciliation.

Manage Attachments

View and download an existing attachment from the Attachments pop-up. If there is no attachment, click Upload Files to add a new attachment to the reconciliation.

Saved Report

On completed reconciliations, view the reconciliation information from when the user last saved the bank or credit card reconciliation.

Live Report

On completed reconciliations, view the reconciliation information from when the user first finished the reconciliation. It also displays any transaction items that were edited or deleted after the reconciliation.
