# Colors (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Colors.htm

Highlight entities and events in Rent Manager by using defined colors. Colors can be applied in many areas of Rent Manager such as appointments, tasks, tenants, and units. For example, you can define the color green as Commercial and apply it to commercial tenants, units, and/or properties so commercial tenants and properties display green anywhere colors are available.
