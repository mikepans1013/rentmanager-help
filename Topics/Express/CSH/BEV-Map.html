View Bird's Eye View (BEV) Maps (Page)

Bird's eye view (BEV) maps provide a visual overview of your properties and allow you to quickly retrieve unit and tenant information. You can use BEV views to filter the units that display based on a specific criterion, such as the occupant's unpaid balance or whether a tenant recently moved out of the unit.

Warning

Rent Manager Express has improved map-making capabilities, allowing you to create very large map images in bird's eye view that may not be accessible in Rent Manager 12. If a map image exceeds 2500 x 2500 px, the map will not load in Rent Manager 12.

Related Privileges

Group Privilege Column
Bird's Eye View (BEV) BEV Maps View

For more information, refer to Control User Access.

To view a BEV map, go to arrow_forward Rental Info arrow_forward Bird's Eye View (BEV) and select one of the maps. Only maps to which your user account has access display in this menu.

Filter Options

The following filtering options are available on this page.

Filter Description

As of Date/Date Range

If the selected View has date-specific information, such as Balance Due or Move Outs, the pins or shapes that display can be further filtered using an As of Date or Date Range. You can select from one of the relative dates (e.g., Today) or date ranges (e.g., This Week).

Floor

If the property has multiple floors, you can select one or more floors to display pins or shapes for only those floors.

Map

In the top left, the name of the current BEV map displays (e.g., Black Bear Mountains). A different map can be selected from the drop-down list.

View

The BEV view used to limit the pins or shapes that display. For example, selecting the Balance Due option removes all units whose tenants do not currently have any unpaid charges. For more information, refer to Manage BEV Map Views.

Pin or Shape Actions

Depending on the map's type, pins or shapes can be selected to display information about the unit's current, future, or most recent occupant. From the card that displays, you can view details such as the tenant's name, move-in and move-out dates, and current balance. The information that displays is based on how the map's settings are customized. For more information, refer to Bird's Eye View (BEV) Map Settings (Pop-Up).
