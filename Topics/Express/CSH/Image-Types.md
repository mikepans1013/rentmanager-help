# Image Types (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Image-Types.htm

Image types sort your uploaded images into categories that can be attached to properties, units, unit types, and assets, each with their own customized set of image types. You can also use image types with ILS marketing sites such as Zillow to add all images of a specified type to the marketing feed, rather than needing to select images individually. The Image Types page allows you to create new image types for each entity, as well as edit or delete existing image types.
