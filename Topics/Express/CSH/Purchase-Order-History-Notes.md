# Purchase Order History/Notes (Pop-Up)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Purchase-Order-History-Notes.htm

Purchase order (PO) history/notes allow you to record information that supplements or clarifies what is entered in other fields, such as the user(s) who updated the status, any bills linked to the PO, and notes about phone conversations or estimates. While some history/note items are automatically created by Rent Manager , you are also able to record information based on your needs.

 Filter Options

 The available filter options are listed below. Depending on the size of your browser window, these filters may display at the top of the page or you may need to click to view the filter options.

 Option
 Description

 Search

 Enter search terms in the Search field to find history/note items that contain the searched text.

 Filter By Date

 Select or enter the From and/or To dates to filter notes created during the selected dates.

 Users

 Click the drop-down list and select users to filter for history/note items created by the selected users.

 History Category

 Click the drop-down list and select categories to filter for history/note items by category. Select Unassigned to include items with no category.

 Type

 Click the drop-down list and select types to filter history/note items by type.

 Only Notes with Attachments

 Check to display only history/note items that have an attachment.

 Column Descriptions

 The following columns are available on this page.

 Column
 Description

 Pin

 Pinned history/note items always display at the top of the list. If there are no pinned items, the column does not display.

 Type

 The system-generated history/note type. For example, if the history/note item was generated when the PO was assigned to or approved by a user, the System type displays.

 Date

 The date and time the note was created.

 Note

 The text entered in the Note field of the history/note item. If no text is entered, the column displays blank.

 If an attachment is uploaded to the history/note item, displays. Click to download the attachment or open it in a new tab.

 Category

 The category that describes the purpose of the history/note item.

 User

 The Rent Manager user who created the history/note item. If this is a system-generated item, the user who performed the task that generated the note displays.
