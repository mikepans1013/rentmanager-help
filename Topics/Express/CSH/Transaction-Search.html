Transaction Search (Page)

The Transaction Search page lets you search for one or more transactions that occurred during a specified date range and then filter the results using additional search criteria. The types of transactions that you can search for include: journal entries, bills, checks, deposits, receivables, and credit card transactions.

Related Privileges

Privileges determine what search results are visible and what further actions you can take. Depending on your user privileges, you may be able to open a new page, drill down from the results to specific pages, and perform certain additional actions.

More Information

Only information related to the properties to which you have access displays. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property.

To search for transactions, go to arrow_forward Search arrow_forward Transactions.

Filter Options

The following filter options are available on this page.

Option Description

Type

The type of transaction (e.g., Bill, Check, Deposit) you wish to search for.

Date Range

The date range during which the transactions occurred.

Search Options

Select Begins With to search for any number or text at the start of the Reference, Comment, or Amount fields. Select Contains to search for any number or text located within the Reference, Comment, or Amount fields.

Reference

Enter a word, phrase, or number to search for a reference of a transaction.

Comment

Enter a word or phrase to search for a comment of a transaction.

Amount

Enter a dollar amount to search for a transaction.

Column Descriptions

The following columns display on the page.

Column Description

Type

The type of transaction (e.g., Bill, Check, Deposit).

Date

The date on which the transaction posted.

Property

The property linked to the transaction.

Reference

A short Reference for the transaction. For example, bills display the Invoice #, checks display the check No., and journal entries display the Journal number.

Information

The account name or name field associated with the transaction. Depending on the transaction type, the following references display:

Journal Detail

The text entered in the Reference field of the journal.

Bill

The name entered in the Payee field on the vendor's details page for the vendor the bill is written out to. If no payee is listed, the name entered in the Name field on the vendor's details page displays.

More Information

The Information column displays only for bills to vendors. If the bill is written out to a tenant, prospect, or owner, the column displays a blank field.

Check

The name entered in the Payee field on the vendor's details page for the vendor the check is paid out to. If no payee is listed, the name entered in the Name field on the vendor's details page displays.

More Information

The Information column displays only for checks to vendors. If the check is paid out to a tenant, prospect, or owner, the column displays a blank field.

Deposit

The bank selected in the Bank Account field of the deposit.

Receivable

The account name the transaction is charged to and the Description as it shows on the account's View Transactions page.

Credit Card

The name entered in the Payee field on the vendor's details page for the vendor the credit card transaction is paid out to. If no payee is listed, the name entered in the Name field on the vendor's details page displays.

Vendor Credit

The name entered in the Payee field on the vendor's details page the vendor's details page for the vendor the credit is from. If no payee is listed, the name entered in the Name field on the vendor's details page displays.

Comment

Additional information about the transaction. Depending on the transaction type, the Comment is pulled from the following fields:

Journal Detail

The text entered in the Memo field of the journal.

Bill

The text entered in the Memo field of the bill.

Check

The text entered in the Memo field of the check.

Deposit

The text entered in the Comment field of the deposit.

Receivable

The text entered in the Comment field on the Charge Details of the receivable.

Credit Card

The text entered in the Comment field of the credit card transaction.

Vendor Credit

The text entered in the Comment field of the vendor credit.

Amount

The total dollar amount of the transaction.
