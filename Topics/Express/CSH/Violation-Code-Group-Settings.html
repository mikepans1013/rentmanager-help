Violation Code Group Settings (Pop-Up)

The Violation Code Group Settings pop-up allows you to manage the general information and default stages associated with a violation code group and the codes withing that group.

Related Privileges

Group Privilege Column
Setup Violation Code Groups View, Edit

For more information, refer to Control User Access.

To view a violation code group's settings, go to arrow_forward Rental Info arrow_forward Rental Info Setup arrow_forward Violations arrow_forward Violation Code Groups and select a violation code group from the list. Then, on the Code Group details page, click Code Group Settings.

General

The following fields are available in this section:

Field Description

Name

The unique name for the code group (e.g., HOA Property Bylaws, Student Housing).

Properties

The properties that use this code group as their rules and regulations.

Code Group Default Options

The following fields are available in this section:

Field Description

Letter

The tenant- or violation-type letter template which populates by default when adding a violation, editing a violation to add a charge, or escalating a violation. Other letters may be chosen during the process, allowing for more specific communication based upon the code or escalation stage.

Charge Type

The charge type which populates by default when adding a violation, editing a violation to add a charge, or escalating a violation. Other charge types may be chosen during the process, allowing for more specific charges based upon the code or escalation stage.

Default Stages

You can define up to ten default violation stages, which are the escalating stages that determine the actions taken or penalties applied for the infraction, and any escalations for failing to comply.

More Information

Default stages are inherited by each code within the code group. The default stages can be overridden for codes that have a different escalation process.

The following columns display in this section:

Column Description

Stage

The level (a number between one and ten) of the stage.

Name

The name of the stage (e.g., First Warning, Second Warning, Eviction Notice).

Days to Comply

The number of days the tenant has to remedy the violation before it can be escalated.

Amount

If applicable, the fee that should be charged to the tenant upon the violation being escalated to this stage.

Letter

The tenant- or violation-type letter template which populates by default when adding a violation, editing a violation to add a charge, or escalating a violation. Other letters may be chosen during the process, allowing for more specific communication based upon the code or escalation stage.

Charge Type

The charge type which populates by default when adding a violation, editing a violation to add a charge, or escalating a violation. Other charge types may be chosen during the process, allowing for more specific charges based upon the code or escalation stage.

Internal Actions

The notes for this stage to further describe the actions taken, or that need to be taken, by a Rent Manager user.

Actions Confirmed

If checked, users are required to complete the Internal Actions for the stage before they can escalate a violation to the next stage.
