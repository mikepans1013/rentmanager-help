# Memorized Issues (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Issues-Memorized.htm

Memorized issues allow you to save time by creating templates for common tasks, such as re-keying locks or unclogging drains. Memorized issues are issue templates that are saved to easily create new issues that are already populated with information. You can either create a new memorized issue, or you can memorize an existing issue into a template.
