# Marketing Configuration Wizard (Pop-Up)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Marketing-Configuration-Wizard.htm

Previously, Rent Manager supported marketing your vacant units from either the property or unit. Since most internet listing service (ILS) sites no longer accept marketing data for individual units, it is recommended that you convert any marketing data stored on units to the property. If you have not converted your unit marketing configuration to a property marketing configuration, the property Marketing Setup pop-up displays a message prompting you to use the Property Marketing Configuration Wizard .

 To help you with the conversion, the Property Marketing Configuration Wizard allows you to convert all marketing data at once from the units at a property to that property's Marketing Setup pop-up.

 Warning

 Once you convert your marketing data to the property, it cannot be reversed. Once this wizard is completed, all marketing data is stored on the property.

 If the property is set up as a single-family home with multiple units, converting to property-level marketing may result in changes to the ILS listings. With the exception of unit names and addresses, all listing details are pulled from the property Marketing Setup pop-up.

 To convert your marketing information for the property, go to   arrow_forward Rental Info arrow_forward General arrow_forward Properties and select the desired property. On the action bar to the right, click arrow_forward Marketing Setup .

 Click Property Marketing Configuration Wizard and read the disclaimer. When finished, select Continue Marketing Configuration Wizard and click Next . The sections of the wizard are detailed below. When the information you want to transfer from unit marketing to property marketing is filled out, click Finished to complete the transfer.

 Company Info

 Information related to the selected property, such as the company's name. This information must be included and accurate for the property to list on ILS feeds.

 Company Website

 The email address prospects can use to contact the company for more information.

 Contact Phone

 The phone number prospects can use to contact the company that is managing the property.

 Listing Details and Features

 This section contains fields with information regarding the available amenities and features for the selected property. To view the unit field values that are currently set at the property, click .

 Field
 Description

 Agent Email

 The email address of the property's leasing agent.

 Agent First Name

 The first name of the property's leasing agent.

 Agent Last Name

 The last name of the property's leasing agent.

 Agent Phone

 The phone number of the property's leasing agent.

 Availability

 The date on which the property is listed as available. If this field is left blank, the property is listed as available by default.

 Deposit Fee(s)

 The deposit amount for the property. To change what displays in this field, select a different value from the drop-down.

 Feed Type

 The feed type determines to which ILS sites the listing will be available. Rent Manager selects a feed type of Multi Family or Single Family , or an unassigned feed type based on the property's Property Type selection. For more information, refer to ILS Marketing Feed Types .

 Incl. Utilities

 These preselected fields, taken from ILS sites, contain the utilities that are included in the rent for the property in the listing.

 Latitude Coordinate

 The latitude coordinates of your property (combined with the Longitude Coordinate field) are used to specify its exact location and make GPS directions easier to obtain.

 Laundry

 These preselected fields, taken from ILS sites, contain the option(s) available for laundry at the property in the listing.

 Lease Terms

 The available lease terms for the property. To change what displays in this field, click the drop-down and select or deselect one or more lease terms. Alternatively, choose Contact For Details if lease terms at the selected property are not determined.

 Listing URL

 The website where the property is primarily listed (for example, your property management company's website). This URL displays on ILS sites to provide more exposure.

 Longitude Coordinate

 The longitude coordinates of your property (combined with the Latitude Coordinate field) are used to specify its exact location and make GPS directions easier to obtain.

 Marketing Description

 A custom description, of up to 1,000 characters, regarding your property's online listing. For example:

 A modern, luxury duplex located just 15 minutes from downtown and two minutes from the highway, while still offering a peaceful, suburban ambiance. The kitchen is recently updated, and all windows have been replaced in the last three years.

 Marketing Name

 The name of the property that displays on ILS sites to promote your property. This is useful if your property's name is shortened in Rent Manager . For example, if your property's name in Rent Manager is Riverview , you can set the marketing name to display on ILS sites as The Apartments at Riverview .

 Pets

 These preselected fields, taken from ILS sites, contain the details regarding pets at the property in the listing.

 Price

 The name of the field where the listing price for the property is being pulled. Use the drop-downs to select an existing Rent Manager field or manually enter a value.

 More Information

 When the feed type for the property is set to Multi-Family , the price field cannot be changed or customized. The price for the listing is pulled from the Floor Plans section in the Price field.

 Property Images

 Each image type for the property that should display in the listing. All images on the property's details page of the selected image types are included.

 Property Type

 The category that best describes the type of property you are marketing. By default, the Field: Property Type is selected and uses the property type set on the property's details page.

 Rental Classification

 The rental classification is assigned a default value based on the Property Type set on the property's details page. If this field defaults to Unspecified , select an option from the drop-down list that further specifies the property you are marketing. For example, you can distinguish different kinds of student housing by selecting Apartment , Campus , House for Rent , and so on.

 This information is used by some ILS providers to match properties and units with specific rental categories as closely as possible.

 Rental Type

 The type of housing the property supports to determine if ILS providers post the property on multiple sites for various rental types. For example, if you select Student , providers know they can post to their sites specifically geared toward housing for students.

 If none of the rental types apply, leave this field blank.

 Unit Images

 Each image type for the associated unit(s) to display in the listing. All images of the selected image type(s) on the Images tile of all the property's units are included.

 Virtual Tour URL

 The website where a virtual tour of the property is available for prospects to view.
