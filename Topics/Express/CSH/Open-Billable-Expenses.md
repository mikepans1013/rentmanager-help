# Open Billable Expenses (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Open-Billable-Expenses.htm

This billing and invoicing tool allows you to charge back expenses to tenants or owners in the form of invoices and, optionally, add a markup amount to each billable expense as part of the reimbursement. The Open Billable Expenses page populates with expenses that are marked as billable on a Rent Manager bill, check, or credit card transaction for which you have not yet created invoices.

 Column Descriptions

 The following columns are available on this page.

 Column
 Description

 Date

 The date of the bill, check, or credit card transaction that contains each open billable expense.

 Vendor

 The name of the vendor being paid by each bill, check, or credit card transaction.

 Transaction Type

 The type of transaction ( Bill , Check , or CC Trans ) for which each billable expense was created. When applicable, the check number or invoice number also display.

 Linked Tenant/Owner

 The name of the tenant (as it displays on the tenant's details page) or owner (as it displays on the owner's details page in the Name field) being charged for the billable expense.

 Amount

 The amount of the expense line item being charged back to the tenant or owner before markup.

 Markup

 The markup amount for each charged back expense.

 Total Amount

 The total amount, including any markup, being charged back to the tenant or owner for the billable expense.
