# Owner History/Notes (Pop-Up)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Owners-History-Notes.htm

History/notes allow you to record information that supplements or clarifies what’s entered in other fields, such as notes about phone conversations, items on a to-do list, and explanations about transactions. While some history/notes are automatically created by Rent Manager , you are also able to record information based on your needs. This makes it easier to track events related to each owner and provide additional details for internal reference.

 Filter Options

 Rent Manager provides history/note filters. Depending on the size of your browser window, these filters may display at the top of the page or you may need to click to view the filter options.

 Option
 Description

 Search

 You can type in the Search field to narrow the list to match your search criteria.

 Filter By Date

 Select or enter the From and/or To dates to filter notes created during the selected dates. Click to select a specific date range.

 Users

 Click the drop-down list and select the desired user(s) to filter for items created by one or more Rent Manager users.

 History Category

 Click the drop-down list and select the desired categories to include. To include history/note items with no category, select Unassigned .

 Type

 Click the drop-down list and select the desired types of history/note items.

 Only Notes with Attachments

 Check to display only history/notes that have an attachment.

 Column Descriptions

 The following columns are available on this page.

 Column
 Description

 Pin

 If the history/note has Pin enabled, displays. If there are no pinned notes, the column does not display.

 Type

 The system-generated history/note type. For example, if the history/note is linked to a service issue, the Service Issue type displays.

 Date

 The date and time the note was created.

 Note

 The information to describe the history/note (e.g., Called to confirm visit to the property). If no text is entered, the column displays blank.

 If an attachment is uploaded to the history/note, displays. Click to download the attachment or open it in a new tab.

 Category

 The category of the history/note selected from the available history categories. If no category is selected, the column displays blank.

 User

 The Rent Manager user who created the history/note. If this is a system-generated history/note, the user displays as Administrator . If the history/note was generated from Tenant Web Access (TWA) , the user displays as <Unassigned> .
