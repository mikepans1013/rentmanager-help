Owner Groups (Page)

Owner groups are a collection of owner accounts with a similar attribute. Creating owner groups makes postings, reporting, and filtering for multiple owners much easier. Rather than selecting each owner individually, you can select the owner group and perform actions on every owner in the group. For example, you could create an owner group for all in-state owners and another group for out-of-state owners.

Related Privileges

To view your list of owners, go to arrow_forward Owners arrow_forward Owners Setup arrow_forward General arrow_forward Owner Groups.

Column Descriptions

The following columns display on the page.

Column Description

Name

The name used to identify the owner group.

Owners

The name of the owners (as it displays on the owner's details page in the Name field) included in the group.
