# Checks (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Checks.htm

You can write checks to vendors, tenants, prospects, and owners. Entering checks into Rent Manager lets you track when they were written, which properties were expensed, and for how much. The Checks page contains all checks written in Rent Manager and also includes checks that are automatically created when you pay bills in Rent Manager .

 To open the Checks page and view your checks, go to   arrow_forward Payables arrow_forward Checks arrow_forward Checks .

 On the Checks page, each check displays on a row with information organized into columns. Click on a check to open the details page for that check, where information specific to that check is available.

 Filter Options

 The following filtering options are available on this page.

 Option
 Description

 Search

 Enter the desired search criteria to display results that include the criteria.

 Saved Filters

 Use to narrow the list of entities that display in the list by using other criteria.

 Bank

 Narrow results based on which bank account is associated with the check.

 Filter by Check Date

 Enter a From and/or To date to display only those transactions dated within the range.

 Column Descriptions

 The following columns display on the page. By default, some columns display only by using .

 Default Column
 Description

 Reference

 The identifying number of the check, or displays CC for credit card payments.

 Bank

 The bank from which funds are drawn by this check.

 Date

 The date on which the check was issued to the payee.

 Amount

 The total dollar amount of this check.

 Vendor

 If the check was written to a vendor, the name of the vendor account that is associated with the payee of the check.

 Properties

 The property expensed by the payee of the check.

 Memo

 An optional message regarding the check.

 Available Column

 Description

 Attachments

 A displays if the check has any files, documents, images, etc. attached, such as a photo of the signed check.

 Cleared

 A green indicates that this check was reconciled against your real-world bank account. For more information, refer to Bank Reconcile .

 Created By

 The user who created the check.

 Created Date

 The date on which the check was entered into Rent Manager .

 Payee

 The recipient of the check payment.

 Updated By

 The user who most recently updated and saved the check details.

 Updated Date

 If applicable, the date on which the check was most recently updated.

 Vendor Category

 If the check was written to a vendor, the type of vendor paid by the check (for example, Locksmith , Plumber , Electrician, and so on).

 Voided

 A green indicates that the check was voided.
