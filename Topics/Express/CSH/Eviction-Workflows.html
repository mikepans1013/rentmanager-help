Eviction Workflows (Page)

The Eviction Workflows page allows you to view and manage eviction workflows, adapted to your unique needs and requirements. Each workflow can contain multiple stages, customized payment settings, and automated letter actions in order to tailor each workflow to fit the various eviction legal processes you may have.

Related Privileges

Group Privilege Column
Setup Manage Eviction Workflows Enabled

For more information, refer to Control User Access.

To view the Eviction Workflows page, go to arrow_forward Rental Info arrow_forward Rental Info Setup arrow_forward Evictions arrow_forward Eviction Workflows.

Column Descriptions

The following columns are available on this page.

Column Description

Active

A displays to indicate the eviction workflow is Active, as displayed on the Eviction Workflow Setup page.

Name

The name assigned to eviction workflow.

Assigned Properties

The Short Name of the property or properties associated with the eviction workflow.
