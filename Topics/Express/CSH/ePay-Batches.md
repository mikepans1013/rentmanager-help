# ePay Batches (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/ePay-Batches.htm

The ePay Batches page allows you to review any recurring ePay batches that were posted within a date range. The page displays the date the batch was posted in Rent Manager and the user who posted the batch, along with the total amount and how many transactions were in the batch to help you track ePay activity.

 To view previously posted recurring ePay batches, go to Receivables arrow_forward Payments arrow_forward ePay History .

 Column Descriptions

 The following columns display on this page.

 Column
 Description

 Batch ID

 The system-generated identification number of the recurring ePay batch.

 User Name

 The user who posted the batch. If the batch was posted via Task Automation , <Unassigned> displays.

 Batch Date

 The actual date that the batch was posted in Rent Manager . This may differ from the post date selected on the Post Recurring ePay Payments page or the Post Day established in a recurring ePay automation schedule.

 # of Transactions

 The number of payments in the batch, including failed payments.

 Amount

 The total dollar amount of payments in the batch, including failed payments.
