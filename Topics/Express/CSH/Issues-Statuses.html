Issue Statuses (Page)

Issue statuses are conditions that you create to describe the current progress of a service issue (e.g., New, Work in Progress, Resolved, Unresolved). You can also sort by the statuses of issues in filters and saved issue lists.

Related Privileges

Group Privilege Column
Service Manager List manager View, Edit

For more information, refer to Control User Access.

To view or manage issue statuses, go to arrow_forward Services arrow_forward Service Setup arrow_forward Service Manager arrow_forward Statuses.

Column Descriptions

The following columns display on this page.

Column Description

Active

If checked, the issue status displays on issues and recurring issues. If unchecked, the issue status displays on the List Manager Statuses page only when Active Only is checked.

Name

A descriptive name that identifies the issue status.

Description

An optional message about when to use the issue status.
