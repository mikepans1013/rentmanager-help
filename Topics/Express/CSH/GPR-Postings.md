# GPR Postings (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/GPR-Postings.htm

Gross potential rent (GPR) is the maximum revenue that a property could generate if it was rented at full capacity and at full market value. You can calculate a property's GPR and use the data to analyze profitability, forecast income, and identify risks. The GPR Postings page displays prior GPR postings for historical and reference purposes.

 Column Descriptions

 The following columns are available on this page.

 Column
 Description

 From Date

 The first day of the last full month prior to the current date or the first day since the last GPR post date.

 To Date

 The last day of the last full month prior to the current date or one month after the From Date .

 Post Date

 The date GPR was posted.

 Market Rent Date

 The date you wish to examine market rent for the associated units.

 Accrual Journal #

 The Journal # of the accrual basis journal entry created when GPR was posted.

 Cash Journal #

 The Journal # of the cash basis journal entry created when GPR was posted.

 Properties

 The name of the property for which GPR was posted. If GPR was posted for multiple properties, <Multiple> displays.

 Comment

 Additional information about the posting displayed on the journal entry.
