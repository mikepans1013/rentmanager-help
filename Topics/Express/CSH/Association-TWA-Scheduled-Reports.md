# Scheduled TWA Reports (Pop-Up)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Association-TWA-Scheduled-Reports.htm

For properties that are designated as association-type properties in Rent Manager , you can manage and schedule the reports that display to association members in Tenant Web Access (TWA) . For example, if you want board members to view the Profit and Loss report each month, you can schedule it to be published to TWA. The board members can access the generated report with data based on the report options you selected in Rent Manager .

 To view the scheduled TWA reports, go to arrow_forward Rental Info arrow_forward General arrow_forward Properties and select an association-type property. Then on the action bar to the right, click   arrow_forward   TWA Report Schedules .

 Check Show Past Schedules to view TWA report schedules that are no longer active.

 Column Descriptions

 The following columns display on this pop-up.

 Column
 Description

 Report Name

 The name of the report scheduled to be published to Tenant Web Access .

 Display Name

 The name for the report that displays when users access the report in TWA.

 Audience

 The board members or committee associated with the property, that are able to review the report.

 Frequency

 How often the report is re-published after the First Run Date . For example, If the first run date was 1/1/ 2026 and the Frequency is Quarterly , the report is generated and then published to TWA on 1/1/ 2026 and again on 4/1/ 2026 and so on until the schedule expires.

 Ends

 The date on which the report is no longer published, if applicable.
