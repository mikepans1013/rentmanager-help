# Assets (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Assets.htm

Rent Manager allows you to manage a variety of assets, like kitchen appliances, furnaces, and manufactured homes. Assets can be assigned to a property to track financial activity, rented to tenants via leases, assigned to a unit that represents a lot of land, linked to their physical location, and have their condition tracked by using asset statuses.

 Column Descriptions

 The following columns are available on this page. By default, some columns display only if added via .

 Default Column
 Description

 Asset Type

 The user-created category that best classifies the type of asset being created.

 Home

 A displays if this asset is a home that a renter can live in.

 Manufacturer

 The user-created company that produced and supplied this asset.

 Model

 The model name of the asset.

 Name

 A unique identifier for the asset.

 Property

 The property where the asset is physically located.

 Status

 The condition that best describes the state of the asset ( In Service , Inventory , Out for Maintenance , etc.).

 Unit

 The unit where the asset is physically located.

 Available Column

 Description

 Age

 How much time has elapsed since the purchase date of the asset.

 Bathrooms

 The number of bathrooms the asset contains. This field is available only if the associated Asset Type is set up as a home.

 Bedrooms

 The number of bedrooms the asset contains. This field is available only if the associated Asset Type is set up as a home.

 Comments

 Additional information or notes about the asset.

 Dimensions

 The measurable size of the asset, such as length and width.

 Financial Property Name

 The name of the property used for tracking financial information about this asset.

 Financial Property Short Name

 The abbreviated name of the property used for tracking financial information about this asset.

 Homeowner Status

 The current legal ownership status (i.e., Community Owned , Employee Owned , etc.) associated with the asset, as displayed on the asset's details page General tile.

 Last Maintenance

 The most recent date on which maintenance was performed for this asset.

 Lienholder

 The name of the financial institution that retains legal claim to the asset until the loan associated with the Loan Number is paid off, as displayed on the asset's details page Purchase & Loan Information tile.

 Loan Number

 The number assigned by the issuer of the loan, as displayed on the asset's details page Purchase & Loan Information tile.

 Location From Date

 The first date on which the asset was at its current physical location.

 Location Property Short Name

 The abbreviated name of the property where the asset is currently located.

 Location To Date

 The last date on which the asset was at its current physical location.

 Manufactured

 The date on which the asset was built.

 Next Maintenance

 The date the next maintenance record is due on this asset.

 If the date displays with an asterisk (*), Rent Manager calculates the date by adding the number of months in the Service Period to the Service Life Start date. This is a projected date for when the next maintenance should be scheduled.

 Purchase Date

 The date on which the asset was purchased.

 Purchase Price

 The price you paid for the asset.

 Rent Amount

 The current rental price that renters pay for the asset.

 Rentable

 A displays if the asset is available to be rented.

 Sale Price

 The price you would sell or sold the asset for.

 Serial Number

 The asset's unique serial identification number.

 Service Agreement

 If enabled, this asset has a maintenance service agreement with the manufacturer or vendor.

 Service Agreement Expiration

 The date that the manufacturer or vendor service agreement for this asset ends.

 Service End Date

 The date on which the use of this asset by your company ends, or is expected to end. The asset can no longer be used past this date.

 Service Length

 The amount of time the asset was in use, or is expected to be in use, by your company. For assets with no end date, this displays a running count since the Service Start Date .

 Service Period

 The number of months that should elapse between each service/maintenance for this asset during the length of your service agreement.

 Service Start Date

 The date on which the asset was first placed at a unit or property.

 Square Footage

 The size of the asset in square feet. This field is available only if the associated Asset Type is set up as a home.

 Status Created By

 The user who created the status that is currently applied to the asset.

 Status From Date

 The date on which the status was first applied to the asset.

 Status To Date

 The date on which the status ended for the asset.

 Title Status

 The current condition of the asset's title (e.g., Clear Title or In Process ).

 Track Financials

 A displays if the asset is associated with a property for the purpose of tracking financial history.

 Vendor

 The primary vendor who is responsible for servicing and/or maintaining this asset.

 Warranty Expiration

 The date that the warranty for this asset expires.

 Warranty Info

 Any additional details regarding the warranty for this asset, such as terms or special stipulations.

 UDF (Asset Type)

 Any asset-type user defined fields that be used with the asset.
