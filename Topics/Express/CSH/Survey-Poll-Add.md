# Add a Survey/Poll (Pop-Up)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Survey-Poll-Add.htm

Surveys allow you to connect with your tenants and collect their feedback on your properties, units, management, and amenities. You can create surveys to publish directly to Tenant Web Access (TWA) . The tenants are prompted to complete them when they next log in and available until the set expiration date when they close. Submitted responses can be viewed from the Surveys page or from a tenant's list of history/notes.

 For example, you may create a survey for TWA when you want to request suggestions for improving the community pool, gather votes for potential new amenities, or poll tenants on their interest in a holiday-themed community event.

 To create a new survey, do the following:

 -
 Go to arrow_forward Communication arrow_forward Surveys arrow_forward Surveys .
The Surveys page displays.

 -
 Click Add Survey .

 -
 In the Details tile, enter information in the following fields:

 Field
 Description

 Survey Type

 Select Tenant to request feedback from residents via TWA. This field cannot be changed once the survey is saved.

 More Information

 If you select Service Issue in this field, you cannot publish the survey to TWA and it is always distributed to groups of tenants using a dedicated portal without requiring a TWA login. Additionally, Service Issue surveys can be automated so when an issue is closed, the survey is sent automatically. For more information, refer to Add and Activate a Survey .

 Name

 The unique identifier for this survey that displays internally for users.

 Display Name

 The title that displays to tenants in TWA.

 Description

 Additional information about the survey, such as when it should be sent to tenants or whether it should be distributed for residential and/or commercial tenants. These comments display only to Rent Manager users.

 -
 In the Introduction Page tile, enter the Introduction Page Text that displays for tenants before they begin answering the survey question(s). To customize the message using scripting, click Open Script Builder for scripting assistance.

 -
 In the Questions tile, click Add Question .
The Add Question pop-up displays.

 -
 Create questions for the survey by entering information in the following fields:

 Field
 Description

 Question

 The text that displays for the tenant to answer.

 Response Type

 The kind of value a tenant can enter as an answer.

 Yes/No

 Allows the tenant to select Yes or No as a response.

 Text

 Allows the tenant to enter a plain text response.

 Dropdown List

 Allows the tenant to select a single option from a drop-down list of options you establish. To add a new list item, click Add Choice .

 Optionally, to add an option where the recipient can submit their own custom response, select Include an 'Other' response option .

 Selection List

 Allows the tenant to select one or more values from a list of options you establish. To add a new list item, click Add Choice .

 Optionally, to add an option where the recipient can submit their own custom response, select Include an 'Other' response option . To restrict the amount of options a tenant can select, check Limit selection to a maximum of items and enter the desired value.

 Star Rating (1-5)

 Allows the tenant to select a response between one and five stars.

 Response Required

 If checked, the tenant cannot submit the survey until they have answered this question.

 -
 Click Add & New to create another question, or click Add & Close to continue creating the survey.

 -
 In the Closing Page tile, enter the Closing Page Text that displays for tenants when they submit their survey answer(s). To customize the message using scripting, click Open Script Builder for scripting assistance.

 -
 In the Send Options tile, select Publish a one time survey to TWA for a specific group of tenants (typically used for polls/voting) .

 More Information

 If you select Send public survey link to individual tenants as needed , the survey is distributed to groups of tenants using a dedicated portal and does not require a TWA login. For more information, refer to Add and Activate a Survey .

 -
 Click Continue .
The second page of the Add Survey pop-up displays.

 Step 2: Select Publishing Options

 On the second page of the pop-up, select the tenants you want to respond to the survey and the date the survey ends by doing the following:

 -
 In the Publish Options tile, enter information in the following fields:

 Field
 Description

 End Date

 The final date that tenants can respond to the survey.

 Properties

 Each property whose tenants can receive and respond to the survey.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Publish to Board Members Only

 If checked, only individuals set up as board members (e.g., Chair , Treasurer ) can respond to the survey. For more information, refer to Association Board Members (Pop-Up) .

 This option is available if you selected only properties with the Property Type of Association .

 -
 In the Publish to TWA for the Following Accounts tiles, select each tenant you want to receive the survey in TWA.

 -
 Click Publish to TWA to create the survey and allow tenants to access it on TWA immediately, or click Save to create the survey and publish it at a later time. For more information, refer to Add and Publish a Survey to Tenant Web Access (TWA) .
The survey can be viewed on the Surveys page in an In Progress or Draft status based on how it was saved.
