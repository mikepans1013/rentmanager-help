Tenant Filters (Pop-Up)

Tenant filters allow you to quickly narrow your search results to get to the tenant information that you really need. Rent Manager gives you the ability to choose from a variety of filtering options to sort your tenants on the Tenants page.

Related Privileges

Group Privilege Column
Tenants/Prospects Tenants View

For more information, refer to Control User Access.

Rent Manager allows you to create filters that can be used temporarily, or saved to use repeatedly. Additionally, they can be saved on a system level for all users, or on a personal level where only your user account can access it. Before saving your filter, enter a Name, and, optionally, a Description to remind you of the filter's purpose.

More Information

If the basic filtering does not meet your needs, you can create an advanced filter which allows you to group your filters for a more granular, precise filtering criteria. For more information, refer to Create an Advanced Filter.

On the Tenants page there are multiple fields available to use for basic filtering of primary tenants. The fields are divided into multiple sections. Each field is described within the corresponding section below.

General Information

This section contains fields for filtering tenants by information that can be found primarily on their detail pages.

In the Search Options field, select whether the filtered tenant list includes results for tenants based on whether the relevant information Contains your filter criteria or Begins With the your filter criteria.

For example, if you are filtering tenants based on Zip codes that start with 4, you can select Contains to display all tenants whose zip code has the number 4. Alternatively, if you select Begins With, you see results only for tenants whose zip code starts with the number 4.

The available filter fields are described in the table below.

Field Description

Account Name

The name of the tenant's account as entered on the General tile.

Account #

The number generated by Rent Manager for the account as shown on the tenant's scoreboard.

City

The Default city as listed on the tenant's Address tile.

Comment

Additional information relating to the tenant, if any, as entered on the Comments tile.

Default Phone

The phone number selected as Default for the tenant as found on the Contacts tile.

Display

The Display Color selected on the tenant's Miscellaneous tile.

Email

The tenant's email address as entered on the Contacts tile.

Employer

The name of the tenant's employer as entered on the View Contacts page.

First Name

The tenant's first name as entered on the General tile.

Include Inactive Contacts

Includes any contacts in the search results that meet the filter criteria, even if the Active checkbox for that contact is unchecked.

Last Name

The tenant's last name as entered on the General tile.

Leasing Agent

The user listed as the tenant's leasing agent as selected on the Miscellaneous tile.

License

The license plate number of the tenant's vehicle as entered on the View Contacts page.

Property

The name of the property associated with the tenant as selected on the General tile.

The Search Options field does not affect this filter option.

Property Group

A group of two or more properties that exist in your Rent Manager database.

The Search Options field does not affect this filter option.

State

The Default state name as listed on the tenant's Addresses tile.

Street

The Default street name as listed on the tenant's Addresses tile.

Subsidy

The financial assistance offered to qualifying tenants.

Vehicle

The make and/or model of the tenant's vehicle as entered on the View Contacts page.

Zip

The Default zip code as listed on the tenant's Addresses tile.

Lease Information

This section contains fields for filtering tenants by their most recent lease information located primarily on the View Leases page.

The available filter fields are described in the table below.

Field Description

Exclude Assets

Exclude tenants in the search results that are linked to rentable asset leases.

Exclude ORI

Exclude tenants in the search results that are linked to other rentable items (ORI) leases.

Expected MO

The date on which the tenant is expected to move out as entered on Lease Details page.

Lease End

The date on which the tenant's lease expires as entered on Lease Details page.

Lease Start

The date on which the tenant's lease started as entered on the Leases tile.

Move In

The date on which the tenant moved in as entered on their lease.

Move Out

The date on which the tenant is set to move out as entered on Lease Details page.

Notice

The date on which the tenant gave notice that they are moving out as entered on Lease Details page.

Unit Name

The name of the unit associated with the lease as selected on Lease Details page.

Unit Type

The type assigned to the unit listed on the lease.

Transaction Information

This section contains fields for filtering tenants by transaction information located on the tenant's View Transactions page.

The available filter fields are described in the table below.

Field Description

Balance Options

Filters tenants based on the current balance on the tenant account.

Click the drop-down arrow at the top right of the field to select a calculation option, then enter the value to compare.

For example, if you select > Greater than and enter 100 in the field, the filtered tenant list results display only tenants with a balance over one hundred dollars.

= Equals

Results equal to the entered value display.

<> Does not Equal

Results that do not equal the entered value display.

> Greater than

Results that are greater than the entered value display.

< Less than

Results that are less than the entered value display.

>= Greater than or equal to

Results that are greater than or equal to the entered value display.

<= Less than or equal to

Results that are less than or equal to the entered value display.

Check #

Filters tenants based on the Reference # of a tenant payment.

Optionally, check Exact Match to display only tenants with a payment reference number that matches your entered criteria exactly. For example, if you enter 123, then the list results are filtered to display only tenants with payment reference numbers of exactly 123. If this option is unchecked, the results include tenants with payment reference numbers that contain 123 anywhere in the field, such as 1234 or 51236.

Open Charges Older Than X Days

Filters tenants based on how long their open charges have not been paid in full.

Other Filters

This section contains additional fields for filtering the tenant list, such as filtering by user defined fields or phone numbers.

The available filter fields are described in the table below.

Field Description

Eviction Outcome

Select the eviction outcome(s) to view only tenants who entered the eviction process that resulted in one of the selected outcomes. For more information, refer to Eviction Outcomes (Page).

Eviction Stage

Select the eviction stage to view only tenants currently associated with the stage.

Phone Number Type

First, select the phone number type in which to search, then in the Phone Number field to the right, enter a full or partial phone number to filter the results. Only tenants that meet the filter criteria for the selected phone number type display.

User Defined Field

Select a tenant-type UDF from the list by which to filter tenants. Then in the Value field, enter or select the information to narrow your results to tenants that meet the entered criteria.
