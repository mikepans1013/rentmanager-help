Subsidy Details (Pop-Up)

A subsidy is a form of financial assistance offered to qualifying tenants. The most common subsidy examples are HUD, Section 8, and FEMA. On the Subsidies Details pop-up, you can view and manage a subsidy's information and add or remove tenants who receive financial aid from the subsidy.

Related Privileges

Group Privilege Column
Subsidies Manage View, Edit

For more information, refer to Control User Access.

To view the details of a subsidy, go to arrow_forward Rental Info arrow_forward Rental Info Setup arrow_forward Properties/Units arrow_forward Subsidies and select a subsidy from the list.

Details

This tile includes the following fields:

Field Description

Name

The name of the subsidy used for the payment (e.g., Housing and Urban Development, Section 8).

Short Name

An abbreviated name for the subsidy (e.g., HUD, FEMA).

Payment From

The name of the person, organization, or program providing the subsidy payment.

Charge Type

The charge type that is paid through this subsidy for qualifying tenants.

Preallocate payments to the Subsidy Charge Type

Prevents subsidy payments from being automatically applied to open charges other than the associated Charge Type.

Subsidy Tenants

This tile displays a list of tenants, and their associated property, who receive financial aid from this subsidy. The Tenant drop-down list populates with every tenant that has the selected Property set as its Default Property.

More Information

Only information related to the properties to which you have access displays. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property.
