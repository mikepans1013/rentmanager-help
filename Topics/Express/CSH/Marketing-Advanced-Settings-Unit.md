# Unit Marketing Advanced Settings (Pop-Up)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Marketing-Advanced-Settings-Unit.htm

The internet listing service (ILS) marketing integration allows you to create online listings for the available units in Rent Manager and push those listings to ILS providers such as Zillow, Trulia, and HotPads. The Advanced Settings pop-up allows you to more specifically describe your units.

 To record more specific marketing information, go to arrow_forward Rental Info arrow_forward General arrow_forward Units and select a unit from the list. Then, on the action bar to the right, click arrow_forward Marketing Setup . From the Marketing Setup pop-up, click Advanced .

 More Information

 Rent Manager 's ILS postings are generated using the MITS file format, which is the industry standard for syndicating available units and properties. As many ILS sites no longer accept marketing data for individual units, it is strongly recommended that you utilize property-level marketing and convert any existing unit-level marketing data.

 If you have not converted your unit configuration to a property configuration, the Marketing Setup pop-up displays a message prompting you to use Property Marketing Configuration Wizard . Once you convert to a property configuration, it cannot be reversed. For more information, refer to Marketing Configuration Wizard (Pop-Up) .

 Feed Information

 This section allows you to input the information that is included in online unit listings, including the ILS feed type, property marketing name, and virtual tour URL. Use the drop-downs to select an existing Rent Manager field or manually enter a value in the fields below.

 Field
 Description

 Feed Type

 Indicate if the unit's property contains Multi Family or Single Family listings to categorize the ILS sites to which this unit is marketed. This field automatically populates based on the Property Type set on the details page of the unit's associated property. For more information, refer to ILS Marketing Feed Types .

 Warning

 This field is required by ILS sites. If left blank, your listing is rejected.

 Property Type

 The category that best describes the type of unit you are marketing. If you do not specify a category, this field automatically populates based on the Property Type set on the details page of the unit's associated property.

 Rental Type

 Specifying a rental type determines if ILS sites post the unit on multiple sites. For example, if you select Student , providers know to post to the listing on student housing sites.

 Click the drop-down arrow and leave the rental type unspecified, or choose the type of housing this unit supports.

 Marketing Name

 The name used on ILS sites to promote your unit. Enter a name or select an option from the drop-down list to determine the marketing name.

 Listing URL

 The URL at which the unit is listed, such as your property management company's website. This URL displays on ILS sites to provide more exposure.

 Virtual Tour URL

 The URL at which a virtual tour is available so that prospects can see the unit from an ILS site.

 Latitude

 The latitude coordinates of the unit to specify the exact location of your listing and make GPS directions easier to obtain.

 Longitude

 The longitude coordinates of the unit to specify the exact location of your listing and make GPS directions easier to obtain.

 Rental Classification

 The rental classification is assigned a default value based on the Property Type set on the details page of the unit's associated property. If the Rental Classification defaults to Unspecified , select an option from the drop-down list that further specifies the unit you are marketing. For example, you can distinguish different kinds of student housing by selecting Apartment , Campus , House for Rent , and so on.

 This information is used by some ILS providers to match units with specific rental categories as closely as possible.

 Agent Information

 In this section, enter the leasing agent's First Name , Last Name , Email Address , and Phone Number . Use the drop-downs to select an existing Rent Manager field or manually enter a value. Use this section to provide ILS sites with agent information that prospects can use to inquire about the unit.
