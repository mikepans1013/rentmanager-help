Violation Details (Page)

The Violation details page allows you to escalate a violation, add history/note items, write letters, and view attachments.

Related Privileges

Group Privilege Column
Tenants/Prospects Violations View, Edit

For more information, refer to Control User Access.

To view the details of a violation, go to arrow_forward Rental Info arrow_forward General arrow_forward Violations and select a violation from the list.

Violation Details

The Violation Details tile displays information about the violation including a description of the infraction and what the tenant needs to do in order to resolve the violation.

Field Description

Violation Date

The date of the infraction occurred or was reported.

Close Date

If applicable, the date the Closed field is checked.

Closed

When checked, the violation is removed from the Violations page, unless the Closed filter is enabled. The violation remains associated with the tenant and if the tenant be linked to another infraction, it displays on the Violation History for Tenant tile.

CC&R Reference

The reference number in the Covenants, Conditions, and Restrictions (CC&R) or similar regulatory document which precedes the text of the code, such as 6.1.2 - Unauthorized Vehicles.

Description

A description of the code or rule.

Action to Resolve

The actions the tenant must take to remedy the violation specific to the code associated with the violation.

Internal Notes

Instructions intended to assist users specific to the code associated with the violation, such as if any code specific paperwork must be done before the violation can be closed.

Violation Image

The Violation Image tile allows you to upload an image related to the violation. Drag an image to the center section, or click to browse your computer for a file to attach to the note.

Stage Information

Violation stages are escalated penalties or actions that apply when time passes on outstanding violations. The Stage Information tile displays information regarding the current stage associated with the violation.

More Information

The Stage Information tile displays information as of the time the violation was created. Any changes made to violation stages are available only on violations created after the changes were made.

Field Description

Current Stage

The stage that the violation is currently escalated to.

Next Stage

The name of the next stage to be applied if the violation is escalated. If there is no further stage, None displays.

Due Date

The date by which the tenant needs to remedy the situation or the violation is escalated to the next stage.

Comm Sent

Signifies correspondence was sent for the current stage of this violation. The date and time of when the field was checked displays. When you hover your cursor over the field, the date, time, and user who sent the communication displays.

More Information

When you use on the Violation details page or Write Letter on the Violations listing, the Comm Sent field is automatically checked. If the violation is escalated, the field is automatically unchecked until new correspondence is sent.

Internal Actions

The actions that need to be taken by an internal employee or Rent Manager user at this escalation level, such as Send the tenant a reminder of the HOA rules.

Actions Confirmed

Indicates that the Internal Actions are completed.

History/Notes

The History/Notes tile displays the most recent history/note item on the violation. History/note items let you record information that supplements or clarifies what’s entered in other fields, such as notes about escalation stages, actions completed, and communication with the tenant.

Column Description

Date

The date the note was created.

Type

The system-generated history/note type. For example, if the history/note is linked to an escalation , the Violation Stages type displays.

Note

The information to describe the history/note (e.g., Decorations were still up after Easter). If no text is entered, the column displays blank.

Violation History For Tenant

The Violation History For Tenant tile displays information about previous violations associated with the tenant.
