# Applications (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Applications.htm

Rent Manager allows you to track electronic applications submitted by prospects. If you use the Web Template Suite or the Web Portal Suite for Apply Now , those electronic applications are automatically imported to your Rent Manager database. You may then decide to use that application to create a new (or update an existing) prospect or tenant record. If you use ePay to accept application fees, Rent Manager automatically creates a prospect account for your applicants.

 More Information

 This feature is licensed and must be purchased separately. For more information, contact your sales representative at sales@rentmanager.com .

 Filter Options

 The following filtering options are available on this page.

 Option
 Description

 Application Date

 Select or enter the From and/or To dates to filter applications created during the selected date range.

 Include associated applications

 Check to display applications that are associated with an existing prospect or tenant record.

 Saved Filters

 Select a previously-saved filter from the list. Alternatively, click to set up a new advanced filter. To save the advanced filter for future use, click Save And Apply .

 Search

 Enter a phrase to filter the applications to only display results that match your criteria.

 Status

 Filter applications by one of the statuses as listed below.

 Canceled

 The application (and any sub-applications) was manually canceled by a Rent Manager user.

 Completed

 The selected applicant submitted their completed application.

 In Progress

 At least one applicant created an Apply Now account, but not all applications or sub-applications are submitted.

 Unable to Verify Identity

 At least one applicant has failed the ID verification after three attempts or if, on the ID Verification pop-up, My information is correct was selected after submitting a failed ID verification attempt.

 Column Descriptions

 The following columns are available on this page. By default, some columns display only if added via .

 Default Column
 Description

 Account Name

 If a Rent Manager account was created, the name of the prospect account.

 Date Created

 The date the application was submitted.

 Name

 The name of the applicant.

 Phone

 The phone number of the applicant.

 Property Short Name

 The abbreviated name of the property to which the application was submitted, as displayed in the property details page's General tile.

 Available Column

 Description

 Amount Charged

 The amount of application fees that were charged.

 Amount Paid

 The amount of application fees that have been paid.

 Application Template

 The name of the primary application template sent to the applicant.

 Completed

 The number of applicants that have completed their application or sub-application, displayed in the following format:

 Number of Completed Applications of Total Applications Sent

 Date Completed

 The date the primary application or last outstanding sub-application was submitted.

 Last Updated Date

 The date that any associated application was most recently updated by an applicant.

 Leasing Agent

 The name of the applicant's Leasing Agent , as displayed in the prospect details page's Lead Information tile.

 Property

 The Full Name of the property to which the application was submitted, as displayed in the property details page's General tile.

 Prospect Status

 The account status ( Prospect , Tenant , Lost/Rejected , or Lost ) of the applicant.

 Screened

 Displays Yes when all applicants and sub-applicants have been screened. If one or more applicants has not been screened, this displays No .

 Status

 One of three statuses may display: Not Started , In Progress , or Completed .

 Not Started

 No applicant(s) have created an Apply Now account.

 In Progress

 At least one of the applicant(s) has created an Apply Now account, but not all applicants have completed their applications.

 Completed

 All applicant(s) have completed their applications.

 Total Applications

 The total number of applications emailed to the primary applicant and their co-applicant(s).

 Web User List

 The email addresses of the applicants who were sent applications, and created an Apply Now account, separated by commas.

 If no Apply Now account has been created by the applicant yet, their email address does not display here.
