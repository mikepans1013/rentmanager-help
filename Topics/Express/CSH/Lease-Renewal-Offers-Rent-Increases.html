Renewal Increases (Page)

The Renewal Increases page allows you to track tenants with leases that have an approaching Lease End date within a specified number of months. This window is also where you can manually set and approve rent increases, which are used when generating renewal offers, to provide a workflow allowing you to manage expiring leases and rent increases on one page

Related Privileges

Group Privilege Column
Tenants/Prospects Set Renewal Rent Increases Enabled
Approve Renewal Rent Increases Enabled

For more information, refer to Control User Access.

To view the Renewal Increases page, go to arrow_forward Rental Info arrow_forward Leasing arrow_forward Renewal Increases.

Expiring leases in the list that have Set rent increases display yellow amounts in the New Rent column, while expiring leases in the list that have Approved rent increases display green amounts in the New Rent column.

As you set or approve rent increases, a count displays in the top left of the page for the number of records that are Not Set, Set, and Approved.

Related Preferences

The Approved count displays only if the Require approval of renewal rent increases before sending offer option is enabled in system preferences. For more information, refer to Lease Renewals (System Preferences).

Filters

The following filter options are used to display expiring leases on this page.

Filter Description

Properties

Select the properties or a Group of properties to include in the list. By default, <All Properties> is selected.

More Information

This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property.

Lease Expiration From/To

Select a date range to display tenants with leases ending during that time period.

Status

Check each desired renewal increase status to be included in the list (Not Set, Set, Approved). By default, all statuses are selected.

Column Descriptions

The following columns are available on this page. To customize the columns that display on the page, click .

Default Column Description

Tenant

The name of the tenant whose lease is expiring.

Property

The property at which the unit or rentable asset associated with the lease is located.

Unit

The unit or rentable asset that the tenant is leasing.

Unit Type

The unit or asset type associated with unit or rentable asset that the tenant is leasing.

Lease End

The date on which the lease officially ends.

Lease Term

The lease term (e.g., 6 Months, 12 Months, 18 Months, and so on) associated with the lease.

Market Rent

The market value of the unit or rentable asset the tenant is leasing as specified on the unit or asset's details page.

Current Rent

The total dollar amount of the tenant's current recurring charges using any charge type(s) specified on the associated property's details page as a Rent Charge Type.

New Rent

If an increase is set, the total dollar amount of the tenant's recurring charges for the lease renewal using a Rent Charge Type. Otherwise, the column is blank.

% Change

If an increase is set, the percent change between the amount of the Current Rent and the New Rent. Otherwise, the column is blank.

Status

The status of the lease renewal increase (Not Set, Set, or Approved).

Available Column

Description

Address

The address marked as Default on the associated unit's details page. For rentable assets, this column displays blank.

Approved

A displays if the renewal increase was approved.

Related Preferences

The Approved column displays only if the Require approval of renewal rent increases before sending offer option is enabled in system preferences. For more information, refer to Lease Renewals (System Preferences).

Approved By

The Username of the user who approved the renewal increase.

Related Preferences

The Approved By column displays only if the Require approval of renewal rent increases before sending offer option is enabled in system preferences. For more information, refer to Lease Renewals (System Preferences).

Approved Date

If applicable, the date the renewal increase was approved in MM/DD/YYYY format.

Related Preferences

The Approved Date column displays only if the Require approval of renewal rent increases before sending offer option is enabled in system preferences. For more information, refer to Lease Renewals (System Preferences).

Charge Type

The type of recurring charge that is being increased.

Display Color

The color to help identify the associated tenant.

Lease Start

The date on which the lease officially starts.

Leasing Agent

The name of the tenant's leasing agent.

Loss to Lease

The amount of possible income lost or gained as a result of leasing the unit or rentable asset to a tenant. Loss to lease is determined by taking the Market Rent and then subtracting out the New Rent.

Owner

The name of the property's owner at which the tenant's leased unit or rentable asset is located.

Pet Age

The age of the pet associated with the tenant.

Pet Breed

The specific group of animals the tenant's pet belongs to.

Pet Color

The color of the pet associated with the tenant.

Pet Description

An optional message about the pet (e.g., Does not play well with other dogs).

Pet Name

The name of the pet associated with the tenant.

Pet Type

The kind of animal, such as a dog or cat, allowed at the associated property.

Pet Weight

The weight of the pet associated with the tenant.

Set By

The Username of the user who set or the renewal increase.

Related Preferences

The Set By column displays only if the Require approval of renewal rent increases before sending offer option is enabled in system preferences. For more information, refer to Lease Renewals (System Preferences).

Set Date

If applicable, the date the renewal increase was set in in MM/DD/YYYY format.

Related Preferences

The Set Date column displays only if the Require approval of renewal rent increases before sending offer option is enabled in system preferences. For more information, refer to Lease Renewals (System Preferences).
