Prospect Stage History (Pop-Up)

Prospect stages track the progression of prospects through the leasing process. For example, you might create a stage called Guest Card for first contact with prospects, and another called Application Complete for prospects who apply to one of your properties. You can also use stages to search for prospect accounts and run prospect-related reports.

The prospect Stage History pop-up displays the prospect stages that have been entered on the prospect account, and information about each stage, including the stage name, the date and duration of the stage, and the Rent Manager user who assigned the stage to the prospect.

Column Descriptions

The following columns are available on this pop-up:

Column Description

Stage

The unique name for the stage (e.g., Guest Card, Application Sent, Application Completed, Property Tour, Awaiting Screening Report).

Date

The date and time the stage was assigned.

Duration

The amount of time the prospect was assigned to the stage.

User

The Username of the user who either manually set the stage, or initiated the trigger which set the stage. For example, if the default stage of Prospect Visit is set, the user who added the history/note item of the visit type is displayed.

More Information

If the stage was set by a prospect action (such as submitting an application or completing a signable document) this field displays blank.
