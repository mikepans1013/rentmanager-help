Manage Smart Bills Inboxes (Pop-Up)

The Rent Manager Smart Bills feature allows you to streamline your invoice management process. With this feature, you can easily upload invoices via a PDF or image format, allowing AI to extract the relevant data and create draft transactions automatically. The Smart Bills feature also includes an intuitive review process, allowing you to ensure the accuracy of transactions before posting them as actual bills. Additionally, vendors can send invoices in PDF format directly to a dedicated email inbox for seamless integration into the Smart Bills workflow. Inboxes can be added and modified using the Manage Smart Bill Inboxes pop-up.

Related Privileges

Group Privilege Column
Payables Smart Bills Inboxes View

For more information, refer to Control User Access.

To manage Smart Bills inboxes, go to arrow_forward Payables arrow_forward Bills arrow_forward Smart Bills and click Manage Inboxes.

Field Descriptions

The following fields display on the Manage Smart Bills Inboxes pop-up. To add a new inbox, click Add Inbox.

Field Description

Inbox Name

The name used to identify the invoices the inbox receives.

Email Options

The following related fields are available the Email Options section.

Email Prefix

A unique name that is added to the beginning of the email address and is used to identify emails from specific vendors who send their invoice PDFs to a specific email address.

Email Address

Vendors send invoice PDF files to this email address to be automatically turned into Smart Bills.

User Options

The following related fields are available in the User Options section.

Users

The users that can access the inbox.

Forward a copy of all emails from the inbox to

The email address to receive a copy of emails received by the Smart Bills inbox. This can be helpful for monitoring emails sent to the wrong email address or are not converted into smart bills.

Default Property

The property to be listed on Smart Bills that do not find a matching property when uploaded. Select Use this property on all Smart Bills to this inbox to use the selected property on all received Smart Bills.

Comment

An option message that can be entered to describe the purpose of the inbox. Information entered in this field does not display anywhere else in Rent Manager.
