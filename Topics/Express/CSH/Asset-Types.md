# Asset Types (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Asset-Types.htm

Asset types are categories assigned to assets to provide additional information and filter asset lists by type. Creating asset types and then assigning an asset to a type as part of asset management also helps you run reports on assets based on the selected type. For example, having asset types assigned allows you to run an Asset Depreciation Schedule report or an Overdue Asset Maintenance report only for the specific asset types you designate.

 Name

 The name of the asset type (e.g., Dishwasher , Disposal , Furnace , and so on). Asset types can also be designated as home-type assets (e.g., Multi-Section , Single-Section , and so on).

 Additional information about when to use this type of asset.

 Is Home

 A displays when assets of this type are designated as home-type assets.

 More Information

 If the Automatically create a lease for linked 'home' assets or units option is enabled in system preferences, and on a lease, you select a unit that is linked to an asset with an asset type that has the option Assets of this type are homes enabled, an additional lease is automatically generated. For more information, refer to General Options (System Preferences) .

 The predetermined workflow this asset type follows.
