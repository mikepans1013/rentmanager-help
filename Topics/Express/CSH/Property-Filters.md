# Property Filters (Pop-Up)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Property-Filters.htm

Property filters allow you to quickly narrow your search results to get to the property information that you really need to see. Rent Manager gives you the ability to choose from a variety of filtering options that you can use to sort your properties on the Properties page.

 Rent Manager allows you to create filters that can be used temporarily, or saved to use repeatedly. Additionally, they can be saved on a system level for all users, or on a personal level where only your user account can access it. Before saving your filter, enter a Name , and, optionally, a Description to remind you of the filter's purpose.

 More Information

 If the basic filtering does not meet your needs, you can create an advanced filter which allows you to group your filters for a more granular, precise filtering criteria. For more information, refer to Create an Advanced Filter .

 There are multiple fields available to use for basic filtering of properties on the Properties page. The fields are divided into multiple sections. Each field is described within the corresponding section below.

 General Information

 This section contains fields for filtering properties by information that can be found primarily on the details page of the property.

 In the Search Options field, select whether the filtered property list includes results for properties with information that Contains or Begins With the data you input into one or more fields.

 For example, If you are filtering properties based on zip codes that start with 4 , and select Contains , your filtered list shows results for all properties with zip codes that have the number 4 in them. Alternatively, if you select Begins With , you see results only for properties with zip codes that start with the number 4 .

 Other Filters

 This section contains additional fields for filtering the property list, such as filtering by user defined fields or property groups. This information can be found primarily on the details page of the property.

 The available filter fields are described in the table below.

 Field
 Description

 Charge Type

 The name of the charge type that can be found on the property Other Information tile.

 Default Bank

 The operating bank account for the property as found on the Other Information tile.

 ePay Enabled

 Includes properties that have Enable ePay for this Property checked on the property ePay Settings pop-up.

 Owner

 The name of the owner which displays on the property Primary Owner card.

 Property Group

 A group of two or more properties that exist in your Rent Manager database. For more information, refer to Property Groups (Page) .

 Property Type

 The category of property, such as apartment or duplex, that best describes the property.

 Special Late Charge Enabled

 Includes properties that have Special Late Charge Enabled on the property Late Fees card.

 System Close

 The accounting period that determines when Rent Manager users are no longer able to add, edit, or delete transactions from the previous period. Depending on the System Close type that you select, additional fields may display.

 The following options are available for filtering properties by their system close status:

 Use system settings

 Properties that use the account close date as set in system preferences displays.

 No close

 Properties with no accounting close date display.

 Specific Date

 Properties that match the accounting close date entered in the Value field display.

 Monthly

 Properties with accounting close days and the effective days that match what is entered in the Closing Day field and the Effective Day field display.

 X days ago

 Properties that match how many days since the accounting close day entered in the Value field display.

 Yearly

 Properties with accounting close dates and the effective dates that match what is entered in the Close Date field and the Effective Date field display.

 Period Accounting

 Properties with accounting periods that match the series selected in the Series field and the number of days entered in the Effective After field display.

 User Defined Field

 A property-type UDF from the list by which to filter properties. Then in the Value field, enter or select the information to narrow your results to properties that meet the entered criteria.

 Unit Count

 The total number of units available at the property. The following filter options are available for filtering properties by their number of units:

 = Equals

 Results equal the entered value.

 <> Does not Equal

 Results do not equal the entered value.

 > Greater Than

 Results are greater than the entered value.

 < Less Than

 Results are less than the entered value.

 > = Greater than or equal to

 Results are greater than or equal to the entered value.

 < = Less than or equal to

 Results are less than or equal to the entered value.
