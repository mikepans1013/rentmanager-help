# My Layouts (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Layouts-My.htm

Personal layouts allow you to customize how the details page displays in select areas of Rent Manager Express , similar to custom tabs in Rent Manager 12 . Tiles can be added, deleted, or repositioned on your layouts to create a personalized experience that best suits your workflow. You can even create blank tiles to completely customize the content that displays.

 To add and manage your layouts, go to arrow_forward Administration , then go to Customization arrow_forward My Layouts . In the Layout Type section on the left, select the desired type.

 Column Descriptions

 The following columns are available on this page:

 Column
 Description

 Name

 The unique name used to identify the layout.

 User Default

 A displays on the default layout for each Layout Type on your user account.

 Type

 The type that indicates if the layout can be customized. Each option is described below.

 Standard

 A Rent Manager default layout. This layout type cannot be edited or deleted, but can be copied to a new Personal layout.

 System

 A system layout available to select users. This layout type can directly be edited or deleted only from the System Layouts page. Clicking a system layout prompts you to create a copy of the layout that is saved as a Personal layout.

 Personal

 A user-created layout that can be customized directly from the My Layouts page.

 Row Actions

 The following row actions are available from the menu:

 Option
 Description

 Make Default

 Set the default layout for the selected entity. Only one layout can be considered the default. A displays on the default layout for each Layout Type on your user account. To change the default layout, select a different layout and click arrow_forward Make Default .

 Edit

 Customize the personal layout.

 Copy

 Copy the layout as a new, editable layout. This is an efficient way to make minor changes to an existing layout's structure without starting from a blank template.

 Export

 Save the layout as a file that can be stored on your computer outside of Rent Manager . You may wish to export a layout to keep a backup copy stored locally, share with a coworker, or move it to a different Rent Manager  location.

 Export to Online Template Library

 Make your layouts available to other Rent Manager users via the Online Template Library .

 Delete

 Delete the personal layout.
