# Unit Type Filters (Pop-Up)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Unit-Type-Filters.htm

Unit type filters allow you to quickly narrow your search results to get to the unit type information that you really need. Rent Manager gives you the ability to choose from a variety of filtering options to sort your unit types on the Unit Types page.

 Rent Manager allows you to create filters that can be used temporarily, or saved to use repeatedly. Additionally, they can be saved on a system level for all users, or on a personal level where only your user account can access it. Before saving your filter, enter a Name , and, optionally, a Description to remind you of the filter's purpose.

 To create unit type-specific filters from the Unit Types page, click .

 More Information

 If the basic filtering does not meet your needs, you can create an advanced filter which allows you to group your filters for a more granular, precise filtering criteria. For more information, refer to Create an Advanced Filter .

 On the Unit Types page there are multiple fields available to use for basic filtering of unit types. The fields are divided into multiple sections. Each field is described within the corresponding section below.

 General Information

 This section contains fields for filtering unit types by information that can be found primarily on their detail pages. For example, if you are filtering unit types that are only available at a specific property, you can select the desired property in the Property Name field.

 The available filter fields are described in the table below.

 Field
 Description

 Bathrooms

 The number of bathrooms associated with the unit type.

 Bedrooms

 The number of bedrooms associated with the unit type.

 Description

 Additional information used to describe the purpose of the unit type. For example, if the unit type represents studio apartments, enter Studio apartments only .

 Property Group

 The group of properties associated with the unit type.

 Property Name

 The name of the property associated with the unit type.

 Unit Type Name

 The name of the unit type as it is displays on the Unit Types page in the Name column.
