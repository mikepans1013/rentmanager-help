Site Classification History (Pop-Up)

For manufactured housing-type properties, units (or sites) are assigned site classifications based on the site's legal owner, whether the site can be rented, the occupancy status, and the type of asset(s) and/or resident-owned RV present on the lease. A new site classification may be assigned if one or more of these conditions change, and any classification changes and the date they occurred can be tracked on a unit's Site Classification History pop-up.

To more closely match your home management workflow, you can rename homeowner statuses and their associated site classifications for a more tailored classification system. Additionally, you can deactivate homeowner statuses that may not be relevant to your home management workflow. For more information, refer to Homeowner Statuses & Site Classifications.

More Information

Site classifications cannot be manually changed by users and are updated automatically by Rent Manager. For more information on site classifications and the conditions that determine those classifications, refer to Site Classification.

Add Site Classification

Related Privileges

Group Privilege Column
Properties/Units Manual Entry Site Classifications Enabled

For more information, refer to Control User Access.

If the unit's associated property does not have site classifications set automatically, the Set Site Classification option displays at the top right of the pop-up, allowing you to manually assign a site classification to this unit.

To manually assign a site classification to the unit, do the following:

  1. Click Set Site Classification.
    The Set Site Classification pop-up displays.

  2. In the Site Classification field, select a classification from the drop-down list. For more information on the list of classifications that display, refer to Site Classification.

  3. In the Start Date field, enter the date on which the classification assignment begins. By default, the current date populates.

  4. Click Save.
    The site classification is manually assigned to the unit.

Row Actions

Row actions, which are available from the menu to the right of each site classification, affect only the selected classification.

Action Description

Delete

Remove the site classification assignment from the unit's history. The unit's first site classification assignment cannot be removed. This action does not delete the site classification from Rent Manager.

Details

View or edit information regarding the unit's site classification assignment.

Column Descriptions

The following columns display on the pop-up:

Column Description

End Date

The final date that the site classification is active for the unit.

Name

The homeowner status assigned to the unit during the date range.

Start Date

The first date that the site classification is active for the unit.

User

The Rent Manager user that manually assigned the site classification to the unit. If the site classification was automatically assigned by Rent Manager, this column is blank.
