Document Packets (Page)

Document packets allow you to send multiple letter templates bundled together. To save time sending out individual documents that are commonly sent at the same time, such as a move-in welcome packet, you can create a document packet that contains both letter templates and signable templates that can be sent all together.

Related Privileges

Group Privilege Column
Letter/Email Templates/Reports/Packets Letter/Email templates/packets View
Entity templates/packets View

Specific Entity templates/packets privileges must be enabled to access each entity type's document packets (e.g., Owner templates/packets).

For more information, refer to Control User Access.

To view and manage your document packets, go to  arrow_forward Communication arrow_forward Signable Documents arrow_forward Document Packets.

Column Descriptions

The following columns display on this page.

Field Description

Create Date

The date the document packet was created.

Description

Additional information used to described the document packet (e.g., Lease packet for new tenants).

Document Type

The types of documents that are included in the document packet. For example, a tenant-type document packet can only contain tenant-type letter templates.

Name

The name of the document packet.

Packet Type

The type of packet, General, Lease, or Contract. For example, the Lease packet type is specific to tenants and is recognized by Rent Manager as an electronic lease.

Properties

The document packet can be sent to entities associated with the properties selected on the document packet's details.

Update Date

The date the document packet was last updated and saved.

Users

The Rent Manager users who can access and send the packet.
