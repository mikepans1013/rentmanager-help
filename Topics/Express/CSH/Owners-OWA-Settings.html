Owner Web Access Settings (Pop-Up)

The Web Access Settings pop-up allows you to view and manage an owner's web user account in order to enable or disable their Owner Web Access (OWA) account, assign or reset OWA credentials, provide individualized OWA messages, and remove OWA account lockouts.

Related Privileges

Group Privilege Column
Owners Owners View, Edit

For more information, refer to Control User Access.

To view the Web Access Settings pop-up, go to arrow_forward Owners arrow_forward General arrow_forward Owners and select an owner from the list. Then, on the action bar to the right, click arrow_forward OWA Settings.

Owner Information

The following fields display in the Owner Information section.

Field Description

Account #

The system-generated ID for the owner account in Rent Manager.

Message to show to Owner

An individualized message that displays on the owner's OWA dashboard.

Name

The name of the primary owner associated with the web account.

Web Users

The following columns display in the Web Users section.

Column Description

Enabled

Indicates that the owner can log in and out of OWA. You can uncheck this box to prevent the user from logging in to OWA while retaining all of their saved information. The account remains inactive until the Enabled box is checked again.

If the account is disabled, an owner can create a new account with a different email address.

Last Failed Login

The date and time of the owner's last unsuccessful login attempt to OWA.

Last Lockout

The date and time of the owner's last lockout, in which they exceeded the number of allowed login attempts as established in system web preferences. For more information, refer to Owner Web Access General (System Web Preferences).

Last Login

The date and time that the owner last successfully logged in to OWA.

Subscription Status

 

Username

The email address that is the owner's OWA username.

Row Actions

The following row actions are available from the menu in the Web Users section.

Option Description

Change Password

Send an email to the web user allowing them to reset their account password. The password recovery email is sent to the email address displayed in the corresponding row.

Delete

Permanently remove the web user account and prevent them from accessing OWA.

Related Preferences

If the system web preference to Allow Owner to Create Accounts is enabled, the user can still create a new OWA account. For more information, refer to Owner Web Access Accounts (System Web Preferences).

Manage Email Subscriptions

View and manage the email subscription settings to ensure your company is honoring the web user's preferences and following email compliance standards. For more information, refer to Unsubscribe From Emails.

Remove User Lockout

Remove the lockout for a web user who has entered an incorrect password too many times, allowing them to try logging in again.

This option displays only for users who are locked out of their account after exceeding the number of Failed Login Attempts Until Lockout established in the system web preferences. For more information, refer to Owner Web Access General (System Web Preferences).

Resend Verification Email

Send a new verification email to the web user's email address, rendering the prior verification email(s) unusable.

This option displays only for a web user that has not yet completed the account creation process.

Update Username

Reset the email address for the web user's OWA account. For additional account security, check Require email and password reset for this web user to force the user to confirm their old password and select a new one before accessing their account.

Owner Settings

If you wish to override the settings selected in Owner Web Access system web preferences for this owner, check the Override System Defaults option in the section header. Once checked, the section can be customized for the selected web owner account.

Show Ownership Information

Set these options to determine what an owner can see in Owner Web Access related to the financial information for properties in their portfolio, such as balances and security deposits.

Option Description

Balance

Allows the owner to view their portfolio bank balances.

Security Deposits

Allows the owner to view the amount of security deposit dollars held for each property in their portfolio.

Percentage

Allows the owner to view the ownership percentage of each property in their portfolio.

Reserve

Allows the owner to view the amount of reserves for each property in their portfolio.

Show Page Visibility

Set these options to determine what pages display in when owners log in to Owner Web Access.

Option Description

Reports

The Reports page displays, which allows owners to run the reports enabled below for Report Privileges.

Notes

The Owner Web Access Notes menu displays to allow owners to see history/note items from their owner account, along with associated properties, units, and tenants.

Contributions

The Make Contribution page displays, which allows owners to make contributions using Zego ePay.

Show Financial Information

Set these options to determine what an owner can see in Owner Web Access related to their financial portfolio, such as bills and checks.

Option Description

Ownerships

Ownership information displays on the dashboard. Ownership information includes the property name, ownership percentage, reserve amount, security deposits held, and ownership bank balance.

Management Fees

Management fees postings display from the last 90 days on the dashboard and provides a Management Fees listing that the owner may filter. Management fees information includes ownership, date range, fee date, pass-through amount, and fee amount.

Checks

Check information displays from the last 90 days on the dashboard and provides a Checks listing that the owner may filter. Check information includes ownership, date range, reference (such as the check number), check date, vendor, comment, and dollar amount.

Bills

Bill information from the last 90 days that expense properties and/or units in the owner's portfolio displays on the dashboard and provides a Bills listing that the owner can filter. Bill information includes the associated vendor, ownership, date range, bill date, due date, whether it is paid or unpaid, and dollar amount.

Owner Checks

Owner check disbursements from the last 90 days display on the dashboard and provide a Owner Distributions listing that the owner may filter. Owner distribution information includes the ownership, date range, reference, check date, and amount.

Bill Attachments

Allows owners to view attachments linked to bills. To view an attachment, the owner clicks a bill on the dashboard and then clicks the attachment link on the detail page.

Passthru Fees

The pass-through fee amount displays on the Management Fees register. Pass-through fees are management fees that re specified to be passed directly to the management company. They typically do not display on owner reports.

Service Issues

Set these options to determine what issues display in Owner Web Access.

Option Description

Open

Allows the owner to view any open service issues that are linked to entities within their portfolio.

Exclude Tenant Information

Prevents the owner from viewing information about any tenant linked to an issue.

Closed

Allows the owner to view any closed service issues that are linked to entities within their portfolio.

Exclude Vendor Information

Prevents the owner from viewing information about any vendor linked to an issue.

Report Privileges

Override the report selections in Owner Web Access system web preferences and select each report the owner should be allowed to view in Owner Web Access.
