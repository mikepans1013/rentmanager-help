# Subsidies (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Subsidies.htm

A subsidy is a form of financial assistance offered to qualifying tenants. The most common subsidy examples are HUD, Section 8, and FEMA. A single subsidy payment can pay off charges on multiple tenant accounts.

 Column Descriptions

 The following columns display on the page.

 Column
 Description

 Name

 The name of the subsidy used for the payment (e.g., Housing and Urban Development , Section 8 ).

 Short Name

 An abbreviated name for the subsidy (e.g., HUD , FEMA ).

 Payment From

 The name of the person, organization, or program providing the subsidy payment.

 Charge Type

 The charge type that is paid through this subsidy for qualifying tenants.

 Tenants

 The tenant(s) who receive financial aid from the subsidy.
