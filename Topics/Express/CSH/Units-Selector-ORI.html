Other Rentable Item (ORI) Unit Selector (Pop-Up)

The ORI Unit Selector allows you to view units with unit types marked as Other Rentable Item that are available for reservation and/or leasing in a defined date range. Once an other rentable item (ORI) unit is chosen, it can be selected and added to the field that opened the pop-up (e.g., ORI Unit).

Related Privileges

Group Privilege Column
Tenants/Prospects Tenants View, Edit
Prospects View, Edit

For more information, refer to Control User Access.

The ORI Unit Selector can be accessed from various areas of Rent Manager by clicking where you need to select an ORI.

Filter Options

The following filters are available on this pop-up:

Filter Description

Property

The property or properties whose ORI units should populate in the list.

Show Vacant Units Only

If checked, only ORI units that do not have an occupant or unavailable unit status in the selected date range display.

Vacancy Based On Date

The date range used to examine the ORI units' Status and determine whether or not they are vacant.

Column Descriptions

The following columns are available on this pop-up:

Column Description

Next Move Out

The current tenant's Move Out date, if applicable.

Next Occupant

The Move In date of the next scheduled tenant.

Property

The property at which the ORI unit is located.

Status

The number of tenants renting the ORI unit during the date range. If the unit is not rented during the date range and if no other tenants are scheduled to move in, Vacant displays.

Unit

The name of the ORI unit.

Unit Type

The category of the ORI unit.
