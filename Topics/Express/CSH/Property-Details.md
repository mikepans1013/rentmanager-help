# Property Details (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Property-Details.htm

You can use Rent Manager properties to track data for any financial entity that generates revenue and incurs expenses, including property management companies. Create properties for any real estate you manage, such as single-family homes, duplexes, apartment buildings, strip malls, storage facilities, and manufactured home sites.

 Properties are the highest level entity in Rent Manager . You can create and link other entities to properties, such as units and tenants. Units and tenants linked to a property inherit settings and charges set up at the property-level.

 From the property details page, you can access an overview of property information, update that information, and configure property-level settings.

 The following tiles display by default. If a custom layout is applied to your details page, you might not see all of the following tiles. For more information about creating and assigning layouts, refer to My Layouts (Page) and System Layouts (Page) .

 Images

 Displays property-type images in a carousel. To add an image, click or Upload Images . These images can be used for marketing your property on internet listing service (ILS) websites.

 General

 Information about the property and contact information for the property manager.

 Field
 Description

 Active

 When unchecked, this property is considered inactive, which means users cannot select or access this property in other areas of Rent Manager . ePay is also disabled for inactive properties.

 More Information

 If there are active leases at the property and you uncheck Active , a warning displays after clicking Save .

 The Move Out Date entered will be applied to all tenants with active leases at the property. After setting the date, click Save to make the property inactive and move out tenants.

 To make the property inactive without moving the tenants out, click Save without adding a date.

 Display Color

 A color to help identify properties of certain types, groups, or any other specifications you prefer. The color displays as a bar to the left of the property in some areas of Rent Manager , such as the Property list page.

 Email

 The email address for contacting the manager of the property. The email subscription status displays as (active), (partially unsubscribed), or (unsubscribed).

 To view and configure the subscription status for emails associated with the property manager's account, click Manage Subscriptions . For more information, refer to Unsubscribe From Emails .

 Full Name

 The complete legal name for the selected property.

 Manager

 The name of the person responsible for managing the property.

 Property Type

 The classification that best suits the property, such as Single Family or Apartment .

 Warning

 Changing the property type of an established property may result in the loss of some functions and/or changes to data.

 For example, if you change a property type to Short Term Rental or RV/Campground , leases are converted to reservations, and Move In and Move Out dates become Arrival and Departure dates.

 Short Name

 An abbreviated name for the property (ten characters or fewer) that displays on reports.

 Primary Address

 The addresses associated with this property, including any custom address types.

 For the address type that has the property's primary address, check Default . For the address type that has the property's address used for billing, check Billing . Click View on Map to view the address's location in Google Maps.

 Property Logo

 A visual logo to represent the property or company. Logos can be added to correspondence and marketing materials. Only one image can be used at a time.

 Additional information associated with the property, such as the property tax ID and square footage.

 Recurring Charges

 The active recurring charges that post to tenants of this property at specified intervals. Tenants inherit recurring charges set at the property level. You can add new recurring charges, including commercial recoverable expense (CRE) charges, from this tile.

 Field
 Description

 Amount

 The dollar amount of the recurring charge that posts to the tenant's account.

 Charge Type

 The charge type to be associated with this recurring charge.

 Comment

 A phrase or note to show on the View Recurring Charges page.

 Frequency

 The number of months, weeks, or days that should elapse between each posting of the recurring charge. For example, if a tenant has a Monthly rent period, a frequency of 1 means the recurring charge posts once every month, and a frequency of 3 means the recurring charge posts once every three months.

 From Date

 The first date on which this recurring charge is applied to the associated tenant accounts when recurring charges are posted.

 To Date

 The final date on which this recurring charge can be posted to the tenant's account. After this date, this recurring charge is no longer applied to the associated tenant accounts when recurring charges are posted.

 This tile displays the difference in the renewal rent amount between the original lease term and the newly selected lease term when offering lease renewals at this property.

 Column
 Description

 Duration

 The lease term duration in days, months, or years.

 Name

 The name of the lease term.

 Rent Offset

 The difference in the renewal rent amount between the original lease term and the newly selected lease term when offering lease renewals.

 For example, if the current base rent amount (without rent offset applied) is $1000, and they renew their lease for a lease term that has a -5% rent offset, 5% of the base rent amount ($1000) is subtracted from the base rent amount to get the new rent amount ($950) for the new term.

 New Term Rent Amount = Original Term Rent Amount +/– Rent Offset
