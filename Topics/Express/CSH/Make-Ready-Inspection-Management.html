Make Ready Management Inspection (Pop-Up)

The Make Ready page helps streamline the process of preparing vacant units for occupancy and provides an up-to-date visual representation of the unit turnover process. Rent Manager allows you to create management inspections that can be associated with any stage of the make ready process.

Related Privileges

Group Privilege Column
Properties/Units Make ready board View
Make ready process View, Edit
Inspections Inspections Add

For more information, refer to Control User Access.

To add a management inspection to a make-ready board process, go to arrow_forward Services arrow_forward Make Ready arrow_forward Make Ready Board. Then, on the desired process, click  arrow_forward Add Management Inspection.

Field Descriptions

The following fields are available on this pop-up.

Field Description

Action

The name of the action that needs to take place through the make-ready process being addressed by the inspection (e.g., Move Out Inspection, Turnover Activities, Maintenance/Repair, Re-Key Locks).

Inspection Description

More detailed information regarding the inspection being performed.

Inspection Type

The type of inspection being performed (e.g., Move Out).

Inspection Status

The condition that describes the current progress of the inspection, such as New or Opened.

Inspection Templates

The inspection form template to use for this inspection. To automatically use the inspection template selected on the associated unit's details page in the Inspection Template field, select <Unit Default>.

Inspector

The user who is performing the inspection, or ensuring the inspection is completed.

New Issues Action

The make-ready action to which any new service issues that were created as part of this inspection are assigned. Alternatively, if you do not want to link any issue(s) created from a make-ready inspection, select <Exclude from Make Ready>.

Notify when ready

If this option is checked, the user selected in the Inspector field receives a notification that the inspection is ready for them to start work. When the make-ready process is started, the associated inspections are created and the notification goes out to the inspector(s) at that time.

If the Enforce Action Sequence option is selected for the make-ready template, this notification instead goes out to the inspector(s) after all issues and inspections scheduled before their inspection are completed.

Scheduled Date Offset

The number of days from the inspection date that the inspection is scheduled to start work.

For example, if you enter 3 and the inspection is created with 10/16/2026 as the start date, the Scheduled date on the inspection is automatically set to 10/19/2026. If you enter 0, the Scheduled date is set to the same date as the make-ready start date.
