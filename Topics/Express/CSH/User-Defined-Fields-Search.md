# User Defined Fields Search (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/User-Defined-Fields-Search.htm

This page lets you search entities by user defined fields (UDFs) and their values. The search helps you find a specific value in one or more UDFs at once.

 Related Privileges

 Privileges determine what search results are visible and what further actions you can take. Depending on your user privileges, you may be able to open a new page, drill down from the results to specific pages, and perform certain additional actions.

 More Information

 Only information related to the properties to which you have access displays. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 To search for UDF values, go to arrow_forward Search arrow_forward User Defined Fields .

 Filter Options

 The following filter options are available on this page.

 Option
 Description

 Type

 The UDF types you wish to search through. To display all available UDF types in the search, select <All Available Types> .

 Name

 The names of the user defined fields associated with the Type selection. To display all available UDFs in the search, select <All Available Fields> .

 Containing

 Depending on the Name selection, enter the value or partial value for the UDFs to narrow the results. Depending on the Type associated with the UDF, search by the following:

 Field

 Search by keyword(s).

 Yes/No

 Search by a Yes or No value.

 Date Range

 Search by a date or date range.

 Drop-down list

 Search by an option from the list of available answers for the UDF.

 Numeric

 Search by a numeric value or amount.

 Column Descriptions

 The following columns display on the page.

 Column
 Description

 Entity Type

 The type of entity (e.g., tenant, prospect, property, unit, and so on) associated with the user defined field.

 Associated With

 The name of the entity associated with the particular user defined field value.

 Name

 The name of the user defined field.

 Value

 The value, if any, associated with the user defined field.
