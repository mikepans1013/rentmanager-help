Prospect Stages (Page)

Prospect stages track the progression of prospects through the leasing process. For example, you might create a stage called Guest Card for first contact with prospects, and another called Application Complete for prospects who apply to one of your properties. You can also use stages to search for prospect accounts and run prospect-related reports.

Related Privileges

Group Privilege Column
Tenants/Prospects Manage Prospect Stages Enabled

For more information, refer to Control User Access.

To view your list of prospect stages, go to arrow_forward Rental Info Setup arrow_forward Tenants/Prospects arrow_forward Prospect Stages.

Column Descriptions

The following columns are available on this page.

Column Description

Active

A displays if this stage is active and can be assigned to prospect accounts.

Name

The unique name of this stage.

Description

A short summary of the stage's purpose.

Triggered By

The action that causes the prospect to be moved to the stage.

Trigger Details

Additional information about the trigger, such as associated charge type or conditions under which the trigger occurs.
