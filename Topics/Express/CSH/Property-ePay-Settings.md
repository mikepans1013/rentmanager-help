# Property ePay Settings (Pop-Up)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Property-ePay-Settings.htm

Zego ePay automatically transfers money either from ePay payments you make to others or that you receive from others in the real world and deposit them into the actual bank account(s). To utilize ePay , each property needs to have the option enabled and settings established to control how those payments are processed.

 Setup

 At the top of the ePay Setting pop-up, the following options are available.

 Option
 Description

 Enable ePay for this Property

 Allows the property to receive ePay payments.

 Use settings from System Preferences

 If checked, the property uses the ePay options selected in system preferences and fields cannot be edited on this pop-up. If unchecked, all ePay options for the property must be selected in this pop-up.

 General Settings

 The following fields are available in the General Settings section.

 Related Preferences

 If the Have Zego manage platform fees option is enabled in system preferences, only the Bank Account and ePay Warning Limit fields display. For more information, refer to General ePay (System Preferences) .

 Field
 Description

 Bank Account

 The general ledger (GL) bank account that ePay payments made to this property are deposited into.

 Related Privileges

 This field populates with only banks to which you have access. Your access to banks can be managed on the user's details page. For more information, refer to User Details (Page) .

 Additionally, this field populates with only banks that have been set up as ePay banks with an associated ePay ID. These IDs are generated and provided by Zego and must be associated with the desired bank account in system preferences.

 ePay Warning Limit

 If a dollar amount is entered in this field, a warning message displays when processing an ePay payment equal to or more than this amount.

 Fee Type

 The charge type used for convenience fee transactions when processing ePay payments for this property.

 Apply fee in Rent Manager / Tenant Web Access to

 The payment methods for which convenience fees are charged in Rent Manager and/or Tenant Web Access . Depending on your ePay settings, fees can be established for each method by checking the box next to ACH , Credit Card , and/or Debit Card .

 This value can be a flat dollar amount or, if Percentage is checked, a percentage of the total transaction amount.

 ePay Batch Settings

 The following options are available in the ePay Batch Settings section, depending on the selection in the Batch Calculation field.

 Option
 Description

 Full Balance

 Tenants at this property are charged the entirety of their account balance, including future-dated charges.

 If Never charge more than is checked, the value entered in the field is the maximum dollar amount collected for ePay payments from this property's tenants.

 Selected Charges

 Tenants at this property are charged only for transactions of the selected charge type(s).

 If Never charge more than is checked, the value entered in the field is the maximum dollar amount collected for ePay payments from this property's tenants.

 Set Amount

 Tenants at this property are charged a specified dollar amount.

 ePay Check Scanning

 If you utilize ePay check scanning and Override Endorsement is checked, the value in the field below is used when endorsing scanned checks.

 Resident Payout

 If you utilize Zego Resident Payout for security deposit refunds, select Allow security deposit refunds to tenants via electronic payout to allow refunds to be processed by Zego for this property. For more information, refer to Zego Resident Payout .
