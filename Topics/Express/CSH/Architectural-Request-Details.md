# Architectural Request Details (Pop-Up)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Architectural-Request-Details.htm

On the Architectural Request Detail pop-up, you can view individual architectural requests to review the votes for the request, approve or deny the request, view and reply to messages from the person making the request, and manage associated history/notes.

 Related Privileges

 Group
 Privilege
 Column

 Associations
 Manage Architectural Requests

 For more information, refer to Control User Access .

 To view the details pop-up of an individual architectural request, go to arrow_forward Services arrow_forward Community arrow_forward Architectural Requests and select a request from the list.

 Details

 The following fields display on the Details tile.

 Field
 Description

 Property

 The property for which the request is being submitted.

 More Information

 Only information related to the properties to which you have access displays. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Control User Access . Additionally, Only properties with a Property Type of Association (as entered on the property's details page) display in the list.

 Tenant

 The name of the tenant requesting the architectural change.

 Status

 The current status of the request.

 Description

 The detailed description of the architectural change the tenant is requesting.

 Request

 A brief summary of the requested architectural change.

 Attachments

 To browse your computer for a file to attach to the request, click Upload Files

 Vote Summary

 The Vote Summary tile displays the committee and/or board members eligible to vote on the architectural request, as well as their current votes made via Tenant Web Access . Alternatively, click to open the Architectural Request Votes pop-up. The request must have a status of Pending for the members to see the request in Tenant Web Access .

 The voting statistics display on the bottom of the tile to provide the total number of votes that are Approved , Denied , are a No Response , and the Total number of voting members.

 The following columns are available in this section:

 Column
 Description

 Name

 The name of the member to participate in voting.

 Vote

 The outcome of their vote. If they have not voted yet, No Response displays.

 Notes

 If applicable, the comment the member added when voting to approve or deny the request.

 If you need to have the board or committee members start the vote over again, click Clear Votes . Any committee and/or board members who previously voted needs to do so again.

 Messages

 If a TWA user submitted the request via Tenant Web Access , you can send and receive messages to them in this section. Only the person who submitted the request and Rent Manager users can see these messages; they are not visible to board and/or committee members. To mark the message as unread (and display the indicator on the Architectural Requests page) click on the last message received and select Mark Unread .

 More Information

 If the request has a status of Approved , Denied , or Canceled , Tenant Web Access users can no longer send messages to you via TWA for that architectural request.

 History/Notes

 The History/Notes tile contains all history/note items associated with the architectural request. To view or add a new note, click to open the History/Notes pop-up for the request.

 Additional Information

 The Additional Information tile contains any custom fields created for Architectural Request Forms . Alternatively, To browse your computer for a file to attach to the request, click to open the Edit Additional Information pop-up.

 The following columns are available in this section:

 Column
 Description

 Field Name

 The name of the custom field as defined on the architectural request form.

 Value

 The input assigned to the selected Field Name .
