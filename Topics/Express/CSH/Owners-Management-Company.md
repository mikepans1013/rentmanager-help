# Owner Management Company (Pop-Up)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Owners-Management-Company.htm

The Management Company pop-up allows you to track charges posted to the owner account and payments received from the owner, which primarily consist of management fee charges, payments associated with the owner, and owner invoices.

 Column Descriptions

 The following columns display on this page. Click Collapse Invoices to show a single line item for the combined total of items on an invoice instead of a separate line for each item on the invoice.

 Column
 Description

 Date

 The date on which the transaction took place. Enter the From and/or To dates to only show transactions created during the specified period.

 Reference #

 The reference number for the charge or payment.

 Description

 A Rent Manager generated description of the transaction type (e.g., Management Fee ).

 Comment

 Additional details regarding the transaction (e.g., Management Fee for September ).

 Amount

 The total dollar amount of the transaction.

 Balance

 The balance as of the time the transaction was recorded.
