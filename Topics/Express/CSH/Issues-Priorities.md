# Issue Priorities (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Issues-Priorities.htm

Issue priorities are levels that you create to describe the urgency you assign to an issue (e.g., Critical , High , Medium , or Low ). They also aid in filters and saved issue lists.

 You can add new priorities that users can select when filling out service issues and format the priorities to add visual distinction. Under certain circumstances, you can also delete unnecessary priorities or make them inactive (which removes them from the drop-down lists).

 Column Descriptions

 The following columns display on this page:

 Column
 Description

 Active

 If checked, the issue priority is displayed on issues and recurring issues.
If unchecked, the issue priority is displayed on the List Manager Priorities page only when Active Only is checked.

 Name

 A descriptive name that identifies the issue priority.

 Description

 An optional message about when to use the issue priority.
