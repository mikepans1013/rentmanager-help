# Banks (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Banks.htm

The Bank Registers page is your ledger in Rent Manager , displaying all deposits, payments, and other transactions that affect each bank account since the G/L Start Date , along with running balances of those accounts. The bank register also displays the transactions that are cleared through bank reconciliations, which ensures your real-world finances are reflected in Rent Manager .

 On the Bank Registers page, each transaction displays on a row with information organized into columns. Click on a transaction to open the Deposits or Check details page for that transaction, where information specific to that transaction is available.

 The balance information for each bank account is displayed to the right of the Filters section.

 Field
 Description

 Actual Balance

 The total balance of cleared and uncleared transactions of the selected bank account as of today's date.

 Cleared Balance

 The balance of reconciled transactions of the selected bank account as of today's date.

 Column Descriptions

 The following columns display on the page. By default, some columns display only by using .

 Default Column
 Description

 Date

 The date the transaction took place. By default, the register displays transactions that took place up to six months prior.

 Reference

 The system-generated or custom identifier for the transaction, such as the check number.

 Information

 Additional information about the transaction including the vendor name and information entered in the Memo or Comment fields of the transaction.

 Cleared

 A green indicates that the transaction was reconciled.

 Deposit

 If the transaction is depositing funds into the bank account, this column displays the amount of the deposit.

 Payment

 If the transaction is removing funds from the bank account, this column displays the amount of the payment.

 Balance

 The total rolling dollar amount in the bank account after the transaction is included.

 Available Column

 Description

 Attachments

 A displays if the transaction has any files, documents, images, etc. attached, such as a copy of the printed bank statement.

 Comment

 The note entered in the Comment field for deposits or the Memo field for payments. If the Comment field on a deposit or the Memo field on a check is blank, this column is blank.

 Payee Name

 If the transaction is a payment, this column displays the name in the Payee Information field.

 Vendor

 If the transaction is a payment, this column displays the vendor who was paid by the transaction,
