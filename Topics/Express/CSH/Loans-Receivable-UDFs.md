# Loans Receivable User Defined Fields (Pop-Up)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Loans-Receivable-UDFs.htm

User-defined fields (UDFs) are custom fields used to track information that Rent Manager does not track by default. UDFs are available for each entity (e.g., tenant, prospect, property, unit, and so on) throughout Rent Manager . Each UDF has a control type to determine how this data is recorded (e.g., text, numeric, file, and so on) which allows users to enter consistent values regardless of who updates the UDF. For example, for loans receivable-type UDFs, you might want to include the amortization or loan type, the originator of the loan, a home warranty expiration date, or other types of information.

 Column Descriptions

 The following columns of information display for UDFs.

 Column
 Description

 Name

 The unique name of this user-defined field.

 Value

 The information you track with this UDF. The information you can include depends on the control type selected for the UDF (e.g., drop-down, text, date, and so on). For example, if a UDF has a Date control, only a date within a year can be entered as the value.
