# Memorized Tasks (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Tasks-Memorized.htm

Memorized tasks are tasks that have been saved as templates to make it easier to create similar tasks in the future. You can either create a memorized task from scratch, or you can click Memorize on an existing task to save it as a template.

 To manage memorized tasks, go to arrow_forward Services arrow_forward Calendar arrow_forward Memorized Tasks .

 Column Descriptions

 The following columns are available on this page.

 Column
 Description

 Name

 The unique name of the memorized task that appears on the Memorized Tasks page.

 Title

 The name of the task as it appears on the Tasks page and on the Tasks dashboard tile.

 Description

 The comment or note of the task (e.g., Check all timecards before they are sent for processing , Put in order and write check ).

 Due Date Days Offset

 The number of days after the current date that a task generated from a memorized task calculates as the Due Date .

 Action

 The action Rent Manager takes, as selected in the Actions drop-down list. If none are selected, No Action displays.
