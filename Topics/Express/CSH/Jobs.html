Jobs (Page)

The job costing tool in Rent Manager makes it possible to track transactions associated with specific jobs completed by your business. For example, you can track the costs of job types such as renovations or construction projects or examine the expenses and revenue associated with landscaping work across your entire portfolio. Jobs are tracked by assigning each financial transaction involved to the job in Rent Manager.

Related Preferences

In order to use the job costing tool in Rent Manager, Enable job costing must be checked in system preferences. For more information, refer to General Options (System Preferences).

Related Privileges

Group Privilege Column
Accounting Jobs View

For more information, refer to Control User Access.

To view the Jobs page, go to arrow_forward Accounting arrow_forward General arrow_forward Jobs.

The number of jobs on the page display in the bottom-right corner. To include jobs that are no longer active on the page, click Show Inactive.

Column Descriptions

The following columns are available on this page. By default, some columns display only if added via .

Default Column Description

Name

The full name for the job.

Description

An explanation for the purpose of the job (e.g., Renovate 3 story parking garage at the north entrance).

Job Type

The type or work to be performed by the job.

Link Type

The entity linked to the job.

Link

The name of the Property, Unit, or Asset linked to the job.
Available Column Description

End Date

If applicable, the date on which the job ended.

Expected End Date

The date on which the job is expected to end.

Start Date

The date on which the job began or is expected to begin.

Row/Bulk Actions

Row actions are available from the menu on the far right of the page and affect only the selected job. To perform actions on multiple jobs, the Bulk Actions menu allows you to select an action and then check all the jobs for which to apply the action.

The following actions are available on this page. Actions that can be performed in bulk are marked with a Check.

Action Bulk Action Description

Delete

 

Related Privileges

Group Privilege Column
Accounting Jobs View, Delete

For more information, refer to Control User Access.

Permanently removes the job from Rent Manager.

Warning

Deleting a job cannot be undone. If you no longer wish to use the job, instead of deleting it, consider marking it as inactive, allowing you to retain the information attached to that job while removing it from available jobs. To make a job inactive, on the job's details page, uncheck Active.

Report Writer

Check

Related Privileges

Group Privilege Column
Letter/Email Templates/Reports/Packets Report writer templates View

Additionally, on the Reports tab, you must have access to at least one job-type Report Writer report.

For more information, refer to Control User Access.

Select an job-level Report Writer report from the list to generate a report for the selected jobs.

Send Email

 

Related Privileges

Group Privilege Column
System Compose Email Enabled

For more information, refer to Control User Access.

Send an email to the user(s) or parties associated with the selected job, such as the job's assigned head contractor or the manager of the linked property. To generate a job-type email from a template, on the Send Email pop-up, select Insert Email Template. For more information, refer to Letter and Message Templates.

Writer Letters

Check

Related Privileges

Group Privilege Column

Additionally, on the Communication tab, you must have access to at least one job-type letter.

For more information, refer to Control User Access.
