# Global Search (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Global-Search.htm

The global search tool allows you to search your entire Rent Manager database for specific alphanumeric strings. The search results populate with every item, account, or transaction matching your entered keyword or phrase. For instance, if you receive a notice from a tenant that they are receiving communications for someone else, you can search for their email address and locate it in the system to see if it was potentially attached to the wrong tenant account.

 Related Privileges

 There are no specific privileges required to access the global search, however, the results that display are limited to what your user privileges allow. For example, if you do not have access to view properties, the results will not display any properties even if there are properties that match the search criteria.

 For more information, refer to Control User Access .

 To access the global search, go to arrow_forward Search arrow_forward Global Search .

 In the search bar at the top, enter the search criteria (such as a word or number) and click to search your database. Your search results are divided into multiple tabs to filter the information in organized categories. Each tab and filter option is described below.

 My Search Settings

 To customize the information that displays in your global search results for each tab, click My Search Settings . On the My Search Settings pop-up, adjust your global search settings as needed and click Save & Close . The available sections and options are described below.

 Section
 Description

 Search Categories

 Each tab that displays on the Global Search page to categorize your search results. To change the order of these tabs, click and drag to move their position in the list. To determine which entities display for a certain category, select that category from the list.

 Search Method

 For the selected category, determines how the global search evaluates keywords or numbers when displaying search results. Each option is described below.

 Contains

 Displays all search results that contain the string, number, or phrase anywhere in the data. For example, if you search Anderson , then any words that contain this word are included, such as Sanderson and Anderson's .

 Begins with

 Displays only search results that start with the entered string, number, or phrase. For example, if you search Security Deposit , then only data that begins with that phrase is included, such as Security Deposit Interest , but not Riverview Apartments Security Deposits.

 Items to Include in Search

 For the selected category, determines which entities are available in the global search and which are excluded from it. The available sections are described below.

 Available Items

 Lists all entities for this category that are currently excluded from global search results. To add an entity to the search results, click that entity to move it to the Select Items section. To add all entities to search results, click Select All .

 Selected Items

 Lists all entities for this category that are currently included in global search results. To remove an entity from the search results, click that entity to move it to the Available Items section. To remove all entities from search results, click Remove All .

 More Information

 In the global search tabs, if any entity items are excluded from that tab's search results, displays. Hover over to display a tooltip which tells you how many entity items are included in the search versus how many are available from you search settings.

 All

 The All tab includes all results across Rent Manager , including all of the information described in the tabs above. This section displays only entities for each section included in the settings of the My Search Settings pop-up. For example, if your search settings have tenant-type history/notes disabled, then history/note items associated with tenants do not display on the   People tab nor on the   All tab.
