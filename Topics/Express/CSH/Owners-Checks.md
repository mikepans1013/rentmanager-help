# Owner Checks (Pop-Up)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Owners-Checks.htm

The Checks pop-up on an owner's details page lets you see previous distributions paid out to the selected owner. Each column represents an important detail that was used to calculate the total amount of the owner distribution on the date the distribution was made.

 In addition, you can view transactions for a specific owner, and if the owner uses NACHA for contributions, that file can be generated from this pop-up

 Column Descriptions

 The following columns are available on this pop-up.

 Column
 Description

 Date

 The date the owner's check was issued as selected on the Pay Owners page. This date represents the check's payment date, not the check date. For example, if the Date is updated on the check's details page, the date in this column does not change.

 Bank Balance

 The balance of the owner's bank prior to this equity distribution.

 Undeposited Funds

 The amount of money collected from properties owned by this owner that has not yet been deposited into the appropriate bank account(s).

 Security Deposits

 The amount of security deposits withheld when this owner's check was calculated. Security deposits show in this column only if the Subtract security deposits held from bank balance when writing owner checks is enabled on the property's Owner Check Setup pop-up. For more information, refer to Property Owner Check Setup (Pop-Up) .

 Total Reserve

 The minimum bank balance that an owner must maintain in their bank at all times to cover possible expenses. When owner checks are calculated, the reserve is subtracted out.

 Convenience Fee Liability

 Bank funds that were set aside as a liability to cover platform fees charged for accepting ePay owner contributions. When owner checks are calculated, the money held in this liability account is subtracted out of the total.

 Excluded Amount

 The total of all accounts whose balances/activities were set to be excluded from the calculation of the owner's check. Exclusion accounts are established on the property's Owner Check Setup pop-up.

 Owner %

 The owner's percent of ownership of this property or unit. The Bank Balance (minus security deposits, if applicable) is multiplied by this percent to determine what portion of the ownership's funds are available to this owner.

 Borrowed Reserve

 Any movement of funds between ownerships to cover other properties in the owner's portfolio that are either operating with a negative bank balance or have dipped below the required reserves amount set for that ownership.

If the amount in this column is negative, funds were transferred from this profitable ownership to balance the reserve of another ownership. If the amount in this column is positive, funds were received by this ownership to increase the ownership's bank balance back to the set reserve amount.

Ownership funds are transferred in this way only if the Balance reserves across ownerships when writing owner checks option is enabled on the owner's Check Setup tile.

 Original Amount

 The amount of the owner's check when it was first written.

 Actual Amount

 The current amount of the owner's check as it shows within Rent Manager .
