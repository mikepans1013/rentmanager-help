# Unit Types (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Unit-Types.htm

Unit types represent the various categories of units that are available at your managed properties. You can create as many unit types as you need to accurately classify your rental units. Unit types can take many forms, such as living spaces (e.g., one bedroom, one bathroom), individual offices, storage units, lots of land, parking spaces, and so on.

 For example, you may have an apartment complex with 100 units. Half of those rental units have two bedrooms and one bathroom, and the other half have one bedroom and one bathroom. You can create unit types for each with easily identifiable names such as 2B/1B and 1B/1B . When you create your units, you can assign them to the appropriate unit type making it easier to track amenities and other unit preferences which can be important when matching prospective tenants to vacant units.

 To view your list of unit types, go to arrow_forward Rental Info arrow_forward General arrow_forward Unit Types

 On the Unit Types page, every unit type displays on a row with information organized into columns. Clicking on any unit type opens the unit type's details page, where information specific to that unit type is available.

 To update multiple unit types' Name , Description , Bedrooms , Bathrooms , etc. simultaneously, click Bulk Actions arrow_forward Mass Edit Mode . Then, click on the applicable fields to make the desired edits. When finished, click Exit . For more information, refer to Mass Edit Account Information .

 Column Descriptions

 The following columns are available on this page.

 Column
 Description

 Bathrooms

 The number of bathrooms, including half bathrooms, available at units of this type.

 Bedrooms

 The number of bedrooms available at units of this type.

 Description

 The details used to describe the unit type.

 Name

 The abbreviated name of the unit type that displays on the unit's scoreboard and on reports such as the Unit Type Listing report.

 Other Rentable Item

 A displays if this unit type is marked on the General tile as an Other Rentable Item . Units of this type are secondary locations and do not impact occupancy reports.
