# Asset-Type User Defined Fields (Pop-Up)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Asset-UDFs.htm

User defined fields(UDFs) are custom fields used to track information that Rent Manager does not track by default. UDFs are available for each entity (e.g., tenant, prospect, property, unit, etc.) throughout Rent Manager . Each UDF has a control type to determine how this data is recorded (e.g., Text , Numeric , File , etc.). You can enter values for user defined fields on the asset's details page. For example, if the vendor provides you with a service agreement related to the asset, you can attach it in the related UDF field so that it always linked to that asset.

 Creating new or modifying existing UDFs must be done through the User Defined Fields page. Managing UDFs from the User Defined Fields page updates how UDFs display across all assets.

 Column Descriptions

 The following columns display on this pop-up.

 Column
 Description

 Name

 The unique name of this UDF. If the name is followed by an asterisk (*), it is a required field and must have a value entered before saving the page.

 The name can be edited from the User Defined Fields page and changes how the UDF displays everywhere it is available.

 Value

 The information you wish to track. For example, if a vendor provides you with a service agreement for the work done on an asset, you can attach it in the Value field for the asset.
