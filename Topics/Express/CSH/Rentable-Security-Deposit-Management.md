# Rentable Security Deposit Management (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Rentable-Security-Deposit-Management.htm

Rent Manager has partnered with Rentable to streamline the entire security deposit management workflow and life cycle. From deposit collection to refunds and withholdings, Rentable provides a simple, guided process for managing security deposits, reducing manual accounting work and risk, while ensuring compliance with complex state and local regulations. The Rentable Security Deposit Management page displays the information needed to manage your security deposits with Rentable, along with options to add more properties and transfer existing standard security deposits to Rentable.

 If Rentable has not been previously enabled for any properties in your database, this page prompts you to set up your first properties with the feature. For more information, refer to Set Up Security Deposits with Rentable .

 More Information

 This feature is licensed and must be purchased separately. For more information, contact your sales representative at sales@rentmanager.com .

 Page Actions

 On this page, you can enable your properties with Rentable and transfer existing standard security deposits over to Rentable.

 Enable Properties

 To set up Rentable security deposits management for more properties, click Enable Properties at the top right of the page. Then, enter the prompted information in the Set Up Security Deposits wizard. For more information, refer to Set Up Security Deposits with Rentable .

 Transfer Deposits

 Existing security deposits held for the property when Rentable is enabled remain standard deposits until they are transferred to Rentable. The Transfer Security Deposits wizard guides you through the required steps and provides instructions for coordinating the transfer with Rentable.

 To initiate the security deposit transfer, do the following:

 -
 At the top right of the page, click Transfer Deposits . If any property listed has a Transfer Status of Create Journal , click the drop-down arrow next to Create Transfer Journal and select Transfer Deposits .

 -
 Select the properties to transfer the associated security deposits to Rentable. Then, at the bottom of the page, select Transfer Deposits .
The Transfer Security Deposits wizard displays.

 -
 Complete the steps in the Transfer Security Deposits wizard.

 More Information

 After completing the steps in the wizard, Rentable provides you with instructions on sending the security deposit funds to your bank. If you need assistance, contact Rentable by clicking Contact Rentable at the bottom left of the wizard.

 -
 Click Submit Transfer to close the wizard and create the journal entries at a later time. Alternatively, to immediately create journal entries, click Submit Transfer & Create Journals to open the Create Transfer Journals pop-up.

 -
 Choose one of the following options depending on the status of your security deposit transfers with Rentable:

 Option
 Description

 Submit Transfer

 If you have not yet confirmed that Rentable has received the security deposit funds, select this option to complete the transfer and close the wizard. You can then create the journal entries at a later time.

 When Rentable confirms it is time to initiate the transfer journal creation, at the top of the Rentable Security Deposit Management page, click Create Transfer Journal and proceed to the steps below.

 Submit Transfer & Create Journals

 If you have confirmed that Rentable has received the security deposit funds, select this option to proceed with creating the transfer journal entries.

 -
 Select the properties for which to create a transfer journal entry. Then, click Create Transfer Journal at the bottom of the page.
The Create Transfer Journals pop-up displays.

 -
 To create line items in the journal for each unit's transferred security deposit balance, check Post Per Unit .

 -
 Click Create Journals .
The security deposit transfer journals are recorded in Rent Manager .

 Column Descriptions

 The following columns display on the page.

 Columns
 Description

 Enabled Properties

 The name of the properties that have Rentable enabled. Properties display in alphanumeric order except for those with a Setup Status of Denied , which are displayed at the end of the list.

 GL Account to Deposit Withholdings

 The bank account to which Rentable sends any security deposit withholdings for the property, as established when the property was enabled for Rentable.

 Rentable GL Account

 The general ledger (GL) account that tracks the property's security deposits held by Rentable in Rent Manager , as established when the property was enabled for Rentable.

 Setup Status

 The current status of the property in the setup process with Rentable.

 The following statuses may display:

 Attention Needed

 The property is no longer fully set up with Rentable. You may need to contact Rentable to resolve the issue.

 Complete

 All setup steps are complete and the property is ready to process Rentable security deposits.

 Denied

 Rentable has decided to not handle security deposits for the property.

 Meet with Rentable

 The property is enabled with Rentable, but the bank account designated as the GL Account to Deposit Withholdings has not been set up with Rentable. Contact Rentable to provide the bank account's information.

 Finalizing

 The bank account designated as the GL Account to Deposit Withholdings is still pending final setup with Rentable.

 Transfer Status

 The current status of the property's existing security deposit transfers to Rentable. If this status is blank, then the security deposit transfer has not been initiated.

 The following statuses may display:

 Create Journal

 The security deposit transfer to Rentable has been completed and its corresponding journal entry must be recorded in Rent Manager . You can click this option to initiate the journal creation process for the property once Rentable has confirmed they received the funds.

 Transfer completed on MM/DD/YYYY

 The security deposit transfer to Rentable has been completed and the corresponding journal entry has been created to reflect the transfer.
