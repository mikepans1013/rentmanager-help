# Rentable Security Deposit Management (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Rentable-Security-Deposit-Management.htm

Rent Manager has partnered with Rentable to streamline the entire security deposit management workflow and life cycle. From deposit collection to refunds and withholdings, Rentable provides a simple, guided process for managing security deposits, reducing manual accounting work and risk, while ensuring compliance with complex state and local regulations. The Rentable Security Deposit Management page displays the information needed to manage your security deposits with Rentable, along with options to add more properties and transfer existing standard security deposits to Rentable.

 If Rentable has not been previously enabled for any properties in your database, this page prompts you to set up your first properties with the feature. For more information, refer to Set Up Security Deposits with Rentable .

 Page Actions

 On this page, you can enable your properties with Rentable and transfer existing standard security deposits over to Rentable.

 Enable Properties

 To set up Rentable security deposits management for more properties, click Enable Properties at the top right of the page. Then, enter the prompted information in the Set Up Security Deposits wizard. For more information, refer to Set Up Security Deposits with Rentable .

 Transfer Deposits

 Existing security deposits held for the property at the time of enabling Rentable remain standard deposits until the security deposit transfer process is completed. This process transfers the existing standard security deposits into Rentable via a guided experience through the Transfer Security Deposits wizard and contact with Rentable. To initiate the security deposit transfer, click Transfer Deposits and select the properties to transfer the associated security deposits to Rentable. After completing the steps in the wizard, Rentable will provide you with instructions on sending the security deposit funds in the real world. If you need assistance, contact Rentable by clicking Contact Rentable at the bottom left of the wizard.

 After clicking Finish , the pop-up closes, and the Transfer Status column is updated to Needs Journal for properties included in the transfer. The Create Transfer Journal option displays in the Transfer Deposits drop-down list. After confirming with Rentable that they received the funds, you can create transfer journals to record the deposit transfers to Rentable in Rent Manager .

 Column Descriptions

 The following columns display on the page.

 Columns
 Description

 Enabled Properties

 The name of the properties that have Rentable enabled. Properties display in alphanumeric order except for those with a Setup Status of Denied , which are displayed at the end of the list.

 GL Account to Deposit Withholdings

 The bank account to which Rentable sends any security deposit withholdings for the property, as established when the property was enabled for Rentable.

 Rentable GL Account

 The general ledger (GL) account that tracks the property's security deposits held by Rentable in Rent Manager , as established when the property was enabled for Rentable.

 Setup Status

 The current status of the property in the setup process with Rentable.

 The following statuses may display:

 Attention Needed

 The property is no longer fully set up with Rentable. You may need to contact Rentable to resolve the issue.

 Complete

 All setup steps are complete and the property is ready to process Rentable security deposits.

 Denied

 Rentable has decided to not handle security deposits for the property.

 Meet with Rentable

 The property is enabled with Rentable, but the bank account designated as the GL Account to Deposit Withholdings has not been set up with Rentable. Contact Rentable to provide the bank account's information.

 Finalizing

 The bank account designated as the GL Account to Deposit Withholdings is still pending final setup with Rentable.

 Transfer Status

 The current status of the property's existing security deposit transfers to Rentable. If this status is blank, then the security deposit transfer has not been initiated.

 The following statuses may display:

 Needs Journal

 The security deposit transfer to Rentable has been completed and its corresponding journal entry must be recorded in Rent Manager .

 Transfer completed on MM/DD/YYYY

 The security deposit transfer to Rentable has been completed and the corresponding journal entry has been created to reflect the transfer.
