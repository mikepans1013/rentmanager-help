Unit Type Details (Page)

The Unit Type details page displays information such as the properties with units of the unit type, basic information like the number of bedrooms and bathrooms, and unit type-level recurring charges. For each property, you can also see how many units are assigned to that unit type, how many of those units are active, and how many of those units are occupied by tenants.

Related Privileges

Group Privilege Column
Properties/Units Unit types View

For more information, refer to Control User Access.

To view and update information about a unit type, go to arrow_forward Rental Info arrow_forward General arrow_forward Unit Types and select a unit type from the list.

Unit Type Image

This tile displays images associated with the selected unit type.

General

This tile displays general details for the selected unit type, such as number of bedrooms and bathrooms.

The following fields display on this tile:

Field Description

Unit Type

The abbreviated name of the unit type that displays on the unit's scoreboard and on reports such as the Unit Type Listing report. For example, you could define a 2 bedroom-2 bath apartment as 2B/2B.

Other Rentable Item

A indicates that units of this type are not included in occupancy-based reporting or calculations, and do not have marketing information associated with them. For example, storage units and garages may be leased by tenants but are not consider occupied and therefore can be excluded from vacancy based reports such as the Unit Turnover report.

Description

The details used to describe the unit type. For example, if the unit type is 2B/2B, the description can be used to enter the full name as 2 Bedroom/2 Bathroom.

Bedrooms

The number of bedrooms at units of this type.

Bathrooms

The number of bathrooms at units of this type.

Inspection Template

If applicable, the template of tasks for move-in and move-out inspections at units of this type. For more information, refer to Inspection Templates (Page).

Properties

This tile displays the properties where the unit type is available.

The following columns display on this tile:

Column Description

Property

The full name of the property where units of this type can be leased.

Short Name

The abbreviated name of the property where units of this type can be leased.

Email

The email address for contacting the manager of the property.

Phone Number

The phone number for contacting the manager of the property.

Manager

The name of the property's manager.

Billing

The full address marked Billing on the property's details page.

Street

The street of the address marked Default on the property's details pages.

City

The city of the address marked Default on the property's details pages.

State

The state of the address marked Default on the property's details pages.

Postal Code

The zip or postal code of the address marked Default on the property's details pages.

Recurring Charges

This tile displays any recurring charges that tenants who lease this unit type inherit.

The following columns display on this page:

Column Description

Charge Type

The abbreviated name of the charge type.

Comment

The note entered on the recurring charge's details page in the Comment field.

Frequency

How many times during the specified date range the recurring charge posts to renters of this unit type. The frequency depends on the tenant's Rent Period. For example, a frequency of 1 posts once a month for a tenant with a monthly Rent Period, while a frequency of 12 posts once every 12 days for a tenant with a daily Rent Period.

From Date

The beginning date on which the recurring charge applies to renters of this unit type.

To Date

The ending date on which the recurring charges applies to renters of this unit type.

Amount

The total dollar amount of the recurring charge.
