Report Writer Manager (Page)

Report Writer allows you to create your own custom reports to meet your business needs by utilizing insertable fields specific to the type of report, as well as scripting for more customizable options. From the Report Writer Manager page, you can create and manage custom reports using Report Writer.

Related Privileges

Group Privilege Column
Letter/Email Templates/Reports/Packets Service Manager report writer templates View, Edit

For more information, refer to Control User Access.

To view the Report Writer Manager page, go to arrow_forward Report Writer.

The list of report entities to select from displays on the left in the Report Type section.

Column Descriptions

The following columns display on this page.

Columns Description

Name

The unique name of the template, which is used when referencing the template throughout Rent Manager.

Description

Additional details about the purpose of the associated report.

Created By

The user who created the associated report.

Create Date

The date the report was created.

Selected Users

The users who can generate the associated report.

On Right Click Menu?

Indicates where the report can be generated from the right-click menu in Rent Manager 12.

On Report Writer Menu?

Indicates whether the report is included on report writer main menu.

Row Action Descriptions

The following row actions are available from the menu.

Option Description

Details

Opens the Edit Custom Report page where you can make changes to the selected report.

Delete

Related Privileges

The privileges for each report-type and individual Report Writer template you wish to delete are required. For more information, refer to Control Custom Report Access.

Delete the selected report from the register.

Warning

Deleting a report from the register deletes it for all users in the database.

Export To File

Exports a copy of the report template as a file that can be stored on your computer outside of Rent Manager.

Report Writer templates are exported in the Rent Manager (.rrtx) file type and can only be opened within Rent Manager.

Export To Online Template Library

Allows your report template to be available to other Rent Manager users via the Online Template Library. The template will be reviewed by London Computer Systems, Inc.. If accepted, it will be available on the online template library in the future.

Settings

Edit a report's settings, such as the report template name, users with access, menu availability, and description of the report.
