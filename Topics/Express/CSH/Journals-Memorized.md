# Memorized Journals (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Journals-Memorized.htm

Memorized journals are journal entries that are saved as templates to easily create new journal entries. You can either create a memorized journal entry from scratch, or you can memorize an existing journal entry into a template.

 Column Descriptions

 The following columns are available on this page. By default, some columns display only if added via .

 Column
 Description

 Name

 The name of the memorized journal (e.g., Monthly Office Supplies ).

 Description

 A description to explain the template in more detail (e.g., Monthly supplies expense ).

 Amount

 The total amount of credit/debit entered in each memorized journal entry.

 Memo

 An additional message about the memorized journal entry (e.g., Adjust monthly office supplies ).

 Reference

 A message about the transaction(s) contained within the memorized journal entry (e.g., BB&T Bank Account ).

 Properties

 The name of the property associated with the memorized journal entry.

 Available Column

 Description

 Basis

 The accounting method for how the journal entry affects financial reports.

 Cash

 The journal entry affects only reports run in a cash accounting basis. All transactions are recorded when cash is paid or received, and unpaid invoices and expenses are not included in financial reports.

 Accrual

 The journal entry affects only reports run in an accrual accounting basis. All transactions are recorded as they are incurred, and unpaid invoices and expenses are included in financial reports.

 Both

 The journal entry affects all reports.

 Created By

 The name of the user who created the memorized journal entry.

 Created Date

 The date the memorized journal entry was created.

 Period Adjustment

 If checked, the journal entry is notated as an adjustment entry.

 Updated Date

 The most recent date when a user edited and saved the memorized journal entry.
