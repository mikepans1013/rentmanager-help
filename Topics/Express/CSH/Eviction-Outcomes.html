Eviction Outcomes (Page)

The Evictions Outcomes page allows you to track and manage the results of the eviction process. Additionally, since eviction outcomes can vary based on court or landlord decisions, you can create and customize a list of results tailored to your specific needs.

Related Privileges

Group Privilege Column
Setup Manage Eviction Reasons and Outcomes Enabled

For more information, refer to Control User Access.

To view the Eviction Outcomes page, go to arrow_forward Rental Info arrow_forward Rental Info Setup arrow_forward Evictions arrow_forward Eviction Outcomes.

Column Descriptions

The following columns are available on this page.

Column Description

Active

A displays to indicate the eviction is Active. If this column is blank, the outcome is inactive and cannot be selected as the result for evictions in Rent Manager.

Name

The name assigned to eviction outcome.

Description

Additional details about the eviction outcome (e.g., Tenant vacated unit-eviction case does not go to court).

Type

The result of the eviction (Evicted or Not Evicted).
