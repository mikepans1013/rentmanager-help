# Phone Number Types (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Phone-Number-Types.htm

With phone number types, you can sort your contacts' phone numbers into categories to make searching, filtering, and reporting easier. This makes it easy to use multiple phone numbers for the same entity. In addition, you can use phone number types for scripting.

 To view your phone number types, go to arrow_forward Administration , then go to Customization arrow_forward Phone Number Types .

 On the left, phone number types are sorted by entity type, such as owner, property, and tenant. On the right, each phone number type created for each entity type displays.

 Column Descriptions

 The following columns display for each phone number type:

 Column
 Description

 Name

 The named used to identify the type of phone number.

 Description

 An optional explanation of the phone number type or its use cases.
