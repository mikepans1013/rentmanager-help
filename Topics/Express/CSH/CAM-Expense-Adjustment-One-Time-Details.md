# One-Time CAM Expense Adjustment Details (Pop-Up)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/CAM-Expense-Adjustment-One-Time-Details.htm

To ensure that your common area maintenance (CAM) reconciliation values are accurate, you can manually create additional expense adjustments to change the expensed general ledger (GL) account for a particular charge or account for one-time exemptions and discounts that are part of a tenant's contract.

 To view the details of a one-time CAM expense adjustment, go to arrow_forward Receivables arrow_forward Commercial arrow_forward CAM Expense Adjustments and select an expense adjustment with the type One-time from the list.

 Field Descriptions

 The following fields are available in the Add One-Time Expense Adjustment pop-up:

 Field
 Description

 Property

 The property associated with the expense adjustment.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 The tenant lease(s) at the property receiving this expense adjustment. To select multiple leases, click and select each applicable tenant lease on the pop-up. Then click OK .

 Adj. Date

 The date on which the expense adjustment was created. This adjustment is included in the CAM reconciliation only if it falls in the selected date range for the reconciliation.

 GL Account

 The GL account associated with the expense adjustment.

 Adj. Amount

 The total dollar amount of the adjustment applied to the GL Account . To deduct an amount from the expense account, enter a negative value. For example, to deduct $5,000 from the selected GL account, enter -5000 .

 Internal Note

 An optional description of the expense adjustment that is viewable only by Rent Manager users.

 Tenant Note

 An optional description of the expense adjustment that posts to tenant accounts and displays on the CAM Reconciliation Statement report.

 More Information

 If the expense adjustment is reconciled for at least one tenant selected on this adjustment, only the Tenants , GL Account , Internal Note , and Tenant Note fields can be edited. Adjustments that are already reconciled are not affected by any changes.
