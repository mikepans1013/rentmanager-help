# Architectural Requests History/Notes (Pop-Up)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Architectural-Request-History-Notes.htm

History/notes allow you to record information that supplements or clarifies what’s entered in other fields, such as notes about phone conversations, items on a to-do list, and explanations about transactions. While some history/note items are automatically created by Rent Manager , you are also able to record information based on your needs. This makes it easier to track events related to each architectural request and provide additional details for internal reference.

 Filter Options

 The following filter options are available on the pop-up. Depending on the size of your browser window, these filters may display at the top of the page, or you may need to click to view the filter options.

 Option
 Description

 Search

 Type in the Search field to narrow the list to match your search criteria.

 Filter By Date

 Select or enter the From and/or To dates to filter history/note items created during the selected dates. Click to select a specific date range.

 Users

 Click the drop-down list and select users to filter for history/note items created by one or more Rent Manager users.

 History Category

 Click the drop-down list and select categories to filter for history/note items by category.

 Select <Unassigned> to include history/notes with no category.

 Type

 Click the drop-down list and select types to filter history/note items by type.

 To select or deselect all options in the list, click the box next to the Search field.

 Only Notes with Attachments

 Check to display only history/note items that have an attachment.

 Column Descriptions

 The following columns are available on this pop-up.

 Column
 Description

 Pin

 If the history/note item has Pin enabled, displays. If there are no pinned items, the column does not display.

 Type

 The system-generated history/note type. For example, if the history/note item is linked to an email record, the Email type displays.

 Date

 The date and time the history/note item was created.

 Note

 The text entered in the Note field of the history/note item. If no text is entered, the column displays blank.

 If an attachment is uploaded to the history/note item, displays. To download the attachment or open it in a new tab, click .

 Category

 The category of the history/note item selected from the available history categories. If no category is selected, the column displays blank.

 User

 The Rent Manager user who created the history/note. If this is a system-generated history/note, the user displays as Administrator . If the history/note was generated from Tenant Web Access (TWA) , the user displays as <Unassigned> .
