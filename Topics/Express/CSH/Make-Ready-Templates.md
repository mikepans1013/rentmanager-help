# Make Ready Templates (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Make-Ready-Templates.htm

Make-ready templates are comprised of issues or inspections and define a workflow that can be used to quickly kick off a make-ready for a unit. Make-ready actions classify and determine the order in which issues and inspections appear within a template. Templates can be created for each property or unit as desired. After creating a template, you can use it whenever you need to prepare a unit for occupancy.

 When the make-ready process is started, each issue or inspection defined through the template is generated and added as a column on the Make Ready board as well as to the Issues or Inspections pages so its progress can be tracked.

 Column Descriptions

 The following columns are available on this page.

 Column
 Description

 Name

 The name that defines the purpose of the make-ready template (e.g., Unit Make Ready , Storage Unit Make Ready , Cleaning ).

 Active

 A displays if the template is currently active and available for use.

 Items

 The number of make-ready items ( Inspection or Service Issue ) in the template.

 Associated Properties

 The properties assigned to the template. Units at properties that have a tenant Move Out date may use this template within the make-ready process.
