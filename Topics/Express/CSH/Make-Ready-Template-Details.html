Make Ready Template Details (Pop-Up)

Make-ready templates define a workflow for unit turnover actions so that units are ready for new tenants to move in. With a make-ready template, you can create and list service issues and checklist steps so you can quickly start and track the make-ready process when a tenant moves out.

Related Privileges

Group Privilege Column
Properties/Units Make ready templates View, Edit

For more information, refer to Control User Access.

To open a make-ready template's details, go to arrow_forward Services arrow_forward Make Ready arrow_forward Make Ready Templates and select a template from the list.

General Details

The top of the pop-up displays the following general information about the make-ready template:

Field Description

Name

The name of the make-ready template.

Active

This option is checked by default and indicates the template is currently active and available. Uncheck this option to deactivate the template and make it unavailable for future make-ready processes.

Enforce Action Sequence

When checked, requires that the make-ready items are completed in the specified order.

Properties

The properties where this make-ready template can be used. To display properties in the list that are not currently active, check Show Inactive Properties.

More Information

This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property.

Make Ready Items

This section displays the steps required to complete the make-ready template. The following columns displays in this section:

Column Description

Action

The name of the make-ready action.

Notify

If the option Notify when ready is selected, a Check displays. This indicates that the user is notified when the item is ready.

Type

Indicates whether the item is a Service Issue or Inspection.

Description

The Issue title for services issues and the Inspection Description for inspections.

Assigned To

The user assigned to the make-ready item.
