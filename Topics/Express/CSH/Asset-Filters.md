# Asset Filters (Pop-Up)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Asset-Filters.htm

Asset filters allow you to quickly narrow your search results to get to the asset information that you really need to see. Rent Manager gives you the ability to choose from a variety of filtering options that you can use to sort your assets on the Assets page.

 Rent Manager allows you to create filters that can be used temporarily, or saved to use repeatedly. Additionally, they can be saved on a system level for all users, or on a personal level where only your user account can access it. Before saving your filter, enter a Name , and, optionally, a Description to remind you of the filter's purpose.

 More Information

 If the basic filtering does not meet your needs, you can create an advanced filter which allows you to group your filters for a more granular, precise filtering criteria. For more information, refer to Create an Advanced Filter .

 There are multiple fields available to use for basic filtering of assets on the Assets page. The fields are divided into multiple tiles. Each field is described within the corresponding tile below.

 General Information

 This tile contains fields for filtering assets by information that can be found primarily on their details pages.

 In the Search Options field, select whether the filtered asset list includes results for assets based on whether the relevant information Contains your filter criteria or Begins With the your filter criteria.

 For example, if you are filtering assets with a Serial Number that start with 4 , you can select Contains to display all assets whose serial number includes the number 4 . Alternatively, if you select Begins With , you see results only for assets whose serial number starts with the number 4 .

 The available filter fields are described in the table below.

 Field
 Description

 Bathrooms

 The number of bathrooms the asset contains as entered on the Details tile.

 This field applies only if the Asset Type for the asset is set up as a home.

 Bedrooms

 The number of bedrooms the asset contains as entered on the Details tile.

 This field applies only if the Asset Type for the asset is set up as a home.

 Comment

 Additional information or notes about the asset as entered on the Comment tile.

 Dimensions

 The measurable size of the asset, such as length and width, as entered on the Details tile.

 Homeowner Status

 The current legal ownership status (i.e., Community Owned , Employee Owned , etc.) associated with the home-type asset as entered on the General tile.

 Lienholder

 The person or business who owns and loaned the asset as entered on the Purchase & Loan Information tile.

 Loan Number

 The number assigned by the issuer of the loan as entered on the Purchase & Loan Information tile.

 Manufactured

 The date the asset was produced by the manufacturing company as entered on the Details tile.

 Model

 The model name of the asset as entered on the Details tile.

 Name

 A unique identifier for the asset as entered on the General tile.

 Purchase Date

 The date that your company purchased the asset as entered on the Details tile.

 Purchase Price

 The price for which your company purchased the asset as entered on the Details tile.

 Serial Number

 The asset's unique serial identification number as entered on the Details tile.

 Square Footage

 The size of the asset in square feet as entered on the Details tile.

 This field applies only if the Asset Type for the asset is set up as a home.

 Title Status

 The current condition of the asset's title (e.g., Clear Title or In Process ) as entered on the Details tile.

 Type

 The category that best classifies the type of asset as entered on the General tile.

 Vendor

 The primary vendor who is responsible for servicing and/or maintaining this asset as entered on the Details tile.

 Status Information

 This tile contains fields for filtering assets by their condition information, located primarily on the Asset Status History tile.

 The available filter fields are described in the table below.

 Field
 Description

 End

 The date range on which the current status ends.

 Start

 The date range on which the current status is first applicable.

 Status

 The condition that best describes the state of the asset (e.g., Inventory , Out for Maintenance ).

 Location Information

 This tile contains fields for filtering assets by their location information, located primarily on the Asset Location tile.

 The available filter fields are described in the table below.

 Field
 Description

 End

 The date range that the asset was or is to be removed from the specified location.

 Property

 The property at which the asset is physically located.

 Start

 The date range that the asset was moved to the specified location.

 Unit

 The unit at which the asset is physically located.

 Warranty/Maintenance Information

 This tile contains fields for filtering assets by their service agreement information, located primarily on the Warranty/Maintenance tile.

 The available filter fields are described in the table below.

 Field
 Description

 Service Expiration

 The date range that the manufacturer or vendor service agreement for the asset ends.

 Service Period

 The number of months that elapse between each maintenance service for the asset for the duration of the service agreement.

 Warranty Expiration

 The date range that the warranty for the asset expires.

 Warranty Information

 Any additional details regarding the warranty for the asset, such as terms or special stipulations.

 User-Defined Fields Information

 This tile contains fields for filtering the asset list by user-defined fields (UDFs).

 Select an asset-type UDF from the list by which to filter assets. Then in the Value field, enter or select the information to narrow your results to assets that meet the entered criteria.
