# Guest Card Templates (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Guest-Card-Templates.htm

The guest card tool allows you to place a contact form on your website for prospects and owner prospects to request more information about your rental properties or management services. When that form is completed, an account is automatically created for the individual in Rent Manager using the information entered on the guest card. In order to match that information to the correct fields on their account, guest card templates must be created.

 Column Descriptions

 The following columns are available on this page. By default, some columns display only if added via .

 Default Column
 Description

 Name

 The name of the template.

 Type

 The entity type ( Owner Prospect or Prospect ) associated with the template.

 Captcha

 Displays a if, on the Guest Card Template pop-up, the Require human verification (CAPTCHA) before Guest Card submission field is checked.

 Property

 The default property with which a guest is associated if they do not make a property selection on the guest card.

 Associated Properties

 The available properties on the guest card that a guest may select.
