Compose Letter (Pop-Up)

Rent Manager includes an integrated word processor, which allows you to write letters and other documents. This word processor contains many common document creation functions. After composing a letter, you may download a copy or email it as an attachment. You may want to write a letter for a one-off communication with a specific tenant, such as a rental discount offer or a personal response to a complaint.

If you are routinely sending letters with similar content, it is recommended to create letter templates instead.
