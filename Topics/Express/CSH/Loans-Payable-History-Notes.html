Loans Payable History/Notes (Pop-Up)

History/notes allow you to record information that supplements or clarifies what’s entered in other fields, such as notes about phone conversations, items on a to-do list, and explanations about transactions. History/notes on loans payable are helpful because they allow you to record and track information about updates to the loan's schedule, automation settings, or journal adjustments.

Related Privileges

Group Privilege Column
Payables Loans Payable View

For more information, refer to Control User Access.

To view and manage history/notes for a loans payable, go to arrow_forward Payables arrow_forward Loans Payable arrow_forward Loans Payable and select the desired loan. On the loan's details page History/Note section, click .

More Information

The following table lists the loans payable events that trigger the automatic creation of a system-generated history/note item. Each event creates a history/note item that includes the username of the Rent Manager user responsible for the event and what changed as a result. These notes have a System type.

Event History/Note

Interest Rate Changed on Fixed Rate Loan

The user changed the interest rate on a fixed loan.

Principle and Interest Amount Changed on Fixed Rate Loan

The user changed the principle and interest amount on a fixed rate loan.

Interest Method Selection Changed

The user selected a new Interest Method on the Loan Payable details page in the Payment Info tile.

Due Day Changed

The user selected a new Due Day on the Loan Payable details page in the Payment Info tile.

Journal Adjustment/True-Up Created

The user created a journal adjustment on the Loan Payable details page in the Transactions & Amortization tile.

Extra Payment Made

The user made an extra payment from the Loan Payable details page.

Balloon Payment Configuration Added

The user scheduled a Balloon Payment on the Loan Payable details page in the Payment Info tile.

Balloon Payment Configuration Removed

The user removed a scheduled Balloon Payment on the Loan Payable details page in the Payment Info tile.

Loan Pay Off Added

The user added a loan pay off amount from the Loan Payable details page.

Loan Automation Enabled

The user enabled loan automation for the first time.

Existing Loan Automation Post Date Changed

The user changed the automation post date for an existing loan automation.

Loan Automation Setup Removed

The user removed the loan automation.

Filter Options

The following filter options are available on the pop-up.

Option Description

Search

Enter information into this field to narrow the list to match your search criteria.

Filter By Date

Select or enter the From and/or To dates to filter notes created during the selected dates. Click to select a relative date range.

Users

Select the desired user(s) to filter for items created by one or more Rent Manager users.

History Category

Select the desired categories (Contract, Late Notices, Legal, etc.) of history note items. To include history/notes with no category, select Unassigned.

Type

Select the desired types (Call, Email, Note, System, etc.) of history/note items.

Only Notes with Attachments

Check to display only history/notes that have an attachment.

Column Descriptions

The following columns display on this pop-up.

Column Description

Pin

If the history/note item has Pin enabled, displays. If there are no pinned notes, the column does not display.

Type

The system-generated history/note type. For example, if the history/note is linked to an email, the Email type displays.

Date

The date and time the note was created.

Note

The information to describe the history/note (e.g., New flyers for grand opening were sent to the printer. Invoice is attached). If no text is entered, the column displays blank.

If an attachment is uploaded to the history/note item, displays. Click to download the attachment or open it in a new tab.

Category

The category of the history/note selected from the available history categories. If no category is selected, the column displays blank.

User

The user who created the history/note. If this is a system-generated history/note, the user displays as Administrator.
