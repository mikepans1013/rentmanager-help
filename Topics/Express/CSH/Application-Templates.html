Application Templates (Page)

The Application Templates page displays a list of the primary and subapplication templates that were created in Rent Manager. From this page, you can export the template to your local computer or network drive, copy a template to a new template, and change the properties that can utilize the application template in Apply Now.

Related Privileges

Group Privilege Column
Tenants/Prospects Application Templates View

For more information, refer to Control User Access.

To view and manage application templates, go to arrow_forward Rental Info arrow_forward Leasing arrow_forward Application Templates.

Column Descriptions

The following columns are available on this page:

Column Description

Name

The unique identifier for the application template.

Number of Sections

The number of major sections included in the template.

Create Date

The date that the template was added to Rent Manager.

Create User

The name of the user who created the template.

Update Date

The date that the template was last edited and saved.

Update User

The name of the user who last edited and saved the template.

Associated Properties

The properties that can utilize the application template in Apply Now. This column displays blank for Sub-Application-type templates, as the associated properties are inherited from their associated Primary-type application templates.

Template Type

Indicates whether the template is for the main applicant (Primary) or a co-applicant (Sub-Application).

Total Fees

The total additional fee amount charged for the specific template, as established in the Application Template Settings pop-up. For more information, refer to Set Up Apply Now Application Settings.

Related Preferences

If additional application fees are set up in system web preferences, this column does not display that amount. Only fees set up on the template-level are listed. For more information, refer to Tenant Web Access Apply Now ePay (System Web Preferences).

Additional Applicant Types

If the Primary-type application template is set up with the Additional Applicant major section, the Applicant Type selected for the subapplication(s) display (i.e., CoApplicant, Guarantor, Occupant, Partner, Spouse).

Row Actions

The following row actions are available from the menu:

Action Description

Details

View the full application template, including sections, fields, and disclaimers.

Export

Saves the application template as an XML file to your computer's designated downloads folder, which can be imported by another Rent Manager user. These XML files are compatible only with Rent Manager.

Copy

Related Privileges

Group Privilege Column
Tenants/Prospects Application Templates Add, View

For more information, refer to Control User Access.

Creates a duplicate version of the application template. Primary- and Sub-Application-type templates can be copied to new templates of the same type, or converted to the other type (i.e., copying a Primary-type template to a new Sub-Application-type template, and vice versa).

Assign Properties

Related Privileges

Group Privilege Column
Tenants/Prospects Application Templates View, Edit

For more information, refer to Control User Access.

Opens a pop-up where the properties that can use this application template in Apply Now display. This option is available only for Primary-type application templates.

More Information

This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property.

Delete

Related Privileges

Group Privilege Column
Tenants/Prospects Application Templates View, Delete

For more information, refer to Control User Access.

Permanently removes the application template from Rent Manager.
