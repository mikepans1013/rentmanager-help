Property Tenant Charge Setup (Pop-Up)

The property Tenant Charge Setup pop-up allows you to automatically generate both recurring and one-time charges for new tenants when a prospect is converted to a tenant with the Move In wizard, or when you create a tenant using Add Tenant wizard.

Related Preferences

By default, properties use the tenant charge setup settings established in system preferences. For more information, refer to Tenant Charge Setup (System Preferences).

Related Privileges

Group Privilege Column
Properties/Units Properties View, Edit

For more information, refer to Control User Access.

To view the property application settings, go to arrow_forward Rental Info arrow_forward General arrow_forward Properties and select a property. Then, on the action bar to the right, select arrow_forward Tenant Charge Setup.

To edit the settings in this pop-up, select Override System Preferences.

Default Recurring Charges

Default recurring charges can be used to create one or more tenant recurring charges that generate automatically for new tenants when prospects are converted to tenants or new tenants are created. To create a recurring charge to automatically apply for new tenants at this property, click TonAdd Recurring Charge.

The following columns display in this section:

Column Description

Charge Source

The entity that the recurring charge is inherited from (i.e., Property, Unit, or Unit Type).

Charge Type

The charge type associated with the recurring charge.

Additionally, to create a one-time charge on new tenant accounts in the current month for each recurring charge that already posted for next month through post recurring charges. check If the recurring charges for next month have already been posted, automatically create one-time charges. The following options are enabled when this is selected.

Option Description

Post Day

To further customize information about the one-time charge posted to new tenant accounts, you may edit the Post Day to adjust which day of the month the one-time charge displays as the posting day.

Use rent due day for posting

If selected, one-time charges are posted on the day established in the tenant details page's Due Day field.

Default One Time Charges

Default one-time charges allow you to automate the creation of one-time charges to be applied to new tenants. For example, a one-time charge can be created for routine charges, like security deposits, which are collected when a tenant begins their lease. Additionally, a one-time charge can be prorated to automatically generate charges for partial charges, such as the first rent charge. To create a one-time charge to automatically apply for new tenants at this property, click Ton Add One-Time Charge.

The following columns display in this section:

Column Description

Charge Source

The entity that the recurring charge is inherited from (i.e., Property, Unit, or Unit Type).

Charge Type

The charge type associated with the recurring charge.

General

This section determines the general options for setting up tenant charges. The following options display:

Field Description

Exclude inherited charges

Prevents recurring charges on the property, unit type, or unit level from being inherited by new tenants .Select the desired charge types from the drop-down list.

Post zero charges

Creates charges on a tenant account even if the charges have a value of 0.
