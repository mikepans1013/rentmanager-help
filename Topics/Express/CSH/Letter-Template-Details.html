Letter Template Details (Page)

Letter templates combine static text with dynamic scripting to produce letters that are customized with the unique information of each recipient. Templates open in a word processor allowing for easy updates to fonts, styling, and formatting.

To view a letter template, go to arrow_forward Communication arrow_forward Letters arrow_forward Letter Templates and select the template.

Add Insertable Fields

For more information, refer to Control User Access.

The Insertable Fields section is a list of available functions that can be used to create dynamic content. All insertable fields that display on a letter template are related to the template type. For example, the insertable fields that display on a vendor-type letter template are different from those that display on a unit-type template.

To add an insertable field to the template, click and drag a function to its correct location on the template. Alternatively, double-click the function to insert it where your cursor is currently located on the template.

On the bottom of the Insertable Fields section, if Signable Document is checked, the template has access to insertable fields that are used only when creating signable templates. For example, you can add areas where the recipient can enter their initials or map insertable fields so when the document is signed, the information in those fields imports directly into Rent Manager.

Save Letter Templates

To save any changes to the letter template in Rent Manager, go to File arrow_forward Save. If you want to save a copy of the template outside of Rent Manager, go to File arrow_forward Save As. Rent Manager prompts you to name the file and then downloads the document as an rmtx file. An rmtx file can only be used within Rent Manager, but can be imported back into Rent Manager if you want to use the letter template with a different template type
