# Lease Renewal Offer Details (Pop-Up)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Lease-Renewal-Offers-Details.htm

The Lease Renewal Register page shows the current status of the lease renewal offers made to tenants via the Create Renewal Offer wizard. From there, you can open a lease renewal to view the details of the offer and perform other actions such as updating the offer's expiration date or changing the offer's status.

 Tenant Information

 The top of the Renewal Offer Details pop-up displays information about the tenant's current lease, including the property, unit or rentable asset, lease dates and term, rent amount, and other additional recurring charges. Below the tenant's name, a badge displays that indicates the renewal offer's current status. If there are multiple units or rentable assets associated with the lease renewal offer, you can click the drop-down badge next to the primary unit or rentable asset to display them.

 More Information

 If you are using the Blue Moon integration, there are additional statuses with a prefix of Blue Moon . These statuses reflect the renewal offer's current status in the Blue Moon integration and work similarly to the statuses listed below.

 Each renewal status is described below:

 Status
 Description

 Needs Landlord Signature

 If the renewal offer was delivered as a signable document, the offer is waiting for an owner or manager of the associated property to sign the document for the lease renewal.

 Offer Accepted

 The lease renewal was approved by the tenant via Tenant Web Access (TWA) or manually by a Rent Manager user.

 Offer Accepted - Signable Document Completed

 If the renewal offer was delivered as a signable document, the tenant approved the lease renewal via TWA and signed the associated document.

 Offer Declined

 The lease renewal was rejected by the tenant via TWA or manually by a Rent Manager user.

 Offer Expired

 If the renewal offer was set to expire, the expiration date for the offer has passed before it was accepted by the tenant. The offer can no longer be completed and may need to be resent.

 Offer Sent

 The lease renewal has been sent to the tenant and is awaiting their response.

 Offer Voided

 The renewal offer was canceled and voided by a Rent Manager user.

 Signable Document Expired

 If the renewal offer was delivered as a signable document set to expire, the expiration date of the document has passed before it was signed or accepted by the tenant. The offer can no longer be completed and may need to be resent.

 Waiting Tenant Signature

 If the renewal offer was delivered as a signable document, the offer is waiting for the tenant to sign the document for the lease renewal.

 Renewal Offer Details

 The Renewal Offer Details section displays information about the new lease being offered to the tenant if they choose to renew. This information cannot be modified (only the Offer Expiration field can be edited).

 More Information

 If there is an issue with the current lease renewal offer and information needs to be changed, it is best practice to void the current renewal offer and generate a new one with the updated information. For more information, refer to Create Renewal Offers .

 To view any letter templates or signable documents sent to the tenant, click View Documents at the bottom.

 The fields that display are described below.

 Field
 Description

 Renewal Start

 The date on which the tenant's renewed lease will begin if they accept the renewal offer.

 Offer Expiration

 The latest date the lease renewal offer can be accepted by the tenant before it is null and can no longer be completed.

 Term(s) Offered

 The lease term(s) offered to the tenant for their renewed lease.

 More Information

 If the tenant was offered multiple leases, multiple lease term cards display. Each lease term card has its own New Rent and Renewal End field. The lease term chosen by the tenant displays highlighted in a separate Accepted Term Offer field.

 The following information displays on each lease term card:

 Lease Term

 The top of the card displays the name of the lease term, which is generally the duration of the lease ( 6 Months , 12 Months , and so on).

 New Rent

 The new dollar amount the tenant will pay for rent on the renewed lease.

 Renewal End

 The date on which the tenant's renewed lease is scheduled to end if they accept the renewal offer.

 Rent Charge Comment

 A note added to the tenant's new rent charge for the renewed lease, such as an explanation about why the rent increased.

 Recurring Charges

 Any additional recurring charges applied to the renewed lease that are not included in the New Rent amount, such as garage rental or utilities.

 The following columns display for each recurring charge:

 Source

 The level the recurring charge template is assigned to. Recurring charged are assigned at the tenant, unit, unit type, or property levels.

 Charge Type

 The name of the Charge Type assigned to the recurring charge.

 Unit

 The unit or rentable asset the recurring charge is assigned to. This column is available only when multiple leases are in the lease renewal offer.

 Current Amount

 The dollar amount the tenant pays for the recurring charge on the current lease.

 Current Comments

 The note(s) attached to the tenant's recurring charge on the current lease.

 Amount

 The dollar amount the tenant will pay for the recurring charge on the new lease.

 New Comments

 The note(s) attached to the tenant's recurring charge on the new lease.

 One-Time Charges

 Any additional one-time charges applied to the renewed lease, such as processing or cleaning fees.

 The following columns display for each one-time-charge:

 Charge Type

 The charge type assigned to the one-time charge.

 Unit

 The unit or rentable asset the one-time charge is assigned to. This column is available only when multiple leases are in the lease renewal offer.

 Amount

 The dollar amount the tenant will pay for the one-time charge on the new lease.

 Comment

 The note(s) attached to the one-time charge on the new lease.

 Signable Document Details

 The Signable Document Details section displays information about any signable documents assigned to the lease renewal offer. This information cannot be modified.

 The sections that display are described below.

 Section
 Description

 Dates

 The dates of when the signable documents assigned to the lease renewal offer were created and either completed, voided, or expired as well as when it was most recently signed.

 Document Information

 The status, entity type, publisher, and name of the primary tenant associated with the lease renewal offer.

 Signatures

 The total number of signers, the signers' email addresses, and the status of the signable documents assigned to the lease renewal offer.

 To view and/or download the PDF of the signable documents assigned to the lease renewal offer, select View Documents .
