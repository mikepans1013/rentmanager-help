# Property Groups (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Property-Groups.htm

Property groups allow you to choose two or more existing properties and group them together under a single heading in Rent Manager . Creating property groups makes selecting a large amount of properties for the sake of postings, reporting, and filtering much easier. Rather than selecting each property individually, you can simply select the property group and perform actions based on every property in the group.

 To create and manage property groups, go to arrow_forward Rental Info arrow_forward Rental Info Setup arrow_forward Properties/Units arrow_forward Property Groups .

 On the Property Groups page, each property group displays on a row with information organized into columns. Click on a property group to open the details pop-up for that transaction, where information specific to that property group is available.

 Column Descriptions

 The following columns are available on this page.

 Column
 Description

 Name

 The unique name used to identify the group.

 Properties

 The properties included in the group.

 More Information

 Only information related to the properties to which you have access displays. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .
