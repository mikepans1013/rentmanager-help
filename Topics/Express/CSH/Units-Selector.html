Unit Selector (Pop-Up)

The Unit Selector pop-up allows you to view units that are available for reservation and/or leasing in a defined date range. Once a unit is chosen, it can be selected and added to the field that opened the pop-up (e.g., Reserved Unit).

Related Privileges

Group Privilege Column
Tenants/Prospects Tenants View, Edit
Prospects View, Edit

For more information, refer to Control User Access.

The pop-up can be accessed from a prospect account's Reservation/Expected Lease Information tile or when creating a new tenant lease by clicking .

Filter Options

The following filters are available on this pop-up:

Option Description

Property

The property whose units should populate in the list.

Vacancy Based On Date

The date range used to examine the units' Status and determine whether or not they are vacant.

Show Vacant Units Only

If checked, only units that do not have an occupant or unavailable unit status in the selected date range display.

Includes

The type of rental (Units or Assets) to display.

These options display only if there is at least one rentable asset at the selected Property.

Column Descriptions

The following columns are available on this pop-up:

Column Description

Unit

The name of the unit.

Status

The number of tenants occupying the unit during the date range. If the unit is not occupied during the date range, Vacant displays.

Next Move Out

The current tenant's Move Out date, if applicable.

Next Occupant

The Move In date of any future tenant.

Unit Type

The category of the unit.
