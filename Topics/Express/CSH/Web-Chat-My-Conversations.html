My Conversations (Web Chat) (Page)

The My Conversations page allows you to access the queues you are assigned to and participate in active or pending conversations through the Web Chat feature. From here, you can log in and out of the available queues and start or transfer Web Chat conversations with visitors to your websites.

Even while logged into Web Chat queues, you can navigate to other areas of Rent Manager and be available for chats. If a new Web Chat request or message response is submitted to a queue you are logged into and you are not currently on the My Conversations page, you receive a red notification dot on the icon at the top right of Rent Manager Express. You can click this icon at any time to be redirected back to the My Conversations page.

Related Privileges

Group Privilege Column
Web Chat Queues View

For more information, refer to Control User Access.

To access Web Chat conversations, go to arrow_forward Communication arrow_forward Web Chat arrow_forward My Conversations.

The tiles described below are available on the page.

Queues

Warning

On the Manage Queues page, you must have Agent checked on the Chat Agents tile to log in to the associated queue. For more information, refer to Manage Queues (Web Chat) (Page).

This tile displays all the queues to which you have access, how many agents are currently logged in to accept chats, and how many incoming Web Chats are waiting for their chats to be answered.

To log in to a queue and begin answering Web Chat conversations, click Login. To log out of a queue, click Logout. Logging out during an active conversation results in the chat recipient receiving a notification of The agent is no longer available.

The following columns display on this tile:

Column Description
Queue

The name of the queue(s) to which you have access.

Pending

The number of visitors who have started a Web Chat from the associated queue's website and are waiting for their chat to be accepted by an agent.

Agent

The number of agents currently logged into the queue versus the total number of agents assigned to the queue.

Status

If you are currently logged into the queue, Online displays. Otherwise, Offline displays.

Active Conversations

This tile displays a list of all your active Web Chat conversations currently open on the right side of the page. Selecting a conversation from the list highlights the associated conversation tile. To refresh the tile and view an updated Duration, click .

The following columns display on this tile:

Column Description

Recipient

The name of the visitor with whom you are chatting.

Email

The email address of the visitor with whom you are chatting.

Duration

The number of minutes (m) that have passed since the chat was answered.

Pending Conversations

This tile displays a list of all Web Chat conversations waiting to be answered by an agent. Only chats for the queue(s) to which you are logged in display.

To refresh the tile and view an updated Waited For time, click . For more information on how to begin and manage active conversations, refer to Conduct a Web Chat Conversation.

The following columns display on this tile:

Column Description

Recipient

The name of the account who initiated the Web Chat on the website.

Queue

The queue in which the conversation is waiting.

Email

The email address of the visitor who initiated the chat.

Waited For

The number of minutes (m) the recipient has been waiting for their chat to be answered by an agent.

More Information

If a recipient closes their chat window before an agent answered the chat request, the conversation is moved from the Pending Conversations tile to the Closed Conversations page and assigned a status of Abandoned. For more information, refer to Closed Conversations (Web Chat) (Page).

Conversation Tile

All of your active conversations display on the right of the page. If you have no chats listed on the Active Conversations tile, no conversation tiles display. The name of the recipient displays in the header of the conversation tile, and a message with the recipient's contact information displays followed by the message they submitted.

The following fields display on the conversation tile:

Field

Description

Queue

The queue from which conversation originated.

Started

The date and time at which the Web Chat was submitted via the website.

Link

If the chat is linked to an account in Rent Manager, the name of that account displays as a hyperlink that jumps to their account when clicked.

If there is a link that is not correct, click to remove the link. Next click to link the conversation to the correct account.

The following actions are available on the conversation tile:

Action

Description

Add Notes

Any additional comments about the chat. These notes are visible only in Rent Manager for the individual conversation.

Completed

Once a chat is finished, click Completed to close the chat and mark it as complete. The conversation is then moved to the Closed Conversations page.

Actions

The available actions that can be taken for this Web Chat.

Send

Send the message entered in the text box to the recipient.

Saved Replies

Use a pre-created reply template from the list. Saved replies populate the text field with the preset answer set up on the Manage Queues page.

Insert Image

Browse your computer for an image file to insert into the chat.
