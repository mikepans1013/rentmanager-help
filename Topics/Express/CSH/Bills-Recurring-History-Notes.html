Recurring Bills History/Notes (Pop-Up)

History/notes allow you to record information that supplements or clarifies what’s entered in other fields, such as notes about phone conversations, items on a to-do list, and explanations about transactions. History/notes on recurring bills enable you to track important information about a bill, such as updates to the bill that were made during the period in which the bill was recurring.

Related Privileges

Group Privilege Column
Payables Recurring Bills View

For more information, refer to Control User Access.

To view your recurring bills history/notes, go to  arrow_forward Payables arrow_forward Bills arrow_forward Recurring Bills and select a recurring bill from the list. Then, on the action bar to the right, click  arrow_forward History/Notes.

Filter Options

The following filter options are available on the page. Depending on the size of your browser window, these filters may display at the top of the page, or you may need to click to view the filter options.

Option Description

Search

Enter information into this field to narrow the list to match your search criteria.

Filter By Date

Select or enter the From and/or To dates to filter notes created during the selected dates. Click to select a relative date range.

Users

Select the desired user(s) to filter for items created by one or more Rent Manager users.

History Category

Select the desired categories to include. To include history/notes with no category, select Unassigned.

Type

Select the desired types of history/note items.

Only Notes with Attachments

Check to display only history/notes that have an attachment.

Column Descriptions

The following columns display on this pop-up.

Column Description

Pin

If the history/note item has Pin enabled, displays. If there are no pinned notes, the column does not display.

Type

The system-generated history/note type. For example, if the history/note item is linked to a service issue, the Service Issue type displays.

Date

The date and time the note was created.

Note

The information to describe the history/note (e.g., The check for this bill has already been written). If no text is entered, the column displays blank.

If an attachment is uploaded to the history/note item, displays. Click to download the attachment or open it in a new tab.

Category

The category of the history/note selected from the available history categories. If no category is selected, the column displays blank.

User

The user who created the history/note. If this is a system-generated history/note, the user displays as Administrator.
