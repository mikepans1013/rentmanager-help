Asset Status History (Pop-Up)

From an asset's details page, you can view a record of the statuses assigned to the asset. Additionally, if the asset is not currently part of an asset workflow, you can change the status or assign the asset to a workflow. If the asset is currently part of a workflow, you can either change or advance the workflow, or undo the most recent status change.

Related Privileges

Group Privilege Column
Asset Management Manage Assets View

For more information, refer to Control User Access.

To view the history of statuses for an asset, go to arrow_forward Rental Info arrow_forward General arrow_forward Assets and select an asset from the list. Then, on the Asset Status History tile, click .

More Information

To remove the current asset status and return to the prior status of the asset, in the upper-right of the View Asset Status page, click Undo Last Status Change. However, if the asset is currently assigned to the starting status of an asset workflow, this option removes the asset from the workflow.

Column Descriptions

The following columns display in the pop-up:

Column Description

Status

The status that indicates the current state of the asset.

Date

The date on which the asset was placed in this status.

Duration

How long the asset has been in the status.

Comment

An optional note explaining the asset status.

User

The user who placed the asset in this status.
