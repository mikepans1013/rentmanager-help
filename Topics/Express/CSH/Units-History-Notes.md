# Unit History/Notes (Pop-Up)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Units-History-Notes.htm

History/notes allow you to record information that supplements or clarifies what’s entered in other fields, such as notes about service issues, items on a to-do list, and explanations about transactions. While some history/note items are automatically created by Rent Manager , you are also able to record information based on your needs. This makes it easier to track events related to each unit and provide additional details for internal reference.

 Filter Options

 The following filter options are available on the pop-up. Depending on the size of your browser window, these filters may display at the top of the page, or you may need to click to view the filter options.

 Option
 Description

 Search

 Enter search terms in the Search field to find history/notes that contain the searched text.

 Filter By Date

 Select or enter the From and/or To dates to filter notes created during the selected dates. Click to select a specific date range.

 Users

 Click the drop-down list and select users to filter for history/note items created by one or more Rent Manager users.

 History Category

 Select which categories of history/note items to include. To include history notes with no category, select Unassigned .

 Type

 Click the drop-down list and select types to filter history/note items by type.

 To select or deselect all options in the list, click the box next to the Search field.

 Only Notes with Attachments

 Check to display only history/note items that have an attachment.

 Tenant Notes

 Check to include history/note items from the tenant account associated with the current entity in the list.

 Column Descriptions

 The following columns are available on this pop-up:

 Column
 Description

 Pin

 Pinned history/notes always display at the top of the list.

 Type

 The system-generated history/note type. For example, if the history/note item is linked to a maintenance record, the Maintenance type displays.

 Date

 The date and time the history/note item was created.

 Note

 The text entered in the Note field of the history/note item. If no text is entered, the column displays blank.

 If an attachment is uploaded to the history/note item, displays. Click to download the attachment or open it in a new tab.

 Category

 The category of the history/note item selected from the available history categories. If no category is selected, the column displays blank.

 User

 The user who created the history/note item. If this is a system-generated item, the user displays as Administrator .
