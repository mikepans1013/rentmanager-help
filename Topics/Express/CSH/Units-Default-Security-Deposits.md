# Unit Default Security Deposits (Pop-Up)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Units-Default-Security-Deposits.htm

The View Default Security Deposits pop-up displays the charge type and amount that is typically charged to tenants when they move into a unit. Once established, these charges can be used in the Tenant Charge Setup system preferences to automatically generate the security deposit when a tenant moves into the unit.
