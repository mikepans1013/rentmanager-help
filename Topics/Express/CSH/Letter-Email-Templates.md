# Letter/Email Templates (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Letter-Email-Templates.htm

Letter/email templates allow you to store commonly used messages, messages you typically send to multiple recipients, or longer messages that contain very specific details that must be the same each time it is sent. This saves you time when creating communication through letters or emails. You can also use dynamic scripting commands in your templates to generate customized content for each recipient.

 Column Descriptions

 The following columns display on this page.

 Column
 Description

 Email

 A displays if the template can be used when writing emails.

 Letter

 A displays if the template can be used when writing letter batches or from the menu of the entity type.

 Signable

 A displays if the template includes a signature field, or other interactive fields, that can be sent to recipients and signed electronically.

 Description

 Additional information that describes the template (e.g., To be sent during lease renewals ).

 Name

 The unique name of the template, which is used when referencing the template throughout Rent Manager .

 Users

 The user(s) who have access to generate letters and/or emails from this template.

 Row/Bulk Actions

 Row actions are available from the menu and affect only the selected account. To perform the same action on multiple accounts, the Bulk Actions menu allows you to select an action and then check all the accounts on which to apply the action.

 The following actions are available from this page. Actions that may be performed in bulk are designated with a Check .

 Action

 Save the template as a file that can be stored on your computer outside of Rent Manager . You may wish to export a template to keep a backup copy stored locally, share with a coworker, or move it to a different Rent Manager  location. Templates are exported in the Rent Manager template (.rmtx) file type.

 Make your templates available to other Rent Manager users via the Online Template Library .
