# Income Verification Details (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Income-Verification-Detail.htm

AmRent 's Income and ID Verification allows property managers to obtain and review prospects' banking and identification information without the need to request paper documentation from the prospect and risk receiving a falsified report. With Income Verification, property managers can send a link to prospects directly from Rent Manager asking them to provide their banking information. When the request is received, the prospect logs into a secure portal and connects to their bank account using their online banking credentials. AmRent 's Income Verification pulls information from the bank account(s) provided and generates a report that includes account balances, transactions, and cash flow. You can also verify they provided a valid identification at the start of the process, ensuring the information is correct before income verification is processed.

 This report is received back into Rent Manager the same way users receive a screening report. Property managers can then use the information to make a quick decision about an applicant’s qualifications.

 More Information

 Although the Income and ID Verification feature is accessible within Rent Manager , the company that provides the service is AmRent 's partner Ibbie. Registered users can retrieve verification reports that can be instantly viewed or printed. Additionally, Income and ID Verification requires different credentials from AmRent Screenings . For information about getting an account or if you have Income Verification and want to utilize ID Verification as well, contact AmRent by calling 800-324-3681 or emailing info@amrent.com.

 Income Verification Information

 Field
 Description

 Status

 The current status of the verification request. To check for updates to the status, select Refresh Status . Each status is described below:

 Canceled

 The income verification invitation can no longer be completed by the tenant or prospect. Links generated by the income verification request expire forty-eight hours after being sent.

 Completed

 The income verification report is available on the tenant or prospect account.

 If there are multiple applicants, the total number of completed applicants displays. For example, if 3 out of 4 total applicants in a single application received income verification requests and only 1 has completed it, the status 1 of 3 Completed displays.

 Error

 AmRent encountered an issue during the income verification process and a new income verification invitation link must be sent.

 Expired

 The most recent income verification link has expired.

 If the applicant has an expired income verification link and requested a new link through Tenant Web Access (TWA) , the status Expired - Link Requested displays, prompting the user to resend an income verification link.

 Invitation Error

 AmRent was unable to send an income verification invitation link to the tenant or prospect. This error is typically caused by an invalid phone number or email address.

 Submitted

 An income verification invitation link has been delivered to the tenant or prospect.

 Sent To / Sent To Web User

 The email address listed on the tenant or prospect's details page. To have Rent Manager send the income verification invitation again, select Resend Invitation .

 Adverse Action Letters

 A drop down list of letter templates Rent Manager can generate and send to the applicant. To generate the letter in Rent Manager , select a template you wish to send and click Write Letter .
