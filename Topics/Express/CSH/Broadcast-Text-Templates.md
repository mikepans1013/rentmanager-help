# Text Templates (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Broadcast-Text-Templates.htm

Text templates allow you to quickly and efficiently populate frequently used messages for both individual and bulk text messaging. This ensures consistency in communicating common messages, regardless of when the text is sent or which user sent it. This reduces the risk of errors and allows users to sent well-composed texts without having to rely on memory of what the text should say.

 It is recommended that you create a template for every type of text that you send on a recurring basis or for texts that need to be sent out to more than one recipient.

 To access your text templates, go to arrow_forward Communication arrow_forward Texting/Phone arrow_forward Text Templates . Then on the left in the Type field, select an option from the drop-down list to display the text templates for that entity (e.g., Tenant , Prospect , Vendor , Owner , and so on).

 To organize your text templates into folders, click the drop-down arrow next to Add Template and select Add Folder . Text templates can then be moved or added to these folders.

 Column Descriptions

 The available columns are described in the table below. By default, some columns display only if added via clicking .

 Default Columns
 Description

 Description

 Additional information that describes the text template and what it is used for (e.g., To be sent to delinquent tenants ).

 Name

 The unique name of the text template, which is used when selecting the template throughout Rent Manager .

 Users

 The user(s) who have access to generate texts from this template.

 Available Columns

 Description

 Create Date

 The date on which this text template was created in Rent Manager .

 Create User

 The username of the Rent Manager user who created the text template.

 Folder

 The folder into which the text template is organized.

 Template Type

 The entity type for which the text template can be generated (e.g., Tenant , Owner , Vendor , and so on).

 Update Date

 The date on which the text template was last modified.

 Update User

 The username of the Rent Manager user who last modified the template.

 Row/Bulk Actions

 Row actions are available from the menu and affect only the selected template. To perform the same action on multiple templates, the Bulk Actions menu allows you to select an action and then check all the templates on which to apply the action.
