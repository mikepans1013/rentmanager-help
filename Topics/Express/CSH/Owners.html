Owners (Page)

In Rent Manager, owners are the people or organizations that own the properties you manage. If you are a fee-based management company, you will utilize the owner features in Rent Manager to perform tasks like receive owner contributions, collect management fees, and pay owners their equity distributions.

Related Privileges

Group Privilege Column
Owners Owners View

For more information, refer to Control User Access.

To view your owners, go to arrow_forward Owners arrow_forward General arrow_forward Owners.

On the Owners page, every owner record displays on a row with information organized into columns. Clicking on any owner opens the owner's details page, where information specific to that owner is available.

Column Descriptions

The following columns are available on this page. By default, some columns display only if added via .

Default Columns Description

Display Name

The name that displays on the Owners page. For example, the owner is a limited liability company (LLC) but the contact name displays for easier identification.

Street

The street of the Default address associated with the owner.

City

The city of the Default address associated with the owner.

State

The state of the Default address associated with the owner.

Postal Code

The postal code of the Default address associated with the owner.

Pay Method

The payment method for how Rent Manager records distribution payments to the owner (ACH, Check, Debit, and so on).

Additional Columns

Description

Address

The full Default address associated with the owner.

Comment

An additional note entered on the Comment tile on the owner's details page.

Email

The primary email address for contacting the owner.

Last Pay Date

The date of the most recent payment made to the owner through owner distributions.

Name

The full name of the owner.

Number of Properties

The total number of properties owned by the owner.

Phone

The Default phone number for contacting the owner.

Address: (Type)

Each Address Type is listed on the Columns pop-up. The owner's associated address of the selected type displays.

Phone Number: (Type)

Each phone number type is listed on the Columns pop-up. The owner's associated phone number of the selected type displays.

UDF:
(Owner Type)

Each owner-type user defined field is listed on the Columns pop-up. The value entered on the owner's account for the selected user defined field displays.

Send Text

  

Related Privileges

Group Privilege Column
Texting/Broadcast Send/Receive texts Enabled

For more information, refer to Control User Access.

Send a text message to the owner through the text messaging center. This option displays only if there is a text-enabled phone number listed on the account.

More Information

The first text sent to a recipient from the text messaging center and any texts sent via text broadcast or automated notification include an opt-out message. If a recipient opts out, that phone number cannot receive texts from Rent Manager unless they choose to opt back in. Recipients can opt out or opt in at any time. If a recipient wishes to opt back into text messaging, they must text Start from the phone number they opted out with to the number they originally requested to opt out of.

Phone numbers that have opted out of text messaging are identified on the account's View Contacts pop-up, where the checkbox in the T column is replaced with the words Opted out in red text.
