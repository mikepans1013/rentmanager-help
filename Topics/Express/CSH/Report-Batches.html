Report Batches (Page)

Report batches are collections of reports that can be generated simultaneously to save time and increase efficiency. You can configure the report options of each report in the batch to generate the reports automatically with little to no input from the user. Report batches can also be scheduled to generate at a certain time and date, and the reports are then emailed to the specified email address(es).

Related Privileges

Group Privilege Column
Letter/Email Templates/Reports/Packets Run reports Enabled

For more information, refer to Control User Access.

To access your report batches, go to arrow_forward Manage Batches.

Filter Options

In the Status drop-down, select the status option(s) to filter the report batches that display in the list:

Option Description

Standard

Include reports that were created by you, or are currently owned by you.

Shared

Include reports that were shared to you by another user, or that had ownership transferred to you.

Scheduled

Include reports that are scheduled to run automatically using report batch automation.

Column Descriptions

The following columns are available on this page:

Column Description

Batch Name

The unique name of the report batch.

Reports

The number of reports included in the batch.

Owned By

The username of the batch's current owner.
