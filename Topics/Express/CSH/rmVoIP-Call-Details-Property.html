rmVoIP Property Call Details (Page)

When you receive a phone call through rmVoIP, Rent Manager attempts to any account in your database with that phone number to immediately provide you with information about the caller. Call records that are linked to properties include basic details about the caller, notes describing the call, and the ability to add a service issue related to the call linked directly to the property.

More Information

This feature is licensed and must be purchased separately. For more information, contact your sales representative at sales@rentmanager.com.

To view the details of an rmVoIP call linked to a property, go to arrow_forward Communication arrow_forward Texting/Phone arrow_forward rmVoIP Incoming Call History. Then, select a call with the Link Type of Property from the list.

Basic Information

At the top of the page, the following read-only details about the incoming call display.

Field Description

Address

The address marked as Default on the property associated with the phone number that received the call.

Related Privileges

To view the linked property's address, the following privilege is required:

Group Privilege Column
Properties/Units Properties View

For more information, refer to Control User Access.

Caller ID

Identifying information provided by the caller's phone service, such as their name, company name, or phone number.

Date/Time

The date (in MM/DD/YYYY format) and time that the call took place.

Link Type

The Rent Manager entity (i.e., Property) linked to the call.

Phone Number

The ten-digit phone number of the caller.

Call History

The Call History tile displays any additional add information to explain the call. This information also displays on the property's History/Notes.

Field Description

Category

The history category related to this comment.

Comment

A note explaining the call, such as the purpose for the call, any next steps that need to be taken, the emotional state of the caller, or the resolution.

Contact was made

Indicates that the call was answered and a conversation took place with the caller, as opposed to a voicemail message or receiving no answer from the caller.
