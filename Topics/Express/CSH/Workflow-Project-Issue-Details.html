Workflow Project Issue Details (Pop-Up)

When adding an issue step to a workflow project, the Edit Issue pop-up allows you to configure details about the service issue. For example, you can link it to a particular entity, edit its basic information, set required user-defined fields (UDFs) and more. When adding steps to a workflow project, use issues rather than tasks when the work involved is more complex.

More Information

The Edit Issue pop-up is available only after you have added an issue step but before you have saved that addition. After you save the workflow project, you can still make changes to the issue from the issue's details page. For more information, refer to Issue Details (Page).

To edit a new issue in a workflow project, go to arrow_forward Services arrow_forward Workflows arrow_forward Workflow Projects and select a workflow project from the list or click Add Workflow Project. Then select Add Step arrow_forward Issue, and, in the issue's row, select arrow_forward Edit.

Issue Details

In the Details tile, the following fields are available.

Field Description

Description

A brief explanation of the work required to complete the issue.

Due

The date by which the issue needs to be completed.

Open

The date the issue was created. This date is used to calculate the age of the issue.

Title

The name of the service issue (e.g., Fill Out Paperwork, Check Water Meter, Change Furnace Filters, and so on).

Issue Information

In the Information tile, the following fields are available.

Field Description

Assigned To

The user assigned to complete the issue. All active Rent Manager users display in this field.

Category

The classification that best describes the type of issue being created.

Job

If job costing is enabled, you can assign this issue to a specific job. All of the charges included in this invoice are tracked by the chosen job. For more information, refer to Jobs (Page).

Related Preferences

In order to use the job costing tool in Rent Manager, Enable job costing must be checked in system preferences. For more information, refer to General Options (System Preferences).

Priority

The issue priority that describes the urgency of the issue.

Status

The condition that describes the current progress of the issue, such as New or In Progress.

Vendor

The vendor associated with the work do be done on this specific issue.

Issue Links

You can link records about the work in this step with the properties, units, tenants, and prospects associated with the issue. Issue links keep detailed historical records on each linked account with history/note items. When links are added to an issue, a history/note item is added to each linked entity account.

Issue Required User Defined Fields

In the Required User Defined Fields tile, issue-type user-defined fields (UDFs) that must have values entered display. Enter information into the Value column for each required UDF.

More Information

This section displays only if at least one UDF is marked as required for issue-type UDFs. For more information, refer to User Defined Fields (Page).
