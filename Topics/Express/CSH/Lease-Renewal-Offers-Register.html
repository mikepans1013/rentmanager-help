Lease Renewal Register (Page)

The Lease Renewal Register page shows the current status of the lease renewal offers made to tenants via the Create Renewal Offer wizard. On this page, you can view and filter a list of all renewal offers that have been generated. You can also perform actions for multiple lease renewals at once.

Related Privileges

Group Privilege Column
Tenants/Prospects Lease Renewal Offers View

For more information, refer to Control User Access.

To view your list of lease renewals, go to arrow_forward Rental Info arrow_forward Leasing arrow_forward Lease Renewal Register.

On the Lease Renewal Register page, every lease renewal offer displays on a row with information organized into columns. Renewal offers display in red text if the tenant's current lease is expired and the offer is not yet completed. Clicking on any renewal offer opens the offer's details page where information specific to that renewal offer is available.

Filter Options

You can filter the list of renewal offers that display on the page. Click Show Quick Filters to configure additional filter options and click Apply to filter the list. The available filters are described below.

Filter Description

Lease Expires

Enter a date range to display only renewal offers for leases with a Lease End date that falls on or within the specified dates.

Lease Terms

Select a lease term(s) to display only lease renewals with that term(s).

Leasing Agent

Select a leasing agent to include only renewal offers assigned to that agent in the list.

Offer Expires

Enter a date range to display only lease renewal offers with an Offer Expiration date that falls on or within the specified dates.

Properties

Select the properties or a Group of properties to include in the list.

Renewal Status

Select a renewal status(es) to narrow down the list to display only lease renewals with that status(es).

Saved Filters

Select a previously saved system filter to narrow down the list based on that filter's criteria. To create a new system filter, click . For more information, refer to Add a System Filter.

Search

Type in a keyword to narrow down the list by that search criteria, such as a tenant name, property, or unit.

Show Recently Completed

If selected, the list includes only lease renewal offers that were completed in the last sixty days.

Unit Type

Select a unit type(s) to include only leases with a unit of that unit type(s) in the list.

User Defined Field

Select a tenant-type user-defined field (UDF) and, in the User Defined Value field, enter criteria by which to narrow down the list based on that UDF value.

Column Descriptions

The following columns are available on this page. To customize the columns that display on the page, click .

Default Column Description

Completed

Indicates that the renewal was manually completed by a Rent Manager user, officially closing the offer.

Delivery Method

The communication method by which the lease renewal offer was sent to the tenant when the offer was created: Write Letters, Compose Email, Publish Signable Document, or Create Document Packet.

Lease End

The date on which the tenant's current lease contract is set to end, as entered in the lease's details.

Name

The full name of the tenant.

Offer Expiration

The latest date the lease renewal offer can be accepted by the tenant before it is null and can no longer be completed.

Property

The property at which the tenant's lease is located.

Renewal Start

The date on which the tenant's renewed lease will begin if they accept the renewal offer.

Renewal Status

The current status of the renewal offer in the renewal process. Each status is described below.

More Information

If you are using the Blue Moon integration, there are additional statuses with a prefix of Blue Moon. These statuses reflect the renewal offer's current status in the Blue Moon integration and work similarly to the statuses listed below.

Needs Landlord Signature

If the renewal offer was delivered as a signable document, the offer is waiting for an owner or manager of the associated property to sign the document for the lease renewal.

Offer Accepted

The lease renewal was approved by the tenant via Tenant Web Access (TWA) or manually by a Rent Manager user.

Offer Accepted - Signable Document Completed

If the renewal offer was delivered as a signable document, the tenant approved the lease renewal via TWA and signed the associated document.

Offer Declined

The lease renewal was rejected by the tenant via TWA or manually by a Rent Manager user.

Offer Expired

If the renewal offer was set to expire, the expiration date for the offer has passed before it was accepted by the tenant. The offer can no longer be completed and may need to be resent.

Offer Sent

The lease renewal has been sent to the tenant and is awaiting their response.

Offer Voided

The renewal offer was canceled and voided by a Rent Manager user.

Signable Document Expired

If the renewal offer was delivered as a signable document set to expire, the expiration date of the document has passed before it was signed or accepted by the tenant. The offer can no longer be completed and may need to be resent.

Waiting Tenant Signature

If the renewal offer was delivered as a signable document, the offer is waiting for the tenant to sign the document for the lease renewal.

Selected Term

If the tenant was offered multiple lease term options to choose from, the term they chose displays. If only one term option was offered, the offered lease term displays.

Unit

The unit associated with the tenant's lease.

Terms Offered

The lease term(s) offered to the tenant for their renewed lease. Additionally, a badge displays when tenants have an offer that includes multiple leases.

Available Column

Description

Completed By

The username of the Rent Manager user who completed the offer.

Completed Date

The date on which the offer was marked complete.

Created By

The username of the Rent Manager user who initiated the lease renewal offer.

Decline Comment

A note entered by the tenant when they declined to renew the lease via TWA.

Document Expiration Date

The latest date the associated signable document can be signed by the tenant.

Document Status

The current stage of the signable document associated with this lease renewal (e.g., Published, Pending Acceptance).

Expected MO

The date on which the tenant tentatively plans to move out of the unit, as entered on their lease's details in the Expected Move Out field.

Last Updated

The date on which the lease renewal was last modified or updated by a tenant or Rent Manager user.

Move Out

The date on which the tenant officially moves out of the unit, as entered on their lease's details in the Move Out field.

Notice Date

The date on which the tenant informed the landlord that they plan to vacate the unit and end their lease.

Renewal End

The date on which the tenant's renewed lease is scheduled to end if they accept the renewal offer.

Unit Type

The unit type of the unit associated with the tenant's lease.

Updated By

The username of the Rent Manager user who last modified the lease renewal. If the lease renewal was last updated by a tenant via TWA, either the name or email address of the tenant displays.

Row/Bulk Actions

Row actions are available from the menu and affect only the selected account. To perform the same action on multiple accounts, click Bulk Actions and select an action, then check all the accounts on which to perform the action.

More Information

You can only change the status (accept, decline, etc.) for multiple records that share the same current renewal Delivery Method and Renewal Status.
