STR Property Marketing Setup (Pop-Up)

The Marketing Setup pop-up for short-term rental (STR) properties allows you to specify how you want your property's information to display for STR Online Booking. Enter details for how you would like to be contacted, how your units are grouped, and what images display on the online booking portal.

Related Privileges

Group Privilege Column
Properties/Units Properties View, Edit

For more information, refer to Control User Access.

Warning

To access the STR Online Booking tool, at least one of your properties in Rent Manager must have the RV/Campground property type assigned.

To manage the marketing information for an STR property, go to arrow_forward Rental Info arrow_forward General arrow_forward Properties and select a property with a Property Type of RV/Campground. Then, on the action bar to the right, select arrow_forward Marketing Setup.

Related Preferences

This page is available only if both of the following settings are enabled in system web preferences:

  • The database location for STR Online Booking in the Licensing section. For more information, refer to Licensing (System Web Preferences).

  • The property in the STR Online Booking section. For more information, refer to RV/Campground Online Booking General (System Web Preferences).

Related Preferences

The date listed in the banner at the top of the Marketing Setup pop-up is based on the settings selected for Number of days in the future a guest can book a reservation in system web preferences. For more information, refer to STR Online Booking RV/Campground Settings (System Web Preferences).

To copy the URL for the property's STR Online Booking portal to your clipboard, click Copy STR Online Booking Link. You can then paste the URL in another location, such as a document, a browser's address bar, or any other text editor.

To send an email that includes the URL to the property's STR Online Booking portal, click Email STR Online Booking Link. The body of the email includes a direct link to the portal and directs the recipient to access the portal from the hyperlink.

Contact Information

In this section, you can specify how your property is named and contacted from the STR Online Booking portal.

Field Description

Property Name

How your property name displays on the online booking portal. Property: Property Full Name, as entered on the property's details page in the General section, is selected by default. Alternatively, select any property-level user-defined field (UDF).

Contact Email

How your property is contacted via email from the online booking portal. Field: Property Email Address, as entered on the details page in the General section, is selected by default. Alternatively, select any property-level UDF.

Contact Phone

The property phone number that displays on the online booking portal. Field: Office Phone, as entered on the details page in the Phone Numbers section, is selected by default. Alternatively, select either Field: Fax Phone (also pulled from the Phone Numbers section) or any property-level UDF.

Property Logo

The logo image for the property that displays on the online booking portal. Field: Property Logo is selected by default and displays the logo image found on the property's details page in the Property Logo section.

Miscellaneous

In this section, you can add images and description information to your STR Online Booking portal.

Field Description

Property Images

The property image types that you want to display on the portal. Any images added to the property's details page with the selected image type(s) are included and display at the top of all site group pages (e.g., Campsites). Click Preview to view images from the selected image types that display on the portal.

Confirm that each image type that you choose has at least one image of that type on the property's details page. Otherwise, no images for the property display on the portal, even if an image type is selected.

Unit Images

The unit image types that you want to display on the portal. For units at the property, any images added to the unit's details page with the selected image type(s) are included and display when on a specific unit tile on the portal, a guest clicks View Images.

Confirm that each image type that you choose has at least one image of that type on the unit's details page. Otherwise, no images for the unit display on the portal, even if an image type is selected.

Unit Description

The descriptive text that advertises the units on the STR Online Booking portal. Unit: Marketing Description (default), as entered in the Miscellaneous section of each units' details page, is selected by default. Alternatively, select any unit-level UDF.

Site Groups

This section displays all site groups currently established at the property. Site groups organize units at an STR property based on their rate schedules. On the STR Online Booking portal, site groups allow for units of a similar price to be grouped together. To add another site group to the property, click Add Item in the section header.
