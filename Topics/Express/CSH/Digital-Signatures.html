Digital Signatures (Page)

Digital signatures are an image of a handwritten signature that can be saved and placed on printed checks to save time. A digital signature is still recognized by banks, making it a valid and secure alternative to handwritten signatures.

Column Descriptions

The following columns display on this page.

Column Description

Name

The name of the digital signature.

Description

The optional message about the digital signature such as when to use the signature.

Signature

A thumbnail image of the digital signature.

Users

The name of each user who can use the digital signature on checks.
