Property Marketing Advanced Settings (Pop-Up)

The internet listing service (ILS) marketing integration allows you to create online listings for the available properties and units in Rent Manager and push those listings to ILS providers such as the Zillow Group (Zillow, Trulia, and HotPads) and the Apartments.com Network. The Advanced Settings pop-up allows you to more specifically describe your property, as well as override system preferences on a property-by-property basis.

More Information

Before enabling online listings, ensure that you have entered marketing information for the properties and units you intend to market on ILS sites. For more information, refer to Property Marketing Setup (Pop-Up).

Related Privileges

Group Privilege Column
Properties/Units Properties View, Edit

For more information, refer to Control User Access.

To record more specific marketing information, go to arrow_forward Rental Info arrow_forward General arrow_forward Properties and select a property from the list. Then, on the action bar to the right, click arrow_forward Marketing Setup. From the Marketing Setup pop-up, click Advanced.

Preferences

The Preferences section contains two sub-sections: Feed Information and Agent Information. These sections allow you to input the information that is included in online listings, including the ILS feed type, virtual tour URL, leasing agent details, and the websites to which listings are posted.

Feed Information

Fill out the following fields to quickly organize any necessary information for your marketing process. Use the drop-downs to select an existing Rent Manager field or manually enter a value.

Field Description

Feed Type

Indicate if the property contains Multi Family or Single Family listings to categorize the ILS sites to which this property is marketed. This field automatically populates based on the property type set on the property's details page. For more information, refer to ILS Marketing Feed Types.

Warning

This field is required by ILS sites. If left blank, your listing is rejected.

Property Type

The category that best describes the type of property you are marketing. If you do not specify a category, this field automatically populates with the Property Type set on the property's details page.

Rental Type

Specifying a rental type determines if ILS sites post the property on multiple sites. For example, if you select Student, providers know to post to the listing as a student housing option on student housing sites.

Click the drop-down arrow to choose the type of housing this property support or leave the rental type unspecified.

Marketing Name

The name used on ILS sites to promote your property. Enter a name or select an option from the drop-down list to determine the marketing name.

Listing URL

The URL on which the property is listed (for example, your property management company's website). This URL displays on ILS sites to provide more exposure.

Virtual Tour URL

The URL on which a virtual tour is available so that prospects can see the property from an ILS site.

Latitude

The latitude coordinates of your property to specify the exact location of your listing and make GPS directions easier to obtain.

Longitude

The longitude coordinates of your property to specify the exact location of your listing and make GPS directions easier to obtain.

Rental Classification

The rental classification is assigned a default value based on the Property Type set on the property's details page. If the Rental Classification defaults to Unspecified, select an option from the drop-down list that further specifies the property you are marketing. For example, you can distinguish different kinds of student housing by selecting Apartment, Campus, House for Rent, and so on.

This information is used by some ILS providers to match properties with specific rental categories as closely as possible.

Agent Information

In this section, enter the leasing agent's first and last name, email address, and phone number. Use the drop-downs to select an existing Rent Manager field or manually enter a value. Use this section to provide ILS sites with agent information that prospects can use to inquire about the property.

Warning

If you wish to include agent information on your listings, you must provide the First Name, Last Name, and Email Address. ILS sites reject all agent information if any of these three fields are not present.

Provider Settings

This section allows you to override the ILS sites established in the Online Listings section of system preferences for a property. To have the property use the settings enabled in system preferences, leave Override System Preferences unchecked.

To set up the property with ILS providers that differ from your system preferences, check Override System Preferences and the Provider Contact Information pop-up displays. Enter your Name, Email, and Phone number. This information is supplied to different ILS providers in case they need to contact you about your paid listings.

Check Enable Online Listings and from the drop-down list, check any ILS providers that you use to market your property. Only providers that are checked can access and post your listings to their sites. Future listings posted from this property follow these settings instead of system preferences.

More Information

ILS providers may have unique requirements or conditions for properties and units to be posted. For more information, refer to the help text below the provider name.
