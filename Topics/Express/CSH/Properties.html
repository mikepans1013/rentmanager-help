Properties (Page)

Most people think of properties in terms of real estate. You may own or manage a variety of real estate: single-family homes, duplexes, apartment buildings, strip malls, storage facilities, manufactured home sites, etc. These properties offer rentable spaces to tenants. In Rent Manager, the definition of property is expanded to include any entity, such as a management company, that has its own financial data (i.e., generates revenue and incurs expenses).

To view a list of your properties, go to arrow_forward Rental Info arrow_forward General arrow_forward Properties.

On the Properties page, each property displays on a row with information organized into columns. Click on a property to open the Property details page, where information specific to that property is available.

More Information

Only properties to which you have access display. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property.

Column Descriptions

The following columns display on the page. By default, some columns display only by using .

Default Column Description

Name

The full name of the property.

Short Name

The abbreviated name of the property.

Email

The email address used to contact the property manager.

Manager Name

The name of the person responsible for managing the property.

Primary Address

The address marked Default for the property.

Billing Address

The address marked Billing for the property.

Available Column

Description

Active

A green indicates that Active is checked on the General tile.

Billing Name1

If applicable, a property name to be used on billing statements.

Billing Name2

If applicable, a secondary property name to be used on billing statements.

City

The city marked Default on the Primary Address tile.

Comment

Any additional notes entered on the Other Information tile.

Default Bank

The operating bank account for this property. This is the bank that typically pays expenses and receives payments for this property.

NSF Fee

The non-sufficient funds (NSF) fee amount charged to tenants whose payments are rejected. The system default amount displays unless a custom amount has been established on the property details page's Other Informationtile.

Owner Email

The email address of the owner associated with the property.

Owners

The name(s) of the owner(s) associated with the property.

Phone

The property phone number marked as Default.

Postal Code

The postal code marked Default on the Primary Address tile.

Posting Day

The day of the month that recurring charges should be posted to the tenant accounts of this property.

Primary Owner

The owner with the highest percentage ownership or the main contact for this property.

Property Type

The system category that best describes the property for organizational or functional purposes.

State

The state marked Default on the Primary Address tile.

Statement Method

The default delivery method for sending statements to tenants at this property.

Street

The street marked Default the Primary Address tile.

Total Square Feet

The combined total of square footage for all units at this property.
