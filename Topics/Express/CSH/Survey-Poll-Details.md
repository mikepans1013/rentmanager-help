# Survey/Poll Details (Pop-Up)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Survey-Poll-Details.htm

Surveys allow you to connect with your tenants and collect their feedback on your properties, units, management, and amenities. The survey tool helps you to create and publish surveys/polls directly to Tenant Web Access (TWA) to prompt tenants to complete them when they next log in. The Survey Details pop-up allows you to view and manage general information and questions associated with the currently selected survey.

 More Information

 This topic describes the details page of surveys distributed through TWA. For more information on the details page of surveys sent via email and/or text message, refer to Survey Details (Pop-Up) .

 Details

 This tile includes the following fields:

 Field
 Description

 Survey Type

 The type of survey. For surveys published to TWA, this field is always Tenant .

 More Information

 Surveys can also created to collect feedback for service issues. These surveys can be manually distributed through email and/or text message, or set up to send automatically based on various criteria. For more information on the details page of Issue -type surveys, refer to Survey Details (Pop-Up) .

 Send Option

 The method ( Publish to TWA ) by which the survey is sent to tenants.

 Status

 The current state of the survey.

 Completed

 The survey was published to TWA and its End Date passed.

 Draft

 The survey was created and saved but has not been published to TWA.

 In Progress

 The survey was published to TWA and has not yet reached its End Date .

 Voided

 The TWA survey was manually voided by a Rent Manager user.

 Void

 When checked, the survey was voided by a Rent Manager user and cannot be published to TWA or receive responses. This option displays only if the survey is currently In Progress .

 Name

 The name of the survey that displays within Rent Manager .

 Display Name

 The name of the survey that displays in TWA.

 Description

 The comments that display only to Rent Manager users.

 Introduction Page

 The Introduction Page tile describes the purpose of the survey, which displays when the tenant begins a survey in TWA. To create a dynamic introduction message using scripting, click Open Script Builder for scripting assistance. For more information, refer to Scripting .

 Questions

 This tile include the following columns:

 Column
 Description

 Question

 The question asked to the tenant taking the survey.

 Required

 Indicates whether the tenant must respond to the question before submitting their response.

 Response Type

 The data type used for collecting tenant responses.

 Dropdown List

 Tenants select a single response from a list of pre-defined options.

 Multiple Selection

 Tenants select one or more responses from a Selection List of pre-defined options.

 Star Rating (1-5)

 Tenants select a numerical rating from 1-5 to indicate their satisfaction.

 Text

 Tenants manually enter a response.

 Yes/No

 Tenants select Yes or No as a response.

 Closing Page

 The Closing Page tile displays the message the tenant sees in TWA upon completing the survey. To create a dynamic closing page message using scripting, click Open Script Builder for scripting assistance. For more information, refer to Scripting .

 Publish Options

 This tile includes the following options If the survey is already published to TWA, this tile becomes read-only.

 Field
 Description

 End Date

 The final date that tenants can respond to the survey.

 Properties

 Each property whose tenants can receive and respond to the survey.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Publish to Board Members Only

 If only properties with the Property Type of Association are selected and this field is checked, only individuals set up as board members (e.g., Chair , Treasurer ) can respond to the poll. For more information, refer to Association Board Members (Pop-Up) .

 Publish to TWA for the Following Accounts

 This tile includes the following columns about the tenants included in the survey. If the survey is already published to TWA, this tile becomes read-only and no additional tenants can be added to participate.

 Column
 Description

 Account Name

 The full name of the tenant account's primary contact.

 Address

 The address marked as Default on the tenant's details page.

 Property

 The property where the tenant resides.

 Unit

 The unit the tenant is leasing.
