Tenant Contacts (Pop-Up)

The View Contacts pop-up lets you view and manage information about the people associated with your tenant's account. Contacts could be other occupants added to the tenant account, co-signers, business contacts, etc. The primary tenant automatically displays first on this pop-up as a contact.

Related Privileges

Group Privilege Column
Tenants/Prospects Tenants View, Edit

For more information, refer to Control User Access.

To view a tenant's contacts, go to arrow_forward General arrow_forward Rental Info arrow_forward General arrow_forward Tenants and select a tenant from the list. Then, on the Contacts tile, click . To view contacts associated with the prospect that are no longer active, click Show Inactive.

The yellow tag is the assigned Type that represents the tenant contact assigned in the Type field. The email that displays beneath the yellow tag can be found in the Email Address field. Additionally, the phone number that displays is the number selected as Default in the Phone Numbers section. If you have an image of your tenant contact, you can add it to the contact.

The following status options are available for the contact:

Field Description

Active

The contact is currently associated with the tenant. This allows you to deactivate a contact, such as in the event of a roommate backing out of the lease, without deleting the contact's historical record.

Board/Committee Member

If the tenant is associated with an Association-type property and is designated as a board and/or committee member, an indicator (Board Member, Committee Member, or Board Member | Committee Member) displays above their name.

Primary

Indicates that the contact is the primary person your property management company communicates with. One contact must be designated as Primary on each tenant's account. When you add a tenant, the first contact on the account is always the tenant.

Show On Statement/Labels

Includes the contact's name on tenant statements or labels. Only two contacts may have Show On Statement/Labels checked on each prospect account. The first contact on the account is always the tenant, so by default, the tenant has Show On Statement/Labels checked.

Personal Information

The following fields display in the Personal Information section.

Field Description

Age

The contact's age based on the date in the Birthday field and the current date.

Annual Income

The contact's annual net income.

Related Privileges

To view the total annual amount, the following privilege is required:

Group Privilege Column
Tenants/Prospects View annual income Enabled

For more information, refer to Control User Access.

Applicant Type

The type of applicant that best describes the contact (e.g., Primary).

Birthday

The contact's date of birth.

Contact Type

The user-created contact type that best describes the contact (e.g., Co-Signer).

Email Address

The contact's primary email address. To view or update the contact's preferences regarding emails from Rent Manager, click Manage Subscriptions. An icon displays if the contact is subscribed to all categories(), unsubscribed from the General category(), or unsubscribed from all categories(). For more information, refer to Unsubscribe From Emails.

Employer

The name of the contact's employer.

First Name

The contact's first name.

Last Name

The contact's last name.

License Plate #

The license plate number of the contact's vehicle.

Middle Name

The contact's middle name.

Social Security #/

Tax ID

The contact's social security number (SSN). For commercial tenants, the field name of Tax ID displays for the contact's taxpayer identification number (TIN).

Related Privileges

To view the full social security number, the following privilege is required:

Group Privilege Column
Tenants/Prospects View complete tenant SSNs Enabled

For more information, refer to Control User Access.

Vehicle

The make and model of the contact's vehicle.

Address

This section displays the associated addresses of the contact. To view additional addresses, select one from the tabs at the top of the tile, using the arrows to view additional tabs.

User Defined Fields

This section displays any contact-type user defined fields (UDFs) and, when applicable, the Value of the UDF.

Phone Numbers

This section tracks the contact numbers for the contact organized by phone number types. The number used as the primary contact for this account is marked as Default. Additionally, if a phone number can be used for text messaging, it is marked in the T column.
