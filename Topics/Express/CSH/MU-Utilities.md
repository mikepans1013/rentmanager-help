# Utilities Page (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/MU-Utilities.htm

The Utilities page allows you to manage utility information for tenants and units using Metered Utilities (MU) . It also allows you to edit and create different utilities such as gas, electric, water, and sewer used to bill tenants based on their consumption (usage) of that utility. To manage these utilities in Rent Manager , you must first create the utilities for each type you track (e.g., gas, water, and so on) and choose the charge type used for billing the utility, as well as which properties use each utility.

 Column Descriptions

 The following columns are available on this page. By default, some columns display only if added via .

 Default Column
 Description

 Charge Type

 The charge type being used to charge the tenants for the selected utility.

 Comment

 Additional information on the utility, as established on the Utility Detail page's Comment section.

 Contact Name

 The name of the utility's company representative.

 Email

 The email address of the utility's company representative.

 Properties

 The properties at which this utility is available.

 Utility Name

 The name of the utility based on what the utility is measuring.

 Available Column

 Description

 Default Expense Account

 The default expense account assigned to this utility, as displayed on the Utility Detail page's Master Meters tile.

 Default Vendor

 The name of the vendor assigned to this utility, as displayed on the Utility Detail page's Master Meters tile.

 Master Meters

 A displays if a master meter is set up for this utility.
