# rmVoIP Unlinked Call Details (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/rmVoIP-Call-Details-Unlinked.htm

When you receive a phone call through rmVoIP , Rent Manager attempts to any account in your database with that phone number to immediately provide you with information about the caller. If there is no match, it displays as an unlinked call to which you can link to an existing account or create a new tenant or prospect account to associate the phone number with.

 More Information

 This feature is licensed and must be purchased separately. For more information, contact your sales representative at sales@rentmanager.com .

 To view the details for an unlinked call, go to arrow_forward Communication arrow_forward Texting/Phone arrow_forward rmVoIP Unlinked Calls and select a call from the list.

 More Information

 If the unlinked call is associated with a tenant or prospect account that does not exist in your Rent Manager database, click Add Tenant or Add Prospect to create a new tenant or prospect to link.

 Call Information

 The section at the top of the page displays the following information about the unlinked call.

 Field
 Description

 Date/Time

 The day and time the incoming call was received.

 Phone Number

 The number associated with the incoming call.

 Caller ID

 The name that displayed when the call was received.

 Call History

 This tile displays the following information for adding call history information to the unlinked call. Once the call is linked to an account, the note displays on the account's History/Notes .

 Field
 Description

 Category

 The history category that identifies what the call was about.

 Comment

 The explanation of what you discussed with the caller.

 Contact was made

 If checked, signifies that you spoke with the caller, as opposed to a voicemail message or receiving no answer from the caller.

 Link Call

 This tile allows you to select the Account Type to link to the call. Once the appropriate Account Type is selected, the Account Name field displays to select the specific entity to link to the call.
