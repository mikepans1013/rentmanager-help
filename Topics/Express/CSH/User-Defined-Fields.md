# User Defined Fields (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/User-Defined-Fields.htm

User defined fields (UDFs) are custom fields used to track information that Rent Manager does not track by default. Each Rent Manager entity (e.g., tenant, prospect, property, unit, etc.) can have a unique set of UDFs. While each account within an entity shares the same set of UDFs, the values are specific to the selected account.

 To view and manage the UDFs, go to arrow_forward Administration , then go to Customization arrow_forward User Defined Fields . User defined fields are organized by Type . Click on a Type , and corresponding UDFs of that type populate in the center of the page.

 Column Descriptions

 The following columns display on the page:

 Column
 Description

 Name

 The unique name of the UDF.

 Field Type

 The control type the UDF value uses. For example, a Date type means the value of the UDF can only be entered as a calendar date.

 Is Required

 If checked, the UDF is mandatory. Entities cannot be created unless the required UDF value is completed.

 Default Value

 The value that populates by default when a new entity is created. It does not affect values already defined for existing UDFs.
