Address Book (Pop-Up)

The Address Book allows you to record the contact information for people or businesses you email. For your convenience, entities like tenants, prospects, and owners are automatically added to your Address Book at the same they are created in Rent Manager. Any contacts manually added to the Address Book, however, are user-specific and can be viewed or edited only by the user that created them.

Related Privileges

Group Privilege Column
System Compose Email Enabled

For more information, refer to Control User Access.

To view and manage the Address Book, go to arrow_forward Communication arrow_forward Email arrow_forward Send Email. Then, click To..., Cc..., or Bcc.... To add a contact to the email from the pop-up, click Add New.

Filter Information

The following filtering options are available on this page.

Filter Description

Search

Enter the desired search criteria to display results with a Name that matches the search criteria.

Show unsubscribed recipients

Check to display entities who are unsubscribed from the General emailing list.

Type

Use the drop-down list to select which entity type(s) to display.

Column Descriptions

The following columns display on the pop-up:

Column Description

Contact

The name of the individual contact.

Email

The contact's email address as entered on the View Contacts pop-up. If the entity is unsubscribed from the General emailing list, displays. Alternatively, if they are unsubscribed from all emails, displays. For more information, refer to Unsubscribe From Emails.

Name

The primary account name associated with the contact. For example, if the primary contact for a tenant account is Alexander Smith and they have a roommate named Jane Smith with separate contact information, Alexander Smith displays in this column.

Phone Number

The contact's phone number marked as Primary on the View Contacts pop-up.

Type

The contact's associated entity type (Tenant, Property, User, etc.). If you manually added contacts to the address book that are not linked to an entity in Rent Manager, those contacts display as Personal Address Book-type.
