# Recurring Issues (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Issues-Recurring.htm

Recurring issues are issues that repeat on a scheduled basis. For example, you can use recurring issues to set a reminder, such as posting monthly late payment notices or replacing smoke alarm batteries yearly. This Service Manager tool allows you to create issue templates that generate single issues automatically based on a schedule you designate.

 Filter Options

 By default, the list filters to show only issues assigned to you. To display all issues, click on the Assigned To filter. The following filter options are available on this page:

 Option
 Descriptions

 Search

 Allows you to display only issues that contain data matching what you enter in this field. For example, you can put in the Issue ID or something from the issue description.

 Show Quick Filters

 A set of commonly used filters to allow easy access.

 You can enter any combination of the following filters:

 Property

 When the Property tab is selected, only issues associated with the properties or property groups selected display.

 Owner

 When the Owner tab is selected, only issues associated with the owner or owner groups selected display.

 Category

 Only issues with the same Category selected in the issue details display.

 Priority

 Only issues with the same Priority selected in the issue details display.

 Status

 Only issues with the same Status selected in the issue details display.

 Vendor

 Only issues with the same Vendor selected in the issue details display.

 Assigned To

 Only issues assigned to the same User display.

 Created By

 Only issues created by the User selected display. If the issue was created from Tenant Web Access (TWA) , the column displays TWA Submitted .

 Linked To

 Only issues linked to the selected entity display. Select the entity type using the drop-down above the field (tenant, prospect, unit, or property) and use the search bar to select a specific entity of that type.

 Column Descriptions

 The following columns are available on this page:

 Column
 Description

 Priority

 The urgency you assigned to this issue.

 Issue

 The name of the issue entered on the issues details page in the Title field.

 Next Post Date

 If this recurring issue has remaining posts, the next date on which the issue posts.

 Last Post Date

 If this recurring issue has previously posted, the date of the last posting.

 Post Period

 How often the issue posts. The issue can post on recurring Days , Weeks , or Months .

 Post Term

 The time period expected to complete the issue, entered on the issues details page in the Due Date field.

 Posts Left

 The number of remaining times that the recurring issue posts before ending.

 Category

 The issue category to sort and track types of service issues.

 Status

 The current stage of progress for this issue.

 Assigned To

 The user responsible for completing this issue.

 Created By

 The user who created this issue.
