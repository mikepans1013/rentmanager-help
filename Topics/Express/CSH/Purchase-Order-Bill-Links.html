Purchase Order Bill Links (Pop-Up)

Purchase orders (POs) are used to request permission to purchase items, prevent unauthorized purchases, and maintain a historical record of items purchased. To bill tenants, prospects, and owners for items purchased through a purchase order, you can create a bill that auto-populates with information from the purchase order and link it to the purchase order or link an existing bill to the purchase order. On a purchase order's details page, the Bills pop-up allows you to view information about bills linked to your POs.

Related Privileges

Group Privilege Column
POs/Estimates Purchase orders View

For more information, refer to Control User Access.

To view a purchase order's linked bills, go to arrow_forward Payables arrow_forward General arrow_forward Purchase Orders and select a purchase order from the list. Then, on the Links tile next to Bills, click .

Column Descriptions

The following columns display on this pop-up:

Column Description

Bill Date

The date the bill was created.

Invoice #

If applicable, the bill's reference number or invoice number.

Memo

An optional explanation of the bill.

Amount

The total dollar amount expensed on the bill.

Action Descriptions

The following actions can be performed from the Bills pop-up:

Action Description

Add Bill

Related Privileges

Group Privilege Column
Payables Bills Add, View

For more information, refer to Control User Access.

Create a new bill and link it to the purchase order. New bills created this way auto-populate with information from the purchase order.

Link Existing Bill

Related Privileges

Group Privilege Column
Payables Bills View

For more information, refer to Control User Access.

Link a bill you already created.

Remove Link

Related Privileges

Group Privilege Column
POs/Estimates Purchase orders View, Edit

For more information, refer to Control User Access.

Remove the bill link from the purchase order.
