# Unit Type Properties (Pop-Up)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Unit-Type-Properties.htm

The Unit Type Properties pop-up shows which properties contain the currently selected unit type.

 Related Privileges

 Group
 Privilege
 Column

 Properties/Units
 Unit types
 View, Edit

 For more information, refer to Control User Access .

 To view the Unit Type Properties pop-up, go to arrow_forward Rental Info arrow_forward General arrow_forward Unit Types and select a unit type from the list. Then on the action bar to the right, click and select View Properties .

 In the Property Group field, enter the desired criteria to display all properties associated with a predefined property group. For more information, refer to Property Groups (Page) .

 Column Descriptions

 The following columns display on the pop-up:

 Column
 Description

 A signifies the property is associated with the selected unit type.

 Property

 The active properties that can be associated with the selected unit type.

 Rent Amount

 If applicable, the standard rent amount associated with the selected unit type.

 Units

 The total number of units at the property associated with the selected unit type.

 Active

 The number of units associated with the selected unit type without the INACT. unit status applied. For more information, refer to Unit Status Types (Page) .

 Occupied

 The current number of units associated with the selected unit type that are occupied by one or more tenants.
