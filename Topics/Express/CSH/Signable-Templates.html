Signable Templates (Page)

In order to publish a signable document for a tenant, prospect, owner, or owner prospect, you must first create signable templates. These templates are set up to collect electronic signatures and/or initials from recipients, and can either be created as letter templates or imported from PDF files. Once created, you can add additional fields and prompts to allow the recipient(s) to provide further information that can be paired with specific Rent Manager account data, such as contact details, social security numbers, and vehicle information.

Signable letter templates are letter templates that include signable fields and, optionally, questions for the recipient. Once a letter template has signable fields added, it becomes a signable letter template. From the Signable Templates page, you can edit the templates to include interactive fields, manage the template's settings, and publish the templates to recipients. However, new signable letter templates cannot be created from the Signable Templates page.

Signable PDF templates are PDF documents that have been imported to add signable fields and other interactive fields, such as questions for the user publishing the document or the recipient(s). To view and manage signable templates that were created from imported PDF files, at the top, set the Template Type to PDF.

For more information, refer to Control Letter / Email Template Access.

To view and manage signable templates, go to arrow_forward Communication arrow_forward Signable Documents arrow_forward Signable Templates.

At the top of the page under Template Type, select Letter or PDF to display only signable templates assigned to that type.

Column Descriptions

The columns below are available on this page.

Column Description

Name

The title of the signable template used for internal reference. The Name displays on the Signable Templates page, but does not display on the published document itself.

Template Type

The entity type (e.g., Tenant) associated with the template.

Description

Additional information about the template as entered on the signable template's settings.

Active

A Check displays if the Active field is checked in the signable template's settings. This option applies only to PDF templates.

Created Date

The date on which the template was created.

Created By

The user who created the template.

Update Date

The date on which the template was last updated.

Updated By

The user who last updated the template.

The user(s) and/or user role(s) that can publish this template as a signable document.
