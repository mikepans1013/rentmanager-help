Floors (Page)

This page lets you track the floors available at your properties—1st Floor, 2nd Floor, Basement, and so on. Once you have entered floors into the database, you can assign them to rental units to make it easier to find specific kinds of units. For example, a tenant may require a ground-level unit or request the topmost floor to have no renters above them.

Related Privileges

Group Privilege Column
Properties/Units Floors View

For more information, refer to Control User Access.

To create and manage floors, go to arrow_forward Rental Info arrow_forward Rental Info Setup arrow_forward Properties/Units arrow_forward Floors.

Column Descriptions

The following columns are available on this page.

Column Description

Name

The name used to identify the floor [e.g.,1st Floor, 2nd Floor].

Properties

The properties where this floor is available and can be specified on each unit.

Create Date

The date on which the floor was added.
