# System Filters (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/System-Filters.htm

System filters give you the ability to create filters that can be used for multiple entities and issues, and be shared with other Rent Manager users. Existing filters created by individual users can be made available to other users by copying and saving them as system filters.

 These filters can be created and used in other areas of Rent Manager but can be edited or deleted only from the System Filters page. When applying system filters from other pages in Rent Manager , the name of the filter is designated with brackets ([ ]).

 More Information

 If the basic filtering does not meet your needs, you can create an advanced filter which allows you to group your filters for a more granular, precise filtering criteria. For more information, refer to Create an Advanced Filter .

 Filter Options

 The following filter options are available on this page.

 Option
 Description

 Search

 Allows you to display only system filters that contain data matching what you enter in this field.

 Saved Filters

 Use the drop-down to select a saved filter list or click to add more advanced filters.

 Type

 Use the drop-down to select a system filter type (e.g., Unit , Property , Tenant ). By default, <All Types> is selected.

 Column Descriptions

 The following columns display on this page. By default, some columns display only if added via .

 Default Column
 Description

 Name

 A brief explanation of the system filter (e.g., Storage Unit Make Ready ).

 Type

 The entity type of the system filter (e.g., Unit , Property , Tenant , Service Issue ).

 Create User

 The username of the user who created the system filter.

 Create Date

 The date that the system filter was created.

 Update User

 The username of the user who last edited the system filter.

 Update Date

 The date that the system filter was last updated.

 Assigned Users

 The usernames of all users or user roles that were assigned the system filter.

 Available Column

 Description

 Description

 An optional note about this system filter (e.g., Tenants with a Balance Due ).
