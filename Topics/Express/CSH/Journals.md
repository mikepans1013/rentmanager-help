# Journals (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Journals.htm

Journal entries are manual accounting entries that debit the balance of certain general ledger (GL) accounts and credit the balance of other GL accounts for selected properties. These special entries can be used to correct accounting mistakes, perform money transfers between bank accounts or properties, and record the appreciation or depreciation of assets.

 Warning

 Rent Manager uses double-entry bookkeeping to track all accounting records. You can save a journal entry only if the debits equal credits by property. If you also include units, the debits and credits must match per unit as well.

 It is recommended that only users with accounting experience use journal entries.

 Column Descriptions

 The following columns are available on this page. By default, some columns display only if added via .

 Column
 Description

 Journal #

 The system-generated number of the journal entry.

 Journal Date

 The date on which this journal entry took effect.

 Amount

 The total dollar amount of the journal entry.

 Memo

 Additional details regarding the purpose of the journal entry transaction (e.g., Security deposit transfer ).

 Reference

 A number or combination of letters and numbers, such as invoice number, used to reference the journal entry.

 Created By

 The user who created the journal entry.

 Description

 Attachments

 A displays if the journal entry has any files, documents, images, etc. attached, such as the signed memo approving the journal entry.

 Created Date

 The date on which this journal entry was created.

 Depreciation Entry

 A displays if the journal entry was notated as a depreciation entry. For more information, refer to Create a Depreciation Schedule .

 Period Adjustment

 A displays if the journal entry is an adjusting entry. This allows for the entry to optionally be excluded from financial reports.

 Properties

 The Short Name of the property impacted by the journal entry. If more than one property is impacted by the journal entry, only the short name of the property associated with the first line of the entry displays.

 Updated By

 The user who most recently updated and saved the journal entry.

 Updated Date

 The date on which the journal entry was most recently updated.
