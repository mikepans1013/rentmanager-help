Recurring Charge Search (Page)

The Recurring Charge Search page lets you search for one or more recurring charges that began and/or ended during specified date ranges and then filter the results using additional search criteria. The types of recurring charges that you can search for include: property, unit type, unit, and tenant.

Related Privileges

Privileges determine what search results are visible and what further actions you can take. Depending on your user privileges, you may be able to open a new page, drill down from the results to specific pages, and perform certain additional actions.

More Information

Only properties to which you have access display. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property.

To search for recurring charges. go to arrow_forward Search arrow_forward Recurring Charges.

Filter Options

The following filter options are available on this page.

Option Description

Type

The type of recurring charge level (Property, Unit Type, Unit, and Tenant).

From Date Range

Recurring charges that began posting during this range display.

To Date Range

Recurring charges that stop posting during this range display.

Search Options

Select Begins With to view only charges that start with the criteria entered in the Frequency, Name, or Comment fields. Select Contains to view only charges that contain the criteria entered in the Frequency, Name, or Comment fields.

Charge Type

The recurring charge with the specified charge type.

Frequency

The numeric value representing how often the charge posts.

Name

The name of a property, unit type, unit, or tenant to search for recurring charges associated with its name.

Comment

A word or phrase to search for a comment of a recurring charge.

Column Descriptions

The following columns display on the page.

Column Description

Name

The initial for the type of recurring charge displays in the color that corresponds to the charge level, followed by the name of the property, unit type, unit, or tenant.

Charge Type

The charge type associated with the recurring charge.

Comment

Additional information about the recurring charge.

Frequency

A numeric value representing how often the charge posts.

From

The starting date of the recurring charge.

To

The ending date of the recurring charge.

Amount

The total amount of the recurring charge.
