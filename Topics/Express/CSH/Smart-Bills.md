# Smart Bills (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Smart-Bills.htm

Rent Manager 's Smart Bills feature allows you to streamline your invoice management process. With this feature, you can easily upload invoices via a PDF or image format, allowing AI to extract the relevant data and create draft transactions automatically. Smart Bills also includes an intuitive review process, allowing you to ensure the accuracy of transactions before posting them as actual bills. Additionally, vendors can send invoices in PDF Format directly to a dedicated email inbox for seamless integration into the Smart Bills workflow.

 More Information

 This feature is licensed and must be purchased separately. For more information, contact your sales representative at sales@rentmanager.com .

 Column Descriptions

 The following columns are available on this page. By default, some columns display only if added via .

 Column
 Description

 Vendor

 The vendor name taken from the file when uploading the invoice.

 File Name

 The file name taken from the uploaded file or emailed to the inbox as an attachment.

 Invoice #

 The invoice number taken from the file when uploading the invoice.

 Uploaded Date and Time

 The date and time the bill was added to Smart Bills page.

 Due Date

 The due date for the bill taken from the file when uploading the invoice.

 Source

 The source of the Smart Bill ( Inbox Name or username). The Inbox Name is the name of the inbox that received an email from the vendor. The username is the name of the user that manually uploaded the invoice file.

 Amount

 The total dollar amount owed taken from the file when uploading the invoice.

 Available Column

 Description
