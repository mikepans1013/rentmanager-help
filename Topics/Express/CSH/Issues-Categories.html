Issue Categories (Page)

Issue categories are classifications that you create to help you sort and track types of issues (e.g., Property Wide, Maintenance, Electrical, Plumbing, Emergency, Office). They also aid in filters and saved issue lists. From this page, you can add new issue categories that users can select when filling out issues and format the categories to add visual distinction. Under certain circumstances, you can also delete unnecessary categories or make them inactive, which removes them from the Category drop-down list on an issue.

Related Privileges

Group Privilege Column
Service Manager List manager View, Edit

For more information, refer to Control User Access.

To view or manage issue categories, go to arrow_forward Services arrow_forward Service Setup arrow_forward Service Manager arrow_forward Issue Categories.

Column Descriptions

The following columns display on this page:

Column Description

Active

If checked, the issue category displays on issues, recurring issues, and memorized issues. If unchecked, the issue category displays on the List Manager Categories page only when Active Only is checked.

Name

A descriptive name that identifies the issue category.

Description

An optional message about the issue category such as Emergency Maintenance.
