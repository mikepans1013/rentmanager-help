# Memorized Invoices (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Invoice-Memorized.htm

Memorized invoices are invoices that are saved as templates to make it easier to create similar invoices in the future. For example, you can create a memorized invoice for when you charge owners for management fees or when tenants reimburse you for upgrades to their units.

 Column Descriptions

 Column
 Description

 Name

 The name used to identify the memorized invoice template (e.g., Management Fees ).

 Description

 Additional information about what the memorized invoice is for.

 Account

 The owner, tenant, or prospect who received the invoice.

 Property

 The name of the property linked to the memorized invoice.

 Unit

 If applicable, the name of the unit linked to the memorized invoice.

 Total Amount

 The final total dollar amount of all items for the invoice using the following formula:

 Total Amount = Sub Total + Markup Total + Tax

 Address

 The address marked as Default on the recipient's details page.

 Street

 The street of the address marked as Default on the recipient's details page.

 City

 The city of the address marked as Default on the recipient's details page.

 State

 The state of the address marked as Default on the recipient's details page.

 Postal Code

 The zip or postal code of the address marked as Default on the recipient's details page.
