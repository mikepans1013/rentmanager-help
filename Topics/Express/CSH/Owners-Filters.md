# Owner Filters (Pop-Up)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Owners-Filters.htm

Owner filters allow you to quickly narrow your search results to get to the owner information that you really need. Rent Manager gives you the ability to choose from a variety of filtering options to sort your owners on the Owners page.

 Rent Manager allows you to create filters that can be used temporarily, or saved to use repeatedly. Additionally, they can be saved on a system level for all users, or on a personal level where only your user account can access it. Before saving your filter, enter a Name , and, optionally, a Description to remind you of the filter's purpose.

 More Information

 If the basic filtering does not meet your needs, you can create an advanced filter which allows you to group your filters for a more granular, precise filtering criteria. For more information, refer to Create an Advanced Filter .

 On the Owners page there are multiple fields available to use for basic filtering of owners. The fields are divided into multiple sections. Each field is described within the corresponding section below.

 General Information

 This section contains fields for filtering owners by information that can be found primarily on their detail pages. For example, if you are filtering owners based on contract end dates, you can enter the date range in the End Date Between field.

 The available filter fields are described in the table below.

 City

 The city of the default address where the owner is located.

 User Defined Fields

 This section contains additional fields used to filter the owner list. The user defined fields in this section are specific to owners. Select an owner-type UDF from the list by which to filter owners. Then in the Value field, enter or select the information to narrow your results to owners that meet the entered criteria.

 Last Fee Posting

 This section contains From and To date fields used to filter the owner list by dates management fees were last posted to the owner's properties.

 Contract Date Options

 This section contains Start Date Between and End Date Between fields used to filter the owner list by contracts that start or end between or between specific date ranges.

 Search Options

 This section contains options for filtering owners based on whether the relevant information Contains your filter criteria or Begins With your filter criteria.
