Unit Amenities (Pop-Up)

The Amenities pop-up lets you manage the amenities associated with the currently selected unit. Tracking amenities can help you match tenants and prospects to units with specific features.

Related Privileges

Group Privilege Column
Properties/Units Units View, Edit

For more information, refer to Control User Access.

To view and manage a unit's Amenities pop-up, go to arrow_forward Rental Info arrow_forward General arrow_forward Unitsand select a unit from the list. Then on the Amenities tile, click .

Column Descriptions

The following columns display on the pop-up:

Column Description

Name

The name of the amenity (e.g., Patio, Gym/Workout Facility, Fireplace, Balcony). A signifies the amenity is linked to the unit.

Comment

An optional comment that provides additional details about the amenity.

Price

If applicable, the price that tenants pay for access to the amenity.
