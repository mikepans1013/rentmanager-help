# Inspection Templates (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Inspection-Templates.htm

Inspection templates define the areas and items of a unit that need to be examined. Create inspection templates in Rent Manager to be used in the Inspection feature of rmAppSuite Pro or to print the inspection and complete it manually. Creating a template for inspections allows you to quickly establish the scope of the inspection based on the types of units you manage and help streamline the inspection process.

 More Information

 Before you customize your inspection templates, it is recommended that you create the areas, items, and statuses you need in your inspection template toolbox. This allows you to quickly add the same components to multiple inspection templates. For more information, refer to Edit an Inspection Template Toolbox .

 To open the Inspection Templates page, go to arrow_forward Services arrow_forward Inspections arrow_forward Inspection Templates . To view the details of a specific template, select that template in the list.

 Template Settings

 At the top of the selected template, you can edit the following fields:

 Field
 Description

 Active

 If checked, the template can be selected when creating a new management inspection or tenant self-inspection, and can also be selected as the default inspection template for a unit or unit type.

 Name

 The unique name used to identify the inspection template when creating inspections.

 Require status for all items

 If checked, the tenant is required to select a status for every item in the inspection. This option is available only if Detailed Mode is selected in the rmResident Mode field.

 rmResident Mode

 Determines whether or not the template can be used for tenant self-inspections, and how that inspection displays to the tenant in rmResident . Select one of the following options:

 Simple Mode

 Tenants see each area and can add items as needed, or they can complete the inspection without adding any items. This mode is ideal for inspections where you just want the tenant to note their primary concerns without going too far into detail.

 Detailed Mode

 Tenants see all items in each area. They can either choose which to review, or you can require them to inspect all items. This mode is ideal for inspections where you want the tenants to review every area in detail.

 Tenant Self-Inspection Disabled

 The inspection template is not available for tenant self-inspections. If you selected No in the field above, this option is selected by default.

 This can be changed later at any time.

 Areas on inspections and inspection templates represent the physical locations that need to be inspected (e.g., bedrooms, kitchens, garages, balconies). Each area includes a list of items that need to be inspected in that location (e.g., floors, walls, cabinets), and each item can be assigned a status to determine if further action needs to be taken (e.g., Poor , Needs Repair , Missing ), or if it is ready to be completed (e.g., Good , Acceptable ).

 You can view and customize the details of each inspection template's areas, items, and statuses. To customize the order of these components, click and hold to drag and drop that area or item to its new position.

 Areas

 When you add, edit, or delete an area on a template, only the individual area in the selected template is modified. If the same area is in other templates, those other instances of the area are not changed.

 Statuses

 Inspection statues indicate the condition of an item (such as Poor , Acceptable , Good , or Missing ) and also allow you to select flags associated with those statuses ( Action Item , Needs Review , Severe , Image Required , and Note Required ).

 More Information

 Editing statuses directly from an item affects only that individual item in its assigned area and does not change the statuses of other instances of that item in other areas. Changes made to an items statuses in the toolbox do not affect any items already added to a template. To change the statuses of an item across all areas and templates, you must edit the item's statuses in the inspection toolbox and then re-add that item to all applicable areas and templates.
