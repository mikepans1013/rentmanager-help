# Charge Type Banks (Pop-Up)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Property-Charge-Type-Banks.htm

If one of your properties has multiple bank accounts to manage deposits for different kinds of transactions, you can set up charge type banks so that any payment of a certain charge type is deposited to a bank account other than the property default. For example, if you have a property with a primary operating account and a secondary bank account to track security deposit payments, you can set a charge type bank for those security deposit payments to ensure that they are not deposited into the operating account.

 Column Descriptions

 Column
 Description

 Charge Type

 The user-created transaction type for services or products you offer as a business.

 Bank

 The general ledger (GL) account to which payments of the charge type are deposited.

 If <Use System Default> is selected, payments of the associated charge type are deposited to the bank account configured for that charge type in system preferences. For more information, refer to Payment Options (System Preferences) .

 If <Use Property Default> is selected, payments of the associated charge type are deposited to the bank account established on the property's details page in the Default Bank field.
