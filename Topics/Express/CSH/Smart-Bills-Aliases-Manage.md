# Manage Aliases (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Smart-Bills-Aliases-Manage.htm

Aliases in Rent Manager are used to improve Smart Bills and Smart Receipts matching by identifying additional property addresses and vendor names that display on the invoices and matching them to existing Rent Manager records. For example, you may find it helpful to create a vendor alias if you have two or more vendors with similar names. Creating individual aliases can help you more quickly identify invoices sent from each vendor. Aliases can be automatically created through the Smart Bills Review and Smart Receipt Review pages, or added manually to ensure accurate matching.
