Owner Prospects (Page)

Owner prospects are potential owners that express interest in having your fee-based management company manage the properties they own. The goal is to get owner prospects to sign a contract with your management company. In Rent Manager, you can manage owner prospect information and track the effectiveness of your marketing campaigns.

Related Privileges

Group Privilege Column
Owners Owner Prospects View

For more information, refer to Control User Access.

To view your list of owner prospects, go to arrow_forward Owners arrow_forward General arrow_forward Owner Prospects.

On the Owner Prospects page, each owner prospect displays on a row with information organized into columns. Click on an owner prospect to open the Owner Prospects details page for that account, where information specific to that owner prospect is available.

Column Descriptions

The following columns display on the page. By default, some columns display only by using .

Default Column Description

Display Name

The name for the account that shows in reports and other areas of Rent Manager.

Street

The street of the Default address associated with the owner prospect.

City

The city of the Default address associated with the owner prospect.

State

The state of the Default address associated with the owner prospect.

Postal Code

The postal code of the Default address associated with the owner prospect.

Number of Units

The total number of units in the owner prospect's portfolio.

Email

The email address for contacting the owner prospect.
Available Column Description

Application Date

The date that the owner prospect applied to have their portfolio managed by your company.

Comment

An additional note entered on the Comment tile on the owner prospect's details page.

Interest Level

The likelihood that the owner prospect will work with your company.

Lead Source

How the owner prospect learned about your company.

Name

The full name of the owner prospect.

Number of Properties

The total number of properties in the owner prospect's portfolio.

Phone

The Default phone number for contacting the owner prospect.

Sales Representative

The employee at your company responsible for managing sales to this owner prospect.

Status

The status of the owner prospect (Owner Prospect, Owner, Lost, Lost/Rejected).

Address: (Type)

Each Address Type is listed on the Columns pop-up. The owner prospect's associated address of the selected type displays.

Phone Number: (Type)

Each phone number type is listed on the Columns pop-up. The owner prospect's associated phone number of the selected type displays.

UDF:
(Tenant Type)

Each owner prospect-type user defined field is listed on the Columns pop-up. The value entered on the tenant's account for the selected user defined field displays.

Send a text message to the selected account through the text messaging center. This option displays only if there is a text-enabled phone number listed on the account.

More Information

The first text sent to a recipient from the text messaging center and any texts sent via text broadcast or automated notification include an opt-out message. If a recipient opts out, that phone number cannot receive texts from Rent Manager unless they choose to opt back in. Recipients can opt out or opt in at any time. If a recipient wishes to opt back into text messaging, they must text Start from the phone number they opted out with to the number they originally requested to opt out of.

Phone numbers that have opted out of text messaging are identified on the account's View Contacts pop-up, where the checkbox in the T column is replaced with the words Opted out in red text.
