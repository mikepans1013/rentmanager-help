# Users (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Users.htm

On the Users page, you can view and manage active and inactive Rent Manager user account information, user privileges, user access to reports, letters, filters, and user display defaults. Managing what each user can view and do in Rent Manager in this way is critical in maintaining your system security.

 Related Privileges

 To view information for any users, the following privileges are required:

 Group
 Privilege
 Column

 System
 Manage all users and privileges
 View

 To view information for users that you supervise, the following privileges are required:

 Group
 Privilege
 Column

 System
 Manage assigned users and privileges
 View

 For more information, refer to Control User Access .

 To open the Users page and view a list of users, go to arrow_forward Administration , then go to Users arrow_forward Users .

 Each user account displays on its own row. You can click a row to open the User details page for the account, where you can view and edit general information, privileges, and access permissions.

 Column Descriptions

 The following columns are available on this page.

 Column
 Description

 Username

 The username used to log in to Rent Manager and that indicates which user took actions, such as in history/notes or the Audit Trail report.

 First Name

 The user's preferred first name.

 Last Name

 The user's last name.

 Active

 A green indicates that the user is active and can log in and use Rent Manager .

 Administrator

 A green indicates that this user has the Administrator account option enabled and all associated privileges and access permissions.

 Email

 The email address used for sending communications to the user.

 Leasing Agent

 A green indicates that this user has the Sales Rep/Leasing Agent account option enabled and all associated privileges and access permissions.

 Sales Representative

 A green indicates that this user has the Sales Rep/Leasing Agent user role and all associated privileges and access permissions.
