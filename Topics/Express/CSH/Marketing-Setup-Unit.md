# Unit Marketing Setup (Pop-Up)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Marketing-Setup-Unit.htm

The internet listing service (ILS) marketing integration allows you to create online listings for the available units in your Rent Manager database. Listings can be pushed to ILS providers such as Zillow, Trulia, and HotPads. From the unit Marketing Setup pop-up, you can customize marketing settings to advertise your units online.

 More Information

 If the property the unit is associated with has a Property Type of RV/Campground , the Marketing Setup pop-up includes fields specific to short-term rentals. For more information, refer to STR Property Marketing Setup (Pop-Up) .

 Warning

 Rent Manager 's ILS postings are generated using the MITS file format, which is the industry standard for syndicating available units and properties. As many ILS sites no longer accept marketing data for individual units, it is strongly recommended that you utilize property-level marketing and convert any existing unit-level marketing data.

 If you have not converted your unit configuration to a property configuration, the Marketing Setup pop-up displays a message prompting you to use Property Marketing Configuration Wizard . Once you convert to a property configuration, it cannot be reversed. For more information, refer to Marketing Configuration Wizard (Pop-Up) .

 To view marketing data for your units, go to arrow_forward Rental Info arrow_forward General arrow_forward Units and select a unit. Then, on the action bar to the right, click arrow_forward   Marketing Setup .

 If this option does not display, the unit's property already has marketing active.

 The sections of the Marketing Setup pop-up contain information about the unit's ILS marketing settings, which control what displays in your ILS listings.

 Include/Exclude

 The following options are available to determine if this property is included in your ILS feeds.

 Option
 Description

 Use System Preference

 Use the system preference for determining if this unit is included in the ILS marketing feed. For more information, refer to Online Listings Availability Filters (System Preferences) .

 Always Include

 This unit is always included in the ILS marketing feed.

 Always Exclude

 This unit is never included in the ILS marketing feed.

 Contact Information

 This section displays the email, phone number, and website address used in ILS marketing feeds for this unit. Manually type custom entries, or use the drop-downs to select information from existing fields found elsewhere in Rent Manager .

 Field
 Description

 Company Info

 The name and address that displays for this unit in your ILS feeds. To change what displays in this field, click to open the Company Information pop-up. Each option is described below.

 Custom Entry

 In the Company Name field, enter the name to display on the unit's online listing. In the Company Address section, enter the Street , City , State , and Postal Code to use for the company on the unit's online listing.

 Property Management Company Info

 Use the name and default address of the property designated as the management company in system preferences. For more information, refer to Management Company (System Preferences) .

 Property Info

 Use the name and default address of the unit's associated property as entered on the Property details page.

 Contact Email

 The email address through which prospects can contact you for more information on the unit.

 Contact Phone

 The phone number prospects can use to contact the company that is managing the unit.

 Company Website

 The website address (URL) of the company managing the unit.

 Marketing Description

 In this section, you can write a custom description to be included in your online listing. Alternatively, click to choose a user defined field that contains the description you want to use for the listing. Descriptions have a 1,000-character limit.

 Listing Details

 This section displays the images, availability status, and lease terms for this unit.

 Field
 Description

 Price

 The location in your Rent Manager database where the listing price for the unit is set. Use the drop-downs to select an existing Rent Manager field or manually enter a dollar amount.

 Deposit Fee(s)

 The total dollar amount for security deposit fees on this unit. Use the drop-downs to select an existing Rent Manager .

 Lease Terms

 The available lease terms for the property. To change what displays in this field, click the drop-down and select or deselect one or more lease terms. Alternatively, choose Contact For Details if lease terms at the selected property are not determined.

 Property Images

 The property image type(s) that display in your unit's ILS feed. Select one or more image types from the drop-down menu. To see the images that display on the listing based on the chosen types, click Preview .

 More Information

 For images to be included in the ILS feed, you must have a valid Path and Caption for your images. You can enter this information when you add new images or by adding them to existing images on the property's details page.

 Unit Images

 The unit image type(s) that display in your unit's ILS feed. Select one or more image types from the drop-down menu. To see the images that display on the listing based on the chosen types, click Preview .

 More Information

 For images to be included in the ILS feed, you must have a valid Path and Caption for your images. You can enter this information when you add new images or by adding them to existing images on the unit's details page.

 Availability

 The date on which the property is listed as available. If this field is blank, the property is listed lists as available by default.

 Features

 This section shows which amenities the property offers and features with preselected fields taken from ILS sites, such as the types of pets that are allowed and laundry options.

 Field
 Description

 Property Amenities

 The amenities available at the property that display in the online listing. These amenities can be changed from the property details page in the Other Information tile by selecting from the Property Amenities drop-down.

 Unit Amenities

 The amenities available at the unit that display in the online listing. These amenities can be changed from the unit details page in the Other Information tile by selecting from the Property Amenities drop-down.

 Laundry

 The laundry options available at the unit.

 Pets

 The types of pets allowed at the unit.

 Included Utilities

 The utilities that are included in the rent payments for the unit.
