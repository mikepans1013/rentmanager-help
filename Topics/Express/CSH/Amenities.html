Amenities (Page)

This page lets you track amenities—features or conveniences such as fireplaces, patios, pools, etc. Once you have entered amenities into the database, you can assign them to rental units. This makes it easier to find units with amenities that match the features desired by tenants and prospects.

Related Privileges

Group Privilege Column
Properties/Units Amenities View

For more information, refer to Control User Access.

To create and manage amenities, go to arrow_forward Rental Info arrow_forward Rental Info Setup arrow_forward Properties/Units arrow_forward Amenities.

Filter Information

The following filtering options are available on this page.

Filter Description

Search

Enter the desired search criteria to display results with a Name that matches the search criteria.

Amenity Type

Use the drop-down to select which type of amenity to display (Unit or Property).

Sort Alphabetically

To display your Amenities list alphabetically by Name, click arrow_forward Sort Alphabetically.

Column Descriptions

The following columns display on the page.

Column Description

Name

The name that displays on the units that you can link the amenity to.

Comment

An optional comment that provides additional details about the amenity.

Price

If applicable, the price that tenants pay for access to the amenity.
