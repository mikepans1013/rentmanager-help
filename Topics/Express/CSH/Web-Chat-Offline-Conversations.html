Offline Conversations (Web Chat) (Page)

Web Chat conversations received while the associated queue is offline are retained on the Offline Conversations page. After reviewing and addressing these messages, you may click Completed to mark them as Read.

To receive offline conversations, both Show button when chat is offline and Allow questions when no agents are logged in must be enabled on the Manage Queues page. For more information, refer to Manage Queues (Web Chat) (Page).

More Information

If you would like to have offline Web Chat messages forwarded to agents or other users via text or email, you can enable the automated notification for Web Chat Offline Message. For more information, refer to Web Chat Offline Message (Automated Notification).

Filter Information

The following filters are available on this page:

Filters Descriptions

Search

Enter the desired search criteria to display results with a Name that matches the search criteria.

Queues

Select each queue for which to display associated conversations. To quickly select or deselect all options in the list, check or uncheck the box in the section header.

To clear the selection(s), click clear.

Read

Check to include conversations in the list that have been marked as Completed.

Unread

Check to include conversations in the list that have not yet been completed.

Filter By Conversation Date

Enter a From and/or To date to filter the list to display only conversations that took place in that date range.

Click to select a date from the calendar, or click Today to select today's date. Alternatively, click to open more options for setting a date range.

Column Descriptions

The following columns are available on this page:

Column Description

Date

The date on which the conversation took place.

Question

The questions established for the queue on the Manage Queues page and the answers provided by the recipient. For more information, refer to Manage Queues (Web Chat) (Page).

Queue

The queue from which the conversation originated.

Link

The name on the account associated with the conversation.

Status

A status of Read or Unread displays depending on whether or not the message has been addressed.

If a conversation has a status of Read, the Rent Manager user clicked Completed after reading or addressing the message.

If a conversation has a status of Unread, the message has not yet been addressed and completed.
