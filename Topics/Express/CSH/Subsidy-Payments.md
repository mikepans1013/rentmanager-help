# Subsidy Payments (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Subsidy-Payments.htm

A subsidy is a form of financial assistance offered to qualifying tenants. The most common subsidy examples are HUD, Section 8, and FEMA. In  Rent Manager , subsidies can be tracked, and payments made by the subsidy can be recorded, including if the subsidy makes overpayments. A history of previous subsidy payments can be viewed on the Subsidy Payments history page.

 Column Descriptions

 The following columns are available on this page.

 Column
 Description

 ID

 The system-generated subsidy payment ID number.

 Subsidy Name

 The name of the subsidy used for the payment (e.g., Housing and Urban Development ).

 Reference #

 If applicable, the note entered by a user describing the type ( CASH , MO , the check number, and so on) of transaction.

 Amount

 The total dollar amount of the subsidy payment.

 Transaction Date

 The date on which the payment took place.

 Payment From

 The name of the subsidy from which the payment was received.

 Comment

 Additional information about the subsidy payment (e.g., Section 8 Payment ).
