Vendor Credits (Page)

Vendors can give you credits for various reasons, such as when you overpay a bill, when services are not performed, or when goods are not available. Creating a vendor credit in Rent Manager allows you to apply that credit to bill(s) that you pay to the vendor. On the Vendor Credits page, you can view a list of available credits that you can apply to bills.

Related Privileges

Group Privilege Column
Payables Vendor credits View

For more information, refer to Control User Access.

To view your list of vendor credits, go to  arrow_forward Payables arrow_forward General arrow_forward Vendor Credits.

On the Vendor Credits page, each vendor credit displays on a row with information organized into columns. Click on a credit to open the Vendor Credit details page for that account, where information specific to that vendor is available.

Filter Options

The following filtering options are available on this page.

Option Description

Saved Filters

Use the filtering tool to narrow the list of entities that display in the list by using other criteria.

Search

Enter search criteria to display results.

Filter By Transaction Date

Use the drop-down list to display only inspections with the selected status(es).

Show Open Credits Only

Check to display only the credits that have a positive Amount Left value.

Column Descriptions

The following columns display on the page. By default, some columns display only by using .

Default Column Description

Vendor

The vendor who issued the vendor credit to you.

Property

The property where the credit can be applied.

Unit

If applicable, the unit that received the vendor credit.

Credit Date

The date when the vendor issued the credit.

Amount

The full dollar amount of the vendor credit when it was first issued.

Amount Left

The remaining dollar amount of the vendor credit that can be applied.

Reference

The reference number (e.g., invoice or account number).

Comment

An optional message about the vendor credit.

Available Column

Description

A

If an attachment is uploaded to the vendor credit, displays. Click to download the attachment or open it in a new tab.

Avid URL

If the credit can be used via AvidXchange, the URL for the payment displays.

Property Short Name

The Short Name of the property where the credit can be applied.
