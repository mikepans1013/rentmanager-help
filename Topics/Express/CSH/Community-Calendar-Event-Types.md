# Community Calendar Event Types (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Community-Calendar-Event-Types.htm

The Community Calendar Event Types page allows you to categorize community-wide events (meetings, trash pickup day, maintenance events, and so on). Additionally, you can assign a color to an event type which displays on the Community Calendar , making it easier to differentiate each event category.

 Column Descriptions

 Columns on the Community Calendar Event Types page display the following information:

 Column
 Description

 Active

 A displays for event types marked as Active .

 Name

 The event's title that displays on the Community Calendar .

 Description

 A short summary of what the event type entails (e.g., information session for disaster preparedness).

 Color

 The color that displays on the Community Calendar to differentiate event types.
