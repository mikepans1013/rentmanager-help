Contact Types (Page)

Contact types are categories that can be assigned to the people/contacts that are associated with a prospect, tenant, or vendor and can provide a more regimented breakdown of these individuals as your business requires.

For example, you may want to identify a tenant contact as a roommate or a vendor contact as a manager. If contact types are defined, you may assign each contact listed on an account to a contact type in the Contacts tile on the Tenant and Vendor details page.

Related Privileges

Group Privilege Column
Setup Contact Types View

For more information, refer to Control User Access.

To create and manage contact types, go to arrow_forward Rental Info arrow_forward Rental Info Setup arrow_forward Tenants/Prospects arrow_forward Contact Types.

Column Descriptions

The following columns display on the page.

Column Descriptions

Name

The name of the contact type (e.g., Co-Signer/Guarantor, Emergency Contact, Caretaker, Billing).

Description

A comment that provides additional details about the contact associated with this type.

Type

The entity type (Tenant/Prospect or Vendor).

Permanently remove an existing contact type from Rent Manager. If the contact type is selected in the Type field for any contact, you are unable to delete the contact type. You must remove the contact type from each contact before you can delete it.
