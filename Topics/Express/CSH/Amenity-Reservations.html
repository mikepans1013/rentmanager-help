Amenity Reservations (Page)

Rent Manager knows your property has a lot to offer your tenants. With the reservable amenities tool, you can keep your tenants happy and engaged by providing them with the ability to reserve the amenities your property has to offer. The reservable amenities tool in Rent Manager allows you to establish an internal calendar to keep track of those reservations.

If you have the Tenant Web Access portal, you can choose to allow your tenants to book their own dates and times to use these reservable amenities, and simply approve or decline the request from within Rent Manager. You can also set specific charge types that can be linked to reservations fees that are associated with the reservable amenity.

After establishing the available reservable amenities on the property, you can manually enter reservations or view and take action on incoming reservation requests from Tenant Web Access on the Amenity Reservations page.

More Information

Only information related to the properties to which you have access displays. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property.

To view requests for amenity reservations, go to arrow_forward Services arrow_forward Community arrow_forward Amenity Reservations.

Filter Options

The following filtering options are available on this page.

Option Description

Search

You can type in the Search field to narrow the list to match your search criteria.

Property

Click the drop-down list and select the property whose requests should display.

Status

Filter the requests in the register based on where the request is in the approval process. By default, requests with a Status of Pending display.

The following status options are available:

Pending

No action is taken on this request for reservation.

Approved

The reservation is accepted.

Denied

The reservation request is declined.

Canceled

The reservation request was manually canceled by a user for a reason such as the request was withdrawn.

The property at which the reservable amenity is located.

The date the reservable amenity is requested for use.

The first and last name of the tenant requesting the reservation. If a tenant is not linked to the reservation, this column remains blank.

Available Column

Description

Amount Charged

The total amount charged to the tenant for the amenity reservation.

Amount Paid

The total amount paid to reserve the amenity reservation.

Created By

The username of the Rent Manager user who created the request. If the request was created in Tenant Web Access, this column is left blank.

Created Date

The date and time on which the reservation request was created.

Notes

Additional information submitted with the reservation request from Tenant Web Access.

Submitted By

The first and last name of the Tenant Web Access user who submitted the request, with their email address in parentheses. This email address is the one associated with their Tenant Web Access account.

Unit

The name of the unit of the first lease listed associated with the tenant making the reservation request.

Updated By

The username of the Rent Manager user who last updated the reservation request.

Updated Date

The date and time the request was last updated.
