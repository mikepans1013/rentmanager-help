Architectural Request Forms (Page)

With Rent Manager, you can customize the forms available on Tenant Web Access (TWA) for homeowners to submit architectural requests. By customizing the forms, you have more control over the information homeowners can submit. Forms can be customized to suit each association's needs, allowing you to cut down or even eliminate the amount of back-and-forth correspondence between the management company and homeowners.

The Architectural Request Forms page displays basic information about each form, such as creation and update information, form names, and which properties each form is assigned to. From this page, you can create, view, edit, and delete custom forms. Additionally, you have the option to copy an existing form, such as one of the System Architectural Request forms, and use the copy as a base for a new form and edit it as needed.

More Information

Architectural requests are available only for properties with a Property Type of Association selected on the property's details page.

Column Descriptions

The following columns display on the page:

Columns Description

Name

The name of the form as it displays to users in Rent Manager.

Display Name

An alternate name for the form that displays to homeowners in Tenant Web Access (TWA).

Assigned Properties

The properties at which this form is available. Additionally, this allows the form to be accessible from TWA for requests from the selected properties.

More Information

Only properties with a Property Type of Association, as entered on the property's details page, display in the list.

Create Date

The date on which the form was created.

Create User

The full name of the user who initially created the form. The system-generated forms display <Unassigned>.

Update Date

The date on which the form was most recently updated.

Update User

The full name of the user who last updated the form. The system-generated forms display <Unassigned>, as the system forms cannot be edited.
