Meter Exceptions (Page)

The Meter Exceptions page displays all unposted meter readings flagged as exceptions for the selected Property, Utility, and Billing Period. This page is accessible only if, on the High/Low Settings pop-up's Approval Workflows tab, Enable Approval Workflow is unchecked or you are assigned as a meter exceptions reviewer or approver.

Related Privileges

Group Privilege Column
Utilities Metered utilities Enabled

For more information, refer to Control User Access.

To view meter exceptions, go to arrow_forward Services arrow_forward Metered Utilities arrow_forward Meter Readings and select the desired Property, Utility, and Billing Period. Then, in the bottom right of the page, click Review Meter Exceptions.

Column Descriptions

The following columns display on this page.

Default Column Description

Charge

The dollar amount that was charged, based on the previous reading.

Consumption

The utility usage in the unit of measurement of the meter. The result is calculated using the following formula:

Consumption = Current Reading – Previous Reading

Consumption Range

The name of the consumption group based on a defined consumption range established on High/Low Settings pop-up's Consumption Groups tab. If the exception is an estimate, Estimate also displays.

Current Reading

The utility usage as of the most recent meter reading.

Exception Reason

The exception reasons (e.g., Water Leak, Recent Move In/Out, Faulty Appliance) established on High/Low Settings pop-ups' Exception Reasons tab.

Image

If an image was attached to the meter reading on the Meter Readings page or in rmAppSuite Pro, displays and can be clicked to view the image.

Occupied By

The current tenant associated with the unit.

Previous Reading

The utility usage as of the last meter reading.

Unit

The name of the unit associated with the meter.

Available Column

Description

Billing UoM

The unit of measurement (e.g., Gallons, Cubic Feet (CF)) used for billing utility usage.

Meter UoM

The unit of measurement (e.g., Gallons, Cubic Feet (CF)) used on the meter for tracking utility usage.

Reading Note

An optional comment providing further information about the reading, as entered on the Meter Readings page's Note field.

Route

The number that represents the order in which this meter is read. The first meter read has a value of 1, the second a value of 2, and so on. If no route is selected, 0 displays.

Site Classification

The name of the unit's site classification as displayed on the Unit details page. A blank row displays if the unit is not associated with a Manufactured Housing-type property. For more information, refer to Site Classification.

Utility

The type of utility that best categorizes the meter type: Water/Sewer, Gas, Electric, or Other.
