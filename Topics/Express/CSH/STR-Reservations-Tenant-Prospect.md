# Prospect and Tenant Reservations (Pop-Up)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/STR-Reservations-Tenant-Prospect.htm

The Reservations pop-up provides reservation details for short term rental (STR) prospects or tenants. For each listed reservation, you can view/edit the details, cancel the reservation, check in the guest, or remove the check-in.

 In addition to these privileges, you must have access to at least one property with either a Short Term Rental or RV/Campground property type assigned.

 For more information, refer to Control User Access .

 Warning

 To access the STR tool, at least one of your properties in Rent Manager must have the Short Term Rental or RV/Campground property type assigned.

 To view an STR prospect or tenant reservation, go to arrow_forward Rental Info arrow_forward General arrow_forward Prospect | Tenants and select a prospect or tenant from the list. Then, on the Reservations tile, click .

 Column Descriptions

 The following columns display on the pop-up.

 Column
 Description

 Property

 The property at which the reservation was made.

 Reserved Unit/Unit

 The name of the unit they have reserved.

 Arrival

 The start date of the guest's occupancy of the unit.

 Departure

 The end date of guest's occupancy of the unit.

 Confirmation #

 The system-generated number associated with the reservation.

 Status

 The current check-in status of the reservation. The column displays only for tenant reservations.
