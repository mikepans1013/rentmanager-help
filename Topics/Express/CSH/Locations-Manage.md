# Manage Locations (Pop-Up)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Locations-Manage.htm

If you work with more than one property management company, you can use separate Rent Manager database locations to keep your data for each company separate. All financial and entity information is unique to each location and maintained independently, including the users that can access the location and their user privileges.

 More Information

 Locations are a licensed feature and must be purchased separately. For more information, contact your sales representative at sales@rentmanager.com .

 More Information

 If you use per unit Rent Manager licensing, each unit in each location uses one license.

 For more information, refer to Assign Unit Licenses .
