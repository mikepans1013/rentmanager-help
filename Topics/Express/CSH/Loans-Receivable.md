# Loans Receivable (Page)

Source: https://rmxhelp.rentmanager.com/Topics/Express/CSH/Loans-Receivable.htm

Rent Manager provides a loans receivable management feature to help users create and manage owner-financed loans. Owner-financed loans are typically used for home sales but can also be used for other loan types such as for land, equipment, appliances, auto, and so on.

 The loans receivable tool provides the ability to set up the terms and conditions of internal loans. After a loan is set up, you can manage, track, and report the loan through its scheduled process, default the loan, or pay off the loan.

 Column Descriptions

 The following columns are available on this page. By default, some columns display only if added via .

 Default Columns
 Description

 Origination

 The date when the loan begins calculating interest.

 Tenant

 The name of the tenant responsible for the loan.

 Property

 The property associated with the loan.

 Unit

 The unit associated with the tenant responsible for the loan.

 Reference

 The system-generated loan number that Rent Manager generated when the loan was created or, alternatively, the manually entered loan number.

 Sale Amount

 The full sale amount of the loan using the following equation:

 Sale Amount = Original principal + Down Payment

 Principal Balance

 The loan's principal remaining balance.

 Status

 If a loan has an open balance , Open displays. If a loan was paid off or defaulted, Closed displays. Closed loans only display in the list if Show Open Loans Only is unchecked.

 Available Columns
 Description

 Acquisition Date

 The date on which the loan was purchased from another lender. If the loan was not acquired from another lender, the column is blank.

 Adjusted Principal

 The outstanding remaining principal for the most recent pre-existing loan that was established prior to being tracked and managed in Rent Manager .

 Adjusted Start Date

 The projected date of the first payment to be collected for the most recent pre-existing loan that was established prior to being tracked and managed in Rent Manager .

 Close Date

 The date the loan was signed.

 Down Payment

 The amount of money applied towards an upfront payment on the sale.

 End Payment

 The date on which the loan's payments end.

 Extend Term

 If applicable, the loan's extended term until all principal is charged when a loan's final payment exceeds the regular monthly amount.

 Increase Principal

 If applicable, the amount of credit to cover the loan's unpaid interest.

 Initial Interest Rate

 The beginning interest rate of the loan as a percentage (e.g., 7.0000 means 7%).

 Initial Payment Amount

 The amount of the first payment on the loan.

 Insurance Expiration

 The date on which the insurance, such as homeowners' or Private Mortgage Insurance (PMI), expires.

 Int. Charge Type

 The charge type for allocating a payment amount to the loan's interest charge after a loan posting.

 Interest Method

 The method used to calculate interest for the loan.

 Last Post Date

 The date loan charges last posted to the tenant's account.

 Payment Day

 The day of the month on which the payments are due for the loan.

 Prepay Charge Type

 The charge type any extra payments are allocated to.

 Princ. Charge Type

 The charge type for allocating a payment amount to a loan's principal charge after your monthly loan postings.

 Principal Credited

 The payment amount to the loan's prepaid principal (credit) between your monthly loan postings.

 Principal Paid

 The total of principal paid for the loan based on actual payments received.

 Prior Interest Amount

 The amount of the previously collected interest for the most recent pre-existing loan that was established prior to being tracked and managed in Rent Manager .

 Prior Interest Year

 The year of the previously collected interest for the most recent pre-existing loan that was established prior to being tracked and managed in Rent Manager .

 Start Payment

 The loan's start date in Rent Manager .

 Starting Payment Number

 The starting payment number for the tenant's loan. If the loan is preexisting, this displays the number of the first payment collected using Rent Manager .

 Tenant Account #

 The system-generated account number for the tenant responsible for the loan.

 Term

 The number of months in the term of the loan.

 Use Average Principal

 If the loan's average principal balance since the last payment is used to calculate the next payment's interest, a displays.
