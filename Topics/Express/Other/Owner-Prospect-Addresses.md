# Owner Prospect Addresses

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Owner-Prospect-Addresses.htm

You can create and manage your own categories for owner prospect addresses on the Address Types page. This makes it easy to record and reference multiple addresses on the same owner prospect account. Additionally, this adds the ability to pull a specific address type into other parts of Rent Manager , such as reports and features that use scripting. Once you define an address type for owner prospects, you can go to any owner prospect account to enter the associated address.

 For more information, refer to Control User Access .

 To add an owner prospect address type, do the following:

 -
 Go to arrow_forward Administration , then go to Customization arrow_forward Address Types .

 -
 In the Type section, select Owner .

 -
 Click Add Address Type .

 -
 Enter the Name for this owner address type. This type is shared between owner and owner prospect accounts.
This name displays as an option on the owner prospect's Addresses tile.

 -
 Click Save .
The address type is added to all owner prospect accounts.

 For more information, refer to Control User Access .

 To add an owner prospect address, do the following:

 -
 Go to arrow_forward Owners arrow_forward General arrow_forward Owner Prospects and select an owner prospect.
The Owner Prospect details page displays.

 -
 On the Addresses tile, select the according address type tab for the address you wish to add.

 -
 In the text field, enter the owner prospect's address.

 -
 If the address is used as the primary source of correspondence, check Default .

 -
 Click Save .
The owner prospect address is added.
