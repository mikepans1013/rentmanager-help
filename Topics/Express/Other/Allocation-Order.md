# Allocation Order

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Allocation-Order.htm

When receiving tenant payments, Rent Manager attempts to pay the oldest charges first by default. You can create custom allocation orders to change the default order in which Rent Manager applies payments to open charges on a tenant's account. For example, if a tenant's rent charges should always be paid before their other charges, the allocation order can be set to pay the rent charge type first. When accepting a single payment, all rent charges display at the top of the list, regardless of the date each charge was posted.

 Allocation orders are stored by property so that a different order can be assigned if payment priorities change between properties.

 Step 1: Select the Desired Property

 To view the Allocation Order page, do the following:

 -
 Go to   arrow_forward Administration arrow_forward Receivables arrow_forward Allocation Order .

 -
 In the Property field, select the property whose allocation order you would like to adjust.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 -
 In the Options section, you can select the following:

 If another property has a saved custom allocation order, then you can select the property from the drop-down list to use that property's allocation order.

 Sort by month before allocation order

 Check to sort charges by month on the Add Payment pop-up, and then follow the allocation order within each month.

 Step 2: Adjust the Allocation Order

 The name and description of each charge type displays on the right. By default, charge types display in alphabetical order. Use to move a charge type up or down to create the desired allocation order for the selected property.

 After confirming the charge types are in the desired allocation order, click Save . When a payment is added for a tenant at this property, the payment is now allocated to open charges according to this new allocation order.
