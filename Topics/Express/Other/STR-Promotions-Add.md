# Add a Short Term Rental (STR) Promotion

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/STR-Promotions-Add.htm

Short-term rental (STR) promotions allow you to offer discounts for STR reservations based on specific criteria. Promotions are set up with a unique promo code that guests can enter in the Online Booking Portal, and promotional periods can be limited based on the date the guest books their reservation and the dates the reservation is for. Additionally, you can control whether promotions are applied to an entire stay or on a nightly basis, and can require a minimum number of nights for the discount to be used.

 To add an STR promotion, do the following:

 -
 Go to arrow_forward Rental Info arrow_forward Rental Info Setup arrow_forward Short Term Rentals arrow_forward STR Promotions .
The STR Promotions page displays.

 -
 Click Add Promotion .

 -
 At the top of the pop-up, enter information in the following fields:

 Field
 Description

 Active

 If checked, indicates that the promotional discount is available to guests based on the defined criteria.

 Amount

 The dollar amount of the promotional discount. To discount by a set percentage, select Percent .

 Charge Type

 The charge type applied to transactions paid by guests who use this promotional discount.

 Name

 The unique identifier for the promotional discount.

 Promo Code

 The alphanumeric code for guests to enter when making reservations on the Online Booking Portal.

 Properties

 The properties for which the promotional discount is available.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 -
 Select one of the following options to determine how the promotion is applied:

 Option
 Description

 Per Night

 If selected, the discounted amount is applied to the cost of each night of the reservation. To limit the number of nights that the discount can be applied for a single reservation, select Set max number of nights the promotion can apply to and enter a value in the field.

 Per Stay

 If selected, the discounted amount is applied to the cost of the guest's full stay. In the Allow promotion on the following lengths of stay , select the duration(s) that the discount can be used for based on the property's STR settings (i.e., Nightly , Weekly , Monthly , etc.). For more information, refer to Property STR Settings (Pop-Up) .

 -
 In the Apply Promotion Code When section, establish the conditions for the promotional discount using the following options:

 Option
 Description

 Booking is made between

 The first ( From ) and last ( To ) date that a guest can make a reservation in the Online Booking Portal with the promotional discount.

 Date of stay is between

 The first ( From ) and last ( To ) date that a guest's reservation can be scheduled for with the promotional discount.

 Reservation is at least X nights

 The minimum number of nights required for a guest to use the promotional discount.

 -
 To finish, click Save & Close , or to create additional STR promotions, click Save & New .
The STR promotion is added to the STR Promotions page.
