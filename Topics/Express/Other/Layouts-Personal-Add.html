Add a Personal Layout

Layouts allow you to customize how the details page displays in select areas of Rent Manager Express. Tiles can be added, deleted, or repositioned on your layouts to create a personalized experience that best suits your workflow. You can even create blank tiles to completely customize the content that displays.

More Information

You can also manage and share layouts with other users by creating a system layout, which can be set as the default for all users or assigned to specific user roles and/or property types. For more information, refer to Add a System Layout.

Step 1: Create a Personal Layout

There are two methods available to create a personal layout: add and build a new layout, or copy an existing layout from a user account. Creating a new personal layout from scratch offers the most granular control for the content and structure of the tiles, but you can also use the default page layout as a base template to save time. Copying a user's layout allows you to utilize a personal layout that has proven useful with other employees.

Option 1: Add Layout

To create a new personal layout, do the following:

  1. On the My Layouts page, click Add Layout.
    The New Layout pop-up displays.

  2. In the Layout Type field, select the desired type from the drop-down list.

  3. In the Layout Template drop-down, select Blank to start with an empty layout or Standard to start with the Rent Manager default layout for the selected type.

  4. Click OK.

  5. Make any necessary changes to the layout.

  6. Click Save.
    The personal layout is created.

Option 2: Copy User's Layout

To copy a user's personal layout and use it as a personal layout for your account, do the following:

  1. On the My Layouts page, click the drop-down arrow next to Add Layout and select Copy User's Layout.
    The Copy Layout pop-up displays.

  2. In the User field, select the account whose dashboard you wish to copy.

  3. In the Layout Type field, select the desired type from the drop-down list.

  4. In the Layout field, select the desired layout from the drop-down list.

  5. In the Save As field, enter the name for the new personal layout.

  6. Click Save.
    A copy of the layout is saved as a new personal layout.

Step 2: Add and Customize Tiles

There are two kinds of tiles available for custom layouts: system tiles and blank tiles. System tiles are populated with various fields by default, while blank tiles can be fully customized.

Add a System Tile

To add a system tile, do the following:

  1. Click Add Tile and select the desired tile from the drop-down list.
    The tile is added to the layout.

  2. Select a tile to access customization options.

  3. Click to edit the tile's header. Each option is described below.

    Option Description

    Header Name

    The text that displays at the top of the tile.

    Header Border Color

    The color that displays above the Header Name. Select a preset color theme from the Theme Colors section or click Custom Color to use the color picker to set a color.

    Select a color using the gradient color slider, then use the color canvas to further refine the lightness and saturation of your selection.

    Alternatively, use to select either Hex, RGB, or HSL format and enter the desired color value.

    Click OK to apply the selected color.

  4. If available, click to add fields and options to the tile. Each is described below.

    Option Description

    Fields

    Data retrieved from default Rent Manager fields, such as names, email addresses, and statement methods. Fields display as either text boxes or check boxes.

    Issue Links Information

    Fields that pull in information about the Rent Manager entity or entities associated with the issue. This option is only available for Issue layouts.

    Buttons

    A button that performs an action or opens a related page, such as adding a history/note item, viewing late fee settings for a tenant, or entering a technician's hours on an issue.

    Buttons are not available for Asset or Vendor layouts.

    User Defined Fields

    Data retrieved from user defined fields (UDFs) of the selected page's type. User defined fields are not available for Vendor layouts.

    Phone Numbers

    Phone numbers associated with the selected page. A unique field is available for each phone number type.

    Phone numbers are not available for Asset, Issue, Unit, or Vendor layouts.

  5. If available, select a field on the tile and click to customize the field. Each option is described below.

    Option Description

    Name

    The label to display for the selected field. Special characters are allowed.

    Width

    The width, as a fraction of the tile, taken up by the selected field (e.g., Full, Half, Two Thirds, and so on). Other fields on the tile adjust automatically to accommodate the resizing.

    Read Only

    Prevents users from editing the field when this layout is selected.

    Delete

    Removes the field from the tile.

  6. Click and drag to move the tile on the layout.

  7. Once finished, click Save.
    The layout and any changes to tiles are saved.

Add a Blank Tile

To add a customizable, blank tile, do the following:

  1. Click Add Tile and select Blank Tile from the drop-down list.
    The tile is added to the layout.

  2. Select the tile to access customization options.

  3. Click to edit the tile's header. Each option is described below.

    Select a color using the gradient color slider, then use the color canvas to further refine the lightness and saturation of your selection.

    Alternatively, use to select either Hex, RGB, or HSL format and enter the desired color value.

    Click OK to apply the selected color.

  4. Click to add additional fields and options to the tile. Each is described below.

    Option Description

    Fields

    Data retrieved from default Rent Manager fields, such as names, email addresses, and statement methods. Fields display as either text boxes or check boxes.

    Buttons

    A button that performs an action or opens a related page, such as adding a history/note item, viewing late fee settings for a tenant, or entering a technician's hours on an issue.

    Buttons are not available for Asset layouts.

    User Defined Fields

    Data retrieved from user defined fields (UDFs) of the selected page's type.

    Phone Numbers

    Phone numbers associated with the selected page. A unique field is available for each phone number type.

    Phone numbers are not available for Asset, Issue, or Unit layouts.

  5. Select a field and click to customize the field. Each option is described below.

    Option Description

    Name

    The label to display for the selected field. Special characters are allowed.

    Width

    The width of the tile taken up by the selected field (e.g., Full, Half, Two Thirds, and so on). Other fields on the tile adjust automatically to accommodate the resizing.

    Read Only

    Prevent users from editing the field when this layout is selected.

    Delete

    Remove the field from the tile.

  6. Click and drag to move the tile on the layout.

  7. Once finished, click Save.
    The layout and any changes to tiles are saved.
