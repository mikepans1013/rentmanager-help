Tenant Listbox Settings (Personal Preferences)

Listboxes are drop-down lists in Rent Manager 12 that populate with rows of tenants and identifying information such as account number, property short name, unit name, and so on. For example, the listbox displays when typing in the Tenant/Prospect field on a service issue. The listbox can be customized in personal preferences, where you can choose what you’d like to display.

More Information

At this time, these settings apply only to Rent Manager 12 and do not apply to Express.

To set these personal preferences, do the following:

  1. Go to arrow_forward Administration, then go to Preferences arrow_forward Personal Preferences arrow_forward Tenant Listbox Settings.
    The Personal Preferences: Tenant Listbox Settings page displays.

  2. Check Override Default Settings to select the desired listbox options.

  3. Edit the settings as desired. Each setting is described in the heading below.

  4. Click Save.
    The personal preference configuration is updated.

Display Settings

Select any of the following options to display in tenant and/or prospect listboxes.

Option Description

Include Tenant Name

By default, the tenant name displays in the listbox. This option cannot be unchecked.

Format as Last Name, First Name

The name of the tenant and/or prospect displays as last name, first name in the listbox.

Include Account Number

The system-generated account number of the tenant and/or prospect displays in the listbox.

Include Property Name

The Short Name of the property associated with the tenant and/or prospect displays in the listbox.

Include Unit Name

The Name of the unit associated with the tenant and/or prospect displays in the listbox.

Include Tenant/Prospect Status

The status of the tenant (Past, Current, or Future) and/or prospect (Tenant, Prospect, Lost, or Lost-Rejected) displays in the listbox.
