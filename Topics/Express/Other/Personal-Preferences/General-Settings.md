# General Settings (Personal Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Personal-Preferences/General-Settings.htm

These personal preferences provide default options for how certain Rent Manager settings display (or don’t display) for your user account.

 To set these personal preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward Personal Preferences arrow_forward General .
The Personal Preferences: General Settings page displays.

 -
 Edit the settings as desired. Each setting is described in the heading below.

 -
 Click Save .
The personal preference configuration is updated.

 Preference Descriptions

 Each setting is described below:

 Field
 Description

 Show Confirm Reconcile Pop-Up

 Receive a pop-up warning whenever you clear a line item outside the reconciliation process in either the Bank Registers page or Credit Card Registers page by clicking arrow_forward Mark as reconciled .

 Show Inactive Charge Types

 Inactive charge types display in areas of Rent Manager where charge types can be selected. For example, when adding a one-time charge to a tenant account from the Transaction Detail pop-up, inactive charge types display in the Charge Type field.
