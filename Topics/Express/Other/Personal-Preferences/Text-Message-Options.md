# Text Message Options (Personal Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Personal-Preferences/Text-Message-Options.htm

These personal preferences allow you to choose when text message alerts display in the list in the top right of Rent Manager . These alerts notify you that a message was received in the Text Messaging Center .

 More Information

 Text messaging with Rent Manager is a licensed feature. Contact your sales representative or sales@rentmanager.com for more information.

 To set these personal preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward Personal Preferences arrow_forward Text Message Options .
The Personal Preferences: Text Message Options page displays.

 -
 In the Notifications section, choose one of the following options:

 Option
 Description

 Alert only when a reply to my message is received

 An alert displays for incoming text messages only if they are replies to a text message you sent.

 Alert when any message is received

 An alert displays for all incoming text messages.

 Do not alert when a message is received

 No alert displays for incoming text messages.

 -
 Click Save .
The system preference configuration is updated.
