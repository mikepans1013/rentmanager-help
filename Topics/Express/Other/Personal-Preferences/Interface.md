# Interface (Personal Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Personal-Preferences/Interface.htm

Interface preferences allow you to control how the Rent Manager Express UI displays, with options for font size, color theme, home page preference, and whether entity details pages automatically open in a new browser tab.

 To set these personal preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward Personal Preferences arrow_forward Interface .
The Personal Preferences: Interface page displays.

 -
 Edit the settings as desired. Each setting is described in the headings below.

 -
 Click Save .
The system preference configuration is updated.

 Preference Descriptions

 Each setting is described below:

 Option
 Description

 Font Size

 The size of the font used in Rent Manager Express . By default, the font size is set to medium.

 Theme

 The color scheme of Rent Manager Express . By default, the theme is set to light mode. Selecting dark mode darkens the background and uses light text, icons, and graphics to reduce eye strain and prevent triggering low vision and photosensitive conditions.

 Home Page

 The page ( My Workspace , Dashboard , Tenants , Properties , etc.) that displays upon logging into Rent Manager Express .

 Open Detail in a New Tab

 The entity details page(s) that automatically open in a new browser tab rather than in your active tab.

 For example, if you select the Properties option, when you navigate to arrow_forward Rental Info arrow_forward General arrow_forward Properties and select a property from the list, the property's details page opens in a new tab.
