# rmVoIP Preferences (Personal Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Personal-Preferences/rmVoIP-Preferences.htm

The rmVoIP phone system offered by LCS integrates your phone with Rent Manager . In your personal preferences, you can customize whether pop-ups display when you receive a call and if phone extensions are included under arrow_forward Extensions .

 Related Privileges

 Group
 Privilege
 Column

 Phone System
 Allow user to edit their own rmVoIP settings
 Enabled

 For more information, refer to Control User Access .

 To set these personal preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward Personal Preferences arrow_forward rmVoIP Preferences .
The Personal Preferences: rmVoIP Preferences page displays.

 -
 Select Override System Preference .

 -
 Edit the settings as desired. Each setting is described in the heading below.

 -
 Click Save .
The personal preference configuration is updated.

 rmVoIP Preferences

 Each setting is described below:

 Option
 Description

 Show incoming calls

 When you receive a phone call while logged in, a pop-up in the top-right of Rent Manager displays basic information, such as the caller ID, phone number, and, if applicable, linked Rent Manager account.

 Show extensions in presence listing

 If enabled, includes each user's extension number under arrow_forward Extensions . Otherwise, only usernames display.

 Connection Status

 The status of the integration for your rmVoIP phone system ( Connected or Closed ).

 Smart Voicemails

 In this section, check Receive notifications for new voicemails to add a notification to your list when a Smart Voicemail is received in a voicemail box you have access to. A notification pop-up also displays in the bottom right of the browser window. For more information, refer to Manage Orion Smart Voicemail Boxes .
