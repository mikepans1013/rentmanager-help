# Command Launch Display Options (Personal Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Personal-Preferences/Command-Launch-Options.htm

Command launch examines tenant, prospect, owner, vendor, and owner prospect accounts when you search by name. You can select which types of account statuses (inactive, past, present, etc.) to include in your search results.

 To set these personal preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward Personal Preferences arrow_forward Command Launch Settings arrow_forward Display Options .
The Personal Preferences: Command Launch Settings - Display Options page displays.

 -
 Edit the settings as desired. Each setting is described in the headings below.

 -
 Click Save .
The system preference configuration is updated.

 Display Options

 Each setting is described below:

 Entity
 Description

 Tenants

 Include tenants of the selected statuses ( Past , Current , Future ) in the search results. Check Exclude Subaccounts to include only tenants that are the Master account in an account group in the search results.

 Prospects

 Include prospects of the selected statuses ( Prospects , Tenants , Lost ) you wish to be included in the search results.

 Owners

 Check Inactive to include inactive owners in the search results.

 Vendors

 Check Inactive to include inactive vendors in the search results.

 Owner Prospects

 Include owner prospects of the selected statuses ( Owner Prospects , Owners , Lost ) in the search results.
