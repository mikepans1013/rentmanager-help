Check Scanning (Personal Preferences)

Check scanning personal preferences allow you to enable or disable check scanning for your user account, and set your default check scanner in Rent Manager.

More Information

LCS offers Epson single-feed and multi-feed check scanners you can use with Rent Manager. For more information, contact your sales representative at sales@rentmanager.com.

If you are already using a TellerScan TS 240 or Panini Vision X50 scanner for your check scanning, these models are also supported and compatible with Rent Manager check scanning. For more information, refer to Set Up TellerScan Check Scanner or Set Up Panini Check Scanner.

To set these personal preferences, do the following:

  1. Go to arrow_forward Administration, then go to Preferences arrow_forward Personal Preferences arrow_forward Check Scanning.
    The Personal Preferences: Check Scanning page displays.

  2. Edit the settings as desired. Each setting is described in the heading below.

  3. Click Save.
    The personal preference configuration is updated.

Check Scanning Mode

Each setting is described below:

Option Description

None

No scanner is connected to your workstation.

Serial COM Port (RM12 Only)

This is a depreciated setting.

Scan Manager (Epson, Magtek MICRImage, and more)

Connect to a Single and Multi-Feed Check Scanner on your workstation.

In the Default Check Scanner field, select your desired default check scanner. This is the scanner that populates by default when scanning checks, but other scanners can be selected as needed. Only check scanners which you have set up for your account display in the drop-down list.
