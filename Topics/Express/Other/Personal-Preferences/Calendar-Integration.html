Calendar Integration (Personal Preferences)

Rent Manager provides the ability to integrate your Rent Manager calendar with your personal calendar in external applications, which can be used to keep track of any appointments and tasks assigned to you. When a new appointment or task is created, you can select the Calendar Integration option to send a calendar item (such as a meeting invitation) to an email address via iCalendar or Google Apps. For more information, refer to Add an Appointment and Add a Task or Memorized Task.

In personal preferences, you can enter the email address to receive notifications about appointments and tasks, and override the system default Integration Method established in system preferences for only your account. For more information, refer to Calendar Integration (System Preferences).

To set these personal preferences, do the following:

  1. Go to arrow_forward Administration, then go to Preferences arrow_forward Personal Preferences arrow_forward Calendar Integration.
    The Personal Preferences: Calendar Integration page displays.

  2. Edit the settings as desired. Each setting is described in the headings below.

  3. Click Save.
    The personal preference configuration is updated.

Calendar Integration

Each setting is described below:

Option Description

Alternate Email

The email address where your calendar items from Rent Manager are sent. An address must be entered in this field to receive calendar items.

Integration Method

The integration method that Rent Manager should use when exporting calendar items. Each option is described below.

<System Default>

The appointment or task is sent using the Integration Method established in system preferences.

Disabled

Appointments and tasks are not integrated with your personal calendar, regardless of the settings established in system preferences.

iCal File Attachment

The calendar item is sent as an iCalendar (iCal) file attachment on an email, which can be opened to add the appointment or task to your personal calendar.

iCalendar MIME Stream (Outlook and Google Calendars)

The calender item is sent as a meeting that is automatically added to your personal calendar or, depending on application settings, sends an invitation to your calendar that you may accept or decline.

Google Apps for Work Calendar

The calendar item is automatically added to your Google calendar depending on the application's settings.
