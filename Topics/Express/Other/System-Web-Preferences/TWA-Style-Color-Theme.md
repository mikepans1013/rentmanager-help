# Tenant Web Access Color Theme (System Web Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Web-Preferences/TWA-Style-Color-Theme.htm

This system web preference group allows you to change the Tenant Web Access (TWA) web page colors to either one of many existing themed presets or to a fully customized theme that coordinates TWA to your business's branding.

 Related Privileges

 Group
 Privilege
 Column

 System
 System Web Preferences
 Enabled

 For more information, refer to Control User Access .

 Related Preferences

 To access Tenant Web Access settings, at least one location must be enabled for TWA. For more information, refer to Licensing (System Web Preferences) .

 To manage the TWA color theme options, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Web Preferences arrow_forward Tenant Web Access arrow_forward Style arrow_forward Color Theme .

 -
 Select a preset color theme. Alternatively, select Custom Color to create a theme of your own.
The themed colors update in the preview section below.

 -
 Optionally, edit the categories as desired. Each category is described below.

 -
 Click Save to apply your changes.

 Category Descriptions

 Each category is described below:

 Option
 Description

 Page Header

 This color displays at the top of each TWA page behind the name of the page as well as in emails generated from TWA.

 Tile Header

 This color displays at the top of each dashboard tile that displays in TWA.

 Button Color

 This color appears on all buttons throughout TWA as well as any buttons that appear in emails generated from TWA.

 Accent Color

 This color appears on other design elements (e.g., icons, checkboxes, borders) throughout TWA.
