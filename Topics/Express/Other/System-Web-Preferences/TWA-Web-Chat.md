# Tenant Web Access Web Chat (System Web Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Web-Preferences/TWA-Web-Chat.htm

These system web preferences allow you to determine whether Web Chat is enabled and to which queue the tenant is directed when beginning a chat on the Tenant Web Access web page.

 Related Privileges

 Group
 Privilege
 Column

 System
 System Web Preferences
 Enabled

 For more information, refer to Control User Access .

 Related Preferences

 To access Tenant Web Access settings, at least one location must be enabled for TWA in Licensing (System Web Preferences) .

 To set these system web preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Web Preferences arrow_forward Tenant Web Access arrow_forward Web Chat .

 -
 Select the option to Enable Web Chat .
A button displays in Tenant Web Access that users can click to begin chatting with you.

 -
 In the Specify queue for Tenant Web Access field, select an option to determine which initial questions a user is asked; when a TWA user starts a chat, this is the queue where their chat is directed.

 -
 Click Save to accept your changes.
