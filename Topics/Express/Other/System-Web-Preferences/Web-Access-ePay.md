# Web Access ePay (System Web Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Web-Preferences/Web-Access-ePay.htm

These system web preferences allow you to determine the parameters of ePay functionality for your web-based licenses.

 Related Privileges

 Group
 Privilege
 Column

 System
 System Web Preferences
 Enabled

 For more information, refer to Control User Access .

 Related Preferences

 To access these options, the system preferences option of Managed Deposits must be unchecked. For more information, refer to Advanced ePay (System Preferences) .

 To set these system web preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Web Preferences arrow_forward Web Access ePay .

 -
 Edit the settings as desired. Each setting is described below.

 -
 Click Save to accept your changes.

 Preference Descriptions

 Each setting is described below:

 Option
 Description

 Automatically deposit ePay payments

 Check to allow online transactions to automatically be deposited into the bank register.

 Combine same day ePay deposits

 Check to allow online web transactions to be combined into a single deposit for the full amount of payments for that day.
