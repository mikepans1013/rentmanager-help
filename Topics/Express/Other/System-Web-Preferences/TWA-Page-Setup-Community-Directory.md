# Tenant Web Access Community Directory Page Setup (System Web Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Web-Preferences/TWA-Page-Setup-Community-Directory.htm

These system web preferences determine if a tenant can access a community directory menu item on Tenant Web Access where they can add their contact information to the directory, as well as access the names and contact information for other tenants at the property.

 Related Privileges

 Group
 Privilege
 Column

 System
 System Web Preferences
 Enabled

 For more information, refer to Control User Access .

 Related Preferences

 To access Tenant Web Access settings, at least one location must be enabled for TWA. For more information, refer to Licensing (System Web Preferences) .

 To set these system web preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Web Preferences arrow_forward Tenant Web Access arrow_forward Page Setup arrow_forward Community Directory .

 -
 Edit the settings as desired. Each setting is described below.

 -
 Click Save to accept your changes.

 Preference Descriptions

 Each setting is described below.

 More Information

 If you don't enter a Menu Title , Title , or Custom Message , Rent Manager uses the associated system default value.

 Option
 Description

 Show Community Directory

 Check to allow your tenants to access the community directory through TWA.

 Menu Title

 The custom text for the menu link to this page.

 Title

 The custom text for the name of this page.

 Custom Message

 A custom message to be displayed on this page for all TWA users.
