# Owner Web Access Dashboard (System Web Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Web-Preferences/OWA-Dashboard.htm

This system web preferences group allows you to manage the Owner Web Access (OWA) dashboard tiles. Select which tiles you wish to display on the OWA dashboard as well as select the order in which they display on the screen.

 Related Privileges

 Group
 Privilege
 Column

 System
 System Web Preferences
 Enabled

 For more information, refer to Control User Access .

 Related Preferences

 To access Owner Web Access settings, at least one location must be enabled for OWA in system web preferences. For more information, refer to Licensing (System Web Preferences) .

 To set these system web preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Web Preferences arrow_forward Owner Web Access arrow_forward Dashboard .

 -
 Manage which dashboard tiles display in OWA and which tiles are excluded from the portal depending on the property at which your tenant resides.

 -
 Optionally, rearrange the order in which the tiles display in OWA.

 -
 Click Save to apply your changes.

 Tile Descriptions

 When new information is available on a tile, a green dot displays next to the line item on the table. The total of new items displays as a numerical value in the upper right corner of the tile.

 Each tile that is available to add to the dashboard is described below:

 Tile
 Description

 Messages

 Displays the contents of the General Owner Message field in system web preferences. For more information, refer to Owner Web Access General (System Web Preferences) .

 Ownership

 Displays ownership information including property name, ownership percentage, reserve amount, security deposits held, and ownership bank balance.

 Notes

 Displays owners' associated history/note items from the properties, units, and tenants in the owner's portfolio.

 Related Preferences

 Only the history/notes associated with the history categories selected in the Displayed Note Categories field display on OWA. For more information, refer to Owner Web Access History/Notes (System Web Preferences) .

 Bills

 Displays bills that expense properties in the owner's portfolio.

 Inspection Reports

 Displays the Web Inspection Report for inspections that were completed at their properties.

 Checks

 Displays check information associated with properties in the owner's portfolio.

 Management Fees

 Displays management fees postings associated with properties in the owner's portfolio.

 Owner Distributions

 Displays owner check disbursements associated with properties in the owner's portfolio.

 Service Issues

 Displays issues associated with properties in the owner's portfolio.

 Related Preferences

 The service issue information available to the owner is dependent on the selections made in system web preferences. For more information, refer to Owner Web Access Service Issues (System Web Preferences) .

 Estimates

 Displays estimates associated with properties in the owner's portfolio.

 Related Preferences

 The estimate information available to the owner is dependent on the selections made in system web preferences. For more information refer to Owner Web Access Estimates (System Web Preferences) .
