# Tenant Web Access Zego Statements Page Setup (System Web Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Web-Preferences/TWA-Page-Setup-Zego-Statements.htm

Zego Resident Billing is a feature that automates the process of billing your tenants. Zego effectively takes over the billing of your tenants, mails out customized statements and, in certain circumstances, takes over the payment process as well. These system web preferences determine if tenant's billing statements generated from Zego Resident Billing display in the Tenant Web Access (TWA) portal and how the page displays.

 Related Preferences

 To access Tenant Web Access settings, at least one location must be enabled for TWA. For more information, refer to Licensing (System Web Preferences) .

 To set these system web preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Web Preferences arrow_forward Tenant Web Access arrow_forward Page Setup arrow_forward Zego Statements .

 -
 Edit the settings as desired. Each setting is described below.

 -
 Click Save to accept your changes.

 Preference Descriptions

 Each setting is described below.

 More Information

 If you don't enter a Menu Title , Title , or Custom Message , Rent Manager uses the associated system default value.

 Option
 Description

 Show Zego Statements

 If using Zego Resident Billing, enable this option to display the tenant's billing statements.

 Related Preferences

 This page displays only when Zego Resident Billing is enabled. For more information, refer to Zego Resident Billing (System Preferences) .
