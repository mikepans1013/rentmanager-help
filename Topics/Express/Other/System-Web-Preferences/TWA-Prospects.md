# Tenant Web Access Prospects (System Web Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Web-Preferences/TWA-Prospects.htm

These system web preferences allow you to set default messages to show prospects who are using  Tenant Web Access (TWA) to fill out an application through Apply Now .

 Related Privileges

 Group
 Privilege
 Column

 System
 System Web Preferences
 Enabled

 For more information, refer to Control User Access .

 Related Preferences

 To access Tenant Web Access settings, at least one location must be enabled for TWA. For more information, refer to Licensing (System Web Preferences) .

 To set these system web preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Web Preferences arrow_forward Tenant Web Access arrow_forward Prospects .

 -
 Edit the settings as desired. Each setting is described below.

 -
 Click Save to accept your changes.

 Preference Descriptions

 Each setting is described below:

 Option
 Description

 Login Page Message

 The message that appears on the login screen for prospects.

 Message To Show All Users

 The message that appears on the dashboard for web user accounts associated with a Rent Manager prospect.

 Override Property Contact Information

 Check to use a custom email signature instead of the property’s contact information, which consists of the Full Name , Manager , and Email Address fields on the property's details page.

 If you select this option, you must enter a Name and Email address to use in email signatures.
