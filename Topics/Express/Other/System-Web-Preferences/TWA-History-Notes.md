# Tenant Web Access History/Notes (System Web Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Web-Preferences/TWA-History-Notes.htm

Tenant Web Access (TWA) offers the ability to select the history categories to be displayed in TWA.

 Related Privileges

 Group
 Privilege
 Column

 System
 System Web Preferences
 Enabled

 For more information, refer to Control User Access .

 Related Preferences

 To access Tenant Web Access settings, at least one location must be enabled for TWA. For more information, refer to Licensing (System Web Preferences) .

 To set these system web preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Web Preferences arrow_forward Tenant Web Access arrow_forward History/Notes .

 -
 Edit the settings as desired. Each setting is described below.

 -
 Click Save to accept your changes.

 Preference Descriptions

 Each setting is described below:

 Option
 Description

 Displayed Notes Category

 Select one or more of the tenant/prospect-type history categories for which history/note items display in TWA.

 To select all available tenant/prospect-type history categories that are applicable to the tenant's account and history, choose the All Categories option. You can also select <Uncategorized> to display history/notes not associated with a category.

 Show Property Notes

 Check to allow web users to view the associated property history/notes of the selected categories.

 Show Unit Notes

 Check to allow web users to view the associated unit history/notes of the selected categories.

 Show Inspection Reports

 Check to allow a web user to view the associated report for inspections completed with the rmInspection feature.
