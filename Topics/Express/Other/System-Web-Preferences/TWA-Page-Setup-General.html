Tenant Web Access General Page Setup (System Web Preferences)

These system web preferences customize the Tenant Web Access (TWA) portal title by replacing Tenant in Tenant Web Access. You can also have a separate customization for association-type properties.

Related Privileges

Group Privilege Column
System System Web Preferences Enabled

For more information, refer to Control User Access.

Related Preferences

To access Tenant Web Access settings, at least one location must be enabled for TWA. For more information, refer to Licensing (System Web Preferences).

To set these system web preferences, do the following:

  1. Go to arrow_forward Administration, then go to Preferences arrow_forward System Web Preferences arrow_forward Tenant Web Access arrow_forward Page Setup arrow_forward General.

  2. Edit the settings as desired. Each setting is described below.

  3. Click Save to accept your changes.

Preference Descriptions

Each setting is described below.

Option Description

Default - 'Tenant'

Select to use the default portal name, Tenant Web Access.

Custom

Select to enter a new name to replace Tenant in Tenant Web Access. For example, you can enter Resident so the portal name displays as Resident Web Access.

Override Title for Association Properties

Check to have a different portal name display for properties with the Property Type of Association. Choose from one of the following options.

Default - Member

Select to use the default portal name, Member Web Access, for properties marked as associations.

Custom

Select to enter a new name to replace Member in Member Web Access. For example, you can enter Association so the portal name displays as Association Web Access.
