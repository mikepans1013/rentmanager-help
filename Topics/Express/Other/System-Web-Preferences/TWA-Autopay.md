# Tenant Web Access AutoPay (System Web Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Web-Preferences/TWA-Autopay.htm

Tenant Web Access (TWA) offers an automatic payment feature called AutoPay which allows tenants with TWA accounts to set up recurring payments for their rent or other charges. These preferences allow you to enable AutoPay and designate on which day(s) of the month a tenant can submit an automatic payment.

 Related Preferences

 To access Tenant Web Access settings, at least one location must be enabled for TWA. For more information, refer to Licensing (System Web Preferences) .

 To set these system web preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Web Preferences arrow_forward Tenant Web Access arrow_forward AutoPay .

 -
 To enable AutoPay setups in TWA, check Enable AutoPay Configuration .

 -
 Edit the settings as desired. Each setting is described below.

 -
 Click Save to accept your changes.

 Warning

 Changing these settings affects only tenants editing or creating new AutoPay schedules. Tenants with an AutoPay schedule already established are not affected.

 To force tenants with already established AutoPay schedules to abide by changes to these settings, do the following, you must uncheck and then recheck the option to Enable AutoPay Configuration .

 Preference Descriptions

 Each setting is described below:

 Option
 Description

 Available Frequencies

 Check which AutoPay frequency option(s), Weekly , Monthly , Quarterly , Semiannually , or Annually , tenants can choose from when using AutoPay.

 Available Frequencies (Associations)

 Check Override Available Frequencies for Associations to enable different frequency options for associations. Then, in the select which AutoPay option(s), Weekly , Monthly , Quarterly , Semiannually , or Annually , association members can choose from when using AutoPay.

 Days of month to allow AutoPay to be run (Monthly only)

 From the drop-down list, select which days per month a tenant may choose as the date their payment is processed. The selected days display in TWA as options in the Day of Month drop-down list.

 More Information

 If you select 31 , any month with less than 31 days defaults to the last day of the month.

 To allow tenants to choose any day of the month as their recurring payment date, check Any Day .

 Warning

 If you use recurring ePay to post ePay payments as a batch and a tenant enables AutoPay in TWA, the tenant is no longer included when posting recurring ePay .
