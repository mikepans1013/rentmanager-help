# Owner Web Access Color Theme (System Web Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Web-Preferences/OWA-Style-Color-Theme.htm

This system web preference group allows you to change the Owner Web Access (OWA) web page colors to either one of many existing themed presets or to a fully customized theme that coordinates OWA to your business's branding.

 Related Privileges

 Group
 Privilege

 System Web Preferences

 For more information, refer to Control User Access .

 Related Preferences

 To access Owner Web Access settings, at least one location must be enabled for OWA in system web preferences. For more information, refer to Licensing (System Web Preferences) .

 To manage the OWA color theme options, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Web Preferences arrow_forward Owner Web Access arrow_forward Style arrow_forward Color Theme .

 -
 Select a preset color theme. Alternatively, select Custom Color to create a theme of your own.
The themed colors update in the preview section below.

 -
 Optionally, edit the categories as desired. Each category is described below.

 -
 Click Save to apply your changes.

 Category Descriptions

 Each category is described below:

 Option
 Description

 Toolbar Color

 This color displays at the top of each OWA page behind the name of the page. It also displays at the top of each dashboard tile in OWA.

 Buttons & Accent

 This color appears on buttons throughout OWA as well as any buttons that appear in emails generated from OWA. This color also appears on other design elements (e.g., icons, checkboxes, borders) throughout OWA.
