STR Online Booking RV/Campground Settings (System Web Preferences)

These system web preferences allow you to establish various settings for short term rental (STR) online booking, including the type of account created for reservations, how far in the future reservations can be booked, and the minimum and maximum length of reservations.

More Information

The STR Online Booking feature is licensed and must be purchased separately. For more information, contact your sales representative at sales@rentmanager.com.

Related Privileges

Group Privilege Column
System System Web Preferences Enabled

For more information, refer to Control User Access.

To set these system web preferences, do the following:

  1. Go to arrow_forward Administration, then go to Preferences arrow_forward System Web Preferences arrow_forward STR Online Booking arrow_forward RV/Campground arrow_forward Settings.

  2. Edit the settings as desired. Each setting is described below.

  3. Click Save to accept your changes.

Preference Descriptions

This preference group is divided into multiple sections. Each setting is described within the corresponding sections below.

RV/Campground - Settings

In this section, establish the account type to use for online booking guests and the dates available for reservations.

Option Description

Type of account created when booking a reservation

Determine whether reservations create a Tenant account or Prospect account for the guest.

Number of days in the future a guest can book a reservation

The final arrival date on which an online booking can be created, up to and including the selected date. For example, if you enter 365 in the Days field and a guest goes to book a reservation on 10/31, they can choose an arrival date on or before 10/31 of the following year.

Alternatively, enter a specific future Date to be the final available arrival date.

Number of days in advanced required to book a reservation

The first arrival date on which an online booking can be created. For example, if you enter 3 in the left field and a guest goes to book a reservation on 10/1, they can choose an arrival date of 10/4 or later.

Alternatively, check Allow same day bookings and reservations do not require advance notice to book.

Stay Options

In this section, choose optional minimum and maximum nights for guest reservations.

Field Description

Minimum nights required for a reservation

Check this box to set the lower limit on the length of online bookings, then enter the minimum required number of nights in the field below.

In the Message to display if reservation does not meet minimum stay requirement field, enter the text to display when a guest attempts to book a reservation lower than the set value.

Maximum nights required for a reservation

Check this box to set a cap on the length of online bookings, then enter the maximum allowed number of nights in the below field.

In the Message to display if reservation exceeds maximum nights allowed field, enter the text to display when a guest attempts to book a reservation higher than the set value.

To allow guests who exceed the maximum number of nights to submit a reservation application via Apply Now, check Allow guest to submit an application for reservations that exceed the maximum nights allowed.

Related Preferences

Apply Now must be enabled in system web preferences to check Allow guest to submit an application for reservations that exceed the maximum nights allowed. For more information, refer to Tenant Web Access Apply Now General (System Web Preferences).

Booking Success Message

In the text box, enter a message to display when a guest successfully completes the booking process.
