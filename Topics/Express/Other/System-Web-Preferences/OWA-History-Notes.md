# Owner Web Access History/Notes (System Web Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Web-Preferences/OWA-History-Notes.htm

These system web preferences allow you to select the history/note categories that display for the owner in Owner Web Access .

 Related Privileges

 Group
 Privilege
 Column

 System
 System Web Preferences
 Enabled

 For more information, refer to Control User Access .

 Related Preferences

 To access Owner Web Access settings, at least one location must be enabled for OWA in system web preferences. For more information, refer to Licensing (System Web Preferences) .

 To set these system web preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Web Preferences arrow_forward Owner Web Access arrow_forward History/Notes .

 -
 Edit the settings as desired. Each setting is described below.

 -
 Click Save to accept your changes.

 Preference Descriptions

 Each setting is described below:

 Preference
 Description

 Displayed Note Categories

 Select one or more of the owner-type history categories which history/note items display in OWA. To select all owner-type history categories, choose the All Categories option. You can also select <Uncategorized> to display history/notes not associated with a category.

 Email When New Owner Notes Are Added In Selected Categories

 Check to email owners when a new history/note that was assigned the owner type is added to a property, unit, or tenant account in their portfolio.

 More Information

 This requires the owner's email address be entered on the Miscellaneous tile of their account.

 Email When New Owner Files Are Published

 Check to email owners when a new file has been sent out for signatures.

 More Information

 This requires the owner's email address be entered on the Miscellaneous tile of their account.

 Show Property Notes

 Check to allow web users to view the associated property history/notes of the selected categories.

 Show Unit Notes

 Check to allow web users to view the associated unit history/notes of the selected categories.

 Show Tenant Notes

 Check to allow web users to view the associated tenant history/notes of the selected categories.
