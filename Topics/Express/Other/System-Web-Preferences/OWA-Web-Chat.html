Owner Web Access Web Chat (System Web Preferences)

These system web preferences allow you to determine whether Web Chat is enabled and to which web chat queue the owner is directed when beginning a chat in Owner Web Access.

Related Privileges

Group Privilege Column
System System Web Preferences Enabled

For more information, refer to Control User Access.

Related Preferences

To access Owner Web Access settings, at least one location must be enabled for OWA in system web preferences. For more information, refer to Licensing (System Web Preferences).

To set these system web preferences, do the following:

  1. Go to arrow_forward Administration, then go to Preferences arrow_forward System Web Preferences arrow_forward Owner Web Access arrow_forward Web Chat.

  2. Select the option to Enable Web Chat.
    A button displays in Owner Web Access that users can click to begin chatting with you.

    More Information

    Depending on your queue settings, the chat button may not display when the chat is offline.

  3. In the Specify queue for Owner Web Access field, select an option to determine which initial questions a user is asked; when an OWA user starts a chat, this is the queue where their chat is directed.

  4. Click Save to accept your changes.
