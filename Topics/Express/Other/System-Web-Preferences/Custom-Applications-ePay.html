Custom Applications ePay (System Web Preferences)

These system web preferences allow you to determine parameters to allow applicants to use ePay to pay a fee charged for submitting an online custom application.

Related Privileges

Group Privilege Column
System System Web Preferences Enabled

For more information, refer to Control User Access.

To set these system web preferences, do the following:

  1. Go to arrow_forward Administration, then go to Preferences arrow_forward System Web Preferences arrow_forward Custom Applications arrow_forwardePay.

  2. Select the option to Enable ePay.
    If checked, applicants see a Payments page when they submit their online application.

    Related Preferences

    To enable ePay for custom applications, ePay must first be set up in system preferences. For more information, refer to General ePay (System Preferences).

  3. Edit the settings as desired. Each setting is described below.

  4. Click Save to accept your changes.

Preference Descriptions

Each setting is described below:

Option Description

Application Fee Amount

Enter the amount to be charged for application fees completed online.

Application Fee Charge Type

Select the charge type to be applied to the prospect account for the application fee.

Have Zego Manage Platform Fees

Check to avoid having to manually set up platform fee charges and instead allow Zego to automatically collect platform fees for online processing directly from applications.

Related Preferences

This option is available only if the option to Have Zego manage platform fees is enabled in system preferences. For more information, refer to General ePay (System Preferences).

CC Platform Fee Amount

If applicable, enter a platform fee amount to be charged when a prospect uses a credit card to pay the application fee online. Optionally, check Percentage and enter a value to charge a percentage of the amount collected instead of a flat fee.

This option is disabled if the option to Have Zego Manage Platform Fees is checked.

ACH Platform Fee Amount

If applicable, enter a platform fee amount to be charged when processing an ACH payment to pay the application fee online. Optionally, check Percentage and enter a value to charge a percentage of the amount collected instead of a flat fee.

This option is disabled if the option to Have Zego Manage Platform Fees is checked.

Platform Fee Charge Type

Select the charge type to be applied to the prospect account for platform fees.

Require a disclaimer for ePay transactions

Check this option if you wish to enter a disclaimer for ePay transactions associated with the application process.

Applicants are required to check the box next to the disclaimer to verify they read the message before submitting the application fee payment.
