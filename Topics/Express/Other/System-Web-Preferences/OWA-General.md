# Owner Web Access General (System Web Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Web-Preferences/OWA-General.htm

These system web preferences allow you to customize a login message and set login/lockout restrictions for Owner Web Access (OWA) users, specify the OWA webpage header, and adjust OWA email settings on the Owner Web Access webpage.

 Related Privileges

 Group
 Privilege
 Column

 System
 System Web Preferences
 Enabled

 For more information, refer to Control User Access .

 Related Preferences

 To access Owner Web Access settings, at least one location must be enabled for OWA in system web preferences. For more information, refer to Licensing (System Web Preferences) .

 To set these system web preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Web Preferences arrow_forward Owner Web Access arrow_forward General .

 -
 Edit the settings as desired. Each setting is described below.

 -
 Click Save to accept your changes.

 Preference Descriptions

 Each setting is described below.

 Preference
 Description

 General Owner Message

 The message that displays on the Messages tile on the dashboard for returning OWA users.

 Failed Login Attempts Until Lockout

 The number of unsuccessful sign in attempts an OWA user is allowed before the account is locked.

 Lockout Time (In Minutes)

 The number of minutes an OWA user's account stays locked after a lockout. To lock the user out indefinitely and require a Rent Manager user to remove the account lockout, enter 0 .

 Days Active After Contract End

 The number of days after the owner's Contract End date, as entered on the owner's details page, that an owner can still access their OWA account.

 Allow Owner to Email Property Manager

 If checked, a link is added to the OWA dashboard allowing the OWA user to compose and send an email to the property manager, using the Manager and Email fields as entered on the property's details page.

 Additionally, to save a copy of the owner's emails to their History/Notes tile, select a default owner/owner prospect-type History/Note Category .

 OWA Email Signature

 The contact information that displays on the signature of automated emails generated from Owner Web Access .

 Use Property Contact Information

 Select to display the property’s contact information as the OWA email signature. The property’s contact information consists of the Full Name , Manager , and Email fields entered on the property's details page.

 Override Property Contact Information

 Select and enter a name and email address to be displayed as the OWA email signature.
