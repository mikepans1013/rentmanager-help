# Tenant Web Access Site Header (System Web Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Web-Preferences/TWA-Style-Site-Header.htm

This system web preferences group allows you to change the Tenant Web Access (TWA) web page header image from the system default to a custom image as well as manage the color of the page headers.

 Related Privileges

 Group
 Privilege
 Column

 System
 System Web Preferences
 Enabled

 For more information, refer to Control User Access .

 Related Preferences

 To access Tenant Web Access settings, at least one location must be enabled for TWA. For more information, refer to Licensing (System Web Preferences) .

 To manage the TWA site header options, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Web Preferences arrow_forward Tenant Web Access arrow_forward Style arrow_forward Site Header .

 -
 Select the option to Customize Site Header image to enable the customization options.

 -
 Edit the settings as desired. Each setting is described below.

 -
 Click Save to apply your changes.

 Preference Descriptions

 Each setting is described below:

 Option
 Description

 Image File

 Select this option to upload an Image that appears on all page headers in Tenant Web Access across your entire property portfolio.

 More Information

 The ideal image size is 1900 x 200 pixels. This allows for a clear image on TWA without cropping or stretching the image.

 Property UDF

 Select this option to choose a property-type user defined field (UDF) for which a custom image has already been specified for each property in your portfolio in order to set TWA page headers unique to each of those properties.

 More Information

 Only information related to the properties to which you have access displays. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 If no user defined fields appear in the drop-down menu, you must first create at least one property-level UDF with a File field type. Acceptable file types for TWA site headers are .jpg, .png, and .bmp.

 Image Alignment

 The alignment ( Left , Center , Right ) of the site header image you have specified.

 Background Color

 Select a color from the menu to appear on all site headers in Tenant Web Access across your entire property portfolio. This color appears behind the site header image.
