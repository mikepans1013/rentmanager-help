# Tenant Web Access Service Issues Page Setup (System Web Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Web-Preferences/TWA-Page-Setup-Service-Issues.htm

These system web preferences determine if a tenant's associated issues can be viewed in the Tenant Web Access (TWA) portal and how the page displays.

 Related Privileges

 For more information, refer to Control User Access .

 Related Preferences

 To access Tenant Web Access settings, at least one location must be enabled for TWA. For more information, refer to Licensing (System Web Preferences) .

 To set these system web preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Web Preferences arrow_forward Tenant Web Access arrow_forward Page Setup arrow_forward Service Issues .

 -
 Edit the settings as desired. Each setting is described below.

 -
 Click Save to accept your changes.

 Preference Descriptions

 Each setting is described below.

 Option
 Description

 Show Service Issues

 Check to allow tenants to view their service issue requests.

 Below is an example of how service issues display in Tenant Web Access .

 Related Preferences

 For more information on how to set up Service Manager options and allow TWA users to submit service issues, refer to Tenant Web Access Service Issues (System Web Preferences) .

 Exclude from Associations

 Check to exclude the Service Issues page for TWA users associated with properties that have the property field for Property Type set to Association .

 Default - 'Service Issues'

 Select to use the default page name, Service Issues .

 Custom

 Select to have a different page name display for issues. Enter the Singular (e.g., Maintenance Request ) and Plural (e.g., Maintenance Requests ) versions of the desired name for the web page.

 Custom Message

 Optionally, enter an custom message to be displayed on this page for all TWA users.
