# Tenant Web Access Accounts (System Web Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Web-Preferences/TWA-Accounts.htm

Tenant Web Access (TWA) offers the ability for tenants to create their own web user accounts and/or change their personal information on their TWA account. Any web user accounts associated with a tenant display in Web Access Settings .

 Related Preferences

 To access Tenant Web Access settings, at least one location must be enabled for TWA. For more information, refer to Licensing (System Web Preferences) .

 To set these system web preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Web Preferences arrow_forward Tenant Web Access arrow_forward Accounts .

 -
 Select the option to Allow tenants to create accounts .

 -
 Optionally, select any of the available verification methods to authenticate the tenant's identity. Each option is described below.

 -
 Click Save to accept your changes.

 Warning

 The values entered by the tenant during account creation must match the data in your Rent Manager database. If the tenant enters incorrect answers, your database contains incorrect information, or the specified data has not been entered in Rent Manager , the tenant receives an error message.

 Additionally, regardless of the options you select, the tenant needs their system generated Account Number to create a TWA account. This number can be found on the tenant's scoreboard.

 Preference Descriptions

 You can verify accounts based on the information found on a tenant's account and their contacts. Each setting is described below:

 Option
 Description

 Allow tenant to change their account information

 Check to allow tenants to change their contact information (e.g., email, phone number, and so on) online. Changes the tenant makes in Tenant Web Access are immediately reflected in tenant history/notes.

 Verify with birth date

 Validate account creation with a birth date.

 Verify with email address

 Validate account creation with an email address.

 Verify with Phone Number

 Validate account creation with a phone number.

 Verify with SSN

 Validate account creation with a social security number.

 Optionally, check Only use last four digits to require only the last four digits.

 Verify with user defined field

 Validate account creation with responses on a tenant-level user defined field selected from the drop-down list. You can require responses for up to three different user defined fields.

 Note that tenant-level File and Image user defined field types are excluded from this drop-down list.
