# Tenant Web Access Message Board (System Web Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Web-Preferences/TWA-Message-Board.htm

This preference group is part of system web preferences which determines the web user's ability to add, view, and delete messages on the Tenant Web Access message board.

 Related Preferences

 To access the message board on TWA, the Show Message Board field must be enabled in system web preferences. For more information, refer to Tenant Web Access Message Board Page Setup (System Web Preferences) .

 Related Preferences

 To access Tenant Web Access settings, at least one location must be enabled for TWA. For more information, refer to Licensing (System Web Preferences) .

 To set these system web preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Web Preferences arrow_forward Tenant Web Access arrow_forward Message Board .

 -
 Edit the settings as desired. Each setting is described below.

 -
 Click Save to accept your changes.

 Preference Descriptions

 This preference group is divided into multiple sections. Each setting is described within the corresponding section below.

 Setup

 Select one of the following options to determine when messages post to Tenant Web Access (TWA) .

 Option
 Description

 Approval Required

 Messages posted to the message board require approval by an administrator before they can be viewed by other users in TWA.

 Auto-Approved

 Messages posted to the message board are viewable by other users in TWA immediately and do not require approval.

 Messages

 All messages posted to the message board display in this section regardless if the message was created on TWA or Rent Manager . You can also filter the displayed messages by selecting <All> , Approved , or Pending . Changing the view does not allow users to see unapproved messages.

 More Information

 Messages on the board display for up to 30 days.

 To manually add a new message to the message board, do the following:

 -
 Click Add .
The Message Details pop-up displays.

 -
 Enter the applicable information.

 Field
 Description

 Date/Time

 The current date and time automatically populates.

 Submitted By

 The name of the current user automatically populates.

 Status

 Select Pending or Approved depending on if the message can be viewed in TWA immediately.

 Pending

 The message is not viewable in TWA until the status is changed to Approved .

 Approved

 The message is immediately viewable in TWA.

 Approved By

 The name of the current user automatically populates.

 Message

 Enter the note to be displayed on TWA.

 -
 Click Save .
The message is added to system web preferences with the relevant information.
