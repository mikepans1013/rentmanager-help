# Tenant Web Access Polls Page Setup (System Web Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Web-Preferences/TWA-Page-Setup-Polls.htm

These system web preferences customize how surveys/polls display in Tenant Web Access (TWA) . This page automatically displays in TWA when a survey has been published, and has not yet reached its end date.

 More Information

 This topic describes surveys/polls created with the intent to be posted to TWA. For more information, refer to Add and Publish a Survey to Tenant Web Access (TWA) .

 Related Preferences

 To access Tenant Web Access settings, at least one location must be enabled for TWA. For more information, refer to Licensing (System Web Preferences) .

 To set these system web preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Web Preferences arrow_forward Tenant Web Access arrow_forward Page Setup arrow_forward Polls .

 -
 Edit the settings as desired. Each setting is described below.

 -
 Click Save to accept your changes.
