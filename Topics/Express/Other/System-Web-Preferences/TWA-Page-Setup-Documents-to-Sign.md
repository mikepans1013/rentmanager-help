# Tenant Web Access Documents to Sign Page Setup (System Web Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Web-Preferences/TWA-Page-Setup-Documents-to-Sign.htm

These system web preferences determine if a tenant's associated signable documents can be viewed in the Tenant Web Access (TWA) portal and how the page displays.

 Related Privileges

 Group
 Privilege
 Column

 System
 System Web Preferences
 Enabled

 For more information, refer to Control User Access .

 Related Preferences

 To access Tenant Web Access settings, at least one location must be enabled for TWA. For more information, refer to Licensing (System Web Preferences) .

 To set these system web preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Web Preferences arrow_forward Tenant Web Access arrow_forward Page Setup arrow_forward Documents to Sign .

 -
 Edit the settings as desired. Each setting is described below.

 -
 Click Save to accept your changes.

 Preference Descriptions

 Each setting is described below.

 More Information

 If you don't enter a Menu Title , Title , or Custom Message , Rent Manager uses the associated system default value.

 Option
 Description

 Show Documents to Sign

 Check to allow tenants to view signable documents in TWA that have been sent to them.

 More Information

 If a signable document needs to be signed by a tenant, the document displays in Tenant Web Access until it is signed, regardless of whether this option is checked or not.

 Below is an example of how a document that is ready to sign displays in Tenant Web Access .
