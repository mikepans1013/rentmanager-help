# Owner Web Access Service Issues (System Web Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Web-Preferences/OWA-Service-Issues.htm

These system web preferences allow you to determine what service issue information the owner can view when accessing the Owner Web Access web page.

 Related Privileges

 Group
 Privilege
 Column

 System
 System Web Preferences
 Enabled

 For more information, refer to Control User Access .

 Related Preferences

 To access Owner Web Access settings, at least one location must be enabled for OWA in system web preferences. For more information, refer to Licensing (System Web Preferences) .

 To set these system web preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Web Preferences arrow_forward Owner Web Access arrow_forward Service Issues .

 -
 Edit the settings as desired. Each setting is described below.

 -
 Click Save to accept your changes.

 Preference Descriptions

 This preference group is divided into multiple sections. Each setting is described within the corresponding section below.

 Service Issues

 In this section, you can choose which issues display in OWA.

 Preference
 Description

 Show

 Determine if Open Issues and/or Closed Issues display in OWA.

 Categories to Show

 Select each issue category to display in OWA. Check <Unassigned> to display issues with no category. Check All Categories to include all current and future categories, including <Unassigned> .

 Include on Service Issues

 In this section, you can determine the information associated issues that should display in OWA. The below options become available if either Open Issues and/or Closed Issues is checked for the Show field.

 Preference
 Description

 Work Order Items

 Check to allow the owner to view information about any work orders included on service issues.

 Vendor Information

 Check to allow the owner to view information about any work orders included on service issues.

 Tenant Information

 Check to allow the owner to view information about any tenant(s) linked to a service issue.

 Include issue History/Notes with the selected history categories

 Check to allow the owner to view the history/note items of a designated category on the service issues. From the drop-down list, select the categories that display for owners in OWA. Check All Categories to display all history/note items, including items that are <Unassigned> .
