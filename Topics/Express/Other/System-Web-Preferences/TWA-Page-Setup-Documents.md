# Tenant Web Access Documents Page Setup (System Web Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Web-Preferences/TWA-Page-Setup-Documents.htm

These system web preferences determine if the files uploaded to the tenant's associated property display in the Tenant Web Access (TWA) portal and how the page displays.

 Related Privileges

 For more information, refer to Control User Access .

 Related Preferences

 To access Tenant Web Access settings, at least one location must be enabled for TWA. For more information, refer to Licensing (System Web Preferences) .

 To set these system web preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Web Preferences arrow_forward Tenant Web Access arrow_forward Page Setup arrow_forward Documents .

 -
 Edit the settings as desired. Each setting is described below.

 -
 Click Save to accept your changes.

 Preference Descriptions

 More Information

 If you don't enter a Menu Title , Title , or Custom Message , Rent Manager uses the associated system default value.

 Each setting is described below.

 Option
 Description

 Show Documents

 Allows the tenant to view the associated property files that have the Show In TWA  option checked.
