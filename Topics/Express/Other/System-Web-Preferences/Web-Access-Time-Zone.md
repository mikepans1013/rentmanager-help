# Web Access Time Zone (System Web Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Web-Preferences/Web-Access-Time-Zone.htm

These system web preferences allow you to determine the time zone that applies to the time stamps for your system activities, such as the time zone of your property's web portals (Tenant Web Access or Owner Web Access), postings, late fees, and so on. While each property can have its own time zone offset configured on property's details page, you can establish these system preferences for your management company as a baseline for your business.

 For more information, refer to Control User Access .

 To set these system web preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Web Preferences arrow_forward Web Access Time Zone .

 -
 Select the Enabled option.

 -
 Edit the settings as desired. Each setting is described below.

 -
 Click Save to accept your changes.

 Preference Descriptions

 Each setting is described below:

 Option
 Description

 Time Zone

 Select a time zone from the drop-down list (i.e., Hawaii, Alaska, Pacific, Mountain, Central, Eastern, Atlantic). By default, the time stamp for web activities is the current LCS server date and time.

 Observe Daylight Savings Time

 If your region observes Daylight Savings Time (DST), check this option to have Rent Manager automatically adjust the time for DST as necessary.
