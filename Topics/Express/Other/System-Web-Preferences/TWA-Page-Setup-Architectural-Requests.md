# Tenant Web Access Architectural Requests Page Setup (System Web Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Web-Preferences/TWA-Page-Setup-Architectural-Requests.htm

These system web preferences determine if a tenant can submit architectural requests through the Tenant Web Access (TWA) portal and how the page displays.

 Related Privileges

 Group
 Privilege

 System
 System Web Preferences
 Enabled

 For more information, refer to Control User Access .

 Related Preferences

 To access Tenant Web Access settings, at least one location must be enabled for TWA. For more information, refer to Licensing (System Web Preferences) .

 To set these system web preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Web Preferences arrow_forward Tenant Web Access arrow_forward Page Setup arrow_forward Architectural Requests .

 -
 Edit the settings as desired. Each setting is described below.

 -
 Click Save to accept your changes.

 Preference Descriptions

 Each setting is described below.

 More Information

 If you don't enter a Menu Title , Title , or Custom Message , Rent Manager uses the associated system default value.

 Option
 Description

 Show Architectural Requests

 Check to allow your tenants to submit requests for making external changes to their home for approval by the association. Additionally, this allows tenants who are members of the association's committee or board to vote on architectural requests.

 Below is an example of how architectural requests submitted by tenants that are not members of an association display in Tenant Web Access .

 More Information

 The Architectural Requests page displays only for TWA users associated with properties that have the property field for Property Type set to Association .
