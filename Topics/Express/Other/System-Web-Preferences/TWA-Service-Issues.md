# Tenant Web Access Service Issues (System Web Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Web-Preferences/TWA-Service-Issues.htm

This system web preference group allows you to determine how tenants can submit or manage their service issues via Tenant Web Access (TWA) .

 Related Privileges

 Group
 Privilege

 System
 System Web Preferences
 Enabled

 For more information, refer to Control User Access .

 Related Preferences

 To access Tenant Web Access settings, at least one location must be enabled for TWA. For more information, refer to Licensing (System Web Preferences) .

 To set these system web preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Web Preferences arrow_forward Tenant Web Access arrow_forward Service Issues .

 -
 Edit the settings as desired. Each setting is described below.

 -
 Click Save to accept your changes.

 Preference Descriptions

 This preference group is divided into multiple sections. Each setting is described within the corresponding section below.

 Create Service Issues

 This section covers settings regarding tenants submitting service issues via TWA.

 Option
 Description

 Allow Tenant to Create Service Issues

 Allows web users to create service issues via Tenant Web Access .

 Optionally, in the Custom Message field, enter text that displays at the top of the Add Service Issue page in Tenant Web Access .

 More Information

 Changes made to the issue via Rent Manager or rmAppSuite Pro are not displayed in TWA unless the Show All Service Issue Details option is also checked.

 Remove 'Pet?' option if pets are not allowed on property

 Check to remove the Pet? option for tenants submitting service issues via Tenant Web Access at properties with no pet types

 This option is available only if Allow Tenant to Create Service Issues is enabled.

 Use Predefined Service Issue Titles

 Check to create preset titles for service issues from which a web user may choose when creating an issue via TWA. Customized titles allow you to quickly identify the type of service requested, as well as the source of the issue as TWA (e.g., Plumbing Issue - TWA ).

 To create titles for issues created via TWA, click Add Predefined Title .

 This option is available only if Allow Tenant to Create Service Issues is enabled.

 Allow Custom Titles

 Check to allow web users to create their own issue titles when submitting service issues via TWA.

 This option is available only if Use Predefined Service Issue Titles is enabled.

 Default Category for Issues from TWA

 From the drop-down list, select the default issue category that populates in the Category field for issues created via TWA. For more information, refer to Issue Categories (Page) .

 Display Service Issues

 This section covers settings regarding tenants viewing their service issues in TWA.

 Option
 Description

 Include issues for all tenants in the account group

 For tenants who are in an account group, check to display all service issues linked to any tenants in the account group in TWA.

 Always display issues created in TWA

 Check to allow tenants to view all open or closed service issues that they have created via TWA.

 Display issues created in Rent Manager with the selected categories

 Check to display only service issues with the selected issue categories in TWA. Check <Unassigned> to include issues with no assigned issue category. Check <All Categories> to include all issue categories, including <Unassigned> .

 Show all Service Issue details

 Allow web users to view all details and updates to any service issues they created via TWA.

 This option is available only if Always display issues created in TWA or Display issues created in Rent Manager with the selected categories is enabled.

 Include issue History/Notes with the selected history categories

 Check to display issue history/notes of a designated issue-type category in TWA. Check <Unassigned> to include issues with no assigned history category. Check <All Categories> to include all history categories, including <Unassigned> .

 This option is available only if Always display issues created in TWA or Display issues created in Rent Manager with the selected categories is enabled.
