# Tenant Web Access Message Board Page Setup (System Web Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Web-Preferences/TWA-Page-Setup-Message-Board.htm

These system web preferences determine if the message board can be viewed in the Tenant Web Access portal and how the page displays.

 The message board is a way for tenants who use Tenant Web Access (TWA) to leave comments or questions directly through their TWA portal. Rent Manager users are able to access and respond to the posted messages, as well as control what gets posted to the message board. Additionally, other tenants are able to view posted messages and respond to members of their community.

 To set these system web preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Web Preferences arrow_forward Tenant Web Access arrow_forward Page Setup arrow_forward Message Board .

 -
 Edit the settings as desired. Each setting is described below.

 -
 Click Save to accept your changes.
