RV/Campground Online Booking ePay (System Web Preferences)

These system web preferences allow you to establish the payment methods available for short-term rental (STR) Online Booking and how ePay platform fees for those payments are managed and collected.

More Information

The STR Online Booking feature is licensed and must be purchased separately. For more information, contact your sales representative at sales@rentmanager.com.

Related Privileges

Group Privilege Column
System System Web Preferences Enabled

For more information, refer to Control User Access.

To set these system web preferences, do the following:

  1. Go to arrow_forward Administration, then go to Preferences arrow_forward System Web Preferences arrow_forward RV/Campground arrow_forward ePay.

  2. Edit the settings as desired. Each setting is described below.

  3. Click Save to accept your changes.

Preference Descriptions

This preference group is divided into multiple sections. Each setting is described within the corresponding sections below.

Account Types

In this section, check Override system preferences default payment types to select the ePay account options that are available only for reservations made via the STR Online Bookings portal. If the same payment options should be available, leave the option unchecked and the account types enabled in system preferences are used. For more information, refer to Advanced ePay (System Preferences).

More Information

If you are licensed for the CashPay feature with Zego, a CashPay field displays in the Account Types section, and you may set the CashPay daily cutoff time. Setting the cutoff time to the local equivalent of Zego's cutoff time of 2:59AM Eastern Standard Time (EST) is recommended.

Platform Fees

In this section, establish how to handle ePay platform fees (i.e., an additional cost for processing payments via ACH or credit cards). You can either allow Zego to manage and collect platform fees directly, or manually track fees as additional tenant transactions in Rent Manager.

Option Description

Have Zego manage platform fees

Allow Zego to automatically collect its platform fees for online processing directly from STR Online Booking ePay transactions.

If this option is unchecked, you are responsible for collecting platform fees from transactions and must pay those fees when invoiced by Zego.

Charge Type

The charge type to assign for platform fee transactions.

This field is available only if Have Zego manage platform fees is unchecked.
ACH, Credit Cards, and Debit Cards

Check the applicable payment type options to determine how platform fees are charged for reservations made via the STR Online Booking portal. Enter the flat fee amount in the field on the right for the associated payment option, or check Percentage and enter a value to charge a percentage of the amount collected instead of a flat fee.

These options are available only if Have Zego manage platform fees is unchecked.

Require a Disclaimer for ePay Transactions

Check to enter a disclaimer that must be acknowledged before an ePay payment is submitted via the STR Online Booking portal.
