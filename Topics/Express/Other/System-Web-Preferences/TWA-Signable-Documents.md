# Tenant Web Access Signable Documents (System Web Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Web-Preferences/TWA-Signable-Documents.htm

This system web preference group allows you to manage the default settings for signable documents which recipients can view and sign through Tenant Web Access (TWA) .

 Related Privileges

 Group
 Privilege
 Column

 System
 System Web Preferences
 Enabled

 For more information, refer to Control User Access .

 Related Preferences

 To access Tenant Web Access settings, at least one location must be enabled for TWA. For more information, refer to Licensing (System Web Preferences) .

 To set these system web preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Web Preferences arrow_forward Tenant Web Access arrow_forward Signable Documents .

 -
 Edit the settings as desired. Each setting is described below.

 -
 Click Save to accept your changes.

 Preference Descriptions

 This preference group is divided into multiple sections. Each setting is described within the corresponding section below.

 Tenant Web Access - Signable Documents

 This section includes settings regarding signable documents in Tenant Web Access (TWA) .

 Option
 Description

 Completed Signable Document Category

 Select a history category from the drop-down list to assign to all completed signable documents on a tenant or prospect's History/Notes page.

 Signable Document expires in x days:

 Enter the default number of days a tenant has to complete the signable document before it is considered expired. This default setting can be overridden when publishing a document.

 Customization

 This section includes settings regarding signature options for signable documents in TWA. Select one of the following options for the Landlord Label when signing documents in TWA.

 Option
 Description

 Default - 'Landlord'

 Select to use the default title of Landlord on the Landlord Signature line for signable documents in TWA.

 Custom

 Select to use a different title to replace Landlord , and enter the desired title in the field below. For example, enter Property Manager to display Property Manager Signature on signable documents in TWA.

 Renewal Offers

 This section includes settings regarding renewal offers options for signable documents in TWA.

 Option
 Description

 Complete renewal offer when the TWA published document is completed

 Determine how renewal offers are completed via signable documents. If enabled, renewal offers are completed automatically once both the tenant(s) and landlord add their signatures to the signable document.

 Require an expected move out date when tenant declines offer

 Check to make the Expected Move Out date in Tenant Web Access a required field when the tenant declines a renewal offer.

 Set notice date if tenant enters expected move out date

 Check to automatically populate a Notice date when a tenant declines a renewal offer and enters an Expected Move Out date in Tenant Web Access . The Notice field on the tenant's details page populates with the date on which the tenant declined the renewal offer.

 Warning

 Checking this option is recommended if the tenant's action of declining an offer from Tenant Web Access can serve as an official notice to vacate.

 This option should be left unchecked if you require a specific form or signature to satisfy your requirements for giving notice to vacate.

 Decline Renewal Message

 Optionally, enter a message that displays to tenants if they decline their lease renewal offer.
