# Tenant Web Access Reports Page Setup (System Web Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Web-Preferences/TWA-Page-Setup-Reports.htm

These system web preferences allow you to enable the Reports page in Tenant Web Access (TWA) for properties with a Property Type of Association . From this page, the association's board members, committee members, and residents can access reports published with your predefined report options.

 Related Privileges

 Group
 Privilege
 Column

 System
 System Web Preferences
 Enabled

 For more information, refer to Control User Access .

 To set these system web preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Web Preferences arrow_forward Tenant Web Access arrow_forward Page Setup arrow_forward Reports .

 -
 Edit the settings as desired. Each setting is described below.

 -
 Click Save to accept your changes.

 Preference Descriptions

 Each setting is described below:

 Option
 Description

 Show Reports

 Enable the Reports page in TWA for association-type properties.

 Below is an example of how the reports display in Tenant Web Access .

 Menu Title

 The custom text for the top menu bar's link to this page.

 Title

 The custom text for the name that displays at the top of this page.

 Custom Message

 A custom message to be displayed on this page for all TWA users, such as Please review the reports below before casting votes in the latest poll .
