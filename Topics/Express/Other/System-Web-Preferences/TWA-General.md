# Tenant Web Access General (System Web Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Web-Preferences/TWA-General.htm

These system web preferences allow you to create login messages and set login and/or lockout restrictions for Tenant Web Access (TWA) users.

 Related Privileges

 Group
 Privilege
 Column

 System
 System Web Preferences
 Enabled

 For more information, refer to Control User Access .

 Related Preferences

 To access Tenant Web Access settings, at least one location must be enabled for TWA. For more information, refer to Licensing (System Web Preferences) .

 To set these system web preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Web Preferences arrow_forward Tenant Web Access arrow_forward General .

 -
 In the Tenant Web Access section, select General .

 -
 Edit the settings as desired. Each setting is described below.

 -
 Click Save to accept your changes.

 Preference Descriptions

 Each setting is described below:

 Option
 Description

 Login Page Message

 The message that displays on the login screen for returning TWA users.

 Type in the Login Page Message field to enter or edit the text.

 More Information

 This message can be overridden for individual tenant accounts from the Web Access Settings pop-up. For more information, refer to Tenant Web Access Settings (Pop-Up) .

 Failed Login Attempts Until Lockout

 The number of unsuccessful sign in attempts a TWA user is allowed before the account is locked.

 Lockout Time (in minutes)

 The number of minutes a TWA user's account stays locked after a lockout. To lock the user out indefinitely and require a Rent Manager user to remove the account lockout, enter 0 .

 Past tenants remain active for X days after move out

 The number of days after a tenant's Move Out date, as entered on the lease, that a tenant can still access their TWA account. This field is capped at 60 days but can be extended for individual tenants on their Web Access Settings pop-up.

 Message to Show All Users

 The message that displays on the dashboard for all TWA user accounts.

 Disable TWA for Selected Properties

 Click the drop-down to select the properties for which Tenant Web Access (TWA) should be disabled. Properties can be selected individually or by property group from the Group drop-down.

 Warning

 Disabling Tenant Web Access (TWA) removes tenants' access to rmResident . Additionally, applicants can still submit applications through Apply Now but once the application is submitted, they cannot log back in until Tenant Web Access is re-enabled.

 Allow Tenant To Purchase Insurance

 By default, this option is automatically enabled for databases with TWA enabled and displays information in TWA and rmResident for purchasing insurance. For more information, refer to LeaseTrack Insurance .

 Allow Tenant To Email Property Manager

 If checked, a link is added to the TWA dashboard allowing the web user to compose and send an email to the property manager, using the Manager and Email Address fields as entered on the property's details page.

 Additionally, to save a copy of the tenant's emails to their History/Notes tile in Rent Manager , select a tenant/prospect-type History/Note Category .

 Use Management Company As Property Name

 Check to display the name of the property management company as entered in system preferences instead of the property name associated with the TWA user's account.

 TWA Email Signature

 The contact information that displays on the signature of automated emails generated from Tenant Web Access .

 Use Property Contact Information

 Select to display the property’s contact information as the TWA email signature. The property’s contact information consists of the Full Name , and Email Address as entered on the property's details page.

 Override Property Contact Information

 Enter a Name and Email address to be displayed as the TWA email signature.
