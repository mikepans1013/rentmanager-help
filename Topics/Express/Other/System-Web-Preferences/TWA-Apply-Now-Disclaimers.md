# Tenant Web Access Apply Now Disclaimers (System Web Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Web-Preferences/TWA-Apply-Now-Disclaimers.htm

The Apply Now Disclaimers preference group is part of Tenant Web Access system web preferences which defines the text in disclaimers that appear on Apply Now applications.

 Related Privileges

 Group
 Privilege
 Column

 System
 System Web Preferences

 For more information, refer to Control User Access .

 Related Preferences

 To access Tenant Web Access settings, at least one location must be enabled for TWA. For more information, refer to Licensing (System Web Preferences) .

 To set these system web preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Web Preferences arrow_forward Tenant Web Access arrow_forward Apply Now arrow_forward Disclaimers .

 -
 Enter or adjust the desired text, hyperlinks, and formatting for the disclaimer messages. Each message type is described in more detail below.

 -
 Click Save to accept your changes.

 Disclaimer Message Descriptions

 Each disclaimer message is described below:

 Option
 Description

 Extended Disclaimer Text

 This field displays no message by default, but can be edited to include any other disclaimer information you wish for the applicant to acknowledge that is not displayed in the Consent to Screening Text and Information Accuracy Certification Text disclaimers. By default if no text is entered, this disclaimer does not display on the Apply Now application.

 If text is entered, this disclaimer appears first at the bottom of the application.

 Consent to Screening Text

 This field displays a default message and dialog box that applicants must check to consent to having a screening report run on their behalf. In this text box, you can enter and edit text, hyperlinks, and character formatting.

 This disclaimer appears second at the bottom of the application. If no Extended Disclaimer Text is entered, this disclaimer displays first.

 Information Accuracy Certification Text

 This field displays a default message and dialog box that applicants must check to acknowledge that the information entered on the application is correct.

 This disclaimer appears last at the bottom of the application.
