# Owner Web Access Accounts (System Web Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Web-Preferences/OWA-Accounts.htm

These system web preferences allow owners to create their own web user accounts and/or change their personal information for Owner Web Access (OWA) .

 Related Privileges

 Group
 Privilege
 Column

 System
 System Web Preferences
 Enabled

 For more information, refer to Control User Access .

 Related Preferences

 To access Owner Web Access settings, at least one location must be enabled for OWA in system web preferences. For more information, refer to Licensing (System Web Preferences) .

 To set these system web preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Web Preferences arrow_forward Owner Web Access arrow_forward Accounts .

 -
 Edit the settings as desired. Each setting is described below.

 -
 Click Save to accept your changes.

 Preference Descriptions

 Each setting is described below:

 Preference
 Description

 Allow Owner To Create Accounts

 Check to allow owners to create their own OWA accounts, optionally using any of the available verification methods below to authenticate the owner's identity. Once created, any web user accounts associated with an owner display on the Web Access Settings pop-up.

 Warning

 The values entered by the owner during account creation must match the data in your Rent Manager database. If the owner enters information incorrectly, your database contains incorrect information, or the specified data has not been entered in Rent Manager , the owner receives an error message when trying to create their account.

 Verify With Phone Number

 Check to require owners to validate their OWA account with their phone number.

 Verify With TaxID

 Check to require owners to validate their OWA account with their tax identification number.

 Optionally, check Only Use Last Four Digits to require only the last four digits of the owner's tax ID number when validating account creation.

 Verify With Email Address

 Check to require owners to validate their OWA account with their email address.

 Verify With User Defined Field

 Check to require owners to validate their OWA account with responses to the owner user defined field selected from the drop-down list. You can require responses for up to three different user defined fields.

 Allow owner to change personal information

 Check to allow owners to change their contact information (e.g., email, phone number, etc.) online. Changes the owner makes in OWA are immediately reflected in the History/Notes tile of the owner's account.
