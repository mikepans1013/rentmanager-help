# Owner Web Access Site Header (System Web Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Web-Preferences/OWA-Style-Site-Header.htm

This system web preferences group allows you to change the Owner Web Access (OWA) web page header image from the system default to a custom image as well as manage the color of the page headers.

 Related Privileges

 Group
 Privilege
 Column

 System
 System Web Preferences
 Enabled

 For more information, refer to Control User Access .

 Related Preferences

 To access Owner Web Access settings, at least one location must be enabled for OWA in system web preferences. For more information, refer to Licensing (System Web Preferences) .

 To manage the OWA site header options, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Web Preferences arrow_forward Owner Web Access arrow_forward Style arrow_forward Site Header .

 -
 Select the option to Customize Site Header image to enable the customization options.

 -
 Edit the settings as desired. Each setting is described below.

 -
 Click Save to apply your changes.

 Preference Descriptions

 Each setting is described below:

 Option
 Description

 Image File

 Select this option to upload an Image that appears on all page headers in Owner Web Access across your entire property portfolio.

 Image Alignment

 The alignment ( Left , Center , Right ) of the site header image you have specified.

 Background Color

 Select a color from the menu to appear on all site headers in Owner Web Access across your entire property portfolio. This color appears behind the site header image.
