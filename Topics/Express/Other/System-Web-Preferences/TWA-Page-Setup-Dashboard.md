# Tenant Web Access Dashboard Page Setup (System Web Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Web-Preferences/TWA-Page-Setup-Dashboard.htm

This system web preferences group allows you to manage the Tenant Web Access (TWA) dashboard tiles. Select which tiles you wish to display on the TWA dashboard as well as select the order in which they display on the screen.

 Related Privileges

 Group
 Privilege
 Column

 System
 System Web Preferences
 Enabled

 For more information, refer to Control User Access .

 Related Preferences

 To access Tenant Web Access settings, at least one location must be enabled for TWA. For more information, refer to Licensing (System Web Preferences) .

 To set these system web preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Web Preferences arrow_forward Tenant Web Access arrow_forward Page Setup arrow_forward Dashboard .

 -
 Manage which dashboard tiles display in TWA and which tiles are excluded from the portal depending on the property at which your tenant resides.

 Option
 Description

 Name

 Check the box next to the name of each dashboard tile to be included on the TWA dashboard.

 To quickly select or deselect all dashboard tiles, check or uncheck the box in the header.

 Exclude Associations

 Check to exclude the tile from the dashboards of tenants whose first lease is at a property where the Property Type on the General Information tile on the property's details page is identified as an Association . Exclusions are limited to the dashboard and do not effect a user's access to related TWA pages.

 More Information

 This preference does not override the Exclude from Associations options found in other Page Setup system preferences.

 -
 Optionally, rearrange the order in which the tiles display in TWA.

 -
 Click Save to apply your changes.

 Tile Descriptions

 Each tile that is available to add to the dashboard is described below:

 Tile
 Description

 Charges

 Displays a total of the tenants' open charges and open credits.

 Notes

 Displays tenants' associated history/note items.

 Leases

 Displays tenants' associated leases.

 Inspections

 Displays tenants' associated inspections.

 Documents

 Displays files uploaded to tenants' associated property files.

 Zego Utility Statements

 Displays billing statements from Zego Resident Billing.

 Related Preferences

 In order for tenants to receive billing statements from Zego , Enable Zego Resident Billing must be enabled in system preference. For more information, refer to Zego Resident Billing (System Preferences) .

 Violations

 Displays tenants' associated violation details.

 Community Calendar

 Displays the scheduled events on the community calendar of the associated property.

 Amenity Reservations

 Displays information on the TWA user's reservable amenities requests at the associated property.

 Architectural Requests

 Display information on the TWA user's architectural requests at the associated property.

 Additionally, tenants who are members of the association's committee or board have access to the Architectural Requests to Review tile to view architectural requests that need to be voted on.

 More Information

 The Architectural Requests tile displays only for TWA users associated with properties that have a Property Type of Association set on the property's details page.

 Messages

 Displays the contents of the Message To Show All Users field in system web preferences. For more information refer to Tenant Web Access General Page Setup (System Web Preferences) .
