# Web Template Suite Web Chat (System Web Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Web-Preferences/Web-Template-Suite-Web-Chat.htm

These system web preferences allow you to enable web chat and specifies which web chat queue should be used for visitors to your Web Template Suite site.

 To set these system web preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Web Preferences arrow_forward Web Template Suite arrow_forward Web Chat .

 -
 Edit the settings as desired. Each setting is described below.

 -
 Click Save to accept your changes.

 Preference Descriptions

 Each setting is described below:

 Option
 Description

 Enable Web Chat

 Places a chat button on your Web Template Suite site and allow users to begin chatting with you. Depending on your queue settings, the chat button may not appear when the chat is offline.

 Specify queue for Web Template Suite

 The selected queue determines which initial questions a user is asked, and when a visitor starts a chat, this is the queue where their chat is directed.
