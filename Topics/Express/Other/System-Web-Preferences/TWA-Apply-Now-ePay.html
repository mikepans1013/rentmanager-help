Tenant Web Access Apply Now ePay (System Web Preferences)

Apply Now ePay is part of Tenant Web Access system web preferences which sets parameters to allow applicants to use ePay to pay a fee charged for submitting an online application.

Related Privileges

Group Privilege Column
System System Web Preferences Enabled

For more information, refer to Control User Access.

Related Preferences

To access Tenant Web Access settings, at least one location must be enabled for TWA. For more information, refer to Licensing (System Web Preferences).

To set these system web preferences, do the following:

  1. Go to arrow_forward Administration, then go to Preferences arrow_forward System Web Preferences arrow_forward Tenant Web Access arrow_forward Apply Now arrow_forward ePay.

  2. Select the option to Enable ePay. If checked, applicants will see a Payments page when they submit the online application.

    Related Preferences

    To enable ePay for custom applications, ePay must first be set up in system preferences. For more information, refer to General ePay (System Preferences).

  3. Edit the settings as desired. Each setting is described below.

  4. Click Save to accept your changes and remain on the page.

Preference Descriptions

Each setting is described below:

Option Description

Application Fee Amount

Enter the amount for application fees completed online. This amount can be overridden in the settings of each application template.
Application Fee Charge Type

Select the charge type associated with application fees. This charge type can be overridden in the settings of each application template.

Have Zego Manage Platform Fees

Check to avoid having to manually set up platform fee charges, and instead, allow Zego to automatically collect its platform fees for online processing directly from applications.

Related Preferences

This option is available only if the system preference option to Have Zego manage platform fees is enabled. For more information, refer to General ePay (System Preferences).

CC Platform Fee Amount

If applicable, enter a platform fee amount for using a credit card to pay the application fee online. Optionally, check Percentage and enter a value to charge a percentage of the amount collected instead of a flat fee.

This option is disabled if the option to Have Zego manage platform fees is checked.

ACH Platform Fee Amount

If applicable, enter a platform fee amount for processing an ACH payment to pay the application fee online. Optionally, check Percentage and enter a value to charge a percentage of the amount collected instead of a flat fee.

This option is disabled if the option to Have Zego manage platform fees is checked.

Platform Fee Charge Type

Select the charge type associated with platform fees.

Additional Application Fees

If applicable, you can create more platform fees using this table.

For each additional application fee, enter a Description, the Charge Type for the fee, and the Fee Amount.

Financial Property

Select the property that receives Apply Now application fees by default, such as the management company. If Apply Now fees should be received by the property that the prospect applied to, leave this field blank. This property can also be overridden on individual application templates.

For custom applications, to use the Default Property, leave this field blank. For more information, refer to Custom Applications General (System Web Preferences).

Do not require payment for application to be submitted

Check this box to allow applicants to submit an Apply Now application without paying the above application fees.

More Information

Applicants who do not pay when submitting their application are not automatically screened. When payment is eventually received, you must manually initiate a screening of the applicant(s).

In the Pay Later Message field, optionally edit the default message which is displayed to the applicant who does not pay upon application submission. This space may be used to explain your organization's policies for handling an application that is not accompanied by payment.

Override System Preferences Default Payment Types

Check to allow different forms of payment for Apply Now applications than the defaults specified in system preferences. After checking the box, check which payment types to allow.

Related Preferences

Payment methods that are not selected in system preferences are not selectable; however, additional payment methods can be removed as desired. For more information, refer to Advanced ePay (System Preferences).

Require a disclaimer for ePay transactions

Check this option if you wish to enter a disclaimer for ePay transactions associated with the application process. Applicants will be required to check the box next to the disclaimer to verify they read the message before submitting the application fee payment.
