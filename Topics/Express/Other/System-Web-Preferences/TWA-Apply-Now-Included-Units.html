Tenant Web Access Apply Now Included Units (System Web Preferences)

The Apply Now preference group is part of Tenant Web Access system web preferences that determines which properties, units, and/or unit types display on Apply Now applications.

Related Privileges

Group Privilege Column
System System Web Preferences Enabled

For more information, refer to Control User Access.

Related Preferences

To access Tenant Web Access settings, at least one location must be enabled for TWA. For more information, refer to Licensing (System Web Preferences).

To set these system web preferences, do the following:

  1. Go to arrow_forward Administration, then go to Preferences arrow_forward System Web Preferences arrow_forward Tenant Web Access arrow_forward Apply Now arrow_forward Included Units.

  2. Edit the settings as desired. Each setting is described below.

  3. Click Save to accept your changes.

Preference Descriptions

This preference group is divided into multiple sections. Each setting is described within the corresponding section below.

Properties to Include

This section lets you determine which properties display as available when prospects choose to start an Apply Now application from your website.

Option Description

By Property

Select to include all units for specific properties.

Check each property to be eligible for applications through Apply Now.

By User Defined Field

Select to include all units with a specified property-level user defined fields with a type of Yes/No. All properties that have the selected user defined field value set to Yes will be eligible for Apply Now applications.

By Property Availability Profile

Select to include all units at properties which meet the availability criteria as determined in the active property profile. For more information, refer to Availability Profile (System Web Preferences).

Units/Unit Types to Include

This section lets you determine which unit or unit types show as available to the applicant, based upon their property selection.

Option Description

By Property Type

Select this option to determine whether to show a unit or unit type selection drop-down list based upon the Property Type set on the property's details page.

If the Property Type is set as Commercial, Manufactured Housing, Single Family, or has no selection, a unit selection drop-down list displays. If the Property Type is set to Apartment, Duplex, Multi Family,Short Term Rental, RV/Campground, or Storage, a unit-type selection drop-down list displays.

Display Units

Select this option to always display a unit selection drop-down list for units associated with the selected properties.

The way units are displayed can be further refined using one of the following options:

All

Select to display all units at the selected property.

By User Defined Field

Select one of the unit-level user defined fields with a type of Yes/No. All units that have the selected user defined field value set to Yes display in the drop-down list

By Unit Availability Profile

Select to display units which meet the availability criteria as determined in the selected unit profile. For more information, refer to Availability Profile (System Web Preferences).

Display Unit Types

Select this option to always display a unit type selection drop-down list for unit types associated with the selected property.

Optionally, check Use Unit Type Description to display the text entered in the Description field of unit types in the selection drop-down list. If no Description is available, the Unit Type name is used.

All

Select to display all unit types at the selected properties.

By Selection

Select to display only the selected unit types. Check each unit type in the list you wish to include.

By Unit Availability Profile

Select to display unit types which meet the availability criteria as determined in the selected unit profile. For more information, refer to Availability Profile (System Web Preferences).

Do not display a unit or a unit type dropdown

Select to never display a unit or unit type drop-down list. After the applicant selects a property, they are directed to the application selection page.
