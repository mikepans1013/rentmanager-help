# Owner Web Access Signable Documents (System Web Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Web-Preferences/OWA-Signable-Documents.htm

These system web preferences allow you to manage the default settings for signable documents that recipients can view and sign through Owner Web Access (OWA) .

 Related Privileges

 Group
 Privilege
 Column

 System
 System Web Preferences
 Enabled

 For more information, refer to Control User Access .

 Related Preferences

 To access Owner Web Access settings, at least one location must be enabled for OWA in system web preferences. For more information, refer to Licensing (System Web Preferences) .

 To set these system web preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Web Preferences arrow_forward Owner Web Access arrow_forward Signable Documents .

 -
 Edit the settings as desired. Each setting is described below.

 -
 Click Save to accept your changes.

 Preference Descriptions

 Each setting is described below.

 Owner Web Access - Signable Documents

 This section allows you to determine how signable documents are categorized and the number of days an owner has to complete a signable documents before it expires.

 Option
 Description

 Completed Signable Document Category

 The owner/owner prospect-type history categories that determine how completed signable documents are categorized on the owner's History/Notes pop-up. These categories can be used to filter notes, and you can also choose which owner/owner prospect-type categories owners are able to view in OWA.

 Signable Document expires in x days

 This setting determines the default number of days an owner has to complete the signable document before it is considered expired. When a Rent Manager user publishes a document, they may choose to override this default setting.

 Customization

 This section allows you to determine the title that displays on the Company Representative Signature line of signable documents. Select to use the Default – ‘Company Representative’ title or select Custom to enter a different title to replace Company Representative on the Company Representative Signature line of signable documents. For example, enter Agent for Landlord to display Agent for Landlord Signature .
