Tenant Web Access Notes Page Setup (System Web Preferences)

These system web preferences determine if a tenant's associated history/note items can be viewed in the Tenant Web Access (TWA) portal and how the page displays.

Related Privileges

Group Privilege Column
System System Web Preferences Enabled

For more information, refer to Control User Access.

Related Preferences

To access Tenant Web Access settings, at least one location must be enabled for TWA. For more information, refer to Licensing (System Web Preferences).

To set these system web preferences, do the following:

  1. Go to arrow_forward Administration, then go to Preferences arrow_forward System Web Preferences arrow_forward Tenant Web Access arrow_forward Page Setup arrow_forward Notes.

  2. Edit the settings as desired. Each setting is described below.

  3. Click Save to accept your changes.

Preference Descriptions

Each setting is described below.

More Information

If you don't enter a Menu Title, Title, or Custom Message, Rent Manager uses the associated system default value.

Option Description

Show History/Notes

Allows the tenant to view the associated history/note items for the categories selected in system web preferences. For more information, refer to Tenant Web Access History/Notes (System Web Preferences).
