Owner Web Access Financial (System Web Preferences)

These system web preferences allow you to determine if a disclaimer is required when owners use ePay to make owner contributions when accessing the Owner Web Access webpage.

Related Privileges

Group Privilege Column
System System Web Preferences Enabled

For more information, refer to Control User Access.

Related Preferences

To access Owner Web Access settings, at least one location must be enabled for OWA in system web preferences. For more information, refer to Licensing (System Web Preferences).

To set these system web preferences, do the following:

  1. Go to arrow_forward Administration, then go to Preferences arrow_forward System Web Preferences arrow_forward Owner Web Access arrow_forward Financial.

  2. Check Require A Disclaimer For ePay Transactions to display the disclaimer text when the owner is using OWA to make payments and require acknowledgment before processing. When this option is checked, you can edit the ePay Disclaimer.

  3. Click Save to accept your changes.
