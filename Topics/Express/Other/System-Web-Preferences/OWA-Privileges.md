# Owner Web Access Privileges (System Web Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Web-Preferences/OWA-Privileges.htm

These system web preferences determine the default owner-related features that can be accessed in Owner Web Access. These privileges can be modified for an owner through the Web Access Settings pop-up.

 Related Preferences

 To access Owner Web Access settings, at least one location must be enabled for OWA in system web preferences. For more information, refer to Licensing (System Web Preferences) .

 To set these system web preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Web Preferences arrow_forward Owner Web Access arrow_forward Privileges .

 -
 Edit the settings as desired. Each setting is described below.

 -
 Click Save to accept your changes.

 Preference Descriptions

 This preference group is divided into multiple sections. Each setting is described within the corresponding section below.

 Page Visibility

 Check to allow owners to view any of the related pages in OWA.

 Preference
 Description

 Reports

 Check to add the Reports page, which allows owners to run the reports enabled below for Report Privileges .

 Contributions

 Check to add the Make Contribution page, which allows owners to make contributions using Zego ePay .

 Notes

 Check to display the OWA Notes menu to allow owners to see property history/notes, unit history/notes, and tenant history/notes.

 Inspection Reports

 Check to display the OWA  Inspection Reports menu, which allows owners to view the Web Inspection report for any inspections that were completed at their properties.

 Financial Information

 Check to allow owners to view any of their financial information in OWA.

 Preference
 Description

 Show Ownerships

 Check to display ownership information on the dashboard. Ownership information includes property name, ownership percentage, reserve amount, security deposits held, and ownership bank balance.

 Show Checks

 Check to display check information from the last 90 days on the dashboard and provide a Checks register that the owner may filter. Check information includes ownership, date range, reference, check date, vendor, comment, and amount.

 Show Owner Checks

 Check to display owner check disbursements from the last 90 days on the dashboard and provide a Owner Distributions register that the owner may filter. Owner distribution information includes ownership, date range, reference, check date, and amount.

 Show Management Fees

 Check to display management fees postings from the last 90 days on the dashboard and provides a Management Fees register that the owner may filter. Management fees information includes ownership, date range, fee date, pass-thru amount, and fee amount.

 Show Bills

 Check to display bills from the last 90 days that expense properties and/or units in the owner's portfolio on the dashboard and provides a Bills register that the owner can filter. Bill information includes vendor, ownership, date range, bill date, due date, paid or unpaid, and amount.

 Show Bill Attachments

 Check to allow owners to view attachments linked to bills. To view an attachment, the owner clicks a bill on the dashboard and then clicks the attachment link on the detail page.

 Show Passthru Fees

 Check to display the pass-thru fee amount on the Management Fees register. Pass-thru fees are management fees that have been specified to be passed directly to the management company. They typically do not appear on owner reports.

 Ownership Information

 Check to allow owners to view any of their ownership information in OWA.

 Preference
 Description

 Show Ownership Balance

 Check to allow the owner to view their portfolio bank balances.

 Show Ownership Percent

 Check to allow the owner to view the ownership percentage of each property in their portfolio.

 Show Security Deposit

 Check to allow the owner to view the amount of security deposit dollars held for each property in their portfolio.

 Show Reserve

 Check to allow the owner to view the amount of reserves for each property in their portfolio.

 General Privileges

 This setting allows you to enable access to all owner reports or to individual reports. Each available report is described below.

 More Information

 To display only financial transactions that have taken place within the owner’s contract period, check Restrict by Owner Contract dates . If you restrict reports based on contract dates, your owners cannot manually select a Separation Method such as Do not separate or Separate by Properties .

 Report
 Description

 All Reports

 Check to quickly give the owner access to every report in the list. By default, this option is selected.

 Balance Sheet

 This report displays the financial position of the owner's property or properties as of the report date.

 Balance Sheet Comparison

 This report displays the assets of one or more of the owner's properties and the claims (liabilities and equities) against those assets at two points in time.

 Bills Paid

 This report displays paid bills that were expensed to the owner's property or properties.

 Budget Comparison

 This report displays budgets alongside real-world financial data across two selected date ranges to help you measure financial activity against forecasted projections.

 Cash Flow

 This report provides the owner with a clear picture of how your management company is receiving and spending cash.

 Cash Flow 12 Month Recap

 This report displays monthly cash flow data for the selected properties or ownerships during the date range of the report. A column is displayed in the report for each month in the report date range so that you may compare up to twelve months at a time.

 Check/Deposit Listing

 This report displays checks, journal entries, and deposits affecting the owner's bank posted during a selected date range.

 Delinquency

 This report displays tenants and prospects with delinquent charges as of the report date.

 Distribution Breakdown

 This report displays information about how Rent Manager calculated an owner's distributions, and/or other exclusions.

 Financial Statement

 This report displays the balances of every asset, liability, and/or equity GL account for the owner's property or properties.

 Fiscal Year Budget

 This displays financial data from your budgets for the fiscal year. The year is determined by either the fiscal start date established on the property level or in system preferences. Totals for your budget(s) display for each month and the entire fiscal year in the report results.

 General Ledger

 This report displays GL account transactional activity that is associated with the owner's property or properties.

 Management Fee Breakdown

 This report displays details about the calculation of standard management fees.

 Market Rent Analysis

 This report displays lease rent and market rent information for the units in the owner's portfolio.

 Move In/Move Out

 This report displays tenant move in and move out data for the owner's property or properties over a date range.

 Owner Activity

 This report displays payments received and expenses paid on behalf of an owner.

 Owner Available Cash Balance

 This report displays the owner's beginning bank balance for the selected date range and the ending balance after transactions of the period have been taken into account.

 Owner Bank Activity

 This report displays an owner's bank balance as of the first day in the report date range and any transactions that occur during the rest of the range.

 Owner Bank Balance

 This report displays the current bank balance, security deposits, and reserve amounts for each property within an ownership as of the selected report date.

 Owner Open Payables

 This report displays the default bank account, balance, and open payables (the total of all unpaid bills) for an owner's property or properties.

 Owner Statement

 This report tracks the income and expenses of an owner's portfolio over a specified period of time.

 Payables Listing

 This report displays paid or unpaid bills associated with vendors across a date range.

 Profit & Loss

 This report displays the totals of the transaction activity of each income and expense GL account in the specified date range for the owner's property or properties.

 Profit & Loss 12 Month Recap

 This report displays income and expense general ledger (GL) accounts for selected properties for up to a 12-month period, allowing you to compare the profitability of your portfolio across multiple months. The report also displays the net income to track the overall financial impact in each month.

 Profit & Loss Previous Year Comparison

 This report displays income and expense GL accounts for the owner's property or properties across two date ranges: one the user selects, and one that covers the same date range in the previous year.

 Rent Roll & Recurring Charges

 This report displays a complete list of recurring charges inherited by tenants as of the selected report date.

 Rent Roll Analysis

 This report tracks information about units and the tenants that lease them, such as held security deposits, potential rental income being missed because of vacancy, transaction summaries, and rent increases, at the owner's property or properties as of a given date.

 Trial Balance

 This report displays GL account balances for the owner's property or properties in terms of debits and credits as of a selected date.

 Trust Account Detail

 This report displays all transactions that impacted the owner's bank account during a date range, and can be filter by property.

 Unit Availability Listing

 This report displays units available for rent as well as other units with a future scheduled unit status change.

 Unit Profit & Loss

 This report displays the ending balances of unit-level income and expense transactions for the units within the owner's portfolio across a date range.

 Unit Transaction Listing

 This report displays tenants and the transactions posted to their accounts over a selected date range.

 Vacancy

 This report displays the active but vacant units of the owner's property or properties as of the selected date.
