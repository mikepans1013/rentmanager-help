RV/Campground Online Booking Guest Info (System Web Preferences)

These system web preferences allow you to select additional information to be required by guests when they enter their information during the Short Term Rental (STR) Online Booking portal.

More Information

The STR Online Booking feature is licensed and must be purchased separately. For more information, contact your sales representative at sales@rentmanager.com.

Related Privileges

Group Privilege Column
System System Web Preferences Enabled

For more information, refer to Control User Access.

To set these system web preferences, do the following:

  1. Go to arrow_forward Administration, then go to Preferences arrow_forward System Web Preferences arrow_forward STR Online Booking arrow_forward RV/Campground arrow_forward Guest Info.

  2. Edit the settings as desired. Each setting is described below.

  3. Click Save to accept your changes.

Preference Descriptions

This preference group is divided into multiple sections. Each setting is described below.

Equipment/Vehicle Info

Select what fields are required when guests book reservations through the STR Online Booking portal.

Option Description

Require make and model

When enabled, guests must provide the make and model of their vehicle or equipment before they can submit a reservation.

Require license plate #

When enabled, guests must enter the license plate number for their vehicle or equipment.

Require year

When enabled, guests must enter the model year for their vehicle or equipment.

Allow guest to enter additional vehicles

When enabled, guests can enter information for an additional vehicle.

Lead Source

Check Allow the guest to select how they heard about your campground by enabling the lead sources below to give guests the option to identify how they found out about your rental. In the Lead Source drop-down, select each option you want to be available for guests to select on the STR Online Booking portal.
