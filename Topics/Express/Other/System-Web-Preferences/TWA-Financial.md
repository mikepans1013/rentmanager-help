# Tenant Web Access Financial (System Web Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Web-Preferences/TWA-Financial.htm

This system web preference group allows you to manage what financial information the tenant can view and how the tenant can process payments on their Tenant Web Access (TWA) portal.

 Related Privileges

 Group
 Privilege
 Column

 System
 System Web Preferences
 Enabled

 For more information, refer to Control User Access .

 Related Preferences

 To access Tenant Web Access settings, at least one location must be enabled for TWA. For more information, refer to Licensing (System Web Preferences) .

 To set these system web preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Web Preferences arrow_forward Tenant Web Access arrow_forward Financial .

 -
 Edit the settings as desired. Each setting is described below.

 -
 Click Save to accept your changes.

 Preference Descriptions

 Each setting is described below:

 Option
 Description

 View total balance due

 Allows tenants to view the total amount due on their account.

 Allow payments over total balance due

 Allows tenants to make payments that exceed their current balance.

 Require payment of

 Check to establish how Rent Manager calculates the balance that tenants are required to pay via TWA.

 Total Balance Due

 Require tenants to pay their full balance due for all charges on their account, including future charges.

 Current Balance Due

 Require tenants to pay only their current balance due.

 More Information

 With this option enabled, tenants are able (but not required ) to overpay their current balance amount and partially or fully pay future charges.

 Current or Total Balance Due

 Require tenants to pay either the current balance due or the total balance due.

 Warning

 With this option enabled, tenants are not able to partially pay future charges.

 Allow tenants to choose which charges to pay

 Allows tenants using Tenant Web Access (TWA) or rmResident to choose which open or future-dated charges to apply payments to. This option is available only if the Require payment of field above is not set to Total balance due or Current or total balance due .

 Exclude subsidy charge types from tenant's balance due

 Prevents all charge types that are used for subsidies from being included in the total balance due for tenants.

 Allow tenant to see amount due for account group and automatically apply payments to the entire group

 Allows tenants who are part of an account group to view the balance due for the account group, and apply payments toward that group balance.

 Allow tenants to enroll in Flexible Rent

 Allows tenants to sign up for Flexible Rent through Tenant Web Access (TWA) and rmResident .

 More Information

 The Flexible Rent service is free to Rent Manager customers, but tenants must pay a monthly fee and a bill payment fee of 1% of their total rent to Flex to use the program. For more information, refer to Flexible Rent .

 Message to display if tenant does not have ePay

 Enter the message to display if the tenant does not have saved ePay payment information. Payment information can be set up by a Rent Manager user in tenant ePay ; or by the tenant themselves within TWA.

 This message displays on the TWA dashboard.

 Require a disclaimer for ePay transactions

 Requires tenants to acknowledge a disclaimer when making ePay payments via TWA. When enabled, you can edit the disclaimer text in the box below the field.
