# Unit Addresses

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Units-Addresses.htm

You can create and manage your own categories for unit addresses on the Address Types page. This makes it easy to record and reference multiple addresses on the same unit account. Additionally, this adds the ability to pull a specific address type into other parts of Rent Manager , such as reports and features that use scripting. Once you define an address type for units, you can go to any unit account to enter the associated address.

 To add a unit address type, do the following:

 -
 Go to   arrow_forward   Administration , then go to Customization arrow_forward Address Types .

 -
 In the Type section, select Unit .

 -
 Click   Add Address Type .

 -
 Enter the Name for this unit address type. This name displays as an option on the unit's View Addresses pop-up.

 -
 Click Save .
The address type is added to all unit accounts.

 To view or edit an address from the View Contacts page, do the following:

 - Go to   arrow_forward Rental Info arrow_forward General arrow_forward Units and select a unit from the list.

 - On the Addresses tile, select the address type tab for the address you wish to add.

 -
 In the text field, enter the unit's address.

 -
 If the address is used as the primary source of correspondence, check Default to have Rent Manager use this address automatically when generating reports and letters.

 -
 Click Save .
The unit address is added.
