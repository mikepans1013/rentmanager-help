# Export 1099 Owner

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Export-1099-Owner.htm

If you are required by the IRS to produce 1099 tax forms for your owners, you can export and save the forms as text (.txt) files to a location on your computer or network. These files are for use with the IRS File Information Returns Electronically (FIRE) system, which is different from the IRIS filing portal and uses a separate Transmitter Control Code (TCC). The 1099 file should then be sent to the IRS by the IRS-mandated deadline(s).

 Step 1: Select Export Options

 To export your 1099 forms, do the following:

 -
 Go to   arrow_forward Payables arrow_forward General arrow_forward Export 1099 .

 -
 Confirm you have the information and details listed on the page and click Next .

 -
 Enter the year and entity type for your 1099 export file using the fields below.

 Field
 Description

 Which tax year will be used for the export?

 The tax year used for the 1099 export file

 What type of returns are you filing?

 Select Owner 1099 to run the 1099 export for owners. If you need to run a separate 1099 export for vendors, refer to Export Vendor 1099 .

 Step 2: Enter Transmitter Information

 Step 3: Select Owners

 Once you enter the sender information, select the Owner Selection tab on the left or click Next . In the Owners To Include field, select the owners whose 1099 transaction data is included in the exported 1099 file from the drop-down list. Alternatively, select an owner Group from the drop-down list.

 To select owners that are not currently active in Rent Manager , check Inactive Owners . The Owners To Include drop-down list updates to include inactive owners.

 Step 4: Select Owner Options

 Once you select any owners needed for the export, select the Owner Options tab on the left or click Next . Use the following fields to enter the information for the owner:

 Field
 Description

 Owner Name Source

 The Rent Manager field that determines how owner names display on the 1099 form.

 The following options are available in this drop-down:

 Owner Name

 The information from the owner's details page under General arrow_forward Name displays.

 Payee

 The information from the owner's details page under General arrow_forward Payee displays.

 User Defined Field

 Provides you with a UDF field that lists owner user defined fields with the field type Text .

 Should values less than $600 be excluded?

 Determines if you want to exclude owners that grossed less than $600 for the selected Year in the 1099 export file.

 Should inactive properties for the selected owners be included?

 Determines if you want to include properties that are no longer active in the 1099 export file.

 Step 5: Review Summary

 Once you enter the owner options, select the Summary tab on the left or click Next . On the tab, verify that the information in each field is correct.

 More Information

 To save a test file than can be sent to the IRS during their specified testing date range, check Generate Test File . Then, in the File Name field, enter the desired file name for the export. For more information, refer to the IRS website .

 When finished, click Download File to download the completed 1099 file and select if you want to print a summary of the export options you selected.

 If you select Yes , the Documents pop-up displays. You can use options on the top right to download or print the summary.
