# Property Addresses

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Property-Addresses.htm

You can create and manage your own categories for property addresses on the Address Types page. This makes it easy to record and reference multiple addresses on the same property account. Additionally, this adds the ability to pull a specific address type into other parts of Rent Manager , such as reports and features that use scripting. Once you define an address type for properties, you can go to any property account to enter the associated address.

 To add a property address type, do the following:

 -
 Go to arrow_forward Administration , then go to Customization arrow_forward Address Types .

 -
 In the Type section, select Property .

 -
 Click Add Address Type .

 -
 Enter the Name for this property address type.
This name displays as an option on the property's View Addresses pop-up.

 -
 Click Save .
The address type is added to all property accounts.

 To add a property address, do the following:

 -
 Go to arrow_forward Rental Info arrow_forward General arrow_forward Properties and select a property from the list.
The property's details page displays.

 -
 On the Primary Address tile, click .

 -
 Select the according address type tab for the address you wish to add.

 -
 In the text field, enter the property's address.

 -
 If the address is used as the primary source of correspondence, check Default .

 -
 If the address is where bills should be sent for the property, check Billing .

 -
 Click Save .
The property address is added.
