# Tenant Addresses

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Tenant-Addresses.htm

You can create and manage your own categories for tenant addresses on the Address Types page. This makes it easy to record and reference multiple addresses on the same tenant account. Additionally, this adds the ability to pull a specific address type into other parts of Rent Manager , such as reports and features that use scripting. Once you define an address type for tenants, you can go to any tenant account to enter the associated address.

 To add a tenant address type, do the following:

 -
 Go to arrow_forward Administration , then go to Customization arrow_forward Address Types .

 -
 In the Type section, select Tenant .

 -
 Click Add Address Type .

 -
 Enter the Name for this tenant address type.
This name displays as an option on the tenant's View Addresses pop-up.

 -
 Click Save .
The address type is added to all tenant accounts.

 To add a tenant address, do the following:

 -
 Go to arrow_forward Rental Info arrow_forward General arrow_forward Tenants and select a tenant from the list.
The tenant's details page displays.

 -
 On the Addresses tile, click .

 -
 Select the according address type tab for the address you wish to add.

 -
 In the text field, enter the tenant's address.

 -
 If the address is used as the primary source of correspondence, check Default .

 -
 Click Save .
The tenant address is added.
