Print Eviction Packet

The eviction process is long and time consuming and requires a variety of different steps and jurisdiction-based requirements. With Rent Manager, you can keep track of evictions in progress by recording information like the date of notice, outcome, and associated judgment amounts. Each part of the eviction process in Rent Manager is designed to help you create eviction processes that best fit your business goals.

For tenants in the eviction process, you can print a series of reports and other information related to their eviction. This eviction packet can be customized to print all relevant reports, or you can choose which reports to generate.

For more information, refer to Control User Access.

To print a tenant's eviction packet, do the following:

  1. Go to arrow_forward Rental Info arrow_forward General arrow_forward Tenants and select a tenant under an eviction process.
    The tenant's details page displays.

  2. In the Eviction tile's header, click .
    The Print Packet pop-up displays.

    More Information

    If the tenant's eviction is closed, you can no longer print the eviction packet. You can still print the Tenant Eviction Summary report from the action bar by clicking arrow_forward Tenant Eviction Summary.

  3. Select each document or report you wish to include when generating the eviction packet.

    Option Description

    Communications Report

    Records of the tenant's calls, emails and text messages in Rent Manager that occurred during the entered time frame.

    Eviction History/Notes and Attachments

    All eviction-related history/note items for the tenant's current eviction.

    Lease Documents

    If there are any leasing documents attached to the tenants current primary lease, those attachments are included in the eviction packet.

    Tenant Eviction Summary Report

    The Tenant Eviction Summary report provides a summary of the tenant's eviction, including all the fields for each stage of their eviction. Additionally, this report displays a list of the dates on which the eviction progressed to each stage.

    Optionally, check Include Eviction UDF Attachments to also generate any files or attachments on the eviction in the eviction packet after the Tenant Eviction Summary report.

    Transaction Ledger

    Records of the tenant's transactions ledger for all transactions that occurred during the entered time frame.

  4. Click Print.
    The eviction packet generates all selected documents in a printable format.

Document Descriptions

The reports and documents that can be generated with the eviction packet are described below.

Tenant Eviction Summary

This report provides a summary of the tenant's eviction, including all the fields for each stage of their eviction. The fields on the report vary based on how the eviction workflow is set up. Additionally, it displays a list of the dates on which the eviction progressed to each stage.

This report is divided into the following sections:

Section Description

Details

This section displays each stage of the eviction the tenant has gone through during this eviction process, as well as information about each stage such as important dates or outcomes.

Eviction Information

This section includes general information about the tenant, their lease, their eviction, and the open balance due.

Eviction Stage History

This section lists out the date on which the tenant advanced to each stage in the current eviction process.

Lease Documents

The lease documents attached to the tenants lease in the Lease Documents section are included in the eviction packet. For more information, refer to Lease Details (Page).

Transaction Ledger

This report displays the transactions linked to the tenant from their View Transactions pop-up. For more information, refer to Tenant Transactions (Pop-Up).

The following columns are available on this report:

Column Description

Amount

The total value of the transaction. Payments and credits display with a negative value while charges display with a positive value.

Balance

The total amount due on the account after the transaction is applied.

Comment

If applicable, the note entered by a user providing more information about the transaction.

Date

The date the charge, credit, or payment posted to the account.

Description

The system-generated details to provide context for the transaction, such as whether it's a received payment or the name of the associated charge type.

Ref #

If applicable, the note entered by a user describing the type (CASH, MO, the check number, and so on) of transaction.

Communications Report

This report displays communication made with the tenant via Rent Manager using the following methods:

  • Emails sent and received via Email Center. For more information, refer to Email Center (Page).

  • Incoming and outgoing calls made or received via rmVoIP. For more information, refer to rmVoIP Phone System.

  • Phone messages sent via Phone Broadcasting. For more information, refer to Create a Phone Broadcast.

  • Text messages sent via Text Broadcasting and the Text Messaging Center. For more information, refer to Create a Text Broadcast and Text Messaging Center (Page).

The following columns are available on this report:

Column Description

Attachments

If the associated history note has any attachments, the number of files displays in this column.

Date

The date and time on which the communication was made.

History Category

The category of the history/note item created by the communication.

History Type

Indicates whether the communication was a text message, phone call, or email.

Note

For emails and texts, displays part of the message sent to or received from the tenant. Additionally, copies of the email messages are appended to the report. For calls, the duration of the call displays instead.

For calls and texts, this column also displays whether the message was incoming or outgoing.

User

The Rent Manager user who participated in the communication with the tenant.

Eviction History/Notes and Attachments

This report displays a list of all the history/note items created from the tenant's Eviction tile, such as stage changes, calls, emails, and other notes. History/note items added via the tenant's normal History/Notes tile are not included in the results.

The following columns are available on this report:

Column Description

Date

The date and time on which the history/note item was created or recorded.

History Category

The category assigned to the history/note item.

History Type

Indicates whether the history/note item was a communication method such as a call or text, a change in eviction stage, or a general note.

Note

The text entered in the Note field when adding this history/note item. If the note has an attachment, that file or document is appended to the report.

User

The Rent Manager user who created the history/note item.
