Approve Renewal Rent Increase

The Renewal Increases page allows you to track tenants with leases that have an approaching Lease End date within a specified number of months. From this page, you can approve any set rent charge increases for tenant renewals before the renewal offer is sent.

Related Preferences

The Approve Rent Increases option displays only if the Require approval of renewal rent increases before sending offer option is enabled in system preferences. For more information, refer to Lease Renewals (System Preferences).

Related Privileges

Group Privilege Column
Tenants/Prospects Approve Renewal Rent Increases Enabled

For more information, refer to Control User Access.

To approve renewal rent increases, go to arrow_forward Rental Info arrow_forward Leasing arrow_forward Renewal Increases. You can filter a list of tenants and approve a group of rent increases at the same time, or you can approve an individual rent increase. Each option is described below.

Option 1: Approve and/or Edit Multiple Renewal Rent Increases

To approve and/or edit multiple renewal rent increases at once, do the following:

  1. Click Approve Rent Increases.

  2. In the Filters tile, set the following options to control the tenants that display:

    Field Description

    Lease Term

    The lease duration(s) for tenants to include in the list.

    Unit Type

    The unit or rentable asset type(s) whose associated tenants are included in the list.

    User Defined Field

    A tenant-type user-defined field (UDF) and its associated User Defined Value that you want to use to filter the tenants from the drop-down list.

  3. In the tenant list, review information about each account as needed. To view values for all columns, click . The available columns are described below:

    Default Column Description

    Tenant

    The full name or company name of the tenant.

    Property

    The property associated with the tenant's current lease.

    Unit

    The unit or rentable asset the lease is attached to.

    Unit Type

    The type of unit or rentable asset the tenant currently resides in.

    Lease Term

    The duration of the tenant's current lease, relative to the start date.

    Market Rent

    The current market rent value of the tenant's unit or rentable asset.

    Current Rent

    The total dollar amount of the tenant's current rent recurring charges using any charge type(s) specified on the associated property's details page as a Rent Charge Type.

    New Rent

    The set rent increase amount for this lease renewal offer.

    Status

    The status of the renewal rent increase (Set or Approved).

    Available Column

    Description

    % Change

    The percentage increased or decreased compared to the tenant's current rent recurring charges.

    Address

    The address marked as Default on the unit's details page.

    Approved

    If the renewal rent increase is approved, displays. If it is not approved, this column is blank.

    Approved By

    The user who approved the renewal rent increase.

    Approved Date

    The date the renewal rent increase was approved.

    Display Color

    The identifying color selected on the tenant's details page.

    Lease End

    The expiration date of the tenant's current lease.

    Lease Start

    The first day of the tenant's current lease.

    Leasing Agent

    The user assigned as the tenant's lease agent on their details page.

    Loss to Lease

    The dollar amount of possible income lost or gained as a result of leasing this unit or rentable asset to this tenant at its current rental rate. Loss to Lease is calculated using the following formula:

    Loss to Lease = Market Rent – Charged Rent – Vacancy Loss

    If this value is negative, then the amount of rent charged to the tenant exceeded what should have been charged based on market rent.

    Owner

    The primary owner of the property where the tenant is currently leasing.

    Pet Age

    The age of the first pet listed in the tenant's View Pets pop-up.

    Pet Breed

    The breed of the first pet listed in the tenant's View Pets pop-up.

    Pet Color

    The color of the first pet listed in the tenant's View Pets pop-up.

    Pet Description

    An optional message on the first pet listed in the tenant's View Pets pop-up.

    Pet Name

    The name of the first pet listed in the tenant's View Pets pop-up.

    Pet Type

    The kind of animal, such as a dog or cat, of the first pet listed in the tenant's View Pets pop-up.

    Pet Weight

    The weight of the first pet listed in the tenant's View Pets pop-up.

    Set By

    The user who set the renewal rent increase amount.

    Set Date

    The date the renewal rent increase amount was set.

    User Defined Fields

    Each tenant-type user defined field is listed on the Columns pop-up. The value entered on the tenant's account for the selected user defined field displays.

  4. Select the tenants whose renewal rent increase you wish to approve.

  5. If you need to manually update multiple tenants' renewal rent increase amount, click Edit New Rent and enter the updated amount(s) in the New Rent column. Then click Save.

  6. Click Save.
    The Renewal Increase Details pop-up closes.

  7. Click Approve Selected & Close to approve the renewal rent increases and close the pop-up, or click Approve Selected to approve the renewal rent increases and leave the pop-up open to approve other increases.
    The renewal rent increases are approved.

Option 2: Approve One Renewal Rent Increase

To approve a single tenant's renewal rent increase, do the following:

  1. Select the tenant from the Renewal Increases list.

  2. If you need to manually update the tenant's renewal rent increase amount or recurring charge comment,  in the Rent Recurring Charges section, select the rent recurring charge you want to modify.
    The Edit Recurring Charge pop-up displays..

  3. Enter a New Comment and/or New Amount for the tenant's increased rent recurring charge.

  4. Click OK.
    The Edit Recurring Charge pop-up closes.

  5. Check Approve.

  6. Click Save.
    The renewal rent increase is approved.
