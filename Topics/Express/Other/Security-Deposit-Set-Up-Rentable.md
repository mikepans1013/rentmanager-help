# Set Up Security Deposits with Rentable

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Security-Deposit-Set-Up-Rentable.htm

Rent Manager has partnered with Rentable to streamline the entire security deposit management process. From deposit collection to refunds and withholdings, Rentable provides a simple, guided process for managing security deposits, reducing manual accounting work and ensuring compliance with complex state and local regulations. Additionally, enabling Rentable at a property doesn't prevent you from managing security deposits outside Rentable, ensuring maximum flexibility for you and your tenants. You can use the Set Up Security Deposits wizard to establish Rentable at any property in your portfolio. After finishing the wizard, you connect with Rentable on a call to complete the setup process.

 Step 2: Create Rentable Accounts

 After selecting properties, you must create a general ledger (GL) account to track Rentable security deposits. When setting up Rentable for the first time, you must select whether to create accounts for each property, or one Rentable trust account that records all security deposits for all properties.

 Warning

 The option you select during initial setup is the system default going forward. When enabling Rentable for additional properties in the future, you cannot select a different account option. If you are unsure which option is best for your company, you can email Rentable for more information by clicking Contact Rentable at the bottom left of the wizard.

 Create One for Each Property

 If you select the option Create One for Each Property , Rent Manager creates a dedicated GL account to record Rentable security deposit activity for each property selected. The following fields display:

For example, if the highest numbered bank-type GL account currently in your chart of accounts is 1006 , the first GL Account Number automatically displays 1007 .

 After selecting an option and updating the fields as needed, click Next .

 Step 3: Choose Banks

 After creating Rentable GL accounts, select the bank account in Rent Manager that Rentable should send security deposit withholdings to. For example, if you deduct $250 from the held deposit to pay a damage fee, the selected bank account receives that payment. Each property's Default Bank populates in the GL Account to Deposit Withholdings column automatically. To choose a different bank for a property, click the drop-down list, enter the bank name, then select the bank from the list.

 More Information

 Only banks selected in a property's Bank Settings field display. For more information, refer to Property Details (Page) .

 Related Privileges

 After selecting banks for each property, click Next .

 After entering you contact information, click Finish to complete the wizard. Rentable will reach out to you using the contact information you provide to guide you through the remaining steps of the process, such as confirming bank setups, transferring security deposits, and recording the journal entries related to deposit transfers.

 Next Steps

 Once you have completed your final setup call with Rentable, you can begin using the feature in Rent Manager . The following actions are available:

 Action
 Description

 Collect Deposits with Rentable

 When adding a security deposit for a tenant or prospect at a property set up with Rentable, you can initiate the request for their security deposit payment. Rentable then sends the tenant or prospect an email inviting them to pay the deposit via the Rentable portal. For more information, refer to Request a Rentable Security Deposit .

 Transfer Deposits via Rentable

 Existing security deposits held at your properties when Rentable is enabled can be transferred to Rentable. To do so, on the Rentable Security Deposit Management page, click Transfer Deposits and complete the wizard. After connecting with Rentable on a call, you can create Journal entries to ensure the transfer is appropriately recorded in Rent Manager . By transferring deposits to Rentable, you can issue electronic refunds to your tenants and eliminate the need to use paper checks. For more information, refer to Rentable Security Deposit Management (Page)
