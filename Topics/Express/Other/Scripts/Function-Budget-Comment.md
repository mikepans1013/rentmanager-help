# Budget Comment Function (Script)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Scripts/Function-Budget-Comment.htm

This function displays the comment entered on the Budget grid of the selected property based on the specified general ledger (GL) account number, year, and month of the budget.

 More Information

 This function must be used in conjunction with the Fill Budget function. The FillBudget function must be run first in your script to generate the collection of budgeted financial data as defined by your parameters (e.g., month and year start and end dates). Then, the BudgetComment function is used to retrieve comments from that data.

 To display comments for multiple Chart Accounts, you need to run the FillBudget function only once to generate data. You can then run the BudgetComment function multiple times with different chart account numbers.

 The class that utilizes this function and the location where the scripting information is pulled from in Rent Manager can be found in the table below.

 Class
 Syntax

 Job

 [Job.BudgetComment()]

 Displays information found on the job's Budget tile.

 Property

 [Property().BudgetComment()]

 Displays information found on the Budget Item Details pop-up found on the Budget page for the selected property.

 Parameters

 Parameters change what the function examines and/or how it displays results. The parameters available to this function are indicated below and must be specified in the order listed in the following syntax. Required parameters must be assigned values for the function to work. For Optional parameters, if no value is provided in the script, Rent Manager uses default values.

 [BudgetComment( "AccountNumber","Year" , "Month" )]

 Warning

 The parameters listed below apply only to the function when it is used with the Property class. If using this function with the Job class, there are no available parameters.

 AccountNumber

 Examine the chart account with this general ledger (GL) account number.

 [BudgetComment("1001"," 2026 ")]

 Displays the budget comment entered for the chart account with GL account number 1001 for the budget year specified in the second parameter.

 Year

 Enter the two-digit or four-digit value for the budget year you wish to examine.

 [BudgetComment("1001"," 2026 ")]

 Displays the budget comment entered for the chart account with GL account number 1001 in the budget year 2026 .

 Month

 Enter the numerical value (e.g., 1–12 ) for the month whose budget comment displays.

 If no Month parameter is specified, this function displays the comment entered for the GL account Total (for P&L budgets) or Final (for Balance Sheet budgets) columns.

 [BudgetComment("1001"," 2026 ","7")]

 Displays the budget comment entered for the chart account with GL account number 1001 for July, 2026 .

 Script Examples

 [Property().BudgetComment("4101"," 2026 ","6")]

 From the data generated by the FillBudget function, this displays the budget comment entered for the chart account with GL account number 4101 for June, 2026 .

 [Property().BudgetComment("4101"," 2026 ")]

 From the data generated by the FillBudget function and with no Month parameter specified, this displays the budget comment entered for the 4101 GL account Total (for P&L budgets) or Final (for Balance Sheet budgets) columns in a 2026 budget.
