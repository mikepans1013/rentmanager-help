# Encrypted Text User Defined Field Function (Script)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Scripts/Function-Encrypted-Text-User-Defined-Field.htm

This function displays the information entered for the specified user defined field with a field type of Encrypted Text selected. Encrypted UDFs are used to store sensitive data that can be viewed only by users with the appropriate privileges.

 To view the information generated by an encrypted user defined field, the user running the a letter containing encrypted text must have the applicable encrypted user defined field privileges.

 For example, if a user wants to have the value of an encrypted tenant-level user defined field display in the letter, in the User Defined Fields privilege group, the Access Tenant encrypted UDFs privilege must be Enabled . Otherwise, the script returns a blank value.

 However, if a user with the tenant-level encrypted user defined field privilege generates the letter, and a PDF copy of the letter is attached to the tenant's history/notes, anyone with the privileges to view tenant history/notes can view this information.

 For more information, refer to User Defined Fields Privilege Group .

 Parameters

 Parameters change what the function examines and/or how it displays results. The parameters available to this function are indicated below and must be specified in the order listed in the following syntax. Required parameters must be assigned values for the function to work. For Optional parameters, if no value is provided in the script, Rent Manager uses default values.

 [UserDefinedField( "Name" )]

 Name

 Specify the name of the encrypted text–type UDF to display.

 [UserDefinedField("Driver's License Number")]

 Displays the information defined in the "Driver's License Number" UDF only if the user has the associated permissions.

 Script Examples

 The following scripts show various ways the function can be used:

 [Prospect().UserDefinedField("Car Model")]

 Displays the information in the encrypted prospect-type UDF "Car Model" for the prospect only if the user has the associated permissions.

 [Tenant().UserDefinedField("License Plate")]

 Displays the information in the encrypted tenant-type UDF "License Plate" for the tenant only if the user has the associated permissions.
