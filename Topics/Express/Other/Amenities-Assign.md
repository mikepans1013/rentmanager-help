# Assign Amenities

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Amenities-Assign.htm

Once amenities are created, they need to be assigned to applicable units and/or properties. This makes it easier to find units and properties with amenities that match the features desired by tenants and prospects, such as garage parking, swimming pools, and included appliances. Using the Assign Amenities page, you can get an overview of all property- and unit-type amenities and verify that the appropriate options are enabled for each property and unit.

 To assign amenities, do the following:

 -
 Go to arrow_forward Administration , then go to Rental Info arrow_forward Properties/Units arrow_forward Assign Amenities .

 -
 At the top of page, select from the following filter options:

 Filter
 Description

 Amenity Type

 Filter the page to display only unit or only property-level amenities.

 Property

 Filter by units at each selected property. By default, <All Properties> is selected.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 If you use property groups, selecting a group in the Property Group drop-down list allows you to filter by all properties in that group.

 Amenities

 Filter by specific unit- or property-level amenities.

 -
 Select or deselect any applicable amenities for each property or unit using the following columns:

 Column
 Description

 Unit/Property

 The name of each unit associated with the selected property, or the name of each selected property.

 All Amenities

 Assign all amenities to the unit or property.

 Amenities

 Each unit-level or property-level amenity is listed in subsequent columns. Check the top box of the column to assign the amenity to all units associated with the selected property, or to assign the amenity to all listed properties.

 -
 Click Save .
The updates are saved to the Assign Amenities page. Changes to these assignments display on the Other Information tile in the Property Amenities field of the respective property, or on the Amenities tile of the respective unit.

 More Information

 Amenities can also be assigned to individual properties on the Other Information tile for the desired property, or assigned to individual units on the Amenities pop-up for the desired unit. For more information, refer to Property Details (Page) and Add and Assign a Unit Amenity .
