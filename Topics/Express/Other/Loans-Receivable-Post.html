Post Loans Receivable

The Post Loans Receivable page allows you to add new payment charges to all applicable tenants for existing loans. Additionally, Rent Manager Online users can make posting loans receivable charges more efficient by automating thee postings. Once set up, Rent Manager automatically posts these charges on a predetermined continuing schedule.

Related Privileges

Group Privilege Column
Loans Receivable Post Loans Receivable Enabled

For more information, refer to Control User Access.

Step 1: Filter Loans

To filter the loans to post, do the following:

  1. Go to  arrow_forward Receivables arrow_forward Loans Receivables arrow_forward Post Loans Receivable.

  2. In the section on the left, select the Properties or property Group that should be included.

    More Information

    This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property.

  3. In the Post Date field, enter the desired posting date to be listed on the charge.

Post Loan Charges

After filtering by properties and post date, the register updates with the applicable tenants.

To update and post tenant charges, do the following:

  1. In the list of populated tenants, check each tenant to be included in the loan posting. To quickly select or deselect all options in the list, check or uncheck the box in the column header. The following columns are available in this section:

    Column Description

    Balance

    The tenant's current unpaid balance on the loan.

    Last Post

    The last date on which the loan was posted.

    Reference

    The system-generated loan number that Rent Manager generated when the loan was created or, alternatively, the manually entered loan number.

    Tenant

    The name of the tenant responsible for the loan.

  2. To create a post automation that includes the selected loans, select Automate.

    Related Privileges

    Group Privilege Column
    Task Automation Automate post loans receivable View, Edit

    For more information, refer to Control User Access.

    Related Preferences

    In order to automate loan postings, the task automation workflow for Loans must be enabled in Task Automation (System Preferences).

  3. Click Post Loans.
    Rent Manager posts the loan(s) for the selected tenant(s).

  4. On the Print Report pop-up, choose a file type from the Select export option drop-down list if you wish to print a report of the posting summary, then click Yes. Otherwise, click No.
    The charges associated with each loan are posted to the tenants' accounts.
