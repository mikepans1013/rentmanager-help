Post a RUBS Master Meter Bill

A ratio utility billing system (RUBS)-enabled master meter bill can be created, reviewed, posted in Rent Manager directly from the Bill details page, streamlining the process of converting a property-wide utility bill taken from the master meter into individual charges to tenants at the property.

More Information

This topic covers posting RUBS charges for a single bill. To post multiple RUBS bills for multiple properties and master meters, you can do so from the Post RUBS page. To post RUBS charges in addition to existing recurring charges, you can do so from the Post Recurring Charges page. For more information, refer to Post RUBS and Post Recurring Charges.

To post charges for a RUBS bill, do the following:

  1. Go to arrow_forward Payables arrow_forward Bills arrow_forward Bills.
    The Bills page displays.

  2. Select the master meter bill whose RUBS charges need to be posted.
    The Bill details page displays.

  3. At the top right of the page, click Post RUBS.

  4. At the top of the page, review the information regarding the master meter bill derived from the Bill details page. For more information, refer to Bill Details (Page).

  5. Enter the information in the following fields:

    Field Description

    Charge Comment

    An optional message that displays on the tenant's View Transactions pop-up, in the Comment column next to the RUBS charge.

    Create Invoices

    If checked, an invoice is generated, and added to the Invoices page, for each master meter bill.

    Invoice Comment

    A default note to be added to each created invoice. This field is available only if Create Invoices is checked.

    Post Date

    The calendar date the RUBS charges are posted.

    Use rent due day for posting

    If checked, each tenant's RUBS charge is posted on the day of the month specified by the Due Day field in the General tab on the tenant's details page. Otherwise, new charges are posted on the month of the chosen Post Date.

  6. In the Charges section, each tenant account being charged displays. Review the information to verify it is correct. Each column is described below:

    Column Description

    Account Number

    The unique Rent Manager account number assigned to the tenant as it displays on the tenant's details page.

    Tenant

    The name of the tenant account in Rent Manager that is charged the utility bill.

    Property

    The short name of the property tied to the master meter bill for which the RUBS charges are posted.

    Unit

    The unit for which the RUBS charges are posted

    Admin Fee

    The dollar amount of the administration fee, as specified by the RUBS template assigned to the master meter, that is charged to the tenant.

    Total Charges

    The total dollar amount charged to the tenant by the RUBS bill.

  7. To view the RUBS charge details for a tenant in the property, click Details on the tenant's row.

  8. On the RUBS Charge Details pop-up, review the column information about the specific RUBS charge.

    Column Description

    Charge Type

    The charge type tied to the utility to which the master meter is assigned, as it displays on the Utility Detail page.

    Admin Fee

    The dollar amount of the administration fee, as specified by the RUBS template assigned to the master meter, that is charged to the tenant.

    Charge Amount

    The total dollar amount charged to the tenant by the RUBS bill.

  9. Click OK to close the pop-up.

  10. Click Post RUBS.
    The RUBS bill is posted to each tenant of the expensed property.
