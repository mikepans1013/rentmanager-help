Send Management Inspection

Management inspections in Rent Manager allow you to streamline and standardize the inspections process by customizing it to fit your needs. Your customizations can be saved as inspection templates, which allow you to create new inspections from the same starting point. You can have multiple templates, allowing you to create unique inspections with consideration to property, unit, or unit type. These inspections can be for individual tenants or for multiple tenants at a time on the Tenants page.

Related Preferences

You can also perform inspections using rmAppSuite Pro's Inspection feature. This feature is licensed and must be purchased separately. For more information, contact your sales representative at sales@rentmanager.com.

Once the feature has been licensed, it must be activated before you can use the Inspection feature in the app. For more information, refer to rmAppSuite Inspection (System Preferences).

Related Privileges

Inspections Inspections Add, View

For more information, refer to Control User Access.

Add a Management Inspection

To add a new management inspection for a tenant, do the following:

  1. Go to  arrow_forward Services arrow_forward Inspections arrow_forward Inspections.
    The Inspections page displays.

    More Information

    If you need to schedule more than one inspection, you can do this from the Tenants page by clicking Bulk Actions and selecting Inspections arrow_forward Add Management Inspection. You can also send a management inspection for individual tenants from this page.

  2. Click Add Inspection arrow_forward Add Management Inspection.
    The Send Management Inspection pop-up displays.

  3. In the Inspection For section, make selections in the following fields:

    Field Description

    Property

    The property where this inspection is scheduled. You can type in the field to narrow the list to match your search criteria.

    If a Tenant or Unit is selected first, this field automatically populates with the associated property.

    Tenant

    If applicable, the tenant associated with this inspection. You can type in the field to narrow the list to match your search criteria.

    If a Unit is selected first, this field automatically populates with the current associated tenant.

    Unit

    If applicable, the unit where this inspection is scheduled. You can type in the field to narrow the list to match your search criteria.

    If a Tenant is selected first, this field automatically populates with the associated unit. For tenants with multiple leases, select the applicable lease from the Unit drop-down.

  4. In the Assigned To section's Inspector field, select the Rent Manager user to be responsible for completing the inspection.

  5. In the Inspection Details section, make selections in the following fields.

    Field Description

    Inspection Description

    Additional details regarding the type of inspection being performed by the inspector.

    Inspection Status

    The current stage or progress of the inspection.

    Inspection Type

    The type of inspection to be performed, such as Move Out.

    Click  Add Type to add a new inspection type.

    Scheduled Date

    The date on which the inspection is scheduled to be completed.

    Template

    The templated checklist of areas in the unit or property to review as part of the inspection.

  6. Click Send.
    The inspection is created and added to the Inspections page.

    More Information

    To notify a user that a inspection is scheduled for them to complete, you can add them to the Management Inspection Scheduled automated notification. For more information, refer to Management Inspection Scheduled (Automated Notification).
