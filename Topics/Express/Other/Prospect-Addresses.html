Prospect Addresses

You can create and manage your own categories for prospect addresses on the Address Types page. This makes it easy to record and reference multiple addresses on the same prospect account. Additionally, this adds the ability to pull a specific address type into other parts of Rent Manager, such as reports and features that use scripting. Once you define an address type for prospects, you can go to any prospect account to enter the associated address.

Add a Prospect Address Type

Related Privileges

Group Privilege Column
Setup Address Types Add

For more information, refer to Control User Access.

To add a prospect address type, do the following:

  1. Go to arrow_forward Administration, then go to Customization arrow_forward Address Types.

  2. In the Type section, select Prospect.

  3. Click This is Add Address Type.

  4. Enter the Name for this prospect address type.
    This name displays as an option on the prospect's View Addresses pop-up.

  5. Click Save.
    The address type is added to all prospect accounts.

Add Prospect Addresses

Related Privileges

Group Privilege Column
Tenants/Prospects Prospects View, Edit

For more information, refer to Control User Access.

To add a prospect address, do the following:

  1. Go to  arrow_forward Rental Info arrow_forward General arrow_forward Prospects and select a prospect from the list.
    The prospect's details page displays.

  2. On the Addresses tile, click .
    The View Addresses pop-up displays.

  3. Select the according address type tab for the address you wish to add.

  4. In the text field, enter the prospect's address.

  5. If the address is used as the primary source of correspondence, check Default.

  6. Click Save.
    The prospect address is added.
