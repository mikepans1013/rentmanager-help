Unit Addresses

You can create and manage your own categories for unit addresses on the Address Types page. This makes it easy to record and reference multiple addresses on the same unit account. Additionally, this adds the ability to pull a specific address type into other parts of Rent Manager, such as reports and features that use scripting. Once you define an address type for units, you can go to any unit account to enter the associated address.

Add Address Type

Related Privileges

Group Privilege Column
Setup Address Types Add

For more information, refer to Control User Access.

To add a unit address type, do the following:

  1. Go to  arrow_forward  Administration, then go to Customization arrow_forward Address Types.

  2. In the Type section, select Unit.

  3. Click  Add Address Type.

  4. Enter the Name for this unit address type. This name displays as an option on the unit's View Addresses pop-up.

  5. Click Save.
    The address type is added to all unit accounts.

Add Addresses to a Unit

Related Privileges

Group Privilege Column
Properties/Units Units View, Edit

For more information, refer to Control User Access.

To view or edit an address from the View Contacts page, do the following:

  1. Go to  arrow_forward Rental Info arrow_forward General arrow_forward Units and select a unit from the list.
  2. On the Addresses tile, select the address type tab for the address you wish to add.

  3. In the text field, enter the unit's address.

  4. If the address is used as the primary source of correspondence, check Default to have Rent Manager use this address automatically when generating reports and letters.

  5. Click Save.
    The unit address is added.
