Create a Text Broadcast

Send a single mass text to multiple owners, tenants, prospects, or vendors at once with Text Broadcasting. Compose outgoing text messages and build one or more Numbers Lists of phone numbers to receive an outgoing message. The recipients can reply to the text through the text messaging center. The maximum number of texts sent per day and per month is determined by your service agreement.

More Information

This feature is licensed and must be purchased separately. For more information, contact your sales representative at sales@rentmanager.com.

Step 1: Create an Outgoing Message

Related Preferences

To perform a text broadcast, ensure you enter the setup information in system preferences. This information includes a username and password that are initially provided to you by LCS. For more information, refer to Phone Broadcast (System Preferences).

To start a new text broadcast, do the following:

  1. Go to arrow_forward Communication arrow_forward Texting/Phone arrow_forward Text Broadcast.

    More Information

    For texts you send on a recurring basis, save time by creating text templates. Then you can quickly populate the text on this page by selecting Text Template. Each text template can be filtered by the Text Template Type so that the correct group of recipients receive the message. For more information, refer to Add Text Templates.

  2. Compose your text message using the following fields in the Outgoing Message section.

    Field Description

    Message

    The name of a previously saved message template. By default, <New Message> is selected.

    To create a new text broadcast template, click .

    Name

    The name of the text broadcast. If you save this text message, this name is added to the Message drop-down list so you can select it again.

    Use Scripting

    Allows you to use scripting in your text broadcast message. Select the script class whose functions you wish to use from the drop-down list.

    Description

    A comment or note about when to use this broadcast message.

    Message Text

    The outgoing message to be sent to the recipients of the text broadcast. Text messages that exceed a character count of 160 are converted into multiple message segments of 160 characters, with a maximum of 1,500 characters.

Step 2: Add Numbers to the Broadcast

The Broadcast to Numbers section is where you compose the Numbers List of text-enabled phone numbers to receive the broadcast. There are a variety of ways to create a list of text broadcast recipients and to customize the broadcast to fit the needs of your business and recipients. Filter options change depending on the entity you have selected to include in your text broadcast.

More Information

Additionally, you can manually add phone numbers when you click  Add Item. Then, click Link Contacts and if Rent Manager recognizes the phone number as being defined within the system, the Link type is automatically filled in.

Filter by Tenants

To add numbers when filtering by tenants, do the following:

  1. Click Add Recipients.

  2. In the Filter Type field, select Tenant.

  3. To further filter the entity list, use the Saved Filter drop-down to select a saved or system filter as created in Rent Manager 12. Alternatively, select One Time Filter to create a filter specific to this broadcast.

  4. Check any applicable of the following options in the Status section.

    Field Description

    Past

    Filters list by tenants that have moved out.

    Current

    Filters list by tenants that have an active lease.

    Future

    Filters by tenants with upcoming move-in dates.

    Exclude Subaccounts

    Filters list by tenants to include only tenants that are the master account on the account group.

  5. To add only primary tenant accounts, select Primary Contacts. Alternatively, to select all contacts associated with a specific contact type, select Contacts By Type.

  6. Click Add Results to instantly add the filter's results to your broadcast list.
    The pop-up closes and the applicable accounts are added to the Numbers List.

Filter by Prospects

To add numbers when filtering by prospects, do the following:

  1. Click Add Recipients.

  2. In the Filter Type field, select Prospect.

  3. To further filter the entity list, use the Saved Filter drop-down to select a saved or system filter as created in Rent Manager 12. Alternatively, select One Time Filter to create a filter specific to this broadcast.

  4. Check any applicable of the following options in the Status section.

    Field Description

    Pros

    Filters list by prospects that have a reserved unit.

    Cust

    Filters list by prospects that do not have a reserved unit.

    Lost

    Filters list by prospects that with a status of Lost or Lost/Rejected.

  5. To add only primary prospect accounts, select Primary Contacts. Alternatively, to select all contacts associated with a specific contact type, select Contacts By Type.

  6. Click Add Results to instantly add the filter's results to your broadcast list.
    The pop-up closes and the applicable accounts are added to the Numbers List.

Filter by Property, Vendor, or Owner

To add numbers when filtering by property, vendor, or owner, do the following:

  1. Click Add Recipients.

  2. In the Filter Type field, select Property, Owner, or Vendor.

  3. To further filter the entity list, use the Saved Filter drop-down to select a saved or system filter as created in Rent Manager 12. Alternatively, select One Time Filter to create a filter specific to this broadcast.

  4. In the Status section, check Show Inactive to include entities that are not marked as active.

  5. Click Add Results to instantly add the filter's results to your broadcast list.
    The pop-up closes and the applicable accounts are added to the Numbers List.

Filter by Owner Prospect

To add number when filter by owner prospect, do the following:

  1. Click Add Recipients.

  2. In the Filter Type field, select Owner Prospect.

  3. To further filter the entity list, use the Saved Filter drop-down to select a saved or system filter as created in Rent Manager 12. Alternatively, select One Time Filter to create a filter specific to this broadcast.

  4. Check any applicable of the following options in the Status section.

    Field Description

    Owner Prospect

    Filters list by owner prospects with the status Owner Prospect on their owner prospect details page.

    Owner

    Filters list by owner prospects with the status Owner on their owner prospect details page.

    Lost

    Filters by owner prospects with a status of Lost or Lost/Rejected on their owner prospect details page.

  5. Click Add Results to instantly add the filter's results to your broadcast list.
    The pop-up closes and the applicable accounts are added to the Numbers List.

Step 3: Send the Broadcast

Once your number list is complete, do the following:

  1. In the Saved List section, to save the current Numbers List for future use, click .

  2. To schedule the broadcast for a later time, enter the date and time in the Schedule Time section. By default, Now is checked and the broadcast is released once you click Broadcast on the bottom of the page.

  3. Confirm on the Text Broadcast pop-up that you wish to send the broadcast.

  4. On the Confirm Text Broadcast pop-up, click Yes to confirm that the message counts towards your daily text limit.
    The broadcast is sent immediately or scheduled to send at a specific time.

Step 4: Review the Broadcast

Once you proceed through both confirmations, the Text Broadcast Batches pop-up opens. The Scheduled Broadcast Batches section lists the broadcast, and the Batch Call Status section displays all the recipients of the selected batch.

Scheduled Broadcast Batches

This section displays a listing of sent text broadcasts. The default view for this pop-up is to display Current broadcasts, which includes any scheduled broadcast that are not sent as of the time the page generated. You can select Past to show broadcasts that were already sent. Select All to view both current and past text broadcasts.

The following columns display in the section:

Column Descriptions

Create Time

The date and time the broadcast was created.

Run Time

The date and time the current broadcast was sent. For scheduled broadcasts, it displays the date and time the broadcast is scheduled to run.

Text Message

The type (e.g.,sms.text) of message that was sent in the broadcast.

Submitted

A Check displays when the broadcast is sent successfully.

Batch Text Status

In this section, review the following information to ensure the text messages in the broadcast are being received. As the broadcast progresses, a Check displays in the Queued, Sent, and/or Received columns to inform you of the message's status.

The following columns display in the section:

Column Description

Number

The ten-digit phone number to which the text broadcast message is sent.

Name

The name associated with the phone number.

Link

The type of account associated with the phone number.

Property

The property associated with the phone number.

Queued

A Check displays when the message is preparing to send.

Sent

A Check displays after the message has been transmitted.

Received

A Check displays when the message is received by the recipient's phone.
