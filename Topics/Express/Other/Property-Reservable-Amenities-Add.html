Add a Reservable Amenity

If your property has amenities that your tenants can reserve for their use, such as a clubhouse or car charging stations, the reservable amenities tool in Rent Manager allows you to establish an internal calendar to keep track of those reservations. You can also allow your tenants to book a reservation to use these amenities in Tenant Web Access (TWA), then have a user approve or decline the request from within Rent Manager.

Related Privileges

Group Privilege Column
Properties/Units Properties View, Edit

For more information, refer to Control User Access.

Step 1: Create the Reservable Amenity

More Information

If you need to edit an existing reservable amenity, you do not need to complete the full process detailed here. For details about input fields you may want to edit, refer to the tables throughout this topic.

To add a reservable amenity to a property, do the following:

  1. Go to arrow_forward Rental Info arrow_forward General arrow_forward Properties and select a property from the list. Then, on the Reservable Amenities tile, click .
    The Reservable Amenities pop-up displays.

  2. Click Add.

Step 2: Enter Reservable Amenity General Information

On the Details tile enter basic information about the reservable amenity and whether it is available for reservations.

Field Description

Name

The internal name of the amenity that displays to Rent Manager users.

Active

If checked, the amenity can be reserved.

Display Name

The name of the amenity that displays to Tenant Web Access (TWA) web users.

Color

The background color of the reservations for the amenity that displays on the Community Calendar page in Rent Manager.

Images

An attachment that is available for download when booking this reservable amenity, such as a list of rules for a clubhouse rental.

Description

Any additional information about the reservable amenity, such as the location of a charging station or the maximum occupancy of a clubhouse.

Step 3: Establish Reservation Fees

On the Reservation Fees tile, you can establish any fees charged when tenants reserve amenities.

Column Description

Charge Type

The charge type associated with the reservation fee transaction.

Comment

An additional comment describing the charge type. By default, this field populates with the text entered in the Charge Type details page's Description field.

Fee Amount

The dollar amount of the reservation fee.

Step 4: Determine TWA Settings

On the TWA Settings tile, you can allow tenants to reserve the amenity in Tenant Web Access (TWA) and choose how reservations made in TWA are handled.

Field Description

Allow to be reserved on TWA

If checked, the amenity can be reserved by TWA users.

Require a disclaimer for reserving the amenity

Require the tenant to acknowledge that they have read the text entered in the Disclaimer field.

Disclaimer

Any conditions or rules that the tenant must agree to in order to submit a reservation request. For example, you can enter details regarding the tenant's responsibilities when reserving the community pool and the condition it must be left in.

Automatically approve requests submitted in TWA

If checked, amenities reserved via TWA are immediately approved. If unchecked, reservations must be approved by a Rent Manager user on the Amenity Reservations page.

Require payment for requests submitted in TWA

If checked, tenants must pay the fee(s) established in the Reservation Fees section.

Step 5: Establish Availability Schedules

On the Availability tile, you can establish schedules for what dates, days of the week, and times that the amenity can be reserved for a specific date range.

Field Description

Dates

The date range for which the availability schedule is active.

Day

The day of the week that the amenity can be reserved.

From Time

The earliest time that a tenant can reserve an amenity on the associated Day.

To Time

The latest time that a tenant can reserve an amenity on the associated Day.

Step 6: Set Up Date Exceptions and Save

On the Date Exceptions tile you can set up dates on which the amenity cannot be reserved. This allows you to prevent reservations on specific dates, such as holidays or maintenance periods, without needing to create multiple reservation schedules.

Column Description

From Date

The first date on which the amenity cannot be reserved.

To Date

The final date on which the amenity cannot be reserved.

Description

An internal note explaining why the amenity cannot be reserved. This field is visible only to Rent Manager users and does not display on TWA.

To finalize the reservable amenity and add it to the Reservable Amenities pop-up, click Save.
