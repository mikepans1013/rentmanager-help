Add Text Templates

Text templates are reusable messages that can be sent from Rent Manager to your tenants, prospects, owners, and more. These templates can utilize Rent Manager's dynamic scripting to ensure each message is personalized to the recipient. Once you create a template, you can save it to a dedicated folder. Organizing templates in this way helps you to stay structured and quickly access the template you need when you need it. After text templates are created, you can use them when sending text messages by clicking Insert Text Template.

Step 1: Create and Name the Template

More Information

To edit an existing text message template, you do not need to complete the full process detailed here. For details about input fields you may want to edit, refer to the information throughout this topic.

To create a new text template, do the following:

  1. Go to arrow_forward Communication arrow_forward Texting/Phone arrow_forward Text Templates.
    The Text Templates page displays.

  2. Click Add Template.
    The Select Template Type pop-up displays.

  3. In the Type field, select the appropriate entity (e.g. Tenant, Owner, etc.), then click OK.
    The Add Text Template pop-up displays.

  4. In the General section, enter the following fields:

    Field Description

    Template Name

    The unique identifier for the template that displays when selecting a template for text messages. This displays on the Text Templates page in the Name column.

    Folder

    The folder to save the template in for organizational purposes. To create a new folder from the drop-down menu, click Add New Folder.

Step 2: Write the Message Template

After naming your template, you can craft the message delivered to recipients when this template is used. In the Message Text section, type out the content of the message. The message field can accommodate a maximum of 1500 characters. If you wish to utilize Rent Manager's dynamic scripting in your message, click Open Script Builder at the top right of the section. For more information, refer to Scripting.

Step 3: Configure Additional Settings and Save

Once you've entered the message, finalize your text template by doing the following:

  1. Configure settings in the following sections to control user access to the template and add more organizational information:

    Section Description

    Users

    The list of users who can use the template when sending text messages. At least one user must be selected. Optionally, select All Users to grant access to all current and future users by default. Access to templates can also be controlled on each user account's Communication tab in the Texting section.

    History/Note Category

    The user-created category that is applied to the history/note item for texts sent with this template. The category is used to filter history/note items and report results.

    Description

    A brief summary about the text template that displays on the Text Templates page in the Description column.

  2. Click Save
    The template can now be used when sending text messages.
