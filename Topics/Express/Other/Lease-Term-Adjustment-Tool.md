# Lease Term Adjustment Tool

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Lease-Term-Adjustment-Tool.htm

With the Lease Term Adjustment Tool , Rent Manager makes it easy to apply a lease term to multiple leases at once. If the leases in your database do not have lease terms currently applied, this tool examines the Lease Start and Lease End dates of tenants you select and allows you to quickly assign a term.

 Step 1: Filter the Leases

 To use the Lease Term Adjustment Tool , do the following:

 -
 Go to arrow_forward Rental Info arrow_forward Rental Info Setup arrow_forward Tenants/Prospects arrow_forward Lease Term Adjustment Tool .

 -
 In the Properties section, select the properties for which you wish to view leases with a Lease Start and Lease End dates. Alternatively, select a property Group from the drop-down list. To include properties that are no longer active, check Show Inactive Properties .

 -
 Make selections in the following fields.

 Filter
 Description

 Lease ending after

 If the Lease End date is after the selected date, the lease displays on the page. Today's date is displayed by default.

 Alternatively, remove the date from this field to display all currently expired leases.

 Lease Term

 Rent Manager examines the Lease Start and Lease End dates to determine which leases have an equivalent duration to the selected lease term.

 This Lease Term is applied to the Lease Term field of the selected leases upon clicking Modify Lease Terms .

 Exclude leases with term specified

 Ignores leases that are already assigned a lease term.

 Exclude commercial leases

 Ignores leases for tenants with Company checked on the tenant's details page General tile.

 Step 2: Modify Lease Terms

 After establishing filters, the register updates with tenant's with leases that meet the filter criteria for lease term modification. To modify the lease terms for tenants, do the following:

 -
 Review the information in the following columns to ensure the correct leases populated.

 Column
 Description

 Tenant

 The tenant's full name as entered on the tenant's details page General tile, in the First Name and Last Name fields.

 Property

 The property associated with the specified lease.

 Unit

 The Name of the unit associated with the specified lease as entered on the unit's details page General tile.

 Lease Start

 The date the lease began as entered on the lease.

 Lease End

 The date the lease ends as entered on the lease.

 Move In

 The date the tenant moved in as entered on the lease.

 Move Out

 The date the tenant is to move out as entered on the lease.

 -
 In the Tenant column, click the checkbox next to each tenant name whose lease terms you wish to modify. By default, all tenants are selected.

 -
 When you are satisfied with your selections, click Modify Lease Terms .
The leases terms for the selected tenants are updated with the new lease terms.
