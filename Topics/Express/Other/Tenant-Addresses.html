Tenant Addresses

You can create and manage your own categories for tenant addresses on the Address Types page. This makes it easy to record and reference multiple addresses on the same tenant account. Additionally, this adds the ability to pull a specific address type into other parts of Rent Manager, such as reports and features that use scripting. Once you define an address type for tenants, you can go to any tenant account to enter the associated address.

Add a Tenant Address Type

Related Privileges

Group Privilege Column
Setup Address Types Add

For more information, refer to Control User Access.

To add a tenant address type, do the following:

  1. Go to arrow_forward Administration, then go to Customization arrow_forward Address Types.

  2. In the Type section, select Tenant.

  3. Click Add Address Type.

  4. Enter the Name for this tenant address type.
    This name displays as an option on the tenant's View Addresses pop-up.

  5. Click Save.
    The address type is added to all tenant accounts.

Add Tenant Addresses

Related Privileges

Group Privilege Column
Tenants/Prospects Tenants View, Edit

For more information, refer to Control User Access.

To add a tenant address, do the following:

  1. Go to arrow_forward Rental Info arrow_forward General arrow_forward Tenants and select a tenant from the list.
    The tenant's details page displays.

  2. On the Addresses tile, click .

  3. Select the according address type tab for the address you wish to add.

  4. In the text field, enter the tenant's address.

  5. If the address is used as the primary source of correspondence, check Default.

  6. Click Save.
    The tenant address is added.
