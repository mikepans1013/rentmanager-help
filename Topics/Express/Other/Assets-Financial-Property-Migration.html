Financial Property Migration Wizard

The Financial Property Migration Wizard helps you move assets associated with one financial property to another. For assets, a financial property is the property used in Rent Manager to track financial activity of the asset as entered on the Asset details page, in the General tile. This process mass moves all previous and future financial transactions linked to the selected asset(s) to the destination property.

Related Privileges

For more information, refer to Control User Access.

More Information

Only properties to which you have access display. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property.

To move assets between financial properties, do the following:

  1. Go to arrow_forward Rental Info arrow_forward General arrow_forward Assets.
    The Assets page displays.

  2. Click Financial Migration Wizard.

  3. Select the Source Property where the assets are currently assigned.

  4. Select the Destination Property to which the assets should be transferred.

  5. Check each asset in the Assets to Migrate section that should be moved. To include assets that are no longer marked as active, check Inactive Assets.

  6. Click Save.

  7. On the Warning pop-up, click Yes.

  8. On the Complete pop-up, click OK.
    The selected assets and their transactions are migrated to the Destination Property.
