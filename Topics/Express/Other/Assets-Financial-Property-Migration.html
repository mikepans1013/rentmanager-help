Migrate Financial Property

The Migrate Financial Property tool helps you move assets associated with one financial property to another. For assets, a financial property is the property used in Rent Manager to track financial activity of the asset as entered on the asset's details page, in the General tile. This process mass moves all previous and future financial transactions linked to the selected asset(s) to the destination property.

Related Privileges

Group Privilege Column
Asset Management Manage Assets View, Edit

For more information, refer to Control User Access.

More Information

Only properties to which you have access display. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property.

To move assets between financial properties, do the following:

  1. Go to arrow_forward Rental Info arrow_forward General arrow_forward Assets.
    The Assets page displays.

  2. On the asset you wish to migrate, select arrow_forward Migrate Financial Property.

  3. In the Destination Financial Property section, enter and review information in the following fields:

    Field Description

    Asset to Migrate

    The name of the asset being migrated. This field is read-only.

    Source Financial Property

    The property that is currently financially responsible for the asset. This field is read-only.

    Destination Financial Property

    The property that will be financially responsible for the asset after the migration is complete.

    New Asset Name

    The unique label to identify this asset. If an asset with the same name already exists, the migration cannot be completed.

  4. In the Asset Location section, indicate whether the asset is also physically moving to a new property. If not, select No. If so, select Yes and enter information in the following fields:

    Field Description

    Property

    The new property the asset is physically moving to.

    Unit

    If applicable, the unit the asset is physically moving to.

    From

    The date that the asset is physically moving to the new location.

  5. Click Migrate Asset.
    The Confirm Financial Property Migration pop-up displays.

  6. Click Confirm.
    The selected asset and its transactions are migrated to the Destination Property.
