# Calendar Integration (System Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Preferences/Calendar-Integration.htm

You have the ability to integrate your Rent Manager calendar with your personal calendar in external applications. These system preferences allow you to enable and set up this feature.

 Related Privileges

 Group
 Privilege
 Column

 System
 System Preferences
 View, Edit

 For more information, refer to Control User Access .

 To set these system preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Preferences arrow_forward Calendar Integration .

 -
 Select the option to Integrate Appointments and Tasks with external calendar applications . This enables Rent Manager to export your calendar.

 More Information

 Meeting invitations and email attachments are sent to the email address specified in the Alternate Email field in personal preferences. Therefore, if you want to use calendar integrations, you must first ensure that your email address is entered in the field.

 -
 Select the Integration Method that Rent Manager should use when exporting calendar items. Each option is described below.

 -
 Click Save to accept your changes.

 Integration Method Descriptions

 The following integration methods are supported by Rent Manager .

 More Information

 You may override the system default Integration Method for only your account in personal preferences. For more information, refer to Calendar Options (Personal Preferences) .

 Option
 Description

 iCal File Attachment

 Attach the iCal file to an email. You may open this file to add the appointment or task to your personal calendar.

 iCalendar MIME Stream (Outlook and Google Calendars)

 Send the appointment or task as a meeting that is automatically added to your personal calendar or, depending on application settings, sends an invitation to your calendar that you may accept or deny.

 Google Apps for Work Calendar

 If you wish to integrate Google apps for work calendars, you can select this option to have meetings automatically added to your calendar depending on application settings.
