# rmVoIP (System Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Preferences/rmVoIP.htm

Once you have purchased the rmVoIP phone service and required hardware (if necessary), you can use these settings to set up the phone integration in Rent Manager .

 More Information

 This feature is licensed and must be purchased separately. For more information, contact your sales representative at sales@rentmanager.com .

 Related Privileges

 For more information, refer to Control User Access .

 To set these system preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Preferences arrow_forward rmVoIP .
The System Preferences: rmVoIP page displays.

 -
 In the Username and Password fields, enter the credentials you received from LCS after purchasing your rmVoIP phone service. These credentials are specific to your account.

 -
 Check Enabled to establish your phone's integration within Rent Manager .

 -
 Edit the settings as desired. Each setting is described in the headings below.

 -
 Click Save .

 More Information

 After saving, displays throughout Rent Manager Express , from which you can view recent calls, user extensions, or place and receive calls. The action may vary depending on the location of the icon. For example, displays at the top of Express only for recent calls and user extensions, while displayed next to a tenant account allows you to start an outbound call to the number on file for that tenant.

 rmVoIP Connection Setup

 These settings allow you to test, determine, and establish your rmVoIP connection to other Rent Manager locations.

 Field
 Description

 Test Settings

 Click to confirm your connection to the rmVoIP service.

 More Information

 If an rmVoIP   Phone Extension is not yet assigned to your user account, then a pop-up displays directing you to enter your phone extension on your account. For more information, refer to User Details (Page) .

 Use different credentials in other locations

 Optionally, check to allow users to set up the phone integration in other Rent Manager locations using different credentials.

 Connection Status

 Displays whether the status of your rmVoIP connection is Connected or Closed . If the connection is Closed , you cannot make or receive calls via the rmVoIP  integration in Rent Manager .

 Default User Settings

 These settings allow you to determine your default settings for using rmVoIP in Rent Manager 12 .

 More Information

 These settings apply only to Rent Manager 12 and do not affect how rmVoIP functions in  Rent Manager Express .

 Field
 Description

 Show incoming calls

 Check to automatically open the rmVoIP Call Histories page whenever you receive a phone call while logged into Rent Manager 12 .

 Show extensions in presence listing

 Check to include the user's extension number in the Phone Extensions section of the left sidebar in Rent Manager 12 .
