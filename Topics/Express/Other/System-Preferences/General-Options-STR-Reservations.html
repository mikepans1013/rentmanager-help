Short Term Rental (STR) Reservations (System Preferences)

These system preferences allow you to determine which accounts (tenant or prospect) can be created and tracked when adding an STR reservation. Alternatively, you can choose to allow the Rent Manager user to specify whether they are creating a reservation for a tenant or prospect.

Related Privileges

Group Privilege Column
System System Preferences View, Edit

For more information, refer to Control User Access.

To set these system preferences, do the following:

  1. Go to arrow_forward Administration, then go to Preferences arrow_forward System Preferences arrow_forward General Options arrow_forward STR Reservations.

  2. Edit the settings as desired. Each setting is described below.

  3. Click Save to accept your changes.

Preference Descriptions

This preference group is divided into multiple sections. Each setting is described within the corresponding section below.

Guest Account

This section allows you to determine the type(s) of accounts users can create when adding guests for STR reservations via the Short Term Rental Reservations page.

Select one of the following options:

Option Description

Add Tenant

Users can create only tenant accounts for guests.

Add Prospect

Users can create only prospect accounts for guests. However, once a prospect checks in to their reservation, they are automatically converted to a tenant.

More Information

Adding a guest as a prospect can be beneficial for tracking your marketing strategies, as well as tracking how many guest prospects actually check in to their reservation and are converted to tenants, such as with the Prospect Listing report.

Add Prospect or Tenant

Users can choose to create either tenant or prospect accounts for guests on an individual basis.

Charge Date

This section allows you to determine which date populates by default when creating charges for reservations. Regardless of your selection, users can manually change the date if needed when adding charges manually. This system preference applies to all reservations, whether they were booked online via the STR Online Booking portal or added manually in Rent Manager.

Select one of the following options:

Option Description

Arrival Date

Charge dates default to the Arrival date selected for the reservation.

Booking Date

Charge dates default to the date on which the reservation is being added.

STR Types

This section allows you to select which unit types are available for each STR type (RV Site, Tent Site, or Campground Lodging). On the STR Online Booking portal, guests can select one of these STR types and only unit types assigned to that STR type display in their search results.

To update which unit types are assigned to an STR type, do the following:

  1. Click and select Details.
    The STR Type pop-up displays.

  2. Select each unit type in the list you wish to assign to the selected STR type.

  3. Click OK.
    The unit types display in the Unit Types column of the according STR type.
