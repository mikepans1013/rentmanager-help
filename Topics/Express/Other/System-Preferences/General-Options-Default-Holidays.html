Default Holidays (System Preferences)

Default holidays system preferences allow you to create system-wide holiday entries for the posting of daily property late fees or tenant late fees.

More Information

The Default Holidays system preferences can be overridden by using property late fees or tenant late fees. Creating tenant-level default holidays overrides both property and system preference defaults, while creating property-level defaults overrides only system preferences defaults.

Related Privileges

Group Privilege Column
System System Preferences View, Edit

For more information, refer to Control User Access.

To set these system preferences, do the following:

  1. Go to arrow_forward Administration, then go to Preferences arrow_forward System Preferences arrow_forward General Options arrow_forward Default Holidays.

  2. Click to open the calendar and use the left and right arrows to change the month and year that displays.

  3. Select the date to add to the calendar, and the pop-up closes. The selected date displays.

    More Information

    Choosing a date creates only that date as a default holiday for the selected year. For example, if you want January 1 to be a default holiday every year, you will have to add January 1 for this year, next year, and so on.

  4. Click to add the selected date to the list as a default holiday.

  5. Click Save to accept your changes.
