# Invoices/Estimates (System Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Preferences/Invoices-Estimates.htm

These system preferences allow you to set up default options for Rent Manager  invoices and estimates, such as what information displays when an invoice is generated and the status of estimates when created.

 Related Privileges

 Group
 Privilege

 System Preferences

 For more information, refer to Control User Access .

 To set these system preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Preferences arrow_forward Invoices/Estimates .

 -
 Edit the settings as desired. Each setting is described below.

 -
 Click Save to accept your changes.

 Preference Descriptions

 Each setting is described below:

 Option
 Description

 Create invoices when posting recurring charges

 Check this option to automatically create invoices after recurring charges have been posted.

 More Information

 This option must be enabled if you have tenants who are set up with tax types and you want the tax to be calculated when tenant invoices (not statements) are created in Rent Manager .

 Invoice Report Options

 These options determine whether certain information is included in or excluded from the system default invoice:

 Hide Property

 Check to exclude the property name on the invoice.

 Hide Account Number

 Check to exclude the system-generated account number on the invoice.

 Hide Unit

 Check to exclude the unit name on the invoice.

 Show Item Code

 Check to include the names of inventory items on printed invoices instead of only the description.

 Show markup on invoices

 Check to display the item's Markup column on the invoice. The Markup is an additional percentage or fixed amount that is added to the item’s cost subtotal (item Rate x Qty ).

 Default estimate status

 Select the desired estimate status that populates when a new estimate is created.

 By default, this is set to Draft .

 Estimate expires in x days (populated when date selected)

 Enter the default number of days before an estimate expires. When the Expiration Date checkbox on the estimate's details page is checked, Rent Manager adds this number of days to the Date of the estimate and populates that projected date in the Expiration Date field.

 More Information

 The expiration date can be overridden manually in the Expiration Date field on the estimate's details page.
