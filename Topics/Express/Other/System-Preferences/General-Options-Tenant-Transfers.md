# Tenant Transfers (System Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Preferences/General-Options-Tenant-Transfers.htm

These preferences allow you to select default settings for which transfers methods are available in the Transfer a Tenant wizard. For more information, refer to Tenant Transfer Wizard .

 Related Privileges

 Group
 Privilege
 Column

 System
 System Preferences
 View, Edit

 For more information, refer to Control User Access .

 To set these system preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Preferences arrow_forward General Options arrow_forward Tenant Transfers .

 -
 Edit the settings as desired. Each setting is described below.

 -
 Click Save to accept your changes.

 Preference Descriptions

 Each setting is described below:

 Option
 Description

 Create a new tenant or prospect account

 If selected, the How do you want to transfer the tenant? drop-down displays on the Transfer a Tenant wizard. The options to create a new tenant account or a new prospect account are available for the user performing the transfer to select from. In the Default Transfer Method drop-drown, select the default option ( Create a new tenant account or Create a new prospect account ) for the transfer method.

 Create a new tenant account

 If selected, only a new tenant account is created when performing a transfer.

 Create a new prospect account

 If selected, only a new prospect account is created when performing a transfer.
