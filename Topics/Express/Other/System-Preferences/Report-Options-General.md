# General Report Options (System Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Preferences/Report-Options-General.htm

These system preferences determine the appearance of reports you generate in Rent Manager .

 Related Privileges

 Group
 Privilege
 Column

 System
 System Preferences
 View, Edit

 For more information, refer to Control User Access .

 To set these system preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Preferences arrow_forward Report Options arrow_forward General .

 -
 Edit the settings as desired. Each setting is described below.

 -
 Click Save to accept your changes.

 Preference Descriptions

 Each setting is described below:

 Option
 Description

 Background Formatting

 Select the line separation method to be used in reports:

 Alternating Shades

 Insert a black line between each line of data.

 Black Lines

 Remove line separators between data on a report.

 Alternating Shades Color

 If Alternating Shades is selected, click the Alternating Shades Color field to optionally select a different shading color from the palettes displayed or the pop-up.

 Formatting and Printing

 The following options are available to customize formatting in reports:

 Format Names by Last Name, First Name

 Use the Last Name, First Name format for the tenant names in reports.

 Use modernized report style

 Use the updated formatting for reports generated in Rent Manager Express .

 Tenant Statements

 Choose what displays on tenant statements and how those statements are generated.

 Do not show Unapplied Credits on Statements

 Unapplied credits are not displayed separately on the statement. Any unapplied credit amount are included in the Balance Due value.

 Default Statement Method

 Generate tenant statements in print form, as email attachments, or to send them via Virtual Post Office . To send statements via VPO, the feature must be enabled in Rent Manager .
