Prospect (System Preferences)

Prospect system preferences allow you to set default documents to be sent to prospects through the Correspondence menu on the prospect's details page, as well as default settings for prospect phone calls and prospect stages, and if a lost reason is required when changing a prospect's status to Lost or Lost - Rejected.

Related Privileges

Group Privilege Column
System System Preferences View, Edit
Tenants/Prospects Prospects View

For more information, refer to Control User Access.

To set these system preferences, do the following:

  1. Go to arrow_forward Administration, then go to Preferences arrow_forward System Preferences arrow_forward Prospect.
    The System Preferences: Prospect page displays.

  2. Edit the settings as desired. Each setting is described in the heading below.

  3. Click Save.
    The system preference configuration is updated.

Preference Descriptions

Each setting is described below:

Option Description

Always update Last Contact date on calls

Check to update the prospect's Last Contact date when a call note is added for a prospect and for all calls via rmVoIP and rmAppSuite Pro. The Last Contact field is updated even if, on a history/note item, the Spoke with prospect option is not checked.

Default Prospect Stage

Select a prospect stage to populate in the prospect add wizard or via importing prospects if no other stage is set.

More Information

This selection can be manually overridden when adding or importing prospects.

Enable “Spoke with prospect” on new calls by default

Check to set the Spoke with Prospect option to be checked by default in the prospect add wizard if the Original Contact for a prospect is a Call, including calls via rmAppSuite Pro.

Lease Document

Select a prospect-level letter template from the drop-down list to use as the default lease document.

Require a reason when setting a prospect as lost or lost - rejected

Check to require a lost reason selection when changing the Status on the prospect's details page to Lost or Lost - Rejected.

Unit Info Document

Select a unit-level letter template from the drop-down list to use as the default Unit Info document.
