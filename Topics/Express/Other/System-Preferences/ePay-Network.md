# Network ePay (System Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Preferences/ePay-Network.htm

These preferences are a legacy option for users behind a strict firewall or proxy server to enter information about the proxy server in order to utilize the ePay module and work with the merchant service providers.

 Warning

 This is a deprecated setting that is no longer applicable in Rent Manager . You are not required to enter information about your proxy server in order to utilize the ePay feature.

 To set these system preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Preferences arrow_forward ePay arrow_forward Network .
The System Preferences: ePay - Network page displays.

 -
 Check Use Proxy Server .

 -
 Enter the Host name (the name or IP address of your proxy server). Contact your system administrator if you are unsure of the name.

 -
 Enter the Port that ePay uses to bypass the proxy server.

 -
 Click Save .
The system preference configuration is updated.
