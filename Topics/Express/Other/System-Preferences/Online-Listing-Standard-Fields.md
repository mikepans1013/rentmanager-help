# Online Listing Standard Fields (System Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Preferences/Online-Listing-Standard-Fields.htm

These system preferences allow you to map default values to the fields on the marketing setups of your units or properties, depending on how your ILS marketing is set up. The default values can be updated or overwritten for individual fields or for all fields at the unit or property level. Additionally, you can opt to update the field(s) for all properties and units, or only for those that currently have no data in the field(s).

 To set these system preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Preferences arrow_forward Online Listings arrow_forward Standard Fields .
The System Preferences: Online Listings - Standard Fields page displays.

 -
 In the Company Name and Company Website fields, enter the name and website URL for the property management company.

 -
 For the available fields in the list, set any applicable default values to apply to all your properties or units.

 Column

 Name

 The list of common fields that display on ILS sites. These fields are found on the unit or property's details page by clicking arrow_forward Marketing Setup .

 Default Value

 The value to populate for the field on each property or unit's marketing setup.

 -
 Click Save .
The default values are saved in system preferences, even if you do not push them to the property/unit marketing pop-ups. Your changes must be saved before updating or overwriting any field values.

 -
 To push a field's value or all field values to the properties and units, refer to the headings below.

 Update Single Field

 To update a single field value, do the following:

 -
 For the field you wish to push to the property or unit's marketing setup, click Update .
The Update Field Values pop-up displays.

 -
 Select one of the following options to specify how the value is copied:

 Option
 Description

 Update x to this value on all marketing tabs

 The default value overwrites all existing field information, including fields with values entered, for each property or unit.

 Only update x to this value on marketing tabs where the field is currently blank

 The default value is copied to the marketing setup only if the field has no current value for that property or unit.

 -
 Click Override Values .
The values for that field are updated for each applicable property or unit.

 Override All Fields

 To update all fields in the list at once, do the following:

 -
 In the section header, click Override Field Values .
The Update Field Values pop-up displays.

 -
 Select one of the following options to specify how the value is copied:

 Option
 Description

 Update to this value on all marketing tabs

 The default values overwrite all existing field information, including fields with values entered, for each property or unit.

 Only update to this value on marketing tabs where the field is currently blank

 The default values are copied to the marketing setup only if the field has no current value for that property or unit.

 -
 Click Override Values .
The values for all fields in the list are updated for each applicable property or unit.
