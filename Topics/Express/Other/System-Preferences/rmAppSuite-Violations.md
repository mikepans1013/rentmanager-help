# rmAppSuite Violations (System Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Preferences/rmAppSuite-Violations.htm

The rmAppSuite Pro violations preference settings allow you to view and manage violations from the app for any properties that have a violation code group assigned. With these preferences enabled, rmAppSuite Pro 's Violations map screen displays a pin for each unit, color-coded by its violation stage.

 To set these system preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Preferences arrow_forward rmAppSuite arrow_forward Violations .
The System Preferences: rmAppSuite - Violation page displays.

 -
 Edit the settings as desired. Each setting is described in the heading below.

 -
 Click Save .
The system preference configuration is updated.

 Map View

 In this section, you can determine if rmAppSuite Pro 's Violations map screen displays a pin for all of your units and the color of each pin by its violation stage number.

 Option
 Description

 Customize pin colors by stage

 If checked, you can assign colors to unit pins by their violation stage number. Click Add Stage and then click each field to select the appropriate Stage Number and Color for each stage.

 Show all units in map view

 If checked, you can display a pin on rmAppSuite Pro 's map screen for each unit. With this option enabled, a   GPS Coordinates button displays on the unit's details page in the Addresses tile, allowing you to view and/or edit the GPS coordinates of the unit.

 If this option is disabled, only units with open violations display.
