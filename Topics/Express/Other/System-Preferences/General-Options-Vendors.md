# Vendors (System Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Preferences/General-Options-Vendors.htm

Adjust these preferences to alter default options in the program for working with vendors.

 Related Privileges

 Group
 Privilege
 Column

 System
 System Preferences
 View, Edit

 For more information, refer to Control User Access .

 To set these system preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Preferences arrow_forward General Options arrow_forward Vendors .

 -
 Edit the settings as desired. Each setting is described below.

 -
 Click Save to accept your changes.

 Preference Descriptions

 Each setting is described below:

 Option
 Description

 Do not enable Auto-Fill on new vendors by default

 Check to disable preassigned default vendor values from populating when creating checks or bills linked to the vendor. This is applied to new vendors defined after this option is set.

 Don’t allow duplicate vendor names

 Check to require a unique name when adding a vendor.

 More Information

 Checks and bills can be issued directly to a tenant, owner, or prospect without creating vendor records for each person. Therefore, a vendor is only someone who is being paid for goods or services.

 Default 1099 Category

 Select the Default 1099 Category for vendors from the list of IRS-based categories. This 1099 category populates wherever <System Default> is selected as a vendor’s 1099 category throughout Rent Manager .
