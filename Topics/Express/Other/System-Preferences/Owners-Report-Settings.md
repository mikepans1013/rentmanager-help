# Owner Report Settings (System Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Preferences/Owners-Report-Settings.htm

Adjust these preferences to help you streamline the report creation process and further customize the information that displays on an owner statement, and any report batches run for owners.

 To set these system preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Preferences arrow_forward Owners arrow_forward Report Settings .

 -
 Edit the chart accounts in the list as desired. Each action you can take is described below.

 -
 Click Save to apply your changes.

 Preference Descriptions

 To streamline the process of running owner reports in batches, you may select a Default Owner Report Batch . This allows you to specify one of the report batches to run by default for owners.

 More Information

 You can override the default batch you selected within an individual owner’s details page.

 To determine what displays in owner statements, manage the settings in the Comments and Statement Accounts sections. Each setting is described within the corresponding section below.

 Comments

 You can set up default comments to display in Owner Statements , as described in the table below.

 Field

 Description

 Cover Letter Closing

 Enter a default closing for owner report cover letters.

 Statement Comment

 Enter a default comment that appears at the bottom of all Owner Statements .

 Statement Accounts

 In this section, you can select the chart accounts that should be included on the Owner Statement . The description you enter for each chart account displays in the Other Transactions section of the Owner Statement . By default, the Owner Distribution and Owner Contribution accounts display.

 Typically, accounts are added to Other Transactions to display important equity and liability accounts that impact an owner's bank account.

 The list is organized into the following columns:

 Column
 Description

 Check

 Check the box if the chart account should show on an Owner Statement even if there is no activity.

 Chart Account

 The name of the chart account.

 Description

 The description that displays on the Owner Statement .

 To add a chart account to the list, do the following:

 -
 Click Add Item to add a new row.
