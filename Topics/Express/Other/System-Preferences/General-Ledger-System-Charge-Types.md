# General Ledger System Charge Types (System Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Preferences/General-Ledger-System-Charge-Types.htm

These system preferences allow you to set up default charge types for several basic Rent Manager transactions.

 Related Privileges

 Group
 Privilege
 Column

 System
 System Preferences
 View, Edit

 For more information, refer to Control User Access .

 To set these system preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Preferences arrow_forward General Ledger arrow_forward System Charge Types .

 -
 Edit the settings as desired. Each setting is described below.

 -
 Click Save to accept your changes.

 Preference Descriptions

 Each setting is described below:

 Option
 Description

 Rent Charges

 The charge type that used as the default Rent Charge Type on the property's details page.

 Beginning Balances

 The charge type applied by default to outstanding charges that were not paid before you started using Rent Manager .

 Non-Sufficient Funds Fees

 The charge type applied by default to NSF fees for bounced checks, declined credit cards, and so on.

 Late Charges

 The charge type applied by default when you post late fees. The charge type selected here displays in the Fee Type field on the Post Late Fees page.

 More Information

 This can be overridden when manually posting late fees, or when you automate late fee postings.

 Account group adjustments

 The charge type applied by default to overpayment transfers between one member of an account group and another.

 Security deposit transfers

 The charge type applied by default to security deposit transfers from one tenant and/or unit to another tenant and/or unit.
