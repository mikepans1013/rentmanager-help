Security Deposit General Options (System Preferences)

These system preferences provide default options for allocating security deposits to specific charge types. This distinction is important for security deposit refunds, accurate reporting, and for properties which hold security deposits in separate trust accounts.

More Information

Security deposits are now refunded by creating a check or bill that is added directly to the tenant’s ledger. A security deposit refund charge is not created. The check or bill reduces the tenant’s security deposit Held and the property’s security deposit liability.

Related Privileges

Group Privilege Column
System System Preferences View, Edit

For more information, refer to Control User Access.

To set these system preferences, do the following:

  1. Go to arrow_forward Administration, then go to Preferences arrow_forward System Preferences arrow_forward General Options arrow_forward Security Deposit arrow_forward General.

  2. Edit the security deposit charge types in the list as desired. Each action you can take is described below.

  3. Click Save to apply your changes.

Manage Security Deposit Charge Types

This section describes how to add, reorder, and remove charge types from the Security Deposit Charge Type(s) list.

Add Charge Types

To add a charge type to the list of default charge types, do the following:

  1. In the Add Charge Type field, click the drop-down arrow.

  2. Select a charge type from the drop-down list. Type a phrase to search for a specific charge type.

  3. Click .
    The charge type is added to the bottom of the list of Security Deposit Charge Type(s).

  4. Repeat for all charge types that should be considered security deposit charge types.

  5. Click Save.
    The charge type(s) are now security deposit charge types in Rent Manager.

Reorder Charge Types

The order of the charge types in the list determines the order in which the security deposit charge types are displayed when collecting a tenant's security deposit and when setting default security deposits for units.

To change the order in which the charge types display in the list of default charge types, select the charge type and use the up or down arrows to move it accordingly in the list. Click to move the selected charge type to the top of the list, and to move it to the bottom of the list.

Remove Charge Types

To delete a charge type from the list of default charge types, do the following:

  1. Click on the charge type to remove it from the list.

  2. Click Yes to confirm the action.
    The charge type is removed from the list. However, the charge type is not deleted from Rent Manager.

More Information

If a charge type in the list is assigned as a default security deposit in the Default Security Deposits tile of any unit(s), the charge type cannot be removed from the list.
