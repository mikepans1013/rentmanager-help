# Phone Broadcast (System Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Preferences/Broadcast-Phone.htm

The Phone Broadcasting feature allows you to record and broadcast a voice message to selected phone numbers. These system preferences allow you to set a default area code for outbound calls and manage your Phone Broadcasting credentials provided by LCS .

 More Information

 This feature is licensed and must be purchased separately. For more information, contact your sales representative at sales@rentmanager.com .

 To set these system preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Preferences arrow_forward Phone Broadcast/Texting arrow_forward Phone Broadcast .
The System Preferences: Phone Broadcast/Texting - Phone Broadcast page displays.

 -
 Edit the settings as desired. Each setting is described in the headings below.

 -
 Click Save .
The system preference configuration is updated.

 General

 These settings allow you to set your default area code, log in, test, and apply different Phone Broadcasting credentials to other locations.

 Option
 Description

 Default area code

 The three-digit area code used as the default for outbound calls. The code entered in this field is added to the beginning of the phone number, but only for contacts with seven-digit numbers that do not have an area code entered (e.g., 555-1234 ).

 Username

 Enter the username for your Phone Broadcasting account, provided by LCS .

 Password

 Enter the password for your Phone Broadcasting account, provided by LCS .

 Test Settings

 Click to verify that the connection to the Phone Broadcasting server is working.

 Use different credentials in other locations

 Check this option to provide unique Phone Broadcasting credentials for each location in your system. This option should be checked only if your sales representative provided you with separate credentials per location.

 More Information

 This option is available only from the default Rent Manager database location. For more information, refer to Manage Locations (Pop-Up) .
