# Preprinted Forms (System Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Preferences/Report-Options-Preprinted-Forms.htm

These system preferences provide default options that you can use to adjust your printer when using preprinted forms (checks, deposit slips, statements, invoices, and labels). Preprinted forms are designed for use with most common printers; however, you may need to adjust the printer settings slightly if your data is not properly aligned on the form.

 To set these system preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Preferences arrow_forward Report Options arrow_forward Preprinted Forms .

 -
 Edit the settings as desired. Each setting is described below.

 -
 Click Save to accept your changes.

 Preference Descriptions

 Each setting is described below:

 Options
 Description

 Printer Offset Value

 For each type of form, select from the following printer offset values in the drop-down menu:

 -1” to -1/16”

 The space between the top of the form and the print area is decreased by the selected value.

 0"

 No offset is applied.

 +1/16” to +1”

 The space between the top of the form and the print area is increased by the selected value.

 Adjust Statement format for mailing envelope

 Check to automatically align statements for mailing in Safeguard eChecks envelopes.
