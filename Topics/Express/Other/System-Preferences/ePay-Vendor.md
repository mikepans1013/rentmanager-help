# Vendor ePay (System Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Preferences/ePay-Vendor.htm

Vendor ePay system-level settings specify which bank account(s) are set up for vendor ePay transactions and whether a warning limit should be set for these transactions.

 More Information

 You can configure ePay privileges for individual vendors through the vendor's details page. For more information, refer to Vendor ePay Settings (Pop-Up) .

 To set these system preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Preferences arrow_forward ePay arrow_forward Vendor ePay .
The System Preferences: ePay - Vendor ePay page displays.

 -
 Select Enable ePay for vendors .

 -
 Edit the settings as desired. Each setting is described below.

 Setting
 Description

 ePay Banks

 Assign ePay IDs (provided by Zego ) to any of your bank accounts that are involved in ePay vendor transactions, such as a bill payment to a vendor. Only banks assigned an ePay ID can be used to complete vendor ePay transactions.

 ePay Warning Limit

 Enter a value to display a warning message when an ePay transaction involving a vendor payment is equal to or beyond the specified threshold.

 -
 Click Save .
The system preference configuration is updated.
