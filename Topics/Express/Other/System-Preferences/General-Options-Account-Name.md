# Account Name (System Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Preferences/General-Options-Account-Name.htm

Rent Manager allows you to determine how the tenant field for Account Name and the tenant contact field for Primary Contact are synchronized for residential tenants.

 More Information

 This system preference determines only whether changes to the Contacts page are synchronized to the Details page. Changes made to the Details page does not change the Contacts page.

 To set these system preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Preferences arrow_forward General Options arrow_forward Account Name .

 -
 Edit the settings as desired. Each setting is described below.

 -
 Click Save to accept your changes.

 Preference Descriptions

 Select the option that describes how (or if) changes you make to the Primary contact's name on the Contacts page of the selected tenant will automatically change the account's Name on the Details page of the tenant, in the tenant list, and on the scoreboard at the top of the window.

 Option
 Description

 Always

 Changes to the Primary contact's name on the Contacts page automatically changes the account name on the tenant's Details page, in the tenant list, and on the scoreboard at the top of the window.

 If previously synchronized

 Maintains the previous synchronization status. If the Primary contact's name on the Contacts page previously matched the account name on the tenant's Details page, changes to the Primary contact's name changes the account name. If these did not previously match, changes to the Primary contact's name do not change the account name.

 Ask

 When users make changes to the Primary contact's name on the Contacts page and click Save , they are asked if they want to change the account's name to match the Primary contact's name.

 Never

 Changes to the Primary contact's name on the Contacts page are not reflected in the account's name on the tenant's Details page, in the tenant list, and on the scoreboard at the top of the window.
