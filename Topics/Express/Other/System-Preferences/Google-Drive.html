Google Drive (System Preferences)

In Rent Manager, you can utilize Google Drive to attach files to various records, including history/note items and bills. You can also save files generated within Rent Manager to your Google Drive account, such as reports, leases, and spreadsheets.

Related Privileges

Group Privilege Column
System System Preferences View, Edit

For more information, refer to Control User Access.

To set these system preferences, do the following:

  1. Go to arrow_forward Administration, then go to Preferences arrow_forward System Preferences arrow_forward Google Drive.

  2. Select the option to Enable Google Drive.

  3. Edit the settings as desired. Each setting is described below.

  4. Click Save to accept your changes.

Preference Descriptions

This preference group is divided into multiple sections. Each setting is described within the corresponding section below.

Google Drive Settings

This section allows you to enable use of a system-wide Google Drive account and permit users to use their own Drive accounts.

Option Description

Setup a system Google Drive account

Enables the System Google Drive Account section, allowing you to set up a system-wide Google Drive account login that can be accessed by multiple users in Rent Manager. This allows users to upload and import files from Google Drive without needing to enter login information.

Allow users to setup personal Google Drive accounts

Enables the personal preference for users to enter their own personal Google Drive account information. For more information, refer to Google Drive Options (Personal Preferences).

System Google Drive Account

This section allows you to set up a system-wide Google Drive account. You can access this section when Setup a system Google Drive account is checked. To set up the account you want to use for system-wide access, click Sign in with Google to open the Google sign in pop-up and enter your Google account information. A verification email is sent to that account, which you can then click to enable Google Drive access in Rent Manager. Once enabled, select the Users who can access the Google Drive account without needing to login.
