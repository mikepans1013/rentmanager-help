# Check Numbers (System Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Preferences/Checks-Bills-Check-Numbers.htm

These preferences may be set to ensure that checks written from each bank or credit card have sequential numbers to eliminate the need to track which check numbers have been used.

 Related Privileges

 Group
 Privilege
 Column

 System
 System Preferences
 View, Edit

 Banks/Checks
 Override sequential check number enforcement
 Enabled

 For more information, refer to Control User Access .

 To set these system preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Preferences arrow_forward Checks/Bills arrow_forward Check Numbers .

 -
 Edit the settings as desired. Each setting is described below.

 -
 Click Save to apply your changes.

 Preference Descriptions

 Each setting is described below:

 Option
 Description

 Use the same check number sequence for standard checks and eChecks

 Check Use the same check number sequence for standard checks and eChecks if you use Safeguard eChecks and want them to be tracked and numbered in the same way as standard checks.

 Next Check Number

 Displays the Next Check # , Next AvidPay Check # , and Next NACHA Check # listed by general ledger account.

 More Information

 If Use the same check number sequence for standard checks and eChecks is unchecked , the Next eCheck Check # column displays.

 In the Name column, select the bank or credit card whose next check number you wish to define or edit. Specify the next check number that should be used when writing checks out of the selected account.
