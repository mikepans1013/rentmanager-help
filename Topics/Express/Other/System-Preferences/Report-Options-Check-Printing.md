# Check Printing (System Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Preferences/Report-Options-Check-Printing.htm

Check printing preferences provide default options that determine how checks are printed.

 Related Privileges

 Group
 Privilege

 System
 System Preferences
 View, Edit

 For more information, refer to Control User Access .

 More Information

 Rent Manager prints the full path (parent account: child account) of a selected GL subaccount on the check's detail stub if the Display GL accounts with full path information system preference has been enabled in system preferences. For more information, refer to General Ledger Settings (System Preferences) .

 To set these system preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Preferences arrow_forward Report Options arrow_forward Check Printing .

 -
 Edit the settings as desired. Each setting is described below.

 -
 Click Save to accept your changes.

 Preference Descriptions

 Each setting is described below:

 Option
 Description

 Top Portion

 Select the item to print in the top part of the page from the drop-down menu.

 Middle Portion

 Select the item to print in the middle part of the page from the drop-down menu.

 Bottom Portion

 Select the item to print in the bottom part of the page from the drop-down menu.

 Pad check amounts with asterisks

 Check to add a series of asterisks in the space to the right of the amount value of the check as well as to the right of the text description of the value.

 Print Canadian Style Checks

 Check to print Canadian-style checks that conform to the Canadian Payments Association standard. This format is required when drawing funds from a bank account physically located in Canada.

 Include the word 'Dollars' after text amount on checks

 Check to print the word DOLLARS between the dollar amount and the xx/100 text description on the printed check. For example, a normal total of TWO HUNDRED FIFTY AND 49/100 would now display TWO HUNDRED FIFTY DOLLARS AND 49/100 .

 Replace vendor stub with owner stub on owner payments

 Check to replace the standard vendor stub info with detailed information about the owner's portfolio when printing owner distribution checks. This includes ownership names and percentages, total income and expenses, management fee deductions, total bank balance, security deposits, other reserves, and the total amount of the check.

 Format payee name on check as uppercase

 Check to print out the name of the check payee in all uppercase letters. For example, a check written out to the vendor Smith Plumbing would print as SMITH PLUMBING . This upper-casing occurs only to the check payee field; it does not affect the vendor's address or any of the other detail stub information.
