Texting (System Preferences)

Using the Text Broadcasting feature, you can compose a text message and broadcast it to selected phone numbers. These system preferences allow you to select the text-enabled number(s) to use for broadcasts and enable a texting consent disclaimer.

More Information

This feature is licensed and must be purchased separately. For more information, contact your sales representative at sales@rentmanager.com.

Related Privileges

Group Privilege Column
System System Preferences View, Edit

For more information, refer to Control User Access.

To set these system preferences, do the following:

  1. Go to  arrow_forward Administration, then go to Preferences arrow_forward System Preferences arrow_forward Phone Broadcast/Texting arrow_forward Texting.
    The System Preferences: Phone Broadcasting/Texting - Texting page displays.

  2. Edit the settings as desired. Each setting is described in the headings below.

  3. Click Save.
    The system preferences configuration is updated.

Which Text Numbers Should be Used for Broadcasts?

This section determines the text numbers that are available to use for text broadcasts sent from Rent Manager. You can view text-enabled numbers and assign them to specific properties by going to the Manage Text Numbers page. For more information, refer to Manage Text Numbers (Page).

Option Description

Use any broadcast text numbers

Use any available text-enabled numbers with the option Broadcast enabled on the Manage Text Numbers page. When enabled, text broadcasts are first sent using the number selected as Default. Once the default number reaches its daily text limit, broadcasts are sent from the next available number until that number reaches its daily text limit, and so on.

Use only text numbers assigned to the property

Use only the Text Numbers designated to perform broadcasts that have the property listed in the Properties column on the Manage Text Numbers page.

More Information

Choosing this option may cause text broadcasts to fail if all the available property text numbers reach their daily text limit. Five numbers can be added to a broadcast account. Contact your sales representative for information on adding more text numbers to your database.

Use text numbers assigned to the property first, then use broadcast text numbers

Use the broadcast-enabled Text Numbers defined on a property's details page when sending text broadcasts to entities linked to that property.

If these numbers reach their texting limit, another Broadcast text-enabled number not assigned to the property is used instead.

Show Texting Consent Disclaimer

This section allows you to include a disclaimer to tenants, owners, and prospects on Web Portal Suite pages (such as Tenant Web Access and Owner Web Access) where a phone number can be entered regarding permission to send texts to the phone number. To enable this disclaimer, check the Show Texting Consent Disclaimer option, then enter the information below in the available fields.

More Information

The texting consent disclaimer displays in Apply Now, Tenant Web Access, Owner Web Access, guest cards, web chats, and online bookings. Click next to the Show Texting Consent Disclaimer option to view a preview of the full disclaimer text that displays to the web users.

Field Description

Company Name

Select your management company from the drop-down list or enter a name to be used in the disclaimer. This field must match the legal name of your company.

Warning

This disclaimer is legally binding and this field must be populated to ensure that the disclaimer text displays correctly.

Privacy Policy URL

Enter the web address for your company's privacy policy documentation. When added, the disclaimer includes a hyperlink for the privacy policy text that leads to the URL entered in this field.

Terms of Service URL

Enter the web address for your company's terms of service documentation. When added, the disclaimer includes a hyperlink for the terms of service text that leads to the URL entered in this field.
