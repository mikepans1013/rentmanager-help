# VPO Defaults (System Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Preferences/VPO-Defaults.htm

Virtual Post Office (VPO) is a Rent Manager feature that allows you to outsource the process of printing and mailing letters, statements, and reports to the appropriate recipients. These system preferences allow users to save time by establishing custom forms and letter templates that are VPO-ready, with a reserved area on their first page that contains the To address of the recipient and the From address of the sender.

 More Information

 To set these system preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Preferences arrow_forward Virtual Post Office arrow_forward Defaults .
The System Preferences: Virtual Post Office - Defaults page displays.

 -
 Edit the settings as desired. Each setting is described in the heading below.

 -
 Click Save .
The system preference configuration is updated.

 Defaults

 In this section, determine your default VPO settings.

 Option
 Description

 Default From Address

 The name and full address of the return address. Rent Manager uses this as the default return address whenever you submit statements, reports, or letters to the Virtual Post Office that do not have the Make VPO Ready report option checked.

 Force forms to print in VPO Ready format

 Check to automatically select the Make VPO Ready report option when generating system default invoices, work orders, estimates, purchase orders, tenant statements, or owner statements.
