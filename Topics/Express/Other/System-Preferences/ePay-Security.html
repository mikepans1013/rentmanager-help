Security ePay (System Preferences)

In ePay security system preferences, Rent Manager allows you to purge inactive ePay data from the system, establish password parameters, and set your ePay password.

Related Privileges

Group Privilege Column
System System Preferences View, Edit
ePay Access ePay Settings Enabled
Set up and perform ePay operations Enabled

For more information, refer to Control User Access.

To set these system preferences, do the following:

  1. Go to arrow_forward Administration, then go to Preferences arrow_forward System Preferences arrow_forward ePay arrow_forward Security.
    The System Preferences: ePay - Security page displays.

  2. Edit the settings as desired. Each setting is described in the headings below.

  3. Click Save.
    The system preference configuration is updated.

General

Both options in this tile are deprecated.

Option Description

This is a deprecated setting.

Number of days to retain ePay data before it is purged

This is a deprecated setting.

Password

In this section, you can set up your ePay password, used to view and edit sensitive ePay data, and/or push it to another location.

Related Preferences

This ePay password is different from the one provided by your Zego representative. This password allows you to access and edit sensitive ePay data. The password provided to you by Zego is used to activate ePay in Rent Manager. For more information, refer to General ePay (System Preferences).

Warning

There is no way for Rent Manager to retrieve your ePay password (as part of PCI-DSS security requirements). Therefore, it is imperative that you choose your password carefully and remember it.

Option Description

Push Password

If you utilize multiple database locations, you can push your current ePay password to other locations by clicking Push Password, then check the desired location(s) that will receive this location's password settings, and clicking Save.

Set Password

Related Privileges

Group Privilege Column
ePay Set up ePay Password Enabled

For more information, refer to Control User Access.

To update your ePay password, click Set Password and enter your Current Password and New Password in the prompted fields, then click Save.
