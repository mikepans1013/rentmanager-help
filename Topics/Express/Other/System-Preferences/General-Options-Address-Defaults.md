# Address Defaults (System Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Preferences/General-Options-Address-Defaults.htm

These system preferences let you specify which address types should be used as the default billing address for properties and the default address for all entity types, as well as how Rent Manager parses address information.

 More Information

 Any of the selections that you make on this page may be overridden for an individual property, vendor, owner, tenant, contact, unit, prospect, or asset manufacturer.

 To set these system preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Preferences arrow_forward General Options arrow_forward Address Defaults .
The System Preferences: General Options - Address Defaults page displays.

 -
 Edit the settings as desired. Each setting is described in the headings below.

 -
 Click Save .
The system preference configuration is updated.

 General

 These settings determine which address types are used as the default address for various entities. For more information, refer to Address Types (Page) .

 Option
 Description

 Property Billing Address

 The default address type to be used as the property's billing address on invoices and statements. On each property's details page, in the Address section, the selected address type has Billing checked.

 Entity Default Address
(i.e., Property, Vendor, Owner, etc.)

 The default address type to be used for the entity in reports, letters, and more, unless otherwise specified. On each entity's details page, in the Address section, the selected address type has Default checked unless manually changed for that entity.

 For example, if you set the Owner Default Address field to the address type called Primary , all owners have the address type Primary set as default unless manually changed for a specific owner.

 Default Address Parser

 This setting determines how Rent Manager interprets the individual components of address information that vary between countries, such as postal codes. Select either  United States  or Canada depending on the primary location of your business.
