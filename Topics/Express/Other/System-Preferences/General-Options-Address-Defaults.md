# Address Defaults (System Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Preferences/General-Options-Address-Defaults.htm

Address defaults system preferences let you select which of an entity's address types are be used as the default.

 More Information

 Any of the selections that you make on this page may be overridden for an individual property, vendor, owner, tenant, unit, prospect, or asset manufacturer.

 Related Privileges

 Group
 Privilege
 Column

 System
 System Preferences
 View, Edit

 For more information, refer to Control User Access .

 To set these system preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Preferences arrow_forward General Options arrow_forward Address Defaults .

 -
 Edit the settings as desired. Each setting is described below.

 -
 Click Save to accept your changes.

 Preference Descriptions

 Each setting is described below:

 Option
 Description

 Property Billing Address

 The default address type to be used for the property's billing address.

 Entity Default Addresses
(i.e., Property, Vendor, Owner, etc.)

 The default address type to be used for the entity throughout Rent Manager .

 Default Address Parser

 The region to which addresses in your database should be formatted:  United States  or Canada .
