# Entity Types (System Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Preferences/Entity-Type.htm

Entity types system preferences allow you to change the naming conventions of entities (property, unit, or tenant) system-wide.

For example, you can change the term Tenant to Resident . Each time the term Tenant would be used in the program, it is replaced with the term Resident .

 For more information, refer to Control User Access .

 To set these system preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Preferences arrow_forward Entity Types .

 -
 Edit the settings as desired. Each setting is described below.

 -
 Click Save to apply your changes.

 Preference Descriptions

 Each setting is described below:

 Option
 Description

 Property

 Provide a singular name, short name, and plural name to replace each instance of the terms Property and Properties in the program. Short names are limited to ten characters and display in error messages and certain register column headers and reports.

 Unit

 Provide a singular name, short name, and plural name to replace each instance of the terms Unit and Units in the program. Short names are limited to ten characters and display in error messages and certain register column headers and reports.

 Tenant

 Provide a singular name, short name, and plural name to replace each instance of the terms Tenant and Tenants in the program. Short names are limited to ten characters and display in error messages and certain register column headers and reports.
