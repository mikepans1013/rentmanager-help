Commercial (System Preferences)

Commercial system preferences allow you to set defaults for commercial tenants, which affects the information tracked on their leases and lease abstracts.

Related Privileges

Group Privilege Column
System System Preferences View, Edit

For more information, refer to Control User Access.

To set these system preferences, do the following:

  1. Go to arrow_forward Administration, then go to Preferences arrow_forward System Preferences arrow_forward Commercial.

  2. Edit the settings as desired. Each setting is described below.

  3. Click Save to accept your changes.

Preference Descriptions

This preference group is divided into multiple sections. Each setting is described within the corresponding section below.

General

Option Description

Track tenant retail sales

Check to enable the Sales button on commercial tenant leases as part of your commercial management. This allows you to track a retail tenant’s monthly or yearly sales, if required by their lease.

Lease Options

Commercial lease user defined fields (UDFs) that populate in this list appear on the tenant’s lease abstract, created by right-clicking a tenant and selecting Lease Abstract. Click Add Item to add a UDF, then click each drop-down arrow to select the appropriate UDF from the list. To delete a UDF, click and select Delete.
