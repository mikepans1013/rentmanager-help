Invoices/Estimates (System Preferences)

These system preferences allow you to set up default options for Rent Manager invoices and estimates, such as what information displays when printing an invoice, and the status and default expiration date of estimates when created.

Related Privileges

Group Privilege Column
System System Preferences View, Edit

For more information, refer to Control User Access.

To set these system preferences, do the following:

  1. Go to arrow_forward Administration, then go to Preferences arrow_forward System Preferences arrow_forward Invoices/Estimates.
    The System Preferences: Invoices/Estimates page displays.

  2. Edit the settings as desired. Each setting is described in the headings below.

  3. Click Save.
    The system preference configuration is updated.

Create

In this section, check Create invoices when posting recurring charges for Rent Manager to automatically create invoices to tenants when recurring charges are posted.

More Information

This option must be enabled if you have tenants who are set up with tax types and you want to calculate tax when generating tenant invoices (not statements) in Rent Manager. For more information, refer to Tax Types (Page).

Invoice Report Options

In this section, determine whether information such as the property name, account number, unit name, and item code is included or hidden in the Invoice report, generated by clicking Print on the invoice's details page. Check each option below to determine what data displays in the report:

Option Description

Hide Account Number

Exclude the system-generated account number of the tenant, owner, or prospect on the Invoice report.

Hide Property

Exclude the name of the property associated with the tenant, owner, or prospect on the Invoice report.

Hide Unit

Exclude the unit name associated with the tenant on the Invoice report.

Show Item Code

Display the Item column on the Invoice report. This column displays the names of inventory items instead of only the description.

General

In this section, determine if a markup can be added to an invoice, the default status of an estimate, and the default number of days before an estimate expires.

The following fields display in this section:

Field Description

Default estimate status

Select the desired estimate status that automatically populates the Status field when creating a new estimate.

By default, Draft is selected.

Estimate expires in x days (populated when date selected)

Enter the default number of days before an estimate expires. If the checkbox next to the Expiration Date field is checked on the estimate's details page, Rent Manager adds this number of days to the estimate's entered value in the Date field and populates that projected date in the Expiration Date field.

For example, if you enter 10 in this setting and an estimate's date is set to 8/20/2026, then the estimate's Expiration Date field populates with 8/30/2026 when enabled.

More Information

The expiration date can be overridden manually in the Expiration Date field on the estimate's details page. For more information, refer to Estimate Details (Page).

Show markup on invoices

Check to display the Markup column on invoices, enabling the user to charge an additional dollar amount or percentage for the item.
