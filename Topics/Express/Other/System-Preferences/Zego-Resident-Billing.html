Zego Resident Billing (System Preferences)

Resident Billing is a feature through our integrated partner Zego which can help to automate the process of billing your tenants. Zego effectively takes over the billing of your tenants, mails out customized statements and, in certain circumstances, takes over the payment process as well. You have the option for Zego to take over only billing of utilities or of all tenant billing. Once Resident Billing has been enabled, these system preferences allow you to set defaults for the feature.

More Information

This feature is licensed and must be purchased separately. For more information, contact your sales representative at sales@rentmanager.com.

Related Privileges

Group Privilege Column
System System Preferences View, Edit

For more information, refer to Control User Access.

To set these system preferences, do the following:

  1. Go to arrow_forward Administration, then go to Preferences arrow_forward System Preferences arrow_forwardZego Resident Billing.

  2. Select the option to Enable Zego Resident Billing.

  3. Edit the settings as desired. Each setting is described below.

    Warning

    When setting up Resident Billing for the first time, a Zego representative schedules a call to help you set these system preferences and acquire additional information to enable the feature. It is not recommended that you adjust any of these settings prior to that call.

  4. Click Save to accept your changes.

Preference Descriptions

Each setting is described below:

Option Description

Contact/Occupant Types

Select from the following options to determine how the number of occupants are calculated for billing purposes.

All contacts

Select this option if each contact entered on the tenant's contacts is considered an occupant.

Selected contact type

Select this option if you would like to determine which contacts are considered occupants based on their assigned contact types.

Check each contact type that you want to be counted as an occupant for the purposes of resident billing. To include contacts not assigned with a contact type, select ** Contacts with no contact type.

Selected applicant type

Select this option if you would like to determine which contacts are considered occupants based on their assigned Applicant Type as entered on the tenant's contacts.

Check each applicant type that you want to be counted as an occupant for the purposes of resident billing. To include contacts not assigned with an applicant type, select ** Contacts with no applicant type.

User defined field

Select this option if you would like to determine which contacts are considered occupants based on Yes/No contact-type user defined fields.

Tenant Address Type

Select one of the address types from the drop-down list to be the default mailing address for tenant statements.
