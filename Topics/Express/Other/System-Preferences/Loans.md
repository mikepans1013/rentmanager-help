# Loans (System Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Preferences/Loans.htm

These system preferences allow you to set default charge types for tracking loans in Rent Manager .

 To set these system preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Preferences arrow_forward Loans .

 -
 Edit the settings as desired. Each setting is described below.

 -
 Click Save to accept your changes.

 Preference Descriptions

 Each setting is described below:

 Option
 Description

 Principal Charge Type

 Select a charge type for allocating a payment amount to a loan's principal charge after your monthly loan postings.
This charge type is typically linked to an asset chart account (e.g., Notes Receivable).

 Interest Charge Type

 Select a charge type for allocating a payment amount to a loan's interest charge after your monthly loan postings. This charge type is typically linked to an Income chart account.

 Principal Prepayment Charge Type

 Select a charge type for allocating a payment amount to a loan's prepaid principal (credit) between your monthly loan postings. This charge type is typically linked to an asset chart account (e.g., Notes Receivable).

 Notes Receivable Charge Type

 Select a charge type to use in conjunction with the Sales Income Charge Type to automatically record the loan in Rent Manager .

 This charge type represents the credit offsetting the Sales Income Charge Type and is typically linked to the same Asset chart account (e.g., Notes Receivable) used by the Principal Charge Type and Principal Prepayment Charge Type . In that way, the negative amount recorded with the initial loan is reduced with positive payments throughout the life of the loan.

 Sales Income Charge Type

 Select a charge type to use in conjunction with the Notes Receivable Charge Type to automatically record the loan in Rent Manager .

 This charge type represents the loan and is offset by the Notes Receivable Charge Type . The sales income charge type is typically linked to an Income chart account.

 Bad Debt Charge Type

 Select a charge type to use when allocating a payment amount to a bad debt charge.
