 To set these system preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Preferences arrow_forward Loans .
The System Preferences: Loans page displays.

 -
 Edit the settings as desired. Each setting is described in the heading below.

 -
 Click Save .
The system preference configuration is updated.

 General

 In this section, select the charge types from the drop-down list to assign the system default charge types for tracking loans in Rent Manager .

 Option
 Description

 Bad Debt Charge Type

 The charge type assigned to bad debt charges created when defaulting a loan receivable. For more information, refer to Default a Loan Receivable .

 Interest Charge Type

 The charge type assigned to a loan's interest charge created after your monthly loan postings. This charge type is typically linked to an income chart account (e.g., Loan Interest ).

 Notes Receivable Charge Type

 The charge type to use in conjunction with the Sales Income Charge Type to automatically record the loan in Rent Manager .

 This charge type represents the credit offsetting the Sales Income Charge Type and is typically linked to the same asset chart account (e.g., Notes Receivable ) used by the Principal Charge Type and Principal Prepayment Charge Type . This way, the negative amount recorded with the initial loan is reduced with positive payments throughout the life of the loan.

 Principal Charge Type

 The charge type assigned to a loan's principal charge created after your monthly loan postings.
This charge type is typically linked to an asset chart account (e.g., Notes Receivable ).

 Principal Prepayment Charge Type

 The charge type assigned to a loan's prepaid principal (credit) charge created between your monthly loan postings. This charge type is typically linked to an asset chart account (e.g., Notes Receivable ).

 Sales Income Charge Type

 The charge type to use in conjunction with the Notes Receivable Charge Type to automatically record the loan in Rent Manager .

 This charge type represents the loan and is offset by the Notes Receivable Charge Type . This charge type is typically linked to an income chart account (e.g., Home Sales ).
