# Owner Settings (System Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Preferences/Owners-Settings.htm

Adjust these preferences to choose default bank accounts for specific owner-related transactions as well as determine whether owner bill approval is active.

 To set these system preferences, do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Preferences arrow_forward Owners arrow_forward Owner Settings .

 -
 Edit the settings as desired. Each setting is described below.

 -
 Click Save to accept your changes.

 Preference Descriptions

 Each setting is described below:

 Preference
 Description

 Bank Account

 Select the default owner bank account for receivables, writing checks, and posting management fees.

 Expense Account

 Select the default GL account used to pay management fees to the management company. This is typically linked to an expense account (e.g., 5000 Management Fees Expense).

 Draw Account

 Select the default GL account to track distributions paid out to an owner. This is typically linked to an equity account (e.g., 3002 Owner Distribution).

 Contribution Account

 Select the default GL account to track contributions made by the owner. This is typically linked to an equity account (e.g., 3003 Owner Contribution).

 Pass Throughs Held Account

 Select the default GL account to track pass-through journal entries for the management company's credit offsets as well as the management company transactions (check, bill, check and bill) that are created to disburse standard management fees to the management company.

 Related Preferences

 By default, this is set to the same GL account specified in system preferences for Tenant check pass-through account . For more information, refer to General Ledger System Accounts (System Preferences) .

 Enable owner bill approval

 Check to allow owners to approve bills that exceed a specified amount through Owner Web Access .

 Related Preferences

 In order to enable owner bill approval, the option to Require bills to be approved before they can be paid must be enabled in system preference. For more information, refer to Checks/Bills General (System Preferences) .
