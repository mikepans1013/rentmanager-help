# Security Deposit General Options (System Preferences)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/System-Preferences/General-Options-Security-Deposit-General.htm

These system preferences allow you to determine the specific charge types to which security deposits are allocated. The charge types selected are used for creating and refunding security deposits. This distinction is important for security deposit refunds, accurate reporting, and for properties that hold security deposits in separate trust accounts.

 More Information

 Security deposits are refunded by creating a check or bill that is added directly to the tenant’s ledger. The check or bill reduces the tenant’s security deposit Held and the property’s security deposit liability. For more information, refer to Refund a Security Deposit .

 -
 Edit the security deposit charge types in the list as desired. Each action you can take is described in the headings below.

 -
 Click Save .
The system preference configuration is updated.

 Manage Security Deposit Charge Types

 The General section describes how to add, reorder, and remove charge types from the Security Deposit Charge Type(s) list.

 Add Charge Types

 To add a charge type to the list of default charge types, do the following:

 -
 In the Charge Type field, select a charge type from the drop-down list. Type a phrase to search for a specific charge type.

 -
 Click .
The charge type is added to the bottom of the list of Security Deposit Charge Type(s) .

 -
 Repeat for all charge types you want to be considered security deposit charge types.

 -
 Click Save .
The charge type(s) are now security deposit charge types in Rent Manager .

 Reorder Charge Types

 The order of the charge types in the list determines the order in which the security deposit charge types are displayed when collecting a tenant's security deposit and when setting default security deposits for units.

 To change the order in which the charge types display in the list of default charge types, select the charge type and use the up or down arrows to move it accordingly in the list. Click to move the selected charge type to the top of the list, and to move it to the bottom of the list. When finished reordering, click Save .

 Remove Charge Types

 To delete a charge type from the list of default charge types, do the following:

 -
 Click on the charge type to remove it from the list.
The Confirm Delete pop-up displays.

 -
 Click Yes to confirm the action and close the pop-up.

 -
 Click Save .
The charge type is removed from the list. However, the charge type is not deleted from Rent Manager .

 More Information

 If a charge type in the list is assigned as a default security deposit in the Default Security Deposits tile of any unit(s), the charge type cannot be removed from the list. For more information, refer to Unit Details (Page) .
