Add a System Layout

Layouts allow you to customize how the details page displays in select areas of Rent Manager Express. Tiles can be added, deleted, or repositioned on system layouts to create an experience tailored to best suits the workflow of certain users. You can even create blank tiles to completely customize the content that displays. System layouts can also be set as the default for all users or assigned to specific user roles and property types.

More Information

You can also build layouts specifically for your user account by creating a personal layout, which can be set as the default throughout Rent Manager. For more information, refer to Add a Personal Layout.

Step 1: Create a System Layout

There are two methods available to create a system layout: add and build a new layout, or copy an existing layout from a user account. Creating a new system layout from scratch offers the most granular control for the content and structure of the tiles, but you can also use the default page layout as a base template to save time. Copying a user's layout allows you to quickly share a personal layout that has proven useful with other employees.

Option 1: Add Layout

To create a new system layout, do the following:

  1. On the System Layouts page, click Add Layout.
    The New Layout pop-up displays.

  2. In the Layout Type field, select the desired type from the drop-down list.

  3. In the Layout Template drop-down, select Blank to start with an empty layout or Standard to start with the Rent Manager default layout for the selected type.

  4. Click OK.

  5. Make any necessary changes to the layout.

  6. Click Save.
    The system layout is created.

Option 2: Copy User's Layout

To copy a user's personal layout and use it as a system layout, do the following:

  1. On the System Layouts page, click the drop-down arrow next to Add Layout and select Copy User's Layout.
    The Copy Layout pop-up displays.

  2. In the User field, select the account whose dashboard you wish to copy.

  3. In the Layout Type field, select the desired type from the drop-down list.

  4. In the Layout field, select the desired layout from the drop-down list.

  5. In the Save As field, enter the name for the new system layout.

  6. Click Save.
    A copy of the layout is saved as a new system layout.

Step 2: Add and Customize Tiles

There are two kinds of tiles available for custom layouts: system tiles and blank tiles. Existing tiles are populated with various fields by default, while blank tiles can be fully customized.

Add a System Tile

To add a system tile, do the following:

  1. Click Add Tile and select the desired tile from the drop-down list.
    The tile is added to the layout.

  2. Select a tile to access customization options.

  3. Click to edit the tile's header. Each option is described below.

    Option Description

    Header Name

    The text that displays at the top of the tile.

    Header Border Color

    The color that displays above the Header Name. Select a preset color theme from the Theme Colors section or click Custom Color to use the color picker to set a color.

    Select a color using the gradient color slider, then use the color canvas to further refine the lightness and saturation of your selection.

    Alternatively, use to select either Hex, RGB, or HSL format and enter the desired color value.

    Click OK to apply the selected color.

  4. If available, click to add fields and options to the tile. Each is described below.

    Option Description

    Fields

    Data retrieved from default Rent Manager fields, such as names, email addresses, and statement methods. Fields display as either text boxes or check boxes.

    Issue Links Information

    Fields that pull in information about the Rent Manager entity or entities associated with the issue. This option is only available for Issue layouts.

    Buttons

    A button that performs an action or opens a related page, such as adding a history/note item, viewing late fee settings for a tenant, or entering a technician's hours on an issue.

    Buttons are not available for Asset or Vendor layouts.

    User Defined Fields

    Data retrieved from user-defined fields (UDFs) of the selected page's type.

    UDFs are not available for Vendor layouts.

    Phone Numbers

    Phone numbers associated with the selected page. A unique field is available for each phone number type.

    Phone numbers are not available for Asset, Issue, Unit, or Vendor layouts.

  5. If available, select a field on the tile and click to customize the field. Each option is described below.

    Option Description

    Name

    The label to display for the selected field. Special characters are allowed.

    Width

    The width, as a fraction of the tile, taken up by the selected field (e.g., Full, Half, Two Thirds, and so on). Other fields on the tile adjust automatically to accommodate the resizing.

    Read Only

    Prevents users from editing the field when this layout is selected.

    Delete

    Removes the field from the tile.

  6. Click and drag to move the tile on the layout.

  7. Once finished, click Save.
    The layout and any changes to tiles are saved.

Edit Action Bar Access

The action bar is located on each entity's details page and provides additional access to other sections of Rent Manager.Within a custom layout, you can select which actions can be performed from the action bar.

More Information

The Edit Action Bar Access button is not available for Asset, Vendor, and Owner Prospect layout types.

To edit what displays on the action bar, do the following:

  1. Click Edit Action Bar Access.
    Depending on the type of layout you are creating, the Edit Action Bar pop up with the relevant actions displays.

  2. Select the actions you want to make available in the particular layout you are viewing.

  3. Once finished, click Save.
    The changes you made to the layout type action bar are saved to the custom layout.

Step 3: Assign Layouts and Save

To assign the layout and save your changes, do the following:

  1. At the top, enter a Name for the layout.

  2. Select the Property Types for which this layout is available. This option does not display for Asset and Issue type layouts.

  3. Select the Rent Manager user Roles for which this layout is available from the drop-down list.

    More Information

    Users must be assigned to at least one of the selected user roles to access the layout. If a user is not assigned to any role, they cannot select the layout. For more information, refer to User Roles (Page).

  4. Click Save.
    The layout is saved.
