Owner Addresses

You can create and manage your own categories for owner addresses on the Address Types page. This makes it easy to record and reference multiple addresses on the same owner account. Additionally, this adds the ability to pull a specific address type into other parts of Rent Manager, such as reports and features that use scripting. Once you define an address type for owners, you can go to any owner account to enter the associated address.

Add an Owner Address Type

Related Privileges

Group Privilege Column
Setup Address Types Add

For more information, refer to Control User Access.

To add an owner address type, do the following:

  1. Go to arrow_forward Administration, then go to Customization arrow_forward Address Types.

  2. In the Type section, select Owner.

  3. Click Add Address Type.

  4. Enter the Name for this owner address type.

    This name displays as an option on the owner's View Addresses pop-up.

  5. Click Save.

    The address type is added to all owner accounts.

Add Owner Addresses

Related Privileges

Group Privilege Column
Owners Owners View, Edit

For more information, refer to Control User Access.

To add an owner address, do the following:

  1. Go to  arrow_forward Owners arrow_forward General arrow_forward Owners.

    The Owners page displays.

  2. Select an owner from the list, then, on the Addresses tile, click .

  3. Select the according address type tab for the address you wish to add.

  4. In the text field, enter the owner's address.

  5. If the address is used as the primary source of correspondence, check Default.

  6. Click Save.
    The owner address is added.
