Export Corrected Owner 1099

If you are required by the IRS to produce 1099 tax forms for your owners, you can export and save the forms as text (TXT) files to a location on your computer or network. These files are for use with the IRS Filing Information Returns Electronically (FIRE) system, which is different from the Information Returns Intake System (IRIS) filing portal and uses a separate Transmitter Control Code (TCC). If you submitted incorrect information on a 1099 generated from Rent Manager, you can quickly generate a corrected form using Export Corrected 1099. The corrected 1099 file should then be sent to the IRS by the IRS-mandated deadline(s).

Related Privileges

Group Privilege Column
Payables Export 1099 Enabled

For more information, refer to Control User Access.

Step 1: Select Export Options

To export your corrected 1099 forms, do the following:

  1. Go to arrow_forward Payables arrow_forward General arrow_forward Export Corrected 1099.

  2. Confirm you have the information and details listed on the page and click Next.

  3. Select the year and entity type for your 1099 export file using the fields below.

    Field Description

    Which tax year will be used for the export?

    The tax year used for the 1099 export file.

    What type of information return are you correcting?

    Select Owner 1099 to run the 1099 export for owners. If you need to run a separate 1099 export for owners, refer to Export Corrected Vendor 1099.

Step 2: Enter Transmitter Information

After you confirm the export options, select the Transmitter Information tab on the left or click Next.

Enter information in the fields below related to the sender of the 1099 form. Click Copy From Management Company to auto-fill the Transmitter Information tab with information from the property management company's details page.

Field Description

Tax ID

The tax identification number (TIN) issued to your business by the IRS.

If you use Copy From Management Company, this displays the information from the property's details page under Other Information arrow_forward Property Tax ID.

TCC

The Transmitter Control Code (TCC) issued to your business by the IRS to submit the 1099 electronically. This code must be obtained from the IRS before you attempt to submit the 1099.

Transmitter Name

The name of your property management company.

If you use Copy From Management Company, this displays the information from the property's details page under General arrow_forward Full Name.

Contact Name

The name of the person the IRS should contact.

If you use Copy From Management Company, this displays the information from the property's details page under General arrow_forward Manager.

Contact Phone

The phone number of your property management company.

If you use Copy From Management Company, this displays the information from the property's details page under Phone Numbers arrow_forward Number that is marked as Default.

Contact Email

The email address of your property management company.

If you use Copy From Management Company, this displays the information from the property's details page under General arrow_forward Email.

Company Name

The name of your property management company used for billing purposes.

If you use Copy From Management Company, this displays the information from the property's details page under Other Information arrow_forward Billing Name 1 and Billing Name 2.

Street Address

The number and street of your property management company's billing address.

If you use Copy From Management Company, this displays the information from the property's details page under Primary Address for the address marked as Billing.

City

The city of your property management company's billing address.

If you use Copy From Management Company, this displays the information from the property's details page under Primary Address for the address marked as Billing.

State

The state of your property management company's billing address.

If you use Copy From Management Company, this displays the information from the property's details page under Primary Address for the address marked as Billing.

Postal Code

The postal code of your property management company's billing address.

If you use Copy From Management Company, this displays the information from the property's details page under Primary Address for the address marked as Billing.

Step 3: Select Owners

After you enter the payer information, select the Owner Selection tab on the left or click Next.

In the Which owner requires corrections? field, select the owner whose 1099 transaction data is included in the corrected 1099 file from the drop-down list.

To select owners who are not currently active in Rent Manager, check Inactive Owners. The drop-down list updates to include inactive owners.

Step 4: Select Correction Type

After you choose which owner needs corrections, select the Correction Type tab on the left or click Next. Check any of the options for information that needs to be corrected.

Step 5: Enter Original File Information

On this tab, enter information as it was on your original file to ensure that Rent Manager correctly matches fields. The fields that display on this tab depend on the options you select on the Correction Type tab. Some options do not require you to enter original file information.

Step 6: Enter Corrected Information

In this tab, enter corrected information as it should display on the new 1099 form. The top of this tab displays fields for providing corrected information. If any information was not completed as part of the Original File tab, the bottom of this tab displays fields required for filing. Enter information in these fields to match your original 1099. The fields that display on this tab depend on the options you select on the Correction Type tab.

Step 7: Review Summary

After all information is entered, select the Summary tab on the left or click Next. On the tab, verify that the information in each field is correct. Then, in the File Name field, enter the desired name for the export file.

More Information

To save a test file than can be sent to the IRS during their specified testing date range, check Generate Test File . Then, in the File Name field, enter the desired file name for the export. For more information, refer to the IRS website.

When finished, click Download File to download the completed 1099 file and select if you want to print a summary of the export options you selected.

If you select Yes, the Export Corrected Owner 1099 Summary pop-up displays along with a generated Export Corrected 1099 Summary report. You can use options on the top right to download or print the summary.
