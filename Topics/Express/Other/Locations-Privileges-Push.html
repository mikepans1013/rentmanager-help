Push Privileges to Locations

If you use more than one Rent Manager database location to store data for more than one property management company, you can set up user accounts in each location. User privileges can differ between locations if desired, but if a user should have the same privileges in multiple locations, you can copy them over from the user's details page.

Before you can push privileges for a user, their account must have access to at least one additional location. You can enable location access for a user on their account's Locations tile. For more information, refer to User Details (Page).

More Information

Locations are a licensed feature and must be purchased separately. For more information, contact your sales representative at sales@rentmanager.com.

Related Privileges

Locations Locations View, Edit

Additionally, you must have access to the location(s) that you are pushing user privileges to on your user's details page.

For more information, refer to Control User Access.

To push a user's privileges to a location, do the following:

  1. Go to arrow_forward Administration, then go to Users arrow_forward Users and select a user account.
    The user's details page displays.

  2. On the action bar to the right, select arrow_forward Push Privileges.

  3. In the Locations field, select the database location(s) to which the user's privileges should be pushed.

  4. Select the user settings to include in the push.

    Option Description

    Options

    Push the settings enabled on the user account's Options tile (e.g., Administrator, Sales Rep/Leasing Agent).

    Privileges

    Push the privileges enabled on the user account's Privileges tab.

    Reports

    Push the system reports enabled on the user account's Reports tab. Report Writer report access is not pushed as reports are unique and customizable in each location.

  5. Click Save.
    The user's privileges are pushed to their account in the selected location(s).
