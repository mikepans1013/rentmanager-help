# Owner Addresses

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Owners-Addresses.htm

You can create and manage your own categories for owner addresses on the Address Types page. This makes it easy to record and reference multiple addresses on the same owner account. Additionally, this adds the ability to pull a specific address type into other parts of Rent Manager , such as reports and features that use scripting. Once you define an address type for owners, you can go to any owner account to enter the associated address.

 To add an owner address type, do the following:

 -
 Go to arrow_forward Administration , then go to Customization arrow_forward Address Types .

 -
 In the Type section, select Owner .

 -
 Click Add Address Type .

 -
 Enter the Name for this owner address type.
 This name displays as an option on the owner's View Addresses pop-up.

 -
 Click Save .
 The address type is added to all owner accounts.

 -
 Select an owner from the list, then, on the Addresses tile, click .

 -
 Select the according address type tab for the address you wish to add.

 -
 In the text field, enter the owner's address.

 -
 If the address is used as the primary source of correspondence, check Default .

 -
 Click Save .
The owner address is added.
