# Open Make Ready Processes (Dashboard Tile)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Dashboard-Tiles/Open-Make-Ready-Processes.htm

The Open Make Ready Processes dashboard tile displays units from selected properties that are assigned to an active make-ready process. It also displays when the next tenant is due to move into the unit as well as how far along the unit is in the turnover process.

 The information on this dashboard tile is represented in a list.

 To filter the information that displays in the dashboard tile, click arrow_forward Settings to open the Open Make Ready Processes Data Filters pop-up. The available filter options are listed below.

 Option
 Description

 Property Filter

 Each property's units that are included in the tile results. To include all current and future properties, select <All Properties> . Alternatively, select a property Group from the drop-down list.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Default Sort Column

 The information used to sort the list of units in a make-ready process. Each option is described below.

 Property

 The results are sorted alphanumerically by each property's Short Name . Units at the same property are further sorted alphanumerically by unit name.

 Unit

 The results are sorted alphanumerically by unit name.

 Next Move In

 The results are sorted chronologically by the future tenant's move in date in ascending order (soonest to farthest in the future). Units with no future move in date display first in the list.

 Progress

 The results are sorted numerically by make-ready process progress in ascending order (least to most) based on how many steps have been completed.

 Ignore dashboard property filter

 If checked, override the property filter configured on the Dashboard page.

 Column Descriptions

 The information that displays on the tile is organized into the following columns.

 Column
 Description

 Property

 The Short Name of the property of the unit undergoing a make-ready process.

 Unit

 The name of the unit undergoing the make-ready process.

 Next Move In

 If a tenant is scheduled to move in to the unit in the future, that tenant's Move In date displays.

 Progress

 How far the unit has progressed in its make-ready process versus how many steps are in its assigned process (completed/total).
