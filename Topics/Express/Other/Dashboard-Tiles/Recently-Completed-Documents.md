# Recently Completed Documents (Dashboard Tile)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Dashboard-Tiles/Recently-Completed-Documents.htm

The Recently Completed Documents dashboard tile helps you track signable documents that have been signed by prospects, tenants, or owners. The tile also allows you to view whether the document is pending acceptance by a Rent Manager user.

 The information on this dashboard tile is represented in a list.

 To filter the information that displays in the dashboard tile, click arrow_forward Settings to open the Recently Completed Documents Data Filters pop-up. The available filter options are listed below.

 Option
 Description

 Days to Include

 The number of days in the past that a tenant, prospect, or owner completed a signable document. For example, if you enter 30 , signable documents completed within the last 30 days display.

 Property Filter

 Each property whose units are included in the tile results. To include all current and future properties, select <All Properties> . Alternatively, select a property Group from the drop-down list.

 If <All Properties> is selected, you can also check Include inactive if 'All Properties' selected to calculate averages for all current and future properties whether they are active or inactive.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Statuses to include

 The status of a signable document ( Pending or Completed ) to include in the tile results.

 Ignore dashboard property filter

 If checked, override the property filter configured on the Dashboard .

 Column Descriptions

 The information that displays on the tile is organized into the following columns.

 Column
 Description

 Last Signed

 The date on which the document was signed by the owner, prospect, or tenant to whom it was sent.

 Name

 The name of the owner, prospect, or tenant to whom the document was sent.

 Property

 The Short Name of the property associated with the prospect or tenant to whom the document was sent. For documents sent to owners, the property management company displays.

 Unit

 The Name of the unit associated with the prospect or tenant to whom the document was sent. For documents sent to owners, no unit displays.

 Pending

 Yes displays in this column if the document is still pending acceptance by a Rent Manager user.
