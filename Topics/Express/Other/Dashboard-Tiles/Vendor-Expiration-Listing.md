# Vendor Expiration Listing (Dashboard Tile)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Dashboard-Tiles/Vendor-Expiration-Listing.htm

The Vendor Expiration Listing dashboard tile helps you track vendors who have expired or imminently expiring insurance or workers' compensation entered on the vendor's details page. This tile can be customized to display vendors with expired or expiring documents within a set number of days, or limit expiration information to vendors associated with specific properties.

 The information on this dashboard tile is represented in a list.

 To filter the information that displays in the dashboard tile, click arrow_forward Settings to open the Vendor Expiration Listing Data Filters pop-up. The available filter options are listed below.

 Option
 Description

 Days to Include

 The number of days in the future that a vendor's insurance or workers' compensation expiration date occurs in order to be included in the tile results. For example, if you enter 30 in this field, vendors with expiration dates in the next month display.

 Vendors with expired insurance or workers' compensation are always included in the tile results.

 Property Filter

 Each property whose associated vendors with expired or expiring documents are included in the tile. To include all current and future properties, select <All Properties> . Alternatively, select a property Group from the drop-down list.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Vendor Expiry Type

 The type(s) of expired or expiring vendor documents included in the tile (i.e., Insurance (INS) , Workers Compensation (WC) , or Both ).

 Ignore dashboard property filter

 If checked, override the property filter configured on the Dashboard .
