# Unconfirm Move Out List (Dashboard Tile)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Dashboard-Tiles/Unconfirm-Move-Out-List.htm

The Unconfirm Move Out List dashboard tile tracks tenants who have an unverified Move Out date on a lease, which is indicated on the tenant's details page by an unchecked verification box accompanying the move-out date. An unverified move-out date permits recurring charges to continue to post for the tenant.

 The information on this dashboard tile is represented in a list.

 To filter the information that displays in the dashboard tile, click arrow_forward Settings to open the Unconfirm Move Out List Data Filters pop-up. The available filter options are listed below.

 Option
 Description

 Days to Include

 The number of days into the future unconfirmed move outs must be to display on the tile. For example, to list only unconfirmed move outs that are at least within one week, enter 7 .

 Property Filter

 Each property whose units are included in the tile results. To include all current and future properties, select <All Properties> . Alternatively, select a property Group from the drop-down list.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Ignore dashboard property filter

 If checked, override the property filter configured on the Dashboard .

 Column Descriptions

 The information that displays on the tile is organized into the following columns.

 Column
 Description

 Tenant

 The tenant whose move-out date is set but not yet confirmed.

 Property

 The property at which the unit is located.

 Unit

 The unit from which the tenant is moving out.

 Move Out

 The date the tenant is set to move out that was not yet confirmed.

 Lease End

 The Lease End date of the tenant as specified on their primary lease.
