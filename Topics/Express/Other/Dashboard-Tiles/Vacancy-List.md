# Vacancy List (Dashboard Tile)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Dashboard-Tiles/Vacancy-List.htm

The Vacancy List dashboard tile helps you track which units and home-type assets are not currently occupied and how long the units and assets have remained vacant. Vacant units or home-type assets that have a tenant with a future Move In date display with an asterisk (*).

 The information on this dashboard tile is represented in a list.

 To filter the information that displays in the dashboard tile, click arrow_forward Settings to open the Vacancy List Data Filters pop-up. The available filter options are listed below.

 Option
 Description

 Property Filter

 Each property whose units are vacant are included in the tile results. To include all current and future properties, select <All Properties> . Alternatively, select a property Group from the drop-down list.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Ignore dashboard property filter

 If checked, override the property filter configured on the Dashboard .

 Exclude pre-leased Units

 If checked, future tenants are excluded from the tile results. Otherwise, pre-leased units with a move-in date of today or earlier as specified on the prospect's Units page are listed in red.

 Combine home and lot market rent into one row

 If selected, the tile consolidates information for units and the home-type assets associated with them on a single line. Additionally, the Rent value is calculated by adding the market rent of the unit and the home-type asset. Otherwise, units and home-type assets display as separate entries.

 This option displays only if, in the  Property Filter field, one or more Manufactured Housing -type properties are enabled.

 Column Descriptions

 The information that displays on the tile is organized into the following columns.

 Column
 Description

 Property

 The property associated with the vacant unit or home-type asset.

 Unit

 The unit or home-type asset that is currently vacant.

 Type

 The Unit Type of the vacant unit as specified on the unit's details page.

 Rent

 The Market Rent of the vacant unit or home-type asset as specified on its details page.

 Days Vacant

 The total number of days since the last time the unit or home-type asset was occupied. A 0 means the unit or home has never been occupied.
