# Budget To Actual NOI Comparison (Dashboard Tile)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Dashboard-Tiles/Budget-Actual-NOI-Comparison.htm

The Budget To Actual NOI Comparison dashboard tile displays budget net operating income (NOI) and the actual net operating income for the current month and the twelve previous months. Budgeted NOI data is derived from values you have entered on budgets for the displayed time period, and actual NOI is calculated in the same way as the Profit & Loss report.

 More Information

 NOI is income minus noncontrollable expenses related to your normal business activities, calculated as follows:

 NetOperatingIncome = Income - CostOfGoodsSold + OtherIncomeExpense - Expense + NonControllableIncome - NonControllableExpense

 The information on this dashboard tile may be represented in a graph or a list.

 To filter the information that displays in the dashboard tile, click   arrow_forward   Settings to open the Budget To Actual NOI Comparison Data Filters pop-up. The available filter options are listed below.

 Option
 Description

 Property Filter

 Each property whose units are included in the tile results. To include all current and future properties, select <All Properties> . Alternatively, select a property Group from the drop-down list.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Period(s)

 The number of months or years (as defined by the Period Category ) to include in the tile results.

 Period Category

 The unit of time to use for the tile results ( Month(s) or Year(s) ).

 Exclude Period Adjustments

 If checked, any journal entries that were notated as adjustment entries are excluded from tile results.

 Graph Type

 The desired display option.

 Line

 The budget to actual net operating income in a line graph with two lines. One line represents the budget and the second line represents the actual.

 Bar

 The budget to actual net operating income in a bar graph. One bar represents the budget and the second bar represents the actual.

 None

 The date, budget net operating income, and the actual net operating income in columns. To quickly sort information, click on the Date or Amount column header.

 Ignore dashboard property filter

 If checked, override the property filter configured on the Dashboard .
