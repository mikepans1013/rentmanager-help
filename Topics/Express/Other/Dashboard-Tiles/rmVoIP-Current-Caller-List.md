# rmVoIP Current Caller List (Dashboard Tile)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Dashboard-Tiles/rmVoIP-Current-Caller-List.htm

The rmVoIP  Current Caller List dashboard tile allows you to view real-time rmVoIP phone service call data for users currently on the phone and the duration of those calls. This tile automatically refreshes every five seconds to ensure you're viewing the most up-to-date information.

 The information on this dashboard tile is represented in a list.

 For more information, refer to Control User Access .

 Column Descriptions

 The information that displays on the tile is organized into the following columns.

 Column
 Description

 Ext

 The extension associated with the user currently on the phone.

 Associated User

 The user associated with the active extension.

 Outside Number

 The dialed or incoming phone number to which the user is connected.

 Duration

 The current duration of the call.

 Call Time

 The time at which the call was made.

 Related Preferences

 The time is determined by the Time Zone established in system web preferences. For more information, refer to Web Access Time Zone (System Web Preferences) .
