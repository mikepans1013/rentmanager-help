# Pending Smart Bills (Dashboard Tile)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Dashboard-Tiles/Pending-Smart-Bills.htm

The Pending Smart Bills dashboard tile allows you to view a list of Smart Bills ready for review on the Smart Bills page. Rent Manager 's Smart Bills feature allows you to streamline your invoice management process. With this feature, you can easily upload invoices via a PDF or image format, allowing AI to extract the relevant data and create draft transactions automatically.

 The information on this dashboard tile is represented in a list.
