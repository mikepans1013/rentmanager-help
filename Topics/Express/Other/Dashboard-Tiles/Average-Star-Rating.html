Average Star Rating (Dashboard Tile)

The Average Star Rating dashboard tile displays the average of specific star rating questions for surveys sent to tenants. This dashboard tile can be useful for property managers by providing at a glance information about how well they are doing in specific areas. For example, if they want to continually monitor their performance when responding to service issue requests from tenants, they can use this tile to track average star ratings to survey response questions involving tenant satisfaction in that area.

For more information, refer to Control User Access.

To filter the information that displays in the dashboard tile, click arrow_forward Settings to open the Average Star Rating Data Filters pop-up. The available filter options are listed below.

Option Description

Property Filter

Each property whose star rating responses are included in the tile. To include all current and future properties, select <All Properties>. Alternatively, select a property Group from the drop-down list.

More Information

This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property.

Ignore dashboard property filter

If checked, override the property filter configured on the Dashboard.

Surveys to Include

The survey(s) whose Star Rating (1-5) responses are included in the tile. To include all surveys, select ***All Surveys.

Questions to Include

The Star Rating (1-5) questions within the selected surveys whose star rating responses are included in the tile. To include all questions, select ***All Questions.
