# Delinquency Trend (Dashboard Tile)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Dashboard-Tiles/Delinquency-Trend.htm

The Delinquency Trend dashboard tile displays the total balance of delinquent charges by property from past, current, and/or future tenants across a specified period of time.

 The information on this dashboard tile may be represented in a graph or a list.

 To filter the information that displays in the dashboard tile, click arrow_forward Settings to open the Delinquency Trend Data Filters pop-up. The available filter options are listed below.

 Option
 Description

 Property Filter

 Each property whose units are included in the tile results. To include all current and future properties, select <All Properties> . Alternatively, select a property Group from the drop-down list.

 If <All Properties> is selected, you can also check Include inactive if 'All Properties' selected to calculate averages for all current and future properties whether they are active or inactive.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Period(s)

 The number of months or years (as defined by the Period Category ) to include in the tile results.

 Period Category

 The unit of time to use for the tile results ( Month(s) or Year(s) ).

 As of Day

 The day of the month that the tile uses as a starting point for displaying data. For example, if you enter 1 , the graph displays data as of the first of the month for each period.

 Tenants to Include

 The status of tenants ( Past , Current , and/or Future ) to determine which tenants are included in the results.

 Show Values

 If checked, the delinquency amount in addition to the date display over each point of the Line graph or each bar of the Bar graph.

 Graph Type

 The desired display option.

 Line

 The delinquency trend displays in a line graph.

 If Show Values is checked, the total delinquency amount displays above each point.

 Bar

 The delinquency trend displays in a bar graph.

 If Show Values is checked, the total delinquency amount displays on each bar.

 None

 The date and the delinquency amount displays in columns.

 Ignore dashboard property filter

 If checked, override the property filter configured on the Dashboard .
