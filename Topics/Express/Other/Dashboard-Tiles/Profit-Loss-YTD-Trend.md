# Profit and Loss YTD Trend (Dashboard Tile)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Dashboard-Tiles/Profit-Loss-YTD-Trend.htm

The Profit and Loss YTD Trend dashboard tile displays a comparison of net income on a cash basis by comparing the current year to date with the same date in previous years. This tile can be customized to display net income based on selected properties.

 The information on this dashboard tile may be represented in a graph or a list.

 To filter the information that displays in the dashboard tile, click arrow_forward Settings to open the Profit & Loss YTD Trend Data Filters pop-up. The available filter options are listed below.

 Option
 Description

 Property Filter

 Each property whose units are included in the tile results. To include all current and future properties, select <All Properties> . Alternatively, select a property Group from the drop-down list.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Period(s)

 The number of years in the past, including the current year, to include in the tile results.

 Exclude period adjustments

 If checked, any journal entries that were notated as adjustment entries are excluded from tile results.

 Show Values

 If checked, net income amount in addition to the date display in either the Line or Bar Graph .

 Graph Type

 The desired display option

 Line

 The profit and loss trend in a line graph. The total amount for each year can be viewed by hovering your cursor over each point on the graph.

 If Show Values is checked, the total is rounded to the nearest whole dollar amount and displays above each point.

 Bar

 The profit and loss trend in a bar graph. The total amount for each year can be viewed by hovering your cursor over each bar on the graph.

 If Show Values is checked, the total is rounded to the nearest whole dollar amount and displays on each bar.

 None

 The date, income, expenses, and the net operating income in columns.

 Ignore dashboard property filter

 If checked, override the property filter configured on the Dashboard .

 Axis Descriptions

 The information that displays on each axis in the graph is described below.

 Axis
 Description

 X
(Horizontal)

 The year being examined in a MM/YY format.

 Y
(Vertical)

 The total net income on a cash basis as of the year specified on the horizontal axis.
