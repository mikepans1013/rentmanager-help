# Needs Renewal Offers (Dashboard Tile)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Dashboard-Tiles/Needs-Renewal-Offers.htm

The Needs Renewal Offers dashboard tile alerts to you leases that will be expiring in a set number of days. The dashboard tile contains a color-coded radial bar chart that displays the number of leases expiring within 3 different customizable sets of days. Additionally, you can tell Rent Manager from which properties to pull lease expiration data. You can also create renewal offers by clicking on the tile and working through the Create Renewal Offer page.

 To filter the information that displays in the dashboard tile, click arrow_forward Settings to open the Needs Renewal Offers Data Filters pop-up. The available filter options are listed below.

 Option
 Description

 Property Filter

 The properties whose upcoming lease expirations are included in the tile results. The lease expiration date is the date on which the tenant's lease legally ends, regardless of whether or not they renew the lease or physically vacate the unit. To include all current and future properties, select <All Properties> . Alternatively, select a property Group from the drop-down list.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Ignore dashboard property filter

 If checked, override the property filter configured on the Dashboard .

 Set Leases Expiring Within

 The number of days within which leases are expiring. The lease expiration date is the date on which the tenant's lease legally ends, regardless of whether or not they renew the lease or physically vacate the unit. The radial bar chart allows you to display three sets of days (e.g., 30, 60, and 90) in the chart, and options you can select for each set range from 30 to 180 days.

 Key Description

 The key for the information that displays on color-coded radial bar chart is described below.

 Key
 Description

 Properties

 The name of each property whose upcoming lease expirations are included in the tile results.

 Leases Expiring Within

 The number of days into the future to examine for leases that are ending. The color-coded radial bar chart displays three sets of days (e.g., 30, 60, and 90). Leases set to expire in the fewest number of days (e.g., 30) are coded red in the radial bar chart , leases set to expire in the longest number of days (e.g., 90) are coded green, and the expiring leases that fall in between the two (e.g., 60 days) are coded yellow.
