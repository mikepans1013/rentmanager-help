rmVoIP Extensions Statistics (Dashboard Tile)

The rmVoIP Extensions Statistics dashboard tile allows you to view a list of users' rmVoIP phone service extensions along with associated daily call data.

The information on this dashboard tile is represented in a list.

Related Privileges

Group Privilege Column
Setup Edit own dashboards Enabled
Phone System View rmVoIP Dashboard Tiles Enables

For more information, refer to Control User Access.

Column Descriptions

The information that displays on the tile is organized into the following columns.

Column Description

Extension

The extension and associated user.

Call Count

The number of calls the user has dialed or received today.

Outbound

The number of calls the user has dialed today.

Talk Time

The amount of time the user has been on the phone today in HH:MM:SS (Hours:Minutes:Seconds) format.

Idle Time

The amount of time that has passed since the user was last on the phone today.

Status

Available

The user is not currently on a call.

On the call

The user is currently on a call.
