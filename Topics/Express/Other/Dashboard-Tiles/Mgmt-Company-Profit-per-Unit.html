Mgmt Company Profit per Unit (Dashboard Tile)

The Mgmt Company Profit per Unit dashboard tile allows you to analyze your management company's average earnings for each unit over time. This is done by calculating your net income divided by the total number of occupied and available units.

Units are considered active if they meet all of the following conditions:

  • The unit's property has an active ownership as of the first of the month.

  • The unit's Active box is checked on its details page.

  • The unit has no unit status or has a unit status where either Show As Available and/or Show As Vacant is selected. For more information, refer to Unit Status Types (Page).

The information on this dashboard tile may be represented in a graph or a list.

Filter Information

Related Privileges

Group Privilege Column
Setup Edit dashboard data filters Enabled

For more information, refer to Control User Access.

To filter the information that displays in the dashboard tile, click arrow_forward Settings to open the Mgmt Company Profit per Unit Data Filters pop-up. The available filter options are listed below.

Option Description

Period(s)

The number of months in the past, including the current month, included in the tile results. For example, if you enter 6, the average profit of your units for the current month and each of the previous five months display.

Show Values

If checked, the average profit of your units display over each point of the Line graph or each bar of the Bar graph.

Graph Type

The desired display option.

Line

The total dollar amount of profits display in a line graph.

If Show Values is checked, the average revenue over time displays above each point.

Bar

The total dollar amount of profits display in a bar graph.

If Show Values is checked, the average revenue displays on each bar.

None

The total dollar amount of profits display in columns.

Axis Descriptions

The information that displays on each axis in the graph is described below.

Axis Description

X
(Horizontal)

The month being examined in a MM/YY format.

Y
(Vertical)

The dollar amounts of management company profits as of the month specified on the horizontal axis.

Column Descriptions

The information that displays on the tile is organized into the following columns.

Column Description

Date

The month being examined in a MMM/YYYY format.

Net Income

The total net income for the management company for the according month.

Units

The total number of active units for the month.

Profit/Unit

The profit per unit for the according month using the following calculation:

Profit Per Unit = Net Income / # of Active Units
