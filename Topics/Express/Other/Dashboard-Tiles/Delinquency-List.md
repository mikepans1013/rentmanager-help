# Delinquency List (Dashboard Tile)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Dashboard-Tiles/Delinquency-List.htm

The Delinquency List dashboard tile helps you track tenants who have not yet fully paid open charges on their account. The tenant's name, the unit they are leasing, and the date and amount of their delinquent charges display in the tile.

 The information on this dashboard tile is represented in a list.

 To filter the information that displays in the dashboard tile, click arrow_forward Settings to open the Delinquency List Data Filters pop-up. The available filter options are listed below.

 Option
 Description

 Days to Include

 The number of days old unpaid charges must be to display on the tile. For example, to list only tenants who have open charges that are at least one week old, enter 7 .

 Property Filter

 Each property whose delinquent tenants are included in the tile results. To include all current and future properties, select <All Properties> . Alternatively, select a property Group from the drop-down list.

 If <All Properties> is selected, you can also check Include inactive if 'All properties' selected to calculate averages for all current and future properties whether they are active or inactive.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Tenants to include

 The occupancy status(es) of tenants to include in the tile (i.e., Past , Current , Future ).

 Default Sort Column

 The information used to sort the list of delinquent tenants. Each option is described below.

 Amount (Descending)

 The results are sorted based on the delinquency amount, with the highest amounts owed at the top.

 Date (Oldest First)

 The results are sorted based on the delinquency date, with the oldest charges at the top.

 Name

 The results are sorted alphabetically by tenant name.

 Property

 The results are sorted alphabetically by property name.

 Unit

 The results are sorted alphabetically by unit name.

 Ignore dashboard property filter

 If checked, override the property filter configured on the Dashboard .

 Column Descriptions

 The information that displays on the tile is organized into the following columns.

 Column
 Description

 Name

 The name of the tenant with delinquent charges.

 Property

 The property with which the delinquent charges are associated.

 Unit

 The unit with which the delinquent charges are associated.

 Date

 The date of the tenant's oldest delinquent charge.

 Amount

 The total dollar amount of the delinquent charges owed by the tenant.
