# Expiring Leases (Dashboard Tile)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Dashboard-Tiles/Expiring-Leases.htm

The Expiring Leases dashboard tile displays how many leases expire and how many are renewed each month for the selected number of months for the selected properties. This includes expiring leases that are converted to month-to-month leases.

 The information on this dashboard tile may be represented in a graph or a list.

 To filter the information that displays in the dashboard tile, click arrow_forward Settings to open the Expiring Leases Data Filters pop-up. The available filter options are listed below.

 Option
 Description

 Property Filter

 Each property whose tenants with expiring leases are included in the tile results. To include all current and future properties, select <All Properties> . Alternatively, select a property Group from the drop-down list.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Months

 The number of months in the future, including the current month, included in the tile results. For example, if you enter 6 , the number of leases that expire and are renewed in the current month and each of the next five months display.

 Show Values

 If checked, the total number of expiring and renewed leases display over each point of the Line graph or each bar of the Bar graph.

 Graph Type

 The desired display option.

 Line

 The total number of expiring leases and renewals display in a line graph, with expiring leases in blue and renewals in orange.

 If Show Values is checked, the number of expiring leases and renewals display above each point.

 Bar

 The total number of expiring leases and renewals display in a bar graph, with expiring leases on the left in blue and renewals on the right in orange.

 If Show Values is checked, the number of expiring leases and renewals display on each bar.

 None

 The total number of expiring leases and renewals display in columns. Options in the footer allow you to navigate to different pages of the tile.

 Ignore dashboard property filter

 If checked, override the property filter configured on the Dashboard .

 Axis Descriptions

 The information that displays on each axis in the graph is described below.

 Axis
 Description

 X
(Horizontal)

 The month being examined in a MM/YY format.

 Y
(Vertical)

 The number of leases expiring renewed for the month.

 Column Descriptions

 The information that displays on the tile is organized into the following columns.

 Column
 Description

 Date

 The month being examined in a MM/YY format.

 Expiring Leases

 The number of expiring leases for the month

 Renewals+MTM

 The combined number of renewed and month-to-month leases for the month.

 Difference

 The difference between the number of expiring leases and number of leases renewed.
