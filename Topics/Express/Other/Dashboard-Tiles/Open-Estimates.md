# Open Estimates (Dashboard Tile)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Dashboard-Tiles/Open-Estimates.htm

The Open Estimates dashboard tile helps you track active estimates. This tile can be customized to display the selected estimate statuses and selected properties. You may choose to display owner or tenant estimates or both. Estimates are considered active if the Active option is checked.

 The information on this dashboard tile is represented in a list.

 To filter the information that displays in the dashboard tile, click arrow_forward Settings to open the Open Estimates Data Filters pop-up. The available filter options are listed below.

 Option
 Description

 Ignore dashboard property filter

 If checked, override the property filter configured on the Dashboard .

 Property Filter

 Each property whose units are included in the tile results. To include all current and future properties, select <All Properties> . Alternatively, select a property Group from the drop-down list.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Sales Rep Filter

 The Rent Manager user(s) responsible for creating the charge or selling the associated inventory item to the invoice recipient.

 More Information

 Only users with the option Sales Rep/Leasing Agent checked on their account display in the list. For more information, refer to User Details (Page) .

 Status

 Estimates with the selected status(es) assigned display in the tile results. To include estimates with any or no status assigned, check All Statuses .

 Type

 Estimates with the selected estimate types ( Tenant and/or Owner ) display in the tile results.

 Column Descriptions

 The information that displays on the tile is organized into the following columns.

 Column
 Description

 Date

 The date of the estimate was created in Rent Manager .

 Property

 The property selected on the line items in owner estimates or the From Property on tenant estimates.

 Reference

 The title of this estimate.

 Sales Rep

 The Rent Manager user responsible for creating the charge or selling the associated inventory item to the invoice recipient.

 Status

 The current status assigned on estimate's details page.
