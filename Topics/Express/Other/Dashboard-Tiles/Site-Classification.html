Site Classification (Dashboard Tile)

The Site Classification dashboard tile allows you to view a list of your site classification codes, the number of units associated with the classification code, and the percentage of units in each code based on the total number of units included in the tile as of the current date. Only site classifications with results display.

The information on this dashboard tile is represented in a list.

Related Privileges

Group Privilege Column
Setup Edit own dashboards Enabled

For more information, refer to Control User Access.

Filter Information

Related Privileges

Group Privilege Column
Setup Edit dashboard data filters Enabled

For more information, refer to Control User Access.

To filter the information that displays in the dashboard tile, click arrow_forward Settings to open the Site Classification Data Filters pop-up. The available filter options are listed below.

Option Description

Default Sort Column

The information used to sort the list of classifications. Each option is described below.

Count - Highest

The results are sorted based on the classification with the highest amount of units at the top.

Count - Lowest

The results are sorted based on the classification with the lowest amount of units at the top.

Site Classification

The results are sorted alphabetically by the classification's name.

Ignore dashboard property filter

If checked, override the property filter configured on the Dashboard page.

Properties Filter

Filter the units examined on the dashboard tile based on the selected active properties with the Manufactured Housing property type.

More Information

This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property.

Show unit type breakdown

If checked, results on the tile are separated by unit type. Additionally, the number of units for each unit type assigned to each site classification, followed by a percentage relative to the total unit count, display.

Site Classifications to Include

The site classification(s) of units to include in the tile (e.g., Resident Owned, Employee Owned, Community Owned - Occupied, Lease to Own, and Change of Ownership).

Unit Types to Include

Select to display the desired unit types (e.g., 1B/1B, 2B/2B, and Lot).

Column Descriptions

The information that displays on the tile is organized into the following columns.

Column Description

Name

The name of the site classification code. If Show unit type breakdown is selected on the Site Classification Data Filters pop-up, the site classification code and unit type display.

Percentage

The percentage of units in each code based on the total number of units included in the tile, rounded to the nearest whole number.

Total

The total count of units at the selected properties and unit types assigned to each site classification.
