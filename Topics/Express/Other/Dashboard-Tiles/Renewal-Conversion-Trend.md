# Renewal Conversion Trend (Dashboard Tile)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Dashboard-Tiles/Renewal-Conversion-Trend.htm

The Renewal Conversion Trend dashboard tile evaluates the number of leases that were renewed and that have expired and then calculates and displays the conversion percentages for those leases over the selected time period (i.e., months or years). The total number of lease expirations and renewals for prior months or years are calculated for the entire period, while the current period is calculated up to the current date.

 More Information

 For renewed leases, the conversion percentage is calculated for the month in which the former lease expired regardless of the new lease's start date. Weekly leases are calculated considering each expiration and renewal, and the conversion percentage is calculated for the month in which each former lease expired.

 The information on this dashboard tile may be represented in a graph or a list.

 To filter the information that displays in the dashboard tile, click arrow_forward Settings to open the Renewal Conversion Trend Data Filters pop-up. The available filter options are listed below.

 Option
 Description

 Property Filter

 Each property whose tenant lease renewals and expirations are included in the tile. To include all current and future properties, select <All Properties> . Alternatively, select a property Group from the drop-down list.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Period(s)

 The number of months or years (as defined by the Period Category ) to include in the tile results.

 Period Category

 The unit of time to use for the tile results ( Month(s) , Quarter(s) , Semiannual(s) , or Year(s) ).

 Include MTM Leases

 If checked, month-to-month leases are included in the tile's percentage calculations.

 Show Values

 If checked, the total number of expiring and renewed leases display over each point of the Line graph or each bar of the Bar graph.

 Graph Type

 The desired display option.

 Line

 The conversion rate percentages display in a line graph. The percentages for each period account can be viewed by hovering your cursor over each point on the graph.

 If Show Values is checked, percentages are rounded to the nearest whole number and display above each point.

 Bar

 The conversion rate percentages display in a bar graph. The percentages for each period account can be viewed by hovering your cursor over each bar on the graph.

 If Show Values is checked, percentages are rounded to the nearest whole number and display on each bar.

 None

 The conversion rate percentages and total number of renewals and expirations display in columns. Options in the footer allow you to navigate to different pages of the tile.

 Ignore dashboard property filter

 If checked, override the property filter configured on the Dashboard .

 Axis Descriptions

 The information that displays on each axis in the graph is described below.

 Axis
 Description

 X
(Horizontal)

 The period being examined in a MM/YY format or, if you selected Year(s) as the period category, YYYY format.

 Y
(Vertical)

 The number of lease renewals as of the month specified on the horizontal axis.

 Column Descriptions

 The information that displays on the tile is organized into the following columns.

 Column
 Description

 Date

 The year or month being examined.

 # Renewed

 The number of leases that have been renewed as of the specified period.

 # Expired

 The number of leases that have expired as of the specified period.

 Conversion Rate

 The conversion percentages for the leases as of the specified period.
