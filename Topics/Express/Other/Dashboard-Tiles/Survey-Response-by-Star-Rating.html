Survey Response by Star Rating (Dashboard Tile)

The Survey Response By Star Rating dashboard tile displays tenant responses to survey questions that request a star rating. You can filter this tile to display ratings for specific surveys, survey questions, and the number of stars the tenant responded with. For example, you may want to limit the results to display only survey responses that include low star ratings so you can follow up with tenants to resolve any issues they have.

The information on this dashboard tile is represented in a list.

Filter Information

To filter the information that displays in the dashboard tile, click arrow_forward Settings to open the Survey Responses By Star Rating Data Filters pop-up. The available filter options are listed below.

Option Description

Days to Include

The number of days in the past, including today, that a survey response was submitted to display on the tile. For example, if you enter 7, survey responses submitted within the last week display.

Property Filter

Each property whose tenants' responses are included in the tile. To include all current and future properties, select <All Properties>. Alternatively, select a property Group from the drop-down list.

More Information

This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property.

Ignore dashboard property filter

If checked, override the property filter configured on the Dashboard.

Surveys to Include

The survey(s) whose Star Rating (1-5) responses are included in the tile.

Questions to Include

The Star Rating (1-5) question(s) included in the tile, based on the surveys selected in the Surveys to Include drop-down list. The question's associated survey displays below the question text.

Ratings To Include

The star rating(s) selected by tenants to be included in the tile.

Column Descriptions

The information that displays on the tile is organized into the following columns.

Column Description

Tenant

The name of the tenant who responded to a Star Rating (1-5) question.

Survey

The survey the tenant responded to.

Question

The full Star Rating (1-5) question that received a response.

Rating

The star rating selected by the tenant. Responses that received a 3-star rating or lower display in red, while 4- and 5-star ratings display in yellow.

Response

The date the tenant submitted the survey response.
