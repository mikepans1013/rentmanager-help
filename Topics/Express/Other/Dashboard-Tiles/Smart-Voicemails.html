Smart Voicemails (Dashboard Tile)

The Smart Voicemails dashboard tile helps you monitor voicemails received through Smart Voicemails—powered by Orion AI—so you can review and respond to callers without leaving your dashboard. The tile lists each voicemail's category, caller name, phone number, associated property, and status. Click any voicemail in the tile to open the associated voicemail's details pop-up.

More Information

This feature is licensed and must be purchased separately. For more information, contact your sales representative at sales@rentmanager.com.

The information on this dashboard tile is represented in a list.

For more information, refer to Control User Access and Manage Orion Smart Voicemail Boxes.

For more information, refer to Control User Access.

To filter the information that displays in the dashboard tile, click arrow_forward Settings to open the Smart Voicemails Data Filters pop-up. The available filter options are listed below.

Option Description

Days

Filter the tile to display only voicemails received within the selected number of days.

Statuses

Filter the tile to display only voicemails with the selected status(es).

Voicemail Boxes

Filter the tile to display only voicemails received in the selected voicemail box(es).

Column Descriptions

The information that displays on the tile is organized into the following columns. Voicemails marked as high priority display with .

Column Description

Category

The category assigned to the voicemail (Maintenance, Billing, Other, or Leasing). Orion AI assigns a category automatically when the voicemail is received, but you can change it manually on the voicemail's details pop-up.

Name

The name of the account linked to the voicemail. This column is blank if no account has been linked.

Phone Number

The phone number the voicemail was received from.

Property

The property associated with the account linked to the voicemail. This column is blank if no account has been linked.

Status

The current status of the voicemail (e.g., New, Viewed). Status is set manually by the user, or updates automatically based on the user's actions, for example changing to Viewed when the voicemail is opened.
