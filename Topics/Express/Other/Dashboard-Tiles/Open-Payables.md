# Open Payables (Dashboard Tile)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Dashboard-Tiles/Open-Payables.htm

The Open Payables dashboard tile tracks the dollar amount and due date for open (unpaid or partially paid) bills issued by your vendors. The total amount owed for all bills in the list displays at the bottom of the tile.

 The information on this dashboard tile may be represented in a graph or a list.

 To filter the information that displays in the dashboard tile, click arrow_forward Settings to open the Open Payables Data Filters pop-up. The available filter options are listed below.

 Option
 Description

 Property Filter

 Each selected property's open bills are included in the tile results. To include all current and future properties, select <All Properties> . Alternatively, select a property Group from the drop-down list.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Show Values

 If checked, the total number of property's open bills display over each point of the Line graph or each bar of the Bar graph.

 Graph Type

 The desired display option.

 None

 Each individual bill and the amount owed displays in a list.

 Line

 The total dollar amounts owed to each vendor display in a line graph. Each individual bill that makes up the total can be viewed by hovering your cursor over each point on the graph.

 If Show Values is checked, percentages are rounded to the nearest whole number and display above each point.

 Bar

 The total dollar amounts owed to each vendor display in a bar graph. Each individual bill that makes up the total can be viewed by hovering your cursor over each bar on the graph.

 If Show Values is checked, percentages are rounded to the nearest whole number and display on each bar.

 Ignore dashboard property filter

 If checked, override the property filter configured on the Dashboard page.
