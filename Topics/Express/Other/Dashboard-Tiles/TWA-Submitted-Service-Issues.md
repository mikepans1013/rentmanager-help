# TWA Submitted Service Issue (Dashboard Tile)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Dashboard-Tiles/TWA-Submitted-Service-Issues.htm

The TWA Submitted Service Issues dashboard tile helps you track open issues that are submitted by tenants through Tenant Web Access (TWA) . The date that the issue was opened, the tenant's name, the unit they are leasing, and optionally, the issue's title display in the tile.

 The information on this dashboard tile is represented in a list.

 To filter the information that displays in the dashboard tile, click arrow_forward Settings to open the TWA Submitted Service Issues Data Filters pop-up. The available filter options are listed below.

 Option
 Description

 Property Filter

 Each properties' Tenant Web Access (TWA) submitted issues display in the tiles results. To include all current and future properties, select <All Properties> . Alternatively, select a property Group from the drop-down list.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Show issue description

 Determines if the service issue title displays in the dashboard tile results.

 Ignore dashboard property filter

 If checked, override the property filter configured on the Dashboard .

 Column Descriptions

 The information that displays on the tile is organized into the following columns.

 Column
 Description

 Description

 The title entered for the issue in Tenant Web Access (TWA) .

 Date

 The date that the issue was opened via Tenant Web Access (TWA) .

 Tenant

 The name of the tenant that submitted the issue.

 Unit

 The unit currently leased by the tenant that submitted the issue.
