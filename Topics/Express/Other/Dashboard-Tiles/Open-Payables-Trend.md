# Open Payables Trend (Dashboard Tile)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Dashboard-Tiles/Open-Payables-Trend.htm

The Open Payables Trend dashboard tile displays the total balance of open (unpaid or partially paid) bills for a selected period of months or years.

 The information on this dashboard tile may be represented in a graph or a list.

 To filter the information that displays in the dashboard tile, click arrow_forward Settings to open the Open Payables Trend Data Filters pop-up. The available filter options are listed below.

 Option
 Description

 Property Filter

 Each selected property's open bills are included in the tile results. To include all current and future properties, select <All Properties> . Alternatively, select a property Group from the drop-down list.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Period(s)

 The number of years or months to examine, depending on your selection in the Period Category field.

 Period Category

 The unit of time to use for the tile results ( Month(s) or Year(s) ).

 As Of Day

 The day of the month or year which the tile examines for open payables to determine the dollar value owed for that period.

 Show Values

 If checked, the total number of property's open bills display over each point of the Line graph or each bar of the Bar graph.

 Graph Type

 The desired display option.

 Line

 The dollar amounts owed for each period display in a line graph. The dollar owed can be viewed by hovering your cursor over each point on the graph.

 If Show Values is checked, percentages are rounded to the nearest whole number and display above each point.

 Bar

 The dollar amounts owed to each period display in a bar graph. The amount owed can be viewed by hovering your cursor over each point on the graph.

 If Show Values is checked, percentages are rounded to the nearest whole number and display on each bar.

 None

 The dollar amount owed for each period displays in a list.

 Ignore dashboard property filter

 If checked, override the property filter configured on the Dashboard page.

 Axis Descriptions

 The information that displays on each axis in the graph is described below.

 Axis
 Description

 X
(Horizontal)

 The period being examined (in months or years) in MM/YY format.

 Y
(Vertical)

 The total dollar amount owed from all open bills during the period.
