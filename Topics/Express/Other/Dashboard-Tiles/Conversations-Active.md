# Conversations - Active (Dashboard Tile)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Dashboard-Tiles/Conversations-Active.htm

The Conversations - Active dashboard tile allows you to view ongoing Web Chats. The Conversations - Active tile can be customized so that it displays chats in queues assigned to selected users. In addition, you can choose to view the statistics of the chats or instead have them displayed in a line or bar graph.

 The information on this dashboard tile may be represented in a graph or a list.

 To filter the information that displays in the dashboard tile, click arrow_forward Settings to open the Conversations-Active Data Filters pop-up. The available filter options are listed below.

 Option
 Description

 Queue Filter

 Each queue to display in the tile results. To include all current queues, select All Queues .

 More Information

 Only queues you have access to display. For more information, refer to Manage Queues (Web Chat) (Page) .

 Agent Filter

 Each agent to displays in the tile results. To include all agents, select All Agents .

 Show Values

 If checked, the tile's rounded averages display along the bottom of each point of the Line graph or each bar of the Bar graph.

 Graph Type

 The desired display option.

 Line

 The number of active conversations per queue display in a line graph.

 If Show Values is checked, the number of active conversations display above each point.

 Bar

 The number of active conversations per queue display in a bar graph.

 If Show Values is checked, the number of active conversations display on each bar.

 None

 The data displays in a register with queue, message, duration, and user in columns.

 Axis Descriptions

 The information that displays on each axis in the graph is described below.

 Axis
 Description

 X
(Horizontal)

 Y
(Vertical)

 Column Descriptions

 The information that displays on the tile is organized into the following columns.

 Column
 Description

 Queue

 The name of the chat queue.

 Message

 The chat message sent by the Tenant Web Access (TWA) account holder.

 Duration

 The amount of time elapsed since the chat message was initiated.

 User

 The agent logged into the queue actively chatting with the user.
