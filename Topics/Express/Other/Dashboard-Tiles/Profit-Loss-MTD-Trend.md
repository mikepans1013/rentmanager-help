# Profit and Loss MTD Trend (Dashboard Tile)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Dashboard-Tiles/Profit-Loss-MTD-Trend.htm

The Profit and Loss MTD Trend dashboard tile displays a comparison of net income, either comparing the current month and months preceding or by comparing the current month with the same month in previous years. This tile can be customized to display the net income numbers or have the balances displayed in a line or bar graph.

 The information on this dashboard tile may be represented in a graph or a list.

 To filter the information that displays in the dashboard tile, click arrow_forward Settings to open the Profit & Loss MTD Trend Data Filters pop-up. The available filter options are listed below.

 Option
 Description

 Property Filter

 Each property whose units are included in the tile results. To include all current and future properties, select <All Properties> . Alternatively, select a property Group from the drop-down list.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Period(s)

 The number of months or years (as defined by the Period Category ) to include in the tile results.

 Period Category

 The unit of time to use for the tile results ( Month(s) or Year(s) ).

 Exclude period adjustments

 If checked, any journal entries that were notated as adjustment entries are excluded from tile results.

 Show Values

 If checked, net income amount in addition to the date display in either the Line or Bar Graph .

 Graph Type

 The desired display option.

 Line

 The net income in a line graph. The total amount for each period can be viewed by hovering your cursor over each point on the graph.

 If Show Values is checked, the total amount is rounded to the nearest whole number and display above each point.

 Bar

 The net income in a bar graph. The total amount for each period can be viewed by hovering your cursor over each bar on the graph.

 If Show Values is checked, the total amount is rounded to the nearest whole number and display on each bar.

 None

 The date and the net income in columns.

 Ignore dashboard property filter

 If checked, override the property filter configured on the Dashboard .
