Expiring Owner Contracts (Dashboard Tile)

The Expiring Owner Contracts dashboard tile displays owners with contracts that have a contract end date within a specified number of days. This allows you to track which ownerships are ending soon. Owner contract information for each property is located on the property's details page from the action bar by clicking arrow_forward Owners.

The information on this dashboard tile is represented in a list.

Filter Information

Related Privileges

Group Privilege Column
Setup Edit dashboard data filters Enabled

For more information, refer to Control User Access.

To filter the information that displays in the dashboard tile, click  arrow_forwardSettings to open the Expiring Owner Contracts Data Filters pop-up. The available filter options are listed below.

Option Description

Days to Include

The number of days to examine for contract end dates and display those owners on the tile. For example, to list only owners with a contract end date in the next thirty days, enter 30.

Property Filter

Each property's owners who are included in the tile results. To include all current and future properties, select <All Properties>. Alternatively, select a property Group from the drop-down list.

If <All Properties> is selected, you can also check Include inactive if 'All properties' selected to calculate averages for all current and future properties whether they are active or inactive.

More Information

This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property.

Ignore dashboard property filter

If checked, override the property filter configured on the Dashboard page.

Column Descriptions

The information that displays on the tile is organized into the following columns.

Column Description

Owner

The Name of the owner with an expiring contract.

Property

The Short Name of the property for which the owner's contract is expiring.

Contract End

The date on which the owner's contract is ending for the property.
