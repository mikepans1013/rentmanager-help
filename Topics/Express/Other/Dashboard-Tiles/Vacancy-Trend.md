# Vacancy Trend (Dashboard Tile)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Dashboard-Tiles/Vacancy-Trend.htm

The Vacancy Trend dashboard tile displays units from selected properties as of the selected date that are vacant. This includes vacant units that are reserved for a prospect with a future move-in date and units with a unit status type that has the option Show As Vacant enabled.

 The information on this dashboard tile may be represented in a graph or a list.

 To filter the information that displays in the dashboard tile, click arrow_forward Settings to open the Vacancy Trend Data Filters pop-up. The available filter options are listed below.

 Option
 Description

 Property Filter

 Each properties' vacant units are included in the tile results. To include all current and future properties, select <All Properties> . Alternatively, select a property Group from the drop-down list.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Period(s)

 The number of months or years (as defined by the Period Category ) to include in the tile results.

 Period Category

 The unit of time to use for the tile results ( Month(s) or Year(s) ).

 As Of Day

 The day of the month that the tile uses as a starting point for displaying data. For example, if you enter 1 , the graph displays data as of the first of the month for each period.

 Show Values

 If checked, displays the tile's vacancy totals above the dates along the bottom of either the Line or Bar Graph Type .

 Graph Type

 The desired display option.

 Line

 The vacancy trend in a line graph. The number for each date can be viewed by hovering your cursor over each point on the graph.

 If Show Values is checked, the number of vacant units display above each point.

 Bar

 The vacancy trend in a bar graph. The number for each date can be viewed by hovering your cursor over each bar on the graph.

 If Show Values is checked, the number of vacant units display on each bar.

 None

 The date and the vacancy totals in columns.

 Ignore dashboard property filter

 If checked, override the property filter configured on the Dashboard .
