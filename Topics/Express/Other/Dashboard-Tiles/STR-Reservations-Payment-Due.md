# STR Reservations Payment Due (Dashboard Tile)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Dashboard-Tiles/STR-Reservations-Payment-Due.htm

The STR Reservations Payment Due dashboard tile displays unpaid charges for short term rental (STR) reservations for tenants and prospects. This tile can be filtered to include STR reservation payments based on how many days in the future the payment is due, while overdue payments are always displayed.

 The information on this dashboard tile is represented in a list.

 To filter the information that displays in the dashboard tile, click arrow_forward Settings to open the STR Reservations Payment Due Data Filters pop-up. The available filter options are listed below.

 Option
 Description

 Days to Include

 The number of days until the STR reservation payment is due. If the payment due date has passed, this column displays Past Due .

 Property Filter

 Each RV/Campground or Short Term Rental type property whose units are included in the tile results. To include all current and future properties, select <All Properties> . Alternatively, select a property Group from the drop-down list.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Ignore dashboard property filter

 If checked, override the property filter configured on the Dashboard .

 Column Descriptions

 The information that displays on the tile is organized into the following columns.

 Option
 Description

 Days Due

 The number of days until the STR reservation payment is due. If the payment due date has passed, this column displays Past Due .

 Balance

 The dollar amount of the account's unpaid STR reservation charge(s).

 Name

 The name of the tenant or prospect who owes the balance.

 Property

 The STR property associated with the unit for which the tenant or prospect owes a balance.

 Unit

 The unit for which the tenant or prospect owes a balance.
