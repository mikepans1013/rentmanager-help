# Open Billable Expenses (Dashboard Tile)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Dashboard-Tiles/Open-Billable-Expenses.htm

The Open Billable Expenses dashboard tile displays billable expenses for which you have not yet created invoices. If a line item on an expense is marked as billable, it is not considered billed back in Rent Manager until associated invoices are created.

 The information on this dashboard tile is represented in a list.

 Column Descriptions

 The information that displays on the tile is organized into the following columns.

 Column
 Description

 Date

 The date that the bill or check was issued.

 Type

 The type of expense, either a Bill or Check .

 Billable To

 The tenant or owner to whom the expense was billed.

 Amount

 The dollar amount of the expense that is owed.
