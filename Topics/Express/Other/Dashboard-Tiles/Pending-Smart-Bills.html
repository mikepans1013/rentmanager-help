Pending Smart Bills (Dashboard Tile)

The Pending Smart Bills dashboard tile allows you to view a list of Smart Bills ready for review on the Smart Bills page. Rent Manager's Smart Bills feature allows you to streamline your invoice management process. With this feature, you can easily upload invoices via a PDF or image format, allowing AI to extract the relevant data and create draft transactions automatically.

The information on this dashboard tile is represented in a list.

Related Privileges

Group Privilege Column
Setup Edit own dashboards Enabled
Payables Smart Bills View

For more information, refer to Control User Access.

Option Description

Inboxes to Include

Column Descriptions

The information that displays on the tile is organized into the following columns.

Column Description

Vendor

The vendor name that was found when uploading the invoice.

Uploaded Date and Time

The date and time the bill was added to Smart Bills page.

Amount

The dollar amount owed that was found when uploading the invoice.
