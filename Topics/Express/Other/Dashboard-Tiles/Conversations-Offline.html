Conversations - Offline (Dashboard Tile)

The Conversation - Offline dashboard tile allows you to view Web Chats which were received from Tenant Web Access (TWA) users when no Rent Manager users were logged into a Web Chat queue. This tile can be customized so that it displays chats in queues assigned to selected users or the total number of chats for each queue.

More Information

In order to utilize this dashboard tile, you must have the Web Chat feature licensed and enabled in Rent Manager. For more information, refer to Set Up Web Chat or contact sales@rentmanager.com.

The information on this dashboard tile may be represented in a graph or a list.

Related Privileges

Group Privilege Column
Setup Edit own dashboards Enabled
Web Chat Queues View

For more information, refer to Control User Access.

Filter Information

Related Privileges

Group Privilege Column
Setup Edit dashboard data filters Enabled

For more information, refer to Control User Access.

To filter the information that displays in the dashboard tile, click arrow_forward Settings to open the Conversations - Offline Data Filters pop-up. The available filter options are listed below.

Option Description

Queue Filter

Each Web Chat queue whose offline conversations are included in the tile. To include all current and future queues, select All Queues.

More Information

Only queues you have access to display. For more information, refer to Manage Queues (Web Chat) (Page).

Show Values

If checked, the total number of offline conversations for each Web Chat queue display over each point of the Line graph or each bar of the Bar graph.

Graph Type

The desired display option.

Line

The number of offline conversations per queue display in a line graph.

If Show Values is checked, the total number of conversations for the queue display above each point.

Bar

The number of offline conversations per queue display in a bar graph.

If Show Values is checked, the total number of conversations for the queue display on each bar.

None

The associated Web Chat queue and contents of each offline conversation display in columns. Options in the footer allow you to navigate to different pages of the tile.

Column Descriptions

The information that displays on the tile is organized into the following columns.

Column Description

Queue

The name of the Web Chat queue.

Message

The chat message sent by the Tenant Web Access (TWA) account holder.

Date

The date the chat message was initiated.

Axis Descriptions

The information that displays on each axis in the graph is described below.

Axis Description

X
(Horizontal)

The name of the Web Chat queue.

Y
(Vertical)

The total number of offline conversations.
