Move In/Move Out By Property (Dashboard Tile)

The Move In/Move Out By Property dashboard tile helps you track scheduled or expected move ins and move outs, indicated on the tenant's details page and occurring within a specified number of days. This tile is organized by property and allows you to see the total move ins and move outs per property and totals for all your properties as well.

The information on this dashboard tile is represented in a list.

Related Privileges

Group Privilege Column
Setup Edit own dashboards Enabled

For more information, refer to Control User Access.

Filter Information

Related Privileges

Group Privilege Column
Setup Edit dashboard data filters Enabled

For more information, refer to Control User Access.

To filter the information that displays in the dashboard tile, click arrow_forwardSettings to open the Move In / Move Out By Property Data Filters pop-up. The available filter options are listed below.

Option Description

Days to Include

The number of days, including the current day, into the future included in the tile results. For example, if you enter 6, any delinquent amounts with a due date older than six days, including the current day, displays in the tile.

Property Filter

Each property whose units are included in the tile results. To include all current and future properties, select <All Properties>. Alternatively, select a property Group from the drop-down list.

More Information

This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property.

Include Reserved Move Ins

If checked, prospects who have a future Move In date listed in the Reserved Unit section of the unit's preferences display in tile results.

Include Expected Move Outs

If checked, tenants who have a future Expected MO date listed on the tenant's account display in tile results.

Default Sort Columns

To sort the tile by a specific result, select the column name from the drop-down list.

Property

Results are arranged in alphabetical order based on the name of the property.

MI Count

Results are arranged in descending numerical order based on the number of move ins.

MO Count

Results are arranged in descending numerical order based on the number of move outs.

Ignore dashboard property filter

If checked, override the property filter configured on the Dashboard.

Column Descriptions

The information that displays on the tile is organized into the following columns.

Column Description

Property

The name of the property as entered on the property's details page.

MI Count

The number of scheduled move ins at each property.

MO Count

The number of expected move outs at each property.
