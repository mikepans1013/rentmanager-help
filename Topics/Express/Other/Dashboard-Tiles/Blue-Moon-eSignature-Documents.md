# Blue Moon eSignature Documents (Dashboard Tile)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Dashboard-Tiles/Blue-Moon-eSignature-Documents.htm

The Blue Moon eSignature Documents dashboard tile allows you to track the progress of Blue Moon lease forms with a requested eSignature. From this tile, you can view the name, property, unit, and status of Blue Moon eSignature documents.

 More Information

 In order to use Blue Moon to generate leasing documents and create leases, you must first purchase a license(s) from the NAA , then enable and configure your Blue Moon integration. For more information, refer to Set Up Blue Moon .

 To filter the information that displays in the dashboard tile, click arrow_forward Settings to open the Blue Moon eSignature Documents Data Filters pop-up. The available filter options are listed below.

 Option
 Description

 Days to Include

 The number of days into the future for which the dashboard tile should display eSignature leasing documents based on their Date Initiated .

 Ignore dashboard property filter

 If checked, override the property filter configured on the Dashboard .

 Property Filter

 Each property whose tenants are included in the tile results. To include all current and future properties, select <All Properties> . Alternatively, select a property Group from the drop-down list.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Statuses to Include

 The status(es) of a Blue Moon eSignature document ( Pending , In Progress , Signed , Completed , Expired ) to include in the tile results.

 Column Descriptions

 The information that displays on the tile is organized into the following columns.

 Column
 Description

 Name

 The name of Resident 1 in the Blue Moon document that was sent out with an eSignature request.

 Property

 The abbreviated short name of the property associated with the unit.

 Status

 The current status of the document: Pending , In Progress , Signed , Completed , Expired .

 Unit

 The name of the unit associated with the Blue Moon lease.
