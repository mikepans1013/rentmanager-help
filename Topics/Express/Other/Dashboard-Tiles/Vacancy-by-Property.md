# Vacancy by Property (Dashboard Tile)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Dashboard-Tiles/Vacancy-by-Property.htm

The Vacancy By Property dashboard tile tracks the number of vacant units, including those with unit status types set to Show As Vacant , at the selected properties.

 The information on this dashboard tile is represented in a list.

 To filter the information that displays in the dashboard tile, click arrow_forward Settings to open the Vacancy by Property Data Filters pop-up. The available filter options are listed below.

 Option
 Description

 Property Filter

 Each properties' vacant units are included in the tile results. To include all current and future properties, select <All Properties> . Alternatively, select a property Group from the drop-down list.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Ignore dashboard property filter

 If checked, override the property filter configured on the Dashboard .

 Exclude pre-leased Units

 Units that are reserved for prospects but they have not yet moved in are excluded from tile results.

 Column Descriptions

 The information that displays on the tile is organized into the following columns.

 Column
 Description

 Property

 The full name of the property.

 Vacant Units

 The total number of vacant units at the property as of today.

 Total Units

 The total number of units at the property.

 Vacant

 The percentage of vacant units at the property.
