Upcoming Amenity Reservation Requests (Dashboard Tile)

The Upcoming Amenity Reservation Requests dashboard tile helps you track amenity reservations your tenants have requested to rent, such as a clubhouse. The date and time of the reservation request, name, and the status of the reservable amenity display. Any reservations with an asterisk (*) indicate that there are charges associated with the reservation that have not yet been paid by the tenant.

The information on this dashboard tile is represented in a list.

Related Privileges

Group Privilege Column
Setup Edit own dashboards Enabled

For more information, refer to Control User Access.

Filter Information

Related Privileges

Group Privilege Column
Setup Edit dashboard data filters Enabled

For more information, refer to Control User Access.

To filter the information that displays in the dashboard tile, click arrow_forward Settings to open the Upcoming Amenity Reservation Request Data Filters pop-up. The available filter options are listed below.

Option Description

Ignore dashboard property filter

If checked, override the property filter configured on the Dashboard.

Include items in the next X days

Enter a value to display upcoming requests that are scheduled up to X days in the future. For example, if you enter 30, then the tile includes reservations that are scheduled in the next thirty days.

Only include unpaid requests

If checked, only reservation requests with charges that have not yet been paid by the tenant display.

Property Filter

Each property with upcoming requests is included in the tile. To include all current and future properties, select <All Properties>. Alternatively, select a property Group from the drop-down list.

More Information

This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property.

Statuses to include

The desired amenity reservation request status (Pending or Approved) to include in the tile results. Optionally, select Both to display pending and approved requests.

Column Descriptions

The information that displays on the tile is organized into the following columns.

Column Description

Amenity

The name of the reservable amenity associated with the reservation request.

Date

The date of the reservation request.

Status

The status of the reservation (Pending, Approved, Denied, Canceled).

Time

The start and end time of the reservation request.
