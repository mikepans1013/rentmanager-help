# Recently Completed Inspections (Dashboard Tile)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Dashboard-Tiles/Recently-Completed-Inspections.htm

The Recently Completed Inspections dashboard tile helps you track inspections that took place at selected properties and that were closed within a set number of days.

 The information on this dashboard tile is represented in a list.

 To filter the information that displays in the dashboard tile, click arrow_forward Settings to open the Recently Completed Inspections Data Filters pop-up. The available filter options are listed below.

 Option
 Description

 Days to Include

 The number of days in the past, including today, that an inspection was completed to display on the tile. For example, if you enter 30 , inspections with a Status of Closed and an Inspection Date within the last 30 days display.

 Property Filter

 Each property whose units are included in the tile results. To include all current and future properties, select <All Properties> . Alternatively, select a property Group from the drop-down list.

 If <All Properties> is selected, you can also check Include inactive if 'All Properties' selected to calculate averages for all current and future properties whether they are active or inactive.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Inspectors

 Each user whose open inspections you would like to view in the tile results. To include inspections that are assigned to every user who has Inspector selected on the Manage Users window's General tab, select All Inspectors .

 More Information

 On the General tab of the Manage Users window, if you have Inspector selected, then this tile is filtered to include only inspections assigned to you by default. If you do not have Inspector selected, then this tile does not display any results until you select an inspector from the Inspectors drop-down list.

 Ignore dashboard property filter

 If checked, override the property filter configured on the Dashboard .

 Column Descriptions

 The information that displays on the tile is organized into the following columns.

 Column
 Description

 Date

 The date specified on the inspection's details in the Inspection Date field.

 Property

 The property Short Name of the property at which the inspection took place.

 Unit

 The name of the unit at which the inspection took place, if applicable.

 Inspector

 The name of the user who performed the inspection.
