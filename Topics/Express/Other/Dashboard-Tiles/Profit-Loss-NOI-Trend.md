# Proft and Loss NOI Trend (Dashboard Tile)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Dashboard-Tiles/Profit-Loss-NOI-Trend.htm

The Profit and Loss NOI Trend dashboard tile displays total income, total expenses, and net operating income for the current month and the twelve previous months. This tile can be customized to display net operating income based on selected properties.

 The information on this dashboard tile may be represented in a graph or a list.

 To filter the information that displays in the dashboard tile, click arrow_forward Settings to open the Profit & Loss NOI Trend Data Filters pop-up. The available filter options are listed below.

 Option
 Description

 Property Filter

 Each property whose units are included in the tile results. To include all current and future properties, select <All Properties> . Alternatively, select a property Group from the drop-down list.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Period(s)

 The number of months or years (as defined by the Period Category ) to include in the tile results.

 Period Category

 The unit of time to use for the tile results ( Month(s) or Year(s) ).

 Exclude period adjustments

 If checked, any journal entries that were notated as adjustment entries are excluded from tile results.

 Graph Type

 The desired display option

 Line

 The profit and loss trend in a line graph. The total amount for each period can be viewed by hovering your cursor over each point on the graph.

 Bar

 The profit and loss trend in a bar graph. The total amount for each period can be viewed by hovering your cursor over each bar on the graph.

 None

 The date, income, expenses, and the net operating income in columns.

 Ignore dashboard property filter

 If checked, override the property filter configured on the Dashboard .

 Axis Descriptions

 The information that displays on each axis in the graph is described below.

 Axis
 Description

 X
(Horizontal)

 The month being examined in a MMM/YYYY format or, if you selected Year(s) as the period category, YYYY format.

 Y
(Vertical)

 The total income, expenses, and net operating income (NOI) as of the specified periods.

 Column Descriptions

 The information that displays on the tile is organized into the following columns.

 Column
 Description

 Date

 The period being examined.

 Income

 The total income as of the specified period.

 Expenses

 The total expenses as of the specified period.

 NOI

 The total net operating income (NOI) as of the specified period.
