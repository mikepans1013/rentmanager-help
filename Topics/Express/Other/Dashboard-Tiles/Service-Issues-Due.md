# Service Issues Due (Dashboard Tile)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Dashboard-Tiles/Service-Issues-Due.htm

The Service Issues Due dashboard tile helps you track outstanding service issues. The issue's name, number, and the date on which the service issue is due displays.

 The information on this dashboard tile is represented in a list.

 To filter the information that displays in the dashboard tile, click arrow_forward Settings to open the Service Issues Due Data Filters pop-up. The available filter options are listed below.

 Option
 Description

 Days to Include

 The number of days in the future an issue can be due to display on the tile. For example, to list issues that are due in at least one week, enter 7 .

 Property Filter

 Each property whose units are included in the tile results. To include all current and future properties, select <All Properties> . Alternatively, select a property Group from the drop-down list.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Users

 Each issue assigned to a user are included in the tile results. To include all current and future users, select <All Users> .

 Exclude issues due more than X days ago

 The number of days in the past that issues are included in the tile results, based on the issue's Due Date . For example, if you enter 21 , issues display only if their Due Date is less than three weeks prior to the current date.

 Ignore dashboard property filter

 If checked, override the property filter configured on the Dashboard .
