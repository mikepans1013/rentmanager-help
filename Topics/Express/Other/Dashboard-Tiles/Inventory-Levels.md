# Inventory Levels (Dashboard Tile)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Dashboard-Tiles/Inventory-Levels.htm

The Inventory Levels dashboard tile helps you track how many inventory items you have on hand. The item name and the quantity of the item displays. By default, items due for reorder display with a blue dot, in stock items display with a green dot, and items with no units in stock display with a red dot.

 More Information

 Only inventory items with Track Inventory checked in the Inventory section of the inventory item details page displays in this dashboard tile.

 The information on this dashboard tile may be represented in a graph or a list.

 To filter the information that displays in the dashboard tile, click arrow_forward Settings to open the Inventory Levels Data Filters pop-up. The available filter options are listed below.

 Option
 Description

 Quantity Status

 The status of an inventory item's quantity ( In Stock , Reorder , or No Qty ) to include in the tile results.

 Show Values

 If checked, the tile's inventory levels display along the bottom of the Bar Graph Type .

 Graph Type

 The desired display option.

 Bar

 The quantity of inventory items displays in a bar graph.

 If Show Values is checked, the quantity displays on each bar.

 None

 The quantity of inventory items displays in columns. Options in the footer allow you to navigate to different pages of the tile.
