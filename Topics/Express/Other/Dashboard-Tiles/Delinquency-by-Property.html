Delinquency By Property (Dashboard Tile)

The Delinquency By Property dashboard tile displays open amounts that are not paid in full on tenant accounts. This tile is organized by property and allowis you to see the total count of delinquent transactions, the total amount of payments due per property, and totals for all your properties.

The information on this dashboard tile is represented in a list.

Related Privileges

Group Privilege Column
Setup Edit own dashboards Enabled

For more information, refer to Control User Access.

Filter Information

Related Privileges

Group Privilege Column
Setup Edit dashboard data filters Enabled

For more information, refer to Control User Access.

To filter the information that displays in the dashboard tile, click arrow_forwardSettings to open the Delinquency By Property Data Filters pop-up. The available filter options are listed below.

Option Description

Days to Include

The number of days, including the current day, into the future included in the tile results. For example, if you enter 6, any delinquent amounts with a due date older than six days, including the current day, displays in the tile.

Property Filter

Each property whose units are included in the tile results. To include all current and future properties, select <All Properties>. Alternatively, select a property Group from the drop-down list.

More Information

This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property.

Tenants to Include

The status of tenants (Past, Current, and/or Future) to determine which tenants are included in the results.

Default Sort Columns

To sort the tile by a specific result, select the column name from the drop-down list.

Property

Results are arranged in alphabetical order based on the name of the property.

Count

Results are arranged in descending numerical order based on the number of open transactions.

Amount

Results are arranged in descending numerical order based on the amount of open transactions.

Ignore dashboard property filter

If checked, override the property filter configured on the Dashboard.

Column Descriptions

The information that displays on the tile is organized into the following columns.

Column Description

Property

The name of the property as entered on the property's details page.

Count

The total of each open transaction due on tenant accounts who have a lease at the property.

Amount

The total amount of all open transactions due on tenant accounts that have a lease at the property.
