# Follow-Up (Dashboard Tile)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Dashboard-Tiles/Follow-Up.htm

The Follow-Ups dashboard tile lets you view history/notes items you created that have been assigned a Follow-up Date . The Follow-up tile can be customized so that it displays history/notes with a Follow-up Date within a selected future date range. Clicking on any item in the Note column opens the History/Notes page of the entity on which the note was entered.

 The information on this dashboard tile is represented in a list.

 To filter the information that displays in the dashboard tile, click arrow_forward Settings to open the Follow-Up Data Filters pop-up. The available filter options are listed below.

 Option
 Description

 Days to Include

 The desired value to determine how many days in the future from today's date to include upcoming history/notes based on their Follow-up Date . For example, if you enter 6 , history/notes with a Follow-up Date of today and each of the next five days display.
