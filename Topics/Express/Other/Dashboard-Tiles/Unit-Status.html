Unit Status (Dashboard Tile)

The Unit Status dashboard tile helps you track the unit status assigned to unoccupied units to monitor their condition. This tile can be customized to view the number of units with active unit statuses or have the unit statuses displayed in a line or bar graph.

The information on this dashboard tile may be represented in a graph or a list.

Related Privileges

Group Privilege Column
Setup Edit own dashboards Enabled
Properties/Units Unit statuses Add

To view this tile in system dashboards, you must be listed as an assigned user for the system dashboard that includes this tile.

For more information, refer to Control User Access.

Filter Information

Related Privileges

Group Privilege Column
Setup Edit dashboard data filters Enabled

For more information, refer to Control User Access.

To filter the information that displays in the dashboard tile, click arrow_forward Settings to open the Unit Status Data Filters pop-up. The available filter options are listed below.

Option Description

Property Filter

Each property whose units are included in the tile results. To include all current and future properties, select <All Properties>. Alternatively, select a property Group from the drop-down list.

More Information

This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property.

Show Values

If checked, the tile's values display above the statuses along the bottom of either the Line or Bar Graph Type.

Graph Type

The desired display option.

Line

The unit status and their respective number of units in a line graph. Number of units can be revealed by hovering your cursor over each point on the graph.

If Show Values is checked, the number of units with the status applied displays above each point.

Bar

The unit status and their respective number of units in a bar graph. Number of units can be revealed by hovering your cursor over each bar on the graph.

If Show Values is checked, the number of units with the status applied displays on each bar.

None

The property, unit, and status in columns.

Ignore dashboard property filter

If checked, override the property filter configured on the Dashboard.

Axis Descriptions

The information that displays on each axis in the graph is described below.

Axis Description

X
(Horizontal)

The applied unit status.

Y
(Vertical)

The number of units the dashboard tile is evaluating.

Column Descriptions

The information that displays on the tile is organized into the following columns.

Column Description

Property

The property short name associated with the unit.

Unit

The name of the unit as entered on the unit's details page.

Status

The active unit status as entered on the unit's details page.
