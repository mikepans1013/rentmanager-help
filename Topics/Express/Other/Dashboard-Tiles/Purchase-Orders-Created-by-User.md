# Purchase Orders Created by User (Dashboard Tile)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Dashboard-Tiles/Purchase-Orders-Created-by-User.htm

This dashboard tile helps you track purchase orders that you have created.

 To view this tile in system dashboards, you must be listed as an assigned user for the system dashboard that includes this tile.

 For more information, refer to Control User Access .

 Column Descriptions

 The information that displays on the tile is organized into the following columns.

 Column
 Description

 PO #

 The internally-generated number, as specified in the purchase order's P.O.# field.

 Description

 A brief summary about the order, as entered in the purchase order's Description field.

 Status

 The status ( Pending , Approved , Fulfilled , or Rejected ) of the purchase order.
