Pending Architectural Requests (Dashboard Tile)

The Pending Architectural Requests dashboard tile helps you track architectural requests, such as repainting buildings or planting trees, that are submitted by tenants at properties with the Property Type of Association.

The information on this dashboard tile is represented in a list.

Related Privileges

Group Privilege Column
Setup Edit own dashboards Enabled
Associations Manage Architectural Requests Enabled

To view this tile in system dashboards, you must be listed as an assigned user for the system dashboard that includes this tile.

For more information, refer to Control User Access.

Filter Information

Related Privileges

Group Privilege Column
Setup Edit dashboard data filters Enabled

For more information, refer to Control User Access.

To filter the information that displays in the dashboard tile, click arrow_forward Settings to open the Pending Architectural Requests Data Filters pop-up. The available filter options are listed below.

Option Description

Property Filter

Each property whose architectural requests are included in the tile results. To include all current and future properties, select <All Properties>. Alternatively, select a property Group from the drop-down list.

If <All Properties> is selected, you can also check Include inactive if 'All Properties' selected to include architectural requests from any property, whether they are active or inactive.

More Information

This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property.

Include inactive if 'All Properties' selected

If checked, architectural requests from both active and inactive properties display only when the Property Filter selection is set to <All Properties>.

Ignore dashboard property filter

If checked, override the property filter configured on the Dashboard.

Column Descriptions

The information that displays on the tile is organized into the following columns.

Column Description

Submitted

The date the architectural request was submitted in a MM/DD/YYYY format.

Submitted By

The name of the tenant who submitted the request.

Request

The subject of the request.
