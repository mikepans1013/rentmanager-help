# Security Deposit Refunds Due (Dashboard Tile)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Dashboard-Tiles/Security-Deposit-Refunds-Due.htm

The Security Deposit Refunds Due dashboard tile helps you track outstanding security deposits. The tenant's name, the property and unit they vacated, the move out date, and the amount of security deposit being held display.

 The information on this dashboard tile is represented in a list.

 To filter the information that displays in the dashboard tile, click arrow_forward Settings to open the Security Deposit Refunds Due Data Filters pop-up. The available filter options are listed below.

 Option
 Description

 Property Filter

 Each properties' security deposit refunds are included in the tile results. To include all current and future properties, select <All Properties> . Alternatively, select a property Group from the drop-down list.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Include move-outs more than X days ago

 The number of days in the past that security deposits are included in the tile results, based on the tenant's Move Out . For example, if you enter 7 , security deposits display if the tenant's Move Out date occurred one week prior to the current date.

 Exclude move-outs more than X days ago

 The number of days in the past that security deposits are included in the tile results, based on the tenant's Move Out date. For example, if you enter 21 , security deposits display only if their Move Out date is less than three weeks prior to the current date.

 Ignore dashboard property filter

 If checked, override the property filter configured on the Dashboard .

 Column Descriptions

 The information that displays on the tile is organized into the following columns.

 Column
 Description

 Tenant

 The name of the tenant who moved out and has not yet received their security deposit refund.

 Property

 The short name of the property at which the past tenant's unit is located.

 Unit

 The vacated unit to which the security deposit is allocated.

 Move Out

 The tenant's move out date listed on tenant's details page.

 Amount

 The total amount of the security deposit being held.
