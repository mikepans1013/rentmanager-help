Bank Balances (Dashboard Tile)

The Bank Balances dashboard tile helps you track the balance of your banks in Rent Manager. This tile displays the current balances in each bank account.

The information on this dashboard tile may be represented in a graph or a list.

Related Privileges

Group Privilege Column
Setup Edit own dashboards Enabled
Banks/Checks View bank registers Enabled

For more information, refer to Control User Access.

Filter Information

Related Privileges

Group Privilege Column
Setup Edit dashboard data filters Enabled

For more information, refer to Control User Access.

To filter the information that displays in the dashboard tile, click arrow_forward Settings to open the Bank Balances Data Filters pop-up. The available filter options are listed below.

Option Description

Bank Filter

Each bank account whose balances are included in the tile.

Related Privileges

This field populates with only banks to which you have access. Your access to banks can be managed on the user's details page. For more information, refer to Limit Access to a Bank or Credit Card.

Show overall bank balance

If checked, the total balances of the selected banks, including funds tied to inactive properties, display.

Property Filter

Each property whose associated bank balances are included in the tile. To include all current and future properties, select <All Properties>. Alternatively, select a property Group from the drop-down list.

This option can be selected only if Show overall bank balance is unchecked.

More Information

This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property.

Alternatively, select a property Group from the drop-down list.

Show Values

If checked, bank balances display over each point of the Line graph or bar of the Bar graph.

Graph Type

The desired display option.

Line

The bank balances display in a line graph. The full balance for each bank account can be viewed by hovering your cursor over each point on the graph.

If Show Values is checked, balances are rounded to the nearest whole dollar and display above each point.

Bar

The bank balances display in a bar graph. The full balance for each bank account can be viewed by hovering your cursor over each bar on the graph.

If Show Values is checked, balances are rounded to the nearest whole dollar and display on each point.

None

The bank balances display in columns. Options in the footer allow you to navigate to different pages of the tile.

Ignore dashboard property filter

If checked, override the property filter configured on the Dashboard.

Column Descriptions

The information that displays on the tile is organized into the following columns.

Column Description

Name

The name of the bank account.

Balance

The total dollar amount currently in the bank account.

Axis Descriptions

The information that displays on each axis in the graph is described below.

Axis Description

X
(Horizontal)

The name of the bank account.

Y
(Vertical)

The total dollar amount currently in the bank account.
