Notes (Dashboard Tile)

The Notes dashboard tile allows you to quickly record tasks or reminders in a text box. Quick thoughts or ideas can easily be notated in the tile for later reference. The contents of this tile are unique to each user and are not shared.

If no notes have been entered, this tile displays as a blank text box.

Related Privileges

Group Privilege Column
Setup Edit own dashboards Enabled

For more information, refer to Control User Access.

Enter Notes on Tile

To record notes on the dashboard tile, do the following:

  1. Click anywhere in the text box.

  2. Type or paste any notes you wish to record.

  3. Click Save.
    The tile is updated to display your notes.
