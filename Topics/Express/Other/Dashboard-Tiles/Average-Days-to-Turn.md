# Average Days to Turn (Dashboard Tile)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Dashboard-Tiles/Average-Days-to-Turn.htm

The Average Days to Turn dashboard tile displays the average number of days it takes to prepare a unit to be rented out. The average duration of all units in specific unit statuses displays for each month.

 The information on this dashboard tile may be represented in a graph or a list.

 To filter the information that displays in the dashboard tile, click arrow_forward Settings to open the Average Days to Turn Data Filters pop-up. The available filter options are listed below.

 Option
 Description

 Property Filter

 Each property whose units are included in the tile results. To include all current and future properties, select *** <All Properties> . Alternatively, select a property Group from the drop-down list.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Unit Status

 The unit statuses that are included in the calculation.

 Months

 The number of months in the past to display, including the current month. For example, if you enter 6 , the average number of days to turnover a unit in the current month and each of the previous five months display.

 Show Values

 If checked, the average days to turnover the unit display over each point of the Line graph or each bar of the Bar graph.

 Graph Type

 The desired display option.

 Line

 The average number of days in a line graph. Averages are rounded up or down to the nearest whole number for display below the date.

 If Show Values is checked, the average days displays above each point.

 Bar

 The average number of days displays in a bar graph. Averages are rounded up or down to the nearest whole number for display below the date.

 If Show Values is checked, the average days displays on each bar.

 None

 The average days to display in columns.

 Ignore dashboard property filter

 If checked, override the property filter configured on the Dashboard .
