# Pending Smart Receipts (Dashboard Tile)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Dashboard-Tiles/Pending-Smart-Receipts.htm

The Pending Smart Receipts dashboard tile allows you to view a list of Smart Receipts ready for review on the Smart Receipts page. With Smart Receipts, you take photos of receipts from purchases you made for your business using rmAppSuite Pro or directly in Rent Manager . You can use Orion AI to quickly and efficiently generate credit card transactions in Rent Manager by pulling information from that receipt's photos and inserting it into the transaction record. Orion AI also helps automatically match information on the receipt to existing accounts in Rent Manager , such as vendors and credit card numbers.

 The information on this dashboard tile is represented in a list.

 To filter the information that displays in the dashboard tile, click arrow_forward Settings to open the Pending Smart Receipts Data Filters pop-up. The available filter options are listed below.

 Option
 Description

 Ignore dashboard property filter

 If checked, override the property filter configured on the Dashboard page.

 Property Filter

 Filter the pending Smart Receipts on the dashboard tile based on the property associated with the receipt.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Column Descriptions

 The information that displays on the tile is organized into the following columns.

 Column
 Description

 Amount

 The total dollar amount of the Smart Receipt transaction.

 Upload Date

 The date and time the receipt was added to Smart Receipts page.

 Vendor

 The vendor account associated with the Smart Receipt transaction.
