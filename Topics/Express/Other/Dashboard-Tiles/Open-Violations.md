# Open Violations (Dashboard Tile)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Dashboard-Tiles/Open-Violations.htm

The Open Violations dashboard tile helps you track tenants with unresolved violations posted to their accounts. The tile can be customized to specify the amount of time before a violation displays or is removed from the tile.

 The information on this dashboard tile is represented in a list.

 To filter the information that displays in the dashboard tile, click arrow_forward Settings to open the Open Violations Data Filters pop-up. The available filter options are listed below.

 Option
 Description

 Violations due in next X days

 The number of days in the future that violations are included in the tile results, based on the violation's Due Date . For example, if you enter 7 , violations display only if their Due Date is at least one week from the current date.

 Exclude violations due more than X days ago

 The number of days in the past that violations are included in the tile results, based on the violation's Due Date . For example, if you enter 21 , violations display only if their Due Date is less than three weeks prior to the current date.

 Property Filter

 Each property whose tenant violations are included in the tile. To include all current and future properties, select <All Properties> . Alternatively, select a property Group from the drop-down list.

 If <All Properties> is selected, you can also check Include inactive if 'All Properties' selected to calculate averages for all current and future properties whether they are active or inactive.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Ignore dashboard property filter

 If checked, override the property filter configured on the Dashboard .

 Column Descriptions

 The information that displays on the tile is organized into the following columns.

 Column
 Description

 Due Date

 The date on which the tenant follow-up on the violation is due.

 Name

 The name of the tenant.

 Property

 The Short Name of the property at which the tenant's violation is active.

 Unit

 The unit at which the tenant's violation is active.

 Code

 The violation code associated with the tenant's violation.
