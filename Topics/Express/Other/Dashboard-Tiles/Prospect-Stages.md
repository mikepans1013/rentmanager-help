# Prospect Stages (Dashboard Tile)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Dashboard-Tiles/Prospect-Stages.htm

The Prospect Stages dashboard tile helps you track prospects that have been created in Rent Manager as they progress through prospect stages. The tile can be customized to display the stages and leasing agents you select. Clicking on a stage opens prospects with a temporary filter, displaying all prospects currently in that stage.

 The information on this dashboard tile is represented in a list.

 To filter the information that displays in the dashboard tile, click arrow_forward Settings to open the Prospect Stages Data Filters pop-up. The available filter options are listed below.

 Option
 Description

 Property Filter

 Each property whose units are included in the tile results. To include all current and future properties, select <All Properties> . Alternatively, select a property Group from the drop-down list.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Prospect Stage Filter

 Each prospect stage included in tile results. To include all prospect stages, select All Stages .

 Agent Filter

 Each leasing agent's prospects included in the tile results. Users assigned the Sales Rep/Leasing Agent role populate in the list of agents. To include all current agents, select All Agents . To include prospects who are not assigned to a leasing agent in the tile results, select No Agent

 More Information

 Prospect accounts created through the submission of guest cards have no agent by default. To display these accounts, No Agent must be included in your filter configuration.

 Exclude stages without prospects

 If checked, prospect stages that are not currently assigned to any prospects do not display.

 Ignore dashboard property filter

 If checked, override the property filter configured on the Dashboard .
