Appointments (Dashboard Tile)

The Appointments dashboard tile allows you to view upcoming scheduled appointments to ensure that you don't miss any upcoming events.

The information on this dashboard tile is represented in a list.

Related Privileges

Group Privilege Column
Setup Edit own dashboards Enabled
Appointments View

For more information, refer to Control User Access.

Filter Information

Related Privileges

Group Privilege Column
Setup Edit dashboard data filters Enabled

For more information, refer to Control User Access.

To filter the information that displays in the dashboard tile, click arrow_forward Settings to open the Appointments Data Filters pop-up. The available filter options are listed below.

Option Description

Days to Include

The number of days in the future, including today, included in the tile results. For example, if you enter 7, violations display only if their Start Date is at least one week from the current date.

Users

Each user who are assigned an appointment are included in the tile results. To include all current and future users, select All Users.

Column Descriptions

The information that displays on the tile is organized into the following columns.

Column Description

Title

The topic of the appointment.

Starts In

The start time of the appointment in days, hours, and minutes.

User

The user assigned to the appointment.
