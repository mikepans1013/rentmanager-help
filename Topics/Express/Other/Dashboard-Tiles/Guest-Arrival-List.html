Guest Arrival List (Dashboard Tile)

The Guest Arrival List dashboard tile allows you to track scheduled or expected arrivals and departures at short-term rental (STR) properties within a set number of days. The property and unit the guests reserved display in the list as well as the start and end dates of their reservation. Arrival dates with an asterisk (*) indicate the guest has already been checked in.

The information on this dashboard tile is represented in a list.

Filter Information

Related Privileges

Group Privilege Column
Setup Edit dashboard data filters Enabled

For more information, refer to Control User Access.

To filter the information that displays in the dashboard tile, click arrow_forward Settings to open the Guest Arrival List Data Filters pop-up. The available filter options are listed below.

Option Description

Days to Include

The number of days to examine for guest reservation start dates and display those guests on the tile. For example, to list only guests arriving for a reservation in the next week, enter 7.

Property Filter

Each property whose guests are included in the tile results. To include all current and future properties, select <All Properties>. Alternatively, select a property Group from the drop-down list.

More Information

This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property.

Exclude checked in guests

If checked, guests that have been checked in for their reservation do not display in the list.

Ignore dashboard property filter

If checked, override the property filter configured on the Dashboard page.

Column Descriptions

The information that displays on the tile is organized into the following columns.

Column Description

Property

The Short Name of the property at which the guest has an upcoming reservation.

Unit

The name of the unit reserved by the guest.

Arrival

The date on which the guest's reservation starts.

Departure

If entered, the date on which the guest's reservation ends.
