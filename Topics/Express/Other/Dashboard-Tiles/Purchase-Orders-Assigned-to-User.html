Purchase Orders Assigned to User (Dashboard Tile)

The Purchase Orders Assigned to User dashboard tile helps you track purchase orders that are assigned to you. If you are managing multiple projects that require the purchasing of materials, this tile can be helpful in keeping track of the status of each purchase order that's involved.

The information on this dashboard tile is represented in a list.

Related Privileges

Group Privilege Column
Setup Edit own dashboards Enabled

For more information, refer to Control User Access.

Filter Information

Related Privileges

Group Privilege Column
Setup Edit dashboard data filters Enabled

For more information, refer to Control User Access.

To filter the information that displays in the dashboard tile, click arrow_forwardSettings to open the Purchase Orders Assigned to User Data Filters pop-up. The available filter options are listed below.

Option Description

Status

The status of a purchase order to include in the tile results.

Column Descriptions

The information that displays on the tile is organized into the following columns.

Column Description

PO #

The internally-generated number as specified in the purchase order's P.O.# field.

Description

A brief description as entered in the purchase order's Description field.

Status

The status (Pending, Approved, Fulfilled, or Rejected) of the purchase order.
