# Violations - Communication Needed (Dashboard Tile)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Dashboard-Tiles/Violations-Communication-Needed.htm

The Violations - Communication Needed dashboard tile helps track open violations with an escalated stage that still needs to be communicated to the tenant. The date, property, unit, and associated violation code display.

 The information on this dashboard tile is represented in a list.

 To filter the information that displays in the dashboard tile, click arrow_forward Settings to open the Violations - Communication Needed Data Filters pop-up. The available filter options are listed below.

 Option
 Description

 Property Filter

 Each property whose violations are included in the tile results. To include all current and future properties, select <All Properties> . Alternatively, select a property Group from the drop-down list.

 If <All Properties> is selected, you can also check Include inactive if 'All Properties' selected to include violations from any property, whether they are active or inactive.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Ignore dashboard property filter

 If checked, override the property filter configured on the Dashboard .

 Column Descriptions

 The information that displays on the tile is organized into the following columns.

 Column
 Description

 Date

 The date of the violation as displayed on the violation's details page.

 Property

 The name of the property associated with the offending tenant's Unit .

 Unit

 The unit associated with the offending tenant.

 Code

 The associated violation code.
