# Tenant Self-Inspections (Dashboard Tile)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Dashboard-Tiles/Tenant-Self-Inspections.htm

The Tenant Self-Inspection dashboard tile helps you track tenants who have inspections assigned to them. The tile displays the Property and Unit associated with the tenant and the inspection's Expiration date and Status ( In Progress , Pending Maintenance , Awaiting Review , etc.).

 The information on this dashboard tile is represented in a list.

 To filter the information that displays in the dashboard tile, click arrow_forward Settings to open the Tenant Self-Inspections Data Filters pop-up. The available filter options are listed below.

 Option
 Description

 Days to Include

 The number of days old inspections must be to display on the tile. For example, to list only tenants who have assigned inspections that are at least one week old, enter 7 .

 Ignore dashboard property filter

 If checked, override the property filter configured on the Dashboard page.

 Include inactive if 'All properties' selected

 If checked, tenants with inspections assigned from both active and inactive properties display only when the Property Filter selection is set to <All Properties> .

 Property Filter

 Each property's tenants with inspections assigned to them are included in the tile's results. To include all current and future properties, select <All Properties> . Alternatively, select a property Group from the drop-down list.

 If <All Properties> is selected, you can also check Include inactive if 'All properties' selected to include tenants with inspections assigned from any property, whether they are active or inactive.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Statuses

 The stage or progress for the inspection to include in the tile (e.g., New , In Progress , Pending Maintenance , Closed ).

 Column Descriptions

 The information that displays on the tile is organized into the following columns.

 Column
 Description

 Expiration

 The date the tenant's self-inspection expires. If a tenant's self-inspection is in the Expired status, the column displays red.

 Name

 The name of the tenant assigned a self-inspection.

 Property

 The Short Name of the property associated with the tenant.

 Status

 The current stage or progress for the inspection.

 Unit

 The name of the unit associated with tenant.
