# Mgmt Company Revenue Per Unit (Dashboard Tile)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Dashboard-Tiles/Mgmt-Company-Revenue-per-Unit.htm

The Mgmt Company Revenue Per Unit dashboard tile allows you to analyze the average revenue of your units over time. This is done by calculating the management company's gross income divided by the number of total active units. Users can view data up to a total of thirteen months into the past, including the current month.

 Units are considered active if they meet all of the following conditions:

 -
 The unit's property has an active ownership as of the first of the month.

 -
 The unit's Active box is checked on its details page.

 -
 The unit has no unit status or has a unit status where either Show As Available and/or Show As Vacant is selected. For more information, refer to Unit Status Types (Page) .

 The information on this dashboard tile may be represented in a graph or a list.

 To filter the information that displays in the dashboard tile, click arrow_forward Settings to open the Mgmt Company Revenue Per Unit Data Filters pop-up. The available filter options are listed below.

 Option
 Description

 Period(s)

 The number of months in the past, including the current month, included in the tile results. For example, if you enter 6 , the average revenue of your units for the current month and each of the previous five months display.

 Show Values

 If checked, the average revenue of your units display over each point of the Line graph or each bar of the Bar graph.

 Graph Type

 The desired display option.

 Line

 The average revenue over time displays in a line graph.

 If Show Values is checked, the average revenue over time displays above each point.

 Bar

 The average revenue over time displays in a bar graph.

 If Show Values is checked, the average revenue displays on each bar.

 None

 The date, net income, units, and profit per unit display in columns.

 Axis Descriptions

 The information that displays on each axis in the graph is described below.

 Axis
 Description

 X
(Horizontal)

 The month being examined in a MM/YY format.

 Y
(Vertical)

 The dollar amount of the management company's revenue per unit for the according month.

 Column Descriptions

 The information that displays on the tile is organized into the following columns.

 Column
 Description

 Date

 The month being examined in a MMM/YYYY format (e.g., Jan/ 26 ).

 Revenue

 The net income for the according month.

 Units

 The total number of active units for the associated month.

 Revenue/Unit

 The net income divided by the total number of active units for the month.
