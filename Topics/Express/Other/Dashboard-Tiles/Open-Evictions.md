# Open Evictions (Dashboard Tile)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Dashboard-Tiles/Open-Evictions.htm

The Open Evictions dashboard tile helps you track tenants who are in the eviction process and displays their associated property, current eviction stage, and balance due.

 The information on this dashboard tile is represented in a list.

 To filter the information that displays in the dashboard tile, click arrow_forward Settings to open the Open Evictions Data Filters pop-up. The available filter options are listed below.

 Option
 Description

 Days in Eviction

 Determines the number of days that display in the tile's Eviction Days column. Selecting Since Eviction Start Date displays the number of days between the current date and the tenant eviction's Start Date . Selecting Since Last Stage Change displays the number of days the tenant has been in their current eviction stage. By default, Since Eviction Start Date is selected.

 Eviction Stage

 Tenants with the selected stage(s) assigned display in the tile results. To include tenants with any stage assigned, check All Stages .

 Ignore dashboard property filter

 If checked, override the property filter configured on the Dashboard .

 Property Filter

 Each property whose tenants are included in the tile results. To include all current and future properties, select <All Properties> . Alternatively, select a property Group from the drop-down list.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Column Descriptions

 The information that displays on the tile is organized into the following columns.

 Column
 Description

 Balance Due

 The tenant's outstanding balance as of the start of the eviction process.

 Eviction Days

 The number of days between the current date and the eviction's Start Date or the number of days the tenant has been in their current eviction stage, as determined on the Open Evictions Data Filters pop-up Days in Eviction field. By default, the days Since Eviction Start Date displays.

 Name

 The name of the tenant in the eviction process.

 Property

 The Short Name of the property at which the tenant's eviction is active.

 Stage

 The name of the step taken in the eviction workflow that allows you to track the eviction process.
