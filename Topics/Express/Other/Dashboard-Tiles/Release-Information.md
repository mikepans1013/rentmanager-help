# Release Information (Dashboard Tile)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Dashboard-Tiles/Release-Information.htm

The Release Information dashboard tile allows you to view the changelog, which document updates and improvements to Rent Manager .

 The information on this dashboard tile is represented in a list.

 Related Privileges

 Group
 Privilege
 Column

 Setup
 Edit own dashboards

 For more information, refer to Control User Access .

 Column Descriptions

 The information that displays on the tile is organized into the following column.

 Column
 Description

 Release Information

 Each Rent Manager release displays and can be clicked to view the full changelog and date of the release.
