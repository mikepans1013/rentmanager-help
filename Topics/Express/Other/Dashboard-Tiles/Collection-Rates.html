Collection Rates (Dashboard Tile)

The Collection Rates dashboard tile calculates the percentage of posted charges that you successfully collect, filtered by property. Each row of the dashboard tile displays information from one month or year of your selected time period. Rent Manager sums the total amount of charges posted for specific charge types dated within your selected time period that were paid prior to the end of the specified period.

More Information

Prepayments that pay a charge are counted for the month of the charge date. For example, if your tenants pay early on October 28 for a rent charge dated November 1, that payment collection is calculated for November.

The information on this dashboard tile may be represented in a graph or a list.

Filter Information

Related Privileges

Group Privilege Column
Setup Edit dashboard data filters Enabled

For more information, refer to Control User Access.

To filter the information that displays in the dashboard tile, click arrow_forward Settings to open the Collection Rates Data Filters pop-up. The available filter options are listed below.

Option Description

Property Filter

Each property whose percentage of collected charges that are included in the tile. To include all current and future properties, select <All Properties>. Alternatively, select a property Group from the drop-down list.

If <All Properties> is selected, you can also check Include inactive if 'All Properties' selected to calculate averages for all current and future properties whether they are active or inactive.

More Information

This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property.

Charge Type

The charge type(s) with collected payments to include in the tile results. To select all current and future charge types, check *** All.

Include payments applied to prior months charges

If checked, payments applied to prior month's charges count payments made in the current month for charges posted in previous months. For example, if a payment was made in November for a charge posted in October, that payment is counted in November's collection rate.

Period(s)

The number of months or years (as defined by the Period Category) to include in the tile results.

Period Category

The unit of time to use for the tile results (Month(s) or Year(s)).

Show Values

If checked, rounded averages display over each point of the Line graph or each bar of the Bar graph.

Graph Type

The desired display option.

Line

The percentage rate of collected payments display in a line graph. The full percentage for each date can be viewed by hovering your cursor over each point on the graph.

If Show Values is checked, averages are rounded to the nearest whole number and display above each point.

Bar

The percentage rate of collected payments display in a bar graph. The full percentage for each date can be viewed by hovering your cursor over each bar on the graph.

If Show Values is checked, averages are rounded to the nearest whole number and display at the bottom of each bar.

None

The percentage rate of collected payments displays in columns. Options in the footer allow you to navigate to different pages of the tile.

Ignore dashboard property filter

If checked, override the property filter configured on the Dashboard.

Axis Descriptions

The information that displays on each axis in the graph is described below.

Axis Description

X
(Horizontal)

The month or year being examined.

Y
(Vertical)

The percentage of posted charges successfully collected as of the month or year specified on the horizontal axis.

Column Descriptions

The information that displays on the tile is organized into the following columns.

Column Description

Date

The month or year being examined.

Amount Paid

The total amount of posted charges that was successfully collected.

Amount Charged

The total amount of posted charges.

Percent Collected

The value of posted charges displayed as a percentage out of 100.
