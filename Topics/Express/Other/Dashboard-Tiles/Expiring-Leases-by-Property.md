# Expiring Leases by Property (Dashboard Tile)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Dashboard-Tiles/Expiring-Leases-by-Property.htm

The Expiring Leases By Property dashboard tile displays how many leases expire and how many are renewed during the selected number of days into the future for the selected properties. This includes expiring leases that are renewed to month-to-month leases.

 The information on this dashboard tile is represented in a list.

 To filter the information that displays in the dashboard tile, click arrow_forward Settings to open the Expiring Leases by Property Data Filters pop-up. The available filter options are listed below.

 Option
 Description

 Days to Include

 The number of days in the future, including today, included in the tile results. For example, if you enter 6 , the number of leases that expire and are renewed today and within the next five days display.

 Property Filter

 Each property whose tenants with expiring leases are included in the tile results. To include all current and future properties, select *** <All Properties> . Alternatively, select a property Group from the drop-down list.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Ignore dashboard property filter

 If checked, override the property filter configured on the Dashboard .

 Column Descriptions

 The information that displays on the tile is organized into the following columns.

 Column
 Description

 Property

 The name of the property where lease expirations will occur during the selected number of days.

 Expiring

 The number of leases expiring at the property during the selected number of days.

 Renewals

 The number of leases renewing at the property during the selected number of days.

 Difference

 The difference between the number of expiring leases and number of leases renewed.
