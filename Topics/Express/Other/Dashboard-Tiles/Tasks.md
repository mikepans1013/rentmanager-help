# Tasks (Dashboard Tile)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Dashboard-Tiles/Tasks.htm

The Tasks dashboard tile allows you to track important business tasks so that you can ensure each one is completed in a timely manner.

 The information on this dashboard tile is represented in a list.

 To filter the information that displays in the dashboard tile, click arrow_forward Settings to open the Tasks Data Filters pop-up. The available filter options are listed below.

 Option
 Description

 Days to Include

 The number of days in the future, including the current day, included in the tile results. For example, if you enter 6 , overdue tasks and tasks with a Due Date of today and each of the next five days display.

 Include History Note Followup

 If checked, tasks that were created when entering a Follow-up Date on a history/note item display.
