# Average Days Vacant Trend (Dashboard Tile)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Dashboard-Tiles/Average-Days-Vacant-Trend.htm

The Average Days Vacant Trend dashboard tile helps you track, on average, how many days a unit is vacant after a move out occurs in a given period. The calculation includes units that are pre-leased to tenants with a future move out date and units with a unit status type that has the option Show As Vacant enabled.

 Prospects with a reserved move in do not impact this value until they are converted to tenants.

 The information on this dashboard tile may be represented in a graph or a list.

 To filter the information that displays in the dashboard tile, click arrow_forward Settings to open the Average Days Vacant Trend Data Filters pop-up. The available filter options are listed below.

 Option
 Description

 Property Filter

 Each property whose units are included in the tile results. To include all current and future properties, select <All Properties> . Alternatively, select a property Group from the drop-down list.

 If <All Properties> is selected, you can also check Include inactive if 'All Properties' selected to calculate averages for all current and future properties whether they are active or inactive.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Period(s)

 The number of months or years (as defined by the Period Category ) to include in the tile results.

 Period Category

 The unit of time to use for the tile results ( Month(s) or Year(s) ).

 Show Values

 If checked, the average days vacant display over each point of the Line graph or each bar of the Bar graph.

 Graph Type

 The desired display option.

 Line

 The average number of days in a line graph. Averages are rounded up or down to the nearest whole number for display below the date.

 If Show Values is checked, the average days displays above each point.

 Bar

 The average number of days displays in a bar graph. Averages are rounded up or down to the nearest whole number for display below the date.

 If Show Values is checked, the average days displays on each bar.

 None

 The average days to display in columns.

 Ignore dashboard property filter

 If checked, override the property filter configured on the Dashboard .

 Axis
 Description

 Y
