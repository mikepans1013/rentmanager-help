Scheduled Asset Maintenance (Dashboard Tile)

This dashboard tile helps you track assets with maintenance that has been scheduled but not yet completed. The asset's name, manufacturer, model, and the date on which the next maintenance is due displays. The tile can be customized to examine the length of time for which to examine scheduled maintenance.

The information on this dashboard tile is represented in a list.

Related Privileges

Group Privilege Column
Setup Edit own dashboards Enabled
Asset Management Manage Assets View

To view this tile in system dashboards, you must be listed as an assigned user for the system dashboard that includes this tile.

For more information, refer to Control User Access.

To filter the information that displays in the dashboard tile, click arrow_forward Settings to open the Scheduled Asset Maintenance Data Filters pop-up. The available filter options are listed below.

Option Description

Days to Include

The number of days, both past and in the future, to examine for scheduled maintenance. For example, if you enter 30, Rent Manager examines the thirty days prior to today's date and the upcoming thirty days for scheduled maintenance.

Column Descriptions

The information that displays on the tile is organized into the following columns.

Column Description

Name

The name of the asset.

Manufacturer

The manufacturer associated with the asset.

Model

The model name of the asset.

Date

The date on which the next maintenance is due.
