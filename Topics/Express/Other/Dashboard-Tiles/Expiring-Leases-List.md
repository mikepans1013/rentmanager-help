# Expiring Leases List (Dashboard Tile)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Dashboard-Tiles/Expiring-Leases-List.htm

The Expiring Leases List dashboard tile helps you track tenants with leases that have an approaching Lease End date within a specified number of days. The tile displays the property and unit the tenant occupies, the tenant's name, and the lease's end date.

 The information on this dashboard tile is represented in a list.

 To filter the information that displays in the dashboard tile, click arrow_forward Settings to open the Expiring Leases List Data Filters pop-up. The available filter options are listed below.

 Option
 Description

 Days to Include

 The number of days in the future, including today, included in the tile results. For example, if you enter 10 , leases with an End Date between today and ten days into the future display.

 Property Filter

 Each property whose tenant violations are included in the tile. To include all current and future properties, select <All Properties> . Alternatively, select a property Group from the drop-down list.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Tenants to include

 The status of a tenant ( Past , Current , and/or Future ) to include in the tile results.

 Ignore dashboard property filter

 If checked, override the property filter configured on the Dashboard .

 Column Descriptions

 The information that displays on the tile is organized into the following columns.

 Column
 Description

 End Date

 The date the tenant's lease ends.

 Name

 The name of the tenant with the expiring lease.

 Unit

 The unit for which the tenant's lease is expiring.

 Property

 The property at which the unit is located.

 Status

 If the lease has a move-out date entered, MO displays.
