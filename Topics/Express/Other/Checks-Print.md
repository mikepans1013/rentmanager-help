# Print Checks

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Checks-Print.htm

Checks can be printed directly from Rent Manager . You may also print blank checks with only bank account information and a check number that you can fill out later. To print checks, you must have the appropriate check stock in your printer. You must also enter the bank's MICR information on its chart of accounts entry before you can print checks.

 Step 1: Filter Checks

 To filter the checks to print, do the following:

 -
 Go to arrow_forward Payables arrow_forward Checks arrow_forward Print Checks .

 -
 In the Filters section, set optional filters to limit which checks display. As you select each filter, the grid updates with checks that match your filter criteria. The following options are available in this section:

 Filter Option
 Description

 Bank

 The bank from which checks are drawn. To see all checks, select <All Banks> .

 Check Date

 Checks with a Date within the specified date range display.

 Include already printed checks

 If selected, displays checks that were already printed out of Rent Manager . This allows you to reprint checks.

 Include checks not selected to print

 If selected, includes checks that do not have the Check will be printed option enabled.

 Step 2: Update Check Information

 To update check information and change the starting check number for different banks, do the following:

 -
 In the Check Information section, make any of the following selections:

 Option
 Description

 Change check date to

 A date to change the actual check date of every printed check. This date displays on the printed check and it also updates the check transaction in Rent Manager .

 Signature

 A digital signature to apply on the printed check.

 More Information

 This field displays only if there is a digital signature assigned to your user account. For more information, refer to Digital Signatures (Page) .

 Show memo on check

 Includes text entered on the memo line of the check on the printed check.

 Show property on check detail

 Includes the individual expenses by property in the detail portion of the printed check.

 Show unit on check detail

 Includes the individual expenses by unit in the detail portion of the printed check.

 Show account numbers on check detail

 Includes the general ledger (GL) account number next to the account name for every expense allocation.

 Renumber checks

 Re-numbers the actual check numbers of the checks that you intend to print. to apply updated check numbers to the checks in the list that do not already have check numbers only check Unnumbered checks only .

 Step 3: Print Checks

 To print checks, do the following:

 -
 Review the checks to print in the following columns.

 Column
 Description

 Date

 The date on which the check was issued to the payee. This date should match your real-world financial records to prevent any issues with reconciliation.

 Vendor

 The name of the vendor, owner, tenant, or prospect being paid.

 Bank

 The bank from which the check is drawn.

 Memo

 Additional information about this check. The memo displays on the printed check and on the associated transaction pages for the payee.

 Check No.

 The identifying number of the check.

 Amount

 The total dollar amount of the check.

 -
 Check the box next to each check that you wish to print. To quickly select or deselect all checks in the list, check or uncheck the box in the section header.

 More Information

 To print the checks in a simple report format, check Print Check Worksheets . For more information, refer to Check Worksheet (Report) .

 Click Print .
The Check Print pop-up displays.
