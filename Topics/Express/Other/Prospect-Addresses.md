# Prospect Addresses

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Prospect-Addresses.htm

You can create and manage your own categories for prospect addresses on the Address Types page. This makes it easy to record and reference multiple addresses on the same prospect account. Additionally, this adds the ability to pull a specific address type into other parts of Rent Manager , such as reports and features that use scripting. Once you define an address type for prospects, you can go to any prospect account to enter the associated address.

 To add a prospect address type, do the following:

 -
 Go to arrow_forward Administration , then go to Customization arrow_forward Address Types .

 -
 In the Type section, select Prospect .

 -
 Click This is Add Address Type .

 -
 Enter the Name for this prospect address type.
This name displays as an option on the prospect's View Addresses pop-up.

 -
 Click Save .
The address type is added to all prospect accounts.

 To add a prospect address, do the following:

 -
 Go to   arrow_forward Rental Info arrow_forward General arrow_forward Prospects and select a prospect from the list.
The prospect's details page displays.

 -
 On the Addresses tile, click .
The View Addresses pop-up displays.

 -
 Select the according address type tab for the address you wish to add.

 -
 In the text field, enter the prospect's address.

 -
 If the address is used as the primary source of correspondence, check Default .

 -
 Click Save .
The prospect address is added.
