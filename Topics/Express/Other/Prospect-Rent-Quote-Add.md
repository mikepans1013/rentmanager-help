# Add a Prospect Rent Quote

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Prospect-Rent-Quote-Add.htm

Rent quotes allow you to offer prospective tenants a price for units they are interested in with various criteria. You can create multiple quotes for different properties and units, change the rent amount depending on the lease term the prospect would like, and create a unit reservation if the prospect has already signed a lease.

 More Information

 Rent quotes cannot be created for prospects associated with RV/Campground - or Short Term Rental -type properties.

 Related Preferences

 If the Create a rent quote with application using market rent system web preference is enabled, rent quotes are automatically generated when a primary applicant submits an application through Apply Now . Rent quotes are created only when a certain set of conditions are met. For more information, refer to Tenant Web Access Apply Now General (System Web Preferences) .

 To create a new prospect rent quote, do the following:

 -
 Go to arrow_forward Rental Info arrow_forward General arrow_forward Prospects and select a prospect.
The prospect's details page displays.

 More Information

 Rent quotes cannot be created for prospects with the Lost , Lost/Rejected , or Tenant status.

 -
 In the Rent Quotes tile, click Add Quote .

 -
 Enter information in the following fields:

 Field
 Description

 Charge Type

 The rent charge type to use for the quoted recurring charge. The charge types displayed are based on the charge types selected on the property's Rent Charge Types field.

 Comment

 An internal note to provide additional information about the rent quote, such as the procedure if the quote expires.

 Date Quoted

 The date the quote is provided to the prospect. Today's date populates by default.

 Expiration

 The date on which the rent quote is no longer valid. You can enter a specific date, or select one of the relative options by clicking (e.g., 7 Days ) to set the expiration to a specified number days after the Date Quoted .

 Lease Term

 The duration of the lease for which the quote price is applicable. For more information, refer to Lease Terms (Page) .

 If the quoted unit is reserved, in the prospect's Reservation/Expected Lease Information tile, the Lease Term field is automatically pre-populated with this selection.

 Move In

 The date on which the prospect plans to move into the unit.

 If the quoted unit is reserved, in the prospect's Reservation/Expected Lease Information tile, the Expected Lease Start , Reserved Move In , and Expected Lease End fields are automatically pre-populated based on this date and the selected Lease Term .

 Property

 The property whose primary unit(s) the prospect has expressed interest in. The property selected on the prospect's General tile populates by default.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Rent

 The dollar amount quoted for rent to the prospect for the selected Unit and Lease Term . To use the value established for the unit's Market Rent or a rent recurring charge amount set up on the unit, unit type, or property level, click Select Amount and choose one of the listed options.

 Unit

 The primary unit the rent quote is created for. To view a filtered list of the property's units, click . For more information, refer to Unit Selector (Pop-Up) .

 -
 To add an other rentable item (ORI) unit to the rent quote, click   Add ORI Unit .

 Enter information on the ORI unit in the following fields:

 Field
 Description

 Amount

 The dollar amount to offer the prospect for the selected ORI unit. To use the value established for the unit's Market Rent or a rent recurring charge amount set up on the unit, unit type, or property level, click Select Amount , choose one of the listed options, and click Save .

 Charge Type

 The rent charge type to use for the quoted recurring charge on the ORI unit. The charge types displayed are based on the charge types selected on the property's Rent Charge Types field.

 Property

 The property of the ORI unit.

 If the property selected on the prospect's primary unit section has an ORI unit, then that property populates by default. Otherwise, this field is left blank by default. Only properties that have ORI units can be listed.

 Unit

 The ORI unit the rent quote is created for. To view a filtered list of the property's ORI units, click . For more information, refer to Other Rentable Item (ORI) Unit Selector (Pop-Up) .
