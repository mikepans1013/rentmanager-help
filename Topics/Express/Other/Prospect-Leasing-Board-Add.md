# Add a Prospect Leasing Board

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Prospect-Leasing-Board-Add.htm

The Prospect Leasing Board allows you to easily visualize where each of your prospects stand in their leasing journey, organized by your existing prospect stages. Rent Manager allows you to create a new leasing board for each of your properties' unique leasing needs. For example, if one (or more) of your properties includes additional stages, you can create a leasing board and assign it to the applicable properties without having to edit other leasing boards.

 Step 1: Enter Leasing Board Details

 To add a new prospect leasing board, do the following:

 -
 Go to arrow_forward Rental Info arrow_forward Leasing arrow_forward Prospect Leasing Board .
The Prospect Leasing Board page displays.

 -
 At the top of the page next to the selected board's name, click   arrow_forward Manage Boards arrow_forward Add Board .

 -
 In the Board Name field, enter the name that best describes the leasing board.

 -
 Click Select Properties to choose which properties the leasing board is assigned to.
The Properties pop-up displays.

 -
 Check all applicable properties from the list, or click Select from Group to add properties that are part of a property group.

 -
 Click Add .
The Properties pop-up closes and this board can be selected when a prospect leasing process is started at one of the selected properties.

 -
 Optionally, to display the prospect's system-generated account number on cards in the leasing board, check Show Account # in Prospect Card .

 Step 2: Set Up Leasing Board Columns

 After naming your new leasing board and assigning it to the appropriate property(s), you can start setting up your columns. You can add as many columns as you have prospect stages in your leasing process. Each column can be used to keep track of each individual stage.

 To configure your leasing board columns, do the following:

 -
 In the Column Name field, enter the name for your first column. For example, if this column should contain prospects that have been waitlisted, name this column Wait List .

 -
 In the Prospect Stages to Include field field, click Edit Stages and select the prospect stage cards to be listed in this column. At least one stage must be selected.

 -
 In the Card Settings section select the from the following Available Fields to add to the prospect card. Only 7 fields can be added to a prospect card.

 Field
 Description

 Agent

 The name of the prospect's Leasing Agent as displayed on the prospect's details page on the Lead Information tile.

 Application Date

 The date the prospect's application was received.

 Application Status

 The current status of the prospect's application ( In Progress , Completed , or Canceled ).

 Balance Due

 The prospect's unpaid balance as of today's date as displayed on the prospect's details page.

 Expected Move in Date

 The date on which the prospect is expected to move into the unit.

 Interest Level

 The prospect's interest level ( 0 through 10 , with 10 being highest) in your property.

 Last Contact

 The date on which the prospect's was most recently contacted by your company.

 Lead Source

 The main source of information that describes how this prospect learned about your company.

 Lease Start

 The date on which the lease is begins as displayed on the prospect's details page.

 Market Rent

 The market rent of the unit associated with prospect as established on the unit's details page.

 Next Contact

 The date on which your company is next scheduled to reach out to the prospect as established on the Prospect Stage Details pop-up.

 Original Contact

 The date on which the prospect was first contacted by your company and the communication method of that contact (such as email or phone call). If the prospect's original contact comes from a guest card/ Apply Now , the type is Web . If the prospect original contact comes from Apply Now , the type is Application .

 Preferred Move in Date

 The date on which the prospect wishes to move into the unit.

 Screening Status

 The prospect's screening Status as displayed on the prospect's details page in the Screening tile.

 Stage

 The prospect's current stage and the date they were moved to that stage.

 -
 Use the Card Preview section to view your completed prospect card and make any adjustments, such as adding or removing fields.

 -
 In the Column section, click Add Column to add your next column to the leasing board and enter the needed information until all the columns you need are added.

 -
 Click Save .
The prospect column and its associated cards are updated.

 Step 3: Establish Card Actions

 Once you have customized the fields for the prospect cards in each column, you can also determine what actions users can perform directly from the cards in that column. These options can be accessed via the icon at the top of the card.

 To determine the available actions, do the following:

 -
 Select a column from the list on the left.

 -
 In the Card Settings section, click Edit Card Actions .
The Edit Card Actions pop-up displays.

 -
 Deselect any actions that should not be available for the cards in this prospect column. Alternatively, uncheck Select All to deselect all actions and then select only the actions that should be available. Each action in the list is described below.

 Action
 Description

 Assign to Agent

 Assign a user to act as the prospects leasing agent.

 Move Stage

 Move the prospect to a different stage on the leasing board.

 Compose Email

 Write and send an email to the prospect.

 Move In

 Move the prospect in to the property in Rent Manager via the Move In pop-up.

 Change Status

 Change the current status of the prospect. For example, if the prospect was rejected during the screening process, their New Status is Lost/Rejected .

 Add to History

 Add a history/note type of Call , Email , Note , or Visit to the prospect's details page on the History/Notes tile.

 Screening

 Which screening actions, Run Screening , View Screening , and Write Screening Adverse Action Letters , can be taken from the prospect leasing board.

 Income Verification

 Which income verification actions, Run Income Verification , View Income Verification , and Write Income Verification Adverse Action Letters , can be taken from the prospect leasing board.

 Write Letters

 Write and send a letter to the prospect.

 Publish Signable Docs

 Publish signable documents to a prospect account via Tenant Web Access (TWA) .

 Create Document Packet

 Create document packet that can be sent to the prospect.

 More Information

 To create a document packet, the user must be selected on the Document Packet page in the Users field.

 Send Application

 Send a application to the prospect.

 Send Text

 Send a text message to the prospect.

 View History

 View the prospects history/notes.

 Add Appointment

 Add an appointment to link to the prospects account.

 Add a Transaction

 Add a payment to the prospects account.

 Add to Phone Broadcast

 Add the prospects phone number to a phone broadcast.

 More Information

 This feature is licensed and must be purchased separately. For more information, contact your sales representative at sales@rentmanager.com .
