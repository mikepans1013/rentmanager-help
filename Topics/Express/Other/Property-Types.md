# Property Types

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Property-Types.htm

A property in Rent Manager is defined as a financial entity that rents to one or more individuals. In Rent Manager , you can set the appropriate Property Type for each property on it's details page. Some property types are used for organizational purposes only to help identify the function of each property at a glance. Some property types function differently than a standard rental property, and therefore have different implications, setups, and use cases.

 To set up a property type for a property, go to arrow_forward Rental Info arrow_forward General arrow_forward Properties and select a property. Then in the General section, select a Property Type .

 The available property types, and their uses, are described in the table below.

 Property Type
 Description

 (No Selection)

 Any property in  Rent Manager that does not fit one of the other property type options. For example, if you are a fee-based management company, you would leave the Property Type field blank for the property that is set as your management company.

 Apartment

 This applies to larger residential properties composed of multiple units and families (generally three or more).

 Association

 Any property that is the establishment for a social committee—such as a Homeowners Association (HOA)—that manages a property or neighborhood. This property type enables additional features for the property such as architectural requests and association settings for Tenant Web Access (TWA) . You can also manage the members of the association's board and/or committees.

 Commercial

 This applies to any property or hybrid property that has one or more commercial leases. This option allows you to set tenants as companies, create commercial leases, and set up commercial recoverable expense (CRE) charges—also known as common area maintenance (CAM). Additionally, you can set up charge escalations and pro rata share amounts. For more information, refer to Add a Commercial Lease .

 Express also contains commercial-specific reports and tools—such as CAM reconciliations and the Commercial Rent Roll report—that examine only properties with the Commercial property type selected.

 Duplex

 This applies to homes or buildings that are split into two residential units that can house two separate families.

 Manufactured Housing

 Any neighborhood or residential park that is composed of prefabricated, single-family residences—such as a manufactured, mobile, or modular homes. These homes are built with standardized parts that are assembled in a factory and then transported to the lot. It is best practice to enter each residential lot as a unit on the property. Then for the prefabricated homes, enter them as home-type assets and link them to the according lot where they are located. This attaches the unit and lot to the same lease, but allows the unit location to be moved, rented, and/or tracked separately from the lot.

 Multi Family

 Any residential property that is built to house multiple families, but does not fit the Apartment or Duplex property types.

 RV/Campground

 Short-term rental properties such as campgrounds and RV parks. This option alters the property's attributes to account for shorter rental periods (generally a few days to a few months). Units at these properties can have one guest check out and another check in on the same day, and can have specific amenities and features established regarding lot size, amperage, and other attributes. You can also establish rate schedules for different time periods where rates change based on the length of stay, number of guests, season, day of the week, or holiday. For more information, refer to Short Term Rentals (STR) .

 Short Term Rental

 Any other type of short-term rental property, such as a hotel, vacation rental, or hostel. This option offers a simplified version of the RV/Campground property type that allows you to establish amenities, check a guest in on the same day another checked out, and focus on short-term rentals for guests.

 Single Family

 Any other home or property that is built to house only one family. This type is best suited to residential properties with a single unit and is not a lot with an attached home-type asset.

 Storage

 A property that provides only storage or other unlivable units. This is best suited to any financial entity that rents out to people, but does not have any occupants.

 More Information

 If you have a property that has occupants—such as an apartment complex or duplex—but also allows the lease holders to rent additional storage units, garages, or parking spaces, it is best practice to create assets for these additional options rather than a separate property. For more information, refer to Assets (Page) .
