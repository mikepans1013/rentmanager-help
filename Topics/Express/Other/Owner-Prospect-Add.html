Add an Owner Prospect

Owner prospects are potential owners that express interest having your fee-based management company manage the properties they own. The goal is to get owner prospects to sign a contract with your management company. This topic covers creating owner prospects in Rent Manager so you can track their information, their status, and the effectiveness of your marketing campaigns.

Step 1: Add Owner Prospect and General Information

Related Privileges

Group Privilege Column
Owners Owner Prospects Add, View

For more information, refer to Control User Access.

To create an owner prospect account, do the following:

  1. Go to arrow_forward Owners arrow_forward General arrow_forward Owner Prospects.
    The Owner Prospects page displays.

  2. At the top, click  Add Owner Prospect.

    On the left, the Owner Prospect Information tab is selected by default when you open the wizard.

  3. In the Account section, enter the owner prospect's information into the available fields described below.

    Field Description

    Name

    The name of the owner prospect, which is used when referencing the owner prospect throughout Rent Manager and for correspondence generated from Rent Manager to the owner prospect.

    Display Name

    The name that displays on the Owner Prospects list page. This is helpful if, for example, the owner prospect is a limited liability company (LLC) but you want to see a contact's name instead.

  4. In the Addresses section, enter the address(es) for the owner prospect. Check Default for the address you wish to use in reports and other areas of Rent Manager that pull the owner prospect's address.

  5. In the Miscellaneous section, enter additional account information into the available fields described below.

    Field Description

    Email

    The primary email address for this owner prospect, which is used for correspondence generated from Rent Manager.

    Display (Color)

    A color to help identify owner prospects of certain types, groups, or any other specifications you prefer. The color displays as a bar to the left of the owner prospect in some areas of Rent Manager, such as the Owner Prospect list page.

    Interest Level

    A general ranking from 0–10 (with 10 being the highest) to measure the level of interest that the owner prospect seems to have. The interest level that you enter here is reflected in the Owner Prospect Listing report.

    Application Date

    The date when the owner prospect applied. This date can be used in letter templates scripts for your owner prospects.

    Lead Source

    The main source of information that describes how this owner prospect learned about your company. This information is reflected in the Owner Prospect Box Score report and can give you insight on what types of marketing strategies are most effective for your company. For more information, refer to Owner Prospect Lead Sources (Page).

    Sales Rep

    The sales representative associated with this owner prospect. These are the Rent Manager users who frequently contact the owner prospect. You can filter the Owner Prospect Listing report by Sales Rep or compare the performance of your Sales Rep using the Owner Prospect Box Score report.

    More Information

    Only users designated as Sales Rep/Leasing Agent can be selected in this field. For more information, refer to User Details (Page).

    Comment

    Any additional comments or notes about the account. The comment can be used in scripting for letter templates and Report Writer.

  6. In the Phone Numbers section, enter any relevant phone numbers for the owner prospect. The available columns are described below.

    Column Description

    Default

    Check to set this phone number as the contact to use in reports and other areas of Rent Manager that pull the owner prospect's phone number. Only one default number can be selected for the owner prospect.

    Name

    The name of each phone number type that currently exists in Rent Manager.

    T (Is Text Ready)

    Check to mark the phone number as text-enabled, meaning the number can receive text messages.

    This is also used with Text Broadcasting to determine which phone numbers can be sent texts from Rent Manager.

    Number

    The full ten-digit phone number of the associated phone number type.

    Extension

    If applicable, the extension that must be dialed for this phone number.

  7. In the Original Contact section, enter additional contact information into the available fields described below.

    Field Description

    Original Contact

    The contact type of the initial contact method. The contact type displays in the Owner Prospect Box Score report.

    Contact Description

    The brief description of the original contact exchange. For example, Received an email from the prospect, they are interested in the Riverview property.

    Spoke with Prospect

    If you selected Call for the Original Contact, check if you actually spoke with the owner prospect. This lists the call in the Owner Prospect Box Score report.

    More Information

    The Enable "Spoke with prospect" on new calls by default option in the prospect system preferences determines if this option is checked by default. For more information, refer to Prospect (System Preferences).

    Contact Date Time

    The date and time of the first contact. For the owner prospect to display in the Owner Prospect Box Score report, the date you enter must be included in the report options.

Step 2: Enter Owner Prospect UDF Values

After entering the owner prospect's general information, select the User Defined Fields tab on the left. In the User Defined Fields section, only required UDFs display in the Name column. Required UDFs are marked with an asterisk (*) and must have a Value entered to create the owner prospect.

To view all the owner prospect-type UDFs in the database, click View All UDFs. For each UDF applicable to the owner prospect you are adding, enter or select the information in the Value column for the associated UDF. For more information, refer to Owner Prospect-Type User Defined Fields (Pop-Up).

Step 3: Save the New Owner Prospect

Once you have established the owner prospect-type UDFs, click Save and Finish to complete the owner prospect creation process and close the pop-up. Alternatively, click Save and New to finish adding the owner prospect and refresh the pop-up to add another owner prospect account.
