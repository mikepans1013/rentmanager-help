# Tenant Profile (Report)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Reports/Tenant-Profile.htm

The Tenant Profile report creates customizable, detailed breakdowns of the tenants at your selected properties, including basic information, lease details, addresses and phone numbers, user defined fields (UDFs), recurring charges, history/note items, transactions, and linked service issues. This report can be used to print the complete history of a tenant's residence for legal proceedings or to provide information to an external contact.

 Related Preferences

 Reports may look different depending on whether or not the Use modernized report style system preference is enabled. For more information, refer to General Report Options (System Preferences) .

 Report Options

 The report options described below determine what data displays in the report.

 Properties to Include

 Select each property or a property Group to be included in the report.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Optionally, check Show Inactive Properties to include properties that are no longer active.

 More Information

 Properties with the Property Type of RV/Campground or Short Term Rental do not display in this report. Short term rental property information is available in reports listed in the Short Term Rentals report category.

 Date Range

 Enter or select the date range to determine the data that displays in the report.

 In the Date Range section, set the From and To dates for which the report should examine data.

 These fields automatically populate with today’s date. Enter a different date or select a date from the calendar. Alternatively, adjust the dates using the available preset buttons or click to open more options for setting a date range.

 Run Properties Separately

 Check to generate a separate report for each selected property. Otherwise, all selected properties are combined into a single report.

 Tenants to Include

 Select an option to determine which accounts display in the report results.

 Option
 Description

 All

 All future, current, and past tenants display.

 Current

 All tenants with a Move In date on or before the report date and with either no Move Out date or a Move Out date after the selected date display.

 Past

 All tenants with a Move Out date set before the selected date display.

 Show on Report

 Select from the following options to determine which sections display:

 Option

 Recurring Charges

 Includes a Recurring Charges section containing all recurring charges for each account.

 Transaction History

 Includes a Transaction History section containing all transactions posted to the account during the Date Range .

 Includes a History/Notes section containing all history/note items posted to the account during the Date Range .

 Includes a Service Issues section containing all associated issues that were created during the Date Range .

 Includes the DOB (Date of Birth) and Age fields in the report.

 Sort Options

 Select one of the following options to determine the order in which profiles generate:

 Option
 Description

 Account Number

 Last Name

 Profiles are sorted alphabetically by the tenant's Last Name .

 Report Results

 The report results are described below including, if applicable, section, column, and subreport or tab descriptions.

 Report Header

 The report header displays the report name and key information selected in the report options, such as date information and which properties were examined in the report.

 Account Info

 The Account Info section displays information from the tenant's details page as well as balance information.

 Field
 Description

 Account Name

 The full name of the tenant in last name, first name format.

 Account Number

 The tenant's system-generated account number.

 Property

 The tenant's default property, as specified in the tenant's Rental Info tile.

 Comments

 The note or memo entered in the tenant's Comment field.

 SD Held

 The amount being held for the tenant as a security deposit as of today's date, as displayed in the tenant's scoreboard.

 More Information

 If a security deposit does not display in the report results, you should check for the following:

 -
 Confirm the charge type is selected as a security deposit charge type in the security deposit options system preferences. For more information, refer to Security Deposit General Options (System Preferences) .

 -
 On the tenant's account, ensure a payment has been allocated to the charge.

 -
 On the security deposit transaction, ensure that the unit selected in the Unit field is linked to same unit where the security deposit is being held.

 Balance Due

 The tenant's unpaid balance as of today's date, as displayed in the tenant's scoreboard or in the Transactions tile.

 Oldest Charge

 The date of the oldest unpaid charge on the tenant's account, as displayed in the tenant's View Transactions pop-up.

 Primary Contact Info

 The Primary Contact Info section displays basic information about each tenant. Unless otherwise noted, all fields display as they are entered in the tenant's View Contacts pop-up. If an image of the tenant is uploaded on the tenant's View Contacts pop-up, that image displays.

 Field
 Description

 First Name

 The first name of the Primary contact.

 Last Name

 The last name of the Primary contact.

 Tax ID

 The Soc Sec # of the Primary contact with the first five digits masked.

 Employer

 The employer of the Primary contact.

 License Plate

 The license plate number of the Primary contact's vehicle.

 Car Description

 The description of the Primary contact's Vehicle .

 DOB

 The Birthday of the Primary contact.

 Age

 The age of the Primary contact.

 Default Address

 The address marked as Default in the tenant's Addresses tile.

 Default Phone

 The phone number marked as Default in the Primary contact's Phone Numbers section.

 Email

 The email address of the Primary contact.

 The Lease Information section displays a breakdown of tenant leases. The following columns display in the section.

 Column
 Description

 Property

 The property associated with each lease.

 The name of each unit the tenant is leasing.

 The category, or unit type, of each unit the tenant is leasing.

 The lease term selected for each of the tenant's leases.

 The date on which each of the tenant's leases expire.

 The date on which the tenant began occupying the unit for each lease.

 Move Out

 The date on which the tenant moved out or will move out of each unit.

 User Defined Fields

 The User Defined Fields section displays information about any tenant-type user defined fields (UDFs) entered for the tenant in the following columns:

 Column
 Description

 Name

 The name of each tenant-type UDF.

 Value

 The value entered or selected for each tenant-type UDF.

 Recurring Charges

 The Recurring Charges section displays information about the recurring charges set up for or inherited by the tenant. The following columns display in the section.

 Column
 Description

 Charge Type

 The charge type used by each recurring charge.

 Amount

 The amount that posts to the tenant's account each time the recurring charge is posted.

 Comment

 The comment entered for each recurring charge.

 Frequency

 How often each recurring charge posts to the tenant's account.

 More Information

 The Frequency is calculated as a number of months, weeks, or days that should elapse between each posting of the recurring charge. For example, 1 means the recurring charge is posted once every month/week/day. 3 means the recurring charge is posted once every three months/weeks/days.

 From Date

 The date on which each recurring charge went into effect.

 To Date

 The date after which each recurring charge is no longer active.

 Open Receivables

 The Open Receivables section displays information about each charge posted to the tenant's account that has not yet been fully paid as of today's date. The following columns display in the section.

 Column
 Description

 Date

 The date on which the charge was posted to the tenant's account, as displayed in the tenant's View Transactions pop-up.

 Description

 The description of each unpaid charge, as displayed in the tenant's View Transactions pop-up.

 Original

 The full Amount of each unpaid charge, as displayed in the tenant's View Transactions pop-up.

 Paid Amount

 The amount of each charge that has previously been paid by the tenant.

 Remaining

 The amount of each charge still left to be paid, calculated using the following formula:

 Remaining Amount = Original Amount - Paid Amount

 Column
 Description

 The date on which each charge or payment was posted to the tenant's account.

 Reference

 The Reference # entered for each charge or payment.

 Description

 The description of the charge type used to post each charge to the tenant's account.

 More Information

 Payments display Payment Received as the description.

 Comment

 The comment entered for each charge or payment.

 Amount

 The amount of each charge posted to the tenant's account during the Date Range .

 Balance

 The tenant's running balance as each charge or payment was posted to their account.

 History/Notes

 The History/Notes section displays information about any history/note items entered for the tenant during the selected Date Range in the following columns:

 Column
 Description

 The type of each history/note item entered for the tenant, such as Email .
