Loans Payable Listing (Report)

The Loans Payable Listing report displays a list of the loans you have borrowed from financial institutions for your business as of a specified date. Payable loans are typically used for mortgages but can also be used for other loan types such as for land, equipment, appliances, auto, and so on. This report allows you to track information about each of your loans such as how much you pay monthly, the total borrowed amount, and the remaining balance yet to be paid.

More Information

The results can include any transaction information even if it started prior to the general ledger (GL) start date since this report does not consider the GL start date.

Related Privileges

Additionally, on the Reports tab, you must have access to Loans Payable Listing.

For more information, refer to Control User Access.

To view the Loans Payable Listing report, do the following:

  1. Go to arrow_forward Payables arrow_forward Loans Payable arrow_forward Loans Payable Listing.
    The Reports: Loans Payable Listing page displays.

  2. Adjust the report options as desired. Each option is described below.

  3. Generate the report in your desired file format(s).

Related Preferences

Reports may look different depending on whether or not the Use modernized report style system preference is enabled. For more information, refer to General Report Options (System Preferences).

Report Options

The report options described below determine what data displays in the report.

Properties to Include

Select each property or a property Group to be included in the report.

More Information

This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property.

Optionally, check Show Inactive Properties to include properties that are no longer active.

As of Date

Rent Manager examines relevant report information as of (up through) the date entered to determine the data that displays in the report.

Run Properties Separately

Check to generate a separate report for each selected property. Otherwise, all selected properties are combined into a single report.

Include Closed Loans

Check to include loans that were paid off or refinanced in the report results.

Sort Options

Select one of the following options to determine how the report results are organized:

Option Description

Name

Loans are sorted alphabetically by each loan's Name.

Property

Loans are sorted alphanumerically by the short name of the associated Property. Loans at the same property are further sorted alphabetically by loan Name.

Loan Number

Loans are sorted numerically by their Loan Number in ascending order (lowest to highest).

Lender

Loans are sorted alphanumerically by the vendor account selected as the loan's Lender. Loans from the same lender are further sorted alphabetically by loan Name.

Origination Date

Loans are sorted chronologically by Origination Date in ascending order (oldest to newest).

Maturity Date

Loans are sorted chronologically by Maturity Date in ascending order (soonest to farthest in the future).

Interest Rate

Loans are sorted numerically by their Interest Rate percentage in ascending order (lowest to highest).

Original Principal

Loans are sorted numerically by their Original Principal amount in ascending order (lowest to highest).

Payment

Loans are sorted numerically by their monthly Payment amount in ascending order (lowest to highest).

Remaining Principal

Loans are sorted numerically by their Remaining Principal amount in ascending order (lowest to highest).

Report Results

The report results are described below including, if applicable, section, column, and subreport descriptions.

Report Header

The report header displays the report name and key information selected in the report options, such as date information and which properties were examined in the report.

Column Descriptions

The columns that display in the report are described below.

Column Description

Name

The unique name of the loan as it displays in Rent Manager.

Property

The property where financial transactions associated with the loan are recorded.

Loan Number

The number assigned to the loan by the lender.

Lender

The financial institution that provided the loan and receives payments from you. The lender is a vendor account in Rent Manager.

Origination Date

The date on which the lender delivered the loan funds.

Maturity Date

The date on which the final loan payment is due.

Interest Rate

The interest rate applied to the loan.

Original Principal

The full, original dollar amount that was loaned to you.

Payment

The total dollar amount you pay towards the loan each month.

Remaining Principal

The remaining loan balance yet to be paid.
