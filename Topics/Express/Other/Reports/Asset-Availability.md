# Asset Availability (Report)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Reports/Asset-Availability.htm

The Asset Availability report displays the active assets in your database that have This asset is rentable enabled, but are not currently associated with a lease.

 For more information, refer to Control User Access .

 To view the Asset Availability report, do the following:

 -
 Go to arrow_forward Assets arrow_forward General arrow_forward Asset Availability .
The Reports: Asset Availability page displays.

 -
 Adjust the report options as desired. Each option is described below.

 -
 Generate the report in your desired file format(s).

 Related Preferences

 Reports may look different depending on whether or not the Use modernized report style system preference is enabled. For more information, refer to General Report Options (System Preferences) .

 Report Options

 The report options described below determine what data displays in the report.

 Properties to Include

 Select each property or a property Group to be included in the report.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Optionally, check Show Inactive Properties to include properties that are no longer active.

 As of Date

 Rent Manager examines relevant report information as of (up through) the date entered to determine the data that displays in the report.

 Asset Types to Include

 Check each asset type to be included in the report. The report displays assets with the selected types applied on the Asset details page. For more information, refer to Asset Types (Page) .

 Asset Statuses to Include

 Check each asset status to be included in the report. The report displays assets with the selected statuses applied on the Asset details page. For more information, refer to Asset Statuses (Page) .

 Run Properties Separately

 Check to generate a separate report for each selected property. Otherwise, all selected properties are combined into a single report.

 Report Results

 The report results are described below including, if applicable, section, column, and subreport or tab descriptions.

 Report Header

 The report header displays the report name and key information selected in the report options, such as date information and which properties were examined in the report.

 More Information

 If all of the assets in the report results have an asset type with Assets of this type are homes checked, or there are no results, the report's title displays as Home Availability .

 Column Descriptions

 The columns that display in the report are described below.

 Column
 Description

 Address

 The address of the unit the asset is currently assigned to as selected on the asset's details page in the Asset Location or Home Location section.

 For assets not assigned to a unit, this column is blank.

 Asset Name

 The unique name of the asset as entered on the asset's details page in the Name field.

 Asset Type

 The category of asset selected on the asset's details page in the Asset Type field.

 Current Status

 The active asset status as displayed on the asset's details page in the Asset Status History or Home Status History tile. For more information, refer to Asset Statuses (Page) .

 Days Vacant

 For assets that have a past lease, the report displays the number of days after the last Move Out through the As of Date .

 If the asset has never been leased, -- displays.

 Market Rent

 The asset’s rental rate as entered on the asset's details page in the Market Rent field.

 Unit

 The unit the asset is currently assigned to, which is set on the asset's details page on the Asset Location or Home Location tile.

 For assets not assigned to a unit, this column is blank.
