Management Fee Breakdown (Report)

The Management Fee Breakdown report displays details about the calculation of standard management fee checks that are dated during the specified date range. You may wish to provide this report to an owner to show them how their fees were calculated. Additionally, this report can be used as a supplement to the Owner Statement report.

More Information

This report is intended for use with standard management fee calculations, which are based upon charge type activity. If you are using an advanced management fee structure, this report will not have relevant data.

Related Privileges

Group Privilege Column
Letter/Email Templates/Reports/Packets Run reports Enabled

Additionally, on the Reports tab, you must have access to Management Fee Breakdown.

For more information, refer to Control User Access.

To view the Management Fee Breakdown report, do the following:

  1. Go to  arrow_forward Owners arrow_forward Management Fees arrow_forward Management Fee Breakdown.
    The Reports: Management Fee Breakdown page displays.

  2. Adjust the report options as desired. Each option is described below.

  3. Generate the report in your desired file format(s).

Related Preferences

Reports may look different depending on whether or not the Use modernized report style system preference is enabled. For more information, refer to General Report Options (System Preferences).

Report Options

The report options described below determine what data displays in the report.

Owners to Include

Select each owner or an owner Group to be included in the report.

More Information

Only information related to the properties to which you have access displays. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property.

Optionally, check Inactive Owners to include owners that are no longer active.

Optionally, check Show Inactive Properties to include properties that are no longer active.

Date Range

Enter or select the date range to determine the data that displays in the report.

In the Date Range section, set the From and To dates for which the report should examine data.

These fields automatically populate with today’s date. Enter a different date or select a date from the calendar. Alternatively, adjust the dates using the available preset buttons or click to open more options for setting a date range.

Detail or Summary

This option determines how much information is displayed in the report.

Option Description

Detail

Displays the management fee postings with each payment allocation on a separate line item for each of the fee setup's charge type.

Summary

Displays the total amount of payment allocations for the fee setup's charge type in each management fee posting.

Run Properties Separately

Check to generate a separate report for each property for the selected owners. Otherwise, all selected owners' properties are combined into a single report per owner.

Include Pass Throughs

Check to include an additional Pass Through Amount column on the report that displays the total amount of fees collected via pass through.

Report Results

The report results are described below including, if applicable, section, column, and subreport descriptions.

Report Header

The report header displays the report name and key information selected in the report options, such as date information and which properties were examined in the report.

Column Descriptions

The report generates with different columns depending on the report options selection in the Detail or Summary section. Each output based on the report option is described below.

Detail

If the report option for Detail is checked, the following columns display.

Column Description

Unit

The Unit Name associated with the charge.

Tenant

The name of the tenant that was charged.

Date Charged

The date of the charge.

Amount Charged

The amount posted during the report date range.

Date Paid

The date the payment was received.

Amount Paid

The amount of the payment allocated to the charge.

Pass Through Amount

The amount of fees collected via pass through. This column displays only if the Include Pass Throughs report option is checked.

Fee Amount

The amount collected by the management company as a fee.

Summary

If the report option for Summary is checked, the following columns display.

Column Description

Posting

The date of the management fee check, with each charge type below.

Charge type names are followed by the fee percentage due to the management company.

Charge Amount

The amount posted during the report date range.

Payment Amount

The amount of the payment allocated to the charge.

Pass Through Amount

The amount of fees collected via pass through. This column displays only if the Include Pass Throughs report option is checked.

Fee Amount

The amount collected by the management company as a fee.

Other Fees Subreport

These fees are populated from the Fees Setup page for each property.

Fee Description

Flat Fee

The amount posted for Monthly Flat Fee as specified on the Fees Setup page.

Per Occupied Fee

the amount posted for Per Occupied Fee as specified on the Fees Setup page.

Per Unit Fee

The amount posted for Monthly Per Unit Fee as specified on the Fees Setup page.

Minimum Fee

The amount posted for Min Fee as specified on the Fees Setup page.

Maximum Fee

The amount posted for Max Fee as specified on the Fees Setup page.

Report Totals Subreport

At the bottom of the Management Fee Breakdown report, totals for all the values in the report display.

Field Description

Amount Charged

The total amount posted during the report date range.

Amount Paid

The total amount of the payment allocated to the charges.

Fee Amount

The total amount collected by the management company as a fee.

Pass Through Amount

The total amount of fees collected via pass through. This column displays only if the Include Pass Throughs report option is checked.
