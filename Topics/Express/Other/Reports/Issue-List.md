# Issue List (Report)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Reports/Issue-List.htm

The Issue List report displays all issues in the selected issue list as it is set up on the Issues page.

 More Information

 To update the filter criteria for an issue list, go to arrow_forward Services arrow_forward Service Manager arrow_forward Issues , then click Filters . The issues that display in the list also display in the report.

 To view the Issue List report, do the following:

 -
 Go to arrow_forward Services arrow_forward  Service Manager arrow_forward Issue List .
The Reports: Issue List page displays.

 -
 Adjust the report options as desired. Each option is described below.

 -
 Generate the report in your desired file format(s).

 Related Preferences

 Reports may look different depending on whether or not the Use modernized report style system preference is enabled. For more information, refer to General Report Options (System Preferences) .

 Report Options

 The report options described below determine what data displays in the report.

 Select a List

 Select a saved issue list to display all associated issues in the report.

 Report Results

 The report results are described below including, if applicable, section, column, and subreport or tab descriptions.

 Report Header

 The report header displays the filter criteria established for the selected issue list, such as the property, assigned user, and issue status associated with the list.

 Column Descriptions

 The columns that display in the report are described below.

 Column
 Description

 Age

 The amount of time that has elapsed since the issue was created, in the d/h/m format.

 Assigned To

 The Rent Manager user to whom the issue is currently assigned.

 Category

 The issue category (e.g., Property Wide , Maintenance , Emergency , Plumbing , etc.) to sort and track types of service issues.

 Closed

 Displays No if the issue is open and Yes if the issue has the Close Date field checked on the issue's details page.

 Closed

 For closed issues, the Closed date as entered on the issue's details page.

 Created By

 The Rent Manager user that created the issue.

 Due

 The date by which the issue needs to be completed, as entered on the issue's details page in the Due field.

 Issue

 The name of the service issue (e.g., Replace Locks , Check Water Meter , Change Furnace Filters , etc.).

 Issue #

 The system-generated number of the issue.

 Open Date

 The date and time entered in the Open Date field on the issue's details page. This date may display as a future date if the Open Date field was manually changed.

 Priority

 The issue priority that describes the urgency of the issue (e.g., Low , Medium , High , etc.).

 Status

 The issue status to describe the current progress of this issue (e.g., New , Work in Progress , Unresolved , Resolved , etc.).
