Inbound Calls by Phone Number (Report)

The Inbound Calls by Phone Number report displays rmVoIP activity in the selected date range for inbound calls to your business. The report results are grouped by phone number within your organization. Each phone number displays its inbound phone calls, to what extension and extension name each phone call was routed, the date and time, duration, the caller's phone number, and any additional information.

Related Preferences

This report is available only if you have rmVoIP Enabled in system preferences. For more information, refer to rmVoIP (System Preferences).

Related Privileges

Group Privilege Column
Letter/Email Templates/Reports/Packets Run reports Enabled

Additionally, on the Reports tab, you must have access to Inbound Calls by Phone Number.

For more information, refer to Control User Access.

To view the Inbound Calls by Phone Number report, do the following:

  1. Go to arrow_forward Communication arrow_forward rmVoIP arrow_forward Inbound Calls by Phone Number.
    The Reports: Inbound Calls by Phone Number page displays.

  2. Adjust the report options as desired. Each option is described below.

  3. Generate the report in your desired file format(s).

Report Options

The report options described below determine what data displays in the report.

Date Range

Enter or select the date range to determine the data that displays in the report.

In the Date Range section, set the From and To dates for which the report should examine data.

These fields automatically populate with today’s date. Enter a different date or select a date from the calendar. Alternatively, adjust the dates using the available preset buttons or click to open more options for setting a date range.

Associated Phone Numbers

Check each phone number to be included in the report. To quickly select all phone numbers listed, check the box in the section header.

Report Results

The report results are described below including, if applicable, section, column, and subreport or tab descriptions.

Report Header

The report header displays the report name and key information selected in the report options, such as date information and which properties were examined in the report.

Column Descriptions

The columns that display in the report are described below.

Column Description

Extension

The extension number receiving the inbound call.

Extension Name

The name of the extension receiving the inbound call.

Call Date

The date the inbound call was received.

From

The phone number of the inbound caller.

Information

Any information about the inbound caller, such as a business name.

Duration

The length of time of the call, in HH:MM:SS (Hours:Minutes:Seconds) format.

Calls Summary Subreport

This subreport in print view or tab in grid view displays the number of inbound phone calls and the total duration of those calls for each of your organization's phone numbers during the report's date range.

The following columns appear in the subreport/tab:

Column Description

Phone Number

The phone number within your organization that received the inbound call.

Count

The total amount of calls for that phone number.

Duration

The length of time of the call, in HH:MM:SS (Hours:Minutes:Seconds) format.
