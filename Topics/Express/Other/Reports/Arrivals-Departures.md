# Arrivals/Departures (Report)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Reports/Arrivals-Departures.htm

The Arrivals/Departures report provides a listing of guests (tenants and prospects with reservations) at selected short-term rental (STR) properties who have Arrival and/or Departure dates within the specified date range. The report also provides general information about each guest, such as their contact information and check-in status, which can help you build check-in and maintenance workflows for your business. For more information, refer to Short Term Rentals (STR) .

 Related Preferences

 Reports may look different depending on whether or not the Use modernized report style system preference is enabled. For more information, refer to General Report Options (System Preferences) .

 Report Options

 The report options described below determine what data displays in the report.

 Properties to Include

 Select each property or a property Group to be included in the report. Only properties with a Property Type of RV/Campground or Short Term Rental display in the list.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Optionally, check Show Inactive Properties to include properties that are no longer active.

 Sort Options

 Select one of the following options to determine how the report results are sorted.

 Option
 Description

 Arrival

 Guests are sorted chronologically by their Arrival date in ascending order (earliest to latest).

 Departure

 Guests are sorted chronologically by their Departure date in ascending order (earliest to latest).

 Last Name

 Guests are sorted alphabetically by their Last Name .

 Unit

 Guests are sorted alphanumerically by Unit name.

 Unit Type

 Guests are sorted alphanumerically by Unit Type name.

 Date Range

 Enter or select the date range to determine the data that displays in the report.

 In the Date Range section, set the From and To dates for which the report should examine data.

 These fields automatically populate with today’s date. Enter a different date or select a date from the calendar. Alternatively, adjust the dates using the available preset buttons or click to open more options for setting a date range.

 Include Arrivals and Departures

 Select an option from to determine the data that displays in the report.

 Option
 Description

 Arrival and Departures

 All guests with a reservation that starts and/or ends during the selected Date Range display.

 Arrivals

 Only guests with a reservation Arrival date during the selected Date Range display.

 Departures

 Only guests with a reservation Departure date during the selected Date Range display.

 Run Properties Separately

 Check to generate a separate report for each selected property. Otherwise, all selected properties are combined into a single report.

 Report Results

 The report results are described below including, if applicable, section, column, and subreport or tab descriptions.

 Report Header

 The report header displays the report name and key information selected in the report options, such as date information and which properties were examined in the report.

 Column Descriptions

 This report is organized by property and information about each property is organized into columns. The columns that display in the report are described below.

 More Information

 Depending on your selection in the Include Arrivals and Departures report option, the report displays the section(s) for Arrivals , Departures , or both.

 Column
 Description

 # of Nights

 The calculated number of nights between the Arrival date and the Departure date.

 If no Departure date is entered, this value displays 0 .

 Arrival

 The first date of the guest's reservation.

 Checked In

 Displays Yes if the guest was checked in to their unit; otherwise, No displays.

 Departure

 The final date of the guest's reservation. Rent Manager automatically ends the rental on the specified departure date.

 Name

 The guest's first and last name.

 Phone

 The phone number of the guest.

 Returning Guest

 Displays Yes if the guest has had a reservation at the property before; otherwise, this is blank.

 Unit

 The Unit Name of the unit associated with the guest's reservation.

 Report Summary

 This subreport displays regardless of the report options selected and provides a breakdown of all guests that were included in the report.

 The subreport displays rows which each provide information on a Detail from the report and its according Value :

 Row
 Description

 Arrivals

 The number of guest check-ins that occurred during the date range.

 Date Range

 The date range entered in the report options.

 Days in range

 The total number of days in the date range, including both the From and To dates.

 Departures

 The number of guest check-outs that occurred during the date range.

 Net Change in Occupancy

 The number of guest check-ins minus the number of guest check-outs that occurred during the date range.

 Total Arrivals/Departures

 The number of guest check-ins plus the number of guest check-outs that occurred during the date range.
