Violations (Report)

The Violations report tracks tenants that have had violations posted to their accounts across a date range, including the violation code used, the date of the violation, and the due date of the violation's resolution. The report can also display the history/notes for each violation to track its escalation.

Related Privileges

Group Privilege Column
Letter/Email Templates/Reports/Packets Run reports Enabled

Additionally, on the Reports tab, you must have access to Violations.

For more information, refer to Control User Access.

To view the Violations report, do the following:

  1. Go to arrow_forward Rental Info arrow_forward Tenants arrow_forward Violations.
    The Reports: Violations page displays.

  2. Adjust the report options as desired. Each option is described below.

  3. Generate the report in your desired file format(s).

Related Preferences

Reports may look different depending on whether or not the Use modernized report style system preference is enabled. For more information, refer to General Report Options (System Preferences).

Report Options

The report options described below determine what data displays in the report.

More Information

The option(s) selected in the Date Restriction On report option determines which date(s) Rent Manager examines within the Date Range report option.

Properties to Include

Select each property or a property Group to be included in the report.

More Information

This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property.

Optionally, check Show Inactive Properties to include properties that are no longer active.

Date Range

Enter or select the date range to determine the data that displays in the report.

In the Date Range section, set the From and To dates for which the report should examine data.

These fields automatically populate with today’s date. Enter a different date or select a date from the calendar. Alternatively, adjust the dates using the available preset buttons or click to open more options for setting a date range.

Violations to Include

Select Open, Closed, All, or None to determine which types of violations display in the report results.

Date Restriction On

Select one of the following options to determine how violations are displayed in the report results:

Option Description

Violation Date

Violations with a Violation Date that falls within the selected Date Range display.

Violation Due Date

Violations with a Due Date that falls within the selected Date Range display.

Violation Notes Options

Check and enter a value in Violation Notes to display the violation's most recent History/Notes in the report. If this option is not checked, the Notes column does not display.

Run Properties Separately

Check to generate a separate report for each selected property. Otherwise, all selected properties are combined into a single report.

Sort Options

Select one of the following options to determine how the report results are sorted within each association-type property subheading.

For tenants with multiple violations, all violations are listed as a new line entry below their first violation with the Tenant Name column left blank.

Option Description

Account Number

Violations are sorted numerically by their tenant's system-generated ID number in ascending order (lowest to highest).

Last Name

Violations are sorted alphabetically by their tenant's Last Name.

Unit

Violations are sorted alphanumerically by Unit name. Accounts with no unit display first in the results.

Violation Date

Violations are sorted chronologically by their Violation Date in ascending order (oldest to newest).

Violation Due Date

Violations are sorted chronologically by their Violation Due Date in ascending order (oldest to newest).

Report Results

The report results are described below including, if applicable, section, column, and subreport descriptions.

Report Header

The report header displays the report name and key information selected in the report options, such as date information and which properties were examined in the report.

Column Descriptions

The columns that display in the report are described below.

Column Description

Tenant

The name of the tenant who had violations posted to their account (or who has violation resolutions due) during the Date Range.

Unit

The name of the unit where the tenant resides.

Date

The Violation Date for each violation posted to the tenant account. Multiple violations are displayed one after the other, grouped below the tenant's name.

Code

The code or rule of which the tenant is in violation. For more information, refer to Violation Code Group Details (Page).

Status

The status (Open or Closed) for each violation posted to the tenant account.

Stage

The current stage of each violation posted to the tenant account as displayed in the Violation Details. For more information, refer to Violation Details (Page).

More Information

Violation stages can be defined in violation code groups stages or for each code individually. For more information, refer to Violation Code Groups (Page).

Due Date

The date in which the tenant must resolve the violation before escalation for each violation posted to the tenant account as displayed in the Violation Details.

Description

The explanation of why the violation was created for each violation posted to the tenant account as displayed in the Violation Details.

Notes

The X most recent history/notes entered on the Violation Details, where X is the value defined in the Violation Notes Option field.
