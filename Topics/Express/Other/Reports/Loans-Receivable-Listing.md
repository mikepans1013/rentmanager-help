# Loans Receivable Listing (Report)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Reports/Loans-Receivable-Listing.htm

The Loans Receivable Listing displays a breakdown of all loans issued as of the selected date. This report can be used as a quick reference document to see the total principal balance and payoff progress of your loans.

 More Information

 The results can include any transaction information even if it started prior to the general ledger (GL) start date since this report does not consider the GL start date.

 Reports may look different depending on whether or not the Use modernized report style system preference is enabled. For more information, refer to General Report Options (System Preferences) .

 Report Options

 The report options described below determine what data displays in the report.

 Properties to Include

 Select each property or a property Group to be included in the report.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Optionally, check Show Inactive Properties to include properties that are no longer active.

 As of Date

 Rent Manager examines relevant report information as of (up through) the date entered to determine the data that displays in the report.

 Open Loans Only

 Check to exclude loans that are defaulted or paid-off from the report results.

 Sort Options

 Select one of the following options to determine how the report results are sorted in each property subheading:

 Option
 Description

 Reference

 Tenants are sorted numerically by their loan's system-generated Reference number in ascending order (lowest to highest).

 Tenant

 Tenants are sorted alphabetically by First Name .

 Report Results

 The report results are described below including, if applicable, section, column, and subreport descriptions.

 Report Header

 The report header displays the report name and key information selected in the report options, such as date information and which properties were examined in the report.

 Column Descriptions

 The report is organized by property with the total number of loans displayed below each .The columns that display in the report are described below.

 Column
 Description

 Tenant

 The name of each tenant with a loan.

 Unit Name

 The name of the unit the tenant is leasing.

 Reference

 The loan's Reference number, as entered on the loan's details page.

 Origination Date

 The date on which the funds were initially disbursed to each tenant.

 Maturity Date

 The date on which the final loan payment is scheduled to be made for each loan.

 Original Principal

 The original amount of each loan.

 Payment Due

 The amount of payment due as of the report date for each loan.

 Interest Rate

 Each loan's current Interest Rate , as displayed in the Rate Schedule tile on the loan's details page.

 Principal Balance

 Each loan principal's remaining balance as of the report date.

 Report Summary

 This subreport displays the sum total dollar amount of all loans in the report, including the total original principal amount and the current principal balance.
