# Vendor Listing (Report)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Reports/Vendor-Listing.htm

The Vendor Listing report displays vendors and the total number and amount of check and/or credit card payments made to them over the course of a selected date range. You can use this information to get a broad overview of your vendors to see vendor accounts that are not being used or export the information for external use.

 More Information

 The results can include any transaction information even if it started prior to the general ledger (GL) start date since this report does not consider the GL start date.

 Report Options

 The report options described below determine what data displays in the report.

 Properties to Include

 Select each property or a property Group to be included in the report.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Optionally, check Show Inactive Properties to include properties that are no longer active.

 Date Range

 Enter or select the date range to determine the data that displays in the report.

 In the Date Range section, set the From and To dates for which the report should examine data.

 These fields automatically populate with today’s date. Enter a different date or select a date from the calendar. Alternatively, adjust the dates using the available preset buttons or click to open more options for setting a date range.

 Exclude Records with Zero Amounts From the Report

 Check to remove vendors from the report results if they received no payments.

 Include Inactive Vendors

 Check to include vendors who do not have Active checked on the General tile of the Vendor details page in the report results.

 Exclude Financial Information From the Report

 Check to remove the Payment Count and Payments columns from the report results.

 Sort Options

 Select one of the following options to determine how the report results are sorted:

 Option
 Description

 1099 Vendor

 Vendors are sorted alphabetically by the vendor's name, with any vendors marked as a 1099 vendor listed first.

 Account Number

 Vendors are sorted numerically in ascending order by the Acc. # .

 PaymentCount

 Vendors are sorted numerically in ascending order by the # of Payments .

 Payments

 Vendors are sorted numerically in ascending order by the Payments .

 Vendor

 Vendors are sorted alphabetically by the vendor's name.

 Report Results

 The report results are described below including, if applicable, section, column, and subreport descriptions.

 Report Header

 The report header displays the report name and key information selected in the report options, such as date information and which properties were examined in the report.

 Column Descriptions

 The columns that display in the report are described below.

 Column
 Description

 Vendor

 The Name of the vendor account as entered on the vendor's details page.

 Acc. #

 The Account Number of the vendor account as entered on the vendor's details page.

 Address

 The street address marked as Default for the vendor account.

 Phone Number

 The phone number marked as Default on the vendor's Primary contact.

 1099

 An X displays in this column if the vendor is marked as a 1099 Vendor .

 # of Payments

 The number of payments made to the vendor during the date range.

 Payments

 The total dollar amount of all payments made to the vendor during the date range.
