# Owner Listing (Report)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Reports/Owner-Listing.htm

The Owner Listing report displays information about past, current, and/or future owners, including their contact information, the properties in their portfolio, contract dates, and amount to hold in reserve.

 For more information, refer to Control User Access .

 To view the Owner Listing report, do the following:

 -
 Go to arrow_forward Owners arrow_forward General arrow_forward Owner Listing .
The Reports: Owner Listing page displays.

 -
 Adjust the report options as desired. Each option is described below.

 -
 Generate the report in your desired file format(s).

 Related Preferences

 Reports may look different depending on whether or not the Use modernized report style system preference is enabled. For more information, refer to General Report Options (System Preferences) .

 Report Options

 The report options described below determine what data displays in the report.

 As of Date

 Rent Manager examines relevant report information as of (up through) the date entered to determine the data that displays in the report.

 Detail or Summary

 This option determines how much information is displayed in the report.

 Option
 Description

 Detail

 Displays portfolio details and contract information for each associated owner account.

 Summary

 Displays condensed information about the associated owner account.

 Sort Options

 Select one of the following options to determine how the report results are organized within each owner's subheading:

 Option
 Description

 Address

 Owners are sorted alphanumerically by their Default address. Owners with no address display first in the results.

 Contract End

 Owners are sorted alphabetically by their Name .

 For owners with multiple ownerships, the properties are further sorted chronologically by the Contract End date in ascending order (oldest to newest). Properties with no Contract End date are listed first.

 Contract Start

 Owners are sorted alphabetically by their Name .

 For owners with multiple ownerships, the properties are further sorted chronologically by the Contract Start date in ascending order (oldest to newest).

 Name

 Owners are sorted alphabetically by their Name .

 For owners with multiple ownerships, the properties are further sorted alphanumerically by property name.

 Owners to Include

 Check each owner status to be included in the report.

 More Information

 Only information related to the properties to which you have access displays. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Option
 Description

 Past

 Includes owners who have expired contracts.

 Current

 Includes owners who have current contracts.

 More Information

 As long as at least one property in the owner's portfolio matches the criteria selected in this section, all of the owner's properties appear in the report. For example, if only Current owners are selected, the owner's current properties display as well as properties for which the owner's contract has expired.

 Future

 Includes owners either without contracts configured, or with contracts that start in the future.

 Report Results

 The report results are described below including, if applicable, section, column, and subreport or tab descriptions.

 Report Header

 The report header displays the report name and key information selected in the report options, such as date information and which properties were examined in the report.

 Column Descriptions

 The report generates with different columns depending on the report options selection in the Detail or Summary section. The report output that displays based on the report option selected is described below.

 Detail

 If you check the report option Detail , the following columns display.

 Column
 Description

 Owner Address

 The Address marked as Default on the Owner page for each owner.

 Phone Number: Default

 The phone number marked as Default on the Owner page for each owner.

 Property

 The Full Name of each property included in the owner's portfolio.

 Property Address

 The Address marked as Default on the Property page for each property.

 Contract Start

 The Start date of the contract for each property in the owner's portfolio as entered on the Property page.

 Contract End

 The End date of the contract for each property in the owner's portfolio as entered on the Property page.

 Ownership %

 The ownership percentage share of each property in the owner's portfolio as entered in the %  column on the Property page.

 Reserve

 The minimum amount to be held in Reserve for each property in the owner's portfolio as entered on the Property page.

 Summary

 If you check the report option Summary , the following columns display.

 Column
 Description

 Owner Address

 The Address marked as Default on the Owner page for each owner.

 Phone Number: Default

 The phone number marked as Default on the Owner page for each owner.
