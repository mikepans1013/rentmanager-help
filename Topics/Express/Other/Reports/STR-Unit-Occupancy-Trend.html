Short Term Rental (STR) Unit Occupancy Trend (Report)

The STR Unit Occupancy Trend report displays the percentage of time each unit at a short-term rental (STR) property was occupied during the specified period (month, quarter, or year) and date range. You can use this report to compare the occupancy percentage between units at STR properties and observe trends over time.

More Information

For information regarding STR occupancy at the property level, you can generate the STR Property Occupancy Trend report. For more information, refer to Short Term Rental (STR) Property Occupancy Trend (Report).

Related Privileges

Group Privilege Column
Letter/Email Templates/Reports/Packets Run reports Enabled

Additionally, on the Reports tab, you must have access to STR Unit Occupancy Trend.

For more information, refer to Control User Access.

To view the STR Unit Occupancy Trend report, do the following:

  1. Go to arrow_forward Short Term Rentals arrow_forward General arrow_forward STR Unit Occupancy Trend.
    The Reports: STR Unit Occupancy Trend page displays.

  2. Adjust the report options as desired. Each option is described below.

  3. Generate the report in your desired file format(s).

Related Preferences

Reports may look different depending on whether or not the Use modernized report style system preference is enabled. For more information, refer to General Report Options (System Preferences).

Report Options

The report options described below determine what data displays in the report.

More Information

The PDF report output can display up to 12 columns of data. To view more than 12 columns of data, you must generate the report in an Excel or CSV format.

Properties to Include

Select each property or a property Group to be included in the report. Only properties with a Property Type of RV/Campground or Short Term Rental display in the list.

More Information

This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property.

Optionally, check Show Inactive Properties to include properties that are no longer active.

Sort Options

Select one of the following options to determine how the report results are organized within each property subheading:

Option Description

Ascending

STR units are sorted numerically by Average occupancy percentage in ascending order (lowest to highest).

Descending

STR units are sorted numerically by Average occupancy percentage in descending order (highest to lowest).

Unit

STR units are sorted alphanumerically by Unit name.

Unit Type

STR units are first sorted alphanumerically by Unit Type name. Units with the same unit type are further sorted alphanumerically by Unit name.

Date Range

Enter or select the date range to determine the data that displays in the report.

In the Date Range section, set the From and To dates for which the report should examine data.

These fields automatically populate with today’s date. Enter a different date or select a date from the calendar. Alternatively, adjust the dates using the available preset buttons or click to open more options for setting a date range.

Period Options

Select the period for which to view the percentage of time each short term rental unit has been occupied. The columns that display in the report results vary based on your selection.

Option Description
Monthly

Each month in the date range, followed by the monthly average.
Quarterly

Each quarter in the date range, followed by the quarterly average.
Yearly

Each year in the date range, followed by the yearly average.

Run Properties Separately

Check to generate a separate report for each selected property. Otherwise, all selected properties are combined into a single report.

Report Results

The report results are described below including, if applicable, section, column, and subreport or tab descriptions.

Report Header

The report header displays the report name and key information selected in the report options, such as date information and which properties were examined in the report.

Column Descriptions

This report is organized by property, and information about each property is organized into columns. The columns that display in the report are described below.

Column Description

Average

The percentage of units included in the report that are occupied as of the date range, calculated using the following formula:

Average = occupied days in the date range / total days in the selected date range

The total average percentage of occupied units during the date range is recorded at the bottom of the column.

Period

The percentage of units included in the report that are occupied as of the period (month, quarter, or year), calculated using the following formula:

Period = occupied days in the period / total days in the selected period

The average percentage of occupied units during the period is recorded at the bottom of each period column.

More Information

The columns that display in the report depend on your selection in Period Options in the report options. A column is created for each month, quarter, or year for the Date Range.

Property

The full name of the short-term rental property as entered on the property's details page.

Total Units

The total number of units that display in the report for each property.

Unit

The name of the short-term rental unit.

Unit Type

The Unit Type as entered on the unit's details page.
