Utility Listing (Report)

The Utility Listing report displays details on the utility, contact information, and meter types. You can use this report to export a list of existing utilities to compare details or to print a physical copy for reference.

Related Privileges

Group Privilege Column
Letter/Email Templates/Reports/Packets Run reports Enabled

Additionally, on the Reports tab, you must have access to Utility Listing.

For more information, refer to Control User Access.

To view the Utility Listing report, do the following:

  1. Go to arrow_forward Services arrow_forward Metered Utilities arrow_forward Utility Listing.
    The Reports: Utility Listing page displays.

  2. Adjust the report options as desired. Each option is described below.

  3. Generate the report in your desired file format(s).

Related Preferences

Reports may look different depending on whether or not the Use modernized report style system preference is enabled. For more information, refer to General Report Options (System Preferences).

Report Options

The report options described below determine what data displays in the report.

Page Break

Select Continuous pages to allow multiple utilities to display on a page. Select New page each record to break to a new page for each utility.

Utilities to Include

Select each utility to be examined in the report.

Report Results

The report results are described below including, if applicable, section, column, and subreport descriptions.

Report Header

The report header displays the report name and key information selected in the report options, such as date information and which properties were examined in the report.

Section Descriptions

The sections that display in the report are described below.

Section Description

Contact Information

The contact's Name, Email Address, and phone number checked as Default on the utility details page.

Meter Types Defined to this Utility

The Meter Types selected on the Meter Readings Setup page.

Properties Defined to this Utility

The Properties associated with this utility as selected on the utility details page.

Short Name/Charge Type

The Short Name and Name for the charge type associated with this utility.

Utility Information

The Utility Name and address checked as Default on the utility details page. This section also includes any additional Comments added on the utility details page, and, if this utility uses the same meter as an existing utility, the Source utility displays. The Source that displays is the option selected on the utility details page as the Source Utility for Readings.
