# Retails Sales (Report)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Reports/Retail-Sales.htm

The Retail Sales report displays the retail sales amounts entered for commercial tenants at your properties for a selected month. The report allows you to see how your commercial tenants are performing while also showing the total amount of sales pulled in at your commercial properties. This is beneficial if you collect fees or negotiate rent charges based on the amount of sales your tenants generate.

 Related Preferences

 To track retail sales for your commercial tenants, the feature must first be enabled in system preferences. For more information, refer to Commercial (System Preferences) .

 Report Options

 The report options described below determine what data displays in the report.

 Properties to Include

 Select each property or a property Group to be included in the report.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Optionally, check Show Inactive Properties to include properties that are no longer active.

 More Information

 Properties with the Property Type of RV/Campground or Short Term Rental do not display in this report. Short term rental property information is available in reports listed in the Short Term Rentals report category.

 As of Date

 Rent Manager examines information as of the date entered to determine the data that displays in the report. Enter a date, or click to select a date.

 More Information

 The report displays retail sales amounts that have been entered for the month of the selected date.

 For example, to view retail sales for April of 2026 , enter any date that falls in the month of April in the year 2026 .

 Tenants to Include

 Select each desired option to determine which tenant accounts display in the report results.

 Option
 Description

 Current

 All tenants with a Move In date on or before the report date and with either no Move Out date or a Move Out date after the As of Date .

 Past

 All tenants with a Move Out date set before the As of Date .

 Future

 All tenants with a Move In date that is undefined or after the As of Date .

 Additionally, select one of the following options to further specify which tenant accounts display in the report results.

 Option
 Description

 Only tenants with sales

 Only tenants who have retail sales values entered for the month of the As of Date display.

 Only tenants without sales

 Only tenants who do not have retail sales values entered for the month of the As of Date display.

 All tenants

 All tenants, regardless of whether or not retail sales values are entered.

 Run Properties Separately

 Check to generate a separate report for each selected property. Otherwise, all selected properties are combined into a single report.

 Sort Options

 Select one of the following options to determine how the report results are sorted in each property subheading:

 Option
 Description

 Account Number

 Tenants are sorted numerically by their system-generated ID number in ascending order (lowest to highest).

 Address

 Tenants are sorted alphanumerically by their Default address. Tenants with no address display first in the list.

 Last Name

 Tenants are sorted alphabetically by their Last Name . Tenants marked as Company are sorted alphabetically by Company Name .

 Unit

 Tenants are sorted alphanumerically by Unit name.

 Unit Type

 Tenants are sorted alphanumerically by Unit Type name. Tenants with the same unit type are further sorted alphanumerically by Unit name.

 Report Results

 The report results are described below including, if applicable, section, column, and subreport descriptions.

 Report Header

 The report header displays the report name and key information selected in the report options, such as date information and which properties were examined in the report.

 Column Descriptions

 The columns that display in the report are described below.

 Column
 Description

 Acc. #

 The tenant's system-generated account ID number.

 Tenant

 The tenant's Company Name (or First Name and Last Name ) as entered on the tenant's details page.

 Unit

 The Name of the unit each tenant is currently leasing.

 Unit Type

 The category of unit that the tenant is currently leasing.

 Address

 The street as entered in the tenant Default address.

 Amount

 The total amount of retail sales that was recorded on the tenant's commercial lease for the month of the As of Date .
