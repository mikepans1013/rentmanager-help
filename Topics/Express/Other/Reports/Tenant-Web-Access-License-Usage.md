# Tenant Web Access License Usage (Report)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Reports/Tenant-Web-Access-License-Usage.htm

The Tenant Web Access License Usage report displays the Tenant Web Access (TWA) account information for tenants with registered accounts across all locations, including the total number of tenants registered for TWA. This report also provides login and lockout history for each account, which can help troubleshoot account access issues. Additionally, tenants must have a Tenant Web Access account to access the rmResident app, so you can use this report to confirm which tenants have never accessed Tenant Web Access or rmResident .

 Adjust the report options as desired. Each option is described below.

 -
 Generate the report in your desired file format(s).

 Related Preferences

 Reports may look different depending on whether or not the Use modernized report style system preference is enabled. For more information, refer to General Report Options (System Preferences) .

 Report Options

 The report options described below determine what data displays in the report.

 Tenants to Include

 Select each desired option to determine which accounts display in the report results.

 Option
 Description

 Current

 All tenants with a Move In date on or before the report date and with either no Move Out date or a Move Out date after the selected date display.

 Past

 All tenants with a Move Out date set before the selected date display.

 Future

 All tenants with a Move In date that is undefined or after the selected date display.

 Include Prospects

 Check to display prospect account information in the report results.

 Sort Options

 Select one of the following options to determine how the report results are sorted in each property subheading:

 Option
 Description

 Account Number

 Tenants are sorted numerically by their system-generated ID number in ascending order (lowest to highest).

 Last Name

 Tenants are sorted alphabetically by their Last Name . Tenants marked as Company are sorted alphabetically by Company Name .

 Unit

 Tenants are sorted alphanumerically by Unit name.

 Report Results

 The report results are described below including, if applicable, section, column, and subreport descriptions.

 Report Header

 The report header displays the report name and key information selected in the report options, such as date information and which properties were examined in the report.

 Column Descriptions

 The columns that display in the report are described below.

 Column
 Description

 Acc. #

 The system-generated account number assigned to each tenant upon creation.

 Last Lockout

 The full date and time when the tenant's Tenant Web Access account was last locked.

 Last Login

 The full date and time when the tenant last accessed their Tenant Web Access account.

 Locked Out

 If the account is actively locked, Yes displays. If the account is not locked, No displays.

 Property

 The Short Name of the property that the tenant is currently occupying.

 Tenant Name

 The account name of each tenant.

 Unit

 The name of the unit that the tenant is currently occupying.

 Username

 The email address the tenant uses to log in to their Tenant Web Access account.
