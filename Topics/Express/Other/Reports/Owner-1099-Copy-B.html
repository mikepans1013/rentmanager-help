Owner 1099 Copy B (Report)

The Owner 1099 Copy B report is designed so that you can print ownership information and the 1099-MISC form layout for owners that earned gross income from selected properties on standard copy paper. This 1099-MISC form is used for all miscellaneous information, and income from rental properties is always reported in Box 1 of the form. The printed form can then be mailed to owners and the IRS to satisfy the IRS requirements for 1099 forms. For information on purchasing Safeguard printable tax forms, refer to Safeguard Tax Forms.

More Information

This report is intended to be sent to recipients as a record of the amount you are reporting to the IRS. The Owner 1099 Copy B report cannot be used as a substitute for the Owner 1099 report to submit to the IRS. You should refer to the official IRS publications and consult with your accountant to determine the best way to provide copies to recipients.

Related Preferences

If your printer is not aligning with the IRS 1099's margins when printing the report, you can adjust the margins through system preferences. For more information, refer to Preprinted Forms (System Preferences).

To view the Owner 1099 Copy B report, do the following:

  1. Go to arrow_forward Owners arrow_forward Accounting arrow_forward Owner 1099 Copy B.
    The Reports: Owner 1099 Copy B page displays.

  2. Adjust the report options as desired. Each option is described below.

  3. Generate the report in your desired file format(s).

Report Options

The report options described below determine what data displays in the report.

Owners to Include

Select each owner or an owner Group to be included in the report.

More Information

Only information related to the properties to which you have access displays. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property.

Optionally, check Inactive Owners to include owners that are no longer active.

Optionally, check Show Inactive Properties to include properties that are no longer active.

Owner Name Source

Select from the following options to determine what information displays on the form for the RECIPIENT'S name.

Option Description

Owner Name

The owner's Name as entered on the owner's details page.

Payee

The Payee name as entered on the owner's details page.

User Defined Field

The value of an owner-level user defined field. Once selected, use the UDF Name drop-down list to select from your owner-level UDFs with a text field type. For more information, refer to Owner-Type User Defined Fields (Pop-Up).

If an owner has no value entered for the selected UDF, the Owner Name option is used for that owner instead.

Exclude Total Values Less Than $600

Check to display forms only for owners who earned more than $600 of gross income in the selected year in the report results.

Hide Complete SSNs/Tax IDs

Check to replace all but the last four digits of the owner's Tax ID as entered on the Owner page with Xs.

Mark as Corrected

Check Mark to print an X in the Corrected box for all generated 1099 reports. Select Yes on the pop-up to mark the 1099 as corrected, or No to return to the report options.

Batch

Check Run owners separately to generate a separate report for each owner. Otherwise, all selected owners are combined into a single report.

Optionally, also check Exclude empty reports to remove reports with no data from the report results.

Year

Select the desired calendar year to display the gross income earned by the selected active owner(s) during that year.

Report Results

The report results are described below including, if applicable, section, column, and subreport or tab descriptions.

Report Header

The report header displays the report name and key information selected in the report options, such as date information and which properties were examined in the report.

Field Descriptions

The fields that display in the report are described below.

Field Description

PAYER's name

The name and default address of your property management company.

PAYER's TIN

The Property Tax ID for the property management company.

RECIPIENT's TIN

The Tax ID or social security number for each owner as entered on Owner details page.

RECIPIENT's name

By default, the owner's Name and default address as entered on Owner details page displays. If Use the owner's payee instead is checked in the report options, the Payee in the Miscellaneous section on the owner's details page displays instead.

Account Number

In order for the Account number to display, an owner-type user defined field must be created and named 1099 Account #.

Enter the account number for each owner on the User Defined Fields page. This number displays on the Owner 1099, Owner 1099 Copy B, Owner 1099 Breakdown, and Export 1099.

1 Rents

The owner's gross income that was earned during the selected year. The IRS requires this amount to be calculated on a cash basis.
