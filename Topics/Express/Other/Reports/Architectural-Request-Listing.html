Architectural Request Listing (Report)

The Architectural Request Listing report provides a breakdown of all architectural requests submitted during a specified date range. This report can be used to quickly see which requests have been approved or denied, as well as which requests are still pending.

Related Privileges

Group Privilege Column
Letter/Email Templates/Reports/Packets Run reports Enabled

Additionally, on the Reports tab, you must have access to Architectural Request Listing.

For more information, refer to Control User Access.

To view the Architectural Request Listing report, do the following:

  1. Go to arrow_forward Services arrow_forward Community arrow_forward Architectural Requests.
    The Reports: Architectural Request Listing page displays.

  2. Adjust the report options as desired. Each option is described below.

  3. Generate the report in your desired file format(s).

Related Preferences

Reports may look different depending on whether or not the Use modernized report style system preference is enabled. For more information, refer to General Report Options (System Preferences).

Report Options

The report options described below determine what data displays in the report.

Properties to Include

Select each property or a property Group to be included in the report. Only properties with a Property Type of Association display in the list.

More Information

This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property.

Optionally, check Show Inactive Properties to include properties that are no longer active.

Date Range

Enter or select the date range to determine the data that displays in the report.

In the Date Range section, set the From and To dates for which the report should examine data.

These fields automatically populate with today’s date. Enter a different date or select a date from the calendar. Alternatively, adjust the dates using the available preset buttons or click to open more options for setting a date range.

Run Properties Separately

Check to generate a separate report for each selected property. Otherwise, all selected properties are combined into a single report.

Report Results

The report results are described below including, if applicable, section, column, and subreport or tab descriptions.

Report Header

The report header displays the report name and key information selected in the report options, such as date information and which properties were examined in the report.

Column Descriptions

This report is organized by property. Information about each property is organized into columns. The columns that display in the report are described below.

Column Description

Created Date

The date on which the request was created.

Description

The detailed description of the architectural change the tenant is requesting.

Request

The subject of the request.

Status

The status of this request (Pending, More Information Needed, Approved, Denied).

Tenant

The name of the tenant or homeowner.

Report Summary

This subreport displays regardless of the report options selected and provides a status breakdown of all architectural requests displayed in the report.

The following columns display in this subreport:

Column Description

Number of Requests

The total number of requests with the according status. The total of all requests in all statuses displays at the bottom of the column.

Status

The statuses of the architectural requests in the report.
