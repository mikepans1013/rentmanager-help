# Extension Details (Report)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Reports/Extension-Detail.htm

The Extension Details report displays rmVoIP activity during the selected date range and then groups this activity by extension within your business. The report results can be filtered by extensions and inbound and/or outbound calls.

 Report Options

 The report options described below determine what data displays in the report.

 Date Range

 Enter or select the date range to determine the data that displays in the report.

 In the Date Range section, set the From and To dates for which the report should examine data.

 These fields automatically populate with today’s date. Enter a different date or select a date from the calendar. Alternatively, adjust the dates using the available preset buttons or click to open more options for setting a date range.

 Associated Phone Numbers

 Check each phone number to be included in the report.

 Extension

 Select each internal extension to display calls made to or from the extension(s) during the selected Date Range .

 Exclude Extension to Extension

 Check to remove your organization's internal calls from the report results.

 Summary Only

 Check to display one row per extension with the extension number, extension name, call count, total duration of received calls in the date range, and the average duration of those received calls.

 Include Calls

 Check to Include Inbound calls, Include Outbound calls, or both in the report results.

 Report Results

 The report results are described below including, if applicable, section, column, and subreport or tab descriptions.

 Report Header

 The report header displays the report name and key information selected in the report options, such as extensions and phone numbers examined in the report.

 More Information

 If the Summary Only report option is checked, only the Extension Summary subreport displays. The report header indicates Summary Report to differentiate from the standard Extension Details report.

 Column Descriptions

 The columns that display in the report are described below.

 Column
 Description

 Date

 The date and time of the call.

 Duration

 The length of time of that extension's call, in ##h ##m ##s (days, hours, minutes, and seconds) format. If a designation is not needed, it is removed (e.g., 12m 44s ).

 Inbound/Outbound

 Calls are designated with Outbound if the listed extension dialed the call, or Inbound  for inbound if the listed extension received the call.

 Information

 Any information about the call, such as a business name, telephone number, or extension number (if internal).

 Outside Number

 The phone number of the caller, or the extension number of a call internal to your organization.

 Extension Summary Subreport

 The Extension Summary subreport details each extension, its name, the number of calls received, the total duration of those calls, and the average duration of the calls to that extension.

 Column
 Description

 # of Calls

 The total number of calls that a phone number received, placed, or both, as determined in the report options, during the selected date range.

 Average Duration

 The average duration of all calls that an extension placed and/or received, as determined in the report options, during the selected date range.

 Extension

 The extension number whose activity is displayed.

 Extension Name

 The first and last name of the Rent Manager user whose extension activity is displayed.

 Total Duration

 The total duration of all calls that an extension placed and/or received, as determined in the report options, during the selected date range.
