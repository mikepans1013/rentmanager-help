Occupancy Listing (Report)

The Occupancy Listing report displays leasing and contact information for tenants who are currently leasing units as of a selected date and their associated contacts. Owners can find this report useful for quickly pulling both contact and lease details for their tenants without having to refer to physical leases. This report can also be exported to serve as a reference for occupancy details for owners with multiple properties.

Related Privileges

Group Privilege Column
Letter/Email Templates/Reports/Packets Run reports Enabled

Additionally, on the Reports tab, you must have access to Occupancy Listing.

For more information, refer to Control User Access.

To view the Occupancy Listing report, do the following:

  1. Go to arrow_forward Rental Info arrow_forward Occupancy arrow_forward Occupancy Listing.
    The Reports: Occupancy Listing page displays.

  2. Adjust the report options as desired. Each option is described below.

  3. Generate the report in your desired file format(s).

Related Preferences

Reports may look different depending on whether or not the Use modernized report style system preference is enabled. For more information, refer to General Report Options (System Preferences).

Report Options

The report options described below determine what data displays in the report.

Properties to Include

Select each property or a property Group to be included in the report.

More Information

This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property.

Optionally, check Show Inactive Properties to include properties that are no longer active.

More Information

Properties with the Property Type of RV/Campground or Short Term Rental do not display in this report. Short term rental property information is available in reports listed in the Short Term Rentals report category.

As of Date

Rent Manager examines relevant report information as of (up through) the date entered to determine the data that displays in the report.

Separation Method

Select one of the following options to determine how the report results are batched:

Option Description

Do not separate

All selected properties are combined into a single report.

Separate by Properties

Generates a separate report for each selected property.

Separate by Units

Generates a separate report for each unit associated with the selected properties.

Units to Include

Select the unit(s) to be examined in the report. Only the units associated with the properties selected in the Properties to Include section display.

Report Results

The report results are described below including, if applicable, section, column, and subreport or tab descriptions.

Report Header

The report header displays the report name and key information selected in the report options, such as date information and which properties were examined in the report.

Column Descriptions

The columns that display in the report are described below.

Column Description

Unit

The name of the selected unit.

Occupant

The name of each tenant who is leasing the selected unit and each associated active contact.

Primary

YES displays if the contact is listed as the Primary contact on the tenant's View Contacts page.

Move In

The date when the tenant moved in as entered on the tenant's lease. For each contact, the move in date for the associated tenant account displays.

Move Out

The move out date of each tenant if it has been entered on the tenant's lease and is after the selected As of Date. Each tenant or contact with move out dates prior to the As of Date does not display in the report. For each contact, the Move Out date for the associated tenant displays.

Notice Date

The Notice date as it has been entered on the tenant's lease.

Date of Birth

The contact’s date of birth as entered on the tenant's View Contacts page.

Phone Number: Default

The contact’s phone number that has been selected as the default on the tenant's View Contacts page.
