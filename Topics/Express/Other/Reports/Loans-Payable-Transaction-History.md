# Loans Payable Transaction History (Report)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Reports/Loans-Payable-Transaction-History.htm

The Loans Payable Transaction History report displays a list of recent payments made to loans payable loans during a specified date range. The report results display each loan name or number as well as its associated property totals. The transaction history on this report also includes a subreport that details the total amount paid for all the loans listed in the report including the principle, interest, and extra payments.

 More Information

 The results can include any transaction information even if it started prior to the general ledger (GL) start date since this report does not consider the GL start date.

 Report Options

 The report options described below determine what data displays in the report.

 Properties to Include

 Select each property or a property Group to be included in the report.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Optionally, check Show Inactive Properties to include properties that are no longer active.

 Date Range

 Enter or select the date range to determine the data that displays in the report.

 In the Date Range section, set the From and To dates for which the report should examine data.

 These fields automatically populate with today’s date. Enter a different date or select a date from the calendar. Alternatively, adjust the dates using the available preset buttons or click to open more options for setting a date range.

 Loans to Include

 Select which loan(s) payable are included in the reports results.

 Run Properties Separately

 Check to generate a separate report for each selected property. Otherwise, all selected properties are combined into a single report.

 Report Results

 The report results are described below including, if applicable, section, column, and subreport descriptions.

 Report Header

 The report header displays the report name and key information selected in the report options, such as date information and which properties were examined in the report.

 Column Descriptions

 The columns that display in the report are described below.

 Column
 Description

 Date

 The date on which the transaction was posted for the loan.

 Transaction

 The reference assigned to the journal entry or check used to pay the loan as listed on the loan's Loan Payable details page.

 Principle Paid

 The total amount paid on the original dollar amount loaned to you.

 Interest Paid

 The total amount paid towards the interest accrued on the loan.

 Other Paid

 The total amount of additional payments made towards the total balance of loan.

 Total

 The full dollar amount of all payments made towards the total balance of the loan.

 Report Totals Subreport

 The columns that display in the subreport are described below.

 Column
 Description

 Principle Paid

 The total amount paid on all of the loans listed in the report.

 Interest Paid

 The total amount paid towards the interest accrued on all of the loans listed in the report.

 Other Paid

 The total amount of additional payments made towards the total balance of all of the loans listed in the report.

 Total

 The full dollar amount of all payments made on the loans listed in the report.
