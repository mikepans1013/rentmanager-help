# Prospect Profile (Report)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Reports/Prospect-Profile.htm

The Prospect Profile report can be used to provide customizable, detailed breakdowns of a selected prospect to property managers or owners that may not interact with your Rent Manager database on a regular basis. This report can be sent to the appropriate parties individually, or to save time, sent as a scheduled batch with other relevant reports.

 Report Options

 The report options described below determine what data displays in the report.

 Properties to Include

 Select each property or a property Group to be included in the report.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Optionally, check Show Inactive Properties to include properties that are no longer active.

 More Information

 Properties with the Property Type of RV/Campground or Short Term Rental do not display in this report. Short term rental property information is available in reports listed in the Short Term Rentals report category.

 Sort Options

 Select one of the following options to determine the order in which profiles generate:

 Option
 Description

 Account Number

 Prospects are sorted numerically by their system-generated ID number in ascending order (lowest to highest).

 Last Name

 Prospects are sorted alphabetically by their Last Name .

 Date Range

 Enter or select the date range to determine the data that displays in the report.

 In the Date Range section, set the From and To dates for which the report should examine data.

 These fields automatically populate with today’s date. Enter a different date or select a date from the calendar. Alternatively, adjust the dates using the available preset buttons or click to open more options for setting a date range.

 Run Properties Separately

 Check to generate a separate report for each selected property. Otherwise, all selected properties are combined into a single report.

 Show On Report

 Select from the following options to determine which sections display:

 Option
 Description

 Show All

 Includes all options in the report.

 User Defined Fields

 Includes a User Defined section containing all prospect-level UDFs with a Value entered on the account.

 Transaction History

 Includes a Transaction History section containing all transactions posted to the account during the Date Range .

 History/Notes

 Includes a History/Notes section containing all history/note entries posted to the account during the Date Range .

 Open Receivables

 Includes an Open Receivables section containing all the account's unpaid charges as of today's date.

 Addresses

 Includes an Addresses section containing all addresses entered for the account.

 Phone Numbers

 Includes a Phone Numbers section containing all phone numbers entered on the View Contacts page for the primary contact of the account.

 Date of Birth/ Age

 Includes the DOB (Date of Birth) and Age fields in the report.

 Stage History

 Include a list of all prospect stages that are assigned to the prospect, the date those stages were assigned, their duration, and the user who assigned the stage(s).

 Report Results

 The report results are described below including, if applicable, section, column, and subreport or tab descriptions.

 Report Header

 The report header displays the report name and key information selected in the report options, such as date information and which properties were examined in the report.

 Account Info

 The Account Info section displays information from the prospect's details page, as well as balance information.

 Field
 Description

 Account Name

 The full name of the prospect in last name, first name format.

 Account #

 The prospect's system-generated account number.

 Property

 The prospect's default property, as specified on the prospect's details page on the General Information tile.

 Comments

 The notes or memos entered on the prospect's details page in the Comment section.

 Balance Due

 The prospect's unpaid balance as of today's date, as displayed on the prospect's details page.

 Oldest Charge

 The age, in days, of the oldest unpaid charge on the prospect's account, as displayed on the prospect's details page.

 Primary Contact Info

 The Primary Contact Info section displays basic information about the prospect. Unless otherwise noted, all fields display as they are entered on the prospect's Contacts tile.

 Field
 Description

 First Name

 The first name of the Primary contact.

 Last Name

 The Last Name of the Primary contact.

 Tax ID

 The Soc Sec # of the Primary contact with the first five digits masked.

 Employer

 The employer of the Primary contact.

 License Plate

 The License plate number of the Primary contact's vehicle.

 Car Description

 The description of the Primary contact's Vehicle .

 DOB

 The Birthday of the Primary contact.

 Age

 The age of the Primary contact.

 Default Address

 The address marked as Default in the Addresses section on the prospect's details page.

 City

 The city of the prospect's default address.

 State

 The ctate of the prospect's default address.

 Zip

 The postal code of the prospect's default address.

 Default Phone

 The phone number marked as Default in the Primary contact's Phone Numbers section.

 Email

 The email address of the Primary contact.

 Photo

 If an image of the prospect has been uploaded to the prospect's Contacts tile, that image displays.

 Reserved Unit Info

 The Reserved Unit Info section displays a breakdown of the unit reserved for the prospect on the Reservation / Expected Lease Information tile. The following fields appear in the section.

 Column
 Description

 Unit

 The Name of the prospect's Reserved Unit .

 Unit Type

 The category of the prospect's reserved unit.

 Exp. Move In

 The Reserved Move In date on which the prospect is expected to begin occupying the unit.

 Exp. Move Out

 The Reserved Move Out date on which the prospect is expected to move out of the unit.

 Addresses

 The Addresses section displays information about addresses entered for the prospect's account. The following fields display in the section.

 Column
 Description

 Address Type

 The address type of each address entered for the prospect.

 Street

 The street address of each address entered for the prospect.

 City

 The city of each address entered for the prospect.

 State

 The state of each address entered for the prospect.

 Postal Code

 The postal code of each address entered for the prospect.

 Default

 If the address is marked as Default for the tenant, Y displays. Otherwise, N displays.

 Billing

 If the address is marked as the Billing address for the tenant, Y displays. Otherwise, N displays.

 Phone Numbers

 The Phone Numbers section displays information about each phone number entered for the prospect on the prospect's Contacts tile. The following fields display in the section.

 Column
 Description

 Phone Number Type

 The phone number types of each phone number entered for the prospect.

 Phone Number

 The phone number(s) entered for the prospect.

 Extension

 The phone number's extension, if applicable.

 Default

 If the phone number is marked as Default for the tenant, Y displays. Otherwise, N displays.

 Text Ready

 If the phone number is enabled for text messaging, Y displays. Otherwise, N displays.

 Secondary Contact Info

 The Secondary Contact Info section displays basic information about each additional active contact or occupant listed on the prospect's Contacts tile. The following fields display for each additional active contact.

 Field
 Description

 Name

 The name of each additional active contact/occupant.

 SSN

 The Soc Sec # of each additional active contact/occupant.

 DOB

 The Birthday of each additional active contact/occupant.

 Age

 The age of each additional active contact/occupant.

 Email

 The email address of each additional active contact/occupant.

 License

 The license plate number of each additional active contact/occupant.

 Car

 The description of each additional active contact/occupant's Vehicle .

 Default Phone

 The phone number marked as Default in the additional active contact/occupant's Phone Numbers section.

 More Information

 If Phone Numbers are configured for the additional occupant, the columns described in the Phone Numbers section also appear beneath the contact's information.

 User Defined

 The User Defined section displays information about any prospect UDFs entered for the prospect in the following columns:

 Column
 Description

 Name

 The name of each prospect-type user defined field.

 Value

 The value entered or selected for each prospect-type user defined field.

 Open Receivables

 The Open Receivables section displays information about each charge posted to the prospect's account that has not yet been fully paid as of today's date. The following columns display in the section.

 Column
 Description

 Date

 The date on which the charge was posted to the prospect's account, as displayed on the Transactions  tile.

 Description

 The description of each unpaid charge, as displayed on the Transactions tile.

 Original Amount

 The full Amount of each unpaid charge, as displayed on the Transactions tile.

 Paid Amount

 The amount of each charge that has previously been paid by the prospect.

 Remaining Amount

 The amount of each charge still left to be paid, calculated using the following formula:

 Remaining Amount = Original Amount - Paid Amount

 Transaction History

 The Transaction History section displays all charges and payments posted to the prospect's account during the selected Date Range . Each column in the section is described below. All information appears as displayed on the Transactions tile.

 Column
 Description

 Date

 The date on which each charge or payment was posted to the prospect's account.

 Ref #

 The Reference # entered for each charge or payment.

 Description

 The description of the charge type used to post each charge to the prospect's account.

 More Information

 Payments display Payment Received as the description.

 Comment

 The comment entered for each charge or payment.

 Amount

 The amount of each charge posted to the prospect's account during the Date Range .

 Balance

 The prospect's running balance as each charge or payment was posted to their account.

 History/Notes

 The History/Notes section displays information about any history notes entered for the prospect during the selected Date Range in the following columns:

 Column
 Description

 Date

 The date on which each history item was entered for the prospect.

 Time

 The time at which each history item was entered for the prospect.

 Regarding

 The body of each history item, as entered in the Note or Description fields.

 History Type

 The type of each history item entered for the prospect, such as Email .

 Stage History

 The Stage History section displays a list of prospect stages assigned to the prospect. All entries are displayed, regardless of the report date range.

 Column
 Description

 Stage

 The name of the stage, as entered on the Prospect Stages page.

 Date

 The date and time the stage was assigned.

 Duration

 The amount of time the prospect was assigned to the stage.

 User

 The Rent Manager user who either manually set the stage or initiated the trigger that set the stage. For example, if the default stage of Prospect Visit is set, the user who added the history/note with the Visit type displays.

 More Information

 If the stage was set by a prospect action (such as submitting an application or completing a signable document) this field displays blank.
