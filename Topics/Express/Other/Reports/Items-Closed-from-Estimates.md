# Items Closed from Estimates (Report)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Reports/Items-Closed-from-Estimates.htm

The Items Closed from Estimates report displays the quantity and value of the inventory items in each user's estimates. Additionally, it displays the value and quantity of those items sold after the estimates are completed via linking them to purchase orders, invoices, and/or service issues.

 More Information

 The results can include any transaction information even if it started prior to the general ledger (GL) start date since this report does not consider the GL start date.

 Report Options

 The report options described below determine what data displays in the report.

 Date Range

 Enter or select the date range to determine the data that displays in the report.

 In the Date Range section, set the From and To dates for which the report should examine data.

 These fields automatically populate with today’s date. Enter a different date or select a date from the calendar. Alternatively, adjust the dates using the available preset buttons or click to open more options for setting a date range.

 Users to Include

 Select the users whose estimates with inventory items sold are examined in the report.

 Optionally, check Include Inactive Users to include user accounts no longer marked as active.

 Report Results

 The report results are described below including, if applicable, section, column, and subreport descriptions.

 Report Header

 The report header displays the report name and key information selected in the report options, such as date information and which properties were examined in the report.

 Column Descriptions

 The columns that display in the report are described below.

 Column
 Description

 Item

 The inventory item included on the user's closed estimates.

 Estimate Value

 The total dollar amount of the item included across all the user's estimates.

 Estimate Qty.

 The total quantity of the item included across all the user's estimates.

 Closed Value

 The total dollar amount of the item sold across the all user's closed estimates.

 Closed Qty.

 The total quantity of the item sold across the all user's closed estimates.

 Open Value

 The total dollar amount of the item sold across the all user's open estimates.

 Open Value = Estimate Value – Closed Value

 % Closed

 The percentage of the item sold on estimates that have been closed and finalized.
