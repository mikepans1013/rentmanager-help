# Maintenance Schedule (Report)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Reports/Maintenance-Schedule.htm

The Maintenance Schedule report displays scheduled issues for each maintenance tech as of the selected date. The report is a printed version of the Maintenance Schedule page and can be used for reference purposes and to provide to the maintenance tech as an itinerary of their work day.

 More Information

 This feature is licensed and must be purchased separately. For more information, contact your sales representative at sales@rentmanager.com .

 -

 -
 Adjust the report options as desired. Each option is described below.

 -
 Generate the report in your desired file format(s).

 Report Options

 The report options described below determine what data displays in the report.

 Techs to Include

 Select each maintenance group or maintenance tech to be included in the report.

 More Information

 Only information related to the properties to which you have access displays. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 As of Date

 Rent Manager examines relevant report information as of (up through) the date entered to determine the data that displays in the report.

 Run Techs Separately

 Check Run Techs separately to generate a separate report for each selected maintenance tech.

 Report Results

 The report results are described below including, if applicable, section, column, and subreport descriptions.

 Report Header

 The report header displays the report name and key information selected in the report options, such as date information and which properties were examined in the report.

 Column Descriptions

 The columns that display in the report are described below.

 Column
 Description

 Maintenance Tech

 The name of the Assigned To User , as displayed on the Details tile of the issue.

 Issue Number

 The system-generated issue number of the issue.

 Allowed to Enter

 Indicates Yes if the Allowed to Enter field on the Description tile of the issue is checked. Otherwise, displays No .

 Pets

 Indicates Yes if the Pets field on the Links tile of the issue is checked. Otherwise, displays No .

 Property

 The property short name associated with the issue.

 Unit

 The unit associated with the issue, as displayed on the Links tile of the issue.

 Tenant

 The tenant's name, as displayed on the Links tile of the issue.

 Phone #

 The tenant's phone number, as displayed on the Links tile of the issue.

 Issue Title

 The name created for the issue, as displayed in the Title field of the issue.
