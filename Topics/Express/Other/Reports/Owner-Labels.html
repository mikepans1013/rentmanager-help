Owner Labels (Report)

The Owner Labels report allows you to print mailing labels with the addresses of your owners. These labels can be affixed to envelopes to save time when sending out notices, forms, or documents. This report is compatible with common label formats (5160-5164, and 5167), and you may select one of those formats when generating the report.

More Information

This report is designed to be printed directly onto adhesive envelope labels. You may wish to print a test page on standard paper before using the label forms, to ensure they are placed in the right direction in the printer.

Related Privileges

Group Privilege Column
Letter/Email Templates/Reports/Packets Run reports Enabled

Additionally, on the Reports tab, you must have access to Owner Labels.

For more information, refer to Control User Access.

To view the Owner Labels report, do the following:

  1. Go to arrow_forward Owners arrow_forward General arrow_forward Owner Labels.
    The Reports: Owner Labels page displays.

  2. Adjust the report options as desired. Each option is described below.

  3. Generate the report in your desired file format(s).

Report Options

The report options described below determine what data displays in the report.

Owners to Include

Check each owner status to be included in the report.

Option Description

Past

All owners with a contract End date set before the selected date display.

Current

All owners with a contract Start date on or before the report date and with either no contract End date or a contract End date after the selected date display.

Future

All owners with a contract Start date that is undefined or after the selected date display.

More Information

Only information related to the properties to which you have access displays. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property.

Select Label Type and Font Formatting

Select the label format that you are using. The type of label can be identified on the box in which they were purchased.

To further customize the label, use the Font drop-down to change the style of the label text. You can change the font Size by selecting a value; the default is 10. Additionally, check Bold or Italic to stylize the font on the labels.

Starting Label Across and Down

If the first label sheet you are using is incomplete, enter a value in Set Starting Label Across to adjust the starting position of the labels to a different column. For example, if the top left label on your sheet has already been used, enter a value of 2 to start printing on the second column of labels.

You can also enter a value in Set Starting Label Down to adjust the starting position of the labels to a different row. For example, if the top two rows of your label sheet have already been used, enter a value of 3 to start printing on the third row of labels.

Sort Options

Select one of the following options to determine the order in which the labels generate:

Option Description

Owner

Labels are generated in alphabetic order by the owner's name.

Address

Labels are generated in alphanumeric order by each owner's address.

Postal Code and Address

Labels are generated in ascending numeric order by the postal code, and then further sorted in alphanumeric order by the address.

Address Type

Select an Address Type to determine which entity address displays on each label.

To use the address that is marked as the Default on the account, select < Use Default >.

Report Results

The Owner Labels report generates in a printer-friendly format and makes it easy to export the report to other formats including PDF, Excel spreadsheet, HTML, and text.

Related Preferences

If your printer is not aligning with the adhesive label forms when printing the report, you can adjust the margins through system preferences. For more information, refer to Preprinted Forms (System Preferences).
