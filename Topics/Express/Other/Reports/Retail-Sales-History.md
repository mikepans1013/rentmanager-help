# Retail Sales History (Report)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Reports/Retail-Sales-History.htm

The Retail Sales History report shows month-to-month sales totals for commercial tenants at selected properties over a specified date range, allowing you to track the performance of these tenants over the life of their lease. The report also displays the total amount of retail sales that were recorded during the date range, allowing you to view trends in rental income alongside tenant retail sales figures.

 More Information

 To track retail sales for your commercial tenants, the feature must first be enabled in Commercial (System Preferences) .

 Report Options

 The report options described below determine what data displays in the report.

 Properties to Include

 Select each property or a property Group to be included in the report.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Optionally, check Show Inactive Properties to include properties that are no longer active.

 More Information

 Properties with the Property Type of RV/Campground or Short Term Rental do not display in this report. Short term rental property information is available in reports listed in the Short Term Rentals report category.

 Date Range

 Enter or select the date range to determine the data that displays in the report.

 In the Date Range section, set the From and To dates for which the report should examine data.

 These fields automatically populate with today’s date. Enter a different date or select a date from the calendar. Alternatively, adjust the dates using the available preset buttons or click to open more options for setting a date range.

 Detail or Summary

 This option determines how much information is displayed in the report.

 Option
 Description

 Detail

 Sales data for each month included in the Date Range display.

 Summary

 Only the sales totals during the Date Range display.

 Run Properties Separately

 Check to generate a separate report for each selected property. Otherwise, all selected properties are combined into a single report.

 Values to Include

 Select one of the following options and enter a value in the Values to Include Amount field to determine what sales amounts display in the report.

 Option
 Description

 All

 All sales amounts display.

 =

 Sales amounts that are equal to the entered value display.

 !=

 Sales amounts that are not equal to the entered value display.

 <

 Sales amounts that are less than the entered value display.

 <=

 Sales amounts that are less than or equal to the entered value display.

 >=

 Sales amounts that are greater than or equal to the entered value display.

 >

 Sales amounts that are greater than the entered value display.

 Sort Options

 Select one of the following options to determine how the report results are sorted:

 Option
 Description

 Account Number

 Tenants are sorted numerically by their system-generated ID number in ascending order (lowest to highest).

 Last Name

 Tenants are sorted alphabetically by their Last Name . Tenants marked as Company are sorted alphabetically by Company Name .

 Unit

 Tenants are sorted alphanumerically by Unit name.

 Report Results

 The report results are described below including, if applicable, section, column, and subreport or tab descriptions.

 Report Header

 The report header displays the report name and key information selected in the report options, such as date information and which properties were examined in the report.

 Column Descriptions

 The columns that display in the report are described below.

 Column
 Description

 Tenant

 Each tenant's Company Name (or First Name and Last Name ) as entered on tenant details.

 Property

 The Full Name of the property as entered on property details.

 Unit

 The Name of the unit each tenant is leasing.

 Acc. #

 Each tenant's system-generated account ID number.

 Month

 The month for which the tenant has retail sales entered during the selected date range.

 The column displays only if Detail is selected in the Detail or Summary field of the report options.

 Year

 The year that corresponds to the month listed in the Month column.

 The column displays only if Detail is selected in the Detail or Summary field of the report options.

 Amount

 If the Detail report option is selected, the column displays the Amount of retail sales that the tenant recorded for each month included in the Date Range , as entered on the tenant's commercial lease. The total of all retail sales entered for the tenant during the Date Range appear after each tenant, and the grand total of all tenants' retail sales appear at the bottom of the column.

 If the Summary report option is selected, the column displays the total of all retail sales that each tenant recorded during the Date Range , as entered on the tenant's commercial lease, and the grand total of all tenants' retail sales appear at the bottom of the column.
