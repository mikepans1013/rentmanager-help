# Chart of Accounts (Report)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Reports/Chart-Accounts.htm

The Chart of Accounts report displays a complete list of every general ledger (GL) account created in your Rent Manager chart of accounts. Each account displays along with its account number, description, and type. This report acts as a physical guide for employees to reference as needed. Chart of accounts reports can be exported in multiple formats including a PDF that can be printed or an Excel or CSV file that can saved to your computer or shared as needed.

 More Information

 The GL start date is considered the financial start date, so any transactions or information dated before the GL start date are not included in the report results.

 Reports may look different depending on whether or not the Use modernized report style system preference is enabled. For more information, refer to General Report Options (System Preferences) .

 Report Options

 The report options described below determine what data displays in the report.

 Include Inactive

 Check to display general ledger accounts in the report results that have Active unchecked in the Chart of Accounts .

 Report Results

 The report results are described below including, if applicable, section, column, and subreport or tab descriptions.

 Report Header

 The report header displays the report name and key information selected in the report options, such as date information and which properties were examined in the report.

 Column Descriptions

 The columns that display in the report are described below.

 Column
 Description

 Name

 The name of each GL account.

 Acc #

 The account number used as the system-wide identifier for the GL account.

 Description

 A more detailed summary of the account.

 Type

 The account type that most closely defines the purpose of the GL account (e.g., Bank , Expense , Equity , etc.).
