# Tenant Labels (Report)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Reports/Tenant-Labels.htm

The Tenant Labels report allows you to print mailing labels with the addresses of the primary tenants on your leases. These labels can be affixed to envelopes to save time when bulk mailing notices, forms, documents, or other premade materials.

 More Information

 This report is designed to be printed directly onto adhesive envelope labels. You may wish to print a test page on standard paper before using the label forms, to ensure they are placed in the right direction in the printer.

 More Information

 The Tenant Labels report can also be generated directly from the action bar of the tenant's details page by doing the following:

 -
 Go to arrow_forward Rental Info arrow_forward General arrow_forward Tenants .
The Tenants page displays.

 -
 Select the desired tenant from the list.
The tenant's details page displays.

 -
 On the action bar to the right, select arrow_forward Generate Mailing Labels .
The Reports: Tenant Labels page displays.

 If you generate the report this way, the report options do not display the Properties to Include , Tenants to Include , and Run Properties Separately sections.

 Report Options

 The report options described below determine what data displays in the report.

 Properties to Include

 Select each property or a property Group to be included in the report.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Optionally, check Show Inactive Properties to include properties that are no longer active.

 Run Properties Separately

 Check to generate a separate report for each selected property. Otherwise, all selected properties are combined into a single report.

 Sort Options

 Select one of the following options to determine how the labels are sorted:

 Option
 Description

 Address

 Labels are sorted alphanumerically by the tenant's address. Tenants with no address display first in the results.

 The address by which labels are sorted depends on the selection in the Address Type report option.

 Last Name

 Labels are sorted alphabetically by the tenant's Last Name . Tenants marked as Company are sorted by the last name of the tenant's Primary contact.

 Postal Code and Address

 Labels are sorted numerically by the tenant's postal code in ascending order (lowest to highest). Tenants with the same postal code are further sorted in alphanumeric order by address.

 The postal code and address by which labels are sorted depends on the selection in the Address Type report option.

 Unit

 Labels are sorted alphanumerically by the tenant's Unit name. Tenants with no unit display first in the results.

 Address Type

 Select an Address Type to determine which entity address displays on each label.

 To use the address that is marked as the Default on the account, select < Use Default > .

 Tenants to Include

 Select each desired option to determine which accounts display in the report results.

 Option
 Description

 Current

 All tenants with a Move In date on or before the report date and with either no Move Out date or a Move Out date after the selected date display.

 Past

 All tenants with a Move Out date set before the selected date display.

 Future

 All tenants with a Move In date that is undefined or after the selected date display.

 Select Label Type and Font Formatting

 Select the label format that you are using. The type of label can be identified on the box in which they were purchased.

 To further customize the label, use the Font drop-down to change the style of the label text. You can change the font Size by selecting a value; the default is 10 . Additionally, check Bold or Italic to stylize the font on the labels.

 Starting Label Across and Down

 If the first label sheet you are using is incomplete, enter a value in Set Starting Label Across to adjust the starting position of the labels to a different column. For example, if the top left label on your sheet has already been used, enter a value of 2 to start printing on the second column of labels.

 You can also enter a value in Set Starting Label Down to adjust the starting position of the labels to a different row. For example, if the top two rows of your label sheet have already been used, enter a value of 3 to start printing on the third row of labels.

 Report Results

 The Tenant Labels report generates in a printer-friendly format and makes it easy to export the report to other formats including PDF, Excel spreadsheet, HTML, and text.

 Related Preferences

 If your printer is not aligning with the adhesive label forms when printing the report, you can adjust the margins through system preferences. For more information, refer to Preprinted Forms (System Preferences) .
