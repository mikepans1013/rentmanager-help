Management Fee Listing (Report)

The Management Fee Listing report shows the total amounts from management fee postings within the date range selected. These amounts are separated by owner, providing a breakdown of the management fees posted in a way that you can review and confirm the amounts match the expected management fee amounts for each owner. Selecting to run the report in a detail view further breaks down these postings by each property for an owner to give a more detailed overview of where management fees are being posted.

Related Privileges

Group Privilege Column
Letter/Email Templates/Reports/Packets Run reports Enabled

Additionally, on the Reports tab, you must have access to Management Fee Listing.

For more information, refer to Control User Access.

To view the Management Fee Listing report, do the following:

  1. Go to arrow_forward Owners arrow_forward Management Fees arrow_forward Management Fee Listing.
    The Reports: Management Fee Listing page displays.

  2. Adjust the report options as desired. Each option is described below.

  3. Generate the report in your desired file format(s).

Report Options

The report options described below determine what data displays in the report.

Owners to Include

Select each owner or an owner Group to be included in the report.

More Information

Only information related to the properties to which you have access displays. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property.

Optionally, check Inactive Owners to include owners that are no longer active.

Optionally, check Show Inactive Properties to include properties that are no longer active.

Date Range

Enter or select the date range to determine the data that displays in the report.

In the Date Range section, set the From and To dates for which the report should examine data.

These fields automatically populate with today’s date. Enter a different date or select a date from the calendar. Alternatively, adjust the dates using the available preset buttons or click to open more options for setting a date range.

Detail or Summary

This option determines how much information is displayed in the report.

Option Description

Detail

Management fee posting details are separated by property for each owner.

Summary

Management fee posting details are separated by owner, displaying the totals from each property they own.

Report Results

The report results are described below including, if applicable, section, column, and subreport descriptions.

Report Header

The report header displays the report name and key information selected in the report options, such as date information and which properties were examined in the report.

Column Descriptions

The rate in which fees are posted are determined by the management fee setup for each property. The columns that display in the report are described below.

Column Description

Owner

The owner that the management fees were posted to.

Property

The property associated with the owner, where the management fees were posted.

The column displays only if Detail is selected in the Detail or Summary report option. If Summary is selected, properties totals are combined and represented per owner.

Minimum Fees

The amount posted for Min Fee as specified on the property's Fees Setup pop-up.

Maximum Fees

The amount posted for Max Fee as specified on the property's Fees Setup pop-up.

Flat Fees

The amount posted for Flat Fee as specified on the property's Fees Setup pop-up.

Per Unit Fee

The amount posted for Per Unit Fee as specified on the property's Fees Setup pop-up.

Per Occupied Fee

The amount posted for Per Occupied Fee as specified on the property's Fees Setup pop-up.

Calculated % of Total Income

The calculated amount posted for the percent of the property's total (gross) income as specified on the Fees Setup pop-up % of Total Income field.

Calculated % of Net Income

The calculated amount posted for the percent of the property's net income as specified on the Fees Setup pop-up % of Net Income field.

Chart % Amount

The calculated amount posted for the percentage of each chart account specified on the Fees Setup pop-up Chart Account Fees section.

Fee Amt

The total amount of fees posted for the property.

Report Totals

The Report Totals subreport provides the totals of all management fees for all owners displayed in the report.
