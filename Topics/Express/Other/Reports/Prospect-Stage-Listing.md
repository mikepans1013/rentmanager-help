# Prospect Stage Listing (Report)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Reports/Prospect-Stage-Listing.htm

The Prospect Stage Listing report provides detailed information about the current stage of prospects as they move through various stages before move-in. This report consists of several sections, each named for a prospect stage, that track the status of prospects as they move through the leasing process. A summary displays at the bottom of the report, with totals of prospects in each stage and a total of all prospects who have a stage assigned.

 Related Preferences

 Report Options

 The report options described below determine what data displays in the report.

 Properties to Include

 Select each property or a property Group to be included in the report.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Optionally, check Show Inactive Properties to include properties that are no longer active.

 Leasing Agent

 Select an active user to display only prospects assigned to those leasing agent(s) in the report results. Optionally, select All to view all prospects, regardless of their leasing agent assignment. Only users with Leasing Agent selected on their User details page display in the list.

 Prospect Stages to Include

 Select the prospect stages and associated prospects to be examined in the report. Optionally, check Inactive Stages to include stages that are no longer active. For more information, refer to Prospect Stages (Page) .

 Run Properties Separately

 Check to generate a separate report for each selected property. Otherwise, all selected properties are combined into a single report.

 Exclude Stages Without Prospects

 Check to remove prospect stages with no currently-assigned prospects from the report results.

 Sort Options

 Select one of the following options to determine how the report results are sorted within each prospect stage subheading.

 Option
 Description

 Account Number

 Prospects are sorted numerically by their system-generated ID number in ascending order (lowest to highest).

 Last Name

 Prospects are sorted alphabetically by their Last Name .

 Property

 Prospects are sorted alphanumerically by Property name. Prospects at the same property are further sorted chronologically by Stage Date in ascending order (oldest to newest).

 Unit

 Prospects are sorted alphanumerically by Unit name. Prospects with no unit display first in the results.

 Report Results

 The report results are described below including, if applicable, section, column, and subreport or tab descriptions.

 Report Header

 The report header displays the report name and key information selected in the report options, such as date information and which properties were examined in the report.

 Column Descriptions

 The columns that display in the report are described below.

 Column
 Description

 Prospect

 The prospect's full name.

 Property

 The property where the prospect is interested in renting, selected on the prospect's details page in the General Information tile.

 Unit

 The name of the unit reserved for the prospect.

 First Contact

 The date of the first contact with the prospect recorded in Rent Manager . First contact is established by the earliest email, visit, or call on the prospect’s History/Notes tile where Spoke With Prospect is checked.

 Last Contact

 The date of the most recent contact with the prospect recorded in Rent Manager . Last contact is established by the most recent email, visit, or call on the prospect’s History/Notes tile where Spoke With Prospect is checked.

 Stage Date

 The date that the prospect was moved to this stage.

 Source

 How the prospect found out about your business.

 Agent

 The leasing agent assigned to the prospect.

 Summary Subreport

 The Summary subreport displays regardless of the report options selected and provides a breakdown of all prospect stages that appeared in the report.

 Column
 Description

 Prospect Stage

 The name of each prospect stage included in the report.

 Total

 The total number of prospects in a given stage at the time of the report. A total of all prospects in all stages displays at the bottom of the Total column.
