# STR Promotions & Member Discounts (Report)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Reports/STR-Promotions-Member-Discounts.htm

The STR Promotions & Member Discounts report displays the usage of short-term rental (STR) promotions and member discounts as of a specified period. For each promotion and member discount selected, the total quantity redeemed during the specified period, discount amount, total amount discounted during the specified period, and the discount type display.

 Report Options

 The report options described below determine what data displays in the report.

 Properties to Include

 Select each property or a property Group to be included in the report. Only properties with a Property Type of RV/Campground or Short Term Rental display in the list.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Optionally, check Show Inactive Properties to include properties that are no longer active.

 Run Properties Separately

 Check to generate a separate report for each selected property. Otherwise, all selected properties are combined into a single report.

 Date Range

 Enter or select the date range to determine the data that displays in the report.

 In the Date Range section, set the From and To dates for which the report should examine data.

 These fields automatically populate with today’s date. Enter a different date or select a date from the calendar. Alternatively, adjust the dates using the available preset buttons or click to open more options for setting a date range.

 Detail or Summary

 This option determines how much information is displayed in the report.

 Option
 Description

 Detail

 The report displays detailed financial information about the each selected STR promotion and member discount. For example, this option displays guest, property, unit, actual price, discounted amount, and final price information in addition to a Summary subreport.

 Summary

 The report displays condensed information about each promotion and member discount (the name of the promotion/discount, the total quantity redeemed, the discount amount, total amount discounted during the specified period, and the type of each promotion/discount).

 Promotions To Include

 Select each active promotion defined on the STR Promotions page to be included in the report.

 Member Discounts To Include

 Select each active member discount defined on active RV/Campground -type properties to be included in the report.

 Report Results

 The report results are described below including, if applicable, section, column, and subreport descriptions.

 Report Header

 The report header displays the report name and key information selected in the report options, such as date information and which properties were examined in the report.

 Column Descriptions

 The columns that display in the report, if, in the Detail or Summary report option, Detail is selected, are described below.

 Column
 Description

 Actual Price

 The total amount charged for the reservation excluding the applied promotion or member discount.

 Discounted Amount

 The dollar amount discounted when the promotion or member discount was applied.

 Final Price

 The difference between the Actual Price and Discounted Amount .

 Property

 The name of the property associated with the reservation where the promotion or member discount was used.

 Tenant

 The name of the guest associated with the reservation where the promotion or member discount was used.

 Unit

 The name of the unit associated with the reservation where the promotion or member discount was used.

 The columns that display in the report, if, in the Detail or Summary report option, Summary is selected, are described below.

 Column
 Description

 Discount Amount

 The discounted percentage or dollar amount for the promotion or member discount.

 Discount Type

 The type of discount ( Promotion or Member Discount ).

 Name

 The Name of the promotion as displayed on the STR Promotions page, or the Name of the member discount as displayed on the Property STR Settings pop-up.

 Quantity Redeemed

 The number of times the promotion or member discount has been used during the selected date range.

 Total Discount

 The total amount of charges added to guest accounts for the associated charge type.

 Summary Subreport

 The Summary subreport displays two additional columns that summarize the discount and promotion information in the report. This subreport displays only if, in the Detail or Summary report option, Detail is selected. Each column is described below.

 Column
 Description

 # Used

 The total number of used member discounts and promotions included in the report.

 Amount

 The total discounted amount of all member discount and promotion included in the report.
