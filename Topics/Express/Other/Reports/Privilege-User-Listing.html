Privilege User Listing (Report)

The Privilege User Listing report displays which users and user roles are granted the selected privileges. The report also displays which users have access to the selected properties, banks, and/or reports for each user. Additionally, this report can be used to track whether specific privileges are granted to users and/or user roles so you can monitor and maintain your Rent Manager database security.

Related Privileges

Group Privilege Column
Letter/Email Templates/Reports/Packets Run reports Enabled

Additionally, on the Reports tab, you must have access to Privilege User Listing.

For more information, refer to Control User Access.

To view the Privilege User Listing report, do the following:

  1. Go to arrow_forward System arrow_forward Users arrow_forward Privilege User Listing.
    The Reports: Privilege User Listing page displays.

  2. Adjust the report options as desired. Each option is described below.

  3. Generate the report in your desired file format(s).

Related Preferences

Reports may look different depending on whether or not the Use modernized report style system preference is enabled. For more information, refer to General Report Options (System Preferences).

Report Options

The report options described below determine what data displays in the report.

Privileges to Include

Check each privilege to be included in the report results.

Reports to Include

Check each report to be examined in the report.

Properties to Include

Check each property to be included in the report.

More Information

This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property.

Banks to Include

Select each bank to be included in the report.

Report Results

The report results are described below including, if applicable, section, column, and subreport descriptions.

Report Header

The report header displays the report name and key information selected in the report options, such as date information and which properties were examined in the report.

Privileges by User

Privileges that are granted to users display and indicates which users the privilege is assigned to.

The columns below display in this section.

Column Description

Add

A Check displays if the user was granted the ability to add items related to the privilege.

Delete

A Check displays if the user wash granted the ability to delete items related to the privilege.

Edit

A Check displays if the user was granted the ability to edit items related to the privilege.

Enabled

A Check displays if the user was granted a privilege that can be enabled.

Role Name

If a user has a user role assigned, the name of the user role displays for each user. If a user has a user role display in the same row as their username, all privileges in the row are inherited from the user role. For more information, refer to User Roles (Page).

Username

The Username as it is entered on the user's General tab. For more information, refer to User Details (Page).

View

A Check displays if the user was granted the ability to view items related to the privilege.

Privileges by Role

Privileges that are granted to user roles display and indicates which user role the privilege is assigned to.

The following columns display in this section:

Column Description

Add

A Check displays if the user role was granted the ability to add items related to the privilege.

Delete

A Check displays if the user role was granted the ability to delete items related to the privilege.

Edit

A Check displays if the user role was granted the ability to edit items related to the privilege.

Enabled

A Check displays if the user role was granted a privilege that can be enabled.

Role

If a user has a user role assigned, the name of the user role displays for each user. If a user has a user role display in the same row as their username, all privileges in the row are inherited from the user role. For more information, refer to User Roles (Page).

View

A Check displays if the user role was granted the ability to view items related to the privilege.

Reports by User

The name of each selected report displays and the Username column indicates each user with access to the report.

Reports by Role

The name of the selected report displays and the Role Name column indicates each user role with access to the report.

Properties by User

The name of the selected property displays and the Username column indicates each user with access to the property.

Banks by User

The name of the selected bank displays and the Username column indicates each user with access to the bank.
