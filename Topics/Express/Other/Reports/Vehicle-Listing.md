# Vehicle Listing (Report)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Reports/Vehicle-Listing.htm

The Vehicle Listing report provides a breakdown of vehicle details for guests at short-term rental (STR) properties as of the current date. You can use this report to review the approved vehicles for guests at an STR property.

 To display on the report, vehicle details must be entered in arrow_forward Rental Info arrow_forward Short Term Rentals arrow_forward Reservations on the Reservations Details pop-up for the guest's associated reservation.

 Related Preferences

 Reports may look different depending on whether or not the Use modernized report style system preference is enabled. For more information, refer to General Report Options (System Preferences) .

 Report Options

 The report options described below determine what data displays in the report.

 Properties to Include

 Select each property or a property Group to be included in the report. Only properties with a Property Type of RV/Campground or Short Term Rental display in the list.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Optionally, check Show Inactive Properties to include properties that are no longer active.

 Run Properties Separately

 Check to generate a separate report for each selected property. Otherwise, all selected properties are combined into a single report.

 Report Results

 The report results are described below including, if applicable, section, column, and subreport or tab descriptions.

 Report Header

 The report header displays the report name and key information selected in the report options, such as date information and which properties were examined in the report.

 Column Descriptions

 This report is organized by property. Information about each property is organized into columns. The columns that display in the report are described below.

 Columns
 Description

 Checked In

 Displays Yes if the guest has been checked in to their unit; otherwise, No displays.

 License

 The License plate number of the guest's RV or vehicle as indicated on the RV/Vehicles tab of the guest's Reservation Details .

 Make

 The Make of the guest's RV or vehicle as indicated on the RV/Vehicles tab of the guest's Reservation Details .

 Model

 The Model of the guest's RV or vehicle as indicated on the RV/Vehicles tab of the guest's Reservation Details .

 Name

 The guest's first and last name.

 Total Vehicles for Property

 The total number of vehicles that display in the report for each property.

 Unit

 The Unit Name of the unit associated with the guest's reservation.

 Unit Type

 The unit type of the unit occupied by the guest.

 Year

 The Year the guest's RV or vehicle was manufactured as indicated on the RV/Vehicles tab of the guest's Reservation Details .
