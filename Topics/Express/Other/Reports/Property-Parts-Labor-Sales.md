# Property Parts/Labor Sales (Report)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Reports/Property-Parts-Labor-Sales.htm

The Property Parts/Labor Sales report lists parts and labor inventory items invoiced to tenants and owners. The report displays the cost to you, the price you sold the items for, and the difference. Sold items are sorted by property.

 Related Preferences

 Reports may look different depending on whether or not the Use modernized report style system preference is enabled. For more information, refer to General Report Options (System Preferences) .

 Report Options

 The report options described below determine what data displays in the report.

 Properties to Include

 Select each property or a property Group to be included in the report.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Optionally, check Show Inactive Properties to include properties that are no longer active.

 Date Range

 Enter or select the date range to determine the data that displays in the report.

 In the Date Range section, set the From and To dates for which the report should examine data.

 These fields automatically populate with today’s date. Enter a different date or select a date from the calendar. Alternatively, adjust the dates using the available preset buttons or click to open more options for setting a date range.

 Run Properties Separately

 Check to generate a separate report for each selected property. Otherwise, all selected properties are combined into a single report.

 Show All Work Order Items Even If They Have Not Been Invoiced

 Check to include all work order items in the report, including those that do not have a linked invoice.

 Report Results

 The report results are described below including, if applicable, section, column, and subreport descriptions.

 Report Header

 The report header displays the report name and key information selected in the report options, such as date information and which properties were examined in the report.

 Column Descriptions

 The report is organized by property and provides the total of products for the property at the bottom of each section. The columns that display in the report are described below.

 Column
 Description

 Product

 The name of the inventory item.

 Description

 An explanation of the item, found in the Description field on the inventory item's details page.

 Quantity

 The total number of the item sold.

 Sales

 The total dollar amount that the tenant or owner paid for the inventory item.

 Cost

 The total dollar amount of the cost you paid for the items.

 Difference

 The difference between the cost you paid for the item and the sale price you charged the recipient.

 Report Totals

 The Report Totals subreport displays the following totals for all properties included in the report:

 Column
 Description

 Total Products Listed

 The total number of parts and labor products included in the report.

 Quantity

 The total number of all items included in the report.

 Sales

 The total dollar amount that tenants and owners paid for the sum total of items in the report.

 Cost

 The total dollar amount of the cost you paid for all items included in the report.

 Difference

 The difference between the total cost you paid for the item and the total sale price you charged the recipient.
