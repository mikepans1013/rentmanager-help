# Issue Detail (Report)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Reports/Issue-Detail.htm

The Issue Detail report creates a detailed profile of every service issue in the selected saved issue lists, including history/note items, user-defined fields, checklist items, and work order costs.

 To view the Issue Detail report, do the following:

 -
 Go to arrow_forward Services arrow_forward Service Manager arrow_forward Issue Detail .
The Reports: Issue Detail page displays.

 -
 Adjust the report options as desired. Each option is described below.

 -
 Generate the report in your desired file format(s).

 Related Preferences

 Reports may look different depending on whether or not the Use modernized report style system preference is enabled. For more information, refer to General Report Options (System Preferences) .

 Report Options

 The report options described below determine what data displays in the report.

 Issue Lists to Include

 Select a saved issue list to display all associated issues in the report.

 This option is available only when the report is generated from the Reports menu. The option does not display when the report is generated from the Issue page because the report only displays the selected service issue and cannot display the entire list.

 Report Results

 The report results are described below including, if applicable, section, column, and subreport descriptions.

 Report Header

 The report header displays the report name as well as the issue Title and system assigned number for each issue the report examines.

 General Information

 This section displays basic information about each service issue in the following fields:

 Field
 Description

 Allowed to Enter

 If, on the Issue Details tile of the issue, the Allow to Enter field is checked, Yes displays. Otherwise, No displays.

 Related Preferences

 This field displays only when Allowed To Enter is checked in system preferences. For more information, refer to Service Issue General Options (System Preferences) .

 Assigned To

 The user to whom the issue is currently assigned to on the Issue Summary tile.

 Category

 The category assigned to the issue on the Issue Details tile.

 Checklist Progress

 The number of checklist items completed out of the total number of checklist items.

 Close Date

 The date and time the service issue was closed, if applicable.

 Close User

 The user who closed the issue, if applicable.

 Close Timestamp

 The date and time the issue was closed, if applicable.

 Closed

 If the issue was closed, Yes displays. Otherwise, No displays.

 Due Date

 The date and time the issue is due to be completed.

 Hours

 The total number of service tech hours recorded for the issue on the Issue Details tile.

 Issue #

 The issue's system-assigned service issue number.

 Link

 The tenant ( T ), property ( P ), and unit ( U ) service issue links.

 Modify Date

 The date and time the service issue was most recently edited.

 Modify User

 The user who most recently modified the issue.

 Open Date

 The date and time the service issue was created.

 Open User

 The user who created the issue.

 Pets

 If, on the Issue Details tile of the issue, the Pets field is checked, Yes displays. Otherwise, No displays.

 Related Preferences

 This field displays only when Pets is checked in system preferences. For more information, refer to Service Issue General Options (System Preferences) .

 Priority

 The priority assigned to the issue on the Issue Details tile.

 Project

 The workflow project the issue is associated with on the Issue Details tile.

 Signature on File

 If, on the Issue Details tile of the issue, the Signature on File field is checked, Yes displays. Otherwise, displays No .

 Related Preferences

 This field displays only when Signature on File is checked in system preferences. For more information, refer to Service Issue General Options (System Preferences) .

 Status

 The status assigned to the issue on the Issue Details tile.

 Vendor

 The vendor associated with the issue, selected on the Issue Details tile.

 Issue

 This section displays the Title as entered in the service issue's details page.

 Description

 This section displays the Description as entered in the service issue's details page.

 Resolution

 This section displays the Issue Resolution as entered in the service issue's details page.

 Checklist

 Information about Issue Checklist items are displayed in the columns described below:

 Column
 Description

 Completed

 A displays for any checklist items that are marked as completed.

 Completed Date

 The date and time the checklist item was marked as completed.

 Completed User

 The user that marked the checklist item as completed.

 Description

 Information that details the purpose of the checklist item.

 User Responsible

 The user assigned to the checklist item.

 History/Notes

 Information about the issue history/note items are displayed in the columns described below:

 Column
 Description

 Date

 The date entered for the history/note item.

 History Type

 The type of history/note item added to the service issue.

 Note

 The description entered for the history/note item

 Time

 The time entered for the history/note item.

 User Defined

 Information about issue-level user defined fields are displayed in the columns described below:

 Column
 Description

 Name

 The name of each issue-type user-defined field.

 Value

 The value entered or selected for each issue-type user-defined field.

 Work Order

 Information about work order items are displayed in the columns described below:

 Column
 Description

 Cost

 The base cost for one unit of each inventory item for your management company.

 Description

 Additional details about each inventory item.

 Item

 The name of each inventory item used to complete the work order.

 Price

 The amount that an owner or tenant will pay for one unit of each inventory item through created invoices.

 Property

 The short name of the property where each billable item is being used.

 Total Cost

 The total cost of each inventory item, calculated using the following formula:

 Total Cost = Cost * Qty

 Total Price

 The total amount that an owner or tenant pays for each inventory item, calculated using the following formula:

 Total Price = Price * Qty

 Unit

 The name of the unit where each billable item is being used, if applicable.

 Qty.

 The number of each inventory item used to complete the work order.
