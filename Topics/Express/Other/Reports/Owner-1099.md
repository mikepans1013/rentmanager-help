# Owner 1099 (Report)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Reports/Owner-1099.htm

The Owner 1099 report is designed so that you can print ownership information for owners that earned gross income from the properties you managed directly on the 1099-MISC form. This 1099-MISC form is used for all miscellaneous income, and income from rental properties is always reported in Box 1 of the form. The printed form can then be mailed to owners and the IRS to satisfy the IRS requirements for 1099 forms.

 More Information

 As of 2023, if you have 10 or more recipients, your must eFile your owner 1099 forms. For more information on how to generate an eFile from Rent Manager , refer to Export 1099 Owner .

 For information on purchasing Safeguard printable tax forms, refer to Safeguard Tax Forms .

 Related Preferences

 If your printer is not aligning with the IRS 1099's margins when printing the report, you can adjust the margins through system preferences. For more information, refer to Preprinted Forms (System Preferences) .

 Report Options

 The report options described below determine what data displays in the report.

 Owners to Include

 Select each owner or an owner Group to be included in the report.

 More Information

 Only information related to the properties to which you have access displays. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Optionally, check Inactive Owners to include owners that are no longer active.

 Optionally, check Show Inactive Properties to include properties that are no longer active.

 Exclude Total Values Less Than $600

 Check to display forms only for owners who earned more than $600 of gross income in the selected year in the report results.

 Hide Complete SSNs/Tax IDs

 Check to replace all but the last four digits of the owner's Tax ID as entered on the Owner page with Xs.

 Mark as Corrected

 Check Mark to print an X in the Corrected box for all generated 1099 reports. Select Yes on the pop-up to mark the 1099 as corrected, or No to return to the report options.

 Owner Name Source

 Select from the following options to determine what information displays on the form for the RECIPIENT'S name .

 Option
 Description

 Owner Name

 The owner's Name as entered on the owner's details page.

 Payee

 The Payee name as entered on the owner's details page.

 User Defined Field

 The value of an owner-level user defined field. Once selected, use the UDF Name drop-down list to select from your owner-level UDFs with a text field type. For more information, refer to Owner-Type User Defined Fields (Pop-Up) .

 If an owner has no value entered for the selected UDF, the Owner Name option is used for that owner instead.

 Year

 The calendar year to display the gross income earned by the selected active owner(s) during that year.

 Report Results

 Field Descriptions

 Each owner is displayed in their own subsection in the report so that it can printed on separate 1099 forms. Each field in the report is described below:

 1099 Form Field
 Description

 PAYER'S name

 The name and default address of your property management company, found on the management company's details page in the General and Primary Address tiles.

 PAYER'S TIN

 The tax ID for the property management company, found on the management company's details page in the Other Information tile.

 RECIPIENT'S TIN

 The tax ID or social security number for each owner, found on the owner's details page in the General tile.

 RECIPIENT'S name

 By default, the name and default address for each owner, found on the owner's details page in the General tile.

 If Payee is select in the Owner Name Source report option, this field displays the name entered on the owner's details page in the Miscellaneous tile in the Payee field.

 Account Number

 To display an account number, you must create an owner-type user defined field (UDF) named 1099 Account # . Enter the account number for each owner on the owner's UDFS  tile. This number displays on the Owner 1099 , Owner 1099 Copy B , Owner 1099 Breakdown , and Export 1099 reports.
