Property Management Fee Listing (Report)

The Property Management Fee Listing report displays the management fees posted for each selected property in a date range. The report can be configured to run separately for each property.

Related Privileges

Group Privilege Column
Letter/Email Templates/Reports/Packets Run reports Enabled

Additionally, on the Reports tab, you must have access to Property Management Fee Listing.

For more information, refer to Control User Access.

To view the Property Management Fee Listing report, do the following:

  1. Go to arrow_forward Owners arrow_forward Management Fees arrow_forward Property Management Fee Listing.
    The Reports: Property Management Fee Listing page displays.

  2. Adjust the report options as desired. Each option is described below.

  3. Generate the report in your desired file format(s).

Related Preferences

Reports may look different depending on whether or not the Use modernized report style system preference is enabled. For more information, refer to General Report Options (System Preferences).

Report Options

The report options described below determine what data displays in the report.

Properties to Include

Select each property or a property Group to be included in the report.

More Information

This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property.

Optionally, check Show Inactive Properties to include properties that are no longer active.

Date Range

Enter or select the date range to determine the data that displays in the report.

In the Date Range section, set the From and To dates for which the report should examine data.

These fields automatically populate with today’s date. Enter a different date or select a date from the calendar. Alternatively, adjust the dates using the available preset buttons or click to open more options for setting a date range.

Detail or Summary

This option determines how much information is displayed in the report.

Option Description

Detail

A line item for each management fee posting organized by the property display.

Summary

The total amount of all management fees combined into a single row for each property display.

Run Properties Separately

Check to generate a separate report for each selected property. Otherwise, all selected properties are combined into a single report.

Report Results

The report results are described below including, if applicable, section, column, and subreport descriptions.

Report Header

The report header displays the report name and key information selected in the report options, such as date information and which properties were examined in the report.

Column Descriptions

The columns that display in the report are described below.

Column Description

Property

The property at which management fees were posted.

The column displays only if Summary is selected in the Detail or Summary report option. If Detail is selected, each property is listed in its own section and the totals of each column for the property display at the bottom of the section.

Posting Date

The date(s) on which the management fees were posted within the selected date range.

The column displays only if Detail is selected in the Detail or Summary report option.

Minimum Fees

The amount posted for Min Fee as specified on the property's Fees Setup pop-up.

Maximum Fees

The amount posted for Max Fee as specified on the property's Fees Setup pop-up.

Flat Fees

The amount posted for Flat Fee as specified on the property's Fees Setup pop-up.

Per Unit Fee

The amount posted for Per Unit Fee as specified on the property's Fees Setup pop-up.

Per Occupied Fee

The amount posted for Per Occupied Fee as specified on the property's Fees Setup pop-up.

Calculated % of Total Income

The calculated amount posted for the percent of the property's total (gross) income as specified on the Fees Setup pop-up % of Total Income field.

Calculated % of Net Income

The calculated amount posted for the percent of the property's net income as specified on the Fees Setup pop-up % of Net Income field.

Chart % Amount

The calculated amount posted for the percentage of each chart account specified on the Fees Setup pop-up Chart Account Fees section.

Fee Amount

The total amount of fees posted for the property.

Report Totals Subreport

The Report Totals subreport provides the totals of all management fees for all properties displayed in the report.
