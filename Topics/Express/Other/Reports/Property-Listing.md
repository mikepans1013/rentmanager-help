# Property Listing (Report)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Reports/Property-Listing.htm

The Property Listing report displays basic property information such as the name and address of the property, occupancy data, and total tenant balance due in addition to management and owner information. This report is useful for owners to view leasing trends and contact information and for exporting general information about properties.

 Related Preferences

 Reports may look different depending on whether or not the Use modernized report style system preference is enabled. For more information, refer to General Report Options (System Preferences) .

 Report Options

 The report options described below determine what data displays in the report.

 Properties to Include

 Select each property or a property Group to be included in the report.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Optionally, check Show Inactive Properties to include properties that are no longer active.

 More Information

 Properties with the Property Type of RV/Campground or Short Term Rental do not display in this report. Short term rental property information is available in reports listed in the Short Term Rentals report category.

 Report Results

 The report results are described below including, if applicable, section, column, and subreport or tab descriptions.

 Report Header

 The report header displays the report name and key information selected in the report options, such as date information and which properties were examined in the report.

 Property Information

 This section displays the property’s name and default address.

 Other Information

 This section displays occupancy and financial information for each selected property.

 Option
 Description

 Total Units

 The total number of units in the property.

 Total Occupied Units

 The number of occupied units in the property as of the current date.

 Total Occupants

 The total number of occupants in the property as of the current date.

 Total Vacant

 The total number of vacant units in the property as of the current date.

 Total Move/Ins MTD

 The total number of tenant move ins month-to-date.

 Total Move/Outs MTD

 The total number of tenant move outs month-to-date.

 Total Balance Due

 The total unpaid balance of all tenants associated with the property.

 Total Charged MTD

 The total amount charged to all tenants associated with the property month-to-date.

 Total Square Footage

 The total square footage of the property entered on property's details page. Alternatively, if an amount has not been entered, the total of the square footage entered on the unit's details page for each unit in the property displays.

 Manager Information

 This section displays information about the property manager, including their name, contact phone numbers, email address, and the optional message entered on the property's details page, in the Comments field.

 Owner Information

 This section displays the names of the property’s owners as defined on the property's Owners pop-up.
