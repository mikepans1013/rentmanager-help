Rental Unit Listing (Report)

The Rental Unit Listing report displays a list of vacant and occupied units over a selected date range. This report provides summarized details of active rental units at your properties, such as the square footage, occupants, rent amounts, and vacancy information. You can utilize this report to provide leasing and occupant information to owners, or to generate a list of active units.

Related Privileges

Group Privilege Column
Letter/Email Templates/Reports/Packets Run reports Enabled

Additionally, on the Reports tab, you must have access to Rental Unit Listing.

For more information, refer to Control User Access.

To view the Rental Unit Listing report, do the following:

  1. Go to arrow_forward Rental Info arrow_forward Listings arrow_forward Rental Unit Listing.
    The Reports: Rental Unit Listing page displays.

  2. Adjust the report options as desired. Each option is described below.

  3. Generate the report in your desired file format(s).

Related Preferences

Reports may look different depending on whether or not the Use modernized report style system preference is enabled. For more information, refer to General Report Options (System Preferences).

Report Options

The report options described below determine what data displays in the report.

Properties to Include

Select each property or a property Group to be included in the report.

More Information

This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property.

Optionally, check Show Inactive Properties to include properties that are no longer active.

Date Range

Enter or select the date range to determine the data that displays in the report.

In the Date Range section, set the From and To dates for which the report should examine data.

These fields automatically populate with today’s date. Enter a different date or select a date from the calendar. Alternatively, adjust the dates using the available preset buttons or click to open more options for setting a date range.

Run Properties Separately

Check to generate a separate report for each selected property. Otherwise, all selected properties are combined into a single report.

Sort Options

Select one of the following options to determine how the report results are sorted in each property subheading:

Option Description

Address

Units are sorted alphanumerically by the address checked as Default. Units with no address display first in the list.

Occupant

Units are sorted alphabetically by the First Name of the most recent occupant. Vacant units display first in the list.

Unit

Units are sorted alphanumerically by Unit name.

Unit Type

Units are sorted alphanumerically by their assigned Unit Type. Units with the same unit type are further sorted alphanumerically by Unit name.

Report Results

The report results are described below including, if applicable, section, column, and subreport descriptions.

Report Header

The report header displays the report name and key information selected in the report options, such as date information and which properties were examined in the report.

Column Descriptions

The columns that display in the report are described below.

Column Description

Unit

The name of the rental unit. A subtotal of all rental units associated with a property displays at the bottom of each property's section.

Unit Type

The Unit Type of the rental unit as defined on the unit's details page.

Sq. Ft.

The Square Footage of the unit as entered on the unit's details page. A subtotal of the square footage of all rental units associated with a property displays at the bottom of each property's section.

Address

The address checked as Default on the unit's details page.

Current Occupant

All tenants that occupied the unit in the selected date range. If there were no occupants in the unit during the selected date range, Vacant displays. The percentage of days the units associated with a property were occupied during the selected date range displays at the bottom of each property's section in Occupancy.

Market Rent

The market rent dollar amount with the most recent From Date as entered on the unit's details page's Current Market Rent tile.

Rent Amount

The total dollar amount of the unit's active recurring rent charges. This value is calculated by adding all active recurring charges with a charge type matching those selected on the property's details page in the Rent Charge Type field.

Days Vacant

The total number of days within the selected date range where a tenant is not leasing the unit. 0 displays if a unit was not vacant during the date range. A subtotal of all days where a unit associated with a property was vacant displays at the bottom of each property.

Summary Subreport

The Summary subreport displays totals based on the units listed in the report results, such as the percentage of occupied units and rent charge amounts.

Column Description

Total Units

The number of units included in the report results.

Total Days in Period

The number of days in the date range.

Total Occupancy

The percentage of units occupied during the date range.

Market Rent Total

The total dollar amount of market rent for units during the date range.

Rent Amount Total

The total dollar amount of rent charges for units during the date range.
