User Activity Log (Report)

The User Activity Log report displays user activity for a specified period. The report shows the date and time that each user logged in and out of Rent Manager. It also shows the duration of each session and the total active time for the period.

Related Privileges

Group Privilege Column
Letter/Email Templates/Reports/Packets Run reports Enabled

Additionally, on the Reports tab, you must have access to User Activity Log.

For more information, refer to Control User Access.

To view the User Activity Log report, do the following:

  1. Go to  arrow_forward System arrow_forward Users arrow_forward User Activity Log.
    The Reports: User Activity Log page displays.

  2. Adjust the report options as desired. Each option is described below.

  3. Generate the report in your desired file format(s).

Related Preferences

Reports may look different depending on whether or not the Use modernized report style system preference is enabled. For more information, refer to General Report Options (System Preferences).

Report Options

The report options described below determine what data displays in the report.

Date Range

Enter or select the date range to determine the data that displays in the report.

In the Date Range section, set the From and To dates for which the report should examine data.

These fields automatically populate with today’s date. Enter a different date or select a date from the calendar. Alternatively, adjust the dates using the available preset buttons or click to open more options for setting a date range.

Report Results

The report results are described below including, if applicable, section, column, and subreport or tab descriptions.

Report Header

The report header displays the report name and date information.

Column Descriptions

The columns that display in the report are described below. The report is organized in headings for each Rent Manager user account.

Column Description

Duration

The time in hours and minutes that the user was logged in to Rent Manager during each corresponding session, the sum of which is displayed in Total Time under each user's section of the report.

Info Message

An annotation indicating whether or how the corresponding session was started or terminated displays after the duration. Depending on the action taken, one of the following annotations display:

Successful Login

The user was actively logged in to Rent Manager at the time the User Activity Log report was generated. If the user is already logged in to one platform (i.e., Rent Manager 12 or Rent Manager Express), the platform may appear in parentheses beside the annotation to indicate to which the log in record applies.

Successful Logout

The user manually logged out of their Rent Manager session.

Logout Override

The user was automatically logged out of Rent Manager due to inactivity.

Failed Login Attempt

A user's log in attempt failed; the computer and user information as well as the user's Username display. Failed log in attempts (e.g., a user enters incorrect credentials) display under the <Unassigned> user.

Login Time

The name, date, and time the user logged in to Rent Manager.

Logout Time

The date and time the user logged out of Rent Manager.
