# Open Evictions (Report)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Reports/Open-Evictions.htm

The Open Evictions report displays a list of tenants in the eviction process during the selected date range. Additionally, the report can be run to include the history/note items tied to each eviction. Tenants are grouped by eviction stage. Clicking on a tenant record from this report displays the Tenant Eviction Summary report, which details the eviction's start date, reason, balance due, notice and court information, and stage history.

 Report Options

 The report options described below determine what data displays in the report.

 Properties to Include

 Select each property or a property Group to be included in the report.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Optionally, check Show Inactive Properties to include properties that are no longer active.

 As of Date

 Rent Manager examines relevant report information as of (up through) the date entered to determine the data that displays in the report.

 Run Properties Separately

 Check to generate a separate report for each selected property. Otherwise, all selected properties are combined into a single report.

 Include Tenants with a Balance Greater than or Equal To

 Check this option and enter an amount in the corresponding field so that only accounts with an open balance greater than or equal to the entered amount are examined.

 Show Eviction Notes

 Check this option and enter an amount in the Number of Eviction Notes field so that only that number of the most recent eviction-type history/note items display.

 Stages To Display

 Select each eviction stage in a workflow associated with an open eviction to include in the report results. Each option is described in the table below.

 Option
 Description

 All

 All ( Legally in eviction and Custom ) stages in a workflow associated with an open eviction are included in the report results. By default, this field is selected.

 Legally in eviction

 Only tenants who are considered to be legally in eviction are included in the report results. This is established on the Eviction Workflow Settings pop-up's Stage Settings field.

 Custom

 Allows you to access the Select Stages drop-down list, which displays a list of all active eviction stages in a workflow associated with the selected properties.

 Report Results

 The report results are described below including, if applicable, section, column, and subreport descriptions.

 Report Header

 The report header displays the report name and key information selected in the report options, such as date information and which properties were examined in the report.

 Column Descriptions

 The columns that display in the report are described below.

 Column
 Description

 Current Balance Due

 The total dollar amount the tenant owes in unpaid charges.

 Days in Stage

 The number of days the tenant has been in the current eviction stage.

 Eviction Reason

 The reason why the eviction process was started. For more information, refer to Eviction Reasons (Page) .

 Notes

 The history/note item(s) tied to the eviction. The number of notes that display correlate to the amount selected Number of Eviction Notes field in report options.

 Outcome

 The result of the eviction when the eviction is closed. For more information, refer to Eviction Outcomes (Page) .

 Property

 The property associated with the open eviction.

 Tenant

 The name of the tenant linked to the open eviction.

 Unit

 The unit associated with the open eviction.
