# Owner Web Access License Usage (Report)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Reports/Owner-Web-Access-License-Usage.htm

The Owner Web Access License Usage report displays the Owner Web Access (OWA) account information for owners with registered accounts across all locations, including the total number of owners registered for OWA. The report also provides login and lockout history for each account, which can help troubleshoot account access issues.

 Related Preferences

 Reports may look different depending on whether or not the Use modernized report style system preference is enabled. For more information, refer to General Report Options (System Preferences) .

 Report Results

 The report results are described below including, if applicable, section, column, and subreport descriptions.

 Report Header

 The report header displays the report name and key information selected in the report options, such as date information and which properties were examined in the report.

 Column Descriptions

 The columns that display in the report are described below.

 Column
 Description

 Last Lockout

 The full date and time when the owner's Owner Web Access account was last locked.

 Last Login

 The full date and time when the owner last accessed their Owner Web Access account.

 Locked Out

 If the account is actively locked, Yes displays. If the account is not locked, No displays.

 Owner Name

 The account name of each owner.

 Username

 The email address the owner uses to log in to their Owner Web Access account.
