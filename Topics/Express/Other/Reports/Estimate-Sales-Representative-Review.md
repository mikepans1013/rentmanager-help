# Estimate Sales Representative Review (Report)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Reports/Estimate-Sales-Representative-Review.htm

The Estimate Sales Representative Review report displays information about the number of estimates opened and closed by each sales representative, the age of the open estimates, and the value of estimates completed.

 More Information

 The results can include any transaction information even if it started prior to the general ledger (GL) start date since this report does not consider the GL start date.

 Report Options

 The report options described below determine what data displays in the report.

 Date Range

 Enter or select the date range to determine the data that displays in the report.

 In the Date Range section, set the From and To dates for which the report should examine data.

 These fields automatically populate with today’s date. Enter a different date or select a date from the calendar. Alternatively, adjust the dates using the available preset buttons or click to open more options for setting a date range.

 Users to Include

 Select the users whose estimates information displays in the report. Only users with the Sales Representative option selected on the General tab of the Users page display.

 Report Results

 The report results are described below including, if applicable, section, column, and subreport descriptions.

 Report Header

 The report header displays the report name and key information selected in the report options, such as date information and which properties were examined in the report.

 Column Descriptions

 The columns that display in the report are described below.

 Column
 Description

 Representative

 The name of the sales representative.

 Opened

 The number of estimates opened by the sales representative in the date range.

 Closed

 The number of estimates closed by the sales representative in the date range.

 Open Estimates Closed

 The number of open estimates closed by the sales representative in the date range.

 Close Rate

 The percentage of open estimates closed by linking the estimate to a purchase order, invoice, service issue, or bill.

 Avg. Age of Open Estimates

 The average number of days the sales representative's open estimates have been open.

 Oldest Open Estimate

 The Reference description of the estimate that has been open for the longest amount of time. The number of days the estimate has been open is displayed in parentheses.

 Total Closed Amount

 The total dollar amount of the sales representative's closed estimates.
