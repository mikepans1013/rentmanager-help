# Inspection Report

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Reports/Inspection.htm

The Inspection Report can be printed and given to an inspector to be used as a guide when evaluating each area and item during an inspection. The report includes all information that was entered when adding the inspection in Rent Manager , and room for the inspector to provide detailed notes about each item's status. The bottom of the report provides lines for both the inspector and the associated tenant (if applicable) to sign off on the inspection once it's completed.

 The report can also be printed when an inspection is complete (either in Rent Manager or with rmAppSuite Pro ) to display all information that was entered throughout the course of the evaluation.

 Related Preferences

 Reports may look different depending on whether or not the Use modernized report style system preference is enabled. For more information, refer to General Report Options (System Preferences) .

 Report Options

 The report options described below determine what data displays in the report.

 Picture Size

 Select how to display images in the report that have been added to each item.

 Option
 Description

 No Pictures

 The images in the inspection do not display in the report.

 Small Pictures

 Includes small versions of the images, fitting approximately three pictures in a row.

 Large Pictures

 Includes large versions of the images, each picture displaying on its own row.

 Picture Quality

 Select an option to determine the quality of the pictures included in the report. The option you choose also determines the speed at which the report generates.

 Option
 Description

 High Quality (Slowest)

 The images maintain their original quality, but the report may take longer to generate.

 Medium Quality

 The report balances image quality and generation speed. The image quality is slightly reduced so that the report generates at an increased speed.

 Low Quality (Fastest)

 Image quality is further reduced, allowing the report to generate quickly.

 Comment

 Optionally, enter a custom note to display at the top of the report.

 Exclude Items With No Status

 Any items on the inspection that do not have a status assigned to them are excluded from the report results.

 Include Header With Logo

 If checked, the company logo, as it displays on the property's details page in the Logo tile, displays at the top left corner of the report.

 Report Results

 The report results are described below including, if applicable, section, column, and subreport descriptions.

 Comment

 The Comment section displays the text entered by the Rent Manager user on the Report options pop-up.

 Inspection Details

 The Inspection Details section displays information regarding the inspection, including the property and unit being examined, the inspector, and more. The fields containing the information on the information are displayed below:

 Field
 Description

 Address

 The default address of the property where the inspection occurs.

 Date

 The date the inspection occurred. If, on a tenant self-inspection, the Inspection Date is blank, Inspection Not Submitted displays.

 Inspector

 The name of the user who is responsible for carrying out the inspection. For tenant self-inspections, this field is replaced by Inspector Type and displays Tenant as the type.

 Move In Date

 The tenant's Move In Date as it displays on the tenant's details page in the Leases tile.

 Property

 The name and default address of the property where the inspection occurred.

 Status

 The current stage of the inspection (e.g., In Progress or Completed ).

 Submitted

 The date the inspection Status was set to Closed . For tenant self-inspections, the date the tenant selected Submit on the inspection in rmResident .

 Tenant

 The name of the tenant associated with the inspection.

 Type

 The type of inspection being performed (such as Move-Out or Unit Updates ).

 Unit

 The name of the unit where the inspection occurred.

 Management Contact Details

 The Management Contact Details section displays information on the property account created for your management company, as entered in system preferences in the Management Company page. Each field is described below:

 Field
 Description

 Address

 The default address of your management company as entered on your management company's property details page in the Primary Addresses tile.

 Name

 The name of your management company as entered on your management company's property details page in the General tile.

 Phone Number

 The phone number of your management company as entered on your management company's property details page in the Phone Numbers tile.

 Description

 The Description section displays a summary of the inspection's purpose as entered on the inspection details Description tile.

 Notes

 The Notes section displays additional details and comments regarding the inspection as entered on the inspection details Notes tile.

 Area Summary

 In the Area Summary section, each area in the inspection is accompanied by the number of items and the number of associated images and videos.

 Follow Up Items

 The Follow Up Items section displays the total number of inspection items with a checked status associated with a status flag (e.g., Actionable Item , Severe Item , Needs Review Item ). The items that are calculated here are based on what statuses are checked in the report and how those statuses are set up on the inspection template. For more information, refer to Edit an Inspection Template Toolbox .

 Field Descriptions

 Each area evaluated in the inspection has its own subsection in the report. The number of areas included and their names are dependent on the inspection template selected when the inspection was created. The fields that display per item in each area are described below.

 Field
 Description

 Images

 If, in the Picture Size report option, Small Pictures or Large Pictures is selected, any images that relate to the item's inspection display. This may be previous photos for reference or new photos taken during the inspection.

 Inspection Video

 A video posted by the inspector regarding the area evaluated. If the document is downloaded as a PDF, the video is opened by clicking this option.

 Name

 Each item evaluated is listed by name in the Area sub-section. The number of items included and their names are dependent on the inspection template selected when the inspection was created.

 Notes

 Any additional details regarding the evaluated item.

 Status

 The reported state entered for each item (such as Poor , Acceptable , or Excellent ). If the item has a status associated with a status flag, the status flag also displays to the right of the item's name.

 Action Required

 Item is in a state that action can be taken to resolve any status concerns.

 Needs Review

 Item needs to be reviewed further to determine the status.

 Severe

 Item is in a state that requires more immediate attention and resolution.
