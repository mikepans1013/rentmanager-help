# Inactive Unit Listing (Report)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Reports/Inactive-Unit-Listing.htm

The Inactive Unit Listing report displays information about inactive units during the report date range for properties. This report helps you track how many days your units are inactive, how many inactive units you have at your properties, and lost potential rent income. This report can be a great tool to get a quick list of units that are unavailable for renting as well as monitor and audit unit statuses to ensure the information regarding the availability of the unit is up to date.

 Report Options

 The report options described below determine what data displays in the report.

 Properties to Include

 Select each property or a property Group to be included in the report.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Optionally, check Show Inactive Properties to include properties that are no longer active.

 As of Date

 Rent Manager examines relevant report information as of (up through) the date entered to determine the data that displays in the report.

 Run Properties Separately

 Check to generate a separate report for each selected property. Otherwise, all selected properties are combined into a single report.

 Sort Options

 Select one of the following options to determine how the report results are sorted.

 Option
 Description

 Unit

 Units are sorted alphanumerically by unit name.

 Unit Type

 Units are sorted alphanumerically by unit type name. Units of the same unit type are further sorted by unit name.

 Address

 Units are sorted alphanumerically by their default address. Units with no address display first in the results.

 Square Feet

 Units are sorted numerically by their square feet in ascending order (least to greatest). Units with the same square footage are further sorted by unit name.

 Report Results

 The report results are described below including, if applicable, section, column, and subreport descriptions.

 Report Header

 The report header displays the report name and key information selected in the report options, such as date information and which properties were examined in the report.

 Column Descriptions

 The columns that display in the report are described below. The units are organized under subsections by property.

 Column
 Description

 Unit

 The name of the unit currently marked inactive via a unit status.

 Unit Type

 The unit category assigned to the inactive unit.

 Address

 The default street address of the inactive unit.

 Comment

 The information that displays on the inactive unit's details page in the Comment field

 Sq. Ft.

 The square footage of the inactive unit.

 Days Inactive

 The number of days the unit is marked as inactive via a unit status.

 More Information

 If the unit's status has a Start Date that matches the As of Date from the report options, one of the following displays:

 -
 A negative number indicates the number of days until the unit's status ends.

 -
 No number indicates that the unit's status has no end date.

 Rent Amount

 The current market rent amount of the inactive unit.

 Summary Subreport

 The Summary subreport displays regardless of the report options selected and provides a breakdown of all properties and the number of inactive units at each.

 The following columns displays on the subreport.

 Column
 Description

 Sum of rent for inactive units

 The total market rent amount of all inactive units at the property.

 Property

 The full name of the property where the inactive unit is located.

 # of Units

 The total number of units at the property.

 Inactive

 The total number of units at the property currently marked as inactive via a unit status.

 % Inactive

 The percentage of units at the property currently marked inactive via a unit status.

 Total Sq. Ft.

 The total square footage of all units at the property.

 Inactive Sq. Ft.

 The total square footage of all inactive units at the property.

 % Inactive Sq. Ft.

 The percentage of square footage that is part of the inactive units.
