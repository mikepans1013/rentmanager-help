# Month to Month Leases (Report)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Reports/MTM-Leases.htm

The Month to Month Leases report displays leasing information for tenants and units whose leases are assigned a lease term of MTM (month-to-month) and are current as of the specified date. This report can be useful for identifying all tenants with month-to-month leases in preparation for getting them signed on with official lease terms.

 Based on your report options, this report can also display leasing information for tenants with no lease term (or with a lease term that is not MTM) whose lease is currently expired but have not yet moved out. This helps identify tenants who have not yet renewed their expiring leases and who to generate renewal offers for.

 Report Options

 The report options described below determine what data displays in the report.

 Properties to Include

 Select each property or a property Group to be included in the report.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Optionally, check Show Inactive Properties to include properties that are no longer active.

 As of Date

 Rent Manager examines relevant report information as of (up through) the date entered to determine the data that displays in the report.

 Run Properties Separately

 Check to generate a separate report for each selected property. Otherwise, all selected properties are combined into a single report.

 Exclude Renewed Leases

 Check to remove tenants who already renewed their lease(s) from the results. Otherwise, tenants with renewed leases are included in the report.

 More Information

 A lease is considered a renewal only if it is generated from Create Renewal Offers tool or, on the tenant's lease details pop-up, by clicking the Renew button. For more information, refer to Create Renewal Offers or Manually Renew a Lease .

 Include Expired Leases with No Renewals

 Check to display leases that have no lease terms or current leases that have a lease term other than MTM but are not renewed by the specified report date. The report includes only leases which ended before the report date and have either no move out date or a move out date after the report date.

 Sort Options

 Select one of the following options to determine how the report results are sorted under each property subheading:

 Option
 Description

 Account Number

 Tenants are sorted numerically by their system-generated ID number in ascending order (lowest to highest).

 Address

 Tenants are sorted alphanumerically by their default address.

 Last Name

 Tenants are sorted alphabetically by their last name. Commercial tenants are sorted by Company Name .

 Lease End - Desc

 Tenants are sorted chronologically by their Lease End date in descending order (newest to oldest).

 Lease Start

 Tenants are sorted chronologically by their Lease Start date in ascending order (oldest to newest).

 Phone

 Tenants are sorted numerically by their default phone number. Tenants with no phone number display first in the results.

 Unit

 Tenants are sorted alphanumerically by Unit name.

 Unit Type

 Tenants are sorted alphanumerically by Unit Type name.

 Report Results

 The report results are described below including, if applicable, section, column, and subreport descriptions.

 Report Header

 The report header displays the report name and key information selected in the report options, such as date information and which properties were examined in the report.

 Column Descriptions

 The columns that display in the report are described below.

 Column
 Description

 Acc. #

 The tenant's system-generated account ID number.

 Lease End

 The date on which the current lease is set to end, as entered on the lease's details in the Lease End field. If no lease end is set, this column displays blank.

 Lease Start

 The date on which the current lease begins, as entered on the lease's details in the Lease Start field.

 Market Rent

 The market-valued rent amount for the unit as entered on the unit's Current Market Rent tile.

 Phone Number: Default

 The tenant’s phone number marked as Default .

 Renewed

 If the tenant already renewed the lease that is active as of the report's specified date, an X displays.

 If the renewed lease is a month-to-month lease and the MTM  lease term has the option Consider As Renewal checked, MTM displays.

 Rent

 The assigned rent amount for the lease as entered on the tenant's Recurring Charges tile.

 Tenant

 The first and last name of the primary tenant associated with the lease. Commercial tenants display the Company Name .

 Unit

 The name of the unit associated with the lease.

 Unit Type

 The unit type assigned to the unit associated with the lease.
