# Prospect Stage Comparison (Report)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Reports/Prospect-Stage-Comparison.htm

This report displays the total number of prospects per leasing agent, and a count of how many prospects are currently in each prospect stage as of the time the report is generated. If you use the prospect stages tool, this report allows you to compare the number of prospects in each stage by leasing agent and get an overview of where prospects are in the leasing process. For more information, refer to Prospect Stages (Page) .

 Related Preferences

 Report Options

 The report options described below determine what data displays in the report.

 Properties to Include

 Select each property or a property Group to be included in the report.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Optionally, check Show Inactive Properties to include properties that are no longer active.

 Leasing Agents

 Select an active user to display only prospects assigned to those leasing agent(s) in the report results. Only users with Leasing Agent selected on their User details page display in the list.

 Prospect Stages to Include

 Select the prospect stages and associated prospects to be examined in the report. Optionally, check Inactive Stages to include stages that are no longer active. For more information, refer to Prospect Stages (Page) .

 Run Properties Separately

 Check to generate a separate report for each selected property. Otherwise, all selected properties are combined into a single report.

 Report Results

 The report results are described below including, if applicable, section, column, and subreport descriptions.

 Report Header

 The report header displays the report name and key information selected in the report options, such as date information and which properties were examined in the report.

 Column Descriptions

 The columns that display in the report are described below.

 Column
 Description

 Agent

 The name of each leasing agent selected in the Leasing Agents report option.

 Stage

 A column displays for each prospect stage selected in the Prospect Stages to Include report option.

 Each column displays the total amount of prospects currently in that stage, separated by leasing agent. The bottom of each column shows a total of all prospects currently in the stage.

 Total

 The total number of prospects currently assigned to each leasing agent.

 A total of all prospects, in all stages, assigned to all leasing agents displays at the bottom of the column.
