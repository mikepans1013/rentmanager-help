# Owner 1099 Breakdown (Report)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Reports/Owner-1099-Breakdown.htm

The Owner 1099 Breakdown report provides a way for you to verify your owners' 1099 income before printing those numbers on an IRS form to complete your taxes. This report displays ownership information, the gross income generated by each of an owner's properties, and the total gross income for the selected calendar year. Furthermore, those numbers are adjusted based on each owner's percent of ownership and contract dates.

 Related Preferences

 Reports may look different depending on whether or not the Use modernized report style system preference is enabled. For more information, refer to General Report Options (System Preferences) .

 Report Options

 The report options described below determine what data displays in the report.

 Owners to Include

 Select each owner or an owner Group to be included in the report.

 More Information

 Only information related to the properties to which you have access displays. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Optionally, check Show Inactive Properties to include properties that are no longer active.

 Exclude total values less than $600

 Check to display forms only for owners who earned more than $600 of gross income in the selected year in the report results.

 Owner Name Source

 Select from the following options to determine what information displays on the form for the RECIPIENT'S name .

 Option
 Description

 Owner Name

 The owner's Name as entered on the owner's details page.

 Payee

 The Payee name as entered on the owner's details page.

 User Defined Field

 The value of an owner-level user defined field. Once selected, use the UDF Name drop-down list to select from your owner-level UDFs with a text field type. For more information, refer to Owner-Type User Defined Fields (Pop-Up) .

 If an owner has no value entered for the selected UDF, the Owner Name option is used for that owner instead.

 Year

 Select the desired calendar year to display the gross income earned by the selected active owner(s) during that year.

 Report Results

 The report results are described below including, if applicable, section, column, and subreport descriptions.

 Report Header

 The report header displays the report name and key information selected in the report options, such as date information and which properties were examined in the report.

 Column Descriptions

 The report results are grouped by owner and displays the following information for each owner included in the report:

 Field
 Description

 Owner Name

 The name of the owner whose information is included in the report.

 Owner Address

 The primary address of the owner as shown on the owner's details page.

 Tax ID

 The ID number for each owner as entered in the 1099 SocSec #/Tax # field on the owner's details page.

 The columns that display in the report are described below.

 Column
 Description

 Property

 The name of each property in the owner's portfolio displayed on the owner's Ownership pop-up.

 From

 The selected calendar year's start date. If the owner's contract at a property starts after the beginning of the calendar year, then the contract start date displays instead.

 To

 The selected calendar year's end date. If the owner's contract at a property ends before the end of the calendar year, then the contract end date displays instead.

 % Ownership

 The percentage of property ownership for this owner as displayed on the owner's Ownership pop-up.

 Amount

 The total amount of gross income an owner earned from each property calculated by their ownership percentage and active contract dates for the selected calendar year. The subtotal of all gross income each owner earned displays at the bottom of each owner's subsection.

 Report Totals Subreport

 The columns that display in the subreport are described below.

 Column
 Description

 Total Owners Listed

 The number of owners listed in the report results.

 Amount

 The total dollar amount of all income for the owners listed in the report.
