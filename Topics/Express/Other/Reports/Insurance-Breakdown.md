# Insurance Breakdown (Report)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Reports/Insurance-Breakdown.htm

If you have the paid insurance integration with LeaseTrack and utilize the Tracking or Enforcement option for insurance, the Insurance Breakdown report displays the current tenants and homeowners with and without insurance policies at each property allowing you to evaluate compliance regarding the policies.

 Related Preferences

 This report displays only if Enable insurance tracking is checked. For more information, refer to Activate and Set Up LeaseTrack Insurance .

 More Information

 The report excludes policies if one or more of the following conditions are true:

 -
 The lease has the Don't require insurance option selected.

 -
 The lease is for a unit type marked as Other Rentable Items (ORI) .

 -
 The lease is at a property that does not have insurance tracking enabled.

 -
 The lease does not have an associated unit.

 -
 If the tenant or homeowner has a lease with both current and future insurance policies, one policy is excluded so they are counted only once for that lease.

 Related Preferences

 Reports may look different depending on whether or not the Use modernized report style system preference is enabled. For more information, refer to General Report Options (System Preferences) .

 Report Options

 The report options described below determine what data displays in the report.

 Properties to Include

 Select each property or a property Group to be included in the report.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Optionally, check Show Inactive Properties to include properties that are no longer active.

 Run Properties Separately

 Check to generate a separate report for each selected property. Otherwise, all selected properties are combined into a single report.

 Sort Options

 The report results are grouped by insurance type (e.g., Personal (Renters) , Master (300k Homeowners) , No Insurance , and so on). The report results for each property are then further sorted by one of the following options:

 Option
 Description

 Account Number

 Tenants and homeowners are sorted numerically by their system-generated Account ID .

 Last Name

 Tenants and homeowners are sorted alphabetically by last name.

 Property

 Tenants and homeowners are sorted alphanumerically by property name. Accounts are further sorted by last name.

 Unit

 Tenants and homeowners are first sorted alphanumerically by property, then further sorted alphanumerically by unit name.

 Report Results

 The report results are described below including, if applicable, section, column, and subreport descriptions.

 Report Header

 The report header displays the report name and key information selected in the report options, such as date information and which properties were examined in the report.

 Column Descriptions

 The columns that display in the report are described below.

 Column
 Description

 Acc #

 The system-generated account number of the tenant or homeowner.

 Lease End

 The date a tenant or homeowner's lease is set to end, as listed on the account's Leases tile.

 Lease Start

 The date a tenant or homeowner's lease started, as listed on the account's Leases tile.

 Property

 The full name for the property associated with the tenant or homeowner.

 Tenant

 The tenant or homeowner's full name.

 Unit

 The name of the unit at which the tenant resides.
