Violation Codes Listing (Report)

The violation Codes Listing report displays information about violation codes within a selected violation code group. This report can be printed as a quick reference of the violation codes for your properties, or to verify that your rules and regulations have been entered into Rent Manager correctly.

Related Privileges

Group Privilege Column
Letter/Email Templates/Reports/Packets Run reports Enabled

For more information, refer to Control User Access.

To view the Codes Listing report, do the following:

  1. Go to arrow_forward Administration arrow_forward Rental Info arrow_forward Violations arrow_forward Violation Code Groups and select a code group.
    The Code Group page displays.

  2. Click Print Codes.
    The Reports: Code Group page displays.

  3. Adjust the report options as desired. Each option is described below.

  4. Generate the report in your desired file format(s).

Report Options

The report options described below determine what data displays in the report.

Violations to Include

Check or uncheck Include stage info by code to determine if the Stage Information section displays for each code group in the report results. This gives more insight into the charges and actions for the default stages entered on each code in the code group. You can also view this information by selecting a code from the Code Group page.

Sort Options

Select one of the following options to determine how the report results are sorted:

Option Description

Category

Violation codes are sorted alphanumerically by category name.

Code

Violation codes are sorted alphanumerically by code name.

CC&R Reference

Violation codes are sorted alphanumerically by the CC&R Reference. Codes with no CC&R reference display first in the results.

Report Results

The report results are described below including, if applicable, section, column, and subreport descriptions.

Report Header

The report header displays the report name and key information selected in the report options, such as date information and which properties were examined in the report.

Column Descriptions

The columns that display in the report are described below.

Column Description

Category

The violation category associated with the code.

Code

The name of each violation code.

Description

Any additional notes regarding the violation code.

Action To Resolve

The action(s) a tenant must take to resolve violations associated with the code.

CC&R Reference

The reference number in the Covenants, Conditions, and Restrictions (CC&R), or similar regulatory document.

Internal Notes

Instructions specific to the code intended to assist users in processing violations associated with the code.

Stage Information

The following columns display if the report option Include stage info by code is selected.

Column Description

Stage

The name of each escalation stage for the violation code

Days

The number of days a tenant has to comply for each stage in the violation code.

Letter

The default letter sent to tenants for each stage in the violation code.

Chg. Type

The default charge type used to charge tenants for each stage in the violation code.

Amount

The default amount of the charge incurred by tenants for each stage in the violation code.

Require Actions

An X displays if the Require user validation of these actions before a violation can be escalated option is enabled in the Stage Details pop-up for each stage.

Actions

The Default Actions required by the tenant to resolve violations at each stage.
