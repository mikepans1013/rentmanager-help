# Charge Type Links (Report)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Reports/Charge-Type-Links.htm

The Charge Type Links report displays a complete list of general ledger (GL) accounts and the charge types that are linked to them. Only GL accounts that are linked to one or more charge types display in the report. This report is useful for auditing linked GL accounts to charge types, and allows you to determine if charge types are linked to incorrect GL accounts.

 More Information

 The GL start date is considered the financial start date, so any transactions or information dated before the GL start date are not included in the report results.

 Report Results

 The report results are described below including, if applicable, section, column, and subreport descriptions.

 Column Descriptions

 The columns that display in the report are described below.

 Column
 Description

 GL Account

 The Name of each general ledger account with charge types linked to it.

 GL Acc. #

 The GL Account No of each general ledger account used as the system-wide identifier for the GL account.

 GL Description

 A more detailed summary of the account.

 Type

 The account type that most closely defines the purpose of the GL account (e.g., Bank , Expense , Equity , etc.).

 Charge Type

 The Name of each charge type linked to the general ledger account.

 Charge Description

 The Description of each charge type linked to the general ledger account.

 Amount

 The Default Amount entered for each charge type linked to the general ledger account.
