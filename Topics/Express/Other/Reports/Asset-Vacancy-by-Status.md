# Asset Vacancy by Status (Report)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Reports/Asset-Vacancy-by-Status.htm

The Asset Vacancy by Status report provides details on the current status of your assets, including information on revenue potential and identification of potential issues in the process of getting an asset back to market.

 Only assets with the option This asset is rentable checked on the asset's details page are included in this report.

 Related Preferences

 Reports may look different depending on whether or not the Use modernized report style system preference is enabled. For more information, refer to General Report Options (System Preferences) .

 Report Options

 The report options described below determine what data displays in the report.

 Properties to Include

 Select each property or a property Group to be included in the report.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Optionally, check Show Inactive Properties to include properties that are no longer active.

 As of Date

 Rent Manager examines relevant report information as of (up through) the date entered to determine the data that displays in the report.

 Asset Statuses to Include

 Check each asset status to be included in the report. The report displays assets with the selected statuses applied on the Asset details page. For more information, refer to Asset Statuses (Page) .

 Include Site Classification

 Check to display the Site Classification column, which displays the short name of each unit's site classification. This option is accessible only when at least one manufactured housing–type property is selected.

 The site classification that displays is based on the date selected in the As of Date section.

 Site Classifications to Include

 If Include Site Classification is checked, select each site classification to be included in the report. The report displays assets with the selected site classifications applied based on the site's legal owner, whether the site can be rented, the occupancy status, and the type of asset(s) and/or resident-owned RV present at that site. For more information, refer to Site Classification .

 Rentable Asset Types to Include

 Check each asset type to be included in the report. The report displays assets with the selected types applied on the Asset details page. For more information, refer to Asset Types (Page) .

 Run Properties Separately

 Check to generate a separate report for each selected property. Otherwise, all selected properties are combined into a single report.

 Report Results

 The report results are described below including, if applicable, section, column, and subreport descriptions.

 Report Header

 The report header displays the report name and key information selected in the report options, such as date information and which properties were examined in the report.

 Column Descriptions

 The columns that display in the report are described below.

 Column
 Description

 Asset Name

 The unique name of the asset, as entered on the asset's details page in the Name field.

 Asset Type

 The category of the asset, as entered on the asset's details page in the Asset Type field.

 Current Status

 The current state of the asset (e.g., Refurb Pending , Refurb in Progress ), as indicated on the asset's details page. For more information, refer to Asset Statuses (Page) .

 Days In Status

 The number of days the asset has been in the status indicated in the Current Status column.

 Days Vacant

 For assets that have a past lease, the number of days after the lease's Move Out date through the report's selected As of Date .

 Market Rent

 The asset's rental rate, as entered on the asset's details page in the Market Rent field.

 Property

 The name of the property where the asset is used, as indicated on the asset's details page in the Asset Location or Home Location tile.

 Site Classification

 The site classification of the unit on which the asset is located, as indicated on the unit's details page in the Site Classification field. This column displays only if the Include Site Classification report option is enabled.

 Unit

 The unit the asset is currently assigned to, as indicated on the asset's details page in the Asset Location or Home Location tile.

 Summary Subreport

 This subreport displays the overall report totals for all of the calculated columns for each status type as well as the total rent amount of all assets listed in the report.

 The following columns displays on the subreport.

 Column
 Description

 # Of Assets

 The total number of assets assigned to the status type.

 % Of Total

 The percentage of total assets listed in the report that are assigned to the status type.

 Average Days In Status

 The running average of days an asset is assigned to the status type.

 Average Days Vacant

 The running average of days an asset assigned to the status type is vacant.

 Market Rent

 The total market rent amount of all assets listed in the report.

 Status

 The name of the status type.
