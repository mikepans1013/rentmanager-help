Top Callers (Report)

The Top Callers report displays rmVoIP activity within the selected date range for the most active inbound or outbound callers, based on your criteria of number of calls or call length. The number of top callers that display in the report, as well as which phone numbers to include in the report results, can be determined in the report options. Totals for inbound and outbound call duration, the number of calls for each top caller, and cumulative totals display at the bottom of their respective columns.

Related Preferences

This report is available only if you have rmVoIP Enabled in system preferences. For more information, refer to rmVoIP (System Preferences).

Related Privileges

Group Privilege Column
Letter/Email Templates/Reports/Packets Run reports Enabled

Additionally, on the Reports tab, you must have access to Top Callers.

For more information, refer to Control User Access.

To view the Top Callers report, do the following:

  1. Go to arrow_forward Communication arrow_forward rmVoIP arrow_forward Top Callers.
    The Reports: Top Callers page displays.

  2. Adjust the report options as desired. Each option is described below.

  3. Generate the report in your desired file format(s).

Report Options

The report options described below determine what data displays in the report.

Date Range

Enter or select the date range to determine the data that displays in the report.

In the Date Range section, set the From and To dates for which the report should examine data.

These fields automatically populate with today’s date. Enter a different date or select a date from the calendar. Alternatively, adjust the dates using the available preset buttons or click to open more options for setting a date range.

Associated Phone Numbers

Check each phone number to be included in the report.

Number of Callers

Select the maximum number of top callers to display in the report. This value is set to 10 by default.

Include Calls

Check to Include Inbound calls, Include Outbound calls, or both in the report results.

Sort Options

Select one of the following options to determine how the report results are organized:

Option Description

Total Call Count

Phone numbers are sorted numerically by the total number of inbound and outbound calls in descending order (greatest to least).

Total Duration

Phone numbers are sorted numerically by the total duration of inbound and outbound calls in descending order (longest to shortest).

Report Results

The report results are described below including, if applicable, section, column, and subreport or tab descriptions.

Report Header

The report header displays the report name and key information selected in the report options, such as date information and which properties were examined in the report.

Column Descriptions

The columns that display in the report are described below.

Column Description

Number

Displays the ten-digit phone number of the caller.

Information

Displays a name or other information associated with the caller.

Inbound Count

Displays the number of times a top caller has called you during the date range.

Inbound Duration

Displays the total length of all inbound calls from the caller during the date range.

Outbound Count

Displays the number of times you called a top caller during the date range.

Outbound Duration

Displays the total length of all outbound calls to the caller during the date range.

Total Count

Displays the total amount of calls during the date range. If both inbound calls and outbound calls were checked in the Include Calls section of the report options, the combined total of both types displays.

Total Duration

Displays the total amount of time that calls from the selected number lasted, in DD:HH:MM:SS (Days:Hours:Minutes:Seconds) format, during the date range. If days are not needed, only HH:MM:SS displays.
