# User Listing (Report)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Reports/User-Listing.htm

The User Listing report displays account details for user accounts in Rent Manager . The report includes their first name, last name, email address, phone number, extension, and roles as they are entered on their account.

 -
 Adjust the report options as desired. Each option is described below.

 -

 Related Preferences

 Reports may look different depending on whether or not the Use modernized report style system preference is enabled. For more information, refer to General Report Options (System Preferences) .

 Report Options

 The report options described below determine what data displays in the report.

 Users to Include

 Select each user or user role to be included in the report. Optionally, check Include Inactive Users to include user accounts no longer marked as active.

 Sort Options

 Select one of the following options to determine how the report results are sorted:

 Option
 Description

 Last Name

 Users are sorted alphabetically by their Last Name .

 First Name

 Users are sorted alphabetically by their First Name .

 rmVoIP Ext

 Users are sorted numerically by their phone extension in ascending order. Users with no phone extension display first in the list.

 Report Results

 The report results are described below including, if applicable, section, column, and subreport descriptions.

 Column Descriptions

 The columns that display in the report, as entered on their user account, are described below.

 Column
 Description

 First Name

 The user's first name.

 Last Name

 The user's last name.

 Email

 The user's primary email address.

 Phone

 The user's primary phone number.

 Ext.

 The user's rmVoIP extension that gives the user access to the integrated rmVoIP phone features in Rent Manager .

 Roles

 The user roles assigned to the user.
