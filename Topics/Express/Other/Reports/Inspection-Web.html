Web Inspection (Report)

The web Inspection report is an inspection recap report that provides a detailed PDF document that can be emailed or downloaded. The downloaded file can also be uploaded to Tenant Web Access (TWA) or Owner Web Access (OWA). The report includes all information, photos, and videos that were entered when performing the inspection in Rent Manager or in the rmAppSuite Pro Inspection feature. The report opens in a responsive web browser window for tenants or owners to review and can then be downloaded as a PDF or HTML file as desired.

Related Privileges

Inspections Inspections View

For more information, refer to Control User Access.

To view the Web Inspection report, do the following:

  1. Go to arrow_forward Services arrow_forward Inspections arrow_forward Inspections and select an inspection.
    The Inspection details page displays.

  2. At the top, click Open Web Inspection Report. Alternatively, if you want to email the report link, click the drop-down arrow next to the button and select Email Web Inspection Report Link to Tenant or Email Web Inspection Report Link to Owner.

    To email the web Inspection report, the following privilege is required:

    Related Privileges

    For more information, refer to Control User Access.

Report Results

The report results are described below including, if applicable, section, column, and subreport descriptions.

Report Header

The report header displays the key information including the report name and the following fields:

Field Description

Date

The date the inspection occurred.

Inspector

The name of the user who is responsible for carrying out the inspection.

Property

The name and default address of the property where the inspection occurred.

Status

The current stage of the inspection (such as In Progress or Completed).

Tenant

The name of the tenant associated with the inspection.

Type

The inspection type assigned to the inspection (such as Move-Out or Unit Updates).

Unit

The name of the unit where the inspection occurred.

Summary

Each area included in the inspection is listed below the Summary header, along with the number of items inspected and the number of associated pictures. Clicking on an area's name quickly jumps to that section of the report. The fields that display in the report are described below.

Field Description

Area Name

Each area evaluated in the inspection has its own subsection in the report. The number of areas included and their names are dependent on the inspection template selected when the inspection was created. Additionally, the number of images associated with the area displays next to .

Item Name

Each item evaluated is listed by name in the Area sub-section. The number of items included and their names are dependent on the inspection template selected when the inspection was created.

Item Notes

Any additional details entered for each item.

Item Status

The reported state entered for each item (such as Poor, Acceptable, or Excellent). If the item is actionable, severe, or needs review, that status flag also displays to the right.

Play Video

Opens a video of the area. If no video is added to the Area sub-section on the inspection, this field does not display.

Related Preferences

This option is available only if, in system preferences, the Video Inspections field is set to Manual or rmAppSuite Pro. For more information, refer to rmAppSuite Inspection (System Preferences).
