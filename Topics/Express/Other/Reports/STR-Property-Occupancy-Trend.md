# Short Term Rental (STR) Property Occupancy Trend (Report)

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Reports/STR-Property-Occupancy-Trend.htm

The STR Property Occupancy Trend report displays the percentage of time a short-term rental (STR) property was occupied during the specified period (month, quarter, or year) and date range. You can use this report to compare the occupancy percentage between STR properties and observe trends over time.

 More Information

 For more detailed information regarding the STR occupancy by unit, you can generate the STR Unit Occupancy Trend report. For more information, refer to Short Term Rental (STR) Unit Occupancy Trend (Report) .

 Report Options

 The report options described below determine what data displays in the report.

 More Information

 The PDF report output can display up to 12 columns of data. To view more than 12 columns of data, you must generate the report in either an excel or CSV format.

 Properties to Include

 Select each property or a property Group to be included in the report. Only properties with a Property Type of RV/Campground or Short Term Rental display in the list.

 More Information

 This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 Optionally, check Show Inactive Properties to include properties that are no longer active.

 Date Range

 Enter or select the date range to determine the data that displays in the report.

 In the Date Range section, set the From and To dates for which the report should examine data.

 These fields automatically populate with today’s date. Enter a different date or select a date from the calendar. Alternatively, adjust the dates using the available preset buttons or click to open more options for setting a date range.

 Period Options

 Select the period for which to view the percentage of time each short term rental property has been occupied. The columns that display in the report results vary based on your selection.

 Option
 Description

 Monthly

 Each month in the date range, followed by the monthly average.

 Quarterly

 Each quarter in the date range, followed by the quarterly average.

 Yearly

 Each year in the date range, followed by the yearly average.

 Run Properties Separately

 Check to generate a separate report for each selected property. Otherwise, all selected properties are combined into a single report.

 Report Results

 The report results are described below including, if applicable, section, column, and subreport or tab descriptions.

 Report Header

 The report header displays the report name and key information selected in the report options, such as date information and which properties were examined in the report.

 Column Descriptions

 The columns that display in the report are described below.

 Column
 Description

 Average

 The percentage of time that units at the property were occupied during the report's date range, calculated using the following formula:

 Average = occupied days in the date range / total days in the selected date range

 The total average percentage of time that units were occupied at all specified properties during the date range is recorded at the bottom of the column.

 Period

 The percentage of time that units at the property were occupied during the period (month, quarter, or year), calculated using the following formula:

 Period = occupied days in the period / total days in the selected period

 The average percentage of time that units were occupied at all the specified properties during the period is recorded at the bottom of each period column.

 More Information

 The columns that display in the report depend on your selection in Period Options in the report options. A column is created for each month, quarter, or year for the selected Date Range .

 Property

 The name of the short-term rental property.
