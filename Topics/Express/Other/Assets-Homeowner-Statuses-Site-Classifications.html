Homeowner Statuses & Site Classifications

For manufactured housing-type properties, the site classification tool allows you to monitor units (or sites) by evaluating several data points and assigning a status accordingly. The site classifications that display in the related reports are determined by the site's legal owner, whether the site can be rented, the occupancy status, and the type of asset(s) and/or resident-owned RV present at that site. To ensure that these classifications are correct for home-type assets, such as manufactured homes and lots, the current legal ownership status (i.e., homeowner status) needs to be tracked and updated for those assets.

The Homeowner Statuses & Site Classifications page allows you to deactivate and modify the Custom Name of your Homeowner Statuses and modify the Custom Name and Custom Short Name of your Site Classifications so that home-type asset tracking and reporting are tailored and relevant to your workflow. Renaming or deactivating your homeowner statuses and site classifications does not change their reporting functionality.

Homeowner Statuses Tab

The Homeowner Statuses tab displays the legal ownership statuses used to track your home-type assets. From this tab, you can deactivate or reactivate a status and modify the status' Custom Name, which displays on the asset's General tile and the Homeowner Statuses pop-up. Once you are satisfied with your edits, click Save.

The following columns display on this tab:

Column Description

Active

If checked, the status is active and can be assigned to home-type assets to classify the ownership of the asset for tracking and reporting. If unchecked, the status' Custom Name field is disabled and cannot be assigned to home-type assets. Deactivated homeowner statuses still retain all past, current, and future status entries.

Custom Name

The customized ownership status that displays for the corresponding site classification Rent Manager automatically applies to the associated unit.

System Name

The system-derived legal ownership status (i.e., Community Owned, Employee Owned, etc.) that corresponds with the site classification Rent Manager automatically applies to the associated unit.

Site Classifications Tab

The Site Classifications tab displays the classifications used to monitor your manufactured housing units (or sites). From this tab, you can modify the classifications' Custom Name and Custom Short Name, which display in applicable filters and reports throughout Rent Manager. Once you are satisfied with your edits, click Save. If a homeowner status is made inactive, the corresponding classification's row is disabled and cannot be edited.

The following columns display on this tab:

Column Description

Custom Name

The customized classification code that displays for units associated with manufactured housing properties.

Custom Short Name

The customized abbreviated classification code that displays for units associated with manufactured housing properties.

System Name

The system-derived classification code for units associated with manufactured housing properties.

System Short Name

The abbreviated system-derived classification code for units associated with manufactured housing properties.
