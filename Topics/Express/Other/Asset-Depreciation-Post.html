Post Depreciation

Businesses that capitalize the cost of certain assets purchased for the business must track the depreciation of these assets over time. Depreciation is the consistent reduction in the value of an asset and the allocation of the asset's cost over a period of time. Posting depreciation creates journal entries that represent the asset's periodic decline in value. Once a depreciation schedule is created through asset depreciation, Rent Manager gives you the ability to post depreciation on a monthly or yearly basis, depending on the asset's schedule.

Related Preferences

To set asset depreciation to post automatically on a scheduled basis, in system preferences the Asset Depreciation option must be checked. For more information, refer to Task Automation (System Preferences).

Related Privileges

Group Privilege Column
Asset Management Post Asset Depreciation Enabled

For more information, refer to Control User Access.

To view the Post Depreciation page, go to arrow_forward Accounting arrow_forward Journals arrow_forward Post Depreciation.

Column Descriptions

The following columns display on the page.

Column Description

Asset

The Name of each asset with available depreciation postings.

Type

The user-created type of each asset.

Property

The name of the property where the asset is located.

Amount

The amount in depreciation that is posted for the date listed in the Post For column. If there is more than one date posted in the Post For column, the amount that is posted for the first date displays.

Last Post

The date of the journal entry created for the most recent depreciation posting for the asset.

Post For

The date(s) of the journal entries that are created by posting depreciation for the asset.
