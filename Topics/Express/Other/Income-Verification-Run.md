# Run Income Verification

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Income-Verification-Run.htm

The Income and ID Verification feature allows you to obtain and review prospects' identification and banking information without the need to request paper documentation and risk receiving falsified data. You can verify they have provided valid identification at the start of the process, ensuring the information is correct before income verification is processed. Then, you can send an income verification invitation link to prospects and tenants directly from Rent Manager , where they are prompted to log into a secure portal and connect their bank account. Financial data is then pulled directly from the bank account(s) provided and a report is generated that includes account balances, transactions, and cash flow.

 More Information

 Although the Income and ID Verification feature is accessible within Rent Manager , the company that provides the service is AmRent 's partner Ibbie. Registered users of AmRent can retrieve verification reports that can be instantly viewed or printed. Additionally, Income and ID Verification requires different credentials from AmRent Screenings . For information about getting an account or if you have Income Verification and want to utilize ID Verification as well, contact AmRent by calling 800-324-3681 or emailing info@amrent.com.

 To run an income and ID verification request, do the following:

 -
 Go to arrow_forward Rental Info arrow_forward General arrow_forward Tenants | Prospects and select an account.
The tenant or prospect's details page displays.

 -
 On the action bar to the right, select arrow_forward Run Income Verification .

 -
 On the left, check the box next to the contact(s) who should receive an income and ID verification invitation link.

 -
 In the Personal Information tile, enter or verify the contact's details in the available fields.

 -
 In the Address tile, select one of the available prospect, tenant, or contact address types from the Fill From Address drop-down list or manually enter an address.

 -
 In the Delivery Method tile, check Text Message and/or Email to choose where the invitation link should be sent. Depending on which method is selected, a corresponding Phone Number and/or Email Address must be entered in the Personal Information tile to send an income and ID verification invitation link.

 -
 Click Submit .
The income and ID verification request is submitted and an invitation link is sent to the contact(s).

 More Information

 If Ibbie cannot identify the contact's identification with the included information, a pop-up displays prompting you to either update their details and retry the ID verification process, or continue to the income verification.
