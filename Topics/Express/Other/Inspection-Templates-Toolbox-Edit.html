Edit an Inspection Template Toolbox

Rent Manager inspections streamline and standardize the inspections process by customizing it to fit your needs. Your customizations can be saved as inspection templates, which allow you to create new inspections from the same starting point. You can have multiple templates, allowing you to create unique inspections with consideration to property, unit, or unit type.

To ensure you record the most accurate information on what needs to be inspected, Rent Manager allows you to create and modify reusable areas, items, and statuses in the inspection template toolbox. Adding these elements (i.e., available areas, items, and statuses) allows you to re-use them on multiple templates and make updates in a central location, saving you time during the creation process and ensure consistency between inspections.

More Information

Any edits made to areas, statuses, and items in the toolbox take effect only when they are next applied to an inspection template. Areas, statuses, and items already applied to an inspection template are not affected by edits made to those same components in the toolbox.

Areas on inspections and inspection templates represent the physical locations that need to be inspected (e.g., bedrooms, kitchens, garages, balconies). Each area includes a list of items that need to be inspected in that location (e.g., floors, walls, cabinets), and each item can be assigned a status to determine if further action needs to be taken (e.g., Poor, Needs Repair, Missing), or if it is ready to be completed (e.g., Good, Acceptable).

Areas

Related Privileges

Group Privilege Column
Inspections Inspection Areas Edit

For more information, refer to Control User Access.

To manage the available areas for inspection templates, select the Areas tab and select an area from the list, or create a new area by clicking Add New. The following sections can be customized for each area on this tab:

Section Description

General

The unique Name of the area. If the Show on Management Inspection Only option is selected, this area displays only on inspections performed by Rent Manager users and is not available for tenant self-inspections.

Help Text

Any additional information that displays between the area name and the first item of the inspection. Information entered in Management Help Text displays for Rent Manager users in rmAppSuite Pro and information entered in Tenant Help Text displays for tenants in rmResident.

Items

The inspection item(s) that need to be completed when performing this inspection. To add an existing item from the Items tab to the area, click Add Available Item.

Items

Related Privileges

Group Privilege Column
Inspections Inspection Items Edit

For more information, refer to Control User Access.

To manage the available items for inspection templates, select the Items tab and select an item from the list, or create a new item by clicking Add New. The following sections can be customized for each item on this tab:

Section Description

General

The unique Name of the item. If the Show on Management Inspection Only option is selected, this item displays only on inspections performed by Rent Manager users and is not available for tenant self-inspections.

Help Text

Any additional information that displays between the item name and the item status. Information entered in Management Help Text displays for Rent Manager users in rmAppSuite Pro and information entered in Tenant Help Text displays for tenants in rmResident.

Statuses

The inspection status(es) that can be assigned when inspecting each item, along with the associated status settings and flags for each status (Action Item, Needs Review, Severe, Image Required, and Note Required). To add an existing status from the Statuses tab to the area, click Add Available Status. For more information, refer to Add an Inspection Status.

Statuses

Related Privileges

Group Privilege Column
Inspections Inspection Statuses Edit

For more information, refer to Control User Access.

To manage the available statuses for inspection templates, select the Statuses tab and select a status from the list, or create a new status by clicking Add New. The following sections can be customized for each item on this tab:

Section Description

General

The unique Name of the status. If the Status is available on all items automatically option is selected, this status is included for any newly created items unless manually removed.

Status Settings

The visibility and additional requirements for this status.

Management Inspection Only

This item status displays only on inspections performed by Rent Manager users and is not available for tenant self-inspections.

Note Required

When this item status is selected, the inspector or tenant must enter at least twenty characters to the Notes section for the item to explain its condition.

Image Required

When this item status is selected, the inspector or tenant must upload at least one image of the item to the Images section.

Status Flags on Inspection Report

The designation assigned to this item on the Inspection Activity Report. For more information, refer to Inspection Activity Report.

Action Item

Items with this status are included in the report's # of Action Items column.

Needs Review

Items with this status are included in the report's # of Review Needed Items column.

Severe

Items with this status are included in the report's Severe Items column.
