# Add a Document Packet

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Document-Packet-Add.htm

Document packets allow you to send multiple letter templates and/or signable documents bundled together. To save time sending out individual documents that are commonly sent at the same time, such as a move-in welcome packet, you can create a document packet that contains both letter templates and signable templates that can all be sent together.

 Specific Entity templates/packets privileges must be enabled for each entity type for which you wish to view signable templates (e.g., Owner templates/packets ).

 Additionally, on the Communication tab, you must have access to the letter templates you wish to add to the packet.

 For more information, refer to Control User Access .

 Step 1: Enter Document Packet Information

 To add a new document packet to Rent Manager , do the following:

 -
 Go to   arrow_forward Communication arrow_forward Signable Documents arrow_forward Document Packets .
The Document Packets page displays.

 -
 At the top of the page, click   Add Document Packet .

 -
 Enter information in the following fields.

 Field
 Description

 Description

 Additional information about document packet (e.g., Lease packet for new tenants ).

 Document Type

 The types of documents that are included in the document packet. For example, a tenant-type document packet can only contain tenant-type letter templates.

 Packet Name

 The name of the document packet that displays on the Document Packets page.

 Packet Type

 The category type of packet: General , Lease , or Contract . This is used for organizational purposes and further determines what document types can be included. Each option is described below.

 Contract

 This packet type is only available for use with owner prospect and owner document types.

 General

 This packet type is available for all entities.

 Lease

 This packet type is only available for use in prospect and tenant document types.

 Properties

 The properties associated with the packet. You can only send packets to entities that are linked to the selected properties.

 Users

 The Rent Manager user(s) who can access the packet.

 Step 2: Add Documents to Packet

 After entering information about the packet, you can add the documents to it. The available letters templates are based on the Document Type you selected. For example, if you selected Prospect , only prospect-type letter templates and signable documents are available to select.

 To add a document, do the following:

 -
 In the document table, click Add Document .

 -
 In the Name column's Select Document drop-down, select a Letter Template or PDF Template to add it to the packet.

 -
 Optionally, check the Required field to ensure that the packet always includes the selected document.

 More Information

 Documents that are not marked as Required can be excluded from the packet when it is generated.

 -
 Repeat steps 1 through 3 for each letter template you want to add to the packet.

 -
 Click Save to complete the packet.
The packet is now available on the Document Packets page.
