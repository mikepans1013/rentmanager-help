Manage Orion Smart Voicemail Boxes

The Smart Voicemails feature brings rmVoIP together with Orion AI to allow you to manage your voicemails all in one place in Rent Manager. Smart Voicemails are recorded in Smart Voicemail boxes that can be accessed in Rent Manager Express. You can create new boxes, or upgrade your existing rmVoIP voicemail boxes to convert them to Smart Voicemail boxes. After Smart Voicemail boxes are created, the users assigned to them can review and manage voicemails directly from Rent Manager.

More Information

This feature is licensed and must be purchased separately. For more information, contact your sales representative at sales@rentmanager.com.

Add a New Smart Voicemail Box

Related Privileges

Group Privilege Column
Phone System Smart Voicemail Boxes View, Add

In addition, on your user details page, you must have a valid rmVoIP Extension.

For more information, refer to Control User Access.

You can create new Smart Voicemail boxes to receive messages from incoming calls. Each Smart Voicemail inbox has a designated rmVoIP extension that receives and records messages. When messages are received, email alerts can be sent to a specified email address to ensure you can quickly reply.

To create a new Smart Voicemail box, do the following:

  1. Go to  arrow_forward Communication arrow_forward Communication Setup arrow_forward General arrow_forward Manage Voicemail Boxes.
    The Manage Voicemail Boxes pop-up displays.

  2. Click Add Voicemail Box.

    More Information

    A pop-up requesting NDT Portal credentials may display. If it does, you must enter your NDT Username and Password to proceed.

  3. Enter information into the following fields:

    Field Description

    Extension

    The dedicated rmVoIP extension assigned to the box. This field cannot be edited.

    Notification Email

    The email address that receives alerts when a voicemail is added to the box.

    Users

    Related Privileges

    Group Privilege Column
    System Manage assigned users and privileges Edit

    For more information, refer to Control User Access.

    The Rent Manager users who can access voicemails added to the box.

    Voicemail Box Name

    The unique name that identifies the box.
  4. Click Save.
    The Smart Voicemail box is added to Rent Manager.

Upgrade an Existing Voicemail Box

Related Privileges

Group Privilege Column
Phone System Smart Voicemail Boxes View, Edit

In addition, on your user details page, you must have a valid rmVoIP Extension.

For more information, refer to Control User Access.

You can convert existing rmVoIP voicemail boxes to a Smart Voicemail box to take advantage of the powerful new features provided by Orion AI. Once an existing voicemail box is converted, users can access the voicemails in it only from Rent Manager.

To upgrade an existing rmVoIP voicemail box to a Smart Voicemail box, do the following:

  1. Go to  arrow_forward Communication arrow_forward Communication Setup arrow_forward General arrow_forward Manage Voicemail Boxes.
    The Manage Voicemail Boxes pop-up displays.

  2. To the right of Add Voicemail Box, click arrow_forward Upgrade Existing Voicemail Boxes.
    The Upgrade Voicemail Boxes pop-up displays.

    More Information

    A pop-up requesting NDT Portal credentials may display. If it does, you must enter your NDT Username and Password to proceed.

  3. For each standard rmVoIP voicemail box you wish to upgrade, check the corresponding Upgrade box and, in the Users column, select the Rent Manager users and/or user roles who can access voicemails in the box. Only voicemail extensions that haven't already been converted to Smart Voicemail boxes display.

  4. Click Save.
    The Upgrade Existing Voicemail Boxes pop-up displays.

  5. To confirm you wish to upgrade the voicemail boxes, click Upgrade.
    The standard voicemail box(es) is converted to a Smart Voicemail box.
