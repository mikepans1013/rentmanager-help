# Vendor Addresses

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Vendor-Addresses.htm

You can create and manage your own categories for vendor addresses on the Address Types page. This makes it easy to record and reference multiple addresses on the same vendor account. Additionally, this adds the ability to pull a specific address type into other parts of Rent Manager , such as reports and features that use scripting. Once you define an address type for vendors, you can go to any vendor account to enter the associated address.

 For more information, refer to Control User Access .

 To add a vendor address type, do the following:

 -
 Go to arrow_forward Administration , then go to Customization arrow_forward Address Types .

 -
 In the Type section, select Vendor .

 -
 Click Add Address Type .

 -
 Enter the Name for this vendor address type.
This name displays as an option on the vendor's View Addresses pop-up.

 -
 Click Save .
The address type is added to all vendor accounts.

 For more information, refer to Control User Access .

 To add a vendor address, do the following:

 -
 Go to arrow_forward Payables arrow_forward General arrow_forward Vendors and select a vendor.
The Vendor details page displays.

 -
 On the Addresses tile, select the according address type tab for the address you wish to add.

 -
 Select the according address type tab for the address you wish to add.

 -
 In the text field, enter the vendor's address.

 -
 If the address is used as the primary source of correspondence, check Default .

 -
 Click Save .
The vendor address is added.
