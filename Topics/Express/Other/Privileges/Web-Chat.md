# Web Chat Privilege Group

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Privileges/Web-Chat.htm

These privileges control Web Chat, the administration of queues, the handling of unlinked conversations, and whether an agent may override the set number of conversations at once.

 To enable a privilege, check the box. Each privilege is described below.

 Privilege Descriptions

 Each privilege is described below.

 Privilege
 Description

 Queues

 Add, view, edit, or delete queues. For more information, refer to Manage Queues (Web Chat) (Page) .

 Manage Unlinked Conversations

 This user may view the Unlinked Conversations (Web Chat) (Page) , Closed Conversations (Web Chat) (Page) , and Offline Conversations (Web Chat) (Page) registers and manage the conversations within them.

 Users may also link these conversations to any entities (tenants, prospects, etc.) to which they have permissions.

 Allow Agent to Exceed Maximum Conversations

 A user with the role of Agent or Admin in a queue may take an unlimited amount of web chat conversations in any queues they have access to.

 Allow To Delete Closed Web Chat Conversations

 Users with this privilege are able to delete conversations in the Unlinked Conversations (Web Chat) (Page) and Closed Conversations (Web Chat) (Page) registers, or the History/Notes tab of the account to which the chat is linked.
