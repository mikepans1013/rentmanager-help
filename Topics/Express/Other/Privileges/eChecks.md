# eChecks Privilege Group

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Privileges/eChecks.htm

The eChecks privileges control the Safeguard eChecks integration used to pay bills and write checks electronically.

 To manage these privileges, do the following:

 -
 Go to arrow_forward Administration , then go to Users arrow_forward Users . Select a user and click the Privileges tab.

 -
 Click next to the privilege group to expand the privilege list.

 -
 To enable a privilege, check the box. Each privilege is described below.

 -
 Click Save .

 Privilege Descriptions

 Each privilege is described below.

 Privilege
 Description

 Post eCheck Batches

 Allows a user to manually post eChecks to Safeguard.

 Related Preferences

 This privilege is ignored if the system preferences options to Automatically process eChecks when paying are checked. For more information, refer to eChecks (System Preferences) .

 Reorder eChecks

 Allows a user to manually reorder eChecks from Safeguard.

 Related Preferences

 This privilege is ignored if the system preferences options to Automatically process eChecks when paying are checked. For more information, refer to eChecks (System Preferences) .

 Edit eChecks Emails on Checks

 Allows a user to edit or change the email address populated for the eChecks recipient before the check is processed.

 Edit eChecks Emails on Bills

 Allows a user to edit or change the email address populated for the eChecks vendor before the bill is processed.
