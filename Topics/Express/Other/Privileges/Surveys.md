# Surveys Privilege Group

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Privileges/Surveys.htm

These privileges control property surveys, the ability to publish/send a survey and view its results, and to add responses to surveys and view individual responses.

 To manage these privileges, do the following:

 -
 Go to arrow_forward Administration , then go to Users arrow_forward Users . Select a user and click the Privileges tab.

 -
 Click next to the privilege group to expand the privilege list.

 -
 To enable a privilege, check the box. Each privilege is described below.

 -
 Click Save .

 Privilege Descriptions

 Each privilege is described below.

 Privilege
 Description

 Surveys

 Add, view, edit, or delete surveys.

 Survey Results

 Allows a user to view the Surveys page, select a survey with responses, and view the Survey Results pop-up.

 Publish/Send Surveys

 Allows a user to publish a survey/poll to Tenant Web Access , where tenants or board members may respond to your questions. Additionally, this allows a user to send a survey/poll on demand from the Tenants or Issues page.

 Add Survey Responses

 Allows a user to add a response after selecting a survey on the Surveys page.

 View Individual Survey Responses

 Allows a user to view survey answers from either the tenant's History/Note tile or the Survey Results pop-up Responses tab.
