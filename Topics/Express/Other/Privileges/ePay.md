# ePay Privilege Group

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Privileges/ePay.htm

ePay privileges provide access to Zego ePay options for Rent Manager 's integrated partner Zego that can be used to electronically process prospect or tenant payments, collect application fees with the Apply Now integration, pay vendor bills, process owner contributions, and pay owner distributions. This feature can automatically debit your customer's checking or credit card account, deposit funds in your bank account, and record the transaction in Rent Manager .

 -
 Go to arrow_forward Administration , then go to Users arrow_forward Users . Select a user and click the Privileges tab.

 -

 -
 To enable a privilege, check the box. Each privilege is described below.

 -
 Click Save .

 Privilege Descriptions

 Each privilege is described below.

 Privilege
 Description

 Access ePay Settings

 Allows a user to access ePay system preferences.

 Set Up ePay Password

 Allows a user to set an ePay password in Security ePay (System Preferences) .

 Setup and perform ePay operations

 Allows a user to enable ePay and enter account information for properties, tenants, prospects, and owners by navigating to the applicable entity and clicking arrow_forward View ePay Account on File .

 Manually process individual ePay payments

 Allows a user to process one (non-recurring) ePay payment for any tenant or prospect for whom ePay has already been established and enabled.

 For more information, refer to Tenant ePay Settings (Pop-Up) .

 Fix Web ePay Transactions

 Allows a user to check ePay issues that have been initiated but not completed due to system and/or network timeouts during the ePay submission process that may have compromised the completeness of data submitted to Rent Manager . ePay issues must be resolved before the correct bank balances are reflected in your Rent Manager database.

 Process ePay refunds

 Allows a user to select a tenant's ePay payment transaction, refund the payment amount, and add the original charges to the tenant's outstanding balance.

 For more information, refer to Tenant ePay Settings (Pop-Up) .

 Perform Owner ePay Contributions

 Allows a user to receive Make a Manual Owner Contribution .

 Perform ePay batch processing

 Allows a user to post recurring ePay payments and scanned check batches. For more information, refer to Post Recurring ePay .

 Edit Vendor ePay

 Allows a user to set up ePay accounts for individual vendors at arrow_forward Payables arrow_forward Vendors arrow_forward select a vendor arrow_forward arrow_forward View ePay Account on File .

 Process Vendor/Owner ePay

 Allows a user to pay bills with ePay transactions.

 CashPay

 View and edit transactions related to Zego CashPay. This licensed feature for Rent Manager users who use Zego as their ePay provider allows residents to electronically pay their rent with cash at CheckFree ePay walk-in payment service locations.

 Perform ePay Deposit Reconciliation

 Allows a user to perform Reconcile ePay Deposits when the Advanced ePay (System Preferences) option Managed Deposits is checked.

 Create manual deposits with managed deposits

 Allows a user to make manual Make ePay Deposits , which allows users to manually record ePay deposits in bank registers.

 Managed deposits

 Edit and delete deposits based on those reported by Zego .

 Perform ePay Returns

 Allows you to view and update all ePay transactions rejected by Zego at arrow_forward Accounting arrow_forward  Check ePay Returns .

 For more information, refer to ePay Returns (Page) .
