# Task Automation Privilege Group

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Privileges/Task-Automation.htm

Task automation privileges give users access to set up posting schedules in Rent Manager for features such as Task Automation and Accounts Receivable Automation .

 More Information

 Task Automation is available only on Rent Manager Online . For more information on Rent Manager Online , you can contact your Sales Representative at sales@rentmanager.com .

 To manage these privileges, do the following:

 -
 Go to arrow_forward Administration , then go to Users arrow_forward Users . Select a user and click the Privileges tab.

 -
 Click next to the privilege group to expand the privilege list.

 -
 To enable a privilege, check the box. Each privilege is described below.

 -
 Click Save .
