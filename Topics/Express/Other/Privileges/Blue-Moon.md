# Blue Moon Privilege Group

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Privileges/Blue-Moon.htm

Blue Moon privileges control access to Blue Moon leases and eSignature documents. Blue Moon is a partner that provides industry-standard leasing documents. The integration between Blue Moon and Rent Manager allows you to seamlessly track your leases and lease documents.

 To manage these privileges, do the following:

 -
 Go to arrow_forward Administration , then go to Users arrow_forward Users . Select a user and click the Privileges tab.

 -
 Click next to the privilege group to expand the privilege list.

 -
 To enable a privilege, check the box. Each privilege is described below.

 -
 Click Save .

 Privilege Descriptions

 Each privilege is described below.

 Privilege
 Description

 Create Lease

 Allows you to create a lease in Rent Manager and record that lease in Blue Moon .

 Edit fields during lease creation

 When creating a Blue Moon lease, you need this privilege to edit the fields.

 Override Blue Moon default values in Other Fields

 When creating a Blue Moon lease, certain field values are populated from Blue Moon . If enabled, you can edit those field values when creating the lease.

 Edit Blue Moon Locked Fields

 Allows locked fields in Blue Moon to be overwritten when generating a Blue Moon lease from a tenant or prospect account.

 Manage eSignature Documents

 Allows you to view the Blue Moon eSignatures page.

 Execute eSignature Documents

 Allows you to sign an eSignature document and complete the Blue Moon lease.

 Delete eSignature Documents

 Allows you to delete an eSignature document from Rent Manager and Blue Moon .
