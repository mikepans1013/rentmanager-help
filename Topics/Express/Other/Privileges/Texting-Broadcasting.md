# Texting/Broadcast Privilege Group

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Privileges/Texting-Broadcasting.htm

Texting and broadcast privileges provide access to features that allow users to send a single outgoing text or audio message to multiple owners, tenants, prospects, or vendors at once as well as allow users to send and receive bulk text messages in the text messaging center.

 Privilege Descriptions

 Each privilege is described below.

 Privilege
 Description

 Delete text messages

 Allows the user to delete text messages from the text messaging center. For more information, refer to Text Messaging Center (Page) .

 Perform phone broadcast

 Allows the user to access the phone broadcasting tool and send out prerecorded phone messages to a group of phone numbers. For more information, refer to Create a Phone Broadcast .

 Manage text messages

 Allows the user to edit the default texting and broadcasting phone numbers for each property. For more information, refer to Manage Text Numbers (Page) .

 Manage text templates

 Add, edit, and/or delete the text message templates used to populate pre-written messages when sending texts or text broadcasts. For more information, refer to Text Templates (Page) .

 Send Bulk Text/Broadcasts

 Allows the user to access the text broadcasting tool and send text broadcasts. Also grants the ability to send a group of texts via bulk actions. For more information, refer to Create a Text Broadcast .

 Send/Receive Text

 Allows the user to send and receive individual text messages to external accounts (such as tenants) via the text messaging center. For more information, refer to Send a Text Message .

 Send/Receive texts to other users

 Allows the user to send and receive individual text messages to other internal Rent Manager users via the text messaging center.
