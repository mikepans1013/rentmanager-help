Sales/Invoicing Privilege Group

Sales/Invoicing privileges provide access to features related to working with invoices and tracking sales data.

Related Privileges

Group Privilege Column
System Manage assigned users and privileges View, Edit
Manage all users and privileges View, Edit

For more information, refer to Control User Access.

To manage these privileges, do the following:

  1. Go to arrow_forward Administration, then go to Users arrow_forward Users. Select a user and click the Privileges tab.

  2. Click next to the privilege group to expand the privilege list.

  3. To enable a privilege, check the box. Each privilege is described below.

  4. Click Save.

Privilege Descriptions

Each privilege is described below.

Privilege Description

Invoices

Add, view, edit, or delete invoices.

You can also create invoices by clicking on a tenant, prospect, or owner on their respective page and selecting Add Invoice or by creating item links through the Work Order section of a Service Issue.

Inventory Transactions

Add, view, or delete tracked Inventory Item data. View the item’s transaction history, display the item’s quantity or value over time on a graph and, if the Track inventory by property option is enabled in P.O./Inventory (System Preferences), transfer items from one property to another property.

Items

Add, view, edit, or delete Inventory Items. These items are products or services for which you can submit an invoice, create a service issue, or receive via a purchase order. Link items to an income charge type and expense account, specify the unit cost and markup, define if the item is taxable and/or active, and identify this item as tracked inventory with an optional reorder quantity.

Tax types

Add, view, edit, or delete the list of Tax Types (such as sales tax). Specify the percentage of tax to charge, and select the charge type to which funds are allocated.

Manually Adjust Inventory Items

Enable the ability for users to manually increase or decrease the on-hand counts for Inventory Items without using Purchase Orders, Service Issues, or Invoices.
