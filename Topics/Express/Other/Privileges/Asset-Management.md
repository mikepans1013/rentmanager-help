# Asset Management Privilege Group

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Privileges/Asset-Management.htm

Asset management privileges provide access to asset features such as managing and tracking asset manufactures, statuses, types, maintenance records, depreciation schedules, and workflows.

 -

 -

 -
 To enable a privilege, check the box. Each privilege is described below.

 -

 Privilege Descriptions

 Each privilege is described below.

 Privilege
 Description

 Manage Assets

 Add, view, edit, and/or delete assets, including changing the financial property of an asset. For more information, refer to Assets (Page) and Financial Property Migration Wizard .

 Asset Manufacturers

 Add, view, edit, and/or delete the manufacturers that can be linked to assets. For more information, refer to Asset Manufacturers (Page) .

 Asset Statuses

 Add, view, edit, and/or delete the statuses that can be assigned to assets. For more information, refer to Asset Statuses (Page) .

 Manage Home Asset Status History

 Allows the user to add, edit, or delete the statuses in the Home Status section of a home-type asset. This applies only to assets assigned an asset type with the option Assets of this type are homes checked.

 Manage Home Asset Locations

 Allows the user to add, edit, or delete locations in the Home Location section of a home-type asset. This applies only to assets assigned an asset type with the option Assets of this type are homes checked.

 Asset Types

 Add, view, edit, and/or delete the asset types that categorize assets. For more information, refer to Asset Types (Page) .

 Homeowner Statuses

 Add, view, edit, and/or delete the current legal ownership status for assets associated with an Asset Type that is marked as a Home . For more information, refer to Homeowner Statuses (Pop-Up) .

 Asset Maintenance Records

 Add, view, edit, and/or delete maintenance records that display on the asset's History/Notes tile. For more information, refer to Add an Asset Maintenance Record to History/Notes .

 Depreciation Schedules

 Add, edit, and/or delete asset depreciation schedules. For more information, refer to Asset Depreciation Schedules (Pop-Up) .

 Post Asset Depreciation

 Allows the user to post depreciation for assets. For more information, refer to Post Depreciation .

 Unit to Asset Conversion Wizard

 Allows the user to convert units into assets using the conversion wizard. For more information, refer to Unit to Asset Conversion Wizard .

 Manage Homeowner Statuses & Site Classifications

 Provides access to the Homeowners Statuses & Site Classification page, which allows you to deactivate and rename Homeowner Statuses and rename Site Classifications . For more information, refer to Homeowner Statuses & Site Classifications .

 Manage Asset Title Statuses

 Allows the user to add, edit, and delete the title statuses that can be assigned to assets. For more information, refer to Asset Title Statuses (Page) .

 Manage Asset Workflows

 Allows the user to add, edit, and delete workflows that can be assigned to assets. For more information, refer to Asset Workflows (Page) .
