Recurring Charges/Market Rent Privilege Group

Recurring charges and market rent privileges provide access to recurring charges that can be assigned to tenants and posted on a scheduled basis as well as adding or updating market rent values for units.

Related Privileges

Group Privilege Column
System Manage assigned users and privileges View, Edit
Manage all users and privileges View, Edit

For more information, refer to Control User Access.

To manage these privileges, do the following:

  1. Go to arrow_forward Administration, then go to Users arrow_forward Users. Select a user and click the Privileges tab.

  2. Click next to the privilege group to expand the privilege list.

  3. To enable a privilege, check the box. Each privilege is described below.

  4. Click Save.

Privilege Descriptions

Each privilege is described below.

Privilege Description

Recurring charges

Add, edit, or delete automatic recurring charges, such as rent charges, that are billed to tenants on a monthly, weekly, or daily basis when recurring charges are posted.

Batch modify recurring charges

Allows a user to make global changes to a batch of recurring charges on the Modify Recurring Charges page.

Post recurring charges

Allows a user to Post Recurring Charges to apply monthly, weekly, or daily charges to each associated tenant's account.

Modify market rent

Allows a user to update the market rent of individual units through Unit Market Rent or Modify Market Rent for a batch of units within a selected property.
