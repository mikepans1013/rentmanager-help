# Loans Receivable Privilege Group

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Privileges/Loans-Receivable.htm

Loans receivable privileges provide access to features used to create and manage owner-financed loans, which can be used for home sales as well as for land, equipment, appliances, and more. This privilege group enables you to establish loan terms and conditions as well as to post loan charges manually or as recurring charges. Posted loan installment charges are added to the loan recipient's View Transactions page.
