# Utilities Privilege Group

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Privileges/Utilities.htm

Utilities privileges provide access to Metered Utilities through which you can calculate utility usage and bill tenants.

 To manage these privileges, do the following:

 -
 Go to arrow_forward Administration , then go to Users arrow_forward Users . Select a user and click the Privileges tab.

 -
 Click next to the privilege group to expand the privilege list.

 -
 To enable a privilege, check the box. Each privilege is described below.

 -
 Click Save .

 Privilege Descriptions

 Each privilege is described below.

 Privilege
 Description

 Metered utilities

 Allows a user to access Metered Utilities .

 Utility Information

 Add, view, edit, or delete utility information.

 Meter types

 Add, view, edit, or delete Meter Types and calculation methods, as well as import and export meter type information in a .txt file.

 Change current read value and date

 Allows a user to change the value and date of current meter readings.

 Change previous read value and date

 Allows a user to change the value and date of past meter readings.

 Change meter type associated with a unit

 Allows a user to change the Meter Type associated with a unit.

 Post utility information

 Allows a user to post utility charges, which applies utility charges to tenant accounts.

 Rollback utility readings

 Allows a user to rollback utility readings for individual tenants or the posting.

 Manage Meter Estimates Settings

 Allows a user to view, add, and edit the estimate settings for metered utilities. For more information, refer to Meter Estimates (Page) .

 Manage High/Low Settings

 Allows a user to access the High/Low Settings pop-up, where they can add, view, edit, and delete the setup of a multi-tiered approval process for meter reading exceptions. For more information, refer to Manage Metered Utilities High/Low Settings .

 Post RUBS Charges

 Allows a user to post ratio utility billing system (RUBS) charges.

 Rollback RUBS Charge Postings

 Allows a user to rollback ratio utility billing system (RUBS) charge postings.

 Manage RUBS Templates

 Allows a user to add, view, edit, or delete ratio utility billing system (RUBS) templates.
