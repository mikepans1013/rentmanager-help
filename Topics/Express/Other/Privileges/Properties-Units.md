# Properties/Units Privilege Group

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Privileges/Properties-Units.htm

Properties/Units privileges provide access to property and unit features such as management fee setup, unit types, unit status and unit status types, property groups, bank settings, floors, amenities, image types, unit pickers, and the make ready process.

 To manage these privileges, do the following:

 -
 Go to arrow_forward Administration , then go to Users arrow_forward Users . Select a user and click the Privileges tab.

 -
 Click next to the privilege group to expand the privilege list.

 -
 To enable a privilege, check the box. Each privilege is described below.

 -
 Click Save .

 Privilege Descriptions

 Each privilege is described below.

 Privilege
 Description

 Properties

 Add, view, edit, or delete Properties .

 Manage STR Rate Schedules

 Enable to allow a user to add, edit, and delete short term rental (STR) rate schedules and to manage STR settings in the STR Rate Schedules section.

 Management fee setup

 Add, edit, and delete property-level sets of management fee structures. For more information, refer to Property Management Fees Setup .

 Unit types

 Add, view, edit, or delete Unit Types .

 Units

 Add, view, edit, or delete Units on the Units List or Units register.

 Unit Migration Wizard

 Enable to allow a user to move one or more units from one property to anther via the Unit Migration Wizard .

 Unit status type

 Add, view, edit, or delete Unit Status Types , which are exceptions to the standard status of occupied or vacant. Status types further define the availability of a rental unit; for example, a unit may be vacant but still unavailable to rent during a make ready period.

 Unit statuses

 Add, edit, or delete a unit status for an individual unit on Unit Details . To Manage a Unit Status in the Unit Status tile, add or delete a unit status or edit a status by changing the start or end date, applying a different status type, or adding a comment.

 Property groups

 Add, view, edit, or delete Property Groups or more properties, such as an owner's entire portfolio.

 Property Bank Settings

 View or edit property Bank Settings (the banks that are available for use by a property) on Property Details .

 Floors

 Add, view, edit, or delete Floors at a property (such as ground level, second floor, third floor, etc.). Assigning floors to rental units (on the Unit General Information tile) makes it easier to search for units that match the features desired by tenants and prospects.

 Amenities

 Add, view, edit, or delete Amenities (features or conveniences such as fireplaces, patios, pools, etc.). Assigning amenities to rental units (on the Unit Amenities tile) makes it easier to find units with amenities that match the features desired by tenants and prospects.

 Unit picker

 Access the unit picker search to find units that match a prospect's preferences, including property, move-in and move-out dates, the number of people the unit can accommodate, price range, floor, unit types, amenities, and user defined fields.

 Image Types

 Add, view, edit, or delete Image Types that you define to help organize the images that display on an entity's Images tile.

 Make ready actions

 Add, view, edit, or delete Make Ready Actions , which are categories of tasks that are performed as part of making your properties or units ready for their next occupant.

 Make ready board

 View the Make Ready Board , which displays a color-coded visual status of any units that are part of the make ready process and which have tasks still to be completed.

 Make ready process

 Assign or delete a unit to the make ready process using Make Ready Templates . You can also assign a make ready template on a lease prompt when the Move Out date is added.

 Make ready templates

 Add, view, edit, or delete Make Ready Templates , which are lists of make ready actions that can be assigned to one or more properties.
