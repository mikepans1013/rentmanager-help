Owners Privilege Group

Owner privileges control access to features related to Owners, Owner Prospects, and their life cycle. For fee-based management companies, this includes the ability to post management fees, access or create templates for those fee structures, receive contributions, and pay out distributions.

Related Privileges

Group Privilege Column
System Manage assigned users and privileges View, Edit
Manage all users and privileges View, Edit

For more information, refer to Control User Access.

To manage these privileges, do the following:

  1. Go to arrow_forward Administration, then go to Users arrow_forward Users. Select a user and click the Privileges tab.

  2. Click next to the privilege group to expand the privilege list.

  3. To enable a privilege, check the box. Each privilege is described below.

  4. Click Save.

Privilege Descriptions

Each privilege is described below.

Privilege Description

Owners

Allows a user to add, view, edit, or delete Owners.

Default check setups

Allows a user to add, view, edit, or delete Owner Check Setup Templates (Page) for individual owners.

Management fee templates

Allows a user to add, view, edit, or delete Management Fee Templates (Page).

Make Owner Contributions

Allows a user to enter and process Make a Manual Owner Contribution.

Post management fees

Allows a user to collect management fees via Post Management Fees.

Create payments for owners

Allows a user to pay out Owner Distributions.

Configure NACHA Bank

Allows a user to create and/or edit bank account information for NACHA, a universal file type used for ACH transfers between banks, on the Owner Details (Page) page.

Generate NACHA File

Allows a user to make NACHA payments to owners using Owner Distributions.

View complete owner TaxIDs

Allows a user to view the entire Tax ID for the owner on the Owner Details (Page) page by clicking . The default is to mask all numbers except for the last four digits (XXXXX9999).

Owner groups

Allows a user to add, view, edit, or delete Owner Groups.

Ownership Transfer Wizard

Allows a user to access the Ownership Transfer Wizard to transfer properties between owners.

Allow backdating of transactions prior to last fee posting

Allows a user to add, edit, or delete transactions with a date prior to the property's last management fee posting.

Owner Prospects

Allows a user to add, view, edit, or delete Owner Prospects.

Change Owner Prospect Status

Allows a user to change an owner prospect's status on the Owner Prospect Details (Page) page.

Edit Owner Prospects that have been converted to Owners

Allows a user to edit the historical owner prospect record after the owner prospect has been converted to an owner.

Owner Prospects Lead Sources

Allows a user to add, view, edit, or delete Lead Sources for owner prospects.
