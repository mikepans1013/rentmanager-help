# Commercial Recoverable Expenses (CRE) Privilege Group

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Privileges/Commercial-Recoverable-Expenses.htm

CRE privileges provide access to commercial recoverable expenses (CRE) features.

 For more information, refer to Control User Access .

 To manage these privileges, do the following:

 -
 Go to arrow_forward Administration , then go to Users arrow_forward Users . Select a user and click the Privileges tab.

 -
 Click next to the privilege group to expand the privilege list.

 -
 To enable a privilege, check the box. Each privilege is described below.

 -
 Click Save .

 Privilege Descriptions

 Each privilege is described below.

 Privilege
 Description

 Non recurring CRE

 Allows a user to enter non-recurring CRE charges.

 Reconcile CAM

 Allows a user to reconcile CAM charges on the CAM Reconciliation page.

 CRE and charge type setups

 View and edit the Recurring Charges tile of a commercial tenant.

 Edit Reconciled Amount

 Allows a user to edit the value(s) in the Reconciled column on the CAM reconciliation page posting charges.

 CAM Expense Adjustments

 Allows a user to add, view, edit, and delete adjustments to CAM expenses on the CAM Expense Adjustments page.
