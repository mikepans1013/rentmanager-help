Importing Privilege Group

Importing privileges allow the user to import external files to add new data to Rent Manager or update existing data.

Related Privileges

Group Privilege Column
System Manage assigned users and privileges View, Edit
Manage all users and privileges View, Edit

For more information, refer to Control User Access.

To manage these privileges, do the following:

  1. Go to arrow_forward Administration, then go to Users arrow_forward Users. Select a user and click the Privileges tab.

  2. Click next to the privilege group to expand the privilege list.

  3. To enable a privilege, check the box. Each privilege is described below.

  4. Click Save.

Privilege Descriptions

Each privilege is described below. To enable a privilege check the box, then click Save.

Privilege Description

Enable the user to import new or update existing properties. For more information refer to Import Properties.

Import Unit Types

Enable the user to import new unit types. For more information refer to Import Unit Types.

Import Units

Enable the user to import new or update existing units. For more information refer to Import Units.

Import Tenants

Enable the user to import new or update existing tenants. For more information refer to Import Tenants.

Import Prospects

Enable the user to import new or update existing prospects. For more information refer to Import Prospects.

Import Charges

Enable the user to import new charges. For more information refer to Import Charges.

Import Recurring Charges

Enable the user to import new or update existing recurring charges.

Import Payments

Enable the user to import new payments. For more information refer to Import Payments.

Import Vendors

Enable the user to import new or update existing vendors. For more information refer to Import Vendors.

Import Owners

Enable the user to import new or update existing owners.

Import Bills

Enable the user to import new bills.

Import Journals

Enable the user to import new journals. For more information refer to Import Journals.

Import Budget

Enable the user to import new or update existing budgets. For more information refer to Import Budgets.

Import Chart of Accounts

Enable the user to import new or update existing chart of accounts. For more information refer to Import Chart of Accounts.

Import Assets

Enable the user to import new or update existing assets. For more information refer to Import Assets.

Import Owner Contracts

Enable the user to import new owner contracts.

Import Owner Prospects

Enable the user to import new or update existing owner prospects.

Import Owner Prospect Properties

Enable the user to import new properties for owner prospects.

Import Inventory Items

Enable the user to import new or update existing inventory items.

Import Tenant/Prospect Contacts

Enable the user to import new or update existing tenant and/or prospect contacts. For more information refer to Import Tenant/Prospect Contacts.

Import Violation Codes

Enable the user to import new or update existing violation codes. For more information refer to Import Violation Codes.

Import Jobs

Enable the user to import new or update existing jobs. For more information refer to Import Jobs.

Related Preferences

In order to use the job costing tool in Rent Manager, Enable job costing must be checked in system preferences. For more information, refer to General Options (System Preferences).

Import Meter Information

Enable the user to import new or update existing meter utility information not related to consumption values.

Import Depreciation Setup

Enable the user to import a new depreciation setup.

Import STR Guests

Enable the user to import short-term rental (STR) guests as new tenant accounts in Rent Manager along with their reservations.

Import STR Guest Prospects

Enable the user to import short-term rental (STR) guests as new prospect accounts in Rent Manager along with their reservations.

Import STR Reservations

Enable the user to import short-term rental (STR) information about guest reservations to existing tenant accounts in Rent Manager.

Import Master Meters

Enable the user to import new or update existing master meter information.
