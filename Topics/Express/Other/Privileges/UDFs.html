User Defined Fields Privilege Group

User defined fields (UDFs) privileges provide access to user defined fields and encrypted user defined fields. Encrypted UDFs are encoded for the safe storage of sensitive information.

Related Privileges

Group Privilege Column
System Manage assigned users and privileges View, Edit
Manage all users and privileges View, Edit

For more information, refer to Control User Access.

To manage these privileges, do the following:

  1. Go to arrow_forward Administration, then go to Users arrow_forward Users. Select a user and click the Privileges tab.

  2. Click next to the privilege group to expand the privilege list.

  3. To enable a privilege, check the box. Each privilege is described below.

  4. Click Save.

Privilege Descriptions

Each privilege is described below.

Privilege Description

User defined fields

Add, view, edit, and/or delete user defined fields (UDFs).

Access encrypted UDFs (Asset, Tenant/Prospect, Contact, etc.)

Access to view encrypted user defined fields for the specified entity.

Warning

To view the information generated by an encrypted user defined field, the user running the letter must have the applicable encrypted user defined field privileges. For example, if a user wants to have the value of an encrypted tenant-level user defined field display in the letter, in the User Defined Fields privilege group, the Access Tenant encrypted UDFs privilege must be Enabled. Otherwise, the script returns a blank value.

However, if a user with the tenant-level encrypted user defined field privilege generates the letter, and a PDF copy of the letter is attached to the tenant's history/notes, anyone with the privileges to view tenant history/notes can view this information.
