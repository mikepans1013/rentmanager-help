# Metro 2 Privilege Group

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Privileges/Metro-2.htm

Metro 2 privileges provide access to Metro 2 features, which are used to export data from loans in a format that is required by the major consumer reporting bureaus (TransUnion, Equifax, Experian, and Innovis).

 Related Preferences

 Metro 2 options must be selected in Metro 2 Reporting (System Preferences)  to include preferred credit bureaus and their agency account numbers, your organization's contact information as known by the bureaus, and default options for Metro 2-related fields in reporting.

 To manage these privileges, do the following:

 -
 Go to arrow_forward Administration , then go to Users arrow_forward Users . Select a user and click the Privileges tab.

 -
 Click next to the privilege group to expand the privilege list.

 -
 To enable a privilege, check the box. Each privilege is described below.

 -
 Click Save .

 Privilege Descriptions

 Each privilege is described below.

 Privilege
 Description

 Set up Metro 2

 Allows a user to access system preferences to prepare for exporting loan data in Metro 2 format.

 If this privilege is not enabled, Metro 2 Reporting (System Preferences) does not display.

 Metro 2 Information

 View and edit the Metro 2 information assigned to a loan.

 Create Metro 2 Exports

 Allows a user to export selected loan data to a file in Metro 2 format.

 This option must be enabled for the Export to Metro2 option at arrow_forward Admin arrow_forward Export to display.
