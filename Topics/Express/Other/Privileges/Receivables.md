# Receivables Privilege Group

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Privileges/Receivables.htm

Receivables privileges allow users to add charges, accept payments, reverse payments, backdate transactions, and make changes to postings or fee settings for tenants, prospects, and owners.

 Privilege Descriptions

 Each privilege is described below.

 Privilege
 Description

 Refund security deposits with a check

 When refunding a tenant or prospect's security deposit, this privilege allows a user to select the option to refund the security deposit as a check. For more information, refer to Refund a Security Deposit .

 Refund security deposits with a bill

 When refunding a tenant or prospect's security deposit, this privilege allows a user to select the option to refund the security deposit as a bill.

 Tenant transactions

 Add, edit, or delete transactions on tenant and prospect accounts, such as one-time charges, security deposit charges, and prorated charges. For more information, refer to Add a One-Time Charge .

 Move payments between tenants

 Allows a user to move a tenant or prospect payment to another account at the same property via the arrow_forward Move Payment option. For more information, refer to Move a Payment in the Same Property .

 Take tenant payments

 Allows a user to apply a payment to a tenant or prospect's open charges, or apply a prepayment to a tenant or prospect. For more information, refer to Add a Payment .

 Allow to NSF/Void a payment

 Allows a user to reverse a payment and either void it or mark it as non-sufficient funds (NSF). For more information, refer to Reverse a Payment for Non-Sufficient Funds (NSF) and Void a Payment .

 Override default NSF fee when processing NSF payments

 When reversing a payment as non-sufficient funds (NSF), allows the user to override the default fee.

 More Information

 The default fee is established on the details page of the charge type assigned as the system default for NSF fees, or the default amount may be overridden on the property's details page. For more information, refer to Charge Type Details (Page) and Property Details (Page) .

 Allow to backdate payments

 When entering payments or prepayments, allows the user to select a date prior to today's date.

 Allow to backdate charges

 When adding charges or credits, allows the user to select a date prior to today's date.

 Allow to credit tenants

 Allows the user to add a negative charge (also called a credit) to a tenant or prospect account. This includes both one-time credits and recurring credits. For more information, refer to Add a Credit and Add a Recurring Tenant Credit .

 Additionally, this privilege allows a user to add calculated recurring charges.

 More Information

 If the user has the privileges to post recurring charges, they can still post recurring charges that contain credits or calculations even if they do not have this privilege.

 Clear tenant transaction allocations

 Allows a user to clear the allocations of a payment on a tenant or prospect's account via the arrow_forward Clear Allocations option. For more information, refer to Clear Transaction Allocations .

 Manage Rentable Security Deposit Transactions

 Allows the user to access the Rentable Security Deposit Management page, manage security deposits with Rentable, and add more properties and transfer existing standard security deposits to Rentable. For more information, refer to Rentable Security Deposit Management (Page) .

 Transfer security deposits

 Allows a user to transfer all or part of a tenant or prospect's security deposit to another account. For more information, refer to Transfer a Security Deposit .

 Post security deposit interest

 Allows a user to post security deposit interest for tenants at eligible properties. For more information, refer to Post Security Deposit Interest .

 Override security deposit interest preferences

 Allows a user to enable security deposit interest for a property, and allows them to opt if they wish to override the security deposit interest settings for that property. For more information, refer to Interest Options for Security Deposits (Pop-Up) .

 Post late fees

 Allows a user to post late fees for all tenants and properties with late fees enabled. For more information, refer to .

 Owner transactions

 Add, edit, or delete transactions on owner accounts, such as one-time charges and management fees. For more information, refer to Add an Owner Charge .

 Allow to Credit owners

 Allows the user to add a negative charge (also called a credit) to an owner account.

 Take owner Payments

 Allows the user to manually add a payment directly to an owner account. For more information, refer to Add an Owner Payment .

 Change late fees

 When posting late fees, allows a user to override the late fee setups established on the property or tenant level.

 View Other Users' Payment Batches

 When posting batch payments, allows you to select a batch of payments that was created by another user. For more information, refer to Make Multiple Payments in a Batch .
