History Privilege Group

History privileges provide access to history/note features for tenants, prospects, properties, units, vendors, owners, service issues, estimates, purchase orders, assets, jobs, and violations. They also provide access to add or update history categories.

Related Privileges

Group Privilege Column
System Manage assigned users and privileges View, Edit
Manage all users and privileges View, Edit

For more information, refer to Control User Access.

To manage these privileges, do the following:

  1. Go to arrow_forward Administration, then go to Users arrow_forward Users. Select a user and click the Privileges tab.

  2. Click next to the privilege group to expand the privilege list.

  3. To enable a privilege, check the box. Each privilege is described below.

  4. Click Save.

Privilege Descriptions

Each privilege is described below.

Privilege Description

Tenant History/Notes

Add, edit, and/or delete history/notes on Tenant History/Notes (Pop-Up), including email, call, visit, and standard notes.

Prospect History/Notes

Add, edit, and/or delete history/notes on Prospect History/Notes (Pop-Up), including email, call, visit, and standard notes.

Property History/Notes

Add, edit, and/or delete history/notes on Property History/Notes (Pop-Up).

Unit History/Notes

Add, edit, and/or delete history/notes on Unit History/Notes (Pop-Up).

Vendor History/Notes

Add, edit, and/or delete history/notes on Vendor History/Notes (Pop-Up).

Owner History/Notes

Add, edit, and/or delete history/notes on Owner History/Notes (Pop-Up), including email, call, visit, Owner Web Access (OWA) file, and standard notes.

Owner Prospect History/Notes

Add, edit, and/or delete history/notes on Owner Prospect History/Notes (Pop-Up), including email, call, visit, and standard notes.

Issue History/Notes

Related Privileges

Group Privilege Column
Service Manager Check in/out times Add, Edit, Delete
Other techs' check in/out times Add, Edit, Delete

For more information, refer to Control User Access.

Add, edit, and/or delete history/notes in Issue History/Notes (Pop-Up).

Estimate History/Notes

Add, edit, and/or delete history/notes on Estimate History/Notes (Pop-Up).

Purchase Order History/Notes

Add, edit, and/or delete history/notes in Purchase Order History/Notes (Pop-Up).

Asset History/Notes

Related Privileges

Group Privilege Column
Asset Management Asset Maintenance Records Add, View, Edit, Delete

For more information, refer to Control User Access.

Add, edit, and/or delete history/notes on the asset History/Notes pop-up.

Job History/Notes

Add, edit, and/or delete history/notes on Job History/Notes (Pop-Up).

Violation History/Notes

Add, edit, and/or delete history/notes in Violation History/Notes (Pop-Up).

More Information

This privilege does not affect history/notes of the Violations or Violation Notes type on the tenant account's History/Notes.

Eviction History/Notes

Enables a user to add, edit, or delete eviction-type history/note items on a tenant's Eviction tile.

Allowed to edit other user’s History/Notes

Allows a user to edit history/notes created by another Rent Manager user.

Allowed to delete other user’s History/Notes

Allows a user to delete history/notes created by another Rent Manager user.

History Categories

Add, view, edit, and/or delete History Categories.
