# Custom Forms Privilege Group

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Privileges/Custom-Forms.htm

These privileges provide access to creating and managing custom forms.

 More Information

 New custom forms may be based on a blank page, an imported form, or existing system tenant statements or other custom statement forms and may contain only the sections and fields that a user selects in a location and style that the user chooses.

 To manage these privileges, do the following:

 -
 Go to arrow_forward Administration , then go to Users arrow_forward Users . Select a user and click the Privileges tab.

 -
 Click next to the privilege group to expand the privilege list.

 -
 To enable a privilege, check the box. Each privilege is described below.

 -
 Click Save .
