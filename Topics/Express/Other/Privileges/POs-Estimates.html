POs/Estimates Privilege Group

POs/estimates privileges provide access to features such as creating or editing purchase orders, editing purchase order workflows, and the approval or denial of purchase orders or estimates.

Related Privileges

Group Privilege Column
System Manage assigned users and privileges View, Edit
Manage all users and privileges View, Edit

For more information, refer to Control User Access.

To manage these privileges, do the following:

  1. Go to arrow_forward Administration, then go to Users arrow_forward Users. Select a user and click the Privileges tab.

  2. Click next to the privilege group to expand the privilege list.

  3. To enable a privilege, check the box. Each privilege is described below.

  4. Click Save.

Privilege Descriptions

Each privilege is described below.

Privilege Description

Purchase orders

Add, view, edit, and/or delete purchase orders. These are used to request permission to purchase items, prevent unauthorized purchases, and maintain a historical record of items purchased.

Change PO numbers

Edit the P.O. # field on the purchase order.

Related Preferences

The system preference to Allow Changing PO # in P.O./Inventory (System Preferences) must also be enabled.

Approve purchase orders

Allows the user to be assigned the Approve action on workflows and enables the Approve button on purchase orders for the user. Requiring approval of purchase orders helps prevent unauthorized purchases.

Fulfill purchase orders

Allows the user to be assigned the Fulfill action on workflows, receive purchase orders, and edit the amount received for line items.

Edit approved purchase orders

Allows users to edit purchase orders that are already marked as approved in Rent Manager.

Perform action for assigned workflow user

Allows the user to access and manage purchase orders that use a workflow as if they were the assigned user. A user with this privilege can perform all actions related to the purchase order that the assigned user can. For example, you could grant this to a user who should be responsible for POs when the typical assigned user is out of the office.

Change PO workflow

Allows the user to edit the workflow on purchase orders.

Override budget restriction when approving POs

Allow you to approve a purchase order that exceeds the budgeted amount for a GL account.

Related Preferences

In Budget (System Preferences), the option to Enable restriction of purchase order approval when over budget must be selected in order for this privilege to display.

PO Workflows

Add, view, edit, and/or delete Purchase Order Workflows (Page). Once a purchase order is created, the workflow determines which user receives the PO to approve it and then which user receives the PO for fulfillment.

Estimates

Add, view, edit, and/or delete Estimates, which provide tentative prices for various sales and/or projects for tenants or owners.

View estimates from all users

View estimates created by any user.

Approve/Reject Estimates

Provides the ability to set an estimate to a Status of Approved or Rejected.
