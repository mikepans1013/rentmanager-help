# Setup Privilege Group

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Privileges/Setup.htm

Setup privileges provide access to features used when setting up Rent Manager such as beginning balances, budgets, CPI adjustments, allocation order, dashboards, scoreboards, and menu ribbons.

 Related Privileges

 Group
 Privilege

 Manage assigned users and privileges

 For more information, refer to Control User Access .

 To manage these privileges, do the following:

 -
 Go to arrow_forward Administration , then go to Users arrow_forward Users . Select a user and click the Privileges tab.

 -
 Click next to the privilege group to expand the privilege list.

 -
 To enable a privilege, check the box. Each privilege is described below.

 -
 Click Save .

 Privilege Descriptions

 Each privilege is described below.

 Privilege
 Description

 Beginning Balances

 View and/or edit Beginning Balances for general ledger accounts to tell Rent Manager how much money you started with and where it is.

 Budgets

 View and/or edit Budget (Page) by manually entering expenses from a previous year, copy the previous year's expenses, or import budget values.

 Forecast Models

 Add, view, edit, and/or delete Forecast Models (Page) . The Profit & Loss Forecast (Report) examines a forecast model over a designated period of time to estimate your business's future profits and expenses. The report uses the projections of the forecast model and general probability to predict financial data.

 CPI Adjustments

 Add, view, edit, and/or delete Consumer Price Index (CPI) (Page) Adjustments.CPI values are the consumer price indexes produced by the government as a measure of inflation. After you enter CPI adjustments, you can then modify recurring charges or market rents based on these adjustments.

 Allocation order

 View and edit the allocation order, which is the order in which posted charges (for a specified property) are paid. If you disable a property's defined allocation order, charges are paid in the order they were created.

 Edit all menu ribbons

 Customize menu ribbons assigned to yourself, other users, or user roles with the menu ribbon designer.

 Edit own menu ribbon

 Customize menu ribbons assigned to yourself with the menu ribbon designer.

 Edit dashboard data filters

 Filter what information displays in dashboard tiles assigned to yourself. To change the filter in Rent Manager 12 for a specific dashboard tile, click on the tile and edit the values for any tile as desired. For more information, refer to Dashboard .

 Edit all dashboards

 Customize dashboards assigned to yourself, other users, or user roles with the dashboard designer.

 Edit own dashboard

 Customize dashboards assigned to yourself with the dashboard designer.

 Edit all scoreboards

 Customize scoreboards assigned to yourself, other users, or user roles with the scoreboard designer.

 Edit own scoreboard

 Customize assigned to yourself with the scoreboard designer.

 Manage system filters

 Add, view, edit, and/or delete system filters assigned to yourself, other users, or user roles.

 Violation Code Groups

 Add, view edit, and/or delete Violation Code Groups (Page) .

 Violation Categories

 Add, view edit, and/or delete Violation Categories (Page) .

 Set accounting close date

 Provides access to Accounting Close (System Preferences) and Property Accounting Close (Pop-Up) to set the accounting close date and lock transactions that occurred on or before the close date.

 Override accounting close date

 Override the accounting close date that is set in Accounting Close (System Preferences) or Property Accounting Close (Pop-Up) .

 More Information

 This privilege is not needed to clear ( C column) transactions dated prior to the accounting close date.

 Appointments

 Add, view, edit, and/or delete Appointments (Page) .

 Tasks

 Add, view, edit, and/or delete Tasks (Page) .

 Manage Community Events

 Add, view, edit, and delete a property's events on its Community Calendar (Page) .

 Manage Amenity Reservations

 View, approve, deny, or cancel Add a Reservable Amenity .

 Users with this privilege also see requests and reservations for reservable amenities on the community calendar. For more information, refer to Add a Reservable Amenity and Community Calendar (Page) .

 Memorized Comments

 Add, edit, and/or delete Memorized Comments (Page) are stored to be reused by right-clicking inside the Comment field in numerous areas of the program.

 Edit Own Layouts

 Create, modify, and delete layouts unique to your user account.

 Design Layouts

 Create and edit system layouts or copy a user's personal layout as a system layout.

 Users with this privilege must also have the Manage System Layouts privilege enabled to access the System Layouts page.

 Assign System Layouts

 Set the layout as the default for selected user role(s) and property type(s), copy existing system layouts, delete system layouts, and set the system-wide default layout for entities.

 Users with this privilege must also have the Manage System Layouts privilege enabled to access the System Layouts page.

 Manage System Layouts

 Set the system-wide default layout for entities.

 Manage form tabs

 Control and assign custom tabs that display for a user or user group and which properties display custom tabs.

 Design custom tabs

 Create custom tabs that contain only the attributes that you select in an order and style that you choose with the custom tab designer.

 Add Wizards

 Add, view, edit, and/or delete custom add wizards to control the fields for which data is entered.

 Entity Types

 View and edit the Singular Name , Short Name , and Plural Name for Property , Unit , and Tenant entities in Entity Types (System Preferences) .

 Address Types

 Add, edit, and/or delete address types throughout Rent Manager .

 Phone Number Types

 Add, edit, and/or delete phone number types throughout Rent Manager .

 Manage Report Layout

 Create system-level report layouts in Rent Manager 12 by clicking while in a report's grid view. Once saved, the layout appears as the default view for all users.

 Edit System UDF Values

 Provides access to system user defined fields and the ability to edit the values of system-level user defined fields. For more information, refer to User Defined Fields (Page) .

 Contact Types

 Add, view, edit, and/or delete contact types, allowing users to define categories for the contacts associated with the primary tenant or vendor. For more information, refer to Contact Types (Page) .

 Manage STR Payment Policies

 Enables user to view and edit the STR Payment Policies register, allowing users to define how much a guest owes at time of booking and, if applicable when the remaining balance is due.

 Manage STR Promotions

 Enables the user to add, view, and edit STR promotions. For more information, refer to Short Term Rental (STR) Promotions (Page) .

 Manage Eviction Workflows

 Enables the user to add, view, edit, and delete eviction workflows.

 Manage Eviction Reasons and Outcomes

 Enables the user to add, view, edit, and delete eviction reasons and eviction outcomes.

 Manage Insurance Setup

 Enables the user to set up and manage tenant and homeowner insurance settings and master policies.

 Manage Rentable Security Deposit Setup

 Enables the user to set up and manage Rent Manager 's integrated partner Rentable's security deposit feature, which streamlines the handling of security deposits while maintaining compliance with local legislation. For more information, refer to Set Up Security Deposits with Rentable .
