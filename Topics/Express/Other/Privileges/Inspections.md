# Inspections Privilege Group

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Privileges/Inspections.htm

These privileges provide access to inspections and the various tools associated with inspections, such as customizing areas, statuses, items, templates, and sending self-inspections to tenants. These privileges are required to use inspections in  Rent Manager Express but also allow you to conduct inspections in the rmAppSuite Pro mobile app if you have the related access to the app.

 More Information

 This feature is licensed and must be purchased separately. For more information, contact your sales representative at sales@rentmanager.com .

 Privilege Descriptions

 Each privilege is described below.

 Privilege
 Description

 Inspections

 Add, view, edit, and/or delete inspections in Rent Manager . Inspections created in Rent Manager become available to rmAppSuite Pro when users are out in the field. For more information, refer to Inspections (Page) .

 Related Privileges

 On the user's details page in the Options tile, the Inspector field must be checked if the user needs access for either of the following:

 -
 The user needs to be an option when selecting the Inspector on an inspection.

 -
 The user needs to access the Inspections module in rmAppSuite Pro .

 For more information, refer to User Details (Page) .

 Inspection Areas

 Add, edit, and/or delete the areas that can be inspected on an inspection, inspection template, or in the inspection template toolbox.

 Inspection Items

 Add, edit, and/or delete the individual items to inspect on an inspection, inspection template, or in the inspection template toolbox.

 Inspection Statuses

 Add, edit, and/or delete the statuses to assign to items on an inspection, inspection template, or in the inspection template toolbox.

 Inspection Templates

 Add, view, edit, or delete the inspection templates that are used to create inspections. For more information, refer to Inspection Templates (Page) .

 Send Tenant Self-Inspections

 Allows the user to send self-inspections to tenants so they can perform a unit inspection on their own via the rmResident app, such as during a move in or move out process. For more information, refer to Send Tenant Self-Inspection .
