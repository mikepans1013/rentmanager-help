# Associations Privilege Group

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Privileges/Associations.htm

These privileges control whether users can view and manage Architectural Requests (Page) received by homeowner associations (HOAs), and the setup of committees that may be part of HOAs. These privileges display only if there is at least one property with a Property Type of Association in your database.

 To manage these privileges, do the following:

 -
 Go to arrow_forward Administration , then go to Users arrow_forward Users . Select a user and click the Privileges tab.

 -
 Click next to the privilege group to expand the privilege list.

 -
 To enable a privilege, check the box. Each privilege is described below.

 -
 Click Save .

 Privilege Descriptions

 Each privilege is described below.

 Privilege
 Description

 Manage Architectural Requests

 Allows a user to view and/or edit the requests listed on the Architectural Request page.

 Approve/Deny Architectural Requests

 Allows a user to change the approval status of a request in the Architectural Request page.

 Manage Architectural Request Forms

 Allows a user to view the Architectural Requests Forms page and add, edit, or delete architectural request forms.

 Manage Committees

 Allows a user to view the Committees page and add, edit, and delete committees. For more information, refer to Association Committees (Page) .
