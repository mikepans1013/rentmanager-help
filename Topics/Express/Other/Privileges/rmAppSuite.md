# rmAppSuite Privilege Group

Source: https://rmxhelp.rentmanager.com/Topics/Express/Other/Privileges/rmAppSuite.htm

Various privileges for rmAppSuite Pro are available in this group, including if the user may view other users' service issues and text conversations, tenant financial information, and if the user can add or edit an inspection. Additionally, you can give permission to attach photos to selected categories.

 More Information

 Privilege Descriptions

 Each privilege is described below.

 Privilege
 Description

 View service issues assigned to other users

 View issues assigned to other service techs in rmAppSuite Pro Service.

 Capture
(Unit, Prospect, Bills, Estimates, etc.)

 Attach photos taken on an iOS or Android device using rmAppSuite Pro Capture to an entity's account or record.

 Inspections

 Add and/or edit inspections while in rmAppSuite Pro Inspections.

 Smart Receipts

 Enable app users to add and edit Smart Receipts via rmAppSuite Pro .

 Submit smart receipts for other users

 Enable app users to select Someone else when submitting Reimbursement receipts via rmAppSuite Pro .

 View tenant financial information

 Enable app users to view tenants' financial information and transaction history, such as payments and charges posted to the account.

 View other users' text messages

 View text messages that other Rent Manager users sent and received in the app. This option also enables the user to view messages that are answered by any Rent Manager user in the last thirty days.

 View History/Notes in Contacts

 Enable app users to access a contact's History/Notes section via rmAppSuite Pro .
