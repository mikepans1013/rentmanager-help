Add a Subsidy

A subsidy is a form of financial assistance offered to qualifying tenants. The most common subsidy examples are HUD, Section 8, and FEMA. You can create as many subsidies as needed in Rent Manager to cover all your subsidized housing, allowing you to easily make payments towards those qualifying tenants.

Related Privileges

Group Privilege Column
Subsidies Manage Add, View, Edit

For more information, refer to Control User Access.

Step 1: Add Subsidy Information

To create a new subsidy, do the following:

  1. Go to arrow_forward Rental Info arrow_forward Rental Info Setup arrow_forward Properties/Units arrow_forward Subsidies.
    The Subsidies page displays.

  2. Click Add Subsidy.

  3. In the Details tile, enter information into the following fields:

    Field Description

    Charge Type

    The charge type that is paid through this subsidy. When making a subsidy payment for this subsidy, open charges using this charge type are paid for qualifying tenants that are part of the subsidy.

    More Information

    It is recommended that you create a separate charge type for the Section 8 or HUD-based portion of rent due for your tenants.

    Name

    The unique name of the subsidy used for payments (e.g., Housing and Urban Development, Section 8).

    Payment From

    The name of the person, organization, or program that provides the payments for this subsidy.

    Preallocate payments to the Subsidy Charge Type

    If checked, prevents subsidy payments from being automatically applied to open charges that are not the selected subsidy Charge Type.

    Short Name

    A unique, abbreviated name for the subsidy, often used in reporting (e.g., HUD, FEMA).

Step 2: Add Tenants to Subsidy

When making a subsidy payment, selecting a subsidy automatically pulls up all tenants that are part of that subsidy so you can apply the payment towards their open charges. To add qualifying tenants to this subsidy, do the following:

  1. In the Subsidy Tenants tile's Property field, select the property of a tenant you are adding.

  2. In the Tenant field, select the tenant to add to the subsidy.

  3. Click Add Tenant.
    The tenant is added to the subsidy.

  4. Repeat for every tenant that qualifies for the subsidy.

  5. When all tenants are added, click Save & Close to complete the subsidy creation. Alternatively, click Save & New to save the subsidy and leave the pop-up open to create another subsidy.
