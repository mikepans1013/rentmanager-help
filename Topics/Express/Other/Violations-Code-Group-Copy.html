Copy a Violation Code Group

With violations, you can create code groups, which are made up of violation categories (e.g., parking) and associated violation codes (e.g., no parking on street), representing the entirety of a property's rules and regulations. For ease of use, you can create a new violation code group by copying an existing group.

Step 1: Copy Violation Code Group General Information

Related Privileges

Group Privilege Column
Setup Violation Code Groups Add, View

For more information, refer to Control User Access.

To copy a violation code group, do the following:

  1. Go to arrow_forward Rental Info arrow_forward Rental Info Setup arrow_forward Violations arrow_forward Violation Code Groups.
    The Violation Code Groups page displays.

  2. Click at the end of the row for the violation code group you'd like to copy and select Copy from the drop-down menu.
    The Violation Code Group Copy pop-up displays.

  3. In the Source Violation Code Group section, verify the violation code group you wish to copy from the drop-down.

  4. In the Destination Violation Code Group section, select options in the available fields.

    Field Description

    New

    The copied violation code group creates a completely new violation code group. The new code group's name defaults to Copy of the copied violation code group. Optionally, enter a different name for this new code group.

    Add to Existing

    The copied violation code group is added to selected existing group.

    How would you like to handle duplicate codes?

    Skip Duplicate Codes

    Ignores any codes copied from the source code group that already exist with the same name in the destination code group.

    Replace Existing Codes

    The codes from the existing violation code group are replaced with the codes from the newly copied violation code group.

Step 2: Select Codes to Copy

After copying the violation code group, select what violation codes you would like to copy to your new code group. The following columns display:

Column Description

Category

The violation category that best applies to this code.

Code

The name of the violation code. Each code within a code group must be unique. However, you may have codes with the same name in other code groups.

Description

Detailed information about the rule(s) associated with this violation code.

Click Save.
The violation code group is created.
