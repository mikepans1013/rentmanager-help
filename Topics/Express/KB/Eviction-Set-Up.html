Set Up Evictions

The eviction process is long and involves a lot of important steps to keep track of. Rent Manager's eviction tool provides a streamlined solution for handling evictions efficiently from start to finish. Each step in the workflow builds off the previous step to help you stay organized and up to date as the process moves to a resolution. If your state, or the states that you manage properties in, requires a specific eviction processes, Rent Manager allows you to create eviction workflows that comply with the regulations of your specific jurisdiction(s).

Related Privileges

Group Privilege Column
Setup Manage Eviction Reasons and Outcomes Enable
Manage Eviction Workflows Enable

For more information, refer to Control User Access.

Step 1: Set Your Eviction Reasons

The first step in setting up your eviction workflow is creating your eviction reasons for situations where evictions take place.

To add an eviction reason, do the following:

  1. Go to arrow_forward Rental Info arrow_forward Rental Info Setup arrow_forward Evictions arrow_forward Eviction Reasons.
    The Eviction Reasons page displays.

  2. At the top of the page, click Add Eviction Reason.

  3. Enter the eviction reason information in the available fields.

    Field Description

    Name

    A unique name that identifies the reason for the eviction.

    Description

    A brief summary that provides further context about when the eviction reason should be used.

  4. Click Save.
    The eviction reason has been added to the Eviction Reasons page.

Step 2: Add Eviction Outcomes

After creating your eviction reasons, you can move on to creating outcomes used to bring the eviction process to a close.

To create an eviction outcome, do the following:

  1. Go to arrow_forward Rental Info arrow_forward Rental Info Setup arrow_forward Evictions arrow_forward Eviction Outcomes.
    The Eviction Outcomes page displays.

  2. At the top of the page, click Add Eviction Outcome.

  3. Enter the eviction outcome information in the available fields.

    Field Description

    Type

    The result generated by the eviction outcome. The type can be either Evicted or Not Evicted.

    Name

    A unique name that identifies the outcome for the eviction.

    Description

    A brief summary that provides further context about when the eviction outcome should be used.

  4. Click Save.
    The eviction outcome has been added to the Eviction Outcomes page.

Step 3: Create an Eviction Workflow

Now that the eviction reasons and outcomes are established, you can then begin the process of creating a workflow where they are implemented. The workflow displays as an Eviction tile on the tenant's details page. As the tenant progresses through the eviction process, the tile for each stage reflects the steps needed to take during that stage.

To create an eviction workflow, do the following:

  1. Go to arrow_forward Rental Info arrow_forward Rental Info Setup arrow_forward Evictions arrow_forward Eviction Workflows.
    The Eviction Workflows page displays.

  2. At the top of the page, click Add Workflows.

  3. Enter a Workflow Name to identify it in Rent Manager.

  4. Click Select Properties to assign the workflow to a property or group of properties. Multiple properties can be added to a workflow, but a property can only be assigned one workflow. When you start an eviction, the workflow selected is the one assigned to the tenant's default property in this field.

  5. In the Set Up Workflow Stages section, enter information in the following fields.

    Field Description

    Stage Name

    The name of the step taken in the eviction workflow that allows you to track the eviction process.

    Write Letter

    The templated letter that generates for the tenant when the eviction workflow starts.

  6. In the Customize the Eviction Tile by Stage section, customize how the Eviction tile displays during each stage of the eviction process including any internal instructions you wish to provide to users and a variety of fields that are available during that specific stage. For more information, refer to Eviction Workflow Setup.

  7. To select the stages at which a tenant is considered legally evicted and when payments should no longer be accepted, click Settings at the top of the page.

  8. Once you are satisfied with your eviction setup, click Save.
    The eviction workflow has been added to your eviction setup.

Next Steps

Once you have set your eviction reasons, outcomes, and created a workflow, you can begin tracking evictions in Rent Manager. Some of the actions you can take using the eviction tool are described in the table below.

Action Description

Start an Eviction Process

Begin using the eviction tool to keep track of the various steps required to complete the eviction process in Rent Manager. For more information, refer to Start an Eviction Process.

Close Evictions

When the eviction process has come to an end, you can close it out with the appropriate outcome and close it in Rent Manager. For more information, refer to Close an Eviction.
