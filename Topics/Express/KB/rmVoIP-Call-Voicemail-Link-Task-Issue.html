Link Tasks and Issues to a Call or Voicemail

If you use the rmVoIP phone system and Smart Voicemails features integrated with Rent Manager, you can link service issues and tasks associated with those calls. This allows you to ensure that any follow-up maintenance, communications, and procedures are completed in a timely manner while tracking the source of the work.

More Information

This feature is licensed and must be purchased separately. For more information, contact your sales representative at sales@rentmanager.com.

To link a task or issue, go to the call or voicemail's details pop-up using one of the following navigation paths:

Details Navigation

Call

arrow_forward Communication arrow_forward Texting/Phone arrow_forward rmVoIP Incoming Call History and select a call.

Voicemail

Related Privileges

Group Privilege Column
Phone System Smart Voicemails View, Edit

Additionally, your user account must be enabled for at least one Smart Voicemail Box.

For more information, refer to Control User Access and Manage Orion Smart Voicemail Boxes.

Link an Issue

If you need to complete additional work to resolve a concern related to the call or voicemail, such as repairs for a tenant or cleaning a unit that is going to be shown to prospects, you can link a service issue directly from the call or voicemail's details pop-up. You can either create a new issue or link an existing issue to ensure that the associated work is finished.

Add a New Issue

Related Privileges

Group Privilege Column
Service Manager Issues Add, View, Edit

For more information, refer to Control User Access.

To create a new issue linked to the call or voicemail, do the following:

  1. In the Links section of the details pop-up, click Add Issue.
    The default add issue wizard displays.

  2. To load a previously saved issue template, at the bottom of the wizard, click Load Memorized to load the issue information from a memorized issue template.

  3. Enter details about the issue. For more information, refer to Add an Issue.

  4. Click Save and Finish.
    The issue is created, linked to the call or voicemail, and displays in the Links section. Repeat these steps for any additional issues needed for the call or voicemail.

Link an Existing Issue

Related Privileges

Group Privilege Column
Service Manager Issues View, Edit

For more information, refer to Control User Access.

To link an existing service issue to the call or voicemail, do the following:

  1. In the Links section of the details pop-up, click the drop-down arrow next to Add Issue and select Link Existing Issue.
    The Link Issues pop-up displays.

  2. In the far left column, select the issue(s) you wish to link to the call or voicemail.

  3. Click Link.
    The issue(s) is linked to the call or voicemail and displays in the Links section.

Link a Task

If you need to perform administrative duties related to the call or voicemail, such as scheduling a meeting with an owner or addressing a tenant concern with your manager, you can link a task directly from the call or voicemail's details pop-up. You can either create a new task or link an existing task to ensure that the any follow-up work is completed.

Add a New Task

Related Privileges

Group Privilege Column
Setup Tasks Add, View, Edit

For more information, refer to Control User Access.

To create a new task linked to the call or voicemail, do the following:

  1. In the Links section of the details pop-up, click Add Task.
    The Add Task pop-up displays.

  2. Enter details about the task. For more information, refer to Add a Task or Memorized Task.

  3. Click Save.
    The task is created, linked to the call or voicemail, and displays in the Links section. Repeat these steps for any additional task needed for the call or voicemail.

Link an Existing Task

Related Privileges

Group Privilege Column
Setup Tasks View, Edit

For more information, refer to Control User Access.

To link an existing task to the call or voicemail, do the following:

  1. In the Links section of the details pop-up, click the drop-down arrow next to Add Task and select Link Existing Task.
    The Link Tasks pop-up displays.

  2. In the far left column, select the task(s) you wish to link to the call or voicemail.

  3. Click Link.
    The task(s) is linked to the call or voicemail and displays in the Links section.
