Add a User Role

Creating user roles is a convenient way to group privileges for activities common to people in the same or similar jobs. For example, you can create a role for your accountants and select a set of privileges that reflect the needs of your accountants. Changing the privileges associated with a user role automatically updates the privileges of each user assigned to that role.

Related Privileges

System Manage all users and privileges Add, View

For more information, refer to Control User Access.

Step 1: Create a User Role

To create a new user role, do the following:

  1. Go to arrow_forward Administration, then go to Users arrow_forward User Roles.
    The User Role page displays.

  2. On the action bar to the right, click .
    The Add User Role pop-up displays.

  3. In the Role Name field, enter a unique descriptor for the user role (e.g., Administrator, Front Office).

  4. To create the role with the privileges of an existing user or user role, in the Copy permissions from existing user or role, select the user or role whose privileges you wish to use.

  5. Click Save.
    The user role is created.

Step 2: Assign Users

To assign users to the role, do the following:

  1. Select the newly created user role from the list on the left.
    The role's General tab displays.

  2. On the Users tile, click .
    The Add Users pop-up displays.

  3. Select the user(s) to be assigned the role.

  4. Click Save.
    The Add Users pop-up closes and the selected user(s) are listed on the Users tile.

  5. Click Save.
    The selected user(s) are assigned to the user role.

Step 3: Customize Role Privileges

To customize the privileges, reports, and letters available to this role, do the following:

  1. From the user role's General tab, select the Privileges tab.

  2. Enable the desired privileges for users assigned to this role. For more information, refer to Control User Access.

    More Information

    Privileges assigned to a user's role cannot be removed from the individual user account's Privileges tab, but additional privileges can be added or removed.

  3. Click Save.
    The selected privileges are enabled for users assigned to the role.

  4. Select the Reports tab.

  5. Select the Rent Manager reports and Report Writer (RW) reports available to users assigned to this role. For more information, refer to Control Custom Report Access.

  6. Click Save.
    The selected reports can be generated by users assigned to the role.

  7. Select the Communication tab.

  8. Select the letter templates, signable templates, and document packets available to users assigned to this role. For more information, refer to Control Letter / Email Template Access.

  9. Click Save.
    The selected templates and/or packets can be distributed by users assigned to the role.
