Zego Resident Payout

The Resident Payout feature from Zego allows you to refund security deposits directly to tenants' bank accounts via ePay, eliminating the need to issue paper checks. Once you initiate a refund in Rent Manager, an email is sent to the tenant inviting them to set up an account with Fintainium, Zego's secure refund processing partner. After they create their account, your tenant can select their preferred method of retrieving payment and submit their information. Fintainium processes the submission and completes the payout process, saving you time and providing maximum flexibility to your tenant. You can monitor the refund's status, as well as any issues that arise during the payout process, all in Rent Manager.

More Information

ePay is a licensed feature by Zego. To use Zego ePay, you must set up an account with Zego and enter that information into Rent Manager. Once you have ePay enabled in Rent Manager, you also need the Resident Payout feature enabled in your Zego account to process security deposit refunds. For more information, contact sales@rentmanager.com.

Once you have added the Resident Payout feature to your Zego account, you can enable the feature within Rent Manager. To enable it, do the following:

  1. Go to  arrow_forward  Administration, then go to Preferences arrow_forward System Preferences arrow_forward ePay arrow_forward Tenant ePay arrow_forward General.
    The System Preferences: ePay- General page displays.

  2. In the Resident Payout section, check Allow security deposit refunds to tenants via electronic payout.

  3. Click Save.
    Your system preferences are updated and you can now refund security deposits via Resident Payout.

More Information

If you wish to disable Resident Payout at certain properties, you can do so from each property's ePay Settings pop-up. for more information, refer to Property ePay Settings (Pop-Up).

Next Steps

Now that you have set up Resident Payout, you are ready to refund security deposits electronically and manage any issues that arise during the refund process. The recommended next steps are described in the table below.

Action Description

Refund Security Deposits

When issuing refunds for a tenant, in the Refund Via field, select Resident Payout. Once the refund is submitted, an email is sent from Zego to the address entered in the Email field inviting the tenant to set up a Fintainium account to receive their refund. For more information, refer to Refund a Security Deposit.

Review Resident Payout Status

Once you submit a Resident Payout refund via Rent Manager, a banner displays on the tenant's details page with information about the refund. Use this banner to track the current status of the refund, or, if necessary, resend the invitation email or cancel the Resident Payout. For more information, refer to Tenant Details (Page).

Review Resident Payout Issues

If an issue occurs that prevents the Resident Payout from being sent or recorded, you can view and resolve it from the Resident Payout Issues page. For more information, refer to Check Resident Payout Issues.
