Send Email to Multiple Recipients

Rent Manager allows you to compose and send emails directly to contacts selected from your Rent Manager database, such as when you need to send a mass email notification about community events. Additionally, you can select a specific group or filter the people you are contacting so that you can send the email to only your target audience. Emails sent this way are automatically sent individually and do not include the email address for any other recipients.

Related Privileges

Group Privilege Column
System Compose Email Enabled

For more information, refer to Control User Access.

Step 1: Filter Recipients

Often, mass emails are intended for specific recipients, so a key part of sending a mass email is being able to quickly filter your recipients and ensure you're including everyone that needs to receive the email. In Rent Manager, mass emails can be sent to various entities such as tenants, owners, or prospects.

You can use letter/email templates that contain scripts to dynamically change the content of your message and keep your messages personalized to each recipient. For more information, refer to Add a Letter Template.

Related Privileges

Group Privilege Column
Tenants/Prospects Tenants View

For more information, refer to Control User Access.

To filter your recipients, do the following:

  1. Navigate to the entity list you wish to send the email batch to (such as tenants, owners, or prospects). For example, if you are sending an email to multiple tenants, go to arrow_forward Rental Info arrow_forward General arrow_forward Tenants.
    The Tenants page displays.

  2. Next to the Saved Filters field, click .
    The Filter Detail pop-up displays.

  3. Enter any fields you want to use for filtering the list of tenants. For example, you may filter by a specific Property or newer tenants using Move In. For more information on the available filters for tenants, refer to Tenant Filters (Pop-Up).

  4. Click Apply. If you plan to use this filter more than once, enter a Name and select Save and Apply. The filter can then be quickly selected from the tenants list in the Saved Filters field.
    The Filter Detail pop-up closes and the filter criteria is applied to the Tenants page.

Step 2: Send the Email

Once you have a filtered list, you can use Bulk Actions to select the recipients of your correspondence from the list. This allows you to fine tune the recipients even further where necessary. Otherwise, you can select all the recipients in your newly filtered list to include them all in your correspondence. You can compose a brand new email or pull in an email template for the body of the email that uses scripting to make each email unique to the recipient.

More Information

If you want to send a letter template as an attachment on an email to multiple recipients, instead select Bulk Actionsarrow_forward Write Letters. For more information, refer to Generate and Distribute Letters from Templates.

To send the bulk email, do the following:

  1. Click Bulk Actions arrow_forward Send Email.

  2. In the Email Template field, select an email template to populate in the body of the email. To instead write a new email from scratch, select <New Email>.

    More Information

    This pop-up displays only if at least one of the letter/email templates for the entity is set as an Email Template in the settings. Otherwise, this pop-up does not display and a new email is generated by default. For more information, refer to Letter/Email Template Settings (Pop-Up).

  3. Click Continue.

  4. Select the recipients from the list to include in the correspondence.

  5. Click Send Email.

  6. At the top of the page, enter the following information:

    Field Description

    From Address

    The email address from which the message is sent that displays for the recipient. A default value can be set for all users in system preferences or on an individual basis in personal preferences.

    Related Preferences

    In system preferences, if the Default (mail.rentmanager.com) mail server is selected, all emails send from email@rentmanager.com. When the email is sent, it displays the entered From Address to recipient(s) and reroutes replies to that email address.

    If you have established settings for an External Server in system preferences, emails send from the address entered in this field. For more information, refer to Email Settings (System Preferences).

    From Name

    The sender's name that displays for the recipient. A default value can be set for all users in system preferences or on an individual basis in personal preferences.

  7. In the Settings/Options section, check Add to History if you want to create a history/note item for each recipient that you sent the email to. The email is attached to that history/note item.

    Related Privileges

    In order to add a history/note item to an entity, your user account must have the Add privilege enabled for the relevant entity type (e.g., Owner History/Notes) in the History privilege group. For more information, refer to Control User Access.

  8. In the Addressee List section, select the Contacts to Include. Select Primary to only include primary accounts, or select Contact Types to choose relevant contact types to include. To add an additional recipient, click Add Contact.

    More Information

    Contacts that are unsubscribed from one or more email categories display an icon next to their email address. If the entity is unsubscribed from the General emailing list, displays. Alternatively, if they are unsubscribed from all emails, displays. For more information, refer to Unsubscribe From Emails.

  9. In the Message section, enter information into the available fields:

    Field Description

    Attachments

    To include additional files or documents in this email, click Upload Files.

    Subject

    The subject line that displays for the recipient.

  10. In the text box below, enter or edit the message in the body of the email.

    More Information

    If you decide you want to pull the content of an email template into the body of the email, you can click Insert Email Template. Select the template to insert and click Continue. You can still make any manual edits to the email body after the template is added. For more information, refer to Letter/Email Templates (Page).

  11. Click Next.
    The Bulk Email - Preview pop-up displays.

  12. Review the email output and the list of recipients set to receive this email to verify everything is correct. If any changes are needed, click Back and make the needed edits.

  13. Click Send All.
    The email is sent to all selected recipients. If Add to History was checked, a history/note with a copy of the email is also attached to each recipient's account.
