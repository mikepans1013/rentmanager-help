Set Up Owner Contracts

The ownership of a property is determined by an owner's contract dates and the percent of ownership entered on a property. Reserve amounts can be set for each owner contract on the property and you can enter multiple contracts for the same owner. For example, you may want to have multiple contracts listed to show changes in ownership or the ownership percentage during a specific period of time. Owners are automatically considered active or inactive based on their ownership contract dates. It is suggested to set owners with historical data as inactive rather than deleting them to ensure that data is retained.

Add an Owner Contract

To add a new owner contract to a property, do the following:

  1. Go to arrow_forward Rental Info arrow_forward General arrow_forward Properties and select an property from the list.

    The property's details page displays.

  2. On the action bar on the right, click arrow_forward Owners.

    The Owners pop-up displays.

  3. Select the Primary Owner from the drop-down list.

    More Information

    If this property is owned by a partnership, consider choosing the owner with the highest percent of ownership or the owner you would consider the primary contact between them.

  4. Click Add Owner.

  5. Enter information in the following columns:

    Column Description

    % (Percentage of Ownership)

    The ownership percentage for each owner. If there are multiple owners with the same contract dates, the percentage of ownership should equal no more than 100% when added together for that period of time. For example, a single owner may have 100% ownership, or two owners may be split with 60% and 40% ownership respectively.

    End

    The last day on which the owner's contract is active for the property. The owner is considered inactive after this date.

    Owner

    The owner account that has ownership on the property.

    Reserve

    The minimum balance that must be maintained in the property's bank for this owner at all times.

    Start

    The first day on which the owner's contract is active for the property. The owner is considered inactive before this date.

  6. Click Save.
    The ownership contract is added to the property.

Owner Contracts in Rent Manager

Owner contracts are examined across multiple areas in Rent Manager and determine if an owner is active, allows Rent Manager to filter data based on contract dates, and ensure certain processes include only the owners that are active during the dates specified.

Area/Tool Description

Active/Inactive Owners

Contract dates determine when an owner is considered active or inactive for a property.

Owner Web Access

Owners must have an active contract to access data for those properties through their Owner Web Access account. For more information, refer to Owner Web Access.

Reports

Some reports, such as the Owner Profit & Loss report, include the ability to filter the results based on an owner's contract dates to ensure you are getting data from that period of time.

Pay Owners

When paying owners, owner contracts are used to determine which owners are included and other details such as ownership percentages on the dates included in the payout. For more information, refer to Pay Owners.

Management Fees

When posting management fees, owner contracts are used to determine which owners are included in each posting. For more information, refer to Post Management Fees.
