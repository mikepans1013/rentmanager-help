Set Up an Owner to Use Owner Web Access (OWA)

Owner Web Access (OWA) is the owner-facing web portal included in Rent Manager's Web Portal Suite package. This feature provides your owners with a valuable online toolkit, enabling them to view the details of their ownerships, run reports, make contributions, and perform many other vital business tasks in a convenient, secure location. For more information on activating Web Portal Suite, refer to Set Up Web Portal Suite.

After your owners are set up with web user accounts, you can customize this toolkit in Rent Manager by adjusting web access settings at a system level or creating unique settings for each owner account.

More Information

This feature is licensed and must be purchased separately. For more information, contact your sales representative at sales@rentmanager.com.

To set up and manage an owner's OWA settings, do the following:

  1. Go to  arrow_forward Owners arrow_forward General arrow_forward Owners and select an owner from the list.
    The owner's details page displays.

  2. On the action bar to the right, click arrow_forward OWA Settings.
    The Web Access Settings pop-up displays.

Step One: Create a Web User Account

More Information

In order to access their OWA account, an owner must have an active owner account in Rent Manager. An owner account is considered active if its contract has a Start date and if that contract's End date is one or more days in the future. For more information, refer to Set Up Owner Contracts.

To log in to the OWA portal, owners must have a web user account. This account can be created by the owner on your OWA website or created by a user in Rent Manager on the owner's behalf.

Create OWA Accounts in Rent Manager

To create a web user account in the Web Access Settings pop-up, do the following:

  1. Go to  arrow_forward Owners arrow_forward General arrow_forward Owners and select an owner from the list.
    The owner's details page displays.

  2. On the action bar to the right, click arrow_forward OWA Settings.
    The Web Access Settings pop-up displays.

  3. In the Web Users section, click Add Web User.
    The Add Web User pop-up displays.

  4. Enter the owner's email address in the Email Address field.

  5. Click Save & Close.
    A verification email is sent to the owner's email address prompting them to verify their account. Alternatively, click Save & New to add additional web user accounts.

After verifying their account, the owner can log in with their OWA credentials.

Allow Owners to Create OWA Accounts

Once you have configured system web preferences to permit them to do so, owners can create their own accounts directly from the OWA portal.

To enable this option in system web preferences, do the following:

  1. Go to arrow_forward  Administration, then go to Preferences arrow_forward System Web Preferences arrow_forward Owner Web Access arrow_forward Accounts.

  2. On the General tile, check Allow Owners to Create Accounts.

  3. Optionally, select any number of account verification methods. When creating their account, they will be prompted to enter matching information.

    More Information

    In addition to any optional verifications methods selected, owners must also enter their system-generated Account #. This number displays in the Web Access Settings pop-up on the owner's account in Rent Manager. For more information about verification options, refer to Owner Web Access Accounts (System Web Preferences).

  4. Click Save.
    Your owners can now create accounts on your OWA website.

More Information

To assist owners with creating and using their accounts, consider downloading a ready-made letter template from the online template library (OTL). These templates, such as the OWA Owner Instructions and OWA Setup Letter, provide owners with step by step instructions and can be customized to meet your business needs. For more information, refer to Online Template Library (Page).

Step Two: Configure Web Access Settings

Once an owner's web user account is created, you can optionally customize its Owner Settings to tailor the OWA experience to meet their specific needs. If you do not configure owner-specific settings, the account is granted all privileges established in system web preferences by default. For more information on system-default settings, refer to Owner Web Access Privileges (System Web Preferences).

To customize an owner's web access settings, do the following:

  1. Go to  arrow_forward Owners arrow_forward General arrow_forward Owners and select an owner from the list.
    The owner's details page displays.

  2. On the action bar to the right, click arrow_forward OWA Settings.
    The Web Access Settings pop-up displays.

  3. Under Owner Settings, check Override System Defaults.
    The settings can now be customized.

  4. Adjust the Show Ownership Information, Show Page Visibility, Show Financial Information, Service Issues, and Report Privileges sections to match your preferences for this owner. For more information, refer to Owner Web Access Settings (Pop-Up).

  5. Click Save.
    The owner's web access settings are updated. The owner's OWA portal now only displays the tools and reports you've selected.
