# Components of an Owner Statement

Source: https://rmxhelp.rentmanager.com/Topics/Express/KB/Owners-Statement-Components.htm

Rent Manager has three types of owner statements for you to generate: the Owner Statement run with the Show Details report options enabled, the Owner Statement , and the Basic Owner Statement . This topic reviews the function of each section of the Owner Statement , with and without the Show Details report options enabled, and Basic Owner Statement to help provide an understanding of when to use one statement over the other.

 The Owner Statement in Rent Manager is a cash-basis accounting report that is used to show financial activity and changes in bank balances over a specified period of time. Fee-based management companies often provide this statement in conjunction with an owner payout to provide details about both the payout and the period's income and expenses. To control how much or how little information is generated, you can use the Show Details report options.

 The Basic Owner Statement  is used to show financial activity and changes in the property's default bank balance over a specified period of time. Your fee-based management company can provide this simple, easily understood statement to describe a certain period's income and expenses.

 Option 1: System Owner Statement with Detailed Transactions

 System-level owner statements with detailed transactions allows you to view financial data for both selected date ranges and the year to date. Additionally, this report examines all trust accounts associated with the owner. The report can be further filtered using the various exclusion options in report options.

 To view the System Owner Statement report with transaction details, do the following.

 -
 Go to   arrow_forward Owners arrow_forward Owner Statements arrow_forward System Owner Statement .
The Reports: Owner Statement page displays.

 -
 In the Show Details drop-down, select Show detailed income , Show detailed expense , and/or Show detailed other transactions .

 Mailing Header

 This section displays your management company’s name, address, and phone number in the top-left corner, if not excluded in the report options. Under that, the owner’s name and address is displayed. If the Phone Number option in the Exclusion Options section of the report options is unchecked, the owner’s phone number also displays.

 Statement Header

 This section displays the name of the property associated with the owner and the date range for which the report was generated.

 Beginning Bank Balance

 By default, the Beginning Bank Balance displays how much money is held in all property default banks (the Default Bank selected on the property's details page) of the owner's properties one day before the report date range. The date of this balance is the starting point of the statement, after which financial activity is examined.

 More Information

 If the exclusion option for Undeposited Funds is checked in report options, this section is renamed Beginning Cash Balance and the balance also includes any undeposited funds.

 Income

 When the Show detailed income report option is selected, this section displays a line item for each transaction that affected the income of the owner's properties.

 Expense

 When the Show detailed expense report option is selected, this section displays a line item for each transaction that affected the expenses of the owner's properties.

 Net Income/Loss

 This section displays the total operating profit (or loss) for the property or portfolio as of the last date in the report date range for the current period.

 Less Undeposited Funds

 This section displays money received but not yet deposited into the bank account for the current period. If a negative number displays, it's because the undeposited funds from a previous month are now deposited into the bank.

 Other Transactions

 This section displays additional transactions that help show the movement of cash. The transactions that display here do not affect the profitability of the property. Typically, accounts are added to Other Transactions to display important equity and liability accounts that impact the bank account of this property, such as owner contributions and payouts (distributions).

 When the Show detailed other transactions report option is selected, a line item for every transaction that affected the general ledger (GL) accounts specified in system preferences displays. By default, owner contributions and distributions are included regardless of the system preferences.

 Related Preferences

 In system preferences, you can select what type of transactions display in the Other Transactions section. For more information, refer to Owner Report Settings (System Preferences) .

 Ending Bank Balance

 This section displays the balance of the bank account at the end of the reporting period and year.

 More Information

 If the report option of Undeposited Funds in Exclusion Options is checked, the row is named Ending Cash Balance and the balance includes the total amount held in all of the property default banks of the owner's properties. This balance also includes any amounts coded to the Undeposited Funds general ledger account specified in General Ledger System Accounts (System Preferences) .

 Cash Requirements

 This section displays the amount of money that is required to be kept in the bank account for reserves and security deposits.

 Distribution Breakdown

 This section displays all payments to the owner with a check date during the specified report date range. Checks are ordered chronologically, and each item that factored into the check's calculation are grouped below the date. If multiple properties are expensed on the check, calculations for those properties are grouped together.

 Comments

 This section displays a custom message from the property manager company.

 Option 3: Basic Owner Statement

 To view a statement that is more simplified with streamlined information instead of further details, go to   arrow_forward Owners arrow_forward Owner Statements arrow_forward Basic Owner Statement .

 Mailing Header

 This section displays your management company’s name, address, and phone number in the top-left corner. Underneath that, the owner’s name and address is displayed. Both can be excluded in the report options.

 Statement Header

 This section displays the name of the property associated with the owner and the date range for which the report was generated.

 Transactions

 This section displays the initial balance of the default bank account of the selected owner's properties and lists all transactions that have affected that account to show how the Ending Bank Balance was calculated. Transactions include deposited prospect/tenant receivables, checks, other income deposits, journal entries that are not flagged as management fees, and owner distributions.

 Bills Outstanding

 This section displays outstanding amounts on open bills for any of the owner's properties.

 Cash Requirements

 This section displays the amount of money that was set aside, such as held security deposits, any reserves, and accounts excluded from check posting.

 Comments

 This section displays a custom message from the property management company.
