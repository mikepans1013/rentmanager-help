Add and Assign an Image Type

Images in Rent Manager allow you to showcase your properties and units with your very best pictures. You can use images to enhance your ILS listings, which gives your prospects the ability to experience everything your properties or units have to offer. Using images can make your online listings even more appealing to visitors to your websites. In addition to showcasing your properties and units, images in Rent Manager can also be used to identify tenant and prospect contacts as well as to organize unit types and assets.

Step 1: Add an Image Type

Related Privileges

Group Privilege Column
Properties/Units Image Types View

For more information, refer to Control User Access.

To add a new image type, do the following:

  1. Go to  arrow_forward  Administration, then go to Customization arrow_forward Image Types.

  2. In the Image Type section, select the image type category you wish to add to.

  3. Click Add Image Type.

  4. Enter information into the following fields.

    Field Description

    Name

    The unique name of the image type.

    Type

    The category the image is associated with. For example, if the Type is set to Unit, only images added to units can have this type.

    Max Size (KB)

    The maximum file size for images of this type.

    Description

    An explanation of when to apply this image type.

  5. Click Save.
    The image type is added to Rent Manager and can be used to categorize images.

Step 2: Apply the Image Type to an Image

After creating a new image type, you can use it to add to images in a variety of areas in Rent Manager. Image types can be used to organize and categorize the images you attach to your entities.

To add an image and apply image types to a property, unit, unit type, or assets, do the following:

  1. Select the location to which you wish to add the image.

    Location Navigation Path

    Properties

    Related Privileges

    Group Privilege Column
    Properties/Units Properties View, Edit

    For more information, refer to Control User Access.

     arrow_forward Rental Info arrow_forward General arrow_forward Properties

    Units

    Related Privileges

    Group Privilege Column
    Properties/Units Units View, Edit

    For more information, refer to Control User Access.

     arrow_forward Rental Info arrow_forward General arrow_forward Units

    Unit Types

    Related Privileges

    Group Privilege Column
    Properties/Units Unit types View, Edit

    For more information, refer to Control User Access.

     arrow_forward Rental Info arrow_forward General arrow_forward Unit Types

    Assets

    Related Privileges

    Group Privilege Column
    Asset Management Manage Assets View, Edit

    For more information, refer to Control User Access.

     arrow_forward Rental Info arrow_forward General arrow_forward Assets

  2. Select the specific property, unit, unit type, or asset from the list to open the details page.

  3. On the action bar to the right, click and select Add Image.
    The Upload Image pop-up displays.

  4. Select an Image Type from the drop-down menu that best describes the image or category of image.

  5. Drag an image to the center section, or alternately click Upload to select an image from your computer or network.

  6. If you wish to add multiple images, repeat the previous step.

  7. Click Add Images.
    The image(s) are added to Rent Manager.

  8. Click Save.
    The images are saved to the account.
