Leasing Dashboard Tiles

Rent Manager includes several dashboard tiles that provide at-a-glance data and analysis to help you track expiring tenant leases, upcoming move in and move outs, tenant and homeowner insurance expirations, and completed documents. With these dashboard tiles, you can view expiring leases grouped by property to help keep property managers informed and up to date on which tenants need to be contacted about renewing their leases.

Add the following leasing-related tiles to your dashboard to ensure you never miss any updates regarding lease activity at your properties:

Dashboard Tile Description

Expiring Leases

The number of expiring leases, including expiring leases that are converted to month-to-month leases, and leases that are renewed each month for the selected number of months for the selected properties.

Expiring Leases by Property

The number of expiring leases, including expiring leases that are renewed to month-to-month leases, and leases that are renewed during the selected number of days into the future for the selected properties.

Expiring Leases List

A list of tenants with leases that have an approaching Lease End date within a specified number of days. The tile displays the property and unit the tenant occupies, the tenant's name, and the lease's end date.

Move In/Move Out by Property

A list of scheduled or expected move ins and move outs, indicated on the tenant's details page and occurring within a specified number of days. This tile is organized by property and allows you to see the total move ins and move outs per property and totals for all your properties as well

Move In/Move Out List

The scheduled or expected move ins and move outs occurring within a set number of days. The property and the unit at which the activity is occurring is displayed, as well as the relevant dates

Needs Renewal Offers

The number of renewal offers expiring in a set number of days. The tile contains a color-coded radial bar chart that displays the number of leases expiring within three different customizable sets of days. Additionally, you can tell Rent Manager from which properties to pull lease expiration data. You can also create renewal offers by clicking on the tile and working through the Create Renewal Offer page.

Previous Month Retail Sales

A list of commercial tenants who have not had retail sales amounts entered for the previous month. The name of the tenant and the unit tied to their commercial lease displays.

Recently Completed Documents

A list of signable documents that have been signed by prospects, tenants, owners, or owner prospects. The tile also allows you to view whether the document is pending acceptance by a Rent Manager user.

Renewal Conversion Trend

The number of leases that were renewed and that have expired and then calculates and displays the conversion percentages for those leases over the selected time period (i.e., months or years). The total number of lease expirations and renewals for prior months or years are calculated for the entire period, while the current period is calculated up to the current date.

Insurance Breakdown

The number of tenants and homeowners with and without insurance policies at each property.

Related Preferences

In order to track insurance in Rent Manager, the option to Enable insurance tracking must be checked. For more information, refer to Activate and Set Up LeaseTrack Insurance.

Insurance Expiration

A list of tenants and homeowners with insurance policies that are expiring within a set number of days.

Related Preferences

In order to track insurance in Rent Manager, the option to Enable insurance tracking must be checked. For more information, refer to Activate and Set Up LeaseTrack Insurance.

Unconfirm Move Out List

A count of tenants who have an unverified Move Out date on a lease, which is indicated on the tenant's details page by an unchecked verification box accompanying the move-out date. An unverified move-out date permits recurring charges to continue to post for the tenant.
