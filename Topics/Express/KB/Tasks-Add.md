# Add a Task or Memorized Task

Source: https://rmxhelp.rentmanager.com/Topics/Express/KB/Tasks-Add.htm

Tasks allow you to maintain your busy schedule with Rent Manager by providing reminders about actions or responsibilities that need to be performed. You can even create tasks to recur on a daily, weekly, monthly, or annual basis. You can then easily view or access your tasks in the Rent Manager calendar or Tasks dashboard tile. Additionally, you can create and memorize task templates so that they can be reused later. For example, you can create a memorized task template for a Monthly Tenant Newsletter , which recurs on a monthly basis.

 Add a Task

 To add a new task, do the following:

 -
 Go to arrow_forward Services arrow_forward Calendar arrow_forward Tasks .
The Tasks page displays.

 -
 Click Add .

 More Information

 You can also create a task from a memorized task by clicking the drop-down arrow and selecting Add From Memorized , then select a memorized task from the list.

 -
 In the General tile, enter the task information into the available fields described below.

 Field
 Description

 Description

 A detailed explanation of the task.

 Display

 The color of the Subject when the task displays in lists, on the calendar, and/or in tiles.

 Subject

 The topic of the task. This also displays in the calendar and on the Tasks dashboard tile.

 Users

 The user(s) that are allowed to view this task on their calendars.

 -
 In the Links tile, you can link to specific accounts or issues to add a history/note item regarding the task to the specified account or issue. To do this, select an entity type from the first drop-down list, then search for a specific account or issue number for that entity in the second drop-down list, and then click .

 More Information

 You can only add one of each type of entity. Attempting to add a second entity of a type already in the list replaces the entity in the list with your selection. If necessary, click next to the name of the linked entity to delete it.

 -
 In the Schedule Options tile, enter the task information into the available fields described below.

 Field
 Description

 Actions

 The action that needs to be taken to complete this task. The options that display are from a predetermined list of actions that can be performed in Rent Manager .

 Once the task is saved, when you click the task from anywhere in Rent Manager , the appropriate page opens so you can perform the task. For example, you can use the Make Deposit action when you need to deposit payments outside of when you normally would. When you click the task, it opens the Make Deposit page, where you can deposit payments.

 Calendar Integration

 If checked, allows the task to be synced with an external calendar.

 Related Preferences

 This option displays only if the Calendar Integration system preference integration option is enabled. Additionally, in personal preferences, you can enter the email address to receive task notifications and override the system default Integration Method established in system preferences for only your account. For more information, refer to Calendar Integration (System Preferences) and Calendar Integration (Personal Preferences) .

 Closed

 If checked, this closes the task. The Closed User and Closed Date populate automatically and cannot be edited. This makes the task inactive, but it is still available on the Tasks page as a historical record.

 Due Date

 The date and time by which the task needs to be completed.

 Recurring

 If checked, this task repeats on a regular schedule in the future. Select from one of the four provided patterns ( Daily , Weekly , Monthly , or Yearly ) and the coordinating increment. If applicable, select an End from the drop-down list.

 Reminder

 If checked, enables a reminder for the task to trigger after a set amount of time. Enter one or more of the three provided increments ( Days , Hours , and Minutes ) to determine when the reminder occurs. For example selecting 3 Days , 2 Hours , and 5 Minutes  schedules a single reminder for that amount of time before the Due Date and time of the task.

 -
 In the Attachments tile, click   Upload to browse your computer for a file, or drag and drop a file into the upload box, to attach to the task. Files copied within Rent Manager Express using can be added here by selecting Paste .

 -
 Click Save .
The task is created.

 Add a Memorized Task

 Memorized tasks are tasks that have been saved as templates to make it easier to create similar tasks in the future. You can either create a memorized task from scratch, or you can click Memorize on an existing task to save it as a template. Memorized tasks do not store links, so you must add links when creating a new task.

 Create a New Memorized Task

 To create a new memorized task, do the following:

 -
 Go to arrow_forward Services arrow_forward Calendar arrow_forward Memorized Tasks .
The Memorized Tasks page displays.

 -
 Click Add Memorized Task .
The Add Memorized Task pop-up displays.

 -
 In the General tile, enter the task information into the available fields described below. The information in these fields populates by default on tasks created from this memorized task.

 Field
 Description

 Description

 A detailed explanation of the task which carries over to new tasks created from this template.

 Display

 The color of the Subject when the task displays in lists, on the calendar, and/or in tiles.

 Memorized Description

 A comment or note about the memorized task which is visible only on the task template.

 Memorized Name

 The name and description for the template task. This is the name that displays when loading a memorized task.

 Subject

 The topic of the task. This also displays in the calendar and on the Tasks dashboard tile.

 Users

 The user(s) that are allowed to view this task on their calendars.

 -
 In the Schedule Options tile, enter the task information into the available fields described below. The information in these fields populates by default on tasks created from this memorized task.

 Field
 Description

 Actions

 The action that needs to be taken to complete this task. The options that display are from a predetermined list actions that can be performed in Rent Manager .

 Once the task is saved, when you click the task from anywhere in Rent Manager , the appropriate page opens so you can perform the task. For example, the Make Deposit action opens the page to deposit payments.

 Calendar Integration

 If checked, allows the task to be synced with an external calendar. The option is checked by default.

 Related Preferences

 This option displays only if the Calendar Integration system preference integration option is enabled. For more information, refer to Calendar Integration (System Preferences) .

 Due Date

 The date and time by which the task needs to be completed.

 Recurring

 If checked, this task to repeats on a regular schedule in the future. Select from one of the four provided patterns ( Daily , Weekly , Monthly , or Yearly ) and the coordinating increment. If applicable, select an End from the drop-down list.

 Reminder

 If checked, enables a reminder for the task. Enter one or more of the three provided increments ( Days , Hours , and Minutes ) to determine when the reminder occurs. For example selecting 3 Days , 2 Hours , and 5 Minutes  schedules a single reminder for that amount of time before the Due Date and time of the task.

 -
 In the Attachments tile, click Upload Files to browse your computer for a file, or drag and drop a file into the upload box, to attach to the tasks created from this memorized task. Files copied within Rent Manager Express using can be added here by selecting Paste .

 -
 Click Save .
The new memorized task is created.

 Create from Existing Task

 To create a memorized task from an existing task, do the following:

 -
 Go to arrow_forward Services arrow_forward Calendar arrow_forward Tasks and select a task from the list.
The Edit Task pop-up displays.

 -
 To create a template from this task, click Memorize .
The New Memorized Task pop-up displays.

 -
 Enter the task information into the available fields described below.

 Field
 Description

 Description

 A comment or note which carries over to the memorized task. It displays as Memorized Description when you view the memorized task details.

 Name

 The unique name for the memorized task. It displays as Memorized Name when you view the memorized task details.

 -
 Click Save .
The task is now saved as a memorized task template.
