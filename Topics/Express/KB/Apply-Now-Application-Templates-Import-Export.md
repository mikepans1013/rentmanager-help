# Import or Export an Application Template

Source: https://rmxhelp.rentmanager.com/Topics/Express/KB/Apply-Now-Application-Templates-Import-Export.htm

Apply Now uses application templates to list the information that prospects at your properties need to submit. These templates contain multiple major sections, which each contain multiple minor sections, which each contain multiple fields. For your convenience, Rent Manager allows you to import or export application templates directly from the Application Templates page so they can be stored locally or quickly copied to other Rent Manager locations.

 Import an Application Template

 To import an application, do the following:

 -
 Go to arrow_forward Rental Info arrow_forward Leasing arrow_forward Application Templates .
The Application Templates page displays.

 -
 At the top of the page, click Import .
The File Explorer pop-up for your computer displays.

 -
 Select the .xml file you wish to use for the application template and click Open .
The Import Successful pop-up displays.

 -
 Click Ok to close the pop-up.
The application template is imported in Rent Manager and ready to be used.

 Export an Application Template

 To export an application template from Rent Manager to your computer, click on the application template you wish to export and select Export . The application template is exported to your downloads folder on your computer as a .xml file.
