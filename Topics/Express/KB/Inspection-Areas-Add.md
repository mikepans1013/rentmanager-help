# Add Inspection Areas

Source: https://rmxhelp.rentmanager.com/Topics/Express/KB/Inspection-Areas-Add.htm

Performing inspections through Rent Manager allows you to streamline and standardize the inspections process by customizing it to fit your needs. For example, you can create service issues for items you notice during the inspection that need attention without leaving the Inspection feature.

 To ensure you record the most accurate information on what needs to be inspected, Rent Manager allows you to create areas. Areas on inspections and inspection templates represent the physical locations that need to be inspected (e.g., bedrooms, kitchens, garages, balconies). Each area includes a list of items that need to be inspected in that location, such as floors and walls. This topic covers the different places you can add areas to your inspections and inspection templates.

 Add a New Area

 To add a new area that applies only to a specific inspection template, do the following:

 -
 Go to arrow_forward Services arrow_forward Inspections arrow_forward Inspection Templates and select a template.
 The inspection template's details page displays.

 -
 In the center of the page, click Add Areas .
The Add Area pop-up displays.

 -
 At the bottom, click Add New Area .

 -
 Enter information in the following sections:

 Section
 Description

 General

 The unique Name of the area. If the Show on Management Inspection Only option is selected, this area displays only on inspections performed by Rent Manager users and is not available for tenant self-inspections.

 Help Text

 Any additional information that displays between the area name and the first item of the inspection. Information entered in Management Help Text displays for Rent Manager users in rmAppSuite Pro and information entered in Tenant Help Text displays for tenants in rmResident .

 -
 To allow this area to be selected on any inspection template, select Add to Toolbox .

 -
 To finish, click Add & Close , or to create additional areas, Add & New .
The new area is added to the template, and you can repeat the process to add as many areas as needed.

 Add an Available Area

 If you already created template-wide areas, you can save time by using the Available areas option to add a copy of any of those areas and edit them as needed.

 To add an available area to an inspection template, do the following:

 -
 Go to arrow_forward Services arrow_forward Inspections arrow_forward Inspection Templates and select a template.
 The inspection template's details page displays.

 -
 In the center of the page, click Add Areas .

 -
 Select the area(s) you want to add to the inspection template.

 -
 Click OK to close the pop-up.
The area is added to the inspection template.

 Areas can be added to inspections from scratch, or by selecting an area already created on the inspection and copying that information. Both options are available by going to the inspection's Areas tile and clicking Add Areas .

 More Information

 Areas cannot be added to existing tenant self-inspections. To add an additional area for a tenant self-inspection, you must update the inspection template, close or delete the existing self-inspection, and send a new self-inspection to the tenant. For more information, refer to Send Tenant Self-Inspection .

 Add a New Area

 To add a new area that applies only to the specific inspection, do the following:

 -
 Go to arrow_forward Services arrow_forward Inspections arrow_forward Inspections and select an inspection from the list.
The inspection's details page displays.

 -
 On the Areas tile, click Add Areas .

 -
 Select New Area and enter the Name for the new area you wish to add.

 -
 Click OK to close the pop-up.
The area is added to the inspection.

 Copy an Existing Area

 To add an area based on an area that was already added to the inspection, do the following:

 -
 Go to arrow_forward Services arrow_forward Inspections arrow_forward Inspections and select an inspection from the list.
The inspection's details page displays.

 -
 On the Areas tile, click Add Areas .

 -
 Select Existing Area and select an area you wish to add from the drop-down list.

 - Click OK to close the pop-up.
The existing area is copied to the inspection. More Information
 If you need to further customize the guidelines of the inspection, in the header of the area you added, click arrow_forward Add Item to add a New Item or Existing Item into that area. For more information, refer to Add Inspection Items .
