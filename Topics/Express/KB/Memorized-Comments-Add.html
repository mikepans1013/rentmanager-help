Add and Apply Memorized Comments

Memorized comments are custom messages that you can save and select in Comment and Memo fields across Rent Manager. This is especially useful for commonly used comments, as you can select the memorized comment rather than manually typing out the same comment every time. This can also be beneficial when you have a comment that requires very specific phrasing and using a memorized comment in these situations can help ensure the correct phrasing is included.

To add a memorized comment, do the following:

  1. Go to arrow_forward Administration, then go to Receivables arrow_forward Memorized Comments.
    The Memorized Comments page displays.

  2. Click Add Comment.
    The Add Memorized Comments pop-up displays.

  3. Enter a Name that helps identify the use and content of the comment. This name is what displays in the drop-down list when selecting memorized comments.

  4. Enter the Comment you want to use when this memorized comment is selected.

  5. Click Save.
    The memorized comment is saved.

Apply a Memorized Comment

Memorized comments can be used on any Comment or Memo field that has the icon on the top right of the field. For example, memorized comments can be used on tenant statements, an entity's details page, journals, and invoices.

To apply a memorized comment, do the following:

  1. On the field you want to insert a memorized comment, click .
    A list of available memorized comments displays.

  2. Select the name of the memorized comment you want to use.
    The Comment from the memorized comment is inserted into the field.
