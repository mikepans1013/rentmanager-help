# Add Inspection Items

Source: https://rmxhelp.rentmanager.com/Topics/Express/KB/Inspection-Items-Add.htm

Rent Manager inspections streamline and standardize the inspections process by customizing it to fit your needs. Your customizations can be saved as inspection templates, which allow you to create new inspections from the same starting point. You can have multiple templates, allowing you to create unique inspections with consideration to property, unit, or unit type.

 To ensure you record the most accurate information on what needs to be inspected, Rent Manager allows you to create items. Items on inspections and inspection templates represent the physical items (e.g., doors, light fixtures, floors, walls, appliances) in each area (e.g., bedrooms, kitchens, garages, balconies) that need to be inspected. This topic details the places in Rent Manager you can add items to your inspections and inspection templates.

 Related Preferences

 Add a New Item

 To add a new item to an inspection template, do the following:

 -
 Go to arrow_forward Services arrow_forward Inspections arrow_forward Inspection Templates and select a template.
The inspection template's details page displays.

 -
 In the Areas section, on the area you wish to add an item to, click arrow_forward Add Item .
The Add Item pop-up displays.

 -
 Click Add New Item .

 -
 Enter information in the following sections:

 Section
 Description

 General

 The unique Name of the item. If the Show on Management Inspection Only option is selected, this item displays only on inspections performed by Rent Manager users and is not available for tenant self-inspections.

 Help Text

 Any additional information that displays for the item. Information entered in Management Help Text displays for Rent Manager users in rmAppSuite Pro and information entered in Tenant Help Text displays for tenants in rmResident .

 Status

 The status (e.g., Good , Poor , Acceptable , Needs Repair , Missing , N/A ) that best describes the condition of the item. You can determine if a status should mark the item as an Action Item , Needs Review , and/or Severe which determines how the status displays on the Inspection Activity report. Additionally, you can determine if a specific status requires an image or note to be added. For more information, refer to Add an Inspection Status .

 To add the new item to your toolbox, making it available for all areas and inspection templates, check Add to Toolbox . For more information, refer to Edit an Inspection Template Toolbox .

 -
 Click Add & Close . Alternatively, click Add & New to continue adding additional items.
The item is added to the inspection template.

 More Information

 Items cannot be added to existing tenant self-inspections. To add an additional item for a tenant self-inspection, you must update the inspection template, close or delete the existing self-inspection, and send a new self-inspection to the tenant. For more information, refer to Send Tenant Self-Inspection .

 Add a New Item

 To add a new item that applies only to a specific inspection, do the following:

 -
 Go to arrow_forward Services arrow_forward Inspections arrow_forward Inspections and select an inspection from the list.
The inspection's details page displays.

 -
 On the Areas tile, for the area you wish to add an item to, click arrow_forward Add Item .

 -
 Select New Item and enter the Name for the item you wish to add.
Click OK to close the pop-up. The new item is added to the inspection area.

 -
 Optionally, on the Areas tile, enter information about the item you added in the following fields.

 Field
 Description

 Images

 If applicable, photos of the item to document its condition.

 Name

 The name of the item, such as Stove or Refrigerator .

 Notes

 Any additional comments or notable observations about the item.

 Status

 The status (e.g., Good , Poor , Acceptable , Needs Repair , Missing , N/A ) that best describes the condition of the item. You can also mark the item as an Action Item , Needs Review , and/or Severe .

 -
 Click Save .
The item(s) are added to the inspection area.

 Copy an Existing Item

 To add a new item based on an item that was already added to the inspection area, do the following:

 -
 Go to arrow_forward Services arrow_forward Inspections arrow_forward Inspections and select an inspection from the list.
The inspection's details page displays.

 -
 On the Areas tile, for the area you wish to add an item to, click arrow_forward Add Item .

 -
 Select Existing Item and use the drop-down menu to select the item you wish to copy.
Click OK to close the pop-up. The existing item is copied to the inspection area.

 -
 Optionally, on the Areas tile, enter information about the item you added in the following fields.
