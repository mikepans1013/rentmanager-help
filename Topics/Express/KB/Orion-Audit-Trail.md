# Audit Trail Analysis Powered by Orion AI

Source: https://rmxhelp.rentmanager.com/Topics/Express/KB/Orion-Audit-Trail.htm

The Audit Trail Analysis—powered by Orion AI —is a feature that provides in-depth analysis of the Audit Trail report, which can be reviewed and refined to help you identify important trends. This feature takes the Audit Trail report, a long, line-by-line log of Rent Manager user actions with little context or insight, and generates a detailed system history with actionable insights instantly.

 More Information

 This feature is licensed and must be purchased separately. For more information, contact your sales representative at sales@rentmanager.com .

 Generate Report Analysis

 The Orion Audit Trail Analysis can be accessed from the generated Audit Trail report by clicking Analyze with Orion in the bottom-right of the page. This pop-up allows you to review, enhance, edit, copy, and download a detailed summary analysis of the Audit Trail report log. You can also add an additional page to the report that displays the AI analysis.

 The following actions are available:

 Options
 Description

 Enhance

 Prompts Orion AI to re-evaluate the report data and generate new AI analysis based on your needs. Select one of the following options:

 More Detail

 Provides a longer, more thorough overview of the report's generated data.

 More Concise

 Condenses the analysis into a shorter summary of the report's generated data.

 Edit

 Opens a pop-up text editor that allows you to manually edit the text directly. AI-generated data is not always completely accurate and cannot account for external factors (such as your specific business processes), so you can type to add content to or delete content from the AI analysis as needed.

 Copy

 Copies the AI analysis text to your clipboard to be pasted into a document or another screen.

 Download

 Saves a PDF file copy of the AI analysis to your local device's downloads folder.

 Add to Report

 Adds a new page to the report that contains your finished AI analysis text. You can opt to attach this analysis page as the First Page in the report or the Last Page .

 Orion Analysis Page

 You can add a page to your Audit Trail report results that displays your AI analysis as a subreport named Orion Analysis . This page can be set as either the first page in the report or the last page.

 After adding this page to the report, you can export and share the report's generated results—including the AI analysis page—just as you would any other report, such as exporting it as an Excel or PDF file. For more information, refer to Share Reports .

 More Information

 If the page is refreshed, closed, or the report is rerun, the AI analysis attached to the report is removed. This action cannot be undone, but you can use the Orion Report Assistant to generate a new AI analysis after refreshing or rerunning the report.
