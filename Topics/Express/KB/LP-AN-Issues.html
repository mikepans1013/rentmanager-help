Automated Notifications for Issues and Service Management

Automated notifications allow you to send alerts to a customizable list of recipients when a certain set of conditions are met to help streamline your workflows and processes. These notifications can be customized using plain text and scripting for personalized text and/or email messages.

There are many options for automated notifications regarding service issues to inform you of updates, submissions, and resolutions for service issues. These notifications are described in the table below.

Attention

Ensure the table is the full and current list of automated notifications related to issues.

Notification Description

Inspection Closed

Informs property managers, other Rent Manager users, tenants, owners, or external recipients when an inspection's status is changed to Closed in Rent Manager or rmAppSuite Pro.

Issue Assigned to User

Informs Rent Manager users—such as service or maintenance techs—when a service issue is assigned to them.

Issue Closed

Informs a tenant or owner when a service issue they submitted has been closed via Rent Manager or rmAppSuite Pro. Additionally, Rent Manager users—such as property managers or maintenance team leads—can receive this notification to track issue resolution.

Issue Confirmed

Informs tenants when their service issue has been scheduled and a time slot has been reserved and confirmed to address the issue, informing them when to expect a maintenance technician to arrive if the tenant requested to be present during service.

More Information

This notification applies only if you have the Maintenance Scheduling feature, which is a licensed feature available only in Rent Manager Express and must be purchased separately. For more information, contact your sales representative at sales@rentmanager.com.

If this notification is not set up, Rent Manager has a default system message that is sent to tenants instead.

Issue Created

Informs Rent Manager users—such as property managers or service technicians—when a service issue has been created in Rent Manager. Additionally, this notification can be configured to be sent to tenants and owners to send them a confirmation that their issue was received and created.

Issue Created via TWA

This notification works the same as the Issue Created notification, but is specifically for issues submitted by tenants via Tenant Web Access (TWA) and can be sent only to tenants and/or Rent Manager users.

Issue Due

Informs Rent Manager users or external recipients when the Due date of a service issue is approaching.

Issue Scheduled

Informs Rent Manager users or external recipients when the Scheduled date of a service issue is approaching.

Management Inspection Scheduled

Informs users, tenants, owners, or other external recipients when a management inspection's scheduled date is approaching in Rent Manager or rmAppSuite Pro.

Next Issue in Project Workflow Waiting

Informs Rent Manager users or external recipients when the next issue in a workflow project is ready to be addressed and completed. This notification is sent only for workflow projects with the setting Steps must be completed in order enabled.

Survey Link Expiring

Informs tenants prior to the expiration of a survey link they were sent, allowing them to respond to a survey before they miss the opportunity to participate.

Survey Response Received

Informs property managers, other Rent Manager users, or external recipients that survey responses were received.

Tenant Self Inspection Awaiting Review

Informs property managers, other Rent Manager users, or external recipients when a tenant has submitted a self-inspection for their unit and needs to be reviewed.
