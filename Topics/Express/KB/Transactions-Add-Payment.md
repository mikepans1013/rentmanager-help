# Add a Payment

Source: https://rmxhelp.rentmanager.com/Topics/Express/KB/Transactions-Add-Payment.htm

To account for the many reasons you need to handle payments in your business, Rent Manager offers two solutions for entering tenant and prospect payments. The payment function in Rent Manager allows you to enter one payment to cover open tenant or prospect charges or partial payments to address multiple open charges.

 Option 1: Enter a Payment

 When a tenant or prospect only has one open charge that needs to be paid, such as monthly rent charge for a tenant or a security deposit for a prospect, the payment can be applied directly to the charge. The same process can also be used if the tenant or prospect presents you with multiple payments to address separate open charges.

 To enter a single payment, do the following:

 -
 At the top, in the Tenant field, enter the name, unit, or account number of the tenant or prospect account from whom you are receiving the payment. Additionally, filter the results that populate in the Tenant field by using the following fields:

 Field
 Description

 Properties

 Limit the results in the Tenant field to display only tenants and/or prospects at the selected properties.

 Status

 Limit the results in the Tenant field to display only tenants and/or prospects with the selected account status(es). Prospects display only if the Prospect option is checked in this field.

 -
 In the Payment Info section, enter the information about your payment.

 -
 In the Open Charges section, verify that the Current Payment amount entered is correct. If the payment does not cover all open charges, in the list of open charges, check the Pay? box next to the open charge to which to apply this payment.

 -
 In the New Late Fees column, verify the late fee amount is correct or enter the desired late fee amount for each charge. This column displays only if any daily (or per-day) late fees have accumulated for the open charges based on the date the charge was posted and the payment's Transaction Date .

 -
 In the Payment Summary section, select additional payment options and verify the payment is being applied appropriately.

 More Information

 If a tenant or prospect comes to you with multiple payments for their account, you can use Rent Manager to record each payment to reflect how the payments were deposited in real life. To do this, use the same process to enter a single payment for as many payments you received.

 For example, if a tenant gives you three checks to cover three separate open charges, enter each check for each payment, one at a time.

 Option 2: Enter a Partial Payment

 When a tenant or prospect has multiple open charges that need to be addressed with a single payment, partial payments can be used to handle the charges. When you receive the payment, you can apply partial payments to multiple charges at once.
