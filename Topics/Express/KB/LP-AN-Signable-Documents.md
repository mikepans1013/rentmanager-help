# Automated Notifications for Signable Documents

Source: https://rmxhelp.rentmanager.com/Topics/Express/KB/LP-AN-Signable-Documents.htm

Automated notifications allow you to send alerts to a customizable list of recipients when a certain set of conditions are met to help streamline your workflows and processes. These notifications can be customized using plain text and scripting for personalized text and/or email messages.

 There are multiple automated notifications related to signable documents that you can use to update and remind internal and external accounts about signable documents that need attention. Each notification is described in the table below.

 Attention

 Ensure the table is the full and current list of automated notifications related to signable documents.

 Notification
 Description

 Document Signed

 Informs the Rent Manager user, such as a property manager, or other external recipients that a document has been signed and submitted.

 Document Published to Owner Web Access (OWA)

 Informs an owner that a signable document was published to their Owner Web Access (OWA) portal.

 Documents Published to Tenant Web Access (TWA)

 Informs a tenant that a signable document was published to their Tenant Web Access (TWA) portal.

 Owner Prospect Signable Document Aging

 Informs an owner prospect that a document is waiting to be signed for a set amount of time.

 Owner Signable Document Aging

 Informs an owner that a document is waiting to be signed for a set amount of time.

 Prospect Signable Document Aging

 Informs a prospect that a document is waiting to be signed for a set amount of time.

 Signable Document Aging

 Informs a Rent Manager users or external recipients that a prospect or tenant document is waiting to be signed for a set amount of time.

 Signable Document Waiting for Landlord's Signature

 Informs Rent Manager users or external users that a signable document was returned by the signer and is waiting for landlord or manager approval.

 Tenant Signable Document Aging

 Informs a tenant that a that a document is waiting to be signed for a set amount of time.
