# Share and Change the Ownership of Report Batches

Source: https://rmxhelp.rentmanager.com/Topics/Express/KB/Report-Batch-Ownership.htm

Report batches are collections of reports that can be generated simultaneously to save time and increase efficiency. You can configure the report options of each report in the batch to generate the reports automatically with little to no input from the user. Report batches can also be scheduled to generate at a certain time and date, and the reports are then emailed to the specified email address(es).

 By default, only the creating user has access to report batches. To allow other users to access the batch, it must first be shared. Sharing a report batch only allows other users to generate the batch, not edit the batch. To allow other users to edit the report batch, you must change the ownership of the batch. Each process is described in this topic.

 Share a Report Batch With Other Users

 To manage which users can and cannot generate a report batch, do the following:

 -
 Go to arrow_forward Manage Batches .
The Report Batches page displays.

 -
 Click on the report batch you wish to share and select Share .
The Report Batch Share pop-up displays.

 -
 Click the drop-down list and check the name of each user and/or user role that you want to have access to the report batch.

 -
 Click Save .
The report batch is shared with the selected users and/or user roles and they can run the report batch.

 Having ownership of a report batch allows a user to edit the batch. In addition, if a user has ownership of a report batch and it is not shared with other users, only the user with ownership can view the report batch.

 To transfer the ability to edit a report batch from one user to another user, from the Report Batches page:

 -
 Click on the report batch you wish to transfer and select Change Ownership .
The Report Batch Ownership pop-up displays.

 -
 In the Select batch from user field, select the name of the user whose report batch you wish to reassign.

 -
 Click the User Report Batch drop-down list and select the report batch to be reassigned.

 -
 If applicable, enter a new name for the report batch in the Rename batch to field.

 -
 In the Assign ownership to user field, select the name of the user to receive ownership of the report batch.

 -
 Click Save .
Ownership of the report batch is reassigned to the selected user.
