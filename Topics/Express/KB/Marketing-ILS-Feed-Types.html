ILS Marketing Feed Types

If you use the internet listing services (ILS) marketing integration, the Marketing Setup pop-up displays a Feed Type in the top right corner which instructs ILS sites what type of property is being marketed. For example, a single family home is assigned the Single Family feed type, but an apartment complex is assigned the Multi Family feed type.

By default, a property is assigned a feed type based on the Property Type field ( arrow_forward Rental Info arrow_forward General arrow_forward Properties arrow_forward select a property arrow_forward General tile). Once initially assigned, the feed type remains the same regardless of changes to the property's Property Type field. Likewise, altering a property's Feed Type field from its default assignment does not impact its Property Type. In order to change a feed type from its default setting, you must do so through the Advanced Settings pop-up.

Rent Manager supports two feed types, a Multi Family feed type and a Single Family feed type. A Single Family feed type indicates that the property listed contains a single, rentable unit. Properties with multiple rentable units are considered a Multi Family feed type. Only properties assigned either a Multi Family or Single Family feed type can list on ILS sites. The two feed types require slightly different information to list on ILS sites. For example, floor plans are available only for properties with a feed type of Multi Family. For more information, refer to Property Marketing Advanced Settings (Pop-Up).

Property types that do not fit into the Multi Family or Single Family feed types, such as Association, Commercial, Short Term Rental, and Storage, are not assigned a feed type. Properties of these types can be manually assigned a feed type on the Advanced Settings pop-up.

More Information

Properties with a Property Type set to RV/Campground market vacancies through an Online Booking portal. These properties have a unique Marketing Setup pop-up to accommodate their listing needs. For more information, refer to STR Property Marketing Setup (Pop-Up).
