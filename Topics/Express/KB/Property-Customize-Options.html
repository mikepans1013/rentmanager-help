Customize Property Options

When you create a property in Rent Manager, you can enter values into property-type user-defined fields (UDFs), select which unit types and amenities are available at the property, and also establish management fees for fee-based management companies. Although you can complete the property add wizard without this information, creating any UDFs, unit types, amenities, and fee templates the property may need before adding your property helps streamline the property creation process.

Property User-Defined Fields

For more information, refer to Control User Access.

User-defined fields (UDFs) are custom fields you create to track data that Rent Manager does not track by default. Property-type UDFs are used specifically to track additional information on property accounts. For more information on creating property-type UDFs, refer to Add a User Defined Field.

Unit Types

Related Privileges

Group Privilege Column
Properties/Units Unit types Add, View

For more information, refer to Control User Access.

Unit types are varying classifications of rooms or spaces that define the type of space including size, price, and so on. For example, you might have units with one bedroom and one bathroom, and also units with two bedrooms and one and a half bathrooms. Additionally, you can even create units for parking spaces or storage units. For more information on creating unit types, refer to Add a Unit Type.

The unit types you need to create may vary depending on the type of properties you manage. For example, at commercial properties, you might have units specific to offices, and also units for retail shops. At short-term rental (STR) properties, you might have vacation units with one bedroom and one bathroom, and also units with two bedrooms and one and a half bathrooms. Additionally, you can create units for campsites that can accommodate RVs and units that allow only tents.

Management Fee Templates

Related Privileges

Group Privilege Column
Owners Management fee templates Add, View

For more information, refer to Control User Access.

If you are a fee-based management company and you are adding multiple properties that have the same fee setup, you can streamline the process by first creating a management fee template that establishes those management fees. Then, when you create the property, you can select the template from the list and the property automatically pulls that fee setup instead of manually entering the setup on each property as you add them. For more information, refer to Management Fee Templates (Page).

Property Amenities

Related Privileges

Group Privilege Column
Properties/Units Amenities Add, View

For more information, refer to Control User Access.

Most properties offer amenities such as dog parks, clubhouses, free Wi-Fi, pools, and so on. During the property creation process, you have the option to select the amenities available at the property. To streamline the process, you can add the amenities available at your properties to Rent Manager first, then simply select the amenities that apply to each property as you create it. For more information, refer to Add an Amenity.
