# Set Up rmVoIP for rmAppSuite Pro

Source: https://rmxhelp.rentmanager.com/Topics/Express/KB/rmVoIP-rmAppSuite-Pro-Set-Up.htm

If you use rmAppSuite Pro , users with rmVoIP extensions can call or text prospects, tenants, vendors, and owners directly through the app without using their personal phone number. As an added benefit, records of calls placed through rmVoIP are saved to Rent Manager .

 More Information

 This feature is licensed and must be purchased separately. For more information, contact your sales representative at sales@rentmanager.com .

 Before a user can use rmVoIP with rmAppSuite Pro , rmVoIP first needs to be enabled in Rent Manager and then users need to be provided access and set up with their rmVoIP extension. For more information, refer to Set Up rmVoIP for Rent Manager .

 Once a user has an rmVoIP extension on their account, they can make calls in rmAppSuite Pro by doing the following:

 -
 Log into rmAppSuite Pro .

 -
 Go to arrow_forward Settings arrow_forward Account Settings .
The Account Settings screen displays.

 -
 If you are using an Android device, in the rmVoIP Settings from RM section, verify that rmVoIP Enabled is selected. If you are using an iOS device, in the rmVoIP section, verify that Use rmVoIP on this Device is enabled.

 -
 Select Device is the active rmVoIP User .

 -
 Choose how the rmAppSuite Pro dialer is used. These settings differ depending on your operating system, and each setting is described below:

 System
 Description

 Android

 Determine whether the rmAppSuite Pro dialer is always used or if the user is prompted when making calls.

 Always use rmVoIP Dialer when making phone calls

 Any outgoing phone calls made from this device automatically use the dialer in rmAppSuite Pro . This option is recommended only for phones that are exclusively used for work.

 Prompt when making phone calls

 Any outgoing phone calls ask the user whether they want to use their phone's default dialer or the rmAppSuite Pro dialer.

 iOS

 If the user should be prompted to use the rmAppSuite Pro dialer when making calls, select Alert User before using device's dialer . If the rmAppSuite Pro dialer should always be used, leave this option unchecked.
