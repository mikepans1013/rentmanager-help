# Increase a Recurring Charge

Source: https://rmxhelp.rentmanager.com/Topics/Express/KB/Recurring-Charge-Increase.htm

When you need to increase a recurring charge, such as a monthly rent charge, it is recommended that you first end the current charge before adding a new one. Instead of deleting the old charge, set an end date so that the charge no longer applies to the tenant account, but remains viewable in your financial records in Rent Manager . Recurring charges can be set at the property, unit, unit type, and tenant levels.

 Step 1: End a Current Recurring Charge

 To end a current recurring charge, do the following:

 -
 Go to the details page for the entity where the recurring charge is set. For example, go to arrow_forward Rental Info arrow_forward General arrow_forward Tenants and select a tenant from the list.
The entity's details page displays.

 -
 On the Recurring Charges tile, click and select the recurring charge from the list.
The Recurring Charge Details pop-up displays.

 -
 In the To field, enter the date on which you want this recurring charge to end.

 -
 Click Save .
The new date displays on the View Recurring Charges pop-up in the To Date column. The recurring charge no longer applies to the account after this date.

 Step 2: Add a New Recurring Charge

 To add a new recurring charge, do the following:

 -
 Go to the details page for the entity where you want to add a new charge. For example, go to arrow_forward Rental Info arrow_forward General arrow_forward Tenants and select a tenant from the list.
The entity's details page displays.

 -
 On the Recurring Charges tile, click and select the recurring charge from the list.
The Recurring Charge Details pop-up displays.

 -
 Click Add arrow_forward Add .

 -
 Enter the following information:

 Field
 Description

 Unit

 The unit associated with this charge This option displays only on tenant-level recurring charges. Only the units associated with this tenant display.

 Charge Type

 The charge type that you use for the recurring charge. Each charge type is linked to one of the general ledger (GL) accounts from your chart of accounts.

 Amount

 The full dollar amount of the new recurring charge.

 Calculation

 If you use a script to calculate the new charge amount, enter the script here instead of entering a value in the Amount field.

 Frequency

 How often per rent period this charge posts. For example, if a tenant has a Monthly rent period, a frequency of 1 means the charge posts once per month. For more information, refer to Tenant Details (Page) .

 From

 The date on which this charge begins posting. If no date is entered, the charge begins posting the next time recurring charges are posted.

 To

 The date on which this charge expires and stops posting. If no date is entered, the charge continues posting until you end it by entering a new To date.

 Comment

 An optional note describing the charge. The comment displays on the View Recurring Charges pop up.

 -
 Click Save .
The new recurring rent charge is added to the entity.
