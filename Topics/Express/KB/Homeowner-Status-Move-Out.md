# Homeowner Statuses Available on Move Out

Source: https://rmxhelp.rentmanager.com/Topics/Express/KB/Homeowner-Status-Move-Out.htm

Depending on the active current homeowner status for a home-type asset, the ability to set a new status in the Homeowner Status field may or may not be available when performing tenant move outs using the Move Out wizard.

 The following table lists whether the Homeowner Status field can be set manually during this process, based on the status the home-type asset has at the time the move out process is performed:
