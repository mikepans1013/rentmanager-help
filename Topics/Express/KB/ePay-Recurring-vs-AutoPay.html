Recurring ePay vs AutoPay

Once you have set up Zego ePay in Rent Manager, you can determine how your company processes ePay payments. If you are using Tenant Web Access (TWA), your tenants can always submit one-time payments through their portal. However, Rent Manager also offers two methods to facilitate automatic payment collection: recurring ePay and AutoPay.

Recurring ePay allows Rent Manager users to debit tenants' bank accounts, debit cards, or credit cards directly from your database. You can utilize Task Automation to create schedules that perform this action automatically. AutoPay enables tenants to configure their own automatic payment schedules from TWA.

This topic outlines the unique features of recurring ePay and AutoPay to help you understand how each option impacts your business.

More Information

ePay is a licensed feature by Zego. To use Zego ePay, you must set up an account with Zego and enter that information into Rent Manager. For more information, contact sales@rentmanager.com.

Warning

While recurring ePay and AutoPay can be used simultaneously, you should not use both methods for the same tenant account. Doing so can result in the tenant receiving duplicate charges.

Recurring ePay

The recurring ePay tool allows you to process ePay payments for your tenants directly from Rent Manager. This action can be performed for one or more tenants at a time, allowing you initiate real-world transactions for tenants across multiple properties with just a few clicks. The bundle of payments processed using recurring ePay is called a batch. You can streamline this task by automating it with Task Automation.

Recurring ePay allows you to control every step of the ePay process, from initial setup to payment processing. However, the added control also means that you are responsible for collecting your tenants' payment information, entering it into Rent Manager, and making the payments on their behalf. This arrangement can greatly benefit tenants who are not tech-savvy or do not have reliable internet access. You may also choose recurring ePay if you are not using Tenant Web Access (TWA).

If you decide to implement recurring ePay, follow the table below as a guide to your next steps.

Task Description

Add tenant payment information to Rent Manager

In order to process recurring ePay payments for your tenants, you must enable ePay on their accounts, enter payment details in their ePay Settings page, and include their accounts in ePay batch postings. For more information, refer to Tenant ePay Settings (Pop-Up).

Post recurring ePay payments

Once you have set up your tenants for recurring ePay, you initiate their payments in Rent Manager from the Post Recurring ePay page. For more information, refer to Post Recurring ePay.

Automate recurring ePay

You can use Task Automation to automate the recurring ePay posting process. For example, you can create a an automation schedule that withdraws funds for rent payments from tenant accounts on the third day of every month. By establishing recurring ePay automation schedules, you can save time and reduce the incidence of errors that occur from manual posting. For more information, refer to Recurring ePay Automation Schedules (Page).

AutoPay

The AutoPay tool in Tenant Web Access (TWA) allows tenants with web user accounts to set up automatic, recurring payments. After you complete the setup steps in system web preferences, you can notify tenants that it is available for use. On the day(s) AutoPay runs, funds are drafted from your tenants' accounts and recorded in Rent Manager.

AutoPay can save your business considerable time by eliminating the need to manually collect and enter payment information for every tenant. With AutoPay, tenants add those details themselves in their TWA account. Tenants can also easily update their payment information in TWA in the event that they change banks or get new debit or credit cards.

If you decide to implement AutoPay, follow the table below as a guide to your next steps.

Task Description

Enable AutoPay and configure preferences

In order for tenants to set up AutoPay in TWA, you must first enable it in system web preferences and determine additional settings, such as what days AutoPay runs. For more information, refer to Tenant Web Access AutoPay (System Web Preferences).

Provide setup instructions to tenants

To help streamline the AutoPay setup process for your tenants, Rent Manager has made the Automatic Payment Instructions letter available for download in the online template library (OTL). This letter provides tenants with step-by-step instructions for configuring AutoPay in TWA. You can download this letter from the Tenant Letters folder in the OTL, customize it to suit your needs, then distribute it to your tenants. For more information, refer to Import and Export Letter Templates

Review tenant AutoPay setup

Once a tenant has set up their AutoPay configuration in TWA, you can review their setup in the Web Access Settings pop-up on their account. You can also disable the tenant's AutoPay from this pop-up. For more information, refer to Tenant Web Access Settings (Pop-Up)
