Add Links to a Work Order

To ensure accurate expense tracking, you can easily link out to bills, invoices, and purchase orders (POs) directly on an issue work order. This allows you to create bills in Rent Manager for vendors and owners to reimburse for items on the issue work order. Additionally, you can create and link a PO to cover the ordering and purchasing of an item you need for the issue, or create an invoice to send to a tenant so they can reimburse you for the item(s) on the issue work order.

Link a Bill

Bills can be created during the work order creation process, but if you already have an existing bill that applies to the work order you are creating, you also have the option to link the existing bill to the work order.

Create and Link a New Bill

Related Privileges

Group Privilege Column
Service Manager Issues View, Edit
Payables Bills View, Add

For more information, refer to Control User Access.

To create a new bill and link it to the work order, do the following:

  1. Go to arrow_forward Services arrow_forward Service Manager arrow_forward Issues and select an issue.
    The issue's details page displays.

  2. In the Work Orders tile header, click Add Item.
    The Add Work Order Item pop-up displays.

  3. In the Details and Billing Information tiles, enter the needed information for the inventory item being added to the work order. For more information, refer to Add a Work Order.

  4. In the Item Links section, check Bill. Then select one of the options below.

    Option Description

    Vendor Bill

    The property pays for the items on the work order.

    Vendor Bill & Owner Bill

    The management company pays for the items, then bills the owner for reimbursement for the purchase.

  5. Click Add Item & Close.
    In the Work Orders tile, an orange badge for the vendor bill (and if applicable, owner bill) displays in the Item Links column. The bills have not yet been created.

  6. In the Work Orders tile header, click Create Item Links.
    The tile refreshes and the badge(s) change to green and contain links to the newly created bill(s).

  7. If needed, click the links in the badges to open the associated bill and fill out any additional information required or make adjustments. Your changes are automatically saved. For more information, refer to Bill Details (Page).

Link to an Existing Bill

Related Privileges

Group Privilege Column
Service Manager Issues View, Edit
Payables Bills View, Edit

For more information, refer to Control User Access.

To link an existing bill to an issue's work order, do the following:

  1. Go to arrow_forward Services arrow_forward Service Manager arrow_forward Issues and select an issue.
    The issue's details page displays.

  2. In the Work Orders tile header, click Add Item.
    The Add Work Order Item pop-up displays.

  3. In the Details and Billing Information tiles, enter the needed information for the inventory item being added to the work order. For more information, refer to Add a Work Order.

  4. In the Item Links section, check Bill. Then select one of the options below.

    Option Description

    Vendor Bill

    The property pays for the items on the work order.

    Vendor Bill & Owner Bill

    The management company pays for the items, then bills the owner for reimbursement for the purchase.

    More Information

    If this work order is already linked to an existing Smart Bill or Smart Receipt that is not yet posted, a View Vendor Bill link displays beneath each field option. Click the link to jump to the linked Smart Bill or Smart Receipt. For more information, refer to Review Smart Bills or Review Smart Receipts.

    Once the Smart Bill or Smart Receipt is posted as a bill, it is automatically linked to this work order.

  5. Click Link Existing Bill.
    The Link Existing Bill pop-up displays.

  6. Use the available filters to locate the vendor bill you wish to link to the work order. The list populates with vendor bills that match your filter criteria. Only bills for the same Vendor as your work order display.

    Filter Description

    Bill Date

    Include only bills that were issued on or between the start and end dates of the selected date range.

    Invoice #

    Enter a number to include only bills with an Invoice # that includes the entered number.

    Job

    Related Preferences

    In order to use the job costing tool in Rent Manager, Enable job costing must be checked in system preferences. For more information, refer to General Options (System Preferences).

    Include only bills associated with the selected job.

    Search

    Enter a keyword or number, such as a bill memo or property name, to display only bills that meet this criteria.

    Show unpaid bills only

    If checked, bills that are paid in full are excluded from the list. Partially paid bills still display.

  7. In the list below, click to the left of the bill that you wish to link to the work order.

  8. Click Link.

  9. Click Add Item & Close.
    In the Work Orders tile, a green badge with a link to the bill displays in the Item Links column. You can click the link to jump to the bill's details.

    More Information

    If you selected the Vendor Bill & Owner Bill option, you must still click Create Item Links in order to create a new owner bill and link it to the work order. Existing owner bills cannot be linked.

  10. If needed, click the links in the badges to open the associated bill and fill out any additional information required or make adjustments. Your changes are automatically saved. For more information, refer to Bill Details (Page).

  11. If you made any other changes to the issue, click Save.

Link a Tenant Invoice

Related Privileges

Group Privilege Column
Service Manager Issues View, Edit
Sales/Invoicing Invoices View, Add, Edit

For more information, refer to Control User Access.

If the issue work order requires you to add an item that the tenant is going to pay for, you can create a tenant invoice directly from the work order with a link.

To create a new invoice and link it to the work order, do the following:

  1. Go to arrow_forward Services arrow_forward Service Manager arrow_forward Issues and select an issue.
    The issue's details page displays.

  2. In the Work Orders tile header, click Add Item.
    The Add Work Order Item pop-up displays.

  3. In the Details and Billing Information tiles, enter the needed information for the inventory item being added to the work order. For more information, refer to Add a Work Order.

  4. In the Item Links section, check Tenant Invoice.

  5. Click Add Item & Close.
    In the Work Orders tile, an orange badge for the tenant invoice displays in the Item Links column. The invoice has not yet been created.

  6. In the Work Orders tile header, click Create Item Links.
    The tile refreshes and the badge changes to green and contains a link to the newly created invoice.

  7. If needed, click the link in the badge to open the associated invoice and fill out any additional information required or make adjustments. Your changes are automatically saved. For more information, refer to Invoice Details (Page).

  8. If you made any other changes to the issue, click Save.

Link a Purchase Order

Related Privileges

Group Privilege Column
Service Manager Issues View, Edit
POs/Estimates Purchase orders View, Add, Edit

For more information, refer to Control User Access.

If the issue work order requires you order and purchase an item you don't currently have in stock, you can create a purchase order (PO) directly from the work order with a link.

To create a new PO and link it to the work order, do the following:

  1. Go to arrow_forward Services arrow_forward Service Manager arrow_forward Issues and select an issue.
    The issue's details page displays.

  2. In the Work Orders tile header, click Add Item.
    The Add Work Order Item pop-up displays.

  3. In the Details and Billing Information tiles, enter the needed information for the inventory item being added to the work order. For more information, refer to Add a Work Order.

  4. In the Item Links section, check Purchase Order.

  5. Click Add Item & Close.
    In the Work Orders tile, an orange badge for the PO displays in the Item Links column. The PO has not yet been created.

  6. In the Work Orders tile header, click Create Item Links.
    The tile refreshes and the badge changes to green and contains a link to the newly created PO.

  7. If needed, click the link in the badge to open the associated PO and fill out any additional information required or make adjustments. Your changes are automatically saved. For more information, refer to Purchase Order Details (Page).

  8. If you made any other changes to the issue, click Save.
