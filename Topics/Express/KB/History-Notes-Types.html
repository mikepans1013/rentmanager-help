History/Note Types

In Rent Manager, history/notes are used to record information that supplements or clarifies what’s entered in other fields, such as notes about phone conversations, details for scheduled tasks, and inventory transactions. Each history/note item is assigned a system-generated type that identifies the source of or reason for the item. These types can be used in filters and reports to help track specific kinds of notes.

More Information

History/note types are system-generated and cannot be created or deleted. However, you can supplement these types by creating custom history categories to provide additional details and filtering options for your history/notes. For more information, refer to History Categories (Page).

The following history/note types display in Rent Manager:

History/Note Type Description

Amenity Reservation Request

Added to a tenant account when they submit an amenity reservation request via Tenant Web Access. Status updates to the request display on the same entry.

Appointments

Added when an entity is assigned to an appointment's Links tile.

Architectural Requests

Added to a tenant when an architectural request linked to their account is submitted. Status updates to the request display on the same entry.

Asset Maintenance

History/note items added to an asset via arrow_forward Add Maintenance Record.

Call

History/note items created via arrow_forward Add Call.

Email

Added for emails sent to or received from an email address linked to the entity.

Email - Note

History/note items created via arrow_forward Add Email Note.

Eviction

Added to a tenant account when an eviction linked to their account is created.

Eviction Notes

Added to an eviction and linked tenant account via the eviction's Add Note button.

Eviction Stage

Added to an eviction when it is initially created and when it is advanced to a new stage.

Guest Card

Added to a prospect or owner prospect account when they submit a guest card.

Inspections

Added to a tenant account when they are linked to an inspection.

Lease Renewal Offer

Added to a tenant account when a lease renewal is generated for their account using the Create Renewal Offer tool.

Make Ready Process

Added to a unit when a make-ready process is kicked off for that unit.

Note

History/note items created via arrow_forward Add Note. This type also displays for ePay errors, automated notification delivery errors, text messaging opt-in/out alerts, and records generated from the merge tool.

OWA File

Added to an owner account when a report is published using the Publish to OWA tool or when any item is added via arrow_forward Add OWA File.

Ownership Transfer

Added to the source and destination properties upon the completion of the ownership transfer wizard.

Phone Broadcast

Added to an entity when a phone broadcast is made to a phone number linked to their account.

Prospect Applications

Added to a prospect account when they create an application using Apply Now.

rmVoIP

When using the integrated rmVoIP phone system, added to calls made to or received from phone numbers linked to the entity's account.

Screening

Added to an entity when an AmRent screening is run for their account.

Service Issues

Added when an entity is assigned to a service issue's Issue Links tile.

Signable Document

Added when a signable document is published to an email address associated with an entity's account.

System

History/note items generated by general Rent Manager operations. Some examples are account created, NSF processed, and tenant moved out.

Tasks

Added when an entity is assigned to a task's Links tile.

Tech Times

Added to a service issue when service tech hours are added via the Tech Time Details pop-up.

Text Messages

Added for text messages sent to or received from a phone number linked to the entity's account.

Violation

Added to a tenant account when a violation linked to their account is created. Violation stage updates display on the same entry.

Violation Notes

Added to a violation and linked tenant account via the eviction's Add Note button.

Violation Stage

Added to a violation when it is initially created and when it is escalated to a new stage.

Violation Stage Revert

When a violation stage is reverted, the associated Violation Stage history/note item type changes to Violation Stage Revert.

Visit

History/note items created via arrow_forward Add Visit.

Voicemail

History/note items added when a Smart Voicemail is received from a Phone Number that is linked to the entity's account. The history/note item displays the entity's name and phone number and an Orion AI summary of the voicemail. If the entity does not leave a voicemail, only their name and phone number display.

Web Account Updates

History/note items added when changes are made to the Tenant Web Access or Owner Web Access account associated with the entity's account.

Web Conversation

History/note items added to an entity's account when a web chat conversation linked to their Tenant Web Access or Owner Web Access account is created.
