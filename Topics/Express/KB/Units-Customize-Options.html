Customize Unit Options

When you create or edit units in Rent Manager, you can enter values into unit-type user-defined fields (UDFs), select which amenities are available at the unit, and also define which floor the unit is located on. Creating any UDFs, amenities, and floors you may need before adding your units helps streamline the unit creation process.

Unit Types

Related Privileges

Group Privilege Column
Properties/Units Unit types Add, View

For more information, refer to Control User Access.

Unit types are varying classifications of rooms or spaces that define the type of space including size, price, and so on. For example, you might have units with one bedroom and one bathroom, and also units with two bedrooms and one and a half bathrooms. Additionally, you can even create units for parking spaces or storage units.

You must create unit types before creating units. For more information on creating unit types, refer to Add a Unit Type.

Amenities

Related Privileges

Group Privilege Column
Properties/Units Amenities Add, View

For more information, refer to Control User Access.

Most residential units offer amenities such as fireplaces, washer/dryer hookups, pet policies, dishwashers, and so on. During the unit creation process, you have the option to select the amenities available at the unit. To streamline the process, you can add the amenities available at your units to Rent Manager first, then simply select the amenities that apply to each unit as you create it. For more information, refer to Add an Amenity.

Floors

Related Privileges

Group Privilege Column
Properties/Units Floors Add, View

For more information, refer to Control User Access.

Adding floors to your database allows you to track and categorize both your units and properties. You can define how many floors a property has, as well as specify which floor a unit is located on. This is a useful option for marketing purposes, as many prospective tenants are interested in units on specific floors. For more information, refer to Floors (Page).

Unit User-Defined Fields

Related Privileges

Group Privilege Column
User Defined Fields User defined fields Add, View

For more information, refer to Control User Access.

User-defined fields (UDFs) are custom fields you create to track data that Rent Manager does not track by default. Unit UDFs are used specifically to track additional information on unit accounts. For more information on creating unit UDFs, refer to Add a User Defined Field.
