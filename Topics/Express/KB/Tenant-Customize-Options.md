# Customize Tenant Options

Source: https://rmxhelp.rentmanager.com/Topics/Express/KB/Tenant-Customize-Options.htm

When you create or edit a tenant in Rent Manager , you can enter values into tenant-type user-defined fields (UDFs), select a lease term, and determine which property, unit, and/or unit-level recurring charges the tenant should inherit. Although you can complete the add wizard without this information, setting up these tools before adding your tenant helps streamline the tenant creation process.

 User-defined fields (UDFs) are custom fields you create that allow you to track data that Rent Manager does not track by default. Tenant-type UDFs are used specifically to track additional information on tenant accounts. For more information, refer to Add a User Defined Field .

 Lease terms in Rent Manager allow you to track the different lease durations available at each property. This also allows you to enter the tenant's Lease Start Date and then select the Lease Term , and Rent Manager automatically populates the appropriate Lease End Date based on the selected term. For more information, refer to Lease Terms (Page) .

 For example, if Property A offers 12 month leases and 16 month leases, but Property B only offers 12 month leases, you can create these lease terms and assign them to the applicable properties. Then when adding tenants to the properties, any tenants added to Property B cannot be given a 16 month lease, since it is not available for that property.

 These system preferences allow you to automatically generate both recurring and one-time charges for new tenants when a prospect is converted to a tenant with the move in wizard, or when you create a tenant using the tenant add wizard.

 For example, a one-time charge can be created for routine charges, like security deposits, which are collected when a tenant begins their lease. Additionally, a one-time charge can be prorated to automatically generate charges for partial charges, such as the first rent charge. For more information, refer to Tenant Charge Setup (System Preferences) .

 Recurring charges are charge templates that can be posted regularly, such as rent, pet fees, and other repeating charges. If you have standard fees that apply to all tenants at a property for the same amount, such as garbage collection fees, you can set up this recurring charge at the property level and all tenants added to that property automatically inherit the recurring charge. Alternatively, if your rent amounts are set depending on the unit type and is the same across all units of a specific unit type, you can establish the rent recurring charge at the unit type level. This helps streamline the process so you do not have to add each of these recurring charges to every individual tenant over and over.

 Tenants inherit all recurring charges from their property, unit, and that unit's unit type by default, but you can choose to exclude tenants from these charges on an individual basis. For more information, refer to Property Recurring Charges (Pop-Up) , Unit-Level Recurring Charges (Pop-Up) , or Unit Type-Level Recurring Charges (Pop-Up) .

 A subsidy is a form of financial assistance offered to qualifying tenants. The most common subsidy examples are HUD, Section 8, and FEMA. In Rent Manager , subsidies can be tracked, and payments made by the subsidy can be recorded. You can create subsidies and then apply them to tenants' leases when you create new accounts. For more information, refer to Make a Subsidy Payment .
