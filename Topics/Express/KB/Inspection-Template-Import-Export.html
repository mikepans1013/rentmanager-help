Import or Export an Inspection Template

Inspection templates define the areas and items of a unit that need to be examined. Creating a template for inspections allows you to quickly establish the scope of the inspection based on the types of units you manage and help streamline the inspection process.

If you have any inspection templates created and stored on your local computer or network, you can upload them to use in Rent Manager. Inspection templates can also be downloaded from the online template library (OTL), which is an ever-expanding collection of templates submitted by both Rent Manager users and LCS staff. You can also download inspection templates to keep a backup copy, share them with a coworker, or move them to a different Rent Manager database location.

Import an Inspection Template

Importing an inspection template allows you and other users to create inspections using those templates, as long as they have the privileges to do so. You can import an inspection template that is currently saved on your local network or computer, or you can download one from the online template library (OTL).

From Online Template Library

To download an inspection template from the OTL into Rent Manager, do the following:

  1. Go to arrow_forward Administration, then select Customization arrow_forward Online Template Library.
    The Online Template Library page displays.

  2. In the Category field, select Inspections.

  3. To display only inspection templates that have been created by LCS employees, check LCS Templates Only.

  4. Navigate the folders and select the inspection template you wish to import.

  5. Review the preview and description to verify that the template suits your needs.

  6. Click I Download.
    The Disclaimer pop-up displays.

  7. Read the disclaimer, then click Accept.

  8. On the confirmation pop-up, click OK.
    The inspection template is added to Rent Manager and can be selected when creating new inspections.

From File

To import an inspection template from your local network or computer, do the following:

  1. Go to arrow_forward Services arrow_forward Inspections arrow_forward Inspection Templates.
    The Inspection Template page displays.

  2. On the action bar to the right, select arrow_forward Import Template.

  3. On your network or computer, select the inspection template file you wish to upload to Rent Manager. Only files with the XML format can be uploaded for use as a inspection template.

  4. Click Open.
    The inspection template is imported and can be selected when creating new inspections.

Export an Inspection Template

Inspection templates can be exported as a local file with the Extensible Markup Language (XML) file type. Exported inspection templates can be imported into other Rent Manager databases. To export an inspection template to your computer, do the following:

  1. Go to arrow_forward Services arrow_forward Inspections arrow_forward Inspection Templates.
    The Inspection Template page displays.

  2. Select the inspection template you wish to export.

  3. On the action bar to the right, select arrow_forward Export Template.
    The inspection template automatically downloads to your browser's default location for downloaded files.
