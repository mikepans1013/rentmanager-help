Add and Assign a Unit Amenity

Amenities are features or conveniences such as fireplaces, patios, pools, and so on. Once you have entered amenities into Rent Manager, you can assign these amenities to rental units. This makes it easier to find units with amenities that match the features desired by tenants and prospects. For example, if you manage a community of single-family homes located on a golf course and a golf club membership is included for tenants, you can create a Golf Club Membership unit amenity and assign it to each applicable unit at a property.

Step 1: Add an Amenity

Before you can assign an amenity, you first need to create them in Rent Manager. To add a new amenity, do the following:

  1. Go to arrow_forward Administration, then go to Rental Info arrow_forward Properties/Units arrow_forward Amenities.
    The Amenities page displays.

  2. Click Amenity.
    The Add Unit Amenity Details pop-up displays.

  3. Enter the new amenity Name.

  4. Enter a Comment about the amenity. For example, if you have a golf club membership amenity, but only some units have access to it, you can create a description that details that the amenity is limited to specific units.

  5. If applicable, enter a Price that is charged when this amenity is reserved.
    This is the amenity's default price and is subject to being overridden on a per-property basis.

  6. In the Per Property Override section, enter a value in the Price column for each desired property.

    More Information

    This field populates only with the properties to which you have access. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property.

  7. Click Save.
    The new amenity is added to the Amenities page.

Step 2: Assign the Amenity to a Unit

To assign the new amenity, do the following:

  1. Go to  arrow_forward Rental Info arrow_forward General arrow_forward Units and select the desired unit from the list.
    The Unit details page displays.

  2. On the Amenities tile, click .
    The Amenities pop-up displays.

  3. Check the box next to the desired amenity.

  4. Click Save.
    The amenity is added to the Amenities tile.
