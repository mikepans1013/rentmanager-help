# Add a Checklist Item to an Issue

Source: https://rmxhelp.rentmanager.com/Topics/Express/KB/Issues-Checklist-Add.htm

Issues in Rent Manager help you and your team track and complete all the most important work you handle each day. In cases where multiple tasks need to be completed for a single issue, you can create an issue checklist. Issue checklists can be created for single issues, memorized issues, and recurring issues.

 Checklists items can be entered on an issue that does not happen often, such as repairing a broken window. In instances where an issue requires the same steps to complete it every time, such as preparing a unit for a new tenant, you can create checklist templates to quickly populate the checklist items.

 Add a Checklist to an Issue

 To add a checklist to an issue, go to arrow_forward Services arrow_forward Service Manager arrow_forward Issues and select an issue from the list.

 On an issue's details page, the Issue Checklist tile displays checklist items and options for adding and advancing the checklist. From this tile, you can create checklists for an issue.

 Option 1: Manually Add Checklist Items

 To add individual checklist items to a one-time issue, do the following:

 -
 In the Issue Checklist tile, click Add Checklist Item .

 -
 Enter a Description of the work required for the checklist step, and assign the step to the User Responsible .

 More Information

 The issue must be advanced before the checklist item displays in the responsible user's issue list.

 -
 To finish, click Save & Close , or to create additional items, click Save & New .
The step is added to the Issue Checklist tile, and you can repeat the process to add as many items as needed.

 Option 2: Add Checklist Items from a Template

 To add checklist items from a template, do the following:

 -
 In the Issue Checklist tile, click the drop-down arrow next to Add Checklist Item and then click Add From Template .

 -
 Select a Template from the drop-down.

 -
 Click Save .
The steps are added to the Issue Checklist tile, and you can repeat the process to add as many items as needed.
