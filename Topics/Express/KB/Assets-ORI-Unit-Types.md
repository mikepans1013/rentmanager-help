# When to Use Assets or Other Rentable Item (ORI) Unit Types

Source: https://rmxhelp.rentmanager.com/Topics/Express/KB/Assets-ORI-Unit-Types.htm

If you need to track financials in Rent Manager for a rentable item or space that is not a residential or commercial unit, such as a storage unit or garage, you can either create them as assets or as units with a dedicated unit type. This topic goes over the best use cases for each option.

 More Information

 If you have a property that leases only non-residential or commercial units, such as a storage facility, it is recommended that you add them as basic unit types so they are appropriately tracked on occupancy reports for that property.

 Option 1: Asset

 If you offer physical objects that can be rented to tenants, such as washers, dryers, and kitchen appliances, you can create them as assets. This allows you to track warranty information, manufacturing dates, the location of the asset, its status history for any repairs or orders, and the rate that its value depreciates. For more information, refer to Add an Asset .

 If you manage manufactured housing properties, you can also use assets to represent the homes occupying lots of land. Home-type assets allow you to enter the square footage of a home, along with the number of bedrooms and bathrooms. It also utilizes the site classification tool, allowing you to monitor the site's legal owner, whether the site can be rented, the occupancy status, and the type of asset(s) and/or resident-owned RV present at that site. For more information, refer to Set Up Manufactured Homes as Assets .

 Option 2: Other Rentable Item (ORI) Unit Type

 If you offer secondary locations that can be rented to tenants but should not impact occupancy reports, such as storage lockers or parking spots, you can create an other rentable item (ORI) unit type and add those locations as units. This allows you to monitor all financial activity, utilize unit-based reporting, and track any assets located at the location.

 The following reports can be used to monitor ORI units:

 Report
 Description

 ORI Lease Expiration

 This report displays leasing information for tenants who have leases expiring at units with a Unit Type marked as Other Rentable Item (ORI) in a chosen month during a selected date range, and whether those leases are renewed.

 For more information, refer to ORI Lease Expiration (Report) .

 ORI Move In/Move Out

 This report displays tenant move in and move out data for units with a unit type marked as Other Rentable Item (ORI) at the specified properties over a date range. This report helps you verify the number of tenants renting ORI units, such as storage units and garages, at your properties.

 For more information, refer to ORI Move In/Move Out (Report) .

 ORI Vacancy

 This report displays the active but vacant units with a unit type marked as Other Rentable Item (ORI) of selected properties as of the specified date. This report provides general information about vacant ORI units such as storage units and garages, including how long the units have been vacant and the market rent values of each unit. You may also filter the report to only show vacant units with specific amenities.

 For more information, refer to ORI Vacancy (Report) .
