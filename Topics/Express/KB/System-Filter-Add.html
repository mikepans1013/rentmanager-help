Add a System Filter

System filters are custom search criteria that you save and reuse to make searching Rent Manager easier. For example, if you manage multiple properties, you can create a tenant-type system filter that displays only those tenants with leases at one specific property. You can add a system filter from the System Filters page, which displays all system filters of all types. Or you can create system filters from the listing page for various Rent Manager entities.

Related Privileges

Group Privilege Column
Setup Manage system filters Add, View

For more information, refer to Control User Access.

More Information

This topic refers to basic filters. If the basic filtering does not meet your needs, you can create an advanced filter which allows you to group your filters for more granular, precise filtering criteria. For more information, refer to Create an Advanced Filter.

Option 1: System Filter Page

To add a system filter from the System Filters page, do the following:

  1. Go to arrow_forward Rental Info arrow_forward General arrow_forward System Filters.
    The System Filters page displays.

  2. Click Add System Filter.
    The Add System Filter pop-up displays.

  3. Select a Filter Type from the drop-down and click Continue.
    The System Filter pop-up for the selected entity type displays.

  4. Enter a unique Name for your filter and a brief Description that provides more context to the filter's purpose.

  5. Click Add Users.
    The Assign Users pop-up displays.

  6. Select the users whom you want to have access to this filter and click Save.
    The pop-up closes.

  7. On the tiles below, use the available fields and options to create the filter.

  8. Click Save.
    The filter is added to this list and can now be selected on the related page for entities of the filter's type.

Option 2: Entity Registers

Related Privileges

You need privileges to view the register page for the entity type you are adding a filter to. For example, to add a tenant-type system filter, you need the following privileges:

Group Privilege Column
Tenants/Prospects Tenants View

For more information, refer to Control User Access.

You can also add system filters from the register page for various Rent Manager entity types, such as tenants, properties, owners, vendors, and issues. To add a system filter from an entity register page, do the following:

  1. Go to the register page for the entity type to which you want to add a system filter. For example, to add a tenant-type system filter, go to arrow_forward Rental Info arrow_forward General arrow_forward Tenants.

  2. At the top of the page, next to the Saved Filters field, click .
    The Filter Detail pop-up displays.

  3. Enter a unique Name for your filter and a brief Description that provides more context to the filter's purpose.

  4. On the tiles below, use the available fields and options to create the filter.

  5. Click Save System Filter.
    The Assign Users pop-up displays.

  6. Select the users you want to have access to this filter and click Save.
    The filter is added as a system filter and can now be selected on the related page for entities of the filter's type.
