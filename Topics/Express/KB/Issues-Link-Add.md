# Add an Issue Link

Source: https://rmxhelp.rentmanager.com/Topics/Express/KB/Issues-Link-Add.htm

Issues are commonly created to perform work for a specific entity (i.e., property, unit, or tenant). You can create links to these entities on the issue, so you can easily reference an entity's associated issues from their details page. When an issue is created, a history/note item is automatically added to each linked entity. Links can be added to recurring issues and memorized issues when the work performed is always for the same entities. For example, you could link a unit to a recurring issue for routine fire extinguisher checks or link a property to a memorized issue for landscaping tasks.

 In addition, the links can be used to invoice tenants or owners from included work orders and generate data found in the Reported Issues by Unit report, which displays the number of issues linked to tenants or units. If more than one tenant is linked to an issue, you cannot add an invoice to the issue. For more information, refer to Reported Issues by Unit (Report) .

 Add a Link to an Issue

 For more information, refer to Control User Access .

 To add an issue link to a one-time issue, do the following:

 -
 Go to arrow_forward Services arrow_forward Service Manager arrow_forward Issues and select an issue from the list.
The Issue details page displays.

 -
 In the Issue Links tile, you can link the following entity types:

 Option
 Description

 Tenants/Prospects

 To link the issue to a tenant or prospect, click Add Tenant Link .

 Select whether you want to link a Current Tenant , Past/Future Tenant , or Prospect . Then search for the account, select it, and click Add .

 Properties

 To link the issue to a property, click the drop-down arrow next to Add Tenant Link and select Add Property Link .

 Search for the property, select it, and click Add .

 Units

 To link the issue to a unit, click the drop-down arrow next to Add Tenant Link and select Add Unit Link .

 Search for the unit, select it, and click Add .

 More Information

 If the issue is related to swapping out a meter, you can also link the meter that is being swapped in the issue. To do so, on the action bar to the right, click and select Link Meter Swap .

 Select the utility you would like to swap the meter for and click Continue .

 After you select an entity to link, the issue is linked to any other associated entities. For example, if you link a tenant, the property, unit, and owner are also linked automatically.
