# Process a Lease Renewal Offer

Source: https://rmxhelp.rentmanager.com/Topics/Express/KB/Lease-Renewal-Offers-Process.htm

When you generate lease renewal offers, you can manage them by accepting, declining, or selecting new terms directly from the Lease Renewal Board page. For example, if you have sent out multiple renewal offers during a certain date range, you can use the board to process the offers for those tenants from one convenient location. New renewal offers can also be generated from this page.

 More Information

 Lease renewals are generated only for residential leases, so any leases marked as a Commercial Lease do not generate lease renewals.

 Step 1: Select a Renewal Offer Response

 When a tenant sends a response regarding their renewal offer, you can input that information in Rent Manager to process the offer. A renewal offer can be managed with several responses. Each response is described below.

 Accept Offer

 More Information

 This workflow details the manual process for accepting a renewal offer for a tenant. Tenants with Tenant Web Access (TWA) accounts can view and accept renewal offers through TWA. For more information, refer to Tenant Web Access Renewal Offers (System Web Preferences) .

 To accept a renewal offer, do the following:

 -
 Go to arrow_forward Rental Info arrow_forward Leasing arrow_forward Lease Renewal Board .
The Lease Renewal Board page displays.

 -
 Click Y arrow_forward Accept on the renewal offer you wish to accept.

 -
 In the Renewal Offer Details section, enter information in the following fields:

 Field
 Description

 Lease Term

 The lease term accepted for the renewal. This option can be changed only if the tenant was offered multiple lease terms.

 Renewal Sign Date

 The date that the tenant signed their lease renewal document.

 Renewal Start

 The date that the tenant's renewed lease begins if the offer is accepted. This date is set automatically when creating the renewal offer and cannot be changed.

 -
 In the Lease Documents section, click Upload to browse your computer for a file, or drag and drop a file into the upload box, to attach to the task. Files copied within Rent Manager Express using can be added here by selecting Paste .

 -
 To add an additional history/note item about this renewal to the tenant's account, click Add History Note and enter the following information:

 Field
 Description

 Category

 The history category used to organize this history/note item.

 File Attachments

 Any files to attach to the history/note item, such as a scan of the new lease signed by the tenant.

 Note

 Additional information about the renewal. The note displays on the History/Notes page associated with the tenant's account.

 -
 If the renewal offer is now completed, check Complete Renewal Offer

 -
 Click Accept .
The renewal offer is accepted and new recurring charges are created for the tenant according to the renewal terms.

 More Information

 If Complete Renewal Offer is selected and there is a signable document associated with the renewal that is not complete, you are prompted to sign (if a landlord signature is needed), void, or delete the document before accepting the renewal. Select one of the options, then click Continue .

 Decline Offer

 More Information

 This workflow details the manual process for declining a renewal offer for a tenant. If enabled in system web preferences, tenants with Tenant Web Access (TWA) accounts can decline renewal offers through TWA. For more information, refer to Tenant Web Access Renewal Offers (System Web Preferences) .

 To decline a renewal offer, do the following:

 -
 Go to arrow_forward Rental Info arrow_forward Leasing arrow_forward Lease Renewal Board .
The Lease Renewal Board page displays.

 -
 Click arrow_forward Decline on the renewal offer you wish to decline.

 -
 In the Notice Date field, enter the date the tenant informed the property management company that they intend to move out.

 -
 In the Expected Move Out field, enter the date on which the tenant is expected to move out of the unit based on the initial lease agreement.

 -
 If applicable, in the Move Out field, enter the date on which the tenant vacated the unit.

 -
 To add an additional history/note item about why this renewal offer was declined to the tenant's account, click Add History Note and enter the following information:

 Field
 Description

 Category

 The history category used to organize this history/note item.

 File Attachments

 Any files to attach to the history/note item, such as a scan of the new lease signed by the tenant.

 Note

 Additional information about the renewal. The note displays on the History/Notes pop-up associated with the tenant's account.

 -
 If the renewal offer is now completed, check Complete Renewal Offer and click Decline .
The renewal offer is declined and is removed from the Lease Renewal Board .

 Set Renewal Offer to Month to Month

 When you offer a tenant renewal terms but the tenant does not want to renew their lease with the proposed terms, you can give them the option to renew with a month-to-month (MTM) term. In this case, you can change the lease term and modify the recurring charges for a renewal that has a Offer Sent status. The current renewal is set as Offer Declined and a lease renewal is created with MTM terms on the tenant's account.

 To set a renewal offer to month to month terms, do the following:

 -
 Go to arrow_forward Rental Info arrow_forward Leasing arrow_forward Lease Renewal Board .
The Lease Renewal Board page displays.

 -
 Click arrow_forward Set MTM on the renewal offer you wish to set to month-to-month.

 -
 In the Recurring Charges section, click Add Recurring Charge to add new recurring charge or delete existing charges based on the MTM lease terms.

 -
 In the One-Time Charges section, click Add One-Time Charge to add new one-time charges to be posted to the tenant's account once the lease renewal is accepted.

 -
 To finalize the offer in Rent Manager , check Complete Renewal Offer and click Create MTM Lease .
The current renewal is set as Offer Declined and a lease renewal is created with MTM terms on the tenant's account.

 Void Offer

 In the event that a renewal offer is no longer relevant the tenant, Rent Manager allows you to void them from the Lease Renewal Board .

 To void a renewal offer, click arrow_forward Void on the renewal offer you wish to void. For more information, refer to Void a Lease Renewal Offer .

 Delete Offer

 If a renewal offer was created in error, Rent Manager allows you to delete them directly from the Lease Renewal Board . This action is permanent and cannot be undone.

 To delete a lease renewal offer, click arrow_forward Delete on the renewal offer you wish to delete. For more information, refer to Delete a Lease Renewal Offer .

 Step 2: Complete Renewal Offer

 If a renewal offer has already been responded to but has not yet been completed, it remains open on the Lease Renewal Board . Marking the offer as complete finalizes the offer and clears it from the page.

 To complete a renewal offer from the Lease Renewal Board , do the following:

 -
 Go to arrow_forward Rental Info arrow_forward Leasing arrow_forward Lease Renewal Board .
The Lease Renewal Board page displays.

 -
 In the Needs Finalized column, click arrow_forward Complete on the offer you wish to complete.
The Confirm Complete Renewal Offer pop-up displays.

 More Information

 If there is a signable document associated with the renewal that is not complete, you are prompted to sign (if a landlord signature is needed), void, or delete the document before accepting the renewal. Select one of the options, then click Continue .

 -
 Click Yes to complete the renewal offer.
The pop-up closes and the completed offer is removed from the Lease Renewal Board .
