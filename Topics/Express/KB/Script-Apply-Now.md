# Apply Now Scripts

Source: https://rmxhelp.rentmanager.com/Topics/Express/KB/Script-Apply-Now.htm

Apply Now scripting functions are used when customizing the Apply Now verification email, found in system web preferences. These functions return data based on information in applications submitted through Apply Now . The Apply Now functions allow for a more detailed verification email to be sent to the applicant.

 To use these functions in your Apply Now verification emails, go to arrow_forward Administration , then go to Preferences arrow_forward System Web Preferences arrow_forward Tenant Web Access arrow_forward Apply Now arrow_forward General arrow_forward Apply Now Verification Email arrow_forward Customize Apply Now Verification Email .

 Available Functions

 Update the email body fields to include the desired Apply Now script functions from the table below.

 Function
 Description

 Applicant Email Address

 [ApplicantEmailAddress]

 Displays the applicant's email address.

 More Information

 If the applicant signs up for Apply Now through Tenant Web Access , this function displays the email address entered when creating the user account.

 If the applicant has an existing prospect account and the application was emailed through the prospect account, this function displays the To email address in the composed email.

 Applicant First Name

 [ApplicantFirstName]

 Displays the first name of the applicant.

 More Information

 If the applicant signs up for Apply Now through Tenant Web Access , this function displays the first name entered when creating the user account.

 If the applicant has an existing prospect account and the application was emailed through the prospect account, this function displays the First Name entered on the prospect account.

 Applicant Last Name

 [ApplicantLastName]

 Displays the last name of the applicant.

 More Information

 If the applicant signs up for Apply Now through Tenant Web Access , this function displays the last name entered when creating the user account.

 If the applicant has an existing prospect account and the application was emailed through the prospect account, this function displays the Last Name entered on the prospect account.

 Property Email Address

 [PropertyEmailAddress]

 Displays the Email Address on the General section of the property to which the applicant applied.

 Property Management Company

 [PropertyManagementCompany]

 Displays the Full Name on the General section of the management company property. For more information, refer to Management Company (System Preferences) .

 Property Management Company Email Address

 [PropertyManagementCompanyEmailAddress]

 Displays the Email Address on the General section of the management company property. For more information, refer to Management Company (System Preferences) .

 Property Manager

 [PropertyManager]

 Displays the name of the Manager on the General section of the property to which the applicant applied.

 Property Name

 [PropertyName]

 Displays the Full Name on the General section of the property to which the applicant applied.
