# Automated Notifications for Prospects and Applications

Source: https://rmxhelp.rentmanager.com/Topics/Express/KB/LP-AN-Prospects-Applications.htm

Automated notifications allow you to send alerts to a customizable list of recipients when a certain set of conditions are met to help streamline your workflows and processes. These notifications can be customized using plain text and scripting for personalized text and/or email messages.

 There are many options for automated notifications regarding prospects to inform you of updates, submissions, and verifications for applications. These notifications are described in the table below.

 Attention

 Ensure the table is the full and current list of automated notifications related to prospects and applications.

 Notification
 Description

 Application Started, Not Completed

 Informs users (e.g., property managers) or applicants after a prospect begins an Apply Now application or sub-application, but has not yet submitted it.

 Application Submitted

 Informs users (e.g., property managers), applicants, or owners after a prospect submits an Apply Now application.

 Income Verification Report Received

 Informs users or external recipients when the income verification process is completed by AmRent for a tenant or prospect.

 Prospect Guest Card Submitted

 Informs users, prospects, or external recipients after a prospect submits a guest card.

 Prospect Not Contacted

 Informs users or external recipients as the length of time since a prospect was last contacted increases. The last contact date is determined by the call, email, or visit history/note item on the account with the most recent Start Date .

 Related Preferences

 Call history/note items must have Spoke with prospect checked, and/or the system preference to Always update Last Contact Date when a call note is added enabled, to be considered when determining last contact date. For more information, refer to Prospect (System Preferences) .

 Prospect Signable Document Aging

 Informs prospects when a signable document has been waiting on their signature for a set amount of time.

 Prospect Stage Changed

 Informs prospects when a stage change occurred. This can be used to inform prospects of where they are in the process of becoming a tenant. Additionally, you can configure this notification to notify users (e.g., property managers) about stage changes that need their attention.

 Rent Quote Expiring

 Informs users—such as property managers or leasing agents—when a prospect's rent quote is a certain number of days away from its expiration date.
