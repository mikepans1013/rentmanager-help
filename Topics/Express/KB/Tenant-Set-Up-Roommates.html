Set Up Roommates

Whether you work with student housing or residential properties, roommates are a common occurrence. When deciding how to manage roommates and their leases, Rent Manager provides two options for your use.

For the first option, if you wish to assign one lease for the entire unit regardless of however many roommates live there, you can create a primary tenant account and list any additional roommates as contacts on the account.

For option two, you can allow multiple tenant accounts to be assigned to the same unit, where each tenant account is designated as Primary, listed independently, and has its own tenant account number and tenant-level charges and transactions.

Option 1: Add a Roommate as a Contact

This option is recommended if you wish to have one lease for all roommates. With this course of action, you assign one lease for the entire unit regardless of however many roommates live there. One tenant is listed as the primary tenant, and all other roommates are listed as contacts on this account. Roommates can still have individual Tenant Web Access (TWA) login and payment information if this option is chosen, but share the same TWA account.

Typically, the primary tenant is the primary signer on the lease and/or the tenant you wish to communicate with in regards to service issues, statements, requests, and so on.

Related Privileges

Group Privilege Column
Tenants/Prospects Tenants View, Edit

For more information, refer to Control User Access.

To add a roommate as a contact, do the following:

  1. Go to arrow_forward Rental Info arrow_forward General arrow_forward Tenants and select a tenant.
    The Tenant details page displays.

  2. On the Contacts tile, click Add Contact.
    The Add Contact pop-up displays with a New Contact tab on the left.

  3. If this is the primary contact for this tenant, check Primary.

    More Information

    One contact must be designated as Primary on each tenant's account. Additionally, only one contact can be designated as Primary on a tenant's account. When you add a tenant, the first contact on the account is always the tenant, so by default, the tenant is considered the Primary contact.

  4. Check Show On Statement/Labels to display this contact's name on statements and printed labels.

    More Information

    Only two contacts may have Show On Statement/Labels checked on each tenant account. The first contact on the account is always the tenant, so by default, the tenant has Show On Statement/Labels checked.

  5. Click on the image to add an image of the contact from your computer or network.

  6. Enter any of the fields in the Personal Information section for the contact.

    Field Description

    Annual Income

    The contact's annual net income.

    Related Privileges

    Group Privilege Column
    Tenants/Prospects View annual income Enabled

    For more information, refer to Control User Access.

    Applicant Type

    The type of applicant that best describes the contact.

    Birthday

    The contact's date of birth.

    Email

    The contact's primary email address in which they can be sent reports, statements, and so on.

    Employer

    The name of the contact's employer.

    First Name

    The contact's first name.

    Last Name

    The contact's last name.

    License

    The license plate number of the contact's vehicle.

    Middle Name

    The contact's middle name.

    Soc Sec#/

    Tax ID

    The contact's social security number. For commercial tenants, the field name of Tax ID displays, and the contact's tax identification number (TIN) should be entered.

    Related Privileges

    Group Privilege Column
    Tenants/Prospects View complete tenant SSNs Enabled

    For more information, refer to Control User Access.

    Type

    The contact type that best describes the contact. For more information, refer to Contact Types (Page).

    Vehicle

    The make and model of the contact's vehicle.

  7. In the Addresses section, select an address type from the drop-down menu and enter the address into the field.

  8. In the User Defined Fields section, enter a Value for any tenant contact-type user-defined fields.

  9. In the Phone Numbers section, enter phone numbers (including area code) and extensions associated with phone number types such as Home, Work, Cell, etc. and check Default next to the number that should be used as the primary contact for this account.
    If a phone number can be used for text messaging, check the box in the T column.

  10. Click Save.
    The contact is added to the tenant account.

Option 2: Add a Roommate as a New Tenant

This option is recommended if you wish to have multiple tenants occupying the same unit, but each tenant has their own Rent Manager account record.

Before you can have multiple tenants occupying a unit at the same time so they can keep their individual accounts but be moved into the same unit, you must enable the general system preference Allow multiple tenants to occupy the same unit (roommates).

Related Privileges

Group Privilege Column
System System Preferences View, Edit

For more information, refer to Control User Access.

To enable this system preference, go to arrow_forward Administration, then go to Preferences arrow_forward System Preferences. In the General Options section, select General. For more information, refer to General Options (System Preferences).

Once the system preference has been enabled, you can create a new tenant account through the Add Tenant wizard, and Rent Manager allows you to enter the unit information of the tenant you wish to move them in with.

Related Privileges

Group Privilege Column
Tenants/Prospects Tenants Add, View

For more information, refer to Control User Access.

To open the Add Tenant wizard, go to arrow_forward Rental Info arrow_forward General arrow_forward Tenants and click Add Tenant. For more information, refer to Add a Tenant.

Create an Account Group

Account groups allow you to group together two or more tenant accounts for transactional and reporting purposes, while maintaining individual account records for each tenant. Each account group has a tenant account that serves as the master account while the other tenants in the group are considered subaccounts. With this course of action and the Allow tenant to see amount due for account group and automatically apply payments to the entire group enabled in system web preferences, anyone in an account group can pay for themselves, and if they choose, for their roommates in Tenant Web Access. For more information, refer to Tenant Web Access Financial (System Web Preferences).

More Information

If you are using Tenant Web Access (TWA), the master account of the group can set up AutoPay only to pay their account's balance, but can make manual payments to the balances of any other members of the group. To set up automatic payments for non-master accounts in the group, each member must create a TWA account and set up AutoPay on their account.

To create an account group, do the following:

  1. Go to arrow_forward Rental Info arrow_forward General arrow_forward Tenants.
    The Tenants page displays.

  2. For the tenant you wish to place in an account group, click arrow_forward Add To Account Groups.
    The Add Account Group pop-up displays.

  3. Select one of the following options depending on the action you wish to take:

    Option Description

    Add the selected account to an existing account group

    Check to add the selected tenant to an existing account as a subaccount. From the drop-down list, select an existing account group.

    Use current account as the master account

    Check to create a new account group, using the selected tenant Account Name to serve as the master account.

  4. Click Save.
    The tenant is added to the new or designated account group and the tenant's account includes additional fields related to their account group.
