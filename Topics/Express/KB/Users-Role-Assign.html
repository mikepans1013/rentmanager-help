Assign Users to a User Role

User roles allow you to assign a specific set of user, report, and letter privileges to one or more users. This makes it easy to create privilege sets that provide the basic functions for a specific role and then be able to quickly apply it to user accounts where appropriate. Privileges assigned this way cannot be unchecked on the user account, ensuring that the basic privileges that user needs to fulfill their duties cannot be removed on accident. For example, creating a user role that gives manager privileges to update other user accounts and perform other administrative actions in Rent Manager and assigning that role to managers can prevent these users from being accidentally locked out of the necessary functions needed to complete their work.

Related Privileges

Group Privilege Column
System Manage all users and privileges View, Edit

For more information, refer to Control User Access.

You can assign a user role in one of two ways. You can either assign a user role while viewing a user account or assign multiple user accounts at once while viewing a user role.

Assign a User to a User Role

Assigning the role directly on the user account is helpful when adding a new user account and assigning a preexisting user role.

To assign a user to a user role, do the following:

  1. Go to arrow_forward Administration arrow_forward Users arrow_forward Users and select a user from the list.
    The user's details page displays.

  2. On the Roles tile, click .
    The User Roles pop-up displays.

  3. Click Add.
    The Add Roles pop-up displays.

  4. Select the role(s) you want to assign the user to and click Save.

  5. On the User Roles pop-up, click Save.
    The user is assigned to the role(s) selected.

Assign Multiple Users to a User Role

Assigning users directly to the user role can be beneficial when you create a new user role, or have a user role that is being reinstated, and it needs to be assigned to multiple user accounts.

To assign multiple users to a user role, do the following:

  1. Go to  arrow_forward  Administration arrow_forward Users arrow_forward User Roles.
    The User Role page displays.

  2. Select a role on the left and on the Users tile, click .
    The Add Users pop-up displays.

  3. Select the user accounts you want to assign to the user role and click Save.

  4. On the User Role page, click Save.
    The users are assigned to the role.
