# Customize Prospect Options

Source: https://rmxhelp.rentmanager.com/Topics/Express/KB/Prospect-Customize-Options.htm

When you create or edit a prospect in Rent Manager , you can enter values into prospect-type user-defined fields (UDFs), select lead sources, and establish prospect stages. Although you can complete the Add Prospect wizard without this information, setting up these tools before adding your prospect helps streamline the prospect creation process.

 User-defined fields (UDFs) are custom fields you create to track data that Rent Manager does not track by default. Prospect-type UDFs are used specifically to track additional information on prospect accounts. For more information on creating prospect-type UDFs, refer to Add a User Defined Field .

 Creating prospect lead sources allows you to manage the different ways a prospect could learn about your available units. Tracking these sources can be beneficial for certain prospecting reports (e.g., Prospect Box Score ) that assess the marketing strategies you have employed. For more information, refer to Prospect Lead Sources (Page) .
