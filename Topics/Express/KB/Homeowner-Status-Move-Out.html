Homeowner Statuses Available on Move Out

Depending on the active current homeowner status for a home-type asset, the ability to set a new status in the Homeowner Status field may or may not be available when performing tenant move outs using the Move Out wizard.

The following table lists whether the Homeowner Status field can be set manually during this process, based on the status the home-type asset has at the time the move out process is performed:

Current Status Homeowner Status Field Default and Available Options

Abandoned (Community Owned, Dealer Owned, etc.)

Enabled

Set to the active version of the status, with the following options available from the drop-down list:

  • Current (active) abandoned status

  • Change of Ownership

Change of Ownership

Disabled

Always set to Change of Ownership.

Community Owned

Enabled

Set to Community Owned by default, with the following options available from the drop-down list if the home-type asset lease is only being move out and the tenant has a current lease for the unit the home is currently located on:

  • Community Owned

  • Resident Owned

  • Employee Owned

  • Change of Ownership

  • Abandoned - Community Owned

For all other conditions:

  • Community Owned

  • Change of Ownership

  • Abandoned - Community Owned

Community Owned - Employee

Enabled

Set to Community Owned by default, with the following options available from the drop-down list if the home-type asset lease is only being move out and the tenant has a current lease for the unit the home is currently located on:

  • Community Owned

  • Resident Owned

  • Employee Owned

  • Change of Ownership

  • Abandoned - Community Owned

For all other conditions:

  • Community Owned

  • Change of Ownership

  • Abandoned - Community Owned

Community Owned - Lease to Own

Enabled

Set to Community Owned by default, with the following options available from the drop-down list if the home-type asset lease is only being move out and the tenant has a current lease for the unit the home is currently located on:

  • Community Owned

  • Resident Owned

  • Employee Owned

  • Change of Ownership

  • Abandoned - Community Owned

For all other conditions:

  • Community Owned

  • Change of Ownership

  • Abandoned - Community Owned

Dealer Owned

Enabled

Set to Change of Ownership by default, with the following options available from the drop-down list:

  • Change of Ownership

  • Abandoned - Dealer Owned

Employee Owned

Enabled

Set to Change of Ownership by default, with the following options available from the drop-down list:

  • Change of Ownership

  • Abandoned - Employee Owned

Lender Owned

Enabled

Set to Change of Ownership by default, with the following options available from the drop-down list:

  • Change of Ownership

  • Abandoned - Lender Owned

No homeowner status set

Enabled

Set to blank by default, with the following options available from the drop-down list:

  • Blank (no status)

  • Change of Ownership

  • Community Owned

  • Abandoned - Community Owned

If there is not a current or future lease on the home-type asset, the following additional options are available:

  • Blank (no status)

  • Change of Ownership

  • Community Owned

  • Abandoned - Resident Owned

  • Abandoned - Employee Owned

  • Abandoned - Community Owned

  • Abandoned - Lender Owned

  • Abandoned - Dealer Owned

Resident Owned

Enabled

Set to Change of Ownership by default, with the following options available from the drop-down list:

  • Change of Ownership

  • Abandoned - Resident Owned
