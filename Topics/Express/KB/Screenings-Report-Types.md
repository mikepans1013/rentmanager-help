# Types of Screening Reports

Source: https://rmxhelp.rentmanager.com/Topics/Express/KB/Screenings-Report-Types.htm

The screening results that you receive are generated based on the types of reports that you have contracted with AmRent , the credit bureau databases selected, report options you define at a system and/or property level, and the number of people you want screened within a screening request. You can check the selected available vendors in system preferences. For more information, refer to Screening Settings (System Preferences) .

 Each screening request that you submit may screen for more than one person, up to a maximum of five people, and produce more than one type of screening report.

 More Information

 If you screen your applicants, it's important to know the federal laws and regulations surrounding this process. For example, you must obtain signed authorization from each applicant to collect their consumer information. You can easily do this with Apply Now applications by setting up templates that include sub-applications. These allow you to collect the required signatures from each applicant, and offers the ability to select additional screening preferences and application fees for the co-applicant(s). For more information, refer to Apply Now Applications .

 Report Formats

 The following report formats determine how much information is displayed are available:

 Format
 Description

 Workflow Solution Report

 Evaluates the returned data (credit, criminal, rental record, and/or eviction information) and displays a Workflow Solution (such as Conditional or Approved ), based on the criteria you have set up with AmRent .

 The types of workflow solution reports available:

 Workflow Solution Only Report

 Includes only the Workflow Solution .

 Workflow Solution Report with Factors

 Includes the Workflow Solution and adverse Factors (such as payments due on accounts, number of accounts with delinquency, limited credit experience, and/or too few bank revolving accounts) associated with the workflow solution.

 Full Workflow Solution Report

 Includes details from all repositories, public sources, and credit bureau databases.

 Non-Workflow Solution Report

 Searches the selected credit bureau database(s) and returns the contracted information (credit, criminal, rental record, and/or eviction information) without formulating a Workflow Solution .

 Credit Report Types

 A credit report may be generated as one of the following types:

 Report
 Description

 Individual

 The report contains the information of a single applicant.

 Joint

 One report with the information of two applicants combined. This type is produced when two applicants are submitted and at least one of them has, on the View Contacts pop-up, the Applicant Type of Spouse .

 Multi-Individual

 Two or more individual reports separated within one PDF file. Information is not combined. If there are three or more applicants, the results are always multi-individual reports.

 Specialized Reports

 The following reports must be contracted with AmRent to be used. Each report searches a specific data source and provides the related findings, and can be accessed only by the users selected in system preferences:

 Option
 Description

 Bundled Screening

 Returns credit, criminal, rental record, and eviction information. If you have not contracted any additional specialized reports with AmRent , this is the only option that displays in system preferences. For more information, refer to Screening Settings (System Preferences) .

 Collection Credit Report

 Return collection credit data without formulating a Workflow Solution .

 Commercial Screening

 Returns contracted credit, criminal, rental record, and eviction information for commercial properties.

 Credit Only

 Returns credit data without formulating a Workflow Solution .

 Criminal Only

 Returns criminal data (beyond criminal records from credit reports) without formulating a Workflow Solution .

 Workflow Solutions, Credit Only

 Returns credit data and displays a Workflow Solution to approve or decline an application based on the criteria you have set up with AmRent . This is typically run for a guarantor not residing in the property.

 Workflow Solutions, Criminal Only

 Returns criminal data (beyond criminal records from credit reports) and displays a Workflow Solution to approve or decline an application based on the criteria you have set up with AmRent .
