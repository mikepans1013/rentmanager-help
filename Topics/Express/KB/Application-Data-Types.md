# Application Field Data Types

Source: https://rmxhelp.rentmanager.com/Topics/Express/KB/Application-Data-Types.htm

When adding a field to an application template, there are multiple options available in the Data Type drop-down list. This selection determines the kind of value an applicant can enter or select in the field. After selecting a data type, the Options tile may update to allow for further customization of the field. Marking a field as required and setting the alignment and column span of each field is available for all data types.

 More Information

 If a Rent Manager field or user-defined field (UDF) is selected in the Match To drop-down list, the Data Type field automatically uses the option that corresponds to the Match To field and cannot be edited.

 Each data type and its related fields are described below.

 Data Type
 Description

 Date

 Allows the recipient to enter a date in mm/dd/yyyy format or select a date from a drop-down calendar. Additionally, you can use the Minimum Date and Maximum Date fields to restrict the earliest and latest date an applicant can enter, respectively.

 Dropdown

 Allows the recipient to select a single option from a drop-down list of options you establish. To determine what options are available for the recipient to select, in the Dropdown Options field, type an option, then click to add it to the list.

 Optionally, to add an option where the recipient can submit their own custom response, check Allow users to enter another choice .

 Email

 Allows the recipient to enter an email address and requires that the entry includes the period ( . ) and @ characters.

 File

 Allows the recipient to attach a file, such as a document or PDF.

 Image

 Allows the recipient to attach an image file, such as a JPG or PNG.

 Lead Source Dropdown

 Allows the recipient to select one of your lead sources from a drop-down list. In the Lead Source column, check each lead source to be available for the applicant to select from. For more information, refer to Prospect Lead Sources (Page) .

 Multi Line Text

 Allows the recipient to enter a longer text response. This is recommended for fields that may require a few sentences in response because it can provide a larger text box for the recipient to write in.

 The following options allow you to further limit what the recipient can enter in the field:

 Minimum Length

 The minimum number of characters that must be entered before the application can be submitted.

 Maximum Length

 The maximum number of character that can be entered into the field.

 Number of Lines

 The height of the text box to display on the application. For example, if you enter 2 , the text box displays two lines tall. The recipient can still type more than two lines as long as it is within the character limit.

 Numeric

 Allows the recipient to enter only numbers into the field. Letters and symbols are not accepted. Additionally, you can use the Minimum Value and Maximum Value fields to limit the lowest and highest number an applicant can enter, respectively.

 Pet Type Dropdown

 Allows the recipient to select one of your pet types from a drop-down list. The options available for the recipient to select are determined by your pet types in Rent Manager . For more information, refer to Pet Types (Page) .

 Phone Number

 Allows the recipient to enter only a ten-digit numeric value. The field formats the numbers into a standard phone number format (e.g., (555) 555-5555 ).

 Property

 The field displays the name of the property linked to the application, such as the property the applicant is applying to or the property management company who manages applications. This data type is used for informational purposes only and the recipient cannot edit the selection in the field.

 SSN

 Allows the recipient to enter only a nine-digit numeric value for their social security number (SSN). The field will format the numbers into a social security number format such as 123-45-6789 .

 State

 Allows the recipient to select a state in the United States (including Puerto Rico) or a province in Canada from a drop-down list.

 Text

 Allows the recipient to enter a plain text response. Additionally, you can use the Minimum Length and Maximum Length fields to set the highest and lowest number of characters an applicant can enter, respectively.

 Unit/Unit Type

 This field displays the name of the unit or unit type linked to this application, such as the option selected by the applicant or assigned to them by a user. This data type is used for informational purposes only and the recipient cannot edit the selection in the field.

 Yes/No

 By default, this displays as the field label with a checkbox next to it on the application. If the recipient checks the box, this indicates Yes or True . For example, if the Label is named Do you have pets? , the recipient would check the box to indicate that they do have pets.

 If the option Display as Dropdown is checked, this field allows the recipient to select either a Yes or No answer from a drop-down list. You can customize how these options display to the recipient in the Yes Display Text and No Display Text fields, such as setting them to True and False respectively.

 More Information

 Fields with this data type can be selected as a Dependent Field on the Information tile for other fields. This means that the field cannot be edited by the recipient unless the Yes equivalent option is selected for the dependent field.
