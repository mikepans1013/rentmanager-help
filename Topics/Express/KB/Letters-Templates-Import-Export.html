Import and Export Letter Templates

Letter templates are customized letters that combine static text and graphics with dynamic scripting commands. These commands allow you to generate customized content for each letter recipient, saving you time in the creation and delivery of letters.

If you have any letters created and stored on your local computer or network, you can also upload them to use in Rent Manager. Letter templates can also be uploaded from the online template library (OTL), which is an ever-expanding collection of templates submitted by both Rent Manager users and LCS staff. You can also download letter templates to keep a backup copy, share them with a coworker, move them to a different Rent Manager location, or even export it to the online template library to share with other companies that use Rent Manager.

Related Privileges

Group Privilege Column
Letter/Email Templates/Reports/Packets Letter/Email templates/packets View, Edit

Entity-specific templates/packets privileges must be enabled for each letter template type you wish to import (e.g., Owner templates/packets).

For more information, refer to Control Letter / Email Template Access.

Import a Letter Template

Importing a letter template allows you and other users to generate and distribute those letters, as long as they have the privileges to do so. You can import a letter template that is currently saved on your local network or computer, or you can download one from the online template library.

More Information

To generate an imported letter template from the letter menu or from directly from a tenant menu, you first need to enable the letter template for those menus. For more information, refer to Letter/Email Template Settings (Pop-Up).

From Online Template Library

To import a letter template from the OTL into Rent Manager, do the following:

  1. Go to arrow_forward Administration, then select Customization arrow_forward Online Template Library.
    The Online Template Library page displays.

  2. In the Category field, select Letter Templates.

  3. To display only letter templates that have been created by London Computer Systems, Inc., check LCS Templates Only.

  4. Navigate the folders and select the letter template you wish to import.

  5. Review the preview and description to verify if the letter suits your needs.

  6. Click I Download.
    The Disclaimer pop-up displays.

  7. Read the disclaimer, then click Accept.

  8. On the confirmation pop-up, click OK.
    The letter template is now available on the Letter/Email Templates page.

From File

To import a letter template from your local network or computer, do the following:

  1. Go to arrow_forward Communication arrow_forward Letters arrow_forward Letter Templates.
    The Letter/Email Templates page displays.

  2. At the top, click Import.

  3. On your network or computer, select the letter template file you wish to upload to Rent Manager. Letters in file formats (RMD, RMT, .RMTX), Microsoft Word formats (DOC, DOCX), rich text (RTF), and ASCII text (TXT) can be uploaded for use as a letter template.

  4. Click Open.
    The Select Template Type pop-up displays.

  5. In the Type field, select which entity this letter template can be generated for. For example, if you are importing a letter template that is intended to be sent to tenants, select Tenant.

  6. Click OK.
    The letter template is now available on the Letter/Email Templates page.

Export a Letter Template

Letter templates can be exported as a local file or they can be shared publicly via the online template library. Letter templates are exported as a Rent Manager template (RMTX) file type. Exported letter templates can be imported to Rent Manager only and cannot be imported to other softwares.

To Online Template Library

To upload a letter template to the OTL, do the following:

  1. Go to arrow_forward Communication arrow_forward Letters arrow_forward Letter Templates.
    The Letter/Email Templates page displays.

  2. For the template you wish to export, click arrow_forward Export to Online Template Library.
    The Disclaimer pop-up displays.

  3. Read the disclaimer and, if you wish to continue, click Accept.
    The template will be reviewed by London Computer Systems, Inc.. If accepted, it will be available on the OTL in the future.

To File

To export a letter template to your local network or computer, do the following:

  1. Go to arrow_forward Communication arrow_forward Letters arrow_forward Letter Templates.
    The Letter Templates page displays.

  2. For the template you wish to export, click arrow_forward Export to File.
    The Export Letter Template pop-up displays.

  3. In the File Name field, enter a name to easily identify the file on your computer.

  4. Click Save.
    The letter is saved to your downloads folder as an RMTX file.
