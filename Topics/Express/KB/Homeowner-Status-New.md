# Homeowner Statuses Available on Move In

Source: https://rmxhelp.rentmanager.com/Topics/Express/KB/Homeowner-Status-New.htm

Depending on the active current homeowner status for a home-type asset, the ability to set a new status in the Homeowner Status field may or may not be available when adding a new tenant, moving a tenant in, creating a new lease for a unit with a home-type asset, or performing tenant transfers using the Transfer a Tenant wizard.

 The following table lists whether the Homeowner Status field can be set manually during those processes, based on the status the home-type asset has at the time the process is performed:
