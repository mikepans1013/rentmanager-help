Add and Assign Phone Number Types

Phone number types let you create and manage your own categories for phone numbers. This makes it easy to record and reference multiple numbers on the same entity. Additionally, this adds the ability to pull a specific phone number type into other parts of Rent Manager, such as reports and features that use scripting. Once you define a phone number type for a specific entity type, you can go to any account for that entity type to enter the associated number.

To add a new phone number type, do the following:

  1. Go to arrow_forward Administration, then go to Customization arrow_forward Phone Number Types.

  2. On the left, select the entity type you want to add a new phone number type to.

  3. Click Add Phone Number Type.

  4. Enter a Name and Description for the phone number type.

  5. Click Save.
    The phone number type is added to the list under the corresponding entity type and can now be assigned phone numbers.

Assign Phone Numbers to Types

To assign phone numbers using phone number types, do the following:

  1. Go to the details page for the entity you want to add a phone number to.

    Entity Type

    		 Location

    Owner

    arrow_forward Owners arrow_forward General arrow_forward Owners and select an owner from the list

    Property

    arrow_forward Rental Info arrow_forward General arrow_forward Properties and select a property from the list

    Prospect

    arrow_forward Rental Info arrow_forward General arrow_forward Prospect and select a prospect from the list, then click in the Contacts tile

    Tenant

    arrow_forward Rental Info arrow_forward General arrow_forward Tenants and select a tenant from the list, then click in the Contacts tile

    Vendor

    arrow_forward Payables arrow_forward General arrow_forward Vendors and select a vendor from the list

  2. In the Phone Numbers tile or View Contacts pop-up, all phone number types available for the entity display. Enter the phone number in the Number or Phone Number field that corresponds with the appropriate phone number type.

    The phone number is assigned to the type and can now be used.
