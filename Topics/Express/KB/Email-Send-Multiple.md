# Send Email to Multiple Recipients

Source: https://rmxhelp.rentmanager.com/Topics/Express/KB/Email-Send-Multiple.htm

Rent Manager allows you to compose and send emails directly to contacts selected from your Rent Manager database, such as when you need to send a mass email notification about community events. Additionally, you can select a specific group or filter the people you are contacting so that you can send the email to only your target audience. Emails sent this way are automatically sent individually and do not include the email address for any other recipients.

 Step 1: Filter Recipients

 Often, mass emails are intended for specific recipients, so a key part of sending a mass email is being able to quickly filter your recipients and ensure you're including everyone that needs to receive the email. In Rent Manager , mass emails can be sent to various entities such as tenants, owners, or prospects.

 You can use letter/email templates that contain scripts to dynamically change the content of your message and keep your messages personalized to each recipient. For more information, refer to Add a Letter Template .

 To filter your recipients, do the following:

 -
 Navigate to the entity list you wish to send the email batch to (such as tenants, owners, or prospects). For example, if you are sending an email to multiple tenants, go to arrow_forward Rental Info arrow_forward General arrow_forward Tenants .
The Tenants page displays.

 -
 Next to the Saved Filters field, click .
The Filter Detail pop-up displays.

 -
 Enter any fields you want to use for filtering the list of tenants. For example, you may filter by a specific Property or newer tenants using Move In . For more information on the available filters for tenants, refer to Tenant Filters (Pop-Up) .

 -
 Click Apply . If you plan to use this filter more than once, enter a Name and select Save and Apply . The filter can then be quickly selected from the tenants list in the Saved Filters field.
The Filter Detail pop-up closes and the filter criteria is applied to the Tenants page.

 Step 2: Send the Email

 Once you have a filtered list, you can use Bulk Actions to select the recipients of your correspondence from the list. This allows you to fine tune the recipients even further where necessary. Otherwise, you can select all the recipients in your newly filtered list to include them all in your correspondence. You can compose a brand new email or pull in an email template for the body of the email that uses scripting to make each email unique to the recipient.

 More Information

 If you want to send a letter template as an attachment on an email to multiple recipients, instead select Bulk Actions arrow_forward Write Letters. For more information, refer to Generate and Distribute Letters from Templates .

 Field
 Description

 From Address

 The email address from which the message is sent that displays for the recipient. A default value can be set for all users in system preferences or on an individual basis in personal preferences.

 Related Preferences

 In system preferences, if the Default (mail.rentmanager.com) mail server is selected, all emails send from email@rentmanager.com . When the email is sent, it displays the entered From Address to recipient(s) and reroutes replies to that email address.

 If you have established settings for an External Server in system preferences, emails send from the address entered in this field. For more information, refer to Email Settings (System Preferences) .

 From Name

 The sender's name that displays for the recipient. A default value can be set for all users in system preferences or on an individual basis in personal preferences.
