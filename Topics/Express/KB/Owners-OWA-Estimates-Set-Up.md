# Set Up Owner Estimates in Owner Web Access (OWA)

Source: https://rmxhelp.rentmanager.com/Topics/Express/KB/Owners-OWA-Estimates-Set-Up.htm

Estimates allow you to record the anticipated parts and labor needed to complete a project, itemize the costs, and provide a total amount due, including any markups and/or taxes you add. If you utilize Owner Web Access (OWA) , you can publish owner estimates directly to their portal, alert them that it is awaiting their review, and allow them to approve or reject the estimate within OWA.

 To enable estimates in Owner Web Access (OWA) , do the following:

 -
 Go to arrow_forward Administration , then go to Preferences arrow_forward System Web Preferences arrow_forward   Owner Web Access arrow_forward Estimates .

 -
 Select Show estimates .

 -
 To allow owners to view history/note items on estimates, check Include estimate History/Notes with the selected history categories and select each desired estimate-type history category that owners can view from the History Categories drop-down list.

 -
 Select Enable owner estimate approval and rejection .

 -
 Enter or select options in the following fields:

 Field
 Description

 Approval Confirmation Message

 A message that displays to the owner on the Approved confirmation pop-up after they sign off on the approval, such as Thank you. We will be in touch to discuss a start date.

 Approval Message

 The message that displays to an owner after they click Approve on an estimate prior to signing.

 Rejection Message

 When an owner rejects an estimate in OWA, a Comments box displays so that they may include information about why they chose to reject the estimate.

 Enter the message that you wish to display above the Comments box. For example, Please comment below to tell us why the estimate was rejected .

 Send notification to owner when estimate set to 'Awaiting Approval'

 Automatically sends an email notification to an owner when the Status of an estimate is set to Awaiting Approval .

 Regardless of whether or not this option is enabled, owners see a notification on their OWA dashboard upon logging in that a new estimate is available to review.

 More Information

 This requires the owner's email address be entered on the Miscellaneous tile of their account. For more information, refer to Owner Details (Page) .

 - Click Save .
Estimates are enabled in OWA and, if selected, notifications are sent to owners when estimates are awaiting their review.

 Next Steps

 Now that you have set up owner estimates in OWA, you are ready to start sending owner estimates for review. The recommended next steps are described in the table below.

 Notification
 Description

 Automated notifications

 With automated notifications, you can send alerts to a customized list of recipients when a certain set of conditions are met. For owner estimates in OWA, you can customize notifications to alert you when an estimate is approved or rejected from the portal.

 For more information, refer to Estimate Approved via OWA (Automated Notification) and Estimate Rejected via OWA (Automated Notification) .

 Publish estimates to OWA

 When creating estimates, ensure that owners are notified when they are waiting to be reviewed in OWA by setting the estimate's Status to Awaiting Approval .

 For more information, refer to Send Estimates for Approval .
