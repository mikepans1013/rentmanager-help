Set up Broadcast Service

With Phone Broadcasting and Text Broadcasting, you can send audio and text messages to owners, tenants, prospects, or vendors. Additionally, you can build Numbers Lists of phone numbers that make it easier to broadcast your messages to multiple recipients at once.

More Information

This feature is licensed and must be purchased separately. For more information, contact your sales representative at sales@rentmanager.com.

Set Up Phone Broadcasting

Related Privileges

Group Privilege Column
System System Preferences View, Edit

For more information, refer to Control User Access.

Once you receive the confirmation email containing your Phone Broadcasting user credentials, you can set up the feature in Rent Manager. To set up Phone Broadcasting, do the following:

  1. Go to  arrow_forward Administration, then go to Preferences arrow_forward System Preferences arrow_forward Phone Broadcast/Texting arrow_forward Phone Broadcast.

  2. In the Default Area Code field, enter the three-digit area code to use as the default for any imported phone numbers that do not have an area code.

  3. In the Username and Password fields, enter your Phone Broadcasting credentials from the confirmation email provided by LCS.

    More Information

    If you already have your broadcast credentials entered and you purchase another broadcast feature, you do not need to enter those credentials again. For example, if you have already purchased Phone Broadcasting and then purchase Text Broadcasting, you can use the same credentials.

  4. If applicable, check Use different credentials in other locations to require that different broadcast credentials be used in different Rent Manager locations. For example, if you use a different Rent Manager location for each property you manage and you want to use different login credentials for broadcasting from each property's location, use this option. For more information, refer to Manage Locations (Pop-Up).

  5. Click Save to save your changes.

  6. Click Test Settings to verify your connection to the phone broadcast server.
    Phone Broadcasting can now be performed by users with the applicable privileges. For more information, refer to Create a Phone Broadcast.

Set Up Text Broadcasting

Related Privileges

Group Privilege Column
System System Preferences View, Edit

For more information, refer to Control User Access.

Once you receive the confirmation email containing your Text Broadcasting user credentials, you can set up the feature in Rent Manager. To set up Text Broadcasting, do the following:

  1. Go to  arrow_forward Administration, then go to Preferences arrow_forward System Preferences arrow_forward Phone Broadcast/Texting arrow_forward Phone Broadcasting.

  2. In the Default Area Code field, enter the three-digit area code to use as the default for any imported phone numbers that do not have an area code.

  3. In the Username and Password fields, enter your credentials from the confirmation email provided by LCS.

    More Information

    If you already have your broadcast credentials entered and you purchase another broadcast feature, you do not need to enter those credentials again. For example, if you have already purchased Phone Broadcasting and then purchase Text Broadcasting, you can use the same credentials.

  4. If applicable, check Use different credentials in other locations to require that different broadcast credentials be used in different Rent Manager locations. For example, if you use a different Rent Manager location for each property you manage and you want to use different login credentials for broadcasting from each property's location, use this option. For more information, refer to Manage Locations (Pop-Up).

  5. Click Save.

  6. On the pop-up, enter a new password and click Save.
    The pop-up closes.

  7. Enter the newly created Password and click Save.

  8. Click Test Settings to verify your connection to the phone broadcast server.

  9. While still in system preferences, go to Phone Broadcasting/Texting arrow_forward Texting.

  10. Select one of the following options to determine the phone numbers that are used as the sender number when sending texts from Rent Manager. For more information, refer to Manage Text Numbers (Page).

    Option Description

    Use text numbers assigned to the property first, then use broadcast text numbers

    Uses the broadcast-enabled Text Numbers defined on the property's details page for the property that corresponds to each recipient in the broadcast.

    If these numbers reach their texting limit, another Broadcast text number that isn't assigned to the property is used instead.

    Use any broadcast text numbers

    Uses any available Broadcast text number to send text broadcasts.

    Use only text numbers assigned to the property

    Uses only the Text Numbers defined on the property's details page for the property that corresponds to each recipient in the broadcast.

    Warning

    Choosing this option may cause text broadcasts to fail if all the available property text numbers reach the per-day limit. Five numbers can be added to a broadcast account. Contact your sales representative at sales@rentmanager.com for information on adding more text numbers to your database.

  11. If applicable, check Show Texting Consent Disclaimer to display a message that explains to recipients what they agree to if they provide you with their phone number. Then, choose options in the following fields:

    Field Description

    Company Name

    Choose whether to use the name entered on the property management company's details page in the Name field or in the Billing Name field.

    Privacy Policy URL

    An optional URL that links to the text of your privacy policy.

    Terms of Service URL

    An optional URL that links to the text of your terms of service agreement.

  12. Click Save to save your changes.
    Text Broadcasting can now be performed by users with the applicable privileges. For more information, refer to Create a Text Broadcast.

    More Information

    The first text sent to a recipient from the text messaging center and any texts sent via text broadcast or automated notification include an opt-out message. If a recipient opts out, that phone number cannot receive texts from Rent Manager unless they choose to opt back in. Recipients can opt out or opt in at any time. If a recipient wishes to opt back into text messaging, they must text Start from the phone number they opted out with to the number they originally requested to opt out of.

    Phone numbers that have opted out of text messaging are identified on the account's View Contacts pop-up, where the checkbox in the T column is replaced with the words Opted out in red text.
