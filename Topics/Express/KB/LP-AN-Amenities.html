Automated Notifications for Amenities

Automated notifications allow you to send alerts to a customizable list of recipients when a certain set of conditions are met to help streamline your workflows and processes. These notifications can be customized using plain text and scripting for personalized text and/or email messages.

There are many options for automated notifications regarding amenities to inform you of reservations that require approval, are upcoming, have been canceled, or have been denied. These notifications are described in the table below.

Attention

Ensure the table is the full and current list of automated notifications related to amenities.

Notification Description

Amenity Reservation Approval Needed

Informs users (e.g., property managers) or external recipients when a reservable amenity request is submitted via Tenant Web Access (TWA) and is awaiting approval.

Amenity Reservation Canceled

Informs users, tenants, or external recipients when a reservable amenity request submitted via TWA is canceled by the submitting tenant.

Amenity Reservation Denied

Informs tenants when a reservable amenity request they submitted via TWA is declined.

Amenity Reservation Upcoming

Informs users or tenants when they have a reservable amenity request date approaching in TWA.
