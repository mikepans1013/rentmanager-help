Owner Web Access Automated Notifications

Automated notifications allow you to send alerts to a customizable list of recipients when a certain set of conditions are met to help streamline your workflows and processes. These notifications can be customized using plain text and scripting for personalized text and/or email messages.

There are many options for automated notifications regarding Owner Web Access (OWA) to inform you of approved and rejected estimates, aging estimates, and published documents.

Attention

Ensure the table is the full and current list of automated notifications related to Owner Web Access.

Notification Description

Document Published in OWA

Informs owners after a signable document is published to their OWA portal.

Estimate Approved via OWA

Informs users (e.g., sales representatives) or owners when an owner estimate is a certain number of days old and has not expired or been set to a status of Approved.

Estimate Rejected via OWA

Informs users (e.g., sales representatives) or owners when an owner estimate is a certain number of days old and has not expired or been set to a status of Rejected

OWA Webuser Locked Out

Informs users (e.g., property manager) when a owner's OWA web user account is locked out due to exceeding the number of incorrect password attempts established in system web preferences.

Owner Estimate Aging

Informs users (e.g., sales representatives) or owners when an owner estimate is a certain number of days old and has not expired or been set to a status of Approved or Rejected.

Owner Estimate Expiring

Informs users (e.g., sales representatives) or owners when a owner estimate is a certain number of days away from its expiration date.

Owner Makes Contribution in OWA

Informs users (e.g., property manager) when an a owner makes a makes a financial contribution via OWA.

Owner Prospect Signable Document Aging

Informs owner prospects when a signable document has been waiting on their signature for a set amount of time.

Owner Signable Document Aging

Informs owners when a signable document has been waiting on their signature for a set amount of time.
