Enable Automatic Screenings with Apply Now

If you use Apply Now and AmRent Screenings for prospects, you can set up Rent Manager to automatically submit a screening to AmRent when a prospect submits their application. Automatic screenings can be enabled for all applications in system web preferences, or be enabled for applications submitted using specific application templates.

More Information

Before you can generate automatic screenings, you must first enable Apply Now and AmRent Screenings in Rent Manager. You also need to set up ePay for any properties for which you want to run automatic screenings. For more information, refer to Set Up Apply Now Application Settings, Set Up AmRent Screenings, and Property ePay Settings (Pop-Up).

Enable Automatic Screenings in System Web Preferences

Related Privileges

Group Privilege Column
System System Web Preferences Enabled

For more information, refer to Control User Access.

To enable automatic screenings for all Apply Now applications, do the following:

  1. Go to arrow_forward Administration, then go to Preferences arrow_forward System Web Preferences arrow_forward Tenant Web Accessarrow_forward Apply Now arrow_forward General.

  2. Select Run screenings for online applications.

  3. In the Screening report type field, select the type of screening to be used for Apply Now applicants. For more information, refer to Types of Screening Reports.

  4. Click Save.
    AmRent Screenings are automatically generated for Apply Now applications.

    More Information

    Automatic screenings are not generated for submitted Apply Now applications if the Do not require payment for application to be submitted option is enabled. When payment is received, you must manually initiate a screening of the applicant(s).

Enable Automatic Screenings for Specific Application Templates

Related Privileges

Group Privilege Column
Tenants/Prospects Application Templates View, Edit

For more information, refer to Control User Access.

If there are specific application templates that need different settings than what is set in system web preferences or on the property-level application settings, you can override those settings at the application template level. Application-level settings apply only to the selected application template.

To override Apply Now settings at the application template level, do the following:

  1. Go to arrow_forward Rental Info arrow_forward Leasing arrow_forward Application Templates and select a template.
    The application template's details page displays.

  2. On the action bar to the right, click .
    The Application Template Settings pop-up displays.

  3. On the left, select Override System Web Preferences.

  4. In the Application Settings section, select Run screenings for online applications.

  5. In the Screening Report Type field, select the type of screening to be used for Apply Now applicants at this property. For more information, refer to Types of Screening Reports.

  6. Click Save.
    The application template's settings are saved, and applications submitted using this template automatically generate screenings.

    More Information

    Automatic screenings are not generated for Apply Now applications submitted using this template if the Do not require payment for application to be submitted option is enabled. When payment is received, you must manually initiate a screening of the applicant(s).
