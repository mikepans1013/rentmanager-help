Automated Notifications for Architectural Requests

Automated notifications allow you to send alerts to a customizable list of recipients when a certain set of conditions are met to help streamline your workflows and processes. These notifications can be customized using plain text and scripting for personalized text and/or email messages.

There are many options for automated notifications regarding architectural requests to inform you of updates and submissions for requests. These notifications are described in the table below.

Attention

Ensure the table is the full and current list of automated notifications related to architectural requests.

Notification Description

Architectural Request Aging

Informs users (e.g., property managers), board/committee members, or external recipients after a predetermined number of days if the request has not been voted on by board or committee members or its status updated to Approved or Denied in Rent Manager.

Architectural Request - New Message Received

Informs users (e.g., property managers), specific tenants, or external recipients when a user sends a message to the submitting tenant from the Architectural Request Detail pop-up or when a tenant sends a message on the request via Tenant Web Access (TWA).

Architectural Request - Status Changed

Informs users (e.g., property managers), board/committee members, specific tenants, or external recipients when the status of an architectural request is updated in Rent Manager.

Architectural Request Submitted

Informs users (e.g., property managers) or board/committee members when an association member submits a new architectural request.

Architectural Request Update via TWA

Informs users (e.g., property managers), board/committee members, or external recipients when a tenant makes a change to an architectural request in TWA.

Architectural Request Voting Complete

Informs users (e.g., property managers) or external recipients after the board or committee has finished voting on an architectural request.
