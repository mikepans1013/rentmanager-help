Add a Letter Template

Letter templates give users the ability to build completely customized letters that can be used as a way to share important information with their Rent Manager entities. From sending new tenant welcome letters to notifying residents of upcoming changes regarding their homes, letter templates are an efficient way to save you time when communicating what matters. Once you have created your letter templates, they may be easily distributed to their recipients via email or physically printing the letters.

Letter templates can be used to generate account-specific letters for any entity (e.g., tenants, owners, properties). For example, tenant-specific letter templates include insertable fields that are only applicable to tenants such as their current account balance. It can be then generated to inform a tenant of a past due balance can help you save time in collecting payments.

Step 1: Create the Template

To add a new letter template, do the following:

  1. Go to  arrow_forward Communication arrow_forward Letters arrow_forward Letter Templates.
    The LetterTemplates page displays.

  2. Click Add Template.
    The Select Template Type pop-up displays.

  3. Select a template Type from the drop-down list. This determines what types of insertable fields are available in the template and what entities the finished template can be generated for.

  4. Click OK.
    The letter template word processor displays.

Step 2: Write the Letter

To write a letter with your template, do the following:

  1. Write the body of the letter, including any headers, the purpose of the letter, and name of the person or property sending the letter.

  2. To include dynamic fields that pull in information from Rent Manager based on the recipient of the letter, click and drag fields from the Insertable Fields section on the left to populate template. It's best practice to write the entirety of the letter and then add insertable fields to replace the static text.

    More Information

    All insertable fields that display on a letter/email template are related to the template type. For example, the insertable fields that display on a tenant-type letter/email template are different from those that display on a unit-type template. For more information, refer to Scripting.

  3. To enable letters to be sent via the Virtual Post Office, check VPO Ready Template. For more information, refer to Virtual Post Office (VPO) (Page).

  4. To add signature block fields, check Signable Document. For more information, refer to Create a Signable Document Template.

More Information

When writing letter templates you can use keyboard shortcuts to perform common actions in the template editor. The following shortcuts are available:

Action Shortcut Keys

Bold

Press Ctrl+B to bold the selected text.

Italics

Press Ctrl+I to italicize the selected text.

Print

Press Ctrl+P to print the letter template from your local printer.

Save

Press Ctrl+S to save changes to the template in Rent Manager. When pressed in a new template for the first time, the Letter/Email Template Settings pop-up displays. For more information, refer to Letter/Email Template Settings (Pop-Up).

Underline

Press Crtl+U to underline the selected text.

Step 3: Save and Access the Letter Template

To save your new letter/email template, go to File arrow_forward Save. The template now displays on the Letter/Email Templates page, and, you can then give users access to use it.

To allow users to generate the template, return to the Letter/Email Templates page and click arrow_forward Settings next to the desired letter template. On the Edit Letter/Email Template Settings pop-up, in the Users section, enable the name of each user who needs access to the letter. Additionally, the user needs privileges to view the letter/email template in Rent Manager on their user account. For more information, refer to Control Letter / Email Template Access.

More Information

Custom letter/email templates can be imported from the Online Template Library, which is an ever-expanding collection of templates submitted by both Rent Manager users and LCS staff. Additionally, letters that you have already created and are stored on your local computer or network can be uploaded as a letter/email template into Rent Manager. For more information, refer to Online Template Library (Page).

Step 4: Next Steps

Once the desired settings are selected, you then can decide how the letters are generated and distributed to your Rent Manager entities. For example, you can go to the Tenants page to generate a letter for one tenant or use bulk actions to select multiple tenants and generate a letter for each tenant at the same time. From there you can send the letter through email to the primary tenant or contacts on the account, print the letter, send it through VPO, and chose to attach the letter to the account's history/notes. For more information on this process, refer to Generate and Distribute Letters from Templates.
