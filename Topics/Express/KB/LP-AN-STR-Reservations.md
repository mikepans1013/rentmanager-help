# Automated Notifications for STR Reservations

Source: https://rmxhelp.rentmanager.com/Topics/Express/KB/LP-AN-STR-Reservations.htm

Automated notifications allow you to send alerts to a customizable list of recipients when a certain set of conditions are met to help streamline your workflows and processes. These notifications can be customized using plain text and scripting for personalized text and/or email messages.

 There are many options for automated notifications regarding short-term rental (STR) reservations to inform you of updates, arrivals, and payments for reservations. These notifications are described in the table below.

 Attention

 Ensure the table is the full and current list of automated notifications related to STR reservations.

 Notification
 Description

 STR Reservation Added

 Informs users (e.g., property managers), guests, or external recipients when an STR reservation is created through Rent Manager or the Online Booking portal.

 STR Reservation Final Payment Made

 Informs guests when the final STR reservation payment is made.

 STR Reservation Payment Reminder

 Informs users (e.g., property managers), guests, or external recipients when an STR reservation payment is due within a selected number of days.

 STR Reservation Upcoming Arrival

 Informs guests when an STR reservation arrival is set to occur within a selected number of days.
