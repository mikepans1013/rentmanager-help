# Late Fee Posting Scripts

Source: https://rmxhelp.rentmanager.com/Topics/Express/KB/Script-Late-Fee-Posting.htm

When posting late fees, you can set up an automated notifications to be sent via email or text message. The communication sent can include additional information by using late fee posting scripting functions that pull data from the posted late fees directly into the body of the email or text you are sending via automated notifications.

 Available Functions

 From the Late Fee Posting automated notification, update the Email Body and Text Message fields to include the desired architectural request script functions from the table below.

 Function
 Description

 Comment

 [LateFee().Comment()]

 Displays the text entered in the Comment field when posting late fees.

 Create Date

 [LateFee().CreateDate()]

 Displays the date and time the late fee charge was created.

 Late Fee Amount

 [LateFee().LateFeeAmount()]

 Displays the date and time the late fee charge was created.

 Post Date

 [LateFee().PostDate()]

 Displays the date on the late fee charge.
