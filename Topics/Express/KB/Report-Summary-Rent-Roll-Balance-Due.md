# Summary Rent Roll and Balance Due

Source: https://rmxhelp.rentmanager.com/Topics/Express/KB/Report-Summary-Rent-Roll-Balance-Due.htm

Both the Summary Rent Roll and Balance Due provide tenant credit and debit balances. The Summary Rent Roll examines the overall balances value for a period of time as well as vacancy loss and loss to lease, while the Balance Due report displays current unpaid tenant transactions as of the report date.

 Warning

 The information contained here does not replace the advice of an accountant. If you are unclear about how to interpret the data presented in the related reports, please consult your accountant.

 The Summary Rent Roll report tracks transaction activity on tenant accounts over a specified period of time. You can examine held security deposits for each of these tenants, as well as vacancy loss and loss to lease totals. This report also provides a breakdown of totals for rent and non-rent charges, credits, prior balances, charges, payments, and credit and debit balances and is a good report to provide to your bank when they request to view your income.

 The Balance Due report displays the current amount of unpaid tenant, and, optionally, prospect transactions as of the report date. This report displays balance totals for each account, each property, and a total for all properties. You can use this report to quickly review tenants that need to be sent notices for payment or prospects that have not paid their application fees.

 Troubleshooting Balances that are Different

 While running the reports with the suggested report options above allows the reports to examine the same data, there are other factors that can cause discrepancies between these value totals.

 Current Tenants Only

 Selecting Current tenants only as the Report Method option for the Summary Rent Roll could cause a discrepancy between the reports. A current tenant according to the Summary Rent Roll is any tenant that occupied the unit at any point during the reporting period. A current tenant according to the Balance Due report is any tenant that occupied the unit as of the report date. If you run both reports for current tenants using a full month, but a tenant moved out during the month, the tenant is included on the Summary Rent Roll but not on the Balance Due report.

 Only Activity in the Period

 Selecting Only activity in the period as the Report Method option for the Summary Rent Roll report could cause a discrepancy between the reports. Tenants without activity (charges or payments) during the report are not included on the Summary Rent Roll , even if they have an account balance, however they are included on the Balance Due report.

 Prospect Balances

 The Balance Due report has the Prospects to Include option which adds prospect transactions into the generated report data. The Summary Rent Roll report examines only tenant transactions. If the Prospects to Include option is enabled, the two reports are not looking at the same data and therefore may show discrepancies.

 Short-Term Rental Property Types

 The Balance Due report includes information from properties with a Property Type set to Short Term Rental and those set to RV/Campground , however the Summary Rent Roll does not include these property types. This can lead to additional information or amount shown on the Balance Due that does not display on the Summary Rent Roll .
