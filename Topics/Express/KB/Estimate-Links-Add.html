Add Links to an Estimate

After you have created and saved an estimate, the Links tile displays in the top right of the estimate's details page. This provides an efficient way to automatically create purchase orders, invoices, and/or service issues with the data supplied on the estimate.

Add a Purchase Order Link

Related Privileges

Group Privilege Column
POs/Estimates Estimates View, Edit
Purchase Orders Add, View
View estimates from all users Enabled
History Estimate History/Notes Add

For more information, refer to Control User Access.

Links can be used to create purchase orders (POs) if you need to order inventory or if you are planning to charge a tenant or owner.

To add a PO link, do the following:

  1. Go to  arrow_forward Receivables arrow_forward General arrow_forward Estimates and select an estimate from the list.
    The Estimate details page displays.

  2. On the Links tile, click Add Purchase Order Link.
    The Create A Link pop-up displays.

  3. Click Yes.
    The Create a Link pop-up displays.

  4. In the Vendor field, select the company or contractor providing the inventory items in the PO. If this is a tenant estimate and the tenant has multiple leases, select the Lease associated with this PO.

  5. Click Save.
    The newly-generated PO link is added to the Links tile and a note is added to the estimate's History/Notes pop-up.

Add an Invoice Link

Related Privileges

Group Privilege Column
POs/Estimates Estimates Add, View
View estimates from all users Enabled
Sales/Invoicing Invoices Add, View
History Estimate History/Notes Add

For more information, refer to Control User Access.

Links can be used to create invoices to bill tenants and owners for products and services.

To add an invoice link, do the following:

  1. Go to  arrow_forward Receivables arrow_forward General arrow_forward Estimates and select an estimate from the list.
    The Estimate details page displays.

  2. On the Links tile, click Add Invoice Link.
    The Create a Link pop-up displays.

  3. Click Yes.

  4. If this is a tenant estimate and the tenant has multiple leases, select the desired Lease associated with the invoice.

  5. Click Save.
    The newly generated invoice link is added to the Links tile and a note is added to the estimate's History/Notes pop-up.

Add a Service Issue Link

Related Privileges

Group Privilege Column
POs/Estimates Estimates Add, View
View estimates from all users Enabled
Service Manager Issues Add, View

For more information, refer to Control User Access.

Links can be used to create service issues with item allocations to the associated property and unit. If the estimate is a tenant estimate, you can also link the service issue to the tenant.

To add an issue link, do the following:

  1. Go to  arrow_forward Receivables arrow_forward General arrow_forward Estimates and select an estimate from the list.
    The Estimate details page displays.

  2. On the Links tile, click Add Service Issue Link.
    The Create A Link pop-up displays.

  3. Click Yes.
    The newly-generated issue link is added to the Links tile and a note is added to the estimate's History/Notes pop-up. Additionally, the linked issue is generated for the tenant and added to the Issues page. The issue title indicates the issue was generated from an estimate (e.g., Work order from estimate #9).
