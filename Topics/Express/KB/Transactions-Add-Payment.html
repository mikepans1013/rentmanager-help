Add a Payment

To account for the many reasons you need to handle payments in your business, Rent Manager offers two solutions for entering tenant and prospect payments. The payment function in Rent Manager allows you to enter one payment to cover open tenant or prospect charges or partial payments to address multiple open charges.

Related Privileges

Group Privilege Column
Tenants/Prospects Tenants View
Prospects View
Receivables Take tenant payments Enabled

For more information, refer to Control User Access.

To enter payments made by tenants or prospects, go to arrow_forward Receivables arrow_forward Payments arrow_forward Receive Payment.

Option 1: Enter a Payment

When a tenant or prospect only has one open charge that needs to be paid, such as monthly rent charge for a tenant or a security deposit for a prospect, the payment can be applied directly to the charge. The same process can also be used if the tenant or prospect presents you with multiple payments to address separate open charges.

To enter a single payment, do the following:

  1. At the top, in the Tenant field, enter the name, unit, or account number of the tenant or prospect account from whom you are receiving the payment. Additionally, filter the results that populate in the Tenant field by using the following fields:

    Field Description

    Properties

    Limit the results in the Tenant field to display only tenants and/or prospects at the selected properties.

    Status

    Limit the results in the Tenant field to display only tenants and/or prospects with the selected account status(es). Prospects display only if the Prospect option is checked in this field.

  2. In the Payment Info section, enter the information about your payment.

    Option Description

    Date

    The date the tenant or prospect is making the payment.

    Reference #

    The following forms of payment to describe the transaction are available to select.

    More Information

    If, in the Payment Summary section, the Process via ePay option is selected, this field displays ePay and cannot be edited.

    Cash

    Record a CashPay payment.

    MO

    Record a money order payment.

    CC

    Record a credit card payment.

    Check

    Manually type the check number into the Reference # field to record a check payment.

    Amount

    The full dollar amount of the payment received.

    Memo

    A brief comment about this payment, such as how it was applied. Payment memos display in the Comment column of the prospect or tenant's View Transactions pop-up.

  3. In the Open Charges section, verify that the Current Payment amount entered is correct. If the payment does not cover all open charges, in the list of open charges, check the Pay? box next to the open charge to which to apply this payment.

  4. In the New Late Fees column, verify the late fee amount is correct or enter the desired late fee amount for each charge. This column displays only if any daily (or per-day) late fees have accumulated for the open charges based on the date the charge was posted and the payment's Transaction Date.

  5. In the Payment Summary section, select additional payment options and verify the payment is being applied appropriately.

    Field Description

    View Receipt

    Check to print a receipt for the prospect or tenant after accepting the payment.

    Process via ePay

    Check to process the payment as an ePay payment. This option is available only if the account's associated property is set up for ePay. For more information, refer to Set Up ePay for Tenants and Prospects.

    When this option is checked, the Reference # field is automatically updated to ePay and cannot be edited.

    Payment Notes

    Any history/note items with the Show on payments tab option enabled display. If there are no items with this option checked, this field does not display. For more information, refer to Tenant History/Notes (Pop-Up) and Prospect History/Notes (Pop-Up).

    Original Amount

    The total dollar amount of all open tenant charges before any partial payments are applied.

    Amount Paid

    If partial payments are allocated to any charges, the total dollar amount of those partial payments displays.

    Amount Due

    If applicable, the total dollar amount due for all open tenant charges after any partial payments are applied.

    Current Payment

    The total dollar amount of the payment as entered in the Payment Info section in the Amount field.

    Overpayment

    If the amount of the payment exceeds the total Amount Due, the exceeded amount displays. This field displays only when making a payment for a positive amount. The overpaid amount can then be applied as prepay allocations in the Prepay Allocations pop-up or left to be applied as a credit at a later time.

    Overpayment = Amount - Amount Due

  6. Click Add Payment.
    The payment is recorded for the prospect or tenant.

    More Information

    If a tenant or prospect comes to you with multiple payments for their account, you can use Rent Manager to record each payment to reflect how the payments were deposited in real life. To do this, use the same process to enter a single payment for as many payments you received.

    For example, if a tenant gives you three checks to cover three separate open charges, enter each check for each payment, one at a time.

Option 2: Enter a Partial Payment

When a tenant or prospect has multiple open charges that need to be addressed with a single payment, partial payments can be used to handle the charges. When you receive the payment, you can apply partial payments to multiple charges at once.

To enter a partial payment, do the following:

  1. At the top, in the Tenant field, enter the name, unit, or account number of the tenant or prospect account from whom you are receiving the payment. Additionally, filter the results that populate in the Tenant field by using the following fields:

    Field Description

    Properties

    Limit the results in the Tenant field to display only tenants and/or prospects at the selected properties.

    Status

    Limit the results in the Tenant field to display only tenants and/or prospects with the selected account status(es). Prospects display only if the Prospect option is checked in this field.

  2. In the Payment Info tile, enter the information about your payment.

    Option Description

    Date

    The date the tenant or prospect is making the payment.

    Reference #

    The following forms of payment to describe the transaction are available to select.

    More Information

    If, in the Payment Summary section, the Process via ePay option is selected, this field displays ePay and cannot be edited.

    Cash

    Record a CashPay payment.

    MO

    Record a money order payment.

    CC

    Record a credit card payment.

    Check

    Manually type the check number into the Reference # field to record a check payment.

    Amount

    The full dollar amount of the payment received.

    Memo

    A brief comment about this payment, such as how it was applied. Payment memos display in the Comment column of the prospect or tenant's View Transactions pop-up.

  3. In the Open Charges tile, check the box in the Pay? column header to automatically apply the payment toward each charge that can be covered by the entered Amount, starting with the oldest.

  4. Adjust the Current Payment amount for each charge so that the payment is applied as desired.

  5. In the Payment Summary tile, select additional payment options and verify the payment is being applied appropriately.

    Field Description

    View Receipt

    Check to print a receipt for the prospect or tenant after accepting the payment.

    Process via ePay

    Check to process the payment as an ePay payment. This option is available only if the account's associated property is set up for ePay. For more information, refer to Tenant ePay Settings (Pop-Up).

    When this option is checked, the Reference # field is automatically updated to ePay and cannot be edited.

    Payment Notes

    Any history/note items with the Show on payments tab option enabled display. If there are no items with this option checked, this field does not display. For more information, refer to Tenant History/Notes (Pop-Up) and Prospect History/Notes (Pop-Up).

    Original Amount

    The total dollar amount of all open tenant charges before any partial payments are applied.

    Amount Paid

    If partial payments are allocated to any charges, the total dollar amount of those partial payments displays.

    Amount Due

    If applicable, the total dollar amount due for all open tenant charges after any partial payments are applied.

    Current Payment

    The total dollar amount of the payment as entered in the Payment Info section in the Amount field.

    Overpayment

    If the amount of the payment exceeds the total Amount Due, the exceeded amount displays. This field displays only when making a payment for a positive amount. The overpaid amount can then be applied as prepay allocations in the Prepay Allocations pop-up or left to be applied as a credit at a later time.

    Overpayment = Amount - Amount Due

    More Information

    If a prepayment or an overpayment is added, the Prepay Unit field displays on the payment's details page, indicating the unit the allocations are associated with.

  6. Click Add Payment.
    The partial payment is recorded for the prospect or tenant.
