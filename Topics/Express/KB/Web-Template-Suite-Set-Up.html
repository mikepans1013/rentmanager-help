Set Up Web Template Suite

Web Template Suite makes it easy to develop websites for your properties and management companies, with little to no experience in web development needed. You can enable Web Template Suite to access Site Manager, the admin tool that lets you control the design and user experience of your website, including which feature integrations are available on your site.

More Information

This feature is licensed and must be purchased separately. For more information, contact your sales representative at sales@rentmanager.com.

Step 1: Give Users Access to Web Template Suite in Rent Manager

Related Privileges

Group Privilege Column
System System Web Preferences Enabled

For more information, refer to Control User Access.

Once you receive the confirmation email containing your Web Template Suite domain name, you can view your default website by going to YourCompanyCode.sitemanager.rentmanager.com. The company code is unique to each company that uses Rent Manager and can be found in the top right corner of your Rent Manager database.

To enable access to Site Manager from Rent Manager, do the following:

  1. Go to  arrow_forward  Administration, then go to Preferences arrow_forward System Web Preferences arrow_forward Web Template Suite arrow_forward General.

  2. Select the Rent Manager users who you want to have access to Site Manager.

  3. Click Save.
    The users you select can now access and make changes to the website with Site Manager.

Step 2: Log in to Site Manager

Any user with access can log in to Site Manager. To log in to Site Manager, do the following:

  1. Go to YourCompanyCode.sitemanager.rentmanager.com/Login.aspx.

  2. Enter your Rent Manager credentials and complete the initial Web Template Suite setup by following the instructions.
    You can now make updates to your website.
