Print Checks on QuickBooks Check Stock

In Rent Manager, the system preference to print checks on QuickBooks check stock allows users to easily manage their financial transactions by aligning Rent Manager-generated checks with the QuickBooks check layout. This feature is designed for businesses that utilize pre-printed QuickBooks-compatible check stock, ensuring a smooth transition for those familiar with QuickBooks while taking advantage of Rent Manager's robust rent management capabilities. Setting up this preference ensures checks are printed accurately, making accounting processes seamless and minimizing the risk of errors.

More Information

This feature is licensed and must be purchased separately. For more information, contact your sales representative at sales@rentmanager.com.

Enable Printing Checks in QuickBbooks Format

Related Privileges

Group Privilege Column
Banks/Checks Print checks Enabled

For more information, refer to Control User Access.

Once you have received confirmation that the feature has been enabled in your database, a system preference is added for you to enable the feature in Rent Manager. To enable the Print checks in QuickBbooks format feature, do the following:

  1. Go to  arrow_forward  Administration arrow_forward System Preferences arrow_forward Report Options arrow_forward Check Printing.

  2. Select Print checks in QuickBooks format.

  3. Click Save.
    The setting is saved and you can print on QuickBooks stock when printing checks from Rent Manager using the Print Checks page.

Next Steps

Once you've enable the Print checks in QuickBooks format system preference, you can print on QuickBooks stock when using the Print Checks page. For more information, refer to Print Checks.
