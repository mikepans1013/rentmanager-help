Customize Vendor Options

When you create or edit a vendor in Rent Manager, you can enter values into vendor-type user defined fields (UDFs), select the properties where the vendor is available, and establish default bill terms and expense accounts for the vendor. Although you can complete the vendor add wizard without this information, creating any UDFs, bill terms, and expense accounts the vendor may need before adding your vendor helps streamline the vendor creation process.

Properties

Related Privileges

Group Privilege Column
Properties/Units Properties Add, View

For more information, refer to Control User Access.

In Rent Manager, each property is its own financial entity that can use different vendors depending on the area, services needed, or other reasons. You can assign vendors to the properties where they provide services, making them available when recording services or payments associated with those properties. For more information on creating properties, refer to Add a Property.

Bill Terms

Related Privileges

Group Privilege Column
Payables Bill terms Add, View

For more information, refer to Control User Access.

Vendor bills often have a set date or time period before payment is due. You can create bill terms to establish these time periods and select one as the default bill term for each vendor when creating bills for that vendor. For more information, refer to Add a Bill Terms.

Expense Accounts

Related Privileges

Group Privilege Column
Accounting General ledger accounts Add, View

For more information, refer to Control User Access.

Many vendors offer specialized services that are always applied to the same general ledger (GL) expense account. Rent Manager allows you to select a default GL expense account to use when adding line items to checks, bills, and so on for each vendor. For more information, refer to Add a General Ledger Account.

Vendor User-Defined Fields

Related Privileges

Group Privilege Column
User Defined Fields User defined fields Add, View

For more information, refer to Control User Access.

User defined fields (UDFs) are custom fields you create to track data that Rent Manager does not track by default. Vendor-type UDFs are used specifically to track additional information on vendor accounts. For more information on creating vendor-type UDFs, refer to Add a User Defined Field.
