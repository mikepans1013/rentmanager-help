# Architectural Request Scripts

Source: https://rmxhelp.rentmanager.com/Topics/Express/KB/Script-Architectural-Request.htm

There are several automated notifications which can be configured to send an email or text message when an architectural request is submitted via Tenant Web Access (TWA) or updated. Architectural request scripting functions allow you to pull data entered in Rent Manager or Tenant Web Access directly into the body of the email or text you are sending via automated notifications.

 Available Functions

 From an architectural request automated notification, update the Email Body and Text Message fields to include the desired architectural request script functions from the table below.

 Function
 Description

 Comments

 [Comments]

 Any comments entered with the most recent status change to the architectural request.

 Create Date

 [CreateDate]

 The date on which the architectural request was created.

 Description

 [Description]

 The details entered in the Description field of the architectural request.

 Request

 [Request]

 The details entered in the Request field of the architectural request.

 Status

 [Status]

 The current status of the architectural request.

 Tenant First Name

 [TenantFirstName]

 The first name of the tenant making the architectural request.

 Tenant Last Name

 [TenantLastName]

 The last name of the tenant making the architectural request.

 Web User Email Address

 [WebUserEmailAddress]

 The email address associated with the Tenant Web Access account of the tenant who submitted the architectural request.

 Web User First Name

 [WebUserFirstName]

 The first name associated with the Tenant Web Access account of the tenant who submitted the architectural request.

 Web User Last Name

 [WebUserLastName]

 The last name associated with the Tenant Web Access account of the tenant who submitted the architectural request.
