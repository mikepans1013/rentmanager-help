# Limit Vendor Access

Source: https://rmxhelp.rentmanager.com/Topics/Express/KB/Vendor-Limit-Access.htm

Similarly to limiting user access to only properties a user is required to view, granting vendors access to only the properties they work with can help you save time when contacting vendors to complete a job. For example, when you create a service issue in which a vendor is involved, Rent Manager populates only the vendors that are assigned to the property for the issue. Vendor property access can be managed from the vendor's details page or from the Add Vendor wizard when adding a new vendor to Rent Manager .

 When modifying vendor access to properties, only vendors that are assigned to properties to which you have access display, even if <All Properties> is selected on the vendor's details page. Your access to properties can be managed from your user account or on the property's details page. For more information, refer to Limit Access to a Property .

 More Information

 When entering bills for a vendor, only bills at properties to which the user has access display. To prevent a user thinking a vendor is not represented in the database and the creation of duplicate vendors, link vendors to all properties that they could be associated with.

 When creating a new vendor in Rent Manager , you can establish which properties they are associated with using the Add Vendor wizard. To select which properties are associated with a vendor, do the following:

 -
 Go to arrow_forward Payables arrow_forward General arrow_forward Vendors and click Add Vendor .
The Add Vendor wizard displays.

 -
 In the General Information tile, click the drop-down arrow in the Associated property field.

 -
 Check the name of the properties that should be associated with the vendor.

 -
 After completing the rest of the wizard, click Save and Finish to close the pop-up or Save and New to continuing adding vendors.
This vendor is now associated with the properties you have selected.

 Limiting a vendor's access to certain properties can also help you save time by only have the appropriate vendors available to be selected. This reduces the risk of making a mistake when selecting vendors for job. To select which properties are associated with a vendor, do the following:

 -
 Go to arrow_forward Payables arrow_forward General arrow_forward Vendors and select a vendor from the list.
The vendor's details page displays.

 -
 On the General tile, click the drop-down arrow in the Associated Properties field.

 -
 Check the name of the properties that should be associated with the vendor.

 -
 Click Save to confirm your changes.
This vendor is now associated with the properties you have selected.
