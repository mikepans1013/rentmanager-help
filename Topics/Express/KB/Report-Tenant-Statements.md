# Tenant Statements

Source: https://rmxhelp.rentmanager.com/Topics/Express/KB/Report-Tenant-Statements.htm

All tenant statements in Rent Manager display tenant transaction history over a specified date range and provide information about the totals for charges, credits, and the current balance due. However, each statement offers unique formatting or features that distinguish it from the others. Many users may find that the Statement - 8.5x11 provides all the details they need. Others may prefer the Statement (Option 2) , as it provides nearly all the same information but with more modernized formatting. Some business may print on legal size paper in their office, and so choose to use the Statement - 8.5x14 Mailer . The variety of statement options available in Rent Manager ensures that all users can generate high-quality reports that meet their business needs.

 This topic provides an overview of each tenant statement to assist you in deciding which option(s) to use.

 Report
 Description

 Post Card Statement - 4x6

 This statement is formatted to fit three records per page on postcard-sized 4x6 sections, which allows you to provide a compact record of a tenant's transactional history. Because of the smaller size, the content displayed in this statement is more limited. For example, it cannot display unposted per day late fees or information about daily interest loans. However, all charge and payment data is displayed, either in a summarized way on a single card, or in full detail spread across multiple postcards.

 This statement would be ideal for users who print their statements, aiming to make the most efficient use of their printer paper, or those who prefer the most concise summary of statement data. For more information, refer to Tenant Post Card Statement - 4x6, 3 per page (Report)

 Statement - 8.5x11

 This statement displays transaction information for selected tenants across a date range and provides information about the totals for charges, credits, and the current balance due. It can be mailed to tenants at the end of each billing period and fits on an 8.5x11 sheet of paper when printed. It includes a mailing address header and a section for personalized comments.

 Most other statement options use the Statement - 8.5x11 as a starting point. It is highly flexible and can be configured to display any statement data (aside from Zego Lockbox information). As a result, this report can used by most users for their basic tenant statement needs. For more information, refer to Tenant Statement 8.5x11 (Report)

 Statement - 8.5x14 Mailer

 This statement is formatted to fit on a legal-size 8.5x14 sheet of paper when printed, which allows extra room for a tenant's transaction history compared to the Statement - 8.5x11 .

 Users who primarily print on legal-size paper can use this report to generate appropriately sized statements. For more information, refer to Tenant Statement - 8.5x14 Mailer (Report) .

 Statement (Option 2)

 This statement generates information similar to the Statement - 8.5x11 but has a different visual presentation allowing for color in the text, section dividers, logo images, and more. This statement omits information on tenants' Unit Type and lacks a Reference column for transactions, but displays all other relevant statement data.

 Users looking for a statement with modernized formatting may find Statement (Option 2) ideal. For more information, refer to Statement (Option 2 Report) .

 Statement (Option 2) - Lockbox

 This statement matches the content and formatting found in Statement (Option 2) , but also displays Zego Lockbox information. To ensure that Lockbox payments process correctly, the Statement (Option 2) - Lockbox includes a system-generated QR code that provides Lockbox information and unique code that tenants add on the memo line of their checks.

 This statement is best suited to users who have Zego Lockbox and prefer the formatting of Statement (Option 2) . For more information, refer to Statement (Option 2) - Lockbox (Report) .

 Statement with MU Info

 This statement matches the content and formatting the Statement - 8.5x11 , but always includes metered utility charge details in the statement's transaction history section. Users who routinely post Metered Utilities in Rent Manager can use this statement to ensure that meter reading and usage information is always included in tenant statements.

 More Information

 To access this statement, you must import it from the online template library (OTL). For more information, refer to Online Template Library (Page) .

 Tenant Statement with Zego Lockbox

 This statement has similar formatting to the Statement - 8.5x11 , but also displays Zego Lockbox information. To ensure that Lockbox payments process correctly, the Tenant Statement with Zego Lockbox includes a system-generated QR code that provides Lockbox information and unique code that tenants add on the memo line of their checks. Unlike the Statement - 8.5x11 , this statement omits the Property , Unit , Type , Account Number , Previous Balance , and Last Payment fields.

 This statement is ideal for users who utilize Zego Lockbox and prefer a streamlined version of the Statement - 8.5x11 .

 More Information

 To access this statement, you must import it from the online template library (OTL). For more information, refer to Online Template Library (Page) .
