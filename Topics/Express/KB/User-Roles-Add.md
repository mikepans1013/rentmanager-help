# Add a User Role

Source: https://rmxhelp.rentmanager.com/Topics/Express/KB/User-Roles-Add.htm

Creating user roles is a convenient way to group privileges for activities common to people in the same or similar jobs. For example, you can create a role for your accountants and select a set of privileges that reflect the needs of your accountants. Changing the privileges associated with a user role automatically updates the privileges of each user assigned to that role.

 Step 1: Create a User Role

 To create a new user role, do the following:

 -
 Go to arrow_forward Administration , then go to Users arrow_forward User Roles .
The User Role page displays.

 -
 On the action bar to the right, click .
The Add User Role pop-up displays.

 -
 In the Role Name field, enter a unique descriptor for the user role (e.g., Administrator , Front Office ).

 -
 To create the role with the privileges of an existing user or user role, in the Copy permissions from existing user or role , select the user or role whose privileges you wish to use.

 -
 Click Save .
The user role is created.

 Step 2: Assign Users

 To assign users to the role, do the following:

 -
 Select the newly created user role from the list on the left.
The role's General tab displays.

 -
 On the Users tile, click .
The Add Users pop-up displays.

 -
 Select the user(s) to be assigned the role.

 -
 Click Save .
The Add Users pop-up closes and the selected user(s) are listed on the Users tile.

 -
 Click Save .
The selected user(s) are assigned to the user role.

 Step 3: Customize Role Privileges

 To customize the privileges, reports, and letters available to this role, do the following:

 -
 From the user role's General tab, select the Privileges tab.

 -
 Enable the desired privileges for users assigned to this role. For more information, refer to Control User Access .

 More Information

 Privileges assigned to a user's role cannot be removed from the individual user account's Privileges tab, but additional privileges can be added or removed.

 -
 Click Save .
The selected privileges are enabled for users assigned to the role.

 -
 Select the Reports tab.

 -
 Select the Rent Manager reports and Report Writer (RW) reports available to users assigned to this role. For more information, refer to Control Custom Report Access .

 -
 Click Save .
The selected reports can be generated by users assigned to the role.

 -
 Select the Communication tab.

 -
 Select the letter templates, signable templates, and document packets available to users assigned to this role. For more information, refer to Control Letter / Email Template Access .

 -
 Click Save .
The selected templates and/or packets can be distributed by users assigned to the role.
