# Customize Your Tenant Web Access (TWA) Portal

Source: https://rmxhelp.rentmanager.com/Topics/Express/KB/LP-TWA-Customize-Portal.htm

You can customize the Tenant Web Access (TWA) web portal to determine the tools and pages are visible and accessible to your tenants. in order to best match your business or industry practices. Customization of TWA is done in system web preferences.

 Customize Your Tenant Web Access Portal Appearance

 Your Tenant Web Access portal appearance can be customized with the following tabs under Tenant Web Access in system web preferences:

 Page
 Description

 General

 Allows you to customize the TWA login page, including creating login messages and setting login restrictions. For more information, refer to Tenant Web Access General (System Web Preferences) .

 Prospects

 Allows you to set default messages to show to prospects who are using TWA. For more information, refer to Tenant Web Access Prospects (System Web Preferences) .

 Page Setup - Dashboard

 Allows you to select and manage which tiles you wish to display on the TWA dashboard. For more information refer to Tenant Web Access Dashboard Page Setup (System Web Preferences) .

 Page Setup - General

 Allows you to customize the TWA portal title. For more information, refer to Tenant Web Access General Page Setup (System Web Preferences) .

 Style - Color Theme

 Allows you to change the TWA web page colors. For more information, refer to Tenant Web Access Color Theme (System Web Preferences) .

 Style - Site Header

 Allows you to change the TWA web page header image and color from the system default. For more information, refer to Tenant Web Access Site Header (System Web Preferences) .

 Customize Tenant Web Access Pages

 Located under the Page Setup tab in system web preferences, the following options allow you to customize the Tenant Web Access portal page to include or exclude a variety of tools and functions that  Rent Manager offers.

 Recommended Pages

 These pages and tiles, while not required, are highly recommended for most business or industry practices:

 Page
 Description

 Charges

 Determines if a tenant's open charges can be viewed. For more information, refer to Tenant Web Access Charges Page Setup (System Web Preferences) .

 Documents

 Determines if documents uploaded to the tenant's associated property display. For more information, refer to Tenant Web Access Documents Page Setup (System Web Preferences) .

 Leases

 Determines if a tenant's associated leases can be viewed. For more information, refer to Tenant Web Access Leases Page Setup (System Web Preferences) .

 Make a Payment

 Determines if a tenant can make payments online via the TWA portal. For more information, refer to Tenant Web Access Make a Payment Page Setup (System Web Preferences) .

 Message Board

 Determines if the message board, a method for Tenant Web Access users to leave comments or questions directly, can be viewed. For more information, refer to Tenant Web Access Message Board Page Setup (System Web Preferences) .

 Notes

 Determines if a tenant's associated history/note items can be viewed. For more information, refer to Tenant Web Access Notes Page Setup (System Web Preferences) .

 Reports

 Determines if reports published to TWA can be viewed for association-type properties. For more information, refer to Tenant Web Access Reports Page Setup (System Web Preferences) .

 Service Issues

 Determines if a tenant's associated issues can be viewed. For more information, refer to Tenant Web Access Service Issues Page Setup (System Web Preferences) .

 Transactions

 Determines if a tenant's transaction history can be viewed. For more information, refer to Tenant Web Access Transactions Page Setup (System Web Preferences) .

 Additional Pages

 These pages and tiles may be useful depending on your business or industry practices:

 Page
 Description

 Amenity Reservations

 Determines if a tenant can make reservations for reservable amenities. For more information, refer to Tenant Web Access Amenity Reservations Page Setup (System Web Preferences) .

 Applications

 Determines if Tenant Web Access users can fill out applications in the portal. For more information, refer to Tenant Web Access Applications Page Setup (System Web Preferences) .

 Architectural Requests

 Determines if a tenant can submit requests to their association to make external changes to their home. For more information, refer to Tenant Web Access Architectural Requests Page Setup (System Web Preferences) .

 Community Calendar

 Determines if a tenant can view the community calendar. For more information, refer to Tenant Web Access Community Calendar Page Setup (System Web Preferences) .

 Community Directory

 Determines if a tenant can access the community directory, where they can add their contact information and access other tenants' contact information at the property. For more information, refer to Tenant Web Access Community Directory Page Setup (System Web Preferences) .

 Documents to Sign

 Determines if a tenant's associated signable documents can be viewed and signed. For more information, refer to Tenant Web Access Documents to Sign Page Setup (System Web Preferences) .

 Metered Utilities

 Determines if a tenant can view the meter readings associated with the unit they are occupying. For more information, refer to Tenant Web Access Metered Utilities Page Setup (System Web Preferences) .

 Polls

 Customizes how surveys and polls displays. This page automatically displays in Tenant Web Access when a survey or poll is published and is still ongoing. For more information, refer to Tenant Web Access Polls Page Setup (System Web Preferences) .

 Violations

 Determines if a tenant's associated violation history can be viewed. For more information, refer to Tenant Web Access Violations Page Setup (System Web Preferences) .

 Zego Statements

 Determines if a tenant's billing statements generated from Zego Resident Billing display. For more information, refer to Tenant Web Access Zego Statements Page Setup (System Web Preferences) .
