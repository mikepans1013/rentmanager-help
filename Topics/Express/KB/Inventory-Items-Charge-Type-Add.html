Add Charge Types to Inventory Items

All inventory items must be linked to a charge type in order to recover the cost of those items. These items can be linked to charge types either from the item itself or by assigning the items directly from the charge type. You can enable tracking for an inventory item by going to the inventory item's details page and, on the Inventory tile, enabling Track Inventory.

Link an Inventory Item to a Charge Type

When you add a new inventory item and need to set the charge type for the first time, or an existing inventory item needs to have their charge type updated, you can update this information directly from the inventory item's details page.

Related Privileges

Group Privilege Column
Sales/Invoicing Items View, Edit

For more information, refer to Control User Access.

To assign an inventory item to a charge type, do the following:

  1. Go to arrow_forward Accounting arrow_forward General arrow_forward Inventory Items and select an inventory item from the list.
    The inventory item's details page displays.

  2. On the Account Links tile, select the Income Charge Type. This determines the income account that collects the money received from the sales of your inventory items.

  3. Select the Expense Chart Account used when this inventory item is purchased.

  4. Click Save.
    The inventory item is now linked to the charge type.

Link Multiple Inventory Items to a Charge Type

When adding a number of inventory items or multiple inventory items need their charge type updated at once, you can link multiple inventory items to a charge type at the same time by going to the charge type's details page.

Related Privileges

Group Privilege Column
Accounting Charge types View, Edit
Sales/Invoicing Items View, Edit

For more information, refer to Control User Access.

To assign inventory items to a charge type, do the following:

  1. Go to arrow_forward Accounting arrow_forward General arrow_forward Charge Types and select a charge type from the list.
    The charge type's details page displays.

  2. In the Inventory Items section, click arrow_forward Link Existing Inventory Items.
    The Select Inventory Items pop-up displays.

  3. In the Available column on the left, check any inventory items you wish to link to the charge type. The selected items appear in the Selected column on the right. Uncheck them to remove the inventory item.

  4. Optionally, check Show Inactive Items to display any inventory items that are not marked as active.

  5. Click Save.
    The selected inventory items are now linked to the charge type.
